answer: "หมอกควันข้ามพรมแดนในมาเลเซียส่วนใหญ่มีต้นเหตุจากไฟไหม้พื้นดินและป่า โดยเฉพาะไฟไหม้พื้นที่พรุและการเปิดพื้นที่ด้วยการเผา ในสุมาตราและกาลีมันตัน อินโดนีเซีย ซึ่งเลวร้ายลงในช่วงฤดูแล้งเอลนีโญ กรมสิ่งแวดล้อม (DOE) วัดคุณภาพอากาศผ่านดัชนีมลพิษทางอากาศ (API) ค่า 101–200 ถือว่า 'ไม่ดีต่อสุขภาพ' และโรงเรียนมักปิดตาม SOP เมื่อ API ถึง 200 มาเลเซียยังไม่ได้ตราพระราชบัญญัติหมอกควันข้ามพรมแดนของตนเอง (พระราชบัญญัติปี 2014 ที่มักถูกอ้างถึงนั้นเป็นของสิงคโปร์) แนวทางหลักยังคงเป็นการทูตและความตกลงอาเซียนว่าด้วยมลพิษหมอกควันข้ามพรมแดน 2002"

ทุกครั้งที่ลมมรสุมเปลี่ยนทิศในฤดูแล้ง ท้องฟ้าในหุบเขากลัง ซาราวัก และคาบสมุทรส่วนใหญ่สามารถกลายเป็นสีเทาได้ในเวลาเพียงไม่กี่วัน ดวงอาทิตย์เลือนราง กลิ่นควันเข้ามาในบ้าน และโทรศัพท์ดังขึ้นพร้อมการแจ้งเตือน API นี่คือหมอกควันข้ามพรมแดน มลพิษที่ไม่ได้เกิดขึ้นในประเทศทั้งหมด แต่ถูกสูดหายใจทุกปีโดยชาวมาเลเซียหลายล้านคน

## เหตุใดท้องฟ้าของมาเลเซียจึงกลายเป็นสีเทาเกือบทุกปี?

หมอกควันหนาที่เกิดซ้ำไม่ใช่ปรากฏการณ์ธรรมชาติทั่วไป สาเหตุหลักคือไฟไหม้พื้นดินและป่าขนาดใหญ่ในภูมิภาค การเผาในที่โล่งและไฟป่าถูกจัดเป็นหนึ่งในแหล่งมลพิษทางอากาศหลักในมาเลเซีย ควบคู่กับอุตสาหกรรม ยานพาหนะ และการผลิตพลังงาน

อย่างไรก็ตาม ช่วงหมอกควันที่เลวร้ายที่สุดมักเกี่ยวข้องกับควันที่ลมพัดพามาจากนอกพรมแดน ตามการวิเคราะห์ของ Center for Strategic and International Studies (CSIS) ไฟไหม้พื้นที่พรุในอินโดนีเซียและมาเลเซียมีส่วนก่อหมอกควันข้ามพรมแดนเป็นส่วนใหญ่ โดยเฉพาะอันเนื่องมาจากเทคนิคการเปิดพื้นที่ด้วยการเผา (*slash-and-burn*) ในสุมาตราและภูมิภาคกาลีมันตัน

พื้นที่พรุเป็นสาเหตุที่ควบคุมได้ยาก เมื่อถูกทำให้แห้งและติดไฟ มันจะคุกรุ่นลึกลงไปในดิน ก่อควันหนาที่อาจยืดเยื้อเป็นสัปดาห์และดับได้ยาก

## หมอกควันนี้มาจากไหน?

แหล่งหลักคือเกาะใหญ่สองเกาะของอินโดนีเซีย ได้แก่ สุมาตราและกาลีมันตัน (บอร์เนียว) ที่ดินถูกเปิดเพื่อการเกษตร รวมถึงสวน ด้วยวิธีการเผาที่ถูกกว่าการถางด้วยเครื่องจักร

ปัจจัยด้านสภาพอากาศทำให้สถานการณ์เลวร้ายลง ปรากฏการณ์เอลนีโญนำฤดูแล้งที่ยาวนานและร้อนขึ้น ทำให้พื้นที่พรุและพืชพรรณติดไฟได้ง่ายขึ้นและปล่อยให้ไฟลุกลาม CSIS บันทึกว่าช่วงหมอกควันปี 2023 เช่น ถูกขับเคลื่อนโดยปรากฏการณ์เอลนีโญที่กระทบอินโดนีเซีย มาเลเซีย และสิงคโปร์

ผลกระทบทางเศรษฐกิจและสุขภาพไม่เล็กน้อย วิกฤตหมอกควันปี 1997 ซึ่งเป็นหนึ่งในที่เลวร้ายที่สุดเท่าที่เคยบันทึกไว้ ทำให้ควันไปถึงมาเลเซีย สิงคโปร์ บรูไน ไทย และฟิลิปปินส์ และประมาณการว่าก่อให้เกิดความสูญเสียราว 9 พันล้านดอลลาร์สหรัฐ ตาม CSIS

บทความนี้อธิบายข้อเท็จจริงเกี่ยวกับแหล่งที่มาและการตอบสนองระดับภูมิภาคโดยไม่ชี้ไปที่ฝ่ายใดฝ่ายหนึ่ง สาเหตุที่แท้จริงของแต่ละช่วงขึ้นอยู่กับการสอบสวนภาคสนามและข้อมูลดาวเทียมของปีนั้น

## มาเลเซียวัดคุณภาพอากาศอย่างไร?

ตัวเลขที่ท่านเห็นบ่อยที่สุดในช่วงหมอกควันคือ **API หรือดัชนีมลพิษทางอากาศ** ดูแลโดยกรมสิ่งแวดล้อม (DOE) ในฐานะตัวชี้วัดสถานะคุณภาพอากาศในพื้นที่หนึ่ง

API คำนวณจาก **มลพิษหลัก 5 ชนิด** และดัชนีย่อยที่สูงที่สุดในบรรดาทั้งห้าเป็นตัวกำหนดค่า API สุดท้าย:

- ซัลเฟอร์ไดออกไซด์ (SO2)
- ไนโตรเจนไดออกไซด์ (NO2)
- คาร์บอนมอนอกไซด์ (CO)
- อนุภาคแขวนลอยขนาดเส้นผ่านศูนย์กลางน้อยกว่า 10 ไมครอน (PM10)
- โอโซนระดับพื้นดิน (O3)

ตามเอกสารของ DOE ความเข้มข้นของมลพิษเหล่านี้ถูกตรวจวัดโดยสถานีตรวจวัดคุณภาพอากาศอัตโนมัติ (Continuous Air Quality Monitoring, CAQM) 52 แห่งทั่วมาเลเซีย โดยได้รับการสนับสนุนจากสถานีเก็บตัวอย่างด้วยมือ 14 แห่ง ซึ่งตั้งอยู่ในพื้นที่อุตสาหกรรม เมือง ชานเมือง และชนบท (เครือข่ายนี้อาจขยายตัวนับตั้งแต่เอกสารนั้น โปรดยืนยันจำนวนล่าสุดกับ DOE)

## แต่ละค่า API หมายถึงอะไรต่อสุขภาพของท่าน?

DOE จับคู่แต่ละช่วงของ API กับสถานะสุขภาพและคำแนะนำการปฏิบัติ ตารางด้านล่างสรุปสเกลทางการนั้น:

| ช่วง API | สถานะ | ผลกระทบต่อสุขภาพ | คำแนะนำ |
|---|---|---|---|
| 0–50 | ดี | มลพิษต่ำโดยไม่มีผลกระทบเสีย | ไม่มีข้อจำกัดกิจกรรมกลางแจ้ง |
| 51–100 | ปานกลาง | มลพิษปานกลาง ไม่มีผลกระทบเสีย | ไม่มีข้อจำกัดกิจกรรมกลางแจ้ง |
| 101–200 | ไม่ดีต่อสุขภาพ | ทำให้สถานะของกลุ่มเสี่ยงสูง (ผู้ป่วยโรคหัวใจและปอด) แย่ลง | กลุ่มเสี่ยงจำกัดกิจกรรมกลางแจ้ง ประชาชนทั่วไปลดกิจกรรมหนัก |
| 201–300 | ไม่ดีต่อสุขภาพอย่างมาก | กระทบความทนต่อการออกกำลังกายและสุขภาพสาธารณะ | ผู้สูงอายุและกลุ่มเสี่ยงอยู่ในบ้าน ผู้ป่วยได้รับคำแนะนำให้พบแพทย์ |
| > 300 | อันตราย | อันตรายต่อกลุ่มเสี่ยงและสุขภาพสาธารณะ | กลุ่มเสี่ยงถูกห้ามทำกิจกรรมกลางแจ้ง ประชาชนทั่วไปหลีกเลี่ยงกิจกรรมกลางแจ้ง |
| > 500 | ภาวะฉุกเฉิน | อันตรายต่อกลุ่มเสี่ยงและสุขภาพสาธารณะ | ประชาชนทั่วไปปฏิบัติตามคำสั่งของ[สภาความมั่นคงแห่งชาติ](/government/national-security-council-mkn)และประกาศทางสื่อ |

หมายเหตุเกี่ยวกับช่วง: ตารางทางการของ DOE ระบุแถบสูงสุดแบบเปิดว่า "> 300" (อันตราย) และ "> 500" (ภาวะฉุกเฉิน) ในทางปฏิบัติ นี่หมายความว่าแถบ **อันตรายครอบคลุม 301–500** และ **ภาวะฉุกเฉินเริ่มที่เกิน 500**

พึงสังเกตว่า "เสี่ยงสูง" หมายถึงเด็ก ผู้สูงอายุ และผู้ที่มีปัญหาหัวใจหรือทางเดินหายใจ พวกเขาได้รับผลกระทบเร็วกว่าและรุนแรงกว่าผู้ใหญ่ที่สุขภาพดี

## โรงเรียนปิดเมื่อใด และเกิดอะไรขึ้นในระดับภาวะฉุกเฉิน?

สำหรับผู้ปกครอง คำถามที่สำคัญที่สุดมักเกี่ยวกับโรงเรียน ตามกระบวนการปฏิบัติงานมาตรฐานที่รายงาน โรงเรียนในพื้นที่หนึ่งมักปิดเมื่อค่า API ถึง **200** ในเดือนกันยายน 2019 เช่น โรงเรียนหลายสิบแห่งในสลังงอร์ถูกสั่งปิดเมื่อหมอกควันเลวร้ายลง

การตัดสินใจจริงทำโดยหน่วยงานโดยอ้างอิงค่าปัจจุบันของ DOE ดังนั้นผู้ปกครองจึงได้รับคำแนะนำให้ติดตามค่าทางการและประกาศของกรมการศึกษาระดับรัฐ ไม่ใช่เพียงสภาพท้องฟ้าที่มองเห็น

ในระดับสุดขั้ว คือ API เกิน 500 สถานะภาวะฉุกเฉินถูกประกาศ และประชาชนทั่วไปได้รับคำแนะนำให้ปฏิบัติตามคำสั่งของสภาความมั่นคงแห่งชาติตลอดจนประกาศทางสื่อมวลชน

## มาเลเซียมีพระราชบัญญัติหมอกควันข้ามพรมแดนของตนเองหรือไม่?

นี่คือความเข้าใจผิดที่พบบ่อย **มาเลเซียไม่มีพระราชบัญญัติหมอกควันข้ามพรมแดนที่มีผลบังคับ** กฎหมาย "Transboundary Haze Pollution Act 2014" ที่มักถูกอ้างถึงจริง ๆ แล้วเป็นของ **สิงคโปร์** ไม่ใช่มาเลเซีย

ในมาเลเซีย ร่างพระราชบัญญัติที่คล้ายกันเคยถูกจัดเตรียมในสมัยรัฐบาล Pakatan Harapan แต่ถูกเลื่อนในปี 2020 และจนถึงปัจจุบันยังอยู่ระหว่างการศึกษา รัฐมนตรีที่เกี่ยวข้องอธิบายความท้าทายหลัก การบังคับใช้เรียกร้องความร่วมมือจากประเทศเพื่อนบ้าน เกี่ยวข้องกับประเด็นอธิปไตยของประเทศที่เป็นแหล่งมลพิษ และหลักฐานสำหรับการดำเนินคดีหาได้ยากเพราะเกี่ยวข้องกับข้อมูลอ่อนไหวข้ามพรมแดน ประสบการณ์ของสิงคโปร์ยังแสดงให้เห็นว่าพระราชบัญญัติในประเทศบังคับใช้ได้ยากต่อนิติบุคคลที่ดำเนินการนอกประเทศนั้น

จุดยืนอย่างเป็นทางการของรัฐบาลคือกฎหมายเพียงอย่างเดียวจะไม่แก้ปัญหานี้ และการมีส่วนร่วมทางการทูตกับเพื่อนบ้านอาเซียนได้รับความสำคัญ

## ความตกลงอาเซียนว่าด้วยมลพิษหมอกควันข้ามพรมแดนคืออะไร?

เนื่องจากควันข้ามพรมแดน การแก้ปัญหาหลักจึงมีลักษณะระดับภูมิภาคด้วย **ความตกลงอาเซียนว่าด้วยมลพิษหมอกควันข้ามพรมแดน** (ASEAN Agreement on Transboundary Haze Pollution) ได้รับการรับรองเมื่อ **10 มิถุนายน 2002** และภายใน **20 มกราคม 2015** ได้รับการให้สัตยาบันโดยประเทศสมาชิกอาเซียนทั้งหมด

ความตกลงนี้มีวัตถุประสงค์เพื่อป้องกันและตรวจวัดมลพิษหมอกควันข้ามพรมแดนที่มีต้นเหตุจากไฟไหม้พื้นดินและ/หรือป่า ดำเนินการผ่านองค์กรกำกับดูแลหลายองค์กร ในจำนวนนั้นได้แก่ ที่ประชุมภาคี (COP) กลุ่มทำงานทางเทคนิค (TWG) และคณะกรรมการอำนวยการระดับรัฐมนตรี (MSC) อาเซียนยังรับรองแผนที่นำทางความร่วมมืออาเซียนสู่การควบคุมมลพิษหมอกควันข้ามพรมแดน (ปีที่รับรองต้องได้รับการยืนยัน มักอ้างถึงปี 2016)

มาเลเซียเป็นภาคีที่แข็งขันในความตกลงนี้ โดย DOE ดำเนินการผ่านองค์ประกอบเชิงยุทธศาสตร์หลักหลายประการและเข้าร่วมการประชุมระดับภูมิภาคเป็นระยะ

## อ่านต่อ

- **ในช่วงฤดูแล้ง:** ตรวจสอบค่า API ทางการของ DOE สำหรับพื้นที่ของท่านก่อนวางแผนกิจกรรมกลางแจ้ง และให้ความสนใจเป็นพิเศษกับเด็ก ผู้สูงอายุ ตลอดจนผู้ป่วยโรคทางเดินหายใจ
- **หาก API เข้าใกล้ 200:** คาดว่าอาจมีการปิดโรงเรียนและติดตามประกาศของกรมการศึกษาระดับรัฐ
- **เพื่อทำความเข้าใจการกำกับดูแล:** ติดตามว่ามาเลเซียจะตราพระราชบัญญัติหมอกควันของตนเองในที่สุดหรือไม่ และผลของการประชุมภายใต้ความตกลงอาเซียน
- **แหล่งข้อมูลเพิ่มเติมในฐานความรู้นี้:** ดูบทความที่เกี่ยวข้องเกี่ยวกับกรมสิ่งแวดล้อมและความตกลงอาเซียนว่าด้วยมลพิษหมอกควันข้ามพรมแดนเมื่อพร้อมใช้งาน

*หมายเหตุ: บทความนี้เป็นฉบับร่างที่จัดทำโดยปัญญาประดิษฐ์และยังไม่ผ่านการทบทวนโดยผู้เชี่ยวชาญที่เป็นมนุษย์ ตัวเลขและเกณฑ์เชิงนโยบายอาจเปลี่ยนแปลง โปรดยืนยันค่าปัจจุบันและ SOP ล่าสุดกับแหล่งข้อมูลทางการของ DOE ก่อนดำเนินการ*
