マレーシアには名称に「サイバーセキュリティ」を含む政府機関が二つあり、人々は
しょっちゅう用件を間違った相手に振り分けてしまう——免許に関する問い合わせを
インシデントのホットラインへ、乗っ取られたアカウントの報告を政策機関へ。名前は
互いに置き換え可能に聞こえる。だが、その仕事は違う。

## どちらがどちらか？

一方は規制者であり、もう一方は実行者である。NACSA——国家サイバーセキュリティ庁
——は、政策、調整および法律に関する国家の主導機関である。サイバーセキュリティ・
マレーシアは、実務的な作業を担う国家技術専門機関であり、インシデントへの対応、
フォレンジックの実施、製品の認証を行う。

| | NACSA | サイバーセキュリティ・マレーシア |
| --- | --- | --- |
| 正式名称 | 国家サイバーセキュリティ庁（National Cyber Security Agency） | サイバーセキュリティ・マレーシア（CyberSecurity Malaysia） |
| 種別 | 政府機関（国家主導） | 保証有限会社 |
| 所管 | 首相府内の国家安全保障会議 | デジタル省 |
| 設立 | 2017年2月 | 2006年3月14日に設立 |
| 主な役割 | 政策、調整、規制 | 技術サービスと保証 |
| 中核機能 | 2024年サイバーセキュリティ法を所管 | MyCERT／Cyber999 を通じたインシデント対応 |

## NACSA は何をするのか？

NACSA は自らをサイバーセキュリティ事務における国家の主導機関と位置づけている。
2017年2月に設立され、首相府内の国家安全保障会議のもとで、プトラジャヤの Perdana
Putra ビルにて運営されている。

その所掌は国家的かつ戦略的である。

- 国家サイバーセキュリティ政策および戦略の策定と実施。
- 国家重要情報インフラ（NCII）の保護。
- サイバー脅威に対抗するための国家的な専門知識の調整。
- 意識向上および能力構築プログラムの牽引。
- 各組織に対するサイバーリスク管理の助言。
- 地域および世界規模のサイバーセキュリティ・パートナーシップの構築。

2024年以降に最も変化した役割は規制である。NACSA は
**2024年サイバーセキュリティ法（Act 854）**を所管しており、同法は2024年6月26日に
官報告示され、2024年8月26日に施行された。NACSA によれば、同法は現在、それより
前の**国家安全保障会議指令第26号**（国家サイバーセキュリティ管理）に取って代わって
おり、この指令は国家安全保障会議によって廃止された。同法は、とりわけ、
サイバーセキュリティ・サービス提供者を規制する規定、NACSA の最高責任者
（Chief Executive）の職務、および NCII セクター主導機関と事業体の義務を定めている。

## 2024年サイバーセキュリティ法は NACSA に何の責任を負わせるのか？

各組織にとって二点が際立つ。第一に、同法は NCII——その途絶が国家安全保障、経済
または公共サービスに重大な影響を及ぼすであろうシステム——を巡る枠組みを構築する。
第二に、**免許付与を通じて**サイバーセキュリティ・サービス提供者を規制する規定を
導入する。

NACSA の免許付与の枠組みのもとで、サイバーセキュリティ・サービスを提供する申請は
**最高責任者（Chief Executive）**に対して行われ、NACSA は二つの規制対象サービス
カテゴリーを特定している。

1. **マネージド・セキュリティ・オペレーション・センター（SOC）監視サービス。**
2. **ペネトレーションテストサービス。**

マレーシアでこれらのサービスを提供する提供者は、NACSA に免許を申請する。これが、
企業がサイバーセキュリティ・マレーシアではなく NACSA と直接やり取りすることに
なりうる、具体的で日常的な理由である。

## サイバーセキュリティ・マレーシアは何をするのか？

サイバーセキュリティ・マレーシアは国家サイバーセキュリティ専門機関であり、現在は
デジタル省の管轄下にある。保証有限会社として構成されており、内閣が MIMOS Berhad
から分離して独立した国家事業体とすることを承認した後、2006年3月14日に設立された。

NACSA がルールを策定・執行するのに対し、サイバーセキュリティ・マレーシアは技術的
な実力を提供する。

| サービス | 内容 |
| --- | --- |
| MyCERT／Cyber999 | コンピュータセキュリティインシデントの報告と対応 |
| デジタルフォレンジック | 認定を受けたフォレンジック・ラボのサービス |
| セキュリティ認証 | ISMS および Common Criteria の製品評価 |
| MySEF | マレーシア・セキュリティ評価施設 |
| 研修 | CyberGuru の能力・認証プログラム |

## 大半の人が実際にこれらの機関と接するのはどこか？

一般市民にとって、日常的な接点は **Cyber999** である。これは **MyCERT**——マレーシ
ア・コンピュータ緊急対応チーム——によって運営されており、同チームは1997年1月13日に
設立され、サイバーセキュリティ・マレーシアのオフィスから運営されている。Cyber999
は、詐欺や乗っ取られたアカウントからマルウェアに至るまで、コンピュータセキュリティ
インシデントを報告するための全国的な窓口であり、オンラインフォームとモバイルアプリ
を通じて報告を受け付ける。

つまり、単純な振り分けのルールはこうだ。何かが侵害されて今すぐ助けが必要なら、それ
はサイバーセキュリティ・マレーシアの MyCERT／Cyber999 である。国家政策、NCII の
義務、あるいはサービス提供者の免許に関する問い合わせなら、それは NACSA である。

## 次のステップ

企業を経営しているなら、まず自分の用件がどの機関に属するのかを見極めること——
進行中のインシデントは Cyber999 へ、免許、NCII の義務、コンプライアンスに関する
問い合わせは NACSA へ。マネージド SOC 監視やペネトレーションテストを提供する
サイバーセキュリティ・サービス提供者は、`nacsa.gov.my` で免許要件を確認すること。
2024年サイバーセキュリティ法のもとでの正確な義務については、要約に頼るのではなく、
司法長官府（Attorney General's Chambers）の法令ポータルを通じて法令本文を読み、
現行のサービスおよび報告チャネルを `cybersecurity.my` と `mycert.org.my` で確認すること。
