あなたはすでに気づかないうちにそれに出会っているかもしれない：MyJPJを開いたり道路税を更新しようとしたりするときに現れる、新しいログイン画面である。それがMyDigital ID（デジタル身分証）であり、2026年を通じて、それは任意のものから、ますます多くの政府サービスへの唯一の入り口へと変わりつつある。

しかし、MyDigital IDが実際に何であるかについては、多くの誤解がある。それはカードではない。MyKadの代替でもない。あなたの個人データが保存される場所でもない。心配すべきかどうかを判断する前に、それが何をするのか——そして何をしないのか——を理解することが重要である。

## MyDigital IDとは実際に何か？

MyDigital IDは、複数のオンラインサービスにまたがる**シングルサインオン**（single sign-on）を可能にする国家デジタルIDのソリューションである。これは国家の研究開発（R&D）センターである**Mimos Berhadによって開発**され、**首相府**の監督の下で**My Digital ID Sdn. Bhd.によって運営**されている。このシステムは**2023年12月1日**に、首相アンワル・イブラヒムを最初の登録者として開始された。

その仕組みは簡潔である：あるサービスがあなたが本当にあなた本人であることを確認する必要があるとき、MyDigital IDは**国民登録局（Jabatan Pendaftaran Negara、JPN）のデータベースを直接参照する**——あなたのデータのコピーをどこかに保存するのではない。公式サイトによれば、このアプリは個人データを保存せず、生体認証データも保存せず、あなたのオンライン活動を収集または追跡もしない。

あなたがログインに使用する生体認証（指紋または顔認証）は**あなた自身のデバイス上の**生体認証であり、そのデータは外部サーバーには送信されない。一方、登録時には、追加のセキュリティ層が、身元を確認するためにあなたの顔をリアルタイムでJPNのデータベースと照合することがある。

## MyDigital ID対MyKad——何が違うのか？

これは最も頻繁な混乱の元である。どちらもあなたの身元であるが、形式と文脈が異なる。

| | MyKad | MyDigital ID |
| --- | --- | --- |
| 形式 | 物理カード | 電話上のアプリ |
| 用途 | 物理カウンターでの手続き | オンラインでの本人確認 |
| 関係 | 基本的な身分証明書 | MyKadの身元をデジタルで確認する |
| データを保存する？ | はい（カード上のチップ） | いいえ——JPNのデータベースを参照する |
| 他方を代替する？ | — | MyKadを代替しない |

キーワードはこれである：MyDigital IDはMyKadを**補完する**のであり、代替するのではない。公式サイトによれば、物理カウンターでの手続きにおいてMyKadを代替することはなく、オンラインでの本人確認にのみ使用される。

## 登録方法は？

登録はすべてのマレーシア国民に**無料**で、いくつかの方法で行える：

- **オンライン** — MyDigital IDアプリを通じてパスワード認証で。
- **キオスク** — 物理的な場所で；MyKad（またはMyTentera）と電話を持参する。
- **事前登録** — 完全な登録プロセスを迅速化するために、EPF（KWSP）のi-AkaunまたはJPNのカウンターを通じて。

## 2026年の義務化——いつシングルサインオンになるのか？

ここが、多くの人にとって切実になるところである。2026年を通じて、MyDigital IDは任意のものから、いくつかの主要な政府アプリの**唯一のログイン方法**へと変わる。

| アプリ | シングルサインオンの日付 | 主管機関 |
| --- | --- | --- |
| MyNIISe（国家統合出入国管理システム） | 2026年1月15日 | 内務省 |
| MyJPJ | 2026年5月1日 | 道路交通局（Jabatan Pengangkutan Jalan、JPJ） |
| MyBayar PDRM | 今後施行予定 | マレーシア王立警察 |

**MyJPJ**については、JPJ長官によれば、2026年5月1日から12歳以上のすべての利用者はアプリにアクセスするためにMyDigital IDの使用が求められる。登録しない利用者はログインしてデジタル運転免許証にアクセスしたり道路税を更新したりできなくなる；MyPR（永住者）保有者には当面のあいだ代替の経路が与えられる。

この義務化の意図は新しいものではないことを覚えておくべきである。MyDigital IDはかつて2024年末に義務化される予定であったが、その決定は国民の反対を受けて延期された。2025年8月時点で、このシステムは300万人を超える利用者を擁し、政府と民間の各部門にまたがる45を超えるプラットフォームで使用されていると報じられた。

## 海外へ行くのに本当に必要なのか？

ここではニュースの見出しが誤解を招きやすいので、この区別が重要である。

MyNIISeは2026年1月15日からMyDigital IDのシングルサインオンを受け入れる。この出入国管理アプリは2025年9月に、ジョホールバル（ジョホール—シンガポール間の陸路国境）のスルタン・イスカンダル・ビル（Bangunan Sultan Iskandar）とスルタン・アブ・バカル・コンプレックス（Kompleks Sultan Abu Bakar）で最初に導入され、2025年12月30日時点で60万件近いダウンロードと28万7,000人を超える登録利用者を記録していた。

しかし、アプリのシングルサインオンは**そのアプリが必須であることを意味しない**。2026年1月14日、移民局長官は出入国審査の通過に**MyNIISeとMyDigital IDが必須ではない**ことを確認した。既存の選択肢は残されている：

- オートゲート（e-Gate）での物理的なパスポート
- 有人の出入国審査カウンター
- MyBorderPassアプリ

デジタルの選択肢を使う場合でも、国際旅行には引き続き物理的なパスポートを携行する必要がある。この変更は外国人訪問者にも影響せず、彼らは引き続き既存の方法を使用できる。

## 未解決のプライバシーの問題

これは最も正直に述べる必要がある部分である。MyDigital IDの設計——アプリはデータを保存せず、参照するだけ——は、確かに一部のリスクを軽減する。しかし、それは懸念を取り除くものではない。なぜなら、真の問題はそのアプリについてではなく、それが参照するデータベースと、それを取り巻く法的枠組みについてだからである。

2つの主要な問題がしばしば提起される：

**第一に、PDPAの適用範囲の問題である。** 批評家は、国民のデータが政府機関によって保持される場合に、2010年個人データ保護法の保護がどの程度適用されるのかを問うている。マレーシア弁護士会の前会長Salim Bashirは、登録を義務付けようとするいかなる試みも、連邦法を通じて国会が制定し、**PDPA 2010と整合させ**なければならないと強調した。

**第二に、データ漏洩の記録である。** マレーシアには繰り返されるデータ漏洩の歴史がある。Salim Bashirは、プライバシー侵害とデータセキュリティを、無許可での個人情報へのアクセスと悪用のリスクを伴う、義務化に対する重大な課題であると評した。

このためにこそ政治的な圧力が存在する。政府が2025年7月に法律を通じて登録を義務付ける可能性を持ち出したとき、前クラン選出国会議員Charles Santiagoは、立法の近道を取るのではなく、まずそのシステムに対する**信頼を築く**よう政府に促した。彼の主張では、利用率の低さは、強制によって解決するのではなく、政府が解決すべき信頼の問題を示している。

## 次のステップ

MyJPJを使っているなら、最も近い日付は**2026年5月1日**である——それ以降、MyDigital IDがなければアプリを通じてデジタル運転免許証にアクセスしたり道路税を更新したりできない。アプリ、キオスク、またはEPF（KWSP）／JPNの事前登録を通じて早めに登録すれば、最後の瞬間の慌ただしさを避けられる。

もしあなたの懸念がプライバシーであるなら、2つのことを区別すること：アプリが何を保存するか（公式の情報源によれば、何も保存しない）、そしてそれが参照するJPNのデータベースに何が起こるか（未解決のままのPDPAの適用範囲の問題に左右される）。この2つ目の問題は未解決であり、このシステムのリスクを正直に評価する人は誰でも、一方だけでなく両方を測る必要がある。

政府の目標は依然として広範である：2026年予算案を通じて、首相アンワル・イブラヒムは**2026年末までに1500万ユーザー**という目標を設定し、政府は2030年までにこのデジタルIDによって**公共サービスの95パーセントを統合**することを目指している。方向性は明確である——ますます多くのサービスがMyDigital IDを入り口とするだろう。登録が最終的に法律で義務付けられるかどうかは、依然として未解決の問題である。
