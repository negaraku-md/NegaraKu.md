คุณอาจเคยเจอมันโดยไม่รู้ตัว: หน้าจอล็อกอินใหม่ที่ปรากฏขึ้นเมื่อคุณเปิด MyJPJ หรือพยายามต่อภาษีถนน นั่นคือ MyDigital ID และตลอดปี 2026 มันเปลี่ยนจากสิ่งที่เป็นทางเลือกเป็นประตูทางเข้าเดียวสู่บริการรัฐบาลที่มากขึ้นเรื่อย ๆ

แต่มีความเข้าใจผิดมากมายเกี่ยวกับว่า MyDigital ID คืออะไรจริง ๆ มันไม่ใช่บัตร ไม่ใช่ตัวแทน MyKad และไม่ใช่ที่ที่ข้อมูลส่วนบุคคลของคุณถูกเก็บ การเข้าใจว่ามันทำอะไร — และไม่ทำอะไร — สำคัญก่อนที่คุณจะประเมินว่าจำเป็นต้องกังวลหรือไม่

## MyDigital ID คืออะไรกันแน่?

MyDigital ID เป็นโซลูชันอัตลักษณ์ดิจิทัลแห่งชาติที่ทำให้เกิด **การล็อกอินเดียว** (single sign-on) ทั่วบริการออนไลน์หลากหลาย มัน **พัฒนาโดย Mimos Berhad** ศูนย์วิจัยและพัฒนา (R&D) แห่งชาติ และ **ดำเนินการโดย My Digital ID Sdn. Bhd.** ภายใต้การกำกับดูแลของ **สำนักนายกรัฐมนตรี** ระบบนี้เปิดตัวเมื่อวันที่ **1 ธันวาคม 2023** โดยมีนายกรัฐมนตรีอันวาร์ อิบราฮิม (Anwar Ibrahim) เป็นผู้ลงทะเบียนคนแรก

วิธีที่มันทำงานเรียบง่าย: เมื่อบริการหนึ่ง ๆ ต้องยืนยันว่าคุณคือคุณจริง ๆ MyDigital ID **อ้างอิงตรงไปยังฐานข้อมูลกรมทะเบียนราษฎร (JPN)** — ไม่ได้เก็บสำเนาข้อมูลของคุณไว้ที่ใด ตามเว็บไซต์ทางการ แอปพลิเคชันนี้ไม่ได้เก็บข้อมูลส่วนบุคคล ไม่ได้เก็บข้อมูลชีวมิติ และไม่ได้รวบรวมหรือติดตามกิจกรรมออนไลน์ของคุณ

ชีวมิติที่คุณใช้ในการล็อกอิน (ลายนิ้วมือหรือการจดจำใบหน้า) เป็นชีวมิติ **บนอุปกรณ์ของคุณเอง** และข้อมูลนั้นไม่ได้ถูกส่งไปยังเซิร์ฟเวอร์ภายนอก ระหว่างการลงทะเบียน ชั้นความปลอดภัยเพิ่มเติมอาจตรวจใบหน้าของคุณแบบเรียลไทม์เทียบกับฐานข้อมูล JPN เพื่อยืนยันอัตลักษณ์

## MyDigital ID เทียบกับ MyKad — ต่างกันอย่างไร?

นี่คือต้นเหตุความสับสนที่เกิดบ่อยที่สุด ทั้งสองเป็นอัตลักษณ์ของคุณ แต่ในรูปแบบและบริบทที่แตกต่างกัน

| | MyKad | MyDigital ID |
| --- | --- | --- |
| รูปแบบ | บัตรทางกายภาพ | แอปพลิเคชันบนโทรศัพท์ |
| ใช้สำหรับ | การทำธุระที่เคาน์เตอร์ทางกายภาพ | การระบุตัวตนออนไลน์ |
| ความสัมพันธ์ | เอกสารระบุตัวตนพื้นฐาน | ยืนยันอัตลักษณ์ MyKad ในรูปดิจิทัล |
| เก็บข้อมูลหรือไม่? | ใช่ (ชิปบนบัตร) | ไม่ — อ้างอิงฐานข้อมูล JPN |
| แทนที่อีกอันหรือไม่? | — | ไม่แทนที่ MyKad |

คำสำคัญ: MyDigital ID **เสริม** MyKad ไม่ใช่แทนที่ ตามเว็บไซต์ทางการ มันไม่ได้แทนที่ MyKad สำหรับการทำธุระที่เคาน์เตอร์ทางกายภาพและใช้เฉพาะสำหรับการระบุตัวตนออนไลน์

## ลงทะเบียนอย่างไร?

การลงทะเบียน **ฟรี** สำหรับพลเมืองมาเลเซียทุกคนและสามารถทำได้หลายวิธี:

- **ออนไลน์** — ผ่านแอปพลิเคชัน MyDigital ID ด้วยการยืนยันด้วยรหัสผ่าน
- **คีออสก์** — ที่สถานที่ทางกายภาพ; นำ MyKad (หรือ MyTentera) และโทรศัพท์ของคุณไปด้วย
- **การลงทะเบียนล่วงหน้า** — ผ่าน i-Akaun KWSP หรือเคาน์เตอร์ JPN เพื่อเร่งกระบวนการลงทะเบียนเต็มรูปแบบ

## ข้อบังคับปี 2026 — เมื่อใดมันจะกลายเป็นการล็อกอินเดียว?

นี่คือที่ที่เรื่องกลายเป็นจริงสำหรับคนส่วนใหญ่ ตลอดปี 2026 MyDigital ID เปลี่ยนจากทางเลือกเป็น **วิธีล็อกอินเดียว** สำหรับแอปพลิเคชันรัฐบาลหลักหลายอัน

| แอปพลิเคชัน | วันล็อกอินเดียว | หน่วยงานผู้มีอำนาจ |
| --- | --- | --- |
| MyNIISe (ระบบตรวจคนเข้าเมืองบูรณาการแห่งชาติ) | 15 มกราคม 2026 | กระทรวงมหาดไทย |
| MyJPJ | 1 พฤษภาคม 2026 | กรมการขนส่งทางบก (JPJ) |
| MyBayar PDRM | จะมีการบังคับใช้ | สำนักงานตำรวจแห่งชาติมาเลเซีย |

สำหรับ **MyJPJ** ตั้งแต่ 1 พฤษภาคม 2026 ผู้ใช้ทุกคนที่อายุ 12 ปีขึ้นไปต้องใช้ MyDigital ID เพื่อเข้าถึงแอปพลิเคชัน ตามอธิบดี JPJ ผู้ใช้ที่ไม่ลงทะเบียนจะไม่สามารถล็อกอินเพื่อเข้าถึงใบอนุญาตดิจิทัลหรือต่อภาษีถนนได้; ผู้ถือ MyPR ได้รับช่องทางทางเลือกชั่วคราว

พึงจำไว้ว่าเจตนาบังคับนี้ไม่ใช่เรื่องใหม่ MyDigital ID เคยถูกกำหนดให้ดำเนินการบังคับในปลายปี 2024 แต่การตัดสินใจนั้นถูกเลื่อนออกไปหลังการคัดค้านของสาธารณะ ภายในเดือนสิงหาคม 2025 ระบบนี้มีรายงานว่ามีผู้ใช้กว่า 3 ล้านคนและใช้ในกว่า 45 แพลตฟอร์มทั่วภาครัฐและเอกชน

## ผมจำเป็นต้องมีมันจริง ๆ เพื่อไปต่างประเทศหรือไม่?

พาดหัวข่าวทำให้เข้าใจผิดได้ง่ายตรงนี้ ดังนั้นความแตกต่างนี้จึงสำคัญ

MyNIISe รับการล็อกอินเดียวของ MyDigital ID ตั้งแต่ 15 มกราคม 2026 แอปพลิเคชันตรวจคนเข้าเมืองนั้นเริ่มแนะนำในเดือนกันยายน 2025 ที่ Bangunan Sultan Iskandar และ Kompleks Sultan Abu Bakar ในยะโฮร์บาห์รู (Johor Bahru) (พรมแดนทางบกยะโฮร์–สิงคโปร์) และภายในวันที่ 30 ธันวาคม 2025 มีการดาวน์โหลดเกือบ 600,000 ครั้งและผู้ใช้ที่ลงทะเบียนกว่า 287,000 คน

แต่การล็อกอินเดียวสำหรับแอปพลิเคชัน **ไม่ได้หมายความว่าแอปพลิเคชันนั้นเป็นข้อบังคับ** เมื่อวันที่ 14 มกราคม 2026 อธิบดีกรมตรวจคนเข้าเมืองยืนยันว่า **MyNIISe และ MyDigital ID ไม่ใช่ข้อบังคับ** ในการผ่านตรวจคนเข้าเมือง ตัวเลือกที่มีอยู่ยังคง:

- หนังสือเดินทางทางกายภาพที่ autogate (e-Gate)
- เคาน์เตอร์ตรวจคนเข้าเมืองแบบแมนนวล
- แอปพลิเคชัน MyBorderPass

คุณยังต้องนำหนังสือเดินทางทางกายภาพสำหรับการเดินทางระหว่างประเทศแม้ใช้ตัวเลือกดิจิทัล การเปลี่ยนแปลงนี้ก็ไม่กระทบผู้มาเยือนต่างชาติ ซึ่งสามารถใช้วิธีที่มีอยู่ต่อไปได้

## คำถามด้านความเป็นส่วนตัวที่ยังไม่ได้รับการแก้ไข

นี่คือส่วนที่จริงใจที่สุดที่ต้องระบุ การออกแบบของ MyDigital ID — แอปพลิเคชันไม่เก็บข้อมูล เพียงอ้างอิง — ลดความเสี่ยงบางส่วนได้จริง แต่มันไม่ได้กำจัดความกังวล เพราะคำถามที่แท้จริงไม่ได้เกี่ยวกับแอปพลิเคชันนั้น แต่เกี่ยวกับฐานข้อมูลที่มันอ้างอิงและกรอบกฎหมายที่ล้อมรอบมัน

สองประเด็นหลักมักถูกยกขึ้น:

**อย่างแรก เรื่องการครอบคลุมของ PDPA** ผู้วิพากษ์วิจารณ์ตั้งคำถามว่าการคุ้มครองของพระราชบัญญัติคุ้มครองข้อมูลส่วนบุคคล 2010 ใช้ได้แค่ไหนเมื่อข้อมูลของประชาชนถูกถือโดยหน่วยงานรัฐบาล อดีตประธานสภาทนายความ ซาลิม บาชีร์ (Salim Bashir) ย้ำว่าความพยายามใด ๆ ในการบังคับให้ลงทะเบียนต้องถูกตราโดยรัฐสภาผ่านพระราชบัญญัติสหพันธรัฐและ **สอดคล้องกับ PDPA 2010**

**อย่างที่สอง ประวัติการรั่วไหลของข้อมูล** มาเลเซียมีประวัติการรั่วไหลของข้อมูลที่เกิดซ้ำ ซาลิม บาชีร์ระบุว่าการละเมิดความเป็นส่วนตัวและความมั่นคงของข้อมูลเป็นความท้าทายที่สำคัญต่อการดำเนินการบังคับ ด้วยความเสี่ยงของการเข้าถึงและการนำข้อมูลส่วนบุคคลไปใช้ในทางที่ผิดโดยไม่ได้รับอนุญาต

ด้วยเหตุนี้แรงกดดันทางการเมืองจึงมีอยู่ เมื่อรัฐบาลยกความเป็นไปได้ในการบังคับให้ลงทะเบียนผ่านกฎหมายในเดือนกรกฎาคม 2025 อดีตสมาชิกรัฐสภาเขตกลัง ชาลส์ ซานติอาโก (Charles Santiago) เรียกร้องให้รัฐบาล **สร้างความเชื่อมั่น** ต่อระบบนั้นก่อน ไม่ใช่ใช้ทางลัดทางกฎหมาย การนำมาใช้ที่ต่ำ เขาโต้แย้ง แสดงถึงปัญหาความเชื่อมั่นที่รัฐบาลต้องแก้ไข ไม่ใช่แก้ด้วยการบังคับ

## อ่านต่อ

หากคุณใช้ MyJPJ วันที่ใกล้ที่สุดคือ **1 พฤษภาคม 2026** — หลังจากนั้น หากไม่มี MyDigital ID คุณจะไม่สามารถเข้าถึงใบอนุญาตดิจิทัลหรือต่อภาษีถนนผ่านแอปพลิเคชันได้ การลงทะเบียนแต่เนิ่นผ่านแอปพลิเคชัน คีออสก์ หรือการลงทะเบียนล่วงหน้า KWSP/JPN หลีกเลี่ยงความเร่งรีบในนาทีสุดท้าย

หากความกังวลของคุณคือความเป็นส่วนตัว ให้แยกสองสิ่ง: สิ่งที่แอปพลิเคชันเก็บ (ตามแหล่งทางการ ไม่มี) และสิ่งที่เกิดกับฐานข้อมูล JPN ที่มันอ้างอิง (อยู่ภายใต้คำถามเรื่องการครอบคลุมของ PDPA ที่ยังไม่ได้รับการแก้ไข) คำถามที่สองนั้นยังไม่ได้รับการแก้ไข และใครก็ตามที่ประเมินความเสี่ยงของระบบนี้อย่างจริงใจต้องวัดทั้งสอง ไม่ใช่เพียงอันเดียว

เป้าหมายของรัฐบาลยังคงกว้าง: ผ่าน Budget 2026 นายกรัฐมนตรีอันวาร์ อิบราฮิมตั้งเป้า **ผู้ใช้ 15 ล้านคนภายในสิ้นปี 2026** และรัฐบาลตั้งเป้า **บริการสาธารณะบูรณาการ 95 เปอร์เซ็นต์** กับอัตลักษณ์ดิจิทัลนี้ภายในปี 2030 ทิศทางชัดเจน — บริการที่มากขึ้นเรื่อย ๆ จะทำให้ MyDigital ID เป็นประตูทางเข้า ส่วนว่าการลงทะเบียนจะถูกบังคับผ่านกฎหมายในที่สุดหรือไม่ยังคงเป็นคำถามที่เปิดอยู่
