十日間。これが、ポルトガル艦隊が1511年8月10日にマラッカ海域へ到着してから、8月24日にこの都市が陥落するまでの間隔である。

百三十年後、同じ場所にある同じ都市が、降伏するまでにオランダの包囲を七か月間耐え抜いた。

都市は移動しなかった。海峡も変わらなかった。変わったのはその城壁である——そして十日間と七か月の間のこの差こそが、この地域随一の富裕港がなぜこれほど早く陥落したのかについての、もっとも率直な説明である。

## 公式記録によると何が起きたのか

マラッカ州政府公式ポータルは、簡潔かつ的確な出来事の順序を記録している。

| 日付 | 出来事 |
| --- | --- |
| 1509年 | ディエゴ・ロペス・デ・セケイラが、ポルトガル王立艦隊の18隻の船とともに到着 |
| 1509年 | 争いが勃発；その艦隊は攻撃を受け、20名の船員が拘束された |
| 1511年8月10日 | ゴアのポルトガル副王アフォンソ・デ・アルブケルケがマラッカに到着 |
| 1511年8月10日 | マラッカにポルトガルの拠点を築きたいという彼の要求は、スルタン・マームード・シャーによって拒否された |
| 1511年8月24日 | 十日間の包囲の末、ポルトガルはマラッカ城を攻略した |
| 1512年1月 | アルブケルケは、五層の塔を持つA Famosa（要塞）を完成させたのち、ゴアへ帰還した |

マラッカ王国はそれ以前、110年間統治していた。ポルトガルはその後130年間統治した。

## 1509年の出来事は単なる誤解ではなかった

アルブケルケの大砲が到来する2年前、すでに一つのポルトガル艦隊がマラッカの港に停泊していた。

セケイラの遠征隊は1509年に18隻の船で到着し、争いが勃発し、その船員20名が拘束された。マラッカの視点から見れば、これは自国の港に停泊する武装した外国艦隊に対して、主権国家が取った行動であった。

リスボンの視点から見れば、これは同時に二つの意味を持つことになった——再来のための公式な口実であり、マラッカに到達可能であることの証拠である。1509年の艦隊は手ぶらで帰ったわけではない——その港についての知識を持ち帰ったのである。

アルブケルケが1511年8月10日に到着し、ポルトガルの拠点を築く許可を求めたとき、その要求は拒否された。攻撃はこの拒否の後に始まった。

## なぜわずか十日間だったのか？城壁を見よ

ここで、たいていの説明は政治的要因で止まり、もっとも検証可能な原因を見逃してしまう。

マレーシア国立公文書館の記録によれば、1409年にマラッカを訪れた鄭和提督（Cheng Ho）の記録に基づき、王国時代のマラッカ城はラジャ・パラメスワラによって**頑丈な木材を城壁として**築かれ、四つの城門を備えていた。その機能は、王室の財宝を保管する場所であり、敵の攻撃に対する防御の要塞であった。

これは十五世紀の地域的脅威——海賊の襲撃、競争相手による略奪、朝貢をめぐる争い——に対してはまったく合理的な設計であった。しかし、艦砲の砲撃に耐えるための設計ではなかった。

都市が陥落した直後にアルブケルケが何をしたかに注目してほしい。国立公文書館によれば、彼はより堅固な新しい要塞の建設を命じ、当初は木材と石材を用いる計画であったが、その後設計は**全面的に石造**へと変更された。

- 高さ3.6メートル、厚さ2.4メートルの石造城壁
- 高さ18から24メートルの見張り塔8基
- 跳ね橋を備えた四つの入口
- 防御線を囲む武装警備兵60名
- 300から400名の奴隷労働者の力によって建設された

ある都市を奪い取ったばかりの者は、その都市の弱点を熟知している。アルブケルケの最初の行動は、彼が何を弱点とみなしていたかを物語っている——そして彼はそれを石で補ったのである。

## それを裏づける試練：1641年

もし「城壁」説が正しいなら、石造の要塞は試練を受けたとき、まったく異なる結果をもたらすはずである。

実際に試された。1641年にオランダが攻撃した際、都市が陥落するまでに**七か月間**の包囲を要した。国立公文書館の記録によれば、彼らは城内で大砲68門とライフル銃74丁を発見した。

| 包囲戦 | 防御 | 持ちこたえた期間 |
| --- | --- | --- |
| ポルトガル、1511年 | 木造城壁の都市、四つの門 | 10日間 |
| オランダ、1641年 | A Famosa、全面石造、塔8基 | 7か月間 |

これは、指導力や内部分裂、あるいは外国商人の忠誠が重要でなかったという意味ではない。これらの要因は、マラッカの歴史叙述の中で確かに広く論じられている。しかし、同じ都市が同じ場所で、城壁が木材から石材に変わっただけで21倍も長く持ちこたえたとなれば、要塞の技術は説明の脚注ではなく、その最前列に置かれるべきである。

マラッカが豊かであったのは、それが開かれていたからである。その富は、誰もが出入りできる中継貿易港であることから生まれたのであり——誰も寄せつけない要塞であることからではなかった。その商業モデルと防衛モデルは実は同一のものであり、通商ではなく征服の意図を持った艦砲艦隊が到来したとき、それこそが弱点となったのである。

> 開放性に依存する港は、要塞のように築くことはできない。マラッカは要塞になる必要もなく、この海峡を百年にわたって支配していた——通商を望まない者が到来するまでは。

## ポルトガル要塞は王宮の丘の麓に立つ

この細部が、その転換の全体を一つの光景に凝縮している。

国立公文書館によれば、王国時代の王宮は現在セント・ポール山（Bukit St. Paul）——かつてはブキ・マラッカ（Bukit Melaka）と呼ばれていた——として知られる丘の上にあり、トゥン・スリ・ラナン（Tun Seri Lanang）著『マレー年代記』（Sejarah Melayu）に描かれているような壮麗な宮殿であったと信じられている。

一方でポルトガル要塞は、国立公文書館の記録によれば、**同じ丘の麓**にどっしりと完成した。かつてマレーの王宮が位置していたその丘は、今やヨーロッパの石壁の陰に覆われている。

そして、その要塞も結局は残らなかった。1806年、英国の指揮官ウィリアム・ファーカー（William Farquhar）は、オランダによる再占領を阻止するためにこれを取り壊し、今日私たちが目にする門と城壁の断片だけを残した。

## マラッカの王統はどこへ行ったのか？

都市は1511年に失われた。その制度は失われなかった。

ジョホール州政府公式ポータルの記録によれば、1528年、**マラッカ王国の血統に連なる**スルタン・アラウディン・リアヤット・シャーがジョホールを開き、ジョホール・ラマに拠点を定めた。ジョホール王室ポータルの記録によれば、王はラジャ・アリ、あるいはスルタン・ムダとしても知られ、同じ1528年にジョホール・ラマのコタ・バトゥに国を開いた。

国立公文書館はこれをより端的に述べている。マラッカ陥落後、「ジョホール王国が、かつてマラッカが果たしていた役割を引き継いだ」と。

**その17年間の空白。** 1511年から1528年の間には、これらの公式ポータルが詳細に記録していない期間が存在する。年代記の伝統や歴史文献は、この期間における宮廷の移動先としていくつかの場所を挙げている。私たちはここでその移動の経路や日付を掲載していない。公式な情報源では確認できないためである——確認できるのは、再出発の地点のみである。すなわち、1528年のジョホール・ラマである。

その後に起きたことは、1511年の教訓が生かされたことを示している。

| 年 | ジョホール・ラマでの出来事 |
| --- | --- |
| 1528年 | スルタン・アラウディン・リアヤット・シャー2世がジョホール・ラマのコタ・バトゥに国を開く |
| 1540年 | コタ・バトゥが築かれる——全石造、長さ50メートル、幅20メートル |
| 1564年 | アチェが猛攻を仕掛け、この城を攻略 |
| 1576年、1578年 | ポルトガルの攻撃を撃退 |
| 1586年 | ポルトガルの攻撃が再び失敗 |
| 1587年 | ポルトガルがゴアからの援軍を得て、コタ・バトゥの攻略に成功 |

今回は要塞が木造ではなく石造であった——そしてポルトガルはこれを突破するために四度の試みと、ゴアからの援軍を必要とした。

1587年以降も、都は移り続けた。ジョホール州政府ポータルの記録によれば、ジョホールの都はジョホール川沿いを20回にわたり移動した末、最終的にリアウ諸島に落ち着いた。このマラッカ王統の王朝は1699年まで統治を続け、その年、国の統治はブンダハラ王朝へと移った。

つまり、[マラッカ王国](/malaysia/melaka-sultanate)の宮廷の血統は、マラッカ城そのものが失われてから、さらに188年にわたって存続したのである。

## 東南アジアにおけるヨーロッパ時代の始まり

1511年は、しばしばこの地域におけるヨーロッパ植民地化の始まりとして語られる。時系列としてはそれは正しい——しかし、その規模については正しく理解される必要がある。

| 期間 | 統治勢力 | 期間の長さ |
| --- | --- | --- |
| 1511～1641年 | ポルトガル | 130年間 |
| 1641～1795年 | オランダ | 154年間 |
| 1795年以降 | 英国 | 1824年ロンドン条約；1826年海峡植民地 |

1511年に手が変わったのは、一つの港湾都市とそれが支配する海峡であって——半島そのものではなかった。ヨーロッパ列強はその後三世紀をかけてこの支配を拡大していき、上記の年表は[1957年の独立](/malaysia/independence-1957)によってようやく終わりを迎える。

## よくある誤り

**「マラッカ王国は1511年に終わった。」** 終わったのは都市である。王室の制度は存続した——マラッカ王統によるマレー統治は1528年にジョホール・ラマで再開され、その王朝は1699年まで存続した。

**「今日残っているA Famosaは、当時のポルトガル要塞そのものである。」** 残っているのは門と城壁の断片だけである。実際の要塞は1806年にウィリアム・ファーカーによって取り壊された。

**「マラッカが陥落したのは、単に防御が弱かったからにすぎない。」** 確かに都市は木造城壁であった——しかし、それは地域的な脅威に対して設計されたものであり、艦砲艦隊に対してではなかった。その弱さは技術世代の違いによるものであり、単なる怠慢ではなかった。

**「1511年は、ポルトガルがマレー半島を植民地化したことを意味する。」** ポルトガルが支配したのはマラッカの都市とその海峡である。半島内陸部に対する彼らの影響力は、しばしば描かれるよりもはるかに限定的であった。

**「マラッカは長期の包囲に耐えたことは一度もない。」** 同じ都市が1641年、オランダを相手に七か月間持ちこたえた。その違いは石である。

## 次のステップ

1511年8月に実際に何が失われたのか——110年かけて築かれた言語、宮廷法、統治構造、そして交易網——を理解したいのであれば、[マラッカ王国](/malaysia/melaka-sultanate)から読み始めるとよい。

この半島における国家としての歴史が、マラッカが存在する以前までどれほど遡るのかを見てみたいのであれば、[ランカスカ](/malaysia/langkasuka)が有用な出発点となる。
