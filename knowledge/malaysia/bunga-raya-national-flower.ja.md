独立したばかりの国を代表すべく、かつて七種類の花が競い合った——そして勝ったのは、もっとも香り高い花でも、もっとも希少な花でもなく、あらゆる町や村でもっともよく知られていた花だった。それがハイビスカス（Bunga Raya）である。

## いつ、誰が宣布したのか？

赤いハイビスカスは、**1960年7月28日**、初代首相トゥンク・アブドゥル・ラーマン・プトラ・アルハジ（Tunku Abdul Rahman Putra Al-Haj）により、マレーシアの国花として宣布された。

この花の学名は*ブッソウゲ（Hibiscus rosa-sinensis）*である。地域によっては、bunga sepatuやkembang sepatuとも呼ばれる。

## なぜ他の花ではなくハイビスカスなのか？

1958年末、農業省（Kementerian Pertanian）は国花候補として**七**種類の花を提案した。

| 候補となった花 |
| --- |
| ハイビスカス |
| イランイランノキ（kenanga） |
| マツリカ（melur） |
| チャンパカ（cempaka） |
| ハス（teratai） |
| バラ（mawar） |
| タンジョン（tanjung） |

情報局（Jabatan Penerangan）も世論調査を実施しており、民衆の選好は地域によって異なっていた。最終的に政府は、次の五つの基準に基づいてハイビスカスを選定した。

- 国内全域ですでに広く知られていること；
- 色と形が魅力的であること；
- 名称が全州を通じて統一されていること；
- どこでも容易に手に入ること、および
- 当時、他のいかなる国の国花にもなっていなかったこと。

最後の基準は重要である。国家の象徴は独自のものであるべきで、他国と共有されるべきではない。

## 五枚の花弁と赤い色にはどのような意味があるのか？

ハイビスカスの五枚の花弁は、**ルクンヌガラ（国家原則、Rukun Negara）の五つの原則**と関連づけられている。ルクンヌガラ自体は、それより十年後の1970年になってようやく宣布されたものであり、したがってこの関連づけは後になって構築された象徴であって、1960年にこの花が選ばれた本来の理由ではない。五つの原則とは次のとおりである。

1. 神への信仰；
2. 国王と国家への忠誠；
3. 憲法の至高性；
4. 法の支配、および
5. 礼節と道徳。

一方、赤い色はあらゆる困難に立ち向かう勇気、そして国家の政治的・経済的な強さを象徴している。全体として、ハイビスカスは多民族からなる国民の団結の象徴とも見なされている。

## ハイビスカスは今日どこで使われているのか？

国家の象徴の一つとして、ハイビスカスは[ジャルール・グミラン（Jalur Gemilang）](/malaysia/jalur-gemilang)（国旗）およびジャタ・ヌガラ（Jata Negara、国章）とともにマレーシアの公式な顔として位置づけられており、その図像は国家的な行事や祝典に頻繁に登場する。

## 次のステップ

ハイビスカスの五枚の花弁に込められた意味をより深く理解するには、**ルクンヌガラの五つの原則**とその1970年の宣布の歴史についての完全な解説を読むとよい。また、他の国家の象徴——ジャルール・グミランとジャタ・ヌガラ——についても調べることで、この三つがどのようにマレーシアの公式なアイデンティティを形づくっているかを知ることができる。
