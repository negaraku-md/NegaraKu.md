七种花卉曾竞相代表一个刚刚独立的国家——而胜出的既不是最芳香的，也不是最稀有的，而是每一个市镇和乡村都最熟悉的那一种。那就是大红花。

## 何时、由谁宣布？

红色大红花于**1960年7月28日**由首任首相东姑阿都拉曼（Tunku Abdul Rahman Putra Al-Haj）宣布为马来西亚国花。

这种花的学名是*Hibiscus rosa-sinensis*（朱槿）。在某些地方，它也被称为bunga sepatu或kembang sepatu（扶桑花）。

## 为什么是大红花，而不是其他花？

1958年年底，农业部提议以**七**种花卉作为国花候选：

| 候选花卉 |
| --- |
| 大红花 |
| 依兰花（kenanga） |
| 茉莉花（melur） |
| 白兰花（cempaka） |
| 莲花（teratai） |
| 玫瑰花（mawar） |
| 香花榄（tanjung） |

新闻局（Jabatan Penerangan）也进行了民意调查，而民众的选择因地区而异。最终政府依据五项标准选定了大红花：

- 已在全国广为人知；
- 颜色与形态吸引；
- 名称在各州之间统一；
- 随处可得；以及
- 当时尚未成为任何其他国家的国花。

最后一项标准很重要：一个国家的象征应当是独一无二的，而不是与其他国家共用。

## 五片花瓣和它的红色有什么含义？

大红花的五片花瓣与**国家原则（Rukun Negara）的五大原则**相关联。国家原则本身直到十年后、即1970年才被宣布，因此这一关联是后来建立的象征意义，并非1960年选定这朵花的最初原因。五大原则是：

1. 信奉上苍；
2. 忠于君国；
3. 维护宪法；
4. 尊崇法治；以及
5. 培养德行。

至于红色，则象征在面对一切挑战时的勇气，以及国家在政治与经济上的坚定。总体而言，大红花也被视为多元种族人民团结的象征。

## 大红花今天用在哪里？

作为国家象征之一，大红花与辉煌条纹旗（Jalur Gemilang，国旗）和国徽（Jata Negara）并列，构成马来西亚的官方形象，其图像也常出现在各类国家活动与庆典中。
