# ジャルール・グミラン（Jalur Gemilang）：なぜ13州に14本の縞があるのか

マレーシア国旗の縞を数えると14本になる。連邦の州を数えると13州になる。この食い違いは仕立て職人の誤りではない——それはある日付がもたらした結果であり、その日付は1957年8月31日ではない。

**簡潔な答え：** 14という数は1963年9月16日に定められたものであり、当時、連邦は実際に14州を有していた。それ以降、この数が調整されたことは一度もない。

## 各要素の意味

マレーシア情報局（Jabatan Penerangan Malaysia）は、マレーシア国旗について次の公式な意味を記録している。

| 要素 | 公式な意味 |
|---|---|
| 14本の赤白の縞 | 13州と一つの連邦の団結 |
| 三日月（新月） | イスラム教が連邦の宗教であること |
| 14の光条を持つ星 | 13州と連邦政府の団結 |
| 赤 | 勇気、そして困難や試練に立ち向かう覚悟 |
| 白 | 純潔、誠実、そして真摯さ |
| 濃紺 | 多民族からなるマレーシア国民の団結 |
| 黄 | 立憲君主の主権——王室の色 |

見落とされがちな点がある：縞と星が持つ数は**同じ**であり、二つの異なる意味ではない。星は縞の数を別の形で繰り返しているにすぎない。国旗の寸法も定められている——幅6フィート、長さ3フィート、比率2:1である。

## 5の光条を持つ星から11、そして14へ

この国旗はもともとマラヤ連邦旗として始まり、その光条の数は1963年より前にすでに一度変更されていた。

- **1948年5月** — 国旗デザインを募るため特別委員会が設立され、373件のデザインが寄せられた。
- **1949年11月15日** — デザインが連邦立法議会（Majlis Perundangan Persekutuan、Federal Legislative Council）に提出された。ジョホール州公共事業局（Jabatan Kerja Raya Johor、JKR Johor）の建築家モハメド・ビン・ハムザ（Mohamed bin Hamzah）のデザインが多数の支持を得て選ばれた。彼の原案は**5の光条を持つ星**であったが、議会はこれを11州の団結を示す**11の光条を持つ星**に改めるよう求めた。
- **1950年2月22～23日** — 統治者会議（Majlis Raja-Raja）が、追加の修正——三日月と星の色を白から王室の色である黄に変更する——を加えたうえで、この国旗を裁可した。
- **1950年4月19日** — 連邦立法議会が国旗案を可決し、英国王室の承認が1950年5月19日に続いた。
- **1950年5月26日** — 11本の縞を持つ国旗が、クアラルンプールのイスタナ・スルタン・セランゴール（Istana Sultan Selangor）で初めて掲げられた。
- **1957年8月31日** — 同じ国旗が、[マラヤの独立](/malaysia/independence-1957)の日にセランゴール・クラブ・パダン（Padang Kelab Selangor）で掲揚され、公の場で初めて演奏された[ヌガラク（Negaraku）](/malaysia/negaraku-anthem)が流れた。
- **1963年9月16日** — サバ、サラワク、シンガポールが連邦に加わった。縞と星の光条の数は11から14へと増えた。

その間、論理は一貫していた——国旗上の数は連邦構成員の数に従っていた。11の構成員には11本の縞。14の構成員には14本の縞。

## なぜ1965年以降も14が維持されたのか

シンガポールは1965年8月9日にマレーシアから離脱した——[マレーシア成立](/malaysia/formation-of-malaysia-1963)からわずか2年後のことである。算術的には、縞の数は13に減るはずであった。

だが減らなかった。情報局の公式記録によれば、14本の縞と14の光条を持つ星は今日に至るまでそのまま維持されているという。

代わりに読み替えられたのは**その意味**である。14番目の数は、もはやシンガポールを指すものではない——今日では連邦政府、すなわちクアラルンプール、ラブアン、プトラジャヤの連邦直轄区を指している。国旗そのものが改められたのではなく、その解釈が改められたのであり、連邦政府が一つの構成員として数えられることで、14という数は依然として正確なのである。

## 名前は遅れてやってきた

この国旗には47年間、特別な名前がなかった。命名の発案はダト・ハシム・ビン・マット・イドリス（Dato' Hashim bin Mat Idris）によるもので、1995年7月11日に第4代首相に提出された。いくつかの初期案を却下した委員会での審議を経て、国立博物館・古物局（Jabatan Muzium Negara dan Antikuiti）の職員レザワン・トゥミン（Redzuan Tumin）が提案した名前が選ばれた——**ジャルール・グミラン（Jalur Gemilang）**である。

この名称は、独立40周年を記念して1997年8月31日にムルデカ広場（Dataran Merdeka）で宣布された。その意味は一度だけ記録されている——*jalur*はまっすぐな道と共通の方向を表し、*gemilang*は輝かしさと卓越を意味する。

## よくある誤り

- **「14本の縞は14州を表す」。** マレーシアは1965年以降、14州を有したことはない。14番目の数は連邦政府である。
- **「この国旗は1957年のムルデカのためにデザインされた」。** これはマラヤ連邦のためにデザインされたものであり、1950年5月26日からすでに掲げられていた。
- **「星は最初から11の光条であった」。** モハメド・ビン・ハムザの原案は5の光条を持つ星であり、11の光条は連邦立法議会による修正である。
- **「月と星はもともと黄色であった」。** もとは白であり、黄色は1950年に統治者会議が王室の色として裁可したものである。
- **ジャルール・グミランを商業目的で自由に使用すること。** 国旗とその名称は、1963年紋章及び名称（不当使用防止）法（Akta Lambang dan Nama (Mencegah Penggunaan Tak Wajar) 1963、Akta 414）によって保護されており、2017年の改正では最高RM20,000の罰金、または最高3年の禁錮、あるいはその両方が科されると定められている。

## 次のステップ

1963年9月16日という日付そのものの背景については、[マレーシア成立](/malaysia/formation-of-malaysia-1963)を読んでほしい。11本の縞の国旗が、新たに独立した国家の国旗として最後に掲揚された日については、[1957年独立](/malaysia/independence-1957)を読んでほしい。その瞬間に流れた旋律——そしてそれがなぜ新たな作曲ではなかったのか——については、[ヌガラク（Negaraku）](/malaysia/negaraku-anthem)で語られている。
