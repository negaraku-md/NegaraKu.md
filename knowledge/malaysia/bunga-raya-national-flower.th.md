ดอกไม้เจ็ดชนิดเคยแข่งขันกันเพื่อเป็นตัวแทนของประเทศที่เพิ่งได้รับเอกราช และผู้ชนะไม่ใช่ชนิดที่หอมที่สุดหรือหายากที่สุด แต่เป็นชนิดที่รู้จักกันมากที่สุดในทุกเมืองและทุกหมู่บ้าน นั่นคือบุหงารายา (ดอกชบา)

## ใครประกาศ และเมื่อใด

ดอกชบาแดงถูกประกาศเป็นดอกไม้ประจำชาติของมาเลเซียเมื่อวันที่ **28 กรกฎาคม 1960** โดยนายกรัฐมนตรีคนแรก ตนกู อับดุล ราห์มาน ปุตรา อัล-ฮัจ (Tunku Abdul Rahman Putra Al-Haj)

ชื่อวิทยาศาสตร์ของดอกไม้นี้คือ *Hibiscus rosa-sinensis* ในบางแห่งมันยังเป็นที่รู้จักในชื่อบุหงาเซอปาตู (bunga sepatu) หรือเก็มบังเซอปาตู (kembang sepatu)

## เหตุใดจึงเป็นบุหงารายา ไม่ใช่ดอกอื่น

ในปลายปี 1958 กระทรวงเกษตรได้เสนอดอกไม้ **เจ็ด** ชนิดเป็นผู้เข้าชิงตำแหน่งดอกไม้ประจำชาติ

| ดอกไม้ผู้เข้าชิง |
| --- |
| บุหงารายา (Bunga raya, ชบา) |
| บุหงาเกอนางา (Bunga kenanga, กระดังงา) |
| บุหงาเมอลูร์ (Bunga melur, มะลิ) |
| บุหงาเจิมปากา (Bunga cempaka, จำปา) |
| บุหงาเตอราไต (Bunga teratai, บัว) |
| บุหงามาวาร์ (Bunga mawar, กุหลาบ) |
| บุหงาตันจุง (Bunga tanjung, พิกุล) |

กรมสารนิเทศยังได้ทำการสำรวจความคิดเห็นของประชาชน และตัวเลือกของประชาชนแตกต่างกันไปตามภูมิภาค ในที่สุดรัฐบาลเลือกบุหงารายาตามเกณฑ์ห้าประการ

- เป็นที่รู้จักอย่างกว้างขวางทั่วประเทศอยู่แล้ว
- มีสีและรูปทรงที่ดึงดูด
- มีชื่อที่เป็นแบบเดียวกันข้ามรัฐ
- หาได้ง่ายทุกที่ และ
- ยังไม่ได้เป็นดอกไม้ประจำชาติของประเทศอื่นใดในเวลานั้น

เกณฑ์ข้อสุดท้ายมีความสำคัญ สัญลักษณ์ของชาติควรมีความเป็นเอกลักษณ์ ไม่ใช่ใช้ร่วมกับประเทศอื่น

## กลีบทั้งห้าและสีแดงของมันมีความหมายอะไร

กลีบทั้งห้าของบุหงารายาเชื่อมโยงกับ **หลักการห้าประการของรูกุนเนอการา** รูกุนเนอการาเองเพิ่งถูกประกาศสิบปีต่อมาในปี 1970 ดังนั้นการเชื่อมโยงนี้จึงเป็นสัญลักษณ์ที่ถูกสร้างขึ้นในภายหลัง ไม่ใช่เหตุผลเดิมของการเลือกดอกไม้ในปี 1960 หลักการห้าประการนั้นได้แก่

1. ความเชื่อในพระเจ้า (Kepercayaan kepada Tuhan)
2. ความจงรักภักดีต่อพระมหากษัตริย์และประเทศชาติ (Kesetiaan kepada Raja dan Negara)
3. ความสูงส่งแห่งรัฐธรรมนูญ (Keluhuran Perlembagaan)
4. อำนาจอธิปไตยแห่งกฎหมาย (Kedaulatan Undang-undang) และ
5. ความสุภาพและศีลธรรม (Kesopanan dan Kesusilaan)

ส่วนสีแดงเป็นสัญลักษณ์ของความกล้าหาญในการเผชิญทุกความท้าทาย ตลอดจนความมั่นคงทางการเมืองและเศรษฐกิจของประเทศ โดยรวมแล้ว บุหงารายายังถูกถือว่าเป็นสัญลักษณ์ของความสามัคคีของประชาชนหลายเชื้อชาติ

## บุหงารายาถูกใช้ที่ใดในปัจจุบัน

ในฐานะหนึ่งในสัญลักษณ์ประจำชาติ บุหงารายายืนเคียงข้าง [ยาลูร์ เกอมีลัง](/malaysia/jalur-gemilang) (ธงชาติ) และตราแผ่นดิน (Jata Negara) ในฐานะใบหน้าอย่างเป็นทางการของมาเลเซีย และภาพของมันปรากฏบ่อยครั้งในกิจกรรมและการเฉลิมฉลองระดับชาติ

## อ่านต่อ

หากต้องการเข้าใจความหมายเบื้องหลังกลีบทั้งห้าของบุหงารายาอย่างลึกซึ้งยิ่งขึ้น อ่านคำอธิบายฉบับเต็มของ **หลักการห้าประการของรูกุนเนอการา** และประวัติศาสตร์การประกาศของมันในปี 1970 คุณยังสามารถสำรวจสัญลักษณ์ประจำชาติอื่น ๆ คือ ยาลูร์ เกอมีลัง และตราแผ่นดิน เพื่อดูว่าทั้งสามสิ่งประกอบกันเป็นอัตลักษณ์อย่างเป็นทางการของประเทศอย่างไร
