马来西亚共有十三个州属，但当中只有九个拥有统治者。其余四个州属——马六甲、槟城、沙巴与砂拉越——由委任产生的州元首（Yang di-Pertua Negeri）领导，而非由统治者领导。

本文列出这九个有统治者的州属，说明各自元首的称号，并说明这九位统治者如何共同构成统治者会议的一部分。本文纯属描述性质：仅陈述宪法与官方资料所载的安排，不对任何州属或统治者作出比较。

## 九个有统治者的州属

统治者御玺守护官办公室的官方网站列出九个拥有统治者的州属。当中七位元首称号为苏丹（Sultan）；一位称号为拉惹（Raja）；另一位则称号为最高统治者（Yang di-Pertuan Besar）。

| 州属 | 元首称号 |
| --- | --- |
| [柔佛](/zh/states/johor) | 苏丹（Sultan） |
| [吉打](/zh/states/kedah) | 苏丹 |
| [吉兰丹](/zh/states/kelantan) | 苏丹 |
| [森美兰](/zh/states/negeri-sembilan) | 最高统治者（Yang di-Pertuan Besar） |
| [彭亨](/zh/states/pahang) | 苏丹 |
| [霹雳](/zh/states/perak) | 苏丹 |
| [玻璃市](/zh/states/perlis) | 拉惹（Raja） |
| [雪兰莪](/zh/states/selangor) | 苏丹 |
| [登嘉楼](/zh/states/terengganu) | 苏丹 |

称号的差异并非地位高低之别，而是反映每个州属各自的历史与习俗安排。玻璃市采用拉惹这一称号，而森美兰采用最高统治者这一称号，是因为该职位的产生方式与其他州属不同——详情将于下文说明。

## 统治者在其州属中的地位

每一位统治者都是其本身州属的州元首，该地位的详情载于各自的州宪法中。

然而，有一项角色是直接载于联邦宪法之中的。第3(2)条规定，凡拥有统治者的州属，该统治者即为其州属的伊斯兰教首长，其方式与范围依该州宪法所承认及订定者为准。

对于没有统治者的州属——马六甲、槟城、沙巴与砂拉越——以及联邦直辖区而言，则由最高元首（Yang di-Pertuan Agong）担任伊斯兰教首长。这意味着伊斯兰教首长的地位，依某一州属是否拥有统治者而有所不同。

## 王位如何产生

统治者一职如何产生，是由各州属本身的宪法与习俗所订定，而非由联邦宪法所订定。在大多数有统治者的州属，该职位是依州宪法与该州本身的习俗，按血统世袭继承的。

森美兰则有其独特的安排。在该州，最高统治者是依据玻璃甲习俗（Adat Perpatih）与《森美兰州宪法》（Undang-Undang Tubuh Kerajaan Negeri Sembilan），经由四位酋长（Undang Yang Empat）——即双溪芙蓉（Sungai Ujong）、日叻务（Jelebu）、瓜拉庇朥（Johol）与林茂（Rembau）四个律法区（luak）的酋长（Undang）——协商推选产生的。这项安排正是「最高统治者」这一称号的由来：由各律法区共同拥立的元首，而非直接世袭。详情载于[森美兰](/zh/states/negeri-sembilan)的州属介绍中。

## 在统治者会议中的集体角色

在联邦层面，九位统治者共同作为统治者会议（Majlis Raja-Raja）的一部分而行事。

联邦宪法第38(1)条设立统治者会议，并依第五附表组成。第五附表第1条指出，会议由诸统治者，以及没有统治者的州属的州元首组成。因此，会议的完整成员，包括九位统治者，连同马六甲、槟城、沙巴与砂拉越的州元首。

然而，成员资格并非在一切事务上均一致。第五附表第7条将州元首排除于下列事项相关程序的成员之外：

- 最高元首的推选或罢免，以及副最高元首的推选；
- 纯粹涉及统治者的特权、地位、尊荣与位阶的事项；以及
- 宗教行为、习俗或仪式。

因此，当会议推选最高元首——依第32(3)条推选、任期五年的联邦最高元首——时，会议以九名成员的形式召开，即仅由九位有统治者的州属的统治者组成。会议的完整职能与程序，见[统治者会议](/zh/government/majlis-raja-raja)一文；而该经推选产生的职位，则见[最高元首](/zh/government/yang-di-pertuan-agong)一文。

## 这项安排如何形成

根据统治者御玺守护官办公室的资料，现代形式的统治者会议始于取代马来亚联邦（Malayan Union）的《1948年马来亚联合邦协定》（Perjanjian Persekutuan Tanah Melayu 1948）。会议的首次会议于1948年2月18日召开，由统治者御玺守护官担任秘书。

会议的成员架构随联邦的发展而扩大。1957年8月31日独立后，槟城与马六甲的州元首加入会议；1963年9月16日马来西亚成立后，沙巴与砂拉越的元首也相继加入。相关背景见[1963年马来西亚的成立](/zh/malaysia/formation-of-malaysia-1963)。在整个扩展过程中，拥有统治者的州属数目始终维持九个。

## 常见误解

**「苏丹这一称号比拉惹或最高统治者更高。」** 这三个称号皆指该州的统治者。其差异源自各州的历史与习俗，而非地位高低之分。

**「全部十三个州属都拥有统治者。」** 只有九个州属拥有统治者。马六甲、槟城、沙巴与砂拉越则由委任产生的州元首领导。

**「每一位州元首都能获选为最高元首。」** 只有九位有统治者的州属的统治者才具备资格并参与该项推选。州元首不参与最高元首推选的程序（第五附表第7条）。

**「所有统治者都以相同方式继承王位。」** 王位如何产生，由各州本身的宪法与习俗所订定。在森美兰，最高统治者是由四位酋长（Undang Yang Empat）推选产生的，而非直接世袭。
