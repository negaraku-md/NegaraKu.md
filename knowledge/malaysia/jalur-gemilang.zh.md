# Jalur Gemilang：为何14条条纹代表13个州属

数一数马来西亚国旗上的条纹，会得到14条。数一数联邦里的州属，会得到13个。这个差异不是裁缝的失误——它是一个日期造成的结果，而那个日期不是1957年8月31日。

**简答：**14这个数目是在1963年9月16日确定的，当时联邦确实拥有14个州属。此后从未再调整过。

## 每个元素的含义

马来西亚新闻部（Jabatan Penerangan Malaysia）记录了马来西亚国旗以下的官方含义。

| 元素 | 官方含义 |
|---|---|
| 14条红白条纹 | 13个州属与一个联邦的团结 |
| 新月 | 伊斯兰教为联邦的宗教 |
| 14角星 | 13个州属与联邦政府的团结 |
| 红色 | 勇气与面对阻碍及挑战的准备 |
| 白色 | 纯洁、真诚与诚恳 |
| 深蓝色 | 马来西亚多元种族人民的团结 |
| 黄色 | 立宪君主的主权——皇室颜色 |

请留意一个常被忽略的地方：条纹与星星所携带的数目是**相同**的，而不是两个不同的含义。星星只是以另一种形式重复条纹的数目。国旗的尺寸也是固定的——宽6英尺、长3英尺，比例为2:1。

## 从五角星到11角，再到14角

这面旗帜最初是马来亚联合邦旗，而其尖角数目早在1963年之前就已经变动过一次。

- **1948年5月**——特别委员会成立，负责征求国旗设计；共收到373份设计。
- **1949年11月15日**——设计提交联邦立法议会（Federal Legislative Council，当时的联邦立法机关）。柔佛公共工程局（JKR Johor）建筑师莫哈末·本·哈姆扎（Mohamed bin Hamzah）的设计获得多数票选中。他的原始设计只有**五角星**；议会要求将其改为**11角星**，以显示11个州属的团结。
- **1950年2月22–23日**——统治者会议（Majlis Raja-Raja／Conference of Rulers）恩准该旗帜，并附加一项修改：新月与星星的颜色由白色改为黄色，即皇室颜色。
- **1950年4月19日**——联邦立法议会通过国旗动议；英国王室的批准随后于1950年5月19日到来。
- **1950年5月26日**——11条条纹的旗帜首次在吉隆坡雪兰莪苏丹王宫升起。
- **1957年8月31日**——同一面旗帜在雪兰莪俱乐部草场（Padang Kelab Selangor）随着[马来亚独立](/zh/malaysia/independence-1957)升起，伴随着首次公开演奏的[《我的国家》（Negaraku）](/zh/malaysia/negaraku-anthem)。
- **1963年9月16日**——沙巴、砂拉越与新加坡加入联邦。条纹与星角数目从11增至14。

这段期间的逻辑是一致的：国旗上的数目跟随联邦成员的数目而变化。11个成员，11条条纹。14个成员，14条条纹。

## 为何1965年后14仍被保留

新加坡于1965年8月9日脱离马来西亚——即[马来西亚成立](/zh/malaysia/formation-of-malaysia-1963)两年之后。按算术推算，条纹本应减至13条。

但它没有减少。新闻部的官方记录指出，14条条纹与14角星此后一直被保留至今。

相反，被重新解读的是**含义**。第14个数目不再指新加坡；它如今指的是联邦政府——吉隆坡、纳闽与布城联邦直辖区。国旗本身没有被修改；被修改的是它的解读方式，而14这个数目之所以仍然准确，是因为联邦政府被算作一个成员。

## 名字来得很迟

长达47年，这面旗帜都没有专属名称。为其命名的构想由拿督哈欣·本·马袭迪里斯（Dato' Hashim bin Mat Idris）提出，并于1995年7月11日提呈给第四任首相。经过一轮委员会程序、否决了几份初步名单之后，博物馆与文物局（Jabatan Muzium Negara dan Antikuiti）官员Redzuan Tumin提议的名称获选：**Jalur Gemilang**。

该名称于1997年8月31日在默迪卡广场（Dataran Merdeka）宣布，以纪念独立40周年。其含义只被记录过一次：*jalur*描绘一条笔直的道路与共同的方向，*gemilang*意为光辉与卓越。

## 常见错误

- **「14条条纹代表14个州属。」**马来西亚自1965年起就不再有14个州属。第14个数目是联邦政府。
- **「这面旗帜是为1957年独立而设计的。」**它是为马来亚联合邦而设计的，早在1950年5月26日就已经开始飘扬。
- **「星星原本就是11角。」**莫哈末·本·哈姆扎的原始设计只有五角星；11角是联邦立法议会所作的修改。
- **「月亮与星星原本就是黄色的。」**它们原本是白色的；黄色是1950年经统治者会议恩准、作为皇室颜色采用的。
- **随意将Jalur Gemilang用于商业用途。**国旗及其名称受《1963年徽章与名称（防止不当使用）法令》（第414号法令）保护；2017年的修正案规定，违者可处最高RM20,000罚款或最高三年监禁，或两者兼施。
