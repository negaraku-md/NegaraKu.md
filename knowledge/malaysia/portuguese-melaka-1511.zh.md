十天。这就是葡萄牙舰队于1511年8月10日抵达马六甲海域，到这座城市于8月24日易手之间的时间差。

一百三十年后，同一座城市、同一处地点，抵御了荷兰人长达七个月的围城才投降。

这座城市并未迁移，海峡也未曾改变。改变的是它的城墙——而十天与七个月之间的这段差距，正是解释这个地区最富有的港口为何垮得如此之快的最诚实的答案。

## 根据官方记载，事情经过如下

马六甲州政府官方网站记录了一段简明扼要的事件序列：

| 日期 | 事件 |
| --- | --- |
| 1509年 | Diego Lopez de Sequiera率领葡萄牙皇家舰队的18艘船抵达 |
| 1509年 | 争执爆发；其船队遭到攻击，20名船员被扣留 |
| 1511年8月10日 | 葡萄牙驻果阿总督Alfonso d'Albuquerque抵达马六甲 |
| 1511年8月10日 | 他要求在马六甲建立葡萄牙据点的请求，遭苏丹马末沙拒绝 |
| 1511年8月24日 | 经过十天围城后，葡萄牙人攻陷马六甲城 |
| 1512年1月 | Albuquerque在完成A' Famosa（一座设有五层塔楼的城堡）后返回果阿 |

在此之前，马六甲苏丹国已统治了110年。葡萄牙人此后则统治了130年。

## 1509年的事件不仅仅是一场误会

早在Albuquerque的大炮到来两年之前，一支葡萄牙舰队就已停泊在马六甲的港口。

Sequiera的远征队于1509年率18艘船抵达，争执爆发，其20名船员被扣留。从马六甲的角度看，这是一个主权国家对停泊在自己港口内、武装的外国舰队所采取的行动。

从里斯本的角度看，这件事同时成了两样东西：一个正式的重返借口，以及马六甲可以被到达的证据。1509年的舰队并非空手而归——它带回了对这个港口的了解。

当Albuquerque于1511年8月10日抵达并要求获准建立葡萄牙据点时，请求遭到拒绝。攻击就是在这次拒绝之后开始的。

## 为何只用了十天？看看城墙

大多数解释都止步于政治因素，而错过了最能得到证实的根源。

马来西亚国家档案局（Arkib Negara Malaysia）记载，根据郑和于1409年到访马六甲时留下的记录，苏丹国时代的马六甲城由拉惹拜里米苏拉（Raja Parameswara）以**坚固的木材筑成城墙**，设有四座城门。其功能是：储存王室财宝之处，以及抵御敌人进攻的防御工事。

对于十五世纪的区域性威胁——海盗劫掠、竞争者掠夺、朝贡纠纷——这是一种完全合理的设计。但它并非为抵御舰炮轰击而设计的。

留意Albuquerque在城市陷落后立刻采取的行动。据国家档案局记载，他下令建造一座更坚固的新城堡，最初计划以木材与石料混合建造，其后设计改为**全石造**：

- 石造城墙高3.6米，厚2.4米
- 八座瞭望塔，高18至24米
- 四座入口，设有吊桥
- 60名武装守卫环绕整个防线
- 动用300至400名奴隶劳工建造

一个刚刚夺取一座城市的人，非常清楚这座城市的弱点在哪里。Albuquerque的第一项举措，正是告诉我们他认为的致命弱点所在——而他用石头修补了它。

## 验证这一点的考验：1641年

如果「城墙」理论成立，那么当石造城堡受到考验时，理应产生截然不同的结果。

它确实受到了考验。1641年荷兰人来袭时，他们需要**长达七个月**的围城，这座城市才陷落。国家档案局记载，他们在城内发现了68门大炮与74支步枪。

| 围城 | 防御工事 | 坚守时长 |
| --- | --- | --- |
| 葡萄牙人，1511年 | 木造城墙的城市，四座城门 | 10天 |
| 荷兰人，1641年 | A' Famosa，全石造，八座塔楼 | 7个月 |

这并不意味着领导层、内部分裂或外国商人的效忠不重要。这些因素确实在马六甲史学中被广泛讨论。但当同一座城市、在同一处地点，仅仅因城墙由木材换成石材，就多坚守了21倍的时间时，防御工事的技术层面理应排在解释的最前列，而不是脚注里。

马六甲之所以富裕，是因为它开放。它的财富来自于成为一个人人皆可进出的转口港——而不是来自于成为一座谁都进不去的堡垒。它的商业模式与它的防御模式，其实是同一件事，而当一支携炮而来、意图征服而非通商的舰队抵达时，这正是它的弱点所在。

> 一个依赖开放性的港口，无法被建造成一座堡垒。马六甲控制这道海峡长达一个世纪，从未需要成为堡垒——直到有人来了，而这个人并不想通商。

## 葡萄牙城堡立于王宫山丘的山脚

这个细节，用一幅画面浓缩了整个转变。

据国家档案局记载，苏丹国的王宫坐落于如今被称为圣保罗山（Bukit St. Paul，旧称Bukit Melaka）的山丘上，据信是一座宏伟的宫殿，正如敦斯里兰南（Tun Seri Lanang）所著《马来纪年》（Sejarah Melayu）中所描绘的那样。

而国家档案局记载，葡萄牙城堡则巍然屹立**在同一座山丘的山脚下**。这座曾经承载马来王宫的山丘，如今笼罩在欧洲石墙的阴影之下。

而这座城堡最终也未能留存下来。1806年，英国指挥官威廉·法夸尔（William Farquhar）将其拆毁，以阻止荷兰人重新占据，只留下我们今天所见的城门与城墙残片。

## 马六甲王室世系去了哪里？

这座城市于1511年失陷。它的体制却没有。

柔佛州政府官方网站记载，1528年，苏丹阿拉乌丁·里雅特沙（Sultan Alauddin Riayat Shah）——**出身马六甲苏丹国世系**——开辟了柔佛，并在Johor Lama立足。柔佛苏丹国官方网站记载，他又名Raja Ali或Sultan Muda，并于同年即1528年在Johor Lama的Kota Batu立国。

国家档案局的表述更为直接：马六甲陷落后，「是柔佛王国接过了马六甲此前所扮演的角色」。

**那17年的空白。** 在1511年至1528年之间，存在一段这些官方网站未曾详细记录的时期。史籍传统与历史文献提及这段期间宫廷曾迁移至若干地点。我们在此不刊载该次迁移的路线或日期，因为无法在官方来源中得到证实——可以确认的，是重新立足的那个起点：1528年，Johor Lama。

此后发生的事情表明，1511年的教训已被吸取：

| 年份 | Johor Lama的事件 |
| --- | --- |
| 1528年 | 苏丹阿拉乌丁·里雅特沙二世（Sultan Alauddin Riayat Shah II）在Johor Lama的Kota Batu立国 |
| 1540年 | Kota Batu建成——全石造，长50米，宽20米 |
| 1564年 | 亚齐发动猛烈攻击并攻陷该城堡 |
| 1576年、1578年 | 葡萄牙人的进攻被成功击退 |
| 1586年 | 葡萄牙人再次进攻失败 |
| 1587年 | 葡萄牙人借助来自果阿的援军，成功攻陷Kota Batu |

这一次城堡是石造的，而非木造——葡萄牙人需要四次尝试，加上来自果阿的援军，才得以攻破。

1587年之后，都城持续迁移。柔佛州政府网站记载，柔佛的都城沿着柔佛河迁移了多达20次，最终才落脚于廖内群岛。这支源自马六甲的王朝一直统治到1699年，此后该邦国的政权转由Bendahara王朝接掌。

也就是说：[马六甲苏丹国](/zh/malaysia/melaka-sultanate)的王宫世系，在马六甲城本身失陷之后，又延续了188年。

## 欧洲时代在马来群岛的开端

1511年常被称为欧洲在这个地区殖民的开端。就时间顺序而言，这没有错——但其规模需要被正确理解。

| 时期 | 统治力量 | 时长 |
| --- | --- | --- |
| 1511-1641年 | 葡萄牙 | 130年 |
| 1641-1795年 | 荷兰 | 154年 |
| 1795年以后 | 英国 | 1824年伦敦条约；1826年海峡殖民地 |

1511年易手的，是一座港口城市及其所控制的海峡——而不是整个半岛。欧洲列强其后花了三个世纪扩大这一控制范围，而上表这条时间线，最终止于[1957年独立](/zh/malaysia/independence-1957)。

## 常见误解

**「马六甲苏丹国于1511年终结。」** 终结的是这座城市。王室体制得以延续：马六甲世系的马来统治于1528年在Johor Lama恢复，该王朝一直延续至1699年。

**「今天矗立的A' Famosa就是葡萄牙城堡。」** 如今留存的只是城门与城墙的残片。真正的城堡已于1806年被威廉·法夸尔拆毁。

**「马六甲陷落纯粹是因为防御薄弱，仅此而已。」** 它的城市确实是木造城墙没错——但那是为区域性威胁而设计的，而非为携炮舰队而设计。这种薄弱是技术世代上的落后，而不仅仅是疏忽。

**「1511年意味着葡萄牙人殖民了整个马来半岛。」** 葡萄牙人控制的是马六甲城及其海峡。他们对半岛内陆的影响，远比常被描绘的要有限得多。

**「马六甲从未抵御过长期围城。」** 同一座城市在1641年抵御了荷兰人长达七个月。差别就在于石头。

## 下一步

如果你想了解1511年8月真正失去的是什么——历经110年建立起来的语言、宫廷法律、政权结构与贸易网络——不妨从[马六甲苏丹国](/zh/malaysia/melaka-sultanate)读起。

如果你想看看这个半岛的立国历史，究竟能追溯到马六甲存在之前多远，[狼牙修](/zh/malaysia/langkasuka)是一个有用的起点。
