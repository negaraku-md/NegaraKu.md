这条时间线把马来西亚历史呈现在一个视图里——从早期王国与马六甲苏丹国，历经数百年殖民统治，
到独立、现代联邦的形成，以及今天的政治。每个事件按时代分组，让故事的整体轮廓在细节之前先
清晰呈现。

## 早期王国与马六甲苏丹国

| 年份 | 事件 |
| --- | --- |
| 约1400 | 拜里米苏拉建立马六甲苏丹国，发展为重要的马来贸易帝国与伊斯兰传播中心。 |
| 1511 | 阿方索·德·阿尔布克尔克率领的葡萄牙军队攻占马六甲，开启数百年的欧洲势力。 |

## 殖民时期

| 年份 | 事件 |
| --- | --- |
| 1641 | 荷兰与柔佛结盟，从葡萄牙手中夺取马六甲。 |
| 1786 | 弗朗西斯·莱特为东印度公司在槟榔屿建立英国贸易据点。 |
| 1824 | 《英荷条约》划分区域，将马来半岛纳入英国势力范围。 |
| 1826 | 槟城、马六甲与新加坡合并为海峡殖民地。 |
| 1874 | 《邦咯条约》引入英国参政司制度，扩大对马来各州的殖民控制。 |
| 1896 | 霹雳、雪兰莪、森美兰与彭亨组成马来联邦。 |

## 占领与迈向独立

| 年份 | 事件 |
| --- | --- |
| 1941–45 | 二战期间日军占领马来亚与婆罗洲，直至1945年投降。 |
| 1946 | 马来亚联邦方案引发广泛反对；巫统应运而生。 |
| 1948 | 马来亚联合邦取代马来亚联邦；对抗共产党叛乱的紧急状态开始。 |
| 1957 | 马来亚联合邦于1957年8月31日独立，东姑阿都拉曼出任首任首相。 |

## 马来西亚的形成

| 年份 | 事件 |
| --- | --- |
| 1963 | 马来西亚于1963年9月16日成立，联合马来亚、沙巴、砂拉越与（短暂的）新加坡。 |
| 1965 | 新加坡脱离马来西亚，成为独立共和国。 |
| 1969 | 大选后吉隆坡爆发族群冲突，导致国家宣布进入紧急状态。 |

## 现代马来西亚

| 年份 | 事件 |
| --- | --- |
| 1971 | 新经济政策启动，旨在1969年后消除贫困并重组社会。 |
| 1981 | 马哈迪·莫哈末出任第四任首相，开启22年快速现代化任期。 |
| 1997–98 | 亚洲金融危机冲击马来西亚；政府实施资本管制应对。 |
| 2018 | 第14届大选促成马来西亚独立以来首次联邦政权更替。 |
| 2022 | 安华·依布拉欣出任第十任首相，在悬峙国会后领导团结政府。 |
