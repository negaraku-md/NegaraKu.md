たいていの新しい鉄道は、人々をどこか新しい場所へ運ぶために建設される。MRT3サークル線が建設されるのは、クアラルンプールがすでに持っている路線を結び合わせるためだ——その主たる役目が被覆ではなく接続である、市を取り巻く一つのリングである。

それはまた、この国の交通史のなかでも最も二転三転した事業の一つでもある。提案され、前倒しされ、2018年に中止され、復活し、そして2025年にようやく用地取得が認められた——その間ずっと、費用の見積もりは動き続けてきたのだ。

## MRT3とは正確には何か

MRT3サークル線は、クランバレーで計画されている**3本目の大量高速輸送路線**であり、クアラルンプール中心部を貫くのではなく、その縁を環状に回る**全長約51.6kmのループ**である。既存のMRT路線が市を横断する放射状のルートであるのに対し、MRT3は**環状線**であり、高速輸送ネットワークを一つのリングに閉じる。

保有者は、MRT1 Kajang LineとMRT2 Putrajaya Lineも保有する政府系企業**Mass Rapid Transit Corporation（MRT Corp）**である。運行は、残りのメトロを運行するのと同じPrasaranaの子会社**Rapid Rail**が担う設計で、4両編成の車両を用い、時速約100kmで走る**完全自動・無人運転**の路線となる。ループを一周する全行程は約75分と見積もられている。

承認された計画は約**33の駅**を描いており、**高架26・地下7**と報じられ、**2つの車両基地**が支える。線形のうち約**11.9kmがトンネル内**で、残りは高架である。MRT3が接続しようとするLRT、KL Monorail、KTMの各サービスとどう組み合わさるかについては、ネットワーク概観 [クアラルンプールのMRT、LRT、KL Monorail、KTMの各路線はどうつながるか](/ja/transport/klang-valley-rail/) を参照。

## 環の眼目：インターチェンジ

MRT3が重要なのは、その**インターチェンジ駅**にある。その停車駅のうち約**10**が他の路線に接続するよう設計されており、乗客はまず中央業務地区に吸い込まれることなく、市の反対側の郊外どうしを移動できる。承認された線形の接続地点には以下が含まれる（駅名とコードは開業前に変わる可能性がある）。

| インターチェンジ駅 | 接続先 |
| --- | --- |
| Bukit Kiara Selatan | MRT Kajang Line (MRT1) |
| Titiwangsa | LRT Ampang Line, LRT Sri Petaling Line, KL Monorail, MRT Putrajaya Line (MRT2) |
| Setiawangsa | LRT Kelana Jaya Line |
| Pandan Indah | LRT Ampang Line |
| Taman Midah | MRT Kajang Line (MRT1) |
| Salak Selatan | LRT Sri Petaling Line |
| Kuchai | MRT Putrajaya Line (MRT2) |
| Pantai Dalam | KTM Komuter (Port Klang Line) |
| Universiti | LRT Kelana Jaya Line |

Titiwangsaは際立った結節点で、複数の路線を一点に集める。西側には、KTM Komuter線と接続する暫定駅も計画されている。正確な最終リストは下記で確認対象として挙げている。

## MRT1・MRT2とどう違うか

3本のMRT路線は同じ保有者、運行者、無人運転技術を共有するが、果たす役割は異なる。

- **MRT1、Kajang Line**は、最初に開業したMRT路線である。クランバレーを**放射状**に横断し、都心の地下を通ってからKajangに向けて高架軌道へと上がる。
- **MRT2、Putrajaya Line**は、2本目の放射状路線で、ネットワーク最長の地下区間を持つ長いルートを、Kwasa DamansaraからPutrajayaまで走る。
- **MRT3、Circle Line**は、中心部を横断するのではなく、その**周りを**回る。それ自体はほとんど新規の集客圏を加えない。その価値は、別々の放射状路線の集まりを一つの統合されたリングに変える連絡路としてのものである。

ネットワークで言えば、MRT1とMRT2はスポーク、MRT3はリム（外輪）である。

## 費用：動き続ける数字

MRT3の費用は、この物語のなかで最も慎重に扱うべき部分である。情報源によって、対象範囲ごとに異なる数字が引用されるからだ。

- MRT Corpは**約RM310億の建設費**を示しており、これはPutrajaya Lineと広く比較できる。
- **用地取得**（数十億リンギ規模と報じられる）やその他の費用を加えると、約**RM390億**というより広い総額が報じられ、高い方では約**RM500億**という見出しの数字も現れている。
- **2023年予算**は、事業を再評価し、総支出を**RM450億未満**に抑える目標を設定した。

したがって同じ事業でも、数字が建設費のみを指すのか、すべてを含めた総額を指すのかによって、RM310億の路線ともRM500億の路線とも表現できる。確定した一つの公式な総額はまだ定まっておらず、だからこそ費用は確認対象として挙げられている。

## 中止、復活、承認

事業の経緯は、技術的であると同時に政治的でもある。

- **2010年代**——MRT3はクランバレーMRT計画の最終路線として提案され、時には前倒しされた。
- **2018年5月30日**——新たに選出された政府が財政上の理由で事業を**中止**する。
- **2019年末**——事業はアンソニー・ローク運輸大臣によって**見直し**に付される。
- **2021年**——再び進めるための**閣議承認**。調査と線形が練られる。
- **2022年3月4日**——政府がMRT3を**再確認**。線形は約50.8kmで、のちに上方修正された。
- **2024年9月〜12月**——**公開縦覧**が大規模な意見を集め、圧倒的に支持的だったと報じられる。
- **2025年7月17日**——運輸大臣が**最終鉄道計画**を承認し、**用地取得**への道を開く。必要な用地区画は**1,012から690に**削減される。
- **2026年末**——用地取得の完了が目標とされ、建設への道を整える。
- **約2027年から**——建設開始が見込まれ、**開業目標は2028年の段階的開始から2032年ごろの全線開業まで幅がある**。

これらの期日は過去にも後ろ倒しになってきた——最も劇的だったのは2018年の中止である——ため、現在の建設・開業スケジュールは、まさに決めつけるのではなくMRT Corpに確認すべき種類の情報である。

## よくある誤解

- **MRT3を完成済み、または現在建設中と扱うこと。** 2026年末時点では、2025年7月の計画承認を受けた用地取得の段階にあった。開業日は事実ではなく目標である。
- **一つの費用を唯一の費用として引用すること。** 約RM310億は建設費の数字であり、用地を含めた総額ははるかに高く、約RM500億まで報じられている。
- **MRT1・MRT2のような放射状路線だと思い込むこと。** それは市を取り巻くループであり、中心部を貫くのではなく既存の路線を結ぶために建設される。
- **クアラルンプール〜シンガポール高速鉄道と混同すること。** 両者はまったく別個の事業である。MRT3はクランバレーの都市メトロ・ループであり、[クアラルンプール〜シンガポール高速鉄道](/ja/transport/kl-singapore-high-speed-rail/) は都市間路線の構想である。

## 次に何が起きるか

注目すべきシグナルは具体的である。MRT Corpが最終的な費用と建設・開業の期日を確定すること、用地取得の完了、主要建設パッケージの発注、そして最終的な駅リストとインターチェンジの設計だ。契約が交わされ、着工されるまでは、費用もスケジュールも、さらには駅数さえも、確定した結果ではなく検証すべき作業中の数字として扱うべきである。

この路線が完成させようとするより広いネットワークについては、[クアラルンプールのMRT、LRT、KL Monorail、KTMの各路線はどうつながるか](/ja/transport/klang-valley-rail/) を参照。そしてこの国のもう一つの看板鉄道事業については、[クアラルンプール〜シンガポール高速鉄道](/ja/transport/kl-singapore-high-speed-rail/) を参照されたい。
