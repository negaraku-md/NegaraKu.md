侵入者が真夜中にあなた自身の家であなたを襲う——その瞬間、マレーシアの法律はあなたに反撃を認めるのか。認める、ただし厳格な条件付きであり、合法な防衛と犯罪との境界線は、多くの人が思うよりもずっと細い。

> **法的助言ではない。** 本ガイドは、教育的な目的のために刑法典の規定を一般的に説明するものである。各事案は、裁判所によってそれ自身の事実に基づいて評価される。何らかの事件に巻き込まれた場合は、直ちに登録弁護士の助言を求めること。

## 法律上の正当防衛権とは何か

刑法典（Act 574）は、s.96からs.106において「正当防衛権」（right of private defence、私的防衛）を定めている。s.96は、この権利を行使する際に行われたことは罪にはならないと明確に規定している。s.97は、s.99の制限に従うことを条件に、すべての人に次の2つのものを防衛する権利を与えている：

- 自己又は他人の**人身**——人の身体に影響を及ぼすあらゆる罪に対して；及び
- 自己又は他人の**財産**（動産又は不動産）——窃盗、強盗、損壊（*mischief*）又は刑事的侵害、あるいはそれらの未遂に対して。

## いつ相手を死亡させる程度にまで達することができるのか

これは最も重要な限界である。s.100によれば、人身を防衛する権利は、次の6つの状況においてのみ、攻撃者を死亡させることにまで及ぶ：

| s.100 のもとでの状況 | その意味 |
| --- | --- |
| (a) 合理的に**死亡**の懸念を生じさせる攻撃 | あなたの命が現実の危険にさらされている |
| (b) 合理的に**重傷害**（*grievous hurt*）の懸念を生じさせる攻撃 | 重大な負傷のリスク |
| (c) **強姦**の意図をもつ攻撃 | |
| (d) **反自然的な情欲**を充足する意図をもつ攻撃 | |
| (e) **誘拐又は拐取**の意図をもつ攻撃 | |
| (f) **不法な監禁**の意図をもつ攻撃 | 被害者が当局の援助を求められない状況において |

攻撃がこのリストに含まれない場合、s.101はあなたが攻撃者を傷つけることのみを認める——殺すことは認めない。

## 遵守しなければならない限界とは何か

s.99 は厳格な境界を定めている：

- **合理的な限度。** 防衛権は、防衛の目的に必要な限度を超えて傷害を加えることには決して及ばない（s.99(4)）。過度の反応は犯罪となり得る。
- **まず公的な手段を用いること。** 公的機関の保護を求める時間がなお残っている場合、正当防衛権は存在しない（s.99(3)）。
- **公務員に対して。** その職務の名目のもとで善意で行動する公務員に対しては、その行為が死亡又は重傷害についての合理的な懸念を生じさせる場合を除き、防衛権は存在しない（s.99(1)）。

## この権利はいつ始まり、いつ終わるのか

s.102 はそのタイミングを明らかにしている：この権利は、企て又は脅威によって人身に対する合理的な危険の懸念が生じた時点で——たとえその罪がまだ実行されていなくても——始まり、その危険の懸念が続いている間のみ存続する。つまり、脅威が終わった後も攻撃を続けることはできない；その後も継続する行為は、防衛ではなく報復的な攻撃とみなされ得る。

## 財産を防衛できるのか

できる。s.103 は、財産を防衛する際に相手を死亡させる程度の行為を、特定の罪に限って認めている：強盗、夜間の住居侵入（*housebreaking by night*）、人が居住する建物又は財産の保管場所に対する放火（*mischief by fire*）、あるいは死亡又は重傷害の懸念を合理的に生じさせる状況における窃盗／損壊／住居への侵害である。その他の事案については、s.104 は死亡ではなく傷害のみを認める。さらに s.106 は、致死的な攻撃から自らを防衛する際に、無実の者を傷つけるリスクを負わざるを得ない場合に、あなたを保護する。

## 裁判所はこの抗弁をどのように評価するのか

s.96 は、この権利が合法的に行使される場合には罪が成立しないと規定しているため、正当防衛は完全な抗弁として機能する——認められれば、被告人を無罪とする。しかしその立証と評価は厳しい：裁判所は各事案をそれ自身の事実に基づいて衡量し、脅威に対する行為の合理性と均衡に重点を置く。実務上、法律上の論評は、防衛を行った側が「クリーンハンド」であるか、現実の又は合理的に信じられた危険が存在したか、安全な逃走経路がなかったか、そして用いられた実力が本当に必要であったか——選択肢がない場合を除き、対決よりも逃走が一般的に望ましいとされる——といった要素を挙げている（Aaron Mathews Advocates & Solicitors, "Self-Defence 101"）。これは、必要を超えた反応が抗弁の失敗を招き得ることを意味する。

## 次のステップ

正当防衛権は法律上の完全な抗弁となり得るが、裁判所はあなたの行為の合理性と均衡に基づいて事案ごとに評価する。本ガイドは法的助言ではない。このような事件に巻き込まれたことがある場合は、直ちに法的助言を求め、あらゆる証拠を保存すること。*grievous hurt*（重傷害）や刑事的侵害といった用語をより正確に理解するには、マレーシア司法長官府の公式 e-LoM ポータルにある刑法典（Act 574）の全文を参照すること。
