拦下路障、报案失窃，或提交行为不当投诉——这些事务最终都汇集到同一个机构的门前：马来西亚皇家警察。与许多把警务职责分割给州级和联邦部队的国家不同，马来西亚把从巡逻警察到情报的一切，全都统合在一个中央集权的指挥框架之下。

## 是什么设立了 PDRM？

PDRM 根据**《1967年警察法令》（第344号法令，Akta 344）**设立。第3条规定该部队"shall … be employed in and throughout Malaysia"，以维护法律与秩序、维持国家的和平与安全、预防和侦查犯罪、逮捕并起诉罪犯，以及收集安全情报。

这使 PDRM 成为一支**全国性且中央集权**的部队——其管辖权覆盖整个马来西亚，包括领海，而不仅限于某一个州。其总部为吉隆坡的**武吉阿曼（Bukit Aman）**，部队隶属**内政部（KDN）**运作。

## 谁掌握指挥权？

《1967年警察法令》第4条规定部队"under the command of an Inspector General"——即**全国总警长（KPN）**——此人必须是一名警官，并就部队的管控与指挥"responsible to the Minister"（对部长负责）。另设一名**副全国总警长**，在其指挥下行事，并可在总警长缺席时行使其职能。

高层领导的任命链——总警长、副总警长、各位专员及副专员——由第5条规定。每名成员的一般职责则载于第20条：遵从上级警官的合法指令，并执行第3(3)条的宗旨，包括逮捕罪犯、处理安全情报及进行起诉。

## 警衔如何编制？

PDRM 设有**18个警衔级别**，分为两大类。《1967年警察法令》将*高级警官（senior police officer）*定义为从总警长至见习督察的级别，将*初级警官（junior police officer）*定义为从副督察至下士的级别。

| 类别 | 警衔（由高至低） |
|---|---|
| 高级警官 | 警察总监（总警长 KPN）· 副警察总监 · 专员 · 副专员 · 高级助理专员 · 助理专员 · 警监 · 副警监 · 助理警监 · 督察 · 见习督察 |
| 初级警官及警员 | 副督察 · 上士 · 中士 · 下士 · 一等警长 · 警员 · 见习警员 |

## 它的主要部门有哪些？

在武吉阿曼，PDRM 的工作分配给**10个主要部门**，每个部门由一名专员或同等级别的总监领导。

| 部门 | 核心职能 |
|---|---|
| 管理部门 | 行政、人力资源及企业事务 |
| 刑事侦查部（JSJ） | 刑事侦查与起诉 |
| 麻醉品刑事侦查部（JSJN） | 与毒品相关的罪行 |
| 商业罪案侦查部（JSJK） | 白领与商业犯罪 |
| 后勤资源与科技部 | 财务、后勤及科技支援 |
| 内部安全与公共秩序部（JKDNKA） | 行动部门，公共秩序管控 |
| 政治部（特别部门） | 情报与安全事务 |
| 廉政与标准合规部（JIPS） | 内部廉政与投诉 |
| 犯罪预防与社区安全部 | 犯罪预防与社区安全 |
| 交通侦查与执法部 | 交通法令执法 |

## 谁监督警察？

除了在总警长指挥下的内部纪律外，还有两个法定机构监督执法人员的行为：

- **警察行为独立委员会（IPCC）**——专门针对 PDRM 的机构，根据**第839号法令（2022年）**设立。该法令于2022年10月8日获得御准，2022年10月18日宪报颁布，**2023年7月1日**生效，IPCC 于**2023年11月1日**开始运作。它监察、调查并处理针对 PDRM 成员的行为不当投诉，并向国会提交年度报告。
- **执法机构廉政委员会（EAIC）**——根据**第700号法令（2009年）**设立，2009年9月3日宪报颁布，**2011年4月1日**生效。EAIC 对**21个执法机构**拥有管辖权，可接受投诉、展开调查，并将纪律或刑事案件转介给相关当局。

## 接下来该怎么做

- 通过 IPCC 或 EAIC 门户，或 PDRM 内部的 JIPS 渠道提交行为不当投诉。
- 阅读《1967年警察法令》（第344号法令）全文，了解有关权力与纪律的完整条文。
- 参阅 rmp.gov.my 上各部门的官方页面，了解详细职能与联系方式。
