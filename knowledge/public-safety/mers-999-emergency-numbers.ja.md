たった一つの番号——**999**——が、あなたを警察、救急車、消防、民間防衛、または海上支援のいずれが必要であっても、マレーシアの五つの緊急対応機関へつなぐ。機関ごとに別々の番号を覚える必要はない。背後のシステムが、その通報をあなたに代わって振り分けてくれる。

## 999を押すと何が起こるのか？

あなたの通報は**Malaysian Emergency Response Services（MERS 999）**の指令センターに入る。これは五つの機関の緊急サービスを一つの番号のもとに統合した統合システムである。担当者が緊急事態の種類、場所、重要な情報を特定し、その通報とデータを正しい機関へ振り分ける。

このシステムは、コンピュータ支援出動指令、地理情報システム（GIS）、電話・コンピュータ連携インターフェース、音声録音、医療エキスパートシステムといった技術で構築されており——すべての機関を通じて通報が一貫して処理されるようになっている。999への通報は**無料**であり、いたずら通報を防ぐために**記録され追跡される**。MERS 999は、マレーシア政府とTelekom Malaysia Berhadの協力によって運営されている。

## 999を通じてどの機関に連絡できるのか？

一件の999通報は、以下の五つの機関すべてに届く：

| 機関 | 連絡すべき場面 |
| --- | --- |
| マレーシア王立警察（PDRM） | 犯罪、交通事故、公共の安全 |
| 消防救助局（JBPM／BOMBA） | 火災、救助活動 |
| マレーシア保健省（救急車／病院） | 医療緊急事態 |
| 民間防衛隊（JPAM／APM） | 人道支援、災害 |
| [マレーシア海事法令執行庁](/public-safety/maritime-enforcement-agency-mmea)（APMM） | 海上の緊急事態 |

## 991と994はどのようにして一つになったのか？

かつては、人々は別々の番号を覚えておかなければならなかった。**991**（民間防衛）回線は1995年5月21日に導入され、クアラルンプールから始まり、2000年12月13日までに全国へ拡大された。

**2007年10月1日**、四つの機関——民間防衛（JPAM）、警察（PDRM）、保健（KKM）、消防（JBPM）——が一つの番号999のもとに統合され、991や994といった旧番号に取って代わった。海事法令執行機関（APMM）は後に加わり、今日の合計五つの機関となった。二つのMERS通報センターは2008年に本格的に稼働を開始し、2012年までにサバとサラワクを含む**七つの州**が追加されて対応範囲が拡大された。今日では、あらゆる緊急事態に999を使う。

## SaveME 999と次世代システムとは何か？

**2025年11月16日**、Telekom Malaysiaは通信省と協力し、全国800か所以上で**次世代MERS 999（NG MERS 999）**を導入した。この新システムは以下を追加した：

- AIを活用した分析および位置情報サービス
- **Advanced Mobile Location（AML）**による、より正確な発信者の位置特定
- 五機関統合プラットフォーム
- 安全な主権クラウドホスティング

音声通話を補完するのが**SaveME 999**アプリである。ユーザーは**動画・テキスト・マルチメディア**による緊急通報と**GPS**データを送信でき、障害者（OKU）向けのアクセシビリティ機能も備わっている。これは、聴覚障害や発話障害のある人も、音声通話なしで999の担当者に連絡できることを意味する。

| チャネル | 用途 | 備考 |
| --- | --- | --- |
| 999通報 | あらゆる緊急事態 | 無料、記録・追跡される |
| SaveME 999アプリ | 動画／テキスト／マルチメディア通報 + GPS位置情報 | 障害者（OKU）向けアクセシビリティを含む |

## いたずら通報をするといくらの罰金になるのか？

緊急回線は冗談のためのものではない。MERS 999公式ポータルによれば、いたずら通報は**1998年通信・マルチメディア法s.233(2)**のもとで、**最高RM500,000の罰金または最長2年の禁錮、あるいはその両方**が科されうる。すべての通報が記録され追跡されるため、この回線の濫用は容易に検出される——そして一件のいたずら通報が、本当に助けを必要とする人への支援を遅らせかねない。

## 次のステップ

- **999を保存**して主要な緊急通報番号とし、緊急時にすぐ使えるよう、SaveME 999アプリを早めにダウンロードしておく。
- **何を伝えるべきか知っておく：**緊急事態の種類、できる限り正確な場所、関係する人数を伝えることで、対応が速くなる。
