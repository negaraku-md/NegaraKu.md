一名入侵者在半夜闯进你的住家袭击你——在那一刻，马来西亚法律允许你还击吗？允许，但附带严格的条件，而合法防卫与犯罪之间的界线，比许多人想象的要细得多。

> **并非法律意见。** 本指南以一般性、教育性的方式解释《刑事法典》的条文。每一起事件都由法院根据其本身的事实来评断。若你卷入任何事件，请立即咨询注册律师。

## 法律上的自卫权是什么？

《刑事法典》（第574号法令）在第96至106条中规定了「自卫权」（right of private defence）。第96条明确指出，行使这项权利时所做的任何事都不构成罪行。第97条赋予每个人防卫以下两样东西的权利，但须受第99条限制：

- 自己或任何他人的**人身**，以对抗任何侵害人身的罪行；以及
- 自己或他人的**财产**（动产或不动产），以对抗盗窃、抢劫、损坏（*mischief*）或刑事侵入，或其未遂行为。

## 我在什么时候可以采取致命的行为？

这是最重要的限制。根据第100条，人身防卫权只有在以下六种情形下才延伸至致使袭击者死亡：

| 第100条下的情形 | 含义 |
| --- | --- |
| (a) 合理地引起对**死亡**担忧的袭击 | 你的生命面临实际危险 |
| (b) 合理地引起对**严重伤害**（*grievous hurt*）担忧的袭击 | 存在严重受伤的风险 |
| (c) 带有**强奸**意图的袭击 | |
| (d) 带有满足**反常情欲**意图的袭击 | |
| (e) 带有**绑架或诱拐**意图的袭击 | |
| (f) 带有**非法监禁**意图的袭击 | 在受害者无法求助于当局的情况下 |

若袭击不属于此列表，第101条只允许你伤害袭击者——而不能杀死他。

## 我必须遵守哪些限制？

第99条设下了严格的界限：

- **合理限度。** 防卫权绝不延伸至造成超出防卫目的所需限度的伤害（第99(4)条）。过度的反击可能构成犯罪。
- **先使用官方途径。** 若仍有时间寻求公共当局的保护，则不存在自卫权（第99(3)条）。
- **针对公职人员。** 对于本着善意、依其职位名义行事的公职人员，不存在防卫权，除非该行为引起对死亡或严重伤害的合理担忧（第99(1)条）。

## 这项权利何时开始、何时结束？

第102条说明了时点：这项权利在因企图或威胁而对人身产生合理担忧危险时即开始——即使罪行尚未实施——并且仅在该担忧危险持续期间才存续。也就是说，你不能在威胁结束后继续攻击；此后仍持续的行为可能被视为报复性袭击，而非防卫。

## 我可以防卫财产吗？

可以。第103条只允许在防卫财产时针对某些特定罪行采取致使对方死亡的行为：抢劫、夜间破门入屋（*housebreaking by night*）、针对有人居住的建筑或财物存放处所纵火（*mischief by fire*），或在合理引起对死亡或严重伤害担忧的情况下的盗窃/损坏/入屋侵入。对于其他情形，第104条只允许造成伤害，而不允许致死。此外，第106条保护你：若在抵御致命袭击时，你不得不承担伤及无辜者的风险，你仍受保护。

## 法院如何评断这项抗辩？

由于第96条规定，在合法行使这项权利时不构成任何罪行，自卫因而作为一项完全抗辩发挥作用——一旦被接纳，即可使被告脱罪。然而其举证与评断都很严苛：法院根据每起案件本身的事实来衡量，重点在于行为相对于威胁的合理性与限度。在实务中，法律评论列出了诸如以下因素：进行防卫的一方是否「手净」（无过错）、是否存在实际或合理相信的危险、是否缺乏安全的逃离路线，以及所使用的力量是否确实必要——除非别无选择，否则逃离通常比对抗更受青睐（Aaron Mathews Advocates & Solicitors, "Self-Defence 101"）。这意味着超出必要限度的反击可能导致抗辩失败。

## 接下来该怎么做

自卫权在法律上可以成为一项完全抗辩，但法院会根据你行为的合理性与限度逐案评断。本指南并非法律意见。若你曾卷入此类事件，请立即咨询法律意见并保存任何证据。若要更准确地理解诸如*grievous hurt*（严重伤害）或刑事侵入等术语，请参阅总检察署官方 e-LoM 门户上《刑事法典》（第574号法令）的完整文本。
