クチンの弁護士にペナンの土地権原をNational Land Codeに照らして確認してもらったとしても、
正直な答えは「ここでは適用されない」というものになる。マレーシアが単一の法令ではなく、
三つの別個の土地法令のもとで運用されているというこの一点こそ、多くの概説が見落として
いる部分である。

## 概要

| | |
| --- | --- |
| 略称 | National Land Code 1965 |
| 法令番号 | Act 828（原名 Act 56 of 1965） |
| 施行日 | 1966年1月1日、Legal Notice 474/1965による |
| 憲法上の根拠 | 連邦憲法第76(4)条——州リスト事項の統一性確保 |
| 地域的適用範囲 | マレーシア半島の十一州 |
| 運用する制度 | トーレンス制度（Torrens）——登記による権原 |
| 対象外 | サバ、サラワク——それぞれ独自の土地法令を有する |

## 「トーレンス」が実際に何を変えたのか

本法令のような登記制度が登場する以前、世界の多くの地域で土地所有権は証書（deeds）に
依拠していた：一連の私的文書の連鎖であり、その一つひとつは、それ以前の文書と同程度に
しか信頼できず、買主の安全性は、その連鎖をどこまで遡って追跡できるかにかかっていた。

トーレンス制度は、19世紀の南オーストラリアの改革者サー・ロバート・トーレンス
（Sir Robert Torrens）にちなんで名付けられ、この構図を転換した。**登記こそが権原で
ある。** 所有権は古い書類を提示することによって証明されるのではなく、いま現在、登記官
（Registrar）がその土地について誰の名前を記入しているかによって証明される。

National Land Codeは、この制度を単一の法令としてマレーシア半島にもたらし、それ以前に
存在していた雑多な州の土地法令に取って代わった——それらの法令は本法典によって正式に
廃止され、Eleventh Schedule（第十一附則）に列挙されている。

## 登記こそが行為であり、署名ではない

本法典のもとでは、譲渡、賃貸借、または担保権設定の文書に署名しただけでは、土地に関す
るいかなる権益も移転しない。当該文書は、登記処権原（Registry title）の土地であれば
登記官（Registrar of Titles）に、土地局権原（Land Office title）の土地であれば
土地行政官（Land Administrator）に提出され、記入されなければならない。その記入のみ
が、取引を完成させる。

この一貫した機械的な規則こそが、登記簿を額面どおり信頼するに足るものにしている——そし
てそれこそがトーレンス制度の眼目である。

## 不可争性——そしてその限界

本法典のSection 340は、登記された所有者（registered proprietor）の権原または権益に
**不可争性（indefeasibility）**を与える：いったんあなたの名前が登記簿に記載されれば、
あなたの権原は何人に対しても有効であり、後になって異議を唱える者は、単に登記されてい
ない以前の主張を提示するだけでは、通常これを覆すことができない。

この保護は絶対的なものではない。同条は、登記そのものが詐欺または偽造によって取得され
た場合、不十分または無効な文書によって取得された場合、あるいは同条が別途定めるその他
の事情がある場合について、例外を設けている——これらの状況は、「繰延不可争性
（deferred indefeasibility）」の法理のもとで、マレーシアの裁判所が数十年にわたって
処理してきたものである。個々の事案以上に重要なのはこの仕組みそのものである：不可争性
が保護するのは登記簿であって、名前が登記簿に載るに至った経路のすべてが保護されるわけ
ではない。

## 制度の背後でも土地は依然として州が所有する

登記は州の所有権を消滅させるものではない。土地は連邦憲法のもとで依然として州の事項で
あり、本法典はそれを実務に落とし込んでいる：**州政府（State Authority）**（州の行政
上の助言に基づいて行動する統治者または州元首）が、そもそも州有地を払下げ、その土地の用
途区分を定め、その後の大半の取引——譲渡、賃貸借、担保権設定、用途区分の変更を含む——
について同意を与えなければならない。本法典は取引に統一的な仕組みを与えるものであり、
土地に関する憲法上の根本的な所有権を各州から奪うものではない。

## なぜ十一の州議会ではなく国会が制定したのか

土地は連邦憲法のNinth Schedule（第九附則）の**州リスト（State List）**に属する事項で
あり——通常は州議会のみが規律できる事項である。それにもかかわらずNational Land Code
が単一の連邦法令として存在するのは、**第76(4)条**が、**法律と政策の統一**という限定
された目的のために、国会が州リスト事項について立法することを認めているからである。国
会はまさにこの権限を用いて本法典を制定した——それゆえ本法典は、各州が個別に採用する必
要なく、半島の十一州すべてに統一的に効力を及ぼすこととなった。

## 本法典が意図的に手を付けなかったもの

本法典は、土地に関連するあらゆる制度を自らのうちに吸収しているわけではない。本法典は
以下を含む、いくつもの並行制度を明示的に維持している：

- マレー人保留地、ならびに慣習地および統治者の土地
- 鉱業権
- wakaf（イスラム寄進財産）とbaitulmal（イスラム公庫）
- クランタン土地入植法1955（Kelantan Land Settlement Act 1955）、トレンガヌ入植法令
  （Terengganu Settlement Enactment）、プルリス土地入植法令（Perlis Land Settlement
  Enactment）、集団入植地域法1960（Land (Group Settlement Areas) Act 1960）など、各州
  固有の入植関連法令

これらのいずれかに関する問題には、本法典の一般規定ではなく、それぞれ固有の法令が必要
となる。

## サバとサラワク：まったく別の法典

これは、多くの簡潔な解説が見落としがちな点である。National Land Codeは、サバまたは
サラワクに**適用されたことが一度もない**。両州はそれぞれ独自の、より古い土地法令を維
持している：

| 地域 | 適用される法令 |
| --- | --- |
| マレーシア半島 | National Land Code 1965 (Act 828) |
| サバ | Sabah Land Ordinance (Cap. 68) |
| サラワク | Sarawak Land Code (Cap. 81) |

この三つの制度は、いずれも同じトーレンスの伝統に連なるという家族的類似性を共有してい
るが、それぞれ別個の条文、別個の土地局、別個の判例法を持つ別個の法令である。コタキナ
バルやクチンにおける権原の調査、原住民慣習権（native customary rights）に関する問題、
または取引手続きは、National Land Codeからではなく、サバまたはサラワク自身の法律に
基づいて答えを出さなければならない。

## よくある誤解

**「マレーシアの土地法」を単一の法令として扱うこと。** 実際には三つあり、互いに置き
換え可能なものではない——サバやサラワクの案件にNational Land Codeの条文を引用するこ
とは、単に誤った法律を引用していることになる。

**署名済みの売買契約書が所有権を移転すると考えること。** 本法典のもとでは、私的な契約
は当事者間に契約上の権利を生じさせるにとどまる。法的な権原を移転させるのは、登記され
た譲渡である。

**不可争性を絶対的なものと考えること。** Section 340には法定の例外があり、「権原が登
記されている」という事実だけでは、その権原がどのように登記されるに至ったかをめぐる争
いのすべてに対する完全な答えにはならない。
