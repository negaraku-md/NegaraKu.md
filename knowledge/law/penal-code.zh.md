几乎每一篇你会读到关于 Act 574 的文章，开头都是同一句话：Penal Code 有511条、
分为23章。这句话的两个部分都是错的。

本页是 Act 574 的法令记录——它的身份、结构、渊源，以及它在马来西亚其他刑事法令
中的位置。本页不阐述任何罪行的构成要件。

## 一览

| | |
| --- | --- |
| 简称 | Penal Code（第1条） |
| 法令编号 | Act 574 |
| 长题目 | "An Act relating to criminal offences" |
| 首次制定 | 1936年，以 F.M.S. Cap. 45 的形式 |
| 修订 | 1997年，修订为 Act 574，自1997年8月7日起生效 |
| 施行范围 | 经由 Act A327，自1976年3月31日起施行于马来西亚全境；P.U. (B) 139/1976 |
| 编号 | 第1条至第511条 |
| 章节 | 26个标题：第I至XXIII章，另加第VA、VIA与VIB章 |
| 最新重印本 | 截至2023年7月4日 |

## 渊源

本法典并非马来西亚原创。它的前身是 Indian Penal Code，由麦考莱勋爵（Lord
Macaulay）领导的首届印度法律委员会起草，其呈交印度总督会议（Governor-General
of India in Council）的引言报告，日期为1837年10月14日。

该法典并非以延伸适用的方式传入 Straits Settlements，而是经由本地重新制定：即
Straits Settlements Penal Code（Ordinance No. 4 of 1871），于翌年生效。
Federated Malay States 在1936年采用了相同模式，以 F.M.S. Cap. 45 的形式制定，
而 AGC 自己的记录至今仍将该1936年立法列为 Act 574 的首次制定。

由此产生三个后果，这也在很大程度上解释了本法典的行文方式。它使用
「illustrations」（例解）——印在条文本文之中的示范例子——这是麦考莱式的写法。
它在第II章中先穷尽性地界定各项用语，然后才定义任何一项罪行。而且它与新加坡、
文莱、斯里兰卡与缅甸的刑法典同出一源，这也是为什么这些法域的案例会在这里被
援引。

## 26章

第I章至第V章及第XXIII章承载一般部分——适用于本法典中每一项罪行的机制。第VI章
至第XXII章承载罪行定义。

| 章节 | 涵盖内容 |
| --- | --- |
| 第I–II章 | 导言；一般解释与定义 |
| 第III章 | 刑罚——现已几乎全部废除 |
| 第IV章 | 一般例外情况，包括正当防卫权 |
| 第V、VA章 | 教唆；刑事共谋 |
| 第VI、VIA、VIB章 | 对国家的罪行；恐怖主义；有组织犯罪 |
| 第VII–VIII章 | 武装部队；公共安宁、非法集会与暴动 |
| 第IX–XI章 | 公务员的犯罪与针对公务员的罪行；藐视合法权力；伪证及妨害公共司法的罪行 |
| 第XII–XIII章 | 硬币与政府印花；度量衡 |
| 第XIV–XV章 | 公共卫生、安全、便利、风化与道德；宗教 |
| 第XVI章 | 侵害人身的罪行，自第299条（可谴责杀人）起 |
| 第XVII章 | 侵害财产的罪行，自第378条（盗窃）起 |
| 第XVIII–XX章 | 文书、货币与银行钞票；刑事违反服务合约；婚姻 |
| 第XXI–XXII章 | 诽谤；刑事恐吓、侮辱与滋扰 |
| 第XXIII章 | 未遂，仅一条 |

**第VA、VIA与VIB章正是关键所在。** 它们以字母而非数字编号，因为它们是后来才
插入既有结构中的——先是刑事共谋，然后是恐怖主义，再后来是有组织犯罪。只数罗马
数字会得出23章，而漏算了它们。

## 为什么条文数并非511

第511条是最后一条，而不是第511项。在第1条与第511条之间，本法典存在：

- **明确的空缺。** 重印本明确说明，没有第14至16条、没有第18条、没有第41至42
  条，也没有第244至245条。
- **被废除的整段条文。** 标题为「Punishments」的第III章，已失去第53至55条、
  第59至60条、第63至64条、第66至70条与第73至74条。只有第57、71、72、75与75A
  条得以保留。
- **带字母的插入条文。** 第121A至121D条、第124B至124N条、第130A至130ZC条与
  第377A至377E条，全都是编号1–511未计入的追加条文。

净效果是：本法典的一般部分被大幅掏空，而罪行部分则被一再扩充。

## 它与马来西亚其他刑事法令的关系

第2条规定，任何人若作出违反本法典的行为，须依本法典而非其他方式受罚。单独看
这句话，听起来像是排他性的规定。第5条随即纠正了这个印象：本法典中的任何规定，
均无意废除、变更、中止或影响任何其他现行成文法律。

第40条补全了这幅图景。「Offence」（罪行）通常是指本法典使得可受处罚的事项——
但在第IV章及一系列列明的条文中，它延伸至可依任何其他现行法律受处罚的一切事项。
本法典是一般性刑事法令，其设计本就是要置于各专门法令之下。

与它关系最密切的伙伴是 Criminal Procedure Code（Act 593），它提供了本法典所
欠缺的程序：逮捕、控告、审讯、保释与判刑。CPC 的 First Schedule（第一附表）
逐条列出 Penal Code 的罪行及其刑罚——这也是为什么 Abolition of Mandatory
Death Penalty Act 2023 必须同时修订本法典与该附表，才能让一项改动真正落实。
至于某一项控罪究竟由哪一级法院审理，则是
[法院层级](/zh/law/court-hierarchy)要回答的问题。

域外效力范围狭窄而具体。第4条仅就第VI、VIA与VIB章——对国家的罪行、恐怖主义
与有组织犯罪——将本法典的适用范围延伸至马来西亚境外，而且也仅限于该条所列明
的八种情况。

第IX章仍在第161至165条中规定了公务员的利益（gratification）罪行；现代反贪
执法体制则单独载于[反贪会（MACC）](/zh/government/macc-sprm)。本法典是由国会
制定的联邦法律——参见
[法案如何成为法律](/zh/law/how-a-bill-becomes-law)——其框架由
[联邦宪法](/zh/law/federal-constitution)所设定。

## 2023年死刑修订

Abolition of Mandatory Death Penalty Act 2023（Act 846）于2023年6月9日获御
准，2023年6月16日刊宪，并经由 P.U. (B) 229/2023 于2023年7月4日生效。

它是一部单一的修订法令，一次过触及七部法令——Penal Code、Firearms (Increased
Penalties) Act 1971（Act 37）、Arms Act 1960（Act 206）、Kidnapping Act
1961（Act 365）、Dangerous Drugs Act 1952（Act 234）、Strategic Trade Act
2010（Act 708），以及 Criminal Procedure Code（Act 593）。这份清单是目前可
得、最清楚呈现马来西亚死刑罪行实际分布之处的地图。

在 Penal Code 之中，Act 846 修订了36条条文：第115、118、119、121、121A、
121B、122、124K、124M、125、125A、128、130、130A、130B、130C、130D、130I、
130J、130K、130KA、130N、130O、130QA、130ZB、201、212、213、214、216、221、
302、307、364、374A 与450条。第302条的修订方式，是在「with death」（处死）
字样之后，插入另一选项：判处不少于三十年、不超过四十年的监禁，并在罪犯未被
判处死刑时，加判不少于十二下的鞭刑。

## 阅读正确的文本

AGC 关于 Act 574 的时间线记录了以下重印本：截至2002年1月1日、2006年1月1日、
2009年10月1日、2018年10月1日、2022年11月30日（网络版）与2023年7月4日，并在
2023年8月、2024年9月与2025年3月有进一步的修订。任何日期早于2023年7月4日的
综合文本，都早于死刑改革之前；而广为流传的2018年10月1日重印本，更是早了将近
五年。

如有任何现实中的疑问，请查核 AGC 的 Laws of Malaysia 网站上的现行版本，而不要
依赖已缓存的 PDF 文件。

## 下一步

本页确立了 Act 574 的身份与结构。罪行定义、第IV章的一般例外情况，以及与
Criminal Procedure Code 的相互关系，各自都值得专文处理，日后写就时将从本页

意味着，答案往往是否定的。
