第159条は、まず自らを自らの規則に服させることから始まる。第(5)款は、統治者会議（Conference of Rulers）の同意なしには改正できない保障条項を列挙しているが――その一覧の最後の項目は「本款」自体である。改正手続が、自らの改正手続自体を保護している。この一点だけで、連邦憲法が単純な一つの規則によって変更されるようには決して意図されていなかったことがわかる。

実際そうではない。第159条は、第161E条とあわせて読むと、四つの独立した手続を定めており――どれが適用されるかは、憲法のどの文言を改正しようとしているかに完全に左右される。

## 概要

| | |
| --- | --- |
| 条項 | 第159条（憲法の改正）及び第161E条（サバ／サラワク保障規定） |
| 編 | 第159条：第12編――一般及び雑則　・　第161E条：第12A編――サバ州及びサラワク州のための追加的保障 |
| 既定の規則 | 第(3)款：各院の全議員総数の3分の2の多数 |
| より軽い経路 | 第(4)款：修正案の短い一覧は単純多数のみで足りる |
| より重い経路一 | 第(5)款：3分の2の多数 **に加えて** 統治者会議の同意 |
| より重い経路二 | 第161E条(2)：3分の2の多数 **に加えて** サバ又はサラワクの州元首（Yang di-Pertua Negeri）の首肯 |

## 経路一：既定の規則――3分の2の多数のみ

第159条第(3)款は一般規則を定める。憲法を改正する法案――又は第10条(4)のもとで可決された法律を改正する法案――は、次のとおりでない限り、いずれの院においても可決することができない。

> 「第二読会及び第三読会において、当該院の全議員総数の3分の2を下回らない票数の支持を得ること。」

ここで重要な点が二つある。第一に、この基準は、出席し投票した議員数ではなく、当該院の全議員総数に対して測られる――したがって、棄権及び空席は、修正案に有利にではなく不利に数えられる。第二に、これが既定の規則である。すなわち、第(4)款が適用除外とせず、かつ第(5)款又は第161E条が追加の制限を課さない、あらゆる修正案に適用される。

## 経路二：例外――単純多数

第(4)款は、国会が他の通常の法律と同じ基準――通常の単純多数――で可決できる、技術的な修正案の短い一覧を切り出している。条文が列挙するところによれば、これらは次の修正案である。

- Second Schedule（第二附則）第3部、又はSixth Schedule（第六附則）若しくはSeventh Schedule（第七附則）に対する改正；
- 憲法の他の箇所で付与された立法権（第74条及び第76条に基づくものを除く）を国会が行使することに付随し、又はそれから生じる改正；
- ある州の連邦加入若しくは連邦との連合のために、又はこれに関連して行われる改正、又は、すでに加入した州への憲法の適用方法に対する付随的な修正――第161E条に服する――；並びに
- 上記第一項に基づき行われた改正から生じる付随的な改正。

これらは、その設計上、憲法の事務的な規定である――事項の附則、技術的な後続の起草作業、そして新たな州を連邦に組み入れるための仕組みである。そのいずれも、憲法が他の点でより高い基準によって保護している実質的な権利や制度上の均衡には触れない。

## 経路三：3分の2の多数に加えて統治者会議

より高い基準が置かれているのは第(5)款である。同款は、いかなる法律によっても、いかなる3分の2の票決によっても、統治者会議が先に同意しない限り改正することができない特定の規定を列挙している。

> 「第10条第(4)款の改正、それに基づき可決された法律、第3編の規定、第38条、第63条第(4)款、第70条、第71条第(1)款、第72条第(4)款、第152条若しくは153条、又は本款の改正を行う法律は、統治者会議の同意なしには可決してはならない。」

詳しく示すと、この一覧が対象とするのは次のとおりである。

| 条項 | 主題 |
| --- | --- |
| 第10条(4)及びそのもとで可決された法律 | 第3編、第152条、153条又は181条によって保護される事項について質問することを制限する国会の権限 |
| 第3編 | 公民権 |
| 第38条 | 統治者会議自体――その構成及び職能 |
| 第63条(4) | 第10条(4)の法律のもとでの犯罪についての国会議員免責特権の除去 |
| 第70条 | 統治者並びに州元首（Yang di-Pertua-Yang di-Pertua Negeri）の席次 |
| 第71条(1) | 統治者がその州の王位を継承し、これを保持する権利についての連邦の保証 |
| 第72条(4) | 州議会における同等の免責特権の除去 |
| 第152条 | 国語 |
| 第153条 | マレー人並びにサバ州及びサラワク州の原住民の特殊な地位 |
| 第(5)款自体 | 同意要件自体――自らを保障条項とするもの |

統治者会議のこの権限は、より広い役割の中の、より狭い一例にすぎない。第38条(2)から(4)は、統治者会議が一般に行うことを定めている――国王（Yang di-Pertuan Agong）及び副国王（Timbalan Yang di-Pertuan Agong）を選出すること、宗教上の儀礼を連邦全体に及ぼすことに同意すること、その同意を要する法律及び任命に同意すること、特別法廷の構成員を任命すること、並びに第42条(12)のもとでの恩赦権を行使することである。第(4)款は、第(5)款の一覧に加えて常設の規則を定めている――「統治者の特権、地位、栄誉又は威厳に直接関わる法律は、統治者会議の同意なしには可決してはならない。」――これは、統治者に関わる一部の立法が、正式な憲法改正の枠外であっても、統治者会議の同意を必要とし得ることを意味する。

## 経路四：3分の2の多数に加えてサバ又はサラワクの同意

第161E条は、サバ及びサラワクの連邦加入に由来する、独立した地理的に限定された保障規定を追加している。第(2)款は次のように規定する。

> 「憲法のいずれかの規定の運用が次のいずれかの事項に関して影響を受けることとなる改正である場合、サバ州若しくはサラワク州の州元首、又は関係するサバ州及びサラワク州それぞれの州元首の首肯なしには、憲法のいかなる改正も行ってはならない……」

同款が保護する五つの事項は、次のとおりである。

1. **マレーシア・デー前に生まれた、サバ又はサラワクと関係を有する者の公民権**、及びその公民権の待遇が、マラヤ諸州と関係を有する者と比較して同等であること。
2. **サバ及びサラワクの高等法院**――その構成、管轄権、並びにその裁判官の任命、罷免及び停職。
3. **サバ及びサラワクにおける州対連邦の立法権及び行政権**、並びに連邦と当該州との間の関連する財政上の取り決め。
4. **宗教、言語の使用、及び当該州の原住民の特別な待遇。**
5. **当該州の下院議員配当数**――1970年8月末までに招集されるいずれの国会においても、当該州に配分される配当数が、他の諸州の総数に対する比率において、マレーシア・デー時点で当該州が保持していた比率を下回らないこと。第(3)款は、この配当数の変更それ自体が、第(1)款の適用上、当該州の地位をマラヤ諸州の地位に「等しくする」ものとして扱われることは決してない旨を明らかにしている。

第(1)款は、構造上の要点を加えている。マレーシア・デー以降、サバ又はサラワクの連邦加入に関連して行われる改正は、当該州の憲法上の地位をマラヤ諸州の地位に等しくし又は同化させるものでない限り、第159条(4)(bb)の単純多数の例外のもとで通過させることはできない。そして第(4)款は、同じ首肯の要件を、サバ又はサラワクへの入国及び居住に関する一定の連邦法上の権利にも拡張し、これらをあたかも憲法の第(2)款の一覧に書き込まれているかのように扱う。

## 二つの同意一覧が重なるとき

統治者会議の一覧とサバ／サラワクの一覧は、互いに排他的ではない。第152条（国語）は統治者会議の一覧に含まれる。第161E条(2)(d)は、サバ及びサラワクにおける「当該州内での……いかなる言語の使用」を別途保護している。第153条（マレー人並びにサバ州及びサラワク州の原住民の特殊な地位）は統治者会議の一覧に含まれる。第161E条(2)(d)は、「当該州の原住民の特別な待遇」を別途保護している。第3編（公民権）は統治者会議の一覧に含まれる。第161E条(2)(a)は、マレーシア・デー前に生まれた、サバ又はサラワクと関係を有する者の公民権を別途保護している。

ある修正案が両方の一覧に同時に該当する場合、3分の2の票決に加えて両方の同意が必要となる――すなわち第159条(5)のもとでの統治者会議の同意、及び第161E条(2)のもとでの関係する州元首の首肯である――いずれの条文も他方に取って代わるものではないからである。

## よくある誤解

**「3分の2があれば常に十分である。」** これは第(3)款のもとでの既定の規則ではあるが、第(5)款及び第161E条(2)は特定の規定についてこれに加えて同意要件を追加しており、第(4)款は短い技術的な一覧について3分の2の要件を完全に取り除いている。

**「修正案を阻止できるのは統治者だけである。」** サバ及びサラワクは、第161E条(2)のもとで独立した拒否権を有しており、それは第159条(5)のもとでの統治者会議の役割に代わるものではなく、これと並行して働く。

**「改正手続自体は、他のいかなる款とも同様に変更できる。」** 第159条(5)は、自らが保護する規定の中に第(5)款自体を含めているため、同意要件を改正すること自体が、その同じ同意要件に服する。
