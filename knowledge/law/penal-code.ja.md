Act 574について読むほとんどすべての記事は、同じ一文で始まる——刑法典（Penal Code、Act 574）は23章に511条を有する、と。この一文は、その両方の部分が誤りである。

本ページは、Act 574の法令記録である——その身分、構造、系譜、そしてマレーシアの他の刑事法令の中での位置づけ。本ページは、いかなる犯罪の構成要件も示さない。

## 概要

| | |
| --- | --- |
| 略称 | Penal Code（s.1） |
| 法令番号 | Act 574 |
| 長題目 | "An Act relating to criminal offences" |
| 最初の制定 | 1936年、F.M.S. Cap. 45として |
| 改正 | 1997年、Act 574に改正、1997年8月7日施行 |
| 適用範囲 | Act A327により1976年3月31日からマレーシア全土に適用；P.U. (B) 139/1976 |
| 番号 | s.1からs.511まで |
| 章 | 26の見出し：I からXXIIIまで、及びVA、VIA、VIB |
| 最新の重印本 | 2023年7月4日現在 |

## 由来

本法典はマレーシア独自のものではない。その祖先はIndian Penal Codeであり、マコーレー卿（Lord Macaulay）のもとで初代インド法委員会（Indian Law Commission）によって起草された。インド総督参事会（Governor-General of India in Council）への序文報告書の日付は1837年10月14日である。

その法典は、延長適用によってではなく、現地における再制定によって[Straits Settlements](/malaysia/straits-settlements)にもたらされた——すなわち**Straits Settlements Penal Code、Ordinance No. 4 of 1871**であり、翌年施行された。Federated Malay Statesは同じ模式を**1936年にF.M.S. Cap. 45として**採用し、この1936年の制定法が、AGC自身の記録において今なおAct 574の最初の制定として記されている法令である。

そこから三つの帰結が生じ、それらは本法典がどのように読まれるかについて多くを説明する。本法典は**illustrations（例解）**——条文本文の中に印刷された実例——を用いており、これはマコーレー式の手法である。本法典はChapter IIにおいて、一つの犯罪も定義する前に、その用語を網羅的に定義する。そして本法典は、シンガポール、ブルネイ、スリランカ及びミャンマーの刑法典と共通の祖先を有しており、これこそが、これらの法域の判例がここでそもそも援用される理由である。

## 26章

Chapter I～V及びChapter XXIIIが一般部分——本法典のすべての犯罪に適用される仕組み——を担う。Chapter VI～XXIIが犯罪の定義を担う。

| 章 | 内容 |
| --- | --- |
| Chapter I–II | 総則；一般的な解釈及び定義 |
| Chapter III | 刑罰——現在ではほぼ全体が廃止 |
| Chapter IV | 私的防衛権を含む一般的抗弁事由 |
| Chapter V、VA | 教唆；刑事共謀 |
| Chapter VI、VIA、VIB | 国家に対する犯罪；テロリズム；組織犯罪 |
| Chapter VII–VIII | 軍隊；公共の平穏、不法集会及び暴動 |
| Chapter IX–XI | 公務員による及び公務員に対する犯罪；適法な権限に対する侮辱；偽証及び公正な司法に対する犯罪 |
| Chapter XII–XIII | 貨幣及び政府印紙；度量衡 |
| Chapter XIV–XV | 公衆衛生、安全、便宜、風紀及び道徳；宗教 |
| Chapter XVI | s.299（故殺）から始まる、身体に対する犯罪 |
| Chapter XVII | s.378（窃盗）から始まる、財産に対する犯罪 |
| Chapter XVIII–XX | 文書、通貨及び銀行券；雇用契約の刑事上の違反；婚姻 |
| Chapter XXI–XXII | 名誉毀損；刑事上の脅迫、侮辱及び迷惑行為 |
| Chapter XXIII | 未遂、単一の条のみ |

**Chapter VA、VIA及びVIBこそが手がかりである。** これらは数字ではなく文字を付されているが、それは既存の構造の中に——まず刑事共謀、次いでテロリズム、そして組織犯罪の順に——挿入されたためである。ローマ数字だけを数えると23となり、これらを見落とすことになる。

## なぜ条文数は511ではないのか

s.511は最後の条であって、511番目の条ではない。s.1とs.511の間には、本法典には以下が存在する。

- **明示的な欠番。** 重印本は、s.14～16、s.18、s.41～42及びs.244～245が存在しないことを明記している。
- **廃止された条文群。** 「Punishments」と題されたChapter IIIは、ss.53～55、59～60、63～64、66～70及び73～74を失っている。同章で残存するのはs.57、71、72、75及び75Aのみである。
- **文字付きの挿入条文。** ss.121A～121D、124B～124N、130A～130ZC及び377A～377Eは、いずれも1～511の番号には数えられていない追加の条文である。

その正味の結果として、本法典は一般部分が空洞化する一方、犯罪部分は繰り返し拡張されてきた。

## マレーシアの他の刑事法令との関係

s.2は、本法典に反する行為について、すべての者が**本法典のもとでのみ、それ以外の方法によらず**処罰されると定める。この一文だけを読めば、排他的であるように聞こえる。s.5はただちにその印象を訂正する——本法典中のいかなる規定も、現に効力を有する他の成文法を廃止し、変更し、停止し、又はこれに影響を及ぼすことを意図するものではない。

s.40が全体像を補う。「Offence」（犯罪）とは、通常は本法典によって処罰可能とされる事項を意味する——しかし、Chapter IV及び列挙された一連の条文においては、現に効力を有する他の法律のもとで処罰可能な事項にまで及ぶ。本法典は**一般的な**刑事法令であり、専門的な法令の下に位置するよう意図的に構築されている。

本法典に最も近い相棒は**[Criminal Procedure Code](/law/criminal-procedure-code)（Act 593）**であり、本法典にはない手続——逮捕、起訴、公判、保釈及び量刑——を定める。CPCのFirst Scheduleは、刑法典の犯罪を条文ごとにその刑罰とあわせて一覧表にしている——これが、Abolition of Mandatory Death Penalty Act 2023が、一つの改正を確実に成立させるために本法典とそのScheduleの両方を改正しなければならなかった理由である。ある特定の罪状を実際にどの裁判所が審理するかは、[裁判所階層](/ja/law/court-hierarchy)が答える問題である。

域外適用範囲は狭く、限定的である。s.4は、本法典の適用範囲をマレーシア域外にまで広げるのは、**Chapter VI、VIA及びVIB**——国家に対する犯罪、テロリズム及び組織犯罪——についてのみであり、しかもその場合でも、同条が列挙する8つの状況に限られる。

Chapter IXには、s.161～165に、公務員によるgratification（不正利得）の罪が今なお含まれている。現代の反汚職の執行体制は、別途[マレーシア汚職防止委員会（MACC）](/ja/government/macc-sprm)で扱われている。本法典は国会が制定する連邦法である——[法案はいかにして法律となるか](/ja/law/how-a-bill-becomes-law)を参照——その枠組みは[連邦憲法](/ja/law/federal-constitution)により定められている。

## 2023年の死刑改正

**Abolition of Mandatory Death Penalty Act 2023（Act 846）**は2023年6月9日に御裁可（Royal Assent）を受け、2023年6月16日に官報に公布され、P.U. (B) 229/2023により**2023年7月4日**に施行された。

これは、一度に七つの法令——刑法典、Firearms (Increased Penalties) Act 1971（Act 37）、Arms Act 1960（Act 206）、Kidnapping Act 1961（Act 365）、Dangerous Drugs Act 1952（Act 234）、Strategic Trade Act 2010（Act 708）、及びCriminal Procedure Code（Act 593）——に及ぶ単一の改正法である。この一覧は、マレーシアの死刑罪が実際にどこに存在するかを示す、現時点で最も明快な地図である。

刑法典内では、Act 846はss.115、118、119、121、121A、121B、122、124K、124M、125、125A、128、130、130A、130B、130C、130D、130I、130J、130K、130KA、130N、130O、130QA、130ZB、201、212、213、214、216、221、302、307、364、374A及び450の36箇条を改正した。s.302は、「with death」（死刑）という文言の後に、死刑に処されない場合には十二回以上の鞭刑を付した、三十年以上四十年以下の禁錮刑という代替刑を挿入する形で改正された。

AGCのAct 574タイムラインには、2002年1月1日、2006年1月1日、2009年10月1日、2018年10月1日、2022年11月30日（オンライン版）及び2023年7月4日時点の重印本が記録されており、さらに2023年8月、2024年9月及び2025年3月にも改正がなされている。2023年7月4日より前の日付を持つ統合テキストはいずれも死刑改革以前のものであり、広く流通している2018年10月1日の重印本は、それより約5年も前のものである。

## 次のステップ

本ページは、Act 574の身分及び構造を確定するものである。犯罪の定義、Chapter IVにおける一般的抗弁事由、及びCriminal Procedure Codeとの相互関係は、それぞれ独自の解説に値するものであり、執筆され次第、本ページからリンクされる予定である。

特定の犯罪を調べようとする場合は、まずそれがそもそも本法典に含まれているかどうかを問うことから始めるとよい——s.5により、その答えはしばしば「否」となる。
