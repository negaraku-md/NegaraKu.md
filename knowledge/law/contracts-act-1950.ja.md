賃貸借契約、雇用契約書、割賦販売契約、WhatsAppで成立した中古車の売買――そのすべて
が、同じ七十年前の一つの法律の上に立つか倒れるかする：1950年契約法（Contracts Act
1950）である。

本ページはAct 136の法令記録である――その身分、構造、淵源、そして合意がそもそも契約
として数えられるためにs.10が定める条件を扱う。救済手段、特定の契約類型、又はいずれ
か一つの法理に関する判例法は扱わない。

## 概要

| | |
| --- | --- |
| 略称 | Contracts Act 1950 |
| 法令番号 | Act 136 |
| 国王裁可 | 1950年5月12日 |
| 官報告示 | 1950年5月23日 |
| 施行 | Kuala Lumpur、Johore、Kedah、Kelantan、Negeri Sembilan、Pahang、Perak、Perlis、Selangor及びTerengganuでは1950年5月23日；Malacca、Penang、Sabah及びSarawakでは1974年7月1日 |
| 構造 | 10のPart、s.1からs.191まで |
| 最新重印本 | 2006年1月1日現在 |

## どこから来たのか

同法はマレーシアの独自の産物ではない。その祖先は**Indian Contract Act 1872**であり、
Federated Malay Statesはこれを現地向けに修正したうえで**Contract Enactment 1899**と
して採用した。同Enactmentはその後、Unfederated Malay Statesへと一州ずつ広がっていっ
た――Johoreが最初にこれを受け入れた州であり、早くも1914年のことであった。

Federation of Malaya自身のFederal Legislative Councilが正式にContracts Ordinanceを
可決したのは1950年になってからであり、これが、根底にある規則がさらに古いものである
にもかかわらず、同法の名称にその年が冠されている理由である。

前身の[Straits Settlements](/malaysia/straits-settlements)であったPenangとMalacca
は、さらに一世代にわたり同Ordinanceではなく英国のコモンローのもとで運用されており、
SabahとSarawakはさらに後になってマレーシアに加わった。これら四つの地域が一斉に同法
の適用対象となったのは**1974年7月1日**であり――これはAGC自身の施行記録に記された日
付と同一である。

## 同法が扱う内容

Act 136は十のPartで構成されている：

| Part | 内容 | 条文 |
| --- | --- | --- |
| I | Preliminary――略称、解釈規定 | 1-2 |
| II | 申込みの伝達、承諾及び撤回 | 3-9 |
| III | 契約、取消可能な契約及び無効な合意 | 10-31 |
| IV | 条件付契約 | 32-37 |
| V | 契約の履行 | 38-68 |
| VI | 契約によって生じる関係に類似する関係（準契約） | 69-73 |
| VII | 契約違反の効果 | 74-76 |
| VIII | 補償及び保証 | 77-100 |
| IX | 寄託 | 101-134 |
| X | 代理 | 135-191 |

二つの契約類型全体が、意図的にここには**含まれていない**。**1957年物品売買法（Sale
of Goods Act 1957、Act 382）**及び**1961年組合法（Partnership Act 1961、Act 135）**
が、それぞれの契約類型に関する具体的な規則を定めている；Act 136が提供するのは、これ
らの法律の基礎をなす契約の一般法である。

## 有効な契約のための四つの条件

s.10は同法の要となる規定である。合意は、次の四つすべてを同時に満たす場合にのみ契約
となる、と定める：

| 要件 | 意味 | 所在 |
| --- | --- | --- |
| 自由な同意 | 強迫、不当威圧、詐欺、不実表示又は錯誤によって得られたものではない同意 | s.14（定義）；ss.15-20 |
| 当事者の行為能力 | 成年年齢に達し、精神が健全であり、かつ他のいかなる法律によっても契約締結資格を失っていないこと | s.11-13 |
| 適法な約因 | その約束と引換えに与えられる有価値なもの；これを欠く合意は無効となるが、三つの狭い例外に服する | s.2(d)（定義）；s.26 |
| 適法な目的 | 法律で禁止されておらず、詐欺的でなく、他人又は財産を害するものでなく、かつ裁判所が不道徳又は公序に反すると見なすものでもないこと | s.24-25 |

s.10の背後には、**s.2**における定義――「proposal」（申込み）、「promise」（承諾さ
れた申込み）、そして「consideration」（約因）など――が控えている。これが、同法自体
は「offer」という語を一度も用いていないにもかかわらず、実務家が今なおマレーシアの契
約分析を申込み、承諾及び約因という観点から説明する理由である。

s.26が約因の要件に設ける三つの例外は狭い：近親関係にある当事者間で自然な愛情から書
面によりなされ登録された約束、既に自発的に何かを行った者に対してそれを補償する約
束、そして時効に関する法律がなければ阻却されていたであろう債務を弁済する約束である。

## どの文本を参照すべきか

AGCのAct 136に関する記録には、1967年から1980年にかけての一連の改正が記載されてお
り、現行重印本の日付は**2006年1月1日**である。それ以降、全面的な再構成は行われてい
ない――たとえば2016年に全面的に再立法された2016年会社法（Companies Act 2016）とは
異なる――したがって、上記の各条文を確認する際に照合すべき文本は、今なお2006年重印本
である。

## 次のステップ

本ページはAct 136の身分、構造及び成立要件を確定するものである。契約紛争が実際にどの
ように争われるかは、[裁判所の階層](/ja/law/court-hierarchy)の問題であり、イスラム金
融又は家族契約が関わる場合には、[民事裁判所とシャリア裁判所](/ja/law/civil-and-syariah-courts)
の境界の問題でもある。同法が特定の契約――雇用関係――をどのように基礎づけているかは、
[1955年雇用法（Employment Act 1955）](/ja/law/employment-act-1955)に定められている；
会社自身の契約をどのように基礎づけているかは、[2016年会社法（Companies Act 2016）](/ja/law/companies-act-2016)
の問題である。
