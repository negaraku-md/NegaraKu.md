連邦憲法の二つの規定は互いに隣り合い、絶えず引用されるが、全文が引用されることは稀である。以下がその条文である。

連邦憲法の公式重印版において、第3条(1)は次のように定めている。

> 「イスラム教は連邦の宗教である。ただし、他の宗教も連邦のいかなる地域においても平穏かつ調和のうちに信仰できる。」

これが第一項の全文である——セミコロンで結ばれた二つの部分からなる一つの文である。以下では、第3条の残りの部分、第11条の残りの部分、そして両条文——及びその他いくつかの条文——が文本上互いに相互参照する具体的な箇所を取り上げる。

## 概要

| | |
| --- | --- |
| 規定 | 第3条（連邦の宗教）及び第11条（信教の自由） |
| 所在 | 連邦憲法——第3条は第1編（各州、連邦の宗教及び法律）に、第11条は第2編（基本的自由）にそれぞれ置かれている |
| 第3条の各項 | 五項：(1) 宣言；(2)から(3) 各統治者をその州におけるイスラムの長とする規定；(4) 不減損規定；(5) 国王を連邦直轄区におけるイスラムの長とする規定 |
| 第11条の各項 | 五項：(1) 信仰・実践・布教の権利；(2) 他の宗教のための強制的な支払いの禁止；(3) 宗教団体の権利；(4) イスラム教徒に対する布教の規制；(5) 公共の秩序・衛生及び道徳に従うこと |
| 明示的な条文上の連結 | 第3条(4)：「本条中のいかなる規定も、本憲法の他のいかなる規定も減損しない」 |
| 関連規定 | 第121条(1A)（シャリア裁判所の事項から民事裁判所を排除）；第九附則州リストitem 1（イスラム法及びシャリア裁判所についての州の権限） |
| 所管 | 裁判所によって解釈され適用される；第159条の手続によってのみ改正される |

## 第3条全文

検事総長室（Attorney General's Chambers）による2020年10月15日現在の公式重印版は、第3条を次のように定めている。

**第(1)項。**「イスラム教は連邦の宗教である。ただし、他の宗教も連邦のいかなる地域においても平穏かつ調和のうちに信仰できる。」

**第(2)項。**統治者を有しない州を除くすべての州において、その州におけるイスラムの長としての統治者の地位は、「当該州の州憲法が認め、かつ宣言する方式及び範囲において」定められており、当該州憲法に従うことを条件として、統治者がその宗教の長として享有する一切の権利、特権、大権及び権限は「影響を受けず、損なわれない」。統治者会議（Conference of Rulers）が連邦全体に及ぼすべきことに合意した行為、儀式又は式典については、各統治者は、イスラムの長としての資格において自己を代表する権限を国王（Yang di-Pertuan Agong）に与える。

**第(3)項。**マラッカ、ペナン、サバ及びサラワクの州憲法——歴史的に独自の統治者を有しなかった四つの州——は、それぞれ、当該州におけるイスラムの長としての地位を国王に付与する規定を設けなければならない。

**第(4)項。**「本条中のいかなる規定も、本憲法の他のいかなる規定も減損しない。」

**第(5)項。**「本憲法にいかなる規定があるとしても、国王は、クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区におけるイスラムの長とする」；国会は、この目的のため、イスラム教務を規律し、かつイスラムに関する事項について国王に助言する評議会を設置する法律を制定することができる。

## 第11条全文

同重印版は、「信教の自由」と題する第11条を次のように定めている。

**第(1)項。**「すべての者は、自己の宗教を信仰し実践する権利、及び第(4)項の規定に従うことを条件として、これを布教する権利を有する。」

**第(2)項。**「何人も、その収益の全部又は一部が自己以外の宗教の目的に特別に充当される租税を支払うことを強制されない。」

**第(3)項。**すべての宗教団体は、(a) 自らの宗教上の事務を管理し、(b) 宗教又は慈善の目的のための施設を設立し維持し、並びに(c) 法律に従って財産を取得し所有し、これを保有し管理する権利を有する。

**第(4)項。**「州法、及びクアラルンプール、ラブアン及びプトラジャヤの連邦直轄区については連邦法律は、イスラム教を信奉する者の間における宗教上の教義又は信仰の布教を規制し、又は制限することができる。」

**第(5)項。**「本条は、公共の秩序、公衆衛生又は道徳に関する一般法律に反するいかなる行為も認めるものではない。」

## 両条文が文本上相互参照する箇所

単独で読めば、第3条と第11条は憲法の異なる編に置かれ、それぞれ異なる問いに答えている——第3条はイスラム教及び各統治者の地位を扱い、第11条はすべての者及びすべての宗教団体に属する権利を定めている。憲法自体の文本は、三つの具体的な箇所でこれらを結び付けている。

- **第3条(4)**は総括的な連結である。第3条は憲法の他のいかなる規定も「減損」しないと明確に定めており、これは、その宣言が、その文言自体において、第11条を含む他のいかなる規定も切り縮めるものではないことを意味する。
- **第11条(4)**は反対方向に働く具体的な連結である。州法（連邦直轄区については連邦法律）がイスラム教を信奉する者の間における宗教上の教義又は信仰の布教を規制又は制限することを認めているのは、第3条ではなく、第11条自体である。文本上のこの制限は、特にムスリムに向けられた布教に適用される。第11条(1)の信仰・実践・布教に関する一般的権利それ自体は、第3条によって限定されるものではない。
- **第4条(1)**、すなわち最高法規条項は、両者のいずれにも適用される。憲法——第3条又は第11条のいずれかを含む——に抵触するいかなる法律も、その抵触する限度において無効である。

## 文本が指し示す他の規定

憲法にはさらに二つの部分があり、イスラム教についてそれぞれ独自の明文規定を有しており、その文言を超えて解釈することなく、第3条及び第11条と併せて読む価値がある。

**第121条(1A)。**司法機関について定める第9編において、この項は次のように定めている。「第(1)項にいう裁判所は、シャリア裁判所の管轄権に属するいかなる事項についても管轄権を有しない。」第(1)項は、二つの民事高等法院を設置する規定である。したがって第121条(1A)は、第3条又は第11条に対する改正としてではなく、管轄権の除外として定められた、民事裁判所とシャリア裁判所との間の文本上の境界線である。

**第九附則州リストitem 1。**この項は、州議会に対し、とりわけ「イスラム教を信奉する者のイスラム法並びに属人及び家族法」、「イスラム教を信奉する者に対してのみ管轄権を有するシャリア裁判所の構成、組織及び手続」、並びに「イスラム教を信奉する者の間における教義及び信仰の布教の規制」について立法する権限を与えている——これは、第11条(4)が州法によって扱うことを認めている布教規制の対象事項と同一である。同附則の文本はまた一つの例外を設けている。この項は「クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区については」適用されない。これは、当該地域において州の統治者ではなく国王をイスラムの長とする第3条(5)と整合的である。

## よくある誤解

- **第3条(1)を後半部分なしに引用すること。** この項は一つの文である。イスラム教が連邦の宗教であるとの宣言に、同じ文の中で直ちに「ただし、他の宗教も連邦のいかなる地域においても平穏かつ調和のうちに信仰できる」という文言が続く。後半部分を省くと、この項が実際に述べている内容が変わってしまう。
- **第3条があたかも「マレーシアはイスラム国家である」と述べているかのように扱うこと。** この文言は条文中には存在しない。第3条(1)はイスラム教を「連邦の宗教」と宣言している——これは憲法自体が用いる語法であり、第3条の中でそれ以上に定義されているものではない。
- **第11条(4)が布教を一般的に制限すると想定すること。** この項自体の文言は、「イスラム教を信奉する者の間における」布教のみを制限している。その文本によれば、非ムスリムの間における他の宗教の布教を制限するものではない。
- **国王があらゆる場所においてイスラムの長であると想定すること。** 第3条(5)は、クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区という三つの場所のみを具体的に挙げている。統治者を有する州においては、第3条(2)がその地位を統治者に留めており、国王は、統治者会議がある式典又は儀式を連邦全体に及ぼすべきことに合意した場合にのみ行動する。
- **第3条(4)を、第3条と第11条が個々の事案においてどのように併せて適用されるかを解決するものと読むこと。** この項が定めているのは、第3条が憲法の他の規定を減損しないということのみであり、紛争において裁判所が両条文をどのように衡量すべきかをそれ自体が定めているわけではない。この問いは裁判所によって事案ごとに決定されるものであり、本稿の範囲外である。

## 次のステップ

第3条及び第11条が憲法本文の残りの部分——各編、基本的自由の章、及び第159条の改正手続——の中でどのように位置づけられているかについては、[連邦憲法](/ja/law/federal-constitution)の概観を参照。第3条が直接名指す二つの職については、[国王（Yang di-Pertuan Agong）](/ja/government/yang-di-pertuan-agong)及び[統治者会議（Majlis Raja-Raja）](/ja/government/majlis-raja-raja)を参照。第121条(1A)がマレーシアの裁判所の中でどこに位置するかについては、[マレーシアの裁判所階層](/ja/law/court-hierarchy)を参照。その原則の中で「Keluhuran Perlembagaan」（憲法の至高性）を別途挙げる、非憲法上の国家宣言については、[国家原則（Rukun Negara）](/ja/malaysia/rukun-negara)を参照。
