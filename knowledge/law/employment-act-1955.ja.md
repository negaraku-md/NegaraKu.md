本ページはAct 265の法令記録——その身元、所管および改正の経緯です。各権利の内容はあえて再述しません。それらは条文番号と現行の数値とともに、
[Employment Act 1955ガイド](/ja/employment/employment-act-1955-guide)に記載されています。

## 一目でわかる概要

| | |
| --- | --- |
| 略称 | Employment Act 1955 |
| 法令番号 | Act 265 |
| 種別 | 国会制定法（1982年改訂版） |
| 裁可 | 1955年6月4日 |
| 公布 | 1955年6月27日 |
| 施行 | 1957年6月1日 |
| 適用地域 | マレー半島とラブアン連邦直轄区 |
| 所管 | 人的資源省の下のJabatan Tenaga Kerja Semenanjung Malaysia（JTKSM） |
| 現行再版 | 2023年8月1日 |

## この法令が規律する内容

Act 265は、サービス契約（contract of service）の法定最低条件を定めます。その対象事項は、サービス契約とその終了、賃金の支払いと合法的な控除、労働時間と時間外労働、休息日、公共の祝日、年次休暇と病気休暇、出産・父性保護、女性の雇用、外国人従業員の雇用、記録と検査、そして労働局長（Director General of Labour）の面前での労働苦情処理の仕組みにまで及びます。

法令より不利な契約条件は、その不足の範囲において無効です。この法令は下限であって上限ではありません——雇用主は常により良い条件を提示でき、ほとんどの労働協約は実際にそうしています。

## 誰が所管するか

執行は、人的資源省の下にある **Jabatan Tenaga Kerja Semenanjung Malaysia** が担います。JTKSMは苦情を登録し、検査を行い、訴追を提起します。労働局長は、外国人従業員の雇用の承認を含め、この法令が付与する裁定権および承認権を行使します。

命名の落とし穴に注意してください：**`kesuma.gov.my` は名前解決されません。** 同省の正式なドメインは `mohr.gov.my` であり、同局は `jtksm.mohr.gov.my` にあります。

## 改正の沿革

Act 265は1955年以来、20回以上改正されてきました。今日この法令を読む上で重要な項目は次のとおりです。

| 文書 | 効果 | 日付 |
| --- | --- | --- |
| Act 265（主法令） | 制定 | 1957年6月1日施行 |
| 原版 | 改訂前の条文 | 1982年1月28日 |
| 改訂版 | Act 265として統合 | **1982年2月18日** |
| 再版 | 1975 · 2001 · 2006 · 2012 | — |
| **Employment (Amendment) Act 2022 (Act A1651)** | **現代における大規模な書き換え——適用範囲、労働時間、休暇、柔軟な勤務、強制労働の罪** | **2022年5月10日公布；2023年1月1日施行** |
| P.U.(A) 262/2022 | Employment (Amendment of First Schedule) Order 2022 | 2022年8月15日 |
| P.U.(A) 273/2022 | P.U.(A) 262/2022を改正 | 2022年8月30日 |
| P.U.(A) 257/2023 | Employment (Exemption) (Revocation) Order 2023——P.U.(A) 240/2016を撤廃 | 2023年8月29日 |
| 再版 | 現行の統合条文 | 2023年8月1日 |

**施行日こそが落とし穴です。** Act A1651には2022年5月10日という公布日が付いており、多くの公表された論評はそれを新しい規則が始まった日として扱っています。そうではありません。施行日は **2023年1月1日** に指定されており、AGC自身のAct 265に関するタイムラインもその日付での再版を記録しています。2022年の改正が2022年中に有効であったとするものは、まだ始まっていなかった法律を説明しています。

第二の落とし穴は適用範囲です。この法令が何を対象とするかは、その **First Schedule（第一附則）** が定めますが、それは法令自体ではなく大臣令によって改正されます——したがって適用範囲の問いは、条文の文言だけではなく、P.U.(A) 273/2022により改正されたP.U.(A) 262/2022によって答えられます。
