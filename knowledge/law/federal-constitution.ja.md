## 概要

| | |
| --- | --- |
| 正式名称 | 連邦憲法（Perlembagaan Persekutuan） |
| 種類 | 最高法規（憲法） |
| 所管 | 裁判所が解釈・適用し、国会が改正する |
| 施行 | 1957年8月31日（マラヤ連邦憲法として発効）；1963年9月16日のマレーシア成立時に適用が拡大され、名称が改められた |
| 適用対象 | 連邦全体——すべての連邦及び州の機関、並びにマレーシア国内のすべての人 |

## 対象範囲

連邦憲法は、第4条において連邦の最高法規と定められており、これに抵触するいかなる法律も、その抵触する限度において無効となる。連邦憲法は編及び附則に編成されており、連邦とその領域、市民権、基本的自由、連邦機関（国王、国会、行政機関及び司法機関）、各州及びその州憲法、連邦政府と州政府の間の権限の分配、財政規定、並びに特別規定を対象としている。

## 構成

- **連邦。** 第I編は、マレーシアを各州からなる連邦として確立し、その領域を定める。
- **市民権。** 第III編は、市民権の取得、喪失及び終了の方法を定める。
- **基本的自由。** 第II編（第5条から第13条）は、人身の自由、奴隷及び強制労働の禁止、遡及的刑事法からの保護、法の下の平等、移動の自由、言論・集会及び結社の自由、信教の自由、教育に関する権利、並びに財産権を含む自由を定める。
- **連邦政府。** 第IV編は、国王（Yang di-Pertuan Agong）を国家元首と定め、連邦レベルにおける行政、立法及び司法の構造を確立する。
- **各州。** 第V編は、州憲法、統治者会議、並びに連邦と各州との関係を対象とする。
- **権限の分配。** Ninth Schedule（第九附則）は、連邦リスト、州リスト及び共通リストを定め、国会と州議会との間で立法権限を分配する。
- **改正手続。** 第159条は憲法改正の一般的な手続を定めており、一般には、国会各院の全議員総数の3分の2を下回らない票数による法案の支持を必要とする。一部の規定には、統治者会議又は特定の州政府の同意といった追加の要件が課される。

## 適用対象

連邦憲法は、すべての連邦及び州の機関に適用され、また、連邦憲法が定める権利及び義務を通じて、マレーシア国内のすべての人に適用される。
