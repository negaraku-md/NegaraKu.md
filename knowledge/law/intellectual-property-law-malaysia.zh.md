一个标志、一道配方、一段代码、一个品牌名——当其中任何一样开始赚钱的那一刻，别人就有了抄袭它的理由。马来西亚法律为您提供了一种方式来宣告"这是我的，这就是证明的凭据"。问题在于，三种主要的知识产权以三种完全不同的方式运作，而弄错其中一种，可能会让企业失去它最宝贵的资产。

本指南梳理创办人、投资者或创作者真正需要了解的框架：三部主导法令保护什么、您必须注册什么（以及不必注册什么）、保护期有多长，以及那些让人栽跟头的实务决定。

## 在马来西亚，什么算作知识产权？

知识产权（IP）是对心智产物享有的一项法律权利——品牌、发明、设计和创作作品。马来西亚通过各自独立的法令来保护它们，每部法令都有自己的规则、自己的保护期和自己的注册机制。一件产品可以同时承载多项权利：一款饮料可能对其名称拥有商标、对其装瓶工艺拥有专利、对瓶身造型拥有注册工业设计，并对标签美术设计拥有版权。

主要支柱包括：

| 知识产权类型 | 主导法令 | 保护对象 | 注册 |
| --- | --- | --- | --- |
| 商标 | 《2019年商标法令》 | 区分商品/服务的品牌名称、标志和记号 | 须注册方能持有注册商标 |
| 专利 | 《1983年专利法令》 | 具备创造性步骤的新发明 | 须注册 |
| 实用新型 | 《1983年专利法令》 | 微小/渐进式发明（无需创造性步骤） | 须注册 |
| 版权 | 《1987年版权法令》 | 文学、音乐、艺术作品、影片、录音、广播 | 自动产生——无需注册 |
| 工业设计 | 《1996年工业设计法令》 | 产品的外观视觉 | 须注册 |
| 地理标志 | 地理标志立法 | 与原产地相关联的产品 | 须注册 |

本文聚焦于对几乎每个企业都最重要的三项——商标、专利和版权——其余则作为辅助角色。

## 谁管理知识产权——MyIPO 处于什么位置？

马来西亚几乎每一项可注册的知识产权权利都要经过同一个机构：**马来西亚知识产权局**，简称 **MyIPO**（*Perbadanan Harta Intelek Malaysia*）。它是隶属于国内贸易及生活成本部（KPDN）的一家法定机构，负责发展和管理国家知识产权制度。

MyIPO 是您办理以下事项的地方：

- 提交并办理商标、专利、工业设计和地理标志申请；
- 缴纳续展费和年费以维持权利有效；
- 提交版权自愿通报，尽管版权本身无需注册；
- 在推出产品或提交申请之前检索现有注册。

申请通过 MyIPO 的在线门户以电子方式办理（例如，专利通过 *iponline2u* 系统提交）。由于知识产权的审查和办理在程序上可能颇为专业，许多申请人——尤其是外国申请人——会通过注册专利或商标代理人办理，不过这并非始终强制。

## 商标在《2019年商标法令》下如何运作？

商标是能将您的商品或服务与他人区分开来的任何记号——名称、标志、口号，如今还包括不太传统的记号。当**《2019年商标法令》（第815号法令）**于 **2019年12月27日**生效、废止较旧的《1976年商标法令》时，马来西亚的商标法得到了实质性的现代化改造。

2019年法令在几个重要方面使马来西亚的实务更接近国际规范：

- **多类别申请。** 根据第18条（"多类别申请"），单一申请如今可列出跨尼斯分类多个类别的商品和服务，而不再强制每个类别分别申请。
- **非传统商标。** 该法令承认文字和标志以外的记号，包括三维形状、颜色、声音、气味和全息图。
- **驰名商标保护。** 第4条*定义*了"驰名商标"，第76条（"驰名商标的保护"）提供实质性保护——真正驰名的商标即使没有在马来西亚注册也可获得保护。
- **加入马德里议定书。** 第十二部分（国际事务）第1章落实《马德里议定书》，马来西亚已加入该议定书，从而本地权利人可提交一份指定多个国家的国际申请，外国权利人也可指定马来西亚。
- **更强的执法。** 第十三部分（边境措施）提供边境措施权力，包括限制侵权商品的进口及其扣押和没收。

### 保护期与续展

根据**第39条**，注册商标自**注册之日起保护十年**，并可**续展多个十年期**。关键在于，续展没有次数上限——商标是唯一一项原则上可以永久存续的知识产权，这正是全球最古老的品牌受商标而非专利保护的原因。若错过续展期限，第39(5)条仍允许在**期满后六个月内**缴纳续展费加附加费办理续展，因此短暂的失效未必致命。

### 先申请制

马来西亚基本上采用**先申请**制：权利通常归于最先提交有效申请的人，而非最先使用该名称的人。在先的未注册使用仍可通过普通法上的**假冒**（passing off）侵权之诉获得抗辩，但这比单纯拥有注册更慢、更贵、也更难证明。实务上的教训很直白——在推出产品前就提出申请，并先检索 MyIPO 的注册簿，以免与现有商标相冲突。

## 专利和实用新型如何运作？

专利是以公开披露一项新发明为交换而授予的一项有时限的垄断权。马来西亚的制度载于**《1983年专利法令》（第291号法令）**和《1986年专利条例》。

### 三项检验

要具备可专利性，一项发明必须满足三项要求：

1. **新颖性**——它必须是新的，即在申请日时不构成全球任何地方"现有技术"的一部分。
2. **创造性步骤**——它对相关领域的技术人员而言不得是显而易见的。
3. **工业适用性**——它必须能够在某种工业中制造或使用。

任何人——包括公司，而不仅仅是自然人发明人——均可单独或共同申请。申请可以用**马来文或英文**提交，MyIPO 会进行**形式审查**（文书和形式要件）和**实质审查**（对可专利性的真正检验）。

### 保护期

获批专利自**申请日起保护二十年**，前提是缴纳规定的**年费**以维持其有效。若不缴费，专利即失效。二十年是上限——与商标不同，专利不能无限续展，因为其中的交易约定是发明最终进入公有领域供所有人使用。

### 实用新型——较轻度的选择

并非每一项有用的发明都能跨过创造性步骤这道门槛。对于渐进式改进，专利法还提供了**实用新型**（有时称为实用模型或"小专利"）。它要求新颖性和工业适用性，但**不**要求创造性步骤，因而更易于获得。实用新型自**申请起保护十年**，并可再延长**两个五年期**，最长合计**二十年**。

| 特征 | 专利 | 实用新型 |
| --- | --- | --- |
| 是否需要创造性步骤 | 是 | 否 |
| 是否需要新颖性 | 是 | 是 |
| 工业适用性 | 是 | 是 |
| 最长保护期 | 自申请起20年 | 最长20年（10 + 5 + 5） |
| 最适合 | 真正新颖、非显而易见的发明 | 渐进式改进、较简单的装置 |

## 版权如何运作——为何它与众不同？

版权是个异类，而这一差异在实务中意义重大：它是**自动产生**的。根据**《1987年版权法令》（第332号法令）**，保护在原创作品被创作并固定为实体形式的那一刻即产生。马来西亚**不存在版权注册**，也无需注册——无论您是否为此采取任何行动，该权利均已存在，这与马来西亚在《伯尔尼公约》下的义务一致。

版权涵盖**文学作品**（包括软件源代码）、**音乐作品**、**艺术作品**、**影片**、**录音**和**广播**，并包括精神权利和表演者权利。

### 保护期

保护期取决于作品类型：

- **文学、音乐和艺术作品：** 作者终生**加去世后50年**。对于合著作品，50年自最后一位在世作者去世时起算。
- **录音、广播和影片：** 作品首次发表或制作后**50年**。

### 自愿通报

由于版权未经注册，在纠纷中证明*谁创作了什么、何时创作*可能颇为困难。为解决这一问题，MyIPO 设有**自愿通报**（Voluntary Notification）系统：所有人可将作品存档并提交通报（通常附有法定声明），从而建立一份对该主张的官方、注明日期的记录。它是可选的，也不是"注册"，但若作品日后遭到争议，它能提供有用的所有权证据。

## 商标、专利与版权：我需要哪一个？

这三项权利并非互相替代——它们保护不同的东西——但创办人常常混淆它们。用下表来定位您的资产：

| 问题 | 若"是"，可考虑…… |
| --- | --- |
| 它是客户借以认出您的*名称、标志或品牌*吗？ | 商标 |
| 它是一项*新发明、装置、工艺或配方*吗？ | 专利（或实用新型） |
| 它是*书写、绘制、编码、创作或拍摄*的内容吗？ | 版权（自动产生） |
| 它是产品的*形状或外观视觉*吗？ | 工业设计 |
| 它是*与地点相关联的产品*（例如一种地方食品）吗？ | 地理标志 |

一条典型初创企业的快速决策路径：

1. **名称和标志 → 提交商标申请**，在推出前于 MyIPO 办理（先申请制）。
2. **核心技术 → 评估可专利性**；若通过新颖性和创造性步骤，则申请专利，否则考虑实用新型。
3. **网站文案、代码、设计、营销内容 → 版权自动产生**；保留注明日期的记录，并对高价值作品考虑自愿通报。
4. **独特的产品形状 → 考虑工业设计**注册。

## 企业常犯的错误

- **在提交商标申请之前就推出产品。** 在先申请制国家，竞争对手（或抢注者）可以在您还在"使用"名称时把它注册下来。先检索、先申请。
- **以为版权覆盖品牌名称。** 并非如此——名称和标志属于商标法的范畴；版权保护创作作品，而非品牌标识。
- **在申请专利前公开披露发明。** 全球任何地方的在先披露都会破坏新颖性。在提交申请前推介、展出或销售都可能葬送可专利性。先申请，后披露。
- **任由权利失效。** 商标需要每十年续展，专利需要缴纳年费；一旦错过，权利就可能消灭。
- **把马来西亚的注册当作全球有效。** 知识产权具有地域性。马来西亚的商标或专利止于国境——如果您在海外经营，应规划境外申请（商标经由《马德里议定书》，专利经由《专利合作条约》途径）。
- **把实用新型与完整专利混为一谈。** 二者在保护力度和要求上各不相同；选错会浪费时间和金钱。
- **未从承包商处取得知识产权转让。** 由外部开发者或代理机构创作的作品，未必自动归属于付费的公司——应以书面方式取得所有权转让。
