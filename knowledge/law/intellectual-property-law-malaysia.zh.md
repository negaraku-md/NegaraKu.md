一个标志、一道配方、一段代码、一个品牌名称——它们中的任何一个一旦开始赚钱，别人就有了模仿它的理由。马来西亚法律给了你一种方式，让你能说「那是我的，这是证明的凭据。」问题在于，三种主要的知识产权以三种完全不同的方式运作，弄错其中一种，可能让企业失去它最宝贵的资产。

本指南梳理创办人、投资者或创作者真正需要的框架：三部主管法令保护什么、你必须注册什么（以及不必注册什么）、保护期有多长，以及那些常让人栽跟头的实务决策。

## 在马来西亚什么算是知识产权？

知识产权（IP）是对智力成果所享有的一种法律权利——品牌、发明、设计和创作作品。马来西亚通过各自独立的法令加以保护，每部法令都有自己的规则、自己的保护期和自己的注册机制。一件产品可以同时承载多项权利：一款饮料可能有名称上的商标、瓶装工艺上的专利、瓶身形状的注册工业设计，以及标签图案的版权。

主要支柱为：

| 知识产权类型 | 主管法令 | 保护对象 | 注册 |
| --- | --- | --- | --- |
| 商标 | 《2019年商标法令》 | 区分商品/服务的品牌名称、标志和记号 | 须注册方持有注册商标 |
| 专利 | 《1983年专利法令》 | 具创造性步骤的新发明 | 须注册 |
| 实用创新 | 《1983年专利法令》 | 微小/渐进式发明（无需创造性步骤） | 须注册 |
| 版权 | 《1987年版权法令》 | 文学、音乐、艺术作品、电影、录音、广播 | 自动——无需注册 |
| 工业设计 | 《1996年工业设计法令》 | 产品的视觉外观 | 须注册 |
| 地理标志 | 地理标志立法 | 与原产地相关联的产品 | 须注册 |

本文聚焦于对几乎每一家企业都最重要的三种——商标、专利和版权——其余的作为辅助角色。

## 谁管理知识产权——MyIPO 又处于什么位置？

马来西亚几乎每一项可注册的知识产权都要经过同一个机构：**马来西亚知识产权局**，简称 **MyIPO**（*Perbadanan Harta Intelek Malaysia*）。它是隶属于国内贸易及生活成本部（KPDN）的法定机构，负责发展和管理国家知识产权体系。

MyIPO 是你办理以下事务的地方：

- 提交并办理商标、专利、工业设计和地理标志申请；
- 缴付续展费和年费以维持权利有效；
- 提交版权自愿通知，即使版权本身无需注册；
- 在推出或申请前检索现有注册。

申请通过 MyIPO 的在线门户以电子方式办理（例如专利通过 *iponline2u* 系统提交）。由于知识产权的审查和办理在程序上颇为专业，许多申请人——尤其是外国申请人——会通过注册专利或商标代理人办理，不过这并非始终强制。

## 商标在《2019年商标法令》下如何运作？

商标是任何能将你的商品或服务与他人区分开来的记号——名称、标志、口号，如今还包括较不传统的记号。马来西亚的商标法律在 **《2019年商标法令》（第 815 号法令）** 于 **2019 年 12 月 27 日** 生效、废止旧的《1976年商标法令》时得到大幅现代化。

2019 年法令在若干重要方面使马来西亚的实务更贴近国际规范：

- **多类别申请。** 依据第 18 条（「多类别申请」），一份申请如今可列出跨越尼斯分类多个类别的商品和服务，而不再强制每个类别单独提交申请。
- **非传统商标。** 该法令承认文字和标志以外的记号，包括三维形状、颜色、声音、气味和全息图。
- **驰名商标保护。** 第 4 条*定义*了「驰名商标」，第 76 条（「驰名商标的保护」）提供实质性保护——真正驰名的商标即使未在马来西亚注册也可获得保护。
- **加入《马德里议定书》。** 第十二部分（国际事项）第一章实施《马德里议定书》，马来西亚已加入该议定书，本地拥有人可提交一份指定多个国家的国际申请，外国拥有人也可指定马来西亚。
- **加强执法。** 第十三部分（边境措施）提供边境措施权力，包括限制侵权商品的进口及其扣押和没收。

### 保护期与续展

依据 **第 39 条**，注册商标自**注册之日起有效十年**，并可**续展十年期**。关键在于，续展没有上限——商标是唯一原则上可以永久存续的知识产权，这正是世界上最古老的品牌以商标而非专利受保护的原因。若错过续展期限，第 39(5) 条仍允许在**期满后六个月内**缴付续展费加附加费办理续展，因此短暂失效不必然是致命的。

### 先申请制

马来西亚基本上采用**先申请**制度：权利一般归于最先提交有效申请者，而非最先使用该名称者。在先的未注册使用仍可通过普通法上的**假冒**侵权之诉加以维护，但那比起单纯拥有一项注册要更慢、更昂贵、也更难证明。实务上的教训直白得很——在推出前提交申请，并先检索 MyIPO 的注册簿，以免与现有商标发生冲突。

## 专利和实用创新如何运作？

专利是以公开披露新发明为交换而授予的、有期限的垄断权。马来西亚的制度载于 **《1983年专利法令》（第 291 号法令）** 和《1986年专利条例》。

### 三项测试

一项发明要具可专利性，必须满足三项要求：

1. **新颖性**——它必须是新的，即在申请日时不属于世界任何地方的「现有技术」的一部分。
2. **创造性步骤**——它对相关领域的技术人员而言不得是显而易见的。
3. **工业实用性**——它必须能够在某种工业中制造或使用。

任何人——包括公司，不限于自然人发明者——均可单独或共同申请。申请可以用**马来文或英文**提交，MyIPO 会同时进行**形式审查**（文件和手续）和**实质审查**（对可专利性的真正测试）。

### 保护期

已授予的专利自**申请日起受保护二十年**，前提是缴付规定的**年费**以维持其有效。不缴费，专利即失效。二十年是上限——与商标不同，专利不能无限期续展，因为这项交易的约定是发明最终进入公共领域供所有人使用。

### 实用创新——较轻度的选择

并非每一项有用的发明都能跨过创造性步骤这道门槛。对于渐进式改进，《专利法令》还提供**实用创新**（有时称为实用新型或「小专利」）。它要求新颖性和工业实用性，但**不要求**创造性步骤，因而更易于取得。实用创新自**申请起受保护十年**，并可延长**两个五年期**，最长合计**二十年**。

| 特征 | 专利 | 实用创新 |
| --- | --- | --- |
| 是否要求创造性步骤 | 是 | 否 |
| 是否要求新颖性 | 是 | 是 |
| 工业实用性 | 是 | 是 |
| 最长保护期 | 自申请起 20 年 | 最长 20 年（10 + 5 + 5） |
| 最适合 | 真正新颖、非显而易见的发明 | 渐进式改进、较简单的装置 |

## 版权如何运作——为什么它与众不同？

版权是个异类，而这一差别在实务中影响巨大：它是**自动**的。依据 **《1987年版权法令》（第 332 号法令）**，保护在原创作品被创作并固定于物质形式的那一刻产生。马来西亚**不存在版权注册**，也不需要注册——无论你是否为之做任何事，这项权利都存在，这与马来西亚在《伯尔尼公约》下的义务相一致。

版权涵盖**文学作品**（包括软件源代码）、**音乐作品**、**艺术作品**、**电影**、**录音**和**广播**，并包括精神权利和表演者权利。

### 保护期

保护期取决于作品类型：

- **文学、音乐和艺术作品：** 作者有生之年**加去世后 50 年**。就合著作品而言，50 年自最后一位在世作者去世时起算。
- **录音、广播和电影：** 作品首次发表或制作后 **50 年**。

### 自愿通知

由于版权无需注册，在纠纷中证明*谁在何时创作了什么*可能很困难。为此，MyIPO 运营一套**自愿通知**系统：拥有人可以存放作品并提交通知（通常辅以法定声明），以建立对该主张的一份官方且注明日期的记录。它是可选的，也不是「注册」，但如果作品日后受到争议，它能提供有用的所有权证据。

## 商标、专利与版权：我需要哪一种？

这三种权利并非彼此的替代方案——它们保护不同的东西——但创办人常常将它们混淆。用下表来定位你的资产：

| 问题 | 若是，请考虑…… |
| --- | --- |
| 它是客户借以认出你的*名称、标志或品牌*吗？ | 商标 |
| 它是一项*新发明、装置、工艺或配方*吗？ | 专利（或实用创新） |
| 它是*书写、绘制、编码、谱写或拍摄*的内容吗？ | 版权（自动） |
| 它是产品的*形状或视觉外观*吗？ | 工业设计 |
| 它是*与地方相关联的产品*（例如某地区食品）吗？ | 地理标志 |

一条典型初创企业的快速决策路径：

1. **名称和标志 → 提交商标申请**，在推出前向 MyIPO 提交（先申请制）。
2. **核心技术 → 评估可专利性**；若通过新颖性和创造性步骤，提交专利申请，否则考虑实用创新。
3. **网站文案、代码、设计、营销内容 → 版权自动产生**；保留注明日期的记录，并就高价值作品考虑自愿通知。
4. **独特的产品形状 → 考虑工业设计**注册。

## 企业常犯的错误

- **在提交商标申请前就推出。** 在先申请制国家，竞争对手（或抢注者）可能在你还在「使用」某名称时就将其注册。先检索并提交申请。
- **以为版权涵盖品牌名称。** 并非如此——名称和标志属于商标法的领域；版权保护创作作品，而非品牌标识。
- **在提交专利申请前公开披露发明。** 新颖性会因世界任何地方的在先披露而丧失。在提交申请前进行推介、展出或销售可能葬送可专利性。先申请，后披露。
- **任由权利失效。** 商标需要每十年续展、专利需要缴付年费；错过它们，权利可能消亡。
- **把马来西亚的注册当作全球性的。** 知识产权具有地域性。马来西亚的商标或专利在国境处止步——若你在境外经营，请规划境外申请（商标通过《马德里议定书》，专利通过《专利合作条约》途径）。
- **将实用创新与完整专利混淆。** 二者在保护力度和要求上有所不同；选错会浪费时间和金钱。
- **未从承包商处取得知识产权转让。** 由外部开发者或代理机构创作的成果，未必自动归属于付款的公司——务必以书面取得所有权转让。
