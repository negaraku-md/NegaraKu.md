連邦憲法第2編は、マレーシア人の最も基本的な権利を保障している――そして、その中のほぼすべての条文が、同じ呼吸の中で、憲法自体が認める制限をも明記している。この保障と許容される制限との組み合わせは、起草上の偶然ではない。それこそが第2編の構築のされ方である。

第2編は第5条から第13条にわたる。以下の各条文は、憲法の現行重印本に記載されているとおりに、憲法自体が含む制限条項とあわせて説明する。

## 概要

| | |
| --- | --- |
| 編 | 第2編――基本的自由 |
| 条文 | 第5〜13条 |
| 拘束を受ける者 | 国会、州議会、行政機関及び公的機関 |
| 執行する主体 | 裁判所――司法審査及び第5条(2)に基づく人身保護令状の申請を通じて |
| 二つの憲法上の凌駕条項 | 第149条（反破壊活動立法）及び第150条（緊急権限） |

## 条文ごとの解説

**連邦憲法第5条（生命及び身体の自由）。** 何人も、法律に従う場合を除き、生命又は身体の自由を奪われない。何者かが違法に拘束されている場合、それを確信した高等法院の裁判官は、その釈放を命じなければならない――これが人身保護令状の申請の憲法上の根拠である。逮捕された者は、逮捕の理由を告げられ、自ら選んだ弁護人を認められなければならず、また不合理な遅延なく、いかなる場合であっても24時間以内(移動時間を除く)に推事(magistrate)の面前に引致されなければならない。その24時間という数字は、当該者が公民ではなく移民法に基づいて逮捕された場合には14日となり、また当該犯罪がシャリア裁判所で審理されるべきものである場合、「推事」という語にはシャリア裁判所の判事も含まれる。第(3)項及び第(4)項のこれらの保障は、敵性外国人には及ばない。

**第6条――奴隷及び強制労働の禁止。** 何人も奴隷状態に置かれてはならず、強制労働は全面的に禁止されている――ただし、国会は法律により国家的目的のための強制的服役を定めることができる。裁判所の有罪判決の結果として行われる労役は、公的機関の監督の下で行われる限り、ここでいう「強制労働」には当たらない。さらに別の項は、ある公的機関の機能が別の公的機関に移される際に異動となる職員についても定めている。その異動もまた強制労働には当たらない。

**第7条――遡及的刑事法律からの保護及び再度の裁判の禁止。** 何人も、行為が行われた当時は犯罪ではなかった行為について処罰されることはなく、また当時の法律が定めた刑罰よりも重い刑罰を科されることもない。既にある罪について無罪又は有罪の判決を受けた者は、その判決が上級裁判所によって破棄され再審が命じられた場合を除き、同じ罪について再び裁判にかけられることはない。第2編の他の大半の条文とは異なり、第7条には国会がこれを制限しうる旨の項は含まれていない。

**第8条――平等。** すべての者は法律の前に平等であり、法律の平等な保護を受ける権利を有する。公民は、法律上又は公的雇用において、宗教、人種、血統、出生地又は性別のみを理由として差別されてはならない。統治者の臣民を優遇する差別があってはならず、また、いかなる公的機関も、自己の管轄区域外に居住し又は事業を営むことを理由に人を差別してはならない。続いて第(5)項は、本条が禁止しない事項を列挙している。すなわち、属人法の規律；宗教団体の雇用をその宗教の信者に限定すること；マレー半島の原住民の保護及び向上のための規定；州レベルの選挙又は任命のための州居住資格；独立以前の州憲法の規定；並びにマレー連隊への入隊をマレー人に限定することである。

**第9条――追放の禁止及び移動の自由。** いかなる公民も、連邦から追放され又は排除されることはない。すべての公民は、連邦全域を自由に移動し、その中のいずれの場所にも居住する権利を有するが、その権利は連邦の治安、公共秩序、公衆衛生又は犯罪者の処罰に関する法律に従う。さらに別の項は、国会が、マラヤ諸州と比較して憲法上特殊な地位を有する州と連邦との間の移動及び居住について制限を課すことを認めている。

**第10条――言論、集会及び結社の自由。** すべての公民は言論及び表現の自由についての権利を有する。すべての公民は、平穏に、かつ武器を持たずに集会する権利、及び結社を組織する権利を有する。これら三つの権利は、いずれも明文で第(2)項から第(4)項に従うものとされている。国会は、連邦の治安、他国との友好関係、公共秩序若しくは道徳のため、又は国会特権を保護し、若しくは法廷侮辱、名誉毀損若しくは犯罪の煽動を防ぐために、言論を制限することができる。集会は、治安又は公共秩序のために制限されることがある。結社は、治安、公共秩序又は道徳のために制限されることがあるほか、労働又は教育に関するいかなる法律によっても別途制限されることがある。さらに別の項は、国会が治安又は公共秩序を理由に立法する際、第3編（国籍）又は第152条、第153条若しくは第181条の下で保護される事項について、それらの規定がいかに実施されるかに関するものを除き、疑義を呈することを禁じることを認めている。

**第11条――信教の自由。** 何人も、自己の宗教を信仰し実践する権利、及び第(4)項に従うことを条件としてこれを布教する権利を有する。何人も、その収益が自己以外の宗教に充てられる租税を支払うことを強制されない。すべての宗教団体は、自らの宗教上の事務を管理し、宗教又は慈善のための施設を設立し維持し、並びに法律に従って財産を取得し管理する権利を有する。州法――クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区については連邦法律――は、イスラム教を信奉する者の間における宗教上の教義の布教を規制又は制限することができる。本条は、公共秩序、公衆衛生又は道徳に関する一般法律に反するいかなる行為も認めるものではない。

**第12条――教育に関する権利。** 第8条を限定することなく、公立の教育施設の運営において、又は教育のための公的財政援助において、宗教、人種、血統若しくは出生地のみを理由として公民を差別してはならない。すべての宗教団体は、宗教のみを理由とする差別なく、自己の宗教により子女を教育するための施設を設立し維持することができる――ただし、連邦又は州がイスラム教の施設又は教育を設立し、維持し又は資金提供することは引き続き適法である。何人も、自己以外の宗教の宗教教育を受け、又はその礼拝に参加することを要求されない。18歳未満の者については、その選択はその父母又は後見人が行う。

**第13条――財産権。** 何人も、法律に従う場合を除き財産を剥奪されず、また、いかなる法律も、十分な補償を伴わずに財産の強制取得又は使用を定めることはできない。

## 二つの憲法上の凌駕条項

第2編の外にある更に二つの条文が、国会に対し、上記に列挙した制限条項を超えることを認めている。

**第149条**は、国会法が、連邦の内外を問わず相当数の人の集団によって、組織的暴力を引き起こすため、国王（Yang di-Pertuan Agong）若しくは政府に対する不満を扇動するため、暴力を引き起こす蓋然性のある人種的若しくは階級的な悪感情を助長するため、法律によって確立された事項の不法な変更を図るため、又は公共秩序、治安若しくは不可欠な供給若しくはサービスを害するために、行動が取られ又はそのおそれがある旨を記載している場合には、その行動を阻止し又は防止することを目的とする当該法律のいかなる規定も、第5条、第9条、第10条又は第13条と抵触する場合であっても有効であると定めている。

**第150条**は、連邦又はその一部の治安、経済生活又は公共秩序を脅かす重大な緊急事態があると確信する場合、国王（Yang di-Pertuan Agong）が緊急事態宣言を発することを認めている。かかる宣言が発効している間、国会は、緊急事態を理由として必要とされる場合には、憲法にいかなる規定があるかにかかわらず、いかなる事項についても法律を制定することができる――そして、第150条自体に定める更なる条件に従うことを条件として、かかる法律及び法令は、単に憲法と抵触することを理由として無効となることはない。

## よくある誤解

- **第2編を絶対的なものとして扱うこと。** 第2編のほぼすべての条文が、その条文自体の中に自らの制限条項を含んでおり、さらに第149条及び第150条がそのうちの複数を追加的に限定しうる。「Fundamental」（基本的）という語が表すのは、それらが憲法の構造の中で占める位置であって、それらに限界がないということではない。
- **あらゆる自由があらゆる者に属すると想定すること。** 第5条、第6条、第7条、第8条(1)、第11条及び第13条は「person」（者）という語を用いており、公民に限定されていない。第9条、第10条、並びに第8条及び第12条の一部は、特に「citizen」（公民）の権利として表現されている。
- **第8条を第(5)項から切り離して読むこと。** 第8条の平等の保障は、同条内に列挙された明文の例外により直ちに限定されている――それは単独で成り立つものではない。
- **第10条の三つの権利がそれぞれ異なる制限理由を有することを見落とすこと。** 言論は、名誉毀損及び法廷侮辱を含め、より多くの理由により制限されうるのに対し、集会は治安又は公共秩序のためにしか制限されえない。

## 誰がこれを執行するか

第2編はそれ自体では執行されない。第4条は憲法を連邦の最高法規とするものであり、したがって第2編に抵触する法律は、その抵触する限度において無効となる――しかし、その無効性は、憲法上の争訟を通じて、又は違法な拘束についてはまさに第5条(2)に基づく人身保護令状の申請を通じて、裁判所によって確立される。
