活動制限令（Perintah Kawalan Pergerakan、PKP）が2020年3月、マレーシアのほぼ全土で人々の移動を停止させたとき、その背後にある法的権限は、いかなる新たな緊急法からも生じたものではなかった——それは、1988年から存在してきた一つの公衆衛生法令から生じたものであった。

その法令とは1988年感染症予防・管理法（Prevention and Control of Infectious Diseases Act 1988、Act 342）、より広く**Act 342**として知られているものである。本稿は、同法令の内容を記述的に説明する——何を規定し、誰がそれを執行し、なぜそれが公的な議論の対象となっているのかを。これは法律助言ではない。

## Act 342とは何か、そしてなぜ存在するのか？

Act 342は、「伝染病の予防及び管理に関する法律を改正し、統合すること」を目的とする連邦法である。同法は、独立以前の時代に存在していた検疫及び疾病予防に関する一連の古い法規に取って代わった。同法のSecond Schedule（第二附表）によれば、廃止された成文法には、マレー連合州（Federated Malay States）の検疫法規及び疾病予防法規、予防接種法規、1939年検疫及び疾病予防条例（Ordinan Kuarantin dan Pencegahan Penyakit 1939）、いくつかの州法規（ジョホール、ケダ、クランタン、パーリス及びトレンガヌを含む）、並びに1971年マラリア撲滅法（Akta Pembasmian Malaria 1971、Akta 52）が含まれる。

総検察庁（Attorney General's Chambers）発行の公式テキストによれば、同法令は**1988年8月13日**に御裁可を受け、**1988年9月8日**に官報告示され、**1989年4月1日**にマレーシア全土で施行された（P.U. (B) 179/1989）。

同法令の執行は、保健大臣、保健総局長、及び「権限を有する職員」——すなわち、あらゆる保健医務官、衛生検査官、又はs.3に基づき大臣が任命した職員——に委ねられている。警察、関税及び入国管理の職員は、要請があった場合に協力を提供することが義務づけられている（s.5）。

## 本法令はどの疾病を対象としているか？

Act 342は「感染症」、すなわち**First Schedule（第一附表）**に列挙された疾病にのみ適用される。総検察庁発行の更新版テキスト（2020年7月1日現在）では、同附表のPart I（第I部）は1から30の番号が付された疾病を列挙しており（COVID-19が追加項目3Aとして含まれる）、Part II（第II部）はヒト免疫不全ウイルス（HIV）感染を列挙している。

列挙されている疾病の一部は次のとおりである。

| Part Iの例 | Part II |
| --- | --- |
| コレラ（cholera、item 3） | HIV感染（すべての形態） |
| デング熱及びデング出血熱（item 4） | |
| 肺結核／結核（tuberculosis）、すべての形態（item 22） | |
| 狂犬病（rabies、item 18）、マラリア（malaria、item 13）、ハンセン病／leprosy（item 11） | |
| COVID-19（AGC英語版テキストのitem 3A） | |
| 「生命を脅かすその他あらゆる微生物感染症」（item 30） | |

この一覧は固定的なものではない。s.30は、大臣に対し、官報における命令によりFirst Scheduleを削除、追加又は改正する権限を与えている。COVID-19は、2020年のFirst Schedule改正（P.U. (A) 179/2020）を通じて追加された。

## 本法令下の主な権限は何か？

同法令のPart IV（第4部）——「感染症のまん延に対する規制」——には、最も日常的に用いられる権限が定められている。以下は、いくつかの中核となる条文の概要である。

- **s.10**——通報義務。感染症が発生した住居のすべての成人居住者、及びそのような症例を治療するすべての医療従事者は、できる限り速やかに保健当局に通報しなければならない。
- **s.11**——感染地域指定の宣言。大臣が、ある地域において疫病の発生又は流行の脅威があると認める場合、当該地域を感染地域指定として宣言し、当該地域内又は当該地域からの移動を管制する規則を制定することができる。
- **s.14**——感染者及び感染が疑われる者の隔離、並びに検疫所への移送。
- **s.15**——接触者に対する観察又は監視（surveillance）。
- **s.18**——消毒及び施設の閉鎖。
- **s.31**——同法令を実施するための規則制定権限。人の入国及び移動の管制並びに検疫手続を含む。

s.11(3)に基づき、感染地域指定命令が効力を有する間、権限を有する職員は、いかなる者又はいかなる部類の者に対しても、治療、予防接種、隔離、観察又は監視を受けるよう命じることができる。s.11(4)及びs.15(2)は、さらに、職員が遵守を確保するために「必要ないかなる実力」も行使できると定めており——この規定は、最も多くの議論を呼んでいる条項の一つである。

## Act 342はどのようにCOVID-19のPKPの基礎となったか？

2020年3月のPKPは、s.11に定める二段階の仕組みの上に築かれた。第一に、大臣は2020年感染症予防・管理（感染地域指定宣言）令［P.U. (A) 87/2020］を通じて感染地域指定を宣言した。RLSEの法的分析によれば、当該款に基づく権限は宣言された地域の「内又はそこから」にのみ適用されるため、制限を全国規模で適用できるよう、すべての州及び連邦直轄区が感染地域指定として宣言された。

第二に、実際の移動制限措置は、同法令s.11(2)に基づき**2020年3月31日**に官報告示された2020年感染症予防・管理（感染地域指定内措置）（第2号）規則を通じて定められた。この構造——宣言令に続く措置規則——こそが、PKP、PKPB及びPKPPの各段階を通じて繰り返された。

## 本法令下の刑罰は何か？

同法令のPart V（第5部）は、罪及び刑罚について詳細に定めている。s.22は、一般的な罪——権限を有する職員を妨害すること、適法な命令に従わないこと、又は虚偽の情報を提供することを含む——を定義している。同法令原文によれば：

- **s.24（一般刑罰）**——特定の刑罰が定められていない罪について：初犯の場合、2年以下の禁錮若しくは罰金又はその両方；再犯又はそれ以降の場合、5年以下の禁錮；継続する罪については、1日につきRM200を超えない追加の罰金。
- **s.25（過料（コンパウンド）による和解）**——保健総局長又は権限を有する職員は、一定の罪について、**RM1,000**を超えない金額を徴収することにより和解することができる。

これらの金額こそが、その後の年に行われた改正の対象の一つとなった。

## なぜ本法令は議論の的となっているのか？

パンデミック後、政府はAct 342を強化するための法案を提出した。CodeBlueの報道によれば、下院（Dewan Rakyat）は**2024年10月14日**、口頭表決によりAct 342改正法案を可決した。

同法案で報じられた変更点には、次のものが含まれる。

- **s.24（一般刑罰）**が、個人については最高RM10,000、法人については最高RM100,000の罰金に引き上げられる。
- **s.25（過料）**が、個人については最高RM5,000、法人については最高RM50,000に引き上げられる。
- **s.31(3)**は、規則に違反した個人について最高RM8,000の罰金若しくは2年以下の禁錮又はその両方を、法人については最高RM50,000を定めている。
- 新設の**s.21A**は、保健総局長に対し、いかなる者又はいかなる部類の者にも、疾病の予防及び管理のための措置を講じるようあらゆる指示を発する権限を与える。

この改正に対する見解は分かれている。支持派は、これが保健省の感染症対応能力を強化し、法律を国際的な動向と整合させるものであると主張する。反対派——与野党双方の一部の国会議員、法曹団体及び権利擁護団体を含む——は、より重い刑罚が低所得層に不均衡な影響を与えかねないこと、保健総局長の権限の濫用に対する保護が不十分であること、そしてこのアプローチが健康教育よりも懲罰に過度に依存していることへの懸念を表明している。本稿はいずれの立場も取らない。それは、公的な議論の中にこれら両方の見解が存在することを記録するにとどまる。

## 次のステップ

Act 342は、マレーシアにおける感染症対策の中核をなす公衆衛生法制の枠組みであり続けており、その構造——宣言、規則、指示、刑罚——は、将来のいかなる保健危機においても再び用いられる可能性が高い。刑罚の金額及び特定の権限は、2024年に下院で可決された改正の対象となっているため、現在実際に適用されている料率は、官報告示された法的文書及びその施行日に左右される。
