一部手机在第二周就报销了。一名装修承包商拿了订金后消失无踪。一张「五折优惠」
的贴纸，贴在一个从未真正是原价的价格上。马来西亚有一部统一应对这三种情况的
法令：Consumer Protection Act 1999。

本页是 Act 599 的法令记录——它涵盖的内容、赋予消费者的权利，以及它为了在
无须律师或法院存档费的情况下执行这些权利而设立的仲裁庭。本页不是逐一说明
每一项罪行、罚则或仲裁庭申索表格的操作指南。

## 一览

| | |
| --- | --- |
| 简称 | Consumer Protection Act 1999 |
| 法令编号 | Act 599 |
| 执行机关 | 国内贸易及生活成本部（KPDN） |
| 执行场所 | 消费人索偿仲裁庭（1999 年 11 月 15 日设立） |
| 仲裁庭申索限额 | RM50,000 |
| 仲裁庭存档费 | RM5 |
| 时限 | 申索须在 3 年内发生 |

## 该法令涵盖的内容

Act 599 赋予消费者若干法定权利，这些权利与一般合约法并行——在某些方面
甚至超越了合约法。其主要保护涵盖：

- **误导与欺骗行为** — 就商品、服务或价格作出虚假或误导性的陈述，包括
  诱饵广告（bait advertising），以及关于库存有限的误导性声明。
- **商品与服务的安全** — 售予消费者的商品与服务须符合的标准，以及对
  供应不安全商品的一般禁止。
- **商品与服务供应中的保证** — 默示保证售予消费者的商品品质可接受、
  适合其已披露的用途，以及服务须以合理的谨慎与技巧执行。
- **不公平合约条款** — 由后来的修正案新增，赋予消费者理由去质疑消费
  合约中造成双方权利显著失衡、且对消费者不利的条款。

该法令同时设立了**国家消费者顾问理事会（National Consumer Advisory
Council）**以向部长提供意见，以及**消费人索偿仲裁庭**作为大多数消费者
实际会接触到的执行机构。

## 消费人索偿仲裁庭

该仲裁庭是这部法令中使用得最多的部分——一个隶属 KPDN 的准司法机构，
作为比民事法院更便宜、更快捷的替代途径。

| | |
| --- | --- |
| 设立 | 1999 年 11 月 15 日 |
| 申索限额 | RM50,000 |
| 存档费 | RM5 |
| 时限 | 申索须在 3 年内发生 |
| 裁决时间表 | 仲裁庭力求在首次聆讯日后 60 天内作出裁决 |
| 终局性 | 裁决属终局且具约束力；可透过推事庭强制执行 |

申索可在全国任何仲裁庭柜台提交，或在网上提交。申索必须是**因购买商品
或服务而产生的补救**——而不是任何涉及金钱的纠纷。

### 仲裁庭不会受理的事项

即使某些争议本身涉及消费交易，仲裁庭仍明确将若干类别的争议排除在外：

- 人身伤害或死亡
- 土地或产业争议
- 受其他成文法监管的专业服务
- 医疗保健服务
- 航空服务
- 属于其他仲裁庭管辖范围的事项

### 若你不同意该裁决

由于裁决根据该法令属终局且具约束力，因此没有一般的上诉权。不服的一方
可向**高庭**申请**司法审查**——这是一种范围更窄的救济，只着重于仲裁庭
的行为是否合法，而不是重新审理案件事实。

## 常见错误

- **以为任何消费者投诉都符合资格。** 人身伤害、土地，以及受监管专业
  服务的争议，即使消费者是吃亏的一方，仍不在仲裁庭的管辖范围之内。
- **拖延申索。** 三年时限从争议发生时起算，而不是从消费者终于抽空
  提交申索的那一刻才开始。
- **期望能上诉。** 把仲裁庭的裁决当作可以直接上诉的初审法院判决——
  事实并非如此；司法审查是另一条不同且更狭窄的路径。

## 下一步

本页确立了 Act 599 的身份、涵盖范围与仲裁庭运作机制。消费交易仍然
建立于其上的一般合约法，载于 [Contracts Act 1950](/zh/law/contracts-act-1950)；
若某项仲裁庭裁决需要强制执行，或某宗争议完全落在仲裁庭管辖范围之外，
相关的处理场所则属于[法院体系](/zh/law/court-hierarchy)。以注册公司身份
进行销售的商家，也应阅读 [Companies Act 2016](/zh/law/companies-act-2016)，
以了解自身的合规义务。
