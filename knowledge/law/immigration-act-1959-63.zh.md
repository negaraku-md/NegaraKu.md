护照里有一张有效签证，本身并不能让你踏足马来西亚——而它也不是你居留过久时会惹上麻烦的那份文件。这两项职责都属于同一部法律：**《1959/63年移民法令》（Act 155）**，这部法规决定谁可以越过边境、他们入境后可做什么，以及当他们违反居留条件时会发生什么。

如果你是外派人员、外籍劳工、数字游民、投资者，或是上述任何人的雇主，Act 155 便是你最可能触及的那部马来西亚法律。本指南解释它的三个环节——**入境、准证与逾期居留**——以及那些让把它们弄对变得值得的罚则。

## 《1959/63年移民法令》究竟是什么？

该法令是马来西亚的基础性移民法规。「1959/63」反映了它的历史：最初于1959年制定，并在1963年沙巴与砂拉越加入联邦时修订，这也是沙巴与砂拉越至今仍保有独立移民自主权的原因。它由**马来西亚移民局（Jabatan Imigresen Malaysia, JIM）**执行，其执法组同时执行《1966年护照法令》以及《2007年反人口贩运及反偷运移民法令》。

非公民在边境及其后所做的一切都经由这部法令：签证背书、入境时盖章的准证、附加于该准证的条件，以及条件被违反时适用的罪名。理解这套术语是第一道防线。

## 签证还是准证——有什么区别，为什么重要？

旅客随意使用「签证」一词，但在马来西亚法律下，签证与准证是两样不同的东西，在两个不同的时刻签发，履行两种不同的职责。

| | 签证 | 准证 |
|---|---|---|
| **它是什么** | 前往马来西亚入境点的许可 | 入境并停留的许可，附带既定目的 |
| **何时签发** | 出发前（或通过 eVISA / eNTRI），或对豁免国民免除 | 抵达时，由移民官签发，或通过外派人员服务组签发 |
| **它管控什么** | 你是否可以登机并抵达边境 | 目的（社交、工作、留学、家属）与居留期限 |
| **真正计时的时钟** | 不是逾期居留的触发点 | 其到期日才是逾期居留的起点 |

实务上的要点很直白：**管控你居留的是准证，而非签证。** 签证可能有效，你的准证却已到期——而正是那张到期的准证使你成为逾期居留者。请务必查看移民官给你的盖章或贴纸，并记下它的到期日，而非签证上的日期。

签证也不保证入境。检查站的移民官仍可拒发准证——例如，如果你被认定为该法令下的*受禁移民*（prohibited immigrant）。

## 我入境马来西亚需要签证吗？

这完全取决于国籍。马来西亚采用三个大类：

- **免签证国民**——许多国家的公民可无需事先签证入境进行社交或商务访问，并在抵达时获发社交访问准证。获批的期限由移民官酌情决定，并因国籍而异，因此请查看盖章，而非假定一个固定的天数。
- **需要签证的国民**——约三十个国家的公民必须在出行前取得签证。移民局的国家清单包括阿富汗、孟加拉、巴基斯坦、斯里兰卡、尼泊尔、哥伦比亚、黑山与塞尔维亚等国的国民。有些安排有时限：例如，印度公民被列为免签证至2026年12月31日。
- **特别便利安排**——诸如 eNTRI 与 eVISA 之类的计划为特定国籍（例如中国大陆与印度国民）简化入境手续，某些国家仅获准以空路入境。

由于这些清单会变动，请在订票前对照移民局当前的*按国家划分的签证要求*（Visa Requirement by Country）核实你自己的国籍。

在*确实*需要签证之处，常见的形式包括单次入境签证（一趟行程）、多次入境签证（在有效期内重复出行）与过境签证。较长期居留及工作目的通常经由**参考签证（Visa With Reference, VDR）**办理，它须凭马来西亚境内某个当局的参考（reference）批准——通常与工作或留学安排挂钩——之后才在海外签发签证。

## 哪种准证让我停留、工作或携带家人？

一旦获准入境，*准证*便界定你可合法做什么。使用错误的准证——例如持社交访问准证工作——本身就是一项罪行。主要类别：

| 准证 | 目的 | 典型持有人 |
|---|---|---|
| **社交访问准证** | 旅游、探亲、短期商务会议；**不得就业** | 游客、短期访客 |
| **就业准证（EP）** | 与特定雇主及合同挂钩的技术性就业 | 外派专业人士与高管 |
| **专业访问准证（PVP）** | 为外国雇主执行的临时专业任务 | 顾问、培训师、短期专家 |
| **临时就业准证** | 获批行业中的半技术与非技术工作 | 制造、种植园等行业的外籍劳工 |
| **家属准证** | 陪同就业准证持有人的家属 | 配偶及18岁以下子女 |
| **长期社交访问准证（LTSVP）** | 家属准证未涵盖的较长期家属停留 | 父母、年龄较大的子女、某些伴侣 |
| **DE Rantau 游民准证** | 为外国雇主或客户进行的远程工作 | 符合条件的数字游民与远程专业人士 |

**DE Rantau 游民准证**由马来西亚数字经济机构（MDEC）管理，让符合条件的远程工作者在马来西亚常驻最长12个月，并可再续期12个月。适用最低收入与经验门槛，且技术与非技术岗位有所不同，因此在申请前请在 MDEC 的 DE Rantau 门户上确认当前的续期条款与资格标准。

## 我持就业准证可以工作多久？

就业准证是专业人士的主力文件，并按**月薪**分级。马来西亚自**2026年6月1日**起修订了这套框架，同时改变了薪资等级与最长期限：

| 类别 | 最低月薪 | 最长期限（同一雇主） | 备注 |
|---|---|---|---|
| **第一类** | 2万令吉及以上 | 最长10年 | 可申请家属准证 |
| **第二类** | 1万 – 19,999令吉 | 最长10年 | 须提交接班计划 |
| **第三类** | 5,000 – 9,999令吉 | 最长5年 | 须提交接班计划 |
| 低于5,000令吉 | — | 不符合就业准证资格 | 考虑其他准证类型 |

实务上有几点值得注意。就业准证受雇佣合同约束，过去每次签发大致以60个月为上限，而*最长累计期限*现已设定为上述数字。移民局已表明，新的最长期限的适用**不考虑此前已签发的任何就业准证**，且该时钟通常**在你更换雇主时重新计算**。对于第二类与第三类，雇主必须提交**接班计划**，说明将如何培训马来西亚员工在准证期限内接手该职位。

外派人员的就业准证通常通过**外派人员服务组（ESD）**及其 MYXpats 服务中心办理，而非在一般移民柜台办理。

## 如果我逾期居留会怎样？

这正是该法令下手最狠之处，也是最代价高昂的误解发生之处。马来西亚法院将逾期居留视为**严格责任罪**——意味着无论逾期居留是否出于故意，你都可能被定罪。「我忘了」、「我的航班取消了」或「我算错了天数」都不是免除责任的抗辩理由。

核心条文是**第15(1)(c)条**，它禁止在准证到期后继续留在马来西亚，而罪名订立于**第15(4)条**。

| 要素 | 详情 |
|---|---|
| **罪名** | 在准证到期或撤销后继续停留（第15(1)(c) / 15(4)条） |
| **罚款** | 不少于1万令吉（法定最低额） |
| **监禁** | 最长5年 |
| **组合** | 罚款、监禁，或两者兼施 |
| **罚款了结** | 在符合条件的情况下最高3,000令吉（庭外和解） |
| **鞭刑** | 单纯逾期居留未列入 |

除了法庭上的刑罚之外，行政后果才是对普通旅客与劳工影响最大的：

- 在案件处理期间被**扣留**于移民扣留所。
- **遣返 / 遣送**，往往由逾期居留者自行承担费用。
- **列入黑名单**——由移民局酌情施加的再入境禁令，实际上可阻止未来的行程；重犯或严重个案可能面临更长的禁令。

即使是短暂、无意的逾期居留，也可能触发罚款了结及一项悄悄阻断未来行程的黑名单。教训是：把准证到期日当作不可变动，并在到期*之前*——绝不在之后——续签或离境。

## 非法入境、伪造文件——它们与逾期居留有何不同？

逾期居留只是数项罪行之一，其中有些罪名的刑罚更严厉，包括肉刑。

| 罪行 | 条文 | 刑罚 |
|---|---|---|
| **非法入境**（无真实护照/准证，或无有效背书） | 6(3) | 罚款最高1万令吉，或最长5年监禁，或两者兼施；**最多6下鞭刑**；罚款了结最高3,000令吉 |
| **逾期居留** | 15(4) | 罚款不少于1万令吉，或最长5年监禁，或两者兼施；罚款了结最高3,000令吉 |
| **文件伪造 / 篡改** | 55D | 罚款不少于3万令吉；监禁5至10年；最多6下鞭刑 |

非法入境与逾期居留之间的差别值得牢记：**非法入境可招致鞭刑；单纯的逾期居留则不会。** 而伪造或篡改移民背书——例如篡改准证以争取额外时间——则跳入最严重的等级，最低罚款3万令吉且须强制监禁。

## 我的雇主或东道主也会被检控吗？

会——该法令刻意将责任扩展至外国人之外。如果你雇用、留宿无证外国人或与之共处场所，你便有自身的风险敞口。

| 罪行 | 条文 | 刑罚 |
|---|---|---|
| **雇用非法移民** | 55B | 罚款1万–5万令吉，或最长12个月监禁，**每名工人**计；雇用5名以上工人：6个月至5年监禁并可能处以鞭刑 |
| **收容非法移民** | 56(1)(d) | 罚款1万–5万令吉；收容5人以上：6个月至5年监禁并可能处以鞭刑 |
| **场所占用人**容许非法入境/居留 | 55E | 每名非法移民罚款5,000–3万令吉，或最长12个月监禁，或两者兼施；第二次犯罪：罚款至少1万令吉，或最长2年监禁，或两者兼施 |

对企业而言，第55B条明确表明移民合规不仅仅是工人的问题：刑罚是**按工人计算**的，而雇用五名或以上无证员工便会升级至监禁的范畴。业主与场所占用人则因视而不见而面对第55E条。

## 我需要哪种准证？一个快速决策框架

按顺序思考以下问题：

1. **你是来马来西亚有偿工作的吗？** 如果不是，**社交访问准证**（免签证或持签证）通常足以应付旅游或短期访问。如果是，继续。
2. **这份工作是为马来西亚雇主长期进行的吗？** 如果是，你需要**就业准证**——挑选与你月薪相匹配的类别（一、二或三）。如果低于5,000令吉，就业准证无法申请；请探讨临时就业准证或行业专属途径。
3. **该任务是短期且为外国雇主进行的吗？** **专业访问准证**可能合适。
4. **你为海外的客户或雇主进行远程工作吗？** 考虑 **DE Rantau 游民准证**。
5. **携带家人？** 薪资高于门槛的就业准证持有人可加办**家属准证**（配偶、18岁以下子女），并为其他人办理 **LTSVP**。

有疑问时，最稳妥的默认做法是在出行或开始工作*之前*——而非之后——向移民局或 ESD 确认。

## 导致被检控的常见错误

- **将签证日期与准证日期混淆。** 逾期居留的时钟从入境时盖章的准证到期日起算，而非签证。
- **持社交访问准证工作。** 即使只是持错误准证进行一天的有偿工作，对工人与雇主而言都是一项罪行。
- **假定意图对逾期居留有影响。** 它是严格责任；忘记或算错都不是抗辩理由。
- **让续签逾期失效。** 在到期*之前*续签或离境；即便只是几天的间隔也构成逾期居留。
- **篡改准证或背书。** 这是第55D条下的文件伪造——一项远比逾期居留严重的罪行。
- **雇主指望工人自行处理其身份问题。** 第55B条的责任明确落在雇主身上，按每名工人计。
- **盲目信任中介。** 你要对自己持有的有效准证负责；请自行核实，而非假定中介已办理续签。

## 接下来该做什么

- **今天就查看你的盖章。** 找到护照里的准证并确认其到期日——那一个日期就是 Act 155 用来衡量你的那个日期。
- **核实你所属国籍的签证规则**，在任何行程前查阅移民局当前的*按国家划分的签证要求*页面。
- **确认当前的就业准证门槛**，如果你或你的员工持有就业准证，请通过外派人员服务组确认，因为薪资等级与期限已于2026年6月1日修订。
- **如果你已经逾期居留**，切勿基于错误假设试图悄悄离境——向移民局咨询罚款了结与离境流程，并鉴于该罪行的严格责任性质，考虑寻求合格的法律意见。

本文是关于《1959/63年移民法令》的一般性信息，而非法律意见。移民规则、薪资门槛与签证清单经常变动；在行动前，请务必向马来西亚移民局或合格顾问确认当前的立场。
