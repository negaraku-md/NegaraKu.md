请古晋的律师依据 National Land Code 核实槟城的一份地契，老实的答案是：它在
那里根本不适用。马来西亚实际施行三套各自独立的土地法令，而非单一一套——
这个单一事实，正是大多数摘要都会略去的部分。

## 一览

| | |
| --- | --- |
| 简称 | National Land Code 1965 |
| 法令编号 | Act 828（原为 Act 56 of 1965） |
| 生效 | 1966年1月1日，经 Legal Notice 474/1965 |
| 宪法依据 | 第76(4)条，联邦宪法——就州清单事项确保统一性 |
| 地域范围 | 马来西亚半岛十一个州属 |
| 施行的制度 | 托伦斯（Torrens）——以登记确立地契 |
| 不涵盖 | 沙巴、砂拉越——各自设有本身的土地法令 |

## "Torrens" 到底改变了什么

在类似本法令这样的登记制度出现之前，世界上大部分地方的土地所有权都建立在
地契文件（deeds）之上：一连串私人文件层层相扣，每一份文件的可靠程度都取决
于它之前的那一份，买家的保障则取决于能否将这条链一路追溯得够远。

托伦斯制度（Torrens system）以十九世纪南澳大利亚改革者 Sir Robert Torrens
命名，彻底颠覆了这种做法。**登记册本身就是地契。** 所有权并非靠出示陈年文
件来证明；而是靠注册官此刻已将谁的名字登记在那块土地之下来证明。

National Land Code 以单一一部法令，将这套制度带入马来西亚半岛，取代了此前
各州林林总总的土地法令——本法令正式废除了这些法令，并将其列于 Eleventh
Schedule 之中。

## 登记才是那项行为，签名不是

根据本法令，签署转让、租赁或抵押文件本身并不会移转土地上的任何权益。该文
件必须呈交予注册官（Registrar of Titles，负责登记处地契土地）或土地行政官
（Land Administrator，负责土地局地契土地）予以登记。唯有该项登记，才使该
交易完成。

正是这一条单纯的机械式规则，使登记册可靠到足以让人照单全信——而这正是托
伦斯制度的全部意义所在。

## 不可推翻性——及其限度

本法令 Section 340 赋予登记产权人（registered proprietor）的地契或权益**不
可推翻性**：一旦你的名字登上登记册，你的地契便对世上任何人皆属有效，日后
的挑战者一般不能仅凭出示一项更早、未经登记的主张，就将其推翻。

这项保障并非绝对。该条文划出若干例外情况：登记本身是经由欺诈或伪造取得、
是通过不充分或无效的文书取得，或属于该条文另行订明的其他情形——这些情形
正是马来西亚各法院数十年来在「延迟不可推翻性」（deferred indefeasibility）
原则下不断处理的问题。这项机制本身，比任何单一案例都更重要：不可推翻性保
护的是登记册，未必是某个名字登上登记册的每一条途径。

## 州政府仍然拥有这套制度背后的土地

登记并不会消灭州政府的所有权。根据联邦宪法，土地仍然是州属事务，而本法令
正是将这一点付诸实行：**州政府当局**（State Authority，即依州行政谘询行事
的统治者或州元首）最初批出州属土地，设定其土地用途类别，并且对其后大多数
交易——包括转让、租赁、抵押与用途类别变更——必须给予同意。本法令为各项土
地交易提供了统一机制；它并不会将土地在宪法层面的根本所有权从各州手中移走。

## 为何由国会——而非十一个州立法议会——通过这部法令

土地属于联邦宪法 Ninth Schedule（第九附表）中的**州清单**事项——通常只有
州立法议会才能规管。National Land Code 之所以仍能以单一一部联邦法令的形式
存在，是因为**第76(4)条**允许国会仅为达成**法律与政策统一**这一有限目的，
而就州清单事项立法。国会正是行使这项权力制定了本法令，这也是它无须每个州
个别采纳，即可在半岛十一个州属统一生效的原因。

## 本法令刻意不触及的事项

本法令并未将每一套与土地相关的制度都纳入其中。它明文保留了数套并行制度，
包括：

- 马来保留地，以及习俗地与统治者土地
- 矿业地权
- wakaf（伊斯兰宗教捐产）与 baitulmal（伊斯兰教产库）
- 各州特定的垦殖法令，例如 Kelantan Land Settlement Act 1955、Terengganu
  Settlement Enactment、Perlis Land Settlement Enactment，以及 Land (Group
  Settlement Areas) Act 1960

关于以上任何一项的问题，都需要查阅其本身的法令，而非本法令的一般条文。

## 沙巴与砂拉越：完全不同的法令

这正是大多数简短说明因遗漏而弄错的地方。National Land Code **从未适用**于
沙巴或砂拉越。两地各自保留本身更早期的土地法令：

| 地区 | 管辖法令 |
| --- | --- |
| 马来西亚半岛 | National Land Code 1965 (Act 828) |
| 沙巴 | Sabah Land Ordinance (Cap. 68) |
| 砂拉越 | Sarawak Land Code (Cap. 81) |

这三套制度带有家族相似性——皆源自同一套托伦斯传统——但它们是各自独立的
法令，条文各异，土地局各异，判例法也各异。无论是地契查册、原住民习俗权利
问题，还是亚庇或古晋当地的交易程序，都必须依据沙巴或砂拉越本身的法律来解
答，而不能引用 National Land Code。

## 常见错误

**把「马来西亚土地法」当作单一一部法令。** 实际上有三部，彼此并不可互相替
代——为沙巴或砂拉越的事项援引 National Land Code 的条文，纯粹是引错了法
律。

**以为已签署的买卖合约就能移转所有权。** 根据本法令，私人合约只在双方之间
创设合约上的权利；真正移转合法地契的，是经登记的转让。

**把不可推翻性当作绝对。** Section 340 设有法定例外；「地契已经登记」本身
并不能完整回答每一宗关于该地契究竟是如何被登记的争议。
