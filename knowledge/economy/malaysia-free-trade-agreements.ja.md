マレーシアの輸出入の大半は、関税がすでに引き下げ交渉済みの国境を越えて動いている。このネットワークは1990年代初頭以降、一つひとつの協定を積み重ねて構築されてきた——ASEAN自由貿易地域から、現在その中核に位置する二つの超大型協定、RCEPとCPTPPに至るまで。

これほど開放的な経済——貿易額が常にGDPを大きく上回る——にとって、FTAポートフォリオは外交上の脚注などではない。マレーシアの輸出業者のどの貨物が無税で到着し、どれが国境で課税されるかを左右するものである。

## マレーシアには実際何件の自由貿易協定があるのか？

マレーシアは、投資貿易産業省（MITI）が交渉・管理する**8件の二国間自由貿易協定（FTA）**と**9件の地域FTA**の当事国である。これに加えて、全面的にではなく特定の品目リストに対してのみ関税を引き下げる、より範囲の狭い二つの「部分適用」特恵協定がある。

二国間協定は、マレーシアを単一のパートナー国と結び付けるものである：

| 二国間FTA | 発効日 |
|---|---|
| マレーシア–日本 | 2006年7月13日 |
| マレーシア–パキスタン | 2008年1月1日 |
| マレーシア–ニュージーランド | 2010年8月1日 |
| マレーシア–インド | 2011年7月1日 |
| マレーシア–チリ | 2012年2月25日 |
| マレーシア–オーストラリア | 2013年1月1日 |
| マレーシア–トルコ | 2015年8月1日 |
| マレーシア–アラブ首長国連邦 | 2025年10月1日 |

2025年10月1日に発効したマレーシア–UAE包括的経済連携協定（CEPA）は、マレーシアにとって湾岸協力会議（GCC）加盟国との初の貿易協定である。

マレーシアは、複数の同一のパートナー国について二国間協定と地域協定の*両方*を有している点に注意が必要だ——日本、インド、オーストラリア、ニュージーランドはそれぞれ二度登場する。出荷ごとに、輸出業者は通常、より有利な関税、あるいはより簡便な原産地規則をもたらす方の協定を選択できる。

## 地域協定はどのような基盤の上に成り立っているのか？

地域FTAはすべてASEANを基盤としている。その土台となるのが**ASEAN自由貿易地域（AFTA）**であり、ASEAN物品貿易協定（ATIGA）を通じて運用され、ASEAN域内貿易の圧倒的多数について関税を撤廃してきた。ここを出発点として、ASEANはブロックとして主要パートナーと交渉を行った。

| 地域FTA | 発効日 |
|---|---|
| ASEAN自由貿易地域（AFTA） | 1993年 |
| ASEAN–中国（ACFTA） | 2003年7月1日 |
| ASEAN–韓国（AKFTA） | 2006年7月1日 |
| ASEAN–日本（AJCEP） | 2009年2月1日 |
| ASEAN–オーストラリア–ニュージーランド（AANZFTA） | 2010年1月1日 |
| ASEAN–インド（AIFTA） | 2010年1月1日 |
| ASEAN–中国香港（AHKFTA） | 2019年10月13日 |
| [RCEP（地域的な包括的経済連携協定）](/international/malaysia-rcep) | 2022年3月18日 |
| CPTPP（環太平洋パートナーシップに関する包括的及び先進的な協定） | 2022年11月29日 |

この中で最も新しい二つの協定が、最も重要な意味を持つ。

## RCEP：世界最大の貿易圏

RCEPは、ASEAN加盟10か国に中国、日本、韓国、オーストラリア、ニュージーランドを加えた枠組みである。マレーシアが批准手続きを完了した後、RCEPは**2022年3月18日**にマレーシアについて発効した。

RCEPの特徴は、深さよりも規模にある：対象となる経済圏は、合計で世界の貿易と人口のきわめて大きな割合を占める。関税については、発効後の数年にわたり段階的に、加盟国間で取引される商品の約**92%**について関税を撤廃する。

より戦略的に重要な特徴は、全15加盟国に共通する**単一の原産地規則**である。製造業者はパートナーごとに異なる原産地算定方式を追跡する必要がなく、RCEP域内のどこからでも部品を調達し、それを現地調達比率の閾値に算入できる——複数のASEAN・東アジア諸国にまたがる地域のサプライチェーンにとって、実質的な利点となる。

## CPTPP：より踏み込んだルール、新たな市場

CPTPPは、より高水準の協定である。加盟国はオーストラリア、ブルネイ、カナダ、チリ、日本、マレーシア、メキシコ、ニュージーランド、ペルー、シンガポール、ベトナムである。マレーシアは2022年9月30日に批准書を提出し、同協定は**2022年11月29日**にマレーシアについて発効した——これにより、マレーシアは同協定を実施した**9番目**の加盟国となった。（実施時点で、ブルネイとチリはまだ批准していなかった。）

CPTPPの商業的な魅力は二つある。第一に、加盟国間で取引される商品の大部分について関税を撤廃し、協定が完全に実施されれば**関税品目の99%**が無税となる。第二に、マレーシアがそれまでFTAを結んでいなかった市場——特に**カナダ、メキシコ、ペルー**——への特恵的なアクセスを開き、輸出業者にこれまで得られなかった米州における関税上の優位性をもたらした。

関税にとどまらず、CPTPPはそれ以前のFTAが手をつけていなかった分野にも踏み込んでいる：政府調達、国有企業、労働・環境に関するコミットメント、電子商取引、知的財産権である。この深さゆえに批准に時間がかかり、また関税の枠をはるかに超えた義務を伴うのである。

## RCEPとCPTPPの比較一覧

| | RCEP | CPTPP |
|---|---|---|
| マレーシアでの発効 | 2022年3月18日 | 2022年11月29日 |
| 加盟国数 | 15か国（ASEAN + パートナー5か国） | 11か国（環太平洋） |
| 関税カバー率 | 時間の経過とともに商品の約92% | 完全実施後に関税品目の99% |
| 特筆すべき特徴 | 単一の地域原産地規則 | カナダ・メキシコ・ペルーへのアクセス |
| 深さ | 広範囲、関税重視 | 深い——調達、国有企業、労働、知的財産 |

## FTAネットワークは貿易にとって何を意味するのか？

実際的な尺度となるのは、マレーシアの商取引のうちどれだけが現在、特恵的な経路を通じて行われているかである。**2024年**、FTAパートナーとの貿易額は輸出入合計で約**RM1.77兆**に上り、約**RM2,210億**の貿易黒字を生み出した。したがって、FTAネットワークはマレーシアの対外貿易の大部分をカバーしている。

新興市場を狙う輸出業者にとっての全体像を補完するのが、二つの部分適用協定である：**イスラム協力機構（OIC）加盟国間貿易特恵制度（TPS-OIC）**と**D-8特恵関税協定**であり、いずれも2023年10月1日にマレーシアについて発効し、加盟する発展途上経済間で特定の品目リストについて関税を引き下げている。

## まだ協議中の協定は何か？

マレーシアの交渉担当者たちの手は止まっていない。最も進展しているのは、二つの欧州関連の交渉トラックである：

- **マレーシア–EU FTA。** 交渉は当初2010年に開始されたが、2012年に中断され、**2025年1月に再開された**。第1回交渉ラウンドは2025年6月下旬に開催された。EUは、物品貿易・サービス貿易、投資、政府調達、デジタル貿易、持続可能性に関するコミットメントを網羅する野心的な協定を追求している。
- **マレーシア–EFTA経済連携協定。** マレーシアは、EFTA加盟国——アイスランド、リヒテンシュタイン、ノルウェー、スイス——との交渉を**2025年4月11日**に妥結し、同協定は2025年6月23日にノルウェーのトロムソで署名された。批准手続きは未了である。

マレーシアの交渉パイプラインには他の二国間トラックも登場しており、イランとの特恵協定が報じられているものも含まれる。

## 今後の展望

輸出入に携わっている場合、実務上の第一歩は、自社の製品と仕向地に適用される具体的な関税表と原産地規則の要件を、MITIの公式FTAポータル（`fta.miti.gov.my`）で確認することである——段階的実施の日程や現地調達比率の閾値は、協定ごと、関税品目ごとに異なる。ASEANや東アジア向けの製造品の多くについては、RCEPの単一原産地規則制度を、より古いASEANプラス系協定と比較検討し、どちらがより良い結果をもたらすかを見極める価値がある。

EUとEFTAの動向に注目してほしい。EUとの協定が妥結すれば、マレーシアにとって同ブロックとの初の包括的協定となり、パーム油、電子製品、サービスのいずれについてもアクセスのあり方を一変させるだろう。その基盤となる地域的な枠組みについては、マレーシアのASEAN加盟に関する関連記事を参照されたい。
