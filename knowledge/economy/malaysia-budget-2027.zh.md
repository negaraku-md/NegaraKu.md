2026年10月9日，首相兼财政部长安华（Anwar Ibrahim）提呈了
**2027财政预算案**——一项总额创纪录、达**RM459.8 billion**的开支计划，政府
将其环绕三大主题：纾解生活成本、减税，以及
调高薪金。

本页是一份平实、不偏不倚的概览，说明所宣布的内容，以及同样
重要的是——**每项措施实际何时生效**。贯穿全文须谨记一点：预算演词是一则*宣布*，
而非一道法律。以下措施
须待《财政法案》、《2027年供应（财政预算）法令》及任何
相关实施命令获国会通过并刊宪后，方具约束力。关于该程序
如何运作，参见[联邦财政预算周期](/economy/federal-budget)。

## 如果你是个人

- **所得税下调。** 居民个人所得税税率下调
  **一个百分点**。一般个人回扣——自2010年以来从未调整——
  从**RM9,000提高至RM12,000**。收入超过**RM1 million**者按
  **30%**征税。据报，回扣与税率一并调整后，可让数
  百万名纳税人的实得收入增加。请参见
  [个人所得税税率](/taxation/personal-tax-rates)以查看现行
  税阶（将在新税表刊宪后更新）。
- **18岁起纳入公积金（EPF）。** 每名公民在**年满18岁时将自动
  注册为公积金会员**，以扩大退休保障的覆盖面。
- **现金援助。** **STR**提高至约**RM16 billion**，另加**SARA**：
  为900万名领取者提供每月最高**RM150**（每年RM1,800），另加一笔
  每年两次（分别在开斋节前及国庆日前后）的**RM100**援助，
  惠及1,300万名18岁及以上的马来西亚人。

## 如果你是打工族

- **最低薪金 → RM2,000。** 全国最低薪金自**2027年6月起从RM1,700
  调高至RM2,000**一个月。**年销售额低于RM50 million的微型中小企业
  初期获豁免**，让它们有时间调整。
- **RM2,500的下限**适用于**半技术工人与毕业生**，以更好地让薪酬
  与资历相匹配。
- **政联公司的生活薪金。** 政联公司及投资公司将其
  生活薪金基准从**RM3,100提高至RM3,400**。
- **零工工作者。** 政府将为零工工作者提供**每年最高RM600的
  公积金配对缴款**（终身最高RM6,000）。
- **外籍配偶。** 持家属准证的第一类别就业准证（Category I Employment Pass）持有者的
  配偶，将**获准自2027年1月1日起工作**，惟须符合
  相关条件。

## 如果你经营企业或中小企业

- **中小企业所得税下调。** 中小型企业的所得税税率获得**一个百分点
  的下调**（据报新税率为**14%与16%**），
  惠及约300,000家企业。
- **资本免税额。** **小额资产**的合格价值提高
  至每项资产**RM3,000**，而非微型中小企业公司的整体申报上限
  则提高至**RM30,000**。参见[资本免税额](/taxation/capital-allowances)。
- **机械销售税。** 制造商将能够为向本地贸易商或分销商购买的
  机械、零配件及设备**申索退还销售税**。
- **乐龄护理服务税**自**2027年1月1日起**从**8%下调至6%**，
  每年最高**RM96,000**的护理费获完全豁免——参见
  [2018年服务税法令](/taxation/service-tax-act-2018)。
- **印花税。** 开设储蓄或往来账户自**2027年1月1日起完全
  豁免印花税**——参见[印花税税率](/taxation/stamp-duty-rates)。
- **半导体。** 国库控股（Khazanah Nasional）与InvestPenang将设立一项
  **RM100 million基金**，供半导体与先进制造业公司使用。

## 每项措施何时生效

| 措施 | 生效时间 |
| --- | --- |
| 乐龄护理服务税 8% → 6% | 2027年1月1日 |
| 开设银行账户豁免印花税 | 2027年1月1日 |
| 外籍配偶工作权（家属准证） | 2027年1月1日 |
| 最低薪金 RM1,700 → RM2,000 | 2027年6月 |
| 个人与中小企业所得税变动 | 2027课税年（待《财政法令》落实） |

## 已宣布与已生效

此处的一切均**以2026年10月9日宣布为准**。目前尚无一项成为法律。
税务变动须通过**《财政法案》**（及相关课税年）生效；
开支由**《2027年供应（财政预算）法令》**授权；而
具体的回扣或税率变动则通过**刊宪命令
（P.U.(A)）**实施。从演词到最终法律之间，日期与数字可能有所变动——
因此，对于任何你用以规划或合规的事项，请查核
belanjawan.mof.gov.my上的**官方2027财政预算案文件**
（[belanjawan.mof.gov.my](https://belanjawan.mof.gov.my/en)）以及宪报。

## 常被混淆之处

**「2027财政预算案改革了SST／更改了电子发票。」** 本次预算案并无此事。
广泛的SST改革与新的电子发票措施是**分析员在预算前的
预测**，而非演词中的宣布。在政府另有说明之前，请将其
视为预期。

**「预算案在提呈当天即获批准。」** 并非如此——它须经过
数周的国会辩论与委员会阶段，方能成为法律。参见
[联邦财政预算周期](/economy/federal-budget)。
