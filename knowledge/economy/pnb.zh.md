## 一览

| | |
| --- | --- |
| 名称 | Permodalan Nasional Berhad（PNB） |
| 成立 | 1978年3月17日，作为马来西亚新经济政策（New Economic Policy）的一部分 |
| 宗旨 | 增进土著（Bumiputera）社群与全体马来西亚人民的经济财富 |
| AUM | RM364亿（截至2025年底，按年增长4.5%） |
| 单位信托管理公司 | Amanah Saham Nasional Berhad（ASNB），全资子公司，成立于1979年5月22日 |
| ASNB管理的基金 | 18个单位信托基金，流通单位约2,800亿个，分布于超过1,500万个账户，由约1,300万名独立账户持有人持有 |
| 旗舰基金 | Amanah Saham Bumiputera（ASB），固定价格基金，于1990年1月2日推出 |
| 本文涵盖的浮动价格基金 | Amanah Saham Nasional（ASN），于1981年4月20日推出 |
| ASB与ASN的受托人 | AmanahRaya Trustees Berhad |
| 注册编号 | PNB：197801001190（38218-X）；ASNB：197901003200（47457-V） |
| 网站 | `pnb.com.my` ／ `asnb.com.my` |

每年12月，一个单一数字——比如5.75仙——都会成为新闻里的「ASB股息」。这个标题没说的是，ASB的单位价格本身从未变动过。这正是固定价格基金的核心所在，也是PNB旗舰产品与一般单位信托的区别所在。

## PNB负责管理，ASNB负责销售

PNB不会为你开户，也不会收取你的RM10。那是ASNB的工作。

PNB是投资经理：它决定每个基金的资金投向哪里——Bursa Malaysia上市股票、非上市持股、固定收益、货币市场工具——它也是全资拥有ASNB的控股公司。ASNB则是单位信托管理公司：它是每份招股书与 Product Highlights Sheet 上列明的「经理（Manager）」，负责发行单位、处理回购，并在全国经营32间分行及超过2,700个代理点（Maybank、CIMB、RHB、BSN、Pos Malaysia等），马来西亚人实际上就是在这些地方办理交易的。

这种分工在实务上很重要：投诉、账户查询与交易事项都应找ASNB，而非PNB。PNB本身的角色在更上游——投资策略与资金配置——主要体现在ASNB每年代表PNB宣布的收益分配上。

## 两种定价模式，同一位管理者

ASNB的18个基金分成运作方式根本不同的两类：六个是固定价格基金，另外十二个是浮动价格基金。

| | 固定价格基金 | 浮动价格基金 |
| --- | --- | --- |
| 例子 | ASB、Amanah Saham Malaysia（ASM） | ASN、ASN Equity、ASN Imbang、ASN Sara |
| 单位价格 | 永久为RM1.00 | 随净资产值（NAV）变动 |
| 获利方式 | 每年的收益分配，以每单位仙数计 | 资本回报（NAV变动）加上任何收益分配 |
| 定价频率 | 不适用——价格不会变动 | 按远期定价的每单位NAV，于Bursa Malaysia收市后估值 |
| 销售费 | 无（ASB） | ASN最高可达每单位NAV的5%（可由经理酌情调低） |

这项区别并非表面文章。固定价格基金RM1.00的估值是由该基金的信托契约（deed）设定的，而非按日按市值计价——ASNB自身的披露文件明确指出，这「并非受 Guidelines 规管的保本或资本保障基金」。该基金在表现不佳的年份仍可能亏损；只是这会反映为较低（或零）的分配，而非单位价格下跌。相较之下，像ASN这样的浮动价格基金，其定价方式与传统股票单位信托完全相同——其每单位NAV可能跌破投资者当初支付的价格。

## ASB：资格、限额与头条数字背后的细节

ASB仅限土著申请，但符合资格的类别比单纯的「土著」更广。根据ASNB公布的 Akaun Dewasa（成人户口）资格：

- 年满18岁的马来西亚土著个人；或
- 年满18岁、属暹罗／泰裔、葡萄牙／欧亚裔或非土著穆斯林皈依者的马来西亚公民。

来自上述任一符合资格类别的监护人，也可为马来西亚未成年人（须持有效出生证明，未满18岁）开立**Akaun Remaja（青少年户口）**。Remaja户口的持有人须年满12岁才可申请赎回，即使如此，每周也设有200单位的上限；一旦该未成年人达到成年年龄，账户会自动转为 Akaun Dewasa。

ASNB公布的交易条款：

| | ASB |
| --- | --- |
| 最低首次投资额 | RM10 |
| 最低追加投资额 | RM1 |
| 最高投资额 | 每个 Akaun Dewasa 30万单位；每个 Akaun Remaja 30万单位 |
| 销售费 | 无 |
| 回购费 | 无 |
| 公积金局（EPF）会员投资计划 | 不适用——ASB不能使用EPF提取资金购买 |
| 常年管理费 | 基金价值的0.35%（信托契约允许最高至1.0%） |

这30万单位的上限并非最初的设计：ASB与ASB 2的限额自2023年起从RM200,000提高至RM300,000，由PNB在2023年财政预算案发布时一并宣布。再投资的分配，或从已故单位持有人处继承的单位，都可能使持有人的余额超过该上限，而不算违规。

截至2025年12月31日的财政年度，ASNB宣布ASB的总收益分配为每单位5.75仙——派发总额RM10.4亿，惠及1,140万名单位持有人，是ASB自1990年成立以来支付的最高年度分配数额，使累计分配达到RM206.7亿。2023年至2025年的分配分别为5.25仙、5.75仙与5.75仙——也就是在RM1.00的单位上分别为5.25%、5.75%与5.75%——每一年都高于用作比较基准的Maybank 12个月定期存款（同期分别为2.84%、2.59%与2.29%）。

## ASN：同一位管理者，不同的结构

ASN于1981年4月20日推出，比ASB早了大约九年。其资格比ASB更窄：年满18岁的马来西亚土著个人，或监护人代符合资格的土著未成年人申请——并不涵盖ASB所涵盖的暹罗／泰裔、葡萄牙／欧亚裔或皈依者类别。

从结构上看，ASN是按NAV定价的增长型股票基金，而非固定价格基金：

| | ASN |
| --- | --- |
| 最低首次投资额 | RM10 |
| 最低追加投资额 | RM1 |
| 最高投资额 | 无限制 |
| 销售费 | 最高可达每单位NAV的5%；可由经理酌情调低（网上投资为2.0%） |
| 回购费 | 无 |
| 冷静期 | 首次投资于ASNB任何浮动价格基金的投资者享有6个营业日 |
| 基准 | 80% FBM 100指数（FTSE Bursa Malaysia Top 100）、20% Maybank 12个月定期存款 |

2025财政年度，ASN的净分配为每单位1.81仙，常年总回报为-0.14%，相较基准回报-0.47%——这提醒我们，与ASB不同，ASN的总回报可能、也确实会转为负值，因为其单位价格并非固定。

## 常见错误

- **把ASB当作储蓄账户。** 它是经大马证券监督委员会核准的单位信托基金，而非银行存款——它并非保本或资本保障基金，分配率也不获保证。
- **假设ASB与ASN的资格相同。** ASB的 Akaun Dewasa 涵盖特定的非土著类别（暹罗／泰裔、葡萄牙／欧亚裔、穆斯林皈依者）；ASN则不涵盖。
- **把「固定价格」与「固定回报」混为一谈。** RM1.00的单位价格是固定的；常年分配率并不固定，取决于该基金每年已实现的收益。
- **忽略投资上限。** ASB的30万单位限额按账户类型分别计算（Akaun Dewasa 与 Akaun Remaja 分开计算），再投资的分配可能使余额超过名义上限，而不算违规。
