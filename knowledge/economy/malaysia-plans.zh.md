2025年7月31日，首相在下议院（Dewan Rakyat）提呈了一项要求至少RM611 billion
投资的发展动议。这不是财政预算案——当年度的财政预算案早在数个月前就已提呈。
这是一项完全不同的动议：第十三大马计划，一项为国家设定发展方向的计划——不
是为期一年，而是为未来五年，即2026年至2030年。

大多数国民只在每年十月才注意到财政预算案。但财政预算案本身，是根据一个更
大的框架编制而成——而那个框架，就是大马计划。

## 简答：三层规划

马来西亚在三个不同的时间层级上规划其发展，各有本身的功能：

| 层级 | 期限 | 例子 | 功能 |
| --- | --- | --- | --- |
| 长期 | 10-30年 | 2020年宏愿（1991-2020）、国家宏愿政策（2001-2010） | 设定国家的宏大抱负与目标 |
| 中期 | 5年 | **大马计划**（RMK13，2026-2030） | 设定施政重点、优先事项、策略与成效目标 |
| 短期 | 1年 | [联邦财政预算案](/zh/economy/federal-budget) | 为特定年度拨出实际令吉款项 |

大马计划是中间层级。它把长期愿景转化为可执行的策略，而年度财政预算案则再
把该策略转化为每年的实际拨款。

## 大马计划究竟是什么

大马计划不是一年的开支数字，也不是法律。它是由经济部编制的政策文件，为期
五年，设定发展重点、政策优先事项、策略与成效目标——然后作为**动议**提呈国
会辩论与批准，而不是像《拨款法案》那样以法案形式提出。

这项传统，以其现今的形式，早于完全独立之前便已展开。第一个马来亚计划
（1956-1960）与第二个马来亚计划（1961-1965），先于第一个大马计划（RMK1，
1966-1970）——使RMK13成为自1956年以来第15个五年发展计划，也是自1966年
「大马计划」这一名称启用以来第13个。

| 计划 | 期限 |
| --- | --- |
| RMK1 | 1966-1970 |
| RMK2 | 1971-1975 |
| RMK3 | 1976-1980 |
| RMK4 | 1981-1985 |
| RMK5 | 1986-1990 |
| RMK6 | 1991-1995 |
| RMK7 | 1996-2000 |
| RMK8-RMK10 | 2001-2015 |
| RMK11 | 2016-2020 |
| RMK12 | 2021-2025 |
| **RMK13** | **2026-2030** |

负责编制它的机构，形态也几经变化。1956年4月24日设立的经济秘书处，于1961
年在首相署之下重组为经济策划单位（EPU），而EPU在第15届全国大选后，于
2022年12月23日最后一次解散，其职能与职责由经济部接管。如今正是这个部门在
协调大马计划的编制工作，透过由上而下（由经济部、财政部与国家银行等中央机
构制定的宏观经济框架）与由下而上（透过机构间规划小组（IAPG）会议与技术工
作小组（TWG）会议进行的参与协商）两种方式进行。

## 它与年度财政预算案的关系

这是最常被误解的关系：大马计划**设定**，财政预算案**落实**。

RMK13设定了五年的成效目标——GDP增长、人均国民总收入、贫穷率——以及政府在
2026-2030年期间RM430 billion的发展投资需求。它并不设定某个部门在2027年具
体可花多少令吉。

年度数字，只有在财政部长每年提呈[联邦财政预算案](/zh/economy/federal-budget)
时才会出现，其中包括决定RMK13当年度分配额的发展开支预算。实际拨款逐年而
异，取决于项目优先次序与当时的财政状况——五年总额并非按年平均分配。

批准程序上的差异，也反映了这两者功能上的差异。大马计划以政策动议的形式获
批准；财政预算案则必须经过《拨款法案》，须在国会走完完整的立法程序，才能
宪报颁布为《拨款法令》——这一循环在
[联邦财政预算案周期](/zh/economy/federal-budget)一文中有完整说明。

## 中期检讨：半途的一次检视

五年是很长的一段时间，不宜守着同一套目标而不加检视。这正是为何一份大马计
划通常会在其期限中段，透过**中期检讨（Kajian Separuh Penggal，简称
KSP）**重新审视——同样以另一项独立动议提呈国会。

以第十二大马计划中期检讨（KSP RMKe-12）为例，首相于2023年9月11日提呈——在
Ekonomi MADANI框架下引进新政策与新策略，而无须等待RMK13。同样的机制也曾用
于RMK2、RMK7、RMK8、RMK9与RMK11。它让政府得以在半途调整策略——而无须重新
拟定整份五年计划。

## RMK13（2026-2030）：有何改变

RMK13以**「重塑发展」**为主题，透过三个维度设定国家社会经济目标：高收入且
可持续、优质且具包容性的生活，以及可持续的环境。

其框架由**4大支柱**与**27项优先事项**构成，并由逾120项策略与逾600项计划支
撑：

| 支柱 | 重点 |
| --- | --- |
| A. 提升经济复杂性 | 高价值产业、绿色／蓝色经济、粮食保障、生产力 |
| B. 提升社会流动性 | 教育改革、劳动市场、区域平衡 |
| C. 加速推动公共服务改革议程 | 服务传递（ILTIZAM）、GovTech、施政治理、财政 |
| D. 提升民生福祉与环境可持续性 | 医疗、房屋、安全、地球健康、灾害管理 |

在投资方面，政府为RMK13议决至少**RM611 billion**的投资——预计RM430
billion来自政府发展拨款，RM120 billion来自政府关联公司（GLC）与政府关联
投资公司（GLIC）在策略领域的国内直接投资，另RM61 billion透过公私伙伴关系
（PPP）方式筹措。

截至2030年的主要成效目标包括：GDP年均增长4.5%-5.5%，人均国民总收入
（GNI）提高至RM77,200，财政赤字低于GDP的3%，绝对贫穷率4.7%，以及雇员薪酬
占GDP比重提高至40%。

其批准程序同样遵循两院制国会的一般路径：动议于2025年7月31日在下议院提
呈，随后于2025年8月25日在上议院提呈。两院皆在计划期限于2026年展开之前通
过该项动议。

## 常见错误

**「大马计划就是五年期的财政预算案。」** 不对。RMK设定重点与目标；它并不
按部门、按年度分配具体令吉款项——那是年度财政预算案的工作。

**「RMK13的RM611 billion全都是政府的钱。」** 不对。政府发展拨款仅RM430
billion；其余来自GLC／GLIC直接投资（RM120 billion）与公私伙伴关系方式
（RM61 billion）。

**「大马计划的批准方式与《拨款法案》相同。」** 不对。它是以政策动议的形式
提呈与批准，而非须走完整立法程序的财务法案。

**「RMK中的目标，在下一份计划出炉前不能调整。」** 不对。期限中段的中期检
讨，让政策与策略得以调整，而无须等待整整五年。
