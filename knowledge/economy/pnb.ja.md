## 概要

| | |
| --- | --- |
| 名称 | Permodalan Nasional Berhad（PNB） |
| 設立 | 1978年3月17日、マレーシアの新経済政策（New Economic Policy）の一環として |
| 前身 | Yayasan Pelaburan Bumiputra（YPB）、1978年1月9日設立 |
| 使命 | ブミプトラ社会および全マレーシア国民の経済的豊かさを高めること |
| AUM | RM3,640億（2025年末時点、前年比4.5%増） |

| ASNBが運用するファンド | ユニット・トラストファンド18本、流通ユニット数は約2,800億、口座数1,500万超、実質の口座保有者数は約1,300万人 |
| 旗艦ファンド | Amanah Saham Bumiputera（ASB）、1990年1月2日開始の固定価格ファンド |

| ASBとASNの受託者 | AmanahRaya Trustees Berhad |
| 登録番号 | PNB：197801001190（38218-X）；ASNB：197901003200（47457-V） |
| ウェブサイト | `pnb.com.my` ／ `asnb.com.my` |

毎年12月になると、5.75センといった単一の数字が「ASB配当」としてニュースになる。その見出しが省いているのは、ASBのユニット価格そのものは一度も動いていないという事実だ。それこそが固定価格ファンドの核心であり、PNBの旗艦商品を一般的なユニット・トラストと分ける点である。

## PNBが運用し、ASNBが販売する

PNBはあなたの口座を開設したり、あなたのRM10を受け取ったりはしない。それはASNBの仕事である。

PNBは投資マネージャーである：各ファンドの資金をどこに投資するか——Bursa Malaysia上場株式、非上場保有株式、債券、マネーマーケット商品——を決定し、またASNBを完全に所有する持株会社でもある。ASNBはユニット・トラスト運用会社である：あらゆる目論見書とProduct Highlights Sheetに「Manager」として記載される主体であり、ユニットを発行し、買戻しを処理し、マレーシア人が実際に取引を行う全国32の支店と2,700を超える代理店（Maybank、CIMB、RHB、BSN、Pos Malaysiaなど）を運営している。

この分業には実務上重要な理由が一つある：苦情、口座に関する問い合わせ、取引はPNBではなくASNBに向けられる。PNB自身の役割はより上流にある——投資戦略と資金配分——であり、主にASNBがPNBに代わって宣言する年次収益分配を通じて可視化される。

この構造は新経済政策にルーツを持つ：PNBに先立ち、ブミプトラ社会の間で株式保有を育成するために1978年1月9日にYayasan Pelaburan Bumiputra（YPB）が設立されていた。基本的な仕組みはそれ以来変わっていない——PNBはマレーシアの大企業の株式を取得し、それを信託ファンドの中に保有し、マレーシア人がより小口で手頃なユニットとしてその保有分に投資できるようにする。

## 二つの価格モデル、一つの運用会社

ASNBの18ファンドは、根本的に異なる動きをする二つのグループに分かれる：6本が固定価格ファンドであり、残る12本が変動価格ファンドである。

| | 固定価格ファンド | 変動価格ファンド |
| --- | --- | --- |
| 例 | ASB、Amanah Saham Malaysia（ASM） | ASN、ASN Equity、ASN Imbang、ASN Sara |
| ユニット価格 | 永久にRM1.00 | 純資産価値（NAV）に応じて変動 |
| 収益の得方 | 年次収益分配（1ユニットあたりセン） | 資本リターン（NAVの変動）に加え、収益分配があればそれも |
| 値付けの頻度 | 該当なし——価格は変動しない | フォワード・プライシングによる1ユニットあたりNAV、Bursa Malaysiaの取引終了後に評価 |
| 販売手数料 | なし（ASBの場合） | ASNは1ユニットあたりNAVの最大5%（Managerの裁量により引き下げられる場合がある） |

この違いは表面的なものではない。固定価格ファンドのRM1.00という評価額は、日々の時価評価によってではなく、ファンドの信託証書（deed）によって定められている——ASNB自身の開示は、これが「Guidelinesのもとでの資本保証または資本保護ファンドではない」ことを明言している。ファンドは業績の悪い年には依然として損失を出しうるが、それはユニット価格の下落としてではなく、より低い（あるいはゼロの）分配として現れるだけである。これに対しASNのような変動価格ファンドは、従来の株式型ユニット・トラストとまったく同様に価格が決まる——その1ユニットあたりNAVは、投資家が支払った金額を下回ることがある。

## ASB：資格、限度額、そして見出しの数字の裏側

ASBはブミプトラに限定されているが、対象となる区分は単なる「ブミプトラ」よりも広い。ASNBが公表するAkaun Dewasa（成人口座）の資格によれば：

- 18歳以上のマレーシア人ブミプトラ個人；または
- 18歳以上で、シャム系／タイ系、ポルトガル系／ユーラシア系、または非ブミプトラのムスリム改宗者であるマレーシア国民。

誰が投資できるかについての権威ある情報源は、Product Highlights SheetではなくASNBのMaster Prospectusであり、そこではブミプトラの中核区分をマレー人、サバ州およびサラワク州の先住民、ならびにオラン・アスリと位置づけている。

いずれかの資格区分に該当する保護者は、マレーシアの未成年者（有効な出生証明書を有し、18歳未満）のために**Akaun Remaja（未成年口座）**を開設することもできる。Remaja口座は12歳になるまで買戻しを請求できず、それ以降も週200ユニットの上限が設けられている；未成年者が成年年齢に達すると、口座は自動的にAkaun Dewasaに転換される。

ASNBが公表する取引条件：

| | ASB |
| --- | --- |
| 最低初回投資額 | RM10 |
| 最低追加投資額 | RM1 |
| 最高投資額 | Akaun Dewasaにつき300,000ユニット；Akaun Remajaにつき300,000ユニット |
| 販売手数料 | なし |
| 買戻し手数料 | なし |
| EPF会員投資制度（EPF Members Investment Scheme） | 該当なし——ASBはEPFの引き出し資金を使って購入することはできない |
| 年間管理報酬 | ファンド価値の年率0.35%（信託証書上は最大1.0%まで認められる） |
| ファンド区分 | 混合資産（ファンドタイプ：インカム型） |
| 資産配分 | 株式に最大90%、その他の資産クラスに最大50%、現金または流動性資産に最低5% |
| ベンチマーク | Maybank 12カ月定期預金金利 |

2026年5月25日以降、ASBは二つのユニットクラスで提供されている：ザカート控除のないクラスAと、ムスリム投資家向けにザカート支払い機能を組み込んだクラスBである。両クラスとも同一の固定価格ファンドであり——同じRM1.00ユニット、同じ特徴——ザカートの扱いのみが異なる。

300,000ユニットという上限は当初からの設計ではない：ASBとASB 2の限度額は2023年からRM200,000からRM300,000に引き上げられ、PNBによって2023年予算（Budget 2023）とあわせて発表された。再投資された分配金や、死亡したユニット保有者から相続したユニットは、違反とみなされることなく保有者の残高を上限より上に押し上げることがある。

2025年12月31日に終了する会計年度について、ASNBはASBの収益分配総額として1ユニットあたり5.75センを宣言した——1,140万人のユニット保有者に恩恵をもたらすRM104億の支払いであり、ASBが1990年に発足して以来最高額の年次分配であり、累計分配額をRM2,067億に押し上げた。2023年から2025年の分配は1ユニットあたり5.25セン、5.75セン、5.75セン——すなわちRM1.00のユニットに対して5.25%、5.75%、5.75%——であり、いずれも比較対象として用いられるMaybank12カ月定期預金ベンチマーク（同期間でそれぞれ2.84%、2.59%、2.29%）を上回った。

この分配金は、ファンドの会計年度を通じて口座に保有された平均最低月次残高に基づいて計算される——そのため、年間を通じて保有されたユニットは、遅く預け入れられたユニットよりも多くの割合を占める——そして分配率は保証されておらず、ファンドの実現利益と市場状況に応じて変動する。FY2025の支払いは、国内株式市場が軟調な中で宣言されたものであり、FBM KLCIは同期間の年初来価格リターンとして約-0.3%を記録した。

## ASN：同じ運用会社、異なる構造

ASNは1981年4月20日に開始された。これはASBよりおよそ9年早い。その資格はASBよりも狭い：18歳以上のマレーシア人ブミプトラ個人、または資格のあるブミプトラの未成年者のために申請する保護者であり——ASBが対象とするシャム系／タイ系、ポルトガル系／ユーラシア系、または改宗者の区分には及ばない。

構造的には、ASNは固定価格ファンドではなく、NAVで価格が決まる成長志向の株式ファンドである：

| | ASN |
| --- | --- |
| 最低初回投資額 | RM10 |
| 最低追加投資額 | RM1 |
| 最高投資額 | 無制限 |
| 販売手数料 | 1ユニットあたりNAVの最大5%；Managerの裁量により引き下げられる場合がある（オンラインの場合2.0%） |
| 買戻し手数料 | なし |
| 冷静期 | ASNBのいずれかの変動価格ファンドへの初回投資者について6営業日 |
| ベンチマーク | FBM 100指数（FTSE Bursa Malaysia Top 100）80%、Maybank 12カ月定期預金20% |

FY2025において、ASNの純分配は1ユニットあたり1.81センであり、年間トータルリターンは-0.14%（ベンチマークのリターン-0.47%に対して）であった——これは、ASBとは異なり、ASNのトータルリターンはそのユニット価格が固定されていないために、マイナスになりうるし、実際になるという事実を思い起こさせる。

## LEAP-6：PNBが目指す方向

毎年のASBの見出しの背後には、PNBの現行の企業戦略であるLEAP-6戦略計画がある；2025年はその実施2年目にあたる。その優先事項として掲げられているのは、顧客の純流入を拡大すること、ユニット保有者に持続可能な収益分配を届けること、そしてPNB自身の資本を強化することである。投資面では、PNBはグローバル資産、プライベート投資、不動産への多様化を進めており、世界の資本市場の不確実性の中で2026年の見通しについて慎重な姿勢を示している。

この計画は、2025年に報告されたRM3,640億から、2027年までに運用資産RM4,000億という主要目標を掲げている。ASNBの全18ファンドを通じて、2025年の収益分配総額はRM153億に達した——そのうちASBのRM104億が単一で最大の構成要素であった。

## よくある誤解

- **ASBを普通預金口座のように扱うこと。** これは証券委員会（Securities Commission Malaysia、SC）の認可を受けたユニット・トラストファンドであり、銀行預金ではない——資本保証または資本保護ファンドではなく、分配率も保証されていない。
- **ASBとASNの資格が同じだと思い込むこと。** ASBのAkaun Dewasaは特定の非ブミプトラ区分（シャム系／タイ系、ポルトガル系／ユーラシア系、ムスリム改宗者）にも及ぶが、ASNは及ばない。
- **「固定価格」と「固定リターン」を混同すること。** RM1.00のユニット価格は固定されているが、年次分配率は固定されておらず、毎年のファンドの実現利益に左右される。
- **投資上限を見落とすこと。** ASBの300,000ユニット限度額は口座タイプごとに適用される（Akaun DewasaとAkaun Remajaは別々に計算される）、そして再投資された分配金は、違反とみなされることなく残高を名目上の上限より上に押し上げることがある。

## 次に読むべきもの

- PNBの株式保有が実際に取引される場所：[Bursa Malaysia](/ja/economy/bursa-malaysia)
- ASBが*その*預金受入れの枠組みの下には置かれていない中央銀行：[マレーシア国立銀行（Bank Negara Malaysia）](/ja/economy/bank-negara-malaysia)
- もう一つの主要なブミプトラ関連貯蓄プールと、なぜASBがその一部ではないのか：[EPF（従業員積立基金）](/ja/glossary/epf)
- 2023年の投資限度額引き上げが発表された場所：[連邦予算（federal budget）](/ja/economy/federal-budget)
- ファンドレベルの詳細情報を自分で確認するには、[ASNBの製品ページ](https://www.asnb.com.my)、またはPNB自身のサイト[pnb.com.my](https://www.pnb.com.my)を参照のこと。
