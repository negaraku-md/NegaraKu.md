もし明日あなたの銀行が閉鎖されたとしても、そこに預けていた最初のRM250,000を失うことはない。その保証には名前がある——PIDMだ。

マレーシア預金保険公社（PIDM）は、マレーシアの銀行預金を支える政府機関であり、2010年末以降は保険およびタカフル給付も支えている。保護は消費者に対して自動的かつ無料で適用され、登録や支払いは不要である。

## PIDMとは何か——概要

PIDMは、2つの消費者保護制度を運営し、加盟金融機関が経営難に陥った際には破綻処理当局として機能する法定政府機関である。銀行の日常的な規制は行わない——それはマレーシア国立銀行（Bank Negara Malaysia、BNM）の役割である——が、監督が機能しなかった場合に消費者を受け止める安全網である。

| 項目 | 詳細 |
| --- | --- |
| 正式名称 | マレーシア預金保険公社（PIDM） |
| 種別 | 政府機関／法定機関 |
| 根拠法 | 2011年マレーシア預金保険公社法（Malaysia Deposit Insurance Corporation Act 2011、Act 720） |
| 運営する制度 | 預金保険制度（DIS）；タカフル・保険給付保護制度（TIPS） |
| 預金保護限度額 | 預金者1人・加盟銀行1行あたりRM250,000 |
| タカフル／保険保護限度額 | 合資格給付ごとにRM500,000；医療給付は全額保護 |
| 消費者の費用 | なし——自動的かつ無料 |
| 資金源 | 加盟銀行および保険会社会員からの年間保険料 |
| 規制機関との関係 | BNMを補完する；PIDMは破綻処理当局である |

## 実際にどれだけのお金が保護されるのか？

預金保険の限度額は**預金者1人・加盟銀行1行あたりRM250,000**であり、この金額には口座の元本ならびに発生した利息または利益の両方が含まれる。銀行にRM250,000以下を預けている場合、全額が保護される。

知っておくべき2つの特徴がある。

- **イスラム預金と通常預金は別個に計算される。** *同一*銀行において、通常口座に最大RM250,000、さらにイスラム預金口座に別途RM250,000を保有することができ、それぞれ独立して保護される。
- **共同口座および適切に記録された信託口座は、それぞれ独自の保護を受ける。** 銀行の記録において各保有者または受益者が明確に特定されている場合、それぞれが個別にRM250,000の限度額を受ける権利を有する。

合資格預金には、普通預金口座および当座預金口座、定期預金、外貨預金、イスラム預金口座に加えて、預金口座を引き当てとした銀行為替手形その他の支払手段が含まれる。

## 保護対象外となるもの

PIDMが保護するのは預金であり、投資ではない。以下は預金保険の対象外である。

- マレーシア国内で支払われない預金
- 銀行間マネーマーケット預け金
- 譲渡性預金証書（NIDs）およびその他の無記名預金
- 買戻し契約（レポ取引）
- ユニットトラスト、株式
- 金関連の投資商品

資金が市場の変動に応じて価値が上下する商品に投じられている場合、預金保険は適用されない——それらは自らが負う投資リスクである。

## 保険とタカフルについてはどうか？

2010年12月31日以降、PIDMは**タカフル・保険給付保護制度（TIPS）**も運営している。保険会社またはタカフル事業者が破綻した場合、生命保険、ファミリー・タカフル、一般保険、および一般タカフルのもとでの給付を保護する。

| 給付の種類 | 保護内容 |
| --- | --- |
| 生命保険／ファミリー・タカフル給付 | 合資格給付ごとに最大RM500,000 |
| 一般保険／一般タカフル給付 | 合資格給付ごとに最大RM500,000 |
| 医療給付 | 全額保護 |

加盟は強制である。2013年金融サービス法（Financial Services Act 2013）のもとで免許を受けたすべての保険会社、および2013年イスラム金融サービス法（Islamic Financial Services Act 2013）のもとで免許を受けたすべてのタカフル事業者は、自動的に保険会員となる。再保険会社、オフショア保険会社、財務保証保険会社、および保険ブローカーは会員ではない。

## PIDMはマレーシア国立銀行とどう違うのか？

人々はしばしば、マレーシア国立銀行が自分たちの貯蓄を保証していると思い込んでいる。しかしそうではない——両機関は異なる役割を担っている。

- **マレーシア国立銀行（Bank Negara Malaysia）** は中央銀行であり、金融機関に免許を付与し、規制・監督を行い、健全性を保つための審慎規則を定める。
- **PIDM** は安全網であり破綻処理当局である。消費者に保険を提供し、早期介入権限を有し、破綻しつつある機関の処理に介入しながら合資格の預金者および保険契約者に補償を行う。

要するに、BNMは銀行の破綻を防ごうとし、PIDMは万一破綻した場合にあなたが保護されることを確実にする。消費者はいずれにも費用を負担しない——加盟銀行および保険会社が保険料を通じてPIDMに資金を提供する。

## 次にすべきこと

- 自分の銀行または保険会社がPIDMの会員であるかを確認する——完全な会員リストはpidm.gov.myに掲載されている。
- 一つの銀行での貯蓄がRM250,000を超える場合、複数の金融機関に分散する、またはイスラム口座と通常口座に分けることで保護がどう変わるかを検討する。
- 市場連動型商品（ユニットトラスト、仕組み商品、株式）を「安全な」現金として扱う前に、それらが預金保険の対象外であることを確認する。
- 正確な法的定義および限度額の変更については、同法およびPIDMの公式ガイドラインを直接参照すること。
