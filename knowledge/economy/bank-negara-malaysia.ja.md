## 概要

| | |
| --- | --- |
| 名称 | マレーシア国立銀行（Bank Negara Malaysia、BNM） / Central Bank of Malaysia |
| 種類 | 法定機関；マレーシアの中央銀行（s.4, Act 701） |
| 業務開始 | 1959年1月26日 |
| 根拠法 | 2009年マレーシア国立銀行法（Central Bank of Malaysia Act 2009、Act 701）、2009年11月25日施行 |
| 前身の法律 | Central Bank of Malaysia Act 1958、s.99により廃止 |
| 資本金 | RM1億（s.6(1)）；増資はすべて政府が引き受け、払い込む（s.6(2)） |
| 本店所在地 | クアラルンプール（s.3(4)） |
| 総裁 | Abdul Rasheed Ghaffour、第10代総裁、2023年7月1日就任（任期5年、s.15(4)） |
| 外部監査人 | 会計検査院長（Auditor General）（s.11） |
| ウェブサイト | `bnm.gov.my` |

同法は新たな機関を創設したものではない。s.3は、廃止された1958年法のもとで
設立された法人団体について「引き続き存続する」("shall continue to be in
existence") と定めている——同一の法人格に、より明確な使命が与えられたもの
である。

## 二つの宗旨と九つの職能

BNMが何を行い得るか、あるいは行い得ないかという問いのほとんどは、最終的に
s.5に帰着する。

**s.5(1)——主要な宗旨：** 通貨の安定、及びマレーシア経済の持続可能な成長に
資する金融安定を促進すること。

**s.5(2)——主要な職能：**

| # | 職能 |
| --- | --- |
| a | マレーシアにおける金融政策の策定及び実施 |
| b | マレーシアにおける通貨の発行 |
| c | 同局が執行する法律の適用を受ける金融機関の規制及び監督 |
| d | 資金市場及び外国為替市場に対する監督の実施 |
| e | 決済システムに対する監督の実施 |
| f | 健全、進歩的かつ包摂的な金融システムの促進 |
| g | マレーシアの外貨準備の保有及び管理 |
| h | 経済のファンダメンタルズと整合的な為替制度の促進 |
| i | 政府の財務アドバイザー、銀行及び財務代理としての役割を果たすこと |

s.5(3)は、これらの職能に「必要、付随的又は補助的」("necessary, incidental
or ancillary") な権限のみを付与しており、s.5(4)は、同局がこれらの権限を
行使するにあたり国益に配慮することを求めている。両者を併せて読めば、これは
許可証であると同時に境界線でもある。

## 誰が何を決めるのか

BNMの意思決定は、総裁一人に集中するのではなく、複数の法定機関に意図的に
分散されている。

| 機関 | 構成 | 決定事項 |
| --- | --- | --- |
| 取締役会（Board of Directors） | 総裁、副総裁最大3名、委任される取締役5〜8名（s.14(3)）；総裁が議長を務める（s.19(1)） | 一般行政、予算、経営陣の監督 |
| 金融政策委員会（Monetary Policy Committee、MPC） | 総裁、副総裁、及び外部委員を含むその他の委員3〜7名（s.23(2)） | 金融政策及び翌日物政策金利（OPR） |
| 金融安定執行委員会（Financial Stability Executive Committee） | 総裁、副総裁1名、及び取締役会の推薦に基づき財務大臣が委任する委員3〜5名（s.37(2)） | s.38に基づき提出される流動性支援、資本注入及び権利移転命令（vesting orders） |
| シャリア諮問理事会（Shariah Advisory Council） | 財務大臣が同局と協議のうえ行う助言に基づき国王（Yang di-Pertuan Agong）が委任する委員（s.53） | イスラム金融業務に関するイスラム法の確定（s.51） |
| 取締役会ガバナンス・監査・リスク各委員会 | s.21が要求する取締役会の下部委員会 | 指名及び予算の提言；監査；リスク監督 |

重要な任命規則が二つある。総裁は国王（Yang di-Pertuan Agong）により任期
5年で任命され、副総裁は財務大臣により任期3年で任命される（s.15(1)、
s.15(4)）。

MPCは年に少なくとも6回会合を開かなければならず（First Schedule（第一附表）
第3項）、s.24は、同局に対し、会合のたびに金融政策声明——決定内容とその
根拠——を公表することを義務付けている。OPRは、2025年7月9日の引き下げ以降
2.75%で据え置かれており、2026年7月9日の会合でも据え置かれた。この一つの
数字がどのようにあなたの融資に影響するかについては、
[翌日物政策金利](/ja/economy/opr-monetary-policy)を参照。

## 国家銀行はどれほど独立しているのか

率直に言えば、運営上は自律的である一方、憲法上は国家が所有し、説明責任を
負う存在である。

自律性の面では、金融政策委員会（MPC）がs.23のもとで金融政策の策定について
**単独の責任**を負っており、s.22(2)は、その政策が外部からの影響を受ける
ことなく策定・実施されることを求めている。金融政策は、正式に招集された
委員会の会合においてのみ策定することができ（s.23(10)）——回覧文書による
政策決定は認められない——これにより、金利設定は短期的な政治的圧力から
隔離されている。

説明責任の面では、BNMは政府が全額を出資する機関であり、公に報告を行い、
その会計は会計検査院長（Auditor General）の監査を受ける。同局はまた、
政府の銀行及び財務代理としての役割も果たす：s.69は、同局を「政府の銀行
及び財務代理」("banker and financial agent to the Government") と定めて
おり、これはs.5(2)の職能(i)に掲げられているのと同じ役割である。ここでいう
独立性とは、安定を*どのように*追求するかを決める自由を意味するのであって、
説明責任からの自由を意味するものではない。

## BNMが実際に規制する対象

BNMの監督権限の及ぶ範囲は、同局が所管する法律によって定められるのであり、
「金融」("financial") という言葉によって定められるのではない。

| 法律 | 適用対象 |
| --- | --- |
| Financial Services Act 2013 | 銀行、保険会社、決済システム運営者及びその他の承認された者 |
| Islamic Financial Services Act 2013 | イスラム銀行、タカフル（takaful）事業者及びイスラム市場参加者 |
| Development Financial Institutions Act 2002 | 指定された開発金融機関 |
| Money Services Business Act 2011 | 両替、送金及び卸売通貨業務 |
| Currency Act 2020 | 通貨管理及び通貨処理業務 |
| AMLA 2001 | BNMは、大臣が任命する所管当局として行動する |
| Central Bank of Malaysia Act 2009 | 同局自体の宗旨、権限及び金融安定のためのツールキット |

免許付与にとどまらず、同法は危機に備える手段を同局に与えている：他の監督
当局及び監督を受けていない主体に対し金融安定に関連する情報を求めること
（s.30）、リスクの蓄積を抑制するための措置を定めること（s.31）、流動性
支援を行うこと（s.32）、並びに金融機関の顧客に関する信用情報を収集する
信用情報機関（credit bureau）を運営すること（s.47）ができる。

## 外国為替政策（FEP）規則

輸入業を営んでいる、海外に投資している、あるいは外貨口座を保有している
という場合、あなたが実際に接する可能性が最も高いBNMの職能はこれだろう。
マレーシアは無制限の国境を越えた資金移動を認めておらず、その代わりに同局
は、Financial Services Act 2013及びIslamic Financial Services Act 2013に
基づき、通貨及び金融の安定を支え、リンギットを保護するための**外国為替
政策（Foreign Exchange Policy、FEP）**規則一式——かつてはForeign Exchange
Administration（FEA）と呼ばれていた——を運用している。

FEPは一連の通達（Notices）から成り、それらが認める内容は、あなたが
**居住者（resident）**であるか**非居住者（non-resident）**であるかに
よって異なる：

- **居住者**は、経常勘定及び金融勘定の取引について、免許を有する国内銀行
  との間でリンギットと外貨を自由に売買することができ、通達に定める限度額
  及び条件に従うことを条件に、外貨口座（Foreign Currency Account）を開設・
  維持することができる——例えば、外貨建て借入れの限度額、及び国内で
  リンギット建て借入れを既に有している居住者が海外投資を行う場合の限度額
  など。
- **非居住者**は、いかなる目的であっても直物（スポット）ベースで外貨と
  リンギットを売買することができ、原資産となる債務がある場合には先物
  ベースでも売買することができ、また国内で外貨口座を保有することができる。
  居住者に適用され得る外貨投資の年間限度額は、非居住者には適用されない。

FEP通達は定期的に改定されるため、黄金律は、国境を越えた取引を組成する前に
`bnm.gov.my/fep` で最新の通達を確認する——あるいは取引銀行の外国為替部門
に問い合わせる——ことである。実際の取引にあたっては、本稿を含めいかなる
要約にも依拠してはならない。

## BNMが管轄しない事項

これは、多くの解説記事が省略している側面である。

- **資本市場。** 株式、債券及びスクーク（sukuk）、ユニットトラスト、ファンド
  マネジメント、企業買収並びに免許を有する仲介機関は、1993年3月1日に設立
  され、Capital Markets and Services Act 2007のもとで免許を付与された
  事業体を規制する証券監督委員会（Securities Commission Malaysia、SC）の
  所管である。クラウドファンディング及びP2Pプラットフォームは、BNMでは
  なくSCへの登録制である——参照：
  [株式型クラウドファンディング及びP2Pファイナンス](/ja/business/equity-crowdfunding-p2p-malaysia)。
- **預金保険。** 適格預金を保護するのはBNMではなくPIDMであり、預金者1人に
  つき会員銀行ごとに最大RM250,000を保護する。これは自動的に適用され、
  無料である。
- **デジタル資産。** 2018年12月6日の共同声明に基づき、SCがICO（初期コイン
  公開）及びデジタル資産取引所を規制し、BNMはデジタル資産がマレーシアに
  おいて法定通貨ではないことを改めて表明した。
- **為替制度。** 同局の勧告に基づき財務大臣が決定する（s.66(1)）。BNMは
  その制度の枠内で外国為替操作を自律的に行う——参照：
  [外国為替政策](/ja/business/foreign-exchange-policy-malaysia)及び
  [リンギット相場を動かすもの](/ja/economy/ringgit)。
- **財政政策及び税務。** 予算、補助金及び税務行政は財務省及び
  [LHDN](/ja/government/lhdn)の所管である。BNMは政府に対して一時的な融資
  のみを供与することができ、s.71(3)により、同局が金融政策操作以外で保有
  する政府証券と合算した場合、連邦の見積受取額の12.5%を上限とする。

s.72が全体像を完結させる。同局は、その主要な宗旨に関連する政策について
財務大臣に常に情報提供しなければならない；両者の見解が一致せず合意に至ら
ない場合、取締役会が声明を提出し、財務大臣はそれを内閣に持ち込み、内閣が
採用すべき政策を決定することができる——その場合、政府がそれについての
責任を負う。一方、s.22(2)は、金融政策は同局が外部からの影響を受けることな
く自律的に策定・実施すると定めている。

## よくある誤解

- **BNMを政府省庁と呼ぶこと。** BNMは独自の資本を有する法定機関であり、
  会計検査院長の監査を受け、その財務諸表及び取締役会報告書は国会両院に
  提出される（s.13）。
- **「金融」に関わるものは何でもBNMが規制していると思い込むこと。** ある
  事業体が上表の法律のもとで免許、承認又は登録を受けていない場合、BNMは
  その規制当局ではない。
- **OPRと自分が実際に支払う金利を混同すること。** MPCが設定するのは政策
  金利であり、貸し手はそこから自らの基準金利を設定する。
- **投資の失敗をBNMが補償してくれると期待すること。** 同局の消費者窓口
  であるBNMLINKが扱うのは、同局が規制する機関に関する事項であり、その
  管轄外のスキームは対象外である。

## リンギット建てビジネスにとってなぜ重要なのか

BNMがあなたに直接融資することは決してないが、その決定は、どんな税務書類
よりも先にあなたのキャッシュフローに影響を及ぼす。リンギット建てで請求書
を発行し、リンギットで借入れを行い、あるいはリンギット預金を保有している
のであれば、同局の金利及び為替に関する判断が、リンギット建てビジネス
すべてのコストを形づくる：

- **OPR**は、あなたの資金調達の基準コスト及び手元資金の運用利回りを定める。
- **外貨準備及び為替制度**は、輸入コスト及び輸出競争力を形づくる。
- **プルーデンス規制**は、あなたがどの銀行及び保険会社と安全に取引できる
  か、そしてそれらが満たすべき基準を定める。

これらのいずれも、税務を理解することの代わりにはならない——SSTは関税局
（RMCD）、電子インボイス及び所得税はLHDNの所管である——しかし、それらの
義務が値付けされ、支払われる際の金融的背景となるものである。

## 一次情報源で確認する

重要な判断の根拠とする場合は、要約ではなく一次情報源にあたること：

- 設立根拠法は**2009年マレーシア国立銀行法（Central Bank of Malaysia Act
  2009、Act 701）**であり、Laws of Malaysia の再版として入手できる。
- **OPRの推移及び金融政策声明**は `bnm.gov.my` で公表されている。
- **外国為替政策通達（Foreign Exchange Policy Notices）**は `bnm.gov.my/fep`
  に掲載されている。
