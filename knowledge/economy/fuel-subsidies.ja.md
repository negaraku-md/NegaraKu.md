2026年7月23日から29日の週、二人のドライバーが同じ給油所の同じポンプに立ち、同じ燃料を入れながら、支払う価格がほぼ二倍近く異なるということが起こり得る。一人は1リットルRM1.99を支払う。もう一人はRM3.62を支払う。

この1リットルあたりRM1.63の差は、店舗の割引ではない。それは補助金であり——しかも政府が事前に決めることのできない数字である。なぜなら、それは毎週ある公式によって再計算されるからだ。

## 簡潔な回答

マレーシアは**自動価格決定メカニズム（APM）**を通じてガソリンとディーゼルの小売価格を設定している。2017年4月以降、価格は毎週算出されており、2021年3月3日以降は毎週水曜日に発表され、木曜日から翌週水曜日まで適用される。

補助金は固定された予算措置ではない。それは**残余額**である。APMが算出した価格から、政府が定めた補助金価格を差し引き、補助金価格で販売された各リットルに乗じたものだ。政府はこの方程式の片側しか制御できない。

だからこそ、2026年最初の7か月間、補助金の負担額は以下のように推移した——政策が毎月変わったからではなく、原油価格が変動したからである。

| 月（2026年） | RON95＋ディーゼル補助金負担額 | 背景 |
| --- | --- | --- |
| 1月 | 約RM7億 | 市場は落ち着いていた |
| 3月 | RM50億近く | 西アジア危機が始まる |
| 4月 | RM75億（ピーク） | ブレント原油が1バレルUS$120に達した |
| 6月（予測） | 月額約RM35億 | ブレント原油は1バレルUS$90前後 |

出典：財務省、2026年6月10日付プレスリリース。この月額RM35億の予測のうち、約RM20億がRON95補助金、RM15億がディーゼル補助金である。

## APMが実際に行っていること

APMは行政上の公式であり、市場メカニズムではない。これは石油製品の週次価格に基づいて給油所の小売上限価格を設定するものである——すなわち、**すでに精製された**燃料の価格であり、原油価格ではない。これはしばしば見落とされる違いである。マレーシアは原油を輸出しているが、給油所の価格は地域市場における精製製品のコストに連動しているのだ。

この公式には、流通チェーン全体にわたる複数の構成要素も含まれる。財務省は、**給油所運営者マージン（Margin Pengusaha Stesen Minyak）**がAPM公式の構成要素の一つであることを公式に確認している——このマージンは、製品価格の変動とは別に見直すことができる。

この設計から、3つの帰結が生じる。

**第一に、小売価格は決して「自由」ではない。** 無補助金価格であっても、支払う数字は政府が算出し発表した数字であり、各給油所が独自に決めた数字ではない。

**第二に、家計への波及経路は週単位である。** 世界の原油価格の変動はゆっくりと吸収されるのではなく、数日のうちに給油所の価格に現れる。これにより、燃料は消費者物価バスケットの中で最も不安定な品目の一つとなっている——[マレーシアのCPIがどう構成されているか](/economy/inflation-cpi)を参照し、運輸分野のインフレ率が全体の水準から大きく乖離しがちな理由を理解してほしい。

**第三に、輸入コストはドル建てで計算される。** 石油製品のコストは外貨建てで評価されるため、[リンギットの価値](/economy/ringgit)の変動は、世界の原油価格がまったく動かなくても給油所の価格に影響を与える。

## なぜ一律補助金が財政負担となるのか

一律補助金の下では、販売されるすべてのリットルが、誰が購入するかにかかわらず補助される。これにより、3つの明確な財政的性質が生じる。

**コストは青天井であり、上限がない。** 予算措置は年初に見積もることができるが、実際のコストは一年を通じた世界価格によって決まる。2026年のデータはその規模を示している。同じ請求額が1月から4月の間に10倍以上に膨らんだ。

**コストは、財政余力が最も逼迫している時に上昇する。** エネルギー価格の高騰は通常、生活費圧力の高まりと同時に起こる——ちょうど他の公共支出も増加している時期と重なるのだ。

**恩恵は対象を絞られていない。** 補助金は人ではなくリットルに結びついているため、マレーシアで給油する誰にでも——非国民や対象外の車両を含め——流れてしまう。財務省は、受給者確認の目的は、資格のない受給者が無補助金価格で購入するようにすること、および漏出と密輸を抑制することだと述べている。

対象を絞った補助金モデルは、価格リスクそのものを消し去るわけではない。それが縮小するのは、誰が資格を持ち、何リットルが補助されるかを制限することによって、そのリスクにさらされる**数量**である。

## 移行の経緯（日付順）

| 日付 | 変化 |
| --- | --- |
| 2017年4月 | 小売価格がAPM公式を用いて毎週設定されるようになる |
| 2021年3月3日 | 価格発表日が金曜日から水曜日に変更 |
| 2024年6月10日 | 半島部でディーゼル補助金が撤廃。価格は1リットルRM2.15からRM3.35に上昇 |
| 2024年6月13日 | ディーゼル価格が半島部とサバ州、サラワク州及び連邦直轄区ラブアンとで別個に発表されるように |
| 2025年9月30日 | BUDI95開始：一般市場RON95はRM2.60、補助金価格は1リットルRM1.99、配給枠は月300リットル |
| 2026年4月1日 | BUDI95の配給枠が月200リットルに調整。価格はRM1.99を維持 |
| 2026年7月1日 | BUDI Diesel：補助金付きディーゼルが全国で1リットルRM2.10に統一 |

BUDI95開始時点では、一般市場価格RM2.60に対し補助金は1リットルあたり61 senに相当し、月300リットルの満額配給枠で最大約RM183の恩恵があった。2026年6月までに、無補助金RON95が1リットルRM3.72となった時点で、財務省は200リットルを使用する消費者の節約額を月約RM346と見積もり、同プログラムの受益者は1400万人を超えると述べた。

2026年4月1日に配給枠が調整された際、政府は、資格のある消費者のほぼ90%が月200リットル未満しか使用しておらず、平均使用量は約100リットルであると述べた。eハイリング事業者向けの追加配給枠は月800リットルのまま据え置かれた。

## 今日、誰がいくら支払っているか

2026年7月23日から29日の期間、ブレント原油が1週間で約16%上昇した後：

| 区分 | 1リットルあたり価格 |
| --- | --- |
| 無補助金RON95 | RM3.62（20 sen上昇） |
| RON97 | RM4.20（20 sen上昇） |
| 無補助金半島部ディーゼル | RM4.42（35 sen上昇） |
| 補助金付きRON95（BUDI95） | RM1.99 |
| 補助金付きディーゼル（BUDI Diesel） | RM2.10 |
| 公共交通・貨物輸送用ガソリン（SKPS） | RM2.05 |
| 公共交通・貨物輸送用ディーゼル（SKDS） | RM2.15 |

最後の2つの制度は、MyKadではなくMySubsidiシステムを通じて、国内取引・生活費省（KPDN）が運営している。SKPSは陸上公共交通及び陸上貨物輸送の各分野にわたる21種類の車両を対象とし——タクシー、スクールバス、救急車、冷凍トラックなどが含まれる。車両は個人名義、企業委員会（SSM）に登録された会社名義、または協同組合及び地方当局の名義で登録することができ、登録はMySubsidiを通じてのみ行われ、手動での申請はない。承認は即時であり、団体の種類、使用区分及び有効な車両道路税に基づく。

2026年7月1日に開始されたBUDI Dieselでは、基本配給枠は月200リットルであり、ピックアップトラック及びジープの所有者はさらに100リットルを追加申請できる。資格は給油所でMyKadを用いて確認される。このプログラムが対象とするのは、私有ディーゼル車両の所有者約700,000人——半島部で約400,000人、サバ州、サラワク州及び連邦直轄区ラブアンで300,000人——であり、これは従来のBUDI Diesel Individu現金給付制度の下での半島部における約180,000人の受給者と比較される。漁業従事者（1リットルRM1.65）及びスクールバスを含む公共交通（1リットルRM1.88）向けにも特別料率が設定されている。

## よくある誤解

**発表された価格が支払う価格だと思い込むこと。** 2025年9月30日以降、財務省の週次発表に記載されているのは*無補助金*価格である。補助金価格は別建てのレートであり、市場価格が変動しても通常は維持される。

**原油価格と燃料コストを混同すること。** APMが参照するのは、すでに精製された石油製品の価格である。ブレント原油は方向性を示す指標であり、直接の入力値ではない。

**配給枠を消費量の上限だと思い込むこと。** 配給枠は購入できる燃料の量を制限するものではなく、補助金価格が適用されるリットル数を制限するものである。配給枠を超えたリットル数は、週次の市場価格で購入する。

**マレーシアはエネルギー輸出国だから高価格から守られていると思い込むこと。** 価格が上昇すれば政府の石油収入も確かに増加するが、同時に補助金の負担も増加する——そして両者は必ずしも同じ割合で動くわけではない。予算への純影響は、数量、価格、補助金構造が同時にどう作用するかに左右され、自動的なヘッジにはならない。

**対象範囲が確定したものだと思い込むこと。** 2026年4月のBUDI95配給枠調整は、世界的な供給状況が安定するまでの暫定措置であると表明されている。価格、配給枠、資格要件といったパラメータは、政策変数であって定数ではない。

## 今後の見通し

注視すべきは、ニュースの見出しではなく**パラメータ**である。この物語のほぼすべてを決定づけるのは3つの数字だ。週次の石油製品価格、固定された補助金レート、そして対象となるリットル数量である。

自分で確認するには：財務省の石油価格に関するプレスリリースは毎週水曜日に発表され、価格の全系列データはOpenDOSMのカタログでオープンデータとして入手できる。BUDI95及びBUDI Dieselの下での個人の資格及び配給枠はBUDI MADANIポータルで確認でき、一方SKPS及びSKDSの車両群制度はKPDNのMySubsidiを通じて運営されている。

燃料価格の変動が全体のインフレや金利の検討にどのように波及するかという、より広いマクロ的な文脈については、[インフレ率とCPI](/economy/inflation-cpi)及び[翌日物政策金利と金融政策](/economy/opr-monetary-policy)を参照のこと。
