在2026年7月23日至29日这一周，两名驾驶人士可以站在同一个油站的同一个油泵前，加同一种燃油，付出的价格却相差近一倍。一人付每公升RM1.99，另一人付RM3.62。

这每公升RM1.63的差距，不是店家给的折扣。它是补贴——而且这是一个政府无法预先定下的数字，因为它每周都由一道公式重新计算。

## 简明答案

马来西亚透过**自动定价机制（APM）**设定汽油与柴油的零售价格。自2017年4月起价格每周计算一次；自2021年3月3日起，宣布日改在每周三，并从周四起生效至下周三。

补贴并非一笔固定拨款。它是一个**余额**：APM计算出的价格，减去政府设定的补贴价格，再乘以每一公升按补贴价售出的燃油。政府只能控制这道方程式的一边。

这就是为何2026年首七个月的补贴账单如下起伏——不是因为政策每个月都在变，而是因为油价在变。

| 月份（2026年） | RON95＋柴油补贴负担 | 背景 |
| --- | --- | --- |
| 1月 | 约RM0.7 billion | 市场平静 |
| 3月 | 接近RM5 billion | 西亚危机开始 |
| 4月 | RM7.5 billion（高峰） | 布伦特原油触及每桶US$120 |
| 6月（预测） | 约每月RM3.5 billion | 布伦特原油约每桶US$90 |

来源：财政部，2026年6月10日新闻稿。在这预计每月RM3.5 billion当中，约RM2 billion为RON95补贴，RM1.5 billion为柴油补贴。

## APM究竟做了什么

APM是一道行政公式，而不是市场机制。它根据石油产品的每周市场价格，设下油站零售价的顶限——也就是**已经提炼**的燃油价格，而非原油价格。这是一个常被忽略的区别：马来西亚出口原油，但油泵价格却与区域市场提炼产品的成本挂钩。

这道公式也涵盖分销链上的多个组成部分。财政部正式确认，**油站经营者利润（Margin Pengusaha Stesen Minyak）**是APM公式下的其中一个组成部分——这项利润可与产品价格的波动分开检讨。

这样的设计带来三个后果。

**第一，零售价从来不是「自由」的。** 即使是在无补贴价格下，你所支付的数字，也是政府计算并宣布的数字，而不是每个油站各自决定的数字。

**第二，传导至家庭的速度是以周计的。** 全球油价的变动不会慢慢被吸收；它会在几天内就反映在油泵上。这使燃油成为消费者价格篮子中最不稳定的成分之一——参见[马来西亚CPI如何编制](/zh/economy/inflation-cpi)，了解为何运输领域的通胀率经常与整体通胀率大幅背离。

**第三，进口成本以美元计算。** 石油产品的成本以外币计价，因此[林吉特币值](/zh/economy/ringgit)的波动会影响油泵价格，即使世界油价完全没有变动。

## 为何全面补贴会变成财政负担

在全面补贴之下，每一公升售出的燃油都获得补贴，不论买家是谁。这带来三个明显的财政特性。

**成本是开放式的，而非封顶的。** 预算拨款可以在年初估算，但实际成本取决于全年的世界价格。2026年的数据显示了这种幅度：同一笔账单在1月至4月之间增加了超过十倍。

**成本在财政能力最紧绷时上升。** 能源价格飙升通常与生活成本压力同时出现——恰好就是其他公共开支也在上升的时候。

**利益并非精准锁定对象。** 补贴附着在每一公升燃油上，而非附着在人身上，因此会流向任何在马来西亚加油的人——包括非公民和并非目标对象的车辆。财政部表示，核实领取者身份是为了确保不符合资格者以无补贴价格购买，并遏制泄漏与走私。

精准补贴模式并不能消除价格风险。它缩小的是暴露于该风险之下的**数量**，方法是限制谁有资格，以及有多少公升获得补贴。

## 转型历程，按日期排列

| 日期 | 变化 |
| --- | --- |
| 2017年4月 | 零售价格开始使用APM公式每周设定 |
| 2021年3月3日 | 价格宣布日从周五改为周三 |
| 2024年6月10日 | 半岛柴油补贴取消；价格从RM2.15涨至每公升RM3.35 |
| 2024年6月13日 | 半岛与沙巴、砂拉越及联邦直辖区纳闽的柴油价格分开宣布 |
| 2025年9月30日 | BUDI95启动：市场普通RON95为RM2.60，补贴价为每公升RM1.99，配额为每月300公升 |
| 2026年4月1日 | BUDI95配额调整为每月200公升；价格维持RM1.99 |
| 2026年7月1日 | BUDI Diesel：补贴柴油在全国统一为每公升RM2.10 |

BUDI95推出时，相较于市场普通价RM2.60，补贴相当于每公升61 sen，以每月300公升的全额配额计算，最高可省约每月RM183。到了2026年6月，当无补贴RON95为每公升RM3.72时，财政部估计使用200公升的消费者可节省约每月RM346——并表示该计划惠及超过1,400万人。

在2026年4月1日调整配额时，政府表示近90%的合格消费者每月使用少于200公升，平均使用量约为100公升。电召车（e-hailing）营运者的额外配额则维持在每月800公升。

## 今天谁付多少

在2026年7月23日至29日这一周，布伦特原油一周内上涨约16%之后：

| 类别 | 每公升价格 |
| --- | --- |
| 无补贴RON95 | RM3.62（涨20 sen） |
| RON97 | RM4.20（涨20 sen） |
| 无补贴半岛柴油 | RM4.42（涨35 sen） |
| 补贴RON95（BUDI95） | RM1.99 |
| 补贴柴油（BUDI Diesel） | RM2.10 |
| 公共交通与货运用汽油（SKPS） | RM2.05 |
| 公共交通与货运用柴油（SKDS） | RM2.15 |

最后两项计划由国内贸易及生活费部（Kementerian Perdagangan Dalam Negeri dan Kos Sara Hidup，KPDN）透过MySubsidi系统管理，而非透过MyKad。SKPS（Sistem Kawalan Petrol Bersubsidi，补贴汽油管控系统）涵盖21种车辆类型，横跨陆路公共交通与陆路货运领域——德士、校车、救护车、冷藏货车等。车辆可以个人名义、在SSM注册的公司名义，或合作社与地方当局名义登记；登记只能透过MySubsidi进行，没有人工申请。批准是即时的，视实体类型、使用类别及车辆路税是否有效而定。

至于2026年7月1日启动的BUDI Diesel，基本配额为每月200公升，皮卡与吉普车车主可另外申请追加100公升。资格在油站以MyKad核实。该计划锁定约70万名私人柴油车车主——半岛约40万人，沙巴、砂拉越及联邦直辖区纳闽约30万人——相较之下，先前的BUDI Diesel Individu现金转移计划在半岛只有约18万名领取者。渔民（每公升RM1.65）以及包括校车在内的公共交通（每公升RM1.88）也订有专属费率。

## 常见错误

**以为宣布的价格就是你要付的价格。** 自2025年9月30日起，财政部每周宣布的价格列的是*无补贴*价格。补贴价格是另一个独立费率，通常即使市场价格波动也维持不变。

**把原油价格与燃油成本混为一谈。** APM指的是已经提炼的石油产品价格。布伦特原油只是方向性指标，不是直接输入项。

**以为配额是消费上限。** 配额不是限制可以买多少燃油；它限制的是有多少公升能享有补贴价格。超出配额的公升数须以每周市场价格购买。

**以为马来西亚身为能源出口国就不受高油价影响。** 政府的石油收入确实会随价格上涨而增加，但补贴负担也在同一时间上升——而且两者不一定以相同的速度变动。对预算的净影响同时取决于数量、价格与补贴结构；这不是一种自动对冲。

**以为精准补贴的目标对象已成定局。** 2026年4月的BUDI95配额调整，被表明为在全球供应状况稳定之前的临时措施。价格、配额、资格等参数，是政策变量，而不是常数。

## 下一步

需要留意的是**参数**，而不是新闻标题。三个数字决定了几乎整个故事：每周的石油产品价格、固定的补贴费率，以及符合资格的公升数量。

想自行查证：财政部的石油价格新闻稿每周三发布，完整的价格数据系列可在OpenDOSM数据目录中作为开放数据取得。BUDI95与BUDI Diesel下的个人资格与配额可透过BUDI MADANI门户网站查核，而SKPS与SKDS车队计划则透过KPDN的MySubsidi系统管理。

若想了解更宏观的背景——燃油价格冲击如何传导至整体通胀与利率考量——参见[通货膨胀率与CPI](/zh/economy/inflation-cpi)以及[隔夜政策利率与货币政策](/zh/economy/opr-monetary-policy)。
