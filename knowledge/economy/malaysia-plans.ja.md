2025年7月31日、首相は下院（Dewan Rakyat）において、少なくともRM6,110億の投資を必要とする開発動議を提出した。予算ではない——その年度の予算はすでに数カ月前に提出済みであった。これはまったく別の動議である。第13次マレーシア計画——1年ではなく、これから5年間、2026年から2030年までの国の開発の方向性を定める計画である。

多くの国民は、毎年10月の予算にしか気づかない。しかし予算そのものが、より大きな枠組みに基づいて策定されている——その枠組みこそがマレーシア計画である。

## 簡潔な回答：3層の計画構造

マレーシアは、それぞれ異なる機能を持つ3つの時間軸で開発を計画している。

| 層 | 期間 | 例 | 機能 |
| --- | --- | --- | --- |
| 長期 | 10-30年 | [ワワサン2020](/malaysia/wawasan-2020)（1991-2020）、国家ビジョン政策（2001-2010） | 国の大きな願望と目標を定める |
| 中期 | 5年 | **マレーシア計画**（13MP、2026-2030） | 施政の主軸、優先事項、戦略、成果目標を定める |
| 短期 | 1年 | [連邦予算](/economy/federal-budget) | 特定年度の実際のリンギットを配分する |

マレーシア計画は中間層にあたる。長期ビジョンを実行可能な戦略へと翻訳し、さらに年次予算がその戦略を毎年の実際の配分へと翻訳する。

## マレーシア計画とは実際には何か

マレーシア計画は1年分の支出額ではなく、法律でもない。経済省（Kementerian Ekonomi）が策定する政策文書であり、5年間の開発の主軸、政策上の優先事項、戦略、成果目標を定める——そして供給法案のような法案としてではなく、国会での審議と承認を得るための**動議**として提出される。

この伝統は、現在の形としては完全独立より前に始まっている。第1次マラヤ計画（1956-1960）と第2次マラヤ計画（1961-1965）が、第1次マレーシア計画（1MP、1966-1970）に先立っていた——これにより13MPは、1956年以来15番目の5カ年開発計画であり、1966年に「マレーシア計画」という名称が使われ始めて以来13番目の計画となる。

| 計画 | 期間 |
| --- | --- |
| 1MP | 1966-1970 |
| 2MP | 1971-1975 |
| 3MP | 1976-1980 |
| 4MP | 1981-1985 |
| 5MP | 1986-1990 |
| 6MP | 1991-1995 |
| 7MP | 1996-2000 |
| 8MP-10MP | 2001-2015 |
| 11MP | 2016-2020 |
| 12MP | 2021-2025 |
| **13MP** | **2026-2030** |

これを策定する機関も、幾度か形を変えてきた。1956年4月24日に設置された経済事務局は、1961年に首相府（Jabatan Perdana Menteri）の下で経済計画ユニット（EPU）に再編され、EPUは第15回総選挙後の2022年12月23日に最終的に解散し、その職能と責務は経済省が引き継いだ。現在マレーシア計画の策定を調整しているのはこの経済省であり、トップダウン方式（経済省、財務省、マレーシア国立銀行（Bank Negara Malaysia、BNM）といった中央機関によるマクロ経済の枠組み策定）とボトムアップ方式（機関間計画グループ（IAPG）会議および技術作業部会（TWG）会議を通じた関係者協議）の両方を通じて行われている。

## 年次予算との関係

ここが最も誤解されやすい関係である：マレーシア計画が**定め**、予算が**実行する**。

13MPは、GDP成長率、1人当たり国民総所得、貧困率といった5カ年の成果目標と、2026-2030年の期間を通じて政府側でRM4,300億の開発投資を必要とすることを定める。特定の省庁が2027年に具体的に何リンギット支出できるかまでは定めていない。

年次の金額が明らかになるのは、財務大臣が毎年[連邦予算](/economy/federal-budget)を提出し、その年の13MP分の割当を決定する開発支出見積り（Anggaran Perbelanjaan Pembangunan）が示されて初めてである。実際の配分額はプロジェクトの優先順位とその時点の財政状況によって年ごとに異なる——5カ年の総額が年ごとに均等に分割されるわけではない。

承認手続きの違いも、この機能の違いを反映している。マレーシア計画は政策動議として承認されるが、予算は供給法案を経て国会での完全な立法手続きを経たうえで供給法（Akta Perbekalan）として官報告示されなければならない——このサイクルの全容は[連邦予算サイクル](/economy/federal-budget)で説明している。

## 中間評価：折り返し地点での見直し

5年間は、見直しを行わないまま一つの目標に固執するには長すぎる期間である。そのため、マレーシア計画は通常、期間の中間時点で**中間評価（Kajian Separuh Penggal、KSP）**を通じて見直される——これもまた国会に別個の動議として提出される。

例えば、第12次マレーシア計画中間評価（KSP RMKe-12）は、2023年9月11日に首相によって提出され——13MPを待つことなく、MADANI経済の枠組みの下で新たな政策と戦略を導入した。同じ仕組みは2MP、7MP、8MP、9MP、11MPでも用いられている。これにより政府は、5カ年計画全体を作り直すことなく、途中で戦略を調整することができる。

## 13MP（2026-2030）：何が変わるのか

13MPは**「開発の再設計」**をテーマとし、高所得かつ持続可能、質が高く包摂的な生活、そして持続可能な環境という3つの次元を通じて国の社会経済目標を位置づけている。

その枠組みは**4つの柱**と**27の優先事項**で構成され、120を超える戦略と600を超える施策に支えられている。

| 柱 | 焦点 |
| --- | --- |
| A. 経済の複雑性を高める | 高付加価値産業、グリーン／ブルー経済、食料安全保障、生産性 |
| B. 社会的流動性を高める | 教育改革、労働市場、地域間の均衡 |
| C. 公共サービス改革アジェンダの実施を加速する | サービス提供（ILTIZAM）、GovTech、ガバナンス、財政 |
| D. 国民の福祉と環境の持続可能性を高める | 保健、住宅、安全、地球の健康、災害管理 |

投資面では、政府は13MPに対し**少なくともRM6,110億**の投資を決定した——うちRM4,300億は政府開発拠出から、RM1,200億は政府関連企業（GLC）および政府関連投資会社（GLIC）による戦略分野への国内直接投資から、RM610億は官民パートナーシップ（PPP）の手法を通じて見込まれている。

2030年までの主な成果目標には、年平均4.5%-5.5%のGDP成長率、1人当たり国民総所得（GNI）のRM77,200への上昇、GDP比3%未満の財政赤字、4.7%の絶対貧困率、GDPに占める雇用者報酬の割合の40%への上昇が含まれる。

その承認手続きも、二院制国会の通常の流れに従っている。動議は2025年7月31日に下院で提出され、続いて2025年8月25日に上院（Dewan Negara）で提出された。計画期間が2026年に始まる前に、両院がこの動議を可決した。

## よくある誤解

**「マレーシア計画は5カ年の予算である。」** 誤りである。マレーシア計画は施政の主軸と目標を定めるものであり、年ごとに省庁別の具体的なリンギット配分を行うものではない——それは年次予算の役割である。

**「13MPのRM6,110億はすべて政府の資金である。」** 誤りである。政府開発拠出はRM4,300億のみであり、残りはGLC/GLIC直接投資（RM1,200億）と官民パートナーシップの手法（RM610億）から来ている。

**「マレーシア計画は供給法案と同じように承認される。」** 誤りである。それは政策動議として提出・承認されるものであり、完全な立法手続きを経る必要がある財政法案ではない。

**「マレーシア計画の目標は、次の計画が出るまで見直すことができない。」** 誤りである。期間中間時点の中間評価により、5年間全体を待たずに政策と戦略を調整することができる。

## 次に読むべきもの

13MPのRM4,300億のうちごく一部が、どのように毎年の実際の配分へと翻訳されるかについては、[連邦予算サイクル](/economy/federal-budget)を参照のこと。13MPの成果目標の基礎となるGDPの背景とマクロ指標については、[マレーシアGDP概観](/economy/gdp-overview)を参照のこと。13MPのような動議が実際にどのように審議・承認されるかについては、[マレーシア国会](/government/parliament)を参照のこと。

13MPの完全な文書——総覧（Buku Utama）、エグゼクティブサマリー、提出演説の全文を含む——は、経済省の公式ポータルサイトrmk13.ekonomi.gov.myで入手できる。
