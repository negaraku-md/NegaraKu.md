2025年12月31日，《2026年拨款法令》颁布于宪报。该法令批准的金额是：
**RM229,080,812,700**。

但在此之前的10月，预算案新闻标题提到的却是RM419.2 billion。两个数字都
没有错。两者之间的落差，正是理解联邦预算实际如何运作的最佳切入点——也
说明了为什么「预算」并不是一份单一文件，而是一个全年运行的立法周期。

## 简答：六个阶段

| 阶段 | 发生的事 | 法律依据 |
| --- | --- | --- |
| 1. 编制 | 库务处（Treasury）设定开支上限；各部门编制预算；预算审查会议 | 库务处通令；财政部程序 |
| 2. 呈递 | 开支预算在议事桌前呈递，随后是拨款法案（Supply Bill）的一读 + 发展预算动议 | 第99–100条；议事常规第65、66(1)条 |
| 3. 政策阶段 | 二读辩论，仅限于一般政策——最多13天 | 议事常规第66(3)条 |
| 4. 委员会阶段 | 每个开支项目逐一表决——最多20天 | 议事常规第66(5)–(17)条 |
| 5. 三读 | 不经修正、不经辩论即予表决 | 议事常规第66(18)条 |
| 6. 上议院与御准 | 上议院（Dewan Negara）只能延搁一个月；其后御准并颁布于宪报 | 第66、67(1)、68条 |

## 为什么拨款法令的金额比预算总额小

联邦宪法第104条订明，资金离开统一基金（Consolidated Fund）只有三条
途径：*已拨付*于其上的资金、透过拨款法令获准动用的资金，或第102条所
指的资金。

第98条则列明了自动获得拨付的项目——当中包括一切退休金与酬金，以及一
切债务费用。这类开支无须每年重新获批。

这就是拨款法令中金额较小的原因。在2026年RM338.2 billion的营运开支
当中，债务偿还费用（RM58.3 billion）与退休金费用（RM42.8 billion）
不会出现在拨款法令的附表内，因为这些款项是直接由统一基金拨付的。

RM81 billion的发展开支同样不在其中。它是根据《1966年发展基金法令》
第4(3)款，透过另一项独立的决议动议获批——该动议依据议事常规第66(2)条，
与法案同时提出。

## 演说之前：开支上限

这个周期远在10月之前，就已经在库务处内部展开。

预算管理司发出编制预算的指示与通令。每个部门都会获得一个**开支上限**
——即为资助**现有政策**（Existing Policy，即一切正在进行中的计划与
活动）而不得超过的金额。

任何新增项目都必须另行申请，列为**新政策**（New Policy）或**One-Off**
（一次性项目）。正是这三分类之间的区别，决定了某个部门的提案是否有任
何直接的机会。

该提案接着会在库务处与该部门之间的**预算审查会议**上受到检验。最终结
果则透过**计划协议**（Programme Agreement）确定下来——就每项活动的投
入、产出与影响达成协议。

大部分实质的决定，都是在这个阶段做出的。到了呈递日，数字早已成为定案。

## 呈递日：不只是一份文件

议事常规第65条说得很清楚：开支预算须在拨款法案提交入议会**之前**，先
呈递于议事桌。预算案演说是伴随该文件而来，并非取而代之。

《2023年公共财政与财政责任法令》（第850号法令）则增添了一层强制性文
件。部长须连同收入与开支的预估报表，一并呈递**经济展望报告**（第32条）
与**财政展望报告**（第33条）。

收入预估须显示上一年度的实际收入、本年度的修订预估，以及下一年度的预
估（第34条）。开支预估则须列明计划与活动、发展项目以及计划绩效（第35
条）。

只有部长才能提出这类法案，而且该法案不得在上议院提出——这是第67(1)条
的效果。

## 政策阶段：一项鲜少被提及的时限规定

在二读动议获得提出与附议之后，辩论**须押后不少于两天**。议事常规第
66(3)条让国会议员有时间先阅读文件，再发言。

辩论恢复后，范围仅限于一般政策与政府的施政。总共可分配**最多13天**，
而在这13天当中，**不少于两天**须留给部长的答复。

这并非自由发言的辩论。它是排定时间表的辩论，并附有断头台式的限制：在
最后一天，议长订定的时间一到，所有为结束讨论所需的问题都会被提出付诸
表决。

## 委员会阶段：部门受考验之处

二读通过之后，下议院（Dewan Rakyat）摇身一变，成为**全体委员会**——
同一批议员，由不同的人主持，辩论规则也较为宽松。

总共可分配**最多20天**。附表须先处理完毕，才轮到条文。

主席依序宣读每个开支项目的标题，并以固定格式提出问题：

> 「即一笔RM……的款项，用于开支项目……，列入附表之内。」

至于发展预算，格式则有所不同：「即开支项目……当中所述的开支，在有关
年度的发展预算内予以批准。」

**削减动议**就是在这个阶段发生的。任何议员都可以提出修正案，削减某个
子项目或细目的拨款——但须至少提前**两天**发出通知。如果有多项削减动
议，最小的削减金额须先提出。

有一项重要的限制常被遗忘：对某个开支项目的辩论，仅限于该笔款项所要拨
付的**服务政策**本身，而不涉及开支的细节。

## 三读、上议院与御准

所有开支项目处理完毕后，法案即向下议院会议报告。由一名部长提出三读动
议——该动议**不经修正、也不经辩论**即付诸表决。戏剧性的部分，如果有
的话，早已在委员会阶段落幕。

在[上议院（Dewan Negara）](/zh/government/parliament)，第68条赋予的
权力相当有限：如果一项金钱法案在会期结束前至少一个月送交上议院，而上
议院未能在一个月内不经修正地通过它，该法案仍会呈交最高元首（Yang
di-Pertuan Agong）予以御准——除非下议院另有指示。

某项法案是否属于金钱法案，取决于下议院议长的意见（第68(6)条）。而下
议院议长关于第68条各项规定已获遵守的证明，就一切目的而言均属最终定
论，不得在任何法院提出质疑（第68(4)条）。

2026年的周期展示了实际的时间表：

| 日期 | 事件 |
| --- | --- |
| 2025年10月10日 | 提呈《2026年拨款法案》与发展开支预算动议 |
| 2025年12月15日 | 获国会通过 |
| 2025年12月22日 | 获御准 |
| 2025年12月31日 | 颁布为《2026年拨款法令》（第A1781号法令） |

## 收入与开支的构成

| 2026年组成部分 | 金额 | 备注 |
| --- | --- | --- |
| 总收入 | RM343.1 billion | 占GDP的16.1% |
| ——税收 | RM270.4 billion | 占总收入的78.8% |
| ——直接税 | RM187.4 billion | 当中CITA为RM103.4 billion |
| ——间接税 | RM83.0 billion | 包括[SST](/zh/taxation/sst-explained) |
| ——非税收入 | RM72.7 billion | 主要为投资收入 |
| 总开支 | RM419.2 billion | 占GDP的19.7% |
| ——营运开支（OE） | RM338.2 billion | 占总开支的80.7% |
| ——发展开支（DE） | RM81.0 billion | 占GDP的3.8% |
| 财政赤字 | 占GDP的3.5% | 目标是到2028年降至3% |

这些数字并非随意选定。第850号法令的First Schedule（第一附表）订明了
中期须达到的量化数值：发展开支须占GDP的**≥ 3%**，财政余额须为
**≤ -3%**，债务水平须为**≤ 60%**，而金融担保须为**≤ 25%**。

如果这些目标未能达成，第27条便要求部长提呈**财政调整计划**，交由下议
院以决议方式批准。

## 常见错误

**「预算在呈递当天就获得通过。」**并非如此。以2026年的周期为例，从呈
递到国会通过之间相隔超过两个月。

**「上议院可以否决预算案。」**对金钱法案而言，第68条只给予上议院一个
月的期限，而非否决权。

**「政府所有开支都列在拨款法令内。」**退休金与债务费用是根据第98条拨
付的；发展开支则是透过《1966年发展基金法令》获批的。

**「一旦通过，数字就成定案。」**第101条容许追加预算与追加拨款法案。议
事常规第66A条容许透过部长动议重新分配拨款。第103条则容许在紧急且未能
预见的需要下，从备用基金（Contingencies Fund）预支款项。

**「法令一经颁布于宪报，监督就此结束。」**第850号法令第36条要求每年不
迟于**9月30日**发布年中开支绩效报告。此外，总审计司（Auditor-General）
则须依据第107条提呈报告，在下议院提呈。
