你可以在 STPM 或大学先修班（matrikulasi）中考得优异成绩，但若缺少了另一项成绩，你的学位申请表仍然不算完整。那项成绩就是 MUET——而许多学生往往要到大学申请截止日期迫近时，才意识到它的重要性。

MUET（Malaysian University English Test，马来西亚大学英语测试）是一项专为衡量预备大学阶段学生是否具备应对高等教育学习能力而设计的英语测试。它由马来西亚考试理事会（MPM）研发并主办——MPM 是教育部辖下的法定机构，同时也负责主办 STPM。

## MUET 是什么，由谁主办？

MPM 依据《1980 年马来西亚考试理事会法令》（Akta Majlis Peperiksaan Malaysia 1980，第 225 号法令）成立，负责主办 STPM 和 MUET 这两项考试。MUET 的目标只有一个：衡量学生在进入大学之前的英语掌握水平，让院校了解一名考生能在多大程度上跟上讲课、阅读学术文本，并以英语撰写学术论文。

根据马来西亚政府官方门户网站，MUET 成绩**是升读公立大学学士学位课程的必备条件**，并须符合各大学评议会（Senat）所制定的条件。有一点很重要必须明白：MUET *并不*用于报读文凭、STPM、大学先修班或基础课程。它只有在你迈向学位阶段时才成为条件。许多学生在就读 STPM 那一年或在基础课程期间应考 MUET，以便在申请大学时成绩已经就绪。

## MUET 如何评估——四张试卷与等级制度？

MUET 分别测试四项语言技能。每项组成部分权重相同，并共同构成一个总分。

| 试卷 | 所测技能 |
| --- | --- |
| 试卷 1 | 听力（Listening） |
| 试卷 2 | 口语（Speaking） |
| 试卷 3 | 阅读（Reading） |
| 试卷 4 | 写作（Writing） |

四张试卷的分数合并成一个**最高 360 分的总分**。该分数随后换算为一个等级。MUET 等级制度共设九个级别，从 Band 1.0（最低）到 Band 5+（最高），依据 MPM 官方《Band Description》文件，各等级的分数区间如下：

| 等级 | 总分区间（满分 360） |
| --- | --- |
| Band 5+ | 331–360 |
| Band 5.0 | 294–330 |
| Band 4.5 | 258–293 |
| Band 4.0 | 211–257 |
| Band 3.5 | 164–210 |
| Band 3.0 | 123–163 |
| Band 2.5 | 82–122 |
| Band 2.0 | 36–81 |
| Band 1.0 | 1–35 |

等级越高，代表考生的英语掌握越好。在《Band Description》文件中，MPM 将 MUET 等级与《欧洲共同语言参考标准》（Common European Framework of Reference for Languages，CEFR）对应，并将考生归为三类使用者——**Proficient**（熟练使用者）、**Independent**（独立使用者）和 **Basic**（基础使用者）——等级越高对应的 CEFR 水平越高。（每个等级与特定 CEFR 水平的确切对应关系，须在 MPM 官方文件中核实。）每位完成全部四项组成部分的考生都会收到一份显示总体等级的成绩单。

## 入读大学你需要哪个等级？

这是最常被问到的问题——而答案并非一个单一的数字。政府门户网站说明，等级要求由**各大学的评议会（Senat）**制定，因此因院校和课程而异。

作为大致参考（并非官方数值——请在相关大学网站核实）：

- **竞争激烈的课程**，如医学和法律，通常要求较高的等级。
- **工程课程**及许多理科学位通常设定中上等级。
- **许多其他课程**接受较低的等级作为最低条件，前提是考生符合其他学术要求。

由于实际门槛各不相同且由评议会制定，最稳妥的做法是在应考之前，先到你所申请的大学网站查询具体课程的条件。同一所大学里，足以入读某一课程的等级，未必足以入读另一课程。

## MUET 与 STPM、大学先修班及 UEC 的关系

MUET 很少单独存在——它是对你主要的预备大学资格的补充：

- **STPM：** STPM 学生在中六（Tingkatan Enam）期间应考 MUET。STPM 成绩决定学术优异程度，而 MUET 等级则满足学位申请的英语条件。
- **大学先修班与基础课程：** 就读先修班或基础课程的学生在迈向学位之前也会应考 MUET，因为大学入学阶段需要 MUET 成绩。
- **UEC（统一考试文凭，Unified Examination Certificate）：** 持有 UEC 并欲申请本地大学的华文独立中学学生，通常提交 MUET 作为英语能力证明。至于申请私立或海外大学，视院校而定，有时也接受 IELTS 或 TOEFL 等同等资格。

简而言之：预备大学资格证明你的学术能力；MUET 证明你的英语准备程度。两者在申请时通常一并被评估。

## 报名费、举办次数与有效期

一般的 MUET 每年举办**三次**。对于需要更灵活考期的考生，MPM 提供以电脑为基础的**按需考试（MUET on Demand，MoD）**，每月都可应考，但收费较高。

| 项目 | 详情 |
| --- | --- |
| 公民考生报名费（一般 MUET） | RM150 |
| 非公民考生报名费（一般 MUET） | RM350 |
| 一般 MUET 举办次数 | 每年三次 |
| 成绩有效期 | 自成绩公布之日起五年 |

请仔细留意五年有效期这一点。如果你很早就应考 MUET——例如在中六下学期——之后又推迟入读大学，成绩可能在你真正提出申请之前就过期。在这种情况下，你就必须重考。

## 常见疑问

许多学生不确定是否可以重考 MUET 以提高等级。可以——你能够多次报考，任何仍在有效期内的成绩都可用于申请。如果你应考不止一次，究竟以哪一个成绩为准，取决于相关大学的政策，因此须专门查询。也有人问 MUET 是否能被 IELTS 或 TOEFL 完全替代以申请公立大学；这项政策取决于大学评议会，因此须专门查询，不能想当然。

## 下一步

如果你计划升读学位阶段：

1. **先查清你所瞄准课程的条件**，到大学网站查找该课程所设定的最低 MUET 等级。
2. **尽早报考 MUET**，理想上是在你的预备大学阶段应考，以便成绩在申请时已就绪且仍在有效期内。
3. **计算有效期**——确保成绩不会在你申请前满五年而过期。
4. **参考 MPM 官方门户网站**，在应考之前查阅最新的考试日期、报名费、报名程序和格式规范。

有关报名、日期和格式的官方及最新信息，请参阅马来西亚考试理事会门户网站 mpm.edu.my。
