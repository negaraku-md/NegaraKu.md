一名来自香港的买家同意以 RM1.8 million 的价格购买八打灵再也（Petaling Jaya）的一间半独立式住宅。融资已经安排妥当，卖方也愿意出售，价格跨过了网上所能查到的每一道门槛。然而，这笔交易仍然无法完成，除非莎阿南（Shah Alam）的一个州政府机构做出决定——完全由其自行酌情——是否允许一名外国人持有这份地契。

这第二步，往往让只读过「最低价格」头条新闻的人感到意外。外国人在马来西亚购买产业，须跨过两道各自独立的关卡，跨过其中一道，并不代表另一道也已跨过。

## 两道关卡，而非一道

第一道关卡是**最低价格**。马来西亚并不存在单一的全国性门槛——每个州各自设定自己的门槛，有些州还会按县、按分区，或按产业是有地产业还是分层产业（公寓、组屋、服务式住宅）来分别设定。

第二道关卡是**州政府当局的书面同意**，依据 National Land Code 1965（Act 56，现已整合为 Act 828），无论价格多高，每一宗外国人收购都必须取得这项同意。在马来西亚的联邦架构下，土地事务归入州属清单——参见[联邦与州政府之间的权力如何划分](/zh/government/federal-state-division)——这正是为什么各州的数字与手续各不相同，而不是遵循同一本联邦规则手册。

跨过最低价格门槛，只是让外国买家走到可以提出申请的那一步。这并不保证州属会批准。

## 法律根本：s.433A 至 s.433E

真正起作用的规定在 National Land Code s.433B：任何土地交易——转让、租赁、抵押——若有利于非公民或外国公司，只有在州政府当局事先书面批准后才能生效。s.433C 则明确规定了后果：任何违反 s.433B 完成的交易一律无效。

这是一部**联邦法规**，却把实际的决定权交给**州级当局**——在马来西亚半岛，是州政府当局透过该州的土地局（Pejabat Tanah）行事；而在吉隆坡、布城与纳闽，则由代表联邦直辖区部长行事的联邦直辖区土地局负责。

在假设本文涵盖全国之前，有两点值得先说明：

- **沙巴与砂拉越不受 National Land Code 管辖。** 两州各自实行独立的土地立法，对非公民土地交易也各自订有独立规则，因此下文所描述的框架仅适用于马来西亚半岛与联邦直辖区。
- s.433B 的适用范围随时间而扩大。外国公司收购工业用地一度无须取得同意；后来该法典的一项修正案关闭了这项豁免，因此如今州政府当局的批准适用于所有土地类别，而不仅限于住宅用地。

## 第一道关卡：各州的最低价格

每个州都会公布（或透过其土地局传阅）自己针对外国人购买的最低价格门槛，并定期修订。作为一个具体且来源官方的例子，**雪兰莪州议会（Dewan Negeri Selangor）**的一份官方书面答复列出了雪兰莪按分区划分的结构：

| 类别 | 第1–2区（Petaling、Gombak、Hulu Langat、Sepang、Klang、Kuala Selangor、Kuala Langat） | 第3区（Hulu Selangor、Sabak Bernam） |
| --- | --- | --- |
| 住宅 | RM2,000,000 | RM1,000,000 |
| 商业与工业 | RM3,000,000 | RM3,000,000 |

请把这张表格视为说明某个州*如何*构建其最低价门槛的例子，而不是可以直接套用到实际交易中的数字——雪兰莪与其他每一个州都会修订这些数字，今天签署的买卖合约，应对照相关州土地局的现行通告核实，而不是对照任何指南（包括本文）。

联邦直辖区则依循另一条由联邦设定的不同轨道。根据**经济策划单位（Economic Planning Unit，简称 EPU）**的《Guideline on the Acquisition of Properties》，配合 2014 年财政预算案修订，外国权益收购吉隆坡、布城或纳闽产业的最低价值被设定为每单位 RM1,000,000。这正是网上最常被引用为马来西亚「最低价」的数字——但它专指联邦直辖区的数字，而非全国性的数字，它与上文所述半岛其他地方各自独立的逐州门槛是并行存在的。

## 无论价格多高都被排除在外的产业

有些产业无论外国买家出价多高，都不对其开放：

- **马来保留地（Malay Reserved Land）。** 根据《Malay Reservation Enactments》（马来保留地法令——这是可追溯至马来联邦（Federated Malay States）时期的州级法律），任何有利于非马来人的马来保留地转让、租赁或抵押均属无效。这是一项独立于 National Land Code 同意制度之外、历史更悠久的限制，并且不仅适用于外国人，同样适用于马来西亚籍的非马来人。
- **归类为农业用途的土地**，各州当局通常出于政策考量，将其排除在外国人同意申请之外。
- **土著配额单位以及低成本或可负担住房**，这些类别由各州住房政策各自保留，并不作为发展项目分配的一部分提供给外国买家。

以上任何一项都不能靠出价高于州属最低价格来协商解决——它们完全处在价格与同意这套框架之外。

## 第二道关卡：申请州政府当局同意

一旦某项产业跨过了最低价格门槛，且不属于被排除的类别，买家（通常透过产业转让律师）便会向州政府当局书面申请该交易的同意。以下几项实际情况值得先有心理准备：

- **批准并非自动。** 州政府当局可以拒绝申请——例如，某个发展计划的外国人持有配额已经用完，或者该州在自己已宪报颁布的门槛之上，还存在一项未公开的内部偏好。
- **并不存在单一公布的处理时限。** 产业转让律师通常将处理周期形容为由数周到数月不等，但没有任何州政府当局就此发布有保证的服务标准——请把这种不确定性纳入购买的时间规划之中，而不要假设一个固定的周数。
- **对于金额非常庞大或会稀释土著权益的交易，存在另一项各自独立且门槛高得多的规定。** EPU 自身的指南要求，只有在产业收购价格高于 RM20 million、且会稀释土著或政府机构对该产业的所有权时，或者透过购股方式进行的间接收购导致一家土著持股公司（其产业资产超过 RM20 million）的控制权发生变化时，才需要这项额外批准。一宗普通外国人购买单一住宅的交易，永远不会触及这第二层、更为罕见的批准。

## 2026 年叠加的税务成本

跨过这两道关卡之后，还剩下税单要处理。自 2026 年 1 月 1 日起，根据 2026 年财政预算案的税务措施，非公民（不包括马来西亚永久居民）与外资公司须为住宅产业转让缴付**统一 8% 的印花税**——是原先统一 4% 税率的两倍。商业与工业产业转让不受此项变动影响。有关涵盖各类文书的完整税率表，参见[按 First Schedule 项目列出的马来西亚印花税率](/zh/taxation/stamp-duty-rates)。

产业拥有的另一端，同样有其专属于外国人的税率：日后出售产业的非公民，须按比公民与永久居民更高、也更为划一的税率缴付产业盈利税（real property gains tax），并且不像公民与永久居民那样，随持有期拉长而逐级递减。有关确切税率与完整的持有期阶梯，参见 [RPGT 税率与盈利如何计算](/zh/taxation/rpgt-rates)。

## 常见错误

**把「RM1 million」当成全国性最低价。** 这其实是 2014 年联邦指南下专属于联邦直辖区的数字，并非适用于全马来西亚的法定门槛。每个州都各自设定，并定期修订自己的数字。

**以为出价够高就能买到任何产业。** 马来保留地、农业类别土地，以及土著配额或低成本单位一律被排除在外——价格对这些类别而言无关紧要。

**把 National Land Code 的同意与 EPU 的批准混为一谈。** 依 s.433B 取得的州政府当局同意，几乎适用于每一宗外国人收购；EPU 各自独立的审查，只在 RM20 million 的土著稀释门槛上才会触发，而几乎没有任何个人购房交易会达到这个门槛。

**以为 MM2H 免除了取得州同意的需要。** [MM2H](/zh/settling-in/mm2h-long-stay-visa) 各等级要求申请人购买的住宅产业，无论落在哪个州，都是一笔普通的购买交易——它仍然必须跨过该州的最低价格门槛，并经过与其他任何外国买家相同的州政府当局同意程序。

**把马来西亚半岛的规则套用到沙巴或砂拉越。** 两州都在 National Land Code 之外实行各自的土地立法，对非公民交易也各自订有独立规则——不要假设某个半岛州属的数字或流程可以照搬套用。
