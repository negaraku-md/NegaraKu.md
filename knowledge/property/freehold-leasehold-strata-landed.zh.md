同一条街上两间几乎一模一样的排屋，可能来自州政府当局截然不同的承诺：一份地契写着「永久地契」，另一份写着「租赁地契，99 年，2118 年到期」。另一个不相关的问题，则决定你是否要与另外四十户人家共同拥有电梯大堂与泳池，还是车道与屋顶完全是你自己的事。买家常把这两个问题混成一个——「这是永久地契，还是公寓？」——但一处房产其实永远同时、各自独立地回答着这两个问题。

## 永久地契与租赁地契：你能持有土地多久

根据 National Land Code 1965 (Act 828)，州政府当局批出土地的方式，要么是**永久**批出，要么是**按固定年限**批出。前者就是买家口中的永久地契；后者，则是租赁地契。

| | 永久地契 | 租赁地契 |
| --- | --- | --- |
| 期限 | 没有到期日 | 由州政府设定的固定年限——通常最长 99 年，有时更短 |
| 期满时会发生什么 | 不适用 | 土地归还州政府当局，除非租约获得续约 |
| 转让 | 一般较为直接简便 | 往往附带明文条件或权益限制，须经州政府当局批准才能生效的转让、租赁或抵押 |
| 典型的转售观感 | 通常更容易获得融资与转售，尤其当租赁地契剩余年限缩短时更明显 | 随着剩余租期减少，融资与转售可能变得更困难 |

在租期之内，租赁地契并非较低一等的拥有权形式——它是该段期限内的完整拥有权，与永久地契一样在托伦斯（Torrens）产权登记制度下登记。它真正意味着的是：时间是这项资产实实在在的特征——1970 年代批出的 99 年租约，如今剩余的年限，比 2015 年批出、同样标称「99 年」的租约要少得多。沙巴与砂拉越施行的是各自的土地法规，而非 National Land Code——National Land Code 的适用范围与托伦斯制度实际如何运作，参见 [National Land Code 1965](/zh/law/national-land-code)。

## 分层地契与有地物业：拥有权的形态

第二条轴线与期限无关——它关乎你的地契涵盖的是整块土地，还是共享发展计划里的一个单位。

**有地物业（个别地契）。** 独立的排屋、半独立式房屋或独立式洋房，通常持有个别地契：一块地段，一个业主，没有共用结构。这里没有管理机构，没有共同产业，别人的装修工程也动不到你的地契。

**分层地契。** 根据 Strata Titles Act 1985，多单位发展计划——公寓、公寓式住宅，以及部分有围篱的有地物业计划——会被细分，使每个单位成为拥有自己分层地契的**分层单位（parcel）**，而不属于任何分层单位的一切（大堂、电梯、停车场、花园、有围篱社区的道路）则是**共同产业**。根据 JKPTG 自己的常见问答，分层地契是由州土地与矿务总监（State Director of Lands and Mines）为每个单位发出的地契文件，赋予政府担保的拥有权——相较于仅持有买卖合约（在分层申请仍在审批期间，买卖合约只提供合约上的权利），这是明显更稳固的地位。

分层地契登记册一经开放，**管理机构（Management Corporation，简称 MC）**便会自动成立，由每一位分层单位业主组成。JKPTG 将其描述为一个永续存在的机构，拥有共同产业，并代表全体业主集体执行该发展计划的管理事务——这正是为什么分层生活总是伴随着共同决策（常年大会、附则、管理基金），而这些是有地物业的拥有权完全没有的。

## 分层地契业主实际收到的账单

这正是分层地契在日常开销上与有地物业差别最大、也最让首次购屋者意外之处：一位分层单位业主要向三个不同机构缴付三笔独立费用，而不是一张账单。

| 费用 | 缴给 | 涵盖内容 |
| --- | --- | --- |
| 管理费 | 管理机构 | 共同产业的维护、员工薪酬，以及共用区域的水电等设施费用 |
| 地税（quit rent） | 土地局 | 附加在该分层单位本身的土地税项 |
| 门牌税 | 地方政府 | 与任何房产一样的地方议会服务 |

JKPTG 自己的常见问答明确指出，若略过中间那一项会有什么后果：分层单位业主若未缴付地税，该地段可能被州政府当局充公。有地物业业主同样面对相应的土地局义务，但永远不会有管理费这一层，因为既没有 MC，也没有共同产业需要资助。

## 把两条轴线合在一起看

每一处房产都同时坐落在这两个问题的交汇点上，绝不会只回答其中一个：**永久地契有地物业**排屋没有到期日，也没有 MC；**永久地契分层地契**公寓没有租期的时钟，但仍有 MC 与上述三笔费用；**租赁地契有地物业**洋房没有 MC，但出售时租期与任何州政府批准限制依然适用；**租赁地契分层地契**公寓则同时背负租期时钟与 MC 安排——这是对长期融资与转售影响最大的组合。一则只写着「公寓」或「永久地契」的广告，只回答了一条轴线，另一条得由你自己去问。

## 常见错误

- **以为「分层地契」能告诉你租期长短。** 它不能——分层地契可以是永久地契，也可以是租赁地契；这两项事实各自独立，都需要分别查证。
- **把买卖合约当成拥有权。** 在分层地契发出之前，买家的地位只建立在 S&P 合约的合约权利上，而 JKPTG 自己的指引也标明，这远比一份已登记的地契来得薄弱。
- **忽略地税这一项。** 人们容易只为管理费编列预算，却忘了另外欠土地局的地税——一旦拖欠，地段本身就有风险。
