多くの新規住宅所有者は、存在するとは思ってもみなかった二枚目の請求書を受け取って驚く。今年すでに「地代」を支払ったのに——なぜ今度は市議会から追討通知が届くのか？

答えはこうだ：これは同じ請求書が二度送られてきたのではない。これは二つの異なる機関が、二つの異なる法律のもとで徴収する、まったく別個の二つの税である。一方を支払っても、もう一方の納付義務は消えない。

## 二つの名称、二つの機関

**査定税（assessment、cukai pintu）**——公式の請求書では現在「cukai taksiran」と呼ばれているものの、いまなお広く使われている古い呼称である——は、**地方自治体（PBT）**、すなわち物件が所在する市庁（majlis bandaraya）、市議会（majlis perbandaran）又は県議会（majlis daerah）、たとえばDBKL、MBPJ又はMBIPによって徴収される。

一方、**地代（quit rent、cukai tanah）**は、地方議会ではなく**州土地局（Pejabat Tanah negeri）**によって徴収される。これは、マレーシアの土地が州政府の管轄下にあるのに対し、都市部・農村部のサービスは、州政府が設立するものの連邦法のもとで運営される地方自治体（PBT）の管轄下にあるためである。

この区別は行政上の偶然ではない——それはマレーシアの三つの政府レベル、すなわち連邦・州・地方の間の権限分割を反映している。土地と地方政府がなぜ異なる権限のもとに置かれているのかを理解するには、[連邦・州間の権限分割](/government/federal-state-division)と[マレーシアの三つの政府レベル](/government/three-tiers-of-government)を参照してほしい。

## 査定税：市政サービスへの支払い

PBTが査定税を課す権限は、**1976年地方政府法（Local Government Act 1976、Act 171）**に由来し、これにはs.127の規定が含まれる。同条は、PBTが——州政府当局の承認を得たうえで——その区域内のすべての課税対象保有地にレート（rate）を課すことを認めている。これには、すでに建物が建っている土地だけでなく、空地も含まれる。

レートは、保有地の年間賃貸価値又は改良価値に基づいて計算され、各PBTはそれぞれの州の承認に従って独自のレートを定める——だからこそ、物件の価値が同等であっても、査定税の総額は市議会ごとに異なる。

徴収された資金は、次のような日常的なサービスに充てるPBTの支出をまかなう：

- 道路及び街灯の維持管理
- ごみ収集及び公共清掃
- レクリエーション公園及びコミュニティ施設
- 草刈り及び空地の維持管理

査定税は通常、**年に二回**、半年ごとの二期に分けて課される。たとえば、クアラ・スランゴール市議会（Majlis Perbandaran Kuala Selangor）のもとでは、第一期は3月1日までに、第二期は9月1日までに納付しなければならない。実際の納付期限は各PBTが自ら定めるため、居住地域の正確な期日については、該当する議会が発行する税務通知を確認すること。

## 地代：土地保有権に対する年間の賃料

地代は、まったく異なる基礎に立って機能する。これは州土地局が**1965年国家土地法典（National Land Code 1965）**のもとで徴収するもので、本質的には土地の保有権そのものに対して課される年間の賃料であり——受けたサービスへの対価ではない。

これに関連する国家土地法典の三つの主要な規定：

| 条項 | 定めている内容 |
| --- | --- |
| s.5 | 登録された土地所有者（又はその代理人）はいずれも、地代を納付する責任を負う |
| s.94 | 地代は年に一度、1月1日から5月31日までの期間に納付する |
| s.100 | その期間を過ぎても納付されない場合、土地局は追討通知（Notis 6A）を発することができる；通知後に定められた期間内になお支払われない場合、土地は没収されうる |

1965年国家土地法典は、**マレーシア半島にのみ適用される**。サバとサラワクは、土地及び地方政府に関する独自の法令（enakmen／ordinan）を有しているため、上記の条項はこの両州には直接適用されない。

## 並べて比較する

| | 査定税（cukai taksiran） | 地代（quit rent） |
| --- | --- | --- |
| 徴収機関 | 地方自治体（市庁／市議会／県議会） | 州土地局 |
| 法的根拠 | 1976年地方政府法（Local Government Act 1976、Act 171） | 1965年国家土地法典（マレーシア半島） |
| 課税対象 | 保有地の年間賃貸価値／改良価値（空地を含む） | 土地の保有権 |
| 納付頻度 | 通常は年二回 | 年一回 |
| 税収の用途 | 都市／地方サービス | 州政府への土地賃料 |
| 未納の場合 | 動産の差押えを含むPBTの執行措置 | Notis 6A、その後に土地の没収 |

## よくある誤り

**一方の支払いで両方が済むと考えること。** これが最も多い誤りである——地代の領収書は査定税の支払い証明としては通用せず、その逆もまた然りである。二枚の請求書は、毎年それぞれ別々に確認し、納付する必要がある。

**空地は査定税を免除されると考えること。** PBTの区域内の空地は、その上に建物が建てられていなくても、なお査定税の対象となる。

**地代には厳格な期限があることを忘れること。** 地代の納付期間は、国家土地法典のもとで毎年5月31日に終了する——それを過ぎるとただちに滞納となり、ほかの一部の家計の請求書のような追加の猶予期間はない。

**半島の規定をサバ／サラワクに当てはめること。** サバとサラワクの土地及び地方政府に関する法的枠組みは、国家土地法典やAct 171とは異なる——この両州の土地所有者は、上で論じた規定ではなく、それぞれの州の法令（enakmen／ordinan）を参照する必要がある。
