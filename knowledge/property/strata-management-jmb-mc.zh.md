你买下一个共管公寓单位，但究竟谁拥有电梯、游泳池和停车走道——又是谁有权向你征收每月的费用？答案藏在一层买家往往在纠纷出现前从不细读的治理架构之中：《2013年分层管理法令》（第757号法令）的框架。

第757号法令将马来西亚半岛的分层管理集中到单一制度之中。它废除了此前规管 JMB 的《2007年建筑物及共有产业（维修与管理）法令》（第663号法令）（第153条），并接管共有产业的管理事务——包括此前依《1985年分层地契法令》（第318号法令）而设的管理机构职能。（第318号法令本身并未被废除；它继续规管分层地契的签发与注册。）第757号法令规定了谁来管理共有产业、资金如何征收与开支，以及当邻居或管理方不履行责任时你该向何处求助。

## 谁来管理分层建筑——JMB 还是 MC？

马来西亚的分层居住经历两个治理阶段。第一阶段是**联合管理机构（JMB）**。它依第17(1)条设立，时点在空置管有权（vacant possession）已交予买家、但管理机构尚未成立之际。JMB 是由发展商与各分层单位买家共同运作的临时机构。由买家选出的委员会成员组成依第22条设立的**联合管理委员会（JMC）**。

第二阶段是**管理机构（MC）**。当分层地契以买家名义注册时，MC 自动成立。与 JMB 不同，MC 作为管理主体**不包括发展商**，且权力远为广泛——它可以拥有土地、借款、签订长期合约，并就共有产业起诉与被起诉。

从 JMB 过渡到 MC 不仅是象征性的。JMB 在 MC 首次周年大会（MMP）后**三个月解散**（第27(1)条），并须在首次 MMP 日期起**不超过一个月**内移交维修账户与偿债基金的所有余额、文件、资产及记录（第27(2)(a)条）。若未履行此义务，第28条规定：过渡期届满时，该等余额与权利自动归属于 MC。

| 特征 | JMB（联合管理机构） | MC（管理机构） |
|---|---|---|
| 何时成立 | 空置管有权后、分层地契前（第17(1)条） | 分层地契注册后 |
| 性质 | 临时 / 过渡 | 永久 |
| 发展商是否参与？ | 是，与买家共同 | 否（仅业主机构） |
| 委员会 | 联合管理委员会（JMC），第22条 | 管理委员会（MC Committee） |
| 拥有土地 / 借款权力 | 无 | 有 |
| 可起诉与被起诉 | 有限 | 有，就共有产业而言 |

## 资金如何征收——为何有两个账户？

每个分层管理机构都必须设立**两个独立账户**，两者之间的资金不得混用。

第一个是**维修账户**（第50条）。这是"日常用途"资金——只能用于实际或预期的一般及经常性开支：共有产业的维修、修理、保险、租金、地税、费用及管理收费。

第二个是**偿债基金账户**（*sinking fund*，第51条）。它专门用于重大且周期性的资本开支——重新粉刷建筑、翻新或更换设备、升级与改装共有产业，以及为共有产业用途购置动产。偿债基金**不得**用于一般维修开支。

须缴多少？费用按各分层单位的份额单位比率确定，而偿债基金的缴款则**相当于**维修费的 **10%**（第52(3)条）。MC 大会可议定更高比率，但缴款**不得低于 10%**（第61(3)条）。

| 项目 | 维修账户（第50条） | 偿债基金（第51条） |
|---|---|---|
| 用途 | 一般及经常性开支 | 重大资本 / 周期性开支 |
| 例子 | 公共区域电费、保安工资、保险、小修理 | 重新粉刷建筑、更换电梯、升级泳池 |
| 缴款 | 按分层单位份额 | 相当于费用的 10%（第52(3)条） |
| 可交叉使用？ | 否 | 否 |

如果业主不缴款会怎样？就 MC 下的分层单位而言，若任何款项在 14 天期限后仍未清缴，业主将按**每年 10% 的利率按日计息**直至清缴（第52(5)条）。至于 JMB 期间，利率由 JMB 确定，但**不得超过每年 10%**（第25(6)(b)条）。

## 出现纠纷时该向何处求助？

当费用未缴或管理方不履行职责时，主要论坛并非普通法院，而是**分层管理仲裁庭（SMT）**。它依第757号法令设立，作为一个廉宜、简易且快捷的论坛。

仲裁庭的管辖权规定于第105条，该条援引第四附表第1部分中的索赔清单。其主要特征：

- **索赔上限 RM250,000。** 仲裁庭不得受理金额超过 RM250,000 的索赔（第105(1)条），或任何涉及土地地契或土地权益的纠纷（第105(3)条）。
- **索赔类型**包括拖欠的维修费与偿债基金缴款、召开大会的命令、撤销决议的命令，以及关于履行法令下职能的纠纷（第四附表第1部分）。
- **谁可提交**——发展商、买家、分层单位业主、JMB、MC、管理代理，以及经仲裁庭许可的任何其他利害关系人。
- **一般无律师。** 各方无权由律师代表，除非案件涉及复杂法律问题、且一方在没有代表的情况下将严重受损。
- **裁决快捷。** 仲裁庭须不延迟地作出裁决，并在可能情况下于首次聆讯日起**60 天内**作出（第117(1)条）。

仲裁庭裁决**视为法院命令**，可据此强制执行。若败诉方拒不遵守，该不遵守即构成**第123条下的刑事罪**——罚款不超过 RM250,000 或监禁不超过 3 年或两者兼施，持续违犯者每日另处不超过 RM5,000 罚款。不遵守的投诉向**建筑物专员（COB）**提出，专员拥有调查与检控的权力。

裁决不得循一般途径上诉，但可基于程序不公或严重不当等有限理由在高等法院提出质疑。

## 案例：某共管公寓的欠费

假设某共管公寓的一个 MC 发现一名业主连续八个月未缴维修费，连同迟缴利息共约 RM6,400。此金额远低于 RM250,000 上限，因此 MC 可向分层管理仲裁庭而非民事法院提交索赔——无需聘请律师。若仲裁庭作出有利于 MC 的裁决而业主仍拒缴，MC 可将该裁决作为法院命令强制执行，并另行向 COB 投诉以循第123条检控。

## 接下来该做什么

- 查明你的房产仍由 **JMB 管理还是已过渡到 MC**——这决定谁有权合法征收费用及召开大会。
- 若你是委员会成员，确保**维修账户与偿债基金**真正分开，且偿债基金缴款达到 10% 门槛（第52(3) / 61(3)条）。
- 对于 RM250,000 以下的欠费，在诉诸民事法院前先考虑**分层管理仲裁庭**——更廉宜、更快捷。
- 参阅第757号法令及《2015年分层管理条例》全文，或就执法问题联系你所在地方政府的**建筑物专员（COB）**。
