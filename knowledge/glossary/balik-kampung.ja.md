**Bahasa Malaysia:** Balik Kampung · **English:** Homecoming / Festive Exodus · **中文:** 返乡

大きな祝祭の数日前になると、クアラルンプールとクラン・バレーは静まり返る——オフィスは閉まり、店は板で閉ざされ、通りは静かになる。住民が消えたわけではない。彼らは高速道路の上にいて、家族の原籍地へ向かっているのだ。それが**バリック・カンプン（帰郷、balik kampung）**である。

この言葉は故郷へ帰ることを意味し、特定の一つの民族だけのものではない。マレー系家族はハリラヤの前に、華人系家族は旧正月の前に、インド系家族は[ディーパバリ](/arts-culture/deepavali)の前に、そしてキリスト教徒の家族はクリスマスの前に帰郷する。パターンは同じで、違うのは日付だけである。

## なぜこれほどの規模なのか

主な要因は経済地理にある。雇用はいくつかの都市クラスターに集中する一方、原籍の家族は依然として他の州にとどまっている。2020年マレーシア人口・住宅センサスによれば、マレーシアの人口の**75.1％**が都市部に居住しており、2010年の70.9％から上昇している。

祝祭のたびに、こうした都市住民の多くが日常の通勤とは逆方向へ一斉に移動し——数日後には再び戻ってくる。

## 交通への影響

2026年ハリラヤの公式数値が、その規模を物語っている：

| 項目 | 数値 |
| --- | --- |
| 高速道路ピーク時交通量予測（LLM） | 一日あたり最大350万台 |
| 高速道路沿線に配置された要員（PLUS） | 6,000名 |
| LLMが配置した緊急対応チーム（ERT） | 戦略拠点12カ所 |
| LLMが稼働させたCCTVカメラ | 873台 |
| Op Selamat 26（PDRM） | 2026年3月19日～24日 |
| PDRMの交通警察（URB）およびMPV要員 | 6,132名 |
| 都市部への帰還車流（PLUS） | 一日あたり200万～230万台、2026年3月27日～29日 |

Op SelamatはPDRMによって各祝祭のたびに実施され、ハリラヤに限らない——Op Selamat 25は旧正月に合わせて実施され、事故率、死亡事故率および死亡者数を前回の作戦と比べて少なくとも5％削減することを目標としていた。

## 経済への影響

バリック・カンプンは人だけでなく、消費支出も移動させる。普段は都市部で使われる資金が、数日間にわたって地方の市場、雑貨店、ガソリンスタンド、宿泊施設へと流れ込む。

この季節的効果は公式データにも表れている。DOSMの報告によれば、マレーシアの卸売・小売取引額は**2026年3月にRM169 bilion（1,690億リンギット）**——その年のハリラヤが含まれる月——に達し、前年同月比で9.8％増加し、うち小売販売額はRM72 bilion（720億リンギット）であった。この月次数値は多くの要因に左右されるため、これは季節的な需要パターンを示すものであり、バリック・カンプンの影響のみを表すものではない。

政府は旅費についても介入している。2026年ハリラヤに際し、LLMは**ペナン大橋（Jambatan Pulau Pinang）**において、2026年3月18日00:00:01から3月19日23:59:59まで、クラス1およびクラス2車両を対象に通行料50％割引を発表した。

## よくある誤解

- **ハリラヤだけの行事だと思い込むこと。** Op Selamatは他の祝祭でも実施される——例えばOp Selamat 25は2026年旧正月に合わせて実施された。
- **帰還車流を見落とすこと。** 都市部への帰り道は、行きと同じくらい混雑することがある——PLUS自身、祝祭後の週末には一日あたり200万～230万台の車両を見込んでいる。
- **「kampung（カンプン、村）」を農村と同一視すること。** 今日では多くの人にとって、故郷そのものが他州にある都市である場合も少なくない。
