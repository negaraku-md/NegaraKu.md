**Bahasa Malaysia:** Syariah / Syarak · **English:** Syariah (Islamic law) · **中文:** 伊斯兰教法

「Syariah」是一个术语，并非单一的法庭，也并非单一的法令。在日常对话中，
它指的是伊斯兰教的宗教法律。而在马来西亚法律体系中，这一术语有更精确
的定位：伊斯兰法与Syarak法属于**州事务**，每个州属都透过本身的州法令
与本身的沙里亚法庭来处理。

本文仅依据宪法与成文法文本，以描述性方式说明这一术语及其地位，并不
评论任何案例。

## 州事务，而非联邦事务

《联邦宪法》透过**第九附表（Ninth Schedule）**中的清单，将立法权在国会
与州立法议会之间划分。伊斯兰法属于**州清单item 1**。

该项将伊斯兰法，以及信奉伊斯兰教的人的属人法与家事法——包括继承、
订婚、婚姻、离婚、赡养、监护、赠与（hibah）、wakaf、zakat、fitrah及
baitulmal——连同「沙里亚法庭的组成、组织及程序」，一并纳入州权力范围。

依据**第74条第(2)款**，州立法议会得就州清单内的任何事项立法。因此每
个州属都通过本身的[州法令](/zh/glossary/akta)，各州的沙里亚法庭即在该
州法令下设立。

联邦清单则从相反方向划出同一条界线。联邦清单item 4赋予国会权力，管
辖「**沙里亚法庭以外**所有法院的组成与组织」。换言之，宪法条文本身即
将沙里亚法庭与联邦法院体系分隔开来。

## 沙里亚法庭管辖权的三项限制

item 1不仅赋予权力，也划定了界限。该项规定，沙里亚法庭

> 仅对信奉伊斯兰教的人具有管辖权

且仅限于该项所列明的事项，并对罪行概无管辖权，惟联邦法律所赋予者除外。

三项限制——均载于宪法之中：

| 限制 | 含义 |
| --- | --- |
| **对象** | 仅限信奉伊斯兰教的人 |
| **事项** | 仅限item 1所列明的事项 |
| **罪行** | 仅限联邦法律所赋予者 |

前两项限制具有累加性：某一事项必须既涉及穆斯林，**又**属于该项清单
所列范围。

## 国会所订定的刑事限制

由于item 1规定，沙里亚法庭对罪行概无管辖权，「惟联邦法律所赋予者除
外」，沙里亚法庭的刑事部分因此有赖于一部国会法令：**Akta Mahkamah
Syariah (Bidang Kuasa Jenayah) 1965（Akta 355）**。

Akta 355第2条赋予管辖权，处理信奉伊斯兰教的人违反伊斯兰教义的罪行，
惟须受以下限制：

| 刑罚 | Akta 355第2条下的限制 |
| --- | --- |
| 监禁 | 不超过3年 |
| 罚款 | 不超过RM5,000 |
| 鞭刑 | 不超过6下 |
| 组合 | 以上刑罚在该等限制内的任何组合 |

州法令可订定较低的限制，但不得订定较高的限制，因为该项权力源自联邦
法律。

## 第121条第(1A)款

第121条第(1A)款被纳入宪法，并自**1988年6月10日**起生效。该款规定，
第(1)款所述的法院——即高等法院（民事法庭）——对属于沙里亚法庭管辖
范围内的任何事项，概无管辖权。

该款是针对民事法庭的**管辖权排除条款**。它本身并未界定沙里亚法庭的
管辖权究竟为何——该界定载于item 1及州法令之中（联邦直辖区则载于联
邦法律）。它也未在两个体系之间创设任何上诉途径。

## 每个州属的三级法庭

每个州属都在本身的州法令下，建构相同的三级架构：

| 层级 | 名称 |
| --- | --- |
| 初级 | Mahkamah Rendah Syariah |
| 高等 | Mahkamah Tinggi Syariah |
| 上诉 | Mahkamah Rayuan Syariah |

由于每个州属各自制定本身的州法令，**mal索偿的金额限制与程序细节因
州而异**——这正是为何「沙里亚法庭的限额」从来不是一个全国统一的数
字。全国统一的只有Akta 355中的刑事限制。

在全国层面，**Jabatan Kehakiman Syariah Malaysia（马来西亚沙里亚司法
厅，JKSM）**——首相署属下的一个机构——协调并统一伊斯兰法律与沙里亚
司法的行政。它负责协调；它并非凌驾于各州法庭之上的法庭。

## 联邦直辖区的例外

item 1开头即有一项例外：它不适用于吉隆坡、纳闽和布城联邦直辖区。在
该处，由于没有州立法议会，沙里亚法庭是依**联邦**法律设立的——即
**Akta Pentadbiran Undang-Undang Islam (Wilayah-Wilayah Persekutuan)
1993（Akta 505）**。

## 常见误解

**「Syariah是指全国单一的一个法庭。」** 不是。每个州属都依本身的州
法令设立本身的沙里亚法庭；JKSM协调行政事务，而非全国最高的法庭。

**「沙里亚法庭可审理任何涉及穆斯林的争议。」** item 1施加两项累加性
限制——须为信奉伊斯兰教的人，**且**仅限于该项内的事项。清单之外的
事项不属其管辖范围。

**「第121条第(1A)款使沙里亚法庭高于民事法庭。」** 该款是针对民事法
庭的管辖权排除条款。它并未提及位阶，也未在item 1的事项清单上增添
任何内容。

**「每个州属的刑罚限制相同。」** Akta 355中的刑事限制是全国性的；
mal的金额限制、条文引用与程序则是逐州订定的。
