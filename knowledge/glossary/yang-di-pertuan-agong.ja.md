**Bahasa Malaysia:** Yang di-Pertuan Agong · **English:** The King of Malaysia (Supreme Head of the Federation) · **中文:** 最高元首

マレーシアの連邦の王位は世襲ではない。それは提呈されるものである。

五年ごとに、統治者会議が開かれ、憲法に定める名簿の順序に従い、ある統治者
に国王（Yang di-Pertuan Agong）の職が提呈される。選挙運動もなければ、公
開の候補者もなく、統治者自身以外に投票者はいない。用いられる投票用紙は番
号を付されず、同一のペンと墨で印を付けたのち、投票箱に投じられる。

この枠組みは[連邦憲法](/law/federal-constitution)第32条及び第三附表
（Third Schedule）に定められている——そして、これは[1957年のメルデカ
（独立）](/malaysia/independence-1957)以来、一度も途切れることなく続いて
いる。

## 概要

| | |
| --- | --- |
| 憲法上の称号 | 連邦最高元首、国王（Yang di-Pertuan Agong）と称される（第32(1)条） |
| 王妃 | ラジャ・プルマイスリ・アゴン（王妃）（第32(2)条） |
| 選出者 | 統治者会議（第32(3)条） |
| 任期 | 5年（第32(3)条） |
| 選出規則 | 第三附表第一部；罷免は第三部に基づく（第32(4)条） |
| 被選資格の範囲 | 九人のマレー統治者 |
| 会議書記 | 統治者御璽守護官（Penyimpan Mohor Besar Raja-Raja）（第五附表第4節） |
| 就任宣誓 | 第37条、統治者会議の前で行う |
| 現在の在位者 | スルタン・イブラヒム・イブニ・アルマルフム・スルタン・イスカンダル（ジョホール）、第17代国王、2024年1月31日より |

## 誰が選出し、誰が選出しないか

統治者会議は第38(1)条に基づき設置され、第五附表に従って構成される。その
完全な構成員は、九人の統治者と、統治者を有しない州の四人の州元首（Yang
di-Pertua Negeri）から成る。

しかし、選出の事務に関しては、構成員の範囲は狭まる。第五附表第7節は、国
王の選出若しくは罷免、又は副国王（Timbalan Yang di-Pertuan Agong）の選出
に関するいかなる手続の目的についても、州元首は会議の構成員と**ならない**
と定めている。

したがって、その場にいるのは九人の統治者のみである。さらに第38(6)(a)条
は、会議の構成員は選出及び罷免の手続において、自らの裁量により行動する
ことができる——すなわち、州首相（Menteri Besar）又は内閣（Jemaah
Menteri）の助言によらずに——と定めている。

統治者御璽守護官は会議の書記として行動し（第五附表第4節）、国王の任期満
了の4週間前までに、また欠員が生じた場合には（第6節）、会議を招集しなけ
ればならない。

## 選出名簿はどのように動くか

ここは最も誤解されやすい部分である。輪番は一度定められれば永久に固定さ
れるものではなく、選出のたびに改めて計算し直される。

第三附表第4節がその仕組みを定めている。

- **最初の名簿（1957年）**は、当時統治者たちが互いの間で認め合っていた優
  先順位に従って編成された——第4(1)(a)節。
- **選出のたびに**、選出された統治者の州より前にある州は名簿の末尾に移さ
  れ、その選出された統治者の州は名簿から外される——第4(2)(a)節。
- **名簿に残っている州で統治者の交代が生じた場合**、その州は名簿の末尾に
  移される——第4(2)(b)節。
- **名簿が尽きたとき**、すべての統治者の州を再び組み入れるよう編成し直さ
  れるが、その順序は当該州の統治者が国王の職に就いた順による——第4(3)節。

第4(3)節のこの効果こそが、第一巡の順序を繰り返す第二巡を生み出している。
第10節は、第4(3)節の目的上、「統治者」という語には元統治者も含まれると
明らかにしている。

## 選出会議の中で

第三附表第2節はその手順を明確に定めている。統治者会議は、名簿の中で州が
最初にある、被選資格を有する統治者にその職を**提呈しなければならない**。
その統治者が受諾しない場合、提呈は次の州の統治者に対して行われ、ある統治
者がその職を受諾するまでこれが繰り返される。

統治者会議の公式ポータルは、その会議の手続を詳細に定めている。

| 手順 | 内容 |
| --- | --- |
| 投票用紙 | 番号は付されず、同一のペンと墨で印を付けたのち、投票箱に投じられる |
| 投票者 | 統治者のみが投票できる |
| 投票の形式 | 統治者御璽守護官が、一人の候補者名のみを記載した投票用紙を配布し、賛否を問う |
| 閾値 | 候補者が5票の多数を得て初めて、会議を主宰する統治者がその職を候補者に提呈する |
| 集計 | 在位期間が最も短く、候補者として名簿に載っていない統治者が、統治者御璽守護官とともに投票用紙を集計する |
| その後 | 投票用紙は統治者の面前で廃棄される |

提呈が受諾されると、第3節は会議がその統治者を選出された者として宣言する
ことを求め、統治者御璽守護官はその決定を書面で[国会](/government/parliament)
の両院に通知する。

その職務を行う前に、第37(1)条は、国王が第四附表第一部に定める就任宣誓
を、統治者会議の前で、かつ連邦裁判所首席判事の立会いのもとで、宣誓し署
名することを求めている。

## 資格と任期

第三附表第1(1)節は、統治者が選出される資格を有するのは、**次のいずれに
も該当しない場合に限る**と定めている——その統治者が成年に達していない場
合、その統治者が統治者御璽守護官に対し選出されることを望まない旨を通知
した場合、又は統治者会議が秘密投票により、その統治者が精神若しくは身体
の欠陥、又はその他の理由により、その職務の遂行に適さないと決議した場合
である。このような決議には、会議の少なくとも五人の構成員の支持が必要で
ある（第1(2)節）。

第32(3)条は、任期が満5年に達する前に終了しうる三つの方法を定めている。
すなわち、自ら署名し統治者会議宛てに提出する書面による辞任、統治者会議
による罷免、又は統治者でなくなったときである。第三附表第三部に基づく罷
免の決議もまた、会議の少なくとも五人の構成員の支持を必要とする。

また、第33条に基づく副国王（Timbalan Yang di-Pertuan Agong）の職も存在
し、統治者会議が第三附表第二部に従って選出し、国王が欠位又は不在のとき
にその職務を行う。

## 憲法上の職務

第39条は、連邦の行政権を国王に帰属させている。第40(1)条は、その職務の遂
行にあたり、国王は内閣（Jemaah Menteri）の助言に従って行動すると定め、
第40(1A)条は、憲法が国王に助言に従って行動することを求める場合、国王は
その助言を受け入れ、これに従って行動しなければならないと確認している。

| 職能 | 規定 |
| --- | --- |
| 首相を任命する——その判断において下院の多数の信任を得られる可能性がある下院議員 | 第43(2)(a)条 |
| 首相の助言により他の大臣を任命する | 第43(2)(b)条 |
| 国会を招集し、休会させ、及び解散する | 第55(1)条及び第55(2)条 |
| 30日以内に法案を裁可する；そうしない場合でも、法案はそのまま法律となる | 第66(4)条及び第66(4A)条 |
| 連邦軍の最高司令官 | 第41条 |
| 軍法会議による罪、並びにクアラルンプール、ラブアン及びプトラジャヤの連邦直轄区における罪に対する恩赦権 | 第42(1)条 |
| クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区におけるイスラム教の首長 | 第3(5)条 |
| それぞれの州憲法に従い、マラッカ、ペナン、サバ及びサラワクにおけるイスラム教の首長 | 第3(3)条 |
| 連邦国璽を保管し、使用する | 第36条 |

第40(2)条は、国王がその裁量により行使できる職能を列挙している。すなわ
ち、首相を任命すること、国会解散の請求に対する裁可を留保すること、そし
て専ら統治者の特権、地位、栄誉及び威厳にのみ関わる統治者会議の招集を求
めることである。

## 在職中の制限

第34条は、国王が在職中に受ける若干の制限を定めている。

- 自州の統治者としての職務を行わない。ただしイスラム教の首長としての職
  務は除く——第34(1)条。
- 報酬を伴ういかなる職も保持しない——第34(2)条。
- いかなる商業活動にも積極的に関与しない——第34(3)条。
- 自州の統治者として自身に支払われるべき手当を受け取らない——第34(4)条。
- 国事訪問中を除き、統治者会議の同意なしに15日を超えて連邦を離れない—
  —第34(5)条。

第32(1)条はまた、第十五部に基づき設置される特別法廷（Mahkamah Khas）を
除き、いかなる裁判所においても国王に対して訴訟手続を提起することができ
ないと定めている。第33A条は、国王がその特別法廷において罪に問われた場
合、国王は国王としての職務の遂行を停止し、その期間もなお五年の任期の一
部として計算されると定めている。

## よくある誤解

**「輪番は自動的である。」** 誤りである。第三附表第2節は*提呈する*という
語を用いている。統治者はその提呈を受諾しないことができ、提呈はその後、
名簿上の次の州へと移る。第1(1)(b)節はまた、統治者が統治者御璽守護官に対
し選出されることを望まない旨を通知することも認めている。

**「十三州すべてが輪番に加わる。」** 誤りである。名簿にあるのは、統治者
を有する九州のみである。マラッカ、ペナン、サバ及びサラワクの州元首は、
被選資格を有せず、その選出において投票することもない（第五附表第7節）。

**「国王は自州の統治者でなくなる。」** 誤りである。国王は自州の統治者で
あり続ける——それどころか、第32(3)条は、統治者でなくなったときに国王の
職を退くと定めている。制限されているのは、連邦の職に就いている間におけ
る、自州の職務の*遂行*である（第34(1)条）。

**「アゴンが完全な称号である。」** 完全な憲法上の称号は国王（Yang
di-Pertuan Agong）であり、その王妃はラジャ・プルマイスリ・アゴンと称さ
れる（第32(1)条及び第32(2)条）。

**「法案は裁可なしには法律となり得ない。」** 第66(4)条は裁可のための30
日という期間を定めており、第66(4A)条は、その期間が経過した場合、当該法
案はあたかも裁可されたかのようにそのまま法律となると定めている。

## 次に読むべきもの

この職位が国家の構造の中でどのように位置づけられるかを理解するには、
[連邦憲法](/law/federal-constitution)と[マレーシア国会](/government/parliament)
を読んでほしい。九つのマレー州の連邦がどのように形成され、その後拡大し
たかという歴史的背景については、[1957年のメルデカ（独立）](/malaysia/independence-1957)
と[1963年のマレーシア結成](/malaysia/formation-of-malaysia-1963)を参照
のこと。

本ページにおける各引用の効力を有するテキストは、総検察庁（Jabatan
Peguam Negara）が発行する連邦憲法そのものである。選出会議の手続について
は、統治者会議がその公式ポータルにおいて公表している。
