**Bahasa Malaysia:** Berhad · **English:** Public Limited Company · **中文:** 大众有限公司

当你看到马来西亚公司名称末尾的「Bhd」——马来亚银行的 Malayan Banking Berhad、Public Bank Berhad、Tenaga Nasional Berhad——你面对的是一家获准向陌生人出售股份的公司。正是这一项许可，把 Berhad 与远为常见的 Sdn Bhd 区分开来，也正因如此，Berhad 要在一套更沉重的规则下运作。

「Berhad」不过是马来语中「有限」一词。它标示《2016年公司法》（Act 777）下的**大众有限公司**，该法由马来西亚公司委员会（SSM）管理。与其私人公司同类一样，Berhad 是一个独立法人，可以拥有财产、签订合同、起诉与被诉，其成员的责任以其股份的未缴款额为限。

## 是什么使一家公司成为「Berhad」而非「Sdn Bhd」？

《2016年公司法》以一个问题划出界线：公司能否邀请一般公众成为股东？**私人公司**（Sendirian Berhad）不能。第42(1)条将私人公司定义为股份有限、成员不超过50人的公司，第42(2)条要求其限制股份转让。第43(1)条更进一步——私人公司不得向公众发售其股份或债券，也不得邀请公众向其存款。

**大众公司**则不受上述任何限制。它的成员人数没有法定上限，其股份可自由转让，并可向公众募集资金。作为交换，它须遵守更严格的治理要求。

| 特征 | Sdn Bhd（私人） | Berhad（大众） |
| --- | --- | --- |
| 名称结尾 | 「Sendirian Berhad」/「Sdn. Bhd.」 | 「Berhad」/「Bhd.」 |
| 成员上限 | 50（第42(1)条） | 无上限 |
| 向公众发售股份 | 禁止（第43(1)条） | 允许 |
| 股份转让 | 受限制（第42(2)条） | 可自由转让 |
| 最少董事人数 | 1名居籍董事（第196(1)条） | 2名居籍董事（第196(1)条） |
| 可在马来西亚交易所上市 | 否 | 可（若符合条件） |

两种形式注册成立时都至少需要一名成员——《2016年公司法》要求每家公司都有一名或以上成员（第9(b)条），这一要求对大众公司与私人公司同等适用——两者都必须委任一名持牌公司秘书。结构上的差异，源于谁被允许持有股份。

## 公司为什么会成为 Berhad？

大多数马来西亚企业从不需要这么做。Sdn Bhd 之所以是默认工具，正因其私人属性能保持所有权集中、合规负担较轻。当一家公司想做私人公司在法律上不能做的事——从广泛的外部投资者群体募集资金，或在证券交易所上市——它便会转换为、或直接注册成立为 Berhad。

上市不只是改个名字。私人公司转换为大众公司时，通常须通过成员特别决议、采用以「Berhad」结尾的名称，并向 SSM 呈报所需文件。自此，公司必须配备两名或以上居籍董事、披露更多信息，若打算募集资金，还须为要求高得多的公开发售流程做准备。

有一点值得强调，因为它常令人误解：**Berhad 并不自动等于上市公司。**许多大众公司——大型集团内的子公司、控股公司，以及以私募方式募资的企业——都带着「Bhd」，却从未在马来西亚交易所交易。上市是另一个独立的步骤。

## Berhad 要在马来西亚交易所上市需要什么？

只有大众公司才能上市。对于**主板**上市，**马来西亚证券监督委员会（SC）**依据《2007年资本市场与服务法》第212条审查并批准上市建议书，对照 SC 的《股本指南》加以核查，并审查董事及主要股东。任何向公众发售股份的行为都必须通过**招股说明书**进行：主板 IPO 的招股说明书由 SC 登记，而 ACE 市场 IPO 的招股说明书自2022年1月1日起由马来西亚交易所登记。随后由**马来西亚交易所**接纳该公司上市，并持续执行其上市要求。

公司还须跨过财务与股权门槛。主板申请人通常须符合两项测试之一：

| 主板上市测试 | 门槛 |
| --- | --- |
| 盈利测试——3至5个财政年度的税后盈利总额 | 至少 RM2000万 |
| 盈利测试——最近一年的税后盈利 | 至少 RM600万 |
| 市值测试——上市时的总市值 | 至少 RM5亿 |
| 公众持股分布 | 至少占已上市股份的25%，其中至少一半分配予土著投资者 |
| 最少公众股东人数 | 至少1,000人，每人持有100股或以上 |
| 最低 IPO 价格（主板） | 每股 RM0.50 |

规模较小、处于较早阶段的公司则在马来西亚交易所的**ACE 市场**募集资金。自2022年1月1日起，马来西亚交易所——而非 SC——成为 ACE 市场 IPO 的一站式中心，审查并登记其招股说明书，且 ACE 市场适用比主板更宽松的上市条件。在任何情况下，上市的实体都是一家大众公司——即 Berhad。

## 谁监管 Berhad？

有两个机构相关，它们分管不同的领域：

- **马来西亚公司委员会（SSM）**——管理《2016年公司法》。它规范公司注册、「Berhad」名称、董事、周年申报表，以及适用于每家公司（无论是否上市）的公司法义务。
- **马来西亚证券监督委员会（SC）**与**马来西亚交易所**——一旦 Berhad 想向公众发售证券或上市，便由它们接手。SC 监管资本市场，并依据《2007年资本市场与服务法》批准主板上市；马来西亚交易所经营交易所及其上市要求，自2022年1月1日起也是 ACE 市场 IPO 的批准机构及其招股说明书的登记机构。

一家从不进入市场的大众公司只须向 SSM 负责。一旦它寻求公众资金，SC 与马来西亚交易所便一同介入。
