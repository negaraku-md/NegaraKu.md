**Bahasa Malaysia:** Syariah / Syarak · **English:** Syariah (Islamic law) · **中文:** 伊斯兰教法

「シャリア（イスラム法）」は一つの用語であって、単一の裁判所を指すもの
でもなく、単一の法令を指すものでもない。日常の会話では、イスラム教の
宗教法を意味する。しかしマレーシアの法体系においては、この用語はより
正確な位置づけを持つ——イスラム法及びシャリア法は**州事務**であり、各
州はそれぞれ独自の州法令と独自のシャリア裁判所を通じてこれを管理して
いる。

本稿は、憲法及び制定法の条文のみに基づき、この用語とその位置づけを記
述的に説明するものであり、いかなる判例についても論評しない。

## 州事務であり、連邦事務ではない

連邦憲法は、**第九附則**の中の各リストを通じて、立法権限を国会と州立
法議会との間で分けている。イスラム法は**第九附則州リスト（List II item
1）**に属する。

この項は、イスラム法、並びにムスリムの身分・家族法——相続、婚約、婚
姻、離婚、扶養、監護、贈与（hibah）、wakaf、zakat、fitrah及びbaitulmal
を含む——を州の権限に置いており、これに加えて「シャリア裁判所の設置、
組織及び手続」もそこに含まれる。

**連邦憲法第74条(2)**のもとで、州立法議会は州リストに含まれる事項につ
いて法律を制定することができる。したがって各州はそれぞれ独自の[州法
令](/glossary/akta)を可決し、各州のシャリア裁判所はその州法令のもとで
存在する。

連邦リストは、同じ境界線を反対の方向から引いている。連邦リストitem 4
は、国会に対し「**シャリア裁判所を除く**すべての裁判所の設置及び組織」
に関する権限を与えている。言い換えれば、憲法の条文自体が、シャリア裁
判所を連邦の裁判所制度から切り離しているのである。

## シャリア裁判所の管轄権における三つの制限

item 1は単に権限を与えるだけではなく、境界も定めている。同項は、シャ
リア裁判所が

> ムスリムに対してのみ管轄権を有する

と定め、かつ同項に列挙された事項についてのみ、そして連邦法律により与
えられた範囲を除き犯罪について管轄権を有しないと定めている。

三つの制限——いずれも憲法に明記されている。

| 制限 | 内容 |
| --- | --- |
| **対象** | ムスリムに限る |
| **事項** | item 1に列挙された事項に限る |
| **犯罪** | 連邦法律により与えられた範囲に限る |

最初の二つの制限は累積的である。ある事項は、ムスリムに関わるもの**で
あり**、かつ同項の一覧に含まれるものでなければならない。

## 国会が定めた刑事上の制限

item 1は、シャリア裁判所が「連邦法律により与えられた範囲を除き」犯罪
について管轄権を有しないと定めているため、シャリア裁判所の刑事部分は
一つの国会法令——**Akta Mahkamah Syariah (Bidang Kuasa Jenayah) 1965
（Akta 355）**——に依拠している。

Akta 355 s.2は、その宗教（イスラム教）を信奉する者によるイスラムの
教えに反する犯罪について管轄権を与えており、以下の制限に服する。

| 刑罰 | Akta 355 s.2のもとでの制限 |
| --- | --- |
| 禁錮 | 3年を超えない |
| 罰金 | RM5,000を超えない |
| 鞭刑 | 6回を超えない |
| 組合 | 上記の刑罰のいずれかの組合せ（当該制限内） |

州法令はこれより低い制限を定めることはできるが、これより高い制限を定
めることはできない。なぜなら、その権限は連邦法律に由来するからである。

## 第121条(1A)

第121条(1A)は憲法に挿入され、**1988年6月10日**に施行された。同項は、
(1)項に定める裁判所——すなわち高等法院（民事裁判所）——が、シャリア
裁判所の管轄権に属するいかなる事項についても管轄権を有しないと定めて
いる。

この項は、民事裁判所に向けられた**管轄権の除外規定**である。この項そ
れ自体がシャリア裁判所の管轄権が何であるかを定めているわけではない
——その定義はitem 1及び各州の州法令（連邦直轄区については連邦法律）
の中にある。またこの項は、両制度の間に上訴の経路を設けるものでもない。

## 各州における三審級の裁判所

各州は、それぞれ独自の州法令のもとで、同様の三審級の形を構築している。

| 審級 | 名称 |
| --- | --- |
| 下級 | Mahkamah Rendah Syariah |
| 上級 | Mahkamah Tinggi Syariah |
| 上訴審 | Mahkamah Rayuan Syariah |

各州がそれぞれ独自の州法令を制定するため、**mal（民事）請求の金額限度
及び手続の細目は州によって異なる**——これが、「シャリア裁判所の限度
額」が全国共通の単一の数字となったことがない理由である。全国的に統一
されているのは、Akta 355における刑事上の制限のみである。

全国レベルでは、首相府傘下の機関である**Jabatan Kehakiman Syariah
Malaysia（JKSM）**が、シャリア法及びシャリア司法の運営を調整し、標準
化している。JKSMは調整を行うものであり、各州の裁判所の上に立つ一つの
裁判所ではない。

## 連邦直轄区の例外

item 1は一つの例外から始まる——それはクアラルンプール、ラブアン及び
プトラジャヤの連邦直轄区には適用されない。これらの地域には州立法議会
が存在しないため、シャリア裁判所は**連邦**法律——**Akta Pentadbiran
Undang-Undang Islam (Wilayah-Wilayah Persekutuan) 1993（Akta 505）**
——によって設置されている。

## よくある誤解

**「シャリアとは全国単一の裁判所を意味する。」** 誤りである。各州はそ
れぞれ独自の州法令のもとで独自のシャリア裁判所を設置している。JKSMは
行政を調整するのであって、国の最高裁判所となるものではない。

**「シャリア裁判所はムスリムが関わるいかなる紛争も審理できる。」**
item 1は二つの累積的な制限を課している——ムスリムであること、**かつ**
同項に含まれる事項のみであることである。この一覧の外にある事項は、そ
の管轄権の外にある。

**「第121条(1A)はシャリア裁判所を民事裁判所より上位にする。」** この
項は、民事裁判所に向けられた管轄権の除外規定である。序列については何
も述べておらず、item 1の事項の一覧に何かを付け加えるものでもない。

**「すべての州は同じ刑罰の制限を有する。」** Akta 355における刑事上の
制限は全国的なものであるが、mal（民事）の金額限度、条文の参照及び手
続は州ごとに定められている。
