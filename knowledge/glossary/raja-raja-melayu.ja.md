年に一度、九人の統治者と四人の州元首（Yang di-Pertua Negeri）がクアラルンプールのある会議室に集まり、国会には下せない決定を行う——その一つが、誰が連邦君主になるかを選ぶことである。この会合が統治者会議（Majlis Raja-Raja）であり、そこに名を連ねる統治者たちはマレー統治者（Raja-Raja Melayu）として知られている。

## マレー統治者とは誰か

「マレー統治者（Raja-Raja Melayu）」とは、マレーシアのマレー諸州における九人の世襲の統治者を指す。各州はそれぞれ独自の称号を君主に用いているため、ここでの「Raja（統治者）」という語は、統一された一つの称号ではなく、君主を戴く州の元首一般を意味する。

九つの君主制州とその君主の称号は次のとおりである。

| 州 | 君主の称号 |
| --- | --- |
| ジョホール | スルタン |
| ケダ | スルタン |
| クランタン | スルタン |
| パハン | スルタン |
| ペラ | スルタン |
| セランゴール | スルタン |
| トレンガヌ | スルタン |
| ヌグリ・スンビラン | 最高元首（Yang di-Pertuan Besar） |
| パーリス | ラジャ（Raja） |

他の四州——マラッカ、ペナン、サバ及びサラワク——には君主が存在しない。これらの州は、任命された州元首（Yang di-Pertua Negeri）によって統治される。この二つの集団——九人の統治者と四人の州元首——が、共に統治者会議を構成する。

## 統治者会議とは何か、そして国王とどう異なるのか

統治者会議は、統治者と州元首が集い協議する公式の機関である。これは連邦憲法第38条に規定されており、その詳細な機能はFifth Schedule（第五附則）に列挙されている。

ここで重要な区別を明らかにしておく必要がある。国王（Yang di-Pertuan Agong）は*一人の個人*である——連邦憲法第32(3)条に基づき、統治者会議によって五年の任期で選出される連邦君主である。これに対し、統治者会議は*集団的な機関*である。統治者会議書記局が詳述するとおり、憲法のThird Schedule（第三附則）の手続に従い、統治者会議こそが九人のマレー統治者の中から国王及び副国王（Timbalan Yang di-Pertuan Agong）を選出する。言い換えれば、国王とは、連邦の最高位の職に就くよう推挙された会議の一員なのである。

統治者会議書記局によれば、国王の選出に参加できるのは現に統治している統治者のみであり、統治者が自らに代わって投票する代理人を送ることは認められない。

## この制度はどのように形成されたのか

統治者会議の起源は、1897年7月13日にクアラ・カンサー（Kuala Kangsar）で開かれた最初のドゥルバー（Durbar）に遡ることができる。これには、ペラ、パハン、セランゴール及びヌグリ・スンビランの四人のマレー統治者が出席した。

現代の形をとる会議は1948年に正式に設立され、マレー連合州統治者会議（ドゥルバー）に取って代わった。これは1948年2月1日に発効したマラヤ連邦協定（Persekutuan Tanah Melayu Agreement）に基づいて構成され、その第一回会議は1948年2月18日に開催された。

会議の構成は、国家の変遷とともに拡大してきた。

- **1948年～1957年：** 九人のマレー統治者で構成され、マラヤ連邦の統治について協議し、英国高等弁務官（Pesuruhjaya Tinggi British）に助言を行った。
- **1957年8月31日以降：** 独立後、ペナン及びマラッカの州元首（知事、Gabenor）が会議に加わった。
- **1963年9月16日以降：** マレーシアの成立に伴い、サバ及びサラワクの州元首も会議に加わった。

## 統治者会議の機能は何か

統治者会議は、他のいかなる機関も担わない、いくつかの憲法上の機能を有する。その主なものは以下のとおりである。

- **国家元首の選出。** 国王及び副国王を選出する。
- **統治者の特権に関する御裁可。** 統治者の特権、地位、栄誉又は威厳に関わる法律は、会議の同意なしには可決され得ない。
- **宗教に関する事項。** 連邦全体に及ぶ宗教上の行為、慣行又は儀式について、同意するか否かを決定する。
- **特別な地位。** マレー人及びブミプトラの特別な地位に関わる第153条に基づく政策変更の前には、会議に諮問される。
- **国家政策の審議。** 第38(2)条に基づき、国家政策の問題及びその他会議が適切と考える事項について審議することができる。
- **任命。** 会議の同意を要する特定の任命について助言を行うほか、第182条に基づき特別法廷（Mahkamah Khas）の構成員を任命し、軍事評議会（Majlis Angkatan Tentera）や[国語・文学局（Dewan Bahasa dan Pustaka）](/arts-culture/dewan-bahasa-dan-pustaka)理事会などの機関への代表を任命する。
- **恩赦権。** 特定の事案において、恩赦、減刑及び刑の軽減を行う。

マレーシア弁護士会（Majlis Peguam Malaysia）の記録によれば、憲法は第38(6)条に基づき国王を罷免する権限も定めているが、同記録によればこの権限はこれまで行使されたことがない。

## 会議はどのように運営されるのか

会議は年に三回開催されるほか、国王の要請により召集されることもある。統治者会議書記局によれば、議長職は九人のマレー統治者の間で輪番により務められる。

会議の事務局は統治者会議書記局であり、第一回会議にあわせて1948年に設立された。統治者会議書記長は会議の書記としての役割を担う。その中でも一般に最もよく知られている役割は、ラマダン（断食月）の開始、並びにアイディルフィトリ及びアイディルアドハ（ハリラヤ・ハジ）の日付を発表することであり、新月の観測のためにマレーシア全土で29か所の地点が定められている。

会議の議事において通例取り上げられる事項には、任命、国防、国家の安全保障及び宗教に関する問題が含まれる。

## 会議の役割はどのように理解されているか
