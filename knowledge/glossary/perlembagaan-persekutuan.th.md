**Bahasa Malaysia:** Perlembagaan Persekutuan · **English:** Federal Constitution · **中文:** 联邦宪法

อักตาฉบับหนึ่งผ่านความเห็นชอบจากรัฐสภาได้ด้วยคะแนนเสียงข้างมากธรรมดา แต่อักตานั้นก็ยังอยู่ภายใต้เอกสารฉบับหนึ่งที่สูงกว่า — และหากมันไม่สอดคล้องกับเอกสารนั้น อักตาก็เป็นโมฆะเท่าที่ไม่สอดคล้องนั้น

เอกสารนั้นคือ **รัฐธรรมนูญแห่งสหพันธรัฐ (Perlembagaan Persekutuan)** มาตรา 4 ประกาศว่ามันเป็นกฎหมายสูงสุดของมาเลเซีย และสถานะนั้นเองที่ทำให้มันแตกต่างจาก [อักตา](/th/glossary/akta) อื่นทุกฉบับในระบบกฎหมายของประเทศ

## ภาพรวมโดยสังเขป

| | |
| --- | --- |
| ชื่อเต็ม | รัฐธรรมนูญแห่งสหพันธรัฐ (Federal Constitution) |
| ประเภท | กฎหมายสูงสุดของสหพันธรัฐ |
| มีผลบังคับใช้ตั้งแต่ | 31 สิงหาคม 1957 (ในฐานะรัฐธรรมนูญแห่งสหพันธรัฐมลายา) ขยายเมื่อมาเลเซียก่อตั้งขึ้นในวันที่ 16 กันยายน 1963 |
| สถานะ | มาตรา 4(1): กฎหมายสูงสุดของสหพันธรัฐ กฎหมายที่ไม่สอดคล้องเป็นโมฆะเท่าที่ไม่สอดคล้องนั้น |

| ตีความและใช้บังคับโดย | ศาล |

## "กฎหมายสูงสุด" หมายถึงอะไร

มาตรา 4(1) กำหนดว่ารัฐธรรมนูญนี้เป็นกฎหมายสูงสุดของสหพันธรัฐ และกฎหมายใด ๆ ที่ผ่านความเห็นชอบหลังวันเมอร์เดกาซึ่งไม่สอดคล้องกับรัฐธรรมนูญเป็น **โมฆะเท่าที่ไม่สอดคล้อง** นั้น

ผลก็คือ กฎหมายอื่นทั้งหมดในมาเลเซียยืนอยู่ **ใต้** รัฐธรรมนูญ ไม่ใช่เทียบเท่ากับมัน:

- **อักตา** ที่ผ่านความเห็นชอบจากรัฐสภาต้องเป็นไปตามรัฐธรรมนูญ
- **เอนัคเมน** ที่ผ่านความเห็นชอบจากสภานิติบัญญัติแห่งรัฐก็อยู่ภายใต้รัฐธรรมนูญด้วย นอกเหนือจากการแบ่งอำนาจที่รัฐธรรมนูญกำหนด
- **อนุบัญญัติ** เช่นกฎและระเบียบจะเกินขอบเขตที่รัฐธรรมนูญและอักตาแม่บทอนุญาตไม่ได้

ศาลเป็นผู้ตีความและใช้บังคับรัฐธรรมนูญเมื่อเกิดคำถามว่ากฎหมายหรือการกระทำหนึ่งเป็นไปตามบทบัญญัติของรัฐธรรมนูญหรือไม่

## มันต่างจากอักตาอย่างไร

ความแตกต่างที่สำคัญที่สุดคือ **วิธีที่มันผ่านความเห็นชอบและถูกแก้ไข**

| | อักตาทั่วไป | รัฐธรรมนูญแห่งสหพันธรัฐ |
| --- | --- | --- |
| สถานะ | กฎหมายทั่วไปของสหพันธรัฐ | กฎหมายสูงสุด (มาตรา 4) |
| ผ่าน/แก้ไขด้วย | เสียงข้างมากธรรมดาในทั้งสองสภา | โดยทั่วไปสองในสามของจำนวนสมาชิกทั้งหมดของแต่ละสภาของรัฐสภา (มาตรา 159) |
| ความสัมพันธ์ระหว่างกัน | ต้องสอดคล้องกับรัฐธรรมนูญ | ยืนอยู่เหนืออักตาทั้งหมด |
| ผลหากไม่สอดคล้อง | เป็นโมฆะเท่าที่ไม่สอดคล้องกับรัฐธรรมนูญ | — |

เนื่องจากรัฐธรรมนูญกำหนดเกณฑ์คะแนนที่สูงกว่าสำหรับการแก้ไข มันจึงเปลี่ยนแปลงได้ไม่ง่ายเท่ากฎหมายทั่วไป นี่คือความหมายของ "ความแข็งตัว" (*rigidity*) ของรัฐธรรมนูญลายลักษณ์อักษร

## รัฐธรรมนูญแก้ไขอย่างไร

มาตรา 159 กำหนดกระบวนการแก้ไข ไม่ใช่กฎเกณฑ์เดียว ช่องทางที่ใช้ขึ้นอยู่กับบทบัญญัติที่จะเปลี่ยน เมื่ออ่านควบคู่กับมาตรา 161E จะมีช่องทางที่แยกจากกันหลายช่องทาง:

| ช่องทาง | เงื่อนไข | บทบัญญัติ |
| --- | --- | --- |
| ปริยาย (การแก้ไขส่วนใหญ่) | คะแนนไม่น้อยกว่าสองในสามของจำนวนสมาชิกทั้งหมดของแต่ละสภาในการอ่านครั้งที่สองและครั้งที่สาม | มาตรา 159(3) |
| เบา (รายการทางเทคนิคที่จำกัด) | เสียงข้างมากธรรมดาเท่านั้น เช่นเดียวกับกฎหมายทั่วไป | มาตรา 159(4) |
| หนักกว่า (เรื่องเฉพาะ) | สองในสาม **พร้อมกับ** ความยินยอมของสภาราชา | มาตรา 159(5) |
| หนักกว่า (เรื่องซาบาห์/ซาราวัก) | สองในสาม **พร้อมกับ** ความยินยอมของยังดีเปอร์ตัวเนอเกอรีของซาบาห์หรือซาราวักที่เกี่ยวข้อง | มาตรา 161E(2) |

มีสองรายละเอียดที่ควรให้ความสนใจ ประการแรก เกณฑ์สองในสามภายใต้มาตรา 159(3) คำนวณจาก **จำนวนสมาชิกทั้งหมด** ของสภา ไม่ใช่เพียงสมาชิกที่มาประชุมและลงคะแนน ประการที่สอง รายการบทบัญญัติที่ได้รับการคุ้มครองตามมาตรา 159(5) รวมถึงเรื่องเช่น สัญชาติ (ภาคที่ 3) [สภาราชา (Majlis Raja-Raja)](/th/government/majlis-raja-raja) (มาตรา 38) ภาษาประจำชาติ (มาตรา 152) และสถานะพิเศษ (มาตรา 153) — และมาตรา 161E(2) คุ้มครองเรื่องบางอย่างที่สงวนไว้สำหรับซาบาห์และซาราวัก รายละเอียดของแต่ละช่องทางอธิบายไว้ในบทความ [การแก้ไขรัฐธรรมนูญ](/th/law/constitutional-amendment)

ส่วนที่ว่าอำนาจในการแก้ไขภายใต้มาตรา 159 มีข้อจำกัดภายในใด ๆ หรือไม่ — คำถามที่มักรู้จักกันในชื่อหลักการ *โครงสร้างพื้นฐาน* — เคยเป็นเรื่องที่ถกเถียงกันในศาล และความเห็นเกี่ยวกับเรื่องนี้แตกต่างกันไป บทความนี้ไม่แสดงจุดยืนใด ๆ ต่อคำถามนั้น

## ในนั้นมีอะไรบ้าง

รัฐธรรมนูญจัดวางเป็นหลายภาคและหลายบัญชีที่ครอบคลุมกรอบพื้นฐานของประเทศ:

- **สหพันธรัฐและดินแดน** — กำหนดให้มาเลเซียเป็นสหพันธรัฐและนิยามดินแดนของมัน
- **สิทธิเสรีภาพขั้นพื้นฐาน** — ภาคที่ 2 (มาตรา 5 ถึง 13) แจกแจงเสรีภาพเช่น เสรีภาพในร่างกาย ความเสมอภาคต่อหน้ากฎหมาย เสรีภาพในการพูด การชุมนุม และการตั้งสมาคม เสรีภาพในการนับถือศาสนา ตลอดจนสิทธิเกี่ยวกับการศึกษาและทรัพย์สิน
- **สัญชาติ** — ภาคที่ 3 กำหนดวิธีที่สัญชาติได้มา ถูกเพิกถอน และสิ้นสุดลง
- **สถาบันของสหพันธ์** — สถานะของ [ยังดีเปอร์ตวนอากง](/th/glossary/yang-di-pertuan-agong) ในฐานะประมุขสูงสุดของรัฐ ตลอดจนโครงสร้างขององค์กรนิติบัญญัติ บริหาร และตุลาการ
- **รัฐต่าง ๆ** — รัฐธรรมนูญของรัฐ สภาราชา และความสัมพันธ์ระหว่างสหพันธ์กับรัฐ
- **การแบ่งอำนาจ** — บัญชีที่เก้ามีบัญชีสหพันธ์ บัญชีรัฐ และบัญชีร่วม ซึ่งแบ่งเขตอำนาจในการตรากฎหมายระหว่างรัฐสภากับสภานิติบัญญัติแห่งรัฐ

## ความเข้าใจผิดที่พบบ่อย

**"รัฐธรรมนูญแก้ไขได้เหมือนอักตาทั่วไป"** ไม่ใช่ มาตรา 159(3) กำหนดเกณฑ์ปริยายที่สองในสามของจำนวนสมาชิกทั้งหมดของแต่ละสภา ซึ่งสูงกว่าเสียงข้างมากธรรมดาที่จำเป็นสำหรับอักตาทั่วไป

**"คะแนนสองในสามเพียงพอเสมอ"** ไม่จำเป็น มาตรา 159(5) กำหนดให้มีความยินยอมของสภาราชาสำหรับบทบัญญัติบางข้อ และมาตรา 161E(2) กำหนดให้มีความยินยอมของยังดีเปอร์ตัวเนอเกอรีของซาบาห์หรือซาราวักสำหรับเรื่องที่สงวนไว้สำหรับรัฐนั้น

**"กฎหมายทั้งหมดเทียบเท่ากัน"** ไม่ใช่ มาตรา 4(1) วางรัฐธรรมนูญไว้เหนือกฎหมายอื่น อักตาหรือเอนัคเมนที่ไม่สอดคล้องกับมันเป็นโมฆะเท่าที่ไม่สอดคล้องนั้น

## อ่านต่อ

สำหรับภาพรวมฉบับเต็มของโครงสร้างเอกสารนี้ อ่าน [รัฐธรรมนูญแห่งสหพันธรัฐ](/th/law/federal-constitution) ในหมวดกฎหมาย สำหรับรายละเอียดของแต่ละช่องทางการแก้ไข ดู [การแก้ไขรัฐธรรมนูญ](/th/law/constitutional-amendment) เพื่อทำความเข้าใจว่ากฎหมายทั่วไปผลิตขึ้นอย่างไรและเหตุใดจึงต้องเป็นไปตามรัฐธรรมนูญ ดู [อักตา](/th/glossary/akta)

ตัวบทที่มีผลบังคับใช้สำหรับทุกการอ้างในหน้านี้คือรัฐธรรมนูญแห่งสหพันธรัฐเอง ที่จัดพิมพ์โดยสำนักงานอัยการสูงสุดในชุด Laws of Malaysia ส่วนการอ้างภาษามลายูที่นี่ยึดถือตามตัวบทภาษามลายูฉบับพิมพ์ซ้ำ 2020
