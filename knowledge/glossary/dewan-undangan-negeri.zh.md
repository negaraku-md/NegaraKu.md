**Bahasa Malaysia：** Dewan Undangan Negeri · **English：** State Legislative Assembly · **中文：** 州议会

在州选举日，你投票两次。一张选票选出你的国会议员，送往吉隆坡。另一张选票选出你的**州议员（ADUN）**——州议会议员——代表你的选区进入州议会。两张选票、两个政府层级、两个完全独立的立法机关。

州议会（DUN）就是第二张选票所指向的地方。它是为一个州通过土地法、伊斯兰家庭法与地方政府法令的机构。本页解释什么是州议会、谁是州议员，以及这一州层级如何与联邦层级的[下议院](/glossary/dewan-rakyat)和[上议院](/glossary/dewan-negara)平行——却又彼此分离。

## 什么是州议会，谁是州议员？

**州议会**是一个州的立法机关——由选举产生的代表所组成、负责通过州法律并监督州政府的集会。每个州都有自己的一个州议会；有些州使用地方名称，例如「州立法议会（Dewan Negeri）」（如柔佛州的Dewan Negeri Johor），但指的是同一样东西。

**州议员（ADUN）**是**Ahli Dewan Undangan Negeri（州议会议员）**的缩写——即当选代表一个州选区、进入该州议会的人。一名州议员是州层级的「民意代表」，正如一名国会议员是联邦层级的民意代表。每个州议席选区都位于一个更大的国会选区之内，因此一个国会选区通常涵盖数个州议席选区。

关于州议会最重要须理解的一点是：它并非一个自行随意订立规则的国会缩小版。它几乎所有的基本特征——组成、任期、成员资格、法律如何通过——都来自同一处：**联邦宪法第71条与第八附表**。

## 州议会与下议院——有什么区别？

两者都是成员经由选举产生的立法机关。主要区别在于*层级*与*范围*：州议会只为一个州制定法律，下议院则为整个联邦制定法律。下表将州议会与国会两个议院并列。

| 特征 | 州议会（DUN） | 下议院（Dewan Rakyat） | 上议院（Dewan Negara） |
| --- | --- | --- | --- |
| 层级 | 州 | 联邦 | 联邦 |
| 成员产生方式 | 选举产生 | 选举产生 | 委任与选举产生 |
| 成员称呼 | 州议员（ADUN） | 国会议员 | 上议员（Ahli Dewan Negara） |
| 数目 | 由州法律规定（第4节）；总计约600（大马统计局快照） | 222（第46条） | 每州2名 + 联邦直辖区4名 + 委任40名（第45条） |
| 任期 | 五年，可提早解散（第9(3)节） | 五年，可提早解散（第55(3)条） | 成员任期三年，不受解散影响（第45(3)条） |
| 立法范围 | 州立法权限清单与共同清单 | 联邦立法权限清单与共同清单 | 与下议院相同（审议法案） |

一个常被忽略的区别在于「数目」一行。下议院的席位数目——222——直接写在联邦宪法**第46条**中（该数字由A1260号法令从219增至222，2006年1月19日生效）。而州议会的席位数目**并未**写在联邦宪法中；它依第八附表第4(1)节交由各州法律决定。这正是各州州议员数目不同的原因。

## 为什么州议会只有一个议院，而国会有两个？

联邦国会有两个议院：经选举产生的[下议院](/glossary/dewan-rakyat)与大部分经委任产生的[上议院](/glossary/dewan-negara)。而每个州议会只有一个经选举产生的议院。

原因在于第八附表第3节，它以一句话说明：**州立法机关应由统治者与一个议院，即州议会组成。** 州层级没有第二个议院。这句话中的「统治者」一词很重要——它表明「州立法机关」不仅是经选举产生的议员议院，也包含统治者，因为一项法案只有在获得御准后才成为州法令（见下文关于州法令的部分）。

## 州议会的权力从何而来？

马来西亚是一个由13个州组成的联邦，而第71条并不允许每个州随意组建其立法机关。第71(4)条规定，若某州的宪法未载有**第八附表第一部分**所述的条文——即所谓的**「必要条文」（essential provisions）**——或实质相同的条文，那么国会可制定法律，在该州执行这些必要条文。

其效果是形成一套共同框架。每个州撰写自己的宪法，但州议会的核心框架由第八附表统一规定。以下各节是每个州议会的骨干：

| 节（第八附表） | 所规定的内容 |
| --- | --- |
| 第2节 | 州行政议会、州务大臣及对州议会的责任 |
| 第3节 | 组成：统治者与一个议院，即州议会 |
| 第4节 | 成员经选举产生；数目由州法律规定 |
| 第5节 | 成员资格：18岁公民，在该州居住 |
| 第6节 | 丧失资格的各项理由 |
| 第9节 | 召集、休会与解散州议会；五年任期 |
| 第10节 | 议长（Speaker） |
| 第11节 | 州法案如何通过并获御准 |
| 第14节 | 岁入与开支预算表（州预算案） |

## 谁可以成为州议员？

第5节以一句话规定了基本条件：每一名**年满十八岁**并**在该州居住**的**公民**都有资格成为州议会成员，除非依宪法或法律丧失资格。

18岁这个数字是新的。此前的年龄门槛为21岁；**2019年宪法（修正）法令〔A1603号法令〕**将第5节中的「二十一岁」替换为「十八岁」。2020年重印版已纳入此项修正。（Undi18（18岁投票）条文的生效日期是分阶段实施的；当此日期成为关键时，请对照官方宪报核实确切日期。）

请注意与上议院的区别：在那里，第47条为上议员规定了较高的最低年龄。对州议会与[下议院](/glossary/dewan-rakyat)而言，资格年龄如今相同，即18岁。

第6节列出使一个人**丧失**成为州议会成员资格的各项理由：

- 被裁定或宣告心智不健全；
- 为未获解除的破产者；
- 担任某项有薪职位；
- 未提交法律所要求的选举开支报表；
- 因某项罪行被定罪并被判处**不少于一年**监禁或**不少于RM2,000**罚款，且未获无条件赦免；
- 依有关选举罪行的法律丧失资格；或
- 自愿取得或行使外国的公民权，或对外国作出效忠宣誓。

对于最后两项与开支报表及定罪有关的理由，第6(2)节允许统治者撤销该项丧失资格；若未予撤销，则在**五年**后终止。

## 一届州议会有多长？

第9节规范州议会的生命周期，它与规范国会的第55条几乎相同：

- **第9(1)节**——统治者应不时召集州议会，且不得让一届的最后一次会议与下一届的首次会议之间相隔超过**六个月**。
- **第9(2)节**——统治者可**休会或解散**州议会。
- **第9(3)节**——除非提早解散，州议会自其首次会议之日起运作**五年**，随后自行解散。
- **第9(4)节**——州议会解散后，须在**60天**内举行大选，并须在解散之日起不迟于**120天**召集新州议会开会。
- **第9(5)节**——意外出缺须在**60天**内填补，但有一项条件：若出缺发生在州议会即将解散前的**两年**内，则不予填补，除非议长通知选举委员会多数党的人数实力受到影响。

由于州议会与国会的任期各自独立，州选举未必与联邦大选同时举行——一个州议会可在自己的时机解散。

## 州法令如何制定？

州议会通过州法律，通常称为**州法令（Enakmen）**。一项法案的路径由第11节规定：

1. **第11(1)节**——立法权通过**由州议会通过并由统治者御准的法案**行使。
2. **第11(2)节**——涉及从州综合基金（Kumpulan Wang Disatukan Negeri）支出的法案，只能由**州行政议会（EXCO）的一名成员**提出。
3. **第11(2A)节**——统治者应在法案提呈后**30天**内予以御准。
4. **第11(2B)节**——若在该期限内未获御准，该法案**在30天期满时成为法律**，如同已获御准一般。
5. **第11(3)节**——它在获御准时成为法律，但**任何法律在公布前不生效**。

主持官员的选举在第10节中说明：州议会选出一名**议长（Yang di-Pertua，Speaker）**，在该职位空缺期间除选举议长外不得处理任何其他事务。有趣的是，第10(1A)节与第10(1B)节允许选举一名**非州议会成员**担任议长，只要他有资格成为成员——在此情况下他成为额外成员，但无投票权。

## 州议会对州政府有什么权力？

州议会不仅是通过法律的机器；它也是州政府取得授权并承担责任的场所。第八附表第2节将其与州行政部门，即**州行政议会（EXCO）**联系起来：

- **第2(2)(a)节**——统治者首先委任一名在其判断下**可能获得州议会多数成员信任**的州议会成员担任[州务大臣](/glossary/menteri-besar)。
- **第2(2)(b)节**——统治者依州务大臣的建议，从州议会成员中委任**不超过十名且不少于四名**其他成员。
- **第2(5)节**——州行政议会**集体对州议会负责**。
- **第2(6)节**——若州务大臣不再获得州议会多数成员的信任，他应辞去州行政议会的职务——除非统治者应其请求解散州议会。

财政权力则在第14节：对每一个财政年度，统治者应使**州岁入与开支预算表**——即州预算案——提呈至州议会之前。通过这种方式，动用州款项的权力有赖于州议会的同意。

## 州议会可以和不可以为哪些事项立法？

州议会的权力范围并非无限。它取决于[联邦、州与共同立法权限清单](/government/federal-state-division)（第九附表）中的权力划分：

- **第73(b)条**——州立法机关可为整个州或州的一部分制定法律。
- **第74(2)条**——州议会只能就**州立法权限清单**（第二清单）或**共同清单**（第三清单）中的事项制定法律。州立法权限清单事项的例子包括土地、地方政府，以及适用于穆斯林的伊斯兰法。
- **第75条**——若州法律与联邦法律**不一致**，联邦法律**优先**，州法律在抵触范围内无效。

也存在相反方向的情形。第76条允许国会在有限情况下就州立法权限清单事项制定法律——为执行国际条约、为促进各州之间的一致性，或**在一个州的州议会提出请求时**。即使在这些情况下，第76(2)条也禁止国会在未与相关州政府协商的情况下，就伊斯兰法或马来习俗，或沙巴与砂拉越土著的法律与习俗制定法律。

州议会的内部程序也受到保护。第72(1)条规定，**州议会内任何程序的有效性不得在任何法院受到质疑**，而第72(2)条则赋予成员豁免权，使其不因在州议会程序中所发表的言论或所投的票而受法院追究。

## 如何辨别某项议题属州议会还是国会管辖

当某项政策议题出现时，一个快速判断哪个层级负责的方法：

1. **它是否在联邦立法权限清单中？**（例如国防、公民权、所得税）——若是，则属国会事务，而非州议会。
2. **它是否在州立法权限清单中？**（例如土地、地方政府、伊斯兰法）——若是，则由相关州的州议会通过其法律。
3. **它是否在共同清单中？**（例如社会福利、房屋）——两个层级都可制定法律，但若发生抵触，联邦法律优先（第75条）。

请参阅[联邦—州权力划分](/government/federal-state-division)以获取完整清单。

## 没有统治者的州

九个州拥有统治者：柔佛、吉打、吉兰丹、森美兰、彭亨、霹雳、玻璃市、雪兰莪与登嘉楼。另外四个州——**槟城、马六甲、沙巴与砂拉越**——没有统治者。第160(2)条将**州元首（Yang di-Pertua Negeri）**定义为「没有统治者的州的州首长」。

在这些州，第八附表赋予「统治者」的职能——召集与解散州议会、御准法案、委任州务大臣或首席部长——由州元首行使。第160(2)条还记录了一个历史细节：「州议会（Dewan Undangan）」的定义特别**包括砂拉越的州议会（Majlis Negeri）**，即砂拉越州议会的旧称。

## 马来西亚有多少个州议席选区？

由于席位数目逐州规定，联邦宪法中没有单一数字规定所有州议会的规模。不过，就整体而言，大马统计局（DOSM）的数据目录涵盖**13个州共600个州议席选区**，按2015至2018年重新划界所确定的边界计算。三个联邦直辖区——吉隆坡、纳闽与布城——因不设州议会而不包括在内。

600这个数字是一个快照，而非固定数字。它已经在变动：2025年7月，砂拉越州议会通过一项法案，将其席位数目从82增至99，从而在下届州选举前触发选举委员会的重新划界。因此，若要取得当前准确的总数，请对照选举委员会的官方宪报，而非旧的目录数字。

## 常见错误

- **将州议会与上议院混淆。** 州议会是一个州的立法机关；[上议院](/glossary/dewan-negara)是联邦国会的上议院。某些州使用的「州立法议会（Dewan Negeri）」这一名称指的是州议会，而非上议院。
- **以为州议会席位数目写在联邦宪法中。** 并非如此。第4(1)节将其交由各州法律规定，因此各州数目不同。
- **以为联邦直辖区有州议会。** 吉隆坡、纳闽与布城并非州属；联邦直辖区的法律由国会制定。
- **以为州议会必须与国会同时解散。** 每个州议会的任期依第9(3)节各自计算，因此州选举可在与大选不同的时间举行。
- **将州行政议会（EXCO）的规模与州议会成员数目混淆。** 第2(2)(b)节将州行政议会成员（州务大臣除外）限制为不超过十名且不少于四名——这并非州议会成员的总数。
- **将州议员资格年龄说成21岁。** 自A1603号法令起，依第5节成为州议会成员的资格年龄为18岁。
