每年一次，九位世袭君主和四位州元首齐聚吉隆坡的一间会议室，作出议会无法作出的决定——其中之一便是推选谁将出任联邦君主。这一聚会就是统治者会议（Majlis Raja-Raja），而组成它的世袭君主则被称为马来统治者（Raja-Raja Melayu）。

## 谁是马来统治者？

“马来统治者”指的是马来西亚各马来州属的九位世袭君主。每个州对其君主都有各自的称号，因此这里的“Raja（统治者）”一词泛指以君主为首的州属首领，而非一个统一的称号。

九个君主制州属及其君主的称号如下：

| 州属 | 君主称号 |
| --- | --- |
| 柔佛 | 苏丹 |
| 吉打 | 苏丹 |
| 吉兰丹 | 苏丹 |
| 彭亨 | 苏丹 |
| 霹雳 | 苏丹 |
| 雪兰莪 | 苏丹 |
| 登嘉楼 | 苏丹 |
| 森美兰 | 严端（Yang di-Pertuan Besar） |
| 玻璃市 | 拉惹（Raja） |

其余四个州——马六甲、槟城、沙巴及砂拉越——没有世袭君主。相反，这些州由受委任的州元首（Yang di-Pertua Negeri）领导。这两个群体——九位统治者和四位州元首——共同组成统治者会议。

## 统治者会议是什么？它与最高元首有何不同？

统治者会议是统治者和州元首会面并商议的正式机构。它由《联邦宪法》第38条设立，其详细职能列于附表五（Jadual Kelima）。

有一个重要区别需要澄清。最高元首（Yang di-Pertuan Agong）是*一位个人*——即联邦君主，根据《联邦宪法》第32(3)条由统治者会议选出、任期五年一届。而统治者会议则是*集体机构*。正是该会议依据《宪法》附表三（Jadual Ketiga）的程序，从九位马来统治者中推选出最高元首及副最高元首（Timbalan Yang di-Pertuan Agong），这一程序由统治者玉玺掌玺官署（Pejabat Penyimpan Mohor Besar Raja-Raja）加以详述。换言之，最高元首是会议成员中被推举出任联邦最高职位的一位。

根据统治者玉玺掌玺官署的说明，只有在位的统治者才可参与最高元首的推选；统治者不得委派代表代其投票。

## 这一机构是如何形成的？

统治者会议的根源可追溯至1897年7月13日在江沙（Kuala Kangsar）举行的首届杜巴（Durbar）会议，出席者为来自霹雳、彭亨、雪兰莪和森美兰的四位马来统治者。

而其现代形式的会议则于1948年正式成立，取代了马来联邦统治者会议（杜巴，Durbar）。它依据于1948年2月1日生效的《马来亚联合邦协定》而组建，并于1948年2月18日举行首次会议。

会议的成员构成随着国家的变迁而演变：

- **1948年–1957年：** 由九位马来统治者组成，就马来亚联合邦的行政事务进行商议并向英国最高专员（Pesuruhjaya Tinggi British）提供意见。
- **1957年8月31日之后：** 独立后，槟城和马六甲的州元首（总督）加入会议。
- **1963年9月16日之后：** 随着马来西亚的成立，沙巴和砂拉越的州元首也加入会议。

## 统治者会议有哪些职能？

统治者会议承担着若干其他机构所不具备的宪法职能。其中包括：

- **推选国家元首。** 推选最高元首及副最高元首。
- **就统治者特权给予御准。** 任何涉及统治者特权、地位、尊荣或威望的法律，未经会议同意不得通过。
- **宗教事务。** 同意或不同意任何覆盖整个联邦的宗教行为、习俗或仪式。
- **特殊地位。** 在依据第153条（涉及马来人及土著特殊地位）作出任何政策变更之前须先咨询会议。
- **讨论国家政策。** 依据第38(2)条，可就国家政策问题及其认为适宜的任何其他事项进行讨论。
- **委任事宜。** 就某些须经会议同意的委任提供意见，并依据第182条委任特别法庭（Mahkamah Khas）成员，以及向诸如武装部队委员会（Majlis Angkatan Tentera）和国家语文局（Dewan Bahasa dan Pustaka）理事会等机构委派代表。
- **赦免权。** 在特定情形下给予赦免、减刑及缓刑。

根据马来西亚律师公会（Majlis Peguam Malaysia）的记载，《宪法》还依据第38(6)条赋予罢免最高元首的权力——据该记载所述，这一权力从未被行使过。

## 会议如何运作？

会议每年举行三次，也可应最高元首的请求召开。根据统治者玉玺掌玺官署的说明，其主席由九位马来统治者轮流担任。

会议的秘书处是统治者玉玺掌玺官署，该署于1948年配合首次会议而设立。统治者玉玺掌玺官（Penyimpan Mohor Besar Raja-Raja）担任会议的秘书。其为公众最熟知的职责之一，是宣布斋戒月（Ramadan）的开始以及开斋节（Aidilfitri）和哈芝节（Aidiladha）的日期；为观测新月，全马来西亚共设定了29个观测地点。

会议例会通常讨论的事项包括委任、国防、国家安全以及宗教课题。

## 会议的角色是如何被理解的？

统治者会议在马来西亚君主立宪制中的地位，是法律界人士与评论者讨论的题材。有人强调它作为宪法制衡的角色——例如它对某些法律保留御准的权力，以及就重要委任和国家政策接受咨询的权利。马来西亚律师公会在其记载中，将会议依据第38(2)条所行使的审议职能描述为一种有可能促进透明度的审查形式。

关于这些权力实际被行使到何种程度——尤其是涉及酌情裁量的事项——的讨论，在宪法论述中持续进行。本文不对该辩论采取任何立场；它仅记录存在不同观点并被公开讨论这一事实。
