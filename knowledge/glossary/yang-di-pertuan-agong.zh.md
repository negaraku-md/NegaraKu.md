**马来文：** Yang di-Pertuan Agong · **英文：** The King of Malaysia (Supreme Head of the Federation) · **中文：** 最高元首

马来西亚的联邦王位并非世袭继承，而是由提呈产生。

每五年，统治者会议（Majlis Raja-Raja）召开会议，依宪法所定名单的顺序，将最
高元首一职提呈给某位统治者。当中没有竞选、没有公开候选人，除了统治者本身
之外也没有其他投票人。所使用的选票不编号，以相同的笔与墨水标记，然后投入
票箱。

这套机制载于[联邦宪法](/zh/law/federal-constitution)第32条与第三附表——
自[1957年独立（Merdeka）](/zh/malaysia/independence-1957)以来从未间断运
作。

## 概览

| | |
| --- | --- |
| 宪制称号 | 联邦最高元首，称为最高元首（Yang di-Pertuan Agong）（第32(1)条） |
| 王后 | Raja Permaisuri Agong（第32(2)条） |
| 推选者 | 统治者会议（第32(3)条） |
| 任期 | 五年（第32(3)条） |
| 推选规则 | 第三附表第一部分；罢免依第三部分（第32(4)条） |
| 合资格人选范围 | 九位马来统治者 |
| 会议秘书 | 统治者御玺守护官（Penyimpan Mohor Besar Raja-Raja）（第五附表第4条） |
| 就职宣誓 | 第37条，在统治者会议前宣誓 |
| 现任最高元首 | 柔佛苏丹依布拉欣（Sultan Ibrahim Ibni Almarhum Sultan Iskandar），第17任最高元首，自2024年1月31日起 |

## 谁有推选权，谁没有

统治者会议依第38(1)条设立，并依第五附表组成。其完整成员包括九位统治者，
以及四位没有统治者的州属的州元首（Yang di-Pertua Negeri）。

然而，就推选事务而言，成员范围会缩小。第五附表第7条规定，就任何与推选或
罢免最高元首，或推选副最高元首（Timbalan Yang di-Pertuan Agong）有关的程
序而言，州元首**不**属于会议成员。

因此，房间里只有九位统治者。第38(6)(a)条则规定，会议成员在推选与罢免程
序中可依其自身酌情行事——也就是无须听取州务大臣或内阁的建议。

统治者御玺守护官担任会议秘书（第五附表第4条），并须在最高元首任期届满前
不迟于四星期召集会议，以及在出现空缺时召集会议（第6条）。

## 推选名单如何变动

这是最常被误解的部分。轮值顺序并非一次订定、永久不变；它在每次推选之后都
会重新计算。

第三附表第4条订明其机制：

- **第一份名单（1957年）**依当时统治者之间彼此承认的优先顺序排列——第
  4(1)(a)条。
- **每次推选之后**，凡排在已获推选的统治者所属州属之前的州属，均移至名
  单末端，而该已获推选统治者所属的州属则从名单中除去——第4(2)(a)条。
- **当名单上仍在其中的某个州属发生统治者更替**时，该州属会被移至名单末
  端——第4(2)(b)条。
- **当名单用尽时**，会重新编排，将所有统治者的州属再次纳入名单，但依这
  些州属的统治者曾经担任最高元首一职的先后顺序排列——第4(3)条。

正是第4(3)条的这项效果，产生了重复第一轮顺序的第二轮。第10条阐明，就第
4(3)条而言，「统治者」一词也包括卸任的统治者。

## 推选会议内部

第三附表第2条明确订定其顺序：统治者会议应将该职位**提呈**给名单上排名第
一、且合资格获推选的统治者。若该统治者不接受，提呈即转交给下一个州属的统
治者，如此类推，直至有一位统治者接受该职位为止。

统治者会议官方网站详细列出该会议的程序：

| 步骤 | 程序 |
| --- | --- |
| 选票 | 不编号，以相同的笔与墨水标记，然后投入票箱 |
| 投票人 | 只有统治者本身可以投票 |
| 选票形式 | 统治者御玺守护官分发只载有一位候选人姓名的选票，供圈选同意或否决 |
| 门槛 | 候选人须获得五票的多数，主持会议的统治者才会将职位提呈给他 |
| 点票 | 在位时间最短、且未被列为候选人的统治者，与统治者御玺守护官一同点算选票 |
| 之后 | 选票在众统治者面前销毁 |

一旦提呈获接受，第3条规定会议须宣布该统治者当选，并由统治者御玺守护官以
书面方式将该项决定通知[国会](/zh/government/parliament)两院。

在执行职务之前，第37(1)条规定最高元首须在统治者会议前，并在联邦法院首席
大法官在场见证下，宣读并签署第四附表第一部分所载的就职宣誓词。

## 资格与任期

第三附表第1(1)条规定，统治者具备获推选的资格，**除非**——该统治者尚未成
年；或该统治者已通知统治者御玺守护官他不愿被推选；或统治者会议以不记名
投票方式议决，认为该统治者因精神或身体上的欠佳，或因任何其他原因，不适
合执行该职务。此类议决须获会议至少五位成员支持（第1(2)条）。

第32(3)条订明任期可在未满五年前结束的三种方式：以本人亲笔签署、致统治者
会议的文书辞职；由统治者会议罢免；或当他不再是统治者时。依第三附表第三
部分作出的罢免议决，同样须获会议至少五位成员支持。

此外还有依第33条设立的副最高元首（Timbalan Yang di-Pertuan Agong）一职，
由统治者会议依第三附表第二部分推选产生，在最高元首出缺或不在时执行最高
元首的职务。

## 宪法下的职能

第39条将联邦行政权赋予最高元首。第40(1)条则规定，最高元首在执行该等职务
时须依内阁的建议行事，而第40(1A)条进一步明确，凡宪法规定最高元首须依建
议行事之处，最高元首须接受并依该建议行事。

| 职能 | 条文 |
| --- | --- |
| 委任首相——最高元首认为在其判断上可能获下议院多数信任的下议院议员 | 第43(2)(a)条 |
| 依首相的建议委任其他部长 | 第43(2)(b)条 |
| 召开、休会及解散国会 | 第55(1)条与第55(2)条 |
| 须在三十天内御准法案；否则法案仍自动成为法律 | 第66(4)条与第66(4A)条 |
| 联邦军队最高统帅 | 第41条 |
| 对军事法庭裁定的罪行，以及在吉隆坡、纳闽和布城联邦直辖区内的罪行行使赦免权 | 第42(1)条 |
| 在吉隆坡、纳闽和布城联邦直辖区担任伊斯兰教首长 | 第3(5)条 |
| 依各自的州宪法，在马六甲、槟城、沙巴与砂拉越担任伊斯兰教首长 | 第3(3)条 |
| 保管并使用联邦御玺 | 第36条 |

第40(2)条列出最高元首可依自身酌情行使的职能：委任首相；不批准解散国会的
请求；以及要求召开纯粹涉及统治者的特权、地位、尊荣与位阶的统治者会议。

## 对该职位的限制

第34条对最高元首在位期间设有若干限制：

- 不执行其本身州属统治者的职务，其作为伊斯兰教首长的职务除外——第
  34(1)条。
- 不担任任何有薪酬的职位——第34(2)条。
- 不积极参与任何商业活动——第34(3)条。
- 不收取以其本身州属统治者身分应支付给他的薪酬——第34(4)条。
- 除国事访问期间外，未经统治者会议同意，不离开联邦超过十五天——第
  34(5)条。

第32(1)条也规定，除在依第十五部分设立的特别法庭之外，不得在任何法院对最
高元首提起任何诉讼程序。第33A条规定，若最高元首在该特别法庭被控以罪行，
他须停止执行最高元首的职务，而该段期间仍计入五年任期之内。

## 常见的误解

**「轮值是自动的。」** 不对。第三附表第2条使用的字眼是*提呈*。统治者可以
不接受该项提呈，提呈随即转交名单上的下一个州属。第1(1)(b)条也允许统治者
通知统治者御玺守护官，表示他不愿被推选。

**「十三个州属都会轮到。」** 不对。名单上只有九个拥有统治者的州属。马六
甲、槟城、沙巴与砂拉越的州元首不具备获推选的资格，也不在该项推选中投票
（第五附表第7条）。

**「他不再是本身州属的统治者。」** 不对。他仍然是本身州属的统治者——事
实上，第32(3)条规定，他是在不再是统治者时，才不再担任最高元首一职。受到
限制的是他在担任联邦职位期间，*执行*该州职务的权力（第34(1)条）。

**「Agong是完整的称号。」** 完整的宪制称号是Yang di-Pertuan Agong（最高
元首）；其王后的称号为Raja Permaisuri Agong（第32(1)条与第32(2)条）。

**「法案没有御准就不能成为法律。」** 第66(4)条订明三十天的御准期限，而
第66(4A)条规定，若该期限届满，法案仍会成为法律，如同已获御准一样。
