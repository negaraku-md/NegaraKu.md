**Bahasa Malaysia:** Perlembagaan Persekutuan · **English:** Federal Constitution · **中文:** 联邦宪法

一部法令可以由国会以简单多数通过。然而，该法令仍须服从一份更高的文件——如果它与那份文件抵触，该法令在抵触的范围内即属无效。

那份文件就是**联邦宪法**。第4条宣告它为马来西亚的最高法律，正是这一地位使它有别于国家法律体系中的每一部其他[法令](/glossary/akta)。

## 一览

| | |
| --- | --- |
| 全名 | 联邦宪法（Perlembagaan Persekutuan / Federal Constitution） |
| 类别 | 联邦最高法律 |
| 生效日期 | 1957年8月31日（作为马来亚联合邦宪法）；1963年9月16日马来西亚成立时扩大适用 |
| 地位 | 第4(1)条：联邦的主要法律；与之抵触的法律在抵触的范围内均属无效 |
| 修改机关 | 国会依据第159条（以及涉及沙巴／砂拉越特定事项的第161E条） |
| 解释与适用者 | 法院 |
| 生效文本 | 由总检察署以《马来西亚法律》（Laws of Malaysia）系列出版，分马来文与英文版本（2020年重印本） |

## "最高法律"是什么意思？

第4(1)条规定，本宪法是联邦的主要法律，而独立日之后通过的任何与宪法抵触的法律，在**抵触的范围内均属无效**。

其效果是，马来西亚所有其他法律都位于宪法**之下**，而非与之平起平坐：

- 国会通过的**法令（Akta）**必须符合宪法。
- 州立法议会通过的**州法令（Enakmen）**同样须服从宪法，并须遵守宪法所定的权力划分。
- **附属法规**（如条例与规则）不得逾越宪法及其母法令所允许的范围。

当出现某项法律或行为是否符合宪法条文的问题时，由法院负责解释与适用宪法。

## 它与一部法令有何不同？

最重要的区别在于**它如何通过与修改**。

| | 普通法令 | 联邦宪法 |
| --- | --- | --- |
| 地位 | 联邦普通法律 | 最高法律（第4条） |
| 通过／修改所需 | 两院简单多数 | 一般为每个国会议院全体议员总数三分之二（第159条） |
| 彼此关系 | 必须符合宪法 | 凌驾于所有法令之上 |
| 抵触的后果 | 在与宪法抵触的范围内无效 | — |

由于宪法为其修改设定了更高的票数门槛，它不能像普通法律那样轻易更改。这正是成文宪法所谓"刚性"（*rigidity*）的含义。

## 宪法如何修改？

第159条规定了修改程序。它并非单一规则；所采用的途径取决于所要更改的条文。与第161E条一并阅读时，存在几条不同的途径：

| 途径 | 条件 | 条文 |
| --- | --- | --- |
| 默认（大多数修改） | 在二读与三读时获得每院全体议员总数不少于三分之二的票数 | 第159(3)条 |
| 从简（有限的技术性清单） | 仅需简单多数，如同普通法律 | 第159(4)条 |
| 更严（特定事项） | 三分之二**并且**须获统治者会议（Majlis Raja-Raja）同意 | 第159(5)条 |
| 更严（沙巴／砂拉越事项） | 三分之二**并且**须获相关的沙巴或砂拉越州元首（Yang di-Pertua Negeri）同意 | 第161E(2)条 |

有两个细节值得留意。第一，第159(3)条下的三分之二门槛是按某议院的**全体议员总数**计算，而非仅按出席并投票的议员计算。第二，受第159(5)条保护的条文清单包括公民权（第三部分）、[统治者会议](/government/majlis-raja-raja)（第38条）、国语（第152条）和特殊地位（第153条）等事项——而第161E(2)条则保护若干专为沙巴与砂拉越保留的事项。各途径的细节在[修宪](/law/constitutional-amendment)一文中说明。

第159条下的修改权是否存在任何内在限制——这一问题通常被称为*基本结构*学说——曾在法院成为讨论的课题，各方对此看法不一。本文对该问题不持任何立场。

## 宪法包含哪些内容？

宪法分为若干部分与附表，涵盖国家的基本框架：

- **联邦及其领土**——确立马来西亚为一个联邦，并界定其领土。
- **基本自由**——第二部分（第5至13条）列明各项自由，如人身自由、法律之前人人平等、言论、集会与结社自由、宗教自由，以及有关教育与财产的权利。
- **公民权**——第三部分规定公民权如何取得、褫夺与终止。
- **联邦机构**——[最高元首](/glossary/yang-di-pertuan-agong)作为国家元首的地位，以及立法、行政与司法机构的架构。
- **各州**——州宪法、统治者会议，以及联邦与州之间的关系。
- **权力划分**——第九附表载有联邦事项表、州事项表与共同事项表，将立法权限划分于国会与州立法议会之间。

## 常见误解

**"宪法可以像普通法令一样修改。"** 不对。第159(3)条设定了三分之二全体议员总数的默认门槛，高于普通法令所需的简单多数。

**"三分之二的票数总是足够的。"** 未必。第159(5)条要求特定条文须获统治者会议同意，而第161E(2)条则要求专属于沙巴或砂拉越的事项须获该州州元首同意。

**"所有法律地位平等。"** 不对。第4(1)条使宪法凌驾于其他法律之上；任何与之抵触的法令或州法令，在抵触的范围内均属无效。
