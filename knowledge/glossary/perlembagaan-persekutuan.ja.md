**Bahasa Malaysia:** Perlembagaan Persekutuan · **English:** Federal Constitution · **中文:** 联邦宪法

Aktaは、国会において単純多数の票決で可決することができる。しかしそのAktaも、
それより上位にある一つの文書に服する——そして、その文書に抵触する場合、Akta
はその抵触する限度において無効となる。

その文書こそが**連邦憲法**である。第4条はこれをマレーシアの最高法規と宣言し
ており、この地位こそが、国の法体系における他のあらゆる[Akta](/glossary/akta)
との違いを生み出している。

## 概要

| | |
| --- | --- |
| 正式名称 | 連邦憲法（Perlembagaan Persekutuan／Federal Constitution） |
| 種類 | 連邦の最高法規 |
| 発効日 | 1957年8月31日（マラヤ連邦憲法として）；1963年9月16日のマレーシア成立時に適用が拡大 |
| 地位 | 第4条(1)：連邦の主要な法律であり、抵触する法律はその抵触する限度において無効 |
| 改正機関 | 第159条に基づく国会（サバ／サラワクの特定事項については第161E条） |
| 解釈・適用機関 | 裁判所 |
| 効力を有するテキスト | 検事総長室（Jabatan Peguam Negara）によりLaws of Malaysiaシリーズで刊行され、マレー語版と英語版がある（2020年重印本） |

## 「最高法規」とは何を意味するか

第4条(1)は、本憲法が連邦の主要な法律であり、独立記念日（Hari Merdeka）以降に
可決された、憲法に抵触するいかなる法律も**その抵触する限度において無効**であ
ると定めている。

その結果、マレーシアの他のすべての法律は、憲法と同格ではなく、憲法の**下位**
に位置する：

- 国会が可決する**Akta**は、憲法に適合しなければならない。
- 州議会（Dewan Undangan Negeri）が可決する**Enakmen**も、憲法及び憲法が
  定める権限配分に服する。
- 規則や規程などの**下位法令**は、憲法及びその根拠となるAktaが許容する範囲を
  超えることができない。

ある法律又は行為が憲法の規定に適合しているかという問題が生じたとき、憲法を
解釈し適用するのは裁判所である。

## Aktaとどう異なるのか

最も重要な違いは、**その可決及び改正の方法**にある。

| | 通常のAkta | 連邦憲法 |
| --- | --- | --- |
| 地位 | 連邦の通常の法律 | 最高法規（第4条） |
| 可決／改正の要件 | 両院での単純多数 | 一般に国会各院の全議員総数の3分の2（第159条） |
| 相互の関係 | 憲法に適合しなければならない | すべてのAktaの上位に立つ |
| 抵触した場合の効果 | 憲法に抵触する限度において無効 | — |

憲法はその改正についてより高い票決の閾値を定めているため、通常の法律ほど
容易には改めることができない。これが、成文憲法における「硬性」（*rigidity*）
の意味するところである。

## 憲法はどのように改正されるか

第159条は改正の手続を定めている。これは単一の規則ではなく、用いられる経路は
改正しようとする規定によって異なる。第161E条と併せて読むと、いくつかの別個
の経路が存在する：

| 経路 | 要件 | 規定 |
| --- | --- | --- |
| 既定（大半の改正） | 第二読会及び第三読会において、各院の全議員総数の3分の2を下回らない票数 | 第159条(3) |
| 軽易（限定された技術的事項の一覧） | 通常の法律と同様、単純多数のみ | 第159条(4) |
| より厳格（特定の事項） | 3分の2**に加えて**統治者会議（Majlis Raja-Raja）の同意 | 第159条(5) |
| より厳格（サバ／サラワク事項） | 3分の2**に加えて**当該のサバ又はサラワク州元首（Yang di-Pertua Negeri）の同意 | 第161E条(2) |

二つの点に留意すべきである。第一に、第159条(3)のもとでの3分の2の閾値は、出席
し投票した議員数のみではなく、当該院の**全議員総数**に対して算定される。第二
に、第159条(5)によって保護される規定の一覧には、市民権（第3編）、
[統治者会議](/government/majlis-raja-raja)（第38条）、国語（第152条）及び
特別な地位（第153条）といった事項が含まれ——さらに第161E条(2)は、サバ及び
サラワクに専属する若干の事項を保護している。各経路の詳細は、
[憲法改正](/law/constitutional-amendment)の記事で説明されている。

第159条のもとでの改正権限に何らかの内在的限界があるか——一般に*基本構造*理論
として知られる問題——は、かつて裁判所で議論された論点であり、これに関する
見解は分かれている。本稿はこの問題について、いかなる立場も取らない。

## 何が定められているか

憲法は、国の基本的な枠組みを網羅するいくつかの編（部）及び附則から構成され
ている：

- **連邦とその領域** ——マレーシアを一つの連邦として定め、その領域を画定
  する。
- **基本的自由** ——第2編（第5条から第13条）は、身体の自由、法の下の平等、
  言論・集会・結社の自由、信教の自由、並びに教育及び財産に関する権利といった
  自由を列挙している。
- **市民権** ——第3編は、市民権の取得、剥奪及び喪失の方法を定めている。
- **連邦機関** ——国家元首としての
  [国王（Yang di-Pertuan Agong）](/glossary/yang-di-pertuan-agong)の地位、
  並びに立法、行政及び司法の各機関の構造。
- **各州** ——州憲法、統治者会議、及び連邦と州との関係。
- **権限の配分** ——Ninth Schedule（第九附則）は連邦リスト、州リスト及び共通
  リストから成り、立法権限を国会と州議会との間で配分している。

## よくある誤解

**「憲法は通常のAktaと同じように改正できる。」** そうではない。第159条(3)は、
各院の全議員総数の3分の2という既定の閾値を定めており、これは通常のAktaに
必要な単純多数よりも高い。

**「3分の2の票数さえあれば常に足りる。」** 必ずしもそうではない。第159条(5)
は特定の規定について統治者会議の同意を要求しており、第161E条(2)は当該州に
専属する事項について、サバ又はサラワクの州元首の同意を要求している。

**「すべての法律は同格である。」** そうではない。第4条(1)は憲法を他の法律の
上位に置いており、これに抵触するAkta又はEnakmenは、その抵触する限度におい
て無効である。
