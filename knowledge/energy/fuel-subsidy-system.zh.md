数十年来，马来西亚的每一个人——无论是百万富翁还是割胶工人——在油站付的汽油价格都一样。2025年9月30日，这套安排画上句号。如今一公升RON95对你可能是RM1.99，对你的邻居却几乎是两倍，而决定这一切的不是国际油价，而是你插入终端机的那张身份证。

这场转变——从*全面*补贴（人人有份）转向*精准*补贴（只有合格者有份）——被政府形容为马来西亚一代人以来最大规模的财政改革之一。本指南解释它对RON95与柴油如何运作、谁有资格，以及其中牵涉多少款项。

## 马来西亚为何终止全面燃油补贴？

按政府的论点，全面补贴代价过于高昂，而且大部分好处流向了并非最需要帮助的群体。

据财政部所述，单是RON95补贴在2023与2024年每年就耗资**近RM200亿**。由于这个低价发放给*所有*消费者，政府认为很大一部分人民的钱也流向了驾驶最多、最有能力支付全价的高收入群体。

至于柴油，政府认为问题更为明显。政府曾为柴油补贴支出**RM143亿**，并指出其中很大一部分被泄漏——不是流向人民，而是流向跨境走私与商业滥用，因为马来西亚柴油比邻国便宜得多。

政府提出的改革逻辑很简单：把价格浮动至市场水平，然后*只*把补贴发放给合格的人民。节省下来的钱可以转用于现金援助与社会安全网。

## BUDI95是什么，谁有资格获得RM1.99的RON95？

BUDI95（隶属BUDI MADANI品牌）是RON95汽油的精准补贴计划。它引入**双层价格**：

- **每公升RM1.99**，供合格的马来西亚公民。
- **未补贴价格**，针对不合格者、外国人，或每月配额用尽之后。此价格每周通过APM厘定——在BUDI95启动之初（2025年9月底）为每公升RM2.60，但到了2026年8月6日至12日那一周已升至**每公升RM3.77**。

未补贴价格为每公升RM3.77时，实际补贴约为**每公升RM1.78**（2026年8月6日至12日那一周）。RON97在BUDI95启动时维持在**每公升RM3.21**（RON97从未获得补贴，完全随市场浮动——在2026年8月6日至12日那一周为每公升RM4.35）。

谁有资格？据财政部与Petron等业者所述，条件为：

- **马来西亚公民**，持有芯片有效的**MyKad**。
- 持有获批类别的有效**驾驶执照**。
- **不属于T15**群体——即收入最高的15%家庭，这些人被排除在外。

首相安华（Anwar Ibrahim）将目标群体形容为约1800万名汽车驾驶者与摩托车骑士，包括16岁以上的青年与零工从业者。截至2025年11月30日，**1390万名公民**——约占1650万名合格者的**84%**——已获得福利，销售额达**RM51.6亿**，消费量达**25.9亿公升**。

## MyKad、配额与PADU如何协同运作？

每次你加油时，有三个部分同时运转：身份验证、配额核查，以及幕后的数据库。

**PADU**（中央数据库，Pangkalan Data Utama）是系统的大脑。它整合来自内陆税收局（LHDN）、陆路交通局（JPJ）与国民登记局（JPN）的数据，判断一个人是否属于T15群体之外。资格名单定期更新，确保没有合格人民被遗漏。

**MyKad**是油站的钥匙。你通过以下几种方式之一验证资格：

- 将MyKad插入油站的**读卡终端机**。
- 使用**油公司应用程序**，如Setel（Petronas）或Shell应用程序。
- **Touch 'n Go电子钱包**或户外付款终端机（OPT）。
- **柜台现金付款**——专为没有电子钱包或互联网接入的人而设。

**配额**限制滥用。每名合格个人每月获得**200公升**的补贴价格——自**2026年4月1日**起由300公升下调，同时价格维持在RM1.99。自**2026年7月1日**起，该200公升配额由补贴RON95（RM1.99）与Budi Diesel（RM2.10）**共享**——两者从同一个余额中扣除。若配额用尽，后续购买将按未补贴价格计算。电召与送餐（p-hailing）司机因工作需要，维持较高的**每月800公升**上限。

以下是RON95价格与福利的摘要：

| 项目 | 数值 |
|---|---|
| 补贴RON95（合格公民） | RM1.99／公升 |
| 未补贴RON95（2026年8月6日至12日那一周） | RM3.77／公升 |
| 实际补贴（2026年8月6日至12日那一周） | 约RM1.78／公升 |
| 每月配额（自2026年4月1日起） | 200公升 |
| RON97（BUDI95启动时） | RM3.21／公升 |
| 陆路公共交通RON95 | RM2.05／公升 |
| 生效日期 | 2025年9月30日 |

*资料来源：马来西亚财政部；Petron Malaysia；Paul Tan's Automotive News。未补贴价格每周通过APM厘定。*

## 柴油如何合理化——2026年有何变化？

柴油比RON95早了一年多，其历程让我们看清这场改革如何演变。

在**2024年6月10日**，政府让半岛马来西亚的柴油价格浮动。零售价当时飙升至**每公升RM3.35**——与市场看齐——高于此前的补贴水平，此后每周变动（在2026年8月6日至12日那一周达到约每公升RM4.57）。沙巴、砂拉越与纳闽获得**豁免**，维持在**每公升RM2.15**。

为保护真正有需要的群体，政府保留了精准补贴：

- **物流业**通过**SKDS 2.0**（补贴柴油管制系统）车队卡：每公升RM2.15。
- **公共交通**（巴士、救护车、消防车）：每公升RM1.88。
- **渔民**：每公升RM1.65。

个人则起初获得**现金援助**——在**BUDI Individu**（柴油车辆车主）与**BUDI Agri-Komoditi**（小园主）之下，后来上调至每月RM400。

截至**2025年9月30日**（快照指标），财政部报告有超过**140,000**名BUDI Individu受益者（RM4.3亿）、**180,000**名BUDI Agri-Komoditi受益者（RM3.5亿），以及**121,618**家公司的**355,074**辆车辆获批车队卡。自**2026年7月1日**起，BUDI Individu与BUDI Agri-Komoditi的现金援助计划被并入Budi Diesel的油站补贴，现有受益者自动迁移。

自**2026年7月1日**起，**Budi Diesel**计划允许合格的私人柴油车辆车主以**每公升RM2.10**购买柴油——约**700,000**名车辆车主（半岛400,000名；沙巴、砂拉越与纳闽300,000名）。资格通过MyKad与JPJ数据库验证。每月基本配额为与BUDI95补贴RON95**共享的200公升**；符合条件的皮卡与SUV车主可申请额外100公升（共300公升）。补贴柴油仅适用于**B10及以上**的混合油；B7维持未补贴，按每周市场价计算。

| 柴油类别 | 价格／公升 |
|---|---|
| 未补贴柴油，半岛（浮动，2026年8月6日至12日那一周） | RM4.57 |
| Budi Diesel个人（自2026年7月1日起） | RM2.10 |
| SKDS 2.0（物流／商业） | RM2.15 |
| 沙巴／砂拉越／纳闽 | RM2.15 |
| 公共交通 | RM1.88 |

## 政府节省了多少，钱又去了哪里？

这才是这场改革真正的赌注所在。

对**柴油**而言，财政部估计自2024年6月10日起**每年节省约RM50亿**——这源自堵住走私漏洞与精准发放补贴。

对**RON95**而言，财政部副部长林慧英（Lim Hui Ying）表示，政府预计每年节省**RM25亿至40亿**，具体取决于全球原油价格介于**每桶US$60至US$80**之间。（全面评估从2026年开始，因为BUDI95迟至2025年9月底才推出。）

政府表示节省下来的钱被重新调配——而非消失。据政府所述，燃油补贴的节省被转用于直接现金援助，如惠及低收入家庭的慈悯现金援助（STR）与慈悯基本援助（SARA）。据财政部所述，2026年STR与SARA合计拨款达**RM150亿**——迄今最高拨款——惠及约**900万名受益者**（SARA触及超过800万人，包括40万名登记eKasih的赤贫群体，而STR第一阶段涵盖370万个家庭及130万名单身乐龄人士）。

## 你是否合格——你需要做什么？

针对RON95，使用以下简单框架：

1. **你是持有芯片有效MyKad的马来西亚公民吗？** 若不是——你将支付未补贴价格（2026年8月6日至12日那一周为每公升RM3.77）。
2. **你持有有效驾驶执照吗？** 这是政府公布的基本资格条件。
3. **你属于T15群体（收入最高的15%）吗？** 若是——你将被排除在补贴之外。
4. **若通过第1至3项：** 你每月有资格获得200公升RM1.99的RON95。对大多数人而言无需特别登记——只需在油站以MyKad或应用程序验证资格即可。
5. **若你是电召／送餐司机或柴油车辆车主：** 请查看BUDI MADANI门户网站，了解额外配额或专属计划（例如针对私人柴油车辆的Budi Diesel）。

对于私人柴油，附加条件是你必须**自己拥有**一辆已注册、路税有效的柴油车辆——所有权通过JPJ数据库验证。

## 应避免的常见错误

- **以为你需要「登记」才能享有RON95。** 对大多数公民而言，资格是在油站通过PADU与MyKad自动验证的——而非通过另设的表格。
- **混淆柴油与RON95价格。** 两者是不同的计划，各有自己的日期、价格与机制。RON95 ＝ RM1.99（BUDI95）；私人柴油 ＝ RM2.10（Budi Diesel，自2026年7月起）。
- **忘记配额上限。** 每月超过200公升的购买（RON95，自2026年4月1日起）按全价计算；自2026年7月1日起，该200公升配额与Budi Diesel共享。此外也有单笔交易上限（例如业者所述的RM250）。
- **以为价格固定不变。** *未补贴*价格由财政部通过自动定价机制（APM）厘定，每周变动；只有RM1.99的补贴价格保持稳定。
- **以为沙巴／砂拉越的柴油与半岛相同。** 沙巴、砂拉越与纳闽的柴油不浮动，维持每公升RM2.15。
- **购买RON97时期待补贴。** RON97从未获得补贴，维持市场价（BUDI95启动时为每公升RM3.21；2026年8月6日至12日那一周为每公升RM4.35）。

## 接下来会怎样

马来西亚的燃油补贴制度仍在演变。以下几点值得关注：

- **2026年全面评估。** 政府将首次计算RON95整整一年的实际节省额，这将决定RM25亿至40亿的估计是否达标。
- **Budi Diesel的扩展。** 2026年7月启动的私人柴油计划标志着从现金援助转向以MyKad为基础的油站补贴——这一模式可能会进一步优化。
- **PADU的准确性。** 整个系统的公平取决于收入数据的准确性。留意政府如何处理上诉与分类错误的个案。
- **全球油价。** 由于*未补贴*价格随市场走，国际油价上涨会扩大RM1.99与全价之间的差距——使配额更为重要。

欲获取官方与最新资讯，请参阅BUDI MADANI门户网站与财政部的新闻稿。本指南中的数字截至更新日期为准确；燃油价格与计划细节可能会有变动。
