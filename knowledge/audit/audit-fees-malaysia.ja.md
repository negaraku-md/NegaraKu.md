マレーシアの監査報酬を検索すると、係数表が示される——最初のRM100,000に対して1.000%、
次のRM150,000に対して0.438%というように段階的に低減し、休眠会社にはRM800の下限がある。
それはMIAの報酬表として、時には認められた最低報酬として示される。

**それは2015年6月1日に撤回された。**

## 撤回の確認

MIAは今もこの文書を公開している。MIA自身が持つ『Recommended Practice Guide 7
(Revised) — A Guide to Charging for Professional Assurance Services』の文書を開くと、
表紙の一行目にこう記されている。

> [WITHDRAWN WITH EFFECT FROM 1 JUNE 2015]

MIAの一覧ページでは、より古い2007年版についても同様の扱いがなされており、
そのタイトルは『RPG 7 — Fees and Commission (Withdrawn)』となっている。

つまり、この日付は実務家の間の言い伝えではなく、一次文書の表紙に記されているものである。

**理由**は別の話である。実務家は一貫して、理事会が2010年競争法（Competition Act 2010）
への抵触を避けるためにRPG 7を撤回したと述べており、その見方によれば、推奨報酬表は
価格協定とみなされ得るという。それはもっともらしく、広く繰り返し語られているが、
それを述べたMIAの通達や理事会決議を公式な情報源から確認することはできなかった。
本稿では、撤回日は「確認済み」、その理由は「そう報じられている」ものとして扱う。

## 撤回された指針には実際に何が書かれていたか

知っておく価値はある。転載され続けているのはこの内容だからだ。

RPG 7 (Revised)は2010年3月1日に発効し、2007年版を置き換えた。そこでは報酬算定の
基礎として時間ベースと価値ベースの2つが示され、そのうえで——実務家が価値ベースでの
交渉に苦労していたことから——総営業収益または総資産に適用する**係数パーセンテージ表**
が示されていた。さらに、この2つが極端な結果を生む場合に備え、総営業支出に基づく
別表も用意されていた。

| 総営業収益または総資産の区分 | 係数 |
| --- | --- |
| 最初のRM100,000 | 1.000% |
| 次のRM150,000 | 0.438% |
| 次のRM250,000 | 0.313% |
| 次のRM500,000 | 0.188% |
| 次のRM1,500,000 | 0.125% |
| 次のRM2,500,000 | 0.100% |
| 次のRM5,000,000 | 0.094% |
| RM10,000,000からRM20,000,000まで | RM1,000,000の増加またはその端数ごとにRM1,000 |
| RM20,000,000超 | 交渉による。ただし1件の委嘱につきRM20,000を下回らないこと |

第4.4.1項はさらに、監査業務の報酬が**RM800**を下回る場合、非現実的に低いとみなす
べきだと付け加えていた——これが休眠会社の数字の出所である。

**この表をここに転載するのは、読者がそれを見分けてもう使わないようにするためだけ
である。** これにはもはや効力がない。そのうえ、この指針自体の第4.3.3(D)(i)項に
注意してほしい——その推奨水準は、**Companies Act 1965**のもとで登録された会社の
法定監査に適用されるものだった。同法は2017年1月31日に廃止されている。この表が
書かれた前提となる枠組み自体、もはや存在しない。

## 今日、報酬を規律しているもの

2024年11月5日に更新されたMIA By-Laws (On Professional Ethics, Conduct and Practice)
のSection 330、それ以外には何もない。

**330.3 A2**——専門職会計士は、自らが適切と考える報酬を提示してよい。他の会計士より
低い報酬を提示すること自体は**非倫理的ではない**。しかし、提示された報酬が、適用される
技術的・専門的基準に従って業務を遂行することを困難にしかねないほど低い場合、その
報酬水準は職業的専門家としての能力及び正当な注意の原則に対する自己利益の脅威を
生じさせる。

マレーシア独自の追補である**330.3 A2 MY**は、すべての業務について請求される報酬が、
当該業務の価値を公正に反映したものであることを求めており、その際には以下を考慮する
としている。

- 当該業務の種類に必要な技能及び知識
- 必要に応じて従事する者の訓練及び経験の水準
- 従事する各人が必要とする時間
- 当該業務に伴う責任の程度及び緊急性

現行の立場はこれがすべてである。それが設けているのは職業的専門能力の下限であって、
リンギットでの下限ではない。

## 何が実際に見積りを動かすか

| 要因 | 工数がかかる理由 |
| --- | --- |
| グループ連結 | 報告の階層が一つ増え、構成単位の作業や相殺消去テストが必要になる。ISA 600 (Revised) は2023年12月15日以後に開始する期間に適用される |
| 棚卸資産 | 棚卸資産が重要な場合、実地棚卸への立会は必須の手続きである。出張や複数拠点があるとさらに増える |
| 初年度の業務 | 期首残高は別途監査する必要があり、前任者の監査調書が入手できないこともある |
| 記録の質 | 未調整の元帳があると、監査工数が監査料率のまま記帳作業の工数に化ける |
| 関連当事者 | 関連当事者を特定しMFRS 124に従って開示することは、修正が遅れる最も一般的な原因の一つである |
| 外貨、収益認識、見積り | 判断を要する領域では、ジュニアスタッフではなくパートナーやマネージャーの時間が使われる |
| 品質管理 | ISQM 1およびISA 220 (Revised) は2022年12月15日以降適用されており、業務単位でのモニタリングが加わり、案件によっては業務品質レビューも必要になる |
| 期限の圧縮 | s.258の6か月配布期限に追われる作業は、時間外労働分として価格に上乗せされる |

通常、監査報酬に**含まれていない**ことが多く、見積りを比較する前に確認しておく価値が
ある2つの事柄がある。財務諸表そのものの作成、そしてMBRSを通じたXBRLへの変換及び
提出である。ある事務所がそれらを込みにし、別の事務所がそうしていなければ、両者の
見積りは比較にならない。

## 観察された市場レンジ——観察であって公式ではない

> **まずここを読んでほしい。** マレーシアでは、いかなる当局も監査報酬表を公表していない。
> 以下のレンジは、マレーシアの中小事務所が提示している報酬の観察結果であり、通常の
> 見積りと外れ値とを見分けられるように示すものである。これらは**基準でも推奨でもなく、
> MIA、SSM、その他いかなる者からも承認されたものでもない**。これらのレンジから
> 外れた見積りが誤っているわけではない。これらの数字を基準として引用したり、報酬を
> 値切る材料として使ったりしてはならない。

| 会社のプロフィール | 法定監査の観察レンジ |
| --- | --- |
| 休眠、取引なし | RM800 – RM1,800 |
| 零細な貿易業・サービス業の会社、営業収益RM500,000未満 | RM1,500 – RM3,500 |
| 小規模会社、営業収益RM1m～RM5m、単一事業体 | RM3,000 – RM9,000 |
| 中堅規模、営業収益RM5m～RM25m、棚卸資産あり又は複数の収益源 | RM8,000 – RM30,000 |
| 連結を伴う小規模グループ | 親会社分の報酬に加え、子会社ごとの構成単位報酬。各社おおむねRM3,000以上 |

いずれかのレンジの下限を大幅に下回る見積りは、感謝ではなく、業務範囲についての
疑問を引き出すべきものである。330.3 A2のもとでは、そのような見積りを提示した事務所は
対処すべき自己利益の脅威を抱えていることになり、挙げられているセーフガードは、
報酬を調整すること、範囲を調整すること、あるいはレビュー担当者を追加することである
——このうち2つは、後になって何らかの代償をあなたに求めることになる。

## よくある誤り

- **係数表を現行のものとして引用すること。** それは2015年6月1日以降撤回されており、
  しかも廃止された法令のために書かれたものである。
- **RM800を法定の最低額として扱うこと。** それは撤回された文書の中の指針にすぎなかった。
- **MIAが報酬をめぐる紛争を仲裁してくれると思い込むこと。** 報酬は事務所と依頼者の間の
  商業上の事柄である。By-Lawsが定めるのは倫理上の境界であって、価格ではない。
- **含まれる業務が異なる見積りを比較すること。** 財務諸表の作成やMBRSへの提出が
  報酬に含まれているかどうかを、明確に確認すること。
- **記録が脆弱な状況で価格だけで選ぶこと。** 安い見積りは、試算表がきれいであることを
  前提に価格設定されており、2か月目には変更指示書が届く。
- **誰が報酬を定めるのかを忘れること。** Companies Act 2016のs.274のもとで、その権限は
  監査人を選任した者——社員、取締役会、または登記官——にある。

## 次のステップ

報酬は業務の内容に従って決まる。したがって次に役立つ問いは、その業務が実際には
何であるか——委嘱の受嘱から署名済み報告書に至るまでの一連の流れ——である。
