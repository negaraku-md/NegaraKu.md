あなたは、正式な肩書きと会計学の学位、そして長年の経験を備えた勅許会計士になることができる——それでもなお、一社の監査報告書に単独で署名することは許されないかもしれない。マレーシアでは、会社を監査する権利は独立した、厳格に管理された免許であり、専門職の会員資格に自動的に付随するものではない。

法律はこれを「認可会社監査人」（*approved company auditor*）と呼ぶ。この資格を有する者のみが、2016年会社法のもとで法定監査報告書を監査し、署名することができる。本稿では、そこに至るために経なければならない三つの段階を説明する。

## 「認可会社監査人」とはどういう意味か？

2016年会社法のもとで、「認可会社監査人」とは、s.263のもとで監査人として認可され、その認可が取り消されていない者を意味する。この表現は重要である。なぜなら、それは誰が正当な資格を有するかを絞り込むからである——どの会計士でもよいわけではなく、どの事務所でもよいわけでもない。

s.263は、この権限を財政を所管する大臣、すなわち財務大臣に与えている。大臣は、申請者が品行方正であり、同法のもとで監査人としての職務を遂行する能力を有すると認めるときは、その者を会社監査人として認可することができる。実務上、財務大臣はこの権限を会計総監へと委任しており、実際の申請はJANMに提出される。

認可は恒久的なものではない。更新も含め、各認可は発行日から二年間有効であり、大臣によってそれより前に取り消されない限り効力を持つ。

## その道の三つの段階とは何か？

資格取得を三段の階段だと考えてほしい。どの段も飛び越えることはできない。

1. **MIAの勅許会計士。** まず、1967年会計士法（Accountants Act 1967）のもとで、マレーシア会計士協会（MIA）に勅許会計士（*Chartered Accountant*）として登録しなければならない。これがこの専門職への入り口である。

2. **有効なMIA開業証明書（*practising certificate*）。** 会員資格だけでは公共実務を行うには不十分である。公共実務を行うことを認める、有効な開業証明書を保持する必要がある。

3. **s.263のもとでの認可（監査免許）。** 最後に、JANMに申請し、面接を受けて合格し、会社監査人としての認可を受ける。この第三段階を経て初めて、法定監査報告書に署名することができる。

三つの段階はすべて同時に有効でなければならない。開業証明書またはMIAの会員登録が失効すれば、監査資格も連動して影響を受ける。

## 申請の資格基準は何か？

第三段階が最も厳格である。JANMは、面接を受ける資格を得る前に、相当な経験の基準を設けている。

| 基準 | 要件 |
| --- | --- |
| 専門職としての地位 | MIAに登録された勅許会計士＋有効な開業証明書 |
| 国籍／居住資格 | マレーシア国民または居住者 |
| 累積経験 | 少なくともフルタイムで6年間の勤務 |
| MIA会員資格取得後の経験 | 少なくとも3年（海外で勤務した経験がある場合は2年） |
| 監査経験 | 少なくとも5年、うち直近2年はマレーシア国内での経験 |
| 監査時間・監査業務件数 | 直近5年間で監査時間7,500時間及び監査業務40件 |
| 監督者としての役割 | 監査主任（Audit Supervisor）として少なくとも1,800時間 |
| 誠実性 | 復権していない破産者でないこと／詐欺又は不誠実に関わる犯罪の有罪判決がないこと（s.264に沿い、期間の制限なし） |

さらに、初めて申請する者は、認可が与えられる前に、MIAが主催する公共実務プログラム（*Public Practice Program*）を修了しなければならない。

## 面接はどのように行われるか？

面接は主要な選抜の場であり、単なる形式ではない。審査団は、次の五つの機関の代表者で構成される。

- JANM（議長）
- 企業委員会（SSM）
- MIA
- 証券委員会（Securities Commission Malaysia、SC）
- マレーシア国立銀行（Bank Negara Malaysia、BNM）

面接で扱われる主題は、会計法制、コーポレートガバナンス、監査基準、財務報告要件、及び監督の枠組みに及ぶ。五つの監督機関の代表者が一つの審査団に同席していることは、この評価が単一の監督上の利害関係者にとどまらないことを示している。

## 費用はいくらで、手続きにはどれくらいかかるか？

直接的な費用は比較的手頃であるが、有効期間が短いため、それは繰り返し発生する。

| 項目 | 内容 |
| --- | --- |
| 申請／更新費用 | 電子決済によるRM500 |
| 認可の有効期間 | 発行日から2年間 |
| 更新期限 | 満了日の3か月前までに提出 |
| 更新の窓口 | BLESSシステム、法定宣言書＋MIA会員登録及び開業証明書の証明を添付 |
| 1年を超えて失効した場合 | 新規申請＋面接の再受験が必要 |

認可の有効期間はわずか二年であるため、現役の監査人はキャリアを通じて定期的な更新のサイクルを経ることになり、その間、有効なMIA会員登録と開業証明書を維持し続けなければならない。

## どのような場合に監査資格を失うか？

資格段階を満たすだけでは十分ではない——同時に、欠格事由のカテゴリーに該当してもならない。2016年会社法s.264は、次のいずれかに該当する場合、特定の会社の監査人として行動することを禁じている。

- 当該会社（または関連会社）に対しRM25,000を超える**債務**を負っていること；
- 当該会社の**役員**であること、またはその配偶者が役員であること；
- 当該会社の役員の**パートナー、雇用主又は従業員**であること；
- 当該会社の社員名簿又は社債権者名簿の**保管**を担っていること；
- 裁判所の許可なく、マレーシア国内又は国外において**復権していない破産者**であること；又は
- 三か月以上の禁錮に処せられうる詐欺又は不誠実に関わる犯罪について**有罪判決**を受けたこと。

その違いに注意してほしい。資格基準は、誰が*一般的に*監査人になれるかを定めるものであるのに対し、s.264は、ある者が*特定の会社*を監査するにあたり利害の対立がないかどうかを定めるものである。この禁止事項に違反した場合、RM100,000を超えない罰金が科されることがある。

## なぜこの制度が存在するのか？

監査報告書は、ある会社の財務諸表が信頼に足るものであることを示す公の声明である。投資家、融資者、税務当局、そして一般市民がそれに依拠している。それゆえ、国は誰でもそれに署名できるようにはしていない。

署名を認可された監査人に限定することによって——専門職の会員資格、積み上げられた経験、五つの監督機関による面接、そして定期的な更新を通じて選別することによって——この制度は、監査報告書の下に記された名前が専門性と説明責任の重みを担うことを確保しようとしている。例えば、監査済み財務諸表を提出する必要がある私会社の*Sdn Bhd*は、単に自社の内部会計担当者を任命するだけでは済まない。その会社は、パートナーが有効な監査免許を保有する事務所を任命しなければならない。

## 次に何をすべきか

- もしあなたが**監査人を目指す会計士**であれば、早い段階から監査時間と業務件数を記録しておくこと——7,500時間及び40件の基準を満たすには何年もかかり、JANMは直近5年間の記録を求める。
- もしあなたが監査人を選任する**会社オーナー**であれば、署名する事務所及びパートナーが、なお有効なs.263の認可を保持しており、s.264のもとでの利益相反がないことを確認すること。
- 法律の実際の文言については、マレーシア企業委員会のウェブサイトで2016年会社法s.263及びs.264の全文を参照し、申請前には会計総署及びMIAのウェブサイトで最新の申請ガイドラインを確認すること。基準は随時見直されるためである。
