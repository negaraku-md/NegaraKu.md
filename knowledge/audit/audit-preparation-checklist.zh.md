faq:
  - q: "PBC 是什么意思？"
    a: "Prepared by client，即客户预备。它是审计团队在实地工作之前与之中所需的明细表、核对表与支持文件的清单。一份好的清单会在规划阶段就送到、按循环编排，并为每一份明细表注明年结日期，好让你所产出的东西能与试算表勾稽得上。"
  - q: "我都已经给了分类账，审计师为什么还要供应商对账单？"
    a: "因为分类账无法证明完整性。一项从未被记录的负债，不会出现在你自己的记录里。供应商对账单是第三方证据，而利用年结后付款来搜寻未记录负债，则是从另一个方向做同一件事。"
  - q: "我必须让审计师查阅会议记录簿与各项登记册吗？"
    a: "必须。Companies Act 2016 第 266(4) 款赋予审计师在一切合理时间查阅会计与其他记录（包括各项登记册）的权利。第 266(12) 款订明，阻挠或拖延审计师即属犯罪，可判最高三年监禁或最高 RM500,000 罚款。"
  - q: "MFRS 124 之下什么算关联方？"
    a: "它的涵盖范围比多数财务团队所预期的更广——母公司、子公司与同集团子公司、联营公司与合营企业、主要管理人员及其近亲家属，以及由上述任何人控制或共同控制的实体。一家由某董事配偶拥有、并向你采购的公司就是关联方，而该项交易即使按公平交易定价，仍须披露。"
  - q: "我应该提前多久开始准备？"
    a: "核对表与明细表应在年结后三到四周内完成。任何需要第三方配合的事项——银行询证函、律师函、与另一个国家的同集团子公司议定公司间协议——都应在第一周启动，因为那些是以周计的，而且不在你的掌控之内。"
  - q: "我可以给审计师管理账目来代替试算表吗？"
    a: "不可以。实地工作是针对一份锁定的试算表进行的。若试算表一直在动，每一份已经测试过的明细表都得重新勾稽，而那是把两周的实地工作变成六周最快的方法。"

索取清单看起来像一份行政文件。它不是。它是审计计划，翻译成你必须产出的东西，
而它上头的每一行，都是为了支持财务报表所作出的某一项特定主张。

一旦你看得出那是哪一项主张，你就不再为文件争论，而开始提供真正管用的那些。

## 一切所对应的六项认定

| 认定 | 受测试的主张 | 典型证据 |
| --- | --- | --- |
| **存在** | 该资产或交易是真实的 | 实物检查、第三方询证 |
| **完整性** | 没有任何东西被遗漏 | 搜寻未记录负债、供应商对账单、核对表 |
| **计价** | 金额是对的 | 成本计算、账龄、减值与可收回性分析 |
| **权利与义务** | 公司拥有它，或欠着它 | 所有权文件、协议、抵押登记册 |
| **截期** | 它属于本期 | 年结日两侧的交易 |
| **呈列与披露** | 它在附注中被正确描述 | 关联方分析、承担、或有事项 |

完整性是难的那一项，因为你自己的记录无法证明它。
这正是审计师不断索取由公司外部产生的东西的原因。

## 在一切之前——那三项会拖垮期限的

**1. 对不上的公司间往来余额。** 每一笔公司间往来余额，在另一个实体的分类账里都有一面镜子。
若两者哪怕只是差了一张在途支票，合并就无法进行，抵销也清不掉。
在实地工作之前，与对手方核对，并让对手方在核对表上签署。
在有外国子公司的集团里，还要把时区与不同的结账日程算进去。

**2. 从未被识别出来的关联方。** MFRS 124 失败在识别阶段，不是披露阶段。
从源头建立名单：董事登记册、成员登记册、董事的利益申报，
以及与股东直接谈一次他们还拥有些什么。一家由某董事配偶控制的公司是关联方。
一家由某股东成年子女控制的公司也是。按公平交易定价并不能免去披露。

**3. 没有支持文件的董事往来账变动。** 一个全年在动、背后却只有日记账分录的董事往来账，
必然会被质询。所需要的是授权——董事会会议记录、相关情况下的贷款协议、
该笔付款用途的证据，以及已经考虑过的税务处理。这同时是审计问题、披露问题与税务问题，
而它所产生的迟来调整，比任何其他单一项目都多。

## 清单，按循环编排

### 总分类账与法定记录

| 项目 | 所支持的认定 |
| --- | --- |
| 最终试算表，已锁定，与财务报表草稿勾稽得上 | 全部 |
| 上年度已签署的财务报表与审计调整 | 期初余额 |
| 全年的总分类账明细与日记账清单，包括所有手工日记账 | 完整性、发生 |
| 全年直至报告日期的董事与成员会议记录 | 权利、期后事项、披露 |
| 成员登记册、董事登记册、抵押登记册、实益拥有权登记册 | 权利、呈列 |
| 公司章程及其任何修订 | 呈列 |

法定登记册往往被当作公司秘书的杂务。在审计中它们是证据，
而 s.266(2)(b) 要求审计师就是否已按 Act 的要求保存**妥善的会计与其他记录，
包括各项登记册**形成意见。

### 收入与应收账款

| 项目 | 所支持的认定 |
| --- | --- |
| 应收账款账龄清单，与分类账控制账户勾稽得上 | 存在、计价 |
| 年结日两侧最后与最初两周的销售发票与交货文件 | 截期 |
| 年结后开出的贷记单 | 发生、计价 |
| 预期信贷亏损的计算及其依据 | 计价 |
| 年结后的收款，与年结余额配对 | 存在、计价 |
| 客户询证请求的已签署授权 | 存在 |

### 采购与应付账款

| 项目 | 所支持的认定 |
| --- | --- |
| 应付账款账龄清单，与分类账勾稽得上 | 完整性 |
| 最大余额的供应商对账单，已核对 | 完整性 |
| 年结后所作的付款，连同其所结清的发票 | 完整性、截期 |
| 年结日两侧的收货单 | 截期 |
| 应计明细表，载明每一项应计的依据 | 完整性、计价 |

### 存货

| 项目 | 所支持的认定 |
| --- | --- |
| 书面盘点指示，于盘点前发出 | 存在 |
| 最终盘点表，已签署且已预先编号 | 存在 |
| 成本计算基础，以及成本构成的抽样 | 计价 |
| 可变现净值分析、年结后的售价 | 计价 |
| 呆滞与陈旧分析，连同拨备政策 | 计价 |
| 在途货物、寄售与第三方存放地点 | 存在、权利 |

### 固定资产

| 项目 | 所支持的认定 |
| --- | --- |
| 固定资产登记册，与分类账核对相符 | 存在、完整性 |
| 添置的发票与处置的证据 | 权利、发生 |
| 折旧的计算与政策 | 计价 |
| 所有权文件，以及租购或租赁协议 | 权利 |
| 已书面考虑过的减值迹象 | 计价 |

### 现金与借款

| 项目 | 所支持的认定 |
| --- | --- |
| 每一个户口的银行核对表，包括休眠户口 | 存在、完整性 |
| 已签署的银行询证授权，于第一周发出 | 存在、权利 |
| 贷款与授信协议，包括契约条款 | 呈列、持续经营 |
| 已向 SSM 登记的抵押，与抵押登记册核对相符 | 权利、披露 |

### 薪资与法定扣除

| 项目 | 所支持的认定 |
| --- | --- |
| 薪资汇总，与分类账核对相符 | 准确性 |
| EPF、SOCSO、EIS 与 PCB 的缴交证据，与薪资核对相符 | 完整性 |
| 董事酬金分析，按类别分列 | 披露 |
| 假期、花红与其他拨备的计算 | 完整性、计价 |

### 税务

| 项目 | 所支持的认定 |
| --- | --- |
| 上年度税务计算，以及所收到的评税或通知 | 计价 |
| 本年度计算草稿，连同递延税项的工作底稿 | 计价、呈列 |
| CP204 与 CP204A 的呈交，连同付款记录 | 完整性 |
| 资本减免明细表，与固定资产登记册核对相符 | 计价 |

### 关联方与披露

| 项目 | 所支持的认定 |
| --- | --- |
| 完整的关联方清单，载明关系的依据 | 完整性、披露 |
| 与每一方的交易与余额，以及定价依据 | 披露 |
| 主要管理人员的薪酬，按类别分列 | 披露 |
| 依 s.221 作出的董事利益申报 | 完整性 |
| 承担、担保与或有负债 | 披露 |
| 律师的联络资料，供发出询证函之用 | 完整性 |

### 收尾用

| 项目 | 所支持的认定 |
| --- | --- |
| 关于持续经营的董事会文件，连同其背后的现金流预测 | 持续经营 |
| 报告期后事项，以及对每一项所采用的处理方式 | 期后事项 |
| 涵盖 Fifth Schedule 各项要求的董事报告草稿 | 呈列 |

## 不在清单上、却应该在的东西

**一份锁定的试算表。** 实地工作开始后的每一次变动，都会使已完成的工作失效。
议定一个锁定日期，并且守住它。

**单一联络窗口。** 经由多个人转手的审计疑问会产生不一致的答案，
而不一致的答案会产生更多疑问。

**一份共享的疑问记录表。** 未结事项、负责人、提出日期、清结日期。
多数审计延误并不是因为难，而是因为疑问躺在收件箱里没人回。

**去年的审计调整，确实已经过账。** 在结案会议上议定却从未入账的调整，
会以往年差异的形式再度出现，然后同一场对话再来一次。

## 这一切底下的法定底线

Companies Act 2016 第 245 条要求保存足以说明交易与财务状况的会计与其他记录，
且其保存方式须使它们能被**方便且妥善地审计**。其中有两个时钟经常被漏掉：
分录须在交易完成后 **60 天**内作出，以及记录须保存 **七年**。
违反者，公司与每一名高职人员可被处以最高 **RM500,000** 罚款或三年监禁。

这一切都不取决于有没有审计。这正是一家取用了审计豁免的公司，
仍然必须保存同样记录的原因。

## 常见错误

- **拿文件来代替核对表。** 一份分类账打印本不是核对表，
  也回答不了一个关于完整性的问题。
- **把银行与律师询证函留给审计师去跟进。** 到了第六周，你没办法让它们变快。
- **从分类账去识别关联方。** 关联方是从各项登记册与股东那里识别出来的，
  然后才追查到分类账。
- **把董事往来账当作调平用的塞子。** 那是复核者第一个看的地方。
- **在实地工作期间变动试算表。**
- **等审计师开口才准备持续经营文件**，那正是它不再像「董事会自己的评估」的那一刻。
- **以为审计师会起草披露附注。** 依 s.244 与 s.248，编制财务报表是董事的责任，
  无论是谁敲的键盘。

## 下一步

这个流程所产出的调整，并不止于财务报表——经审计的盈利是税务计算的起点，
而一项迟来的调整同样会牵动税务数字。
