ある企業が、自社の主要株主が所有する別の会社に粗パーム油を販売する。請求書のどこにも、それが通常の供給契約なのか、それとも少数株主から価値を抜き取る第一歩なのかは書かれていない。監査人の仕事は、そのどちらであるかを突き止めることである——そしてそれこそが、国際監査基準第550号「関連当事者」（International Standard on Auditing 550, *Related Parties*）が書かれた目的そのものである。

## 関連当事者とはそもそも何か？

ISA 550 para 10は、適用される財務報告フレームワークにおける定義を指し示しており、マレーシアにおいてそれはMFRS 124『関連当事者の開示』（*Related Party Disclosures*）——IAS 24のマレーシアにおける対応基準であり、2012年1月1日以後に開始する年次期間から適用される——である。大まかに言えば、関連当事者とは、当該事業体を支配し、それに支配され、又はそれと共通の支配下にある当事者、及び主要経営陣とその近親者を指す。

同じ段落は、この検討全体が拠って立つ基準も定義している。**独立第三者間取引（arm's length transaction）**とは、「互いに関連がなく、それぞれ独立して行動し、自らの最善の利益を追求する、自発的な買主と自発的な売主の間で」行われる取引をいう。関連当事者について懸念されるのは、まさにこの独立性が欠けているかもしれないという点である。

## なぜこれらの取引を特に取り上げるのか？

それらが財務諸表不正の典型的な手口だからである。ISA 550 para 2は、多くの関連当事者取引が日常的なものであり、無関係の相手との取引よりもリスクが高いわけではないことを率直に認めている。しかし同基準は、関連当事者取引が通常の市場条件のもとで行われているとは限らないこと、そしてそうした関係が共謀・隠蔽・操作のより大きな機会を生み出しうることも警告している。

だからこそpara 18は明確な一線を引いている。監査人は、識別された、事業体の通常の事業活動の過程の範囲外にある重要な関連当事者取引を、**特別な検討を必要とするリスク（significant risk）**を生じさせるものとして扱わなければならない——これは監査上の注意の最高位の階層であり、特定の対応を要する。

## 監査人は実際に何を行うのか？

ISA 550は、日常的な質問から的を絞ったテストに至るまでの段階を定めている。次の表は主な要求事項を示したものである。

| 段階 | ISA 550の要求事項 | 参照 |
| --- | --- | --- |
| 質問 | 関連当事者の識別、関係の性質、及び取引の有無について経営者に質問する | Para 13 |
| 統制の理解 | 事業体が関連当事者取引をどのように識別し、授権し、承認しているかを理解する | Para 14 |
| 警戒を怠らない | 記録を閲覧する際、未開示の関係がないか注意する——銀行確認書、法律事務所確認書、取締役会及び株主総会の議事録 | Para 15 |
| リスクの評価 | 通常の事業活動の過程の範囲外にある重要な取引を、特別な検討を必要とするリスクとして扱う | Para 18 |
| 例外的取引のテスト | 基礎となる契約を閲覧し、不正の観点から事業上の合理性を評価し、授権及び承認の証拠を入手する | Para 23 |
| 主張への疑問 | 経営者が取引を独立第三者間取引であったと主張する場合、その主張について十分かつ適切な証拠を入手する | Para 24 |
| 書面での確認 | すべての関連当事者及び取引が開示され、適切に会計処理されている旨の書面による確認を取得する | Para 26 |
| 報告 | 重要な関連当事者事項を統治責任者に報告する | Para 27 |

中心となる手続はpara 23である。通常の事業活動の過程の範囲外にある重要な取引について、監査人は契約を閲覧し、事業上の合理性——又はその欠如——が不正な財務報告や資産の流用の隠蔽を示唆していないかを問い、条件が経営者の説明と一致しているかを確認し、当該取引が適切に授権されていたことを確かめる。

## Bursa Malaysiaはどこで別の層を加えるのか？

上場発行体にとって、財務報告と監査は三つの層のうち二つにすぎない。第三の層は、Bursa Malaysiaメインマーケット上場規則のもとでのコーポレートガバナンスである。

| 層 | 根拠 | 規律する内容 |
| --- | --- | --- |
| 開示 | MFRS 124 | 財務諸表が関連当事者及びその取引について開示しなければならない内容 |
| 監査 | ISA 550 | 監査人が虚偽表示リスクをどのように識別し、評価し、対応するか |
| ガバナンス | Bursa第10章 | 上場発行体がいつ公告を行い、通知書を発行し、又は株主の承認を求めなければならないか、及び利害関係者が議決を棄権すること |

第10章のもとでは、収益的又は取引的性質を有する経常的な関連当事者取引は、通常、para 10.09が想定するとおり、年次株主総会ごとに更新される**株主授権（shareholders' mandate）**を通じて処理される。一回限りの関連当事者取引は、para 10.02のパーセンテージ比率によって測定されるその規模に応じて、直ちに公告を行うこと、株主への通知書（circular）の発行、及び株主総会での事前の承認——利害関係を有する取締役又は主要株主は議決権の行使を禁じられる——を要することがある。

## 投資家は注記の中で何に注目すべきか？

関連当事者に関する注記は、次のチェックリストに照らして読むとよい。価格条件は明示されているか、そしてそれは独立第三者間取引であると主張しているか——もしそうであれば、その根拠は何か。経常的な取引は、現行の株主授権によってカバーされているか。通常の事業活動の過程の範囲外にある取引はなかったか、あったとすればそれは独立して承認されたか。沈黙、あいまいな「市場条件」という表現、あるいは取締役と関係のある事業体に対する多額の未払残高は、ISA 550がまさに明るみに出すよう設計されているシグナルである。

## 次のステップ

ある関連当事者取引が自分の判断にとって重要と思われる場合は、三つの層すべてをたどって確認するとよい。すなわち、MFRS 124の開示注記、Bursa Malaysiaのウェブサイト上にある第10章の公告又は通知書、そして監査意見そのものである。こうした取引がより広い監査全体にどのように組み込まれるかを知るには、法定監査プロセスと監査人がどのように意見を形成するかについての記事を読むとよい。関連当事者が経営難に陥った事業を支えていた場合には、継続企業（ゴーイング・コンサーン）が次に確認すべき関連リスクである。
