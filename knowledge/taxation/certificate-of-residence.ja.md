この証明書は、あなたがマレーシア人であることの証拠ではない。特定の協定相手国が、あなたを特定の租税条約（DTA）の適用対象として認めなければならないことの証拠である。LHDNは自らのページでそう述べている——この証明書は、租税条約（DTA）に基づく特典を申請し、同一の所得に対する二重課税を避けるために発行されるものであり、したがって**その目的のためだけに**、かつマレーシアの条約相手国に対してのみ発行される。この一文が、却下の大半を説明している。

## 申請前に居住者資格を確立する

この証明書が確認するのは、別の場所で判定された資格である。LHDNは四つの条文を挙げている。

| 申請人 | テスト |
| --- | --- |
| 個人 | 1967年所得税法（Act 53）の s.7 |
| 会社、人の団体、LLP、事業信託 | 1967年所得税法（Act 53）の s.8 |
| 信託団体 | 1967年所得税法（Act 53）の s.61(3) |
| ラブアン事業体 | 1990年ラブアン事業活動税法（Labuan Business Activity Tax Act 1990）の s.3B |

会社については、s.8 は経営及び管理がどこで行われているかにかかっている。Public Ruling 9/2019 の立場は容赦がない——クアラルンプールで開催され、海外の取締役がビデオ会議で出席した取締役会は、経営及び管理を構成**しない**と判断されており、マレーシアでの事業活動、取締役及び株主の存在は明示的に無関係とされている。申請の後ではなく、申請の前に取締役会の運営プロセスを整えておくこと。

## e-Residenceでの申請

**2023年2月1日**以降、条約目的の申請はe-Residenceを通じて行わなければならない。これにより、受け取る側の外国税務当局が証明書を直接確認できるようになる。マレーシアと協定が**ない**国については、代わりに**Form STM1**を証明書類とともに電子メールで提出する。

## 申請人の種類ごとに必要なアップロード書類

| 申請人 | 証明書類 |
| --- | --- |
| 個人 | パスポートの全ページ。パスポートの記録が不完全な場合、又は自動化ゲート（オートゲート）を利用できる場合は、移民局の出入国記録も必要 |
| 会社 | 経営及び管理がマレーシアで行われていることを示す取締役会議事録又は取締役の確認書、加えて取締役及び役員に関する最新のSSM抄本 |
| クラブ、団体又は類似の組織 | 運営委員会又は年次総会（AGM）の議事録、又は確認書、加えて所轄当局が発行する最新の役員名簿抄本 |
| LLP | LLP契約書、加えて組合員の議事録又は経営及び管理に関する確認書 |
| パートナーシップ | 各パートナーの区分に対応する書類、加えて所轄当局が発行するパートナー名簿の抄本 |
| 信託団体 | 信託証書、加えて受託者の区分に対応する書類 |
| 事業信託 | 信託証書、加えて受託管理者がその立場でマレーシアにおいて当該事業を営んできたこと、及び経営及び管理がここで行われていることを確認する書簡 |
| ラブアン事業体 | 非市民である取締役のパスポート及び出入国記録シート、取締役会議事録、経営及び管理に関する確認書、Form 25及びForm 27 |

自動化ゲート（オートゲート）の点は見落とされがちである。オートゲートで入国審査を通過すると、パスポートにスタンプが押されないため、マレーシアでの滞在日数を証明できない。着手する前に、移民局の出入国記録を取得しておくこと。

## 処理過程、及び受け取るもの

- 申請が提出されると、確認票（スリップ）が表示される。
- 書類が完全かつ整然としていることを条件に、証明書は提出から**10営業日**以内に処理される。
- 承認は**PIN**が記載された電子メールで届く。
- 申請人はそのPINを用いて、e-Residenceポータルから証明書を印刷する。
- 証明書はポータルによって生成され、**署名は付されない**——これは意図的な設計であり、署名がないことを問い合わせる条約相手国には、検証機能を案内すること。
- **費用は課されない**。

## よくある誤り

**未申告の申告書がある状態で申請すること。** LHDNは明確に、すべての書類が完全かつ適正に提出されている場合に限り申請が処理されると述べており、**そこには完全かつ最新の所得税申告書の提出も含まれる**。期限を過ぎたForm C又はForm BEがあると、申請は審査される前に止められる。

**LHDNに相手方の様式への署名を求めること。** このサービスはすでに廃止されている。e-Residenceの証明書自体がその確認となる。

**協定のない国についてe-Residenceを使用すること。** 代わりにForm STM1を電子メールで使用すること。

**経営及び管理を示さない取締役会議事録を送付すること。** 回覧により署名された決議、又は参加者が海外から電話会議で参加した会議の議事録は、まさにPublic Ruling 9/2019が否定する事実関係そのものである。

**パスポートを不完全なまま提出すること。** 全ページ、そして空白期間があれば移民局の出入国記録も必要である。

## 次のステップ

早めに申請すること。処理期間は10営業日だが、証拠——マレーシアで適正に開催された取締役会、移民局の出入国記録、最新のSSM抄本——を揃えるのには、通常、様式への記入よりも長い時間がかかる。外国の支払人が条約税率で源泉徴収するためにこの証明書を必要とする場合、それは支払いの前に、後ではなく、その支払人の手元になければならない。

問い合わせは `cor@hasil.gov.my` 宛て。自社が s.8 の基準を満たすか疑わしい場合は `company-tax-residence` を、協定の存在を確認する場合は `dta-network` を参照すること。
