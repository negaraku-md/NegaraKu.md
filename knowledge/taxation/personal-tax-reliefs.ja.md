有効に申請できる減免の1リンギットごとに、あなたの課税所得はその分減る——そしてマレーシアの個人税制は累進的であるため、ある減免の価値は、それがどの税率区分に該当するかによって決まる。申告する前に、見落としているものがないか、このチェックリストで確認してほしい。

## ほぼ誰もが申請する中核的な減免

| 減免カテゴリー | 対象となるもの | 一般的な上限（当年度で要確認） |
| --- | --- | --- |
| 個人（本人） | すべての居住者納税者に自動的に適用される減免 | 固定額、領収書不要 |
| 配偶者 | 無職の配偶者、又は合算課税を選択した場合 | 固定額 |
| 子女 | 18歳未満の未婚の子女、又は全日制教育を受けている子女 | 子女ごとの金額、高等教育／障害のある子女は増額 |
| EPF及び生命保険 | EPF拠出金と生命保険料を合算 | 合算年間上限 |
| SOCSO／EIS拠出金 | SOCSO及び雇用保険制度（EIS）への従業員拠出分 | 別枠の小額上限 |

## チェックリスト：申告前に確認すべき減免

- [ ] **個人減免（individual relief）**——自動的に適用される。適用されていることを確認すること。
- [ ] **配偶者減免又は合算課税**——今年、あなたの世帯にとって個別課税と合算課税のどちらが有利な結果になるかを判断すること。
- [ ] **子女減免**——18歳未満の未婚の子女、又は全日制教育を受けている子女ごとに（高等教育についてはより高い金額、障害のある子女については別区分を含む）。
- [ ] **父母扶養減免（parental care relief）**——父母の医療、特別なニーズ、又は介護に係る費用。父母の所得及び居住に関する条件に従う。
- [ ] **EPF及び承認された制度への拠出**——申請しようとしている金額がEPF明細と一致しているか確認すること。
- [ ] **生命保険及びタカフル保険料**——多くの納税者にとってはEPFと一つの上限のもとで合算される。年金制度のもとにある公共部門の従業員は、異なる仕組みとなる。
- [ ] **医療保険／教育保険料**——一般の生命保険とは別の減免カテゴリーである。
- [ ] **本人、配偶者又は子女の医療費**——重病治療、不妊治療、予防接種、健康診断は、それぞれより広い医療減免の中で独自の小上限を持つ。
- [ ] **生活方式減免（lifestyle relief）**——書籍、雑誌、コンピューター、スマートフォン、インターネット契約、及びスポーツ・ジム費用を、一つの合算年間上限にまとめたもの。
- [ ] **スポーツ向け追加の生活方式減免**——年度によっては、スポーツ用品及び大会参加費に特化した、一般の生活方式上限とは別の小額の減免が設けられることがある。
- [ ] **託児減免（childcare relief）**——所定の年齢までの子女について、登録された託児センター又は幼稚園に支払った費用。
- [ ] **障害のある本人、配偶者又は子女の減免**——標準のカテゴリーに加えて適用される追加の固定減免であり、社会福祉局（Department of Social Welfare、JKM）への登録が必要である。
- [ ] **SSPN（国家教育貯蓄制度）純預入額**——子女の教育のためのSSPN口座における純貯蓄増加額。
- [ ] **国内旅行又はPRS（私的退職スキーム、Private Retirement Scheme）減免**——当該賦課年度についてなお有効であれば。一部の減免は一時的なものであり、すべての予算案で繰り返されるわけではない。

## よくある誤り

- 前年度の規則の記憶に基づいて、直近の予算案で失効又は上限が変更された減免カテゴリーを申請してしまうこと。
- 標準の子女減免と障害のある子女の減免の両方で同じ子女を二重に計上してしまうこと。それらが想定したような形で加算されるものではないことを確認しないまま。
- 医療、生活方式及び教育の各減免にはそれぞれ独自の書類要件があることを忘れてしまうこと——申告書に添付する必要がなくても、領収書及び登録番号は保管しておくべきである。
- 合算課税が常に有利だと思い込んでしまうこと——収入が同程度の共働き夫婦にとっては、個別課税の方が効率的な場合もある。
- 減免の申告期限そのものを逃してしまうこと——Form BE／Bの提出後の修正期間の外では、減免を遡って申請することはできない。

## 次のステップ

減免は個人税制の中で課税所得を減らすだけであり、事業がどのように課税されるかとは無関係である。あなたがSdn Bhdも経営しているなら、法人税率の仕組みは別途確認すること。また、雇用主として、法定拠出金が従業員が後に減免として申請できるものとどのように関わるかを理解したいのであれば、EPF及びSOCSOガイドを参照すること。
