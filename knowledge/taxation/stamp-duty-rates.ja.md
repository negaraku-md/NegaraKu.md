印紙税は**取引ではなく法律文書**に対して課される。同一の商取引であっても、何に署名したか、そしてFirst Schedule（第一附則）のどの項目に該当するかによって、税額はゼロのこともあれば、RM10のこともあれば、六桁になることもある。項目を正しく特定することがこの作業のすべてであり——自己評価制度のもとでは、それは今や徴収官（Collector of Stamp Duties）ではなく納税者自身の仕事である。

## 従価印紙税の法律文書

| 項目 | 法律文書 | 税額 |
| --- | --- | --- |
| **32(a)** | 株式（stock、shares）、有価証券及び一定の帳簿上の債権を除く、不動産の譲渡又は売却 | 対価又は市場価値のいずれか高い方を基準に：最初のRM100,000については**RM100につきRM1**；RM100,000を超えRM500,000までは**RM100につきRM2**；RM500,000を超えRM1,000,000までは**RM100につきRM3**；RM1,000,000を超える部分は**RM100につきRM4** |
| **32(aa)** | **非住宅**不動産を**外国会社、又は市民でなくかつ永住者でもない者**へ移転する場合 | 対価又は市場価値のいずれか高い方を基準に、一律**RM100につきRM4** |
| **32(ab)** | 2026年1月1日以降、**住宅**不動産を**外国会社、又は市民でなくかつ永住者でもない者**へ売却する場合 | 対価又は市場価値のいずれか高い方を基準に、**RM100につきRM8**——**8%** |
| **32(b)** | 株式又は有価証券の移転 | 移転日における価格又は価値のいずれか高い方を基準に、RM1,000ごと又はその端数ごとに**RM3**——**0.3%** |
| **32(c)** | ファクタリング契約に基づき、免許銀行、マーチャントバンク又はファイナンス会社へ売掛金又は帳簿上の債権を絶対的に売却する場合 | **RM10** |
| **27(a)(iii)** | 金銭の返済のための主たる担保である担保権又は抵当権、一般の場合 | RM1,000ごと又はその端数ごとに**RM5**——**0.5%** |
| **27(a)(i)** | 同上、ただし貸付又はシャリア・ファイナンス（Syariah financing）が**中小企業**向けである場合 | 暦年における貸付合計額の最初のRM250,000についてはRM1,000ごとに**RM0.50**；RM1,000,000までの追加額についてはRM1,000ごとに**RM2.50**；それを超える追加のRM1,000ごとに**RM5** |
| **27(a)(ii)** | 外貨建て貸付、又はリンギット以外の通貨によるシャリア・ファイナンス | RM1,000ごと又はその端数ごとに**RM5** |
| **27(b)** | 主たる担保が適正に印紙を貼付されている場合の、担保、補助、追加又は代替の担保 | 主たる担保にかかる税額の**5分の1**、**上限RM10** |
| **27(c)** | 衡平法上の抵当（equitable mortgage） | 担保権にかかる税額の**2分の1** |
| **22(1)(a)** | 確定期間について一定額を担保する債券、契約、貸付、サービス又は設備リース契約 | その総額について**担保権又は抵当権**と同じ従価税額 |
| **49A** | 融資又は返済の担保のための、Al-Ijarah原則に基づくリース又はリース契約 | その総額について**担保権又は抵当権**と同じ従価税額 |
| **71** | 無記名の株式ワラント又は株券 | **RM100ごとにRM1** |

## リース及び賃貸借——item 49

Item 49(a)は、権利金（fine）又はプレミアム（premium）がない場合に適用される。税額は、**平均年間賃料及びその他の対価**、並びに**期間**による。

**この細目はFinance Act 2024（Act 862）により全面的に置き換えられ、2025年1月1日から施行されている。** 現行の比例表は、年間賃料の**RM250ごと又はその端数ごと**に、次のとおり課される：

| リースの期間 | RM250ごと又はその端数ごとの税額 |
| --- | --- |
| 1年を超えない場合 | **RM1.00** |
| 1年を超え3年を超えない場合 | **RM3.00** |
| 3年を超え5年を超えない場合 | **RM5.00** |
| 5年を超える場合、又は無期限の場合 | **RM7.00** |

ここでの二つの変更は、ほとんど誰もが見落としがちである：

- **RM2,400の免税枠は廃止された。** 置き換え後の細目には免除の閾値が含まれていないため、賃料の最初の1リンギットから税額が発生する。今なお「年間賃料がRM2,400以下であれば税額なし」と記載している案内は、既に廃止された法律を説明しているものである。
- **上位の税率が引き上げられ、区分も一つ追加された。** 旧比例表は3区分のRM1／RM2／RM4であったが、現行は4区分のRM1／RM3／RM5／RM7である。

Item 49のその他の細目：

- **49(b)**——賃料なしで権利金又はプレミアムを対価とする場合：その対価についての**譲渡証書**と同じ税額。
- **49(c)**——権利金又はプレミアムに加えて賃料もある場合：権利金又はプレミアムについては**譲渡証書**の税額を、**さらに**賃料についてはリースの税額を課す。
- **49(d)**——土地の産出物の一定割合又は比率を留保する場合：(a)、(b)又は(c)のもとでの税額に加えて**RM10**。
- **49(e)**——適正に印紙を貼付された契約に基づいて付与され、当該契約を提示する場合：**RM10**。
- **49(f)**——その他の場合：**RM10**。

**免除：** 確定期間が3年を超えず、留保賃料が年RM200を超えない農業用リース。

## Item 4に組み込まれた免除

Item 4は、あらゆる場合を包括する契約項目であり、そのRM10という税率よりも、それ自体の免除リストの方が重要である。次のいずれかに該当する契約又は覚書である場合、当該法律文書には課税**されない**：

- 物品、商品又は商材の販売に関する、又はこれに係るもの（割賦購入契約を除く）；
- **賃金が月額RM3,000を超えないサービス又は個人の雇用**に関するもの、及び船舶の船長と船員との間の賃金に関する契約——この閾値は、**Finance Act 2025（Act 874）により2026年1月1日から、RM300からRM3,000へ引き上げられた**；
- 対象事項の価額がRM300未満であるもの；
- 事項を仲裁に付するためのもの；
- 銀行に預け入れられた金銭についての利息の支払のためのもの；
- マレーシア国立銀行（Bank Negara Malaysia）が発行を認可した譲渡性預金証書の買戻しのためのもの。

この変更の意義は、item 4のRM10という税率をはるかに超える。2025年末まで、RM300という閾値は低すぎたため、事実上あらゆる雇用契約が課税対象であった。2026年1月1日からは、月額**RM3,000以下**を支払う契約は免除となり、これによりマレーシアの労働人口のかなりの部分が課税の対象から完全に外れることになる。

## 最低税額規則

Act 862により追加され、**2025年1月1日**から施行されているsection 36CBは、ある法律文書についての税額が**RM10未満となる場合には、代わりにRM10の税額を課す**と定めている——小切手及び契約ノート（contract note）を除く。したがって、少額の従価計算は、わずか数リンギットを算出するのではなく、RM10に切り上げられることになる。

## 免除及び減免の探し方

三つの別個の仕組みがあり、それらは互換性がない：

- **s.35のもとでの一般的な免除**——First Scheduleの中で「General Exemptions」という見出しのもとに列挙されている。
- 個々の項目に付随する**特定の免除**——とりわけitem 2、4、23、24、32、49及び58。
- **s.80のもとでの大臣による免除又は減免**——財務大臣により付与され、P.U.(A)命令として官報告示される。これを申し立てる際は、官報番号を引用するか、財務省の免除書を提示しなければならない。

別途、**s.15及びs.15Aのもとでの減免**は、会社の再編及び合併、並びに関連会社間の不動産の移転を対象とする。申請は、通常の押印手続ではなく、関係する州局長事務所（State Director's Office）へ提出する。

## よくある誤り

- **取引に対して課税してしまうこと。** 印紙税は個々の法律文書に付着するため、三通の署名済み契約書で記録された一つの取引には、三回税額が発生し得る。
- **item 32(aa)及び32(ab)を見落とすこと。** 外国人又は非市民の譲受人は、非住宅不動産については一律4%を、2026年1月1日からは住宅不動産について8%を負担する——1%から始まる区分ではない。
- **株式移転に上限を適用してしまうこと。** Item 32(b)には金額の上限がない——それは全額の価格又は価値に対する0.3%である。人々が記憶しているRM1,000の上限は、item 31のもとでの契約ノートに属するものである。
- **副本を忘れること。** 複本にはitem 34(b)のもとでRM10がかかる。
- **RM2,400のリース免除を引用すること。** これは2025年1月1日に廃止された。
- **旧RM1／RM2／RM4のリース比例表を引用すること。** 現在は4区分のRM1／RM3／RM5／RM7である。
- **会社の定款を見落とすこと。** Item 29AはRM200を課す。

## 次のステップ

何かを計算する前に、まずFirst Scheduleの項目を特定すること——自己評価の誤りは項目の選択から生じるものであり、項目さえ確定すれば税率は機械的に導かれる。次に、s.80の命令又はs.15の減免が適用されるかどうかを確認すること。これらは自動的に適用されるのではなく、申し立てて初めて適用されるものだからである。
