收据上印着*依第 44(6) 款免税*。这句话是慈善机构自己印上去的，不是 LHDN 印的，
而且它只在批准仍然有效的期间才成立。批准是会失效的。LHDN 自家的查询工具就带着
一个对应的状态值——**TAMAT TEMPOH KELULUSAN**，批准已到期——旁边还有
**KELULUSAN DITARIK BALIK**，批准已撤回。在这段空窗期捐出去，扣除就没了，
不管这笔赠与多么真心实意。

## s.44(6) 究竟允许什么

依 Income Tax Act 1967 s.44(6)，以下金钱赠与可从总收入中扣除：

- 捐给联邦政府、州政府或地方政府——**没有上限**；或
- 捐给由**总监应该机构申请而批准的机构、组织或基金**——**上限为总收入的 10%**。

扣除是从**总收入**中扣，在任何 s.44(1) 调整之后。它不能制造亏损，也不能结转。
捐得比你消化得了的还多，超出的部分就是白白没了。

请注意什么不符合资格。Section 44(6) 只涵盖**金钱赠与**。货物、服务、义工时间与
实物赞助都在它之外，而确实存在的实物途径都很窄——依 s.44(6A) 捐给政府的文物、
手稿与画作，依 s.44(9) 供残疾人士使用的设施，依 s.44(10) 捐给获批医疗设施的
医疗器材，以及依 s.44(11) 捐给国家或州立美术馆的画作。

## 那 10% 是一个额度，不是四个

这是连称职的报税代理都还会弄错的地方。第 44(11B)、(11C) 与 (11D) 款的但书，
各自把扣除上限定在*总收入的 10% 减去已在另外三项下扣除的总额*所得的差额。
与 s.44(6) 合起来读，效果就是一个共用的上限。

| 条文 | 赠与 | 是否共用 10% 上限 |
| --- | --- | --- |
| s.44(6) | 捐给获批机构、组织或基金的金钱 | 是 |
| s.44(11B) | 用于部长批准的体育活动的金钱 | 是 |
| s.44(11C) | 用于部长批准的国家利益项目的金钱或实物 | 是 |
| s.44(11D) | 捐给获批宗教当局或团体的 wakaf，或捐给公立大学的捐赠基金 | 是 |
| s.44(6) | 捐给政府、州政府或地方政府的金钱 | 否——没有上限 |
| s.44(8) | 用于公共图书馆设施的金钱 | 否——另有 RM20,000 上限 |
| s.44(11A) | 商业天课（zakat perniagaan） | 否——另有四十分之一的上限 |

## 捐款前如何查证批准

这是没人写出来的一步，而它只需要两分钟。

1. 在 hasil.gov.my 的 Institusi/Organisasi/Tabung Bukan Berasaskan Keuntungan
   栏目下，打开 LHDN 的 **Semakan Kelulusan Derma** 查询工具。
2. 以 **Nama Institusi**（机构名称）搜寻，或者更好的做法，以收据上印着的
   **No. Rujukan Kelulusan**（批准参考编号）搜寻。用参考编号搜可以避开几乎
   一模一样的慈善机构名称。
3. 把 **Subseksyen** 设为 *SUBSEKSYEN 44(6) AKTA CUKAI PENDAPATAN 1967*。
   同一个工具也涵盖 s.44(11D) 的 wakaf 与捐赠基金，以及 Income Tax (Exemption)
   Order 2020, P.U.(A) 139/2020 下另一条豁免途径——收据上可能笼统引用这三套
   不同的制度。
4. 查 **Kategori**（类别）。批准是发给特定载体的——机构或组织、wakaf、捐赠基金、
   校舍建筑基金、宗教场所建筑基金、宗教场所管理基金、福利与教育基金。就某一项
   基金获批的团体，不等于就另一项也获批。
5. 读 **Status**（状态）。只有 *DILULUSKAN* 与 *DILULUSKAN (LANJUTAN TEMPOH)*
   ——已批准，以及已批准并延长期限——才支撑得起申索。
   *TAMAT TEMPOH KELULUSAN* 与 *KELULUSAN DITARIK BALIK* 都不行。

「延长期限」这个状态的存在就是线索：批准是有期限的，不是永久的。要以赠与当日
的日期去查，而不是申索当日，并把带日期的截图连同收据一起存档。

若某团体被拒批，s.44(6B) 给它自获通知起 30 天向部长上诉的时间——这就是为什么
一家慈善机构可以诚实地说申请「正在处理中」。处理中不等于已批准。

## 常见错误

**按应课税收入的 10% 申索。** 上限是**总收入**的 10%，那是税务计算中早好几行
的位置。

**把机构、体育、国家利益与 wakaf 四项各自申索 10%。** 这些但书共用一个上限。

**相信收据上的字眼。** 那句关于批准的话是慈善机构自己说的，而且经常已经过时。

**在 s.44(6) 下申索实物赠与。** 只有金钱符合资格。

**公司忘了基期规则。** 对公司、LLP、信托团体或合作社而言，s.44(12) 把提及基年
之处读作该课税年的基期。

## 下一步

在下一笔公司捐款之前，把参考编号丢进查询工具跑一遍，并把结果连同付款凭单一起
归档。如果你打算捐出超过总收入 10% 的金额，就把这笔赠与拆到两个基期——某一年
超出的部分不会递延，它是没了。
