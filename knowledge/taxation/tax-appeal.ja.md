マレーシアの税務上訴の大半を決定づける唯一の事実は、上訴に関する規定の中にはまったく存在しない。それは1967年所得税法の**s.103(1)**の中にある——賦課決定のもとでの税額は、**その者が当該賦課決定に上訴するか否かにかかわらず**、納付期限において納付すべきものである。Section 103(2)は、税務調査による賦課決定、最良の判断による賦課決定及び増額賦課決定について同じことを繰り返している。そして**s.106(3)**が輪を閉じる——追徴手続において、法院は、金額が過大である、誤って賦課決定された、又は*上訴中*であるといういかなる抗弁も**受理してはならない**。

つまり上訴が買うのは見直しであって、時間ではない。上訴が進行している間、未納の税額はs.103(3)又は(5)のもと**10%加算**され、それは長官（Director General）の裁量により、s.103(9)のもと正当な理由がある場合に限り免除され得る。

## 実際に何が上訴の対象となるか

Section 99(1)は、**自己に対してなされた賦課決定について不服のある**者に上訴権を与える。しかしs.99(4)は、自己賦課制度の中で最もよく見られる二種類の文書を除外している。

- s.90(1)のもとでの**みなし賦課決定**——自己の申告書が、提出された日に賦課決定とみなされるもの、及び
- s.91Aのもとでの**修正申告によるみなし賦課決定**。

自分自身の数字について上訴することはできない。例外は狭い——あるPublic Ruling上の取扱いに同意しない場合、又は賦課決定がなされた時点で有効であった長官の**立場、裁定若しくは慣行**——私的裁定若しくは事前裁定、LHDNの指針、既に裁定された特別専門委員会若しくは法院の事案、又はその他の書面による陳述——に同意しない場合には、みなし賦課決定について上訴*できる*（PR 7/2020, para 4.2）。

明確に上訴の対象となるのは、**税務調査又は犯則調査**から生じた賦課決定、追加賦課決定、事前賦課決定又は不課税通知書、及びs.90(3)若しくはs.91(1)のもとでの最良の判断による賦課決定である。s.96Aのもとでの総合賦課決定はそうではない——それは既に合意に達した後にのみ発行されるものだからである。

## 30日間の時計、そしてそれが起算される時点

時計は**賦課通知書の送達**から起算され、あなたが封筒を開けた日からではなく、それに先立つ*Surat Penyelesaian Kes*からでもない。三十日間である。二つの例外がある。

- **事前賦課決定（s.92）：** 期間は代わりに**翌賦課年度の最初の3か月**となる。
- **未申告者に対する最良の判断による賦課決定（s.90(3)）：** 会社、LLP、信託団体又は協同組合については、s.99(1A)が、同じ30日以内に**未提出の申告書をForm Qとともに提出する**ことを要求する。Form Qのみでは上訴とならない。

## Form Qは、思われている以上に手続的である

Form Qは**CP 14**であり、現行版はPin. 1/2025、s.152のもと所定の様式である。落とし穴はいずれも事務的なものであり、それぞれ単独で致命的となる。

| 要件 | 出典 |
| --- | --- |
| 賦課年度ごとに**4部**——正本1部、写し3部 | PR 7/2020 para 7.1 |
| **賦課年度ごとに個別の通知書** | Form CP 14, note (i) |
| **賦課決定を受けた本人**による署名——会社又はLLPの場合はs.75又はs.75Bのもと権限を付与された者 | PR 7/2020 para 7.3.3 |
| 税務代理人又は弁護士による署名は**不可** | PR 7/2020 para 7.4 |
| 他の書類との合綴不可；上訴理由を全文記載すること | PR 7/2020 paras 7.2, 8.1 |
| **電子メール及び電子提出は受け付けない** | LHDN上訴ページ、2026年6月25日更新 |
| 不備のあるForm Qは上訴人に**返却される** | PR 7/2020 para 7.5 |

最後のこの組み合わせこそが痛手となる。28日目に不備を理由に返却されたForm Qは、あなたに残り2日しか与えない。しかも、他のあらゆるLHDNの提出手続で今や使われている電子的な経路は、あなたには閉ざされている。

Form Qは一種類ではなく五種類ある——Income Tax Act 1967、**Real Property Gains Tax Act 1976**、Petroleum (Income Tax) Act 1967、**s.109H源泉徴収税**案件、及び**Labuan Business Activity Tax Act 1990のs.6D**について、それぞれ別バージョンが存在する。RPGT上訴は別制度ではない——RPGT Actのs.18が、必要な修正を加えたうえでss.99から102及びSchedule 5を適用する。

## 30日を過ぎた場合：Form N

期限を過ぎた上訴は、**s.100**のもとで**Form N**を用いて期限の延長を申請することにより行う——賦課年度ごとに2部、これも紙媒体のみである。YA2020以降、その申請は30日間の期間の終了後**7年以内**に行わなければならない。2020年より前の賦課年度については外限が定められておらず、これが古い案内に期限が示されていない理由である。

長官が合理的な理由があったと認める場合、期限を延長し**Form CP15A**を発行する。これにより、あなたはその発行日から**30日以内**にForm Qを提出できる。長官が認めない場合、s.100(2)(b)は、長官の理由書である**Form CP15B**とともに、当該申請を特別専門委員会の書記に送付することを要求する。その場合、あなたには書面による陳述を行う**21日間**が与えられる。特別専門委員1名が決定を下し、その決定は**終局的**である——それに対する上訴は存在しない。

## s.101に基づく見直し、そして二つの静かな期限

上訴通知書を受領すると、長官は**12か月以内に当該賦課決定を見直さ**なければならない（s.101(1)）。長官は、その期間が満了する30日前までに大臣（Minister）へ延長を申請することができ、大臣は**さらに最長6か月**を認めることができる（ss.101(1A)及び(1B)）。大臣の決定は終局的である。

s.101の中の二つの小節は、沈黙を拘束力のある和解へと変える。

- **s.101(3)**——**口頭**による合意に達し、LHDNが書面による確認を送達した場合、あなたが**21日以内**に書面でこれを否認しない限り、当該合意は拘束力を持つ。
- **s.101(4)**——LHDNが当該賦課決定を確認、減額、増額又は取消しするための**書面による提案**を送達し、あなたがそれを受諾も拒否もしない場合、**30日**後にそれらは**受諾されたものとみなされる**。

みなされた合意は取り消され得るが、それはみなされた合意から**30日以内**に特別専門委員へ申請する場合に限られ（s.101(5)）、その決定もまた終局的である。

## 争議解決部門とPRP

提出と特別専門委員会の間には、他のほとんどの競合ページが説明していない段階が存在する。**Prosiding Resolusi Pertikaian（PRP）**は、LHDNの代替的紛争解決の仕組みであり、**2013年7月1日**に導入され、**Jabatan Resolusi Pertikaian（JRP、争議解決部門）**又は関係する州総監事務所が中立的な仲介者として機能し、案件が特別専門委員会に送られる前に法廷外での和解に至らせる。

セッションは、**あなたのForm Qを受理した旨の支店からの書簡を受け取り次第、書面、書簡又は電子メールにより**申請できる。JRP自身は、多国籍税務、特別産業、大口納税者及び調査の各部門、並びに特別作戦及び特別任務部門が保有する案件を扱う。それ以外はすべて州総監事務所に送られる。PRPはs.99上訴だけでなく、s.97A不課税案件、s.109H源泉徴収上訴、s.43石油上訴、s.18 RPGT上訴、及びss.131並びに131Aのもとでの**救済申請**もカバーする。

公表されている*Garis Panduan Prosiding Resolusi Pertikaian*は**2019年3月**付であり、なおもPR 7/2020によって取って代わられたPublic Ruling 12/2017を参照している。手続そのものは現行のものとして扱い、その引用は古いものとして扱うこと。

## 特別専門委員会

合意に至らない場合、長官はs.102のもと上訴を送付し、以後はSchedule 5が規律する。

- **構成：** 特別専門委員3名のうち少なくとも1名は司法又は法律の経験を有する者でなければならない——ただしpara 1Aは、迅速化のため委員長が**単独委員**による審理を指示することを認めている。
- **通知：** 日時及び場所について、少なくとも**28日前**に行う（para 8）。開廷地はイポー、コタキナバル、クアラルンプール、クチン、マラッカ及びペナンである。
- **立証責任：** para 13は、当該賦課決定が過大又は誤りであることを証明する責任を、まさに**上訴人**に課している。
- **非公開性：** 審理は**非公開**で行われる（para 43）——ただし長官が公開審理を申請する場合は別であり、その場合、委員会はあなたの異議にかかわらず、そのように指示*しなければならない*。
- **費用：** 一つの場合を除き費用に関する命令は行われない——**濫用的又は軽率な**上訴の場合であり、para 29は委員会に対し**RM5,000**を上限とする費用の裁定を認めている。

結果として下されるのは、当該賦課決定を確認若しくは取り消す、又は長官にそれを修正するよう指示する**裁決命令**である（para 26）。

## 高等法院、そしてそこで終わるもの

いずれの当事者も、**法律問題に限り高等法院**へ上訴できる（Schedule 5, para 34(1)）。その手続は厳格である。

| 段階 | 期限 |
| --- | --- |
| 書記へ上訴通知書を提出する | 決定の日から**21日** |
| 高等法院の登記処へ副本を送付し、他のすべての当事者へ複本を送達し、かつ審理記録及び決定理由の書面による交付を申請する | 同じく21日 |
| 高等法院へ上訴記録を提出する | 上訴通知書の提出から**60日** |
| 書類索引案に対する被上訴人の異議 | **48時間** |

**審理記録又は決定理由が準備できていない場合であっても**、記録は60日以内に提出しなければならない——それらは補充記録として後から提出される（para 34A(3)及び(4)）。高等法院は上訴通知書の提出期限を延長できる（para 34(7)）。そこから先は、para 41が、その控訴審の民事管轄権から生じるのと同じさらなる上訴の権利を与える——控訴院、そして連邦裁判所である。

## その他の階梯

**印紙税**は特別専門委員会とはまったく関わらない——Stamp Act 1949のs.38Aは、徴収官（Collector）への**30日間の異議通知**を認め、s.39はさらに**21日間**、**高等法院**への上訴を認めるが、それは決定に*従って印紙税を納付したうえで*行うことが明文で定められている。先に納付し、後で争う。

当該賦課決定が租税条約上の争点にかかるものである場合、s.102(1A)は上訴を停止させる——同一の理由による**相互協議手続（mutual agreement procedure）**の申請が進行している間、上訴を送付することはできず、MAPの決定後、あなたには長官にそれを送付するよう求める**30日間**が与えられ、長官はその後**3か月以内**にそれを行わなければならない。

## 上訴か、それとも救済か

問題があなた自身の申告書にあり、LHDNの賦課決定にあるのではない場合、上訴の道は閉ざされており、**救済**の道が開かれている。

| 経路 | 対象 | 時限 |
| --- | --- | --- |
| **s.131** | 自己の申告書における誤り又は過失 | みなし賦課決定がなされた賦課年度の終了後**5年** |
| **s.131A** | 誤りではなく——申告*後*に得られた官報上の免税、奨励措置の承認又は控除 | 官報告示又は承認のいずれか遅い方から**5年**；源泉徴収納付の分項については**1年** |
| **s.97A(5)** | **課税所得がない**場合の申告書の修正 | 誤り又は過失について、提出から**6か月** |

救済は、書簡又は**Form CP15C**により申請する。二つの条件が人々を捕らえる——申告書がLHDNの当時の見解に従っていた場合は拒否される（つまり、救済を用いてPublic Rulingを再び争うことはできない）、そして**賦課決定された税額はすでにすべて納付されていなければならない**。救済が拒否された場合、あなたには、その申請を特別専門委員会へ送付するよう書面で求める**6か月間**が与えられ、LHDNは3か月以内にそれを送付しなければならない。

## よくある誤り

**上訴を納付の停止と考えてしまうこと。** そうではなく、s.106(3)はこの論点を追徴手続から完全に除外している。税額と10%の加算分を予算に織り込むこと。

**自己のみなし賦課決定について上訴してしまうこと。** 公表されたLHDNの見解を争うのでない限り、s.99(4)があなたを締め出す——その経路はs.131救済であり、5年の時計が動き、かつ税額を先に納付することが求められる。

**税務代理人にForm Qを署名させてしまうこと。** PR 7/2020 para 7.4はこれを禁じている。代理人は審理に出席できるが、通知書に署名することはできない。

**Form Qを電子メールで送ってしまうこと。** LHDN自身のページが、大文字で、電子メール又は電子媒体による提出は受け付けないと述べている。

**LHDNからの書面による提案を無視してしまうこと。** s.101(4)のもとでの30日間の沈黙は、様子見の立場ではなく和解である。

**s.90(3)の最良の判断による賦課決定に対してForm Qだけを提出してしまうこと。** 会社の場合、s.99(1A)は未提出の申告書をそれとともに提出することを要求する。

## 次のステップ

賦課通知書が届いたばかりであれば、送達の日から30日間を日程に書き込み、争いがLHDNの賦課決定に関するもの（Form Q）なのか、それとも自己の申告書に関するもの（s.131救済）なのかを判断し、いずれにせよ納付しなければならない税額を見積もること。

既にForm Qを提出しているのであれば、支店に受理通知書を求め、それを用いて**PRPセッション**を申請すること——実際にはほとんどの紛争がこの段階で終わる。

その指摘が税務調査から生じたものであれば、本ページと合わせて[LHDN税務調査を乗り切る](/ja/taxation/tax-audit)を読むこと——s.113(2)の罰金は、しばしば争いの対象となっている税額そのものより大きな数字であり、s.124(3)のもと別途免除され得る。
