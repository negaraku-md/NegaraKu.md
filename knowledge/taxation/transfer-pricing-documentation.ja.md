人を破滅させるのはその14日間である。LHDNは2023年所得税（移転価格）規則（Income Tax (Transfer Pricing) Rules 2023、P.U.(A) 165/2023）の rule 5(3) のもとで通知を送達し、14日後には文書が完全な形でLHDNの手元にあるか、そうでないかのいずれかとなる。Rulesには延長の規定は一切ない。2週間遅れれば、その賦課年度だけでRM60,000に直面することになり、しかもこの罰則は監査ごとではなく賦課年度ごとに科される。

もう一つ人を破滅させるのが追徴金である。多くのオーナーは、未吸収損失を抱える会社は移転価格調整を恐れる必要がないと考える——税額を生じさせない調整は罰則を生じさせないはずだ、というわけである。しかしLHDN自身のFAQはこれと正反対のことを明言している。s.140A調整には、「納税者が損失状態にあるか免税会社であるかを問わず」追徴金が課されるとしており、それはこの5%が税額ではなく調整額に対して課されるためである。

本稿は、シンガポールに親会社を1社持ち、マネジメントフィーを支払う、売上高RM4,000万の企業のために書かれている——社内に税務専門部門を抱える企業グループ向けではない。

## 誰が対象となり、誰が本当に対象外なのか

まずは1967年所得税法（Income Tax Act 1967、Act 53）の s.140A(5) 及び (5A) から始める。なぜなら、これらの規定が適用されるためには、取引がまず「関連者間取引（controlled transaction）」に該当していなければならないからである。取引は、一方が他方を支配している場合、両当事者が互いに親族である個人である場合、又は両者が第三者に支配されている場合に、関連者間取引となる。

s.140A(5A) 条のもとでの支配とは、**株式資本の20%以上**を——直接に、又は双方に持分を有する第三者を通じて間接に——保有していることに加え、**次のうち少なくとも一つ**を満たすことをいう。

- 一方の事業運営が、特許、未特許のノウハウ、商標又は著作権など、他方が提供する専有権利に依存していること。
- 一方の事業活動——仕入、販売、又はサービスの受領若しくは提供など——が他方によって指定されており、価格及び供給条件がそれによって左右されていること。又は
- 一方の一名以上の取締役が他方によって任命されていること。

これは大半の人が予想するよりも低い持株比率の基準であり、この三つの要件は、ごく普通のグループ子会社の姿をほぼそのまま言い当てている。

次に、Malaysia Transfer Pricing Guidelines 2024の paragraph 1.5 を適用する。以下の場合には、同時文書化された移転価格文書は不要である。

- 事業を営んでいない個人。
- パートナーシップを含め事業を営む個人で、国内の関連者間取引のみを行っている者。
- 関連者間取引の総額が**RM100万を超えない**者。又は
- 他の者との国内関連者間取引**のみ**を行っており、双方が税務優遇措置を享受しておらず、同一の名目税率で課税され、かつ当該取引前の連続2年間に損失を被っていない者。

paragraph 1.6 に痛烈な但し書きがある。免除された者であっても、独立企業間原則を遵守しなければならず、価格がどのように設定されたかを裏付ける文書は保存しておかなければならない。免除されるのは正式なファイルの作成であって、基準そのものではない。

## 完全な文書化と最低限度の文書化

paragraph 1.7 は完全な文書化の閾値を定める。次のいずれかに該当する者は、完全な同時文書化ファイルを作成しなければならない。

- **(a)** 課税事業所得の合計が**RM3,000万を超え**、**かつ**年間の国境を越えた関連者間取引の合計が**RM1,000万以上**であること。**又は**
- **(b)** 年間に受領又は提供する関連者間の資金援助が**RM5,000万を超える**こと。

Guidelines自身が示す設例が、この各要件がどのように機能するかを示している。収入RM4,000万、国境を越えた取引RM900万、国内取引RM1,000万の会社は、paragraph 1.7の**範囲外**となる——国内取引はRM1,000万の計算に含まれない。収入はわずかRM500万だが会社間融資がRM5,100万ある会社は、(b)を通じて**範囲内**となる。そして、収入RM2,000万、国境を越えた取引RM2,000万、融資RM4,000万の会社は、いずれのテストも完全には満たさないため、両方の要件の範囲外となる。

paragraph 1.5の範囲外であり、かつparagraph 1.7の範囲外である場合、paragraph 1.8によって**最低限度CTPD**のカテゴリーに分類される。最低限度の文書化は要件が縮減されており、報税表の提出前に完成させ日付を付さなければならず、paragraph 1.10のもとで、独立企業間原則の遵守を証明できるものであれば長官（Director General）が認める任意の方法が許容される。LHDNは移転価格のページに最低限度文書化のテンプレート及び説明ノートを公表している。いつでも代わりに完全なファイルを作成することを選択してもよい。

一つのカテゴリーにはそもそも閾値が存在しない——関連者間取引を有する**恒久的施設（permanent establishment）**は、paragraph 1.7の如何にかかわらず、完全なファイルを作成しなければならない。

## 「同時」とは実際には何を意味するのか

P.U.(A) 165/2023 の rule 4(1)：文書は「関連者間取引が行われた賦課年度の基年において、報税表の提出期限が到来する前に作成されて」いなければならない。

したがって、期限は審査通知の日ではなく、Form Cの提出期限である。通知が届いた週に日付を付したファイルは、内容がどうであれ同時のものとはいえない。

Rule 4(2) は内容を定める。

| 要件 | Rule 4(2) |
| --- | --- |
| 多国籍企業グループに関する情報 | (a)、Schedule 1 |
| 当該人物自身の事業に関する情報 | (b)、Schedule 2 |
| コスト分担契約に関する情報 | (c)、Schedule 3 |
| 文書の索引 | (d) |
| 文書化が完了した日付 | (e) |
| 分析の基礎を成し、これを裏付け、又は分析中で言及されている文書 | (f) |
| 業務状況の重大な変化を含め、独立企業間価格を決定するために用いた情報、データ及び文書 | (g) |

Rule 4(3) は、ある項目が該当しない場合、それを黙って省略するのではなく、明示的にその旨を記載することを求めている。Rule 4(5) は長官（Director General）にガイドラインを発出する権限を与えており、これが2024年のGuidelinesの効力の根拠となっている。

rule 5(1) に注意すること——独立企業間価格は、*決定を行う時点で*合理的に入手可能な、最新かつ信頼できる情報に基づかなければならない。Guidelinesのparagraph 11.3は続けて、監査の間に、より新しい比較対象データを用いてベンチマーキングを更新しても、同時性は損なわれないと認めている——ただし、その更新によって調整が生じた場合には、それに対して追徴金が課される可能性があると警告している。

## 方法の選択、そしてLHDNがそれを変更する権限

rule 6(1) は**最も適切な方法**を要求する。すなわち、伝統的取引法——比較対象非関連者間価格法、再販売価格法又は原価加算法——、取引利益法である利益分割法若しくは取引純利益率法、又は長官（Director General）が認めるその他の方法で、最も高い比較可能性を与えるものである。

rule 6(2) は続けて、この選択そのものに文書化の負担を課す。選択した方法及び利益水準指標が、独立企業間価格のよりよい近似として適切である理由を説明し、それを事実及び正確に画定された取引の経済的に関連する特徴に基づけなければならない。

rule 6(3) は、小規模な申告者が過小評価しがちな部分である。長官（Director General）は、選択した方法が最も適切ではなかったと信じる理由がある場合、その方法を審査し、列挙された他の方法に**差し替える**ことができる。方法を正当化せずに主張するだけのファイルは、この差し替えを招くことになり、その結果生じる調整には後述の追徴金が付随する。

## s.113Bの罰則——LHDNが実際に用いる金額

s.113B(1) は不履行を刑事犯罪と定める——有罪判決を受けた場合、RM20,000以上RM100,000以下の罰金、若しくは6か月以下の禁錮、又はその両方が科される。s.113B(2) は、文書が提供されたことを証明する責任を被告人に負わせる。s.113B(3) は、裁判所が30日以内の履行を命じることを認めている。

s.113B(4) はあなたが実際に直面する条文である。提控が行われていない場合、長官（Director General）は、書面による通知により、又は評税通知書の中で、RM20,000以上RM100,000以下の罰則の支払いを求めることができる。これを支払えば、同一の事実についての提控は妨げられる。

2025年7月31日発効の移転価格監査フレームワーク（Transfer Pricing Audit Framework）が金額を定める。遅延は、14日間の期限が満了してから、完全な文書がLHDNに到達するまでの期間で測定される。

| 14日間を超える遅延 | s.113B(4) のもとでの罰則 |
| --- | --- |
| 7日以内 | RM20,000 |
| 7日を超え14日以内 | RM40,000 |
| 14日を超え21日以内 | RM60,000 |
| 21日を超え28日以内 | RM80,000 |
| 28日超 | RM100,000 |

本フレームワークは、文書が遅れて提供された場合、**又は**提供された内容がP.U.(A) 165/2023及び現行のGuidelinesに照らして不完全であると判断される場合に、監査の終結段階において、**賦課年度ごとに個別に**罰則を適用する。提控は、まったく応答しなかった納税者のために留保されている。

経過的な緩和措置がある。本フレームワークは、**P.U.(A) 165/2023が2023年5月29日に官報告示される前**に開始した会計期間について、s.113B(4) の罰則を適用しないこととしている。その自身の設例では、2022年6月1日から2023年5月31日までの財務期間は緩和を受けるが、2023年6月1日から2024年5月31日までの期間は受けない。2023暦年は緩和を受けるが、2024暦年は受けない。

s.113B(4) の通知は、評税通知書の場合と同様に、**30日以内**に特別専門委員会（Special Commissioners of Income Tax）へ上訴することができる。

## 税額を伴わずに課される追徴金

s.140A(3C) は、s.140A(3) のもとでの価格の置換又は s.140A(3A) のもとでの構造の無視の結果生じた収入の増加、又は控除若しくは損失の減少に対し、**5%を超えない**追徴金の支払いを長官（Director General）が求めることを認めている。

コストがどれだけになるかは、次の4点で決まる。

**税額ではなく調整額に対して課される。** LHDNのFAQは損失事案に関する疑問に直接答えている——評税又は追加評税が生じるか否かにかかわらず、納税者が独立企業間原則を遵守しなかった場合には追徴金が課される。フレームワークもこれを繰り返している——評税が行われない場合であっても、追徴金は依然として課され得る。

**一般税率は5%である。** 2025年7月31日改正のFAQは、公表された等級表はなく、最終的な税率は事案の実質に応じて異なり、自主開示にはより低い税率が提供されると述べている。フレームワークは自主開示を**0%から4%**と定めている。

**適用されるのは2021年1月1日以降に開始する基年に限られる。** これより前の基年における調整については、LHDNは代わりに、少納税額に対する s.113(2) の罰則を適用し、フレームワークのもとで初犯は15%、再犯は30%、それ以降は45%とし、s.124(3) による減免の裁量が及ぶ。

**税として徴収されるが、税ではない。** s.140A(3D)：追徴金は納付すべき税額であるかのように徴収されるが、s.103からs.106を除く本法令のいかなる規定についても税として扱われない。したがって、延滞納付に対する10%の加算及び徴収の仕組みの対象とはなるが、税額の計算には反映されない。

追徴金は相互協議手続（mutual agreement procedure、MAP）の結果に従う——調整がMAPのもとで減額された場合、追徴金もそれに応じて調整されることをFAQは確認している。

## よくある誤り

**国内取引は安全だと思い込むこと。** 純粋な国内取引を免除するのは paragraph 1.5(d) の特定の例外のみであり、一方に優遇措置があるか、異なる名目税率であるか、又は連続2年間の損失年度があった瞬間に、その適用は失われる。損失を出しているSdn Bhdから黒字の姉妹会社へのマネジメントフィーは、まさに対象範囲に含まれる。

**RM3,000万の閾値を出発点と読み違えること。** それは*完全な*文書化の出発点にすぎない。文書化そのものの出発点は、RM100万の関連者間取引である。

**国内取引をRM1,000万の計算に含めてしまうこと。** paragraph 1.7(a) が定めているのは国境を越えた取引である。

**会社間貸付を無視すること。** 無利息の取締役又は株主による資金提供がRM5,000万を超えれば、収入の閾値にかかわらず、それ単独で paragraph 1.7(b) のもとで完全な文書化が発生する。

**グループのマスターファイルで十分だと考えること。** 必要な情報をすべて含んでいれば、Schedule 1の情報に代えることができるが、Schedule 2——マレーシア事業体自身の事業、機能及びベンチマーキング——は現地で作成しなければならない。

**損失状態が保護になると想定すること。** そうではなく、これは中堅企業層で最もよく見られる誤解である。

**報税表の後にファイルの日付を付すこと。** それだけで、内容の質にかかわらず、同時性が失われる。

## 次のステップ

二つのことを、この順序で行うこと。第一に、去年の数字ではなく今年の数字を用いて、自分が1.5、1.7、1.8のどのparagraphに該当するかを見極めること——閾値は毎年テストされるからである。第二に、1.7又は1.8に該当する場合は、完成日をForm Cの期限に合わせて設定し、そこから逆算して作業すること。罰則制度全体が、通知が届いた時点ですでに存在していたファイルを基準としているためである。

自社のグループの連結収益が7億5,000万ユーロ又はRM30億を超える場合は、`cbcr-and-master-file`もあわせて読むこと——そこでの報告義務は別の時計で動いている。取引相手がマレーシア国内の人員を通じて事業を行う外国親会社である場合は、`permanent-establishment`が、価格付けとはまったく別に、グループがマレーシアに課税上の存在を有するリスクを扱っている。
