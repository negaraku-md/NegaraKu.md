マレーシアの税務調査に関する大半の手引きは、**机上調査**と**実地調査**を説明している。そのどちらの語も、LHDNが実際に運用しているフレームワークには登場しない。現行の文書――*Rangka Kerja Audit Cukai Pendapatan dan Majikan*（所得税・雇用主税務調査フレームワーク）、**2025年3月15日**発効――は二つの異なる方法を用いており、その違いが、あなたがどれだけの通知を受け、全体がどれだけ長く続くかを決める。

そのフレームワークはまた、構造上のことも行った。それは**五つの独立したフレームワークを撤回**し、一つのものに置き換えた――2022年5月1日のTax Audit Framework、2022年5月1日のFinance and Insurance Tax Audit Framework、2022年5月1日のPetroleum Tax Audit Framework、2021年10月1日のEmployer Audit Framework、そして2015年8月1日のWithholding Tax Audit Frameworkである。あなたが読んでいる情報源がこれらのいずれかを引用している場合、それは撤回された手続を説明している。

## Semakan umumとsemakan menyeluruh――机上調査でも実地調査でもない

**semakan umum**（一般レビュー）は、**LHDNの事務所のみ**で行われる文書レビューである。それは所得の調整、雇用主のコンプライアンス確認、ラブアン事業活動のレビュー、及び往復書簡で解決できるあらゆる事項を対象とする。それは包括レビューへと引き上げられることがあり、引き上げられた場合は書面で通知される。

**semakan menyeluruh**（包括レビュー）は、事業の運営方法についての面談を伴い、**あなたの事業所、LHDNの事務所（対面又はオンライン）、又は双方が合意するその他の場所――あなたの税務代理人の事務所を含む――**で行われ得る。それはすべての業務文書を対象とする――所得記録、経費及び控除の申告、実質優先の原則で検証される契約、承認された優遇措置の条件の遵守、源泉徴収の控除及び納付、並びに給与記録である。

調査訪問を伴うのは包括レビューのみである。一般レビューが伴うことは決してない。

どちらも同じように始まる――公式な電子メール又は郵送で発行される**Surat Memohon Dokumen dan Maklumat**（文書・情報要請書）であり、回答には**14暦日**が与えられる。訪問が計画されている場合、別途の**Surat Pemberitahuan Lawatan Pematuhan**（コンプライアンス訪問通知書）を、訪問日の少なくとも**14暦日前**までに発行しなければならず、そこには訪問日、準備すべき記録、対象となる賦課年度、担当官の氏名及び見込まれる期間が記載される。合理的かつ避けられない理由があれば、延期を申請することができる。

書簡がまったく来ない状況が一つだけある――LHDNが賦課決定を行う根拠となる明確な文書及び情報をすでに保有している場合、要請書簡は発行されず、調整の詳細と税務計算を添付した賦課決定通知書が届く。

## LHDNが案件の選び方について何を述べているか

フレームワークは簡潔だが具体的である。選定は**既定の税務リスク基準に照らしたコンピューターシステムによる分析**によるものであり、また「随時変わり得る」情報源から行われる。三つの根拠が挙げられている――

- **第三者**から受領した情報。
- **業界の課題**。そして
- 一つの会社が重要な取引金額に対して行った**関連者間取引の金額**。

第三のものは移転価格の掛かり口であり、それは別のフレームワーク――**Rangka Kerja Audit Cukai Harga Pindahan**（移転価格税務調査フレームワーク）、**2025年7月31日**発効――と並んで存在し、そのフレームワークは同時文書化の欠如について独自の段階的なs.113B(4)罰金を定めている。

フレームワークはまた、選定が**納税者が違反を犯したことを意味するわけではない**と明確に述べている。それは、神経質になっている取締役会に引用して伝える価値がある。

## 対象となる年度、そして存在しない上限

| 調査対象 | 典型的な範囲 | 法定時効 |
| --- | --- | --- |
| 所得税（源泉徴収税、雇用主、ラブアンを除く） | 至多**3賦課年度** | 5年、s.91(1) |
| 源泉徴収税 | 至多3賦課年度 | 5年、s.91(1) |
| 雇用主調査 | 至多**2年分の報酬** | s.83の罪は違反行為から**12年**以内に訴追され得る、s.121(1) |
| ラブアン事業活動 | 至多3賦課年度 | 5年、s.6(2) LBATA |

決定的な一行は、フレームワーク自身の表の最後の欄にある――調査が**詐欺、故意の不履行又は過失**を伴う場合、**対象範囲の上限は適用されない**。それは1967年所得税法（Income Tax Act 1967、Act 53）のs.91(3)であり――詐欺だけでなく過失だけでも、それを取り除くのに十分である。

## 罰金の段階表

所得の過少申告又は申告漏れを伴う調査の発見事項について、s.113(2)は**少なく徴収された税額に等しい**罰金――すなわち100%――を認めている。フレームワークはその代わりに優遇的な段階表を適用する。

| 状況 | s.113(2)のもとでの税率 |
| --- | --- |
| 初回の違反 | **15%** |
| 2回目の違反 | **30%** |
| 3回目以降の違反 | **45%** |
| 技術的調整 | **0%** |
| 税務詐欺、故意の不履行 | **100%** |
| 申告期限後の自主開示 | **15%** |
| 修正申告書が先に提出され、申告期限から6か月以内の自主開示 | **10%** |

二つの細目が、あなたがどの行に落ち着くかを決める。

**違反の回数の数え方には固定の基準期間がある。** あなたが初犯か2回目の違反者かは、**2020年1月1日から2022年4月30日**の間のs.113(2)罰金の記録によって決まる。その期間内に罰金がなければ、2022年5月1日以降のいかなる調査の発見事項も**初回の違反、15%**として扱われる。その期間内に罰金があれば、**2回目の違反、30%**として扱われる。

**技術的調整は、聞こえるよりも狭い。** それは、各案件の事実及び争点に基づいて判定される、税法の解釈の相違を意味する。LHDNがすでにPublic Ruling、Guidelines、実務通知（Practice Note）、Income Tax Rules又は免除命令を通じてその立場を表明している場合、それは明文で**利用できない**。LHDNが一旦見解を公表すれば、それに同意しないことは技術的調整ではない。

内国歳入庁長官（Director General）は**s.124(3)**のもとで罰金を減額又は免除することができる。

## 自主開示の損得勘定

この提案は、非常に厳密な形で時間的に限定されている。自主開示とは、申告期限の後、かつ**調査行動が始まる前のいつでも**、関連する州業務局長（State Operations Director）又は部門局長（Division Director）に対して行う書面による開示を意味する――そして調査行動は**Surat Memohon Dokumen dan Maklumatの日付**に始まる。

したがって、損得勘定は次のとおりである。

- **書簡の前**：15%（又は狭い修正申告書のケースでは10%）。
- **書簡の後**：それが正真正銘あなたの初回の違反であれば15%、そうでなければ30%又は45%、事実が故意の不履行を裏付けるものであれば100%。

単純な申告漏れがある初めての納税者にとって、開示と調査の発見事項は同じ15%に落ち着く。開示の価値はその裾野にある――それは30%、45%及び100%という結果を選択肢から外し、あなたに事実を先に整理させてくれる。

つまずきやすい条件が二つある。開示には、定められた一連の文書――申告書、監査済み会計又は損益計算書、優遇措置情報及び条件の遵守状況、完全な原本及び修正後の税務計算、並びに裏付けとなる帳簿を伴う争点の完全な詳細――を添えなければならない。**合理的な理由なく**不完全な一式を提出することは、その開示が**受理されない**ことを意味する。そしてこの優遇措置は、**申告義務を遵守している納税者にのみ提供される**――未提出の申告書がある会社は、その15%を買い取ることはできない。

## LHDNに守らせられる期限

調査訪問は**1日から3日**続き、取引の規模及び複雑さ、保管されている記録の形式、並びに提供される協力の程度に応じて延長され得る。

案件解決期間は、調査の開始――一般レビューについては要請書簡の日付、事業所での包括レビューについては訪問初日、又は包括レビューがLHDNの事務所で行われる場合は*Surat Penentuan Permulaan Tempoh Penyelesaian Kes*（案件解決期間起算決定書）の日付――から起算する。

| 調査の種類 | 解決期間 |
| --- | --- |
| 税務調査／雇用主調査 | **90暦日** |
| 源泉徴収税――支払者 | 90暦日 |
| 源泉徴収税――受取人 | **180暦日** |
| 金融・保険――ブローカー、銀行、リース、仲介業者 | 90暦日 |
| 再保険及び再タカフルを含む、保険及びタカフル事業 | **240暦日** |
| 石油――探査及び生産 | **450暦日** |

これらは、他の当事者からのさらなる確認が必要な場合には適用されない――それは広い例外だが、それでもこれらの期間は、案件が静かになったときの正当な参照点であり続ける。

解決済みの調査は、**同一の賦課年度及び同一の争点について再調査されることはない**。その年度についての新たな争点又は新たな情報があれば、それでも再開され得る。

## 調査結果が出た後

調整、税額及び罰金は**Surat Penyelesaian Kes**（案件解決書）で届き、続いて賦課決定通知書又は不課税通知書が届く。何も発見されなかった場合は、*Surat Penyelesaian Kes Tanpa Pelarasan Pendapatan*（所得調整なし案件解決書）を受け取る。

納付は**賦課決定通知書が発行された日から30日以内**に、Bill Number又はTINを用いてByrHasilを通じて行う。分割納付は、正当な理由とともに、州業務局長又は部門局長に申請することができる。期限を逃す、又は合意した分割払いを不履行にすると、未納残高に加算が適用される。

調査の発見事項と不服申立ては別々の道筋である。発見事項に同意しないことは納付を停止させない――通知書が送達された時点で始まる30日間のForm Qの時計については、[税務賦課決定への不服申立て](/ja/taxation/tax-appeal)を参照のこと。

## よくある誤り

**2022年のフレームワークに依拠すること。** それは他の四つとともに2025年3月15日に撤回された。罰金の表は大部分がそのまま残ったが、手続は残らなかった。

**14日間を緩やかなものと捉えること。** 回答しなくても調査は止まらない――それはLHDNがすでに保有する文書に基づいて進めることを可能にするだけであり、フレームワークは、申告された経費が否認され、追加賦課決定が行われ得ると明文で警告している。

**海外に保管されている記録はLHDNの問題だと思い込むこと。** フレームワークは、関連会社が海外に保管している文書を入手し、それを完全な形で提出する責任を納税者に課している――包括レビューについてはあなたの事業所で、又は訪問の前に。

**あらゆる調整を技術的調整と呼ぶこと。** LHDNがPublic Ruling、guideline、practice note、rules又は免除命令でその立場を公表している場合、0%の税率は選択肢から外れる。

**書簡が届いた後に開示すること。** 窓は*Surat Memohon Dokumen dan Maklumat*の日付で閉じるのであって、訪問の日付で閉じるのではない。

**雇用主の部分を忘れること。** 同じフレームワークはs.83及びs.107のもとでの雇用主調査を対象としており、そこでのリスクはパーセンテージの罰金ではなくs.124のもとでのコンパウンドであり――再犯はそのコンパウンドの金額を引き上げる。

## 次のステップ

要請書簡が届いた場合は、14日間を日程に書き込み、どのレビュー方法が動いているかを確認し、引用されている年度が3年の対象範囲内にあるか、それともLHDNがさらに遡ることで過失を示唆しているかを確認すること。

何も届いておらず、提出済みの申告書に誤りがあると分かっている場合、上記の開示の算術こそが決定のすべてである――そしてそれは、あなたが書簡より先んじている間にしか機能しない。

課題が移転価格である場合は、本稿と併せて2025年の別個の移転価格税務調査フレームワークを読むこと――その文書化に関する罰金は、別の、はるかに急な段階表で動く。
