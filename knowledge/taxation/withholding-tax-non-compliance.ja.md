RM5,000の源泉徴収税を控除し忘れても、その代償はRM5,000では済まない。RM5,500の税、損金算入を失ったことによるRM12,000、そして他のすべてを払い終えた後もなお記録に残り続ける罰金がかかる。この算術は、一度きちんと計算しておく価値がある。

## 三つの独立した打撃

それらは三つの異なる条文に由来し、異なる振る舞いをする。

**一つ目——10%の加算。** 各課税条文はそれぞれ独自の第(2)項を備えている。ss.107A(2)、109(2)、109B(2)及び109F(2)はいずれも、あなたが納付しなかった金額は「shall be increased by a sum equal to ten per cent」との規定を置き、その合計額は政府に対する債務として即時に支払うべきものとする。これはs.113の罰金ではないが、各条文は内国歳入庁長官がそれを正当な理由に基づき免除することを認めている。

**二つ目——費用全体の損金不算入。** Section 39(1)は、当該支払いの全額を損金不算入とし、条文ごとに次のように振り分けられる。

| 支払い | 不算入条項 |
| --- | --- |
| s.109の下の利子又は使用料 | s.39(1)(f) |
| s.107Aの下の契約支払 | s.39(1)(i) |
| s.109Bの下の特定種類の所得、及びs.109Fの下の4(f)所得 | s.39(1)(j) |

失うのはその費用に対する損金算入であって、税額に対するものではない。Public Ruling 10/2019のpara 14.2はこれを率直に述べている——当該費用はs.33(1)のもとで発生したものであっても、源泉徴収税が未納である間はその一部たりとも損金算入できない。

**三つ目——s.113(2)の罰金。** これらの各段落の但書(ii)は、申告書において当該損金算入が申索されていた場合、遅延して納付しても「shall not prejudice the imposition of penalty under subsection 113(2)」と規定する。Section 113(2)は、不正確な申告書について**少なく徴収された税額に等しい**罰金を認める。

## 算術——LHDN自身の例で

Public Ruling 10/2019 Example 18。ある居住会社が、マレーシア国内で提供された役務についてインドのサービス提供者にRM50,000を支払い、源泉徴収を一切行わない。同社はYA2017の申告書を提出し、課税所得RM1,000,000、税額RM240,000を示し、そのRM50,000を損金算入として申索していた。その後、税務調査が行われる。

| | RM |
| --- | --- |
| 申告時点の課税所得 | 1,000,000 |
| 24%で課される税額 | 240,000 |
| 加算：s.39(1)(j)により損金不算入となるサービス料 | 50,000 |
| 税務調査後の課税所得 | 1,050,000 |
| 24%で課される税額 | 252,000 |
| **少なく徴収された税額** | **12,000** |
| s.113(2)の罰金、100%で例示 | 12,000 |
| **追加で納付すべき税額** | **24,000** |

これとは別に、そのRM5,000の源泉徴収税は、s.109B(2)のもとでRM500の加算を受け、s.106(1)のもとで追徴可能なRM5,500の債務となる。

**RM50,000の請求書に対する総エクスポージャー：RM29,500**——源泉で控除されるべきであったRM5,000の税額に対して。ほぼ6倍である。

## 後から納付しても、直るものと直らないもの

同じRulingのExample 19は、その続きを描く。同社は2018年12月15日にRM5,500を納付する。

損金算入は戻ってくる。課税所得はRM1,000,000に、税額はRM240,000に戻り、減額された評価が発行される。しかしRulingは明確である——2018年7月31日に不正確な申告書が提出されたため、s.113(2)の罰金は**維持される**。

覚えておくべき非対称性はそこにある。10%の加算は正当な理由があれば免除され得る。損金不算入は納付により逆転する。しかし、権利のない損金算入を申索したことに対する罰金はそうならない。誤りは滞納ではなく申告書そのものにあったからであり——LHDNの源泉徴収税ページは、これが申告書が期限内に提出されたか遅延して提出されたかを問わず適用されることを確認している。

## 未払いの請求書にひそむ罠

申告書の提出期限までに当該非居住者への支払又は入金が行われておらず、源泉徴収税が**まだ発生していない**場合、当該損金算入は——いかなる源泉徴収税が納付されているかを問わず——**一切認められない**。年度末に海外サービス料を計上し、ベンダーに支払う前にそれを申索することは、別の扉からあなたをs.39(1)(j)の外へ押し出す。

救済はs.131Aにある。申告し納付済みの支払者は、その理由により評価額が過大であるとして、**支払いが行われた年の終了後一年以内に**、書面により救済を申請できる。LHDNの例——YA2023の費用について、使用料及び源泉徴収税が2024年10月30日に支払われた場合——は、2025年12月31日より前に申請しなければならない。

## よくある誤り

- **10%をs.113の罰金と呼んでしまうこと。** それは誤りである。10%の加算は課税条文の中にあり、両者を混同すると、それらが積み重なるという事実が見えなくなる。
- **滞納分を納付すればファイルが閉じると思い込むこと。** それは損金算入を回復させるにすぎない。すでに提出された申告書に課されたs.113(2)の罰金を取り下げるものではない。
- **エクスポージャーを税額プラス10%として予算立てすること。** 損金不算入の方が通常はより大きな金額になる。なぜならそれは源泉徴収税ではなく、費用全体に対して法人税率で計算されるからである。
- **税務調査が来るまで自主是正を待つこと。** s.113(2)のリスクは、すでに提出した申告書に付着しており、さらに一年経過するごとにそれが積み増される。
- **「まだ発生していない」場面でs.131Aの一年の時計を忘れてしまうこと。**
