統合は、電子インボイス制度のもとでマーマッ食堂（mamak）やミニマーケット、クリニックが生き延びられるようにしてくれる譲歩措置である。同時に、それはあなたの足元から真っ先に取り上げられる可能性が高い譲歩措置でもある——RM10,000の分界線によって、あなたの業種によって、あるいは月の29日に正式なインボイスを求めてくる一人の顧客によって。

仕組みは単純である。買い手に電子インボイスが必要かどうかを尋ねる。不要だと言われれば、今日と全く同じように通常の領収書を渡せばよい——その領収書はどこにも提出されない。そのうえで、**月末から7暦日以内に**、前月分の領収書を1件の統合電子インボイスにまとめ、収入の証明として検証のために提出する。

根拠となるのは1967年所得税法（Income Tax Act 1967）のs.82C(7)であり、これは内国歳入庁長官が、ある者について、取引を統合し、指定された期間内に送信される統合取引インボイスにまとめることができると決定できると定めるものである。その指定された期間は、e-Invoice Specific Guidelineのsection 3.6.2に定められている。

## 統合電子インボイスには何を記載するか？

Specific GuidelineのAppendix 2が、買い手欄を固定している。

| 項目 | 値 |
| --- | --- |
| 買い手名 | **General Public** |
| 買い手TIN | **EI00000000010** |
| 買い手の登録／身分証／パスポート番号 | NA |
| 買い手の住所 | NA |
| 買い手の連絡先電話番号 | NA |
| 買い手のSST登録番号 | NA |

実質的な要件があるのは説明欄（description field）である。LHDNは次の3つの方法、またはその組み合わせを認めている。

1. 各領収書を**個別の明細行**として要約する方法
2. **連続する領収書番号の連番**を1つの明細行とし、番号の連なりが途切れるたびに新しい明細行を起こす方法
3. **支店または拠点**ごとに、方法1または方法2を用いて、それぞれが自らの統合電子インボイスを提出する方法

どの方法を選んでも、各取引の領収書参照番号は説明欄に記載しなければならない。金融機関、決済システムおよび類似の事業体といった規制対象業種は、section 4.3.7に基づき、明細書または請求書の参照番号を開示する義務を免除されている。

## システム上の上限は何か？

MyInvoisの性能を保護するため、section 3.6.4は3つの上限を定めている。

- 1回の提出につき最大**5MB**
- 1回の提出につき最大**100件**の電子インボイス
- 電子インボイス1件につき最大**300KB**

繁忙月にはこれらの上限を超えることになるが、LHDNは領収書を複数の統合電子インボイスに分割することを明示的に認めている。40,000件の領収書を持つ小売業者が、1件の巨大な書類を提出する必要はない。

## どの活動が決して統合できないのか？

Specific GuidelineのTable 3.6である。これらはいずれも、買い手の実際の詳細情報を伴う個別取引電子インボイスを必要とする。

| 業種または活動 | 範囲 |
| --- | --- |
| **自動車** | トレーラーを含む、あらゆる自動車の販売 |
| **航空** | 航空券の販売、プライベートチャーター |
| **高級品・宝飾品** | 保留中——詳細は今後公表予定、追って通知があるまで統合は引き続き認められる |
| **建設** | Income Tax (Construction Contracts) Regulations 2007に定義される建設契約に基づく建設請負業者 |
| **免許制の賭博・ギャンブル** | 勝者への払戻金。ただしカジノおよびゲーミングマシンの払戻金は除く。これらは追って通知があるまで免除される |
| **代理店・ディーラー・販売代理店への支払い** | 1967年所得税法s.83A(4)に定義されるもの |
| **全業種** | RM10,000を**超える**単一取引——**2026年1月1日**より |
| **電力サービス提供事業者** | 電力の配電、供給または販売——**2026年1月1日**より |
| **電気通信** | 後払いプラン、インターネット契約、電子機器の販売——**2026年1月1日**より |

この9項目のうち3つは新しいものである。RM10,000ルール、電力および電気通信はいずれも2026年1月1日に施行されており、ネット上で今なお上位に表示される情報の多くはそれ以前のものである。

**多くのガイドはRM10,000ルールを業種別のルールとして説明している。** それは誤りである。Table 3.6はそれを*全業種*の下に列挙している。ある金物店による1件のRM12,000の販売は、その月の他のすべての販売が統合できるとしても、個別取引電子インボイスを必要とする。LHDN自身のExample 24が、まさにこのケースを扱っている。

## 詳細情報を提供しない個人の買い手についてはどうか？

Section 3.7.3はこの実務上の問題を認め、section 3.5.4の通融へと導く。マレーシア人個人はTINを提供することができ、**または**MyKadもしくはMyTentera番号を、**あるいは**その両方を提供することができる。非マレーシア人個人はTINを提供することができ、あるいはTINとパスポート、MyPRもしくはMyKAS番号の両方を提供することができる——そしてTINを一切持たない場合、供給者は一般TINをパスポート番号とあわせて使用する。

それだけあれば、車を買いに来た一見の客に対しても、要件を満たす個別取引電子インボイスを発行するのに十分である。

## 買い手の要求は、月次の締切とどう関係するのか？

Section 3.6.8は、同業他社が普段見落とす答えを示している。すでに領収書を受け取った買い手は、後から戻ってきて電子インボイスを求めることができるが、それは**取引が行われた月の中に限られる**。この境界線が存在するのは、供給者がその統合を締め切ることができるようにするためである。3月になってから1月分の領収書について要求するのは、期限切れである。

まだ暫定緩和期間内にある供給者は、統合を行っている限り、section 16.2(d)に基づいてその要求を全面的に拒否することができる。フェーズ4の納税者については、この通融は2027年12月31日まで続く。

## ワークフローの何が異なるのか？

2点あり、いずれもsection 3.6.10に定められている。

- LHDNは**供給者のみ**に通知する。買い手への通知は存在せず、したがって**買い手による拒否要求も存在しない**——統合文書には72時間の拒否経路が存在しない。
- 検証済みの統合電子インボイスは供給者の収入の証明であり、**買い手とは共有されない**。

検証から72時間以内の供給者によるキャンセルは、引き続き適用される。それ以降の調整は、クレジットノート、デビットノートまたは返金通知の電子インボイスを通じて行う。

## よくある誤り

- **RM10,000を超える取引を統合してしまうこと。** 2026年1月1日以降、これは一部の列挙業種だけでなく、すべての業種に適用される。
- **7日間の期限を見落とすこと。** これは7*暦*日であり、あなたの会計締めからではなく、月末から起算される。
- **暫定緩和期間を恒久的なものと勘違いすること。** フェーズ1から3は、それぞれ2025年1月31日、2025年6月30日、2025年12月31日に、包括的な統合の通融を失った。
- **緩和期間終了後も説明欄に自由記述を入れること。** Section 16.2(c)は緩和期間中に限りあらゆる文字列を認めていた。それ以外では、領収書参照番号が必須である。
- **自己請求文書を統合してしまうこと。** section 3.6.5に定める4つの狭いケースのみが対象となる。
- **建設請負業者が小規模な工事を統合できると思い込むこと。** Table 3.6は、インボイス金額ではなく、2007年Regulationsにおける契約の定義を基準としている。
- **小売業の1か月分をまとめて1回で提出すること。** 100件・5MBの上限に引っかかり、拒否される。

## 次のステップ

直近の丸1か月分の領収書を、2つのフィルターにかけてみるとよい。RM10,000を超えるもの、そしてTable 3.6のリストに該当するもの。両方をくぐり抜けたものが、あなたの統合基盤であり、その規模が無料のPortalで対応できるかどうかを教えてくれる。代理店、個人または海外の供給者にも支払いを行っている場合、自己請求のルールには、それ自体のはるかに狭い統合の例外がある。
