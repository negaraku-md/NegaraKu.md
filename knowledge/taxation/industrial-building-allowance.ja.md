answer: "工業用建物控除（industrial building allowance、IBA）は、1967年所得税法（Income Tax Act 1967、Act 53）のSchedule 3（所得税法第3附則）のpara 63のもとで工業用建物として使用される建築物、または同定義を病院、研究用建築物、輸出倉庫、ホテル、空港、学校及び従業員宿舎に拡張する各paraのもとで使用される建築物への資本的支出を軽減する。初期控除（initial allowance、IA）は適格建物支出の10%であり、年次控除（annual allowance、AA）は3%であるため、一般的な工業用建物は償却が完了するまでに賦課年度で30年を要する。"

ある会社がRM120万で工場を購入し、RM120万について工業用建物控除を申請する。2年後、税務調査はその申索をRM500,000をやや上回る額へと修正し、それ以降の各年について超過分を加算して戻し、さらに罰金を課す。建築物について何も変わっていない。この会社は単に、法令が使用を認めたことのない数字で申索していただけである。

工業用建物控除は、Schedule 3の中で最も控えめな軽減措置であり——年3%、完全償却まで30年——同時に最も頻繁に過大申告されるものでもある。2つの難問が誤ったタイミングで問われるからである。

## どの建築物が対象となるか

Schedule 3のpara 63は短く、限定的である。建築物は、事業の目的で使用され、かつ以下に該当する場合に工業用建物となる：

- **(a)** 工場として使用されること；
- **(b)** 埠頭、波止場、桟橋またはその他類似の建築物として使用されること；
- **(c)** 倉庫として使用され、**かつ当該事業が公衆への貯蔵スペースの賃貸から構成される、または主としてそれから構成される**こと；
- **(d)** 当該事業が公衆に供給する水道もしくは電気事業、または公衆にサービスを提供する電気通信事業であること；
- **(e)** 農場の運営に関連して使用され、当該事業が主として当該農場の運営から構成されること；または
- **(f)** 鉱山の運営に関連して使用され、同様の基準によること。

Para 64は*工場*の範囲を広げ、製造、加工またはその工程のための動力発生のための機械もしくは設備を収容する製粉所、作業場その他の建築物を含める——ただし、物品の販売に付随して、またはこれと結合して行われる、物品の修理もしくは保守のために使用される作業場は明示的に除外する。また、工場と**同一の敷地内**にあり、原材料、燃料、在庫品または販売前の加工済み製品を保管する倉庫用建築物も含める。

Para 65(1)は、当該事業の従業員のために提供される食堂、休憩室、娯楽室、便所、浴室または洗面所を工業用建物として扱う。Para 65(3)はその後、逆方向の疑義を払拭する：**住宅、小売店舗、ショールームまたは事務所**は工業用建物ではなく、また工業用建物として扱われてはならない。

Para 66は許容範囲を定める。建築物の一部が工業用建物として使用され、一部がそうでない場合、不適格部分の建設費用が全体の**10分の1を超えなければ**、全体が対象となる。それを超える場合、支出は床面積により、または内国歳入庁長官の指示に従って按分される。

この定義は厳格に適用されるが、狭く適用されるわけではない。*DGIR v Classic Japan (M) Sdn Bhd*において、控訴院は、別個の輸出奨励措置については納税者の主張を退けたものの、納税者の工場がpara 63の範囲内の工業用建物であること、及び工業用建物控除が適正に申請されたことを確認した。

## 拡張によって対象となる建築物

実務上、工業用建物控除の申請の大半はpara 63ではなく、工業用建物に関する規定を他の対象に*準用*する各paraに依拠している：

| Para | 建築物 | 控除 |
| --- | --- | --- |
| 37A | 免許を受けた私立病院、産院、介護施設 | 標準；賃借物件の改装を含む |
| 37B | 承認された研究開発のために使用される建築物 | 標準；賃借物件の改装を含む |
| 37C | **もっぱら**輸出用貨物、または加工の上再輸出される輸入貨物の保管のために使用される倉庫 | 10年間にわたり毎年10分の1 |
| 37E | Schedule 7Bのもとで承認されたサービスプロジェクトのための建築物 | 標準 |
| 37F | **観光省に登録された**ホテル | 標準 |
| 37G | 滑走路及び付属構造物を含む空港 | 標準 |
| 37H | 大臣が承認した自動車レース場 | 標準 |
| 42 | 工業用建物が使用中である場合の従業員のための居住宿舎 | 初期控除は**5分の2** |
| 42A(1) | 製造業、ホテル業、観光業または承認されたサービスプロジェクト事業における従業員宿舎 | 10年間にわたり毎年10分の1 |
| 42A(2) | 従業員のための託児施設 | 10年間にわたり毎年10分の1 |
| 42B | 学校または承認された教育機関 | 10年間にわたり毎年10分の1 |
| 42C | 工業、技術または職業訓練用建築物 | 10年間にわたり毎年10分の1 |

Para 42(2)及び42A(4)に書き込まれた除外事項に留意されたい：従業員宿舎について、*従業員*には、取締役、当該事業を支配する個人、または管理職、事務管理職もしくは事務職員は含まれない。財務部長のための宿舎は工業用建物ではない。

## 多くの解説がいまだ見落としている賃貸制限

2016賦課年度以降、subparagraph 16B(1)は、当該建築物またはその一部が、賃貸事業を含め当該人物により**不動産の賃貸**に使用される場合、para 37A、37B、37C、37E、37F、37G、37H、42A、42B及び42Cに関連する支出について、para 12及び16のもとでいかなる控除も与えられないと定めている。

申請者は所有者であり、かつ事業の運営者でもなければならない。Subparagraph 16B(2)は10分の1の許容範囲を維持している：賃貸部分が建築物全体の床面積の10分の1を超えない場合、建築物全体が依然として対象となる。Subparagraph 16B(3)は、その許容範囲を超える場合に、控除を賃貸されていない床面積に限定する。

Public Ruling No. 3/2018は、これを実例——薬局とカフェテリアを賃貸に出す病院、小売区画を賃貸するホテル——を用いて説明している。その計算は、全体の適格建物支出に床面積の割合を適用するものであり、賃貸が続く限り毎年繰り返される。

## 購入建築物の落とし穴

Subparagraph 3(1)は、適格建物支出を、工業用建物として使用される建築物の**建設または購入**に係る資本的支出と定めている。Subparagraph 3(2)はその上で、購入の場合についてこれを定義する：当該建築物の購入価格の金額である。

2つの調整が、この金額を実際に申請できる数字に変える。

**Para 70は付随費用を含め、土地を除外する。** 工業用建物に関する購入価格には、購入者が当該購入に関連して負担した弁護士費用、印紙税その他の付随費用を含む——しかし、土地または土地に係る権益に帰属する価格部分は**含まない**。建築物と土地は別個の資産として扱われる。

**契約書がこれらを分けていない場合、誰かがそれを行わなければならない。** Public Ruling No. 3/2018は、評価・不動産サービス局または専門の評価人による評価を要求し、その上で同一の比率で付随費用を按分する。

RM1,200,000の購入で、弁護士費用と印紙税がRM36,000であり、売買契約書には1つの数字しか記載されていない場合を考える。評価によりそれを分けると：土地RM700,000、建築物RM500,000となる。

| 項目 | RM |
| --- | --- |
| 評価による建築物の費用 | 500,000 |
| 建築物に帰属する弁護士費用及び印紙税（500,000 ÷ 1,200,000 × 36,000） | 15,000 |
| **適格建物支出** | **515,000** |

10%の初期控除はRM51,500であり、3%の年次控除はRM15,450である。RM120万の支出に対し、初年度の軽減はRM66,950となる——そして残りの支出は、その後の29賦課年度にわたり毎年RM15,450ずつ償却される。

それが落とし穴である。申請そのものが否認されるわけではない。申請可能な基礎額が実際に支払った額のおよそ43%にすぎず、軽減の期間が30年にも及ぶという点にある。表示価格をもとに税務効果を試算する購入者は、初年度の軽減を2倍以上過大に見積もることになる。

Schedule 3のpara 3A、para 4及びpara 5——かつて、購入建築物の適格支出を売主が支出した金額を参照して制限していた——は、2005賦課年度をもって廃止された。Public Ruling No. 3/2018は、これらがその年より前に購入された建築物についてのみ、なお関連性を有することを確認している。

## 初期控除は取り戻されることがある

Para 13(c)は、基期の末日において当該人物が所有者でなかった場合、または当該建築物が工業用建物として使用されていない、もしくは使用されようとしていなかった場合に、初期控除を否定する。Para 13(d)はさらに踏み込む：初期控除が**すでに**与えられており、かつ当該建築物が**翌**賦課年度の基期中のある時点において工業用建物として使用されていない、または使用されようとしていなかった場合、その控除が与えられた年について、その控除に等しい均衡課税額が課される。

12月に建築物を購入し、初期控除を申請し、内装工事が翌年にまたがって行われるだけで、これが発動するのに十分である。

## よくある誤り

**購入価格全体について申請すること。** 土地はpara 70により除外され、付随費用は按分しなければならない。

**あらゆる倉庫を工業用建物として扱うこと。** Para 63(c)は、当該事業が**公衆への**貯蔵スペースの賃貸から構成される、または主としてそれから構成されることを要求する。自社の在庫を保管する倉庫は、工場と同一の敷地内にあるとしてpara 64(b)のもとで、または輸出保管についてpara 37Cのもとでのみ対象となる。

**店舗区画や事務所について申請すること。** Para 65(3)は完全な除外規定であり、para 66の10分の1ルールにのみ服する。

**混合用途建築物においてpara 16Bを無視すること。** 床面積の10分の1を超えて賃貸に出す病院、ホテルまたは学校は、賃貸部分について控除を失い、この制限は毎年繰り返される。

**初期控除は一度申請すれば安全だと思い込むこと。** 翌年に当該建築物が工業用として使用されていない場合、para 13(d)はそれを取り消す。

**売主の税務上の未償却残高をそのまま引き継ぐこと。** 独立当事者間の売買では、買主の適格支出は買主自身の価格である。Para 38から40のもとでの被支配譲渡のみが、残存支出額に置き換える。

## 次のステップ

商業用物件の売買契約書に署名する前に、土地と建築物の価値を契約書自体の中で分けて記載させておくこと——3年後に税務調査の圧力のもとで評価報告書を取得するよりも、はるかに安く済む。意図する用途がpara 63のリストに載っているか、それとも拡張各paraのいずれかを通じてのみ工業用建物としての取扱いに達するかを確認すること。賃貸制限は拡張カテゴリーには適用されるが、para 63の建築物には適用されないからである。そして、費用を分割する前に、真に機械設備（プラント）であって建築物ではないものが何かを確認すること。機械設備は年14%または20%で償却されるのに対し、建築物は3%だからである。
