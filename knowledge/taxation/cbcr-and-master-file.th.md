กำหนดเวลาที่จับกลุ่มบริษัทได้ไม่ใช่กำหนดยื่น มันคือการแจ้ง และมันตกใน **วันสุดท้ายของปีบัญชี
ที่รายงาน** — ก่อนที่ปีจะปิดด้วยซ้ำ และเต็มสิบสองเดือนก่อนที่รายงานเองจะครบกำหนด

## ใครอยู่ในขอบเขต

Rule 2 ของ Income Tax (Country-by-Country Reporting) Rules 2016 ตามที่เขียนใหม่โดย P.U.(A)
416/2017 ใช้กฎกับกลุ่มวิสาหกิจข้ามชาติเมื่อ:

- **รายได้รวมของกลุ่มที่จัดทำงบรวม** ในปีบัญชีก่อนปีบัญชีที่รายงาน **อย่างน้อย RM3 พันล้าน**; **และ**
- นิติบุคคลที่เป็นส่วนประกอบใด ๆ ของกลุ่มเป็นนิติบุคคลถือหุ้นสูงสุด (ultimate holding entity) ที่มี
  ถิ่นที่อยู่ในมาเลเซีย นิติบุคคลที่เป็นส่วนประกอบที่มีถิ่นที่อยู่ในมาเลเซีย นิติบุคคลถือหุ้นตัวแทน
  (surrogate holding entity) ที่มีถิ่นที่อยู่ในมาเลเซีย หรือ **สถานประกอบการถาวรในมาเลเซีย**

นิติบุคคลลาบวนที่ดำเนินกิจกรรมธุรกิจลาบวนอยู่ภายใต้ตราสารคู่ขนาน คือ Labuan Business Activity
Tax (Country-by-Country Reporting) Regulations 2017

โปรดสังเกตสกุลเงิน RM3 พันล้านไม่ใช่การแปลงจาก EUR 750 ล้านของ OECD และไม่ใช่เกณฑ์ Pillar Two —
กลุ่มหนึ่งอาจอยู่ในระบบหนึ่งและอยู่นอกอีกระบบหนึ่ง

## การแจ้ง

Rule 6 กำหนดให้นิติบุคคลที่เป็นส่วนประกอบที่มีถิ่นที่อยู่ในมาเลเซียทุกแห่งแจ้งอธิบดีเป็นลายลักษณ์อักษร
**ภายในหรือก่อนวันสุดท้ายของปีบัญชีที่รายงาน**:

- หากเป็นนิติบุคคลที่รายงาน ให้ระบุว่าเป็นนิติบุคคลถือหุ้นสูงสุดหรือนิติบุคคลถือหุ้นตัวแทน; หรือ
- หากไม่ใช่ ให้ระบุตัวตนและถิ่นที่อยู่ทางภาษีของนิติบุคคลที่เป็น พร้อมด้วยปีบัญชีของนิติบุคคลนั้น

ตั้งแต่ปีภาษี 2021 การแจ้งสามารถทำผ่าน **Form e-C** หรือ **Form LE1** สำหรับนิติบุคคลลาบวน ทางเลือก
คือหนังสือทางการบนหัวจดหมายของบริษัท ลงนามตาม s.75 ของ Income Tax Act 1967 ตามแบบที่ LHDN เผยแพร่
และส่ง **ด้วยมือหรือทางไปรษณีย์ด่วน** หน้าเว็บของ LHDN ระบุชัดเจนว่าต้องปฏิบัติตามแบบอย่างเคร่งครัด

## การยื่น

Rule 7: ไม่เกิน **สิบสองเดือนหลังวันสุดท้ายของปีบัญชีที่รายงาน**

Rule 5 กำหนดภาระให้นิติบุคคลถือหุ้นสูงสุดเมื่อมีถิ่นที่อยู่ในมาเลเซีย นิติบุคคลตัวแทนในมาเลเซียยื่นแทน
เมื่อบริษัทแม่ต่างประเทศไม่มีภาระการยื่นในประเทศของตน เมื่อเขตอำนาจของบริษัทแม่มีข้อตกลงระหว่าง
ประเทศกับมาเลเซียแต่ไม่มีข้อตกลงเจ้าหน้าที่ผู้มีอำนาจที่เข้าเกณฑ์มีผลบังคับ หรือเมื่อ LHDN แจ้ง
**ความล้มเหลวเชิงระบบ** (systemic failure) ในเขตอำนาจนั้น

รายงานมีสามตาราง — การจัดสรรเงินได้ ภาษี และกิจกรรมทางธุรกิจตามเขตอำนาจ; รายการนิติบุคคลที่เป็น
ส่วนประกอบต่อเขตอำนาจ; และข้อมูลอธิบายเพิ่มเติม ข้อมูลทางการเงินระบุเป็นริงกิตภายใต้ rule 4(2)
การยื่นทำผ่านแพลตฟอร์ม **HiDEF** ในรูปแบบ CbCR XML schema ของ OECD เข้ารหัสด้วยกุญแจสาธารณะของ IRBM

Rule 8 จำกัดการใช้รายงานของ LHDN ไว้ที่การประเมินความเสี่ยงการกำหนดราคาโอนและ BEPS ระดับสูง
และการวิเคราะห์ทางเศรษฐกิจ และห้ามใช้เป็นสิ่งทดแทนการวิเคราะห์การกำหนดราคาโอนโดยละเอียดเมื่อ
ทำการปรับปรุง

## คำถามเรื่อง Master File

มาเลเซียไม่กำหนดภาระการยื่น Master File แบบแยกต่างหาก สิ่งที่กำหนดคือ rule 4(2)(a) ของ Income Tax
(Transfer Pricing) Rules 2023 — ข้อมูลเกี่ยวกับกลุ่มวิสาหกิจข้ามชาติตามที่ระบุใน **Schedule 1**
ภายในเอกสารการกำหนดราคาโอนร่วมสมัย

Paragraph 11.7(a) ของ Malaysia Transfer Pricing Guidelines 2024 จึงระบุว่าเมื่อกลุ่มได้จัดทำ master
file ที่มีข้อมูลที่กำหนดทั้งหมด แฟ้มนั้น **สามารถยื่นแทน Schedule 1 ได้** ดังนั้น group master file
จึงเป็นสิ่งทดแทนที่อนุญาตสำหรับ schedule ของมาเลเซีย ไม่ใช่สิ่งที่ต้องส่งมอบแยกต่างหากพร้อมกำหนดเวลาของตนเอง

## ข้อผิดพลาดที่พบบ่อย

**ถือว่าการแจ้งเป็นการเตือนประจำปี** มันเป็นกำหนดเวลาตามกฎหมายที่ตกในวันสุดท้ายของปีบัญชี และใช้
กับนิติบุคคลที่เป็นส่วนประกอบในมาเลเซียทุกแห่ง รวมถึงแห่งที่ไม่ใช่นิติบุคคลที่รายงาน

**สันนิษฐานว่าการยื่นของบริษัทแม่ต่างประเทศครอบคลุมมาเลเซีย** โดยปกติมันครอบคลุมผ่านการแลกเปลี่ยน —
แต่เฉพาะเมื่อมีข้อตกลงเจ้าหน้าที่ผู้มีอำนาจที่เข้าเกณฑ์มีผลบังคับ เมื่อไม่มี นิติบุคคลตัวแทนในมาเลเซีย
ต้องยื่น

**สับสนเกณฑ์** RM3 พันล้านสำหรับ CbCR EUR 750 ล้านสำหรับภาษีขั้นต่ำระดับโลก RM30 ล้านและ RM10 ล้าน
สำหรับเอกสารการกำหนดราคาโอนเต็มรูปแบบ เป็นการทดสอบสามอย่างที่แตกต่างกัน

**ยื่น master file แล้วหยุด** Schedule 2 ของ Transfer Pricing Rules 2023 — ธุรกิจและการเทียบเคียง
ของนิติบุคคลมาเลเซียเอง — ไม่เคยถูกครอบคลุมโดย group master file

## หัวข้อที่เกี่ยวข้อง

ลงกำหนดการแจ้งเทียบกับวันสิ้นปีบัญชี ไม่ใช่วันที่ยื่น และยืนยันว่านิติบุคคลใดในกลุ่มเป็นนิติบุคคลที่
รายงานก่อนปีปิด จากนั้นอ่าน `transfer-pricing-documentation` สำหรับ local file และ
`global-minimum-tax-pillar-two` หากรายได้ที่จัดทำงบรวมใกล้ EUR 750 ล้าน
