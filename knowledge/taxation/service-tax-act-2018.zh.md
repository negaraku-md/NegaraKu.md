马来西亚的每一张餐厅账单、电话配套和停车收据上，都有一栏大多数人从不细看的内容——服务税。它背后的法律是**《2018年服务税法令》（807号法令）**，一部为对指定应税服务进行征收、课征和收取服务税而制定的法令。它于**2018年9月1日**生效，由**马来西亚皇家关税局（RMCD）**管理。各家公司的「SST更新」页面往往只是快照当年恰好适用的税率，很快就过时；本文将807号法令视为活的法律来处理——阐述其机制，并附上一条记录每一次税率与范围变动的单一带日期时间线。

## 什么是《2018年服务税法令》？

807号法令是让马来西亚得以课征服务税的法规。它是**销售与服务税（SST）**制度中服务税的那一半：服务税与销售税共同取代了**商品及服务税**，2014年商品及服务税法令自**2018年9月1日**起废除。

其机制刻意保持简单。服务税是一种由注册人对在营业过程中于马来西亚提供的指定应税服务征收的**单阶段税**。「单阶段」意味着它只在服务提供的环节征收一次——不像商品及服务税那样有进项税抵扣，因此税款并非沿供应链向上回收，而是流转至最终客户。应税服务的类别、门槛与豁免全部为*指定*——列于根据本法令制定的附属条例与命令之中，因此政府无需重写法规即可扩大征税范围。

除了本地供应，本法令的效力还跨越国界。服务税适用于**进口应税服务**（自2019年1月1日起生效），以及自**2020年1月1日**起供应予马来西亚消费者的**进口数字服务**——这是由2019年服务税（修订）法令引入的企业对消费者（B2C）制度。

## 服务税是多少？

税率由根据本法令制定的命令订定。2018年推出时为**6%**。自**2024年3月1日**起，标准税率上调至**8%**，但若干日常类别被刻意保留在6%。信用卡与签账卡服务完全不在百分比制度之内，而是按每张卡固定金额征税。

| 税率 | 适用于 |
|------|-----------|
| 8%（标准） | 大多数应税服务，自2024年3月1日起 |
| 6% | 餐饮、电信、停车及物流服务 |
| 每张卡RM25 | 信用卡与签账卡服务 |

## 谁必须注册并征收？

注册由营业额触发，而非出于自愿。任何提供应税服务的人士，一旦其在**12个月期间内**所提供应税服务的总值**超过规定门槛**，即**须注册**。一般门槛为应税营业额**RM500,000**，但2025年新增的服务群组门槛较高。注册后，商家必须对其应税服务征收服务税，并向RMCD入账。

| 服务群组 | 注册门槛 |
|------|-----------|
| 一般（大多数应税服务） | RM500,000 |
| 金融服务（以收费为基础） | RM1,000,000 |
| 租赁 | RM1,500,000 |
| 建筑 | RM1,500,000 |
| 私人医疗 | RM1,500,000 |

租赁群组于2025年7月1日成为应税时，门槛定为RM1,000,000，随后自**2026年1月1日起提高至RM1,500,000**。教育服务按每名学生的收费门槛征税，而非按营业额门槛（见下文）。

外国供应者并不获豁免：进口应税服务与进口数字服务的提供者同样落入这张网内，在达到相关门槛时必须注册并为税款入账。

## 服务税如何申报与缴纳？

注册人使用**SST-02申报表**申报并缴纳服务税。该申报表涵盖**两个月的应税期**，须**不迟于该期结束后一个月的最后一天**提交——例如，一月至二月的期间须在3月31日之前提交。缴款截止日期相同。

## 2025年7月1日有什么变化？

自2018年以来最大的转变发生在**2025年7月1日**，当时政府扩大了服务税的范围，涵盖此前不在其列的服务：**租赁、建筑、金融服务、私人医疗与教育**。原拟将范围扩大至**美容服务**——修甲、面部护理、理发与美发——的建议，在生效日之前经公众反馈后**撤回**，因此并无美容服务群组。

此次扩大并非单一统一税率。以收费为基础的金融服务按**8%**征税，而建筑、教育与私人医疗按**6%**征税，各有针对性的豁免：

| 扩大群组（自2025年7月1日起） | 税率 | 主要范围说明 |
|------|------|------|
| 以收费为基础的金融服务 | 8% | 以收费与佣金为基础的服务 |
| 建筑 | 6% | 注册门槛RM1,500,000 |
| 租赁 | 8%，自2026年1月1日起降至6% | 注册门槛RM1,000,000，自2026年1月1日起提高至RM1,500,000 |
| 私人医疗 | 6% | 仅适用于向非马来西亚公民提供的服务；向马来西亚公民提供的服务获豁免 |
| 教育 | 6% | 适用于每名学生每学年收费超过RM60,000者 |

**私人医疗**（RMCD服务税政策第5/2025号）仅对向**非马来西亚公民**提供的服务适用6%税率，涵盖私人医院、传统与辅助医学及联合医疗服务；向马来西亚公民提供的服务获豁免，政府与大学设施亦然。

**教育**（RMCD服务税政策第4/2025号）对每名学生每学年收费超过**RM60,000**的私立与国际学校及私立高等教育课征6%服务税，特殊教育学校及向持有OKU（残障）卡的马来西亚公民提供的服务则获豁免。

政府认识到数以千计新纳入应税范围的商家需要时间合规，因此设立宽限期：对采取措施遵守扩大规定的商家，**直至2025年12月31日不予检控或处罚**。

## 2026年1月1日对租赁的修订

在进一步的业界反馈之后，政府自**2026年1月1日**起修订了租赁规则：租赁服务的服务税率由**8%下调至6%**，租赁（MSME）注册门槛由**RM1,000,000提高至RM1,500,000**。这些变动于2026年1月5日宣布，并于2026年3月13日刊宪，RMCD在刊宪前自2026年1月1日起给予2%的临时豁免。建筑（6%）、金融服务（8%）、教育（6%）与私人医疗（6%，非公民）的税率与门槛未因此次修订而改变。

## 807号法令的时间线

由于该法规长久稳定，但其税率与范围随每份财政预算案而变，掌握807号法令最清晰的方式，是将其视为一连串带日期的事件：

| 日期 | 变化 |
|------|--------|
| 2018年9月1日 | 807号法令生效；服务税＋销售税（SST）取代已废除的商品及服务税。推出税率6%。 |
| 2019年1月1日 | 服务税扩大至进口应税服务。 |
| 2020年1月1日 | 通过2019年服务税（修订）法令，对进口数字服务（B2C）开征服务税。 |
| 2024年3月1日 | 标准税率由6%上调至8%；餐饮、电信、停车及物流维持在6%。 |
| 2025年7月1日 | 范围扩大至租赁（8%）、建筑（6%）、金融服务（8%）、私人医疗（6%，非公民）与教育（6%）。原拟扩大至美容服务的建议撤回。 |
| 直至2025年12月31日 | 对遵守2025年扩大规定的商家设罚则宽限期。 |
| 2026年1月1日 | 租赁税率由8%下调至6%，其注册门槛由RM1,000,000提高至RM1,500,000（2026年1月5日宣布，2026年3月13日刊宪）。 |

## 接下来

关于实务操作细节，请对照RMCD的**[MySST门户](https://mysst.customs.gov.my/)**及根据本法令制定的最新命令，确认现行税率、门槛与应税服务类别，并在**[总检察署](https://lom.agc.gov.my/ilims/upload/portal/akta/outputaktap/1690140_BI/ACT%20807%20Final%2022072021%20Portal.pdf)**查阅主要法规原文。由于税率与范围随每份联邦预算案而变动，在依据本文数据行事之前，请务必查证是否已有较晚的预算案取代此处的数字。
