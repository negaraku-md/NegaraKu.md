フリーランスの税額を決める問いは、いくら稼いだかではない。
そのお金がs.4のどの段に落ちたかである——なぜならs.4(a)は控除機構をまるごと
持ち込むのに対し、s.4(f)はほとんど何も持ち込まないからだ。

これを誤ると、すでに使ってしまった総収入に対して税金を払うことになる。

## Section 4(a)か、section 4(f)か

1967年所得税法（Act 53）のsection 4は、課税所得の各区分を列挙している。ここで
重要なのは二つである。

- **s.4(a)**——**事業**からの収益又は利得。経営された期間の長短を問わない。
- **s.4(f)**——**それ以前のいずれの段にも該当しない**収益又は利得。残余の受け
  皿である。

同法のどこにも、フリーランスがそのどちらに当たるかは書かれていない。この分類
は事実認定の問題であり、それを決める要素はおなじみのものである。すなわち、
継続性と反復性、組織と仕組み、営利を求める意図、顧客への売り込み、施設又は
設備の使用、そして活動の規模である。

| | s.4(a) 事業 | s.4(f) その他所得 |
| --- | --- | --- |
| 典型例 | 定期的なフリーランス業務、店舗、生計を立てるための配車サービス、収益化されたチャンネル | 一件のコンサルティング報酬、孤立した一回限りの収入 |
| 経費 | s.39に従いつつs.33(1)の下で控除可能 | s.33(1)の下での直接的な経費のみ——それ以上広い機構はない |
| 資本減免 | Schedule 3の下で利用可能 | 利用不可 |
| 欠損 | 法定の限度に従いつつ、総所得に対して繰り越すことができる | 救済なし |
| 申告書 | **B様式（Form B）**、6月30日期限 | BE様式（Form BE）、4月30日期限。ただし他の事由でBに引き込まれる場合を除く |
| 分割納付 | s.107Bの下でのCP500 | s.107Bの下でのCP500 |

s.4(f)のほうが小さく聞こえるからという理由でそちらを好む直感は、逆さまである。
実際に働いて生計を立てている者にとって、section 4(a)はほとんど常により良い
結果であり、通常はそれが正しい分類でもある。

混同されがちな二点を整理しておく。**プラットフォーム**からの収入は自動的に
事業所得になるわけではない——それが事業所得であるのは、誰があなたに支払うか
ではなく、あなたが何をするかによる。そしてs.4(b)の下での**雇用**収入はまったく
別の第三の区分である。その関係が支配性、統合性及びサービス契約（contract of
service）のその他の指標を備えているなら、いくら請求書を発行しようとフリーランス
にはならない。

## ホームオフィスは実際に何を控除できるか

Section 33(1)は、総収入の生産のために**完全かつ専ら**支出された経費の控除を
認めている。続いてSection 39(1)は、以下を除外する。

- **(a)** 家庭的又は私的な支出；
- **(b)** 総収入を生み出す目的のために完全かつ専ら支出されたものではない
  支払い；
- **(c)** 引き出された資本又は資本として用いられた金額。

住まいはデフォルトでは家庭的な支出である。その一部を控除可能にするのは、
定められた一部分が収入を生み出すために使われており、同時に家庭用途に使われて
いないことである。

審査に耐える申告には、通常次の要素がある。

| 要素 | それを裏付けるもの |
| --- | --- |
| 按分の基準 | 専用の作業スペースの床面積を総床面積で割った比率を、家賃及び光熱費に適用する |
| 専用性 | 業務に使う部屋又は定められた区域であること。食卓ではない |
| 書類 | 賃貸借契約書又はローン明細書、光熱費の請求書、間取り図、そして計算過程そのもの |
| 設備 | 経費としてではなく、Schedule 3の下での資本減免として申告する |
| 混合用途の項目 | 電話及びインターネットは、説得力のある使用実態の基準で按分する |

最もよくある失敗は、根拠のないきりの良いパーセンテージを申告することである。
二番目によくあるのは、ノートパソコンを経費として申告することである——それは
s.39(1)(c)の下での資本であり、資本減免の計算に属する。

## CP500と分割納付の落とし穴

雇用によらない収入を得るようになると、s.107Bが適用される。内国歳入庁長官
（Director General）は、雇用所得に対する税を**除いた**税額の見込み分割払いを、
自ら指定する時期と金額で——CP500として発出し——税額が賦課されているか否かに
かかわらず指示する。この見積もりは通常、直近の賦課年度を基に組み立てられる。

案内書がよく飛ばす、二つの仕組みがある。

**修正の窓は一つではなく二つある。** s.107B(2)のただし書きは、その賦課年度
において、**6月30日までに一度、又は10月31日までに一度、あるいはその両方**、
分割払いの金額及び回数を変更する申請を認めている。崩れつつある年でも、二度
調整できる。

**二つの10%加算は互いに異なる仕組みで働く。** s.107B(3)の下では、ある分割
払いが期日から**三十日以内**に納付されない場合、未納額に対し自動的かつ通知なく
10%が加算される。s.107B(4)の下では、あなたが変更を申請していて、最終的な税額
が分割払いの合計額を**30%超**上回った場合、10%は差額のうち**30%の幅を超えた
部分**のみに課される——不足額全体にではない。雇用所得も併せてある場合、ただし
書きは、s.107B(4A)の算式によって計算された雇用に帰属する部分だけ、納付すべき
税額を減額する。

実務上の帰結はこうだ。CP500を引き下げた後に好調な年を迎えたフリーランスが
自動的に罰されることはない。単に納付をやめた者は罰される。

## 電子インボイスの対象となるのはいつか

電子インボイスの義務化は売上高によって範囲が定められており、小規模の端は
本当にその範囲外である。

| 状況 | 効果 |
| --- | --- |
| 年間売上高又は収入が**RM1,000,000**未満 | **免除**——常設の免除であり、先延ばしではない |
| 事業を営んでいない個人 | 免除 |
| 2023年から2025年の間に開業し、売上高が少なくともRM1 million | **2026年7月1日**から義務化 |
| 2026年以降に開業 | 2026年7月1日又は開業日のいずれか |
| 第4段階群組の過渡的な緩和 | **2027年12月31日**まで |

発行を免除されているからといって、見えなくなるわけではない。対象範囲に
入っている取引先企業は、自らの記録のために有効な文書を依然として必要とし、
相手方が**自己請求電子インボイス（self-billed e-Invoice）**を発行する場合、
あなたがアカウントを持っているか否かにかかわらず、あなたの情報はMyInvoisに
現れる。あなたの顧客が申告した収入は、内国歳入庁（LHDN）に見える収入である。

## ギグワーカー法2025はどこに位置づけられるか

ギグワーカー法2025（Gig Workers Act 2025、Act 872）は**分類**のための法令
である。ギグワーカー及びサービス提供契約（service agreement）を定義し、審判所
と紛争処理手続を設け、強制的なプラットフォーム拠出を課す。それが変えるのは、
一連の労働及び社会保障上の義務の対象となる者の範囲である。

それは1967年所得税法のs.4を変えるものではない。Act 872の内に入っても、
税務上あなたが従業員になるわけではなく、PCBの対象になるわけでもなく、B様式
（Form B）の義務が免除されるわけでもない。この二つの法令は、異なる目的のため
に異なる基準で分類しており、ある労働者がAct 872の下でギグワーカーでありながら、
税務上はs.4(a)の事業を営んでいることもありうる。

それが実際に変えるのは範囲である。以前は普通の独立請負人として扱われて
いた労働者が、いまでは特定され、登録され、記録に残る経路を通じて支払いを
受けるようになる。記録に残る収入は、申告される収入である。

## よくある間違い

- **フリーランス収入があるのにBE様式（Form BE）を提出すること。** 事業所得
  があれば6月30日期限のB様式（Form B）になる。BEを提出すると、収入源を過小
  申告することになる。
- **家賃を丸ごと申告すること。** Section 39(1)(a)は家庭的な支出を阻む。按分
  し、その根拠を文書化し、間取り図を保管すること。
- **設備を経費計上すること。** 資本的な項目はs.33(1)ではなく、Schedule 3の
  資本減免を通す。
- **賦課がまだされていないからとCP500を無視すること。** Section 107B(1)は
  税額が賦課されているか否かにかかわらず作動し、s.107B(3)の下での10%は通知なく
  適用される。
- **s.77Cの最終税額選択が自分をカバーしていると思い込むこと。** それは雇用
  所得**のみ**であることを要求する。フリーランス収入が少しでもあれば対象外と
  なり、申告しなければならない。
- **RM1 millionという電子インボイスの数字を先延ばしだと捉えること。** それは
  売上高に連動した常設の免除であり、それを超えた年に消える。
- **Act 872を税務上の再分類と読むこと。** そうではない。

可能性のテストをきちんと検討したうえで、売上高が電子インボイスの対象範囲に
自分を入れていないかを確認すること。
