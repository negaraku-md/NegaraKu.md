あなたの様式を決めるのは二つのことである。s.7(1)のもとで**居住者**であるかどうか、そして**事業所得**があるかどうかである。
それ以外のすべては、この二点に従う。

## 決定表

| あなたは | 様式 | e-Filing様式 | 法定期限 | e-Filing猶予 |
| --- | --- | --- | --- | --- |
| 居住者個人、事業所得**なし** | BE | e-BE | 4月30日 | **15日** |
| 居住者個人、事業所得**あり** | B | e-B | 6月30日 | **15日** |
| 居住者の知識労働者、専門家、又は重要な地位にある非市民 | BT | e-BT | 4月30日、事業所得があれば6月30日 | **15日** |
| 非居住者個人 | M | e-M | 4月30日、事業所得があれば6月30日 | **15日** |
| 非居住者の知識労働者 | MT | e-MT | 4月30日、事業所得があれば6月30日 | **15日** |
| パートナーシップ（商号自身の申告書） | P | e-P | 6月30日 | **15日** |
| 団体又は組合 | TF | e-TF | 4月30日、事業所得があれば6月30日 | **15日** |
| 死亡した者の遺産 | TP | e-TP | 4月30日、事業所得があれば6月30日 | **15日** |
| ヒンドゥー合同家族 | TJ | e-TJ | 4月30日、事業所得があれば6月30日 | **15日** |
| 雇主、酬金申告書 | E | e-E | 3月31日 | **1か月** |
| 会社 | C | e-C | 会計期間終了後7か月以内 | **1か月** |
| 有限責任事業組合 | PT | e-PT | 会計期間終了後7か月以内 | **1か月** |

期限は賦課年度の**翌**年に落ちる。YA2025のBE様式は2026年4月30日が期限であり、
e-BEは2026年5月15日まで受理された。

## 猶予期間がカバーするもの、カバーしないもの

| 論点 | 立場 |
| --- | --- |
| 適用対象 | e-Filingを通じて提出された申告書のみ |
| 併せて延長されるもの | s.103(1)の税額残高の納付日 |
| 納付日を**延長しない**様式 | E様式、P様式及びCPE様式 |
| 猶予を逃した場合の効果 | 猶予期間の終了時点からではなく、**本来の法定日から**遅延として扱われる |

最後の行が落とし穴である。LHDN自身の申告プログラムのExample 1では、YA2025の
e-BEを2026年5月16日に提出した場合、**2026年5月1日から**遅延したものとみなされる。
猶予期間は加算税の時計に対する15日間のクッションではない——それは、あなたが中に
入るか、入らないかのいずれかである窓である。

E様式とP様式が除外されるのは**納付**の延長のみである。いずれも税額残高を伴わない
ためである。両方とも申告の延長は引き続き受けられる。

## 義務化されたe-Filing、カテゴリー別

| カテゴリー | 義務化される時期 |
| --- | --- |
| 会社（e-C） | YA2014 |
| 会社又はラブアン会社である雇主（e-E） | 酬金年度2016 |
| 有限責任事業組合（e-PT） | YA2021 |
| 個人、パートナーシップ、団体、遺産（e-BE、e-B、e-BT、e-M、e-MT、e-P、e-TF、e-TP） | **YA2023** |
| 会社以外の雇主（e-E） | 酬金年度2023 |
| 石油事業（e-CPP、e-CPE） | YA2023 |
| 協同組合及び信託団体（e-CS、e-TA、e-TC、e-TR） | YA2024 |
| ヒンドゥー合同家族（e-TJ） | YA2024 |
| ラブアン実体（e-LE1） | YA2025 |

税務代理人はMyTaxではなくTAeF 2.0を通じて提出する。

## 雇主の並行カレンダー

| 文書 | 交付先 | 期限 |
| --- | --- | --- |
| EA様式 | 各従業員 | **2月28日**、s.83(1A) |
| C.P.8DとともにE様式 | LHDN | **3月31日**、1か月のe-Filing猶予 |
| CP22 | LHDN、新規従業員 | 就業開始から**30日**以内 |
| CP22A | LHDN、雇用終了 | 雇用終了の**30日以上前** |
| CP21 | LHDN、マレーシアを離れる従業員 | 出国の**30日以上前** |
| CP58 | 代理店、ディーラー、販売店 | **3月31日** |

E様式は、C.P.8Dが同じ期限までに提出されて初めて完全なものとして受理される。
休眠中の会社、LLP、信託団体及び協同組合も、E様式とC.P.8Dを提出しなければならない。
**従業員がいない**独資経営、パートナーシップ、ヒンドゥー合同家族又は遺産は、
C.P.8Dを免除される。

## 遅延申告の結果

| 様式 | 条文 |
| --- | --- |
| E様式及びP様式以外のすべての申告書 | s.112(1)のもとでの訴追**又は**s.112(3)のもとでの加算税 |
| E様式及びP様式 | s.120(1)のもとでの措置 |

## よくある誤り

- **BE様式に1か月の猶予があると思い込むこと。** それは15日である。1か月という
  数字はE様式と会社系の様式のものであり、これを混同すると、申告書が取り返しの
  つかない点を2週間過ぎてしまう。
- **フリーランス収入があるのにBEを提出すること。** いかなるs.4(a)の事業源泉も、
  あなたをB様式と6月30日に移す。代わりにBEを提出すると、収入源を過小申告する
  ことになる。
- **P様式が組合員の税を清算すると考えること。** P様式はパートナーシップの情報
  申告書である。各組合員は依然としてB様式で自らの持分を申告しなければならない。
- **休眠中はE様式を任意だと扱うこと。** 会社、LLP、信託団体及び協同組合は、
  営業していたか否かにかかわらず提出しなければならない。
- **紙の様式を待つこと。** e-Filingは個人についてYA2023以降義務化されており、
  申告プログラムの郵送欄にはいかなる延長も一切ない。
