在马来西亚买一辆车，你所缴的税可能几乎与车价本身相当。主要原因是一项鲜少被讨论却极具威力的税项：**消费税（excise duty）**。

消费税是对被视为奢侈、不健康，或可能加重公共卫生系统负担的特定商品征收的国内税。它不是像销售税那样的普遍税项——它只针对少数几个类别：机动车辆、烈酒、香烟与电子烟、含糖饮料、预混调制品，以及扑克牌与麻将。

## 什么是消费税？由谁征收？

消费税由**《1976年消费税法令》（Excise Act 1976）**规定，并由**马来西亚皇家关税局（JKDM）**执行。与在边境征收的进口税不同，消费税既针对在国内制造的商品，也针对进口的商品征收。

一般而言，消费税在商品制造时即产生应课性质，并在商品从持牌制造商厂房运出时应缴——对于来自国外的商品则在进口时应缴。因此，酒厂或车辆组装商等消费税商品的制造商必须持有消费税执照，并将其商品置于关税监管之下，直至税款结清。

税率以两种形式计算：

- **从价（Ad valorem）**——按商品价值的百分比计算（例如小型汽车为75%）。
- **从量（Specific）**——按每单位的固定金额计算（例如含糖饮料每公升90仙，或预混调制品每100克47仙）。

某些商品如烈酒采用**复合税率（composite rate）**——固定税额与百分比的结合。

## 汽车的消费税是多少？

机动车辆是马来西亚消费税的最大来源，也是本地汽车价格高昂的主要原因。对于载客汽车（saloon），消费税按引擎容量以从价方式计算：

| 引擎容量 | 消费税率（载客汽车） |
|---|---|
| 1,800cc以下 | 75% |
| 1,800–1,999cc | 80% |
| 2,000–2,499cc | 90% |
| 2,500cc及以上 | 105% |

上述税率表所记录的是本地组装汽车（CKD，*completely knocked-down*）的税率。进口整车（CBU，*completely built-up*）承担相同的消费税率——差别在于CBU汽车还需在此之上缴纳进口税。所有税率均以完税价值（duty-paid value）为计算基础。

使汽车价格高昂的是三层税项的**叠加效应**。对于从东盟以外进口的CBU汽车，顺序如下：

1. **进口税**先征收——来自东盟以外的CBU汽车为30%（来自东盟国家的汽车在东盟协定下享有0%）。此税率取决于自由贸易协定；例如，某些来自中国的电动车在ACFTA下享有低至5%的进口税率。
2. **消费税**就*完税价值*（即基础价格加进口税）计算。
3. **10%销售税**最后征收，以已包含消费税的总额为基础。

由于每一层都在被上一层膨胀后的总额之上计算，一辆进口汽车的价格可能超过原价的两倍。相反，在国内组装的CKD汽车通常其零部件可豁免进口税，因此只承担消费税和销售税——这就是本地制造汽车较便宜的原因。

## 酒类和香烟的消费税是多少？

酒类和烟草是典型的消费税商品——既提高价格又用以承担公共卫生成本的「罪恶税」（sin tax）。以下是一些税率作为参考（特定烈酒和烟草的绝对数额需向JKDM核实）：

| 商品 | 消费税率 |
|---|---|
| 啤酒 / 黑啤（stout） | 每公升RM175.00（100%酒精浓度）+ 15%从价（复合） |
| 葡萄酒 | 每公升RM450 |
| 烈酒 / 蒸馏酒 | 每公升RM1.10 + 15%（复合） |
| 伏特加 | 每公升RM150（100%酒精浓度） |
| 清酒（sake） | 每公升RM60（100%酒精浓度） |
| 香烟 | 每支RM0.42（自2025年11月1日起生效） |
| 雪茄 / cheroot / 小雪茄 | 每公斤RM440 |
| 加热烟草制品 | 每公斤RM798 |
| 咀嚼烟草 | 5% + 每公斤RM27 |

通过《2026年财政预算案》，多项税率自2025年11月1日起提高：香烟每支上调2仙（从RM0.40提高至RM0.42），酒类消费税全面上调10%，加热烟草制品每公斤上调RM20，雪茄每公斤上调RM40。咀嚼烟草则是通过《2024年财政预算案》引入的全新消费税类别。

## 含糖饮料税又如何？

含糖饮料（SSB，*sugar-sweetened beverages*）消费税是马来西亚最年轻的消费税之一，于2019年7月1日作为卫生部「对糖宣战」（Perang Terhadap Gula）行动的一部分而引入。其门槛因类别而异，并非单一统一门槛：HS 2202项下的即饮饮料若每100毫升含糖量超过5克则征税；乳制饮料（同属HS 2202）若每100毫升含糖量超过7克则征税；HS 2009项下的果汁或蔬菜汁若每100毫升含糖量超过12克则征税。

税率先后两次上调：

| 生效日期 | 税率 |
|---|---|
| 2019年7月1日 | 每公升40仙 |
| 2024年1月1日 | 每公升50仙 |
| 2025年1月1日 | 每公升90仙 |

上调至每公升90仙——较50仙飙升80%——是在《2025年财政预算案》中宣布的。其影响相当显著：仅在2025年1月至11月间，政府便从SSB消费税征收了**RM73.81百万**，使自2019年该税开征以来的总征收额达到**RM521.35百万**。在2025年的征收额中，RM25百万拨予卫生部，用于倡导计划、为糖尿病患者提供SGLT-2药物，以及为末期肾病患者提供腹膜透析设施。

除含糖饮料外，预混调制品（premix）如3合1速溶咖啡和茶也自2024年3月1日起，根据《2024年消费税（修订）令》被征收每100克47仙的消费税。

## 其他征收消费税的商品

消费税商品清单比想象中更长。除了汽车、酒类、香烟和含糖饮料，以下类别也在征税范围内：

- **其他车辆**——摩托车、轻便摩托车（moped，20%），以及全地形车/ATV（65%）。
- **气泡酒（sparkling wine）**——每公升RM450（100%酒精浓度）。
- **扑克牌**——10%从价。
- **麻将**——10%从价。

扑克牌和麻将等博彩商品基于历史和社会原因仍留在消费税清单中，尽管相比汽车和烟草，其征收额较小。

## 接下来

消费税构成了你为汽车、烈酒、香烟和甜饮所支付价格的很大一部分——而且税率经常在每年10月的财政预算案提呈时修订。在购买进口汽车等高价值商品之前，请在JKDM官方网站查看现行税率，因为数字可能逐年变化。

若想全面了解马来西亚的税务，也请阅读我们关于**销售与服务税（SST）**和**进口税**的文章，因为这三者常常在同一商品上叠加。对于制造商和进口商，请参考**马来西亚皇家关税局**以了解消费税执照与合规要求。
