在马来西亚买一辆车，你所缴的税可能几乎与车价本身相当。其主要根源是一项鲜少被讨论却极具威力的税项：**消费税（国内货物税，duti eksais）**。

消费税是对被视为奢侈、不健康或可能加重公共卫生体系负担的特定商品所征收的一种国内税。它并非像销售税那样的普遍税项——它只针对少数几个类别：机动车辆、烈酒、香烟与电子烟、含糖饮料、预混制品，以及扑克牌与麻将牌。

## 什么是消费税，由谁征收？

消费税由**《1976年消费税法》（Akta Eksais 1976）**规定，并由**马来西亚皇家关税局（JKDM）**执行。与在边境征收的进口税不同，消费税既对国内制造的商品征收，也对进口商品征收。

一般而言，消费税在商品制造时即应课征，并在该商品从持牌制造商厂房出厂时应缴——对于来自国外的商品，则在进口时应缴。因此，啤酒厂或车辆组装商等消费税商品制造商必须持有消费税执照，并将其商品置于关税管制之下，直至税款结清。

税率以两种形式计算：

- **从价（Ad valorem）**——按商品价值的百分比计算（例如小型汽车为75%）。
- **从量（Spesifik）**——按每单位征收固定金额（例如啤酒每公升RM7.40，或含糖饮料每公升90仙）。

某些商品如烈酒使用**复合税率（kadar komposit）**——固定税率与百分比的结合。

## 汽车的消费税是多少？

机动车辆是马来西亚最大的消费税来源，也是此地汽车价格高昂的主要原因。对于载客汽车（saloon），消费税按发动机排量以从价方式计算：

| 发动机排量 | 消费税税率（载客汽车） |
|---|---|
| 1,800cc以下 | 75% |
| 1,800–1,999cc | 80% |
| 2,000–2,499cc | 90% |
| 2,500cc及以上 | 105% |

上表所列税率是针对本地组装汽车（CKD，*completely knocked-down*）记录的。进口整车（CBU，*completely built-up*）承担相同的消费税率——区别在于CBU汽车还需在此之上缴纳进口税。所有税率均以完税价值（nilai duti-dibayar）为基础计算。

使汽车价格高昂的是三层税项的**叠加效应**。对于从东盟以外进口的CBU汽车，征收顺序如下：

1. **进口税**先行征收——来自东盟以外的CBU汽车为30%（来自东盟国家的汽车在东盟协定下享有0%）。此税率取决于自由贸易协定；例如，来自中国的某些电动车在ACFTA下享有低至5%的进口税率。
2. **消费税**以*完税价值*（即基础价格加进口税）为基础计算。
3. **10%销售税**最后征收，以已包含消费税的总额为基础。

由于每一层都是以已被前一层膨胀的总额为基础计算，一辆进口汽车的价格可能高达其原价的两倍以上。相反，在国内组装的CKD汽车通常对其零部件免征进口税，因此只承担消费税和销售税——这正是本地制造汽车更便宜的原因。

## 酒类和香烟的消费税是多少？

酒类和烟草是典型的消费税商品——它们既抬高价格，又用以填补公共卫生成本的"罪恶税"。以下是2025年11月修订后的一些最新税率：

| 商品 | 消费税税率 |
|---|---|
| 啤酒／黑啤（stout） | 每公升RM7.40 |
| 葡萄酒 | 每公升RM450 |
| 烈酒／spirit | 每公升RM1.10 + 15%（复合税率） |
| 伏特加 | 每公升RM150（100%酒精浓度） |
| 清酒 | 每公升RM60（100%酒精浓度） |
| 香烟 | 每支RM0.42（自2025年11月1日起生效） |
| 雪茄／cheroot／小雪茄（cigarillo） | 每公斤RM440 |
| 加热烟草制品 | 每公斤RM798 |
| 咀嚼烟草 | 5% + 每公斤RM27 |

香烟税自2014年起一直冻结，直到2025年11月才每支上调2仙，同时酒类产品税率在同一日上调10%。咀嚼烟草则是通过2024年财政预算案引入的新消费税类别。

## 含糖饮料税又如何？

含糖饮料（SSB，*sugar-sweetened beverages*）消费税是马来西亚最年轻的消费税之一，于2019年7月1日引入，作为卫生部"抗糖之战"（Perang Terhadap Gula）的一部分。它针对HS 2202项下、每100毫升含糖量超过5克的即饮饮料，以及部分依各自含糖量门槛而定的果汁和调味乳类别。

税率曾连续两次上调：

| 生效日期 | 税率 |
|---|---|
| 2019年7月1日 | 每公升40仙 |
| 2024年1月1日 | 每公升50仙 |
| 2025年1月1日 | 每公升90仙 |

上调至每公升90仙——较50仙跃升80%——是在2025年财政预算案中宣布的。其影响相当显著：政府仅在2025年1月至11月期间就从SSB消费税征收了**7381万令吉**，使自2019年该税开征以来的总征收额达到**5亿2135万令吉**。在2025年的征收额中，2500万令吉拨予卫生部，用于倡导计划、供糖尿病患者使用的SGLT-2药物，以及供末期肾病患者使用的腹膜透析设施。

除含糖饮料外，3合1速溶咖啡和茶等预混制品（premix）也需缴纳每100克47仙的消费税，自2024年3月1日起根据《2024年消费税（修订）令》生效。

## 其他需缴消费税的商品

消费税商品清单比想象中更长。除汽车、酒类、香烟和含糖饮料外，以下类别同样适用：

- **其他车辆**——摩托车、轻便摩托车（20%），以及全地形车／ATV（65%）。
- **气泡酒（sparkling wine）**——每公升RM450（100%酒精浓度）。
- **扑克牌**——10%从价税。
- **麻将牌**——10%从价税。

扑克牌和麻将牌等赌博用品因历史和社会原因仍留在消费税清单中，尽管其征收额相较汽车和烟草而言微不足道。

## 接下来该怎么做

消费税构成你为汽车、烈酒、香烟和甜味饮料所付价格的很大一部分——其税率常在每年十月呈报财政预算案时被修订。在购买进口汽车等高价值商品前，请在JKDM官方网站查阅最新税率，因为数字可能逐年变动。

若要全面了解马来西亚的税务，也请阅读我们关于**销售与服务税（SST）**和**进口税**的文章，因为这三者常对同一商品叠加征收。制造商和进口商则可参阅**马来西亚皇家关税局**，了解消费税的执照与合规要求。
