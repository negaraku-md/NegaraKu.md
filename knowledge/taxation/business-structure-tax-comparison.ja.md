マレーシアの事業形態を比較する記事の多くは、「会社は15%、個人は最高30%」で
止まっている——これは正しいが、役に立たない。利益RM100,000の時点では、個人
事業主のほうが会社より納める税が少ない。会社が勝つのは利益が上がってからで
あり、どれだけ勝つかは、そのお金をどう扱うかに完全に左右される。

以下では、同じ利益を四つの事業形態に通し、計算過程をそのまま示す。

## 実際に選んでいる税率

**個人**はparagraph 1 of Part I of Schedule 1の累進表で課税される：最初の
RM5,000は非課税、その後1%、3%、6%、11%、19%とRM100,000まで上がり、続いて
**RM100,001からRM400,000までは25%**、RM600,000までは26%、RM2 millionまでは
28%、それ以上は30%となる。個人事業主が不利になり始めるのは、この25%の階層
からである。

**会社**はparagraph 2のもとで24%課税されるが、paragraph 2Aが適用される場合
は別である：**最初のRM150,000に15%、続くRM450,000に17%、RM600,000超に24%**
となる。Paragraph 2Aは、会社がマレーシアの居住者であり*かつ*マレーシアで設
立されていること、基期開始時点で普通株の実払込資本がRM250万以下であること、
そして総事業収入がRM5,000万を超えないことを要求する。

**パートナーシップ（組合）**は透明体である——パートナーシップ自体が申告書
を提出するが、各組合員は可分配所得のうちの自らの持分について、累進税率で
個別に評価される。

**LLP（有限責任事業組合）**は実体として課税され、資本出資がRM250万以下かつ
総事業収入がRM5,000万を超えない場合、paragraph 2Dにより同じ15、17、24の三
段階税率が与えられる。

## 個人事業主が決して受けられない控除

個人事業主とその事業は一つの法律上の人である。引き出された金銭は利益の分配
であり、section 39(1)は三重にそれを阻む：paragraph (a)は家庭的又は私的な
支出を認めず、paragraph (b)は総収入を生み出すために完全かつ専ら支出された
ものではない支出を認めず、paragraph (c)は引き出された資本を一切認めない。

Sdn Bhd（非公開有限会社）は独立した人であるため、取締役給与は通常の事業支
出であり、s.33(1)のもとで控除できる——そしてそれに対する**雇主EPF拠出**も
同様に控除できる。この一つの構造的な違いが、以下の数字の大半を左右してい
る。

同じ論理は従来型のパートナーシップにも当てはまる。「組合員の給与」は可分配
所得の配分であって、それに対する控除ではない。

## 利益RM300,000での実算比較

マレーシア居住者である事業主を想定し、事業主への報酬支払い前の業務利益を
RM300,000、申告する個人減免はRM9,000のみとして、両者を同じ土俵で比較する。

**個人事業**

| 項目 | RM |
| --- | --- |
| 法定事業所得 | 300,000 |
| 個人減免控除後 | (9,000) |
| 課税所得 | 291,000 |
| 税額：RM100,000までの累計 | 9,400 |
| 税額：RM191,000に25% | 47,750 |
| **税額合計** | **57,150** |

**月RM10,000の取締役給与を支払うSdn Bhd**

| 項目 | RM |
| --- | --- |
| 報酬支払い前利益 | 300,000 |
| 取締役給与控除後 | (120,000) |
| 雇主EPF12%控除後 | (14,400) |
| 雇主SOCSO（最高等級、月RM104.15）控除後 | (1,250) |
| 会社の課税所得 | 164,350 |
| 会社税額：RM150,000に15% | 22,500 |
| 会社税額：RM14,350に17% | 2,440 |
| **会社税額** | **24,940** |
| 取締役の雇用所得 | 120,000 |
| 個人減免控除後 | (9,000) |
| 取締役の課税所得 | 111,000 |
| 取締役税額：RM100,000までの累計 | 9,400 |
| 取締役税額：RM11,000に25% | 2,750 |
| **取締役税額** | **12,150** |
| **合計税額** | **37,090** |

この利益水準では、会社形態はおよそ**RM20,000**を節税し、さらに**RM27,600**
を取締役のEPF口座へ振り向ける——雇主分がRM14,400、従業員11%分がRM13,200で
ある。それは税ではない。個人事業主であれば自ら任意で積み立てなければなら
ない、繰延貯蓄である。

EPFの数字には一点留保がある：拠出額は、月給がRM20,000を超える場合を除き、
正確なパーセンテージで算出されるのではなく、賃金の等級ごとにThird Schedule
から読み取られる。RM14,400は等級レベルの近似値として扱うこと。

## 交差点は実際どこにあるか

給与への分割を取り除き、最も単純な問いを比較する——個人事業主対、すべてを
保留する会社。

| 報酬支払い前利益 | 個人事業主の税額 | Sdn Bhdの税額（全額保留） | 勝者 |
| --- | --- | --- | --- |
| RM100,000 | RM7,690 | RM15,000 | 個人事業主 |
| RM200,000 | RM32,150 | RM31,000 | ほぼ互角 |
| RM300,000 | RM57,150 | RM48,000 | Sdn BhdがRM9,150差で勝る |
| RM500,000 | RM108,060 | RM82,000 | Sdn BhdがRM26,060差で勝る |

RM100,000で会社が負ける理由は、個人の累進表が最初のRM5,000を無税とし、
RM100,000までは1%から19%しか課さないのに対し、会社は最初のリンギットから
一律15%を課されるからである。個人の低い税率階層と個人減免は、利益が多くの
人が想定する水準のおよそ倍になるまで、優遇された法人税率を上回り続ける。

二つの調整がこの線を動かす：

- **利益を給与と保留利益に分けることは、両方の列より有利になる**——
  RM300,000の例が示すとおり、給与が個人の低い税率階層を使い切り、残りは
  15%にとどまる。
- **コンプライアンス費用がこの線を押し上げる。** Sdn Bhdは会社秘書役の費
  用、会計費用、SSMの年次報告書、そして監査免除の要件を満たさない限り法
  定監査を負担する。それらは実際にかかるリンギットであり、会社設立が割
  に合うためには、節税額がそれを上回っていなければならない。

## お金を取り出すことは、第二の、課税される段階である

Sdn Bhdに15%で保留された利益は、まだ事業主の懐には入っていない。単一階層
制度のもとでは、居住会社からの配当は株主の手元で非課税となる——しかし
**YA2025**以降、年間**RM100,000**を超える配当所得を受け取る個人株主は、
Part XXII of Schedule 1のもとで超過分に**2%**を課され、課税対象額は2025年
5月7日にP.U. (A) 148/2025として官報告示されたIncome Tax Rulesにより定ま
る。LHDNのForm BE説明注記は次の実例を示している：RM2,500,000の配当は、
RM100,000の控除後、RM2,400,000の配当法定所得となる。

2%は、この利益水準で比較の結論を逆転させはしないが、現金が最終的に事業主
に届かなければならない以上、会社の表向きの有利さがすべてではないことを意
味する。

## 答えをひっくり返す持株条件

普通株式の**50%**超が、実払込普通資本がRM250万を超える**関連会社**——い
ずれの方向であれ、又は共通の親会社を通じて——により直接若しくは間接に保
有されている場合、Paragraph 2Bは15%と17%の税率を完全に撤廃する。Paragraph
2Cがその関連会社を定義している。

**YA2024**以降、第四の要件が加わった。Paragraph 2B(d)は、基期開始時点で
普通株の実払込資本の**20%**を超える部分が、マレーシア国外で設立された一
社若しくは複数社、又は非マレーシア市民である一名若しくは複数名の個人によ
り、直接又は間接に保有されている場合、その会社を対象から除外する。

Public Ruling No. 8/2025は、この規定がどれほど厳しく効くかを示している。
Example 15では、あるマレーシア企業が、二名のマレーシア市民を株主とする
シンガポール企業に全株保有されている。直近の保有者がマレーシア国外で設立
されているため、その企業は20%基準を**満たさない**。Example 14は、あるド
イツ人個人が直接保有する30%と、別のマレーシア企業を通じて間接に保有する
28%を合算し、58%に達して失格となる例を扱っている。

あなたの会社がいずれかに該当する場合、税率は最初のリンギットから一律24%
となり、個人事業は利益曲線上のはるかに高い位置で再び競争力を取り戻す。そ
して同じ条件が、s.107C(4A)のCP204免除と、上限のない少額資産減免をも失わ
せる。

## LLPについてはどうか

LLPはparagraph 2Dのもとで、実払込資本ではなく資本出資を基準として、会社
と同様の三段階税率を得ており、組合員の利益持分は再課税されない。LLPが得
られ**ない**のは、2年間のCP204免除である：Public Ruling No. 8/2025の
paragraph 6.6.3は、s.107C(4A)が会社のみを対象とし、新たに登録されたLLP
にも、LLPへ転換した会社にも及ばないことを確認している——たとえその事業
が継続しているとみなされる場合であっても、である。

## よくある誤り

- **15%と30%を比べること。** SME水準の利益で関係する個人税率は19%から
  25%であり、最高税率帯ではない。課税所得の最初のRM100,000はそれよりは
  るかに軽く課される。
- **事業主にはいずれにせよ支払いが必要であることを忘れること。** 会社の
  15%は保留利益に適用される。報酬はどのみち個人の側で課税される；最適
  化されるのは分割の仕方だけである。
- **雇主EPFを純粋なコストとして扱うこと。** それは会社にとって控除可能
  であり、取締役自身の口座に入るものでもあるため、帳簿の両側に計上され
  るべきものである。
- **マレーシアで登録された会社は自動的にSME税率になると思い込むこと。**
  居住者性、実払込資本、総事業収入、50%の関連会社基準、及び20%の外資持
  株基準のすべてが満たされていなければならない。
- **コンプライアンス費用を無視すること。** 利益がおよそRM200,000を下回
  ると、節税額はわずか又はマイナスになるが、秘書役、会計及び監査の費用
  はそうはならない。
- **パートナーシップがLLPと同じように振る舞うと思い込むこと。** 一方は
  透明体であり組合員の側で課税されるが、他方は実体であり会社の段階税率
  で課税される。

## 次のステップ

何かをモデル化する前に、自分の会社が実際にどの税率に該当するのかを確認す
ること。優遇税率には五つの別個の条件が付いているためである。次に、見積り
及び分割納付の仕組みを確認すること。2年間のCP204免除の要件を満たす新規設
立会社は、満たさない会社に比べて最初の2年間が大きく楽になるからである。
