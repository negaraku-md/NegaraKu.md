マレーシアで自動車を購入すると、車両本体の価格にほぼ匹敵する税金を支払うことになるかもしれない。その主な原因は、あまり議論されることのない、しかし極めて強力な税——**物品税**である。

物品税は、贅沢品、不健康、又は公共医療制度に負担を及ぼしうるとみなされる特定の物品に課される国内税である。売上税のような一般的な税とは異なり——対象となるのはごく少数の区分のみである：自動車、酒類、たばこ及び電子たばこ（ベイプ）、加糖飲料、プレミックス調製品、並びにトランプ及び麻雀牌。

## 物品税とは何か、誰が徴収するのか？

物品税は**1976年物品税法（Excise Act 1976、Act 176）**により規定され、**マレーシア王立関税局（RMCD）**によって執行される。国境で課される輸入税とは異なり、物品税は国内で製造された物品と輸入された物品の両方に課される。

一般に、物品税は物品が製造された時点で課税対象となる性質を帯び、物品が免許を受けた製造業者の敷地から搬出された時点——又は海外からの物品については輸入の時点——で納付すべきものとなる。このため、ビール醸造所や車両組立業者など物品税課税品目の製造業者は、物品税ライセンスを保持し、税額が清算されるまで自社の物品を関税管理下に置かなければならない。

税率は次の二つの形態で計算される：

- **従価税**——物品の価値に対する百分率（例えば小型車で75%）。
- **従量税**——単位ごとの固定額（例えば加糖飲料は1リットルあたり90仙、プレミックス調製品は100グラムあたり47仙）。

烈酒など一部の物品は**複合税率**——固定額と百分率を組み合わせたもの——を用いる。

## 自動車の物品税はいくらか？

自動車はマレーシアにおける物品税の最大の源泉であり、当地の自動車価格が高い主な理由である。乗用車（サルーン）については、物品税はエンジン容量に応じて従価方式で計算される：

| エンジン容量 | 物品税率（乗用車） |
|---|---|
| 1,800cc未満 | 75% |
| 1,800～1,999cc | 80% |
| 2,000～2,499cc | 90% |
| 2,500cc以上 | 105% |

上記の税率表は、国内組立車両（CKD、*completely knocked-down*）について記録されたものである。完成車として輸入される車両（CBU、*completely built-up*）も同じ物品税率を負担する——違いは、CBU車両にはさらにその上に輸入税が課される点である。いずれの税率も完税価値（duty-paid value）を基準に計算される。

自動車を高くしているのは、三層の税が**積み重なる効果**である。ASEAN域外から輸入されるCBU車両の場合、その順序は次のとおりである：

1. **輸入税**が先に課される——ASEAN域外からのCBU車両には30%（ASEAN加盟国からの車両はASEAN協定のもとで0%の優遇を受ける）。この税率は自由貿易協定によって異なり、例えば中国からの一部の電動車両はACFTAのもとで5%という低い輸入税率を享受する。
2. **物品税**は*完税価値（duty-paid value）*（すなわち基本価格に輸入税を加えた額）を基準に計算される。
3. **10%の売上税**が最後に課され、すでに物品税を含んだ金額の上に課される。

各層が前の層によってすでに膨らまされた金額の上に計算されるため、輸入車の価格は元の価格の2倍を超えることもある。これに対し、国内で組み立てられるCKD車両は通常、その部品について輸入税を免除されるため、物品税と売上税のみを負担する——これが国内製の自動車がより安価である理由である。

## 酒類とたばこの物品税はいくらか？

酒類とたばこは典型的な物品税課税品目である——価格を引き上げると同時に、公共医療費を賄う一助となる「罪悪税」（sin tax）である。以下は参考としての税率の一部である（特定の酒類及びたばこの絶対額はRMCDに確認する必要がある）：

| 物品 | 物品税率 |
|---|---|
| ビール／スタウト | 1リットルあたりRM175.00（アルコール度数100%）＋15%従価（複合） |
| ワイン | 1リットルあたりRM450 |
| 烈酒／蒸留酒 | 1リットルあたりRM1.10＋15%（複合） |
| ウォッカ | 1リットルあたりRM150（アルコール度数100%） |
| 清酒 | 1リットルあたりRM60（アルコール度数100%） |
| たばこ | 1本あたりRM0.42（2025年11月1日発効） |
| 葉巻／シガー／シガリロ | 1キログラムあたりRM440 |
| 加熱式たばこ製品 | 1キログラムあたりRM798 |
| 噛みたばこ | 5%＋1キログラムあたりRM27 |

2026年予算を通じて、複数の税率が2025年11月1日付で引き上げられた：たばこは1本あたり2仙上昇し（RM0.40からRM0.42へ）、酒類の物品税は一律10%引き上げられ、加熱式たばこ製品は1キログラムあたりRM20上昇し、葉巻は1キログラムあたりRM40上昇した。一方、噛みたばこは2024年予算を通じて新たな物品税区分として導入された。

## 加糖飲料税はどうか？

加糖飲料（SSB、*sugar-sweetened beverages*）に対する物品税は、マレーシアで最も新しい物品税の一つであり、保健省の「対糖戦争（Perang Terhadap Gula）」の取り組みの一環として2019年7月1日に導入された。その閾値は単一の統一基準ではなく、品目区分によって異なる：HS 2202項下の即飲飲料は100mlあたり5グラムを超える糖分を含む場合に課税され、乳製品ベースの飲料（同じくHS 2202）は100mlあたり7グラムを超える糖分を含む場合に課税され、HS 2009項下の果汁又は野菜ジュースは100mlあたり12グラムを超える糖分を含む場合に課税される。

税率は連続して二度引き上げられた：

| 発効日 | 税率 |
|---|---|
| 2019年7月1日 | 1リットルあたり40仙 |
| 2024年1月1日 | 1リットルあたり50仙 |
| 2025年1月1日 | 1リットルあたり90仙 |

1リットルあたり90仙への引き上げ——50仙からの80%の急騰——は2025年予算で発表された。その効果は相当なものであった：政府は2025年1月から11月の間だけで、SSB物品税から**RM7,381万**を徴収し、この税が2019年に開始して以来の総徴収額は**RM5億2,135万**に達した。2025年の徴収額のうち、RM2,500万が保健省に配分され、啓発プログラム、糖尿病患者向けのSGLT-2薬剤、及び末期腎疾患患者向けの腹膜透析設備に充てられた。

加糖飲料に加えて、3-in-1インスタントコーヒーや紅茶などのプレミックス調製品（premix）にも、2024年物品税（改正）令のもとで2024年3月1日付で100グラムあたり47仙の物品税が課されている。

## その他の物品税課税品目

物品税課税品目の一覧は、想像以上に長い。自動車、酒類、たばこ及び加糖飲料のほか、次の区分もその対象となる：

- **その他の車両**——オートバイ、モペット（20%）、及び全地形車（ATV、65%）。
- **発泡ワイン（sparkling wine）**——1リットルあたりRM450（アルコール度数100%）。
- **トランプ**——10%従価。
- **麻雀牌**——10%従価。

トランプや麻雀牌といった賭博関連の物品は、歴史的及び社会的理由から物品税の対象に残っているが、その徴収額は自動車やたばこに比べて小さい。

## 次のステップ

物品税は、自動車、酒類、たばこ、甘い飲料のために支払う価格の大きな部分を占めており——その税率は、10月に行われる年次予算案の提示の際にしばしば改定される。輸入車のような高額な物品を購入する前には、数字が年ごとに変わりうるため、RMCDの公式サイトで現行の税率を確認すること。

マレーシアの税制を包括的に理解するには、**売上・サービス税（SST）**及び**輸入税**に関する当サイトの記事もあわせて読まれたい。これら三つの税は、同一の物品に対してしばしば積み重なるためである。製造業者及び輸入業者は、物品税のライセンス及びコンプライアンス要件について**マレーシア王立関税局**を参照されたい。
