再投資控除（RA）が失敗するのは、最初から申請を拒否される場合よりも、監査の段階でつまずく場合の方がはるかに多く、しかもその理由がお金を使わなかったからであることはほとんどない。失敗するのは、会社が間違ったプロジェクトのために正しい資産を買ったからである。完成した箱をカートンに詰める機械は、実在する機械であり、実在する工場に実際に設置されている——それでも適格とはならない。鉛筆が箱に入った時点で、製造はすでに完了していたからである。

それがPublic Ruling No. 10/2022の例6であり、大半のRAをめぐる紛争の縮図である。

## この控除の内容

1967年所得税法（Income Tax Act 1967、Act 53）のSchedule 7A（所得税法第7A附則）のpara 1のもとで、マレーシアに居住する法人であって：

- **36か月を下回らない期間、営業していること**；かつ
- ある賦課年度の基期内に、適格プロジェクトのためマレーシア国内で使用される**工場、プラント又は機械に係る資本的支出**を発生させたこと、

の両方を満たす場合、その法人には当該支出の**60%**に相当する再投資控除が与えられる。para 1Aは、農業プロジェクトに係る資本的支出についても同じ60%を与える。

para 1の但書は、取締役、又は経営、管理若しくは事務職員の使用のために全部若しくは一部提供されるプラント又は機械を除外する。36か月の測試は、その支出が発生した時点までを対象とする——PR 10/2022の例3は、32か月の会社について申請を拒否している。

## どれだけの所得を遮蔽するか

para 3は、当該控除に相当する法定所得を免税とするが、**その事業からの法定所得の70%を超えない範囲**に限る。当該適格プロジェクトが大臣（Minister）の定める生産性の水準を達成した場合、この制限は解除され、免税は法定所得の全額を吸収し得る。

para 4Aは見落としやすい：para 3及び4における法定所得とは、**当該適格プロジェクトに係る事業から構成される源泉の**法定所得を意味し、会社全体の法定所得ではない。

未吸収の控除は、para 4のもとで、当該事業から法定所得が生じる最初の後続年度へと繰り越される。免税された所得は、para 5のもとで免税口座に記入され、免税配当として支払うことができ、para 5(6)のもとでは、法人株主自身の株主の手において第二段階の免税がある。

## その期間

para 2は、**連続十五個の賦課年度**の基期内に発生した資本的支出について、この控除を与える。その起算点は、**申告書において最初に申請が行われた基期が属する賦課年度**である。

これは注意深く読む必要がある。この時計は、あなた自身の最初の申請から動き出すのであって、設立の時点からでも、最初の適格支出の時点からでも、全国一律に定められた日付からでもない。同じ業界の二つの競合会社が、それぞれ異なる年に自らの期間の中にいることもあり得る。

その上に、さらに二つの経過規定が重なる。

- **para 2B**——PENJANA特別再投資控除。十五年の期間がYA2019以前に終了した会社は、YA2020からYA2024までに発生した資本的支出について、さらなる権利を得た。期間がYA2020、2021、2022又は2023に終了した会社は、それに応じて短い期間を得たが、いずれも**YA2024**で終了する。この延長措置は、今ではすでに使い果たされている。
- **para 4C**——para 2Bのもとでの十五年間の期間の後、YA2024までに発生した支出に係る控除は、**YA2024の直後から始まる連続七個の賦課年度**にわたってのみ吸収できる。その終了時点で未吸収のものは、一切考慮されない。

para 4Bは、通常の十五年の期間終了時に残った残高についても、同じ七年吸収制限を適用する。

## 適格プロジェクトとは何か

para 8がこれを網羅的に定義している：

| 号 | プロジェクト |
| --- | --- |
| 8(a) | 同一の産業内における製品又は関連製品の製造に関して、既存の事業を拡張、近代化若しくは自動化すること、又は同一の産業内の関連製品へと多角化すること |
| 8(c) | 耕作及び農業を拡張、近代化又は多角化する農業プロジェクト。**ただし養鶏及び養鴨を除く** |

para 9は続けてこれらの動詞を定義しており、その定義は通常の用法よりも狭い：

- **拡張**——製品の生産能力の増加、又は工場面積の拡張；
- **近代化**——製造設備及び工程のアップグレード；
- **自動化**——人手による操作を機械的な操作に置き換え、人の関与を最小限に抑える又は削減すること；
- **多角化**——同一の産業に関連する製品の範囲を拡大又は多様化すること。

**製造**も定義されており、建設のための機械設備の設置、単純な梱包、単純な固定、単純な混合、部品の単純な組立て、輸送及び保管中の保存、出荷を容易にする活動、並びに販売のための商品の梱包又は陳列を除外する。**単純**とは、特別な技能、機械、器具又は設備を必要としない活動を意味する。

**プラント**及び**機械**はいずれも、**工場内**における製造活動に関して使用され、かつその遂行に直接使用される器具又は装置と定義される。そして**工場**とは、当該適格プロジェクトのために使用される床面積の部分を意味し——貯蔵スペースは、当該建物又は増築部分の総床面積の**十分の一を超えない**場合に限り、これに算入される。

## 申請が監査で失敗する理由

**その活動が製造に当たらない。** PR 10/2022の例5は、顧客の仕様に従って切断及び溶接を行う会社への申請を拒否している：その活動はSchedule 7Aの定義に該当しないため、新しい作業場の建物は何も得られない。

**資産が製造の終了地点より後にある。** 例6は、鉛筆を小売用の箱に入れる機械については認め、その箱をカートンに詰める機械については拒否している。

**それは再投資ではなく更新である。** paragraph 8.3.2及び例26は、拡張、近代化、自動化又は多角化を証明できない限り、摩耗した工具又は機械部品の更新について控除を拒否している。

**貯蔵スペースが十分の一の基準を超える。** 当該裁定の図3では、75,000平方フィートのうち5,000平方フィートの貯蔵スペースが適格となる。図4では、同じ75,000平方フィートのうち8,000平方フィートは適格とならない——しかも超過分だけでなく、貯蔵区画全体が対象から外れる。販売事務所のスペースは、いずれの場合も適格とならない。

**再利用されない廃棄物処理。** 例7は、廃棄のために有毒な排水を処理する設備について拒否している；例8は、処理された水が同一製品の生産に再利用される場合にこれを認めている。

**グループ内の資産の移し替え。** para 1Bは、取得者と処分者が**共通の支配下**にある場合、又は当該取得が**組織再編若しくは合併**に起因する場合、Schedule全体を適用除外とする。

**五年以内の処分。** para 2Aは、当該控除が一度も与えられなかったものとみなし、処分の年度の法定所得にこれを加算して戻す。*処分*には使用の停止も含まれ、para 9は、Schedule 3のpara 61Aのもとで売却目的保有に分類された資産も引き込む——そのため、減損による再分類が、売却を伴わずに控除の取り戻しを引き起こすことがある。

**両立しない優遇措置。** para 7は、当該基期において、パイオニア・ステータスを保有し若しくは申請中である会社、又は奨励対象活動若しくは製品について投資税額控除を付与されている会社を除外する。

**RA claim form（RA申請書）がない。** PR 10/2022のparagraph 13は明確である：LHDNからの書面による承認は不要だが、その申請は**RA claim form**に記録されなければならず、正本は裏付け資料とともに保存されなければならない。会社はしばしば申告書上で申請を行うだけで、その用紙を記入し終えることがなく——そして調査対象に選ばれたときに、提出できるものが何もないことになる。

para 6は、内国歳入庁長官（Director General）が、当該免税が与えられた賦課年度の満了後**五年以内**に評税を行い、不当に得られた利益を打ち消すことを認めている。

## よくある誤り

**十五年を誤った起点から数えること。** para 2のもとで、それは申告書における最初の申請から起算される。

**PENJANA延長措置が今も利用できると思い込むこと。** para 2BはYA2024で閉鎖されており、para 4Cは、すでに得られたものをYA2025から七年間で*吸収する*権利を保つに過ぎない。

**法定所得の総額に対して申請すること。** para 4Aは、それを当該適格プロジェクトの事業源泉に限定する。

**取締役又は経営陣の資産を含めること。** para 1の但書は、彼らの使用のために全部若しくは一部提供されるプラント又は機械を除外する。

**一般的な工場の増築を適格な床面積として扱うこと。** 当該適格プロジェクトのために使用される部分のみが算入され、貯蔵スペースは十分の一までしか算入されない。

## 次のステップ

次の資本予算が承認される前に、各項目がpara 8のどの号に該当するか、そして工場内のどこに設置されるかを書き留めておくこと。**RA claim form**とともに保管されるその一枚の文書こそが、五年後に、弁護可能な申請を生き残れる申請へと変える。
