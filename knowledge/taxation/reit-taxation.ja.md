マレーシアのREITのユニットを買うと、あなたは実質的に、建物の税金の請求書を一度も目にすることのない大家となる——なぜなら、その建物を保有する信託が、税務当局が手を付けるより先に、ほぼすべてをあなたに引き渡してしまうからだ。1967年所得税法のs.61Aに書き込まれたこの一つの設計上の選択こそが、REIT及びPTFを機能させている仕組みである。しかし2026賦課年度（YA 2026）には、この取引のもう半分——*あなた*、すなわち受益者がどのように課税されるか——が、ここ数年で初めて変わった。

## なぜREIT自体は課税されないのか？

Bursa Malaysiaに上場するREIT又はPTFは、パススルー（導管）事業体である。1967年所得税法のs.61Aのもとで、**基準期間内に総収入の90%以上を受益者に分配する場合**、当該賦課年度についてその総収入への所得税が免除される。

その論理は単純である。ファンドと投資家の双方の段階で課税するのではなく、最終的にその資金を手にする者の手元で一度だけ課税する。90%の基準を満たせば、ファンドは一切納税しない。収入は受益者へと流れ出し、代わりにそこで課税される。

この基準を満たせなければ、状況は逆転する。あるREITがある年に総収入の**90%未満**しか分配しなかった場合、その年はs.61Aの免税は適用されない——ファンドは通常の信託機関と同様にその収入に課税され、その後支払われる分配には、受益者が自らの税務上の負担と相殺できる税額控除が付随する。実務上、上場REITはまさにこの90%の基準の正しい側にとどまるために、100%又はそれに近い水準まで分配している。

## 90%ルールは私の分配に対する税額控除にどう影響するか？

ここは投資家が最も誤解しやすい部分である。ファンドがs.61Aのもとで免税となる場合、その収入は一度も課税されていない——したがって控除できるものが何もない。その免税収入から支払われる分配には、通常、**s.110の税額控除は付随しない**。

これが重要なのは、受益者に対する源泉徴収又は申告の仕組みが、その収入に課税する作業の*全体*を担っていることを意味するからである。相殺すべき、それより前の段階の課税は存在しない。（ファンドが課税されていた場合——90%未満のケース——には税額控除が生じ、源泉徴収を受けた非課税の受益者は還付を請求できる。）

## YA 2026以前、受益者はどのように課税されていたか？

REIT／PTFの免税収入から支払われる分配については、ファンドが分配の時点で1967年所得税法のs.109Dのもとで源泉徴収を行っていた。YA 2020からYA 2025まで、税率は次のとおりであった。

| 受益者の区分 | 源泉徴収税（YA 2025まで） | 性質 |
| --- | --- | --- |
| 居住者個人／非法人 | 10% | 最終税 |
| 非居住者個人 | 10% | 最終税 |
| 外国機関投資家（例：退職年金基金、集団投資スキーム） | 10% | 最終税 |
| 居住法人 | 0%（法人税率で課税） | 申告書で報告 |
| 非居住法人 | 24% | 最終税 |

この10%という税率こそが、最大の訴求点であった。個人や外国のファンドにとって、分配に対する税は「源泉徴収で完結（final and forget）」であった。すなわち、源泉で10%が徴収されれば申告の必要は一切なく、支払額がどれほど大きくてもそれ以上の税負担は生じなかった。

## YA 2026で何が変わったのか？

この優遇された10%の税率は落日条項——法律で定められた失効日——のもとに置かれており、更新されないまま2025年12月31日に失効した。LHDNは2026年3月、YA 2026以降に適用される取扱いを明示するため、Practice Note No. 2/2026を発出した。

中核となる変化はこうだ。個人及び外国機関投資家に対する10%の*最終*源泉徴収税は廃止された。源泉での一律かつ最終的な控除に代わって、大半の受益者は今や分配を自らの確定申告に組み入れ、現行税率で課税される。

| 受益者の区分 | YA 2026以降 |
| --- | --- |
| 居住者個人 | 最終源泉徴収税なし；分配を申告し、累進税率（0%～30%）で納税 |
| 居住法人／実体 | 最終源泉徴収税なし；申告し、適用される税率で納税 |
| 非居住者個人 | 非居住者個人の標準税率である30%で課税 |
| 外国機関投資家 | 従来の10%の最終税率は利用不可；現行税率で課税 |
| 非居住法人 | **変更なし**——24%の最終源泉徴収税 |

申告の観点からは、居住者個人は今や、源泉で完結したものとして扱うのではなく、大まかに言えば「その他の利得又は利益」からの法定所得として、その分配を申告する。

## 新しい規則のもとで、誰が得をし、誰が損をするのか？

それは完全にあなたの限界税率次第である。

- **小口の居住者個人投資家**は*得をする*可能性がある。個人所得が低い税率区分——旧来の10%を下回る水準——にある人は、今や一律10%ではなく、分配に対して自分自身の（より低い）税率を実質的に負担することになる。
- **高所得の居住者**は*より多く*支払うことになる。累進税率が旧来の10%の最終税ではなく、最高30%まで及ぶためである。
- **非居住者個人及び外国機関投資家**は最も明確な敗者である。一律10%が最大30%もの税率に置き換わり、マレーシアのREITを海外資金にとって魅力的なものにしていた税引後利回りを削っている。
- **非居住法人**はまったく変化がない——依然として24%、依然として最終税である。

この優遇措置を終了させる理由として挙げられているのは、マレーシアのREITセクターが、資本を呼び込むために優遇税制による支援をもはや必要としない、広く受け入れられた資産クラスへと成熟したということであり、この変更はまた、REIT分配を標準的な所得税ルールに合わせることで課税ベースを広げるものでもある。セルサイドのリサーチは概ね、この変更がファンダメンタルズよりもセンチメントを傷つけるという見方で一致していた。Maybank Investment Bankは、純分配利回りは依然としておおむね4.7%から6%の平均水準を維持し、他のセクターに対して競争力を保つと見積もっており、BIMB SecuritiesやRHB Researchを含む他の証券会社も、このセクターに対して前向きな評価を維持した。

## 次のステップ

マレーシアのREITを保有している場合、実務上のやるべきことは短いが、現実的なものである。

- **分配証票（distribution voucher）を保管しておくこと。** YA 2026からは、単に保管しておくだけでなく、確定申告でREIT／PTFの所得を申告するためにこれが必要になる。
- **旧来の10%ではなく、自分自身の限界税率を試算すること。** この変更が有利に働くか不利に働くかは、あなたがどの税率区分に属するかによって決まる。
- **外国及び非居住者の投資家**は、マレーシアのREITを域内の同業と比較する前に、税引後利回りの前提及び適用され得る租税条約（DTA）上の救済措置を再確認すべきである。

拘束力のある詳細については、LHDN Practice Note No. 2/2026を1967年所得税法のs.61A及びs.109Dとあわせて参照し、当年度の取扱いについては免許を有する税務代理人に確認すること——数字及び閾値は各Budgetにより変動しうる。
