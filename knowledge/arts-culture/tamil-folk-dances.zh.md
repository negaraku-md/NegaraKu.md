在庙会那一天，当塔维尔鼓的擂动与纳达斯瓦兰的乐声充满街道时，一个人头顶着以鲜花
装饰的铜壶（karagam），一边起舞一边走来，却丝毫不让它倾斜。一旁，列队而立、挥动
彩色手帕的青年，扮成孔雀的小女孩，腰系假马、踩着高跷敲出马蹄声的人——这一切都是
马来西亚淡米尔人**民间舞蹈**传统的景象。

这些舞蹈诞生于淡米尔纳德邦乡村的庙宇、丰收与祭祀传统；由南来的淡米尔人带入马来
西亚，至今仍在节庆与文化活动中生气勃勃地延续着。本文以中立的方式介绍那些形式——
它既不是巴拉塔那亚姆、卡那提克音乐那样的舞台**古典艺术**（另有专文介绍），也不是
纳达斯瓦兰那样的**庙宇乐器**传统。这里所谈的，是诞生于民间、广为人们所舞的**大众
艺术**。

## 主要的民间舞蹈形式

马来西亚淡米尔人传承的舞蹈形式众多；其中广为人知的有：

| 舞蹈 | 简要说明 |
| --- | --- |
| **卡拉甘顶壶舞**（Karagattam） | 一种平衡舞，头顶装饰华丽的卡拉甘（karagam，铜壶）而不使之倾斜；与玛丽安曼（Mariamman）祭祀相关 |
| **手帕舞**（Oyilattam） | 一种优雅的群舞，舞者列队而立、挥动彩色手帕起舞（oyil = 美） |
| **卡瓦迪舞**（Kavadi Aattam） | 以大宝森节所扛的卡瓦迪（kavadi）为基础的穆鲁干（Murugan）祭祀舞 |
| **孔雀舞**（Mayilattam） | 扮成孔雀起舞、敬献穆鲁干神的舞蹈 |
| **假腿马舞**（Poikkal Kuthirai） | 踩高跷敲出马蹄声、腰系假马形道具起舞 |
| **库米 / 棍舞**（Kummi / Kolattam） | 以拍手（库米）或互击小棍（棍舞）合着节拍起舞的群舞 |
| **街头剧**（Therukkoothu） | 在街头演出的民间戏剧-舞蹈形式 |

此外，还有配合**乌杜凯（udukkai）与帕莱（parai）**等皮革乐器擂动的鼓乐舞形式，以及
**踩高跷舞**（thattukkaal aattam，踩在高跷上起舞）等。卡拉甘顶壶舞常配合**纳达斯瓦兰
与塔维尔**的乐声演出；手帕舞则依靠塔维尔鼓乐与民谣。

## 根源：乡村与庙宇

这些舞蹈根植于淡米尔纳德邦的**乡村文化**。卡拉甘顶壶舞、卡瓦迪舞、孔雀舞等诞生于
庙会、阿曼女神祭祀与丰收庆典的情境之中。卡拉甘顶壶舞尤其与**玛丽安曼**（司雨/力量
之女神）的祭祀相连——它被奉为一种为好雨与丰饶而谢恩的形式。由于玛丽安曼祭祀在
马来西亚的园坵社群中根植甚深，这些舞蹈传统也透过那些社群在此延续。
[玛丽安曼祭祀](/zh/arts-culture/mariamman-worship)对玛丽安曼祭祀传统有详细说明。

把这些艺术带来的，大多是英殖时期为园坵工作而南来的南印度淡米尔人；
[园坵淡米尔社群](/zh/arts-culture/estate-tamil-community)对他们的社会历史有更多阐述。

## 它们如何在马来西亚得以传承

这些舞蹈在马来西亚以多种方式得以保存：

- **庙会：** 在大宝森节、吉提来月圆节（Chithirai Pournami）等节庆期间，会演出
  卡拉甘顶壶舞、卡瓦迪舞等。参见：[大宝森节](/zh/arts-culture/thaipusam)。
- **文化节庆：** 在霹雳等州属随淡米尔新年举办的**淡米尔同胞节**（Tamilar Thirunal）
  等盛会上，这些平日难得登台的舞蹈会被集中呈献于舞台之上。关于淡米尔新年，参见
  [淡米尔新年](/zh/arts-culture/tamil-new-year)。
- **淡米尔学校表演：** 在淡米尔文源流学校的年度活动以及**校际比赛**中，孩子们学习
  并演出这些舞蹈。参见：[淡米尔文小学](/zh/education/tamil-vernacular-schools)。
- **节日活动：** 文化团体也在屠妖节活动、开放门户（rumah terbuka）庆典以及社团联谊
  会上演出。参见：[屠妖节](/zh/arts-culture/deepavali)。
- **团体与交流：** 本地文化团体教授这些舞蹈；来自淡米尔纳德邦的艺人团体的巡回演出
  也强化着这一传统。

## 与古典艺术、庙宇音乐的区别

不应把民间舞蹈与马来西亚其他淡米尔艺术传统混为一谈：

- **并非古典艺术：** 巴拉塔那亚姆、卡那提克音乐等是有既定教授规范、以舞台形式呈现的
  **古典艺术**；这些另有[印度古典艺术](/zh/arts-culture/indian-classical-arts-in-malaysia)
  一文专门介绍。而民间舞蹈则是诞生于乡村的大众艺术。
- **并非庙宇乐器传统：** 纳达斯瓦兰、塔维尔等庙宇乐器的传统在
  [庙宇音乐——纳达斯瓦兰](/zh/arts-culture/temple-music-nadaswaram)一文中说明。这些
  乐器为这些舞蹈提供**背景音乐**；但舞蹈与乐器传统是彼此独立的艺术形式。
- **并非武术：** 西兰邦（silambam）等淡米尔武术则是另一回事；参见：
  [西兰邦](/zh/arts-culture/silambam)。
