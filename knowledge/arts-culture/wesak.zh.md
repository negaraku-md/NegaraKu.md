问卫塞节落在哪一天，答案并不固定——它会变动。2026年落在5月31日，2027年落在5月20日，2028年落在5月9日。原因很简单：卫塞节是依月相而定，不是依固定的日历日期，而阴历与西历每年都会彼此产生偏移。

这一个特点——一项月圆纪念活动，被安放进马来西亚固定的公共假期日历中——正是理解这一天最值得把握的关键。

## 概览

| | |
| --- | --- |
| 纪念的内容 | 按照佛教传统，纪念佛陀的诞生、成道与涅槃（parinirvana），三者一同于同一天举行 |
| 别称拼法 | Vesak；亦称卫塞节（Buddha Purnima）或佛诞日 |
| 时间 | 阴历卫塞月（Vesakha）的月圆之日——一般为4月或5月；西历日期每年变动 |
| 假期地位 | 所有州属与联邦直辖区的全国公共假期 |
| 首次宣布为公共假期 | 1962年 |
| 2026年日期（官方） | 2026年5月31日（星期日）；替代假期为2026年6月2日（星期二） |
| 庆祝者 | 马来西亚佛教社群，涵盖上座部（Theravada）、大乘（Mahayana）与金刚乘（Vajrayana）传统 |

## 这一天纪念的内容

在佛教传统中，卫塞节将悉达多·乔达摩（Siddhartha Gautama，即佛陀）一生中三个各自独立的事件汇聚在一起——他的诞生、他证得成道，以及他的逝世，即涅槃（parinirvana）。据信这些事件发生在卫塞月（Vesakha）同一个月圆之日，只是年份不同，这正是为何一项纪念活动会同时承载这三者的原因。

由于它与阴历某月的月圆相绑定，其日期相对于西历并不固定。它大致落在4月或5月，并且逐年变动——这与其他阴历纪念活动的日期变动机制相同。

## 卫塞节落在哪一天，以及2026年的日期

马来西亚的公共假期日期由政府每年确认。就2026年而言，国家安全理事会（Majlis Keselamatan Negara）与大马半岛劳工局（Department of Labour Peninsular Malaysia）声明，卫塞节（Hari Wesak）落在**2026年5月31日（星期日）**。

| 年份 | 卫塞节 |
| --- | --- |
| 2026年 | 5月31日（星期日） |
| 2027年 | 5月20日（星期四） |
| 2028年 | 5月9日（星期二） |

由于2026年5月31日是星期日——大多数打工者的每周休息日——因此适用替代假期。官方声明将该替代日定为**2026年6月2日（星期二）**。其间的星期一，即2026年6月1日，本身已经是最高元首（Yang di-Pertuan Agong）官方诞辰的经宪报颁布假期，这正是卫塞节的替代假期顺延至下一个工作日的原因。根据《1955年雇佣法令》，凡经宪报颁布的公共假期落在休息日者，即享有替代有薪假期的权利。

## 自1962年起的全国公共假期

卫塞节在马来西亚所有州属与联邦直辖区均作为公共假期庆祝——它是全国性假期之一，而非仅限于某个州属。

根据马来西亚僧王（Chief High Priest）拿督沙里·法宝法师（Datuk K. Sri Dhammaratana）所述，佛教社群曾于1961年向政府请愿要求承认卫塞节，该节日遂于1962年被宣布为公共假期。同一份记述将马来亚正式的卫塞节庆祝活动，追溯到吉隆坡增江（Brickfields）的佛教大寺（Buddhist Maha Vihara）——该寺创立于1894年，翌年即举行了首次卫塞节庆典。

## 卫塞节的常见庆祝方式

马来西亚的庆祝活动以寺院为中心。以下这些形式均被广泛奉行；本文在此仅将其作为文化事实加以描述，不做优劣排序，也不诠释其教义意涵。

- **黎明时分参访寺院。** 信众清晨聚集，进行祈祷、诵经与禅修，许多人在当天还会持守额外的戒律。
- **供奉。** 鲜花、蜡烛与香在佛像前供奉——花朵会凋谢、蜡烛会燃尽、香会散尽，在佛教中常被解释为对无常的提醒。
- **浴佛。** 将香水倒在婴儿佛像上，是若干传统中常见的卫塞节仪式。
- **布施与行善（dana）。** 食物供养僧侣，许多寺院也会举办募捐活动、为有需要人士提供餐食，以及血液捐献活动。
- **穿着白色服装。** 许多信众当天穿着白色服装，并持守素食。
- **烛光游行。** 夜间游行队伍会携带灯笼与蜡烛。

最广为人知的公开活动是**吉隆坡卫塞节游行**，队伍从增江的佛教大寺出发。装饰花车——通常载有一尊巨大的发光佛像——历经数小时穿行市区，吸引大批信众与围观民众观看。其他城镇与州属的佛教社群也会举办类似的花车游行与开放门户活动，尤以槟城最为知名。

## 常见误解

- **「卫塞节有固定日期。」** 并非如此。它是依阴历卫塞月（Vesakha）的月圆之日而定，因此西历日期每年都会变动——务必确认当年经宪报颁布的日期。
- **「卫塞节只纪念佛陀诞辰。」** 在马来西亚以及更广泛的上座部传统中，这一天同时纪念三件事——诞生、成道与涅槃——而非仅纪念诞生，尽管「佛诞日」是常见的别称。
- **「2026年的假期是6月1日。」** 卫塞节本身是2026年5月31日；6月1日是最高元首诞辰的另一项独立假期，卫塞节的替代假期则落在6月2日。
- **「卫塞节与其他一些假期一样，只是州级假期。」** 它是每个州属与联邦直辖区都庆祝的全国公共假期。
