这套甘美兰乐器从一座宫廷迁往另一座宫廷，靠的不是买卖，也不是掠夺——而是婚姻。当一位公主迁入夫君的宫邸时，乐器、舞者与乐曲也随她一同迁移。马来宫廷就是这样拥有了甘美兰。

## 甘美兰是如何进入马来宫廷的？

根据JKKN文化测绘记录，joget gamelan于**1811年在彭亨北根（Pekan）**为Tengku Hussain的婚礼上首次公开演出。这门艺术形式便是从这里在彭亨王室之间扎下根来。

随后，它通过两座宫廷之间的姻亲关系跨越到登嘉楼。最常被提及的人物是**Tengku Ampuan Mariam**，一位彭亨公主，她于**1913年**嫁给了登嘉楼的Sultan Sulaiman Badrul Alam Syah。她把一套甘美兰乐器从彭亨带来，培训当地乐手，并整理其舞蹈段落与服饰。JKKN记录提到，原本多达77套曲目（ragam）的剧目如今只剩下仍在演出的**12套ragam**——包括Timang Burung、Lambang Sari、Togok、Topeng与Perang Manggung。

## 马来甘美兰与爪哇甘美兰有何区别？

马来甘美兰与马来群岛的甘美兰传统同根同源。但当它被彭亨与登嘉楼的宫廷吸纳后，其乐器被**重新设计以配合马来的造型与音色**——据Warisan KL门户所述，这一改造使它独树一帜、有别于其他甘美兰。它的重心在于以金属琴键乐器与铜锣组成、伴奏宫廷舞的乐队，而非像爪哇甘美兰那样带有声乐的庞大编制。

马来宫廷乐团通常由七种乐器组成：

| 乐器 | 作用 |
| --- | --- |
| Keromong | 架于木框上的一排小铜锣；负责主旋律 |
| Saron（大与小） | 敲击的金属琴键；负责旋律线 |
| Gambang | 用槌敲击的木琴键 |
| Kanong | 中音的凸脐铜锣；标记节拍 |
| Gong（一对） | 强调乐句与节奏收尾 |
| Gendang | 双面鼓；掌控整体速度 |

这一编制凸显了马来甘美兰作为金属打击乐团的性质——它着重于旋律与节奏的交织，而非歌唱。

## 它为何几乎失传——又是如何被重新发现的？

甘美兰活动于约**1942年**因第二次世界大战而中断，其乐器静静地存放在登嘉楼的Istana Kolam。据Warisan KL所述，它直到**1966年**才被「重新发现」，当时Tan Sri Mubin Sheppard正在追踪几近失传的马来传统，发现了这套存放已久的甘美兰乐器。

这套原装甘美兰乐器随后于**1973年归还彭亨**，如今在北根的彭亨博物馆（Muzium Pahang）展出——回到了它一个多世纪前首次公开演出的那个州。

## 马来甘美兰是官方文化遗产吗？

是的。在2009年的宪报颁布中，国家文物局将**「甘美兰」（Gamelan）**列为国家文化遗产，归入**非物质文化遗产——表演艺术（Kesenian）**类别。此类认定依据的是《2005年国家文化遗产法令》（Akta 645）。
