映画が登場する前には、明かりの灯る舞台と手描きの緞帳、そして同じ一晩の公演の中でマレーの宮廷風の調べから中東のリズムへと切り替わることのできるオーケストラがあった。それがバンサワンである——かつて半島の都市部で最も活気のある娯楽であり、やがて自らの俳優と歌手を新興のマレー映画産業へと送り出すことになった舞台オペラだ。

## バンサワンはどこから来たのか？

バンサワンは農村から生まれたのではなく、港湾都市の交流の中から生まれた。その起源は**Wayang Parsi**（ペルシャ劇場）と呼ばれる、ペルシャ系コミュニティ——ペルシャ系インド人——の劇場であり、この形式は1870年代にペナンで最初に上演された。

歴史記録はより具体的な契機を伝えている。1875年、ボンベイ出身のペルシャ劇団がペナンで公演を行い、大きな反響を呼んだ。そこからバンサワンが形成され始めた。初期の段階では、この Wayang Parsi の公演はヒンディー語で行われ、俳優はインドから招かれていた。

大きな転機は、この形式が地元の担い手たちによって引き継がれ、**マレー語**で上演されるようになったときに訪れた。ペナンの Pushi (Indera) Bangsawan 劇団は最初のバンサワン劇団——少なくとも「bangsawan」という語を最初に用いた劇団——として記録されており、舞台上でのマレー語による台詞の先駆けとなった。

20世紀初頭までに、この形式は新聞で論評されるほど確立されていた。1903年の*Straits Times*紙の記事は、これを "an opera of Indian origin conducted in the Malay language"——「インド起源でマレー語によって行われるオペラ」——と評している。

## なぜ「バンサワン」と呼ばれるのか？

マレー語で *bangsawan* という語は、貴族あるいは王族を意味する。この名称はその内容にふさわしい——多くのバンサワンの物語は国王、王子、王女、宮廷をめぐって展開し、豪華な衣装と壮麗な舞台装置に彩られている。

しかし、それを「マレー」たらしめているのは言語だけではない。バンサワンはさまざまな出典——物語、歌、様式——を吸収し融合させ、コスモポリタンな都市娯楽の一形態となった。JKKN（国家文化芸術局）は、これを伝統的なマレー劇場と近代マレーシア演劇とをつなぐ**過渡期の劇場**と位置づけている。

## 上演はどのようなものだったのか？

屋外や幕の後ろで上演される mak yong や wayang kulit とは異なり、バンサワンは手描きの背景（backdrop）を用いた**西洋式プロセニアム舞台**を使用する。よく使われる背景には、緞帳、街路の場面、庭園、宮殿の大広間、森林の風景などがある。この色彩豊かな手描きの背景は、劇団の財政力を反映するものでもあった——劇団が裕福であるほど、背景も豪華になった。

バンサワンの演技はメロドラマ的で、即興が多く用いられた。台本は通常大まかな筋書きにすぎず、俳優は観客の反応に応じて台詞や場面を調整することができた。戦闘の場面にはシラット（silat）の動きが取り入れられていた。

一回のバンサワン公演は、通常次のような決まった構成に従っていた。

| 部分 | 内容 |
| --- | --- |
| Gurindam（グリンダム） | 演技開始前に、詩の形式で物語のあらすじが語られる |
| 開幕の歌 | 公演の開始を告げる |
| メインの演目 | 芝居、恋愛劇、シラットの立ち回り、そして滑稽な場面 |
| Extra turn（エクストラ・ターン） | 休憩時間の幕間演芸——コメディの寸劇、舞踊、歌唱 |
| 閉幕の歌 | 観客への謝意を示す |

この**extra turn**こそがバンサワンの大きな魅力の一つであった。本筋の物語の枠を超えた歌や踊りを取り入れる幕間の場であり、アメリカ大陸、中東、インドなど外国の歌も含まれていた。

## 音楽：一つのオーケストラ、二つの世界

バンサワンの伴奏は、伝統楽器と西洋楽器を組み合わせた生のオーケストラによって奏でられた。用いられた楽器には**ピアノ、バイオリン、タブラ**などがある。この組み合わせにより、一つの劇団が一回の公演の中で、古典的なマレーの旋律からより現代的、あるいは異国情緒あふれるリズムへと移行することができた——これが当時のバンサワンに「国際的」な印象を与えていた一因である。

## 物語と登場人物

バンサワンのレパートリーは非常に幅広い。観客を引きつけるものであれば、どのような題材からも取り入れていたためである。その物語は通常、*Sejarah Melayu*（マレー年代記）、インドの二大叙事詩である*Mahabharata*（マハーバーラタ）と*Ramayana*（ラーマーヤナ）、アラブの物語（hikayat）、中国の古典、ヨーロッパの物語、さらにはシェイクスピア劇にまで及ぶ題材から翻案されていた。

登場人物には定型的な類型があり、物語ごとに繰り返し現れた。

- **若き英雄** — 主人公の戦士または王子
- **ヒロイン** — 物語の女主人公
- **国王と大臣** — 権力を持つ登場人物
- **精霊、隠者、道化師** — 脇役

こうした定型的な人物構成は俳優の即興を容易にした。物語の筋が異なっていても、観客はそれぞれの登場人物の「役割」をすでに理解していたためである。

## 劇団と劇場

最盛期のバンサワンは、大規模な劇団と専用の劇場を備えた、本格的な娯楽産業であった。特にペナンとシンガポールでその傾向が顕著であった。以下は記録に残る劇団と劇場の一部である。

| 劇団 / 劇場 | 備考 |
| --- | --- |
| Pushi (Indera) Bangsawan、ペナン | 最初のバンサワン劇団。マレー語による台詞の先駆者 |
| Star Opera Company | 1909年に Cheong Koon Seng が設立 |
| Wayang Kassim (Indra Zanibar Royal Theatrical Company) | 20世紀初頭の代表的な劇団の一つ |
| Nahar Opera | 俳優約90人、音楽家28人を擁した |
| Grand Nooran Opera | Pak Yem がショウ兄弟から5,000ドルを借り入れて設立 |
| Theatre Royal、North Bridge Road（シンガポール） | 1908年開業。収容人数は観客約1,300人 |

バンサワン劇団は国境を越えても活動した。第二次世界大戦前、バンサワンの巡業団はスマトラやジャワにまで足を延ばし、現地の大衆演劇に影響を与えた。

## なぜバンサワンは衰退したのか？

バンサワンの衰退は、より新しい娯楽技術によってもたらされた。20世紀半ばまでに、ラジオ・映画・テレビとの競争が観客をバンサワンの劇場から遠ざけていった。

この変化は建物そのものにも表れていた。1930年代末までに、シンガポールの多くのバンサワン劇場が映画館へと改装された。戦後、バンサワンはほぼすべての資金源を失い、この産業は——大規模な商業形態としては——ほぼ姿を消すこととなった。

## バンサワンはいかにしてマレー映画を育てたのか？

バンサワンの衰退は、その人材の終焉ではなく、移行を意味していた。このオペラ産業が崩壊すると、多くの従事者が映画制作スタジオに吸収されていった。ショウ兄弟——ラン・ラン・ショウとラン・ミー・ショウ——は、もともと遊園地でバンサワンの従事者を起用しており、後には映画でも彼らを起用するようになった。

これこそがバンサワンの最も持続的な遺産である。バンサワンの舞台で鍛えられた俳優、歌手、音楽家、演出家たちは、メロドラマ的な演技、歌唱、即興、そして演出様式といった技能をそのまま初期のマレー映画へと持ち込んだ。その意味で、マレー映画スターの第一世代は、実質的にはバンサワン舞台スターの最後の世代であったと言える。

バンサワン自体が完全に姿を消したわけではない。ラジオ番組*Bangsawan di Udara*（1958年頃から1980年代にかけて）や、現在に至るまでのさまざまな保存活動を通じて受け継がれてきた。
