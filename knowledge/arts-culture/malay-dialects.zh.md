一位来自哥打峇鲁的说话者、一位来自亚罗士打的说话者，与一位来自古晋的说话者，或许都会说自己讲的是马来语——但当他们各自在家乡随意闲聊时，其声音可以如此不同，以致需要稍加适应才能彼此理解。这种差异便称为方言，或在日常用语中称为 loghat（口音）。

本文以描述性的方式说明马来方言：什么是方言、它如何与标准语相关、半岛与婆罗洲的主要群组，以及这些变体彼此之间的差异。

## 标准语与方言

首先需要理解的区别，是**标准马来语**与**地方方言**之间的分别。标准语是[马来语](/zh/arts-culture/bahasa-melayu)的规范变体，用于教育、官方广播、政府文件与出版。它是一种经协调与发展的变体，部分由语文出版局（DBP）统筹，作为跨地区的共通语言。

根据语言学研究，马来西亚的标准马来语大体上以**柔佛—廖内方言**为基础，即半岛南部的马来语变体。在 Mukhlis Abu Bakar 关于柔佛—廖内发音与标准发音的研究中，柔佛—廖内发音被形容为在20世纪中叶电台的作用之后，成为马来西亚与新加坡标准参照的发音。官方发音究竟应以拼写为准（标准发音）抑或以柔佛—廖内发音为准，曾是一个不时改变的语言政策议题。

地方方言则是当地社群的日常口语。一个人通常在与家人闲聊时使用家乡的口音，却在官方事务中切换到标准语——这是多方言社会中常见的一种语域切换。方言的差异主要在于**音系**（声音与发音系统）与**词汇**，并在语法上有少许不同。

以下是几个主要马来方言及其地区的简要概览：

| 方言 / 口音 | 主要特点与地区 |
| --- | --- |
| 柔佛—廖内（南部） | 标准马来语的基础；涵盖柔佛、马六甲、雪兰莪，以及霹雳中部与南部 |
| 吉兰丹—北大年 | 音系与词汇极其独特；吉兰丹与泰国南部的北大年地区 |
| 登嘉楼 | 东海岸变体，与吉兰丹—北大年群组相关但有所不同 |
| 北部 / 吉打 | 涵盖吉打、玻璃市、槟城与霹雳北部（太平一带） |
| 霹雳 | 有若干次方言；部分归入南部群组 |
| 彭亨 | 内陆与河流方言；由 James T. Collins 等人研究 |
| 森美兰 | 与来自苏门答腊的米南加保后裔相关 |
| 砂拉越马来语 | 发音与词汇独特的婆罗洲变体 |
| 沙巴马来语 | 沙巴的通用语；与文莱马来语相近 |
| 峇峇马来语 | 土生华人社群的变体；马来语词汇带有福建话影响 |

## 半岛北部与东部方言

在半岛北部有**北部方言**，即吉打方言。根据 Asmah Haji Omar 的分类，吉打方言涵盖吉打（包括浮罗交怡）、玻璃市、槟城与太平一带的霹雳北部，并再细分为若干次方言，如沿海吉打与北吉打。北部口音以其独特的发音特点著称，包括词尾元音的音变。

在东北海岸则有两种最为独特的变体。**吉兰丹口音**——与泰国南部的北大年方言关系密切——其声音系统与词汇是如此不同，以致其他地区的说话者往往需要时间才能适应。**登嘉楼方言**与吉兰丹—北大年群组共享一些特点，但仍有所不同。近期的学术研究甚至提出，这些东北部变体是如此独特，以致部分学者在考量它们是否应被视为独立的语言，而不仅仅是方言。

方言学家对于半岛方言的分类方式并未完全一致。Ismail Hussein（1973）将其分为四个主要群组——柔佛—马六甲—雪兰莪连同霹雳中部；北大年—吉兰丹—登嘉楼群组；森美兰群组；以及吉打方言。Asmah Haji Omar 则透过音系比较，提出划分为若干群组，并以吉打方言为马来语北部方言。此外也有按说话者地区更细致的列表。

## 南部方言与森美兰

**南部**群组——柔佛、马六甲、雪兰莪，连同霹雳中部与南部——是最接近标准语的地区，因为正是这柔佛—廖内方言成为规范变体的基础。对许多说话者而言，南部口音听起来最「寻常」，因为它是广播中最常听到的口音。

**森美兰方言**因其历史背景而引人注目。森美兰的马来族群大体上是来自西苏门答腊的米南加保移民后裔，并一同带来了母系习俗制度（adat perpatih）。因此，森美兰方言常与米南加保语相关联。然而，词汇研究显示它实际上比米南加保语本身更接近标准马来语——这是一个说明说话者的历史渊源与语言学上的亲近程度未必一致的例子。米南加保移民本身的时间与性质，至今仍为历史学者所争议。

## 婆罗洲方言：砂拉越与沙巴

在南中国海的另一端，东马来西亚有着独特的婆罗洲马来语变体。**砂拉越马来语**的发音与词汇与标准语有显著差异，并在该州多元族群社群之间作为交际语言发挥作用。

**沙巴马来语**则据 T. G. Hoogervorst 的研究，发展成为沙巴的通用语，并与文莱马来语相近，其音系与词汇也受到该州原住民与外来者语言的塑造。部分学者将沙巴、砂拉越与文莱马来语视为同一方言连续体的一部分，而非界线分明的分离变体。这些婆罗洲马来语变体与数十种并不属于马来方言的[婆罗洲原住民语言](/zh/arts-culture/borneo-indigenous-languages)并存。

## 峇峇马来语及其他变体

除地方方言外，也有透过文化与语言接触形成的变体。其中最著名的是**峇峇马来语**，即土生华人或海峡华人社群的变体。根据 Nala Huiying Lee 对峇峇马来语语法的研究，这一变体将以马来语为基础的词汇与福建话方言的影响结合起来，是讲福建话的商人与马来世界当地社群接触的产物。它主要在马六甲、槟城与新加坡使用，如今属于濒危变体。峇峇马来语的地位——究竟应被视为克里奥尔语抑或一种马来方言——至今仍为学者所讨论。

此外，几乎每个州属与地区都有自己的次方言与个人语言习惯，以致 James T. Collins 等研究者编纂了庞大的马来方言宝库，涵盖彭亨方言、刁曼等岛屿方言，以及许多其他方言。

## 方言在今日生活中

马来方言并非走向消亡的遗存，相反它活在日常口语之中。口音是地方身份的有力标志：说话者往往仅凭听人的发音与用词便能猜出其出身。口音也成为娱乐、戏剧、音乐与社交媒体的素材，其中一部分如今由语言学家与 DBP 等机构记录与研究。

与此同时，标准马来语仍是教育、行政与官方沟通的共通变体——使来自差异甚大的方言的说话者仍能轻易沟通。因此，方言与标准语并非相互竞争，而是马来社群语言生活中相辅相成的两个层次。欲更广阔地了解本国的各种语言，请参阅马来西亚[所通行的语言](/zh/malaysia/languages-spoken)。
