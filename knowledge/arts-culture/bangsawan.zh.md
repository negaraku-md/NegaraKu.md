在电影出现之前，就有了灯火通明的舞台、手绘的幕布，以及一支能够在同一晚的演出中，从舒缓的马来宫廷曲调切换到中东节奏的乐队。那就是班沙湾——曾是马来半岛城市里最热闹的娱乐形式，后来又把自己的演员和歌手交给了新生的马来电影业。

## 班沙湾从何而来？

班沙湾并非生长于乡村，而是源自港口城市的交汇碰撞。它的起源是波斯社群——波斯裔印度人——的剧场，称为 **Wayang Parsi**，这一形式最早于1870年代在槟城上演。

历史记录留下了一个更为具体的催化时刻：1875年，一个来自孟买的波斯剧团在槟城演出，反响热烈，班沙湾便由此开始成形。在早期，这些 Wayang Parsi 的演出以印地语呈现，演员从印度请来。

重大的转变发生在这一形式被本地从业者接手，并以**马来语**演出之时。来自槟城的 Pushi（Indera）Bangsawan 剧团被记载为第一个班沙湾剧团——或至少是第一个使用“bangsawan”这一名称的剧团——并且是在舞台上使用马来语对白的先驱。

到20世纪初，这一形式已足够成熟，引起了报章的评论。1903年《海峡时报》（*Straits Times*）的一篇报道将它描述为 "an opera of Indian origin conducted in the Malay language"——一种源自印度、以马来语演出的歌剧。

## 为什么叫“班沙湾”？

马来语中的 *bangsawan* 一词意为贵族或王室成员。这一名称与其内容相称：许多班沙湾故事围绕着国王、王子、公主和宫廷展开，充满华丽的服饰和恢弘的布景。

但使它成为“马来”的，不仅仅是语言。班沙湾吸收并融合了各种来源——故事、歌曲和风格——形成一种世界性的城市娱乐形式。国家文化与艺术局（JKKN）将它定性为一种**过渡性剧场**，连接了传统马来剧场与现代马来西亚戏剧。

## 一场演出是什么样子？

与在露天空间或幕后演出的玛蓉舞（mak yong）或皮影戏（wayang kulit）不同，班沙湾采用**西式镜框式舞台（prosenium）**，配以手绘布景（backdrop）。常见的布景包括幕帘、街道场景、花园、宫廷大殿和森林景观。这些色彩斑斓的手绘布景也反映了一个剧团的财力——剧团越富有，布景就越气派。

班沙湾的表演具有强烈的情节剧色彩，并大量即兴发挥。剧本通常只是一个粗略的框架，让演员能够根据观众的反应调整对白和场次。而打斗场面则融入了席拉武术（silat）的动作。

一场班沙湾演出通常遵循固定的顺序：

| 部分 | 内容 |
| --- | --- |
| Gurindam | 在表演开始前以诗歌形式呈现故事梗概 |
| 开场曲 | 标志演出开始 |
| 主体演出 | 戏剧、爱情、席拉武打和诙谐幽默 |
| Extra turn | 休息时段的插演——喜剧小品、舞蹈和歌唱 |
| 结尾曲 | 向观众致谢的标志 |

**extra turn** 这一部分正是班沙湾的一大魅力所在：一个插演空间，允许加入主线故事之外的歌曲和舞蹈，包括来自美洲、中东和印度的外来歌曲。

## 音乐：一支乐队，两个世界

班沙湾的伴奏由一支现场乐队呈现，将传统乐器与西方乐器融合在一起。所用的乐器包括**钢琴、小提琴和塔布拉鼓（tabla）**。这种组合使得一个剧团能够在一场演出中，从古典马来曲调切换到更现代或更具异国情调的节奏——这正是班沙湾在当时给人以“国际化”感觉的原因。

## 故事与角色

班沙湾的剧目极为广泛，因为它会从任何能吸引观众的来源取材。其叙事通常改编自《马来纪年》（*Sejarah Melayu*）、印度两大史诗《摩诃婆罗多》（*Mahabharata*）和《罗摩衍那》（*Ramayana*）、阿拉伯传奇（hikayat）、中国古典、欧洲故事，甚至莎士比亚戏剧。

其角色则是定型化的——在一个又一个故事中反复出现的类型：

- **年轻英雄** — 主要的勇士或王子
- **女主角** — 故事的女英雄
- **国王和大臣** — 掌权的角色
- **精灵、隐士和小丑** — 配角

这种固定的角色框架便于演员即兴发挥，因为即使剧情不同，观众也已经认得每个角色的“定位”。

## 剧团与剧院

在鼎盛时期，班沙湾是一门认真的娱乐生意，拥有大型剧团和专门的剧院，尤其是在槟城和新加坡。以下是一些有记录的剧团和剧院：

| 剧团 / 剧院 | 备注 |
| --- | --- |
| Pushi（Indera）Bangsawan，槟城 | 第一个班沙湾剧团；马来语对白的先驱 |
| Star Opera Company | 由 Cheong Koon Seng 于1909年创办 |
| Wayang Kassim（Indra Zanibar Royal Theatrical Company） | 20世纪初的知名剧团之一 |
| Nahar Opera | 约90名演员和28名乐手 |
| Grand Nooran Opera | 由 Pak Yem 以向邵氏兄弟借来的5,000元创立 |
| Theatre Royal，North Bridge Road（新加坡） | 1908年开业；可容纳约1,300名观众 |

班沙湾剧团也跨越国界。在第二次世界大战之前，班沙湾巡演团的足迹远达苏门答腊和爪哇，并影响了当地的通俗剧场。

## 班沙湾为什么会衰落？

班沙湾的衰落源于更新的娱乐技术。到20世纪中叶，来自广播、电影和电视的竞争把观众从班沙湾剧场里带走。

这一变化在建筑物本身就能看得出来。到1930年代末，新加坡许多班沙湾剧院被改造成电影院。战后，班沙湾几乎失去了所有资金来源，这个行业——以其大规模商业形式而言——几近消失。

## 班沙湾如何滋养了马来电影？

班沙湾的衰落并非其人才的终结，而是一次转移。当这个歌剧行业崩溃时，许多从业者被吸纳进电影制片厂。邵氏兄弟——Run Run 和 Run Me Shaw——起初在游乐场里起用班沙湾从业者，后来又在电影中起用他们。

这正是班沙湾最为持久的遗产。在班沙湾舞台上受训的演员、歌手、乐手和导演，把他们的技艺——情节剧式的表演、歌唱、即兴发挥和演出风格——直接带进了早期的马来电影。从这个意义上说，第一代马来电影明星其实就是最后一代班沙湾舞台明星。

班沙湾本身并未完全消失。它通过广播节目 *Bangsawan di Udara*（约1958年至1980年代）以及至今各种保存努力得以延续。
