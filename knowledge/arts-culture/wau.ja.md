ワウ（wau）を目にする前に、まずその音が聞こえてくる。正しく作られた伝統的なワウは、空中にある間ずっと唸り続ける——それは風の音ではなく、意図的にその構造に組み込まれた音である。

マレーシア手工芸開発公社（Kraftangan Malaysia）の記録によれば、クランタン州出身の伝統的ワウのAdiguru Kraf（工芸マイスター）であるEncik Shafie bin Jusoh（2006年に授与）について、次のように正確に記されている——彼が制作するワウの全種類は、Wau Baratを除いて音を鳴らすことができる。Wau Merakは七つの音を出す。Wau Bulanは三つ。

これが、ワウと普通の凧との根本的な違いである。一方は遊び道具であり、もう一方は見るため*そして*聞くために作られた物である。

## 竹、紙、そして五つの工程

『Kamus Dewan』（国語・文学局の国語辞典）は、ワウを簡潔に定義している——紙と竹で作られた凧、と。国家文化芸術局（Jabatan Kebudayaan dan Kesenian Negara、JKKN）の文化地図（Peta Budaya）に記された道具の一覧も同じくらい簡素である：竹、ナイフ、紙、鉛筆、はさみ、のり、そして紐。

この材料の簡素さこそが、手仕事を重要なものにしている。JKKNは、制作の五つの段階を次のように説明している：

| 工程 | 内容 |
| --- | --- |
| 竹を削る | 竹を割り、左右のバランスが取れるよう精細に削る |
| 骨組みを作る | 選んだワウの形に合わせて骨組みを結び上げる |
| 下地を貼る | ワウの本体として、骨組みに紙を貼り付ける |
| 装飾する | 花柄模様に合わせて色紙、金紙、銀紙を裁ち、層状に貼り重ねる |
| 仕上げ | 飛ばす前の最終確認とバランス調整 |

竹そのものも、入念に選び抜かれる。パーリス州出身で「Pak Non」と呼ばれ、1972年からワウ作りを始めた2018年のAdiguru Kraf（工芸マイスター）、Samat bin Manについてのマレーシア手工芸開発公社（Kraftangan Malaysia）の記録によれば、彼は曲げやすいよう成熟した竹幹から竹を採り、成形する前に乾燥させるという。

装飾の層は、作り手の署名にもなり得る。Pak Nonは花柄模様の彫刻を五層用いるが、他の多くのワウ職人は三層にとどまる。

## 図案の名前、州の名前

ワウの図案は、木彫りや織物と同じマレーの装飾語彙に由来する——マレーシア手工芸開発公社（Kraftangan Malaysia）の記録によれば、awan larat、lada hitam、ketam guri、daun kacang、daun jarak、daun kangkung、daun jawaなどである。[バティック（batik）](/ja/arts-culture/batik)を見たことがある人なら、そのデザインの論理に見覚えがあるだろう：人物像ではなく、花と葉である。

種類は、たいてい州の名前を冠している：

- **Wau Bulan**——クランタン州
- **Wau Burung**——トレンガヌ州
- **Wau Jalabudi**——ケダ州

JKKN文化地図（Peta Budaya JKKN）はまた、ワウがジョホール州、ヌグリ・スンビラン州、セランゴール州にも分布していると記録している。一人のAdiguru Kraf（工芸マイスター）が複数の種類を制作することもある：Encik ShafieはWau Bulan、Wau Merak、Wau Puyuh、Wau Baratを制作している。

## なぜWau Bulanが勝ち残ったのか

Wau Bulanは、数ある種類の中の単なる一つではない。[国家安全保障会議](/ja/government/national-security-council-mkn)（Majlis Keselamatan Negara、MKN）のポータルは、これを最も人気のある種類として、大きなサイズと三日月に似た形を持つと説明している——そして、この二つの特徴こそがすべてを物語っている。

その三日月形は、一本の線にまで単純化されても、すぐにそれと分かる。それは絵として機能する前に、象徴として機能する。マレーシア航空自身の刊行物『Going Places』は、この国営航空会社のロゴがwau bulanに着想を得たものであると述べている。

この結びつきは、単なる図案上のものではない。マレーシア手工芸開発公社（Kraftangan Malaysia）の記録によれば、マレーシア航空はEncik Shafieをブランド大使に任命し、オーストラリア、ドイツ、モルディブ、日本での彼のワウ実演を後援した。一方Pak Nonへの注文は、パーリス州のアラウ王宮（Istana Arau）やマレーシア航空から寄せられたこともあるという。

[クランタン州](/ja/states/kelantan)では、ワウは地域社会と密接に結びついた伝統遊戯であり続けており、MKNの記録によれば、東海岸では今なお普及活動や競技会が続けられている。JKKNはその目標を率直に述べている：ワウの遊び方と制作工程は、クランタン州の継続的なアイデンティティとなるよう保存されなければならない。

その規模は今や、田んぼをはるかに超えている。[ジョホール州](/ja/states/johor)では、2026年2月7日に開催された第28回パシール・グダン世界凧祭り（Festival Layang-Layang Sedunia Pasir Gudang）が、『Most Countries Participating in a Wau Flying Event』の達成についてMalaysia Book of Recordsの認定証を授与された。

## よくある誤解

- **ワウはクランタン州だけのものだと思い込むこと。** クランタン州はその中心地であるが、ケダ州、トレンガヌ州、パーリス州、ジョホール州、ヌグリ・スンビラン州、セランゴール州にも、それぞれワウの伝統がある。
- **「ワウ」と「wau bulan」を同一視すること。** ワウは一つの分類であり、Wau Bulanはその中の一種類にすぎない。
- **ワウを形だけで評価すること。** 音は仕様の一部であり、副次的な効果ではない。
- **未確認の主張を繰り返すこと。** もっとも頻繁に出回っている二つの主張——Wau Bulanが50セント硬貨に描かれているというものと、マレーシア航空のロゴが実際にはwau kucingであるというもの——について、私たちは公式な出典で確認することができなかったため、いずれもここでは事実として記載していない。

マレーの諺は、ワウに最後の意味を与えている：*bagai wau putus teraju*（糸が切れたワウのように）——希望を失い、運命に身を委ねること。その美しい物は、糸を握る手がある限りにおいてのみ、美しいのである。
