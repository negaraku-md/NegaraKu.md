コタバルの話者、アロースターの話者、クチンの話者は、三者とも自分はマレー語を話していると言うかもしれない——だが、それぞれの村でくつろいで雑談すると、その響きは互いに理解し合うのに少しの調整を要するほど大きく異なることがある。この違いこそが方言、すなわち日常のことばでロガット（loghat）と呼ばれるものである。

本稿はマレー語の方言を記述的に説明する。方言とは何か、標準語とどう関わるのか、半島部とボルネオの主要な方言群は何か、そしてこれらの変種が互いにどう異なるのか。

## 標準語と方言

まず理解すべき第一の区別は、**標準マレー語**と**地域方言**の区別である。標準語は、教育、公式放送、政府文書、出版で用いられる[マレー語](/ja/arts-culture/bahasa-melayu)の標準的な変種である。それは、とりわけ国語・文学局（DBP）によって、地域を越えた共通語として調整され発展させられた変種である。

言語学的研究によれば、マレーシアの標準マレー語は大部分が半島部南部のマレー語の変種である**ジョホール・リアウ方言**に基づいている。Mukhlis Abu Bakar によるジョホール・リアウ発音と標準発音の研究では、ジョホール・リアウ発音は、20世紀半ばのラジオの役割を経てマレーシアとシンガポールにおける標準の基準となった発音として特徴づけられている。公式発音を綴字に基づくべき（標準発音）か、ジョホール・リアウ発音に基づくべきかという問題は、時代によって変化する言語政策上の論点であった。

一方、地域方言は地元社会の日常の話しことばである。人は通常、家族と雑談するときは自分の村のロガットを使い、公的な業務では標準語に切り替える——これは多方言社会で一般的な変種の切り替えの一形態である。方言は主に**音韻**（音と発音の体系）と**語彙**の面で異なり、文法の面でもわずかに異なる。

以下は、いくつかの主要なマレー語方言とその地域の簡単な見取り図である。

| 方言／ロガット | 主な特徴と地域 |
| --- | --- |
| ジョホール・リアウ（南部） | 標準マレー語の基礎；ジョホール、マラッカ、セランゴール、およびペラ中部・南部を含む |
| クランタン・パタニ | 音韻と語彙が非常に独特；クランタンとタイ南部のパタニ地域 |
| トレンガヌ | クランタン・パタニ群に関連するが異なる東海岸の変種 |
| 北部／ケダ | ケダ、パーリス、ペナン、ペラ北部（タイピン周辺）を含む |
| ペラ | いくつかの下位方言；一部は南部群に属する |
| パハン | 内陸・河川の方言；James T. Collins らによって研究された |
| ヌグリ・スンビラン | スマトラ由来のミナンカバウの子孫と結びつけられる |
| サラワク・マレー語 | 発音と語彙の面で独特なボルネオの変種 |
| サバ・マレー語 | サバのリンガフランカ；ブルネイ・マレー語に近い |
| ババ・マレー語 | プラナカン社会の変種；福建語の影響を受けたマレー語の語彙 |

## 半島部北部・東部の方言

半島部の北部には、**北部方言**すなわちケダ方言がある。Asmah Haji Omar の分類によれば、ケダ方言はケダ（ランカウイを含む）、パーリス、ペナン、タイピン周辺のペラ北部を含み、さらに Kedah Persisiran（沿岸ケダ）や Kedah Utara（北ケダ）などいくつかの下位方言に分けられる。北部のロガットは、語末の母音の変化を含む特有の発音の特徴でよく知られている。

北東海岸には、最も独特な二つの変種がある。**クランタン方言**——タイ南部のパタニ方言と密接に関連する——は、音と語彙の体系が非常に異なるため、他地域の話者はしばしば慣れるのに時間を要する。**トレンガヌ方言**はクランタン・パタニ群といくつかの特徴を共有するが、やはり異なる。近年の学術研究はむしろ、これらの北東部の変種は十分に独特であるため、一部の学者はそれらを単なる方言ではなく独立した言語とみなすべきかを検討しているとさえ指摘している。

方言学者は半島部の方言の分類方法について完全には一致していない。Ismail Hussein（1973年）はそれを四つの主要な群に分けた——ジョホール・マラッカ・セランゴールとペラ中部；パタニ・クランタン・トレンガヌの群；ヌグリ・スンビランの群；そしてケダ方言である。一方 Asmah Haji Omar は、音韻の比較を通じて、ケダ方言を北部マレー方言としていくつかの群への分割を提示した。話者の地域ごとにより詳細に分けた一覧もある。

## 南部方言とヌグリ・スンビラン

**南部**の群——ジョホール、マラッカ、セランゴール、およびペラ中部・南部——は、標準語に最も近い地域である。というのも、このジョホール・リアウ方言こそが標準的な変種の基礎となっているからである。多くの話者にとって、南部のロガットは放送で最もよく聞かれるため、最も「ふつう」に感じられる。

**ヌグリ・スンビラン方言**は、その歴史的背景ゆえに興味深い。ヌグリ・スンビランのマレー人住民は大部分が西スマトラからのミナンカバウの移住者の子孫であり、慣習法アダット・プルパティ（adat perpatih）もともに持ち込んだ。それゆえ、ヌグリ・スンビラン方言はしばしばミナンカバウ語と結びつけられる。しかしながら、語彙の研究が示すところでは、実際にはミナンカバウ語そのものよりも標準マレー語に近い——これは、話者の歴史的なつながりと言語的な近さが必ずしも一致しないことの一例である。ミナンカバウの移住そのものの時期と性質は、なお歴史家によって議論されている。

## ボルネオの方言：サラワクとサバ

南シナ海を越えた東マレーシアには、独特なボルネオのマレー語の変種がある。**サラワク・マレー語**は、標準語とは発音と語彙の面で明らかに異なり、同州の多民族社会の間で意思疎通の言語として機能している。

一方、**サバ・マレー語**は、T. G. Hoogervorst の研究によれば、サバのリンガフランカとして発展し、ブルネイ・マレー語に近く、その音韻と語彙は同州の先住民の言語や渡来者の言語によっても形づくられている。一部の学者はサバ、サラワク、ブルネイのマレー語を、明確に分かれた変種ではなく、一つの方言連続体の一部とみなしている。これらのボルネオのマレー語の変種は、マレー語の方言には属さない数十の[ボルネオの先住民言語](/ja/arts-culture/borneo-indigenous-languages)と並んで存在している。

## ババ・マレー語とその他の変種

地域方言のほかに、文化と言語の接触を通じて形成された変種もある。最もよく知られているのは**ババ・マレー語**、すなわちプラナカン（海峡華人）社会の変種である。Nala Huiying Lee によるババ・マレー語の文法研究によれば、この変種はマレー語を基礎とする語彙と福建語方言の影響を結びつけ、マレー世界における福建語を話す商人と地元社会との接触の結果として形成された。主にマラッカ、ペナン、シンガポールで話され、今日では危機に瀕した変種に属する。ババ・マレー語の地位——クレオールとみなすか、マレー語の一方言とみなすか——は、なお学者の議論の対象である。

これに加えて、ほとんどすべての州と地域が固有の下位方言と個人語をもっており、James T. Collins のような研究者は、パハン方言、ティオマンのような島の方言など、広範なマレー語方言の宝庫を編纂している。

## 今日の暮らしのなかの方言

マレー語の方言は消えゆく遺物ではなく、日常の話しことばのなかに生きている。ロガットは地域のアイデンティティの強力な標識であり、話者はしばしば、発音と語の選び方を聞くだけである人の出身を推測できる。ロガットはまた、娯楽、ドラマ、音楽、ソーシャルメディアの題材ともなり、その一部は今や言語学者や DBP のような機関によって記録され研究されている。

同時に、標準マレー語は教育、行政、公式な意思疎通のための共通の変種として存続し——大きく異なるロガットの話者どうしが容易に連絡を取り合えるようにしている。したがって方言と標準語は競合するものではなく、マレー人社会の言語生活において互いを補い合う二つの層である。この国のさまざまな言語についての広い見取り図には、マレーシアで[話されている言語](/ja/malaysia/languages-spoken)を参照してほしい。

## 次に読むもの

マレー語を全体として——歴史、公式な地位、表記体系を——理解するには、[マレー語](/ja/arts-culture/bahasa-melayu)を参照してほしい。非マレー語を含む、国のより広い言語景観の見取り図には、[話されている言語](/ja/malaysia/languages-spoken)を、そしてマレー語の方言ではない東マレーシアの言語の変種には、[ボルネオの先住民言語](/ja/arts-culture/borneo-indigenous-languages)を参照してほしい。
