5月的最后一天，时钟尚未敲响午夜，在砂拉越某条河边的一座长屋里，铜锣已在等待。稻米已经收成入仓。长廊已经打扫干净，挂上了新的草席。一坛 tuak（米酒）已备妥待用。当铜锣终于敲响，长屋头人便会举杯，沿着长长的公共走廊，众人齐声为同样的三个字祝酒：长寿、健康、繁荣。

这正是**达雅节（Gawai Dayak）**的核心——砂拉越达雅族的丰收节，每年于6月1日及2日庆祝。

## 「达雅节」（Gawai Dayak）到底是什么意思

这个名字由两个词组成，各自承担不同的意义。

*Gawai* 意为节庆或仪式。*Dayak（达雅）*则是砂拉越乃至更广泛的婆罗洲原住民族群的统称。它并非单一族群，而是涵盖众多社群的一个总称。

根据 Sarawak Tourism Board 的资料，庆祝达雅节的达雅族群包括 **Iban、Bidayuh、Kayan、Kenyah、Kelabit、Lun Bawang——以及更多族群**。其中的上游族群——Kayan、Kenyah、Kelabit、Lun Bawang 等——常被合称为 **Orang Ulu**，意即「上游人」。

因此，达雅节并非某一社群的节日被其他社群借用，而是众多族群共同庆祝的丰收感恩节——每个族群都拥有自己的长屋、语言与习俗上的差异。

## 一个围绕稻米丰收而建立的节日

达雅节标志着*padi*（稻米）收成季节的结束。在完成播种、照料与收割的劳作之后，这是社群停下脚步、感谢田地所出产的一切，并祈求来年风调雨顺的时刻。

正是这一农耕核心，使日期变得重要。节庆落在收成周期的尾声，按传统信仰，感恩的对象是**Petara**——神灵。NegaraKu.md 将这些记录为社群自身的信仰，以尊重的态度加以描述，而非作为事实的断言。

## 达雅节之夜的仪式次序

尽管公共假期落在6月1日，庆祝活动却在前一晚就已展开。Sarawak Tourism Board 记录了长屋内一套可辨识的仪式次序。

| 阶段 | 活动内容 |
| --- | --- |
| Muai Antu Rua（5月31日前夕） | 在庆典开始前，驱除贪念与厄运之灵 |
| Miring | 感恩献祭，以敲击*gendang rayah*（仪式乐鼓）开场 |
| Ngalu Petara | 年轻少女与勇士组成的队伍，沿*ruai*（长屋走廊）来回游行七次 |
| 午夜祝酒 | 铜锣敲响，头人带领众人以*Ai Pengayu*——祈求长寿的 tuak 米酒——祝酒 |
| Ngajat 与开放门户 | 随后数日充满舞蹈、美食、tuak 与访客往来 |

**Miring** 是整个仪式的核心。它由**Tuai Rumah**（长屋头人）主持，感谢丰收。午夜铜锣敲响时，社群共饮*Ai Pengayu*，互祝长寿、健康与繁荣。

## Ngajat、犀鸟与舞池

若不提及**ngajat**——达雅族的传统舞蹈——任何关于达雅节的叙述都不完整。

男子 ngajat 模仿**犀鸟**的动作——这种鸟正是砂拉越「犀鸟之乡」（Land of the Hornbills）别称的由来——舞步旨在展现勇气、英雄气概与力量。女子 ngajat 的气质则截然相反：柔美、优雅，动作缓慢而身段转折精准。

舞蹈之外，还有节庆的其余部分。**Tuak**——为此场合特别酿制的米酒——被端上桌招待宾客。长屋的桌上摆满传统佳肴，其中包括**ayam pansuh**——以竹筒盛装鸡肉，加入香料与木薯叶炖煮而成的菜肴，是 Iban 与 Bidayuh 特地为达雅节准备的一道菜。长屋的大门也随之敞开：对访客、家人与邻里的待客之道是节庆本身的一部分，而非附加的点缀。

## 卷起草席

达雅节并非在6月2日黄昏戛然而止。在许多社群中，整个达雅节庆典季会延续整个月份，并以一个独特的仪式为其画上句点。

这一收尾仪式即**ngiling tikai**，有时也称作*ngiling bidai*——字面意思是「卷起草席」。按照传统理解，通过卷起庆典期间所用的草席，社群借此宣示达雅节季已经结束：这是一种郑重的方式，向 Petara 与众神灵告知庆典已经落幕，使长屋得以回归日常生活。这一仪式通常在6月底举行。

## 达雅节如何成为公共假期

这些习俗由来已久，但公共假期的历史并非如此——这段历史值得如实道来。

早在**1957年**，为砂拉越所有达雅族设立单一年度节庆的构想，就已经在 Radio Sarawak 上公开提出。在这一节庆获得正式承认之前，殖民地政府曾将6月1日简单地定为「Sarawak Day」（砂拉越日）。

达雅节于**1964年9月25日经宪报颁布为公共假期**，并于**1965年6月1日**首次正式庆祝。自此以后，它便成为砂拉越达雅族群共同的感恩、返乡与身份认同的场合。

| 年份 | 里程碑 |
| --- | --- |
| 1957 | 达雅族节庆的构想在 Radio Sarawak 上公开提出 |
| 1964年9月25日 | 达雅节经宪报颁布为公共假期 |
| 1965年6月1日 | 首次正式庆祝达雅节 |

## 常见误解

**「Dayak 是单一族群。」** 这是一个统称。Iban、Bidayuh 以及各个 Orang Ulu 社群都是拥有各自语言与习俗的独立族群，只是共同庆祝这一节日。

**「达雅节与丰收节（Kaamatan）是同一回事。」** 两者都是丰收节，但彼此独立。达雅节属于砂拉越的达雅族，落在6月1日及2日；[丰收节（Kaamatan）](/zh/arts-culture/kaamatan)则属于沙巴的卡达山—杜顺族及其他族群，落在5月30日及31日。

**「庆典在6月1日举行。」** 主要的仪式次序其实从*5月31日傍晚*就已展开，而整个节庆季要到6月稍晚的*ngiling tikai*仪式才正式落幕。

**「这只是给游客看的表演。」** 公开庆典与开放门户确实欢迎访客，但达雅节首先是家庭与长屋的庆祝活动——是一次返乡、一次感恩，对许多人而言，也是回到自己出生的*kampung*（甘榜）或长屋。
