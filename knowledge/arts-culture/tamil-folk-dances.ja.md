寺院の祭りの日、タヴィルの打ち鳴らしとナーダスワラムの音色が通りを満たすなか、頭上に
花で飾った壺（karagam）を乗せた人が、それを少しも傾けずに舞いながらやって来る。そのそば
には、列をなして色とりどりのハンカチを振る若者たち、孔雀の装いをした少女たち、腰に模造
の馬をくくりつけ、竹馬で蹄の音を響かせる人——これらはすべて、マレーシアのタミル人の
**民俗舞踊**の伝統の情景である。

これらの舞踊は、タミル・ナードゥの村々の寺院、収穫、信仰の伝統のなかに生まれた。移住した
タミル人によってマレーシアにもたらされ、今日も祭りや文化の催しで生き生きと受け継がれて
いる。本稿はそれらの形式を中立的に記述する——バラタナティヤムやカルナータカ音楽のような
舞台の**古典芸術**（別途記述される）ではなく、ナーダスワラムのような**寺院の楽器**の伝統
でもない。ここで語るのは、地域社会に生まれ、広く踊られてきた**民衆の芸術**である。

## 主要な民俗舞踊の形式

マレーシアのタミル人が受け継ぐ舞踊の形式は多い。そのうち広く知られるものには次がある。

| 舞踊 | 簡単な説明 |
| --- | --- |
| **カラガッタム**（Karagattam） | 飾り立てたカラガム（karagam、真鍮の壺）を頭上に乗せ、傾けずに舞う均衡の舞。マリアンマン信仰と結びつく |
| **オイラッタム**（Oyilattam） | 色とりどりのハンカチを振り、列をなして立って舞う優雅な群舞（oyil=美） |
| **カヴァディ・アッタム**（Kavadi Aattam） | タイプーサムで担がれるカヴァディ（kavadi）に基づくムルガン信仰の舞 |
| **マイラッタム**（Mayilattam） | 孔雀の装いで、ムルガン神に捧げて舞う舞踊 |
| **ポイッカール・クティライ・アッタム**（Poikkal Kuthirai） | 竹馬を履いて蹄の音を響かせ、腰に模造の馬の形をつけて舞う |
| **クンミ / コーラッタム**（Kummi / Kolattam） | 手を打ち（クンミ）、または小さな棒を打ち合わせて（コーラッタム）拍子に合わせて舞う群舞 |
| **テルクートゥ**（Therukkoothu） | 通りで演じられる民俗演劇-舞踊の形式 |

これらに加えて、**ウドゥッカイ（udukkai）やパライ（parai）**のような革の楽器の打ち鳴らし
に合わせる音楽舞踊の形式や、**タットゥッカール・アッタム**（thattukkaal aattam、竹馬の上
で舞う）などもある。カラガッタムは多く**ナーダスワラムとタヴィル**の音楽とともに演じられ、
オイラッタムはタヴィルの音楽と民謡に支えられている。

## 由来：村と寺院

これらの舞踊は、タミル・ナードゥの**村の文化**に根ざしている。カラガッタム、カヴァディ・
アッタム、マイラッタムなどは、寺院の祭り、アンマン信仰、収穫の祝いの文脈のなかで生まれた。
カラガッタムはとりわけ**マリアンマン**（雨/シャクティの女神）信仰と結びついており、よい雨と
豊穣への感謝を表す形式として尊ばれている。マリアンマン信仰はマレーシアのプランテーション
社会に深く根ざしていたため、これらの舞踊の伝統もそうした社会を通じてここで受け継がれた。
[マリアンマン信仰](/ja/arts-culture/mariamman-worship)は、マリアンマン信仰の伝統を詳しく
説明している。

これらの芸術をもたらしたのは、多くが英国統治時代にプランテーションの労働のためにやって
来た南インドのタミル人であった。彼らの社会史については
[プランテーションのタミル社会](/ja/arts-culture/estate-tamil-community)がさらに説明している。

## マレーシアでどのように受け継がれているか

これらの舞踊は、マレーシアでさまざまな形で生き生きと保たれている。

- **寺院の祭り：** タイプーサムやチッティライ・プールナミ（Chithirai Pournami）などの祭りの
  際に、カラガッタムやカヴァディ・アッタムなどが演じられる。参照：
  [タイプーサム](/ja/arts-culture/thaipusam)。
- **文化の祭り：** ペラ州のような州で、タミルの新年に合わせて行われる**タミラル・ティルナル**
  （Tamilar Thirunal）のような催しでは、普段は舞台で見る機会の少ないこれらの舞踊が集められ、
  舞台上で披露される。タミルの新年については[タミルの新年](/ja/arts-culture/tamil-new-year)を
  参照。
- **タミル学校の公演：** タミル語教育学校の年次行事や**学校対抗の競演**で、子どもたちがこれら
  の舞踊を学び、演じる。参照：[タミル語学校](/ja/education/tamil-vernacular-schools)。
- **祝祭の催し：** 文化団体は、ディーパバリの催し、オープンハウス（rumah terbuka）の祝い、
  地域団体の催しでも演じる。参照：[ディーパバリ](/ja/arts-culture/deepavali)。
- **団体と交流：** 地元の文化団体がこれらの舞踊を指導する。タミル・ナードゥから来る芸人
  団体の巡回公演も、この伝統を強めている。

## 古典芸術・寺院音楽との違い

民俗舞踊を、マレーシアのほかのタミル芸術の伝統と混同してはならない。

- **古典芸術ではない：** バラタナティヤムやカルナータカ音楽などは、教授される規則をもち、
  舞台の形式に整えられた**古典芸術**である。これらは別途
  [インドの古典芸術](/ja/arts-culture/indian-classical-arts-in-malaysia)の記事で扱っている。
  一方、民俗舞踊は村に生まれた民衆の芸術である。
- **寺院の楽器伝統ではない：** ナーダスワラムやタヴィルのような寺院の楽器の伝統は、
  [寺院音楽——ナーダスワラム](/ja/arts-culture/temple-music-nadaswaram)の記事で説明している。
  これらはこれらの舞踊に**背景の音楽**を提供するが、舞踊と楽器の伝統はそれぞれ独立した芸術
  の形式である。
- **武術ではない：** シランバム（silambam）のようなタミルの武術は別物である。参照：
  [シランバム](/ja/arts-culture/silambam)。
