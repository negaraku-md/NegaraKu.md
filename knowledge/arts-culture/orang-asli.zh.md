早在「马来西亚」这个名字出现在地图上之前，就已经有族群居住在半岛的森林、高地与沿海地带。今天，他们统称为「原住民」（Orang Asli）——这个马来语词汇的意思是「最初的人」或「原始居民」。

然而，在这一个统称之下，蕴含着广泛的多样性：不同的语言、不同的生活方式，以及各自独立的聚居历史。本文以描述性的方式说明三件事——从法律角度看，谁是原住民；他们在官方上如何被分类；以及负责处理其事务的政府机构是哪一个。

## 从法律角度看，谁是原住民

从地理上看，「原住民」指的是**马来西亚半岛**的原住民族群。沙巴与砂拉越的原住民并不被归类为原住民（Orang Asli）；他们被另行归类为各自州属的土著（bumiputera）。根据JAKOA的官方数据，槟城、玻璃市与联邦直辖区并无原住民聚居点的记录。

一个人是否具有原住民身份，并非单纯的文化标签——它是由法律界定的。**1954年原住民法令（Akta 134）s.3**规定了谁被视为原住民。该定义将三个要素相互连结：

- **血统**——父亲为某原住民族群成员的人；
- **语言**——使用原住民语言的人；及
- **生活方式**——一般依循原住民生活方式、习俗与信仰的人。

同一法令也涵盖诸如被收养并以原住民身份抚养长大的儿童等情况。重要的是，s.3规定，任何有关**某人是否为原住民的问题，均应由部长裁定**。换言之，这项身份具有明确的法律地位，而不仅仅是自我认同的问题。

## 三大族群与18个支系

原住民发展局（Jabatan Kemajuan Orang Asli，JAKOA）将原住民族群分为**三大族群**——尼格利陀人（Negrito）、塞诺伊人（Senoi）与原马来人（Proto-Malay）。每个族群各包含六个支系，合计共**18个支系**。

以下是JAKOA所采用的官方分类：

| 主要族群 | 支系 |
| --- | --- |
| **尼格利陀人（Negrito）** | Kensiu, Kintak, Lanoh, Jahai, Mendriq, Bateq |
| **塞诺伊人（Senoi）** | Che Wong, Mah Meri, Jah Hut, Semoq Beri, Semai, Temiar |
| **原马来人（Proto-Malay）** | Temuan, Semelai, Jakun, Kuala, Kanaq, Seletar |

如JAKOA所描述，每个族群都有其各自独特的聚居特征与历史：

- **尼格利陀人（Negrito）**常被形容为半岛最早的居民之一，小规模群体主要分散在北部地区。
- **塞诺伊人（Senoi）**是人数最多的族群。根据JAKOA，**塞芒人（Semai）**是原住民中人数最多的支系——1993年的人口普查记录超过**42,000人**——聚居于蒂蒂旺沙山脉（Banjaran Titiwangsa）沿线，涵盖霹雳与彭亨。
- **原马来人（Proto-Malay）**涵盖聚居于半岛中部与南部地区的支系。在这些支系当中，JAKOA记录**Kanaq**人数为最少之一。

这些支系各自使用不同的语言或方言。这种语言多样性，是[马来西亚的语言](/zh/malaysia/languages-spoken)这幅更广图景的一部分。

## 他们居住在哪里

原住民的聚居分布在半岛各地并不均衡。JAKOA在data.gov.my门户网站上的官方数据看板，记录了按州属划分的原住民人口分布如下（数据日期为2023年6月24日）：

| 州属 | 原住民人口 |
| --- | --- |
| 彭亨 | 78,615 |
| 霹雳 | 61,225 |
| 雪兰莪 | 20,961 |
| 吉兰丹 | 17,487 |
| 柔佛 | 15,825 |
| 森美兰 | 12,221 |
| 马六甲 | 1,833 |
| 登嘉楼 | 1,072 |
| 吉打 | 336 |

根据这些州属数字，该数据看板记录的总数约为**209,575人**。彭亨与霹雳两个州属合计占了该总数的一半以上。这一图景补充了[马来西亚人口构成](/zh/malaysia/population-composition)的整体面貌。

## JAKOA：负责的机构

负责处理原住民事务的政府机构是**原住民发展局（Jabatan Kemajuan Orang Asli，JAKOA）**，目前隶属于乡村及区域发展部（Kementerian Kemajuan Desa dan Wilayah）。

原住民事务的行政管理有着悠久的历史。根据JAKOA的记录：

- **1939年**——霹雳州政府颁布了一项与原住民部落相关的法令，并委任一名官员担任「原住民保护官」（Protector of Aborigines）。
- **1954年**——原住民局（Jabatan Orang Asli，JOA）根据《原住民条例》（Ordinan Orang Asli）成立，作为专门负责这个族群的部门。
- **2011年1月15日**——部门名称由原住民事务局（Jabatan Hal Ehwal Orang Asli，JHEOA）更名为**原住民发展局（Jabatan Kemajuan Orang Asli，JAKOA）**，以配合朝向社群发展方向扩大的职能。

JAKOA表示，其成立的基本宗旨，是保护原住民及其生活方式，使其免受快速发展与外部势力剥削的影响，同时在教育、医疗与社会经济发展方面提供设施与援助。

## 宪法下的保护

原住民的地位在《联邦宪法》中同样有所提及。

**第8条**订立了法律面前人人平等的原则。第**8条(5)款(c)项**规定，该平等条文并不妨碍订立任何**为保护、增进福祉或提升马来亚半岛原住民**的条文——包括**保留土地**——或为他们保留合理比例适当的公共服务职位。

此外，宪法的**Ninth Schedule（第九附表）**将「原住民福利」（*welfare of the aborigines*）列入联邦清单（Federal List）之内。这意味着原住民福利事务是联邦政府的职责，而非州属事务。这一框架说明了为何是像JAKOA这样的联邦部门，而非州属部门，负责管理原住民事务。这项规定是[联邦宪法](/zh/law/federal-constitution)更广泛架构的一部分。

## 常见误解

**「原住民、马来人与土著都是同一回事。」**这三者相关，但并非同一术语。原住民（Orang Asli）是半岛原住民族群的特定类别，依据Akta 134拥有自己的法律定义，有别于宪法第160条对「马来人」的定义，也有别于沙巴与砂拉越原住民的类别。

**「原住民只是单一的一个族群。」**恰恰相反，JAKOA将原住民分为三大族群，共涵盖18个支系，各自拥有本身的语言与文化。

**「原住民遍布马来西亚各地，包括沙巴与砂拉越。」**从官方角度而言，「原住民」一词仅指半岛的原住民族群。沙巴与砂拉越的原住民则另行归类。
