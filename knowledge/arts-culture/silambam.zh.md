在马来西亚的庙会或泰米尔新年活动上，你或许会看到一名青年随着鼓乐的节拍，以迅雷般的速度将一根长竹棍在头顶上方与身体四周旋转。那旋转并非徒为美观——它是锡拉邦的标志，一门已有一千五百余年历史的泰米尔武术。

锡拉邦是**一门源自泰米尔纳德邦、以竹棍为主要武器的武术**。它随泰米尔人的移居传入马来西亚，如今作为武术、体育与文化表演延续至今。本文中立地叙述这门武术的起源、技法，以及它在马来西亚泰米尔社群中的地位。

## 历史与起源

锡拉邦是一门在泰米尔纳德邦发展起来的古老兵器之术。学者根据桑伽姆时代文学的记载认为，它**至少自公元前四世纪起**便已传习；在《西拉巴提卡拉姆》（Silappadikaram）等典籍中可见其踪迹。有人将其渊源上溯至三千年——因此其确切年代尚无定论。

关于名称，一般认为它与意为「山」的泰米尔词语**silambu**有关；据说生长于古林吉山区的锡拉姆布竹，为这门棍术赋予了名字。也有民间说法，将此名与棍子旋转时所发出的声响，以及脚铃（silambu）的声响联系起来。

历史记载称，在十八世纪反抗英国东印度公司的斗争中，普利·德瓦尔（Puli Thevar）、迪兰·钦纳马莱（Dheeran Chinnamalai）与马鲁杜（Marudu）兄弟等人曾运用其锡拉邦本领。殖民统治后来查禁了这门武术；随着以枪械为本的训练受到推崇，锡拉邦开始式微。

## 武器与技法

锡拉邦的核心是**长竹棍**——其长度按习练者的身高裁切。将棍子在头顶上方、身体四周旋转，并在双手之间交替挥舞的技法（旋棍），是这门武术的标志性景象。在基本棍术训练之后，技法会延伸到多种武器：

| 武器 | 说明 |
| --- | --- |
| 长棍（long staff） | 以竹制成的主要武器；长度按习练者身高而定 |
| 马鲁／马杜（maru） | 以鹿角制成的双头刺击武器 |
| 瓦尔（vaal，剑） | 通常为弯剑 |
| 萨乌库（savuku，鞭） | 旋转的鞭子 |
| 卡提／阿鲁瓦尔（katti／aruval，刀／镰） | 短柄砍击武器 |
| 乌鲁米（urumi） | 可弯曲的金属软剑 |

这一切武器训练皆以棍术训练中所习得的动作与节奏为基础。

## 步法与阿达乌

在锡拉邦中，人们说**步法**而非兵器技艺才是根本。将双脚前后、左右与旋转移动的那些经过设计的动作，称为**阿达乌**（adavu，或称 kaaladi）。它们培养平衡、速度与绕着对手移动的能力；正是棍子的旋转与双脚的移动相结合，构成了锡拉邦的流动。

不持武器、以徒手相搏的部分，称为**库图瓦里赛**（kuttu varisai）；其中包含以动物动作为本的招式（forms）。入门阶段的训练，着重于强化柔韧、敏捷、手眼协调与耐力。

## 锡拉邦传入马来西亚的历程

今日马来西亚的锡拉邦传统，大体上与**英国殖民时期**的泰米尔人移居紧密相连。在十九世纪后期至二十世纪初期，从南印度——主要是泰米尔纳德邦——前来在橡胶园及其他行业工作的劳工，一如带来他们的语言与文化那般，也随身带来了锡拉邦这门武术。

在与世隔绝的园丘社群中，锡拉邦作为体能锻炼、自卫方式，以及庙会上的表演而延续下来。正是由于这些社群根源，锡拉邦至今在马来西亚仍拥有强大的社群支持。欲进一步了解此背景，可参阅[马来西亚的泰米尔人](/zh/arts-culture/tamil-in-malaysia)与[园丘泰米尔社群](/zh/arts-culture/estate-tamil-community)。

## 今日马来西亚：艺术、体育、自卫

今天在马来西亚，锡拉邦具有**三重身份**——武术、竞技体育与文化表演。

- **作为文化表演：** 锡拉邦的展演是泰米尔新年、庙会、社群庆典等活动的常见环节。它被推广为将年轻人与其根源相连的一种途径。
- **作为竞技体育：** 马来西亚举办全国锡拉邦赛事；它曾在某些年份出现于马来西亚运动会（SUKMA）（例如2010、2011、2013年作为奖牌项目；2004、2008、2022年作为示范项目），但其地位逐年有所变动。马来西亚选手也在国际层面参赛——2026年在槟城某大学校园举行、有十一个国家参与的国际锦标赛，便是一例。
- **作为武术：** 它透过学校与青年培训计划、工作坊，以及在个别师父门下的每周训练而传授；它也被视为一种培养自信与纪律的训练。

马来西亚有若干**协会**在统筹锡拉邦（例如 Persatuan Silambam Malaysia，以及与锡拉邦流派相关的其他独立团体）。这些团体之间的关系，以及其体育行政认可的地位，曾不时变动；因此，最好以相关时期的来源核实当前的官方情况。

## 常见误解

- **「锡拉邦与席拉是一回事。」** 不是。锡拉邦是源自泰米尔纳德邦的泰米尔艺术；席拉（silat）则是马来／努山达拉传统的另一门武术。两者虽同在马来西亚，却各有其历史与技法。
- **「锡拉邦只是舞台艺术。」** 锡拉邦不仅是文化表演，也是一门具有明确技法的武术，以及一项竞技体育。
- **「锡拉邦就只是棍子而已。」** 棍子虽是主要武器，但这门武术也包含马鲁、剑、刀、乌鲁米等多种武器，称为阿达乌的步法，以及徒手的库图瓦里赛。
