ウェサック・デー（Wesak Day、Vesakとも表記）がいつなのかを尋ねても、決まった答えはない——毎年変わるのだ。2026年は5月31日、2027年は5月20日、2028年は5月9日にあたる。理由は単純である。ウェサックは暦の特定の日付ではなく月の満ち欠けによって定まり、陰暦と西暦は毎年互いにずれていくからである。

この一点——満月の日の宗教行事が、マレーシアの固定された公共祝日カレンダーに組み込まれているという特徴——こそが、この日について理解しておくべき最も重要な点である。

## 一目でわかる概要

| | |
| --- | --- |
| 記念する内容 | 仏教の伝統において、仏陀の誕生・成道・涅槃（parinirvana）を、同じ一日にまとめて記念する |
| 別表記 | Vesak；ブッダ・プールニマー（Buddha Purnima）または仏誕日（Buddha's Birthday）とも呼ばれる |
| 時期 | 陰暦ウェサーカ月（Vesakha）の満月の日——おおむね4月か5月；西暦の日付は毎年変わる |
| 祝日としての位置づけ | すべての州と連邦直轄区における全国公共祝日 |
| 公共祝日として初めて宣言された年 | 1962年 |
| 2026年の日付（公式） | 2026年5月31日（日曜日）；振替休日は2026年6月2日（火曜日） |
| 祝う人々 | マレーシアの仏教徒コミュニティ——上座部仏教、大乗仏教、金剛乗仏教の各伝統にわたる |

## この日が記念すること

仏教の伝統において、ウェサックは、仏陀シッダールタ・ガウタマ（Siddhartha Gautama）の生涯における三つの別々の出来事——誕生、成道（悟りを開いたこと）、そして涅槃（parinirvana）と呼ばれる入滅——を一つにまとめて記念する。これらの出来事は、年こそ異なるものの、いずれもウェサーカ月（Vesakha）の同じ満月の日に起きたとされており、それゆえ一つの行事がこの三つすべてを担うのである。

陰暦のある月の満月と結びついているため、日付は西暦に対して固定されていない。おおむね4月か5月に落ち、年ごとに移動する——他の陰暦に基づく行事の日付を動かすのと同じ仕組みである。

## ウェサックがいつ落ちるか、そして2026年の日付

マレーシアの公共祝日の日付は、政府によって毎年確認される。2026年については、[国家安全保障会議](/government/national-security-council-mkn)（Majlis Keselamatan Negara）と大馬半島労働局（Department of Labour Peninsular Malaysia）が、ハリ・ウェサック（Hari Wesak）が**2026年5月31日（日曜日）**にあたると発表した。

| 年 | ウェサック・デー |
| --- | --- |
| 2026年 | 5月31日（日曜日） |
| 2027年 | 5月20日（木曜日） |
| 2028年 | 5月9日（火曜日） |

2026年5月31日は日曜日——多くの労働者にとって毎週の休息日——にあたるため、振替休日が適用される。公式発表では、この振替日を**2026年6月2日（火曜日）**としている。その間に挟まる月曜日、2026年6月1日は、それ自体すでに国王（Yang di-Pertuan Agong）の公式誕生日として官報告示された祝日にあたっており、これがウェサックの振替が次の稼働日にずれ込む理由である。1955年雇用法（Employment Act 1955）の下では、官報告示された公共祝日が休息日に重なる場合、振替の有給休日を受ける権利が生じる。

## 1962年以来の全国公共祝日

ウェサックは、マレーシアのすべての州と連邦直轄区において公共祝日として祝われる——これは全国的な祝日の一つであり、特定の州だけの祝日ではない。

マレーシアの僧王（Chief High Priest）、ダトゥック・K・スリ・ダンマラタナ（Datuk K. Sri Dhammaratana）の説明によれば、仏教徒コミュニティは1961年に政府へウェサックの承認を求めて陳情し、1962年に公共祝日として宣言されたという。同じ説明では、マラヤにおける正式なウェサックの祝賀行事の起源を、クアラルンプールのブリックフィールズ（Brickfields）にある仏教大寺院マハー・ヴィハーラ（Buddhist Maha Vihara）——1894年に創建され、その翌年に最初のウェサックが祝われた——にまで遡らせている。

## ウェサックの一般的な祝い方

マレーシアにおける祝賀行事は寺院を中心に行われる。以下の形式は広く実践されているものであり、ここでは優劣をつけたり教義上の意味を解釈したりすることなく、文化的事実として記述する。

- **夜明けの寺院参拝。** 信者は早朝に集まり、祈り、読経、瞑想を行う。多くの信者はこの日、追加の戒律を守る。
- **供物。** 花、蝋燭、線香が仏像の前に供えられる——しおれる花、燃え尽きる蝋燭、立ち消える線香は、仏教においてしばしば無常を思い起こさせるものとして説明される。
- **仏像への灌水（浴仏）。** 幼子仏陀の像に香水を注ぐことは、いくつかの伝統において一般的なウェサックの儀礼である。
- **布施と喜捨（dana）。** 僧侶へ食物が供えられ、多くの寺院が募金活動、困窮者への食事提供、献血キャンペーンを催す。
- **白い衣服の着用。** 多くの信者はこの日、白い衣服を身にまとい、菜食を守る。
- **キャンドルライト行列。** 夕方の行列では、提灯や蝋燭が掲げられる。

最もよく知られる公開行事は、ブリックフィールズのマハー・ヴィハーラを出発する**クアラルンプールのウェサック行列**である。装飾を施した山車——しばしば大きく光る仏像を載せている——が数時間かけて市内を練り歩き、大勢の信者と見物人がそれを見守る。同様の山車行列やオープンハウス行事は、他の町や州の仏教徒コミュニティ、とりわけペナンでも開催される。

## よくある誤解

- **「ウェサックには固定された日付がある」** そうではない。陰暦ウェサーカ月の満月によって定まるため、西暦の日付は毎年変わる——常にその年の官報告示された日付を確認すること。
- **「ウェサックは仏陀の誕生日だけを記念するものだ」** マレーシアおよびより広い上座部仏教の伝統では、この日は誕生・成道・涅槃という三つの出来事を共に記念するものであり、誕生だけではない——「仏誕日（Buddha's Birthday）」という呼び方も一般的に使われてはいるが。
- **「2026年の祝日は6月1日だ」** ウェサック当日は2026年5月31日である。6月1日は国王（Yang di-Pertuan Agong）誕生日のための別の祝日であり、ウェサックの振替休日は6月2日にあたる。
- **「ウェサックは他のいくつかの祝日と同様、州レベルの祝日にすぎない」** これはすべての州と連邦直轄区で祝われる全国公共祝日である。

## 次に読む

ウェサックは、マレーシアのより広い宗教構成の中に位置づけられる——どれほどの数のマレーシア人が仏教徒であると自認しているか、またそれが各州にどのように分布しているかについては、[宗教統計](/ja/malaysia/religion-statistics)を参照のこと。イスラム教以外の宗教も実践しうるという保証を含む、マレーシアにおける宗教の憲法上の枠組みについては、[第3条と第11条](/ja/law/article-3-religion)を参照のこと。そして、最大規模のウェサック行列が行われる都市については、[クアラルンプール](/ja/states/kuala-lumpur)を参照のこと。
