PDRMについての説明の多くは、「国家警察部隊」という表現で止まってしまう。より有用な問いはもっと絞り込まれている——法律は実際にこの部隊に何を認めているのか、誰がこれに対する指揮権を有しているのか、そしてどの機関がその人員の任命及び懲戒を決定するのか、という点である。

## 概要

| | |
| --- | --- |
| 正式名称 | マレーシア王立警察（Polis Diraja Malaysia、PDRM） |
| 設立法令 | 1967年警察法（Police Act 1967、Act 344）第三部（Bahagian III） |
| 前身部隊 | 1963年マレーシア王立警察法（Akta Polis Diraja Malaysia 1963）のもとのマレーシア王立警察、s.3(1)により継続 |
| 部隊の長 | 警察長官（Ketua Polis Negara、Inspector-General of Police、IGP）、s.4のもとで設置 |
| 責任を負う対象 | 大臣（警察を所管する大臣） |
| 名誉総司令官 | 国王（Yang di-Pertuan Agong）、s.6Aのもとで |
| 人事機関 | 警察部隊委員会（Police Force Commission）、連邦憲法第140条 |
| 本部 | ブキッ・アマン（クアラルンプール） |
| 所管省庁 | 内務省（KDN） |
| ウェブサイト | `rmp.gov.my` |

Act 344はこの部隊をゼロから設立したわけではない。s.3(1)は、本法施行の直前まで1963年マレーシア王立警察法のもとでマレーシア王立警察の人員であった者は、「相応する階級をもって、相応する性質において」新法のもとでの部隊の人員となる、と定めている。つまり1967年法は、すでに存在していた部隊を再編し、強化するものである。

## 起源と「王立」（DiRaja）の称号

Act 344によって再編されたこの部隊のルーツは、マレーシアという国家そのものよりもはるかに古い。マラヤにおける近代的な警察組織は、1807年3月25日にペナンで発効した**司法憲章（Charter of Justice、Piagam Keadilan）**に始まる。19世紀を通じて各州の部隊はそれぞれ別々に発展し、その一部は1896年7月1日に設立された**マレー連合州警察（Federated Malay States Police）**によって統合された。

「王立」（DiRaja）の称号は、国王（Yang di-Pertuan Agong）トゥアンク・アブドゥル・ラーマン（Tuanku Abdul Rahman Ibni Almarhum Tuanku Muhammad）により、1948年から1960年の非常事態における警察人員の功績を称え、1958年7月24日にマラヤ連邦警察部隊に授与された。1963年9月16日にマレーシアが成立すると、この部隊は今日まで続く名称——マレーシア王立警察（Polis Diraja Malaysia）——を得た。

| 日付 | 出来事 |
| --- | --- |
| 1807年3月25日 | ペナンにおける司法憲章の発効——近代警察の基礎 |
| 1896年7月1日 | マレー連合州警察の設立 |
| 1948年～1960年 | 非常事態——共産主義武装反乱に対する警察の功績 |
| 1958年7月24日 | 国王による「王立」（DiRaja）称号の授与 |
| 1963年9月16日 | マレーシア成立——マレーシア王立警察の名称使用開始 |

## 部隊の五つの目的

PDRMの核心的職能は、単一の規定——s.3(3)——に収められている。同条は、本法に従うことを条件として、この部隊がマレーシア国内及び全域（その領海を含む）において次の五つの目的のために用いられると定めている：

- 法と秩序の維持；
- マレーシアの安寧及び治安の維持；
- 犯罪の防止及び捜査；
- 犯罪者の逮捕及び訴追；並びに
- 治安情報の収集。

政府公式ポータル（malaysia.gov.my）も同じ職能を列挙しており、s.3(3)をその法的根拠としている。この「国内及び全域において」という範囲は重要である。これは州ごとに分立した部隊ではなく、単一の連邦部隊であることを示している。

## 指揮系統

PDRMの指揮構造は、あわせて読むべき二つの条文——s.4（部隊の統制）とs.5（任命）——によって定められている。

s.4(1)は、この部隊を「警察長官（Ketua Polis Negara）の指揮のもと」に置くと定めており、警察長官は警察官でなければならず、部隊及び警察の職務のために任命されたその他すべての者の統制及び指揮について「大臣に責任を負う」。警察長官は、警視総監（Pesuruhjaya）又は警察本部長（Ketua Pegawai Polis）に付与されるすべての権限を有する。

その下で、s.4(2)は警察長官の指揮下にある副警察長官（Timbalan Ketua Polis Negara）の任命を定めており、s.4(3)はその副警察長官に警視総監又は警察本部長のすべての権限を与えている。さらにs.4(4)は、警察長官の行為が——その指示に従うことを条件として——副警察長官、警視総監、副警視総監、上級警視監又は権限を与えられた警視監によって実行されることを認めている。

s.5は、本法を執行する目的で任命され得る職位を列挙している：

| 階層 | s.4～5における職位の例 |
| --- | --- |
| 最高指揮 | 警察長官；副警察長官 |
| 上級警官 | 警視総監；副警視総監；上級警視監；警視監 |
| 執行層 | その他の上級警官及び下級警官；巡査 |

上級警官及び下級警官の具体的な階級は、s.5(2)に従い、本法の第一附表（First Schedule）に定められている。本法は人員を、*上級警官*（警察長官から見習警部まで）と*下級警官*（副警部から巡査まで）に区分している。PDRM公式サイトは18の階級を掲げている：

| 区分 | 階級（高い順） |
| --- | --- |
| 上級警官 | 警察長官（IGP・KPN）・副警察長官・警視総監・副警視総監・上級警視監・警視監・警視正・副警視正・警視・警部・見習警部 |
| 下級警官及び巡査 | 副警部・上級巡査部長・巡査部長・巡査長・上等巡査・巡査・見習巡査 |

州及び編制の階層では、s.6が、大臣の定める地域又は州について警視総監又は警察本部長が、また警察長官の指定する編制、地区警察（daerah polis）又は部門については警察長官の指定する警官が、部隊の人員を統制すると定めている。

一つの象徴的な規定がこの構造を完結させている：s.6Aは、国王（Yang di-Pertuan Agong）をマレーシア王立警察の名誉総司令官（Panglima Besar Kehormat、Honorary Commissioner-in-Chief）と定めている。国王の役割の憲法上の背景については、[Yang di-Pertuan Agong](/government/yang-di-pertuan-agong)を参照のこと。

## 主要部門

行政の面では、ブキッ・アマン本部における部隊の業務は十の主要部門に配分されており、各部門は通常、警視総監又は同等の階級の局長によって率いられている。

| 部門 | 中核的職能 |
| --- | --- |
| 管理部 | 行政、人事及び組織事務 |
| 刑事捜査部（JSJ） | 刑事捜査及び訴追 |
| 麻薬犯罪捜査部（JSJN） | 薬物関連犯罪 |
| 商業犯罪捜査部（JSJK） | ホワイトカラー犯罪及び商業犯罪 |
| ロジスティクス・技術資源部 | 財務、ロジスティクス及び技術支援 |
| 国内治安・公共秩序部（JKDNKA） | 実働部門、公共秩序の統制 |
| 特別部門 | 情報及び治安事務 |
| 誠実性・基準遵守部（JIPS） | 内部の誠実性及び苦情処理 |
| 犯罪予防・地域安全部 | 犯罪予防及び地域社会の安全 |
| 交通捜査・取締部 | 交通法令の執行 |

## 法律が警察官に認めていること

s.20は警務人員の一般的職務を定めている。s.20(1)は、すべての警官に対し、法律により課された職務を遂行し権限を行使すること、並びに上級警官のあらゆる適法な指示に従うことを義務付けている。

続くs.20(3)は、警官の職務がs.3(3)に定める目的を遂行することであると定め、その職務に含まれる適法な措置を列挙している：

- 法律により逮捕の権限を与えられたすべての者を逮捕すること；
- 治安情報を処理すること；
- 訴追を行うこと；
- 歳入、消費税、衛生、検疫、移民及び登録に関する法律の執行を援助すること；
- 港、船渠及び空港における秩序の維持を助けること；
- 適法に発せられた召喚状、召喚令状、令状その他の命令を執行すること；
- 所有者不明の財産及び遺失物を保護すること；
- 生命及び財産の保護を助けること；
- 刑事法廷に出席し（また、特別に命じられた場合は民事法廷にも出席し）、その秩序を維持すること；並びに
- 囚人その他警察の拘束下にある者を護送し監視すること。

ここで二点、留意すべきことがある。第一に、訴追の権限はここに列挙された職務の一つであるが——多くの場合、訴追の決定は他の法律のもとで検察官（Pendakwa Raya、Public Prosecutor）に委ねられている（権限構造の比較として、[SPRM](/government/macc-sprm)が捜査を行いながら検察官に送致する仕組みを参照のこと）。第二に、s.20(4)は、囚人を護送する際、警官は刑務官とみなされ、刑務官の権限及び保護を有すると定めている。この護送職務を支えるため、s.21は、警察の護送に関する適法な指示を妨害し又は違反した場合、最高RM10,000の罰金及び2年の禁錮を定めている。

これらの職務の多くは、他の法執行機関と交差する——例えば、移民及び登録への言及は[移民局](/government/imigresen)の業務と関わり、法廷に出席し秩序を維持する職務は[裁判所制度](/government/kehakiman-mahkamah)と関わっている。

## 誰が人員を任命し評価するのか

この部分はしばしば見落とされる。PDRMは自らの活動を主導しているが、その人員の人事事項を独立して管理しているわけではない。連邦憲法第140条は、警察部隊の人員の任命、確認、常任又は年金付き職への配置、昇進、異動及び懲戒統制を担う**警察部隊委員会（Police Force Commission）**を設けている。

内務省によれば、この委員会は以下の構成員から成る：

| 委員会の構成員 | 地位 |
| --- | --- |
| 警察を所管する大臣 | 委員長 |
| 警察長官 | 委員 |
| 省の事務次官 | 委員 |
| 国王が任命する公共サービス委員会（Suruhanjaya Perkhidmatan Awam）の委員一名 | 委員 |
| 国王が任命するその他の委員二名以上六名以下 | 委員 |

内務省（KDN）によれば、委員会の職能の一部は、2000年12月14日付のP.U.(B) 441号官報を通じて、警察長官及び上級警官に委任されている。この分離により、人員の任命及び懲戒に関する事項は合議制の機関のもとに置かれ、部隊の実働上の指揮系統に完全に委ねられているわけではない。より広い憲法上の根拠については、[連邦憲法](/law/federal-constitution)を参照のこと。

## 外部監督と苦情処理

内部の懲戒統制及び警察部隊委員会の役割の外側では、人員の行動は部隊自体から独立した二つの法定機関によって監督されている：

- **独立警察行為委員会（IPCC）** — Act 839のもとでのPDRM専門の機関。同法は2023年7月1日に施行され、IPCCは2023年11月1日に活動を開始した。PDRM人員の不正行為に関する苦情を監視、捜査及び処理し、国会に年次報告書を提出する。
- **法執行機関誠実性委員会（EAIC）** — Act 700のもとで設立され、2011年4月1日に施行された。EAICは21の法執行機関に対する管轄権を有し、苦情を受理し、捜査を行い、懲戒又は刑事の案件を関係当局に付託することができる。

部隊内部では、誠実性・基準遵守部（JIPS）が内部の誠実性及び人員の不正行為に関する苦情を取り扱う。

## 支援部隊

常備部隊に加えて、1967年警察法は同一の枠組みのもとで警察職務を遂行するいくつかの支援組織を設けている。その中には、マレーシア王立警察義勇予備隊（Simpanan Sukarela Polis Diraja Malaysia、Volunteer Reserve）、補助警察（Polis Bantuan、Auxiliary Police）、臨時警察官（pegawai polis tambahan、Extra Police）、マレーシア王立警察予備隊（Simpanan Polis Diraja Malaysia）及びマレーシア王立警察少年団（Pasukan Kadet Polis Diraja Malaysia）が含まれる。政府ポータルもまた、これらの支援団体を、公共の治安維持における一般任務部隊の補助者として挙げている。

## 政府における位置づけ

警察長官はs.4(1)のもとで大臣に責任を負うため、PDRMは警察を所管する大臣——すなわち[内閣](/government/kabinet-perdana-menteri)における内務大臣——の所管に属する。しかし、警察官の日常的な権限は、本法及び他の法律に由来するものであり、政治的な指示に由来するものではない：s.20は、警官を「法律により課された」職務及び部隊内の上級警官の適法な指示に拘束している。
