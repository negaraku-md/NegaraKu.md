土地は州の事項である。国防は連邦の事項である。公衆衛生は、両者が触れることのできる第三のリストに位置する。マレーシアにおいて、ある法律を制定する権限が連邦にあるのか州にあるのかは、意見や交渉によって決まる問題ではない——それは、連邦憲法の末尾にある一つの附則の中に、事項ごとに書き記されている。

その附則こそが**Ninth Schedule（第九附則）**である。それは三つの事項リスト——さらにサバとサラワクのために留保された二つの追加リスト——を定めており、憲法の第74条から第77条までが、これらのリストを「誰が何について立法するか」という実際に機能する規則へと変えている。

## 概要

| | |
| --- | --- |
| 所在 | 第九附則、第74条及び第77条のもとで読む |
| List I | **連邦リスト** —— 国会のみ |
| List II | **州リスト** —— 州議会のみ |
| List III | **共管リスト** —— 双方が立法可能 |
| List IIA | サバとサラワクのための州リスト補充（第95B条(1)(a)） |
| List IIIA | サバとサラワクのための共管リスト補充（第95B条(1)(b)） |
| 抵触規則 | 第75条 —— 連邦法が優先し、州法はその抵触する限度において無効 |
| 残余 | 第77条 —— いずれのリストにも属さない事項は州に属する |

## 原動力：第74条から第77条まで

リストはそれ自体では作用しない。四つの条文がそれらに効力を与えている。

**第74条**は割り当てを行う。国会は**連邦リスト又は共管リスト**に含まれるいかなる事項についても法律を制定することができる。州議会は**州リスト又は共管リスト**に含まれるいかなる事項についても法律を制定することができる。いずれも相手の専属リストに踏み込むことはできず、この権限は憲法自体が課す条件に服して行使される。

**第75条**は重複を扱う。共管リストは双方に開かれているため、両者が衝突することがある。その場合、「連邦法が優先し、州法はその抵触する限度において無効となる」。州法が全面的に失効するわけではなく——抵触する部分のみが失われる。

**第76条**は、国会が州リストに入り込むことのできる狭き門である。国会が州の事項について立法できるのは、次の三つの目的のいずれかに限られる：条約、協定若しくは規約（又は連邦が加盟する国際機関の決定）を履行すること；二つ以上の州の法律の**統一性**を促進すること；又は、ある州の議会から**要請**があったとき。統一性又は要請を理由として制定された法律は、その州自身の議会がこれを採択するまでその州において効力を生じず、採択された時点で州法として扱われる。

**第77条**は、残ったすべての事項を拾い上げる。「いずれのリストにも列挙されていない」事項——かつ、国会が他の方法によっても立法できない事項——は、州議会に帰属する。残余権限は連邦にではなく、州に帰属する。

## List I —— 連邦リスト

連邦リストは最も長い。27の番号付きitemから成り、国家政府の機構を対象としている。同附則が定める主要な項目は次のとおりである。

- **外交事務** —— 条約、外交及び貿易代表、犯罪人引渡し、旅券及び査証、マレーシア国外への巡礼。
- **国防** —— 軍隊、戦争と平和、武器及び爆発物、国民奉仕、民間防衛。
- **内部安全** —— 警察、犯罪捜査、公共秩序、刑務所、予防拘禁、国民登録。
- **民事及び刑事法並びに司法行政** —— シャリア裁判所*以外の*すべての裁判所の構成及び管轄権、契約、不法行為、財産及びその移転（土地を除く）、婚姻及び離婚、相続、破産、並びに証拠法。
- **連邦公民権及び帰化；外国人。**
- **財政** —— 通貨、国民貯蓄、公債、税制、並びに連邦及び州の監査。
- **貿易、商業及び産業**、**海運**、**通信**（郵便、電気通信、放送及びテレビを含む）、並びに**連邦の公共事業及び電力**（電力及び州間水道を含む）。
- **教育**、**医療及び保健衛生**、**労働及び社会保障**、**原住民の福祉**、**検閲**、**新聞及び出版**、**協同組合**、並びに**観光業**（item 25A）。
- クアラルンプール、ラブアン及びプトラジャヤの**連邦直轄区に関するすべての事項**（item 27）。

item 4は、憲法の他の部分が繰り返し立ち返る一つの境界線を引いている：連邦の民事及び刑事法は、婚姻、離婚、後見、扶養、養子縁組、嫡出、家族法、贈与及び相続に関するイスラム属人法を明文で**除外**している。これらの事項は連邦リストから切り出され、代わりに州リストに置かれている。

## List II —— 州リスト

州リストは短く——12の番号付きitemに加えitem 12Aがあるのみである——が、日常生活を形作る事項を収めている。item 1とitem 2が最も重要な二つである。

**item 1 —— イスラム法とマレー慣習。**連邦直轄区を除き、これはイスラム教を信奉する者に対するイスラム属人法及び家族法、ザカート（Zakat）及びバイトゥルマール（Baitulmal）、モスク、ムスリムによるイスラムの教義に反する犯罪の創設及び処罰（連邦リストの事項を除く）、並びに「シャリア裁判所の構成、組織及び手続」を対象とする。これらの法院は、イスラム教を信奉する者に対してのみ、かつ本項に定める事項についてのみ管轄権を有する。

**item 2 —— 土地。**土地保有、権原の登記、マレー保留地（サバ及びサラワクでは土着保留地）、鉱業許可及び賃借権、並びに土地の強制収用は、いずれも州の事項である。

その他の項目：

| item | 事項 |
| --- | --- |
| 3 | 農業及び林業 |
| 4 | 連邦直轄区以外の地方政府——市の法人、地方当局、地方税率及び選挙 |
| 5 | その他の地方サービス——下宿屋、埋葬地及び火葬場、市場及び市、劇場及び映画館の免許 |
| 6 | 州の公共事業及び水道——州道路、橋梁及び渡し船；河川及び運河（連邦リストに従う） |
| 7 | 州政府の機構——シビル・リスト（Civil List）、州の年金、州の借入及び債務 |
| 8 | 州の祝日 |
| 9–11 | 州の犯罪、州の目的のための審問、及び州法のもとでの補償 |
| 12 | 海亀及び河川漁業 |
| 12A | 連邦のものと宣言されていない図書館、博物館、古跡及び遺跡 |

## List III —— 共管リスト

共管リストは、国会と州議会の**双方**が法律を制定できる事項を収めており——抵触が生じた場合は第75条により連邦に有利に決せられる。同附則が列挙する内容は次のとおりである。

1. 社会福祉及び社会サービス；女性、児童及び青少年の保護
2. 奨学金
3. 野生動物及び鳥類の保護；国立公園
4. 畜産、獣医サービス及び動物検疫
5. 都市及び農村計画（連邦首都を除く）
6. 浮浪及び行商人
7. 公衆衛生、衛生設備及び疾病予防
8. 排水及び灌漑
9. 鉱業用地及び侵食された土地の復旧
9A. 建築物の建設及び維持における防火措置
9B. 文化及びスポーツ
9C. 住宅及び住宅設備
9D. 給水及び水道サービス（連邦リストに従う）
9E. 遺産の保存

## List IIA及びList IIIA —— サバとサラワクの補充リスト

サバとサラワクが1963年に連邦に加入した際、両州はマラヤ諸州が有していなかった立法事項を保持した。**第95B条**は、これらを第九附則に対する二つの補充リストとして規定しており、これらはこの二州にのみ適用される。

**List IIA —— 州リストの補充**は、とりわけ次の事項を追加している：

- **土着法及び慣習**（item 13）——土着属人法、並びに土着裁判所の構成、組織及び手続を含む；
- **州当局の法人化**（item 14）；
- 連邦のものと宣言されていない**港及び港湾**（item 15）；
- **地籍測量**（item 16）；
- サバにおいては、**サバ鉄道**（item 18）；
- 並びに、連邦リストに従うことを条件とする**給水及び水道サービス**（item 20）。

**List IIIA —— 共管リストの補充**は、連邦とこれらの州の双方が立法できる事項を追加しており、婚姻及び相続に関する属人法（item 10）、食品の不純化（item 11）、登録トン数15トン未満の船舶及び河口漁業（item 12）、水力発電（item 13）、農業及び林業の研究（item 14）、並びに州の慈善事業（item 15）が含まれる。

これらの補充リストは、憲法が関係する州の同意なしには改正から保護している事項に含まれる——[憲法改正](/ja/law/constitutional-amendment)及び[MA63](/ja/malaysia/ma63)を参照のこと。

## よくある誤り

**「保健衛生は連邦の事項だから、州には関係がない。」** 連邦リストのitem 14は*医療及び保健衛生*を対象としているが、*公衆衛生、衛生設備及び疾病予防*は**共管**リストのitem 7である——双方が立法でき、抵触が生じた場合は連邦法が優先する。

**「ある事項が州リストになければ、それは必ず連邦の事項である。」** 既定の規則はむしろ逆である。第77条は、国会が他に権限を有しない限り、**いずれの**リストにも列挙されていないすべての事項を州議会に与えている。

**「国会は土地やイスラム法について立法することは決してできない。」** 原則としてこれらは州の事項である。しかし第76条は、条約のため、統一性のため、又は州の要請によるという限られた形で、州リストへの道を開いており、統一性又は要請を理由とする法律は、通常、その州が採択して初めてその州で効力を生じる。

**「三つのリストはどこでも同じように適用される。」** サバとサラワクは第95B条のもとで二つの追加リスト（IIA及びIIIA）を有しており、また州リストのいくつかの項目は、クアラルンプール、ラブアン及びプトラジャヤの連邦直轄区を明文で除外しており、これらの直轄区の事項は連邦リストのitem 27のもとで連邦が扱う。

## 次のステップ

第九附則が憲法全体の中でどこに位置するかについては、[マレーシア連邦憲法](/ja/law/federal-constitution)を参照のこと。州リストitem 1及び連邦リストitem 4に名を挙げられている裁判所については、[民事裁判所とシャリア裁判所](/ja/law/civil-and-syariah-courts)を参照のこと。連邦の立法権を有する両院がどのように構成されているかについては、[国会](/ja/government/parliament)を参照のこと。サバとサラワクの補充リストを改正から保護するより高い基準については、[憲法改正](/ja/law/constitutional-amendment)及び[MA63](/ja/malaysia/ma63)を参照のこと。
