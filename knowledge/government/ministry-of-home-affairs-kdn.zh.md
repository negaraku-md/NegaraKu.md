当一个马来西亚人续办护照、当警察实施逮捕、当外籍劳工的准证被查验，或当一部电影被评级以便上映时——背后都是同一个部门在支撑这四种情形。这个部门就是**内政部**，马来文称为 **Kementerian Dalam Negeri（KDN）**，英文称为 **MOHA**。

KDN 是负责马来西亚*内部*事务的联邦部门——安全、公共秩序、移民、登记、社团与执法——有别于对外防务，后者归属于独立的国防部。其官方门户网站为 `moha.gov.my`，也可通过 `kdn.gov.my` 访问。

## KDN 负责什么

该部将其职责范围划分为约**十个职能领域**：安全与公共秩序；登记事务；移民与外籍劳工；社团管理；民防；反毒工作；出版物与《古兰经》文本的管制；电影审查；志愿人员管理；以及刑罚的改造与执行。

在所有这些领域中，KDN 将其内部安全方针描述为建立在三大支柱之上——**预防、执法和改造**。用它自己的话说，其使命是管理马来西亚的内部安全政策，使国家的主权、完整、和平与利益免受内部安全威胁的侵害。

## 它统管的部门与机构

KDN 面向公众的大部分权力，并非由该部本身的总部人员行使，而是由其下属的执法机构行使。这些机构分为联邦**部门**以及各类**机构与委员会**。

| 部门（jabatan） | 机构与委员会 |
| --- | --- |
| 皇家马来西亚警察（PDRM） | 国家反毒机构（AADK） |
| 移民局（JIM） | 电影审查委员会（LPF） |
| 监狱局 | 马来西亚公共安全学院（IPSOM） |
| 国民登记局（JPN） | 反人口贩运理事会（MAPO） |
| 社团注册局（ROS） | 预防犯罪委员会 |
| 人民志愿军团（RELA） | 假释委员会 |
| 马来西亚海事执法机构（MMEA） | 预防恐怖主义委员会 |
| 沙巴东部安全司令部（ESSCOM） | 马来西亚国家印刷有限公司（PNMB） |

这一结构解释了为何日常与国家机器打交道的许多情形都可追溯到同一个部门：你的大马卡（MyKad）和出生证明（JPN）、你的护照和入境印章（移民局）、一份警察报案（PDRM）、一个注册的非政府组织或俱乐部（ROS），以及一部电影的年龄评级（LPF），全都属于 KDN 的事务范围。

## KDN 的由来

马来西亚自独立以来就以各种形态存在着内政部门，但其**现今形态可追溯到2008年3月18日**，当时原本的**内部安全部**并入了内政部。正是这一整合，使得警察、监狱和反毒职能——曾经归属于内部安全——如今与移民、登记和社团一同置于单一的职权范围之内。

## KDN 与其他安全机构的区别

马来西亚的安全架构很容易混淆，因此厘清界限会有所帮助：

| 机构 | 职权所在 |
| --- | --- |
| **KDN**（内政部） | 内部安全、治安、移民、监狱、登记、公共秩序 |
| **MINDEF**（国防部） | 对外防务与武装部队 |
| **国家安全理事会（MKN）** | 协调各机构之间的国家安全政策与应急/危机应对 |

KDN 运作日常的内部安全机制；MINDEF 抵御来自外部的威胁；而设于首相署之下的 MKN 则协调全政府的安全应对。
