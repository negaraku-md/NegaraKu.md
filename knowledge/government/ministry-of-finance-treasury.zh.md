联邦政府所花的每一令吉——从地区医院护士的薪水到伦敦债券持有人的利息付款——都经过同一道会计门户：马来西亚国库（Perbendaharaan Malaysia）。财政部就是掌管这道门户的部门，而自2024年初起，它是在一套载入法律的量化上限之下掌管它的。

本页说明该部门实际上做些什么：财政预算案如何编制与通过、谁领导国库、国债有多大及其上限为何，以及哪些部门与机构隶属其下。

## 财政部实际上做些什么？

财政部负责国家资产负债表的两端：进来的收入与出去的开支。它制定财政政策、编制联邦财政预算案、管理政府贷款的取得与偿还、管控政府会计与国库事务，并监督其他部门、机构及法定机构的财务管理。

它也是国家金融体系的牵头部门。通过属下的机构，财政部监管直接税与间接税机构、资本市场、存款保险及公共领域融资。《2023年公共财政与财政责任法令》（第850号法令，Akta 850）——如今约束该部门财政管理的法律——将这一职权概括为负责任财政管理的四项原则：确保宏观经济稳定、实现可持续的财政平衡、维持审慎的债务水平，以及有效管理财政风险。

## 谁领导国库？

有两个层级的领导经常被混淆。政治层级由财政部长领导——如今由首相本人兼任第一财政部长——并由第二财政部长及一名副部长辅助。公务员层级由**国库总秘书**（Ketua Setiausaha Perbendaharaan）领导，这是领导马来西亚国库并主持众多金融法定机构董事会的高级官员。

国库总秘书之下有三位副总秘书——分管政策、管理与投资——负责监督国库的各核心部门。

| 国库核心部门 | 职能 |
| --- | --- |
| 国家预算办公室 | 编制与协调年度财政预算案 |
| 税务组 | 直接税与间接税政策 |
| 财政与经济组 | 财政分析、预测与目标 |
| 政府采购组 | 公共采购政策与治理 |
| 信用报告机构注册官办公室 | 监管信用报告机构 |
| 法定机构策略管理组 | 监督法定机构 |

国库也管理沙巴与砂拉越的州属联邦国库，以及审理税务纠纷的所得税特别专员（Pesuruhjaya Khas Cukai Pendapatan）与关税上诉庭（Tribunal Rayuan Kastam）。

## 哪些部门与机构隶属其下？

财政部的结构分为属于公务员体系一部分的**部门**（jabatan），以及大多数为拥有自身董事会的法定机构或政府公司的**机构**（agensi）。

| 财政部属下部门 | 功能 |
| --- | --- |
| 马来西亚国库（Treasury） | 该部门的核心机器 |
| 马来西亚皇家关税局（RMCD） | 间接税——销售与服务税（SST）、消费税、关税 |
| 马来西亚国家会计师局 | 政府会计与付款 |
| 产业估价与服务局（JPPH） | 政府房地产估价 |

| 财政部属下机构 / 法定机构 | 职能 |
| --- | --- |
| 马来西亚国家银行 | 中央银行；货币政策与银行监管 |
| 马来西亚证券委员会 | 资本市场监管 |
| 马来西亚交易所（Bursa Malaysia Berhad） | 股票交易所 |
| 内陆税收局（LHDN） | 直接税——所得税、印花税、产业盈利税（CKHT） |
| 雇员公积金局（KWSP） | 私人领域退休储蓄 |
| 退休基金（机构）（KWAP） | 公共领域退休金 |
| 马来西亚存款保险公司（PIDM） | 存款与回教保险的保险 |
| 国民储蓄银行（Bank Simpanan Nasional） | 储蓄银行 |
| 纳闽金融服务局（Labuan FSA） | 监管纳闽离岸金融中心 |
| 公共领域房屋融资局（LPPSA） | 公务员房屋贷款 |
| 浮罗交怡发展局（LADA） | 浮罗交怡区域发展（第423号法令下的法定机构） |

注：浮罗交怡发展局（LADA）依据《1990年浮罗交怡发展局法令》（第423号法令，Akta 423）设立为法定机构。财政部官方门户在行政上将其列入“部门”一组，与国库、关税局、国家会计师局及JPPH并列；但从法律上它是一个法定机构。

这里有两个机构因为都征税而最常被公众提及：**LHDN** 负责直接税，**关税局** 负责间接税。两者隶属同一部门，但属于各自独立的机构——参见 [LHDN](/government/lhdn) 与 [马来西亚皇家关税局](/government/rmcd-kastam)。

## 联邦财政预算案如何编制与通过？

财政预算案不是一场演讲；它是一个历时数月、最终以一部法律收尾的过程。国家预算办公室协调各部门提出的开支建议，财政与经济组预测收入与增长，财政部长在预算案日之前敲定立场。

它在国会的路径如下：

1. **提呈（预算案日）。** 财政部长在下议院提呈财政预算案演讲与**供应法案（Supply Bill）**。2026年财政预算案于2025年10月10日提呈。
2. **政策阶段。** 下议院就财政预算案整体进行辩论，随后表决通过政策阶段。
3. **委员会阶段。** 下议院逐个部门审议拨款。例如，就是在这个阶段，三个特定部门的拨款于2025年11月10日获得通过。
4. **上议院（Dewan Negara）。** 经下议院通过后，送交上议院。
5. **御准与供应法令。** 获御准后，成为授权该年度开支的供应法令（Akta Perbekalan）。

一项重要的宪法特点：供应法案属于**金钱法案**。这意味着只有一名部长可提呈，它必须从下议院开始，而上议院只能延搁它——不能阻止它。下议院在《联邦宪法》第67条与第68条（Perkara 67 dan 68）下的财政权力细节，见 [下议院](/government/dewan-rakyat) 与 [法案如何成为法律](/law/how-a-bill-becomes-law)。

## 2026年财政预算案的钱花到哪里去？

2026年财政预算案的总动员金额为4700亿令吉，高于2025年的4520亿令吉。这4700亿令吉并非全部是联邦政府的直接开支——它包括不经普通预算的政府相关投资公司（GLIC）投资及公私合作（PPP）项目。

| 组成部分 | 拨款 |
| --- | ---: |
| 行政开支 | 3382亿令吉 |
| 发展开支 | 810亿令吉 |
| **联邦核心预算** | **4192亿令吉** |
| GLIC投资 | 300亿令吉 |
| 公私合作（PPP） | 100亿令吉 |
| 联邦法定机构及财政部公司（MKD） | 108亿令吉 |
| **总动员金额** | **4700亿令吉** |

在收入方面，政府目标是2026年征收3431亿令吉，高于2025年估计的3341亿令吉。收入与开支之间的差距就是财政赤字，2026年目标为GDP的3.5%——低于2025年的3.8%目标。

## 联邦债务有多大，其上限为何？

当开支超过收入时，政府就借款来填补差距——多年累积的借款便成为联邦债务。债务对GDP的比率是最常被关注的指标。截至2026年3月底，该比率降至**GDP的63.1%**，低于2025年底的65.2%——这是连续数年收窄赤字的财政巩固的成果。

根据2026年财政预算案所列的数字，联邦财政赤字已逐步下降：2022年为GDP的5.5%、2023年为5.0%、2024年为4.1%，2025年目标为3.8%，2026年为3.5%。

政府不能随意借款。四项主要法令管控其借贷，各自有已宪报的工具与上限：

| 贷款法令 | 工具 | 法定上限 |
| --- | --- | --- |
| 1959年（地方）贷款法令 [Akta 637] | MGS、MGII | MGS + MGII + MITB 总额不超过GDP的65% |
| 1983年政府融资法令 [Akta 275] | MITB、市场贷款、项目贷款 | （包含在上述65% GDP上限内） |
| 1963年外债法令 [Akta 403] | 离岸外债 | 不超过350亿令吉 |
| 1946年（地方）国库券法令 [Akta 188] | MTB | 不超过100亿令吉 |

注：MGS为马来西亚政府证券；MGII为马来西亚政府投资债券（符合伊斯兰教义）；MITB为马来西亚伊斯兰国库券；MTB为马来西亚国库券。各法令的量化上限需对照法令文本与 Fiscal Outlook 2026（第4节）文件核实。

这些法令约束政府只能为资助发展开支及为现有债务再融资而借款——而非用于日常行政开支。联邦债务的大部分以令吉计价，取自国内资本市场；离岸外债始终远低于350亿令吉的门槛。

## 第850号法令要求什么？

在2024年之前，法定债务上限在《2020年政府融资（2019冠状病毒病（COVID-19））临时措施法令》下从GDP的60%暂时提高到65%，而 COVID-19 基金的上限也从650亿令吉提高到1100亿令吉，以资助疫情的刺激与经济复苏配套。作为后疫情改革的一部分，政府推出了**《2023年公共财政与财政责任法令》（第850号法令，Akta 850）**，于2024年1月1日起生效。

第850号法令改变了财政管理的报告与设限方式。它在其第一附表中以**量化数值**设定财政目标：

| 财政目标（第一附表，第850号法令） | 量化数值 |
| --- | ---: |
| 年度最低发展开支（占GDP%） | 3% |
| 财政平衡（占GDP%） | -3% |
| 债务水平（占GDP%） | 60% |
| 财政担保（占GDP%） | 25% |

第18(1)分节规定政府债务总额不得超过第一附表所列的GDP百分比——即中期目标60%。请注意这是第850号法令的**中期目标**，与个别贷款法令下仍然宪报的65%上限不同；当前的63.1%比率处于65%的法定上限内，同时朝60%的目标迈进。这四项财政目标——包括25% GDP的财政担保上限——应在三至五年的中期内实现。

第850号法令也设立了**财政政策委员会**（第28节）来监督财政政策的执行，并规定必须发布各种财政报表，包括财政风险报表。其目的，如该法令原则所述，是透明度与代际公平——使今天的借款不损害未来世代的福祉。

## 决策框架：您的事务该找哪个机构？

由于国家如此多的金融职能汇集于同一部门之下，公众常常联系错误的一方。请使用以下对照：

- **所得税、印花税、产业盈利税、电子发票（e-Invois）** → [LHDN](/government/lhdn)，而非直接找财政部。
- **销售与服务税（SST）、消费税、进口关税** → [马来西亚皇家关税局](/government/rmcd-kastam)。
- **政府付款与会计、联邦财务报表** → 国家会计师局。
- **私人领域退休储蓄（KWSP公积金缴款）** → 雇员公积金局。
- **银行存款保障** → 马来西亚存款保险公司（PIDM）。
- **资本市场投资、经纪投诉** → 马来西亚证券委员会。
- **货币政策、利率、银行监管** → 马来西亚国家银行。
- **整体财政预算案与财政政策** → 财政部（国库）。

## 常见误解

**“财政部征税。”** 该部门制定税务政策，但征收由其属下机构进行——LHDN 负责直接税，关税局负责间接税。将税务询问发送给该部门只会被转介。

**“2026年财政预算案的4700亿令吉全部是政府开支。”** 该金额是总动员，也涵盖 GLIC 投资与 PPP 项目。联邦核心预算——行政与发展开支——为4192亿令吉。

**“国债上限是60%。”** 第850号法令下GDP 60%的中期目标与贷款法令下仍然宪报的GDP 65%法定上限并非同一回事。当前比率可能介于这两个数字之间。

**“国家银行是国库的一部分。”** 国家银行是该部门属下的机构，但它是在运作上具自主权的中央银行。政策利率的决定由中央银行作出，而非财政部长。

**“财政预算案一经提呈即成为法律。”** 提呈只是开始。财政预算案必须经过下议院的政策阶段与委员会阶段，然后经上议院及御准，才能成为供应法令。
