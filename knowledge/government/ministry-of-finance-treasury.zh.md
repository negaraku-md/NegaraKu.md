    a: "联邦预算案通常在年度最后一季就翌年的财政年度提呈。2026年预算案由财政部长于2025年10月10日在下议院提呈。随后在政策阶段与委员会阶段进行辩论，才通过为供应法令（Akta Perbekalan）。"

联邦政府所花的每一令吉——从地区医院护士的薪水，到支付给伦敦债券持有人的利息——都经过同一道会计门户：马来西亚国库。财政部就是掌管那道门的部门，而自2024年初起，它是在一套载于法律的数值上限之下掌管着它。

本页说明该部门究竟做什么：预算案如何编制与通过、谁领导国库、国债有多大及其上限为何，以及哪些部门与机构隶属其下。

## 财政部究竟做什么？

财政部负责国家资产负债表的两端：进来的收入与出去的开支。它制定财政政策、编制联邦预算案、管理政府贷款的取得与偿还、掌管政府会计与国库，并监督其他部门、机关与法定机构的财务管理。

它也是国家金融体系的牵头部门。透过其下的机构，财政部监督直接与间接税务机关、资本市场、存款保险及公共部门融资。《2023年公共财政与财政责任法令》（第850号法令，Akta 850）——如今约束该部财政管理的法律——将此职权浓缩为负责任财政管理的四项原则：确保宏观经济稳定、达致可持续的财政平衡、维持审慎的债务水平，以及有效管理财政风险。

## 谁领导国库？

有两个层面的领导常被混淆。政治层面由财政部长领导——如今由首相本人兼任第一财政部长——并由第二财政部长拿督斯里阿米尔韩查及财政部副部长拿督刘镇东（于2025年12月17日接任）协助。公共服务层面由**国库秘书长**领导，这位高级官员领导马来西亚国库，并主持众多金融法定机构的董事会。

在国库秘书长之下有三位副秘书长——分管政策、管理与投资——监督国库的各核心部门。

| 国库核心部门 | 职能 |
| --- | --- |
| 国家预算办公室 | 编制与协调年度预算案 |
| 税务组 | 直接与间接税务政策 |
| 财政与经济组 | 财政分析、预测与目标 |
| 政府采购组 | 公共采购政策与治理 |
| 信用报告机构注册处 | 监管信用报告机构 |
| 法定机构策略管理组 | 监督法定机构 |

国库也管理沙巴与砂拉越的联邦国库，以及审理税务纠纷的所得税特别专员（Pesuruhjaya Khas Cukai Pendapatan）与关税上诉庭（Tribunal Rayuan Kastam）。

| 产业估价与服务局（JPPH） | 政府房地产估价 |

| MOF之下的机构 / 法定机构 | 角色 |
| --- | --- |

这里有两个机构最常被民众提及，因为两者都征税：**LHDN** 征直接税，**关税局** 征间接税。两者隶属同一部门，但是分开的机关——参见 [LHDN](/zh/government/lhdn) 与 [马来西亚皇家关税局](/zh/government/rmcd-kastam)。

## 联邦预算案如何编制与通过？

预算案不是一场演讲；它是一个历时数月、以一部法律告终的过程。国家预算办公室协调每个部门的开支建议，财政与经济组预测收入与增长，财政部长在预算案日之前敲定立场。

它在国会的路径如下：

1. **提呈（预算案日）。** 财政部长在下议院提呈预算案演辞与**供应法案（Supply Bill）**。2026年预算案于2025年10月10日提呈。
2. **政策阶段。** 议院就预算案整体进行辩论，然后投票在政策阶段通过。
3. **委员会阶段。** 议院逐个部门审查拨款。例如，三个特定部门的拨款便是在此阶段于2025年11月10日获得通过。
4. **上议院。** 经下议院通过后，送交上议院。
5. **御准与供应法令。** 获御准后，成为授权当年开支的供应法令（Akta Perbekalan）。

一项重要的宪法特征：供应法案属于**金钱法案**。这意味着仅一名部长可提呈，它必须在下议院发起，而上议院只能拖延——不能阻止。下议院在《联邦宪法》第67及68条之下的财政权力细节，见 [下议院](/zh/government/dewan-rakyat) 与 [法案如何成为法律](/zh/law/how-a-bill-becomes-law)。

## 2026年预算案的钱花到哪里去？

2026年预算案是总动员额RM470亿，高于2025年的RM452亿。RM470亿这个数字并非全是联邦政府的直接开支——它包括政府相关投资公司（GLIC）的投资，以及不经过一般预算的公私合作项目。

| 组成部分 | 拨款 |
| --- | ---: |
| 行政开支 | RM338.2亿 |
| 发展开支 | RM81.0亿 |
| **核心联邦预算** | **RM419.2亿** |
| GLIC 投资 | RM30.0亿 |
| 公私合作（PPP） | RM10.0亿 |
| 联邦法定机构及MKD公司 | RM10.8亿 |
| **总动员额** | **RM470.0亿** |

在收入端，政府为2026年设定征收RM343.1亿的目标，高于2025年的估计RM334.1亿。收入与开支之间的差距即为财政赤字，2026年目标定于KDNK的3.5%——低于2025年的3.7%。3.7%这个数字是2025年全年的实际成绩，优于原定的3.8%目标（2024年：4.1%）。

## 联邦债务有多大，其上限为何？

当开支超过收入时，政府便举债以填补差距——多年累积的贷款成为联邦债务。债务对KDNK的比率是最常被监测的指标。截至2026年3月底，该比率降至**KDNK的63.1%**，低于2025年底的65.2%——这是连续数年收窄赤字的财政巩固的成果。

联邦财政赤字已逐步下降：2022年为KDNK的5.5%、2023年为5.0%、2024年为4.1%、2025年为3.7%（实际数字，优于3.8%的目标），并为2026年设定3.5%的目标。

政府不能随意举债。四项主要法令管制其举债，各有其已宪报颁布的工具与上限：

| 举债法令 | 工具 | 法定上限 |
| --- | --- | --- |
| Loan (Local) Act 1959 [Akta 637] | MGS、MGII | MGS + MGII + MITB 总额不超过KDNK的65% |
| Government Funding Act 1983 [Akta 275] | MITB、Market Loans、Project Loans | （包含在上述65% KDNK的上限内） |
| External Loans Act 1963 [Akta 403] | 离岸外部贷款 | 不超过RM35亿 |
| Treasury Bills (Local) Act 1946 [Akta 188] | MTB | 不超过RM10亿 |

注：MGS 为马来西亚政府证券；MGII 为马来西亚政府投资发行（符合伊斯兰教义）；MITB 为马来西亚伊斯兰国库券；MTB 为马来西亚国库券。这三项法令的数值上限载于 Fiscal Outlook 2026（第4节，第151页图1及第161页表4.2），其中亦记录了2025年6月底的实际数字：MGS+MGII+MITB 的法定债务为KDNK的63.5%、离岸外部贷款RM22.8亿、MTB RM2亿——全部在上限之内。

这些法令约束政府仅可为资助发展开支及为现有债务再融资而举债——不可用于日常行政开支。联邦债务的绝大部分以令吉计价并取自国内资本市场；离岸外部贷款仍远低于RM35亿的门槛。

## 第850号法令要求什么？

在2024年之前，法定债务上限曾根据《2020年政府融资临时措施（2019冠状病毒（COVID-19））法令》从KDNK的60%暂时上调至65%，而 COVID-19 基金的上限也从RM65亿上调至RM110亿，以资助疫情期间的经济刺激与复苏配套。作为疫后改革的一部分，政府推出**《2023年公共财政与财政责任法令》（第850号法令，Akta 850）**，于2024年1月1日生效。

第850号法令改变了财政管理的报告与限制方式。它在其第一附表中以**数值**衡量并订立财政目标：

| 财政目标（第一附表，第850号法令） | 数值 |
| --- | ---: |
| 年度最低发展开支（% KDNK） | 3% |
| 财政平衡（% KDNK） | -3% |
| 债务水平（% KDNK） | 60% |
| 金融担保（% KDNK） | 25% |

第18(1)分节规定，政府债务总额不得超过第一附表所列的KDNK百分比——即60%的中期目标。请注意，这是第850号法令的**中期目标**，有别于各项个别举债法令之下仍宪报颁布的65%上限；目前63.1%的比率在65%的法定上限之内，同时朝着60%的目标迈进。这四项财政目标——包括25% KDNK的金融担保上限——应在三至五年的中期内达成。

第850号法令也设立了**财政政策委员会**（第28节）以监督财政政策的执行，并规定发布多项财政报表，包括财政风险报表。如其法令原则所述，其目的在于透明度与代际公平——使今日的举债不损害未来世代的福祉。

## 决策框架：您的事务该找哪个机构？

由于国家如此众多的金融职能汇集于同一个部门之下，民众常常联系错对象。请使用以下对应：

- **所得税、印花税、产业盈利税、e-Invois（电子发票）** → [LHDN](/zh/government/lhdn)，而非直接找财政部。
- **销售与服务税（SST）、消费税、进口关税** → [马来西亚皇家关税局](/zh/government/rmcd-kastam)。
- **政府付款与会计、联邦财务报表** → 会计总长署。
- **私人界退休储蓄（KWSP 缴纳）** → 雇员公积金局。
- **银行存款保障** → 马来西亚存款保险公司（PIDM）。
- **资本市场投资、经纪投诉** → 马来西亚证券委员会。
- **货币政策、利率、银行监管** → 马来西亚国家银行。
- **整体预算与财政政策** → 财政部（国库）。

## 常见误解

**「财政部征税。」** 该部制定税务政策，但征收工作由其下的机构进行——LHDN 征直接税，关税局征间接税。把税务查询寄给该部只会被转介。

**「2026年预算案的RM470亿全是政府开支。」** 该总额是总动员额，也涵盖 GLIC 投资与 PPP 项目。核心联邦预算——行政与发展开支——为RM419.2亿。

**「国债上限是60%。」** 第850号法令之下60% KDNK的中期目标，与举债法令之下仍宪报颁布的65% KDNK法定上限并不是同一回事。目前的比率可能介于这两个数字之间。

**「国家银行是国库的一部分。」** 国家银行是该部之下的机构，但是运作上具自主权的中央银行。政策利率的决定由中央银行作出，而非财政部长。

**「预算案一经提呈即成为法律。」** 提呈只是开始。预算案必须经下议院的政策阶段与委员会阶段，再经上议院与御准，才成为供应法令。
