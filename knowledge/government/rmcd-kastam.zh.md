answer: "RMCD（Jabatan Kastam Diraja Malaysia），即大马关税局，是隶属财政部的一个联邦部门，管理马来西亚的间接税与边境事务。它征收进口税与出口税、消费税、销售税、服务税、旅游税与离境税，并在港口、机场与陆路关卡执行 Customs Act 1967。所得税、印花税与产业盈利税不属于它的业务范围——那些归 LHDN 管辖，一个隶属同一部门的独立法定机构。"
keyTakeaways:
  - "是联邦部门，不是法定机构——财政部把 Kastam 列在其部门之下，把 LHDN 列在其机构之下"
  - "间接税与边境事务：关税、消费税、销售税、服务税、旅游税、离境税、暴利税"

faq:
  - q: "Kastam 征收所得税吗？"
    a: "不。RMCD 管理的是间接税——针对货物、服务与跨境流动课征的税项。所得税、石油所得税、产业盈利税与印花税则由 LHDN 依各自独立的法令管理。两者隶属同一个部门，这正是它们如此常被混淆的原因，但它们是两个不同的机构，各有不同的法令、不同的注册编号与不同的申报系统。"
  - q: "RMCD 是 LHDN 的一部分吗？"
    a: "不是，而且这个差异是结构性的。RMCD 是一个联邦政府部门，其人员编制隶属公共服务体系，由一名关税总监领导。LHDN 则是由国会自身立法设立的法定机构。财政部把两者列在不同的类别之下——Kastam 归部门类，LHDN 归机构类。"
  - q: "我该到哪里查一项产品的税率？"
    a: "在经宪报颁布的 Customs Duties Order 里查，而不是在指南文件里。RMCD 发布了 ezHS 税则查询平台，让你按 HS 编码或说明，对照现行的 Customs Duties Order 以及马来西亚各项自由贸易协定的优惠税表进行搜寻。税率取决于税则编码，若是优惠税率，还取决于原产地证明。"

两个机构，一个部门，还有一条几乎没有人第一次就能划对的界线。如果那项税
附着于**跨越边境的物品、离开工厂的货物，或被提供的服务**，那是 Kastam 的
事。如果它附着于**收入、盈利或文书**，那是 LHDN 的事。

## 一览

| | |
| --- | --- |
| 全名 | Jabatan Kastam Diraja Malaysia／Royal Malaysian Customs Department |
| 类型 | 联邦政府部门 |
| 汇报对象 | 财政部——被列在该部的部门之下，而非机构之下 |
| 首长 | 关税总监（Director General of Customs） |
| 总部 | No. 3, Persiaran Perdana, Presint 2, 62596 Putrajaya |
| 厅（Division） | 关税、国内税务、执法、合规管理、技术服务与法务等 |
| 培训机构 | Akademi Kastam Diraja Malaysia（AKMAL） |
| 网站 | `customs.gov.my` |

## 它管理什么

| 法令 | 事项 |
| --- | --- |
| Customs Act 1967 (Act 235) | 边境的进出口税、申报、估价、扣押与检控 |
| Excise Act 1976 (Act 176) | 消费税与发照——机动车辆、酒类、烟草及其他应课消费税货物 |
| Sales Tax Act 2018 (Act 806) | 对在马来西亚制造的应税货物及进口货物课征的单阶段销售税 |
| Service Tax Act 2018 (Act 807) | 对指定应税服务课征的单阶段服务税 |
| Free Zones Act 1990 (Act 438) | 自由商业区与自由工业区 |
| Tourism Tax Act 2017 (Act 791) | 对住宿课征的旅游税 |
| Departure Levy Act 2019 (Act 813) | 对经航空离开马来西亚课征的离境税 |
| Windfall Profit Levy Act 1998 (Act 592) | 对指定商品的暴利课征的暴利税 |

销售税与服务税都在**2018 年 9 月 1 日**生效，取代了 GST。两者是各自独立
的法令，各有独立的注册测试——见[SST 详解](/zh/taxation/sst-explained)。

## 与 LHDN 的分工，一张表看懂

两者都隶属财政部。相似之处仅止于此。

| 你的问题 | 由谁解答 |
| --- | --- |
| 我公司利润的税 | [LHDN](/zh/government/lhdn) |
| 我开立发票上的服务税 | RMCD |
| 一批货物的进口税 | RMCD |
| 向外国供应商支付的预扣税 | LHDN |
| 租赁协议的印花税 | LHDN |
| 一辆汽车的消费税 | RMCD |
| 出售店屋的产业盈利税 | LHDN |
| 酒店收取的旅游税 | RMCD |
| 机票上的离境税 | RMCD |
| 电子发票的提交 | LHDN |

在职能差异之下，还有一个结构性的差异。**RMCD 是一个部门**——隶属联邦公共
服务体系，由一名关税总监领导。**LHDN 是一个法定机构**，由其自身的法令设
立。财政部把 Kastam 列在*部门*之下，把 LHDN 列在*机构*之下，而这个分类正
是区分两者最清楚的方式。

## 它营运的平台

- **MySST**——销售税与服务税的注册、申报与缴付，以及经宪报颁布的 Order、
  条例与政策声明。
- **ezHS（JKDM HS Explorer）**——按 HS 编码或说明查询税则，涵盖现行的
  Customs Duties Order，以及马来西亚各项自由贸易协定（ATIGA、ACFTA、
  AANZFTA、RCEP 等）的优惠税表。
- **MyTTx**——马来西亚旅游税系统。
- **MyDLV**——离境税申报。
- **税务印花系统（TMS）**——应课消费税货物的税务印花。
- **MNTR**——Malaysia National Trade Repository，用于贸易措施与程序。

## 两件容易让人栽跟头的事

**税率是经宪报颁布的，不是发布出来的。** 关税税率由一份 Customs Duties
Order 订定，服务税税率则由一份 Rate of Tax Order 订定。各平台上的指南文
件与 FAQ 页面只是说明；P.U.(A) 那份法律文书才是法律本身。两者不一致时，
以宪报为准。

**执法与评税是同一个机构。** 为你放行货件的官员，和审计你 SST-02 申报表
的官员，隶属同一个部门，依据的是带有扣押与检控权力的法令。这与直接税那一
边不同——那边的评税与执法遵循的是民事追讨模式。

## 下一步

在你去找表格之前，先弄清楚你的义务落在哪一边。如果是 Kastam 的事，就从
[SST 详解](/zh/taxation/sst-explained)开始——针对你所提供的服务与货物；
或者到 ezHS 查询你所进口的任何东西。如果是收入、盈利或文书方面的问题，
那就改到 [LHDN](/zh/government/lhdn)。
