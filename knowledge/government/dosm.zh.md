几乎每一个你会读到的马来西亚经济数字——部长引用的增长率、新闻标题里的通胀
数字、银行研究报告里的失业率——都源自布城的同一栋大楼。了解那栋大楼如何
运作，能让你从一个只会复述数字的人，变成一个能够核实数字的人。

## 一览

| | |
| --- | --- |
| 全名 | Jabatan Perangkaan Malaysia／Department of Statistics Malaysia |
| 类型 | 联邦政府部门 |
| 上级部门 | 经济部 |
| 授权法令 | Statistics Act 1965（Act 415，统计法令），1989年修订版 |
| 御准／生效 | 1965年6月22日／1965年8月16日 |
| 部门首长 | Ketua Perangkawan Malaysia（Chief Statistician Malaysia，首席统计官） |
| 总部 | Block C6 & C7, Complex C, Federal Government Administrative Centre, 62514 Putrajaya |
| 网站 | `dosm.gov.my`（门户网站）、`open.dosm.gov.my`（开放数据） |

该部门的历史可追溯至1965年之前：它于1949年在 Statistics Ordinance 1949
（统计条例）之下成立为 Bureau of Statistics（统计局），当时职能仅限于对外
贸易与庄园农业，1965年在新法令之下才取得现名。该法令本身于1975年经过修
订，1989年12月28日获得修订版本，编号为 Act 415，并于2001年及2006年重印。
DOSM 在每个州属都设有州办事处。

## 如何在数字成为新闻之前就知道它

这是大多数人忽略的部分。**DOSM 会提前公布其发布日期。** Advance Release
Calendar（提前发布日历）列出每一项已排期的出版物及其发布日期，发布当天还
会向媒体发出附有指定解禁时间的新闻稿。

它不只是一个网页。同样的内容也是一个结构化数据集（`arc_dosm`），当中载有
出版物编号、发布时间戳、英文与马来文标题、类别、频率及参考期间。你可以通
过以下方式取得：

- **CSV 或 Parquet** ——供分析使用。
- **可订阅的 Google 日历** ——发布日期会出现在你自己的日历中。
- **iCalendar `.ics` 文件** ——供其他任何日历应用程序使用。
- **API 调用**，透过 `data.gov.my`——文档见于 `developer.data.gov.my`。

为了解典型一个月的情况，以下是 DOSM 为2026年7月排定的发布：

| 日期 | 发布内容 |
| --- | --- |
| 7月1日 | 按州属划分的GDP，2025年 |
| 7月9日 | 工业生产指数，2026年5月 |
| 7月9日 | 月度制造业统计，2026年5月 |
| 7月17日 | 消费者价格指数，2026年6月 |
| 7月17日 | GDP预估数据，2026年第二季 |
| 7月20日 | 月度对外贸易统计，2026年6月 |
| 7月24日 | 马来西亚经济指标，2026年5月 |

这张表反映出两件事。月度价格与贸易数据大约在参考月份结束后两到三周内发
布，而生产指数的滞后期则更长。而2026年第二季的GDP预估数据于7月17日发布，
实际GDP发布则排定在8月14日——这四周的间隔期间，初步数字广泛流传，随后才
悄然被修订。

## 引用 DOSM 数据时的常见错误

- **把预估数据当作GDP数字来引用。** 它只是初步数据。若完整发布已经存在，
  应改为引用完整发布。
- **混淆月度与季度劳动力数据。** DOSM 两者都发布，它们是参考期间不同的不
  同产品。
- **把仪表板当作数据来源。** 仪表板会更新。应引用有日期标注的出版物或数
  据集，并记录你查阅的日期。
- **假定门户网站的链接是永久性的。** DOSM 自2026年5月1日起将数码发布作为
  其主要发布渠道，此前也曾迁移过门户网站版本。请将你所依赖的 PDF 存档。
- **未注明出处就重复使用数据。** OpenDOSM 的数据集采用 CC BY 4.0 授权——
  可以自由重复使用，但注明出处是一项条件，而不是礼貌之举。

## 数据在哪里

| 渠道 | 最适合用于 |
| --- | --- |
| `dosm.gov.my` | 有日期标注的发布、技术说明、发布日历 |
| `open.dosm.gov.my` | 仪表板与机器可读数据目录 |
| `data.gov.my` | 涵盖 DOSM 在内的全政府开放数据门户 |
| `developer.data.gov.my` | 供程序化访问的API文档 |

该目录本身涵盖人口统计、家庭与收入、国民账目、价格、劳动市场、教育、环境
及各经济部门——当中有若干数据集来自其他机构而非 DOSM，因此在将某个数字归
于该部门之前，应先查核数据来源说明。
