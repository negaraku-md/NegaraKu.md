多数关于PDRM的介绍，止步于「国家警察部队」这一说法。更有用的问题应该更加
具体：法令究竟准许这支部队做什么、谁掌握对它的指挥权，以及哪个机构决定其
成员的委任与纪律事宜？

## 概览

| | |
| --- | --- |
| 全称 | 皇家马来西亚警察部队（Polis Diraja Malaysia） |
| 设立法令 | 《1967年警察法令》（第344号法令）第三部分 |
| 前身部队 | 根据《1963年皇家马来西亚警察法令》设立的皇家马来西亚警察部队，由s.3(1)延续 |
| 部队首长 | 总警长（Inspector-General of Police），依据s.4设立 |
| 负责对象 | 部长（负责警务事务的部长） |
| 名誉总司令 | 最高元首（Yang di-Pertuan Agong），依据s.6A |
| 人事机构 | 警察部队委员会，联邦宪法第140条 |
| 网站 | `rmp.gov.my` |

第344号法令并非从零设立这支部队。s.3(1)规定，凡在本法令生效之前，根据
《1963年皇家马来西亚警察法令》成为皇家马来西亚警察部队成员者，须以「相应
的职级并以相应的身份」成为新法令下该部队的成员。因此，1967年法令是对一支
已经存在的部队进行重组与巩固。

## 部队的五项目的

PDRM的核心职能载于单一条文——s.3(3)。该条文规定，在符合本法令的前提下，
该部队须在马来西亚境内及全境（包括其领海）使用，以实现五项目的：

- 维护法律与秩序；
- 维护马来西亚的安宁与安全；
- 预防与侦查罪案；
- 逮捕与检控罪犯；以及
- 收集治安情报。

政府官方门户网站（malaysia.gov.my）列出了相同的职能，并将s.3(3)列为其法律
依据。「境内及全境」这一范围十分重要：它标志着这是单一的联邦部队，而非按
州属分设的部队。

## 指挥体系

PDRM的指挥架构由两个须一并阅读的条文所设定——s.4（部队的管控）与s.5
（委任）。

s.4(1)将该部队「置于一名总警长的指挥之下」，总警长必须是一名警官，并须
「向部长负责」，负责该部队及所有其他获委任执行警务职务人员的管控与指挥。
总警长持有赋予总监或警察总长的一切权力。

在总警长之下，s.4(2)规定委任一名副总警长，副总警长受总警长指挥；s.4(3)
则赋予该副总警长总监或警察总长的一切权力。s.4(4)进一步准许总警长的
行动——在遵从其指示的前提下——由副总警长、总监、副总监、高级助理总监，
或获授权的助理总监执行。

s.5列出为执行本法令目的而可委任的职位：

| 层级 | s.4–5中的示例职位 |
| --- | --- |
| 最高指挥层 | 总警长；副总警长 |
| 高级警官 | 总监；副总监；高级助理总监；助理总监 |
| 执行层 | 高级警官及其他初级警官；警员 |

高级警官与初级警官的具体职级，则依据s.5(2)列于该法令的第一附表（First
Schedule）。

在州属及编制层级，s.6规定该部队成员由部长所决定区域或州属的总监或警察
总长管辖，并由总警长指定的官员管辖任何编制、警区或分区。

一项象征性条文补全了这一架构：s.6A将最高元首（Yang di-Pertuan Agong）
定为皇家马来西亚警察部队的名誉总司令（Panglima Besar Kehormat，Honorary
Commissioner-in-Chief）。有关最高元首角色的宪法背景，参见
[最高元首](/zh/government/yang-di-pertuan-agong)。

## 法律准许警务人员做什么

s.20规定了警务人员的一般职责。s.20(1)要求每位警务人员履行法律所赋予的
职责并行使相关权力，并遵从其上级警官的一切合法指示。

s.20(3)接着规定，警务人员的职责是执行s.3(3)所述的各项目的，并列出属于
该职责范围内的合法措施：

- 逮捕依法获授权逮捕的所有人；
- 处理治安情报；
- 进行检控；
- 协助执行与税收、货物税、卫生、检疫、移民及登记相关的法律；
- 协助维持港口、船坞及机场的秩序；
- 执行依法发出的传票、传唤令、拘捕令及其他命令；
- 保护无人认领及遗失的财物；
- 协助保护生命与财产；
- 出席刑事法庭（若受特别指示，亦包括民事法庭）并维持庭内秩序；以及
- 押解及看管囚犯与其他被警方拘留的人。

这里有两点值得留意。第一，检控权是所列职责之一——尽管在许多事项上，
检控的决定权依据其他法律归属于公共检控官（Public Prosecutor）（作为权力
架构的比较，可参见[SPRM](/zh/government/macc-sprm)如何负责调查，但须将
案件转介公共检控官）。第二，s.20(4)规定，警务人员在押解囚犯时，须被视为
监狱官员，并具有监狱官员的权力与保障。

这些职责中有许多与其他执法机构相互交叉——例如，与移民及登记相关的部分，
涉及[移民局](/zh/government/imigresen)的工作；而出席法庭并维持庭内秩序的
职责，则与[法院体系](/zh/government/kehakiman-mahkamah)相关。

## 谁负责委任与考核成员

这是常被忽略的部分。PDRM主导自身的行动，但并非独立自主地处理其成员的
人事事务。联邦宪法第140条设立了一个**警察部队委员会（Police Force
Commission）**，负责警察部队成员的委任、确认、纳入常任或可享退休金编制、
晋升、调职及纪律管制事宜。

根据内政部（Kementerian Dalam Negeri）资料，该委员会由以下成员组成：

| 委员会成员 | 职位 |
| --- | --- |
| 负责警务事务的部长 | 主席 |
| 总警长 | 委员 |
| 部门秘书长 | 委员 |
| 一名由最高元首委任的公共服务委员会（Public Services Commission）成员 | 委员 |
| 不少于二名、不多于六名由最高元首委任的其他成员 | 委员 |

内政部指出，委员会的部分职能已透过2000年12月14日颁布的P.U.(B) 441号宪报，
转授予总警长及高级警官。这种分工意味着，成员的委任与纪律事宜由一个法定
机构负责，而非完全掌握在部队本身的行动领导层手中。有关更广泛的宪法依据，
参见[联邦宪法](/zh/law/federal-constitution)。

## 辅助部队

除常规部队外，《1967年警察法令》还设立了若干在同一框架下执行警务职责的
辅助机构，其中包括皇家马来西亚警察志愿后备队（Volunteer Reserve）、辅助
警察（Polis Bantuan，Auxiliary Police）、额外警察人员（Extra Police）、
皇家马来西亚警察后备队，以及皇家马来西亚警察学警团（Police Cadet Corps）。
政府门户网站亦将这些辅助团体列为协助普通任务部队维护公共治安的力量。

## 在政府架构中的定位

由于总警长根据s.4(1)须向部长负责，PDRM归属于负责警务事务的部长——即
[内阁](/zh/government/kabinet-perdana-menteri)架构中的内政部长——的职权
范围。然而，警务人员的日常权力源自本法令及其他法律，而非来自政治指示：
s.20将警务人员的职责限定为「法律所赋予」的职责，以及部队内其上级警官所
发出的合法指示。
