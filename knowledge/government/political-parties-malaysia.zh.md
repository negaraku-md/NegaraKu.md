在马来西亚，一个政党并非始于国会，也非始于竞选舞台。它始于社团注册局
柜台上的一张表格——因为从法律上说，政党是一种*社团*，就如同一个俱乐部
或协会一样。

本页以描述性、公正的方式说明三件事：政党如何注册、主要联盟有哪些，
以及选举结果如何转化为一个政府。本页不支持任何政党或联盟，也不评价
任何人的政策。

## 概览

| | |
| --- | --- |
| 政党注册 | 依据《1966年社团法令》（第832号法令）作为社团 |
| 主管机构 | 社团注册局（Registrar of Societies, ROS） |
| "政党"的定义 | 于《1966年社团法令》的释义部分中界定 |
| 注册流程 | 申请 → 准予或拒绝注册的决定 → 注册证书 |
| 政府组成 | 《联邦宪法》第43(2)(a)条 |

## 政党如何注册？

马来西亚没有单独的"政党法令"。相反，政党依据**《1966年社团法令》**
注册——该法令的完整名称说明它"与社团注册相关"。现行版本为第832号
法令（2021年修订），于2021年11月15日公布，并于2021年12月1日生效。

该法令对政党作出了具体的定义。在其释义部分，"政党"被定义为任何其宗旨
或方法规定该社团通过其候选人参与下议院、州立法议会或任何地方政府选举
的社团。换言之，使一个社团在法律上成为"政党"的，并非其名称，而是其
在选举中提名候选人的意图。

注册本身遵循与其他任何社团相同的流程：

1. **申请。** 社团连同其章程或规则，向社团注册局申请注册。
2. **注册或拒绝。** 注册局可依据法令所规定的理由，注册该社团或拒绝
   其注册。
3. **注册证书。** 成功注册的社团获颁注册证书。

一旦注册，社团必须依照其本身的章程行事。法令也规定在特定情况下可
**撤销与暂停注册**。管理所有这些程序的机构是马来西亚社团注册局，
即一般所称的社团注册局（ROS）。

这一框架意味着两件常被混淆的事情实则相互分离：**政党注册**由《1966年
社团法令》管辖并由ROS负责，而**选举的进行**——提名、投票与计票——则
由宪法及选举法律管辖，并由选举委员会（SPR）负责。两个机构，两种职责。

## 何谓联盟（coalition），它与政党有何不同？

大多数政党并不单独参选。它们集结成*联盟*——多个政党同意共同参选的
组合，通常在一个共享的选举标志之下，并按照约定分配议席，以免其候选人
彼此对撞。

其区别可概括如下：

- **政党**拥有自己的成员、章程与领导层，并单独注册。
- **联盟**是政党成员之间的合作协议。它也可依据同一法令注册为社团，
  但其成员党仍保持为独立的实体。

一名候选人通常是某成员党的党员，但在联盟的标志下参选。

## 今日的主要联盟有哪些？

当政党加入或退出某个阵营时，联盟版图会随时间而改变。截至本页撰写之时，
主要的联邦联盟包括以下各个。下方成员党名单为简略列举，并非详尽无遗。

| 联盟 | 部分成员党 | 简要说明 |
| --- | --- | --- |
| **国民阵线（国阵，BN）** | 巫统（UMNO）、马华（MCA）、国大党（MIC） | 成立已久的联邦联盟之一 |
| **希望联盟（希盟，PH）** | 公正党（PKR）、行动党（DAP）、诚信党（Amanah） | 在第15届全国大选（2022）中赢得最多议席的阵营 |
| **国民联盟（国盟，PN）** | 土团党（Bersatu）、伊斯兰党（PAS）、民政党（Gerakan） | 参与第15届全国大选（2022）的联盟 |
| **砂拉越政党联盟（GPS）** | 由土保党（PBB）领导，连同其他政党 | 以砂拉越为基地的联盟 |
| **沙巴人民联盟（GRS）** | 以沙巴为基地的政党 | 以沙巴为基地的联盟 |

也有一些政党在这些大联盟之外参选，包括如沙巴的民兴党（Warisan）等
地区性政党，以及其他独立参选或在较小联盟中参选的政党。

## 投票结果如何转化为政府？

选民为其选区选出议员；这些议员随后决定由谁执政。《联邦宪法》
**第43(2)(a)条**规定，最高元首委任一名"依其圣意可能获得下议院多数
议员信任"的下议院议员为首相。

关键在于*多数信任*这一措辞。由于下议院有222个议席，简单多数意味着
至少**112席**。当一个联盟赢得112席或以上时，组成政府的途径通常清晰
明了。当没有任何联盟达到该门槛时——即所谓的**悬峙国会**——数个联盟
可以协商以共同形成多数。

## 第15届全国大选（2022）之后发生了什么？

第15届全国大选于2022年11月19日举行，产生了悬峙国会：没有任何联盟
达到112席。根据MalaysiaNow所公布的官方计票板，希望联盟以81席取得最大
阵营，其次为国民联盟（74席）、国民阵线（30席）、砂拉越政党联盟（23席）、
沙巴人民联盟（6席），以及其他若干政党。（在初期阶段，确切数字因若干
议席被展延并稍后计算而略有出入——见核实说明。）

由于没有任何单一阵营能够独自执政，进程转向了协商。最高元首苏丹阿都拉
（Al-Sultan Abdullah）与马来统治者商议后，呼吁组建一个结合一个以上
阵营的**团结政府**。2022年**11月24日**，安华·依布拉欣依据宪法第
40(2)(a)条及第43(2)(a)条获委任为马来西亚第10任首相，领导一个将希望
联盟连同国民阵线、砂拉越政党联盟、沙巴人民联盟及其他若干方联合起来的
团结政府。

这一安排体现了马来西亚制度的一个特点：由于首相是根据下议院的*信任*
获委任，而非通过直接投票，执政联盟可以在投票日之后，通过政党与联盟
之间的协议而形成。

## 常见误解

**"选民直接投票选首相。"** 并非如此。选民只为其选区选出议员；第43(2)(a)
条将首相的委任交予最高元首，依据下议院多数议员的信任而定。

**"政党与联盟是同一回事。"** 政党是拥有自己成员的单一社团；联盟则是
多个共同参选的政党之间的合作。

**"马来西亚有单独的政党法令。"** 政党依据《1966年社团法令》作为社团
注册，而非依据某个专门的政党法令。

**"执政联盟必定是赢得最多议席的联盟。"** 决定性的是下议院多数议员的
信任。即使没有任何一个联盟单独取胜，数个联盟也可以联合起来形成多数。
