土地是州事项。伊斯兰家庭法是州事项。地方政府是州事项。但究竟是谁在一个州属真正通过有关这些事项的法律，又依循什么规则？答案并非仅止于惯例或做法——它逐节写明在联邦宪法末尾的一份附表之中。

那份附表就是**第八附表**，通往它的入口则是**第71条**。本页以描述性方式说明这两者对**州立法议会（Dewan Undangan Negeri，DUN）**所作的规定：它如何组成、能维持多久，以及宪法容许它做些什么。

## 概览

| | |
| --- | --- |
| 名称 | 州立法议会（Dewan Undangan Negeri，State Legislative Assembly） |
| 类型 | 州属的立法机关，单一议院 |
| 宪法依据 | 第71条；联邦宪法第八附表第一部分 |
| 组成 | 统治者与一院，即DUN（第3条） |
| 议员组成 | 民选议员，人数由州法律订定（第4条） |
| 合资格年龄 | 不低于18岁（第5条，经Undi18修正） |
| 最长任期 | 自首次开会起五年（第9(3)条） |
| 主持官员 | 议长（Yang di-Pertua）（第10条） |
| 州政府首长 | 州务大臣／首席部长，领导州行政议会（第2条） |

## 第71条：为何每个州属都必须设有DUN

马来西亚是由13个州组成的联邦。第71条并不容许每个州随意组成自己的立法机关。相反，第71(4)条规定，如果某州的宪法未载有**第八附表第一部分**所列——即所谓**「基本条文」**——的条文，或本质上相同的条文，国会可制定法律使该等基本条文在该州生效。

其效果是形成一套共同的框架。每个州各自撰写自己的宪法，但DUN的核心骨架——组成、任期、议员资格、法律如何通过——则由第八附表统一规范。以下各节将逐一梳理这些核心条文。

## 组成：统治者与一院

第八附表第3条以一句话订明：州立法机关由**统治者与一院组成，即Dewan Undangan Negeri**。换言之，「州立法机关」并非仅指由民选议员组成的议院；它涵盖统治者，因为法案唯有经御准后方能成为法律（见下文第11条）。

第4(1)条则规定，DUN由**该立法机关本身透过法律所订定人数的民选议员**组成。这与[下议院（Dewan Rakyat）](/zh/government/dewan-rakyat)形成重要对比——下议院的议席数目（222）直接载于联邦宪法第46条文本之中。就DUN而言，联邦宪法并未订定数目——每个州透过州法律自行订定其议席数目，而这一数目因州而异。

## 议员的资格与丧失资格

第5条订明基本资格：每一名**年龄不低于18岁**、居住于该州的**公民**，只要未依宪法或法律丧失资格，即有资格成为DUN议员。此年龄限制原为21岁；经**Akta Perlembagaan (Pindaan) 2019**——即所谓Undi18——降低为18岁，该法案自**2021年12月15日**起生效，而该修正案也触及第八附表第5条，并不仅限于下议院。

第6条列出丧失资格的理由——其中包括精神不健全、未获解除的破产人、担任有收益的职位、因罪行被定罪并被判处不少于一年监禁或不少于RM2,000罚款，以及自愿取得外国国籍。第7条则加上一项简单规则：任何人不得同时担任一个以上选区的DUN议员。

## 任期、召集与解散

第9条规范DUN的整个生命周期：

- **第9(1)条**——统治者须不时召集DUN，且**不得让六个月过去**而不召开由一个会期最后一次开会至下一会期首次开会之间的会议。
- **第9(2)条**——统治者可**中止（prorogue）或解散**DUN。
- **第9(3)条**——DUN除非提早解散，否则自其首次开会之日起**持续五年**，其后自动解散。
- **第9(4)条**——DUN一旦解散，须在**60天**内举行大选，新召集的DUN须不迟于解散之日起**120天**内开会。
- **第9(5)条**——意外出缺须在**60天**内填补，但须受与下议院所适用者相似的两年但书所限。

须留意的是，解散DUN的决定并非纯粹属于例行事务。第八附表第1(2)(b)条将**「不批准解散Dewan Undangan Negeri的请求」**列为统治者可依其酌情权行使的职能之一。

## 议长与立法权

第10条规定，DUN须选出一名**议长（Yang di-Pertua）**，而在该职位悬空期间，除选出议长外不得处理任何其他事务。依第10(1A)条与第10(1B)条，非DUN议员之人亦可获选为议长，惟其须符合成为议员的资格——在此情形下，他成为额外议员，但无投票权。

一项州法律如何形成，载于第11条：

1. **第11(1)条**——立法机关的立法权透过**DUN通过并经统治者御准的法案**行使。
2. **第11(2)条**——涉及从州统一基金支出的法案或修正案，只能由**州行政议会议员**提出。
3. **第11(2A)条**——统治者须在法案呈交后**30天**内予以御准。
4. **第11(2B)条**——若在该期限内未获御准，该法案在**30天期限届满时即成为法律**，犹如已获御准一般。
5. **第11(3)条**——法案经御准后即成为法律，但**任何法律在公布之前均不得生效**。

以此方式由DUN通过的法律，通常称为**Enakmen（州法令）**（在砂拉越则称为**Ordinan（州条例）**）。

## 对州财政的权力

第14条要求统治者就每一财政年度，将**该州收支预算的报表**——即州属的财政预算案——呈交DUN。该预算须将由统一基金负担的支出与其他拟议支出分开列明。以此方式，动用州属资金的权力须取决于DUN的同意。

## 州政府对DUN负责

第八附表第2条将DUN与该州的行政机关——即**州行政议会**（Executive Council，或EXCO）——连结起来：

- 第2(2)(a)条——统治者须首先委任一名**依其判断可能获得该议院多数议员信任**的DUN议员出任**州务大臣**。
- 第2(2)(b)条——依州务大臣的意见，统治者从DUN议员当中委任**不超过十名、不少于四名**的其他成员。
- 第2(5)条——州行政议会须**对DUN集体负责**。
- 第2(6)条——若州务大臣不再获得DUN多数议员的信任，则除非应其请求，统治者将DUN解散，否则他须辞去州行政议会的职务。

在设有首席部长而非州务大臣的州属，该称谓在宪法之下所指的意义相同。

## DUN的特权及其与联邦的关系

第72条保障DUN的内部程序。第72(1)条规定，**DUN中任何程序的效力，不得在任何法院受到质疑**，而第72(2)条则赋予议员就其在DUN程序中所发表的言论或所投的票，免受法院追究的豁免权。

DUN立法权的范围，则取决于[第九附表](/zh/government/federal-state-division)所定的权力划分。第73(b)条容许州立法机关就该州全部或部分地区制定法律；第74(2)条将其限于**州清单**与**共同清单**所列事项；第75条则规定，若州法律与联邦法律不符，**联邦法律优先适用**，州法律在不符的范围内失效。

## 没有统治者的州属

九个州属拥有统治者：柔佛、吉打、吉兰丹、森美兰、彭亨、霹雳、玻璃市、雪兰莪与登嘉楼。其余四个州属——**槟城、马六甲、沙巴与砂拉越**——没有统治者。第160条将**州元首（Yang di-Pertua Negeri）**定义为没有统治者的州属之元首。在这些州属中，第八附表基本条文赋予「统治者」的职能——召集与解散DUN、御准法案、委任州务大臣——均由州元首行使。

亦须留意，第160条中「Dewan Undangan Negeri」的定义，特别**包括砂拉越的Council Negri**——这是砂拉越州立法议会的历史名称。

## 常见错误

- **将DUN与Dewan Negara混淆。** DUN是州属的立法机关；[Dewan Negara](/zh/government/dewan-rakyat)则是联邦国会的上议院。部分州属所使用的「Dewan Negeri」这一名称（例如Dewan Negeri Johor）指的是该州的DUN，并非Dewan Negara。
- **以为DUN的议席数目载于联邦宪法之中。** 并非如此。第4(1)条将议员人数交由各州自身的法律订定，因此各州之间的数目并不相同。
- **将EXCO的规模与DUN的议员人数混淆。** 第2(2)(b)条将州行政议会（州务大臣以外）的成员人数限定为不超过十名、不少于四名——这并非DUN的议员总数。
- **以为联邦直辖区设有DUN。** 吉隆坡、纳闽与布城并非州属，没有DUN；联邦直辖区的法律由国会制定。
- **将候选人年龄限制说成21岁。** 自Undi18于2021年12月15日生效以来，第5条下出任DUN议员的合资格年龄为18岁。
