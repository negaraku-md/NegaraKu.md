マレーシアの有権者のうち、「首相」と書かれた投票用紙に印を付ける者は一人もいない。
総選挙の投票用紙は、単一の下院選挙区の候補者を指名するものにすぎない。

この地位は、投票の後、連邦憲法の一つの文に定められた一つのテストを通じて充足される
——そしてその文は、政党、連合、議席数のいずれにも言及していない。

## 概要

| | |
| --- | --- |
| 憲法上の根拠 | 連邦憲法第39条～第43C条、第IV部第3章 |
| 首相を任命する者 | 国王（Yang di-Pertuan Agong）、第43(2)(a)条 |
| 任命のテスト | 国王の判断において下院議員の多数の信任を得られる可能性がある下院議員であること |
| 他の大臣を任命する者 | 国王が首相の助言に基づき任命、第43(2)(b)条 |
| 大臣の出身 | 国会のいずれか一方の議院の議員——下院又は上院 |
| 責任の負い方 | 国会に対する連帯責任、第43(3)条 |
| 下院の議員数 | 民選議員222名、第46(1)条 |
| 宣誓 | Sixth Schedule（第六附表）に定める就任、忠誠及び守秘の宣誓、第43(6)条 |
| 改正の閾値 | 各議院の全議員数の三分の二、第159(3)条 |

## 行政権は実際どこに帰属するのか

第39条は、連邦の行政権を国王（Yang di-Pertuan Agong）に帰属させている。その権限は、
国王自身によって、あるいは内閣（Jemaah Menteri）によって、あるいは内閣から授権され
た大臣によって行使され得る——そして国会は、法律により、行政上の職務を他の者に付与す
ることができる。

続いて第43(1)条は、国王が**その職務の遂行にあたり自身に助言する**内閣を任命するよう
定めている。これが憲法の用いる表現である：内閣は、行政権の保持者に対する諮問機関とし
て存在する。

第40(1)条がその環を完結させる。憲法又は連邦法律のもとで職務を遂行するにあたり、国王
は、憲法に別段の定めがある場合を除き、内閣の助言、又は内閣の一般的な授権のもとで行動
する大臣の助言に従って行動しなければならない。同条はまた、国王に対し、その要求によ
り、連邦の施政に関して内閣が入手し得るあらゆる情報を得る権利を与えている。

Akta A885により追加され、1994年6月24日に発効した第40(1A)条は、これをより明確に定め
ている：国王が助言に従って、助言に基づいて、又は助言を考慮した上で行動することを要求
される場合、国王は**その助言を受け入れ、それに従って行動しなければならない**。

## 任命のテスト：一つの文、二つの条件

第43(2)(a)条は、国王がまず最初に、内閣を主宰させるため、その判断において下院議員の
多数の信任を得られる可能性があると認める下院議員一人を首相として任命しなければならな
いと定めている。

その文には、二つの条件しか含まれていない：

1. **候補者は下院議員でなければならない。** 上院ではない。これは、第43条の中で唯一、
   一つの議院に限定された地位である。
2. **国王の判断において、候補者が下院議員の多数の信任を得られる可能性があること。**
   その判断は国王に委ねられている。

さらなる制限が第43(7)条にある：帰化により、又は第17条のもとでの登録により市民となっ
た者は、首相に任命されてはならない。重印本の公式注記は、第17条自体がAkta 14/1962によ
り、1963年7月1日をもって廃止されたことを記録している。

第46(1)条は、[下院](/government/dewan-rakyat)が民選議員222名から構成されると定めて
いる。222名の議院における多数とは、少なくとも112名の議員を意味する。

### 第43条が定めていないこと

これは、通俗的な要約において最も見落とされがちな部分である。第43条の条文は、次のいず
れにも**言及していない**：

- いかなる政党又は連合の名称；
- 「最多議席を獲得した政党」という概念；
- 多数信任を確定するための特定の方法——宣誓供述書、支持書簡、面談、議院での表決、その
  他いずれの方法によるかを問わず。

憲法が定めているのは**テスト**であって、**手続き**ではない。下院議員の多数の信任がそ
の基準であり、その基準をどのように測定するかは、第43条には成文化されていない。

## 他の大臣：助言に基づき、両議院から任命される

首相が任命された後、第43(2)(b)条が引き継ぐ。国王は、首相の助言に基づき、国会のいず
れか一方の議院の議員の中から他の大臣を任命しなければならない。

首相の任命との二つの相違点に注目してほしい。他の大臣の任命は**助言に基づいて**行われ
るのであり、裁量によるものではない。また、候補者の範囲もより広い：
[上院](/government/dewan-negara)議員も資格を有する。

第43(2)条には、国会が解散している状況に関する但書が一つ含まれている。国会解散中に任
命が行われる場合、前回の下院議員であった者が任命され得るが、次の国会の会期が開始した
後もその地位に留まり続けることはできない——ただし、首相に任命された場合はその新たな下
院の議員であるとき、その他のいかなる場合においても下院又は上院いずれかの議員であると
きを除く。

任命された後、第61(1)条は、内閣の各構成員に対し、自身が所属する議院の議員としての権
利に加えて、もう一方の議院の議事に参加する権利を与えている。第61(3)条はその限界を明
らかにしている：この権利は、ある議院の議員でない者がその議院において投票することを認
めるものではない。

## 連帯責任は単なる慣例ではない

第43(3)条は、一つの短い文から成る：内閣は国会に対して連帯責任を負わなければならな
い。

他の多くのウェストミンスター制度においては、連帯責任は不文の慣例である。マレーシアで
は、それは憲法典それ自体の中に、明文の義務として定められている。

その実際上の効果は、第43(4)条の文言に表れている。同条は、内閣全体の命運を、個々の大
臣の実績にではなく、首相一人の地位に結びつけている。

第38(3)条は、連帯責任を別の角度から示している。
[統治者会議](/government/majlis-raja-raja)が国家政策に関する事項を審議する際、国王
には首相が随行しなければならず、その審議は、国王が内閣の助言に従って行使する職務の一
つである。

## 多数信任が失われたとき

第43(4)条は、首相が下院議員の多数の信任を得られなくなった場合、その請求により国王が
国会を解散しない限り、首相は内閣を総辞職させなければならないと定めている。

定められている道は二つしかなく、その第二の道は完全に首相の手中にあるわけではない。第
40(2)条は、国王が**その裁量により**行使し得る職務を、次のとおり列挙している：

| 条文 | 裁量的職務 |
| --- | --- |
| 40(2)(a) | 首相を任命すること |
| 40(2)(b) | 国会解散の請求を裁可しないこと |
| 40(2)(c) | 統治者の特権、地位、栄誉及び威厳にもっぱら関する統治者会議の開催を要求し、その会議におけるいかなる行動をも要求すること |

第40(2)条は、「及びこの憲法に定めるその他の場合において」という文言で締めくくられて
おり、したがってこの一覧は閉じた一覧ではない。

解散が生じた場合、第55条が時期の定めを引き継ぐ。先に解散されない限り、国会はその最初
の会議の日から五年間存続し、その後解散する。国会が解散したときは、解散の日から六十日
以内に総選挙を実施しなければならず、その日から百二十日を超えない日に国会を招集しなけ
ればならない。

## 任期、宣誓及び報酬

第43(5)条は、第43(4)条に従うことを条件として、首相以外の大臣は国王の意向に従って在
職すると定めている——ただし、いずれかの大臣の任命が、首相の助言に基づき国王によって取
り消された場合を除く。いずれの大臣も自ら辞職することができる。首相の助言に基づく取消
しに関する文言は、Akta 10/1960により追加され、1960年5月31日に発効した。

「第(4)項に従うことを条件として」という文言は重要である：第43(4)条が発動される場合、
辞職は一体としての内閣全体に及ぶ。

第43(6)条は、各大臣が職務を遂行する前に、国王の面前で、Sixth Scheduleに定める三つの
宣誓——就任宣誓、忠誠宣誓、及び守秘宣誓——を行い、これに署名することを求めている。

第43(9)条は、国会が内閣構成員の報酬について法律により定めることを求めている。重印本
の公式注記は、読者を『1980年国会議員（報酬）法令』（Akta Ahli Parlimen (Saraan)
1980、Akta 237）へと導いている。第43(8)条は、Akta A857により、1993年8月20日をもって
廃止された。

## しばしば混同される三つの他の地位

第43A条、第43B条及び第43C条は、内閣の構成員であることとしばしば同一視される、三つの
独立した役職を設けている。

| 地位 | 条文 | 任命者 | 国会議員である必要 |
| --- | --- | --- | --- |
| 副大臣 | 43A | 首相の助言に基づき国王 | 要——いずれか一方の議院 |
| 国会秘書 | 43B | 首相 | 要——いずれか一方の議院 |
| 政治秘書 | 43C | 首相 | 不要 |

副大臣は、大臣がその職務及び機能を遂行するのを補佐し、その目的のために大臣の有するす
べての権限を有する。第43A(3)条は、第43(5)条及び第43(6)条を副大臣にも適用させるため、
その任期及び宣誓義務は大臣と同じである。

国会秘書は、大臣及び副大臣を補佐し、その目的のために大臣及び副大臣の有するすべての権
限を有する。彼らの任命は首相がいつでも終了させることができ、その守秘宣誓は国王ではな
く首相の面前で行われる。

政治秘書が際立っているのは、第43C(2)(a)条が、彼らは国会のいずれの議院の議員でも**あ
る必要はない**と定めているためである。その職務、機能及び報酬は、第43C(4)条のもとで内
閣が定める。

第61条の目的に限り、第61(4)条における「内閣構成員」の定義には、副大臣及び国会秘書が
含まれる。

## よくある誤解

**「国民が首相に投票する。」** 投票用紙は下院選挙区の投票用紙である。首相の任命は、
選挙結果が判明した後、第43(2)(a)条のもとで行われる。

**「最多議席を獲得した政党の党首が自動的に首相になる。」** 第43(2)(a)条のテストは、
下院議員の多数の信任である。条文は政党にも最多議席にも言及していない。

**「大臣は国会外から任命され得る。」** 第43(2)(b)条は、大臣が国会のいずれか一方の議
院の議員の中から選ばれることを求めている。議員資格の要件から除外されるのは、第43C条
のもとの政治秘書のみである。

**「上院議員は大臣になれない。」** なれる——第43(2)(b)条は国会のいずれか一方の議院に
言及している。下院への限定は首相にのみ適用される。

**「多数を失うことは選挙を意味する。」** 第43(4)条は、辞職を既定の結果として定めてい
る；解散は国王がその請求を裁可した場合にのみ生じ、第40(2)(b)条はその請求を拒否するこ
とを裁量的職務として掲げている。

**「連帯責任は単なる慣行にすぎない。」** 第43(3)条は、これを憲法典の条文において明文
で定めている。

## これらの規定を改正するには

第43条の規定は、通常の立法によって改正することはできない。第62(3)条は、国会の各議院
が投票を行った議員の単純多数によって決定を行うことを認めているが、その項自体が、とり
わけ第159(3)条に従うことが明記されている。

第159(3)条は、憲法にいかなる改正を加える法案も、第二読及び第三読において、**当該議院
の全議員数の三分の二を下回らない**票数の支持を得なければ、国会のいずれの議院において
も可決されてはならないと定めている。

この閾値は、出席して投票した議員数ではなく、全議員数を基準に算定される。
