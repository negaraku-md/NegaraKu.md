每一位马来西亚公民在JPN都有一份档案，从他还不会说话之前就已开立，直到他去世之后
才会关闭。出生证明书、MyKad、结婚证书、死亡证——全都出自同一个部门。

## 一览

| | |
| --- | --- |
| 全名 | Jabatan Pendaftaran Negara / National Registration Department |
| 类型 | 联邦部门 |
| 起源 | Peraturan-Peraturan Darurat (Kawasan-Kawasan Pendaftaran) 1948，紧急状态时期的安全措施 |
| 隶属 | 内政部 |
| 总部 | 布城联邦政府行政中心第2区（自2004年12月起） |
| 网站 | `jpn.gov.my` |

正是1948年的这项法规，首次规定每位居民须在年满12岁时登记并持有身份证——这项
义务延续至今。此后，该部门被赋予额外职能，负责登记所有重要事件：出生、死亡、
领养、结婚、离婚与公民权。

## 核心法令

| 法令 | 事项 |
| --- | --- |
| Akta Pendaftaran Negara 1959 (Akta 78) | 人员登记与身份证 |
| Peraturan-Peraturan Pendaftaran Negara 1990 | 登记年龄与领证条件 |
| Akta Pendaftaran Kelahiran dan Kematian 1957 (Akta 299) | 出生与死亡登记册 |
| Akta Membaharui Undang-Undang (Perkahwinan dan Perceraian) 1976 (Akta 164) | 非穆斯林婚姻与离婚 |
| 联邦宪法，第三部分 | 公民权地位 |

Akta 78在各地区生效的日期并不相同：西马为1960年8月1日，砂拉越为1966年3月30日，
沙巴为1972年6月1日，纳闽联邦直辖区则为1984年4月16日。这就是为什么JPN门户网站
上的出生与死亡申请类别，会针对三个地区分别列明。

## 它管理的五项登记

- **出生**——普通登记与迟报登记；出生证明书与登记摘录；证书遗失或损毁时的重新
  登记（Seksyen 4A）。
- **死亡**——死亡登记与登记摘录，包括更正死亡资料。
- **婚姻与离婚**——办理有执照或无执照的非穆斯林民事婚姻登记，以及境外婚姻的
  重新登记。
- **领养**——领养登记。
- **公民权**——公民权地位的申请、地位确认、联邦以外出生的登记、资料更正，以及
  依据联邦宪法办理的放弃与剥夺公民权（包括依据第15A条办理的特殊情况登记）。

## 它签发的身份证件

| 证件 | 适用对象 |
| --- | --- |
| MyKad | 12岁以上公民 |
| MyKid | 尚未符合申请MyKad资格的公民儿童 |
| MyPR | 永久居民——须自2006年6月1日起换成MyPR |
| MyKAS | 暂时居民 |

## 最常被错过的三个期限

**出生登记：60天。** 普通登记是指在出生之日起60天内办理的登记，不收取任何
费用。超过这段期限，就会转为审核更严格的迟报登记。

**首次申请MyKad：30天。** Peraturan 3, Peraturan-Peraturan Pendaftaran Negara
1990 (Pindaan 2007) 规定，公民儿童年满12岁须登记身份证。申请须在年满12岁
之日起30天内办理；逾期则须缴付手续费。此处未列出费用金额——请在办理当日
查阅JPN官方收费表。

**境外婚姻：6个月。** 依据外国法律结婚的公民，须依据Akta 164 Seksyen 31，将
该婚姻重新登记——须在婚姻于境外登记之日起6个月内，亲临JPN柜台或马来西亚
驻外代表处办理。未能办理者，可能须依据同一法令Seksyen 35承担后果。

## 最常被误解的地方

**穆斯林的婚姻不属JPN的业务范围。** JPN的婚姻服务仅适用于非穆斯林申请人，
依据Akta 164办理，该法令于1982年3月1日生效。穆斯林婚姻（nikah）的登记，
属于州伊斯兰宗教局的职权范围。

**程序在全马并不统一。** 表格与申请类别须依照事件登记所在的地区选取——
西马、沙巴或砂拉越——而非申请人目前的居住地。

## 服务渠道

- **e-Services JPN**——在`jpn.gov.my`办理出生登记、证书摘录、身份证申请与
  民事婚姻的在线申请。
- **ezJPN**——JPN官方推出的手机应用程式，汇集了面向公众、政府机构、法定机构
  与律师事务所的数码服务，涵盖用户注册、申请、缴费与文件递交。
- **MEKAR**——一项流动服务，把JPN柜台带到弱势群体面前：Mekar Ihsan（乐龄
  人士、残障人士（OKU）、卧床病人）、Mekar Komuniti（政府机构、非政府组织
  （NGO）与居民协会）、Mekar Pahlawan（军警人员）与Mekar Identiti（被扣留者、
  看护中心与有公民权地位问题的人士）。
