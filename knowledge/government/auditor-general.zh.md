每一年，一份厚厚的报告会呈交给下议院（Dewan Rakyat）。它审视数以百亿计的
公共资金——由部会、州属部门、法定机构与政府公司——是如何被使用的。撰写者
不是反对党政治人物，也不是政府以外的独立机构，而是一名政府官员——而宪法
刻意保障这名官员，使其不会被自己正在审计的那个政府革职。

这个职位就是总审计司（Auditor General），而这样做的权力并非来自行政政策
——它写在联邦宪法本身之中。

## 概览

| | |
| --- | --- |
| 职位 | 总审计司（Auditor General） |
| 部门 | 国家审计局（马来西亚） |
| 宪法依据 | 联邦宪法第105–107条 |
| 法定依据 | 《1957年审计法令》（第62号法令） |
| 委任人 | 最高元首，依首相建议，并在与统治者会议磋商后 |
| 任期保障 | 只能以联邦法院法官相同的理由、以相同的方式被革职 |
| 报告呈交对象 | 最高元首（联邦层级）以及统治者／州元首（Yang di-Pertua Negeri）（州属层级） |
| 报告提呈地点 | 下议院，以及各自的州立法议会 |

## 委任：第105条

第105(1)条规定应设有一名总审计司，由最高元首依首相建议、并在与统治者
会议磋商后委任。这一模式与
[总检察长](/zh/government/attorney-general)的委任方式相似——正式权力
属于最高元首，但须依建议行使。

曾担任该职位者有资格获重新委任，但没有资格获委任至联邦或州属公务体系中
的任何其他职位。此项限制防止该职位被当作跳往其他政府职位的踏脚石。

最重要的保障在于任期：总审计司可随时辞职，但只能以联邦法院法官相同的
理由、以相同的方式被革职。其薪酬与服务条件一经委任，不得作出对其不利
的更改。该薪酬由国会立法拨付，并由统一基金（Consolidated Fund）支付
——不像一般部会开支那样须每年获得批准，如
[联邦预算](/zh/economy/federal-budget)一文所述。

这些特征的组合——依建议委任、禁止转任其他职位，以及与法官相当的任期
保障——都是为了同一个目的而设计：让总审计司能够审计政府，而不必仰赖
这个同一政府的施舍。

## 审计权力：第106条与《1957年审计法令》

第106条规定，联邦与各州的账目应由总审计司审计并作出报告。国会亦可通过
联邦法律赋予他额外职责。

《1957年审计法令》（第62号法令）详细规定了该范围。该法令s.1说明，它
适用于对联邦、各州及其他指定公共机关账目的审计。s.5设定该审计的
管辖范围——涵盖联邦与各州会计官员的账目，以及领取政府拨款或贷款的
机构与实体的账目。s.6设定该审计的标准：核实公共资金是否受到适当的
管控、开支是否依正当权限支出，以及资金是否已用于其被拨付的用途。

s.7则赋予总审计司广泛的调查权力——传召任何人提供所需的解释与资料、
免费查阅一切相关记录、文件与财产，以及在宣誓或誓愿下查问证人。这项
权力使国家审计局得以开展工作，而无需等待被审计实体的许可。

## 报告去向：第107条

第107条设定了呈报路径。总审计司应将其报告呈交最高元首，最高元首将促使
该报告在[下议院](/zh/government/dewan-rakyat)提呈。就与某一州账目有关
的报告而言，副本亦须送交有关的统治者或州元首，以便在该州的州立法议会
提呈。

提呈之后，该报告通常会转交下议院的公共账目委员会（Public Accounts
Committee）作进一步审查——这是国会的一个特别委员会，依据总审计司的
发现审查公共开支。本文只聚焦于国家审计局本身的宪法授权，而非任何特定
报告或发现的内容。

## 国家审计局的架构

国家审计局由总审计司领导，并由多个部门支援，其中包括：

- **总审计司办公室**——协调审计运作与部门行政事务。
- **国家审计学院**——培训官员在审计、会计、资讯科技、管理及国际事务方面的能力。
- **资讯及通讯科技审计组**——规划并监督公共部门资讯系统的审计研究。
- **法律顾问组**——提供法律意见，并审阅合约与谅解备忘录。
- **技术组**——向各领域及州属办事处提供审计技术咨询服务。
- **政策与国际关系组**——制定审计政策、品质保证，以及双边／多边关系。
- **廉正组**——管理治理、侦测、投诉与廉正合规事宜。
- **审计跟进组**——确保被审计实体落实纠正行动。

## 审计的种类

国家审计局执行数种目的各异的审计：

| 审计类型 | 重点 |
| --- | --- |
| 财务报表审计 | 某一实体的财务报表是否作出真实与公平的呈现，以及会计记录是否妥善保持最新 |
| 绩效审计 | 某项政府计划或活动的经济性、效率与成效 |
| 治理审计 | 系统与运作是否遵循既定的治理要求 |
| 政府公司审计 | 政府相关公司的财务与营运表现 |

在进行审计之前，会与被审计实体举行一场启动会议（entrance
conference），以说明审计的目标、范围与方法——这是该局本身的常见问题
解答中经常提到的一项程序特征。

## 常见错误

**「总审计司是国会议员，或是政府以外某个独立机构的成员。」**总审计司是
受宪法保障的公共服务官员，不是民选代议士，也不是非政府组织成员。

**「总审计司报告只涵盖联邦部会。」**第106条与《1957年审计法令》下的
授权，同时涵盖州政府、法定机构及其他指定公共机关的账目。

**「若政府不满意报告内容，便可以革职总审计司。」**第105条下的任期
保障，将革职的理由与方式等同于联邦法院法官——远高于一般公共服务官员。

**「报告即是最终决定。」**在下议院提呈的报告，通常会转交公共账目委员会
作进一步审查与后续跟进行动。
