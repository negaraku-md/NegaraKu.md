すべてのマレーシア国民は、言葉を話せるようになる前に開かれ、死去した後に閉じられる
一つのファイルをJPNに持っている。出生証明書、MyKad、結婚証明書、死亡証明書——すべて
同じ部門から発行される。

## 概要

| | |
| --- | --- |
| 正式名称 | Jabatan Pendaftaran Negara / National Registration Department |
| 種類 | 連邦部門 |
| 起源 | 1948年緊急事態規則（登録地域）（Peraturan-Peraturan Darurat (Kawasan-Kawasan Pendaftaran) 1948）、緊急事態時代の治安措置 |
| 所管 | 内務省（KDN） |
| 本部 | プトラジャヤ連邦政府行政センター、プレシンクト2（2004年12月以降） |
| ウェブサイト | `jpn.gov.my` |

この1948年の規則こそが、すべての住民に満12歳に達した時点での登録と身分証明書の
保有を初めて義務付けたものであり——この義務は今日まで続いている。その後、同部門
にはあらゆる重要な出来事、すなわち出生、死亡、養子縁組、婚姻、離婚、国籍に関する
登録という追加の機能が与えられた。

現代における画期的な出来事は、それから数十年後に訪れた。2001年9月5日、JPNはMyKad
を導入した——内蔵チップに写真による本人確認と指紋の生体認証データの両方を統合
した、世界初の身分証明書である。これはMSC Malaysiaの旗艦アプリケーションの一つで
あり、政府多目的カード（Government Multipurpose Card）として構想されたものである。

## 中核となる法令

| 法令 | 内容 |
| --- | --- |
| 1959年国民登録法（Akta Pendaftaran Negara 1959、Akta 78） | 個人の登録および身分証明書 |
| 1990年国家登録規則（Peraturan-Peraturan Pendaftaran Negara 1990） | 登録年齢および発給条件 |
| 1957年出生死亡登録法（Akta Pendaftaran Kelahiran dan Kematian 1957、Akta 299） | 出生・死亡登録簿 |
| 1976年法律改正（婚姻及び離婚）法（Akta Membaharui Undang-Undang (Perkahwinan dan Perceraian) 1976、Akta 164） | 非イスラム教徒の婚姻及び離婚 |
| 連邦憲法、第3部 | 国籍資格 |

Akta 78は地域ごとに異なる日付で施行された——半島部では1960年8月1日、サラワクでは
1966年3月30日、サバでは1972年6月1日、ラブアン連邦直轄区では1984年4月16日である。
このため、JPNポータルにおける出生・死亡の申請区分は、3つの地域ごとに別々に掲載
されている。

## 管理する5つの登録

- **出生**——普通登録および遅延登録、出生証明書および登録抄本、証明書の紛失・
  毀損時の再登録（Seksyen 4A）。
- **死亡**——死亡登録および登録抄本の発行、死亡情報の訂正を含む。
- **婚姻及び離婚**——許可証の有無を問わない非イスラム教徒の民事婚姻登録、および
  海外での婚姻の再登録。
- **養子縁組**——養子縁組の登録。
- **国籍**——国籍資格の申請、資格の確認、連邦域外での出生登録、詳細事項の訂正、
  並びに連邦憲法に基づく国籍の放棄及び剥奪（第15A条に基づく特別な状況の登録を
  含む）。

## 発行する身分証明書

| 証明書 | 対象者 |
| --- | --- |
| MyKad | 12歳以上の国民 |
| MyKid | MyKadの取得資格を得る前の国民の子ども |
| MyPR | 永住者——2006年6月1日よりMyPRへの切り替えが義務付けられている |
| MyKAS | 一時居住者 |

MyKadに印字される12桁の身分証明書番号は、YYMMDD-PB-###Gの形式に従う——生年月日、
出生地コード、通し番号、そして保有者の性別に対応する末尾の数字（男性は奇数、
女性は偶数）である。

## MyKad紛失時の再発行手数料

MyKadの紛失には、紛失した回数に応じて段階的な手数料が課される。

| 状況 | 手数料 | 要件 |
| --- | --- | --- |
| 1回目の紛失 | RM110 | 警察報告書が必要 |
| 2回目の紛失 | RM310 | 警察報告書が必要 |
| 3回目以降の紛失 | RM1,010 | 警察報告書が必要 |

再発行の都度、警察報告書を提出しなければならない。写真や個人情報の変更が伴わ
ない場合は、MyKad再発行システムを通じてオンラインで申請することができる。

## 最も見落とされやすい3つの期限

**出生：60日。** 普通登録とは、出生日から60日以内に行われる登録であり、無料で
ある。この期限を過ぎると、より厳格な審査を伴う遅延登録となる。

**最初のMyKad：30日。** 1990年国家登録規則（Peraturan-Peraturan Pendaftaran
Negara 1990、2007年改正）規則3は、満12歳に達した国民の子どもに身分証明書の
登録を義務付けている。申請は満12歳に達した日から30日以内に行わなければならない。
この期限内の登録は無料であり、期限を過ぎるとRM10の手数料が課される。

**海外での婚姻：6か月。** 外国法に基づいて婚姻した国民は、Akta 164のSeksyen 31
に基づき、その婚姻を再登録する必要がある——海外で婚姻が登録された日から6か月
以内に、JPNの窓口またはマレーシア在外公館に出向かなければならない。これを怠った
場合、同法のSeksyen 35に基づく措置が取られることがある。

## 最もよく誤解されている点

**イスラム教徒の婚姻はJPNの管轄ではない。** JPNの婚姻サービスは、1982年3月1日に
施行されたAkta 164に基づき、非イスラム教徒の申請者のみを対象とすると明記されて
いる。イスラム教徒の婚姻（nikah）の登録は、州のイスラム宗教局の管轄である。

**手続きはマレーシア全土で統一されていない。** 申請書式と申請区分は、その出来事
が登録される地域——半島部、サバまたはサラワク——に従って取得しなければならず、
申請者の現在の居住地には従わない。

## サービス窓口

- **e-Services JPN**——`jpn.gov.my`における、出生登録、証明書抄本、身分証明書
  の申請及び民事婚姻のオンライン申請。
- **ezJPN**——一般市民、政府機関、法定機関及び法律事務所向けのデジタルサービス
  を集約したJPN公式モバイルアプリケーションであり、利用者登録、申請、支払い、
  書類の提出を網羅する。
- **MEKAR**——JPNの窓口を脆弱な立場にある人々のもとへ届ける移動サービスであり、
  Mekar Ihsan（高齢者、障害者（OKU）、寝たきりの患者）、Mekar Komuniti（政府
  機関、NGO及び住民協会）、Mekar Pahlawan（軍人及び警察官）、Mekar Identiti
  （被拘留者、ケア施設の入所者及び国籍資格に問題を抱える個人）から成る。

## 次のステップ

窓口へ行く前に、`jpn.gov.my`で地域ごとの申請書式及び必要書類を確認すること。
半島部、サバ及びサラワクでは要件が異なるためである。国籍に関する手続きに
ついては、申請書式を選ぶ前に、該当する[連邦憲法](/law/federal-constitution)
第3部の規定から確認を始めること。
