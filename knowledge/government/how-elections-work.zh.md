## 概览

| | |
| --- | --- |
| 投票制度 | 单一议席选区，得票最多者当选（first-past-the-post） |
| 宪法依据 | 联邦宪法 Part VIII（第八部分，第113–120条） |
| 所选出的对象 | 下议院（联邦）议员与州立法议会（DUN）议员 |
| 投票资格 | 公民、年满18岁、居住、已登记（第119(1)条） |
| 执行机构 | 选举委员会（第113、114条） |
| 选区重划周期 | 间隔不少于八年（第113(2)条） |
| 解散之后 | 60天内举行大选（第55(4)条） |

在投票日，整套制度收缩为一个简单的动作：一名选民在一间安静的房间里，
在一张选票上做出标记。围绕着这个动作的一切——选民名册、选区边界、点票
的机构——都是宪法框架，决定谁可以在何处标记那张选票，以及一个铅笔记号
如何变成一个议席。

本页依据宪法文本，以描述性方式说明这套框架：选票如何计算、谁具备资格、
由谁执行选举，以及从解散到结果之间的程序顺序。本页并不涉及任何特定政党、
候选人或结果。

## 一区一议席，得票最多者当选

出发点不是选民人数，而是选区的形状。第116(2)条规定，「选区总数须与议员
人数相等，使每个选区各选出一名议员」。每个选区只送出一名代表——不多不少。

由于每个选区只选出一人，选出方式因而变得简单：在该选区中得票最多的候选
人即告当选。无需百分之五十的绝对多数，也没有第二轮投票。这种单一议席多
数决制度，通常称为*领先者当选制*（first-past-the-post，FPTP）。宪法订
明其结构；至于如何计算最高票数的具体方法，则载于 Akta Pilihan Raya
1958 等选举法律之中，第113条的官方注释亦提及此点。

第117条将同一形式复制到州级。就州立法议会议员的选举而言，该州须划分为
「按所选议员人数而定的若干选区，使每个选区各选出一名议员」。联邦与州的
结构相同；不同的只是所填补的议院。

## 同一天选出的两个议会

马来西亚透过类似的多数决制度，选出两个层级的代表。

- **下议院（Dewan Rakyat）。** 联邦国会的下议院，第46条订明共有222个
  议席。每个议席即第116条下的一个联邦选区。
- **州立法议会（Dewan Undangan Negeri，DUN）。** 每个州都设有自己的立
  法议会，议席数目由该州自身的州宪法订定，并按第117条划分。

在大多数州属，州选举与联邦大选同时举行。第113(2)条透过要求州选区的边
界检讨须与下议院的检讨「在同一时间」进行，强化了这种同步安排。在此类
州属的选民，通常会在同一天收到两张分开的选票：一张用于国会，一张用于
州立法议会。

半岛上有些州属选择在不同的时间解散其州立法议会，从而产生一场与大选分开
的州选举。这属于各该州属自身的权限范围。

## 谁有资格投票

第119(1)条设定了三项须同时符合的条件。一名公民若符合以下条件，即有权
投票：

1. 在合格日期已**年满18岁**；
2. 在该日期**居住**于某个选区，或已登记为不在籍选民；以及
3. 已在其所居住选区的选民名册上**登记**。

18岁这一年龄，是经过通常称为*Undi18*的宪法修正案——Akta Perlembagaan
(Pindaan) 2019——之后的现行规定，该修正案将投票年龄从21岁降至18岁。
同一项修正案也引入了自动选民登记制度，使合格公民无需另行申请，即可由
选举委员会登记入选民名册。

第119(1)条也设下一项重要限制：「任何人不得在同一场选举中于超过一个选
区投票」——每人每院一票。

第119(3)条列出丧失选民资格的理由：在合格日期正被以精神不健全为由拘留，
或正在服刑；或已被定罪并被判处死刑，或被判处超过十二个月的监禁而仍须
服该刑期。

## 选举委员会：执行选举的机构

选举不会自行运作。第113(1)条设立了选举委员会（Suruhanjaya Pilihan
Raya，SPR），并赋予其两项核心任务：执行下议院与州立法议会的选举，以及
编制及检讨选民名册。

第114条订明该机构的组成与独立性。

| 特征 | 规定 |
| --- | --- |
| 组成 | 主席、副主席及**另外五名成员**——共七人（第114(1)条） |
| 委任 | 由最高元首在**咨询统治者会议**后委任（第114(1)条） |
| 考量因素 | 最高元首须顾及确保选举委员会**获得公众信任**的重要性（第114(2)条） |
| 卸任年龄 | 66岁（第114(3)条） |
| 免职 | 只能基于与**联邦法院法官**相同的理由，并依照相同的方式（第114(3)条） |
| 薪酬 | 由**统一基金（Consolidated Fund）**支付；委任后不得调整为对成员不利（第114(5)、(6)条） |

这样的设计赋予选举委员会若干与司法机构相同的独立性保障：委任过程涉及
统治者会议、透过严格的免职条件保障任期，以及薪酬受统一基金保护，使其
不必依赖年度拨款投票。

## 选区重划：选区边界如何划定

由于每个选区只选出一名议员，边界线画在何处，决定了哪些选民被归入同一
组。第113(2)条赋予选举委员会检讨联邦及各州划分为选区的方式的任务，并
就此提出修改建议，以符合宪法**Thirteenth Schedule（第十三附表）**所载
必须遵循的原则。

两项时限规范着这个周期：

- **至少八年的间隔。** 第113(2)(ii)条规定，一次检讨完成之日与下一次检
  讨开始之日之间，间隔不得少于八年。
- **两年内完成。** 第113(2)(iii)条要求每次检讨须自开始之日起，在不超过
  两年的期限内完成。

第113(6)条要求就马来亚各州、沙巴及砂拉越分别进行检讨——每一个都被视为
独立的「检讨单位」。选举委员会的建议报告须呈交首相，边界修订须经下议院
批准方能生效。

## 选举何时召开

大选并非在固定日期举行，而是由解散所触发。第55(3)条规定，国会自其首次
会议起运作五年，其后自动解散，除非最高元首根据第55(2)条提前将其解散。

国会一旦解散，宪法所定的时限即告启动。第55(4)条设下两项限制：

| 事项 | 解散后的时限 |
| --- | --- |
| 举行大选 | **60天**内 |
| 国会须重新召开会议 | 不得迟于**120天** |

至于在两次大选之间某个议席意外悬空的情形，可依第54条举行补选——尽管
第54条的附带条款在特定情况下，豁免在国会即将解散前两年内所产生的悬空
议席。

## 一场选举的进行程序

国会解散后，选举委员会为每一场选举设定相同的程序顺序。选举委员会官方
网站将其阶段说明如下。

1. **发出令状。** 选举委员会向每个选区的选举主任（Returning Officer）
   发出令状——即授权文书——以执行该选区的选举，并订定提名日期与投票
   日期。
2. **提名日。** 在订定的日期，选举主任接受候选人连同其提案人与附议人
   提交的提名表格。
3. **竞选期。** 提名完成后，候选人及其代表可以展开竞选活动。竞选活动
   必须在投票日前一晚的午夜准时停止。
4. **投票日。** 已登记的选民在其选区所订定的投票中心标记选票。
5. **点票。** 投票结束后，选票即被点算。
6. **宣布结果。** 每个选区中得票最多的候选人，由选举主任宣布为当选人。

确切的细节——提名时间、竞选期与候选人按金——受 Akta Pilihan Raya 1958
及其下的规例管辖，且可能有所变动；现行数字应对照选举委员会就每一场选
举发布的官方公告加以核实。

## 从议席到政府

选票选出议员；这些议员其后决定政府的组成。第43(2)(a)条规定，最高元首
须委任一名下议院议员为首相，此人须是最高元首认为可能获得该议院议员多
数信任的人选。多数决制度决定下议院的组成；第43条则据此院的信任，决定
由谁执政。这一路径的细节，见[下议院](/zh/government/dewan-rakyat)与
[马来西亚国会](/zh/government/parliament)。

## 常见错误

**「候选人必须以百分之五十的多数票获胜。」** 不然。在第116(2)条所塑造
的多数决制度下，得票最多的候选人即告当选，即使其票数不足总票数的一半，
且无需第二轮投票。

**「一票直接选出首相。」** 选民只选出其所属选区的议员。第43(2)(a)条将
首相的委任权交由最高元首，依据下议院多数议员的信任而定。

**「投票年龄是21岁。」** 第119(1)条现已将其定为18岁，此乃经 Akta
Perlembagaan (Pindaan) 2019 修正之后的规定。

**「选举委员会属于一般政府的一部分。」** 第114条赋予其成员如法官般的
任期保障、来自统一基金的薪酬，以及涉及统治者会议的委任程序。

**「边界可以随时更改。」** 第113(2)条规定，一次选区重划检讨与下一次之
间，间隔不得少于八年。
