大半の公職は、国会が書き換えることのできる成文法によって定められている。連邦司法長官の職務は
そのいずれにも該当しない。それは連邦憲法そのものに、単一の条文——第145条——として書き込まれ
ており、この条文が、誰がこの職に就くか、この職が何を行わなければならないか、そして憲法が保持
者自身の裁量に委ねる唯一の権限を定めている。

この条文を注意深く読むことが、この職務を理解する最も確実な方法である。なぜなら、マレーシアに
おける司法長官について語られることのほぼすべてが、その六つの款にまで遡ることができるからである。

## 概要

| | |
| --- | --- |
| 職名 | 連邦司法長官（Peguam Negara） |
| 憲法上の根拠 | 連邦憲法第145条 |
| 任命者 | 国王（Yang di-Pertuan Agong）、首相の助言にもとづく（第145(1)条） |
| 資格 | 連邦裁判所の裁判官となる資格を有する者（第145(1)条） |
| 中核的職務 | 法律事項について国王、内閣及び各大臣に助言すること（第145(2)条） |
| 象徴的権限 | 裁量により、罪に関する訴訟手続を提起し、遂行し、又は中止すること（第145(3)条） |
| 別称 | 第(3)款の権限を行使する際は検察官（Public Prosecutor） |
| 出廷権 | 連邦内のあらゆる裁判所又は審判廷における出廷権及び優先権（第145(4)条） |
| 任期 | 国王の意思のもとで保持される（第145(5)条） |

## 職位の任命方法：第145条第(1)款

第145条第(1)款は、国王が**首相の助言にもとづき**、連邦裁判所の裁判官となる資格を有する者を連
邦司法長官に任命すると定めている。

ここから直接、二つの文言上の要点が導かれる。第一に、任命は助言にもとづいて行われる——正式な
行為は国王のものであり、助言は首相のものである。これは、[第40条](/ja/government/yang-di-pertuan-agong)のもとで助言にもとづき行使される職務の一般的な型と軌を一にする。

第二に、資格は司法制度を基準として定められている。資格を得るには、連邦裁判所の裁判官となる資
格を満たすのと同じ条件——憲法が別の箇所で、上級裁判所の弁護士としての、又は司法及び法律職の
一員としての在職年数によって定義している条件——を満たさなければならない。したがって、この職
務は上級の法律家に限定されているが、それ自体は司法上の職ではない。

## 助言義務：第145条第(2)款

第145条第(2)款は、この職務の恒常的な義務を定めている。司法長官は、国王又は内閣が随時付託し
又は指定する法律事項について国王、内閣又は大臣に助言し、また法律的性質を有するその他の職務を
遂行する義務を負い、さらに憲法又はその他の成文法により、あるいはこれらにもとづき付与された職
務を遂行する義務を負う。

平易に言えば、これにより司法長官は政府の主席法律顧問となる。この義務は、この職務に**付託され
又は指定された**助言として構成されている——司法長官は、この職務に提示された事項について助言
し、他の法律が付与するさらなる法律上の職務を遂行する。

## 訴追権限：第145条第(3)款

この款が、この職務に独自の性格を与えている。第145条第(3)款は、司法長官が**その裁量により行
使できる**権限として、罪に関するあらゆる訴訟手続を提起し、遂行し、又は中止する権限を有すると
定めている——ただし、シャリア裁判所、原住民裁判所（native court）又は軍事法廷における手続を
除く。

三つの動詞が、この権限の範囲を示している。

- **提起（Institute）**——訴追を開始すること。
- **遂行（Conduct）**——それを継続すること。
- **中止（Discontinue）**——それを終わらせること。

この権限がこの職務に帰属しているため、司法長官はこの資格において、国の**検察官（Public
Prosecutor）**である。この二つの呼称は、同一人物の異なる役割を表している——職務全体について
は「司法長官」、この職務が刑事訴訟手続に関する第(3)款の権限を行使するときは「検察官」である。

この款はまた、それ自体の境界を定めている。この権限は、通常裁判所における「罪に関するあらゆる
訴訟手続」に及ぶが、条文は三つの審理の場を除外している。

| 除外される審理の場 | 対象範囲 |
| --- | --- |
| シャリア裁判所 | 州のイスラム法にもとづく罪であり、各州の管轄に属する |
| 原住民裁判所（native court） | サバ及びサラワクにおける原住民の慣習に関する事項 |
| 軍事法廷（court-martial） | 軍法にもとづく軍務上の罪 |

これらの除外は、この職務の及ぶ範囲を理解するうえで重要である——第(3)款の裁量権は、連邦の通常
裁判所における訴追に関する権限であり、不法行為を審理しうるあらゆる審判機関に及ぶものではな
い。通常の刑事裁判所がどのように編成されているかについては、[裁判所の階層](/ja/law/court-hierarchy)を、シャリア側の境界線については、[民事裁判所とシャリア裁判所](/ja/law/civil-and-syariah-courts)を参照のこと。

## 裁判所の選択：第145条第(3A)款

第145条第(3A)款は、第(3)款に付随する規定である。**連邦法律により**、司法長官に対し、同人が
第(3)款のもとで提起する権限を有する訴訟手続をどの裁判所又はどの場所で提起するか、あるいはど
こへ移送するかを決定する権限を付与することができると定めている。

この款は、自動的に効力を生じるものではなく、授権的な性質のものである——それ自体が場所選択の
権限を付与するのではなく、国会が連邦法律によりこれを付与することを認めるものである。この規定
は訴追裁量と並んで置かれており、事件をどこで審理するかという選択を同一の枠組みの中で定めるこ
とができるようにしている。

## 出廷権及び優先権：第145条第(4)款

第145条第(4)款は、司法長官がその職務の遂行にあたり、連邦内のあらゆる裁判所又は審判廷におい
て**出廷権**を有し、また**そこに出廷する他のいかなる者に対しても優先する**と定めている。

これにより二つの事柄が同時に付与される。出廷権とは、この職務があらゆる裁判所又は審判廷におい
て出廷し、意見を述べることができることを意味する。優先権とは、司法長官が出廷する際、その職務
が当該事件に出廷する他のいかなる者よりも上位に位置づけられることを意味する。両者が合わさるこ
とで、この職務は連邦の裁判所における法律的代理の中で最上位に置かれる。

## 任期及び報酬：第145条第(5)款及び第(6)款

第145条第(5)款は、この職務が保持される条件を定めている。第(6)款に従うことを条件として、司
法長官は**国王の意思のもとで職務を保持し**、いつでも辞職することができ、また——内閣の構成員
である場合を除き——国王が定める報酬を受けるものとする。

「意思のもとで（during pleasure）」とは、憲法上定義された専門用語であり、この職務が固定され
た任期のもとで保持されるものではないことを意味する。この款はまた、保持者が内閣の構成員である
場合とそうでない場合の両方を想定し、それぞれの場合について報酬の問題を異なる形で定めている。

第145条第(6)款は、経過的な保護規定である。この款は、この条文が施行される直前にこの職務にあ
った者は、それ以前よりも不利でない条件のもとで在職を継続し、また連邦裁判所の裁判官と同様の理
由及び同様の方法によらなければ解任されないと定めている。第(5)款が「従うことを条件として」と
定めているのは、この第(6)款のことである。

## 職務と総検察庁

司法長官は**総検察庁**（Attorney General's Chambers、Jabatan Peguam Negara）を率いる。総検
察庁は、この憲法上の職務が遂行される連邦の部局である。総検察庁は、刑事訴追、政府のための民事
訴訟、法律助言業務、及び法令の起草・改正などの業務を扱う部門に編成されている。総検察庁内で
は、**副司法長官（Solicitor General）**が上級の代理を務める。

この区別は明確にしておく価値がある——第145条は、この職務を一人の指名された保持者に帰属させ
ているのに対し、総検察庁は、その職務の遂行を補佐する官吏——司法及び法律職の構成員——からな
る常設の機関である。

## よくある誤解

**「司法長官と検察官は別々の職務である。」** 条文上、両者は同一の職務である。検察官とは、第
145条第(3)款の権限を行使する司法長官のことである。（この二つの役割を*分離すべきか*どうかは
政策上の議論の対象であり、条文に即した本稿ではこれに立ち入らない。）

**「訴追権限は[刑事訴訟法典](/law/criminal-procedure-code)（Criminal Procedure Code）に由来する。」** 同法典は刑事訴訟手続がどのように進行するかを規律しているが、それを提起し、遂行し、又は中止する
裁量権は、憲法そのものが第145条第(3)款において付与しているものである。

**「司法長官はあらゆる裁判所で訴追を行うことができる。」** 第(3)款の権限は、シャリア裁判所、
原住民裁判所（native court）又は軍事法廷には明文で**及ばない**。

**「この職務には固定された任期がある。」** 第145条第(5)款は、この職務が国王の意思のもとで保
持されると定めている。憲法はこの職務について固定された任期を定めていない。

## 次に読むべきもの

この職務を一次文献から読むには、第145条を款ごとに読み進めるとよい——任命と資格については
**第145(1)款**、助言義務については**第145(2)款**、訴追権限とその除外事項については
**第145(3)款**及び**第145(3A)款**、出廷権については**第145(4)款**、任期及び経過的保護につ
いては**第145(5)款～第(6)款**である。権威ある条文は、総検察庁のマレーシア法令集（Laws of
Malaysia）ポータル、及び連邦憲法の公式再版を通じて入手できる。
