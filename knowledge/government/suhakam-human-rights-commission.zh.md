当有人向 SUHAKAM 提交侵犯人权的投诉时，这个委员会究竟能做什么、不能做什么？
答案不是修辞——它就落在一部1999年的简短法令中，该法令精确地规定了四项职能、
一排调查权力，以及几条不可逾越的红线。

## 一览

| | |
| --- | --- |
| 全称 | 马来西亚人权委员会（SUHAKAM） |
| 类型 | 国家人权机构；法人团体（第3条） |
| 设立法令 | 《1999年马来西亚人权委员会法令》（第597号法令） |
| 御准 | 1999年8月27日 |
| 宪报颁布 | 1999年9月9日 |
| 生效 | 2000年4月20日（PU(B) 122/2000） |
| 最近一次重大修正 | A1714号法令 2024（宪报颁布于2024年6月27日） |
| 网站 | `suhakam.org.my` |

SUHAKAM 是一个独立的法人团体——它可以其自身名义起诉与被起诉——但它不是法院，
也不是执法当局。它的角色是调查、建议与报告。

## 本法令下的"人权"是什么意思？

这是最常被误解的问题。第597号法令第2条把"人权"明确地定义为
*《联邦宪法》第二部分所载明的基本自由*。因此 SUHAKAM 的第一参照点
始终是国家宪法本身——诸如人身自由、平等、言论、集会与宗教自由等权利。

第4(4)条增加了第二层：为本法令的目的，*1948年《世界人权宣言》*
在其不与《联邦宪法》相抵触的范围内应予关注。国际标准会被纳入考量，
但《宪法》仍居于优先地位。

## 它的四项核心职能是什么？

第4(1)条列出四项职能——不多，不少：

- **(a) 意识与教育** — 推广人权意识并提供与人权相关的教育。
- **(b) 立法建议** — 就制订立法、行政指令与程序向政府提供建议与协助，
  并建议应采取的必要措施。
- **(c) 国际条约建议** — 就在人权领域加入或参与国际条约与文书向政府提出建议。
- **(d) 投诉调查** — 依据第12条所述，调查与侵犯人权有关的投诉。

## 支撑这些职能的权力是什么？

第4(2)条赋予 SUHAKAM 一系列权力以执行上述职能。其中在实务上最重要的包括：

| 权力（第4(2)条） | 实务含义 |
| --- | --- |
| (a) 研究与项目 | 举办研讨会、工作坊、研究，并传播其成果 |
| (b) 与投诉有关的建议 | 就针对政府/当局的投诉向其提供建议，并建议适当措施 |
| (c) 审查并确认侵权 | 依据法令调查并确认侵犯人权 |
| (d) 探访扣留场所 | 探访任何扣留场所、机构及其他地方，并提出建议 |
| (e) 公开声明 | 在必要时就人权发表公开声明 |
| (f) 其他适当活动 | 依据成文法进行任何其他必要的活动 |

探访扣留场所的权力（第4(2)(d)条）经2024年修正案获得强化：
新的第4(3)条规定，只要遵守法律或指南所规定的程序，负责该场所的人
**不得拒绝**该探访。同一修正案也增设了接收并处理儿童投诉的专门机制
（第4(2)(ea)条）。

## 谁是专员，他们如何获得委任？

根据第5条，SUHAKAM 由**不少于七人、不多于二十人**的成员组成。他们由
**最高元首依据首相的建议**委任，而首相在提供建议之前须与第11A条下的
委员会协商。

2024年修正案收紧了成员资格条件：

- **第5(3A)条** — 成员必须至少包括一名残疾人士（OKU）代表，以及至少
  30% 的女性代表。
- **第5(3B)条** — 任何活跃于政治并已在任何政党注册的人不得获委任为成员。

任期为**三年**，成员有资格再获委任**一次**，以再任三年（第5(4)条）。
主席由最高元首从成员中委任（第6条），副主席则由成员互选产生。2024年修正案
也设立了**儿童首席专员**及两名**儿童专员**的职位（第6A条），以处理
与儿童相关的人权事务。

## 投诉与调查的流程如何进行？

本法令第三部分（第12–15条）规范调查。SUHAKAM 可**主动**调查，
或依据受屈者、团体，或代表他们行事的人所提出的**投诉**进行调查（第12(1)条）。

在调查方面，第14条赋予 SUHAKAM 类似审裁庭的权力：传召任何居住在马来西亚的人
出席作证或提交文件、宣誓取证，甚至接受依据《1950年证据法令》可能不可采纳的证据。
第15条以与法院证人相同的特权保护证人。

不过这些权力有其尽头。当调查**未**揭露侵权时，SUHAKAM 记录该发现并通知投诉人
（第13(1)条）。当调查**揭露**侵权时，SUHAKAM 可将该事项连同必要的建议转交
相关当局（第13(2)条）——而自2024年修正案起，该当局**必须告知** SUHAKAM
所采取的行动（第13(3)条）。

## 法令本身设下了哪些限制？

三项重要限制使 SUHAKAM 成为一个调查与咨询机构，而非惩处机构：

1. **不得与法院重叠。** 第12(2)条禁止 SUHAKAM 调查法院正在审理（包括上诉）
   或已终局判决的投诉。若某事项在调查进行期间进入法院，SUHAKAM 必须立即停止
   （第12(3)条）。
2. **建议不具约束力。** 法令赋予 SUHAKAM 建议与报告的权力，而非执法。
   它须依靠政府与国会采取行动。
3. **不得接受外国资金。** 第19(2)条禁止 SUHAKAM 接受任何外国资金；
   第19(3)条下的狭窄例外仅允许为人权教育与意识用途接受无附加条件的资金。
   政府每年必须提供足够的资金（第19(1)条）。

## 它如何报告并维持其独立性？

第21条规定 SUHAKAM 须就其所有活动向国会提呈**年度报告**，不迟于翌年国会的
首次会议，并附上转交予它的事项清单及所采取的行动。它也可在任何必要时提呈
特别报告。作为一个法定机构，其账目须受《1980年法定机构（账目与年度报告）法令》
（第20条）规范。

SUHAKAM 的独立性也从外部得到衡量。透过日期为2026年6月9日的第32-2026号媒体声明，
SUHAKAM 宣布，全球国家人权机构联盟（GANHRI）下的认证小组委员会（SCA）
在其第47届会议上，重新确认了 SUHAKAM 的**"A级"**认证——这是最高级别，
反映其持续符合《巴黎原则》，即规范国家人权机构的独立性、有效性、多元性与职权的
国际标准。（2026年6月9日是 SUHAKAM 的公告日期；SCA 会议实际决定的日期
在本资料来源中尚未确认。）"A级"使 SUHAKAM 得以充分参与联合国人权机制，
包括人权理事会。

## 接下来该做什么

如果你想提出投诉，先从检查两件事开始：该问题是否落在《联邦宪法》第二部分的
基本自由范围内（第2条的定义），以及它是否正在或已在法院审理（第12(2)条的限制）。
要理解作为 SUHAKAM 职权基础的权利，请阅读[《联邦宪法》](/law/federal-constitution)
中的基本自由条文。要了解其年度报告如何受到审议，请参阅
[国会](/government/parliament)的角色。在采取行动前，请在 `suhakam.org.my`
核实当前的投诉表格与渠道。
