世界上大多数君主制国家，都以同样的方式回答同一个问题：谁将成为下一任国王？答案通
常是世袭继承，任期通常是终身。

马来西亚的答案与众不同。联邦最高元首是推选产生的——由统治者本身，从他们自己之
中，推选出任期五年的人选，依一份在每次推选之后都会重新编排的名单进行。这项安排载
于联邦宪法第三附表之中。

## 概览

| | |
| --- | --- |
| 称号 | 最高元首（Yang di-Pertuan Agong） |
| 宪制地位 | 联邦最高元首（第32(1)条） |
| 推选者 | 统治者会议（第32(3)条） |
| 任期 | 五年 |
| 资格 | 在位统治州属的统治者（第三附表第一部分） |
| 推选程序 | 第三附表及统治者会议规则 |
| 就职宣誓 | 在统治者会议前，并有首席大法官在场见证（第37(1)条） |
| 副职 | 副最高元首（Timbalan Yang di-Pertuan Agong）（第33条） |
| 配偶 | Raja Permaisuri Agong（第32(2)条） |
| 所在地 | Istana Negara（国家皇宫），吉隆坡 |

## 这套机制何以无与伦比

马来西亚有九个州属拥有统治者。另外四个州属——马六甲、槟城、沙巴与砂拉越——没有
统治者，其各自的州宪法规定由最高元首担任该州的伊斯兰教首长（第3(3)条）。

第五附表订明，统治者会议由统治者**与**州元首组成。但就推选与罢免最高元首的事务
而言，宪法将参与范围限于统治者本身。只有在位的统治者可被推选；州元首并非候选人。

这正是这套安排之所以不同寻常的原因：九位世袭统治的君主在彼此之间投票，以决定谁将
出任联邦最高职位，而他们每五年就重复一次这项程序。

## 推选如何进行

第五附表第6条指示统治者御玺守护官，须在最高元首任期届满前**不迟于四星期**召集
统治者会议，并在出现空缺时同样召集。

第三附表第一部分接着规范推选本身的程序：

1. **资格。**统治者具备获推选的资格，除非他尚未成年、已通知统治者御玺守护官他
   不愿被推选，或统治者会议以不记名投票方式议决，认为他因精神或身体上的欠佳或任
   何其他原因而不适合。
2. **五票门槛。**此类议决非经至少五位会议成员投票支持，不得通过。
3. **依名单提呈。**统治者会议将该职位提呈给在推选名单中排名第一、且具备资格的
   统治者。若他不接受，提呈即转移至下一个州属，如此类推，直至有统治者接受为止。
4. **宣布。**提呈获接受后，统治者会议宣布他当选，统治者御玺守护官则以书面方式
   将该决定通知国会两院。

统治者会议官方网站说明，投票以不记名方式进行，使用不编号的选票，以笔与墨水填写，
而统治者须获得五票的多数，该职位才会提呈给他。统治者御玺守护官负责选票的分发与点
算。

获推选后，第37(1)条规定，最高元首须在执行其职务之前，于统治者会议前、并在联邦
法院首席大法官在场见证下，宣读并签署第四附表第一部分所载的就职宣誓词。该宣誓由统
治者会议委任的两名人士见证。

## 推选名单：轮值顺序会变动

这是最常被误解的部分。宪法并未订立固定不变的轮值顺序。它订明的是一份**会变动**
的名单。

第三附表第4条就其效力而言，大致如下：

- 就首次推选而言，名单载有所有统治者的州属，按其当时彼此承认的优先顺序排列。
- 每次推选之后，凡排在已获推选统治者所属州属之前的州属，均移至名单末端，而已获
  推选统治者所属的州属则**从名单中除去**。
- 当名单上某个州属发生统治者更替时，该州属会被移至名单末端。
- 当名单上不再留有任何州属时，名单便会**重新编排**：重新纳入所有统治者的州属，
  其中曾经出任最高元首的统治者所属的州属，依其担任该职位的先后顺序排列。
- 依重新编排的名单每次推选之后，排在已获推选统治者所属州属之前的州属会移至末
  端，而已获推选统治者所属的州属则置于最末。

统治者会议官方网站记载，第一轮在霹雳苏丹成为第九任最高元首时结束，此后的推选依重
新编排的名单进行，该名单以曾经出任该职位的统治者所属州属之优先顺序排列，从第一位
排至第九位。

现任在位的最高元首是**第十七任**。根据官方报道，苏丹依布拉欣苏丹依斯干达
（Sultan Ibrahim Sultan Iskandar）自2024年1月31日起开始履任，登基典礼于2024年7月
20日在国家皇宫（Istana Negara）正殿（Balairung Seri）举行，任期五年。

## 依建议行使的权力，与酌情权力

第39条将联邦行政权赋予最高元首。第40条接着说明该项权力如何行使——而这正是整个
主题中最重要的区分所在。

**第40(1)条。**在执行宪法或联邦法律所赋予的职务时，最高元首须依内阁的建议，或
依在内阁一般授权下行事的部长的建议行事，宪法另有规定者除外。同一条文也赋予他权
利，得应其要求，获得内阁所能取得的有关联邦施政的任何资料。

**第40(1A)条。**凡最高元首依规定须依建议、按建议，或于考量建议后行事者，他须
接受并依该建议行事。

**第40(2)条。**他得就三项列明的职能，以及「本宪法所述的任何其他情形」，依自身
酌情行事。

| 类别 | 依宪法条文所列的例子 |
| --- | --- |
| 酌情（第40(2)条） | 委任首相；不批准解散国会的请求；要求召开纯粹涉及统治者特权、地位、尊荣与位阶的统治者会议 |
| 依建议（第40(1)条、第40(1A)条） | 依首相的建议委任其他部长（第43(2)(b)条）；在咨询统治者会议后，依首相的建议委任法官（第122B(1)条） |

第43(2)(a)条订明委任首相的准绳：最高元首须委任下议院议员中**依其判断**可能获
得下议院议员多数信任者为首相。正是「依其判断」这一措辞，使此事成为他本身的考量。

第43(4)条则补足了整个图景：若首相不再获得下议院议员多数信任，首相须提呈内阁总
辞，除非应其要求，最高元首解散国会。

## 宪法赋予的其他职能

- **国会。**第44条规定，国会由最高元首连同上议院（Dewan Negara）与下议院
  （Dewan Rakyat）组成。参见[马来西亚国会](/zh/government/parliament)。
- **会期。**第55(1)条要求他不时召开国会会议，且不得让六个月的时间在某一会期的
  最后一次会议与下一会期的第一次会议之间流逝。第55(2)条规定他可休会或解散国会。
- **御准。**第66(4)条订明三十天的期限，以盖用御玺的方式御准法案。第66(4A)条
  规定，若在该期限内未给予御准，该法案将在期限届满时成为法律，犹如已获御准一样。
- **武装部队。**第41条使他成为联邦武装部队的最高统帅。
- **赦免权。**第42(1)条赋予对军事法庭审理的罪行，以及在吉隆坡、纳闽和布城联邦
  直辖区所犯罪行，给予赦免、缓刑与减刑的权力。
- **伊斯兰教。**第3(5)条使他成为三个联邦直辖区的伊斯兰教首长。第3(2)条规定，
  凡统治者会议同意将某项行为、惯例或仪式推广至整个联邦，其他每一位统治者均授权
  最高元首代表其担任伊斯兰教首长。
- **紧急状态公告。**第150(1)条规定，若最高元首认为存在重大紧急状态，他可发出
  紧急状态公告。

## 宪法对该职位施加的限制

第34条列出他在位期间的若干限制。最高元首不执行其本身州属统治者的职务，惟担任伊
斯兰教首长的职务除外；不担任任何有酬劳的职位；不积极参与任何商业活动；且除国事访
问期间外，未经统治者会议同意，不离开联邦超过十五天。

第32(1)条规定，除在第十五部分所设立的特别法庭之外，不得在任何法院对他提起任何
诉讼程序。第33A条规定，若他在该特别法庭被控以罪行，他须停止执行最高元首的职务，
而该段期间仍计入五年任期之内。

## 副最高元首

第33条设立副最高元首一职，同样由统治者会议推选，任期五年，或为在位最高元首的余
下任期。副最高元首在职位出缺，或最高元首无法执行其职务期间，代为执行其职务，但对
于预料少于十五天的不在场，则不如此行事，除非副最高元首认为有必要或适宜这样做。

第三附表第二部分订明其推选方式，而在最高元首职位出缺期间，统治者会议不推选副最
高元首。

## 对此职位常见的误解

**「轮值顺序依字母顺序或州属大小而定。」**不对。它依第三附表第4条所定的推选名
单进行，该名单在每次推选之后，以及每次州属统治者更替之后，都会以机械化方式重新编
排。

**「统治者会议的所有成员都投票。」**就推选最高元首而言并非如此。第五附表将州
元首列为会议成员，但宪法将推选与罢免最高元首的职能限于统治者本身。

**「他签署法律只是形式而已。」**宪法订明的是一个具体的期限，而非一项没有结构
的形式：第66(4)条所定的三十天，并附有第66(4A)条所载的后果。

**「酌情权即是一般性的权力。」**第40(2)条具体列明酌情职能，并加上「本宪法所述
的任何其他情形」——也就是宪法所述明的情形，而非一个开放式的类别。

**「统治者会议只负责推选最高元首。」**第38(2)条也赋予其其他职能，包括就特定
法律给予同意；而第38(4)条规定，任何直接触及统治者特权、地位、尊荣或位阶的法律，
非经统治者会议同意不得通过。
