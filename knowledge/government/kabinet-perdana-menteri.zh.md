马来西亚没有任何一名选民，会在选票上圈选写着「首相」字样的选项。大选选票
只为单一下议院（Dewan Rakyat）选区的候选人提名。

首相一职是在投票之后，透过写在联邦宪法一个句子里的一项测试来填补的——而
那个句子并未提及政党、联盟，也没有提及议席数目。

## 概览

| | |
| --- | --- |
| 宪法依据 | 联邦宪法第39条至第43C条，第四部分第3章 |
| 谁委任首相 | 最高元首（Yang di-Pertuan Agong），第43(2)(a)条 |
| 委任测试 | 一名在最高元首看来可能获得下议院多数议员信任的下议院议员 |
| 谁委任其他部长 | 最高元首依首相的建议委任，第43(2)(b)条 |
| 部长人选来源 | 国会任一议院的议员——下议院或上议院 |
| 负责方式 | 对国会负集体责任，第43(3)条 |
| 下议院议员人数 | 二百二十二名民选议员，第46(1)条 |
| 宣誓 | Sixth Schedule（第六附表）所载的就职、效忠与保密三项誓言，第43(6)条 |
| 修宪门槛 | 每一议院全体议员人数的三分之二，第159(3)条 |

## 行政权力究竟归属何处

第39条把联邦的行政权赋予最高元首（Yang di-Pertuan Agong）。这项权力可由
最高元首本人行使，也可由内阁行使，或由获内阁授权的任何部长行使——而国会
也可以透过立法，把行政职能赋予其他人。

第43(1)条接着要求最高元首委任一个内阁，**在行使其职能时向他提供意见**。
这正是宪法所采用的表述：内阁的存在，是作为行政权力持有者的咨询机构。

第40(1)条把这个循环补上。最高元首在依宪法或联邦法律行使其职能时，须依照
内阁的意见，或依照在内阁一般授权下行事的某位部长的意见行事，宪法另有规
定者除外。同一条文也赋予最高元首一项权利：他可应其要求，取得内阁所能取
得的、有关联邦施政的任何资料。

第40(1A)条由第A885号法令加入，自1994年6月24日起生效，把这一点表述得更
为坚定：凡最高元首被要求依照意见、按照意见，或在考虑意见之后行事时，他
**须接受该项意见并依照其行事**。

## 委任测试：一个句子，两项条件

第43(2)(a)条规定，最高元首须先委任一名下议院议员出任首相、主持内阁——该
议员须是在最高元首看来，可能获得该议院多数议员信任者。

该句子中只有两项条件：

1. **候选人必须是下议院议员。** 不是上议院。这是第43条中唯一一个仅限于
   一个议院的职位。
2. **在最高元首看来，该候选人可能获得下议院多数议员的信任。** 这项判断
   由最高元首作出。

第43(7)条另设一项限制：透过入籍归化，或依第17条登记而成为公民者，不得被
委任为首相。重印本上的官方注记记载，第17条本身已由第14/1962号法令废除，
自1963年7月1日起生效。

第46(1)条规定[下议院](/zh/government/dewan-rakyat)由二百二十二名民选议
员组成。在一个222人议院中的多数，即至少112名议员。

### 第43条没有规定的事

这是通俗简述中最常被遗漏的部分。第43条的条文**并未**提及：

- 任何政党或联盟的名称；
- 「赢得最多议席的政党」这个概念；
- 确定多数信任的任何特定方法——无论是透过宣誓声明、支持信函、面谈、议院
  表决，还是其他方法。

宪法规定的是**测试**，不是**程序**。下议院多数议员的信任是衡量的标准；
这项衡量如何进行，第43条并未加以成文规定。

## 其他部长：依建议委任，来自两个议院

首相获委任之后，第43(2)(b)条接手。最高元首须依首相的建议，从国会任一议
院的议员中委任其他部长。

留意这与首相的委任有两点不同。其他部长的委任是**依建议**作出，而非由最
高元首自行酌情决定。而且人选范围也更广：[上议院](/zh/government/dewan-negara)
议员同样合资格。

第43(2)条对国会已解散的情形另设一项但书。若某项委任是在国会解散期间作
出，曾任上一届下议院议员者可获委任，但在下一届国会任期开始之后，不得继
续留任——除非：若他获委任为首相，他须是新一届下议院的议员；而在其他任何
情况下，他须是下议院或上议院的议员。

获委任之后，第61(1)条赋予每一位内阁成员权利，可参与国会另一议院的议事程
序，此项权利在其作为本身所属议院议员的权利之外另行赋予。第61(3)条则澄清
其限制：该项权利并不容许非属某议院议员者在该议院内投票。

## 集体负责不仅仅是一项惯例

第43(3)条只有一句简短的条文：内阁须对国会负集体责任。

在许多其他西敏寺体制中，集体负责是一项不成文的惯例。在马来西亚，它被写
入宪法文本本身，成为一项明文规定的义务。

其实际效果，体现在第43(4)条的措辞之中——它把整个内阁的命运，系于首相一
人的地位，而不是系于个别部长的表现。

第38(3)条从另一个角度展示了这种集体负责。当[统治者会议（Majlis Raja-Raja）](/zh/government/majlis-raja-raja)
审议有关国家政策的事项时，最高元首须由首相陪同，而这项审议，本身即属最
高元首依内阁意见行使的职能之一。

## 当多数信任不复存在时

第43(4)条规定，若首相不再获得下议院多数议员的信任，则首相须将内阁辞职，
除非最高元首应其请求解散国会。

条文只列明两条路径，而第二条并不完全操之在首相手中。第40(2)条列出最高
元首可**自行酌情**行使的职能：

| 条文 | 酌情职能 |
| --- | --- |
| 40(2)(a) | 委任首相 |
| 40(2)(b) | 不批准解散国会的请求 |
| 40(2)(c) | 要求召开统治者会议，议程仅限于统治者的特权、地位、荣誉与尊严，以及该次会议上的任何行动 |

第40(2)条以「以及本宪法所述及的任何其他情形」一语作结，因此该清单并非
封闭清单。

若解散发生，第55条接手掌管时间安排。除非提前解散，国会自其首次会议之日
起运作五年，其后自动解散。国会解散后，须在解散之日起六十日内举行大选，
并须在该日起不迟于一百二十日的日期召开国会会议。

## 任期、宣誓与酬金

第43(5)条规定，在符合第43(4)条的前提下，首相以外的部长，其任期由最高元
首决定去留——除非最高元首依首相的建议撤销该部长的委任。任何部长亦可自行
辞职。有关依首相建议撤销委任的措辞，由第10/1960号法令加入，自1960年5月
31日起生效。

「在符合第(4)款的前提下」这句话很重要：当第43(4)条被触发时，辞职涵盖的
是作为一个整体的内阁。

第43(6)条要求每一位部长在行使其职务前，须在最高元首面前宣读并签署Sixth
Schedule（第六附表）所载的三项誓言：就职誓言、效忠誓言，以及保密誓言。

第43(9)条要求国会以立法方式，就内阁成员的酬金作出规定。重印本上的官方
注记，将读者指向《1980年国会议员（薪酬）法令》（第237号法令）。第43(8)
条已由第A857号法令废除，自1993年8月20日起生效。

## 三个常被混淆的其他职位

第43A、43B与43C条各自设立了三个独立的角色，它们常被误认为等同于内阁成
员。

| 职位 | 条文 | 由谁委任 | 须为国会议员？ |
| --- | --- | --- | --- |
| 副部长 | 43A | 最高元首依首相的建议 | 是——任一议院 |
| 国会秘书 | 43B | 首相 | 是——任一议院 |
| 政治秘书 | 43C | 首相 | 否 |

副部长协助部长履行其职责与职能，并为此目的拥有部长的一切权力。第43A(3)
条把第43(5)与43(6)条适用于他们，因此其任期与宣誓义务与部长相同。

国会秘书协助部长与副部长，并为此目的拥有部长与副部长的一切权力。其委任
可由首相随时终止，其保密誓言在首相面前而非最高元首面前宣读。

政治秘书之所以突出，是因为第43C(2)(a)条规定他们**不必**是国会任一议院
的议员。其职责、职能与酬金，由内阁依第43C(4)条决定。

仅就第61条而言，第61(4)条中「内阁成员」的定义包括副部长与国会秘书。

## 常见错误

**「人民投票选出首相。」** 选票是下议院选区选票。首相的委任发生在选举结
果揭晓之后，依据第43(2)(a)条进行。

**「赢得最多议席的政党领袖自动成为首相。」** 第43(2)(a)条的测试是下议院
多数议员的信任。条文并未提及政党，也未提及最多议席。

**「部长可以从国会以外委任。」** 第43(2)(b)条要求部长须从国会任一议院的
议员中选任。只有第43C条下的政治秘书获豁免于这项议员资格要求。

**「上议员不能成为部长。」** 可以——第43(2)(b)条提及的是国会任一议院。
仅限于下议院的限制，只适用于首相。

**「失去多数即意味着大选。」** 第43(4)条把辞职列为默认结果；解散只有在
最高元首批准该项请求时才会发生，而第40(2)(b)条把拒绝该项请求列为一项酌
情职能。

**「集体负责仅仅是一种做法。」** 第43(3)条已在宪法文本中明文规定。

## 修改上述任何规定

第43条中的规定，不能透过普通立法修改。第62(3)条容许国会每一议院依出席
并投票议员的简单多数作出决定，但该款本身明文规定须受包括第159(3)条在内
的其他条文限制。

第159(3)条要求，任何旨在修改宪法的法案，除非在二读与三读时获得**不少于
该议院全体议员人数三分之二**的票数支持，否则不得在国会任一议院通过。

该门槛是按全体议员人数计算，而非按出席投票的人数计算。
