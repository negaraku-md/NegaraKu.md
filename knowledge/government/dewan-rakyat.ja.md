## 概要

| | |
| --- | --- |
| 名称 | 下院（Dewan Rakyat、House of Representatives） |
| 種類 | 二院制国会における選挙により選出される下院 |
| 憲法上の根拠 | 連邦憲法第4部第4章 |
| 議員数 | 222名の民選議員（第46(1)条） |
| 資格年齢 | 18歳以上（第47(b)条） |
| 最長任期 | 最初の会議から5年間（第55(3)条） |
| 定足数 | 議長を務める者を除く26名（下院議事規則第13(1)条） |
| 議長 | 下院議長（第57条） |

マレーシア国内のあらゆる人を拘束する国会法令は、ほとんど目に留まらない出来
事から始まる。すなわち、書記官が議事卓で一件の法案の名称を読み上げ、誰も異
議を唱えないという出来事である。それが一読である。それ以降のすべて——討議、
逐条修正、表決、御裁可——は、その紙片が法律としての効力を得る前に、順を追っ
て満たされなければならない一連の条件にほかならない。

本稿は、その一連の流れを記述的に説明する。誰が下院に議席を占めるのか、彼ら
がどれだけの期間在任するのか、そして憲法が実際にこの議院に何を許しているの
かである。

## 222議席——憲法そのものに定められている

大半の情報源は222という数字で止まっている。しかし憲法はそうではない。第
46(2)条は、その数字を各州及び連邦直轄区へと、条文そのものの中で細分化して
いる——普通の法律によってではなく、また行政命令によってでもない。

| 州／連邦直轄区 | 議席 |
| --- | ---: |
| サラワク | 31 |
| ジョホール | 26 |
| サバ | 25 |
| ペラ | 24 |
| セランゴール | 22 |
| ケダ | 15 |
| クランタン | 14 |
| パハン | 14 |
| ペナン | 13 |
| ヌグリ・スンビラン | 8 |
| トレンガヌ | 8 |
| マラッカ | 6 |
| パーリス | 3 |
| **州の合計** | **209** |
| クアラルンプール連邦直轄区 | 11 |
| ラブアン連邦直轄区 | 1 |
| プトラジャヤ連邦直轄区 | 1 |
| **連邦直轄区の合計** | **13** |
| **総計** | **222** |

国会の公式ポータルが述べるとおり、各議員は一つの選挙区を代表する。この数字
が憲法に規定されているため、これを変更することは憲法改正を意味する——そし
て第159(3)条は、二読及び三読の際に議員総数の3分の2以上の支持を要求してい
る。

222という数字そのものは、2006年1月19日にAkta A1260が219という数字を置き換
えたことにより発効した。議席数の変遷は、第46条の改正記録から直接読み取るこ
とができる：1962年には104名、1963年のマレーシア成立後は159名（シンガポール
からの15名を含む）、1965年以降は144名であった。

## 誰が議員となる資格を有するか

第47条は二つの基本的な要件を定めている——国民であること、そして連邦に居住
していることである。残るは年齢であり——ここで両議院は異なる。

- **下院** —— **18歳**以上。
- **上院** —— **30歳**以上。

第48(1)条は資格喪失の理由を列挙している：精神に異常があると認定されたと
き；未解除の破産者であるとき；報酬を伴う職を保持しているとき；選挙費用の明
細書を提出しなかったとき；有罪判決を受け、無条件の恩赦を受けることなく1年
以上の禁錮またはRM2,000以上の罰金を科されたとき；または外国の国籍を自発的
に取得したときである。

## 5年の時計

下院は永続するものではない。第55条はその周期全体を定めており、その数字は正
確である。

| 規定 | 期限 |
| --- | --- |
| 第55(1)条 | ある会期の最後の会議と次の会期の最初の会議との間に**6か月**を超えて経過してはならない |
| 第55(3)条 | 国会はその最初の会議の日から**5年間**継続し、その後解散する |
| 第55(4)条 | 解散から**60日**以内に総選挙を実施する |
| 第55(4)条 | 国会は解散から**120日**以内に召集されなければならない |

第55(3)条の文言に注意されたい——「それより早く解散されない限り……その後は
解散する」。この自動解散は、いかなる行為もなく生じる。それより早く解散する
権限は、第55(2)条に基づき国王に属する。

休会（Prorogation）は解散ではない。第55(5)条は、未処理の法案が休会によって
失効しないと定めており、第55(7)条は、御裁可を待っている法案が休会または解
散のいずれによっても失効しないよう保護している。

## 法案の経路

第66(1)条は、国会が法律を制定する権限は、両院が可決した法案——または第68条
にいう場合には下院のみが可決した法案——であって、国王が御裁可したものを通じ
て行使されると定めている。下院議事規則は、その手続きの詳細を定めている。

1. **一読。** 議事規則第48条に基づき、大臣は少なくとも1日の通知を行った
   後、議院の命令を要することなく法案を提出することができる。法案の名称は
   書記官が議事卓で読み上げる。討議は行われない。
2. **二読。** 議事規則第53条は、一読後できるだけ早く通知を発することを求
   めており、議事規則第53(2)条は、法案が議員に送付されるまで二読を行うこ
   とを禁じている。この段階の討議は原則に関するものである。
3. **委員会段階。** 議事規則第54(2)条：二読を経た後、法案は全院委員会
   （Committee of the Whole House）に付託される——ただし議院が選考委員会
   （Jawatankuasa Pilihan）への付託を求める動議を可決した場合を除く。議事
   規則第54(1)条は、二読の前に選考委員会へ付託することを認めている。この
   段階で条項が一つずつ審査される。
4. **三読。** 議事規則第61(1)条は、審議をその法案の内容に限定している。
5. **上院、**そして**御裁可。** 第66(3)条は、法案をもう一方の議院に送付す
   る。

表決は、憲法が特別多数を要求する場合を除き、投票した議員の普通多数によって
決せられる（第62(3)条）。議長を務める者は、同数となることを避ける必要があ
る場合にのみ投票し、それ以外のいかなる場合にも投票することができない。第
62(5)条は、出席していない議員が投票することを禁じている。

国王には御裁可のための**30日**の期間がある（第66(4)条）。その期間が経過し
た場合、第66(4A)条は、当該法案が「あたかも御裁可を与えたのと同じ方法で」法
律となると定めている。第66(5)条はさらに一つの最終的な条件を加えている：い
かなる法律も、公布されるまでは効力を生じない。

## 下院が単独で有する二つの権限

ここが、簡略な説明において最も見落とされがちな部分である。

**財政はここから始まる。** 第67(1)条は、財政に関する規定の七つの類型を列
挙している——租税の賦課または引上げ、連邦による借入、統合基金（Consolidated
Fund）からの支出、及び会計の監査などである。そのような規定を含む法案または
修正案は、**大臣以外の者が提出または動議することができず**、また**上院で開
始することができない**。その資格は、財政を所管する大臣が、当該規定が付随的
なものにとどまらないことを示すことに依拠している。

**上院は遅延させることができるが、阻止することはできない。** 第68条は二つ
の異なる時計を定めている：

| 法案の種類 | 上院が可決しなかった場合の効果 |
| --- | --- |
| 金銭法案 | 会期終了の少なくとも**1か月**前に上院に送付される；**1か月**以内に修正なく可決されなかった場合、下院が別段の指示をしない限り国王に提出される |
| その他の法案 | 下院は次の会期において再びこれを可決することができるが、最初に可決されてから**1年を経過する前であってはならない**；上院が再度これを可決しなかった場合、御裁可のため提出される |

二つの細目がこの権限を強化している。第68(6)条は、「金銭法案」の定義を**下
院議長の意見**に委ねている。そして第68(4)条は、同条の規定が遵守された旨の
議長による証明を要求している——その証明は「あらゆる目的について最終的なも
のであり、いかなる裁判所においても争うことができない」。

第68(5)条はその限界を設けている：この仕組みは憲法改正法案には適用されな
い。ただし第159(3)条の適用が除外される改正案はこの限りでない。

## 監督機能

第43(3)条は、その基礎を一文で定めている——「内閣は国会に対して連帯して責任
を負う」。第43(2)(a)条は、首相が、国王の見解において下院の多数議員の信任を
得る可能性が高いと判断される下院議員の中から任命されると定めており、第
43(4)条は、その信任が失われた場合の結果を定めている。

その日常的な監督の手段は、下院議事規則の中に定められている。

- **質問。** 議事規則第21(1)条は、大臣に対し、その職務の範囲内の事項につ
  いて質問を行うことを認めている。議事規則第22(2)条は、会議開始の10営業日
  前までに書面による通知を行うことを求めており、議事規則第22(3)条は、各議
  員が一つの開会日について提出できる「口頭回答」と表示された質問を3件まで
  に制限している。
- **公共会計委員会（Public Accounts Committee）。** 議事規則第77条は、こ
  の委員会が各国会の当初に任命され、マレーシア政府の会計及び第107条に基づ
  き提出される会計検査院長（Ketua Audit Negara）の報告書を検査すると定め
  ている。委員会は、議院が任命する委員長及び副委員長並びに6名から12名の議
  員から構成される。議事規則第77(4)条は、大臣が委員長を務めることまたは委
  員となることを禁じており、議事規則第77(5)条は、証人の出席を求め、書類及
  び記録の提出を求める権限を委員会に与えている。
- **特権。** 第63(1)条は、議事の有効性を裁判所の管轄権の外に置いており、
  第63(2)条は、議事に参加している間に発言された事項または投じられた票に
  ついて、何人も裁判所の訴訟から保護する。

## よくある誤り

**「国会の任期はちょうど5年である。」** 第55(3)条が測る5年は、選挙の日から
ではなく、**最初の会議の日**からである。第55(1)条は、会期間について6か月と
いう別個の上限を定めている。

**「議長は必ず国会議員でなければならない。」** 第57(1)(a)条は、議員として
選出される*資格*を有する者であれば、たとえ議員でなくとも選出されることを認
めている。

**「すべての空席は補選をもたらす。」** 第54(1)条の但書は、第55(3)条に基づ
き国会が解散する予定の日から2年以内に確認された空席については、議長が多数
派の議席数が影響を受ける旨を選挙委員会に書面で通知しない限り、補充されない
と定めている。

**「国会が休会になると法案は失効する。」** 第55(5)条は、未処理の法案につい
てはその逆を定めている。

**「国会の権限には限りがない。」** 第九附表（Ninth Schedule）は、事項を連邦
事項表（Federal List）、州事項表（State List）及び共同事項表（Concurrent
List）に区分している——[マレーシア国会](/government/parliament)及び
[連邦憲法](/law/federal-constitution)を参照。

## 次のステップ

第44条における上院及び国王の位置づけを含む、連邦立法機関全体の概観について
は、[マレーシア国会](/government/parliament)を参照されたい。第159条に基づ
く改正手続きを含む、上記のすべての限界を定める文書の構造については、
[連邦憲法](/law/federal-constitution)を参照されたい。サラワク及びサバが第
46(2)条に列挙されたとおりの議席数を有する背景は、
