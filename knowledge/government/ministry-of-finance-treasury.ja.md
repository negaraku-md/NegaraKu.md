  - q: "財務省と国庫（Perbendaharaan）はどう違うのか？"
    a: "両者は同一の機関を指すが、階層が異なる。「財務省」（Kementerian Kewangan、Ministry of Finance）は政策面での省であり、財務大臣が率いる。「国庫」（Perbendaharaan、Treasury）はその省の中核的な行政機構であり、財務省事務総長が率いる。MOF公式ポータルによれば、国庫（Perbendaharaan Malaysia）はこの省の下の主要な部局として掲載されており、関税局、会計総監（会計局）及び評価・不動産サービス局が他の部局として挙げられている。（ランカウイ開発局（LADA）はこの省の下の法定機関であるが、MOFポータルでは行政上、部局と並んで掲載されている。）"
  - q: "マレーシアの財務大臣は誰か？"
    a: "第一財務大臣は首相ダト・スリ・アンワル・イブラヒムである。同氏を、第二財務大臣ダト・スリ・アミル・ハムザ・アジザン、及び財務副大臣ダトゥ・リュー・チンタン（Datuk Liew Chin Tong）——2025年12月17日の内閣改造で就任——が補佐している。この省の公務員トップは財務省事務総長ダトゥ・ジョハン・マフムード・メリカン（Datuk Johan Mahmood Merican）である。"
  - q: "予算案は毎年いつ提呈されるのか？"
    a: "連邦予算案は通常、翌年度の会計年度に向けて、その年の最終四半期に提呈される。2026年予算案は、財務大臣により2025年10月10日に下院で提呈された。その後、政策段階及び委員会段階で討議され、歳出法として可決される。"
  - q: "政府債務の総額に法的な上限はあるのか？"
    a: "ある。それぞれ官報告示された借入法令のもとで、マレーシア政府証券（MGS）、マレーシア政府投資発行証券（MGII）及びマレーシア・イスラム国庫証券（MITB）の合計はGDPの65%を、海外借入はRM350億を、そして国庫証券（MTB）はRM100億を、それぞれ超えてはならない。この三つの上限は『Fiscal Outlook 2026』第4節（図1及び表4.2）で確認されている。さらに、Akta 850は、債務総額がGDPの60%を超えないという中期目標を定めている。"
  - q: "マレーシア国立銀行は財務省の一部なのか？"
    a: "マレーシア国立銀行は財務省傘下の機関であり、この省の組織の一部として掲載されているが、金融政策の運営面では自律的な中央銀行である。財務大臣は中央銀行との関係において政府を代表するが、政策金利の決定は中央銀行自身が行う。"
  - q: "下院で予算案が可決されなかった場合、何が起こるのか？"
    a: "歳出法案は、政府に対する財政的信任の試金石である。それは金銭法案であるため、下院で発議されなければならず、提出できるのは一人の大臣のみである。下院が政府の予算配分を否決した場合、それは通常、多数派の信任を失ったものと解釈される——連邦憲法第67条及び第68条のもとでの下院の財政権限を参照。"

連邦政府が支出するすべてのリンギット——地方病院の看護師の給与から、ロンドンの債券保有者への利払いに至るまで——は、同じ一つの会計の門を通過する：国庫（Perbendaharaan Malaysia）である。財務省はその門を握る省であり、2024年初頭以降、それを法律に明記された一連の数値上限のもとで握っている。

本ページでは、この省が実際に何を行っているのかを説明する：予算案がどのように編成・可決されるか、誰が国庫を率いるか、国債の規模とその上限はどれほどか、そしてどの部局・機関がその傘下にあるかである。

## 財務省は実際に何を行っているのか？

財務省は、国家の貸借対照表の両側——入ってくる歳入と出ていく歳出——を所管する。財政政策を策定し、連邦予算案を編成し、政府借入の調達及び返済を管理し、政府の会計及び国庫を統制し、他の省庁・部局・法定機関の財務管理を監督する。

また、国家金融システムを主導する省でもある。傘下の機関を通じて、財務省は直接税及び間接税の当局、資本市場、預金保険、並びに公共部門融資を監督する。2023年公共財政及び財政責任法（Public Finance and Fiscal Responsibility Act 2023、Akta 850）——現在、この省の財政管理を拘束する法律——は、この職権を責任ある財政管理の四つの原則に集約している：マクロ経済の安定を確保すること、持続可能な財政均衡を達成すること、慎重な債務水準を維持すること、そして財政リスクを効果的に管理することである。

## 誰が国庫を率いるのか？

しばしば混同される二つの指導層が存在する。政治層は財務大臣が率いる——現在は首相自身が第一財務大臣を兼任しており、第二財務大臣ダト・スリ・アミル・ハムザ・アジザン、及び財務副大臣ダトゥ・リュー・チンタン（2025年12月17日就任）が補佐する。公務員層は**財務省事務総長**が率いる。同事務総長は国庫を率いる上級官僚であり、数多くの金融法定機関の理事会を主宰する。

財務省事務総長の下には、政策、管理及び投資をそれぞれ担当する三人の副事務総長がおり、国庫の中核部門を監督している。

| 国庫の中核部門 | 役割 |
| --- | --- |
| 国家予算局 | 年次予算案を編成・調整する |
| 税務部門 | 直接税及び間接税の政策 |
| 財政・経済部門 | 財政分析、予測及び目標設定 |
| 政府調達部門 | 公共調達の政策及びガバナンス |
| 信用報告機関登記官事務所 | 信用報告機関を規制する |
| 法定機関戦略管理部門 | 法定機関の監督 |

国庫はまた、サバ州及びサラワク州における連邦国庫、並びに税務紛争を審理する所得税特別コミッショナー及び関税不服審判所を運営している。

## どの部局と機関がその傘下にあるのか？

財務省の構造は、公務員制度の一部である**部局**と、その大半が独自の理事会を持つ法定機関又は政府会社である**機関**とに分かれている。

| MOF傘下の部局 | 機能 |
| --- | --- |
| 国庫（Perbendaharaan Malaysia、Treasury） | 省の中核機構 |
| マレーシア王立関税局（Jabatan Kastam Diraja Malaysia、RMCD） | 間接税——SST、消費税、関税 |
| 会計総監（会計局、Jabatan Akauntan Negara Malaysia） | 政府の会計及び支払い |
| 評価・不動産サービス局（Jabatan Penilaian dan Perkhidmatan Harta、JPPH） | 政府不動産の評価 |

| MOF傘下の機関／法定機関 | 役割 |
| --- | --- |
| マレーシア国立銀行（Bank Negara Malaysia） | 中央銀行；金融政策及び銀行監督 |
| マレーシア証券委員会（Suruhanjaya Sekuriti Malaysia） | 資本市場の規制 |
| ブルサ・マレーシア（Bursa Malaysia Berhad） | 証券取引所 |
| 内国歳入庁（Lembaga Hasil Dalam Negeri、LHDN） | 直接税——所得税、印紙税、CKHT |
| 従業員積立基金（Kumpulan Wang Simpanan Pekerja、KWSP） | 民間部門の退職貯蓄 |
| [公務員退職基金](/companies/kwap)（Kumpulan Wang Persaraan (Diperbadankan)、KWAP） | 公共部門の年金 |
| マレーシア預金保険公社（Perbadanan Insurans Deposit Malaysia、PIDM） | 預金保険及びタカフル保険 |
| ナショナル貯蓄銀行（Bank Simpanan Nasional） | 貯蓄銀行 |
| ラブアン金融監督庁（Lembaga Perkhidmatan Kewangan Labuan、Labuan FSA） | ラブアン・オフショア金融センターの規制 |
| 公共部門住宅融資局（Lembaga Pembiayaan Perumahan Sektor Awam、LPPSA） | 公務員向け住宅融資 |
| ランカウイ開発局（Lembaga Pembangunan Langkawi、LADA） | [ランカウイ](/tourism/langkawi-visitor-guide)の地域開発（第423号法令のもとでの法定機関） |

注：ランカウイ開発局（LADA）は、1990年ランカウイ開発局法（Akta Lembaga Pembangunan Langkawi 1990、第423号法令）のもとで法定機関として設立された。MOF公式ポータルは、行政上これを国庫、関税局、会計総監及びJPPHとともに「部局」のグループに掲載しているが、法律上は法定機関である。

ここに挙げた機関のうち、一般の人々が最も頻繁に言及するのは二つである。どちらも税を徴収するからだ：直接税を扱う**LHDN**と、間接税を扱う**関税局**である。両者は同じ省の傘下にあるが、別個の当局である——[LHDN](/government/lhdn)及び[マレーシア王立関税局](/government/rmcd-kastam)を参照。

## 連邦予算案はどのように編成・可決されるのか？

予算案は一つの演説ではない。数か月にわたるプロセスであり、一つの法律をもって終わる。国家予算局が各省庁からの支出提案を調整し、財政・経済部門が歳入及び成長を予測し、財務大臣が予算案の日を前に最終的な方針を固める。

国会での経路は次のとおりである：

1. **提呈（予算案の日）。** 財務大臣が下院（Dewan Rakyat）において予算案演説及び**歳出法案（Rang Undang-Undang Perbekalan、Supply Bill）**を提呈する。2026年予算案は2025年10月10日に提呈された。
2. **政策段階。** 下院は予算案全体を討議し、その後、政策段階での可決を投票にかける。
3. **委員会段階。** 下院は省庁ごとに予算配分を精査する。例えば、特定の三つの省庁への予算配分は、この段階で2025年11月10日に可決された。
4. **上院（Dewan Negara）。** 下院で可決された後、上院に送付される。
5. **国王の裁可と歳出法。** 裁可を受けると、それはその年の支出を認める歳出法（Akta Perbekalan）となる。

重要な憲法上の特徴が一つある：歳出法案は**金銭法案**である。これは、提出できるのが一人の大臣のみであること、下院で発議されなければならないこと、そして上院はそれを遅延させることしかできず——阻止することはできないことを意味する。連邦憲法第67条及び第68条のもとでの下院の財政権限の詳細は、[下院](/government/dewan-rakyat)及び[法案はいかにして法律になるか](/law/how-a-bill-becomes-law)で説明されている。

## 2026年予算案の資金はどこへ向かうのか？

2026年予算案の総動員額はRM4,700億であり、2025年のRM4,520億から増加した。このRM4,700億という数字は、そのすべてが連邦政府の直接支出というわけではない——通常の予算を経由しない政府系投資会社（GLIC）の投資や官民パートナーシップ（PPP）事業も含まれている。

| 内訳 | 金額 |
| --- | ---: |
| 経常支出 | RM3,382億 |
| 開発支出 | RM810億 |
| **中核連邦予算** | **RM4,192億** |
| GLIC投資 | RM300億 |
| 官民パートナーシップ（PPP） | RM100億 |
| 連邦法定機関及びMKD（財務大臣（法人）、Menteri Kewangan Diperbadankan）系企業 | RM108億 |
| **総動員額** | **RM4,700億** |

歳入面では、政府は2026年についてRM3,431億の徴収を目標としており、2025年の見積りRM3,341億から増加している。歳入と歳出の差が財政赤字であり、2026年についてはGDPの3.5%を目標としている——2025年の3.7%から低下する。この3.7%という数字は、2025年通年の実績値であり、当初目標の3.8%を上回った（2024年：4.1%）。

## 連邦債務はどれほどの規模で、その上限は何か？

歳出が歳入を上回るとき、政府はその差を埋めるために借入を行う——そして何年にもわたって積み重なった借入が連邦債務となる。GDPに対する債務比率は、最も頻繁に監視される指標である。2026年3月末までに、この比率は2025年末の65.2%から**GDPの63.1%**へと低下した——これは、数年連続で赤字を縮小させてきた財政健全化の成果である。

連邦財政赤字は段階的に縮小してきた：2022年はGDPの5.5%、2023年は5.0%、2024年は4.1%、2025年は3.7%（実績値、目標の3.8%を上回る）、そして2026年はGDPの3.5%を目標としている。

政府は自由気ままに借入を行うことはできない。四つの主要な法令がその借入を規律しており、それぞれ官報告示された金融商品及び上限を有する：

| 借入法令 | 金融商品 | 法定上限 |
| --- | --- | --- |
| Loan (Local) Act 1959 [Akta 637] | MGS、MGII | MGS＋MGII＋MITBの合計がGDPの65%を超えないこと |
| Government Funding Act 1983 [Akta 275] | MITB、Market Loans、Project Loans | （上記のGDP65%の上限に含まれる） |
| External Loans Act 1963 [Akta 403] | 海外借入 | RM350億を超えないこと |
| Treasury Bills (Local) Act 1946 [Akta 188] | MTB | RM100億を超えないこと |

注：MGSはマレーシア政府証券（Malaysian Government Securities）、MGIIはマレーシア政府投資発行証券（Malaysian Government Investment Issues、シャリア準拠）、MITBはマレーシア・イスラム国庫証券（Malaysian Islamic Treasury Bills）、MTBはマレーシア国庫証券（Malaysian Treasury Bills）である。これら三つの法令の数値上限は『Fiscal Outlook 2026』（第4節、151ページの図1及び161ページの表4.2）で確認されており、同書は2025年6月末時点の実績値も記録している：法定債務MGS＋MGII＋MITBはGDPの63.5%、海外借入はRM228億、MTBはRM20億——いずれも上限の範囲内である。

これらの法令は、政府に対し、開発支出の資金調達及び既存債務の借換えのためにのみ借入を行うことを義務付けており——日々の経常支出のためではない。連邦債務の大部分はリンギット建てであり、国内資本市場から調達されている；海外借入はRM350億の閾値を大きく下回る水準にとどまっている。

## Akta 850は何を求めているのか？

2024年以前、法定債務上限は、2020年政府資金調達（新型コロナウイルス（COVID-19））暫定措置法（Temporary Measures for Government Financing (Coronavirus Disease 2019 (COVID-19)) Act 2020）のもとで、GDPの60%から65%へと一時的に引き上げられ、COVID-19基金の上限も、パンデミックによる景気刺激及び経済回復のパッケージに資金を供するため、RM650億からRM1,100億へと引き上げられた。パンデミック後の改革の一環として、政府は**2023年公共財政及び財政責任法（Public Finance and Fiscal Responsibility Act 2023、Akta 850）**を導入し、同法は2024年1月1日に施行された。

Akta 850は、財政管理の報告及び制限の方法を変えた。同法は、その別表第一（First Schedule）において**数値**で測定される財政目標を定めている：

| 財政目標（別表第一、Akta 850） | 数値 |
| --- | ---: |
| 年間開発支出の最低額（GDP比） | 3% |
| 財政均衡（GDP比） | -3% |
| 債務水準（GDP比） | 60% |
| 金融保証（GDP比） | 25% |

s.18(1)は、政府債務の総額が別表第一に定めるGDP比率——すなわち60%という中期目標——を超えてはならないと規定している。これはAkta 850の**中期目標**であり、個別の借入法令のもとで今なお官報告示されている65%の上限とは異なる点に留意されたい；現在の63.1%という比率は、60%の目標に向かいながらも、65%の法定上限の範囲内にある。これら四つの財政目標——GDPの25%という金融保証の上限を含む——は、三年から五年の中期のうちに達成されなければならない。

Akta 850はまた、財政政策の実施を監督するため**財政政策委員会**（s.28）を設置し、財政リスク報告書を含む各種財政報告書の発行を義務付けている。同法の原則に述べられているとおり、その目的は透明性と世代間の公平性にある——今日の借入が将来世代の福祉を損なわないようにするためである。

## 判断の枠組み：あなたの用件はどの機関か？

国家の金融機能の実に多くが一つの省の下に集約されているため、人々はしばしば誤った窓口に連絡してしまう。以下の対応表を用いること：

- **所得税、印紙税、不動産譲渡益税、e-Invois** → [LHDN](/government/lhdn)であり、財務省に直接ではない。
- **売上・サービス税（SST）、消費税、輸入関税** → [マレーシア王立関税局](/government/rmcd-kastam)。
- **政府の支払及び会計、連邦財務諸表** → 会計総監（会計局）。
- **民間部門の退職貯蓄（KWSP拠出金）** → 従業員積立基金。
- **銀行預金の保護** → マレーシア預金保険公社（PIDM）。
- **資本市場投資、ブローカーに関する苦情** → マレーシア証券委員会。
- **金融政策、金利、銀行規制** → マレーシア国立銀行。
- **予算案及び財政政策全般** → 財務省（国庫）。

## よくある誤解

**「財務省が税を徴収している。」** この省は税務政策を定めるが、徴収を行うのは傘下の機関である——直接税はLHDN、間接税は関税局が担う。税務に関する問い合わせを省に送っても、転送されるだけである。

**「2026年予算案のRM4,700億はすべて政府支出である。」** この金額は総動員額であり、GLIC投資やPPP事業も含んでいる。中核連邦予算——経常支出と開発支出——はRM4,192億である。

**「国債の上限は60%である。」** Akta 850のもとでのGDP比60%という中期目標は、借入法令のもとで今なお官報告示されているGDP比65%の法定上限とは同じものではない。現在の比率は、この二つの数字の間に位置しうる。

**「マレーシア国立銀行は国庫の一部である。」** マレーシア国立銀行はこの省の傘下の機関であるが、運営面で自律的な中央銀行である。政策金利の決定は中央銀行自身が行うのであって、財務大臣ではない。

**「予算案は提呈されるとすぐに法律になる。」** 提呈はあくまで始まりにすぎない。予算案は、下院での政策段階及び委員会段階を経て、その後上院と国王の裁可を経てはじめて、歳出法となる。
