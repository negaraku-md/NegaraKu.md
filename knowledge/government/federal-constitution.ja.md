マレーシアで可決されるあらゆる法律——連邦国会によるものであれ、州議会（Dewan Undangan Negeri）によるものであれ——は、一つの単一の文書を基準として測ることができる。その法律がこの文書に抵触する場合、その法律は抵触する限度において無効とみなされうる。その文書こそが連邦憲法（Perlembagaan Persekutuan）である。

本稿は三つの事柄を記述的に説明する。憲法が自らを「最高」と称するとき何を意味するのか、その文本がどのように編成されているのか、そしてそれを改正するために定められた手続である。

## 概要

| | |
| --- | --- |
| 名称 | 連邦憲法（Perlembagaan Persekutuan） |
| 種類 | 連邦の最高法規（第4条） |
| 発効 | 独立記念日（Hari Merdeka）、第160条により1957年8月31日と定義される |
| 構成 | 第1編～第15編（第12A編を含む）及び十三の附則 |
| 改正手続 | 第159条 |

## 「最高法規」とは何を意味するか？

第4条(1)は次のように規定している："This Constitution is the supreme law of the Federation and any law passed after Merdeka Day which is inconsistent with this Constitution shall, to the extent of the inconsistency, be void."（本憲法は連邦の最高法規であり、独立記念日以降に可決された、本憲法に抵触するいかなる法律も、その抵触する限度において無効とする。）簡潔に言えば、憲法は、独立記念日以降に可決された他の法律の有効性を測る基準として自らを位置づけている。

第4条には手続的な規定も含まれている。それに続く各項は、法律の効力に対する異議申立てに関する制限を定めており、特定の理由に基づき当該法律が無効である旨の宣言がなされる前に、連邦裁判所（Mahkamah Persekutuan）の裁判官の許可を得ることを要求している。他方、第160条は「Merdeka Day」（独立記念日）を1957年8月31日と定義している——これは第4条(1)自体が言及する基準日である。

## 憲法はどのように編成されているか？

憲法の文本は十五の編に編成されている。各編は、テーマ別に条文をまとめている。

| 編 | 標題 |
| --- | --- |
| I | 各州、宗教及び連邦の法律 |
| II | 基本的自由 |
| III | 市民権 |
| IV | 連邦 |
| V | 各州 |
| VI | 連邦と各州との関係 |
| VII | 財政規定 |
| VIII | 選挙 |
| IX | 司法機関 |
| X | 公共サービス |
| XI | 破壊活動、組織的暴力、並びに公衆に害を及ぼす行為及び犯罪に対抗する特別権限、及び緊急事態における権限 |
| XII | 一般及び雑則 |
| XIIA | サバ州及びサラワク州のための追加的保障 |
| XIII | 暫定及び経過規定 |
| XIV | 統治者の主権に関する適用除外 |
| XV | 国王（Yang di-Pertuan Agong）及び統治者に対する訴訟手続 |

第12A編は、1963年に連邦が結成された際にサバとサラワクを組み入れるために挿入されたものである。[連邦と州の権限配分](/government/federal-state-division)を参照。この編成は、中核となる機関——第4編にある[国会](/government/parliament)、第9編にある司法機関、そして第38条を通じて第4編に置かれる統治者会議（Majlis Raja-Raja）——がそれぞれ文本の中に定まった位置を持つことを意味する。

## 附則には何が定められているか？

編のほかに、憲法には主要な文本の後ろに置かれた十三の附則がある。附則には、特定の条文が引用する詳細事項が定められている。その主なものは以下のとおりである。

- **Third Schedule（第三附則）** — 国王及びその代理の選出手続。
- **Fifth Schedule（第五附則）** — 統治者会議の構成員及び手続。
- **Ninth Schedule（第九附則）** — 立法権限を配分する連邦リスト、州リスト及び共通リストからなる。
- **Thirteenth Schedule（第十三附則）** — 選挙区の画定に関する規定。

公式重印版の目次によれば、一部の附則（例えばTwelfth Schedule（第十二附則））は廃止されているが、編成上は引き続き記載されている。

## 憲法はどのように改正されるか？

改正手続は第159条に定められている。第159条(1)は、同条の他の規定及び第161E条に従うことを条件として、憲法の規定は連邦法律によって改正することができると規定する。しかし、この「連邦法律」がすべて同じ方法で可決されるわけではない。第159条自体が、いくつかの異なる経路を定めている。

| 経路 | 規定 | 要件 |
| --- | --- | --- |
| 3分の2の多数 | 第159条(3) | 改正法案は、第二読会及び第三読会において、国会各院の全議員総数の3分の2を下回らない票数によって支持されなければならない |
| 通常多数（適用除外） | 第159条(4) | 特定の改正は第159条(3)の要件から除外される——その中には、Second Schedule（第二附則）第3部又はSixth Schedule（第六附則）若しくはSeventh Schedule（第七附則）の改正、特定の立法権限に付随し若しくはそれから生じる改正、並びに州の連邦加入に関する改正が含まれる |
| 統治者会議の同意を要するもの | 第159条(5) | 特定の規定の一覧の改正は、統治者会議の同意なしには可決することができない |

第159条(6)は、同条において「改正」には追加及び廃止が含まれると明らかにしている。

第159条(3)はまた、別の一類の法案——第10条(4)のもとで可決された法律を改正するための法案——についても、同じ3分の2の閾値に服するとして言及している。

## 3分の2を超える票数が必要となるのはどの規定か？

一部の規定については、両院における3分の2の支持だけでは十分ではない。第159条(5)は、その改正が[統治者会議](/government/majlis-raja-raja)の同意なしには可決できない規定を列挙している。

- 第10条(4)及びそのもとで可決された法律；
- 第3編（市民権）の規定；
- 第38条、第63条(4)、第70条、第71条(1)、第72条(4)；
- 第152条及び第153条；並びに
- 第159条(5)項自体。

さらに、第159条(1)は、改正権限全体を第161E条——サバ州及びサラワク州の憲法上の地位に対する保障を含む、第12A編内の規定——に服させている。第159条(4)(bb)と第161E条を合わせた効果は、サバ及びサラワクに関わる特定の改正が、通常の経路とは別に扱われるというものである。

## よくある誤解

**「すべての憲法改正には3分の2の票数が必要である。」** 第159条(4)は、いくつかの種類の改正を3分の2の要件から除外しており、それらの種類は通常多数で可決することができる。

**「3分の2の票数さえあれば、いかなる改正にも十分である。」** 第159条(5)に列挙された規定については、統治者会議の同意が追加の要件として必要であり、サバ及びサラワクに関する事項については第161E条が適用される。

**「憲法は1963年のマレーシア成立時に効力を生じた。」** 第160条は独立記念日を1957年8月31日と定義しており、原文はその日付にマラヤ連邦憲法（Perlembagaan Persekutuan Tanah Melayu）として効力を生じ、その後サバ及びサラワクが連邦に加入した際に適用が拡大された。

## 次に読むべきもの

憲法の規定が実際にどのように機能するかを見るには、[マレーシア国会](/government/parliament)——第159条のもとでの改正を含む連邦法律を可決する機関——、及び[統治者会議](/government/majlis-raja-raja)——第159条(5)に列挙された規定についてその同意が必要とされる機関——から始めるとよい。

Ninth Schedule（第九附則）のもとでの連邦と州との間の権限配分については、[連邦と州の権限配分](/government/federal-state-division)を参照のこと。

第4条、第159条及び第160条の全文は、検事総長室（Jabatan Peguam Negara）が管理するマレーシア法律ポータル（Portal Perundangan Malaysia）上の連邦憲法公式重印版で読むことができる。
