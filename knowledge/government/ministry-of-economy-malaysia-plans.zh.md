每当首相在下议院站起来提呈国家的五年期发展蓝图时，他手中那本厚厚的文件并非
凭空出现。它是由一个大多数人鲜少留意的部门——经济部——耗费数年编制而成。而
这个部门本身，以其目前的形态而言也算年轻，尽管它所从事的工作早在完全独立之前
就已经开始。

## 概览

| | |
| --- | --- |
| 名称 | 经济部（Ministry of Economy） |
| 类型 | 联邦部门 |
| 成立 | 第十五届全国大选后；于2022年12月23日接手EPU的职能 |

| 网站 | `ekonomi.gov.my` |

## 经济部究竟做什么

经济部既不是每天替政府花钱的部门，也不是负责征税的部门。它的工作是**规划**
——为国家未来数年设定发展方向，然后决定拨出多少发展资源、投向何处。

根据该部自己的职能页面，其任务可分为四大类：

- **社会经济发展规划**——在国家、区域与州层面制订中长期社会经济发展蓝图；
  开展研究并就经济事务向政府提供建议；强化包容性发展，包括土著议程；以及
  制订与石油天然气相关的能源政策。
- **拨款资源分配**——设定发展开支的上限与分配，并对开支超过**5000万令吉**的
  发展项目实施价值管理（value management）。
- **执行、统筹与监督**——追踪国家发展计划与倡议的进展，并执行该部本身的
  计划。
- **利益相关方协调**——担任社会经济规划机构的国家秘书处，包括国家经济行动
  理事会与国家发展规划委员会。

最有用的划分方式是：经济部**规划并拨配**发展，而由财政部提呈的[联邦财政
预算案](/economy/federal-budget)则逐年把当中的部分规划转化为实际的令吉款项。

## 从EPU到经济部

这个机构已多次变换形态，但其核心使命——编制国家发展蓝图——在历次重组中始终
不变。

故事始于**1956年4月24日**成立的**经济秘书处**，用以支持联邦政府会议经济
委员会。**1961年**，它改组为首相署辖下的**经济策划署（EPU）**。到了
**1970年**，EPU开始在总监制度下运作，Tan Sri Dato' Thong Yaw Hong（汤耀荣）
出任首任总监。

接着是一连串与政治相关的重组：

| 日期 | 变动 |
| --- | --- |
| 2018年 | 第十四届全国大选后，EPU改组为经济事务部（MEA） |
| 2019年12月18日 | EPU正式裁撤；其角色与职能由MEA接手 |
| 2020年3月10日 | EPU在首相署辖下重新设立 |
| 2022年12月23日 | 第十五届全国大选后，EPU再次被裁撤；其职责移交予新成立的经济部 |

也就是说，当你在政策文件中读到旧有的"EPU"或"经济策划署"字眼时，它所指的
职能如今归属经济部。部长一职也几度易手：在拉菲兹·南利（Rafizi Ramli）于
2025年6月17日生效辞职后，阿克玛·纳斯鲁拉·莫哈末·纳西（Akmal Nasrullah
Mohd Nasir）于2025年12月16日获委为经济部长——职位轮替，但部门与其使命
维持不变。

## 马来西亚计划：该部的主要成果

经济部最广为人知的成果是**马来西亚计划（RMK）**——国家的五年期中期发展蓝图。
正是该部统筹其编制工作，提出宏观经济目标，并通过自上而下与自下而上相结合的
方式，向所有部门与机构发出规划指南。

在送抵国会之前，草案要经过一连串核准：由国家总秘书主持的**国家发展规划委员会
（JPPN）**，接着是首相特别委员会，再来是内阁，最后以**动议**形式提交国会
辩论与核准——而非以法案形式。

这一传统的起源，比"马来西亚计划"这一名称本身还要早。第一马来西亚计划涵盖
1966至1970年，此后这一周期便不曾中断：

| 计划 | 期间 |
| --- | --- |
| 第一至第五马来西亚计划 | 1966-1990 |
| 第六至第十马来西亚计划 | 1991-2015 |
| 第十一马来西亚计划 | 2016-2020 |
| 第十二马来西亚计划（RMKe-12） | 2021-2025 |
| 第十三马来西亚计划（RMK13） | 2026-2030 |

RMKe-12（2021-2025）以**"繁荣、包容、可持续的马来西亚"**为主题，聚焦于以
私人领域作为发展引擎、以包容性发展消除贫困与收入差距、朝低碳国家迈进的绿色
发展，以及对沙巴与砂拉越基础设施与基本服务的专项关注。现行版本
**RMK13（2026-2030）**以**"重塑发展"**为主题。每份计划的完整细节——支柱、
目标与投资数额——详见[马来西亚计划](/economy/malaysia-plans)一文。

## 经济部辖下的机构

除了编制马来西亚计划，经济部还监管若干负责统计、区域发展与土著议程工作的
部门与机构：

- **马来西亚统计局（DOSM）**——其主要部门，负责编制经济、社会、人口与环境
  方面的官方统计数据。参见[DOSM——马来西亚统计局](/government/dosm)。
- **区域走廊管理机构**——依斯干达区域发展局（IRDA）、北马经济走廊发展机构
  （NCIA）、东海岸经济区发展理事会（ECERDC）、沙巴经济发展与投资局（SEDIA）
  与砂拉越区域走廊发展局（RECODA）。
- **土著议程机构**——土著议程主导单位（TERAJU）、Yayasan Peneraju与国民
  股权公司（EKUINAS）。
- **石油与天然气**——马来西亚石油资源公司（MPRC）与柔佛石油发展公司（JPDC）。

经济部官方机构页面在核查之日列出了特定数目的机构。在将其用于正式用途之前，
请在`ekonomi.gov.my`核实当前的准确名单，因为该部的机构架构可能在内阁重组
后有所变动。

## 经济部 vs 财政部

这两个部门常被混淆，因为两者都与国家的"钱"打交道——但它们的职责分工不同：

| | 经济部 | 财政部 |
| --- | --- | --- |
| 侧重 | 规划中长期发展 | 管理年度收入、税务与开支 |
| 主要工具 | 马来西亚计划（5年） | 联邦财政预算案（年度） |
| 设定 | 发展开支的上限与分配 | 每年实际的令吉拨款 |
| 核准形式 | 国会的政策动议 | 《供应法案》（Supply Act，供应法令） |

简而言之：经济部设定五年框架，财政部则逐年将其填满。
