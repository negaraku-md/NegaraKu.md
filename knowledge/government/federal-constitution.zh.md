马来西亚通过的每一项法律——无论是由联邦国会还是由某个州立法议会通过——都可以以一份单一的文件为标准来衡量。如果该法律与之抵触，则在抵触的范围内可视为无效。这份文件就是联邦宪法。

本文以描述性方式说明三件事：宪法称自己为“最高”时是什么意思、其文本如何编排，以及为修订它所规定的程序。

## 概览

| | |
| --- | --- |
| 名称 | 联邦宪法（Perlembagaan Persekutuan / Federal Constitution） |
| 类型 | 联邦的最高法律（第4条） |
| 生效 | 独立日，由第160条定义为1957年8月31日 |
| 编排 | 第一至第十五篇（包括第十二A篇）及十三个附表 |
| 修订程序 | 第159条 |

## “最高法律”是什么意思？

第4(1)条规定："This Constitution is the supreme law of the Federation and any law passed after Merdeka Day which is inconsistent with this Constitution shall, to the extent of the inconsistency, be void."（本宪法是联邦的最高法律，凡在独立日之后通过而与本宪法抵触的任何法律，在抵触的范围内应属无效。）简而言之，宪法确立自己为衡量在独立日之后通过的其他法律是否有效的标准。

第4条也包含程序性条文。其后的各款涉及对法律效力提出挑战的限制，并要求在以某些理由宣告某项法律无效之前，须先获得联邦法院一名法官的许可。第160条则将"Merdeka Day"（独立日）定义为1957年8月31日——这正是第4(1)条本身所提到的参照日期。

## 宪法如何编排？

宪法文本编排为十五篇。每一篇按主题将各条文归类：

| 篇 | 标题 |
| --- | --- |
| I | 各州、宗教与联邦法律 |
| II | 基本自由 |
| III | 公民权 |
| IV | 联邦 |
| V | 各州 |
| VI | 联邦与各州之间的关系 |
| VII | 财政条文 |
| VIII | 选举 |
| IX | 司法机关 |
| X | 公共服务 |
| XI | 对付颠覆行为、有组织暴力以及危害公众的行为和罪行的特别权力，及紧急状态权力 |
| XII | 一般与杂项 |
| XIIA | 对沙巴州和砂拉越州的额外保障 |
| XIII | 临时与过渡条文 |
| XIV | 统治者主权的豁免 |
| XV | 针对最高元首和统治者的诉讼 |

第十二A篇是在1963年组成联邦时为容纳沙巴和砂拉越而插入的；参见[联邦与州权力划分](/government/federal-state-division)。这种编排意味着核心机构——第四篇中的[国会](/government/parliament)、第九篇中的司法机关，以及透过第38条列于第四篇的统治者会议——在文本中各有其固定的位置。

## 各附表包含什么内容？

除了各篇之外，宪法还有十三个附表，位于主要文本之后。附表载有由某些条文所援引的详细规定。其中包括：

- **第三附表**——最高元首及其副手的推选程序。
- **第五附表**——统治者会议的成员组成与程序。
- **第九附表**——划分立法权限的联邦事项表、州事项表及共同事项表。
- **第十三附表**——有关划分选区的条文。

根据官方重印版的目录，部分附表（例如第十二附表）虽已被废除，但仍列于编排之中。

## 宪法如何修订？

修订程序载于第159条。第159(1)条规定，在符合该条其他条文以及第161E条的前提下，宪法条文可透过联邦法律予以修订。然而，这类"联邦法律"并非全部以相同的方式通过。第159条本身规定了若干不同的途径：

| 途径 | 条文 | 条件 |
| --- | --- | --- |
| 三分之二多数 | 第159(3)条 | 修订法案须在二读和三读时获得每一个国会议院全体议员不少于三分之二的票数支持 |
| 简单多数（获豁免） | 第159(4)条 | 某些修订获豁免于第159(3)条的要求——其中包括对第二附表第三部分或对第六或第七附表的修订、附带于或衍生自某些立法权力的修订，以及与某个州加入联邦有关的修订 |
| 须经统治者会议同意 | 第159(5)条 | 对某些指定条文清单的修订，未经统治者会议同意不得通过 |

第159(6)条阐明，在该条中，"修订"包括增补和废除。

第159(3)条也提到另一类法案——用以修订依据第10(4)条通过之法律的法案——同样受制于相同的三分之二门槛。

## 哪些条文需要超过三分之二的票数？

对于某些条文，仅在两院获得三分之二的支持仍不足够。第159(5)条列出其修订未经[统治者会议](/government/majlis-raja-raja)同意不得通过的条文：

- 第10(4)条及依据其通过的任何法律；
- 第三篇（公民权）的条文；
- 第38条、第63(4)条、第70条、第71(1)条、第72(4)条；
- 第152条和第153条；以及
- 第159(5)条本身。

此外，第159(1)条使整个修订权力受制于第161E条，即第十二A篇中载有对沙巴州和砂拉越州宪法地位保障的条文。第159(4)(bb)条与第161E条的合并效果是，涉及沙巴和砂拉越的某些修订须与一般途径分开处理。

## 常见误解

**“所有宪法修订都需要三分之二的票数。”** 第159(4)条将若干类别的修订豁免于三分之二的要求；这些类别可以简单多数通过。

**“三分之二的票数足以进行任何修订。”** 对于第159(5)条所列的条文，须以统治者会议的同意作为额外条件；而对于涉及沙巴和砂拉越的事项，则适用第161E条。

**“宪法在1963年马来西亚组成时生效。”** 第160条将独立日定义为1957年8月31日；原始文本在该日作为马来亚联合邦宪法生效，其后在沙巴和砂拉越加入联邦时予以扩展。

## 接下来

若要了解宪法条文在实践中如何运作，可从[马来西亚国会](/government/parliament)入手，它是通过联邦法律（包括第159条之下的修订）的机构；以及[统治者会议](/government/majlis-raja-raja)，第159(5)条所列条文的修订须获其同意。

关于第九附表之下联邦与各州之间的权力划分，参见[联邦与州权力划分](/government/federal-state-division)。

第4条、第159条和第160条的全文，可在由总检察署所维护的马来西亚法律门户网站（Portal Perundangan Malaysia）上的联邦宪法官方重印版中阅读。
