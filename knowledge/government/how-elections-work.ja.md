## 概要

| | |
| --- | --- |
| 投票制度 | 単一選挙区制、最多得票者当選（小選挙区制、first-past-the-post） |
| 憲法上の根拠 | 連邦憲法第八部（第113条～第120条） |
| 選出対象 | 下院（Dewan Rakyat、連邦）議員及び州議会（DUN）議員 |
| 投票資格 | 国民、18歳以上、居住、登録済み（第119(1)条） |
| 執行機関 | 選挙管理委員会（第113条、第114条） |
| 選挙区画定の周期 | 8年を下回らない間隔（第113(2)条） |
| 解散後 | 60日以内に総選挙（第55(4)条） |

投票日には、この制度全体が一つの単純な行為に凝縮される：一人の選挙人が、
静かな部屋の中で一枚の投票用紙に印をつける。その周囲にあるすべてのもの
——選挙人名簿、選挙区の境界、票を数える機関——は、誰がどこでその用紙に印
をつけることができるか、そして一つの鉛筆の印がどのようにして一つの議席
へと変わるのかを定める憲法上の枠組みである。

本ページは、憲法の条文に沿って、この枠組みを記述的に説明する：票がどの
ように数えられるか、誰が資格を有するか、誰が選挙を執行するか、そして解
散から結果までの手続の順序である。本ページは、いかなる政党、候補者又は
特定の結果にも言及しない。

## 一選挙区一議員、最多得票者当選

出発点は選挙人の数ではなく、選挙区の形である。第116(2)条は、「選挙区の
総数は議員数と同数とし、各選挙区から一名の議員が選出されるようにする」
と定めている。各選挙区は一名の代表のみを送り出す——それ以上ではない。

各選挙区が一名しか選出しないため、選出方法は単純になる：その選挙区で最
多得票を得た候補者が当選する。百分の五十の絶対多数は必要なく、第二回投
票もない。この単一選挙区・最多得票制度は、一般に*小選挙区制*（first-
past-the-post、FPTP）と呼ばれる。憲法はその構造を定めており、最多得票の
具体的な計算方法自体は、第113条の公式注記でも言及されているAkta Pilihan
Raya 1958（1958年選挙法）等の選挙法に規定されている。

第117条は、同じ形式を州のレベルに複製している。州議会の議員選出に
ついては、その州は「選出される議員数に応じた数の選挙区に、各選挙区から
一名の議員が選出されるように」分割される。連邦と州の構造は同一であり、
異なるのは満たされる議院のみである。

## 同じ日に選出される二つの議院

マレーシアは、類似の最多得票制度を通じて二つの階層の代表者を選出する。

- **下院（Dewan Rakyat）。** 連邦国会の下院であり、第46条に定める222議
  席を有する。各議席は、第116条に基づく一つの連邦選挙区である。
- **州議会（Dewan Undangan Negeri、DUN）。** 各州はそれぞれ独自の立
  法議会を有し、議席数はそれぞれの州憲法により定められ、第117条に基づき
  画定される。

ほとんどの州では、州選挙は連邦総選挙と同時に実施される。第113(2)条は、
州選挙区の境界見直しを下院の境界見直しと「同時に」実施することを求める
ことで、この同期を強化している。そのような州の選挙人は、通常、同じ日に
二枚の別個の投票用紙を受け取る：一枚は国会用、一枚はDUN用である。

半島の一部の州は、自州のDUNを異なる時期に解散することを選択しており、
その結果、総選挙とは別個の州選挙が実施される。この事項は、それぞれの州
の権限に属する。

## 誰が投票できるか

第119(1)条は、同時に満たされなければならない三つの要件を定めている。国
民は、次の場合に投票する権利を有する：

1. 資格判定日において**18歳**に達していること。
2. その日においていずれかの選挙区に**居住**しているか、又は不在者選挙人
   として登録されていること。かつ
3. 居住する選挙区の選挙人名簿に**登録**されていること。

この18歳という年齢は、一般に*Undi18（18歳選挙権）*として知られる憲法改
正——Akta Perlembagaan (Pindaan) 2019（2019年憲法（改正）法令）——の後の
現行の状態であり、同法令は投票年齢を21歳から18歳に引き下げた。
同じ改正は自動有権者登録も導入し、資格を有する国民は別途申請することな
く、選挙管理委員会により名簿に記載される。

第119(1)条はまた、一つの重要な制限を定めている：「何人も、同一の選挙に
おいて二つ以上の選挙区で投票することはできない」——一人につき、各議院に
つき一票である。

第119(3)条は、選挙人資格を喪失する理由を列挙している：資格判定日におい
て精神に異常があるとして拘禁されている場合、又は禁錮刑に服している場合；
あるいは犯罪について有罪判決を受け、死刑又は12か月を超える禁錮刑を宣告
され、なおその刑に服さなければならない場合。

## 選挙管理委員会（SPR）：選挙を執行する機関

選挙は自ら運営されるものではない。第113(1)条は選挙管理委員会（SPR）を
設立し、二つの中核的職務を与えている：下院及び各州議会の選挙を執行
すること、並びに選挙人名簿を作成し検討することである。

第114条は、この機関の構成及び独立性を定めている。

| 特徴 | 規定 |
| --- | --- |
| 構成 | 委員長、副委員長及び**その他委員5名**——合計7名（第114(1)条） |
| 任命 | 国王（Yang di-Pertuan Agong）により**統治者会議（Majlis Raja-Raja）との協議の後**に任命される（第114(1)条） |
| 考慮事項 | 国王は、SPRが**公衆の信頼を得る**ことの重要性に留意しなければならない（第114(2)条） |
| 退任年齢 | 66歳（第114(3)条） |
| 撤職 | **マレーシア連邦裁判所の裁判官**と同一の理由及び同一の方法によってのみ（第114(3)条） |
| 報酬 | **統合基金（Kumpulan Wang Disatukan）**に賦課される；任命後に不利益に変更することはできない（第114(5)、(6)条） |

この設計は、SPRに司法機関と同様のいくつかの独立性の盾を与えている：統
治者会議が関与する任命、厳格な撤職要件による在任期間の保障、そして年次
の議決に依存しないよう統合基金によって保護される給与である。

## 選挙区画定：選挙区の境界はどのように定められるか

各選挙区が一名の議員を送り出すため、境界線がどこに引かれるかによって、
どの選挙人がまとめられるかが決まる。第113(2)条は、SPRに、連邦及び各州
の選挙区への区割りを見直し、遵守すべき原則を含む憲法の**第十三附表
（Thirteenth Schedule）**の規定に沿うよう変更を勧告する任務を与えてい
る。

この周期を規律する二つの期限がある：

- **最低8年の間隔。** 第113(2)(ii)条は、一つの見直しの完了日と次の見直
  しの開始日との間に8年を下回らない期間を定めている。
- **2年以内の完了。** 第113(2)(iii)条は、各見直しがその開始日から2年を
  超えない期間内に完了することを求めている。

第113(6)条は、マラヤ諸州、サバ州及びサラワク州について、それぞれ別個の
見直しを行うことを求めている——それぞれが独立した「見直し単位」として扱
われる。SPRの勧告報告書は首相に提出され、境界の改正は発効前に下院の承
認を受けなければならない。

## 選挙はいつ実施されるか

総選挙は固定された日に実施されるものではない。それは解散によって引き起
こされる。第55(3)条は、国会がその最初の会議から5年間継続し、その後自動
的に解散すると定めているが、第55(2)条に基づき国王（Yang di-Pertuan
Agong）によってより早く解散される場合は、この限りでない。

国会が解散すると同時に、憲法上の時計が動き始める。第55(4)条は二つの期
限を定めている：

| 事項 | 解散後の期限 |
| --- | --- |
| 総選挙の実施 | **60日**以内 |
| 国会の再招集 | **120日**を超えない |

総選挙の間に議席が突発的に空席となった場合については、第54条に従い補欠
選挙を実施することができる——ただし、第54条のただし書は、一定の状況にお
いて、国会が解散する2年前以内に生じた空席を除外している。

## 選挙の実施手続

解散後、SPRはすべての選挙について同一の手続順序を定める。SPRの公式ポ
ータルサイトは、その段階を次のとおり説明している。

1. **令状の発行。** SPRは、各選挙区の選挙管理官（Pegawai Pengurus、
   Returning Officer）に対し、選挙を執行するための令状——授権状——を発
   し、立候補届出日及び投票日を定める。
2. **立候補届出日。** 定められた日に、選挙管理官は、候補者から、提案者
   及び支持者を伴う届出書を受理する。
3. **選挙運動期間。** 届出が完了した後、候補者及びその代理人は選挙運動
   を行うことができる。選挙運動は、投票日前日の午前0時に必ず停止しなけ
   ればならない。
4. **投票日。** 登録された選挙人は、それぞれの選挙区について定められた
   投票所において投票用紙に印をつける。
5. **開票。** 投票終了後、投票用紙が数えられる。
6. **結果の宣言。** 各選挙区で最多得票を得た候補者が、選挙管理官により
   当選者として宣言される。

正確な詳細——届出の時刻、選挙運動期間及び候補者供託金——は、Akta Pilihan
Raya 1958及びその下位規則により規律されており、変更されることがある；
現行の数値は、各選挙についてSPRが発表する公式告知に照らして確認する必
要がある。

## 議席から政府へ

投票は議員を選出し、その議員たちが政府を決定する。第43(2)(a)条は、国王
（Yang di-Pertuan Agong）が、その所見において下院議員の多数の信任を得
られる可能性があると判断する下院議員一名を首相に任命すると定めている。
最多得票制度は下院の構成を決定し、第43条はその後、その議院の信任に基づ
いて誰が統治するかを決定する。この経路の詳細は、
[下院（Dewan Rakyat）](/government/dewan-rakyat)及び
[マレーシア国会](/government/parliament)で説明されている。

## よくある誤解

**「候補者は50パーセントの多数で勝たなければならない。」** そうではな
い。第116(2)条により形成された最多得票制度の下では、総得票数の半分に満
たなくても、最多得票を得た候補者が当選し、第二回投票は行われない。

**「一票が首相を直接選ぶ。」** 選挙人は、自らの選挙区の議員のみを選出す
る。第43(2)(a)条は、下院の多数の信任に基づき、首相の任命を国王（Yang
di-Pertuan Agong）に委ねている。

**「投票年齢は21歳である。」** 第119(1)条は、Akta Perlembagaan
(Pindaan) 2019による改正の後、現在は18歳と定めている。

**「SPRは通常の政府の一部である。」** 第114条は、その委員に裁判官と同
様の在任期間の保護、統合基金からの報酬、及び統治者会議が関与する任命を
与えている。

**「境界はいつでも変更できる。」** 第113(2)条は、一つの選挙区画定見直
しと次の見直しとの間に、8年を下回らない間隔を定めている。

## 次に読むべきもの

この選挙によって満たされる議院、及び議席がどのようにして法律に変わるか
を理解するには、[下院（Dewan Rakyat）](/government/dewan-rakyat)及び
[マレーシア国会](/government/parliament)を読んでほしい。国会の解散及
びSPRの任命における国王（Yang di-Pertuan Agong）の役割は、
[国王（Yang di-Pertuan Agong）](/government/yang-di-pertuan-agong)及び
[統治者会議](/government/majlis-raja-raja)で説明されている。上記のすべ
ての規定を定める文書の構造については、
[連邦憲法](/law/federal-constitution)を読んでほしい。

本ページのいずれかの規定を確認するには、SPRが
[spr.gov.my](https://spr.gov.my/wp-content/uploads/2024/10/perkara-113-penjalanan-pilihanraya.pdf)
で公開している連邦憲法第八部の条文、及び
[lom.agc.gov.my](https://lom.agc.gov.my/federal-constitution.php)
にある憲法全文を参照すること。
