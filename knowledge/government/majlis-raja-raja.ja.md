連邦憲法には、あまり言及されることのない、ある短い一覧がある。国会が単独では可決できない事項の一覧である。これらの事項については、下院（Dewan Rakyat）及び上院（Dewan Negara）における三分の二の賛成票だけでは足りない。もう一つの機関の同意が必要となる——それが統治者会議である。

統治者会議（Majlis Raja-Raja）は、連邦憲法第38(1)条によって設立され、第五附則に従って構成される。それは国会の第三院ではなく、法律を制定するものでもない。その役割は一覧の形で定められている——特定の事項にはその同意が必要であり、別の事項にはその諮問が必要であり、そしてごく一部は完全にその独自の権限に属する。

本稿は、憲法典に定められたとおりに、この一覧を説明する。

## 概要

| | |
| --- | --- |
| 正式名称 | 統治者会議（Majlis Raja-Raja / Conference of Rulers） |
| 憲法上の根拠 | 第38条；第五附則に従って設立 |
| 構成員 | 統治者、及び統治者を有しない州の州元首（Yang di-Pertua Negeri）（第五附則第1節） |
| 書記 | 統治者御璽守護官（Penyimpan Mohor Besar Raja-Raja）（第五附則第4節） |
| 定足数 | 構成員の過半数（第五附則第5節） |
| 第一回会議 | 1948年2月18日 |
| 事務局 | 統治者御璽守護官事務所、クアラルンプール、Jalan Bukit Petaling |

## 構成員は誰か

第五附則第1節は、統治者会議が諸統治者陛下（Duli-Duli Yang Maha Mulia Raja-Raja）、及び統治者を有しない州の州元首（Yang di-Pertua Negeri）から構成される旨を定めている。

統治者御璽守護官事務所の公式ウェブサイトによれば、現在の構成員は九人のマレー統治者に加え、マラッカ、ペナン、サバ及びサラワクの州元首から成り——合計13名の構成員である。「統治者を有しない州」という表現は、サバ及びサラワクが連邦に加わった際に、もとの「マラッカ及びペナン」という表現に代わって用いられるようになったものである。[1963年のマレーシア結成](/malaysia/formation-of-malaysia-1963)を参照。

構成員資格は、あらゆる事務について一様ではない。第五附則第7節は、次の事項に関する手続については、州元首を構成員から除外している。

- 国王（Yang di-Pertuan Agong）の選出若しくは罷免、及び副国王（Timbalan Yang di-Pertuan Agong）の選出；
- 専ら統治者の特権、地位、栄誉及び威厳に関わる事項；並びに
- 宗教上の行為、慣行又は儀式。

これらの事務については、会議は九名の構成員から成る機関として開催される。

また、第五附則第2節は、当該州の州憲法にその旨の定めがある場合には、統治者又は州元首の席を他の者が代わって占めることを認めている。

## 第38(2)条に列挙された五つの職能

第38(2)条は、統治者会議の職能を次のとおり列挙している。

1. **国王（Yang di-Pertuan Agong）及び副国王（Timbalan Yang di-Pertuan Agong）を選出すること**、第三附則の規定に従う。
2. 何らかの宗教上の行為、慣行又は儀式を連邦全体に及ぼすことについて、**同意し又は同意しないこと**。
3. 憲法に基づき会議の裁可を要し、又は会議への諮問を経て行うことが求められる法律について、**裁可を与え又は与えないこと**、及び任命について決定し又は意見を述べること。
4. 第182(1)条に基づき**特別法廷（Mahkamah Khas）の構成員を任命すること**。
5. 第42(12)条に基づき、**恩赦、刑の執行猶予及び刑の減免を与えること**、又は刑罰を免除し、停止し若しくは軽減すること。

第38(2)条はさらに、会議は「国家政策に関する問題（例えば移民政策の変更）、及びその他会議が適切と考える事項について審議することができる」と付け加えている。

この宗教上の職能は、第3(2)条と結びついている。会議が連邦全体に及ぼすことに同意した行為、慣行又は儀式について、他のすべての統治者は、イスラム教の首長としての資格において自らを代表する権限を国王に付与しなければならない。

## 国王の選出はどのように行われるか

第32(3)条は、国王が統治者会議によって任期5年で選出される旨を定めている。国王は、会議宛ての書簡により辞任することができ、又は会議によって罷免されることがあり、また統治者でなくなったときはその職を退く。

その仕組みは第三附則に定められている。

| 段階 | 規定 | 内容 |
| --- | --- | --- |
| 資格 | 第一部第1節 | 統治者は、成年に達していない場合、統治者御璽守護官に対し選出されることを望まない旨を通知した場合、又は統治者会議が秘密投票により適格でないと決定した場合を除き、選出される資格を有する |
| 表決の閾値 | 第一部第1(2)節 | 不適格の決議案は、少なくとも五名の構成員が賛成票を投じない限り、可決され得ない |
| 提呈 | 第一部第2節 | 職位は、選出名簿において最上位にある州の適格な統治者に提呈される；受諾されない場合は、次の州の統治者に提呈され、以下同様に続く |
| 宣言 | 第一部第3節 | 提呈が受諾された後、会議は国王が選出された旨を宣言し、統治者御璽守護官はその決定を国会の両院に書面で通知する |
| 罷免 | 第三部第8節 | 国王を罷免する決議案は、少なくとも五名の構成員が賛成票を投じない限り、可決され得ない |

選出名簿そのものは輪番制である。第三附則第4節は、各選出の後、選出された統治者の州より前にある州は名簿の末尾に移され、選出された統治者の州は名簿から除外される旨を定めている。名簿にいずれの州も残らなくなったときは、名簿は再編成される。

副国王（Timbalan Yang di-Pertuan Agong）もまた、会議によって任期5年で選出される（第33(2)条）。また、国王の職が欠位である間、会議は副国王を選出することができない（第三附則第6節）。

第37(1)条は、あまり言及されることのない一つの手続を付け加えている。国王は統治者会議の前で就任の宣誓を行い、その宣誓は、その目的のために会議が任命した二人の者によって立ち会われる。

## 統治者会議の同意を要する事項

「同意」は、憲法の中で最も強い要件である。それがなければ、当該法律は[国会](/government/parliament)によって可決され得ない。

| 規定 | 会議の同意なしには生じ得ない事項 |
| --- | --- |
| 第38(4)条 | 統治者の特権、地位、栄誉又は威厳に直接関わる法律 |
| 第2(b)条 | 州の境界を変更する法律（当該州の同意も必要） |
| 第159(5)条 | 第10(4)条、第三部、第38条、第63(4)条、第70条、第71(1)条、第72(4)条、第152条、第153条、又は第159(5)条自体の改正 |
| 第33(5)条 | 特定の状況において統治者が国王の職務を行うことを定める法律 |
| 第34(5)条 | 国王が国事訪問の場合を除き15日を超えて連邦の外にあること |

この第159(5)条こそが、列挙された規定について、統治者会議を国会両院における三分の二の多数決に加えて、[連邦憲法](/law/federal-constitution)の改正手続の一部たらしめている。

## 諮問のみを要する事項

諮問は、同意とは異なる要件である。憲法は、次の事項については、会議の同意を求めるのではなく、会議への諮問を求めている。

- **第38(5)条**——第153条に基づく行政上の措置に関わる政策変更を行う前。
- **第122B(1)条**——首相の助言に基づき、統治者会議への諮問を経て、国王が連邦裁判所首席判事、控訴院長、高等法院首席判事及びその他の判事を任命すること。
- **第114(1)条**——統治者会議への諮問を経て、国王が選挙委員会（Suruhanjaya Pilihan Raya）を任命すること。
- **第139(4)条**——公共サービス委員会（Suruhanjaya Perkhidmatan Awam）の構成員の任命。
- **第141A(2)条**——教育サービス委員会（Suruhanjaya Perkhidmatan Pelajaran）の構成員の任命。

さらに二つの任命は、会議自身によって行われる。連邦裁判所又は高等法院の判事の職にある者又はかつてあった者二名を特別法廷（Mahkamah Khas）の構成員として任命すること（第182(1)条）、及び諸統治者陛下を代表する軍事評議会（Majlis Angkatan Tentera）の構成員一名を任命すること（第137(3)(b)条）である。

## 構成員が自らの裁量により行動する場合

マレーシアにおける憲法上の職能の大半は、助言に従って行われる。第38(3)条は、会議が国家政策に関する事項を審議する際には、国王には首相が同席し、他の統治者及び州元首にはそれぞれの州首相（Menteri Besar）又は首席大臣（Ketua Menteri）が同席する——そして、その審議は内閣（Jemaah Menteri）及び州行政会議（Majlis Mesyuarat Kerajaan Negeri）の助言に従って行われる旨を定めている。

第38(6)条は、この規則から六つの類型を除外している。会議の構成員は、次の事項に関する手続においては、自らの裁量により行動することができる。

- 国王の選出若しくは罷免、又は副国王の選出；
- 任命に関する意見の提供；
- 州の境界を変更する法律、又は統治者の特権、地位、栄誉及び威厳に関わる法律に対する裁可の付与又は不付与；
- 宗教上の行為、慣行又は儀式を連邦全体に及ぼすことについての同意又は不同意；
- 第182(1)条に基づく特別法廷構成員の任命；並びに
- 第42(12)条に基づく恩赦権。

## 決定はどのように行われ、確認されるか

会議の手続は第五附則に定められている。

- **定足数**は構成員の過半数であり、会議は自らの手続を自ら定めることができる（第5節）。
- **会議**は、国王又は三名以上の構成員が求めたときに、統治者御璽守護官によって招集される。また、求めがない場合であっても、国王の任期満了前4週間より遅くない時点で、及び国王又は副国王の職に欠位が生じたときに招集される（第6節）。公式ウェブサイトによれば、会議は通常、年に三回開催される。
- **投票**——会議が全会一致に至らない場合、決定は、第三附則の規定に従うことを条件として、投票した構成員の過半数によって行われる（第8節）。
- **確認**——会議のいかなる同意、任命又は意見も、統治者御璽をもって確認される。提案された任命については、構成員の過半数が統治者御璽守護官宛ての書簡により支持を表明した場合、会議を招集することなく、その意見を御璽により確認することができる（第9節）。

また、第40(2)(c)条は、専ら統治者の特権、地位、栄誉及び威厳に関わる会議の開催を求めること、並びに当該会議におけるいかなる行動も、国王が自らの裁量により行使できる職能の一覧に含めている。

## よくある誤解

**「統治者会議は法律を可決する。」** 誤りである。会議は法律を制定又は可決しない。特定の類型については、その同意が、国会によって可決された法律が効力を生じる前の追加的な要件となる——それは一つの要件であって、立法過程ではない。

**「同意と諮問は同じ意味である。」** 誤りである。第38(4)条及び第159(5)条は同意の文言を用い、第38(5)条、第114(1)条及び第122B(1)条は諮問の文言を用いている。両者は異なる憲法上の効果をもたらす。

**「すべての構成員があらゆる事項について投票する。」** 誤りである。第五附則第7節は、特定の類型の手続から州元首を除外しており、また第42(13)条は、第42(12)(b)号及び(c)号の目的については、州元首を——当該統治者とともに——構成員から除外している。

**「決定は全会一致でなければならない。」** 誤りである。第五附則第8節は、会議が全会一致に至らない場合、投票した構成員の過半数による決定を定めている。

**「国王は構成員として会議を主宰する。」** 統治者御璽守護官事務所の公式ウェブサイトは、国王が統治者会議の構成員ではなく、国家元首として会議に出席し、その顧問として首相が同席する旨を述べている。

## 次に読むべきもの

統治者会議がより広い憲制の枠組みの中でどこに位置づけられるかを理解するには、まず[連邦憲法](/law/federal-constitution)を読み、次に[マレーシア国会](/government/parliament)を読んで、第38(4)条及び第159(5)条の同意要件が適用される前に連邦法律がどのように可決されるかを見てほしい。

その歴史的背景は、二つの出来事にある。憲法が施行された[1957年の独立](/malaysia/independence-1957)、及び、構成員の枠組みが[サラワク](/states/sarawak)を含む統治者を有しない州にまで拡大された[1963年のマレーシア結成](/malaysia/formation-of-malaysia-1963)である。

第38条、第三附則及び第五附則の全文は、総検察庁（Jabatan Peguam Negara）のポータルにおける連邦憲法の公式重印本で読むことができ、会議の役割に関する公式な説明は、統治者御璽守護官事務所によって公表されている。
