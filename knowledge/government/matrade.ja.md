初めて輸出を手がける事業者に、貿易見本市のブースを担当する政府機関はどこかと
尋ねれば、およそ半数はMIDAと答えるだろう。だがMIDAはこの業務を扱っていない。
それはMATRADEの職務であり——両機関は同じ貿易関係の対極に位置している。

## 概要

| | |
| --- | --- |
| 正式名称 | マレーシア対外貿易開発公社（Malaysia External Trade Development Corporation、MATRADE） |
| 種別 | 法定機関、独自の法令に基づき設立 |
| 根拠法 | 1992年マレーシア対外貿易開発公社法（Malaysia External Trade Development Corporation Act 1992）、Act 490 |
| 施行日 | 1993年3月1日 |
| 所管 | 投資貿易産業省（Ministry of Investment, Trade and Industry、MITI） |
| 中核職務 | マレーシアの輸出振興、及びマレーシア企業の海外市場進出支援 |
| 海外網 | 2026年初め時点で47の貿易事務所と報じられている |
| 本部 | Menara MATRADE、クアラルンプール |
| ウェブサイト | `matrade.gov.my` |

## MATRADEが実際に行っていること

MATRADE自身のサイトは、その目的を簡潔に、マレーシア企業が「世界市場で新たな
フロンティアを切り拓く」のを支援し、マレーシアを主要な貿易国として位置づける
こととしている。実務上、この使命はいくつかの具体的なサービスを通じて遂行され
ている。

- **貿易見本市。** MATRADEは、国際貿易見本市へのマレーシアの参加を組織・運営
  し、会場予約、ブースのデザイン及び施工、事前の広報活動、バイヤーとの面談日
  程調整を担う。
- **貿易ミッション及び輸出加速ミッション。** MITIと、また時にはMIDAとも共同で
  実施されるこれらのミッションは、マレーシア企業を既存及び新興市場へ連れて行
  き、外国政府関係者及びバイヤーとの人脈構築を図る。
- **商機マッチング。** MATRADEは、マレーシアからの調達を希望する海外の輸入業
  者とマレーシア企業を引き合わせる。
- **市場情報。** 商業情報、市場調査及び国別情報を提供し、輸出業者に競争優位を
  与える。
- **財務支援。** **市場開発グラント（Market Development Grant、MDG）** は、
  マレーシアの製品又はサービスを海外で振興する費用を相殺する返済型グラント
  である。

これらはいずれも投資振興でも貿易政策でもない。まさに輸出振興そのものであり
——そしてこれこそが、MIDA及びMITIとの混同が生じやすい点である。

## MATRADE対MIDA対MITI

三機関はいずれも同じ制度上の系列に属するが、担う職務は同じではない。

| 機関 | 方向 | 何を行うか |
| --- | --- | --- |
| **MITI** | 政策 | 貿易・産業政策を策定し、自由貿易協定（FTA）を交渉する。個別案件そのものを承認又は振興することはしない |
| **MIDA** | インバウンド | マレーシアの製造業及びサービス業へ**流入する投資**を振興・審査する |
| **MATRADE** | アウトバウンド | 海外市場へ**流出するマレーシアの輸出**を振興する |

簡単な覚え方として、MIDAは入ってくる投資家に向き合い、MATRADEは出ていく輸出
業者に向き合う。MITIは両者の上に立ち、それぞれが実行する政策を定める。三機関
は正式にも結びついている——MITI自身が管轄法令として掲げる一覧では、Act 490
がMATRADEの根拠法として、MIDAのAct 397と並んで挙げられている。

## 海外事務所網

MATRADEが海外で用いる主要な実施手段は、それぞれ貿易委員（trade commissioner）
が統括する海外貿易事務所の網である。2026年初め時点で、この網は**47の海外貿易
事務所**からなると報じられている。

2026年4月、MATRADEの会長Reezal Merican Naina Merican氏は、これらの事務所の
使われ方における変化を説明した。純粋な振興拠点として機能するのではなく、政策
変更、海運ルートの混乱、新たに生じる調達ギャップを海外で追跡し、より不安定化
する世界貿易環境を乗り越えようとするマレーシアの輸出業者へその情報を還元する
市場情報の「フロントラインハブ」へと再編されつつある。

## 2026年の優先事項

2026年に向けて、MATRADEの最高経営責任者Abu Bakar Yusof氏は、**13,400社のマ
レーシア企業**を支援することを目指す**203件の貿易開発・振興プログラム**から
なるロードマップを打ち出した。これは5つの柱を軸に構成されている。

1. **事業継続性と人的資本開発**——AI及び変化する貿易動向に対応する労働力の能
   力構築。
2. **戦略的協働**——民間セクター及び金融パートナーとの連携深化。
3. **ESGと持続可能性**——海外バイヤーが求める環境・社会・ガバナンス（ESG）へ
   の対応を輸出業者に準備させるプログラムの拡充。
4. **デジタル化**——輸出業者向けのデジタル貿易プラットフォーム。
5. **市場多様化**——従来のパートナーに加え、ラテンアメリカ、中央・南アジア、
   西アジア、アフリカの新興市場を対象とする。

## よくある誤解

**投資インセンティブの案件でMATRADEを訪ねること。** MATRADEはマレーシア企業
が海外で販売するものを振興する。製造ライセンス、税務インセンティブ、及びイン
バウンド投資の便宜供与は、MATRADEではなくMIDAの職務である。

**MATRADEを政策策定機関として扱うこと。** MATRADEは輸出振興プログラムを実施
するのであって、自由貿易協定を交渉したり産業政策を策定したりはしない。それは
MITIの職務である。

**MATRADEが大手輸出業者のみを対象としていると思い込むこと。** その2026年ロー
ドマップは、プログラム、ミッション、グラントの対象として明確に数千社を掲げて
いる——市場開発グラントは、とりわけ、すでに地位を確立した企業だけでなく、規
模の小さい輸出業者にとっても海外振興を手の届くものにするために存在している。
