สองหน่วยงาน หนึ่งกระทรวง และเส้นแบ่งที่แทบไม่มีใครขีดถูกในครั้งแรก หากภาษีติดกับ **สิ่งที่ข้ามชายแดน สินค้าที่ออกจากโรงงาน หรือบริการที่ให้** นั่นคือศุลกากร หากติดกับ **รายได้ กำไร หรือเอกสาร** นั่นคือ LHDN

## การแยกกับ LHDN ในตารางเดียว

ทั้งสองอยู่ภายใต้กระทรวงการคลัง นั่นคือจุดที่ความเหมือนสิ้นสุด

| คำถามของคุณ | ใครเป็นผู้ตอบ |
| --- | --- |
| ภาษีบนกำไรของบริษัทฉัน | [LHDN](/th/government/lhdn) |
| ภาษีบริการบนใบแจ้งหนี้ที่ฉันออก | RMCD |
| อากรนำเข้าบนการขนส่งสินค้า | RMCD |
| ภาษีหัก ณ ที่จ่ายบนผู้ขายต่างชาติ | LHDN |
| อากรแสตมป์บนสัญญาเช่า | LHDN |
| ภาษีสรรพสามิตบนรถยนต์ | RMCD |
| ภาษีกำไรจากทรัพย์สินบนการขายตึกแถว | LHDN |
| ภาษีการท่องเที่ยวที่โรงแรมเรียกเก็บ | RMCD |
| ค่าธรรมเนียมขาออกบนตั๋วเครื่องบิน | RMCD |
| การส่งใบกำกับภาษีอิเล็กทรอนิกส์ | LHDN |

มีความแตกต่างเชิงโครงสร้างอยู่ใต้ความแตกต่างเชิงหน้าที่ **RMCD เป็นกรม** — ส่วนหนึ่งของราชการพลเรือนระดับสหพันธ์ มีอธิบดีเป็นหัวหน้า **LHDN เป็นหน่วยงานตามกฎหมาย** ที่สร้างขึ้นโดยพระราชบัญญัติของตนเอง กระทรวงการคลังระบุศุลกากรไว้ภายใต้ *กรม* และ LHDN ไว้ภายใต้ *หน่วยงาน* และการจัดประเภทนั้นเป็นวิธีที่ชัดเจนที่สุดในการแยกทั้งสอง

## พอร์ทัลที่ดำเนินการ

- **MySST** — การจดทะเบียน การยื่นแบบ และการชำระเงินสำหรับภาษีขายและภาษีบริการ พร้อมด้วยคำสั่ง ระเบียบ และข้อความนโยบายที่ประกาศในราชกิจจานุเบกษา
- **ezHS (JKDM HS Explorer)** — การค้นหาพิกัดอัตราด้วยรหัส HS หรือคำอธิบาย ครอบคลุมคำสั่งอากรศุลกากรปัจจุบันและบัญชีอัตราพิเศษของความตกลงการค้าเสรีของมาเลเซีย (ATIGA, ACFTA, AANZFTA, RCEP และอื่น ๆ)
- **MyTTx** — ระบบภาษีการท่องเที่ยวของมาเลเซีย
- **MyDLV** — การสำแดงค่าธรรมเนียมขาออก
- **ระบบแสตมป์ภาษี (TMS)** — แสตมป์ภาษีบนสินค้าที่ต้องเสียภาษีสรรพสามิต
- **MNTR** — คลังข้อมูลการค้าแห่งชาติมาเลเซีย สำหรับมาตรการและขั้นตอนทางการค้า

## สองสิ่งที่ทำให้คนสะดุด

**อัตราถูกประกาศในราชกิจจานุเบกษา มิใช่เผยแพร่บนเว็บ** อัตราอากรกำหนดโดยคำสั่งอากรศุลกากรและอัตราภาษีบริการโดยคำสั่งอัตราภาษี หมายเหตุแนวทางและหน้าคำถามที่พบบ่อยบนพอร์ทัลเป็นความเห็นประกอบ; เครื่องมือ P.U.(A) คือกฎหมาย เมื่อขัดแย้งกัน ราชกิจจานุเบกษาชนะ

**การบังคับใช้และการประเมินเป็นหน่วยงานเดียวกัน** เจ้าหน้าที่ที่ตรวจปล่อยการขนส่งสินค้าของคุณและเจ้าหน้าที่ที่ตรวจสอบแบบ SST-02 ของคุณทำงานให้กรมเดียว ภายใต้กฎหมายที่มีอำนาจในการยึดและการฟ้องคดี ซึ่งแตกต่างจากด้านภาษีทางตรงที่การประเมินและการบังคับใช้เป็นไปตามรูปแบบการเรียกคืนทางแพ่ง
