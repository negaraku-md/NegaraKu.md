首相が下院（Dewan Rakyat）に立ち、国の5カ年開発計画を提示するたびに、その手にある
分厚い文書は、突如として現れたものではない。それは、多くの国民がほとんど意識する
ことのない一つの省庁——経済省——によって、何年もかけて準備されたものである。そし
てこの省庁自体、現在の形としては新しいものであるが、それが行ってきた仕事そのもの
は、完全独立よりも前から始まっている。

## 概要

| | |
| --- | --- |
| 名称 | 経済省（Ministry of Economy） |
| 種類 | 連邦省庁 |
| 設立 | 第15回総選挙後；2022年12月23日にEPUの機能を継承 |
| 機能の継承元 | 経済計画ユニット（EPU） |
| 主要な成果 | マレーシア計画（5カ年開発計画） |
| 主要部門 | マレーシア統計局（DOSM） |
| ウェブサイト | `ekonomi.gov.my` |

## 経済省が実際に行っていること

経済省は、政府の日常的な支出を担う省庁でもなければ、徴税を行う省庁でもない。その
仕事は**計画すること**——今後数年間の国家開発の方向性を定め、次に開発資源をどれ
だけ、どこに配分するかを決定することである。

同省自身の機能ページによれば、その任務は四つの分野に分かれている。

- **社会経済開発計画**——国家、地域、州レベルでの中長期の社会経済開発計画を策定
  すること；調査を行い、経済に関して政府に助言すること；ブミプトラ・アジェンダを
  含む包摂的開発を強化すること；そして石油・ガスに関連するエネルギー政策を策定す
  ること。
- **配分資源の分配**——開発支出の上限と配分を決定し、**RM5,000万**を超える開発プ
  ロジェクトに対して価値管理（value management）を実施すること。
- **実施、調整及び監督**——国家開発プログラム及び施策の進捗を追跡し、同省自身の
  プログラムを実施すること。
- **利害関係者の円滑化**——国家経済行動理事会（Majlis Tindakan Ekonomi Negara）
  及び国家開発計画委員会（Jawatankuasa Perancang Pembangunan Negara）を含む、社
  会経済計画機関の国家事務局としての役割を果たすこと。

最も理解に役立つ区分は次のとおりである：経済省が開発を**計画し配分する**一方で、
財務省が提出する[連邦予算](/economy/federal-budget)が、その計画の一部を毎年実際
のリンギットへと翻訳する。

## EPUから経済省へ

この機構はこれまでに何度も形を変えてきたが、その中核的な使命——国家開発計画の策
定——は、いずれの再編を経ても変わることなく続いている。

その物語は、連邦執行評議会経済委員会（Jawatankuasa Ekonomi Majlis Mesyuarat
Kerajaan Persekutuan）を支援するために**1956年4月24日**に設置された**経済事務局**
から始まる。**1961年**、それは首相府（Jabatan Perdana Menteri）のもとで**経済計
画ユニット（EPU）**へと改組された。**1970年**までに、EPUは総局長制のもとで運用を
開始し、Tan Sri Dato' Thong Yaw Hongが初代総局長を務めた。

その後、政治に連動した一連の再編が続いた。

| 日付 | 変化 |
| --- | --- |
| 2018年 | 第14回総選挙後、EPUは経済事務省（MEA）へと改組された |
| 2019年12月18日 | EPUが正式に解散し、その役割と機能はMEAが引き継いだ |
| 2020年3月10日 | EPUは首相府のもとで再設置された |
| 2022年12月23日 | 第15回総選挙後、EPUは再び解散し、その責務は新たに設立された経済省へと移管された |

つまり、政策文書の中で「EPU」や「経済計画ユニット」への古い言及を目にした場合、そ
れは現在経済省が所管する機能を指している。大臣職もまた手を替えてきた：ラフィジ・
ラムリ（Rafizi Ramli）が2025年6月17日付で辞任した後を受けて、アクマル・ナスルッ
ラー・モハマド・ナシル（Akmal Nasrullah Mohd Nasir）が2025年12月16日に経済相に任
命された——役職は入れ替わっても、省庁とその使命は変わらない。

## マレーシア計画：同省の主要な成果

経済省の最もよく知られた成果は、**マレーシア計画（RMK）**——国の5カ年中期開発計
画である。同省がその策定を統括し、マクロ経済目標を提案し、トップダウンとボトムア
ップの両方のアプローチを通じて、すべての省庁と機関に計画指針を発出する。

国会に提出される前に、その草案は一連の承認プロセスを経る：国家事務総長（Ketua
Setiausaha Negara）が委員長を務める**国家開発計画委員会（JPPN）**、次いで首相特
別委員会、続いて内閣、そして最終的に国会に**動議**として提出され、審議と承認を受
ける——法案としてではない。

この伝統は、「マレーシア計画」という名称そのものよりも早くから始まっている。第1
次マレーシア計画は1966年から1970年にかけての期間を対象としており、その周期はそれ
以来途切れることなく続いている。

| 計画 | 期間 |
| --- | --- |
| 第1次から第5次マレーシア計画 | 1966-1990 |
| 第6次から第10次マレーシア計画 | 1991-2015 |
| 第11次マレーシア計画 | 2016-2020 |
| 第12次マレーシア計画（RMKe-12） | 2021-2025 |
| 第13次マレーシア計画（RMK13） | 2026-2030 |

RMKe-12（2021-2025）は**「繁栄し、包摂的で、持続可能なマレーシア」**をテーマとし、
開発の原動力としての民間セクター、貧困と所得格差を是正する包摂的開発、低炭素国家
に向けた緑の開発、そしてサバ州とサラワク州のインフラと基礎サービスへの特別な焦点
に重点を置いた。現行版である**RMK13（2026-2030）**は、**「開発の再設計」**をテー
マとしている。各計画の詳細——主軸、目標、投資額——は、[マレーシア計画](/economy/malaysia-plans)
の記事で説明されている。

## 経済省傘下の機関

マレーシア計画の策定に加え、経済省は統計業務、地域開発、ブミプトラ・アジェンダを
担う複数の部門と機関を監督している。

- **マレーシア統計局（Jabatan Perangkaan Malaysia、DOSM）**——その主要部門であり、
  経済、社会、人口及び環境に関する公式統計を作成する。[DOSM——マレーシア統計局](/government/dosm)
  を参照。
- **地域回廊管理機構**——イスカンダル地域開発庁（IRDA）、北部回廊実施庁（NCIA）、
  東海岸経済地域開発評議会（ECERDC）、サバ経済開発投資局（SEDIA）、サラワク地域
  回廊開発庁（RECODA）。
- **ブミプトラ関連機関**——ブミプトラ・アジェンダ推進ユニット（TERAJU）、Yayasan
  Peneraju、国民資本会社（Ekuiti Nasional Berhad、EKUINAS）。
- **石油・ガス**——マレーシア石油資源公社（Malaysia Petroleum Resources
  Corporation、MPRC）、ジョホール石油開発公社（Johor Petroleum Development
  Corporation、JPDC）。

経済省の機関公式ページは、確認日時点で特定数の機関を掲載している。内閣再編後は省
庁の機関構成が変わりうるため、正式な用途に依拠する前に、`ekonomi.gov.my`で現行の
正確な一覧を確認すること。

## 経済省 vs 財務省

この二つの省庁は、いずれも国の「お金」を扱うためしばしば混同されるが——その役割
分担は異なる。

| | 経済省 | 財務省 |
| --- | --- | --- |
| 焦点 | 中長期の開発を計画する | 年次の歳入、税務及び支出を管理する |
| 主要な手段 | マレーシア計画（5年） | 連邦予算（年次） |
| 設定するもの | 開発支出の上限と配分 | 毎年の実際のリンギット配分 |
| 承認形式 | 国会における政策動議 | 歳出法案（Akta Perbekalan） |

要するに：経済省が5カ年の枠組みを設定し、財務省がそれを一年ごとに満たしていく。

## 次に読むべきもの

マレーシア計画そのものの詳細——各版の主軸、成果目標、投資額——については、
[マレーシア計画](/economy/malaysia-plans)を参照のこと。5カ年の枠組みがどのよう
