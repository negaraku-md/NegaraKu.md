何者かがSUHAKAMに人権侵害の苦情を申し立てたとき、この委員会は実際に何ができ、
何ができないのか。その答えは修辞ではない——それは、四つの職能、一連の調査権限、
そして越えてはならないいくつかの一線を正確に定める、1999年制定の簡潔な一つの
法律の中にある。

## 概要

| | |
| --- | --- |
| 正式名称 | マレーシア人権委員会（Suruhanjaya Hak Asasi Manusia Malaysia、SUHAKAM） |
| 種類 | 国内人権機関（NHRI）、法人団体（s.3） |
| 設立法 | 1999年マレーシア人権委員会法（Act 597） |
| 国王の裁可 | 1999年8月27日 |
| 官報掲載 | 1999年9月9日 |
| 施行 | 2000年4月20日（PU(B) 122/2000） |
| 直近の主要な改正 | Act A1714 2024（2024年6月27日官報掲載） |
| ウェブサイト | `suhakam.org.my` |

SUHAKAMは独立した法人団体であり——自らの名において訴え、また訴えられることが
できる——しかし裁判所でも執行当局でもない。その役割は、調査し、勧告し、報告する
ことである。

## 本法における「人権」とは何を意味するのか？

これは最も誤解されやすい問いである。Act 597 の s.2 は「人権」を、連邦憲法
第II編に定める基本的自由として明確に定義している。したがって、SUHAKAMにとって
の第一の参照点は常に国家自身の憲法である——身体の自由、平等、言論・集会・信仰
の自由といった権利である。

s.4(4)はもう一段の層を加える——本法の目的上、1948年世界人権宣言は、連邦憲法
に抵触しない範囲において考慮されなければならない。国際基準は勘案されるが、
憲法が依然として優先する。

## 四つの中核的職能とは何か？

s.4(1)は四つの職能を列挙している——それ以上でも、それ以下でもない。

- **(a) 啓発・教育** — 人権に関する啓発を推進し、教育を提供すること。
- **(b) 立法に関する助言** — 政府による立法、指令及び行政手続の起草を助言・
  支援し、必要な措置を勧告すること。
- **(c) 国際条約の勧告** — 人権分野における国際条約及び国際文書への加入又は
  参加について政府に勧告すること。
- **(d) 苦情申立ての調査** — s.12に定めるとおり、人権侵害に関する苦情申立て
  を調査すること。

## その職能を支える権限は何か？

s.4(2)は、SUHAKAMがこれらの職能を遂行するための権限の一覧を定めている。
実務上とりわけ重要なものは以下のとおりである。

| 権限（s.4(2)） | 実務上の意味 |
| --- | --- |
| (a) 研究及びプログラム | セミナー、ワークショップ、調査研究を実施し、その成果を普及させること |
| (b) 苦情申立てに関する助言 | 政府／当局に対する苦情申立てについて助言し、適切な措置を勧告すること |
| (c) 侵害の調査及び確認 | 本法に従い人権侵害を調査し確認すること |
| (d) 拘禁場所への訪問 | あらゆる拘禁場所、施設その他の場所を訪問し、必要な勧告を行うこと |
| (e) 公的声明 | 必要に応じ人権に関する公的声明を発すること |
| (f) その他の適切な活動 | 成文法に基づき必要なその他の活動を行うこと |

拘禁場所を訪問する権限（s.4(2)(d)）は、2024年の改正によって強化された。
新設のs.4(3)は、法律又は指針が定める手続が遵守される限り、当該場所を管理
する者はその訪問を拒否してはならないと定めている。同じ改正は、子どもの苦情
申立てを受理し対応するための専用の仕組み（s.4(2)(ea)）も追加した。

## 委員とは誰で、どのように任命されるのか？

s.5のもとで、SUHAKAMは7人以上20人以下の委員から構成される。委員は、国王
（Yang di-Pertuan Agong）により、首相の勧告に基づいて任命される。首相は、
その勧告を行う前に、s.11Aのもとに設けられた委員会と協議しなければならない。

2024年の改正は、委員資格の要件をより厳格にした。

- **s.5(3A)** — 委員には、障害者（OKU）の代表を少なくとも1名、及び女性代表
  を少なくとも30パーセント含めなければならない。
- **s.5(3B)** — 政治活動に従事し、いずれかの政党に登録している者は、委員と
  して任命されてはならない。

任期は3年であり、委員は1回に限り再任され、さらに3年の任期を務める資格を有する
（s.5(4)）。委員長は委員の中から国王により指名され（s.6）、副委員長は委員の
互選による。2024年の改正はまた、子どもに関する人権事項を扱うため、児童担当
委員長（Ketua Pesuruhjaya Kanak-Kanak）1名及び児童担当委員（Pesuruhjaya
Kanak-Kanak）2名の職（s.6A）を新設した。

## 苦情申立てと調査のプロセスはどう進むのか？

本法のPart III（第III部、s.12～s.15）が調査を規律する。SUHAKAMは、自らの
発意により、又は不服を有する者、団体、若しくはこれらを代理する者による苦情
申立てに基づき、調査を行うことができる（s.12(1)）。

調査に関して、s.14はSUHAKAMに審判所（tribunal）に類する権限を与えている
——マレーシアに居住するあらゆる者を召喚して証言又は書類の提出のため出頭
させ、宣誓のうえ証拠を採取し、さらには1950年証拠法（Evidence Act 1950）の
もとでは許容されないかもしれない証拠をも受理する権限である。s.15は、裁判所
における証人と同一の特権をもって証人を保護する。

しかし、この権限には限界がある。調査の結果、侵害が明らかにならなかった場合、
SUHAKAMはその認定を記録し、申立人に通知する（s.13(1)）。調査の結果、侵害が
明らかになった場合、SUHAKAMは必要な勧告とともにその事案を関係当局に付託する
ことができる（s.13(2)）——そして2024年の改正以降、当該当局は、講じた措置に
ついてSUHAKAMに通知する義務を負う（s.13(3)）。

## 法令自体が課す限界とは何か？

三つの重要な限界が、SUHAKAMを処罰機関ではなく、調査及び助言を行う機関たら
しめている。

1. **裁判所と重複してはならない。** s.12(2)は、SUHAKAMが、裁判所で係属中の
   （上訴を含む）苦情申立て、又は既に終局的に判決が下された苦情申立てを調査
   することを禁じている。調査の進行中に、当該事項が裁判所の手続の対象と
   なった場合、SUHAKAMは直ちに調査を停止しなければならない（s.12(3)）。
2. **勧告に拘束力はない。** 本法がSUHAKAMに与える権限は、勧告及び報告を
   行うことであり、執行することではない。行動を起こすかどうかは、政府及び
   国会に委ねられている。
3. **外国資金の受領禁止。** s.19(2)は、SUHAKAMがいかなる外国資金も受け取る
   ことを禁じている。s.19(3)のもとの狭い例外は、人権教育及び啓発を目的と
   する無条件の資金のみを認めている。政府は、毎年十分な資金を供与しなければ
   ならない（s.19(1)）。

## どのように報告し、独立性を維持しているのか？

s.21は、SUHAKAMに対し、その全活動に関する年次報告書を、翌年の国会の最初の
会期までに、SUHAKAMに付託された事案の一覧及び講じられた措置とともに国会に
提出することを義務づけている。SUHAKAMはまた、必要に応じ随時、特別報告書を
提出することもできる。法定機関として、その会計は1980年法定機関（会計及び
年次報告書）法（Statutory Bodies (Accounts and Annual Reports) Act 1980）
の適用を受ける（s.20）。

SUHAKAMの独立性は、外部からも測定されている。2026年6月9日付の第32-2026号
メディア声明において、SUHAKAMは、国内人権機関世界連盟（GANHRI）のもとにある
認定小委員会（SCA）が、その第47回会期において、SUHAKAMの「A」格付けの認定を
再確認したと発表した——これは、国内人権機関の独立性、実効性、多様性及び権限を
規律する国際基準であるパリ原則への継続的な遵守を反映する最高位の格付けである。
（2026年6月9日はSUHAKAMの発表日であり、SCA会期における実際の決定日は本資料
では確認されていない。）「A」格付けは、SUHAKAMが、人権理事会を含む国連の
人権メカニズムに全面的に参加することを可能にする。

## 次にすべきことは？

苦情を申し立てたい場合は、まず二つの点を確認することから始めるとよい。その
問題が連邦憲法第II編の基本的自由（s.2の定義）に該当するかどうか、そしてそれ
が裁判所で係属中又は既に審理済みであるかどうか（s.12(2)の限界）である。
SUHAKAMの権限の根拠となる権利を理解するには、[連邦憲法](/law/federal-constitution)
の基本的自由に関する規定を読んでほしい。その年次報告書がどのように審査される
かを知るには、[国会](/government/parliament)の役割を参照してほしい。行動を
起こす前に、`suhakam.org.my`で現行の申立書式及び申立窓口を確認すること。
