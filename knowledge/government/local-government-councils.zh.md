最贴近日常生活的政府层级——负责垃圾收集、路灯、营业执照、建筑图则批准与门牌税的那一层——并非联邦政府或州政府，而是**地方政府机构（Pihak Berkuasa Tempatan，PBT）**。然而，与通过选举产生成员的[下议院](/government/dewan-rakyat)和[州立法议会](/government/state-assemblies-dun)不同，今天的PBT成员是**委任**的，而非**民选**的。

本文依据法律条文与官方来源，说明PBT的结构、法律框架与组成，以及从民选议会过渡到委任议会的历史背景——采取描述性方式，不作评价。

## 概览

| | |
| --- | --- |
| 通用名称 | 地方政府机构（PBT）／地方政府（*local authority*） |
| 地位 | 第三层行政机构，位于联邦政府与州政府之下 |
| 主要法律（西马） | 《1976年地方政府法令》（171号法令） |
| 法律（沙巴） | 《1961年地方政府条例》 |
| 法律（砂拉越） | 《1996年地方机构条例》 |
| 类别 | 市政厅、市议会、县议会 |
| 组成 | 主席／市长 + 不少于8名、不多于24名议员（171号法令第10条） |
| 委任者 | 州政府机构（第10条） |
| 议员任期 | 不超过三年；可获重新委任（第10条） |
| 统筹部门 | 房屋及地方政府部（KPKT）／地方政府局（JKT） |

## PBT的三种类别

根据KPKT辖下地方政府局（JKT）的官方门户，PBT依据人口总数与年收入标准分为三种类别：

| 类别 | 人口总数 | 年收入 |
| --- | --- | --- |
| **市政厅**（*City Council*） | 超过500,000人 | 超过1亿令吉 |
| **市议会**（*Municipal Council*） | 超过150,000人 | 超过2,000万令吉 |
| **县议会**（*District Council*） | 少于150,000人 | 少于2,000万令吉 |

市政厅一般管辖主要城市地区与州首府，市议会管辖半城市地区，而县议会则较侧重于乡区。这些标准决定一个PBT的地位，并可在某地区发展时重新审视。

根据JKT KPKT门户，马来西亚共有**151个PBT**——19个市政厅、40个市议会与92个县议会。此外，还有若干其他机构获各自的州政府授权执行PBT职能，包括布城机构（Perbadanan Putrajaya）、纳闽机构（Perbadanan Labuan）、居林高科技PBT（PBT Kulim Hi-Tech）与刁曼发展局（Lembaga Pembangunan Tioman）。（确切数目会不时变动，须对照KPKT最新统计核实。）

## 法律框架：一个西马，两个婆罗洲

马来西亚的地方政府并非由单一法律管辖，因为它涉及联邦与州的权力划分：

- **西马** —— 《1976年地方政府法令》（171号法令），适用于西马。
- **沙巴** —— 《1961年地方政府条例》。
- **砂拉越** —— 《1996年地方机构条例》。

171号法令赋予州政府机构在各自州内设立、合并或解散PBT，以及划定其行政区域界线的权力。关于地方政府权力如何被置于州司法权范围之下的背景，参见[联邦—州权力划分](/government/federal-state-division)。

## 组成：171号法令第10条的规定

171号法令第10条规定一个PBT的组成。一个地方政府机构由以下人员组成：

1. 一名**主席**（Yang Dipertua，适用于市议会与县议会）或一名**市长**（Datuk Bandar／*Mayor*，适用于市政厅）；以及
2. **不少于八（8）名、不多于二十四（24）名议员**（*Councillors*）。

全部成员**由州政府机构委任**——即由州政府通过相关的州政府机构委任。第10条也列明议员的资格：他们须在该地方政府机构辖区内居住，且在州政府机构看来，是在地方政府事务方面具有丰富经验，或在任何专业、商业或工业领域取得卓越成就，或有资格代表该地区社会利益的人士。

每名议员的**任期**不超过三年，且议员在任期届满后可获重新委任。

值得注意所使用的用语：在第10条之下，议员由州政府机构**委任**。171号法令并未规定通过选举产生议员——这一区别正是下文历史讨论的基础。

## 职能与权力

PBT依据171号法令及相关法律执行各种市政职能，包括：

- 公共服务，如固体废物管理、清洁、沟渠与路灯；
- 发展规划与管制——建筑图则批准、准证与合规；
- 营业执照发放与附例（*by-laws*）执法；
- 公共设施的维护，如公园、市场与礼堂。

PBT的主要收入来源是对其辖区内应课差饷产业征收的**差饷**（rate）——常称为门牌税或估价税——此外还有执照费、罚款及来自联邦与州政府的拨款（*grant*）。（171号法令中管辖差饷的确切条文号码须对照法令原文核实。）

## 从民选议会到委任议会

今天的委任议会制度并非原本的状态。马来亚的地方政府曾经拥有民选成员：

- **1952年** —— 首次市议会选举在吉隆坡举行，由巫统—马华联盟胜出，赢得十二席中的九席。地方选举在1950年代及1960年代初于多个城市推广。
- **1965年** —— 在**印马对抗（Konfrontasi）**（始于1964年末）期间宣布紧急状态之后，原定于1965年及1966年举行的地方政府选举被暂停。此项暂停此后一直生效。
- **1965至1970年** —— 政府于1965年成立由参议员阿蒂·纳哈潘（Athi Nahappan）主持的**地方政府调查皇家委员会**。其报告于1970年发表，建议恢复民选代表——包括须设立民选地方政府机构管理每个州首府，以及在其他PBT通过选举产生代表。
- **1973年** —— 《1973年地方政府（临时条款）法令》赋予联邦政府审查地方政府法律及临时管理PBT行政的权力。（此文书的细节须对照法律原文核实。）
- **1976年** —— **《1976年地方政府法令》（171号法令）**获得通过。171号法令并未如阿蒂·纳哈潘委员会所建议恢复民选议会，而是规定了由州政府机构**委任**议员的制度。

在砂拉越，据报地方政府选举比西马持续得更久，最终才不再举行。（确切年份须对照官方记录核实。）

## 恢复地方选举的尝试

恢复地方政府选举的课题——有时称为"第三票"——不时重新浮现：

- **2008年** —— 槟城州与雪兰莪州政府表达恢复PBT选举的意愿，但未能实现。
- **2021年** —— 当时的房屋及地方政府部长提到成本是一项考量（估计每个议会约需200万令吉）。
- **2024年** —— 政府表示地方政府选举当时并非优先事项。

地方选举能否恢复的问题也涉及联邦与州权力的法律议题——这一领域至今仍是公众与法律辩论的题材。

## 常见误解

**"PBT议员由居民选出。"** 在171号法令第10条之下，议员由州政府机构**委任**。地方政府选举自1965年起被暂停，且未再恢复。

**"一部法律管辖马来西亚所有PBT。"** 171号法令仅适用于西马；沙巴受《1961年地方政府条例》管辖，砂拉越则受《1996年地方机构条例》管辖。

**"市长与主席是一样的。"** *市长*（Datuk Bandar／Mayor）一词用于市政厅，而*主席*（Yang Dipertua）用于市议会与县议会。

**"市政厅、市议会或县议会的地位是任意决定的。"** PBT的类别依据KPKT所列明的人口与年收入标准设定，一个PBT在符合相关标准时可获升格。

**"阿蒂·纳哈潘委员会建议委任议会。"** 恰恰相反——由阿蒂·纳哈潘主持的皇家委员会（1970年报告）建议恢复**民选**代表。171号法令选择了不同的做法，保留了委任议会。
