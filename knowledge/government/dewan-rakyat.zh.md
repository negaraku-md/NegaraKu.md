  - q: "下议院议长是否必须是国会议员？"

  - q: "如果最高元首不御准一项法案，会发生什么情况？"
    a: "第66(4)条规定，一项法案呈交后有30天期限，须透过加盖御玺予以御准。第66(4A)条规定，若该法案在该期限内未获御准，则该期限届满时该法案即成为法律，其方式与已获御准时相同。第66(5)条则规定，任何法律在公布之前均不得生效。"
  - q: "上议院可以否决下议院已通过的法案吗？"
    a: "第68条将该项否决的效果限于延迟。就金钱法案而言，若上议院未在一个月内不经修正通过该法案，该法案即呈交最高元首，除非下议院另有指示。就非金钱法案而言，下议院可在下一会期再次通过该法案，但不得早于其首次通过后一年，其后该法案即呈交以供御准。第68(5)条将宪法修正法案排除于此机制之外。"
  - q: "每一个悬空议席都必须透过补选填补吗？"

## 概览

| | |
| --- | --- |
| 名称 | 下议院 Dewan Rakyat（House of Representatives） |
| 类型 | 两院制国会中经选举产生的下议院 |
| 宪制依据 | 联邦宪法 Part IV（第四部分）第4章 |
| 议员人数 | 222名民选议员（第46(1)条） |
| 资格年龄 | 不低于18岁（第47(b)条） |
| 最长任期 | 自首次开会起五年（第55(3)条） |
| 法定人数 | 26名议员，不包括主席（议事常规第13(1)条） |
| 主持官员 | 下议院议长（第57条） |

一部约束马来西亚境内每一个人的国会法令，始于一件几乎不为人所察觉的事：秘书在
议事桌前宣读一项法案的名称，而无人提出异议。那就是一读。此后的一切——辩论、
逐条修正、表决、御准——都是一连串必须依序满足的条件，法案才能取得法律效力。

本文以描述性方式说明这一连串程序：谁出任下议院议员、他们任职多久，以及宪法
究竟允许该院做些什么。

## 222个议席，规定于宪法本身之中

大多数资料来源仅止于222这个数字。宪法却不然。第46(2)条在其本身文本之中，将
该数字细分至各州属与联邦直辖区——并非透过普通立法，也非透过行政命令。

| 州属／直辖区 | 议席 |
| --- | ---: |
| 砂拉越 | 31 |
| 柔佛 | 26 |
| 沙巴 | 25 |
| 霹雳 | 24 |
| 雪兰莪 | 22 |
| 吉打 | 15 |
| 吉兰丹 | 14 |
| 彭亨 | 14 |
| 槟城 | 13 |
| 森美兰 | 8 |
| 登嘉楼 | 8 |
| 马六甲 | 6 |
| 玻璃市 | 3 |
| **州属总数** | **209** |
| 吉隆坡联邦直辖区 | 11 |
| 纳闽联邦直辖区 | 1 |
| 布城联邦直辖区 | 1 |
| **联邦直辖区总数** | **13** |
| **总数** | **222** |

每名议员代表一个选区，如国会官方门户网站所述。由于这项数字载于宪法之中，更改
它意味着修宪——而第159(3)条规定，须在二读与三读时获得议员总数不少于三分之
二的支持。

222这个数字本身于2006年1月19日生效，当时Akta A1260将「二百一十九」这一数字
取代。议席数目的历史沿革可直接从第46条的修正记录中读到：1962年为104名议员，
1963年马来西亚成立后为159名（包括来自新加坡的15名），1965年后为144名。

## 谁有资格出任议员

第47条规定了两项基本条件：具有公民身份，以及在联邦境内居籍。其余的就是年龄
问题——而这正是两院有所不同之处。

- **下议院** —— 不低于 **18岁**。
- **上议院** —— 不低于 **30岁**。

第48(1)条列出丧失资格的理由：被裁定精神不健全；未获解除破产的破产人；担任有
收益的职位；未能提交选举开支报表；因罪行被定罪并被判处不少于一年监禁或不少
于RM2,000罚款，且未获无条件赦免；或自愿取得外国国籍。

## 五年时钟

下议院并非永久存在。第55条规定了它的整个周期，其中的数字十分精确。

| 条文 | 时限 |
| --- | --- |
| 第55(1)条 | 某一会期最后一次开会与下一会期首次开会之间，不得相隔超过**六个月** |
| 第55(3)条 | 国会自其首次开会之日起持续**五年**，其后解散 |
| 第55(4)条 | 须于解散后**60天**内举行大选 |
| 第55(4)条 | 国会须在解散后不迟于**120天**内被召集开会 |

请留意第55(3)条的措辞：「除非提前解散……随后即告解散」。这项自动解散无须任何
行动即可发生。提前解散的权力则归于最高元首，依据第55(2)条行使。

休会（Prorogation）并非解散。第55(5)条规定，尚未处理完毕的法案不因休会而失
效，而第55(7)条则保障正等待御准的法案，不因休会或解散而失效。

## 法案的路径

第66(1)条规定，国会制定法律的权力，是透过获两院通过的法案——或在第68条所指
的情形下，仅由下议院通过——并经最高元首御准而行使的。议事常规则填补其中的程
序细节。

1. **一读。** 根据议事常规第48条，部长在发出至少一天的通知后，可将法案提呈
   会议，而无须获得该院的命令。法案的名称由秘书在议事桌前宣读。不作辩论。
2. **二读。** 议事常规第53条规定，须在一读后尽快发出通知，而议事常规第53(2)
   条则规定，在法案送交议员之前，不得进行二读。此阶段的辩论涉及法案的原则。
3. **委员会阶段。** 议事常规第54(2)条：法案经二读后，即交付全体委员会，除非
   该院通过动议将其交付遴选委员会。议事常规第54(1)条则容许在二读之前将法案
   交付遴选委员会。逐条条文的审议就在此阶段进行。
4. **三读。** 议事常规第61(1)条将辩论限制于该法案的内容。
5. **上议院，** 然后是 **御准。** 第66(3)条将法案送交另一议院。

表决依出席投票议员的普通多数议决（第62(3)条），除非宪法要求特别多数。主席仅
在为避免票数相同而有必要时方投票，在其他任何情形下均不得投票。第62(5)条禁止
不在场的议员投票。

最高元首有**30天**的期限予以御准（第66(4)条）。若该期限届满，第66(4A)条规
定，该法案即成为法律，「其方式犹如他已予以御准一样」。第66(5)条另加上一项最
后条件：任何法律在公布之前均不得生效。

## 下议院独有的两项权力

这正是简短说明中最常被遗漏的部分。

**财政事务由此开始。** 第67(1)条列出七类财政规定——其中包括征收或提高税捐、
联邦借款、由统一基金（Consolidated Fund）拨支款项，以及账目审计。凡包含此类
规定的法案或修正案，**不得由部长以外的人提出或动议**，且**不得在上议院提
出**。该资格取决于负责财政事务的部长表明该项规定并非仅属附带性质。

**上议院可以延迟，但不能阻挡。** 第68条设定了两种不同的时钟：

| 法案类型 | 若上议院未予通过的效果 |
| --- | --- |
| 金钱法案 | 至少在会期结束前**一个月**送交上议院；若未能在**一个月**内不经修正通过，则呈交最高元首，除非下议院另有指示 |
| 其他法案 | 下议院可在下一会期再次通过该法案，但**不得早于其首次通过后一年**；若上议院再次未予通过，该法案即呈交以供御准 |

两项细节强化了这项权力。第68(6)条将「金钱法案」的定义交由**下议院议长的意
见**判断。而第68(4)条则要求议长出具证明，表明该条的规定已获遵循——该证明
「就一切目的而言均属最终定论，不得在任何法院提出质疑」。

第68(5)条设下限制：此机制不适用于宪法修正法案，获第159(3)条豁免的修正案除
外。

## 监督职能

第43(3)条以一句话确立其基础：「内阁应对国会负集体责任。」第43(2)(a)条规定，
首相须从下议院议员中委任，此人须是最高元首认为可能获得该院多数议员信任者，
而第43(4)条则规定该信任丧失时的后果。

其日常监督工具载于议事常规之中。

- **质询。** 议事常规第21(1)条容许向部长提出关乎其职务范围内事务的质询。议
  事常规第22(2)条规定，须于会议开始前不迟于14个工作日发出书面通知，而议事
  常规第22(3)条则将每名议员在一个开会日内可提出、标注为「口头回答」的质询
  限制为三则。
- **公共账目委员会。** 议事常规第77条规定，本委员会须在每一届国会开始时获委
  任，以审查马来西亚政府的账目，以及依据第107条呈交的总审计司（Auditor
  General）报告书。本委员会由该院委任的一名主席与一名副主席，连同六至十二
  名议员组成。议事常规第77(4)条禁止部长出任主席一职或成为其成员，而议事常
  规第77(5)条则赋予其传唤人士出席，以及要求提交文件与记录的权力。
- **特权。** 第63(1)条将议事程序的有效性置于法院管辖权之外，而第63(2)条则保
  障任何人，就其在参与议事程序期间所发表的言论或所投的票，不受法院诉讼追
  究。

## 常见错误

**「国会任期恰好为五年。」** 第55(3)条所计算的五年，是从**首次开会之日**起
算，而非从选举日期起算。第55(1)条则另设一项相隔六个月的独立限制，规范各会期
之间的间隔。

**「议长必须是国会议员。」** 第57(1)(a)条容许选出一名*符合资格*当选为议员的
人士，即使此人并非议员。

**「每一个悬空议席都会引发一场补选。」** 第54(1)条的但书规定，若某议席出缺是
在国会依第55(3)条将解散之日起两年内确定的，该出缺不予填补，除非议长以书面
方式通知选举委员会，指出多数党的议席实力已受影响。

**「国会休会时，法案就会失效。」** 第55(5)条对尚未处理完毕的法案另有相反规
定。

**「国会的权力不受限制。」** Ninth Schedule（第九附表）将事务划分为联邦事项
表（Federal List）、州事项表（State List）与共同事项表（Concurrent
List）——参见[马来西亚国会](/zh/government/parliament)与
[联邦宪法](/zh/law/federal-constitution)。
