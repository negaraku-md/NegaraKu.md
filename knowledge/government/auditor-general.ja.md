毎年、分厚い一冊の報告書が下院（Dewan Rakyat）に提呈される。それは、数十億リンギットもの公金が
——各省庁、州の部局、法定機関、そして政府関連企業（GLC）によって——どのように使われたかを
検証するものである。その執筆者は、野党の政治家でも、政府の外にある独立機関でもない。それは
一人の政府職員であり、憲法は、彼が監査する対象であるその政府自身によって罷免されることのない
よう、意図的にこの職員を保護している。

その職こそが会計検査院長であり、そうする権限は行政上の方針から生じたものではない——それは
連邦憲法そのものに書き込まれている。

## 概要

| | |
| --- | --- |
| 職位 | 会計検査院長 |
| 部局 | 国家監査局（マレーシア） |
| 憲法上の根拠 | 連邦憲法第105-107条 |
| 法定上の根拠 | 1957年監査法（Audit Act 1957、Act 62） |
| 任命者 | 国王、首相の助言に基づき、統治者会議と協議のうえ |
| 職の保障 | 連邦裁判所の裁判官と同一の理由及び方法によるのでなければ罷免されない |
| 報告先 | 国王（連邦レベル）及び統治者／州元首（Yang di-Pertua Negeri）（州レベル） |
| 報告の提呈先 | 下院、及びそれぞれの州議会 |

## 任命：第105条

第105条(1)は、会計検査院長を置くものとし、国王が首相の助言に基づき、かつ統治者会議と
協議のうえ任命すると定めている。このパターンは
[司法長官](/government/attorney-general)の任命と類似している——正式な権限は国王に
あるが、助言に基づき行使される。

この職を過去に務めた者は再任される資格を有するが、連邦又は州の公務においていかなる他の
職にも任命される資格を有しない。この制限は、この職が他の政府職への足がかりとして利用
されることを防ぐものである。

最も重要な保障は任期にある：会計検査院長はいつでも辞職することができるが、連邦裁判所の
裁判官と同一の理由及び方法によるのでなければ罷免されない。その報酬及び勤務条件は、
いったん任命された後は、その者にとって不利益となるように変更することができない。その
報酬の措置は国会が法律によって定め、統合基金（Kumpulan Wang Disatukan）に負担させる
ものであり——[連邦予算](/economy/federal-budget)における通常の省庁支出のように、
毎年の承認を要するものではない。

これらの特徴の組み合わせ——助言に基づく任命、その後の他職就任の禁止、そして裁判官と
同等の任期保障——は、一つの目的のために設計されている。すなわち、会計検査院長が、自らが
監査するその同じ政府の温情に頼ることなく、政府を監査できるようにすることである。

## 監査権限：第106条及び1957年監査法

第106条は、連邦及び各州の会計は会計検査院長によって監査され、報告されるものとすると
定めている。追加の職務は、連邦法律によって会計検査院長に付与することができる。

1957年監査法（Act 62）はその範囲を詳細に定めている。同法s.1は、連邦、各州及びその他
指定された公的機関の会計監査に適用されると規定する。s.5は、その監査の管轄範囲を定めて
おり——連邦及び各州の会計官の会計、並びに政府の補助金又は貸付を受ける団体及び事業体の
会計を対象とする。s.6は、その監査の基準を定めている：公金に対して適正な管理が存在する
かどうか、支出が正当な権限にしたがっているかどうか、そして資金がその充当された目的の
ために使用されたかどうかを確認するものである。

一方、s.7は会計検査院長に広範な調査権限を与えている——必要な説明及び情報を求めて何人を
も召喚すること、関連するすべての記録、文書及び財産に無償でアクセスすること、並びに
宣誓又は宣言のもとで証人を尋問することである。この権限により、国家監査局は、被監査
機関の許可を待つことなく、その業務を遂行することができる。

## 報告の行き先：第107条

第107条は報告経路を定めている。会計検査院長はその報告書を国王に提出しなければならず、
国王はその報告書を[下院](/government/dewan-rakyat)に提呈させる。ある州の会計に関する
報告書については、副本が当該の統治者又は州元首にも送付され、その州の州議会で提呈される。

提呈後、その報告書は通常、さらなる検討のため下院の公会計委員会（Jawatankuasa Kira-Kira
Wang Negara、PAC）に付託される——これは、会計検査院長の指摘事項に基づいて公金の支出を
審査する国会の特別委員会である。本稿は、いずれか特定の報告書又は指摘事項の内容ではなく、
国家監査局そのものの憲法上の権限に焦点を当てるものである。

## 国家監査局の組織構造

国家監査局は会計検査院長によって率いられ、いくつかの部門によって支えられている。その
一部を挙げると：

- **会計検査院長室** — 監査業務及び局の行政事務を調整する。
- **国家監査アカデミー** — 監査、会計、IT、管理及び国際事務の分野で職員を養成する。
- **ICT監査部門** — 公共部門の情報システム監査の調査を計画し、監督する。
- **法律顧問ユニット** — 法律上の助言を行い、契約書及び了解覚書を審査する。
- **技術部門** — 各分野及び州事務所に対し監査上の技術的助言サービスを提供する。
- **政策・国際関係部門** — 監査政策、品質保証、並びに二国間及び多国間関係を策定する。
- **廉正ユニット** — ガバナンス、検知、苦情及び廉正遵守を管理する。
- **監査フォローアップ部門** — 被監査機関が是正措置を実施することを確保する。

## 監査の種類

国家監査局は、目的の異なるいくつかの種類の監査を実施している：

| 監査の種類 | 重点 |
| --- | --- |
| 財務諸表監査 | ある事業体の財務諸表が真実かつ公正な概観を示しているかどうか、及び会計帳簿が適切に最新の状態で維持されているかどうか |
| 業績監査 | 政府の計画又は活動の経済性、効率性及び有効性 |
| 統治監査 | システム及び運用が定められた統治に従っているかどうか |
| 政府関連企業監査 | 政府関連企業の財務及び運営の実績 |

監査を実施する前に、被監査機関とともに着手会議（entrance conference）が開催され、
監査の目的、範囲及び方法が説明される——これは同局のよくある質問（FAQ）で頻繁に言及
される手続上の特徴である。

## よくある誤解

**「会計検査院長は国会議員である、あるいは政府の外にある独立機関の一員である。」**
会計検査院長は憲法によって保護された公務員であり、民選の代議士でもNGOの一員でもない。

**「会計検査院長の報告書は連邦の省庁のみを対象とする。」** 第106条及び1957年監査法の
もとでの権限は、州政府、法定機関及びその他指定された公的機関の会計も対象としている。

**「政府は、報告書の内容に不満があれば会計検査院長を罷免できる。」** 第105条のもとでの
任期保障は、罷免の理由及び方法を連邦裁判所の裁判官と同一のものとしており——これは
通常の公務員よりもはるかに高い水準である。

**「その報告書がそのまま最終的な決定となる。」** 下院に提呈された報告書は、通常、さらなる
審査及び後続の措置のため公会計委員会に付託される。

## 次のステップ

第105-107条が位置づけられるより広い憲法上の枠組みを理解するには、まず
[連邦憲法](/law/federal-constitution)から始め、次に報告書が
[下院](/government/dewan-rakyat)でどのように提呈され、審査されるかを見るとよい。
任命及び報告書の受理における国王の役割を理解するには、
[Yang di-Pertuan Agong](/government/yang-di-pertuan-agong)を参照のこと。監査対象と
なる公金の文脈については、[連邦予算](/economy/federal-budget)を参照のこと。また、
公金の不正使用を同じく捜査する別の機関については、
[SPRM](/government/macc-sprm)を参照のこと。

指名された人間の査読者によっても、まだ審査されていない。
