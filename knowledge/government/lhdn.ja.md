## 概要

| | |
| --- | --- |
| 正式名称 | Lembaga Hasil Dalam Negeri Malaysia／Inland Revenue Board of Malaysia |
| 種類 | 法定機関 |
| 根拠法 | 1995年内国歳入庁法（Inland Revenue Board of Malaysia Act 1995、Act 533） |
| 裁可／官報公示 | 1995年2月7日／1995年2月16日 |
| 施行 | 1995年3月1日 |
| 報告先 | 財務省 |
| 管理理事会 | 財務省事務総長（Secretary General of the Treasury）が主宰する理事会（Act 533, s.6） |
| ウェブサイト | `hasil.gov.my` |

## 所管法令

| 法令 | 対象 |
| --- | --- |
| 1967年所得税法（Act 53） | 個人、法人及び石油所得税；源泉徴収税 |
| 1976年不動産譲渡益税法（Real Property Gains Tax Act 1976） | 不動産及び不動産会社株式の処分による利益 |
| 1949年印紙法（Stamp Act 1949） | 法律文書に対する印紙税 |
| 1990年ラブアン事業活動税法（Labuan Business Activity Tax Act 1990） | ラブアン実体 |
| 1986年投資奨励法令（Promotion of Investments Act 1986） | 税務優遇措置、MIDAと共同で所管 |

## 運営するプラットフォーム

- **MyTax**——納税者向けサービスのシングルサインオン・ポータル。
- **e-Filing**——個人及び法人の申告書提出。
- **e-CKHT**——RPGTの申告。2025年1月1日より義務化されている。
- **STAMPS**——印紙税の賦課及び納付。
- **MyInvois**——全国的な電子インボイスプラットフォームであり、売上高に応じて段階的に導入される。

## 公表物とその位置づけ

三つの階層があり、しばしば混同される。

- **Public Rulings**は、ある条文についての同局の解釈を示す。裁判所を拘束するものではないが、LHDNが税務調査において取る立場である。
- **運用ガイドライン**（Garis Panduan Operasi）は、申告手続き、罰則、減免といった手順を定める。これらは互いに取って代わることがあり、部分的にのみ取って代わる場合もあるが、その入れ替わりが着地ページで常に告知されるとは限らない。
- **Filing Programme**——申告及び納付についての年間カレンダーで、猶予期間を含む。毎年PDFとして公表される。

## 情報収集上の二つの注意点

**LHDNの英語ページは機械翻訳である。** 確認されている一例では、*"Kesemua balasan"*——すなわちすべての*対価（consideration）*——が*"All replies"*（すべての返信）と訳されており、これは法定上限の意味を逆転させている。重要な内容については、マレー語ページを読むこと。

**URLパスは変わる。** 雇用主向けページは `/en/employers/` から `/en/majikan/` に移行した。`hasil.gov.my/en/legislation/` は404の空ページを返す。`media/<hash>/` 形式のPDFパスは古くなっており、`/wp-content/uploads/` に置き換わっている。
