世界のほとんどの君主制は、同じ一つの問いに同じような方法で答えている。次の王は誰に
なるのか、と。その答えは通常、血統による世襲であり、任期は通常、終身である。

マレーシアはこれに異なる形で答える。連邦最高元首は選出される——統治者自身によっ
て、統治者自身の中から、任期5年で、選出のたびに再編成される一つの名簿に従って。こ
の仕組みは、連邦憲法第三附則に定められている。

## 概要

| | |
| --- | --- |
| 称号 | 国王（Yang di-Pertuan Agong） |
| 憲法上の地位 | 連邦最高元首（第32(1)条） |
| 選出者 | 統治者会議（第32(3)条） |
| 任期 | 5年 |
| 資格 | 在位する州の統治者（第三附則第一部） |
| 選出手続 | 第三附則及び統治者会議規則 |
| 就任宣誓 | 統治者会議の前で、連邦裁判所首席判事の立会いのもとで行う（第37(1)条） |
| 副職 | 副国王（Timbalan Yang di-Pertuan Agong）（第33条） |
| 王妃 | ラジャ・プルマイスリ・アゴン（第32(2)条） |
| 所在地 | イスタナ・ヌガラ（Istana Negara、国家宮殿）、クアラルンプール |

## この仕組みに比類がない理由

マレーシアの九つの州には統治者が存在する。残る四州——マラッカ、ペナン、サバ及び
サラワク——には統治者が存在せず、それぞれの州憲法は、国王をその州におけるイスラム
教の首長と定めている（第3(3)条）。

第五附則は、統治者会議が統治者と州元首とから構成されると定めている。しかし、国王
の選出及び罷免の事務に関しては、憲法は参加を統治者のみに限定している。在位する統治
者のみが選出され得るのであり、州元首は候補者とならない。

この仕組みを類のないものにしているのはそこにある。九人の世襲の統治者が、互いの間
で投票し、連邦最高の職位を誰が担うかを決定し、そしてこの営みを五年ごとに繰り返して
いるのである。

## 選出はどのように行われるか

第五附則第6節は、統治者御璽守護官に対し、国王の任期満了の四週間前までに、また欠
員が生じた場合にも同様に、統治者会議を招集するよう指示している。

続いて、第三附則第一部が選出そのものを規律する。

1. **資格。** 統治者は、成年に達していない場合、統治者御璽守護官に対し選出される
   ことを望まない旨を通知した場合、又は統治者会議が秘密投票により精神若しくは身体
   の欠陥、その他の理由によりその職務に適さないと決定した場合を除き、被選資格を有
   する。
2. **5票の閾値。** このような決議は、会議の少なくとも五人の構成員がこれに賛成の
   投票をしない限り、可決され得ない。
3. **名簿順の提呈。** 統治者会議は、選出名簿の首位にある州の、被選資格を有する統
   治者にその職を提呈する。その統治者が受諾しない場合、提呈は次の州へと移り、いず
   れかの統治者が受諾するまでこれが繰り返される。
4. **宣言。** 提呈が受諾されると、統治者会議はその統治者が選出されたことを宣言
   し、統治者御璽守護官はその決定を書面により国会の両院に通知する。

統治者会議の公式ポータルは、投票は番号を付されない投票用紙を用い、ペンと墨で記入
する方式で、秘密裏に行われること、そして統治者がその職を提呈される前に五票の多数を
得る必要があることを説明している。統治者御璽守護官が投票用紙の配布及び集計を取り扱
う。

選出後、第37(1)条は、国王がその職務を行う前に、統治者会議の前で、かつ連邦裁判所
首席判事の立会いのもとで、第四附則第一部に定める就任宣誓を宣誓し署名することを求め
ている。この宣誓は、統治者会議が任命する二名の者によって立ち会われる。

## 選出名簿：輪番の順序は変動する

ここは最も誤解されやすい部分である。憲法は固定された順序を定めていない。それが定
めているのは、変動する一つの名簿である。

第三附則第4節は、その効力について概ね次のように定めている。

- 最初の選出については、名簿には、当時彼らの間で認められていた優先順位に従い、す
  べての統治者の州が含まれる。
- 各選出の後、選出された統治者の州より前にある州は名簿の末尾に移され、選出された
  統治者の州は名簿から除かれる。
- 名簿にある州において統治者の交代が生じた場合、その州は名簿の末尾に移される。
- 名簿に州が残らなくなったとき、名簿は再編成される。すなわち、すべての統治者の州
  が再び組み入れられ、そのうち統治者が国王の職に就いたことのある州は、その職に就
  いた順序に従って並べられる。
- 再編成された名簿による各選出の後、選出された統治者の州より前にある州は末尾に移
  され、選出された統治者の州は最後尾に置かれる。

統治者会議のポータルは、ペラ州スルタンが第9代国王となった時点で第一巡が終了し、
その後の選出は、当該職に就いたことのある統治者の州の優先順位——第1位から第9位ま
で——に基づき再編成された名簿によって行われたと記録している。

現在在位している国王は第17代である。公式の報道によれば、スルタン・イブラヒム・
スルタン・イスカンダルは2024年1月31日より治世を開始し、登位式典はイスタナ・ヌガラ
のバライルン・スリ（正殿）において2024年7月20日に、任期5年をもって執り行われた。

## 助言に基づく権限、そして裁量権

第39条は連邦の行政権を国王に帰属させている。第40条は続いて、その権限がいかに行
使されるかを定めている——そして、ここにこそ、この主題全体の中で最も重要な区別があ
る。

**第40(1)条。** 憲法又は連邦法律に基づく職務の遂行にあたり、国王は、憲法に別段の
定めがある場合を除き、内閣（Jemaah Menteri）の助言、又は内閣の一般的な権限のもとで
行動する大臣の助言に従って行動しなければならない。同条はまた、国王に対し、その要求
により、内閣が入手し得る連邦の統治に関するあらゆる情報を得る権利を与えている。

**第40(1A)条。** 国王が助言に従って、助言に基づいて、又は助言を考慮したうえで行
動することを求められる場合、国王はその助言を受け入れ、これに従って行動しなければな
らない。

**第40(2)条。** 国王は、列挙された三つの職能の遂行、及び「本憲法に規定するその他
の場合」において、自らの裁量により行動することができる。

| 区分 | 憲法の条文による例 |
| --- | --- |
| 裁量（第40(2)条） | 首相を任命すること；国会解散の請求に対する裁可を留保すること；専ら統治者の特権、地位、栄誉及び威厳にのみ関わる統治者会議の招集を求めること |
| 助言に基づく（第40(1)条、第40(1A)条） | 首相の助言により他の大臣を任命すること（第43(2)(b)条）；統治者会議と協議したうえで首相の助言により裁判官を任命すること（第122B(1)条） |

第43(2)(a)条は、首相任命の基準を定めている。国王は、下院議員のうち、その判断に
おいて下院議員の多数の信任を得られる可能性がある者を首相として任命しなければならな
い。「その判断において」という文言こそが、これを国王自身の判断とするものである。

第43(4)条は、その全体像を補う。首相が下院議員の多数の信任を得られなくなった場
合、首相は、その要求により国王が国会を解散する場合を除き、内閣を総辞職させなければ
ならない。

## 憲法が定めるその他の職能

- **国会。** 第44条は、国会が国王、上院（Dewan Negara）及び下院（Dewan Rakyat）と
  から構成されると定めている。[マレーシア国会](/government/parliament)を参照。
- **会期。** 第55(1)条は、国王が随時国会を招集すること、及びある会期の最終会合と
  次の会期の最初の会合との間に六か月を超える期間を置かないことを求めている。第
  55(2)条は、国王が国会を休会又は解散することができると定めている。
- **御裁可。** 第66(4)条は、国璽を押すことにより法案を御裁可するための30日の期間
  を定めている。第66(4A)条は、その期間内に御裁可が与えられない場合、当該期間が満
  了したときに、あたかも御裁可されたかのように、当該法案がそのまま法律となる旨を
  定めている。
- **国軍。** 第41条は、国王を連邦国軍の最高司令官と定めている。
- **恩赦権。** 第42(1)条は、軍事法廷において審理される罪、並びにクアラルンプー
  ル、ラブアン及びプトラジャヤの連邦直轄区において犯された罪について、恩赦、刑の
  執行猶予及び減刑を行う権限を与えている。
- **イスラム教。** 第3(5)条は、国王を三つの連邦直轄区すべてにおけるイスラム教の
  首長と定めている。第3(2)条は、統治者会議がある行為、慣行又は儀式を連邦全体に拡
  大することに同意した場合、他のすべての統治者が、イスラム教の首長として国王が自
  らを代表することを許可する旨を定めている。
- **緊急事態布告。** 第150(1)条は、国王が重大な緊急事態が生じていると認める場
  合、緊急事態布告を発することができると定めている。

## 憲法がこの職位に課す制限

第34条は、在職中のいくつかの制限を列挙している。国王は、イスラム教の首長として
の職務を除き、自州の統治者としての職務を行わない。いかなる有給の職も保持しない。い
かなる商業活動にも積極的に関与しない。そして、国事訪問中を除き、統治者会議の同意な
しに15日を超えて連邦を離れない。

第32(1)条は、第十五部に基づき設置される特別法廷を除き、いかなる裁判所においても
国王に対して訴訟手続を提起することができないと定めている。第33A条は、国王がその特
別法廷において罪に問われた場合、国王は国王としての職務の遂行を停止するものとし、そ
の期間もなお5年の任期の一部として計算される旨を定めている。

## 副国王（Timbalan Yang di-Pertuan Agong）

第33条は副国王（Timbalan Yang di-Pertuan Agong）の職を設けている。副国王もまた、
統治者会議によって、5年の任期、又は在位する国王の残任期間のいずれかで選出される。
副国王は、国王の職が欠位の間、又は国王が職務を遂行できない間、その職務を行うが、15
日未満と見込まれる不在については、副国王がそれを必要又は適当と認める場合を除き、職
務を行わない。

第三附則第二部は、その選出方法を定めている。統治者会議は、国王の職が欠位の間は、
副国王を選出しない。

## この職位についてよくある誤解

**「輪番はアルファベット順又は州の規模による。」** 誤りである。それは第三附則第4
節の選出名簿に従うものであり、この名簿は各選出の後、及び各州における統治者の交代の
後、機械的に再編成される。

**「統治者会議のすべての構成員が投票する。」** 国王の選出に関しては、そうではな
い。第五附則は州元首を会議の構成員に含めているが、憲法は国王の選出及び罷免の職能を
統治者のみに限定している。

**「国王が法律に署名するのは単なる形式にすぎない。」** 憲法が定めているのは、構
造を伴わない形式ではなく、具体的な期間である。すなわち第66(4)条に基づく30日であ
り、その効果は第66(4A)条に定められている。

**「裁量権とは一般的な権限を意味する。」** 第40(2)条は裁量に属する職能を具体的に
列挙し、これに「本憲法に規定するその他の場合」を加えている——これは憲法が規定する
場合を指すのであり、開放的な範疇ではない。

**「統治者会議は国王を選出するだけである。」** 第38(2)条は、特定の法律への同意を
含む他の職能も与えている。また第38(4)条は、統治者の特権、地位、栄誉又は威厳に直接
関わる法律は、統治者会議の同意なしには可決され得ないと定めている。
