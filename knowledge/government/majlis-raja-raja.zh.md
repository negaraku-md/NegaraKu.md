联邦宪法中有一份很少被提及的简短清单：国会不能单独通过的事项清单。对这些事项而言，仅在下议院（Dewan Rakyat）与上议院（Dewan Negara）取得三分之二多数票并不足够。还须获得另一个机构的同意——那个机构就是统治者会议。

统治者会议由联邦宪法第38(1)条设立，并依第五附表组成。它不是国会的第三个议院，也不制定法律。它的角色以清单方式界定：某些事项须获其同意，另一些事项须与其谘询，还有一小部分事项则完全属于其自身的权限范围。

本文按宪法文本所载，说明这份清单的内容。

## 概览

| | |
| --- | --- |
| 官方名称 | 统治者会议（Majlis Raja-Raja / Conference of Rulers） |
| 宪制依据 | 第38条；依第五附表组成 |
| 成员 | 统治者，以及没有统治者的州属的州元首（Yang di-Pertua Negeri）（第五附表第1条） |
| 会议秘书 | 统治者御玺守护官（Penyimpan Mohor Besar Raja-Raja）（第五附表第4条） |
| 法定人数 | 多数成员（第五附表第5条） |
| 首次会议 | 1948年2月18日 |
| 秘书处 | 统治者御玺守护官办公室，吉隆坡Jalan Bukit Petaling |

## 谁是其成员

第五附表第1条指出，统治者会议由诸统治者陛下（Duli-Duli Yang Maha Mulia Raja-Raja）及没有统治者的州属的州元首（Yang di-Pertua Negeri）组成。

统治者御玺守护官办公室的官方网站指出，现时的成员为九位马来统治者，连同马六甲、槟城、沙巴与砂拉越的州元首——共13名成员。「没有统治者的州属」这一措辞，是在沙巴与砂拉越加入联邦后，取代原本「马六甲与槟城」的说法；参见[1963年马来西亚的成立](/zh/malaysia/formation-of-malaysia-1963)。

成员资格并非在一切事务上均一致。第五附表第7条将州元首排除于下列事项相关程序的成员之外：

- 最高元首的推选或罢免，以及副最高元首的推选；
- 纯粹涉及统治者的特权、地位、尊荣与位阶的事项；以及
- 宗教行为、习俗或仪式。

就该等事务而言，会议以九名成员的形式召开。

第五附表第2条则容许在该州宪法有此规定的情况下，由他人代替某统治者或州元首的席位。

## 第38(2)条列出的五项职能

第38(2)条将统治者会议的职能列举如下：

1. **推选最高元首与副最高元首**，依第三附表的规定。
2. **同意或不同意**将任何宗教行为、习俗或仪式扩展至整个联邦。
3. **对任何法律予以同意或不同意**，并就宪法规定须经会议同意或经与会议谘询后方可作出的任何委任，作出决定或提供意见。
4. **依第182(1)条委任特别法庭成员**。
5. **给予赦免、缓刑及暂缓行刑**，或减免、暂停或减轻刑罚，依第42(12)条。

第38(2)条并补充，会议「得审议有关国家政策的问题（例如移民政策的变更）以及其认为适当的任何其他事项」。

该项宗教职能与第3(2)条相连：就会议已同意扩展至整个联邦的任何宗教行为、习俗或仪式，其余每一位统治者均须授权最高元首，以其作为伊斯兰教首长的身分代表该统治者。

## 最高元首的推选如何进行

第32(3)条规定，最高元首由统治者会议推选，任期五年。最高元首可致函统治者会议辞职，或由统治者会议罢免，并在他不再是统治者时卸任。

其机制载于第三附表：

| 阶段 | 条文 | 情形 |
| --- | --- | --- |
| 资格 | 第一部分第1条 | 统治者具备获推选的资格，除非他尚未成年、已通知统治者御玺守护官他不愿被推选，或统治者会议以不记名投票方式裁定他不适合 |
| 表决门槛 | 第一部分第1(2)条 | 不适合的决议案须获至少五名成员投票支持方可通过 |
| 提呈 | 第一部分第2条 | 职位提呈给合资格且其州属在推选名单上排名最前的统治者；如未获接受，则提呈给下一个州属的统治者，依此类推 |
| 宣布 | 第一部分第3条 | 提呈获接受后，统治者会议宣布该统治者当选，统治者御玺守护官以书面方式将该决定通知国会两院 |
| 罢免 | 第三部分第8条 | 罢免最高元首的决议案须获至少五名成员投票支持方可通过 |

推选名单本身会轮转。第三附表第4条规定，每次推选之后，排在已获推选统治者所属州属之前的州属移至名单末端，而该已获推选统治者所属的州属则从名单中除去；当名单上不再有任何州属时，名单即重新编排。

副最高元首同样由统治者会议推选，任期五年（第33(2)条），而在最高元首职位出缺期间，统治者会议不得推选副最高元首（第三附表第6条）。

第37(1)条另加一项鲜少被提及的程序：最高元首须在统治者会议前宣誓就职，该宣誓由会议为此目的委任的两人见证。

## 哪些事项须经统治者会议同意

「同意」是宪法中门槛最高的要求：未获同意，相关法律便不能由[国会](/zh/government/parliament)通过。

| 条文 | 未经统治者会议同意不能发生的事项 |
| --- | --- |
| 第38(4)条 | 直接触及统治者的特权、地位、尊荣或位阶的法律 |
| 第2(b)条 | 更改某州属边界的法律（也须获得该州属的同意） |
| 第159(5)条 | 对第10(4)条、第三部分、第38条、第63(4)条、第70条、第71(1)条、第72(4)条、第152条、第153条，或对第159(5)款本身的修改 |
| 第33(5)条 | 规定某统治者在特定情况下执行最高元首职务的法律 |
| 第34(5)条 | 最高元首离开联邦超过十五天，国事访问除外 |

正是第159(5)条使统治者会议成为[联邦宪法](/zh/law/federal-constitution)就上述所列条文之修改程序的一部分，此外还须获国会两院三分之二多数通过。

## 哪些事项仅需谘询

谘询是与同意不同的门槛。宪法在下列事项中规定须谘询统治者会议——而非规定须获其同意：

- **第38(5)条**——在作出任何触及第153条下行政行动的政策变更之前。
- **第122B(1)条**——最高元首在首相的意见下，于谘询统治者会议后，委任联邦法院首席大法官、上诉庭庭长、各高庭首席法官及其他法官。
- **第114(1)条**——最高元首于谘询统治者会议后委任选举委员会。
- **第139(4)条**——委任公共服务委员会成员。
- **第141A(2)条**——委任教育服务委员会成员。

另有两项委任则由统治者会议本身作出：委任现任或曾任联邦法院或高庭法官的两人为特别法庭成员（第182(1)条），以及委任一名代表诸统治者陛下的武装部队理事会成员（第137(3)(b)条）。

## 成员何时依自身酌情行事

马来西亚大多数宪制职能须依建议行事。第38(3)条规定，统治者会议审议国家政策事项时，最高元首由首相陪同，而其余统治者与州元首则各自由其州务大臣或首席部长陪同——而该项审议须依内阁及州行政议会的意见进行。

第38(6)条将六类事项排除于上述规则之外。会议成员可在下列事项的程序中依自身酌情行事：

- 最高元首的推选或罢免，或副最高元首的推选；
- 就任何委任提供意见；
- 同意或不同意更改州属边界，或触及统治者特权、地位、尊荣或位阶的法律；
- 同意或不同意将宗教行为、习俗或仪式扩展至整个联邦；
- 依第182(1)条委任特别法庭成员；以及
- 依第42(12)条行使赦免权。

## 决定如何作出与核证

统治者会议的程序载于第五附表：

- **法定人数**为多数成员，会议可自行决定其程序（第5条）。
- **会议**由统治者御玺守护官在最高元首或不少于三名成员要求时召集；并在无须任何要求的情况下，须于最高元首任期届满前不迟于四星期召集，以及在最高元首职位或副最高元首职位出现空缺时召集（第6条）。官方网站指出，会议通常每年举行三次。
- **投票**——若会议未能一致议决，决定依出席投票成员的多数作出，但须受第三附表的规定约束（第8条）。
- **核证**——会议的任何同意、委任或意见均以统治者御玺核证。就拟议中的委任而言，若多数成员以书面方式向统治者御玺守护官表明支持，会议的意见可无须召集会议即予核证（第9条）。

第40(2)(c)条则将「要求召开纯粹涉及统治者特权、地位、尊荣与位阶的会议」，以及该次会议上的任何行动，列入最高元首可依自身酌情行使的职能清单之中。

## 常见误解

**「统治者会议通过法律。」** 不对。它并不制定或通过法律。对于特定类别的事项，其同意只是国会所通过法律得以生效前的一项附加条件——是一项条件，而非一道立法程序。

**「同意与谘询意思相同。」** 不对。第38(4)条与第159(5)条使用「同意」的用语；第38(5)条、第114(1)条与第122B(1)条则使用「谘询」的用语。两者带来的宪制后果并不相同。

**「所有成员在一切事项上均可投票。」** 不对。第五附表第7条将州元首排除于特定类别的程序之外，而第42(13)条则将州元首——连同有关的统治者——排除于第42(12)(b)与(c)条所指的会议成员之外。

**「决议须一致通过。」** 不对。第五附表第8条规定，若会议未能一致议决，决定依出席投票成员的多数作出。

**「最高元首以成员身分主持会议。」** 统治者御玺守护官办公室的官方网站指出，最高元首并非统治者会议的成员，而是以国家元首的身分出席会议，并由首相作为其顾问陪同出席。

## 下一步

若要理解统治者会议在更广泛的宪制架构中所处的位置，可从[联邦宪法](/zh/law/federal-constitution)开始，再看[马来西亚国会](/zh/government/parliament)，了解联邦法律在第38(4)条与第159(5)条的同意要求适用之前是如何通过的。

其历史背景则源自两个事件：[1957年独立](/zh/malaysia/independence-1957)（宪法自此开始生效），以及[1963年马来西亚的成立](/zh/malaysia/formation-of-malaysia-1963)（成员架构自此扩展至没有统治者的州属，包括[砂拉越](/zh/states/sarawak)）。

第38条、第三附表与第五附表的完整文本，可在总检察署门户网站的联邦宪法官方重印本中查阅；有关统治者会议角色的官方说明，则由统治者御玺守护官办公室发布。
