faq:
  - q: "MIDAは製造ライセンスを承認するのか？"
    a: "承認しない。MIDA自身のガイダンスは明確である。製造ライセンスの申請はMIDAに提出されるが、そこでMIDAは「マレーシアにおける産業開発の推進と調整を担うMITI傘下の機関」と説明されている——だがライセンス自体は投資貿易産業省の承認を必要とする。MIDAは申請を受理し処理するが、それを発行するのはMITIである。"
  - q: "MIDAは政府の部局なのか、それとも独立した機関なのか？"
    a: "MIDAは法定機関であり、一般公務員制度のもとに直接編制された部局ではなく、独自の法令——1965年マレーシア産業開発庁（法人設立）法、Act 397——に基づいて設立されている。MIDAはMITIの政策権限のもとで運営されており、MITIもMIDAを傘下機関の一つとして挙げている。"
  - q: "MIDAとMITIの違いは何か？"
    a: "MITIは省である。産業・貿易政策を定め、関係法令を所管し、製造ライセンスのような法律文書について最終的な承認権を握っている。MIDAは実施機関である。投資家にマレーシアを売り込み、申請を受理・評価し、業種別ガイドラインを公表し、それらの申請が流れていくワンストップ・ファシリテーションセンターを運営する。大臣又は委員会の署名を必要とする決定については、その署名はMIDAのものではない。"
  - q: "MIDAが評価する税務優遇申請は、誰が承認するのか？"
    a: "優遇措置の種類による。だが新優遇枠組み（New Incentive Framework）のような主要な制度については、MIDAが評価表に基づき申請を評価し、国家投資委員会（NCI）がそれを承認し、その後MIDAが優遇レターを発行する。MIDAの役割は評価と行政運営であって、最終的な承認決定ではない。"
  - q: "Invest Malaysia Facilitation Centreとは何か？"
    a: "これは、MIDAがクアラルンプール・セントラルの本部に設置し運営するワンストップセンターであり、2023年12月1日に稼働を開始した。内国歳入庁、移民局、関税局、マレーシア通信・マルチメディア委員会（MCMC）、マレーシア半島労働局、Tenaga Nasional Berhad及びTelekom Malaysia Berhadの職員を実際に一か所に収容しており、投資家が各機関を個別に訪れることなく、機関横断的な承認を進められるようにしている。その後、ジョホール向けの拠点であるIMFC-Jが開設され、ジョホール・シンガポール経済特区の投資家に対応している。"

外国投資家は誰もが、いずれMIDAと関わることになる。だが、MIDAが「イエス」と言う機関ではないことを、最初に知らされる者はほとんどいない。

## At a glance

| | |
| --- | --- |
| 全名 | マレーシア投資開発庁（Malaysian Investment Development Authority、MIDA） |
| 種別 | 法定機関、独自の法令に基づき設立 |
| 根拠法令 | 1965年マレーシア産業開発庁（法人設立）法（Malaysian Industrial Development Authority (Incorporation) Act 1965、Act 397） |
| 所管省庁 | 投資貿易産業省（MITI）——MITIの傘下機関の一つとして掲載 |
| 対象分野 | 製造業及びサービス業 |
| 本部 | MIDA Sentral, No. 5, Jalan Stesen Sentral 5, KL Sentral, 50470 Kuala Lumpur |
| ワンストップセンター | インベスト・マレーシア・ファシリテーション・センター（Invest Malaysia Facilitation Centre、IMFC）、2023年12月1日よりMIDA本部で運営 |
| ウェブサイト | `mida.gov.my` |

Act 397は、同局がまだ元の名称——マレーシア*産業*開発庁（Malaysian *Industrial* Development
Authority）——を名乗っていた**1966年6月23日**に施行された。MIDA自身の資料は、業務開始の年を
1967年としている。同局は今日、マレーシア*投資*開発庁（Malaysian *Investment* Development
Authority）として知られている——この対外名称が変更された正確な年を確定する公式ページはなく、
したがって本稿ではその年を日付として記載しない。

## What MIDA actually does

MIDAは自らの使命を、**「政府の推進活動を調和させ、資源を最適化し、効果的かつ体系的な投資推進
機関（IPA）ガバナンスを確立すること」**と説明しており、マレーシアを*「卓越した、選ばれる投資
先」*とするビジョンを掲げている。実務上、この使命は四つの業務に分かれる。

- **推進。** 国内及び海外ネットワークを通じて、将来の投資家にマレーシアを売り込み、業種別の
  投資ガイドブックを発行すること。
- **申請の受理及び評価。** 製造ライセンス、ICA 10免除の確認、及びマレーシアの各種税務優遇制度
  に基づく申請は、いずれもまずMIDAを経由する。
- **円滑化。** 投資家が通過しなければならない他の機関——税務、関税、移民、通信、公共事業——を
  調整し、それぞれ別個の五つの手続としてではなく、一つの手続として審査が進むようにすること。
- **MITIへの助言。** 政策を策定する省庁に対し、投資家の経験をフィードバックすること。

この四つのいずれも「最終承認」ではない。この区別を正確に示すことこそが、本稿の残りの部分の
目的である。

## Where MIDA's authority stops

MIDA自身のライセンスに関するページは、これを明確に述べている。製造ライセンスの申請はMIDAに
提出されるが、そこでMIDAは**「マレーシアにおける産業開発の推進と調整を担うMITI傘下の機関」**
と説明されている——だがライセンス自体は**投資貿易産業省の承認**を必要とする。同じ分担は優遇
申請にも見られる——MIDAの事業円滑化に関する資料は、主要プロジェクトが**国家投資委員会
（National Committee on Investment、NCI）**によって承認されると説明しており、MIDAはその
決定をめぐる受理、評価及び実施状況の追跡を担っている。

| 手順 | 担当 |
| --- | --- |
| 投資家にマレーシアを売り込む | MIDA |
| 製造ライセンス申請を受理する | MIDA |
| 製造ライセンスを承認する | MITI |
| 評価表に基づき優遇申請を評価する | MIDA |
| 主要な優遇申請を承認する | 国家投資委員会 |
| 結果としての優遇レターを発行する | MIDA |
| その後、機関横断的な承認を調整する | MIDA（IMFC経由） |

つまり、同じ案件を二つの機関が扱うが、承認書に署名するのはそのうちの一方だけである。

## The Invest Malaysia Facilitation Centre

「窓口が多すぎる」という問題に対するMIDAの最も具体的な回答が、**インベスト・マレーシア・
ファシリテーション・センター（Invest Malaysia Facilitation Centre、IMFC）**であり、MIDA
Sentralに実際に設置され、**2023年12月1日**より運営されている。内国歳入庁、移民局、関税局、
マレーシア通信・マルチメディア委員会、マレーシア半島労働局、Tenaga Nasional Berhad及び
Telekom Malaysia Berhadの職員を一つの物理的な場所に集めており、承認済みの投資家がその後の
各種承認を得る際、機関ごとに別々に足を運ぶ必要がない。その後、地域拠点である**IMFC-J**が
開設され、ジョホール・シンガポール経済特区に進出する投資家に対応している。

## A widening remit

マレーシアの投資推進を巡る構図には、歴史的に複数の窓口が存在してきた——全国の製造業及び
サービス業についてはMIDAだが、大クアラルンプールに特化したInvestKLのような別個の機関も
存在した。この状況は**2026年3月15日**に変化した。この日、MIDAはInvestKLの大クアラルンプール
向け投資推進及び円滑化機能を吸収し、InvestKLは独立機関としての運営を終えた。MIDAはこの動き
を、同じ投資家を奪い合う機関同士の重複を減らすものだと説明している。

## Common mistakes

**MIDAが自ら処理する事項を許可できると思い込むこと。** MIDAに提出された製造ライセンス申請
には、なおMITIの承認が必要である。MIDAが好意的に評価した優遇申請でも、国家投資委員会の段階
で却下されることがある。MIDAとの前向きなやり取りは、強いシグナルとして受け止めるべきであり、
ライセンスを手にしたものと考えてはならない。

**MIDAを業種別の監督機関と混同すること。** MIDAは製造業及びサービス業を幅広く対象とするが、
ICTはMDECのマレーシア・デジタル認定（Malaysia Digital status）の所管であり、免許を受けた
金融機関はBank Negara（マレーシア国立銀行）の所管であり、その他いくつかの業種はそれぞれ独自
の監督機関の所管である。どの機関と関わることになるかは、あなたが投資しているという事実だけ
でなく、何を設立しようとしているかによって決まる。

## What's next

MIDAがあなたに最終的な答えを出せるかどうかを見極めたいなら、あなたの疑問が上表のどの列に
当てはまるかを確認すること。もしそれが本当にMIDAの判断——評価、円滑化、推進——であるならば、
[投資機関名録](/ja/business/investment-agency-directory)から始めて、あなたの具体的な申請を
位置づけること。もしMITI又はNCIの署名が必要であるならば、その追加の手順にかかる時間を見込ん
だうえで、承認日を計画すること。
