# 上议院（Dewan Negara）：上议员如何获得委任，以及本院为何延搁而非否决

上议院（Dewan Negara）可以否决一项已经下议院（Dewan Rakyat）通过的法案。它做不到的，是永远否决那项法案。

联邦宪法赋予这个上院的，是一个秒表，而非一把门锁。第68条规定，一旦某段特定期限届满，下议院即可将同一项法案直接呈交最高元首（Yang di-Pertuan Agong）——上议院则被完全绕过。

## 概览

| | |
| --- | --- |
| 名称 | 上议院（Dewan Negara） |
| 议员称谓 | 上议员（Senator） |
| 宪法依据 | 联邦宪法第44至48条、第54条、第56条、第66至68条及第七附表 |
| 议员总数 | 70 |
| 由州立法议会（Dewan Undangan Negeri）选出 | 26（13个州各两名） |
| 由最高元首委任 | 44（40名依第45(1)(b)条；吉隆坡两名、纳闽一名、布城一名） |
| 最低年龄 | 30岁（第47(a)条） |
| 任期 | 三年；最多连任两届 |
| 主持官员 | 上议院主席与副主席，从议员中选出（第56(1)条） |

## 进入上议院的两条途径

第45(1)条将议员组成分为两个类别，两者的权力来源截然不同。

**州属上议员。** 每个州由该州的州立法议会各选出两名，依第七附表所订程序进行。以13个州计算，合共26名——不论是 Perlis 还是 Selangor，每个州获得同等的比重。

**委任上议员。** 40名由最高元首依第45(1)(b)条委任，另加代表联邦直辖区（Wilayah Persekutuan）的4名：吉隆坡两名、纳闽一名、布城一名。

第45(2)条订明最高元首委任人选的资格：最高元首认为曾提供杰出公共服务，或在专业、商业、工业、农业、文化活动或社会服务方面有卓越成就的人士，或是代表少数种族，或有能力代表原住民（Orang Asli）利益的人士。

留意其中的比例。委任上议员的人数（44）超过州属上议员的人数（26）。1957年的原始设计正好相反——李特宪制委员会（Reid Commission）的报告建议州属上议员22名，对委任上议员11名。第45(1)(b)条原本只规定16名委任议员；该数字在1963年提高至22名，1964年再增至32名，最终于1978年定为40名。

## 州立法议会实际上如何选出其上议员

这项选举程序甚少被讨论，但第七附表逐步订明了整个程序。

1. 一旦出现空缺，最高元首会向有关州属的统治者（Raja）或州元首（Yang di-Pertua Negeri）发出通知，后者再要求州立法议会进行选举。
2. 候选人的姓名由州立法议会议员提名及附议。提名或附议的议员须提交一份由候选人本人签署的书面声明，表明其若获选愿意就任。
3. 主持官员按字母顺序宣布候选人姓名，并交付表决。
4. 每名出席的议员均有权按须填补的空缺数目投票。投票支持每名候选人的议员姓名均会被记录——此项投票并非不记名。
5. 获得最多票数的候选人获宣布当选。如果出现平票，且候选人数目超过空缺数目，则以抽签方式决定结果。
6. 主持官员透过其本人签署的函件，将当选者的姓名证明予上议院秘书。

如果就某位上议员是否已获妥善选出而产生疑问，第七附表将该决定权交由上议院本身，而其决定为最终决定。

## 不受选举周期约束的三年任期

第45(3)条将任期定为三年——并加上一项重要条款：该任期**不受国会解散影响**。

这是两院之间最大的结构性差异。当下议院为大选而解散时，其所有议席均告悬空。上议院则在整段期间以相同的议员组成继续存在。

第45(3A)条将任何人限制在最多两届之内，「不论是否连续」——该限制于1981年加入。

资格要求同样有别。第47(a)条将上议院的最低年龄定为30岁，而下议院依第47(b)条，自2019年9月11日生效的修正案起为18岁。第48条下的不合资格情形——包括尚未获解除的破产、担任有报酬的职位，或因刑事罪行被判处不少于一年监禁或不少于RM2,000罚款——则同时适用于两院。

委任上议员当中的空缺，须自上议院主席确定该空缺存在之日起60天内填补（第54(1)条）。未能在该期限内完成，并不会使其后作出的委任无效。第54(3)条将须由州属选举填补的议席，排除于该60天限期之外。

## 延搁的权力，而非否决的权力

上议院真正的设计，正体现于此。第66(1)条规定，国会的立法权力透过由两院通过的法案行使——「或者，在第68条所指的情形下，由下议院单独行使」。这句括注文字，就是整个故事的关键。

| 法案类型 | 上议院的地位 |
| --- | --- |
| 金钱法案 | 不得在上议院提出（第67(1)条）。若在会期结束前至少一个月送交上议院，且在一个月内未获不经修正通过，即呈交最高元首以取得御准，除非下议院另有指示（第68(1)条） |
| 普通法案 | 可予否决或修正。但如果下议院在下一个会期再次通过该法案，且不早于首次通过后一年，而上议院再次未予通过，该法案即呈交最高元首（第68(2)条） |
| 宪法修正法案 | 第68条不适用（第68(5)条）。第159(3)条要求在二读及三读时，获得每一院议员总数不少于三分之二的支持 |

就该第二条途径而言，重新提出的法案唯一容许作出的改动，是下议院议长证明因时间经过而属必要的改动，或为反映上议院在先前会期所作修正的改动（第68(3)条）。

下议院议长证明第68条已获遵守的证明书，**就一切目的而言均属最终决定，不得在任何法院提出质疑**（第68(4)条）。

《马来西亚国会期刊》本身将其效果描述为让下议院得以绕过上议院的严重反对，从而排除两院之间陷入僵局的可能性。同一期刊记录了该否决权近期一次的使用实例，即上议院投票否决一项旨在废除 Akta Berita Tidak Benar 2018 的法案。

1957年草拟宪法的李特宪制委员会，确实曾预期这项延搁立法的权力仅在「特殊」情况下使用。

## 常见错误

**「上议院可以否决任何法律。」** 就普通法案而言并非如此。第68(2)条给予它至少一年的延搁，而非最终否决。真正的否决权仅存在于宪法修正法案，因为第68(5)条将其排除于绕过机制之外，而第159(3)条要求两院议员总数的三分之二支持。

**「上议员代表自己的州属。」** 70名当中只有26名如此。多数议员是在联邦层级委任的。

**「上议员由选民选出。」** 不是。州属上议员是由州立法议会议员选出的，而非由公众选出。第45(4)条确实容许国会立法，将每个州的议员人数提高至三名，或规定由该州选民直接选举产生，或减少乃至废除委任议员——但这项权力至今尚未被行使。

**「上议院随下议院一并解散。」** 不是。第45(3)条规定，该三年任期不受国会解散所触动。

**「上议员不能出任部长。」** 可以。第43(2)(b)条容许最高元首从国会任何一院的议员当中委任部长。唯有首相必须是下议院议员。
