マレーシアの国境を越えるすべての人——パスポートを更新する国民、到着する旅行者、働く駐在員——は、同じ一つの部門を通る。しかし、そこが発給する文書は互いに混同されがちであり、その混同こそが移民に関する問題の大半の原因である。

## 概要

| | |
| --- | --- |
| 正式名称 | Jabatan Imigresen Malaysia (Immigration Department of Malaysia) |
| 略称 | JIM |
| 種別 | 連邦部門 |
| 所管 | 内務省（Kementerian Dalam Negeri、KDN） |
| ウェブサイト | `imi.gov.my` |

## 4つの中核機能

この部門は、その所掌を4つに分けて示している：

1. **パスポートおよび渡航文書の発給** — マレーシア国民および永住者に対して。
2. **外国人へのビザ・パス・許可証の発給** — マレーシアに入国する外国人に対して。
3. **人の移動の管理** — 合法な出入国地点において。
4. **移民関連法令の執行** — 1959/63年移民法、1963年移民規則、1966年パスポート法、および2007年反人身売買・反移民密輸法（2010年改正）。

## ビザ・パス・許可証——3つの異なる文書

これはもっとも頻繁に生じる誤解であり、単なる用語の問題ではない。

| 文書 | 役割 |
| --- | --- |
| **ビザ（Visa）** | マレーシアに*到着*するための許可——ビザを必要とする国籍の者は渡航前に取得する。 |
| **パス（Pas）** | *どれだけの期間*、*どのような目的*で滞在できるかを定めるもの——訪問、就学、就労など。 |
| **入境許可証（Permit Masuk / Entry Permit）** | 外国人が*無期限で*合法的にマレーシアに入国し定住するための便宜——永住権（MyPR）取得への道。 |

3つの基本的なビザ種別が発給される：**シングルエントリービザ**（通常は社会訪問向けで、発給日から3か月間有効なのが一般的）、**マルチプルエントリービザ**（通常はビジネスまたは政府間の用務向けで、3〜12か月間有効なのが一般的）、そして**トランジットビザ**。

**リファレンス付きビザ（Visa Dengan Rujukan、VDR）**は別系統の経路である：在外マレーシア公館は、移民局本部が申請を承認した*後にのみ*これを発給する。国民の配偶者や特定国籍の国民などの区分は、この経路を通る。

一方、入境許可証（Entry Permit）は、マレーシア政府が外国人に与える最高の特権であると同部門は位置づけている——定められた条件に違反した場合は取り消され得る。

## 主要なパスの種類

| パス | 対象者 |
| --- | --- |
| エンプロイメントパス（Employment Pass） | マレーシアの企業に雇用される駐在員 |
| 一時就労パス（Visit Pass, Temporary Employment、PLKS） | 特定業種の外国人労働者 |
| 短期社会訪問パス（Short-Term Social Visit Pass） | 観光および短期訪問 |
| 長期社会訪問パス（Long Term Social Visit Pass、LTSVP） | 最短6か月の一時滞在 |
| 専門訪問パス（Professional Visit Pass、PVP） | 短期の専門的業務 |
| 専門訪問パス（PVP）——エキスパート | 専門分野の区分 |
| 学生パス（Student Pass） | 国際学生 |
| レジデントパス（Resident Pass） | 特別承認による居住区分 |

長期社会訪問パス（LTSVP）の対象には、国民の外国籍配偶者（最長5年まで付与され、就労も認められる）、マレーシアに身元保証家族を持つ60歳以上の高齢者、国際学生の家族、マレーシアの病院で治療を受ける患者とその付添人1名、そして駐在員の扶養家族が含まれる。

## 主なオンライン窓口

- **ESD（Expatriate Services Division、移民局外国人サービス部門）** — `esd.imi.gov.my` — 駐在員を雇用しようとする企業にとっての最初の窓口。すべての企業は、パスの申請前にまずESDへ登録しなければならない。
- **MDAC（Malaysia Digital Arrival Card）** — `imigresen-online.imi.gov.my` — 外国人訪問者が到着前にオンラインで登録するデジタル入国カード。対象要件と免除については、当該ポータル自体に記載されている。

## 手数料についての注記

本ページは意図的に**手数料を掲載していない**。ビザ、パス、パスポートの料率は随時改定されており、第三者サイトから転載された数字はしばしば古くなっている。手続きを行う日に、`imi.gov.my` の公式手数料表、または移民局のカウンターで確認すること。

## 次にすべきこと

あなたが雇用主であれば、まず[就労パスの一覧](/employment/work-passes-malaysia)で正しいパスを特定し、そのうえでESDポータルに企業を登録すること。あなたが個人であれば、まず自分の用件が*到着*（ビザ）、*在留*（パス）、*定住*（入境許可証）のいずれに関するものかを見極め、そのうえで該当区分の必要書類一覧を`imi.gov.my`で確認すること。申請の大半は、添付書類の不備によって滞っているためである。
