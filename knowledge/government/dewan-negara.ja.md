# 上院（Dewan Negara）：上院議員はどのように任命されるか、そして本院はなぜ否決ではなく遅延にとどまるのか

上院（Dewan Negara）は、下院（Dewan Rakyat）が可決した法案を否決することができる。上院にできないのは、その法案を永久に否決することである。

連邦憲法がこの上院に与えているのは、ストップウォッチであって、ドアの鍵ではない。第68条は、一定の期間が経過した後、下院が同一の法案を国王（Yang di-Pertuan Agong）に直接送付できると定めている——上院は完全に迂回される。

## 概要

| | |
| --- | --- |
| 名称 | 上院（Dewan Negara） |
| 議員の呼称 | 上院議員（Senator） |
| 憲法上の根拠 | 連邦憲法第44～48条、第54条、第56条、第66～68条及び第七附表 |
| 議員総数 | 70 |
| 州議会（Dewan Undangan Negeri）が選出 | 26（13州各2名） |
| 国王が任命 | 44（40名は第45(1)(b)条に基づく；クアラルンプール2名、ラブアン1名、プトラジャヤ1名） |
| 最低年齢 | 30歳（第47(a)条） |
| 任期 | 3年；最長2期 |
| 議長 | 上院議長及び副議長、議員の中から選出（第56(1)条） |

## 上院への二つの道

第45(1)条は、議員の構成をその権限の源泉がまったく異なる二つのカテゴリーに分けている。

**州選出の上院議員。** 各州から2名ずつ、それぞれの州議会が第七附表の手続きに従って選出する。13州であるため、合計26名となる——パーリスであれセランゴールであれ、各州は同等の比重を得る。

**任命上院議員。** 40名は第45(1)(b)条に基づき国王が任命し、さらに連邦直轄区を代表する4名が加わる：クアラルンプール2名、ラブアン1名、プトラジャヤ1名。

第45(2)条は、国王が任命する者の要件を定めている：国王の見解において、卓越した公共サービスを提供した者、または専門職、商業、工業、農業、文化活動もしくは社会奉仕において卓越した実績を上げた者であるか、あるいは少数民族を代表する者、またはオラン・アスリ（Orang Asli）の利益を代表する能力を有する者でなければならない。

その比率に注目してほしい。任命上院議員の数（44）は州選出上院議員の数（26）を上回っている。1957年当初の設計はその逆であった——李特委員会（Reid Commission）の報告書は、州選出上院議員22名に対し任命上院議員11名を提案していた。第45(1)(b)条は当初、任命議員をわずか16名としか定めていなかった。その数は1963年に22名、次いで1964年に32名へと引き上げられ、最終的に1978年に40名となった。

## 州議会は実際どのように上院議員を選出するか

この選出手続きが議論されることはほとんどないが、第七附表に段階を追って規定されている。

1. 欠員が生じると、国王は当該州の統治者（Raja）または州元首（Yang di-Pertua Negeri）に通知を行い、統治者または州元首はさらに州議会に選挙の実施を求める。
2. 候補者の氏名は、州議会の議員により提案・附議される。提案または附議する議員は、候補者本人が署名した、選出された場合に就任することへの同意を示す書面を提出しなければならない。
3. 議長は候補者の氏名をアルファベット順に発表し、投票に付する。
4. 出席する議員は、補充すべき欠員の数に応じて投票する権利を有する。各候補者に投票した議員の氏名は記録される——この投票は秘密投票ではない。
5. 最多票を得た候補者が当選者として宣言される。同数となり、かつ候補者数が欠員数を上回る場合は、抽選によって決定される。
6. 議長は、自ら署名した書面により、当選者の氏名を上院事務総長に証明する。

ある上院議員が適正に選出されたかどうかについて疑義が生じた場合、第七附表はその決定を上院自身に委ねており、その決定は最終的なものである。

## 選挙サイクルに縛られない3年の任期

第45(3)条は任期を3年と定めており——さらに一つの重要な条項を加えている：その任期は**国会の解散による影響を受けない**。

これが両院間の最大の構造的相違点である。下院が総選挙のために解散されると、そのすべての議席が空席となる。上院はその期間を通じて、同じ議員構成のまま存続する。

第45(3A)条は、「連続するか否かを問わず」何人も2期のみに制限しており——この制限は1981年に追加された。

資格要件も異なる。第47(a)条は上院の最低年齢を30歳と定めており、これに対し下院は、2019年9月11日発効の修正以降、第47(b)条に基づき18歳である。第48条に基づく欠格事由——未解除の破産、有給の職の保有、または1年以上の禁錮もしくはRM2,000以上の罰金を伴う刑事有罪判決を含む——は両院に適用される。

任命上院議員の欠員は、上院議長が当該欠員の存在を確認した日から60日以内に補充されなければならない（第54(1)条）。この期間内にそれがなされなかったとしても、その後になされた任命が無効となるわけではない。第54(3)条は、州による選挙で補充すべき議席をこの60日の期限から除外している。

## 遅延の権限であって、否決の権限ではない

ここに上院の真の骨格が映し出されている。第66(1)条は、国会の立法権は両院が可決した法案を通じて行使される——「あるいは、第68条に定める場合には、下院のみによって」と規定している。この挿入句こそがすべてを物語っている。

| 法案の種類 | 上院の立場 |
| --- | --- |
| 金銭法案 | 上院に提出することはできない（第67(1)条）。会期終了の少なくとも1か月前に送付され、1か月以内に修正なしで可決されなかった場合、下院が別段の指示をしない限り、御裁可のため国王に提出される（第68(1)条） |
| 普通法案 | 否決または修正することができる。ただし、下院が次の会期において、最初に可決されてから1年を経過する前でなければ、これを再度可決し、上院が再び可決しなかった場合、当該法案は国王に提出される（第68(2)条） |
| 憲法改正法案 | 第68条は適用されない（第68(5)条）。第159(3)条は、二読及び三読において、各院の議員総数の3分の2以上の支持を要求している |

この第二の経路について、再提出される法案に認められる唯一の変更は、下院議長が、経過した時間のために必要であると証明した変更、または前の会期において上院が行った修正を反映するための変更に限られる（第68(3)条）。

第68条が遵守された旨の下院議長の証明書は、**あらゆる目的について最終的なものであり、いかなる裁判所においても争うことができない**（第68(4)条）。

『マレーシア国会ジャーナル』自体は、その効果について、下院が上院の重大な異議を乗り越えることを可能にし、それによって両院間の行き詰まりの可能性を排除するものだと述べている。同ジャーナルは、当該否決権が近年行使された一例として、上院が2018年虚偽ニュース法（Akta Berita Tidak Benar 2018）を廃止する法案を否決した投票を記録している。

1957年に憲法を起草した李特委員会（Reid Commission）は、この立法遅延の権限が「例外的な」状況においてのみ行使されることを想定していた。

## よくある誤解

**「上院はどのような法律でも否決できる。」** 普通法案についてはそうではない。第68(2)条が与えているのは少なくとも1年の遅延であり、最終的な否決ではない。真の拒否権が存在するのは憲法改正法案の場合のみである。第68(5)条がこれを迂回機構から除外しており、第159(3)条が両院の議員総数の3分の2を要求しているためである。

**「上院議員は自身の州を代表している。」** 70名のうち26名のみがそうである。議員の過半数は連邦レベルで任命される。

**「上院議員は有権者によって選出される。」** そうではない。州選出の上院議員は、一般の有権者ではなく州議会の議員によって選出される。第45(4)条は、国会が立法により各州の議員数を3名に増やすこと、州の有権者による直接選挙を規定すること、または任命議員を削減もしくは廃止することを認めているが——この権限はまだ行使されていない。

**「上院は下院とともに解散される。」** そうではない。第45(3)条は、その3年の任期が国会の解散によって左右されないと定めている。

**「上院議員は大臣になれない。」** なれる。第43(2)(b)条は、国王が国会いずれの院の議員からでも大臣を任命することを認めている。下院議員でなければならないのは首相のみである。
