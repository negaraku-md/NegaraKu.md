大多数公职是由国会可以修改的成文法所界定。联邦总检察长一职并非如此。它写入联邦宪法本身，
见于单一条文——第145条——该条文订明谁出任此职、此职必须做什么，以及宪法赋予持有者本身自行
酌情行使的那一项权力。

细读该条文，是理解此职位最可靠的方法，因为在马来西亚，几乎所有关于总检察长的说法，都可追溯
至该条文的六款规定。

## 一览

| | |
| --- | --- |
| 职称 | 联邦总检察长（Peguam Negara） |
| 宪制依据 | 联邦宪法第145条 |
| 委任者 | 最高元首（Yang di-Pertuan Agong），经首相建议（第145(1)条） |
| 资格 | 具备出任联邦法院法官资格的人士（第145(1)条） |
| 核心职责 | 就法律事宜向最高元首、内阁及各部长提供意见（第145(2)条） |
| 标志性权力 | 可自行酌情就罪行提起、进行或终止诉讼程序（第145(3)条） |
| 又称 | 行使第(3)款权力时，称为公共检控官 |
| 出庭权 | 在联邦任何法院或法庭出庭，并享有优先权（第145(4)条） |
| 任期 | 按最高元首的意愿而任职（第145(5)条） |

## 职位的委任方式：第145条第(1)款

第145条第(1)款规定，最高元首应**经首相建议**，委任一名具备出任联邦法院法官资格的人士，出任
联邦总检察长。

由此可直接得出两个文本要点。第一，委任是依建议而行：正式行为属于最高元首，建议则来自首相。
这与[第40条](/zh/government/yang-di-pertuan-agong)下依建议行使职能的一般模式相呼应。

第二，资格是以司法体系为参照而设定的。要符合资格，一个人必须满足与出任联邦法院法官相同的条
件——宪法在其他条文中，以担任高等法院辩护律师或司法及法律服务成员的年资来界定这些条件。因
此，此职位是保留给资深律师的，尽管它本身并非司法职位。

## 咨询职责：第145条第(2)款

第145条第(2)款订明该职位的常设职责。总检察长有责任就最高元首、内阁或任何部长不时提交或指
派给他的法律事宜提供意见，并履行具有法律性质的其他职责，同时须履行由宪法或任何其他成文法所
赋予或据以赋予的职能。

简单来说，这使总检察长成为政府的首席法律顾问。该职责被表述为**提交或指派**给该职位的意见—
—总检察长就提交给该职位的事项提供意见，并履行其他法律所赋予的进一步法律职能。

## 检控权力：第145条第(3)款

这是赋予该职位鲜明特征的条款。第145条第(3)款规定，总检察长应拥有**可自行酌情行使**的权
力，就罪行提起、进行或终止任何诉讼程序，惟沙里亚法庭、原住民法院或军事法庭的诉讼程序除外。

三个动词划定了该权力的范围：

- **提起**——开始一项检控。
- **进行**——将其继续下去。
- **终止**——使其结束。

由于这项权力归属于该职位，总检察长在此身份下即为国家的**公共检控官**。这两个称谓所描述的是
同一个人在不同角色下的身份："总检察长"指整个职位，而当该职位行使第(3)款针对刑事诉讼程序的
权力时，则称为"公共检控官"。

该条款也划定了自身的界限。该权力覆盖普通法院中"任何罪行的诉讼程序"，但条文本身排除了三个审
判场所：

| 被排除的审判场所 | 涵盖范围 |
| --- | --- |
| 沙里亚法庭 | 州伊斯兰法律下的罪行，属各州管辖范围 |
| 原住民法院 | 沙巴与砂拉越的原住民习俗事务 |
| 军事法庭 | 军事法律下的军人罪行 |

这些排除事项，对理解该职位权力的覆盖范围十分重要：第(3)款的自由裁量权，是对联邦普通法院中
检控事宜的权力，而非对每一个可以审理不法行为的法庭均有权力。关于普通刑事法院的架构安排，见
[法院层级](/zh/law/court-hierarchy)；关于沙里亚这一侧的界线，见
[民事法庭与沙里亚法庭](/zh/law/civil-and-syariah-courts)。

## 选择审理法院：第145条第(3A)款

第145条第(3A)款是第(3)款的配套条文。它规定，**联邦法律可赋予**总检察长权力，决定他依第
(3)款有权提起的任何诉讼程序，应在哪些法院或哪个地点提起，或应转移至何处。

该条款是授权性质，而非自动生效的条文：它本身并不授予场地选择权，而是允许国会以联邦法律赋予
该权力。它与检控自由裁量权并列，使案件应在何处审理的选择，可在同一框架内予以确定。

## 出庭权与优先权：第145条第(4)款

第145条第(4)款规定，总检察长在履行职责时，应在联邦任何法院或法庭**享有出庭权**，并**优先
于在该处出庭的任何其他人士**。

这一条同时授予两项权利。出庭权意味着该职位可在任何法院或法庭出庭并陈词。优先权则意味着，当
总检察长出庭时，该职位在该案件中的排位先于任何其他出庭人士。两者合在一起，使该职位在联邦各
法院的法律代表中居于首位。

## 任期与酬金：第145条第(5)款及第(6)款

第145条第(5)款订明该职位的任职条件。在不违反第(6)款的前提下，总检察长**按最高元首的意愿
而任职**，可随时辞职，并且——除非他是内阁成员——应获得最高元首所决定的酬金。

"按意愿而任职"是宪法上一个特定的专门用语：该职位并非任期固定。该条款也预见到持有者可能是也
可能不是内阁成员，并针对两种情形分别规定了酬金问题。

第145条第(6)款是一项过渡性保障。它规定，在该条文生效之前紧接着担任此职位的人，其任职条件
不得比之前更差，并且除非依照与联邦法院法官相同的理由及方式，不得将其免职。第(5)款所称"在
不违反……的前提下"，指的正是第(6)款。

## 职位与总检察署

总检察长领导**总检察署**（Jabatan Peguam Negara），这是执行上述宪制职能的联邦部门。总检
察署下设多个组别，工作范围包括刑事检控、代表政府进行的民事诉讼、法律咨询工作，以及法律的草
拟与修订等。总检察署内设有**Solicitor General**一职，是总检察署内最资深的副手。

这一区别值得厘清：第145条将此职位赋予一位具名的持有者，而总检察署则是协助履行其职能的常设
机构——由司法及法律服务成员组成的官员团队。

## 常见误解

**"总检察长与公共检控官是两个不同的职位。"** 在条文中，两者是同一个职位。公共检控官，即是
行使第145条第(3)款权力的总检察长。（这两个角色*是否应当*分开，是一个政策辩论问题，本文这
篇以文本为依据的文章不作讨论。）

**"检控权力来自刑事诉讼法典（Criminal Procedure Code）。"** 该法典规范刑事诉讼程序如何进
行，但提起、进行或终止诉讼程序的自由裁量权，是由宪法本身在第145条第(3)款中赋予的。

**"总检察长可以在任何法院进行检控。"** 第(3)款的权力明文规定**不**延伸至沙里亚法庭、原住
民法院或军事法庭。

**"该职位有固定任期。"** 第145条第(5)款规定，该职位按最高元首的意愿而任职；宪法并未为该
职位设定固定任期。
