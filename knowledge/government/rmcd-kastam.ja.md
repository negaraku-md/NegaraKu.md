二つの機関、一つの省、そしてほとんどの人が最初は正しく引けない境界線がある。
その税が**国境を越える物、工場から出ていく物品、又は提供されるサービス**に
付着するものであれば、それはKastamの事だ。それが**所得、利得、又は文書**に
付着するものであれば、それはLHDNの事だ。

## 概要

| | |
| --- | --- |
| 正式名称 | Jabatan Kastam Diraja Malaysia／Royal Malaysian Customs Department |
| 種類 | 連邦政府部門 |
| 報告先 | 財務省——同省の*部局*の下に一覧掲載されており、*機関*の下ではない |
| 首長 | 関税局長（Director General of Customs） |
| 本部 | No. 3, Persiaran Perdana, Presint 2, 62596 Putrajaya |

| ウェブサイト | `customs.gov.my` |

## 所管法令

| 法令 | 対象 |
| --- | --- |
| 1967年関税法（Customs Act 1967、Act 235） | 国境における輸入税及び輸出税、申告、評価、押収及び訴追 |
| 1976年物品税法（Excise Act 1976、Act 176） | 物品税及び免許——自動車、酒類、たばこその他の物品税課税品目 |
| 2018年売上税法（Sales Tax Act 2018、Act 806） | マレーシア国内で製造された課税対象物品及び輸入品に対する単一段階の売上税 |
| 2018年サービス税法（Service Tax Act 2018、Act 807） | 指定された課税サービスに対する単一段階のサービス税 |
| 1990年自由地域法（Free Zones Act 1990、Act 438） | 自由商業地域及び自由工業地域 |
| 2017年観光税法（Tourism Tax Act 2017、Act 791） | 宿泊に対する観光税 |
| 2019年出国税法（Departure Levy Act 2019、Act 813） | 航空機によるマレーシア出国に対する課徴金 |
| 1998年暴利税法（Windfall Profit Levy Act 1998、Act 592） | 指定商品からの暴利に対する課徴金 |

売上税とサービス税はいずれも**2018年9月1日**に施行され、GSTに取って代わっ
た。両者は別個の登録基準を持つ、それぞれ独立した法令である——
[SST解説](/ja/taxation/sst-explained)を参照。

## LHDNとの分担を一つの表で

両者はいずれも財務省の下にある。共通点はそこまでだ。

| あなたの疑問 | 誰が答えるか |
| --- | --- |
| 自社の利益にかかる税 | [LHDN](/ja/government/lhdn) |
| 自分が発行する請求書のサービス税 | RMCD |
| 貨物の輸入税 | RMCD |
| 海外業者への源泉徴収税 | LHDN |
| 賃貸借契約の印紙税 | LHDN |
| 自動車の物品税 | RMCD |
| ショップハウス売却の不動産譲渡益税 | LHDN |
| ホテルが課す観光税 | RMCD |
| 航空券の出国税 | RMCD |
| 電子インボイスの提出 | LHDN |

機能面の違いの下には、構造面の違いがある。**RMCDは部門である**——連邦公務
員制度の一部であり、関税局長が率いる。**LHDNは法定機関である**——それ自身
の法令によって設立された。財務省はKastamを*部局*の下に、LHDNを*機関*の下
に一覧掲載しており、その分類こそが両者を区別する最も明快な方法である。

## 運営するプラットフォーム

- **MySST**——売上税及びサービス税の登録、申告及び納付、並びに官報告示さ
  れたOrder、規則及び政策声明。
- **ezHS（JKDM HS Explorer）**——HSコード又は品目説明による税率検索であ
  り、現行のCustoms Duties Order、及びマレーシアの自由貿易協定（ATIGA、
  ACFTA、AANZFTA、RCEPなど）の優遇税率表を対象とする。
- **MyTTx**——マレーシア観光税システム。
- **MyDLV**——出国税の申告。
- **税務印紙システム（TMS）**——物品税課税品目への税務印紙。
- **MNTR**——Malaysia National Trade Repositoryであり、貿易措置及び手続を
  扱う。

## 見落としやすい二つの点

**税率は官報告示されるものであり、単に公表されるものではない。** 関税率は
Customs Duties Orderによって、サービス税率はRate of Tax Orderによって定め
られる。各プラットフォーム上の案内文書やFAQページは解説にすぎない——
P.U.(A)の法定文書こそが法律である。両者が食い違う場合は、官報が優先する。

**執行と課税評価は同一の機関が担う。** 貨物を通関させる担当官と、SST-02申
告書を監査する担当官は、同じ一つの部門に属しており、押収及び訴追の権限を
伴う法令のもとで働いている。これは、課税評価と執行が民事回収モデルに従う
直接税側とは異なる。

## 次にすべきこと

書式を探し始める前に、自分の義務がどちら側にあるのかを見極めること。
Kastamの事案であれば、自らが提供するサービス及び物品については
[SST解説](/ja/taxation/sst-explained)から、輸入するものについてはezHSか
ら始めること。所得、利得又は文書に関する問題であれば、代わりに
[LHDN](/ja/government/lhdn)へ。
