あなたがこれまでに目にしたマレーシアの経済数字——大臣が引用する成長率、
ニュースの見出しに出るインフレ指標、銀行の調査レポートにある失業率——の
ほぼすべては、プトラジャヤにある同じ建物から始まっている。その建物が
どのように機能しているかを知ることで、あなたは数字をただ繰り返す人から、
それを確かめられる人へと変わる。

## 一覧

| | |
| --- | --- |
| 正式名称 | Jabatan Perangkaan Malaysia／Department of Statistics Malaysia |
| 種類 | 連邦政府部門 |
| 所管省庁 | 経済省 |
| 根拠法 | 1965年統計法（Statistics Act 1965、Act 415）、1989年改訂版 |
| 御裁可／施行 | 1965年6月22日／1965年8月16日 |
| 部門首長 | 統計局長（Chief Statistician Malaysia、Ketua Perangkawan Malaysia） |
| 本部所在地 | Block C6 & C7, Complex C, Federal Government Administrative Centre, 62514 Putrajaya |
| ウェブサイト | `dosm.gov.my`（ポータル）、`open.dosm.gov.my`（オープンデータ） |

同部門の歴史は1965年よりもさらにさかのぼる。1949年統計条例（Statistics
Ordinance 1949）のもと、当時は対外貿易とエステート農業に限定された統計局
（Bureau of Statistics）として発足し、1965年に新法のもとで現在の名称と
なった。同法自体は1975年に改正され、1989年12月28日にAct 415として改訂版
が公布され、2001年と2006年に再版された。DOSMは全州に州事務所を置いている。

## 旗艦シリーズ

DOSMは年間300件を超える出版物を発表している。以下は特によく引用される
ものである。

| シリーズ | 頻度 | 本サイトでの解説 |
| --- | --- | --- |
| 国内総生産（GDP） | 四半期、州別年次GDPもあり | [マレーシアのGDP概況](/ja/economy/gdp-overview) |
| GDP速報値 | 四半期、完全なGDPに先立って発表 | [マレーシアのGDP概況](/ja/economy/gdp-overview) |
| 消費者物価指数（CPI） | 毎月 | [インフレとCPI](/ja/economy/inflation-cpi) |
| 労働力 | 毎月および四半期 | [失業と労働力](/ja/economy/unemployment-labour-force) |
| 対外貿易統計 | 毎月 | [対外貿易](/ja/economy/external-trade) |
| 鉱工業生産指数（IPI） | 毎月 | — |
| 生産者物価指数（PPI） | 毎月 | — |
| マレーシア経済指標 | 毎月（先行・一致・遅行） | — |

これらに加えて、出版物カタログは分野別に編成されている。国民経済計算、
物価、労働市場、対外部門、製造業、建設業、サービス業、鉱業・採石業、農業、
環境、家計所得・支出、人口・人口統計、小地域統計、そして臨時発表である。

## 数字がニュースになる前にそれを知る方法

これはほとんどの人が見落としている部分である。**DOSMは発表日をあらかじめ
公表している。** 事前発表カレンダー（Advance Release Calendar）には、
予定されているすべての出版物とその発表日が一覧で示されており、発表当日
には指定された解禁時刻とともに報道機関向けの声明が発出される。

これは単なるウェブページではない。同じ内容は構造化データセット
（`arc_dosm`）としても提供されており、出版物ID、発表日時、英語とマレー語
のタイトル、カテゴリー、頻度、参照期間が含まれている。以下の形式で取得
できる。

- **CSVまたはParquet** ——分析用。
- **購読可能なGoogleカレンダー** ——発表日が自分のカレンダーに表示される。
- **iCalendarの`.ics`ファイル** ——他のカレンダーアプリ用。
- **`data.gov.my`経由のAPI呼び出し** ——`developer.data.gov.my`で文書化
  されている。

典型的な月の様子を見るために、DOSMが2026年7月に予定していた発表を以下に
示す。

| 日付 | 発表内容 |
| --- | --- |
| 7月1日 | 州別GDP、2025年 |
| 7月9日 | 鉱工業生産指数、2026年5月 |
| 7月9日 | 月次製造業統計、2026年5月 |
| 7月17日 | 消費者物価指数、2026年6月 |
| 7月17日 | GDP速報値、2026年第2四半期 |
| 7月20日 | 月次対外貿易統計、2026年6月 |
| 7月24日 | マレーシア経済指標、2026年5月 |

この表から2つのことがわかる。月次の物価・貿易データは参照月からおよそ
2〜3週間以内に発表される一方、生産指数はより長いラグを伴う。そして2026年
第2四半期のGDP速報値は7月17日に発表され、正式なGDP発表は8月14日に予定
されていた——この4週間の間、暫定的な数字が広く流通し、その後静かに改定
される。

## DOSMを引用する際によくある誤り

- **速報値をGDPの数字として引用すること。** それは暫定値である。正式発表
  が存在する場合は、そちらを引用すること。
- **月次と四半期の労働力データを混同すること。** DOSMは両方を発表して
  いる。これらは参照期間の異なる別個の統計である。
- **ダッシュボードを情報源として扱うこと。** ダッシュボードは更新される。
  日付の入った出版物またはデータセットを引用し、取得した日付を記録する
  こと。
- **ポータルのリンクが恒久的だと思い込むこと。** DOSMは2026年5月1日より
  デジタル発信を主要な発表チャンネルとしており、これまでにもポータルの
  バージョンを移行したことがある。依拠するPDFはアーカイブしておくこと。
- **出典を明示せずにデータを再利用すること。** OpenDOSMのデータセットは
  CC BY 4.0であり、自由に再利用できるが、出典明示は義務であって、礼儀では
  ない。

## データはどこにあるか

| チャンネル | 最も適した用途 |
| --- | --- |
| `dosm.gov.my` | 日付入りの発表、技術資料、発表カレンダー |
| `open.dosm.gov.my` | ダッシュボードと機械可読データカタログ |
| `data.gov.my` | DOSMを含む政府全体のオープンデータポータル |
| `developer.data.gov.my` | プログラムからのアクセス用API文書 |

カタログ自体は、人口統計、家計と所得、国民経済計算、物価、労働市場、教育、
環境、各経済部門にまたがっている——複数のデータセットはDOSMではなく他の
機関に由来するものであるため、ある数字をDOSMに帰属させる前に、出所の
記載を確認すること。

この機関そのものではなく特定の数字を探しているのであれば、
[マレーシアのGDP概況](/ja/economy/gdp-overview)、
[インフレとCPI](/ja/economy/inflation-cpi)、または
[失業と労働力](/ja/economy/unemployment-labour-force)から始めるとよい。
