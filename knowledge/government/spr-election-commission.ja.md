マレーシアで選挙を執行する機関は、通常の法令によって設立されたものではなく、通常の法令によって廃止することもできない。それは連邦憲法に直接規定されている——そして第113条と第114条という二つの条文が、その機関が何を行うことができ、誰がその委員となり得るかを定めている。

選挙管理委員会（Suruhanjaya Pilihan Raya、SPR）が、その機関である。本記事は、憲法の条文に含まれるとおりの権限と職能を、記述的かつ評価を加えることなく説明する。

## 概要

| | |
| --- | --- |
| 正式名称 | 選挙管理委員会（Suruhanjaya Pilihan Raya、Election Commission） |
| 憲法上の根拠 | 第113条（職能）；第114条（構成）；連邦憲法第八部（第113条～第120条） |
| 設立 | 1957年9月4日 |
| 構成 | 委員長、副委員長及びその他委員5名（第114(1)条） |
| 任命者 | 国王（Yang di-Pertuan Agong）が統治者会議（Majlis Raja-Raja）との協議の後に任命（第114(1)条） |
| 委員の退任年齢 | 66歳（第114(3)条） |
| 関連法律 | 1957年選挙委員会法（Akta Suruhanjaya Pilihan Raya 1957、Akta 31）；1958年選挙法（Akta Pilihan Raya 1958、Akta 19）；連邦憲法第十三附表 |
| 公式サイト | `spr.gov.my` |

## 第113条のもとでの三つの中核的職能

第113(1)条は「選挙管理委員会を置く」と規定し、同委員会は第114条により構成され、——連邦法律の規定に従うことを条件として——下院（Dewan Rakyat）及び州議会（Dewan Undangan Negeri）の選挙を執行し、それらの選挙のための選挙人名簿を作成し検討しなければならない。

選挙管理委員会の公式サイトは、この権限を三つの中核的職能に整理している。

1. **選挙区の区割り**——8年を下回らない間隔で、国会及び州の選挙区の区割りを見直し、変更を勧告する。
2. **選挙人登録**——選挙人登録の事務及び選挙人名簿の検討を行う。
3. **選挙の執行**——[下院（Dewan Rakyat）](/government/dewan-rakyat)及び州議会の総選挙、並びに補欠選挙を執行する。

これら三つの職能に加えて、第113(4)条は、連邦又は州の法律が、第(1)項に定める選挙以外の選挙を執行する権限をSPRに与えることができると規定している。第113(5)条は、SPRがその職能のために必要な範囲内で規則を制定することを認めているが、当該規則の効力は連邦法律に従うことを条件とする。

## 選挙区の区割り：第113(2)条が定めるもの

最も詳細に定められた職能は、第113(2)条にある。SPRは、必要と認めるときに随時、連邦及び各州の選挙区への区割りを見直し、**第十三附表**の規定を遵守するために必要と認める変更を勧告しなければならない。州議会についての見直しは、下院についての見直しと同時に行われる。

二つの期限がこの過程を規律している：

| 規定 | 期限 |
| --- | --- |
| 第113(2)(ii)条 | 一つの見直しの完了日と次の見直しの開始日との間に、**8年を下回らない**間隔を置く |
| 第113(2)(iii)条 | 各見直しは、開始日から**2年を超えない**期間内に完了しなければならない |

第113(9)条は、見直しの**開始**日を、第十三附表第4節に基づき官報（Warta）に通知が掲載された日と定め、第113(10)条は、**完了**日を、第十三附表第8節に基づき首相（Perdana Menteri）に報告書が提出された日と定めている。

ここで用いられている用語に留意すべきである：選挙区の区割りにおいて、SPRは変更を**勧告する**にすぎない。その勧告がどのように効力を与えられるかは、第113条自体ではなく、第十三附表に規定されている。

第113(6)条は、マラヤ諸州、並びにサバ州及びサラワク州それぞれについて別個の見直しを行うことを定め、「見直し単位」を定義している。第113(3)条は、第2条（州境の変更又は新州の設立）に基づき制定された法律により見直しが必要であるとSPRが認める場合には、前回の見直しから8年が経過しているか否かにかかわらず、これを行わなければならないと規定している。

第113(3A)条及び第113(3B)条の追加規定は、[第46条](/government/parliament)又は州法律の改正により下院又は州議会の民選議員数が変更された場合の見直しを規律している。

## 区割りの勧告はどのように承認されるか：第十三附表

第113条がSPRは区割りを**勧告する**にすぎないと定めているため、その勧告がどのように評価され効力を与えられるかは、第十三附表に規定されている。SPRが「実行可能な限り」遵守すべき原則は、同附表第2節に定められている。

- **2(a)**——選挙区は州境を越えるべきではなく、すべての選挙人には合理的に便利な投票の機会が与えられるべきである。
- **2(b)**——登録及び投票の行政上の便宜に配慮すべきである。
- **2(c)**——一州内の各選挙区における選挙人数はおおむね同数であるべきであるが、僻地及び農村地域の選挙人に接触することのより大きな困難を考慮して、「地域についての加重の措置」を与えるべきである。
- **2(d)**——境界の変更に伴う不便、及び地域的なつながりの維持に配慮すべきである。

第十三附表第II部は、段階的な手続を定めている。

1. SPRは、提案する勧告の通知を官報（Warta）及び少なくとも一つの新聞に掲載する（第4節）。
2. **1か月**以内に意見の申立てを行うことができる（第4節）。
3. 州政府、地方当局、又は**100名以上の選挙人**から異議が提出された場合、SPRは現地調査を行わなければならない（第5節）。
4. SPRは首相（Perdana Menteri）に報告書を提出し（第8節）、首相はそれを命令案とともに下院（Dewan Rakyat）に提出する（第9節）。
5. 命令案は、下院により議員総数の半数を下回らない票数をもって承認されなければならない（第10節）。
6. その後、国王（Yang di-Pertuan Agong）が当該命令を発する（第12節）。

したがって、SPRが見直し及び調査を主管するとはいえ、区割りの最終的な承認権は下院及び国王（Yang di-Pertuan Agong）にあり、SPR単独にあるのではない。

## 第114条のもとでの構成

第114(1)条は、SPRが[国王（Yang di-Pertuan Agong）](/government/yang-di-pertuan-agong)により、[統治者会議（Majlis Raja-Raja）](/government/majlis-raja-raja)との協議の後に任命され、委員長1名、副委員長1名及びその他委員5名から構成されなければならないと規定している。

統治者会議との協議は、特定の憲法上の要件である——憲法が求めているのは統治者会議への**協議**であって、その**同意**ではない。

第114(2)条は、一つの考慮事項を加えている：SPRの委員を任命するにあたり、国王（Yang di-Pertuan Agong）は「公衆の信頼を得る選挙管理委員会であることを確保することの重要性を考慮しなければならない」（*enjoys public confidence*）。

## 在職期間の保障

憲法は、SPR委員の地位に、司法機関に匹敵するいくつかの保護を付している。これらは第114(3)条から第114(6)条に定められている。

| 規定 | 定める内容 |
| --- | --- |
| 第114(3)条 | 委員は66歳（Akta A1320により2007年12月27日から65歳より引き上げ）に達したとき、又は資格を失ったときに退任する；国王（Yang di-Pertuan Agong）宛ての書面により辞職することができる；**[連邦裁判所](/government/kehakiman-mahkamah)の裁判官と同一の理由及び同一の方法によらなければ撤職させられない** |
| 第114(4)条 | 国王（Yang di-Pertuan Agong）は、復権していない破産者となった委員、その職務外で有給の職若しくは雇用に就いた委員、又は国会のいずれかの院若しくは州議会の議員となった委員を撤職させなければならない |
| 第114(4A)条 | 委員長は、任命後3か月を経過してから、いずれかの団体又は事業の取締役会若しくは経営陣の一員、役員若しくは従業員となり、又はその業務に関与した場合（福祉活動又はボランティア活動については例外あり）、資格を失う |
| 第114(5)条 | 国会は法律により委員の報酬を定めなければならず、**当該報酬は統合基金（Kumpulan Wang Disatukan）に賦課される** |
| 第114(6)条 | 委員の報酬及び在職条件は、任命後、**当該委員に不利益となるよう変更することはできない** |

第114(7)条は、委員長が休暇中であるか、又はその職能を果たすことができない場合には副委員長がその職能を果たし、副委員長もそれを果たすことができない場合には、国王（Yang di-Pertuan Agong）がその期間、委員長の職能を果たす委員1名を任命することができると規定している。

## 職員及び支援：第115条

第115(1)条は、SPRが国王（Yang di-Pertuan Agong）の承認を得て自ら定める条件により、必要な人数を雇用することを認めている。

第115(2)条は、すべての公的機関に対し、要請があったときはSPRに実行可能な支援を提供する義務を課している。選挙区の区割りを勧告する職能については、SPRは、見直し単位の地形及び人口分布について専門的知識を有する連邦政府職員2名の助言を得なければならず、当該職員は国王（Yang di-Pertuan Agong）により選定される。

## 選挙結果はどのように争われるか

第118条は、選挙結果を争う唯一の方法を定めている：下院又は州議会のいかなる選挙も、その選挙が行われた地について管轄権を有する高等法院に提出される**選挙呈請**（election petition）によるほかは、争うことができない。第118A条は、当選人不宣布（*no return*）に関する呈請を規定している。

連邦憲法第八部のその他の関連規定には、第116条（連邦選挙区）、第117条（州選挙区）、第119条（選挙人資格）及び第120条（上院への直接選挙）がある。

## 構成はどのように発展してきたか

SPRの構成の歴史は、第114条に対する一連の改正を反映している。SPRの公式サイトによれば——

| 年 | 変化 |
| --- | --- |
| 1957年 | SPRは委員長1名及び委員2名で設立された |
| 1963年 | 委員数が3名に増加し、サバ又はサラワクからの追加委員が輪番で加わった |
| 1981年 | 第114条の改正により、副委員長1名の任命が可能になった |
| 2002年 | 構成が7名に増加：委員長、副委員長及び委員5名（サバから1名、サラワクから1名を含む） |

第114条の公式注記は、この構成を特定の憲法改正と関連づけている：Akta 26/1963（1963年9月16日施行）は、その他委員の数を2名から3名に引き上げ；Akta A514（1981年5月15日施行）は副委員長職を導入し；Akta A1130（2001年9月28日施行）は、その他委員について「3名」を「5名」に置き換え、合計人数を7名とした。SPRのポータルサイトによれば、同委員会の初代委員長はDato' Dr. Mustafa Albakri bin Haji Hassanであった。

## よくある誤解

**「SPRが選挙区の境界を最終的に定める。」** 第113(2)条は、SPRが第十三附表に従って変更を見直し勧告すると定めている。第113条は、SPRに境界を最終的に定める権限を与えていない；勧告がどのように効力を与えられるかは、第十三附表に規定されている。

**「SPRは国会のある法令によって設立された。」** SPRは連邦憲法（第113条及び第114条）により直接規定されている。1957年選挙委員会法（Akta Suruhanjaya Pilihan Raya 1957）及び1958年選挙法（Akta Pilihan Raya 1958）は、報酬、任期及び手続を規律しているが、当該機関の存在そのものは憲法に依拠している。

**「SPRの委員は、一般の公務員と同様に撤職させられ得る。」** 第114(3)条は、委員が連邦裁判所の裁判官と同一の理由及び同一の方法によらなければ撤職させられないと定めている——これは高度な在職期間の保護である。

**「SPRの委員を任命するには、統治者会議の同意が必要である。」** 第114(1)条が求めるのは、国王（Yang di-Pertuan Agong）が統治者会議と**協議**することであり、その**同意**を得ることではない。協議と同意は、二つの異なる憲法上の要件である。

**「8年の間隔とは、区割りの見直しを8年ごとに行わなければならないという意味である。」** 第113(2)(ii)条が定めているのは、一つの見直しと次の見直しとの間に8年を下回らない間隔を置くことであり——これは最低限度であって、固定された予定表ではない。

## 次に読むべきもの

SPRがより広い憲法上の枠組みの中でどこに位置するかを見るには、まず[連邦憲法](/law/federal-constitution)、次に[マレーシア国会](/government/parliament)及び[下院（Dewan Rakyat）](/government/dewan-rakyat)——SPRが執行する選挙によって構成される議院——を読んでほしい。

統治者会議との協議の後の国王（Yang di-Pertuan Agong）による任命の仕組みについては、[国王（Yang di-Pertuan Agong）](/government/yang-di-pertuan-agong)及び[統治者会議](/government/majlis-raja-raja)を参照してほしい。

第113条から第120条まで及び第十三附表の全文は、検事総長室（Jabatan Peguam Negara）のポータルサイトにある連邦憲法の公式再版で読むことができ、公式の職能説明は選挙管理委員会が`spr.gov.my`で公表している。
