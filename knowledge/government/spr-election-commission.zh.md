马来西亚执行选举的机构，并非由一般法令设立，也不能由一般法令废除。它直接由联邦宪法所规定——而第113条与第114条这两条条文，设定了它可以做什么、由谁组成。

选举委员会（Suruhanjaya Pilihan Raya，SPR）就是这个机构。本文以描述性、不作评价的方式，说明其授权与职能，一切均依宪法文本所载。

## 概览

| | |
| --- | --- |
| 正式名称 | 选举委员会（Suruhanjaya Pilihan Raya） |
| 宪法依据 | 第113条（职能）；第114条（组成）；联邦宪法第八部分（第113–120条） |
| 成立日期 | 1957年9月4日 |
| 组成 | 主席、副主席及另外五名成员（第114(1)条） |
| 委任人 | 最高元首在咨询统治者会议后委任（第114(1)条） |
| 成员卸任年龄 | 66岁（第114(3)条） |
| 相关法律 | Akta Suruhanjaya Pilihan Raya 1957 (Akta 31)；Akta Pilihan Raya 1958 (Akta 19)；宪法Thirteenth Schedule（第十三附表） |
| 官方网站 | `spr.gov.my` |

## 第113条下的三项核心职能

第113(1)条规定「应设有一个选举委员会」，该委员会依第114条组成，并——在受限于联邦法律规定的情况下——应执行下议院及州立法议会的选举，并为该等选举编制及修订选民名册。

选举委员会官方网站将此授权归纳为三项核心职能：

1. **选区重划**——检讨并建议国会及州属选区的重划，间隔不少于每八年一次。
2. **选民登记**——处理选民登记事务及选民名册的修订。
3. **执行选举**——执行[下议院](/zh/government/dewan-rakyat)及州立法议会的大选，以及补选。

除这三项职能外，第113(4)条规定，联邦或州法律可授权选举委员会执行第(1)款所述以外的其他选举。第113(5)条则允许选举委员会就其职能制定必要范围内的规则，惟该等规则的生效，须受限于联邦法律。

## 选区重划：第113(2)条的规定

最详尽的职能载于第113(2)条。选举委员会应不时按其认为必要，检讨联邦及各州划分为选区的方式，并按其认为必要的程度，建议作出符合**Thirteenth Schedule**规定的修改。就州立法议会而言，其检讨须与下议院的检讨同时进行。

两项时限规范着这个过程：

| 条文 | 时限 |
| --- | --- |
| 第113(2)(ii)条 | 一次检讨完成之日与下一次检讨开始之日之间，间隔**不得少于八年** |
| 第113(2)(iii)条 | 每次检讨须自开始之日起，**在不超过两年的期限内完成** |

第113(9)条将一次检讨的**开始**日期，定为根据Thirteenth Schedule s.4在宪报刊登通知之日；而第113(10)条则将**完成**日期，定为根据Thirteenth Schedule s.8向首相提交报告之日。

这里所用的措辞值得留意：在选区重划中，选举委员会所做的是**建议**修改。该建议如何生效，规定于Thirteenth Schedule之中，而非第113条本身。

第113(6)条就马来亚各州以及沙巴、砂拉越各州分别规定独立的检讨，并界定「检讨单位」。第113(3)条则规定，若选举委员会认为因根据第2条（修改边界或设立新州属）所制定的法律而须进行检讨，则不论自上次检讨以来是否已过八年，均须进行该检讨。

第113(3A)条及第113(3B)条另有补充规定，规范因[第46条](/zh/government/parliament)或州法律的修正，导致下议院或州立法议会的民选议员人数变动时的检讨事宜。

## 第114条下的组成

第114(1)条规定，选举委员会须由[最高元首](/zh/government/yang-di-pertuan-agong)在咨询[统治者会议](/zh/government/majlis-raja-raja)后委任，并由一名主席、一名副主席及另外五名成员组成。

咨询统治者会议，是一项特定的宪法门槛——宪法要求的是须咨询统治者会议，而非须获得其同意。

第114(2)条增加了一项考量：在委任选举委员会成员时，最高元首「须顾及确保设立一个获得公众信任的选举委员会之重要性」（*enjoys public confidence*）。

## 任期保障

宪法为选举委员会成员的职位，附加了若干与司法机构相当的保障。这些规定载于第114(3)条至第114(6)条：

| 条文 | 规定内容 |
| --- | --- |
| 第114(3)条 | 成员在年满66岁或丧失资格时卸任；可致函最高元首辞职；**不得被免职，除非基于与[联邦法院](/zh/government/kehakiman-mahkamah)法官相同的理由，并依照相同的方式** |
| 第114(4)条 | 最高元首须将下列成员免职：成为未获解除的破产者、在职责以外担任任何有薪职位或受雇工作，或成为任何国会院或州立法议会的议员 |
| 第114(4A)条 | 主席若在委任后三个月，成为任何机构或商业企业的董事会或管理层成员、职员或雇员，或参与其事务（惟就慈善或义务工作设有例外），即丧失资格 |
| 第114(5)条 | 国会须以法律规定成员的薪酬，且**该薪酬由统一基金支付** |
| 第114(6)条 | 成员的薪酬及任职条件，在委任后**不得作出对其不利的更改** |

第114(7)条规定，当主席休假或无法履行其职能时，由副主席履行该职能；若副主席也无法履行，最高元首可委任一名成员在该段期间履行主席的职能。

## 职员与协助：第115条

第115(1)条允许选举委员会按其所需聘用人员，聘用条款与条件由选举委员会决定，惟须获最高元首批准。

第115(2)条规定，所有公共机关在获选举委员会要求时，须提供切实可行的协助。就提出选区重划建议的职能而言，选举委员会须征询两名联邦政府官员的意见，该等官员须对检讨单位的地形与人口分布具有专门知识，并由最高元首挑选。

## 选举结果如何受到质疑

第118条规定了质疑选举结果的唯一途径：任何下议院或州立法议会的选举，不得受到质疑，除非透过向该选举所在地具有管辖权的高等法院提呈**选举呈请**（election petition）。第118A条规定了与无宣布结果（*no return*）有关的呈请。

联邦宪法第八部分中其他相关条文，包括第116条（联邦选区）、第117条（州选区）、第119条（选民资格）及第120条（下议院直接选举）。

## 组成如何演变

选举委员会组成的历史，反映了第114条历经的一连串修正。根据选举委员会官方网站：

| 年份 | 变化 |
| --- | --- |
| 1957年 | 选举委员会成立时设一名主席及两名成员 |
| 1963年 | 成员人数增至三名，另设一名来自沙巴或砂拉越的轮值成员 |
| 1981年 | 第114条的修正案，容许委任一名副主席 |
| 2002年 | 组成人数增至七人：一名主席、一名副主席及五名成员，其中包括一名来自沙巴、一名来自砂拉越 |

## 常见错误

**「选举委员会最终决定选区的边界。」** 第113(2)条规定，选举委员会检讨并建议依据Thirteenth Schedule作出修改。第113条并未赋予选举委员会最终决定边界的权力；建议如何生效，规定于Thirteenth Schedule之中。

**「选举委员会是由某项国会法令设立的。」** 选举委员会由联邦宪法（第113及114条）直接规定设立。Akta Suruhanjaya Pilihan Raya 1957 及 Akta Pilihan Raya 1958 规范薪酬、任期条款与程序，但该机构的存在本身，依据的是宪法。

**「选举委员会成员可以像一般公务员那样被免职。」** 第114(3)条规定，成员不得被免职，除非基于与联邦法院法官相同的理由，并依照相同的方式——这是一项极高的任期保障。

**「委任选举委员会成员需要统治者会议的同意。」** 第114(1)条要求最高元首咨询统治者会议，而非取得其同意。咨询与同意，是两项不同的宪法门槛。

**「八年间隔意味着选区重划必须每八年进行一次。」** 第113(2)(ii)条规定，一次检讨与下一次检讨之间的间隔不得少于八年——这是最低限度，而非固定时间表。
