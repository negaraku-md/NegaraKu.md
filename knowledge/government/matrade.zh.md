问一位首次出口的商家，哪个政府机构负责他们的贸易展览摊位，大约一半的人
会回答 MIDA。MIDA 并不负责这项工作。那是 MATRADE 的职责——而这两个机构
在同一条贸易关系上，各自面向相反的一端。

## 概览

| | |
| --- | --- |
| 全称 | 大马对外贸易发展局（Malaysia External Trade Development Corporation，MATRADE） |
| 类型 | 法定机构，依据自身法令设立 |
| 管辖法令 | Malaysia External Trade Development Corporation Act 1992，Act 490 |
| 生效日期 | 1993年3月1日 |
| 隶属 | 国际贸易及工业部（MITI） |
| 核心职责 | 推广马来西亚出口，协助马来西亚公司进入海外市场 |
| 海外网络 | 截至2026年初，据报道设有47个贸易办事处 |
| 总部 | Menara MATRADE，吉隆坡 |
| 网站 | `matrade.gov.my` |

## MATRADE 实际上做什么

MATRADE 自身网站将其宗旨简明地概括为：协助马来西亚公司「在全球市场开拓
新疆界」，并将马来西亚定位为主要贸易国。在实践中，这项使命透过几项具体
服务落实：

- **贸易展览会。** MATRADE 组织并管理马来西亚在国际贸易展览会上的参与，
  负责场地预订、展位设计与搭建、活动前宣传，以及买家会面时间表的安排。
- **贸易与出口加速团。** 与 MITI，有时也与 MIDA 联合举办，这些代表团带
  领马来西亚公司前往现有及新兴市场，与外国官员及买家建立联系。
- **商机配对。** MATRADE 将马来西亚公司与希望从马来西亚采购的外国进口
  商配对。
- **市场情报。** 提供商业情报、市场研究与国别层面的信息，帮助出口商获
  得竞争优势。
- **财务援助。** **市场开发津贴（Market Development Grant，MDG）** 是
  一项可退还津贴，帮助出口商分担在海外推广马来西亚产品或服务的费用。

以上这些都不属于投资推广，也不属于贸易政策。这些具体而言就是出口
推广——而这正是与 MIDA 及 MITI 产生混淆的地方。

## MATRADE 与 MIDA、MITI 的比较

这三个机构同属一个体制家族，但各自的职责并不相同。

| 机构 | 方向 | 职责 |
| --- | --- | --- |
| **MITI** | 政策 | 制定贸易与工业政策，谈判自由贸易协定；本身并不批准或推广个别交易 |
| **MIDA** | 引进 | 推广并审核**流入**马来西亚制造业与服务业的投资 |
| **MATRADE** | 输出 | 推广**流向**海外市场的马来西亚出口 |

一个简单的记忆方式：MIDA 面对的是走进来的投资者；MATRADE 面对的是走出
去的出口商。MITI 位于两者之上，制定由两者各自执行的政策。三个机构在形
式上彼此相连——MITI 本身所管辖法令的清单，将 Act 490 列为 MATRADE 的
管辖法令，与 MIDA 的 Act 397 并列。

## 海外办事处网络

MATRADE 在海外的主要执行机制，是其由贸易专员领导的海外贸易办事处网络。
截至2026年初，该网络据报道设有**47个海外贸易办事处**。

2026年4月，MATRADE 主席 Reezal Merican Naina Merican 描述了这些办事处
使用方式上的转变：它们不再单纯扮演推广据点的角色，而是正被重新定位为
市场情报「前线枢纽」——追踪海外的政策变化、航运路线中断与新兴采购缺口，
并将这些情报回馈给正在应对更为动荡的全球贸易环境的马来西亚出口商。

## 2026年的优先事项

就2026年而言，MATRADE 首席执行官 Abu Bakar Yusof 提出的路线图涵盖
**203项贸易发展与推广计划**，旨在协助**13,400家马来西亚公司**，并围
绕五大支柱展开：

1. **业务持续性与人力资本发展**——为人工智能与不断变化的贸易格局建设
   劳动力能力。
2. **战略合作**——深化与私营部门及金融伙伴的合作关系。
3. **ESG 与可持续发展**——扩大帮助出口商应对海外买家所要求的环境、社
   会与治理合规的计划。
4. **数码化**——为出口商提供数码贸易平台。
5. **市场多元化**——在传统合作伙伴之外，锁定拉丁美洲、中亚与南亚、西
   亚及非洲等新兴市场。

## 常见误解

**为投资奖励事宜找上 MATRADE。** MATRADE 推广的是马来西亚公司在海外销
售的产品。制造业执照、税务奖励与引进投资的便利化事宜，都由 MIDA 而非
MATRADE 负责。

**把 MATRADE 当作制定政策的机构。** MATRADE 执行的是出口推广计划；它
并不谈判自由贸易协定，也不制定工业政策。这些工作属于 MITI。

**以为 MATRADE 只服务大型出口商。** 其所公布的2026年路线图明确将数以
千计的公司列为计划、代表团与津贴的对象——市场开发津贴的存在，正是为了
让规模较小的出口商也能负担得起海外推广，而不只是已站稳脚跟的公司。

## 下一步

如果你的问题与在海外销售马来西亚产品或服务有关——贸易展览会、代表团、
市场情报，或用于推广费用的津贴——MATRADE 就是你要找的机构。如果是把
投资或工厂引入马来西亚，请改为从 [MIDA](/zh/government/mida) 入手；如
果是政策或自由贸易协定方面的问题，那属于 [MITI](/zh/government/miti)
的职责范围。
