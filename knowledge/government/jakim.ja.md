JAKIMという名称が最もよく目にされるのは、食品パッケージに記載されたハラルロゴにおいてである。しかし、ハラル認証はこの部局が担う数ある機能のうちの一つに過ぎない。その背後には、より広い役割がある——イスラム教務の行政を州に委ねている国において、連邦レベルでイスラム関連事務を調整することである。

## 概要

| | |
| --- | --- |
| 正式名称 | Jabatan Kemajuan Islam Malaysia／マレーシア・イスラム開発局（Department of Islamic Development Malaysia） |
| 種別 | 連邦部局 |
| 所属 | 首相府（Jabatan Perdana Menteri）傘下 |
| 政策上の報告先 | マレーシア国家イスラム教事務評議会（Majlis Kebangsaan Bagi Hal Ehwal Ugama Islam Malaysia、MKI） |
| 部局への昇格 | 1997年1月1日 |
| ウェブサイト | `islam.gov.my` |

## 憲法上の根拠

JAKIMの公式ポータルは、その設立根拠を連邦憲法第3条(1)に求めており、同条はイスラム教を連邦の宗教と定めている。同じページでは、その職権を支える参照枠組みとして、第3条、第12条(2)、第37条(1)、第38条(3)、第39条および第121条(1A)も挙げられている。

ここで明確にしておくべき点が一つある。それがJAKIMの役割の形を決定づけているからである。**イスラム法の行政は州の事項である。** これは州リスト（State List、連邦憲法第九付表 List II）に列挙されている。各州はそれぞれ独自のイスラム教権力機関を有しており、マレー統治者（Raja-Raja Melayu）はそれぞれの州においてイスラム教の首長である。

そのためJAKIMは、州の宗教権力に取って代わる権限機関としてではなく、**調整と統一**を担う連邦機関として位置づけられている。この二つの体系の違いについては、[民事裁判所とシャリア裁判所](/law/civil-and-syariah-courts)および[連邦と州の権限分配](/government/federal-state-division)で詳しく説明されている。

## 設立の沿革

公式ポータルの「JAKIM Berpelembagaan」ページによれば：

| 年 | 出来事 |
| --- | --- |
| 1968年 | マレーシア国家イスラム教事務評議会（MKI）が統治者会議（Majlis Raja-Raja）の承認を得て設立され、首相が議長を務めた |
| 1974年 | 宗教担当部門が首相府宗教局（Bahagian Ugama）に昇格 |
| 1984年 | 組織再編によりイスラム関連事務局（Bahagian Hal Ehwal Islam、BAHEIS）が設置され、MKI事務局としての機能は維持された |
| 1997年1月1日 | BAHEISが正式な部局——マレーシア・イスラム開発局（JAKIM）に昇格 |

この初期段階における統治者会議（Majlis Raja-Raja）との関係については、[統治者会議](/government/majlis-raja-raja)のページで説明されている。

## 三つの中核機能

JAKIMの公式ポータルは、三つの中核機能を挙げている：

1. **シャリア法（undang-undang syarak）の制定と統一** — 全国レベルでのシャリア法および関連する法規事項の統一化に向けた取り組み。
2. **イスラム教育の調整と発展** — 全国的なイスラム教育の政策調整と発展。
3. **イスラム行政の調整** — 連邦機関と州機関の間でのイスラム関連事務の行政調整。

これら三つの機能のもとで、公式ポータルは、中央計画機関としての役割、アキーダ（akidah、信仰教義）の純正性の保持、執行メカニズムの調整、イスラム関連プログラムの評価、情報センターとしての役割、そして地域的・国際的な協力の促進といった支援的責務も挙げている。

公式ページはまた、JAKIMのビジョンを「連邦及び州レベルにおける効果的なイスラム管理を実現する」こと、その使命を「アキーダ、シャリア及びムアマラート（muamalah、イスラム取引法）の分野において権威ある参考源となる」ことと述べている。

## MKI事務局

JAKIMが継続的に担う役割の一つは、マレーシア国家イスラム教事務評議会（MKI）の**事務局**を務めることである。MKIは、イスラム関連事務の調整と審議のための全国レベルのプラットフォームである。

この役割において、JAKIMはシャリア、アキーダ、タサウフ（tasawuf、イスラム神秘主義）、ファラク（falak、イスラム天文暦学）に関する事項を審議する委員会や専門家パネルの会議を運営し、全国レベルでの決定を導くプラットフォームとなっている。この事務局機能は、JAKIMが評議会に行政面および調査面の支援を提供することを意味しており、その構成員である権力機関に取って代わるものではない。

## ハラル認証

一般市民が最も頻繁に目にするJAKIMの機能は、ハラル認証である。これは**ハラル管理部門（Bahagian Pengurusan Halal）**を通じて実施されている。

同部門の公式プロフィールによれば、国内のイスラム関連事務を所管する権力機関として、JAKIMはハラル管理部門を通じてハラル認証及び執行を管理する主要機関である。これは各州の州イスラム宗教局（JAIN）と共同で実施されており、公式ポータルによれば、ハラル認証の管理は**2009年8月1日**からJAKIMのもとに一元化された。

申請及びハラル状況の確認は、公式ハラルポータル（MYeHALALシステム）`halal.gov.my`を通じて行われる。

## 調整役割と州の権限との関係

イスラム教務の行政は州に属しているため、JAKIMの機能の多くは調整と統一の性格を持つ——指針を統一し、参考資料を提供し、連邦と州にまたがるプログラムを調整することである。現場での実施、州のシャリア法の執行、そしてシャリア裁判所の行政は、それぞれの州の権力機関のもとに残されている。

これは、二つの層が同時に存在することを意味する：

- **連邦レベル** — 調整機関、MKI事務局、そして連邦ハラル権力機関としてのJAKIM。
- **州レベル** — それぞれの管轄区域内でイスラム法を管理する、[州イスラム宗教評議会](/states/state-islamic-religious-councils)（MAIN）及び州イスラム宗教局（JAIN）。

## よくある誤解

- **JAKIMを裁判所や処罰権限を持つ機関だと考えること。** JAKIMは連邦の行政部局である。JAKIMはシャリア裁判所ではない——シャリア裁判所は州の法令によって設置された州の裁判所である。
- **JAKIMが各州の宗教行政を管轄していると考えること。** イスラム法の行政は州の事項である。JAKIMの役割は調整と統一であり、州の権限に取って代わるものではない。
- **JAKIMとMKIを同一視すること。** JAKIMはMKIの事務局を務める部局であり、MKIはその全国レベルの評議会そのものである。
- **州のハラルロゴとJAKIMのハラルロゴを同一のものだと考えること。** 認証は共同で実施されるが、JAKIMは連邦レベルにおけるハラル認証の主要機関として自らを位置づけている。
