当一名马来西亚人滞留海外，当马来西亚在联合国投票，或当一位新任大使在外国首都递交国书时，
支撑这三者的是同一个机构——Wisma Putra。

"Wisma Putra" 是**外交部**（Kementerian Luar Negeri）的日常称呼。这个别称源自该部
曾经使用的大楼；即使搬迁之后，这个名字也沿用了下来。它今天的官方网站是 `kln.gov.my`。

## 一览

| | |
| --- | --- |
| 官方名称 | 外交部（Kementerian Luar Negeri） |
| 通俗名称 | Wisma Putra |
| 类型 | 联邦部门 |
| 总部 | 布城第二区，Jalan Wisma Putra 1 号 |
| 网站 | `kln.gov.my` |
| 驻外使团 | 在 85 个国家设有 111 个使团 |
| 部长（截至 2026 年） | 拿督斯里乌达玛莫哈末哈山（Dato' Seri Utama Mohamad Hasan） |

## Wisma Putra 实际上做什么？

它的职责是处理马来西亚与世界其他国家的关系。根据该部自己的职能说明，它在政治、经济、
安全以及社会文化等各方面开展马来西亚的对外关系。

它列出的职能可归为以下几类：

- **维护国家利益**——捍卫马来西亚的主权、领土完整和国家利益，并监测区域和全球
  局势的发展。
- **开展外交**——处理与外国及国际组织（如联合国、东盟和伊斯兰合作组织 OIC）的
  双边、区域和多边关系。
- **提供建议与统筹**——制定外交政策以向政府提供建议，并在其他部门和机构之间协调
  和主导政府在国际议题上的立场。
- **经济外交**——在政府对政府的层面上促进与外国的贸易和投资。

注意这里的规律：Wisma Putra 是马来西亚在海外的*协调者和代言人*。它并不负责国家的
贸易政策，也不负责护照印制流程——它为马来西亚发声，并维持外交机器的运转。

## 这个部门是怎么来的？

其基础在独立之前就已奠定。**1956 年**，一支由 11 名职业外交官组成的先锋队被派往
英国和澳大利亚接受培训，以充实当时称为**外务部（Ministry of External Affairs，
MEA）**的机构。

独立时，外交事务位于政府的最高层：首任首相东姑阿都拉曼同时担任首任外务部长，被视为
马来亚早期外交政策的主要缔造者。

后来的两个里程碑塑造了大多数人如今所认识的这个部门：

- **1966 年**，外务部更名为**外交部**，并从苏丹阿都沙末大厦迁往吉隆坡武吉必南
  （Bukit Petaling）一座名为 **Wisma Putra** 的新建筑群——这就是别称的由来。
- **2001 年 9 月 17 日**，该部开始在其位于布城第二区 Jalan Wisma Putra 的现址
  运作。

## 马来西亚的外交网络有多大？

外交需要在当地有实际存在，而 Wisma Putra 运营着庞大的海外布局。据其自己统计，
马来西亚在 **85 个国家设有 111 个使团**，包括：

| 使团类型 | 数量 |
| --- | --- |
| 大使馆 | 66 |
| 高级专员公署 | 18 |
| 总领事馆 | 21 |
| 领事馆 | 2 |
| 常驻联合国代表 | 2 |
| 常驻东盟代表 | 1 |
| 马来西亚友好贸易中心 | 1 |
| **总计** | **111** |

（马来西亚在英联邦成员国的使团是高级专员公署，而非大使馆——两者在级别上是对等的。）
这些使团是马来西亚政府在海外的机构延伸，负责与外国及联合国、东盟、伊斯兰合作组织
（OIC）等机构保持良好关系，并推进马来西亚的国家利益。

## 身在海外的马来西亚人可以向使团寻求什么？

对大多数公民来说，这正是 Wisma Putra 与个人切身相关之处。使团提供**领事服务**，
包括签发护照、旅行证件和签证，认证和公证文件，出具良好行为证明，以及解答领事咨询。

在出现问题时，它们也会介入。Wisma Putra 及其使团为身陷困境的海外马来西亚人提供
协助——当公民在海外冲突或紧急情况中需要帮助时，这项工作便显现出来。

一个实用的提示：在国内的常规护照续办由移民局处理，但在海外则由马来西亚使团签发
旅行证件。如果你身在海外并遇到困难，最近的大使馆、高级专员公署或领事馆就是你的
第一道门。

## Wisma Putra 与 MITI 的界限在哪里？

这是最常见的混淆之处。马来西亚的国际经济关系在外交与贸易之间分工：

| 机构 | 负责范围 |
| --- | --- |
| **Wisma Putra**（外交部） | 外交、外交政策、政府对政府的经济关系，以及驻外使团 |
| **MITI**（投资、贸易及工业部） | 贸易和工业政策；谈判自由贸易协定 |
| **MATRADE** | 促进马来西亚产品进入海外市场 |

Wisma Putra 搭建关系框架并打开大门；MITI 制定贸易规则，MATRADE 负责出口促进。
实践中界限会模糊——经济外交是共同议程，马来西亚使团也常常支持贸易目标——但贸易的
政策和促进杠杆掌握在贸易部门手中，而非外交部。

## 什么是《2026-2030 战略计划》？

2026 年 2 月 23 日，首相拿督斯里安华（Dato' Seri Anwar Ibrahim）在布城的一场
Wisma Putra 活动上推出了**《外交部 2026-2030 战略计划》**，这是该部的五年路线图。
它围绕 **8 大战略重点、33 项战略和 139 个方案**构建，延续自 2021-2025 计划的
中期检讨。

据 Business Today 报道，这八大重点涵盖巩固双边外交、多边领导力、东盟中心地位、
海洋主权、经济外交、公共外交与服务交付、机构能力，以及马来西亚在《化学武器公约》
下的义务。这一时期的核心主题是**经济外交**——同一报道将该计划描述为将马来西亚定位为
全球北方与南方之间的"桥梁"，借助其在清真产业、数字经济和高价值半导体方面的优势。
（这些表述应在发布前对照《战略计划》原始文件核实。）
