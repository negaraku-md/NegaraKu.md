每一个跨越大马边境的人——续领护照的国民、抵境的游客、前来工作的外籍专才——都要经过同一个部门。但它所签发的文件却常被彼此混淆，而这种混淆正是多数移民问题的根源。

## 一览

| | |
| --- | --- |
| 全名 | Jabatan Imigresen Malaysia (Immigration Department of Malaysia) |
| 简称 | JIM |
| 类型 | 联邦部门 |
| 隶属 | 内政部（Ministry of Home Affairs） |
| 网站 | `imi.gov.my` |

## 四项核心职能

该部门以四个部分阐明其职责：

1. **签发护照与旅行证件**予大马公民与永久居民。
2. **签发签证、准证与入境准证**予进入大马的外国公民。
3. **管理人员的出入境流动**，在合法出入境口岸。
4. **执行移民法律**——《移民法令1959/63》（Immigration Act 1959/63）、
   《1963年移民条例》（Immigration Regulations 1963）、《护照法令1966》
   （Passports Act 1966）与《2007年反贩卖人口及反移民走私法令（2010年修正）》
   （Anti-Trafficking in Persons and Anti-Smuggling of Migrants Act 2007
   (Amendment 2010)）。

## 签证、准证、入境准证——三份不同的文件

这是最常见的误解，而且不仅仅是用词的问题。

| 文件 | 作用 |
| --- | --- |
| **签证（Visa）** | *抵达*大马的许可——须由需要签证的国民在出发前预先取得。 |
| **准证（Pas）** | 决定一个人可以停留*多久*，以及*为了什么目的*——旅游、留学或工作。 |
| **入境准证（Entry Permit）** | 让外国公民合法进入并*无期限*定居大马的便利——通往永久居民身份的途径。 |

共签发三种基本签证类型：**单次入境签证**（通常用于社访，一般自签发日起有效三个月）、
**多次入境签证**（通常用于商务或政府对政府事务，一般有效三至十二个月）与
**过境签证**。

**Visa With Reference（VDR）**是一条独立的途径：大马驻外使团只有在移民局
总部批准申请*之后*，才会签发。公民的外籍配偶及来自特定国家的国民等类别，
须经此途径办理。

入境准证则被该部门形容为大马政府给予外国公民的最高礼遇——若违反所订明的
条件，可被撤销。

## 主要准证类型

| 准证 | 适用对象 |
| --- | --- |
| 就业准证（Employment Pass） | 受大马公司聘用的外籍专才 |
| 临时工作准证（Visit Pass, Temporary Employment） | 特定行业的外籍工人 |
| 短期社访准证（Short-Term Social Visit Pass） | 旅游与短期访问 |
| 长期社访准证（Long Term Social Visit Pass） | 最短六个月的临时逗留 |
| 专业访问准证（Professional Visit Pass） | 短期专业性工作 |
| 专业访问准证——专家类（Professional Visit Pass — Expert） | 专业类别 |
| 学生准证（Student Pass） | 国际学生 |
| 居民准证（Resident Pass） | 特别批准的居民类别 |

长期社访准证（Long Term Social Visit Pass）的适用对象包括：公民的外籍
配偶（可获批最长五年，并获准工作）、在大马有担保家庭的六十岁以上乐龄
人士、国际学生的家属、在大马医院接受治疗并有一名陪同人员的病患，以及
外籍专才的受养人。

## 主要在线渠道

- **ESD（Expatriate Services Division，外籍人士服务组）**，网址为
  `esd.imi.gov.my`——是有意聘请外籍专才的公司的第一接触点。所有公司必须
  先在 ESD 注册，才能提出准证申请。
- **MDAC（Malaysia Digital Arrival Card，大马数码入境卡）**，网址为
  `imigresen-online.imi.gov.my`——外国访客在抵境前于网上登记的数码入境
  卡。资格与豁免规定载于该门户网站本身。

## 关于收费的说明

本页刻意**不列出收费**。签证、准证与护照的费率会不时修订，从第三方网站
抄录的数字通常已经过时。请在办理当天查阅 `imi.gov.my` 上的官方收费表，
或向移民局柜台查询。

## 下一步

若你是雇主，可从[所有工作准证一览](/zh/employment/work-passes-malaysia)
入手，先确认合适的准证，再到 ESD 门户网站为公司注册。若你是个人申请者，
请先厘清你的事项属于*抵达*（签证）、*停留*（准证）还是*定居*（入境
准证）——然后在 `imi.gov.my` 查阅相应类别所需的文件清单，因为多数申请
卡关都是因为辅助文件不齐全。
