マレーシア人が海外で立ち往生したとき、マレーシアが国連で票を投じるとき、あるいは
新任大使が外国の首都で信任状を提出するとき——この三つすべての背後に同じ機関が
存在する。Wisma Putraである。

「Wisma Putra」は**外務省**（Kementerian Luar Negeri）の通称である。この愛称は
同省がかつて入居していた建物に由来する。移転後もその名は使われ続けた。現在の
公式ウェブサイトは`kln.gov.my`である。

## 概要

| | |
| --- | --- |
| 正式名称 | 外務省（Kementerian Luar Negeri） |
| 通称 | Wisma Putra |
| 種別 | 連邦省庁 |
| 本部 | プトラジャヤ（Putrajaya）Precinct 2、Jalan Wisma Putra 1番地 |
| ウェブサイト | `kln.gov.my` |
| 在外公館数 | 85か国に111公館 |
| 大臣（2026年現在） | ダト・スリ・ウタマ・モハマド・ハサン（Dato' Seri Utama Mohamad Hasan） |

## Wisma Putraは実際に何をしているのか？

その役割は、マレーシアと世界各国との関係を運営することである。同省自身の職務
説明によれば、政治・経済・安全保障、そして社会文化の各分野にわたってマレーシアの
対外関係を担っている。

同省が挙げる職務は、いくつかの分類にまとめられる。

- **国益の保護**——マレーシアの主権、領土保全、国益を守り、地域および世界の
  動向を監視する。
- **外交の遂行**——外国および国連、ASEAN、OIC（イスラム協力機構）などの国際
  機関との二国間・地域間・多国間関係を管理する。
- **助言と調整**——外交政策を策定して政府に助言し、他の省庁や機関にまたがる
  国際問題への政府の立場を調整・主導する。
- **経済外交**——政府間レベルで外国との貿易・投資を促進する。

ここでのパターンに注目してほしい。Wisma Putraは海外におけるマレーシアの*調整役
であり代弁者*である。国の貿易政策を運営するわけでも、パスポート発給ラインを
運営するわけでもない——マレーシアを代表して発言し、外交の機構を動かし続けて
いるのである。

## この省庁の起源は？

その基盤は独立以前に遡る。**1956年**、11名の職業外交官からなる先発隊が、当時
「**外務省（Ministry of External Affairs、MEA）**」と呼ばれていた組織を担うため、
訓練を受けにイギリスおよびオーストラリアへ派遣された。

独立時、外交は政府の最上位に位置していた——初代首相トゥンク・アブドゥル・
ラーマンは初代外務大臣も兼任し、マラヤ初期の外交政策の主な立案者とみなされて
いる。

その後の二つの節目が、今日多くの人が認識するこの省庁の姿を形作った。

- **1966年**、外務省（Ministry of External Affairs）は**外務省（Ministry of
  Foreign Affairs）**へと改称され、スルタン・アブドゥル・サマド・ビルディング
  からクアラルンプールのブキ・プタリン（Bukit Petaling）にある**Wisma Putra**
  と呼ばれる新しい複合施設へ移転した——これが愛称の由来である。
- **2001年9月17日**、同省はプトラジャヤ第二区（Precinct 2）のJalan Wisma
  Putraにある現在の複合施設での業務を開始した。

## マレーシアの外交ネットワークはどれほどの規模か？

外交には現地でのプレゼンスが必要であり、Wisma Putraは大規模な海外拠点網を
運営している。同省自身の集計によれば、マレーシアは**85か国に111の在外公館**を
維持しており、その内訳は次のとおりである。

| 公館の種類 | 数 |
| --- | --- |
| 大使館 | 66 |
| 高等弁務官事務所 | 18 |
| 総領事館 | 21 |
| 領事館 | 2 |
| 国連常駐代表部 | 2 |
| ASEAN常駐代表部 | 1 |
| マレーシア友好貿易センター | 1 |
| **合計** | **111** |

（高等弁務官事務所は、大使館ではなく、マレーシアが同じ英連邦加盟国に置く公館で
ある——両者は格において同等である。）これらの在外公館は、海外におけるマレーシア
政府の機構的延長であり、国連、ASEAN、OICなどの外国および機関との良好な関係の
維持と、マレーシアの国益の推進を任務としている。

## 海外のマレーシア人は在外公館に何を求めることができるか？

多くの国民にとって、ここがWisma Putraが身近な存在になる部分である。在外公館は
**領事サービス**を提供しており、パスポート・渡航文書・査証の発給、文書の認証・
証明、素行証明書の発行、領事関連の問い合わせへの対応を含む。

また、事態が悪化した際にも介入する。Wisma Putraとその在外公館は、海外で困難に
陥ったマレーシア人への支援を行っている——これは国民が海外での紛争や緊急事態の
際に助けを必要とするときに目に見える形となる仕事である。

実務上の注意点として、国内での通常のパスポート更新は移民局が扱うが、海外では
渡航文書を発給するのはマレーシアの在外公館である。海外で困難な状況にある場合、
最寄りの大使館、高等弁務官事務所、または領事館が最初の窓口となる。

## Wisma PutraとMITIの境界はどこにあるのか？

これは最もよく混同される点である。マレーシアの国際経済関係は、外交と貿易の間で
分担されている。

| 機関 | 担当領域 |
| --- | --- |
| **Wisma Putra**（外務省） | 外交、外交政策、政府間の経済関係、そして在外公館 |
| **MITI**（投資・貿易・産業省） | 貿易・産業政策；自由貿易協定の交渉 |
| **MATRADE** | マレーシア製品の海外市場への輸出促進 |

Wisma Putraは関係の枠組みを構築し扉を開く役割を担い、MITIが貿易ルールを定め、
MATRADEが輸出振興を行う。実務上、この境界は曖昧になることもある——経済外交は
共通の課題であり、マレーシアの在外公館も貿易目標を支援することが多い——しかし
貿易の政策・振興のてこは外務省ではなく貿易関連の省庁が握っている。

## 『戦略計画2026-2030』とは何か？

2026年2月23日、アンワル・イブラヒム首相（Dato' Seri Anwar Ibrahim）は、
プトラジャヤで開催されたWisma Putraのイベントにおいて、同省の5か年ロードマップ
である**『外務省戦略計画2026-2030』**を発表した。この計画は**8つの戦略的推進軸、
33の戦略、139のプログラム**を軸に構成されており、2021-2025計画の中間レビューを
引き継ぐものである。

Business Todayの報道によれば、この8つの推進軸は、二国間外交の強化、多国間での
リーダーシップ、ASEAN中心性、海洋主権、経済外交、広報外交およびサービス提供、
組織的能力、そして化学兵器禁止条約（Chemical Weapons Convention）の下での
マレーシアの義務をカバーしている。この期間の中心テーマは**経済外交**である——
同じ報道は、この計画がマレーシアをグローバル・ノースとグローバル・サウスの間の
「橋」として位置づけ、ハラル産業、デジタル経済、高付加価値半導体における強みを
活かすものだと説明している。（これらの記述は、公開前に一次資料である戦略計画
文書と照合して確認する必要がある。）
