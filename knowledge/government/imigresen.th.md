ทุกคนที่ข้ามพรมแดนของมาเลเซีย — ประชาชนที่ต่ออายุหนังสือเดินทาง นักท่องเที่ยวที่เดินทางมาถึง ชาวต่างชาติที่ทำงาน — ล้วนผ่านหน่วยงานเดียวกัน แต่เอกสารที่หน่วยงานนี้ออกมักถูกสับสนระหว่างกัน และความสับสนนั้นเองคือต้นตอของปัญหาตรวจคนเข้าเมืองส่วนใหญ่

## โดยสังเขป

| | |
| --- | --- |
| ชื่อเต็ม | กรมตรวจคนเข้าเมืองมาเลเซีย (Jabatan Imigresen Malaysia / Immigration Department of Malaysia) |
| อักษรย่อ | JIM |
| ประเภท | หน่วยงานระดับสหพันธ์ |
| ภายใต้ | กระทรวงมหาดไทย (Kementerian Dalam Negeri) |
| เว็บไซต์ | `imi.gov.my` |

## สี่หน้าที่หลัก

หน่วยงานนี้ระบุอำนาจหน้าที่ไว้เป็นสี่ส่วน:

1. **ออกหนังสือเดินทางและเอกสารการเดินทาง** ให้แก่พลเมืองมาเลเซียและผู้มีถิ่นที่อยู่ถาวร
2. **ออกวีซ่า พาส และเพอร์มิต** ให้แก่ชาวต่างชาติที่เข้ามาในมาเลเซีย
3. **จัดการการเคลื่อนย้ายของบุคคล** ณ จุดเข้าและออกที่ถูกกฎหมาย
4. **บังคับใช้กฎหมายตรวจคนเข้าเมือง** — พระราชบัญญัติตรวจคนเข้าเมือง 1959/63 (Immigration Act 1959/63) ระเบียบตรวจคนเข้าเมือง 1963 พระราชบัญญัติหนังสือเดินทาง 1966 (Passport Act 1966) และพระราชบัญญัติต่อต้านการค้ามนุษย์และต่อต้านการลักลอบขนผู้ย้ายถิ่น 2007 (แก้ไข 2010)

## วีซ่า พาส เพอร์มิต — เอกสารสามชนิดที่แตกต่างกัน

นี่คือความเข้าใจผิดที่เกิดขึ้นบ่อยที่สุด และมิใช่เพียงเรื่องของถ้อยคำเท่านั้น

| เอกสาร | หน้าที่ |
| --- | --- |
| **วีซ่า** | การอนุญาตให้ *เดินทางมาถึง* มาเลเซีย — ได้มาก่อนการเดินทางสำหรับพลเมืองที่ต้องมี |
| **พาส (Pass)** | กำหนด *ระยะเวลา* ที่บุคคลอาจพำนักได้และ *เพื่อวัตถุประสงค์ใด* — เยี่ยมเยียน เรียน หรือทำงาน |
| **เพอร์มิตเข้าเมือง (Permit Masuk)** | สิ่งอำนวยความสะดวกให้ชาวต่างชาติเข้าและตั้งถิ่นฐานได้อย่างถูกกฎหมายในมาเลเซีย *โดยไม่มีกำหนดเวลา* — เป็นเส้นทางสู่สถานะผู้มีถิ่นที่อยู่ถาวร |

วีซ่าพื้นฐานสามประเภทที่ออก ได้แก่ **วีซ่าเข้าครั้งเดียว** (โดยทั่วไปสำหรับการเยี่ยมเยียนทางสังคม ปกติสามเดือนนับจากวันที่ออก) **วีซ่าเข้าหลายครั้ง** (โดยทั่วไปสำหรับธุรกิจหรือระหว่างรัฐบาลกับรัฐบาล ปกติสามถึงสิบสองเดือน) และ **วีซ่าผ่านทาง (Transit)**

**วีซ่าแบบมีการอ้างอิง (Visa Dengan Rujukan, VDR)** เป็นช่องทางแยกต่างหาก กล่าวคือ สถานผู้แทนของมาเลเซียในต่างประเทศออกวีซ่านี้เฉพาะ *หลังจาก* คำขอได้รับอนุมัติจากสำนักงานใหญ่กรมตรวจคนเข้าเมืองแล้ว หมวดต่าง ๆ เช่น คู่สมรสของพลเมืองและพลเมืองจากบางประเทศผ่านช่องทางนี้

ส่วนเพอร์มิตเข้าเมืองนั้น หน่วยงานอธิบายว่าเป็นเอกสิทธิ์สูงสุดที่รัฐบาลมาเลเซียมอบให้แก่ชาวต่างชาติ — และอาจถูกเพิกถอนได้หากมีการฝ่าฝืนเงื่อนไขที่กำหนดไว้

## ประเภทพาสหลัก

| พาส | สำหรับใคร |
| --- | --- |
| พาสการจ้างงาน (Employment Pass) | ชาวต่างชาติที่บริษัทในมาเลเซียจ้างเข้าทำงาน |
| พาสเยี่ยมเยียน (ทำงานชั่วคราว) | แรงงานต่างชาติในบางภาคส่วน |
| พาสเยี่ยมเยียนทางสังคมระยะสั้น | การท่องเที่ยวและการเยี่ยมเยียนระยะสั้น |
| พาสเยี่ยมเยียนทางสังคมระยะยาว | พำนักชั่วคราวขั้นต่ำหกเดือน |
| พาสเยี่ยมเยียนวิชาชีพ | งานวิชาชีพระยะสั้น |
| พาสเยี่ยมเยียนวิชาชีพ — ผู้เชี่ยวชาญ | หมวดความเชี่ยวชาญ |
| พาสนักเรียน | นักเรียนต่างชาติ |
| พาสผู้พำนัก (Residen) | หมวดผู้พำนักที่ได้รับอนุมัติเป็นพิเศษ |

พาสเยี่ยมเยียนทางสังคมระยะยาวครอบคลุม อาทิ คู่สมรสชาวต่างชาติของพลเมือง (อาจได้รับสูงสุดห้าปี และได้รับอนุญาตให้ทำงาน) ผู้สูงอายุ 60 ปีขึ้นไปที่มีครอบครัวเป็นผู้อุปการะในมาเลเซีย ครอบครัวของนักเรียนต่างชาติ ผู้ป่วยที่เข้ารับการรักษาในโรงพยาบาลของมาเลเซียพร้อมผู้ติดตามหนึ่งคน ตลอดจนผู้อยู่ในความอุปการะของชาวต่างชาติ

## ช่องทางออนไลน์หลัก

- **ESD (Expatriate Services Division)** ที่ `esd.imi.gov.my` — จุดสัมผัสแรกสำหรับบริษัทที่ต้องการจ้างชาวต่างชาติ บริษัททั้งหมดต้องลงทะเบียนกับ ESD ก่อนที่จะยื่นคำขอพาส
- **MDAC (Malaysia Digital Arrival Card)** ที่ `imigresen-online.imi.gov.my` — บัตรขาเข้าดิจิทัลที่ผู้มาเยือนชาวต่างชาติลงทะเบียนออนไลน์ก่อนเดินทางมาถึง คุณสมบัติและข้อยกเว้นระบุไว้ที่พอร์ทัลนั้นเอง

## หมายเหตุเกี่ยวกับค่าธรรมเนียม

หน้าเว็บนี้จงใจ **ไม่ระบุค่าธรรมเนียม** อัตราค่าวีซ่า พาส และหนังสือเดินทางถูกแก้ไขเป็นครั้งคราว และตัวเลขที่คัดลอกมาจากเว็บไซต์บุคคลที่สามมักล้าสมัยแล้ว ให้ดูตารางค่าธรรมเนียมทางการที่ `imi.gov.my` หรือเคาน์เตอร์ตรวจคนเข้าเมือง ณ วันที่คุณดำเนินการ
