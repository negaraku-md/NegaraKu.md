YouTubeでバイラルになった映画は、映画検閲委員会を一度も通っていないかもしれない——しかし同じ映画であっても、映画館で上映しようとすれば、まずその承認の印を得なければならない。この違いは偶然生まれた緩さではない。それはマレーシアの法律が、公衆が何を見ることができるかを管理する仕組みそのものに組み込まれている。

一般の観客にとって、この制度はポスター上の一文字か一つの数字として現れる：U、P12、13、16、あるいは18。その記号の背後には、一つの公的機関、一つの法令、そしてカラオケセンターがあなたの家の隣の店舗に開業できるかどうかを決める、もう一つ別の規則の系列がある。

## 映画が映画館に届く前に、誰がそれを承認するのか？

映画検閲委員会（Lembaga Penapisan Filem、LPF）——別名、映画検閲処（Pejabat Penapisan Filem）——は、内務省（Kementerian Dalam Negeri、KDN）のもとにある一部門である。その権限は**2002年映画検閲法（Film Censorship Act 2002、Act 620）**に由来する。

KDNによれば、LPFは「マレーシアで製作、発行、所有、保管、管理、上映、展示又は販売されるすべての映画及び映画宣伝材料」が、事前に同委員会による検閲と承認を受けていることを確保する責任を負う。これは劇映画に限らない——予告編や映画の広告資材も同じ手続きの対象となる。

映画が提出されると、LPFは次の三つの決定のいずれかを下すことができる：

- **無削除承認（Lulus Bersih）** — 一切の削除なしに承認
- **修正付き承認（Lulus Dengan Pengubahan）** — 承認するが、特定の部分を削除又は修正
- **上映不承認（Tidak Diluluskan Untuk Tayangan）** — 完全に却下

承認を得た後、初めてその映画に年齢区分が付与される。つまり、マレーシアの映画館で観るすべての映画は、実際には二段階の決定を経ている：内容が承認され、その後に年齢が設定される。

## U、P12、13、16、18とは何を意味するのか？

現在の区分制度は**2023年映画区分制度（Klasifikasi Filem 2023）**として知られ、**2023年2月2日**に施行され、内務大臣ダト・スリ・サイフディン・ナスティオン・イスマイル（Datuk Seri Saifuddin Nasution Ismail）によって発表された。

この制度は、U、P13、18の三段階のみを用いていた従来の制度に、P12、13、16という三つの新しい区分を追加したものである。KDNによれば、その目的は、成人観客が映画を選ぶ自由を守りつつ、子どもを不適切なコンテンツから保護することにある。

| 区分 | 対象 |
| --- | --- |
| **U** | すべての年齢層 |
| **P12** | すべての年齢が対象だが、12歳未満の観客は親／保護者の指導が必要 |
| **13** | 13歳以上の観客 |
| **16** | 16歳以上の観客 |
| **18** | 18歳以上の観客 |

理解すべき最も重要な違いは、文字「P」と単独の数字との間にある。**P12は年齢制限ではない**——12歳未満の子どもも鑑賞できるが、同伴者が必要なだけである。これに対し、**13、16、18は実際の年齢制限**である：定められた年齢に満たない観客は本来入場を許されない。

## なぜインターネット上の映画は「より緩やか」に見えるのか？

ここに、マレーシアの映画法における最大の非対称性がある。LPFの上映前承認プロセスは、映画館での上映のように公開上映を目的とした映画に適用され、その予告編や広告も含まれる。

しかし、同じ事前承認プロセスは、インターネットを通じて配信される映画には**求められない**。印刷物や視覚芸術、舞台芸術といった他の媒体形態についても同様である。これは、ある映画が一度もLPFを通ることなくオンラインに現れる一方で、その映画館版は検閲を受けなければならないことを意味する。オンラインコンテンツが完全に自由というわけではない——それは依然として他の形態の規制の対象となる——が、映画館と同じ上映前検閲の関門を通過することはない。

映画検閲に関する違反は軽いものではない。適切な許可又は承認を得ずに映画を所持、頒布又は上映することは、2002年映画検閲法のもとでの刑事違反であり、**RM5,000からRM30,000の罰金及び／又は最長3年の禁錮**という刑罰が科される。

## 誰がカラオケセンターの開業を許可するのか？

ここで一般の人々はしばしば混同する：LPFはカラオケセンター、ナイトクラブ、娯楽施設を**許可しない**。その権限は、施設が営業する地域の**地方自治体（pihak berkuasa tempatan、PBT）**——市議会、地方議会、県議会——が有しており、それぞれの娯楽附例に基づいて行使される。

この権限は地方的な性質を持つため、条件は地域ごとに異なる。クアラルンプールは分かりやすい例を示している。ファミリーカラオケセンターについて、クアラルンプール市庁（Dewan Bandaraya Kuala Lumpur、DBKL）は次のような条件を課している：

| 項目 | DBKLの条件（ファミリーカラオケ） |
| --- | --- |
| 立地 | 住宅地、学校、病院、大学又は礼拝施設の近くに設置してはならない |
| 営業時間 | 午前10:00から深夜12:00まで |
| 年齢制限 | 来場者は21歳以上；21歳未満は保護者の同伴が必要 |
| 禁止事項 | 学校の制服を着た子どもの入場は認められない |
| 費用 | *ジュークボックス*1台につき月額RM10 |
| 保証金 | RM200（*ジュークボックス*1台につき一回限り） |

娯楽許可を申請する前でさえ、申請者はまず会社を登録し、DBKLから施設許可及び看板許可を取得する必要がある。関係するPBTによっては、施設は通常、警察や消防といった他の当局の支持も得る必要がある。

## 「娯楽許可」は一つのライセンスだけなのか？

いいえ。生演奏やカラオケのある施設を開業する経営者は、同時に複数の独立した承認に直面することがある：

- **PBTからの娯楽施設許可** — その場所で娯楽活動を営むための基本的な許可。
- **公開演奏許可（Lesen Persembahan Awam、Public Performance Licence）** — Music Authors' Copyright Protection（MACP）Berhadのような著作権団体から取得するもので、DJやカラオケの夜の客による演奏を含め、著作権のある楽曲が生演奏される場合に必要となる。報告されている費用は、顧客数及びその演奏が事業の主要な呼び物であるかどうかによって、年間**RM1,200からRM27,000**の範囲である。
- **録音音楽に関するMACPライセンス** — 著作権のある音楽が施設内で再生される場合に必要となる。レストランの場合、報告されている費用は年間**RM847からRM1,376**程度である。

著作権ライセンス（MACP）は、PBTの娯楽許可とはまったく異なるものであることに注意されたい。一方は音楽家の権利に関するものであり、もう一方は施設を運営する許可に関するものである。両方が同時に適用されることがある。

## なぜ規則は州ごとに異なるのか？

娯楽ライセンスの権限はPBTに委ねられているため、全国で統一された規則集は存在しない。各議会は、営業時間、学校や礼拝施設からの最低距離、許可される娯楽の種類、来場者の年齢制限について、それぞれ独自の附例を定めている。

つまり、ある地域では深夜遅くまで営業できるカラオケセンターも、別の地域ではより早い閉店時刻に従わなければならないことがある。センシティブな地域から必要とされる最低距離も、議会によって異なる。経営者にとって、これは一つの重要なことを意味する：施設が所在するPBTの附例を確認すべきであり、ある都市の条件が別の都市にも適用されると想定してはならない。
