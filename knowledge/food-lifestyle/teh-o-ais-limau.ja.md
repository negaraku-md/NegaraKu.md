「teh tarik」と注文すれば、マレーシアのコーヒー店の、こくがあって泡立つミルキーな
象徴が出てくる。「teh-O ais limau」と注文すれば、その対極が出てくる。ミルクなし、
泡なし、ただ冷たい紅茶を、小さな緑のライムの鋭く芳しい果汁で切ったものだ。うだるような
午後には、多くの人にとってそれはより良い飲み物であり——どの mamak でももっとも多く
注文されるグラスの一つである。

## teh-O ais limau とは何か

teh-O ais limau は **アイスのライムティー** だ。濃い紅茶をブラック（ミルクなし）で、
氷の上に注ぎ、ライムで引き締める。teh tarik が練乳で濃くて甘いのに対し、これは軽く、
酸味があり、すっきりしている——ごちそうというより、のどを潤すものだ。紅茶はたいてい
甘くされ、残りはライムが担い、この飲み物に明るい柑橘の香りと、暑さのなかでとりわけ
引き立つ酸味の縁を与える。それは実のところ、teh tarik のミルクなしの、柑橘の従兄弟だ。
引っ張る茶の原型は [teh tarik](/ja/food-lifestyle/teh-tarik)で詳しく扱っている。

それがこの国のより広い飲み物の品揃えのなかでどこに位置するかについては、
[マレーシアの飲み物](/ja/food-lifestyle/malaysian-drinks)のハブを参照されたい。

## 名を、一語ずつ

この注文の妙は、名が *そのまま* レシピだという点にある。各語はコーヒー店の暗号における
修飾子だ。

| 語 | 意味 |
| --- | --- |
| teh | 紅茶 |
| O | ブラック——ミルクなし |
| ais | 氷入り（「peng」とも聞かれる） |
| limau | ライム |
| kosong | 砂糖なし（任意の追加） |
| panas | 温かい（温かい版向け） |

だから「teh-O ais limau」はそのまま *紅茶、ブラック、氷入り、ライム添え* と読め、
「teh-O limau panas」は温かい版だ。甘くしたくない？ **kosong** を加える。
「teh-O ais limau kosong」。*O*、*C*、*kosong*、*gao*、*peng* の全論理はカウンターの
あらゆる飲み物に通じており、
[kopi、teh tarik、コーヒーショップの飲み物](/ja/food-lifestyle/kopi-teh-tarik-and-coffeeshop-drinks)
案内に示されている。

### 「O」の意味

物語のある唯一の語が **O** だ。これは紅茶（やコーヒー）がブラックで、ミルクなしで
供されることを示す——が、それがどこから来たのかは議論がある。もっとも一般的な説明は、
それが **Hokkien の「黒い」という語** だというもので、一部の説は代わりに
**「original（オリジナル）」** と解する。どちらの読みも流通しているので、その論争を
書き留めて先へ進むのが最善だ。実際には、「O」は常にミルクなしを意味する。

## どのライムが入るか

そのライムはただのライムではない。マレーシアは仕事ごとに数種類の異なる柑橘を使い分け、
teh-O ais limau に通常入るのは、小さく丸く、強く芳しい **calamansi**——マレー語で
*limau kasturi* ——だ。その果汁は鋭く酸っぱく、皮は香り高く、それこそがこの飲み物に
独特の高まりを与えるものだ。大きく味の淡い西洋のライムに替えれば、それはもう同じ
グラスではない。

## なぜ mamak の定番なのか

teh-O ais limau がその地位を得るのは、この上なく平明な理由による。安く、ノンアルコール
で、ミルクなしで、きわめて清々しい——それが、卓の誰にとっても注文しやすい一杯にし、
暑さのなかで teh tarik が重く感じられるときの自然な選択肢にする。それはコーヒー店の
メニューの残りと同じ、24 時間営業の、腰を据えて語り合う世界に属している——その制度
そのものについては [kopitiam と mamak の文化](/ja/food-lifestyle/kopitiam-mamak-culture)を
参照されたい。
