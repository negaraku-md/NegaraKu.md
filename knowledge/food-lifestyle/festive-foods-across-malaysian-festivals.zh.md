沿着马来西亚的日历从年头走到年尾，你换的不只是日期——你换的是厨房。这个月弥漫着仁当与竹筒糯米饭的椰浆香；几个月后，餐桌上摆满被高高捞起、众人齐声喝彩的生鱼沙拉；接着轮到酥脆的木鲁古螺旋，最后是被剖开、倒出热腾腾鸡肉的竹筒。

本文不是每个节庆的历史——那些各有专文。它是一趟**餐桌**之旅：每个重大庆典的标志佳肴，以及把它们全都串在一起的一项习俗。

## 是什么把马来西亚的节庆餐桌串在一起？

在提起任何一道菜之前，先说它的习俗：**开放门户**（rumah terbuka）。在每个重大节庆，主人都向亲戚、邻居与朋友敞开大门，让人们前来大快朵颐。据沙巴州立图书馆，家家户户"向亲戚、朋友与邻居敞开家门，以各式传统佳肴款待宾客"。

在马来西亚，这项习俗往往跨越族群——来自不同社群的宾客受邀而至。但有一点很重要：**桌上的内容因主人而异**。开斋节的餐桌坚持清真食物；某些家庭的屠妖节餐桌完全素食；丰收节与卡马丹节的餐桌上有着别人家没有的米酒。正是那些佳肴，诉说着是谁在款待。

## 开斋节（Hari Raya Aidilfitri）：马来粽、竹筒糯米饭与仁当

斋戒一个月之后，节庆餐桌上摆满了耗时又需要协力才能备好的佳肴。据沙巴州立图书馆，其中的传统佳肴包括：

- **马来粽（Ketupat）**——把米压实在棕榈叶编织的容器里，煮至紧实，然后切片。
- **竹筒糯米饭（Lemang）**——糯米与椰浆放进竹筒里慢火烹煮。
- **仁当（Rendang）**——肉与香料、椰浆一同久炖。
- **节庆糕点（Kuih raya）**——各式甜糕点与饼干。

马来粽与竹筒糯米饭很少单独食用；两者都配着仁当或花生酱。它们的准备工作——挤椰浆、编织粽套、看顾竹筒糯米饭数小时不熄的炭火——本身就成了节庆前的家庭盛事。

## 农历新年：鱼生与「捞生」

马来西亚没有哪道农历新年佳肴比**鱼生**（或称 *lou sang*）更"声势热闹"。据 The Rakyat Post，它是一道粤式生鱼沙拉——生鱼切成薄片，拌入切丝的蔬菜、调味料与各种配料——在新年首十五天作为开胃菜端上。

让它与众不同的是它的仪式。每一种食材都带着吉祥的寓意，一边加进盘里一边念出。据 The Rakyat Post：

| 食材 | 象征意义 |
| --- | --- |
| 生鱼 | 丰盛与富贵 |
| 红萝卜 | 鸿运当头 |
| 白萝卜 | 事业机遇 |
| 油（绕圈淋下） | 财源从四面八方而来 |
| 酸梅酱 | 生活与家庭情谊的甜美 |
| 花生 | 财富 |
| "枕头"薄脆 | 金子 |

当所有食材都淋好，全桌人用筷子把这道菜高高举起，同时高喊吉祥话——这就是*捞生*。据 The Rakyat Post，人们相信**捞得越高，来年运势越好**。同一来源把如今流行的五彩缤纷版本追溯到芙蓉（Seremban）的厨师陆祯发（Loke Ching Fatt），他在1940年代推出更多彩的版本，到1960年代广为流传。

## 屠妖节（Deepavali）：木鲁古、甜点与分享的精神

临近屠妖节，许多家庭的厨房变成了小食工厂。主角是**木鲁古**（murukku）——据 Periuk.my，这种酥脆小食有多种模样：

- **Mullu murukku**——用木鲁古模具压出的锯齿螺旋。
- **Ribbon pakoda**——用鹰嘴豆粉做的薄而扭卷的木鲁古，有时撒上芝麻。
- **Achu murukku**（也叫*玫瑰饼／kuih ros*）——甜而柔软，以椰浆调和，用 *achu* 模具塑形。

在甜的这一边则有**nei urundai**（*酥油*球）、**adhirasam**（红糖色的油炸圈饼）、**payasam**、印度粗面粉饼干与五彩的椰糖果。据 Periuk.my，这些小食是为了分享而准备——在节庆前几天成群结队地制作，再端给前来拜访的宾客与邻居。

## 圣诞节：从西式烤味到沙巴的 hinava

马来西亚的圣诞节鲜少千篇一律。在许多城市家庭，餐桌是混搭的——西式烤味旁摆着在地佳肴。但最鲜明的写照来自婆罗洲。据 Bernama，沙巴的社群会准备这样的佳肴：

- **腌 bambangan（Jeruk bambangan）**——腌渍的本地野芒果，沙巴料理的主食。
- **竹筒鸡（Manok pansuh）**——把鸡放进竹筒里烹煮。
- **生鱼沙拉（Hinava）**——生鱼沙拉。
- **Tuhau**——腌渍的野姜，以及**sambal lada**（辣椒酱）。

Bernama 也记载，比起西方国家的烤火鸡，沙巴许多人更爱享用烤鸡翅与鸡腿，配上米饭与鱼汤。庆典以社群为中心：邻居与亲戚互赠食物、互道祝福，伴随着锣（gong）与*kulintangan*（铜排琴）的乐声。再一次，是开放门户的习俗——带着在地的风味。

## 丰收节与卡马丹节：收割、竹筒料理与米酒

婆罗洲的两个收割节庆——砂拉越的**丰收节**（Gawai Dayak）与沙巴的**卡马丹节**（Kaamatan）——共享对稻米收成感恩的主题，它们的餐桌以在地食材与共同烹煮的方式为核心。据 The Star：

| 节庆 | 标志佳肴 | 是什么 |
| --- | --- | --- |
| 丰收节（砂拉越） | 竹筒鸡（Manok pansuh） | 把鸡放进竹筒里烹煮 |
| 丰收节（砂拉越） | Ensabi；酸茄（terung asam） | 木薯叶配椰浆；婆罗洲酸茄配熏鱼 |
| 丰收节（砂拉越） | Nuba laya；sinamu | 用叶子包裹的捣压米饭（Lun Bawang 族）；腌渍后以辣椒煎炒的什料 |
| 卡马丹节（沙巴） | 生鱼沙拉（Hinava） | 沙巴式"ceviche"——生马鲛鱼配青柠、姜与苦瓜 |
| 卡马丹节（沙巴） | Linopot | 用 *doringin* 叶包裹的芋头饭 |
| 卡马丹节（沙巴） | Bosou；pinarasakan | 腌渍的鱼／肉；鱼配 bambangan 慢炖 |

串起这两张餐桌的是它们的饮品。The Star 记载了**tuak**（米酒）与各种其他**tapai**（发酵米饮）——包括**montoku**与**tumpung**，用吸管从共享的容器里啜饮。这些米酒是达雅族（Dayak）与卡达山杜顺族（Kadazandusun）的传统；它标志着收割宴席，也不会出现在坚持清真饮品的节庆餐桌上。

也请留意一条细线：**竹筒鸡（manok pansuh）**既出现在丰收节，*也*出现在沙巴的圣诞节。竹筒烹煮的技法超越了单一节庆——它是一门跨越社群与季节、共享的婆罗洲烹饪语言。

## 关于清真、素食与米酒的一点说明

由于节庆餐桌诉说着是谁在款待，聪明的宾客会稍加留意。开斋节的餐桌坚持清真食物——没有猪肉，没有酒。某些家庭在屠妖节端出完全素食的餐点。Tuak、montoku 与 tumpung 等米酒是相关社群丰收节与卡马丹节传统中正当的一部分，但在别人家则不会预期见到。

并不存在单一的"马来西亚餐桌"，而这正是它的意义所在。开放门户并非要把佳肴统一——它是要邀请他人品尝那些标志着你家的味道。
