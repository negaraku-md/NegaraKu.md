一部在 YouTube 上疯传的电影，或许从未经过电影审查局——但同一部电影，若要在电影院放映，就必须先取得它的批准盖章。这种差异并非无意间的宽松；它内建于马来西亚法律如何管控公众可以看到什么的方式之中。

对普通观众而言，这套制度呈现为海报上的一个字母或数字：U、P12、13、16 或 18。在那个符号背后，有一个官方机构、一部法令，以及另一套独立的规则——后者进而决定一家卡拉OK中心能否在你家隔壁的店铺开张。

## 谁在电影抵达电影院之前批准它？

电影审查局（LPF）——即电影审查处——是内政部（KDN）辖下的一个部门。它的权力来自 **《2002年电影审查法令》（第620号法令）**。

根据 KDN，LPF 负责确保「所有在马来西亚制作、生产、拥有、保管、控制、放映、展示或销售的电影及电影宣传材料」都已先经过该局审查和批准。这不仅仅指剧情片——预告片和电影广告材料也同样受制于相同的程序。

当一部电影被提交时，LPF 可作出三种决定之一：

- **无删减批准** — 不作任何删剪即予批准
- **经修改批准** — 批准，但删剪或修改特定部分
- **不批准放映** — 完全驳回

在批准之后，电影才会被赋予年龄分级。因此你在马来西亚电影院观看的每一部电影，实际上都经过了两层决定：内容获批准，然后年龄被设定。

## U、P12、13、16 和 18 是什么意思？

今天的分级制度称为 **《2023年电影分级》**，自 **2023年2月2日** 起生效，由内政部长拿督斯里赛夫丁纳苏迪安（Datuk Seri Saifuddin Nasution Ismail）宣布。

这套制度在此前仅使用三个级别（U、P13 和 18）的旧制度基础上，新增了三个类别——P12、13 和 16。据 KDN 表示，其目的是在保护儿童免受不适合内容影响的同时，维护成年观众选择电影的自由。

| 分级 | 适合对象 |
| --- | --- |
| **U** | 所有年龄层 |
| **P12** | 所有年龄，但12岁以下观众需父母/监护人指导 |
| **13** | 13岁及以上观众 |
| **16** | 16岁及以上观众 |
| **18** | 18岁及以上观众 |

最重要须理解的区别在于字母「P」和单一数字之间。**P12 不是年龄限制**——12岁以下儿童仍可观看，只是需要有人陪同。相反，**13、16 和 18 是真正的年龄限制**：低于所述界限的观众不应被允许入场。

## 为什么互联网上的电影看起来「更宽松」？

这正是马来西亚电影法律中最大的不对称之处。LPF 的放映前批准程序适用于供公众观赏的电影——例如电影院放映——包括其预告片和广告。

然而，同样的预先批准程序 **不适用于** 通过互联网发行的电影，也不适用于其他媒体形式，如印刷材料以及视觉与表演艺术。这意味着一部电影可以在网上出现而从未经过 LPF，而其电影院版本却必须接受审查。在线内容并非完全自由——它仍受制于其他形式的监管——但它没有经过与电影院相同的放映前审查关卡。

与电影审查相关的罪行并非小事。未经适当执照或批准而拥有、发行或放映电影，是《2002年电影审查法令》下的刑事罪行，惩罚为 **罚款介于 RM5,000 至 RM30,000 之间，和/或最长3年的监禁**。

## 谁批准一家卡拉OK中心开张？

这里正是公众经常混淆之处：LPF **不** 为卡拉OK中心、夜总会或娱乐场所发放执照。这项权力属于该场所营业地区的 **地方政府（PBT）**——市政局、市议会或县议会——依据各自的娱乐地方附例。

由于这项权力属于地方性质，其条件因地区而异。吉隆坡提供了一个清晰的例子。对于家庭卡拉OK中心，吉隆坡市政局（DBKL）设下如下条件：

| 事项 | DBKL 条件（家庭卡拉OK） |
| --- | --- |
| 地点 | 不得靠近住宅区、学校、医院、大学或宗教场所 |
| 营业时间 | 上午10:00 至午夜12:00 |
| 年龄限制 | 访客须21岁及以上；21岁以下须有监护人陪同 |
| 禁令 | 不允许身穿校服的儿童入内 |
| 费用 | 每台 *点唱机（jukebox）* 每月 RM10 |
| 押金 | RM200（每台 *点唱机* 一次性缴付） |

即使在申请娱乐执照之前，申请人也须先注册公司并向 DBKL 取得场所执照和招牌执照。视所涉的 PBT 而定，场所通常还需取得警方和消防等其他当局的支持。

## 「娱乐执照」只是一张执照吗？

不是。一名开设现场音乐或卡拉OK场所的经营者，可能同时面对多项独立的批准：

- 来自 PBT 的 **娱乐场所执照** — 在该地点经营娱乐活动的基本许可。
- 来自版权机构如马来西亚音乐作者版权保护（MACP）有限公司的 **公开演出执照（Public Performance Licence）** — 当有版权歌曲被现场演出时（包括由 DJ 或卡拉OK之夜的顾客演出）所需。据报费用介于每年 **RM1,200 至 RM27,000** 之间，视顾客数量以及演出是否为该业务的主要卖点而定。
- **MACP 录制音乐执照** — 当有版权音乐在场所内播放时所需。对餐馆而言，据报费用约为每年 **RM847 至 RM1,376**。

请注意，版权执照（MACP）与 PBT 的娱乐执照完全不同。前者关乎音乐人的权利；后者关乎经营场所的许可。两者可同时适用。

## 为什么各州的规则各不相同？

由于娱乐执照发放权交给了 PBT，全国并没有一套统一的规则手册。每个议会都自行制定关于营业时间、与学校和宗教场所的最短距离、允许的娱乐类型以及访客年龄限制的地方附例。

这意味着，在某个地区可以营业到深夜的卡拉OK中心，在另一个地区可能须遵守更早的打烊时间。距离敏感区域所需的最短距离也因议会而异。对经营者而言，这意味着一件重要的事：查阅场所所在 PBT 的地方附例，而不要假设某座城市的条件适用于另一座城市。
