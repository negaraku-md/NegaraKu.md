ペナンで誰かに夜遅くどこで食べられるかと尋ねれば、答えはたいてい二語で返ってくる
——ナシ・カンダー。湯気の立つ一皿のごはん、汗をかいたカウンターの奥にはカレーの
並んだガラスケース、そして最後の決定的な動作——ごはんがほとんど見えなくなるまで、
全体にグレービーがかけられる。屋台料理から一つの伝統へと育ったこの料理が、どのよう
にしてそうなったかの物語は、ジョージタウンの波止場から全国各地の24時間カウンター
へと続いている。

## ナシ・カンダーとは実際に何か

もっとも簡単に言えば、ウィキペディアの言葉を借りれば、ナシ・カンダーとは「蒸した
ごはんに、それぞれ異なる各種のカレー、付け合わせ、グレービーを組み合わせたもの」
である。ペナンに根ざし、インドから来たタミル系ムスリムの商人によってもたらされた
マレーシア北部の料理だ。

注文すること自体が一つの儀式である。カウンターに近づき、欲しいものを指さす——
ここにフライドチキンを一切れ、そこにイカをひとすくい、オクラをひとすくい——すると
給仕があなたの目の前で皿を組み立てる。一人前に決まったレシピはない。皿はあなたの
指さす先に合わせて盛りつけられる。この自分で選ぶ、並んで選ぶという形式こそ、この
料理が現代のファストフードのカウンターの先駆けと呼ばれる理由だ。休憩が短く、何が
食べたいかがはっきりしている労働者に向いている。

栄養面では、バランスの取れた働く人の食事として読み取れる——炭水化物のごはん、
たんぱく質のカレー卵・鶏肉・魚・牛肉、そして付け合わせにオクラや生の青唐辛子などの
野菜。これは偶然ではない。体力を必要とする人のために作られたものなのだ。

## 「Banjir」：ごはんを氾濫させる

ナシ・カンダーの真骨頂はグレービーにある。**Banjir** はマレー語で「氾濫した」を
意味し、起きていることをそのまま言い表している。一種類のソースではなく、複数の
カレーのグレービーの混合がごはんにかけられ、味が互いに染み合い、二口として同じ味
がしない。

この混ぜ合わせこそが肝心だ。良いカウンターは複数のカレー——魚、マトン、鶏、ダール
（dhal）——を、それぞれの深みをもって用意しており、あなたが別の注文をしない限り、
給仕はそれらをあなたのごはんの上で混ぜる。伝統的にはごはんと付け合わせを一枚の皿
に盛り、グレービーをごはんに直接かけた。今では多くの店が付け合わせを小さなメラミン
の器に盛るが、ごはん自体は今も氾濫させられる。皿を *banjir* にしてくれと頼むのは、
フルの仕立てを頼むということだ。

## 波止場から天秤棒へ：ペナンのタミル系ムスリムのルーツ

ナシ・カンダーは生まれながらにして港湾労働者の料理だ。1900年代初頭、放浪する
インド系ムスリムの行商人が、ジョージタウンの賑やかな海辺 **Weld Quay** の労働者に
カレーとごはんを売っていた。最初期の皿は質素なものだった——ナスやオクラ入りの魚
カレー、揚げたカレー牛肉、揚げ魚、ゆで卵一個——で、値段はそれぞれ五セントほど
だった。

名前はそれがどう売られていたかを記録している。初期の行商人は、食べ物を **kandar**
と呼ばれる長い木の天秤棒で担いだ。一方の端にごはんの鍋、もう一方の端にカレーを
吊るし、売り手が客の間を歩くにつれ前後で釣り合わせた。（マレー語では *mengandar* が
荷を肩に担ぐことを意味し、ウルドゥー語の *kandha'* は肩を意味する。）*The Star* が
語り直したある起源譚では、Hameediyah の背後にいた香辛料商人が Campbell Street の店
の裏手で料理していたという——植民地時代の規則は衛生上の懸念から店内での食品販売を
好まなかった——そしてカレーを天秤棒に吊るしたかごに入れ、通りの向かいの日陰まで
運んだ。その方法が料理に名前を与えたのだ。

その行商人たちはペナンのインド系ムスリム共同体に属していた。彼らは商人で、その
子孫は今日 **mamak** として知られている。彼らは何世紀にもわたってこの地域一帯で
香辛料を商い、カレー作りを携えてきた。やがて商いは定着した。行商人は桟橋の腰掛け
から屋台や路地へと移り、1930年代を通じて戸別に売り歩き、1970年代からはますます
本格的な店を構えるようになった。天秤棒は消え、言葉は残った。この同じインド系
ムスリムの食文化が、より広い [kopitiam と mamak の飲食](/ja/food-lifestyle/kopitiam-mamak-culture)
の世界を支えている。

## 料理と付け合わせ

ナシ・カンダーの楽しみの半分はカウンターでの選択にある。その品揃えは大きくインド系
ムスリムに寄っており、揚げ物が汁気のあるカレーと釣り合っている。よく目にする料理
のいくつかを挙げる。

| 料理 / 付け合わせ（マレー語） | それは何か |
| --- | --- |
| Ayam goreng | フライドチキン。多くは下味をつけてカリッと揚げたもの |
| Sotong goreng | イカのフライ |
| Udang goreng | エビのフライ |
| Telur ikan | 魚卵。通常はカレー風味または揚げたもの |
| Telur | ゆで卵または目玉焼き。最初期からこの料理の一部 |
| Kari kambing | マトンカレー |
| Kari daging / kari limpa | ビーフカレー / 牛の脾臓のカレー |
| Bendi | オクラ。多くはグレービーの中またはグレービーに添えて |
| Terung / peria | ナス / ニガウリ |
| Papadom | パリッとした豆のせんべい |

これら以外にも、カウンターはハニーチキン、オニオンチキン、カレーレバーといった品で
その幅を見せつけ、ごはん自体も普通の蒸しごはんのこともあれば、ビリヤニ（biryani）
やトマトライスのような味つきの *nasi* のこともある。変わらないのは、上からかけられる
グレービーだ。

## 名店と24時間の習慣

いくつかのペナンの名が、この料理の代名詞になっている。ジョージタウンの Lebuh
Campbell にある **Hameediyah** は島最古のナシ・カンダー店として知られ、その物語は
1907年までさかのぼる。今も創業家の後の世代によって営まれている。Penang Road の
そばの路地に身を潜める **Line Clear** はもう一つの誰もが知る名で——長年24時間営業の
店として知られ、2017年に発表された World Street Food Masters のリストで第9位に
ランクされた。両店とも、営業許可をめぐる争いから衛生検査まで、長く続く飲食店に
ありがちな騒動を乗り越えてきており、どちらも今なお行列を引き寄せている。

ナシ・カンダーのアイデンティティの一部は、*いつ* 食べられるかにある。多くの mamak
店は非常に長い時間営業しており、昼夜を問わないカウンターがこの料理の魅力の中心だ
——真夜中過ぎに、熱くて腹を満たす一皿のために立ち寄れる場所。（どの一店の営業時間
も時とともに変わりうるので、名前の挙がった店が今も24時間営業だと思い込むより、
わざわざ出かける前に確認する価値がある。）Kayu や Pelita といった全国的に知られた
名が、その常に開いていてカウンターで注文するという形式を、ペナンをはるかに越えて
広げた。

## マレーシア全土にどう広まったか

Weld Quay の労働者のための食べ物として始まったものが、今やマレーシア社会のあらゆる
階層で食べられている。その広がりは二つの道をたどった。第一に、mamak の店主たちが
ジョージタウンの外に常設の店を構えた——たとえばケダでは、ある有名なアロースターの
店が、その常設の店舗を独立の日そのものである1957年8月31日にさかのぼるとしている。
第二に、この形式はチェーンへと拡大した。ブランド化され、しばしば24時間営業の
ナシ・カンダー店が、指さして選ぶカウンターを全国の都市に置いた。

純粋主義者はチェーン店が本来のペナンの皿に匹敵するかをめぐって議論するが、その議論
自体が、この料理がどれほど遠くまで旅してきたかの証しである。ナシ・カンダーは今、
国の他の名物と並んでマレーシアのアイデンティティの指標として堂々と腰を据えている
——肩に天秤棒をかけた一人の男まで、ずっとさかのぼってたどれる料理として。
