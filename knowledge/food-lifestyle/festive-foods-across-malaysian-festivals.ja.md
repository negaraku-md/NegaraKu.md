マレーシアの暦を一年の端から端までたどると、変わるのは日付だけではない——台所が変わるのである。ある月はルンダンと椰子ミルクのレマンの香りが漂い、数か月後には、人々が歓声を上げながら高く掬い上げる生魚サラダで食卓が埋め尽くされる；やがてパリパリとしたムルクの渦巻きの番が来て、最後には竹筒が割られ、熱々の鶏肉が取り出される。

本稿は各祭りの歴史ではない——それについては別稿がある。これは**食卓**をめぐる旅である：それぞれの主要な祝祭を象徴する料理と、それらすべてを結びつける一つの作法をたどる。

## マレーシアの祝祭の食卓を結びつけるものは何か

一つの料理に触れる前に、まずその作法について述べよう：**オープンハウス（rumah terbuka）**である。すべての主要な祭りにおいて、主人は親戚、隣人、友人に向けて扉を開き、食事でもてなす。サバ州立図書館によれば、家々は「親戚、友人、隣人に向けて家の扉を開き、さまざまな伝統料理で客をもてなす」という。

マレーシアでは、この作法はしばしば民族の垣根を越える——さまざまなコミュニティからの客が招かれ、実際に訪れる。しかし重要な点が一つある：**食卓の中身は主人によって異なる**ということだ。ハリラヤの食卓はハラルな食品を守る；ディーパバリの食卓は、家庭によっては完全にベジタリアンである；ガワイとカアマタンの食卓には、他の家にはない発酵米飲料がある。その料理こそが、誰がもてなしているのかを物語っている。

## ハリラヤ・アイディルフィトリ：クトゥパット、レマン、ルンダン

1か月にわたる断食の後、ハリラヤの食卓は、時間と協力を要して準備される料理で満たされる。サバ州立図書館によれば、伝統料理には次のようなものがある：

- **クトゥパット（Ketupat）**——ヤシ科の葉で編んだ容器に米を詰めて煮込み、固く仕上げてから切り分ける。
- **レマン（Lemang）**——もち米と椰子ミルクを竹筒の中でじっくりと炊く。
- **ルンダン（Rendang）**——肉を香辛料と椰子ミルクでじっくりと煮込む。
- **クイ・ラヤ（Kuih raya）**——さまざまな甘い菓子とビスケット。

クトゥパットとレマンは単独で食べられることは少なく、どちらもルンダンやピーナッツソース（kuah kacang）と組み合わせられる。その準備——椰子ミルクを絞り、クトゥパットの袋を編み、レマンの竹筒の炭火を何時間も見守ること——それ自体が、ハリラヤを迎える前の家族の行事となる。

## 旧正月：イーサンと「ロウサン」

マレーシアの旧正月料理の中で、**イーサン**（または*ロウサン*）ほど「賑やかな」ものはない。The Rakyat Postによれば、これは広東式の生魚サラダであり——薄く切った生魚に、細切りにした野菜、調味料、さまざまな添え物を混ぜ合わせたもので——新年最初の15日間、前菜として供される。

これを特別なものにしているのは、その儀式である。それぞれの具材が縁起の良い意味を持ち、皿に加えられるたびにその意味が唱えられる。The Rakyat Postによれば：

| 具材 | 象徴的な意味 |
| --- | --- |
| 生魚 | 豊かさと繁栄 |
| ニンジン | 幸運 |
| 大根 | 仕事の機会 |
| 油（円を描くように注ぐ） | あらゆる方向から富がもたらされる |
| 梅ソース | 人生と家族の絆の甘さ |
| ピーナッツ | 富 |
| 「枕」形のクラッカー | 黄金 |

すべての具材が注ぎ終わると、食卓を囲む人々は箸でその料理を高々と掲げ、縁起の良い言葉を唱和する——これが*ロウサン*である。The Rakyat Postによれば、**高く掲げるほど、来る年の運勢が良くなる**と信じられている。同資料は、今日人気の色鮮やかなバージョンを、スレンバン（Seremban）の料理人ロク・チンファット（Loke Ching Fatt）に結びつけている。彼は1940年代により色彩豊かなバージョンを考案し、1960年代までに広く普及した。

## ディーパバリ：ムルク、甘味、そして分かち合いの精神

ディーパバリが近づくと、多くの家庭の台所は小さな軽食工房へと姿を変える。その主役は**ムルク**——Periuk.myによれば、さまざまな形で登場するパリパリとした軽食である：

- **ムッル・ムルク（Mullu murukku）**——ムルク用の型で作る、ギザギザした渦巻き形。
- **リボン・パコダ（Ribbon pakoda）**——ひよこ豆粉で作る、薄く撚られたムルクで、ゴマを振りかけることもある。
- **アチュ・ムルク（achu murukku）**（*クイ・ロス／kuih ros* とも呼ばれる）——甘くやわらかく、椰子ミルクを混ぜ込み、*アチュ（achu）*型で成形する。

甘い側には、**ネイ・ウルンダイ（nei urundai）**（*ギー*の団子）、**アディラサム（adhirasam）**（黒糖色の揚げ輪菓子）、**パヤサム（payasam）**、セモリナ粉のビスケット、そして色とりどりのココナッツキャンディーが並ぶ。Periuk.myによれば、これらの軽食は分かち合うために用意される——祭りの数日前にみなで集まって作られ、訪れる客や隣人にふるまわれる。

## クリスマス：西洋風の焼き料理からサバ州のヒナバまで

マレーシアのクリスマスは、画一的であることがほとんどない。多くの都市部の家庭では、食卓は混ざり合っている——西洋風の焼き料理の隣に地元の料理が並ぶ。しかし最も鮮明な姿はボルネオ島から見えてくる。Bernamaによれば、サバ州のコミュニティは次のような料理を用意する：

- **ジェルック・バンバンガン（Jeruk bambangan）**——地元の野生マンゴーの漬物で、サバ料理の主食。
- **マノック・パンスー（Manok pansuh）**——鶏肉を竹筒の中で調理する。
- **ヒナバ（Hinava）**——生魚のサラダ。
- **トゥハウ（Tuhau）**——野生ショウガの漬物、そして**サンバル・ラダ（sambal lada）**（唐辛子ソース）。

Bernamaはまた、西洋諸国の七面鳥の丸焼きに対して、サバ州の多くの人々は焼いた鶏の手羽や腿肉をご飯と魚スープと共に楽しむと記している。祝い方はコミュニティを中心に据える：隣人と親戚が食べ物と挨拶を交わし、ゴング（gong）と*クリンタンガン（kulintangan）*の音楽が伴う。ここでもまた、オープンハウスの作法である——地元の風味を添えて。

## ガワイとカアマタン：収穫、竹筒料理、そしてトゥアック

ボルネオ島の二つの収穫祭——サラワク州の**ガワイ・ダヤック**とサバ州の**カアマタン**——は、稲の収穫への感謝という主題を共有しており、その食卓は地元の食材と共同での調理法を軸とする。The Starによれば：

| 祭り | 象徴的な料理 | それは何か |
| --- | --- | --- |
| ガワイ（サラワク州） | マノック・パンスー（Manok pansuh） | 鶏肉を竹筒の中で調理したもの |
| ガワイ（サラワク州） | エンサビ（Ensabi）；テルン・アサム（terung asam） | 椰子ミルクで煮たキャッサバの葉；燻製魚を添えたボルネオ式の酸味ナス |
| ガワイ（サラワク州） | ヌバ・ラヤ（Nuba laya）；シナム（sinamu） | 葉に包んだ搗き米（ルン・バワン族の料理）；漬け込んでから唐辛子で炒めた具材 |
| カアマタン（サバ州） | ヒナバ（Hinava） | サバ風の「セビーチェ」——生のサワラに、ライム、ショウガ、ニガウリを合わせたもの |
| カアマタン（サバ州） | リノポット（Linopot） | *ドリンギン（doringin）*の葉で包んだタロイモ入りご飯 |
| カアマタン（サバ州） | ボソウ（Bosou）；ピナラサカン（pinarasakan） | 漬け込んだ魚／肉；バンバンガン（bambangan）と煮込んだ魚 |

両方の食卓を結びつけているのは、その飲み物である。The Starは、**トゥアック（tuak）**（米酒）と、その他さまざまな**タパイ（tapai）**——中でも、共有の容器から管で吸って飲む**モントク（montoku）**と**トゥンプン（tumpung）**——を記録している。これらの発酵米飲料はダヤック族とカダザンドゥスン族の伝統であり、収穫の宴を象徴するもので、ハラルな飲み物を守る祝祭の食卓には登場しない。

また、一つの細やかなつながりにも注目してほしい：**マノック・パンスー**はガワイ*にも*、サバ州のクリスマス*にも*登場する。竹筒で調理する技法は一つの祭りにとどまらない——それはコミュニティと季節を越えて共有される、ボルネオの料理の言語なのである。

## ハラル、ベジタリアン、そしてトゥアックについての一言

祝祭の食卓は誰がもてなしているのかを物語るがゆえに、賢明な客は少し注意を払う。ハリラヤの食卓はハラルな食品を守る——豚肉はなく、酒もない。ディーパバリでは、完全にベジタリアンの料理を供する家庭もある。トゥアック、モントク、トゥンプンのような発酵米飲料は、該当するコミュニティにとってはガワイとカアマタンの伝統の正当な一部であるが、他の家では見られるとは限らない。

単一の「マレーシアの食卓」というものは存在せず、それこそが意味するところである。オープンハウスは料理を均一化することではない——それは、あなたの家族を象徴するものを、他の人にも味わってもらうよう招くことなのである。
