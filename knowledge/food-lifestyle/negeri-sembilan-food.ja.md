Seremban や Rembau で料理を注文すると、食卓にひとつの色が繰り返し戻ってくる。
ココナッツミルクで薄く、唐辛子で騒がしい、輝くような、ほとんど蛍光の黄緑色の
グレイビーだ。これが masak lemak cili api であり、それは Negeri Sembilan の台所
について知っておくべきことのほとんどを物語る——半島のほかの地域を見やるのと同じ
だけ、マラッカ海峡の向こうのスマトラを見やる料理である。

## Minangkabau のルーツと adat perpatih の食卓

Negeri Sembilan の料理は、この州に定住したのが誰かということと切り離せない。
そのマレー人の人口は、その祖先を西スマトラ高地の Minangkabau の人々にたどる。
彼らは海峡を渡って移住し、この地域に食と社会秩序の両方を与えた。マレーシアの
Jabatan Kebudayaan dan Kesenian Negara（JKKN）が維持する文化遺産記録は、この
州を「Gulai Lemak Chili Api で有名」と形容し、この料理を Minangkabau の影響から
生まれた Negeri Sembilan の伝統的マレー料理の象徴として枠づけている。同じ記録は
その移住を14世紀としているが、本格的な定住がいつ根づいたかについては歴史家の
あいだで見解が分かれるため、正確な年表は慎重に扱うのがよい。

Minangkabau とともに *adat perpatih* がやって来た。土地と祖先の財産が女系を通じて
受け継がれる、母系の慣習体系である。それは今なお Negeri Sembilan、Melaka、Johor
の一部における家族生活と土地保有を形づくっており、この州の料理が母から娘へと
受け継がれてきた文化的枠組みでもある。ここでの食は、[マレー料理](/ja/food-lifestyle/malay-cuisine)
の地域的な一変種であると同時に、そのスマトラの遺産の生きた表現でもある——マレー
シアのより広い[地域・民族料理](/ja/food-lifestyle/regional-and-ethnic-cuisines)
の地図上で、より際立った項目の一つだ。

## Masak lemak cili api：州を代表する料理

Negeri Sembilan に一つだけ料理があるとすれば、それは **masak lemak cili api**
だ——*masak lemak cili padi* とも書かれ、州の方言では *masak lomak lado api* と
呼ばれ、その色から *gulai kuning*（「黄色の gulai」）と呼ばれることもある。その核心
は、ココナッツミルクと生ターメリックの煮込みで、鷹の爪唐辛子で強く火を入れ、明る
く汁気のあるグレイビーに煮詰めたものだ。Wikipedia の項目はこれを「伝統的な Negri
料理において最も決定的な料理」と呼んでおり、その描写には反論しがたい。

その大きな強みは融通の利くことだ。このグレイビーは一つのレシピというよりは一つ
の手法であり、ほぼどんな主材料でも受け止める。牛肉（*daging*）、鶏肉（*ayam*）、
薫製肉（*salai*）、ナマズ（*ikan keli*）のような淡水魚、エビ、*siput sedut*（田螺）、
そしてさまざまな野菜——その中には *pucuk ubi*（キャッサバの新芽）、シダの若芽
（*pucuk paku*）、未熟のジャックフルーツ、タケノコがある。よく知られた取り合わせ
の一つ *daging salai masak lemak* は薫製牛肉をグレイビーに入れ、もう一つの
*ayam masak lemak cili api* は鶏肉を使う。食の書き手 Abirami Durai が The Star で
述べたように、それは「Minang の定番」であり、「Negri のどのマレー人家庭も、おそらく
自分たちの版を持っているだろう」。より濃厚で乾いたカレーとは違い、これはご飯の上に
たっぷりとすくいかけるための、ゆるいグレイビーなのだ。

## ターメリックと鷹の爪唐辛子：二つの決め手の風味

二つの食材がほとんどの仕事をこなし、どちらも訪問者を驚かせるほどの気前のよさで
使われる。第一は**生ターメリック**（*kunyit*）であり、乾燥粉末ではない——グレイ
ビーに特徴的な鮮やかな黄緑色と、すっきりとした土の苦みを与えるのがこれだ。
The Star が公開したある家庭のレシピは、masak lemak cili api ayam 一鍋に15cm の
生ターメリックを求めており、その分量は規模の感覚を伝えてくれる。

第二は**鷹の爪唐辛子**——*cili api* または *cili padi* で、この料理に名前と辛さ
を与える、小さく激しい唐辛子だ。同じレシピはそれを11本使う。The Star が描くよう
に、Negeri Sembilan のスタイルの際立った特徴は、調味ではなく技法における抑制に
ある。料理人はしばしば「cili padi とターメリックだけ」を使い、重いスパイスペースト
を先に *tumis*（炒める）せず、二つの看板の香味料をココナッツミルクを通してあり
のままに語らせる。その結果は、近隣のほとんどの州の料理よりも辛く、ターメリックが
前面に出て読める料理である——より広い[マレーシアのカレー](/ja/food-lifestyle/malaysian-curries)
の一族のいとこでありながら、それとは異なる存在だ。

## Daging salai：薫製肉の伝統

Negeri Sembilan は薫製肉の国でもある。**Daging salai**——締まり、濃く、香り高く
なるまで薫製にした牛肉——は、州南部の Pedas と Rembau 一帯と強く結びついた名物で、
そこでは路傍のレストランがそれで評判を築いてきた。Free Malaysia Today はそれを、
「ふつうカレーのグレイビーか sambal belacan とともに供される」薫製牛肉の料理と
形容し、その薫香は存在するが圧倒するほどではないとする。

最も多いのは、薫製肉が州を代表するグレイビーで仕上げられ、*daging salai masak
lemak* になることだ。牛肉の薫香がココナッツと唐辛子の土台を貫いて走る。Pedas の
ような村はそのためのちょっとした食の目的地となり、地元流に調理された薫製肉を食べ
るためだけに南北高速道路を降りる食客を引き寄せている。薫製は牛肉を保存すると同時
に、生肉では得られない深みを加える——冷蔵に先立つこの技法は、味覚の問題として
生き残ってきた。

## Rendang、Negeri Sembilan 流

Minangkabau の国であるがゆえに、Negeri Sembilan は [rendang](/ja/food-lifestyle/rendang)
の遺産も分かち合っている。Minangkabau がこの地域一帯に運んだ、じっくり煮込んだ
乾いた肉のカレーだ。この州自身の版は、しばしば重いドライスパイスの配合よりも香味
料——生姜、ガランガル、レモングラス、そしてたっぷりのココナッツミルク——に依ると
形容される。もっとも説はさまざまで、この区別は地元の料理資料と照合して確認するの
がよい。正確なバランスがどうであれ、rendang は Negeri Sembilan の食卓で masak
lemak と並んで心地よく収まる。同じスマトラの系譜の二つの表現——一方は乾いた濃縮
の煮込み、他方はゆるく火を噴くグレイビーだ。

ご飯とともに——そしてしばしば *ulam*（生のハーブと野菜）や sambal とともに——これ
らの料理は、明らかにマレー風でありながら紛れもなく地元的な一食をなす。ココナッツ
の糸は国民的定番の [nasi lemak](/ja/food-lifestyle/nasi-lemak) にも通っており、
各地域がそれをそれぞれの目的に曲げていくとしても、ココナッツがマレーシア料理全体
でいかに中心的であるかを思い出させてくれる。

## Lemang と祝祭の食卓

Negeri Sembilan の食についての記述は、祝祭の食卓なしには完結しない。そこで
**lemang** は誉れある位置を占める。もち米はココナッツミルクとともにバナナの葉を
敷いた中空の竹に詰められ、濃厚でかすかに薫香のある棒状に固まるまで直火でじっくり
焼かれ、それから切り分けられて rendang や *serunding*（肉でんぶ）とともに食され
る。マレー世界全体の Hari Raya やその他の祝い事での定番である lemang は、この州
が祝祭で rendang や Minangkabau に根ざした他の料理を重んじることを思えば、ここ
ではとりわけ重みを帯びる。

まとめれば、その祝いの食卓——lemang、rendang、daging salai、そして一つか二つの
masak lemak cili api の鍋——は、ひとつの考えをさまざまに表現したものとして読める。
ココナッツ、火、そして煙を、スマトラの人々が携えてきてこの州に名を与えた九つの
*luak* の中で自分たちのものにした技法を通じて、こしらえたものだ。
