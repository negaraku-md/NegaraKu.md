毎年年末になると、約1,140万人のユニット保有者が同じ発表を待つ——Amanah Saham Bumiputera（ASB）の年間分配金はいくらになるのか。これは国家の経済政策に深く根ざした金融上の恒例行事であり、その背後にはPermodalan Nasional Berhadという機関が存在する。

## PNBとは何か、どのように始まったのか

Permodalan Nasional Berhad（PNB）は、政府の新経済政策（Dasar Ekonomi Baru、DEB）の手段として1978年3月17日に設立された。これは、ブミプトラ（Bumiputera）社会における株式資本の保有を育成するために設立されたYayasan Pelaburan Bumiputra（YPB）の1978年1月9日の設立に先立つものである。

PNBの公式サイトによると、その使命はブミプトラ社会および全マレーシア国民の経済的豊かさを高め、国家の繁栄に資することにある。その基本的な仕組みは単純である。マレーシアの大企業の株式を取得して信託ファンドに移し、それをより手頃な小口のユニットとして投資家に再販売するというものだ。

その1年後、1979年5月22日にAmanah Saham Nasional Berhad（ASNB）が、PNBの全額出資によるユニット・トラスト運用会社として設立された。PNBはこれらのファンドの投資マネージャーであり続ける一方、ASNBはユニット保有者と直接やり取りするファンドマネージャーとして機能する。

## ASNBとそのファンドの役割は何か

ASNBは18のユニット・トラストファンドを運用しており、これらは大きく2つのカテゴリーに分かれる。

- **固定価格ファンド** — ASBおよびAmanah Saham Malaysia（ASM）を含み、1ユニットあたりの価格はRM1.00に維持される。
- **変動価格ファンド** — ASN Equity、ASN ImbangおよびASN Sara等を含み、ユニット価格は市場価値に応じて変動する。

ASNBの事業規模は、国内業界でも最大級である。以下の表は、PNBが2025年12月19日付で発表したプレスリリースに基づく主要な数値をまとめたものである。

| 指標 | 数値（2025年時点） |
| --- | --- |
| PNB運用資産（AUM） | RM3,640億（4.5%増） |
| ASNBのユニット・トラストファンド数 | 18ファンド |
| 流通ユニット数 | 約2,800億ユニット |
| 唯一口座保有者数 | 1,300万 |
| ASNB支店数 | 32支店 |
| 代理店（銀行含む） | 2,700以上 |
| ASNB分配総額（2025年） | RM153億 |

注：同じプレスリリースは、その企業向け注記の中で流通ユニット数を「約2,800億ユニット、1,500万口座にまたがる」と述べる一方、本文では**唯一口座保有者数**が1,300万であるとしている。この差異は、一個人が複数の口座を保有し得ることを反映しているが、出典内では整合が取られておらず、人によるレビューでの確認が必要である。

## ASBはどのように機能するのか

Amanah Saham Bumiputeraは1990年1月2日に開始された。その主な特徴は、ASBの公式な商品概要書（Product Highlights Sheet、PHS）に記載されているとおりである——ただし投資家の適格基準は例外で、これはASNBのProspektus Induk（基本目論見書）に詳細が定められており、PHSには**記載されていない**。

- **ファンド区分：** 混合資産（*Mixed Asset*）。ファンドの種類はインカム型。
- **ユニット価格：** 1ユニットあたりRM1.00の固定価格。**資本保証**ファンドではない。
- **適格性：** ブミプトラ個人——マレー人、サバ州およびサラワク州の先住民、ならびにオラン・アスリ——に開かれている。この適格基準はASNBのProspektus Indukに記載されており、ASBのPHSには記載されていない。
- **資産配分：** 株式に最大90%、その他の資産クラスに最大50%、現金または流動性資産に最低5%。
- **ベンチマーク：** Maybankの12カ月定期預金金利。
- **年間管理報酬：** ファンド純資産価値の年率0.35%（信託証書上は最大1.0%まで認められている）。
- **受託者：** AmanahRaya Trustees Berhad。

2026年5月25日より、ASBは2つのユニットクラスを導入した。クラスA（ザカート控除なし）とクラスB（ムスリム投資家向けのザカート支払い機能付き）である。両クラスとも、同一の固定価格ファンドとしての特徴を維持する。

## ASBの分配金はいくらで、どのように計算されるのか

2025年12月31日に終了した会計年度（FY2025）について、ASNBはASBの収益分配として**1ユニットあたり5.75セン**を宣言した。この支払総額は**RM104億**にのぼり、**1,140万人のユニット保有者**が対象となった——これはASB設立以来最高の年間分配額である。この数字により、ASBの収益分配の累計総額はRM2,067億に達した。

PNBのプレスリリースによると、ASBの分配金の算定は、ファンドの会計年度を通じて保有された**平均最低月次残高**に基づく。分配率は保証されておらず、ファンドが実現した利益や市場環境によって上下し得る。

以下の表は、PNBのプレスリリースで報告された、直近3会計年度のASBの1ユニットあたり分配金を示す。

| 会計年度（12月31日） | 1ユニットあたり分配金（セン） |
| --- | --- |
| 2025 | 5.75 |
| 2024 | 5.75 |
| 2023 | 5.25 |

注：ASBのPHSでは、この年間の主要な数値は2つの構成要素（収益分配＋ボーナス）に分けて表示されており、合計すると同じ主要な料率になる。PNBのプレスリリースは、上記のとおり統合された主要な数値を表示している。

FY2025において、ベンチマークであるMaybankの12カ月定期預金金利は平均2.29%を記録し（PNBのプレスリリースによると、2025年11月28日までの平均値）、ASBの分配金とベンチマークとの利ざや（*spread*）は346ベーシスポイントとなった。（ASBのPHSは同期間について2.28%というベンチマーク数値を掲載しており、この小さな差異は確認が必要である。）この実績は、地場株式市場が厳しい環境にある中で達成されたものであり、同プレスリリースの本文によれば、FBM KLCIは2025年の年初来で-0.3%の価格リターンを記録した。

## LEAP-6戦略計画とは何か

LEAP-6は、PNBの現行の戦略計画である。PNBグループの社長兼グループ最高経営責任者によると、2025年は同計画の実施2年目にあたる。示された優先事項には、顧客の純流入を拡大すること、ユニット保有者に持続可能な収益分配を届けること、そしてPNBの自己資本を強化することが含まれる。

その結果、PNBのAUMは2025年に4.5%増加し、RM3,640億に達した。PNBは、**2027年までにAUM RM4,000億**という目標達成に向けて順調に進んでいると述べている。その投資戦略には、グローバル資産、プライベート投資、不動産への分散が含まれる。PNBはまた、世界の資本市場の不確実性を受け、2026年の投資見通しについて慎重な姿勢を示している。

## PNBは経済政策の枠組みの中でどのような位置づけか

本節は構造を説明することを目的としており、それを評価するものではない。PNBおよびASBは、DEBに由来するアファーマティブ・アクションの枠組みの中に存在する——PNBの公式資料に述べられているとおり、この政策の根本的な目標は、ブミプトラの株式資本保有を育成し、貧困を削減することにある。

ASNBのファンド構造は、この使命の2つの側面を反映している。ASBシリーズのようなファンドは、Prospektus Indukに定められた適格基準に基づき、ブミプトラの投資家に特化している。同時に、PNBは自らの役割をより広く位置づけている——すなわちブミプトラ社会**および**全マレーシア国民に資することであり——その運用ポートフォリオにはASNBが運用する他のファンドも含まれる。

このような対象を絞った株式保有政策は、マレーシアで続く公共政策論議の一部であり、その設計や影響については様々な立場から異なる見解が示されている。本記事はこの点について特定の立場を取るものではなく、公式な情報源に基づき、これらの機関とファンドがどのように組織され、機能しているかを説明するにとどまる。
