マレーシアの兵士と水兵は皆、給与の一部を同じ場所に積み立てている——そしてその資金は長年にわたり、負債を抱えたあるコングロマリットの命運に左右されてきた。それがLTATとBoustead Holdingsの物語である。

## LTATとは何か、誰を守っているのか

軍人積立基金局（Lembaga Tabung Angkatan Tentera、LTAT）は**1973年軍人積立基金法（Akta Tabung Angkatan Tentera 1973、Akta 101）**に基づき設立された法定機関である。[マレーシア軍](/government/malaysian-armed-forces-mindef)（ATM）人員のための退職金基金として機能しており——軍人版の従業員積立基金（KWSP）に相当する。

強制拠出者（下士官兵、Lain-Lain Pangkat）については、**月給の10%**が拠出として控除され、政府がさらに**15%**を上乗せする——毎月合計25%の給与相当額が積み立てられる。任意拠出者は月額**RM25からRM2,000**の範囲で拠出できる。

近年、拠出者への還元は安定している。2023会計年度、LTATは123,380名の拠出者に対し**5%**・**RM48,508万**の配当を宣言した。2025会計年度には配当が**5.35%**（RM52,474万）に上昇した——2017年以降で最高の支払額である。

| 概要 | 詳細 |
| --- | --- |
| 設立根拠法 | 1973年軍人積立基金法（Akta Tabung Angkatan Tentera 1973、Akta 101） |
| 種別 | 法定機関／退職金基金 |
| 強制拠出者 | 給与の10%＋政府15% |
| 任意拠出者 | 月額RM25–RM2,000 |
| 2023会計年度配当 | 5%（RM48,508万、拠出者123,380名） |
| 2025会計年度配当 | 5.35%（RM52,474万） |
| 最高経営責任者 | Mohammad Ashraf Md Radzi |
| 会長 | 退役陸軍大将 Tan Sri Azizan Ariffin |

## BousteadはいかにしてLTATの企業部門となったのか

拠出者の積立金の大部分は、債券や上場株式ではなく**Boustead Holdings Berhad**——プランテーション、製薬、防衛重工業、不動産、貿易にまたがるコングロマリット——に投資されている。

Bousteadの業績が悪化すると、LTATは同社を全面的に買収することを決定した。残る40.58%の株式を1株**85.5セン**（RM70,320万相当）で取得する自主的買収提案を通じて、LTATの持株比率は約**97.63%**まで上昇した。これを受け、Boustead Holdingsは上場規則（Listing Requirements）para 16.07(a)に従い、**2023年6月28日にBursa Malaysiaのメインマーケット（Pasaran Utama）から上場廃止**された。

統合の動きは集団の子会社にも及んだ。Boustead Plantationsは1株**RM1.55**で全面買収された——残る32%を取得するのに約**RM11億1,000万**を要し——LTATおよびBousteadの持株比率は68%から100%へと上昇した。

| 主要な戦略的持株 | 推定持株比率 |
| --- | --- |
| Boustead Holdings Bhd | ~100% |
| Pharmaniaga Bhd（製薬） | ~54.9% |
| Boustead Plantations Bhd（プランテーション） | 100%（上場廃止） |
| Affin Bank Bhd（銀行業） | ~22% |

## なぜLTATは再編が必要なのか

問題は一社の業績不振にとどまらず、基金の構造そのものにある。LTATは低リターン——推定でわずか約**2.9%**——の戦略資産に過度にエクスポージャーを持っており、これに対して固定利付資産へのエクスポージャーははるかに小さい。

以前の再建計画である**Project Moonshot**は2023年以降凍結されており、その結果Boustead集団には約**RM34億**の債務負担が残された。国家歳出委員会（Jawatankuasa Kira-Kira Wang Negara、PAC）は2024年11月、さらなる遅延はLTATに資産処分を強いる可能性があり、Bousteadの財務問題がLTAT基金の最大半分——総資産約**RM115億**のうち拠出者資金約**RM50億**——を侵食しかねないと警告した。

これに代わりLTATが導入したのが**Project Earth**である——理事会は**2024年8月9日**に承認し、**2024年12月13日**に内閣へ報告された。その目標は、3年以内に戦略資産保有比率を約**56%**から**35%**へ引き下げる一方、固定利付資産への配分を20%–25%まで引き上げることである。最高経営責任者Mohammad Ashraf Md Radziによれば、同基金は約**RM136億**の資産を運用しており、段階的な資産の現金化によって「投げ売り」を回避することを目指している——財務が回復した際にはBoustead Plantationsのような子会社の再上場も選択肢に含まれる。

## 今後の展望

Project Earthはまだ実施の初期段階にあり、その成否は拠出者の価値を損なうことなく資産を現金化できるかどうかにかかっている。注視すべき点は、年間配当率（基金の健全性を示す指標）、35%に向けた戦略資産保有比率削減の進捗、Boustead集団の債務解消、そして子会社の再上場の有無である。公式情報についてはLTATの年次報告書および国防省（Kementerian Pertahanan）の発表を参照されたい。
