马来西亚最大的电信故事，并非单一的网络，而是一家拥有六个国家移动运营商部分股权的控股公司。Axiata Group Berhad 坐落于吉隆坡中环（Kuala Lumpur Sentral）的一座办公大楼内，控制、部分持有或共同经营着连接南亚与东南亚数以亿计人口的运营商。

## 概览

Axiata Group Berhad 是一家总部设于马来西亚的区域电信与数码控股公司，在 Bursa Malaysia 上市，股票代码6888。它主要并不以自己的名义经营网络；相反，它持有亚洲各地运营公司（「opcos」）与联营公司的股权，并将它们作为一个投资组合来引导。其最大股东是马来西亚政府的主权财富基金国库控股（Khazanah Nasional），其他国家关联机构——国民投资公司（PNB）与公积金局（EPF）——也位列最大持股者之中（持股据公开来源摘要，无日期；见核实说明）。

该集团的触及范围横跨马来西亚、印度尼西亚、斯里兰卡、孟加拉国与柬埔寨，连同 edotco 电信塔基础设施业务以及 Boost 金融科技平台与 ADA 数据与营销公司等数码单位。

## 历史：从 TM International 到 Axiata

Axiata 的根源在于前国家垄断企业内部。它于1992年6月12日注册成立为 **TM International Berhad**，是 [Telekom Malaysia](/zh/malaysia) 的国际与移动业务部门。在随后数年间，它在亚洲新兴市场各地累积了移动电话业务的股权，并于2008年在 Bursa Malaysia 单独上市。

2009年4月2日，公司更名为 **Axiata Group Berhad**，标志着一个独立于其前母公司的身份，以及一个以区域移动增长、而非马来西亚固网渊源为中心的战略。此名称其后成为其数家运营商所采用的伞状品牌，例如 XL Axiata 与 Dialog Axiata。

## 区域运营公司

Axiata 的结构最好理解为一家持有若干独立管理的运营商股权的母公司，其中数家在各自本土的交易所上市。下表列出主要的移动业务以及 Axiata 的大致持股（数字随时间变动——日期见核实说明）。

| 运营公司 | 国家 | 品牌 / 状态 | Axiata 持股（大致） |
| --- | --- | --- | --- |
| CelcomDigi | 马来西亚 | CelcomDigi（与 Telenor 共同控制） | 约33.1% |
| XLSmart | 印度尼西亚 | XL / Axis / Smartfren（共同控制） | 约34.8% |
| Link Net | 印度尼西亚 | 固定宽带 / 光纤 | 约79.5% |
| Dialog Axiata | 斯里兰卡 | Dialog | 约73.75% |
| Robi Axiata | 孟加拉国 | Robi / Airtel | 约61.82% |
| Smart Axiata | 柬埔寨 | Smart | 约72.48% |

**CelcomDigi（马来西亚）。** Axiata 的本土市场运营商多年来是 Celcom，马来西亚最老的移动品牌之一。2022年11月，Celcom 与 Telenor 的 Digi 合并，缔造出按用户计马来西亚最大的移动运营商 CelcomDigi。Axiata 与 Telenor 各取约33.1%并共同控制合并后的实体；Digi 于2023年2月更名为 CelcomDigi Berhad。此次合并使 CelcomDigi 与 [Maxis](/zh/companies/maxis) 及 U Mobile 在马来西亚市场正面交锋。

**XLSmart 与 Link Net（印度尼西亚）。** Axiata 历史悠久的印尼运营商 XL Axiata 于2025年与对手 Smartfren 合并组成 XLSmart，一家在合并后报告用户基础大幅扩大、共同控制的业务。与之并立的是，Axiata 持有 Link Net 的控股权益，这是一家定位为印度尼西亚第二大「FibreCo」的固定宽带与光纤公司。

**Dialog Axiata（斯里兰卡）。** Dialog 是斯里兰卡的市场领导者。2024年中，它完成了对 Bharti Airtel 斯里兰卡业务的收购与合并，使其报告的用户基础超过2,000万，并以此换取 Bharti 在 Dialog 的少数股权。

**Robi Axiata（孟加拉国）与 Smart Axiata（柬埔寨）。** 在孟加拉国经营 Robi 与 Airtel 品牌的 Robi，以及在柬埔寨的 Smart，构成了前沿市场的投资组合。两者皆为控股持有，并在集团的报告中都是韧性十足的利润贡献者。

## edotco 与基础设施

Axiata 一个独特的部分是 **edotco**，其电信塔业务——即运营商租用以安置天线的实体塔杆、楼顶与电力设备。edotco 是亚洲最大的独立电信塔公司之一；截至2025年，Axiata 持有其约63%，国库控股与退休基金（KWAP）持有其余部分。Edge Malaysia 2025年10月的一篇报道，在诸如以 US$940 million 收购约13,000座巴基斯坦电信塔等交易之后，将 edotco 各市场的组合规模列为「超过47,000座电信塔」。

由于电信塔是一种资本密集、产生现金、有别于运营网络的资产，edotco 屡屡出现在 Axiata 的资产负债表规划中，包括据报为减少集团债务而将部分股权变现之举。

## 规模与重要性

Axiata 形容自身服务着一个非常庞大的区域客户群——公司在2019年将这一数字列为亚洲各地约1.5亿，其后透过合并与市场扩张而增长。就截至2025年9月30日止九个月而言，该集团报告利润 RM403.3 million，并一直强调削减控股公司债务与简化其投资组合。

该集团对马来西亚的重要性体现在三个层面。它是国库控股投资组合的旗舰，因此其表现关系到国家财政实力。它是马来西亚资本与管理专长进入快速增长的亚洲电信市场的渠道。而透过 CelcomDigi，它对马来西亚自身的移动与5G格局至关重要，该格局由马来西亚通讯及多媒体委员会（MCMC）监管。

## 为何重要

对任何梳理马来西亚经济的人而言，Axiata 是一个案例，展示一家前国有垄断企业的分支如何成为泛亚洲的投资者。其控股公司模式——持有股权而非始终直接经营网络——意味着关于「Axiata」的头条往往实际上关乎某一特定运营公司（马来西亚的 CelcomDigi、斯里兰卡的 Dialog），或一项投资组合举措（将 XL 与 Smartfren 合并、出售 edotco 电信塔）。弄清一则消息属于哪一层，是正确解读这个集团的关键。
