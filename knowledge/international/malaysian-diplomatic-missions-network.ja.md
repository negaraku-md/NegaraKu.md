リマでパスポートを紛失する、ドーハで逮捕される、あるいはソウルで文書の公証が
必要になる——そのとき実際に助けてくれる窓口は、85か国に広がる111のマレーシア
公館ネットワークの一つの拠点にすぎない——そのすべてが、プトラジャヤの外務省
（Wisma Putra）から統括されている。

## マレーシアの海外ネットワークはどれほどの規模か？

外務省は、その海外におけるプレゼンスをいくつかの公館タイプに分類している。
合計すると**85か国に111の公館**となる。

| 公館の種類 | 数 | 内容 |
| --- | ---: | --- |
| 大使館 | 66 | 非英連邦加盟国におけるマレーシアの主要公館 |
| 高等弁務官事務所 | 18 | 英連邦加盟国における大使館に相当する公館 |
| 総領事館 | 21 | 主要都市に置かれる、総領事が率いる次席公館 |
| 領事館 | 2 | より小規模な領事拠点 |
| 国連常駐代表部 | 2 | マレーシアの国連向け公館 |
| ASEAN常駐代表部 | 1 | マレーシアの地域機構向け公館 |
| マレーシア友好貿易センター | 1 | 正式な外交関係を維持していない場合の事実上の公館 |

「大使館」と「高等弁務官事務所」の区別は、最もよく人を混乱させる点である。
両者はいずれも一国の最上位公館であり、同格の使節——大使または高等弁務官——
が率いており、行う業務も同じである。マレーシアは、派遣先が他の英連邦加盟国
（英国、インド、シンガポール、オーストラリアなど）である場合に**高等弁務官
事務所**を、それ以外のすべての場合に**大使館**を用いているにすぎない。

## 公館はどのような領事サービスを提供しているか？

公館の任務は政府間の外交だけではない。海外にいる一般のマレーシア人にとって、
大使館、高等弁務官事務所、総領事館はマレーシア政府の窓口である。中核となる
領事サービスは、各公館を通じておおむね共通している。

| サービス | 内容 |
| --- | --- |
| パスポート | 公館の管轄区域に居住する国民のマレーシア国際パスポートの更新 |
| 緊急証件（SPC） | パスポートを紛失、失効、または失効間近の際にマレーシアへ帰国するための片道渡航文書 |
| 公証・認証 | 真正な写しの証明、文書の認証、商業送り状および公式文書の認証 |
| 登録 | オンラインのe-Consularシステムを通じた、管轄区域に居住するマレーシア人の登録 |
| 困難時の援助 | 逮捕、入院、犯罪被害、その他海外で困難に陥ったマレーシア人への支援 |

政府自身の案内は、最も一般的な緊急事態について率直に述べている：マレーシア
人が旅行中にパスポートを紛失した場合、帰国への道筋は最寄りの公館と**緊急証件
（Sijil Perakuan Cemas、SPC）**であり——即日再発給のパスポートではない。これは
マレーシアへの帰国の旅程のみに有効な、一回限りの文書である。

すべてのサービスがすべての駐在公館で行われるわけではない。小規模な領事館は
公証業務や緊急対応を扱う一方、パスポートの完全な手続きは上級の大使館へ回す
ことがあるため、渡航前に該当する公館のページを確認することが重要である。

## どの公館がどの国を管轄しているか？

各公館には**管轄区域**——その公館が責任を負う国、時には特定の地域——が
割り当てられている。一つの大使館が近隣の複数の国を同時に管轄することは珍しく
なく、そのため常駐の大使館がない国にいるマレーシア人は、近隣国の首都にある
公館によって対応される。総領事館の場合はさらに細分化される：大国においては、
ある都市の総領事館が特定の州や省のみを管轄し、残りは首都の大使館が管轄する
ことがある。

実務上のポイントは次のとおりである：「ここにはマレーシア大使館がない」と
決めつける前に、その国を管轄している公館を確認すること。たいていの場合存在
する——ただし、必ずしも国境の内側にあるとは限らない。

## マレーシアにある外国大使館については？

往来は双方向である。数十の外国政府がマレーシアに常駐の大使館や高等弁務官
事務所を維持しており、その圧倒的多数が**クアラルンプールとプトラジャヤ**に
集中している。また、複数の国がペナン、ジョホールバル、コタキナバル、クチン
といった地方都市でも領事館を運営している。一部の国は、クアラルンプールに
常駐公館を置かず、他のアジアの首都から大使を兼轄させている。

現在誰が駐在しているかを示す権威ある登録簿が**『外交・領事名簿』（Diplomatic
and Consular List）**であり、外務省の儀典局（Protocol Department）が発行して
いる。これは、マレーシアに常駐するすべての外国公館の認定外交官・領事官に
加え、名誉領事や国際機関の上級職員を記録しており、同省のポータルを通じて
無料で発行されている。

## 次のステップ

海外へ渡航するマレーシア人であれば、出発前に渡航先を管轄する公館とその領事
連絡先を控えておくこと——それが必要になる瞬間（パスポートの紛失、逮捕、
文書の公証）は、たいてい探し始める余裕のある瞬間ではない。外国の外交官の
所属を特定したい、あるいはマレーシアに派遣されている公館を確認したい場合は、
外務省の『外交・領事名簿』が参照すべき登録簿である。そして、あなたの関心が
国民への対応ではなく海外への輸出振興にあるならば、それは大使館ではなく、
[MATRADE](/ja/government/matrade)の貿易事務所という並行のネットワークを
通じて行われる。
