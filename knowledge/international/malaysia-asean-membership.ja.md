1967年8月8日、5人の男たちがバンコクの外務省本館の大広間に集まり、2ページの文書に
署名した。そのうちの一人、マレーシア副首相トゥン・アブドゥル・ラザク・フセイン
（Tun Abdul Razak Hussein）は、この国の外交政策の主要な枠組みとして今後およそ60年
にわたって機能することになる組織――そしてマレーシア自身が2025年に議長国を務める
ことになる組織――にマレーシアを位置づけつつあった。

## 概観：ASEANにおけるマレーシア

| | |
| --- | --- |
| 正式名称 | Association of Southeast Asian Nations（東南アジア諸国連合） |
| 設立 | 1967年8月8日、タイ・バンコク |
| 創設文書 | ASEAN宣言（バンコク宣言） |
| マレーシア署名者 | トゥン・アブドゥル・ラザク・フセイン（当時の副首相） |
| 現在の加盟国数 | 11カ国 |
| 法定文書 | ASEAN憲章（2008年12月15日発効） |
| 組織構造 | ASEAN共同体の三本の柱（2015年12月31日以降） |
| 事務局 | インドネシア・ジャカルタ |
| マレーシアの議長国歴 | 5回――1977年、1997年、2005年、2015年、2025年 |

マレーシアは単なるASEAN加盟国ではない。この組織を最初に築いた5カ国のうちの一つで
あり、ASEANのおよそ60年の歴史はマレーシアの外交政策の歴史と密接に絡み合っている。

## ASEANはどのように始まり、マレーシアはどのような役割を果たしたか？

ASEAN（東南アジア諸国連合）は、1960年代の東南アジアの地政学的不安――地域対立、
冷戦の緊張、そして大国の介入を受けずに自国間の関係を管理する必要に迫られた新独立
国家群――から生まれた。その解決策は軍事同盟ではなく、地域協力のためのフォーラム
であった。

バンコク宣言には5人の外相が署名した：アダム・マリク（Adam Malik、インドネシア）、
トゥン・アブドゥル・ラザク・フセイン（マレーシア）、ナルシソ・R・ラモス（Narciso
R. Ramos、フィリピン）、S・ラジャラトナム（S. Rajaratnam、シンガポール）、タナッ
ト・コーマン（Thanat Khoman、タイ）である。この5人は後にASEANの「建国の父」と呼ば
れるようになった。マレーシアにとって、この参加は今日まで続く一つの原則を確立した：
地域による解決を優先すること、近隣諸国の内政に干渉しないこと（内政不干渉）、そし
て協議による一致（コンセンサス）によって意思決定を行うことである。

この宣言は、この地域における経済成長の加速、社会的進歩、文化発展を促進すること、
そして地域の平和と安定を育むことを目標として掲げた。それは意図的に簡潔かつ拘束力
のないものとされた――これは「ASEAN方式」（the ASEAN Way）として知られる特徴である。

## 今日のASEAN加盟国は？

1967年の5カ国から、ASEANは11カ国へと拡大した。以下は各加盟国とその加入日である：

| 加盟国 | 加入日 |
| --- | --- |
| インドネシア | 1967年8月8日（創設国） |
| マレーシア | 1967年8月8日（創設国） |
| フィリピン | 1967年8月8日（創設国） |
| シンガポール | 1967年8月8日（創設国） |
| タイ | 1967年8月8日（創設国） |
| ブルネイ・ダルサラーム | 1984年1月7日 |
| ベトナム | 1995年7月28日 |
| ラオス（Lao PDR） | 1997年7月23日 |
| ミャンマー | 1997年7月23日 |
| カンボジア | 1999年4月30日 |
| 東ティモール | 2025年10月26日 |

東ティモール（Timor-Leste）の加入は、1999年以来ASEANにとって初めての拡大である。
これはマレーシアの議長国任期中に確定した：東ティモールを第11の加盟国として受け入
れる決定は2025年5月の第46回ASEAN首脳会議で行われ、東ティモール加入宣言は2025年
10月26日、クアラルンプールで開催された第47回ASEAN首脳会議の開会式で署名された。

## ASEAN憲章とは何か、なぜ重要なのか？

最初の40年間、ASEANは正式な憲章を持たずに運営されていた。それはASEAN憲章によって
変わった。

この憲章は、2007年11月20日にシンガポールで開催された第13回ASEAN首脳会議において
10の加盟国の首脳によって署名され、すべての加盟国による批准を経て2008年12月15日に
発効した。憲章は初めて、政府間組織としてのASEANに**法人格**を付与した――これは
ASEANが今や単なる緩やかな国家の集合体ではなく、独立した法的実体となったことを意味
する。

憲章が行ったこと：

- ASEANの目標、原則、価値観を法的拘束力のある文書とした。
- 内政不干渉、主権平等、協議とコンセンサスによる意思決定といった中核原則を維持した。
- 制度構造を定めた――ASEAN首脳会議、調整理事会、共同体理事会、そして事務局。
- ASEAN共同体形成の基盤を築いた。

マレーシアにとって、この憲章は、南シナ海紛争からミャンマー危機に至るまでの地域的
な課題を、その場しのぎの経路ではなく一つの公式な場に持ち込むことを可能にする枠組
みを、さらに強化するものであった。

## ASEAN共同体の三本の柱とは何か？

2015年12月31日、ASEANは正式に**ASEAN共同体**を設立し、三本の柱に沿って組織した。
各柱にはそれぞれ独自の行動計画がある。

| 柱 | 焦点 | マレーシアにとっての意味 |
| --- | --- | --- |
| ASEAN政治・安全保障共同体（APSC） | 平和、安定、紛争解決、地域規範 | 南シナ海やミャンマーなど安全保障問題のためのフォーラム |
| ASEAN経済共同体（AEC） | 単一の市場と生産基盤――財、サービス、投資、資本、技能の自由な移動 | 6億人を超える地域市場へのアクセス |
| ASEAN社会・文化共同体（ASCC） | 教育、保健、環境、文化、災害対応 | 市民同士の協力と社会的保護 |

経済の柱（AEC）は、おそらくマレーシア企業への影響が最も顕著である。その構想は、
加盟国それぞれ分離した経済を単一の市場と共同の生産基盤に置き換え、企業が地域を横
断する産業ネットワークを構築し、グローバル・サプライチェーンに参加できるようにす
ることである。シンガポール政府の経済教育ポータル（SG101）によれば、AECはこの地域
の約6億人の消費者へのアクセスを開いている。AECはまた、RCEP（[地域的な包括的経済連携](/international/malaysia-rcep)）
のようなより広範な貿易協定の基盤ともなっており、これによりASEANは中国、日本、韓国、
オーストラリア、ニュージーランドといったパートナーと統合されている。

## ASEANの主要機関：誰が決定するのか？

ASEANはしばしば中央集権的な官僚機構であると誤解される。実際には、加盟国主導で議
長国が輪番制をとる組織である。

**ASEAN首脳会議**は最高位の政策決定機関であり、国家元首または政府首脳を一堂に集
める。通常、議長国を務める国において年2回開催される。

**ASEAN事務局**はインドネシアのジャカルタを拠点とし、1976年のASEAN事務局設立に関
する協定を通じて設立された。ASEANの決定の実施を調整・支援するが、加盟国に対する
強制力は持たない。

**ASEAN事務総長**が事務局を率いる。現職は第15代事務総長のカオ・キム・ホーン博士
（Dr. Kao Kim Hourn）で、2023年1月に就任し、この職に就いた初めてのカンボジア国民
である。

**ASEAN議長国**は、加盟国名の英語アルファベット順に毎年交代する。議長国は首脳会
議を主催し、その年のテーマと優先事項を定め、主要な会議を主宰する。これが、2025年
にマレーシアを主導的な立場に置いた仕組みである。

## 2025年ASEAN議長国としてのマレーシアの役割

マレーシアは2025年、1977年、1997年、2005年、2015年に続く**5度目**のASEAN議長国を
務めた。議長国の座は、2024年10月にビエンチャンで開催された第44回・第45回ASEAN首
脳会議の終わりにラオスから引き継がれ、議長国任期は2025年1月1日に正式に始まった。
アンワル・イブラヒム首相（Anwar Ibrahim）がその年を通じてこの地域圏を率いた。

テーマは**「Inclusivity and Sustainability」**（包摂性と持続可能性）であった。こ
のテーマの選択には意味がある：2025年はASEAN共同体設立10周年にあたり、今後20年間
の方向性を定める自然な節目であった。[マレーシア財務省](/government/ministry-of-finance-treasury)
によれば、マレーシアはその年、全国で300を超える主要な会議・プログラムを主催した。
Bernamaの報道によれば、年末までに三本の柱すべてにわたるASEAN関連会議の最終的な合
計は約320回に達した。

公式情報源および通信社の報道によれば、マレーシアの2025年議長国任期中の主な出来事
には、次のものが含まれる：

- **東ティモールの第11加盟国としての加入**――2025年10月にクアラルンプールで開催
  された第47回首脳会議で確定した。1999年以来ASEANにとって初めての拡大である。
- **ASEAN共同体ビジョン2045の採択**――テーマは「Resilient, Innovative, Dynamic,
  and People-Centred ASEAN」（強靭で、革新的で、力強く、人を中心としたASEAN）であ
  り、2025年5月26日にクアラルンプールで開催された第46回ASEAN首脳会議で、ASEAN2045
  に関するクアラルンプール宣言とともに採択された。このビジョンは今後20年間のASEAN
  の方向性を描いている。マレーシア外相ダト・スリ・モハマド・ハサン（Datuk Seri
  Mohamad Hasan）は、下院（Dewan Rakyat）での発言（2025年2月6日）において、マレ
  ーシアをこのビジョンの「恒久的な羊飼い」（permanent shepherd）と表現した――これ
  は政府によるマレーシアの役割の描写的な呼称であり、法定の公式な役職ではない。
- **クアラルンプール平和合意（Kuala Lumpur Peace Accord）**――カンボジアとタイの
  間で、2025年10月26日、第47回ASEAN首脳会議に合わせてクアラルンプールで署名され
  た。アンワル・イブラヒム首相のもとで2025年ASEAN議長国を務めたマレーシアは、こ
  の署名の主催者かつ仲介者となった（米国のドナルド・トランプ大統領も共同で立ち会
  った）。この合意により国境監視団が設置され、拘束されていた18人のカンボジア兵士
  の解放につながった。
- 新たなプラットフォームの主催――**第2回ASEAN・GCC首脳会議**および初の**ASEAN・
  GCC・中国首脳会議**であり、いずれも2025年5月27日、第46回ASEAN首脳会議に合わせ
  てクアラルンプールで開催された。これにより地域の外交的な広がりが拡大した。

マレーシアは2025暦年を通じてASEAN議長国を務めた。2025年10月28日の第47回ASEAN首
脳会議閉会式において、議長槌はフィリピンに引き継がれたが、フィリピンが正式に議長
国を務めるのは2026年1月1日からである。

## ASEANを正しく理解するための枠組み

ASEANが複雑なのは、それが意図的に緩やかに構築されているためである。ASEANに関す
るどのような問題も正確に読み解くには、次の3つの問いを順に立てるとよい：

1. **どの柱に属するか？** 安全保障問題（南シナ海、ミャンマー）はAPSCの下に、貿易・
   投資問題はAECの下に、災害・教育・文化問題はASCCの下に位置づけられる。柱によっ
   て、関与する会議や担当官が決まる。
2. **どの機関に属するか？** 重要な政策決定は首脳会議から出され、日常的な調整は事
   務局から行われる。事務局の声明を、加盟国を拘束する決定と誤解しないよう注意する
   必要がある。
3. **拘束力があるか？** ASEANの成果の大半は宣言や行動計画であり、強制執行可能な
   法律ではない。憲章には拘束力があるが、首脳会議の声明の多くは政治的なコミット
   メントの性質を持つ。

## マレーシアとASEANに関するよくある誤解

- **マレーシアがASEANに「加盟した」と考えること。** マレーシアは1967年にASEANを
  創設したのであり、後になって加盟したのではない。
- **ASEANの加盟国は10カ国だと考えること。** その数字は2025年10月までは正しかった。
  2025年10月26日の東ティモールの加入以降、ASEANは11の加盟国を擁している。
- **バンコク宣言とASEAN憲章を混同すること。** バンコク宣言（1967年）はASEANを創
  設したものであり拘束力を持たない。ASEAN憲章（2008年発効）がその法定文書である。
- **ASEANを欧州連合（EU）と同一視すること。** ASEANは共通通貨を持たず、超国家的
  な議会も持たず、多数決ではなくコンセンサスによって意思決定を行う。
- **議長国であることが統治権限を与えると考えること。** 議長国は議題を設定し会議
  を主催するが、他の加盟国に強制することはできない。決定には依然として合意が必要
  である。

## 次のステップ

特定の分野をさらに掘り下げたい場合は、自分のニーズに最も関連する柱から始めるとよ
い――経済（AECおよびRCEPのような貿易協定）、安全保障（APSC）、あるいは社会・文化
（ASCC）である。ASEANに関する事実を確認するには、ASEAN事務局の公式ポータル
`asean.org`を、マレーシアの立場については外務省（Wisma Putra）のウェブサイト
`kln.gov.my`を参照されたい。首脳会議に関するニュースを読む際には、ある成果が政治
的な宣言なのか、それとも真に拘束力のある文書なのかを常に確認すること――その違い
は、ASEANが実際にどのように機能しているかを理解する上で重要である。
