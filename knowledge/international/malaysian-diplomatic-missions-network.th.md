answer: "กระทรวงการต่างประเทศของมาเลเซีย (Wisma Putra) คงเครือข่ายคณะผู้แทนทางการทูต 111 แห่งใน 85 ประเทศ คือ สถานเอกอัครราชทูต 66 แห่ง สำนักงานข้าหลวงใหญ่ 18 แห่ง สถานกงสุลใหญ่ 21 แห่ง สำนักงานกงสุล 2 แห่ง ผู้แทนถาวรประจำสหประชาชาติและอาเซียน และศูนย์มิตรภาพและการค้ามาเลเซีย คณะผู้แทนเหล่านี้ดำเนินการทูตและให้บริการกงสุลแก่ชาวมาเลเซียในต่างประเทศ คือ หนังสือเดินทาง เอกสารเดินทางฉุกเฉิน การรับรองเอกสาร การลงทะเบียนพลเมือง และการช่วยเหลือในยามคับขัน ในทิศทางกลับกัน มีสถานทูตและสำนักงานข้าหลวงใหญ่ต่างชาติหลายสิบแห่งประจำในมาเลเซีย กระจุกตัวในกัวลาลัมเปอร์ (Kuala Lumpur) และปุตราจายา (Putrajaya)"

ทำหนังสือเดินทางหายที่ลิมา (Lima) ถูกจับกุมที่โดฮา (Doha) หรือต้องการรับรองเอกสารที่โซล (Seoul) และสำนักงานที่สามารถช่วยท่านได้จริงคือหนึ่งจุดในเครือข่ายคณะผู้แทนมาเลเซีย 111 แห่งที่กระจายอยู่ทั่ว 85 ประเทศ ซึ่งทุกแห่งดำเนินการจาก Wisma Putra ในปุตราจายา (Putrajaya)

## เครือข่ายในต่างประเทศของมาเลเซียใหญ่เพียงใด

กระทรวงการต่างประเทศแบ่งการปรากฏตัวในต่างประเทศของตนเป็นประเภทคณะผู้แทนไม่กี่ประเภท เมื่อรวมกันแล้วเป็น **คณะผู้แทน 111 แห่งใน 85 ประเทศ**

| ประเภทคณะผู้แทน | จำนวน | คืออะไร |
| --- | ---: | --- |
| สถานเอกอัครราชทูต | 66 | คณะผู้แทนหลักของมาเลเซียในประเทศที่ไม่ใช่เครือจักรภพ |
| สำนักงานข้าหลวงใหญ่ | 18 | คณะผู้แทนที่เทียบเท่าสถานเอกอัครราชทูตในประเทศเครือจักรภพด้วยกัน |
| สถานกงสุลใหญ่ | 21 | คณะผู้แทนรองในเมืองใหญ่ นำโดยกงสุลใหญ่ |
| สำนักงานกงสุล | 2 | สำนักงานกงสุลขนาดเล็กกว่า |
| ผู้แทนถาวรประจำสหประชาชาติ | 2 | คณะผู้แทนของมาเลเซียประจำสหประชาชาติ |
| ผู้แทนถาวรประจำอาเซียน | 1 | คณะผู้แทนของมาเลเซียประจำกลุ่มภูมิภาค |
| ศูนย์มิตรภาพและการค้ามาเลเซีย | 1 | คณะผู้แทนโดยพฤตินัยในที่ที่ไม่ได้คงความสัมพันธ์อย่างเป็นทางการ |

การแยกระหว่าง "สถานเอกอัครราชทูต" และ "สำนักงานข้าหลวงใหญ่" เป็นสิ่งที่ทำให้ผู้คนสับสนบ่อยที่สุด ทั้งสองเป็นคณะผู้แทนระดับสูงสุดของประเทศ ทั้งสองนำโดยทูตที่มีระดับเท่ากัน คือ เอกอัครราชทูตหรือข้าหลวงใหญ่ และทั้งสองทำงานเดียวกัน มาเลเซียเพียงใช้คำว่า **สำนักงานข้าหลวงใหญ่** เมื่อประเทศเจ้าภาพเป็นสมาชิกเครือจักรภพอีกประเทศหนึ่ง (สหราชอาณาจักร อินเดีย สิงคโปร์ ออสเตรเลีย และอื่น ๆ) และ **สถานเอกอัครราชทูต** ในที่อื่นทั้งหมด

## คณะผู้แทนให้บริการกงสุลอะไรบ้าง

งานของคณะผู้แทนมิใช่เพียงการทูตระหว่างรัฐบาล สำหรับชาวมาเลเซียทั่วไปในต่างประเทศ สถานเอกอัครราชทูต สำนักงานข้าหลวงใหญ่ หรือสถานกงสุลใหญ่คือเคาน์เตอร์ด้านหน้าของรัฐบาลมาเลเซีย บริการกงสุลหลักค่อนข้างสม่ำเสมอในบรรดาคณะผู้แทน

| บริการ | ครอบคลุมอะไร |
| --- | --- |
| หนังสือเดินทาง | การต่ออายุหนังสือเดินทางระหว่างประเทศของมาเลเซียสำหรับพลเมืองที่พำนักในเขตอำนาจของคณะผู้แทน |
| ใบรับรองฉุกเฉิน (SPC) | เอกสารเดินทางเที่ยวเดียวเพื่อกลับมาเลเซียเมื่อหนังสือเดินทางหาย หมดอายุ หรือใกล้หมดอายุ |
| การรับรองและพิสูจน์เอกสาร | การรับรองสำเนาถูกต้อง การรับรองความแท้ของเอกสาร และการรับรองใบแจ้งหนี้ทางการค้าและเอกสารทางการ |
| การลงทะเบียน | การลงทะเบียนชาวมาเลเซียที่อาศัยในเขตอำนาจผ่านระบบ e-Consular ออนไลน์ |
| การช่วยเหลือในยามคับขัน | ความช่วยเหลือแก่ชาวมาเลเซียที่ถูกจับกุม เข้ารักษาในโรงพยาบาล ตกเป็นเหยื่ออาชญากรรม หรือประสบความยากลำบากในต่างประเทศ |

แนวทางของรัฐบาลเองตรงไปตรงมาเกี่ยวกับกรณีฉุกเฉินที่พบบ่อยที่สุด คือ หากชาวมาเลเซียทำหนังสือเดินทางหายระหว่างเดินทาง เส้นทางกลับบ้านคือคณะผู้แทนที่ใกล้ที่สุดและ **ใบรับรองฉุกเฉิน (Sijil Perakuan Cemas, SPC)** มิใช่หนังสือเดินทางที่ออกใหม่ในวันเดียวกัน เป็นเอกสารใช้ครั้งเดียวที่ใช้ได้เฉพาะการเดินทางกลับมาเลเซีย

มิใช่ทุกบริการที่ดำเนินการจากทุกสำนักงาน สำนักงานกงสุลขนาดเล็กอาจจัดการงานรับรองเอกสารและกรณีฉุกเฉินแต่ส่งการดำเนินการหนังสือเดินทางเต็มรูปแบบไปยังสถานเอกอัครราชทูตที่กำกับดูแล ดังนั้นการตรวจสอบหน้าของคณะผู้แทนที่เฉพาะเจาะจงก่อนเดินทางจึงสำคัญ

## คณะผู้แทนใดดูแลประเทศใด

คณะผู้แทนแต่ละแห่งได้รับมอบหมาย **เขตอำนาจ** คือ ประเทศและบางครั้งภูมิภาคเฉพาะที่รับผิดชอบ สถานเอกอัครราชทูตแห่งเดียวมักได้รับการแต่งตั้งให้ประจำหลายประเทศใกล้เคียงพร้อมกัน ซึ่งเป็นเหตุผลที่ชาวมาเลเซียในประเทศที่ไม่มีสถานเอกอัครราชทูตประจำจะได้รับบริการจากคณะผู้แทนในเมืองหลวงข้างเคียง สถานกงสุลใหญ่จำกัดเรื่องนี้ให้แคบลงอีก คือในประเทศขนาดใหญ่ สถานกงสุลใหญ่ในเมืองหนึ่งอาจดูแลเฉพาะบางรัฐหรือมณฑล โดยสถานเอกอัครราชทูตในเมืองหลวงดูแลส่วนที่เหลือ

ข้อสรุปในทางปฏิบัติคือ ก่อนจะสมมติว่า "ไม่มีสถานเอกอัครราชทูตมาเลเซียที่นี่" ให้ตรวจสอบว่าคณะผู้แทนใดได้รับการแต่งตั้งให้ประจำประเทศนั้น โดยปกติจะมีหนึ่งแห่ง เพียงแต่ไม่ได้อยู่ภายในพรมแดนเสมอไป

## สถานทูตต่างชาติในมาเลเซียเป็นอย่างไร

การจราจรไปทั้งสองทาง รัฐบาลต่างชาติหลายสิบแห่งคงสถานทูตและสำนักงานข้าหลวงใหญ่ประจำในมาเลเซีย โดยกระจุกตัวอย่างท่วมท้นใน **กัวลาลัมเปอร์ (Kuala Lumpur) และปุตราจายา (Putrajaya)** โดยหลายประเทศยังมีสถานกงสุลในเมืองภูมิภาคเช่น ปีนัง (Penang) ยะโฮร์บาห์รู (Johor Bahru) โกตากีนาบาลู (Kota Kinabalu) และกูจิง (Kuching) บางรัฐแต่งตั้งเอกอัครราชทูตจากเมืองหลวงอื่นในเอเชียแทนที่จะคงคณะผู้แทนประจำในกัวลาลัมเปอร์

ทะเบียนที่เชื่อถือได้ของผู้ที่อยู่ที่นี่คือ **บัญชีรายชื่อทางการทูตและกงสุล (Diplomatic and Consular List)** เผยแพร่โดยกรมพิธีการทูตของกระทรวงการต่างประเทศ บันทึกเจ้าหน้าที่ทางการทูตและกงสุลที่ได้รับการแต่งตั้งของทุกคณะผู้แทนต่างชาติที่ประจำในมาเลเซีย พร้อมกงสุลกิตติมศักดิ์และเจ้าหน้าที่อาวุโสขององค์การระหว่างประเทศ และออกให้โดยไม่คิดค่าใช้จ่ายผ่านพอร์ทัลของกระทรวง

## อ่านต่อ

หากท่านเป็นชาวมาเลเซียที่กำลังจะไปต่างประเทศ ให้จดคณะผู้แทนที่ได้รับการแต่งตั้งให้ประจำจุดหมายของท่านและช่องทางติดต่อกงสุลของคณะผู้แทนนั้นก่อนออกเดินทาง เพราะช่วงเวลาที่ท่านต้องการมัน (หนังสือเดินทางหาย ถูกจับกุม เอกสารที่ต้องรับรอง) ไม่ค่อยเป็นช่วงเวลาที่จะเริ่มค้นหา หากท่านพยายามระบุตำแหน่งนักการทูตต่างชาติหรือยืนยันคณะผู้แทนที่ประจำในมาเลเซีย บัญชีรายชื่อทางการทูตและกงสุลของกระทรวงการต่างประเทศคือทะเบียนที่ควรปรึกษา และหากคำถามของท่านเกี่ยวกับการส่งเสริมการส่งออกในต่างประเทศมากกว่าการให้บริการพลเมือง เรื่องนั้นดำเนินผ่านเครือข่ายคู่ขนานของสำนักงานการค้า [MATRADE](/th/government/matrade) มิใช่สถานเอกอัครราชทูต
