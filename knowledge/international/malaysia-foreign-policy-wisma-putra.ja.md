アメリカがマレーシア経済における最大の外国投資家であり、一方で中国が最大の貿易相手国であるとき、開放的な小国にはどちらかに肩入れする余裕はない。だからこそ、マレーシアの外交政策は何十年もの間、口にするのはたやすいが守るのは難しい一つの言葉——中立——に基づいてきた。その均衡を日々守る任務を担う省庁が、Wisma Putraである。

## 実際にマレーシアの外交政策を策定しているのは誰か？

多くの人は「外交政策」が一つの省庁だけの仕事だと考えている。しかし実際には、それは重層的なものである。

外務省——その建物の名にちなんで、より広く**Wisma Putra**として知られる——は、連邦憲法に基づき、マレーシアの外交政策を*実施*し調整する任務を担っており、国際的な場で国益を守り、かつ推進することを目標としている。Wisma Putraは、世界各地にあるマレーシアの大使館、高等弁務官事務所、領事館のネットワークを運営し、国際的な場で国の立場を交渉し、海外のマレーシア国民の福祉を守っている。

しかし、最高レベルの政策決定は同省だけのものではない。それは**首相と内閣**が握っている。首相は公式訪問やサミットにおいてしばしば国家外交の顔として行動する一方、外相はWisma Putraを率い、大半の閣僚級会合でマレーシアを代表する。マレーシアの歴史においては、首相と外相の職を同一人物が兼任していた時期もあり、この二つの役割がいかに密接であるかを示している。

最も理解しやすい捉え方はこうだ。内閣がマレーシアの立場が*何であるか*を定め、Wisma Putraがその立場が日々どのように伝えられ、交渉され、守られるか、その*方法*を管理する。

## マレーシアの外交政策を導く核心原則は何か？

マレーシアの外交政策は、世界の出来事に対する場当たり的な反応ではない。それは、異なる政権を通じてかなり安定したいくつかの原則に基づいている。

その主な重点は、次のようにまとめられる。

| 原則 | 実践における意味 |
| --- | --- |
| **開放経済** | マレーシアは貿易を基盤とする国であり、対外関係は市場アクセス、投資、サプライチェーンを守るために構築されている |
| **平和と安定** | 外交的解決を優先し、特に東南アジアにおける地域の安定を支持する |
| **不干渉** | 他国の主権を尊重し、その内政に干渉しない——そして同様の扱いを期待する |
| **自由と非同盟** | 独立した立場を取り、大国の軍事ブロックに加わらない一方、不公正、侵略、主権侵害を拒む |

これらの原則は互いに支え合っている。マレーシアは複数の相手との貿易に同時に依存しているため、ある大国に肩入れすることは、もう一方の大国との関係を危険にさらすことを意味する。したがって中立は、単なる道徳的立場ではなく——経済的な論理でもある。

Wisma Putraが示す方向性によれば、マレーシアの外交政策のアプローチは国益、価値観、国家の優先事項に基づいており、連邦憲法、ASEAN憲章、国連憲章の原則と目的に沿ったものである。それは、**原則的かつ実務的**な外交を通じて、二国間、地域、多国間の関与への取り組みを重視している。

## Wisma Putraはどこから始まったのか？

中立がなぜこれほど根付いているのかを理解するには、それを守る機関の起源を見てみるのがよい。

外務省自身の歴史記録によれば、その設立の基礎は独立の前年にあたる**1956年**に遡り、当時は *Ministry of External Affairs*（対外事務省）として知られていた。**11名の職業外交官**からなる先駆者たちがイギリスとオーストラリアへ訓練のため派遣された——この小さな一歩が、この若い国家の外交サービスの中核を築いた。

**1966年**、同省は *Ministry of Foreign Affairs*（外務省）へと改称され、スルタン・アブドゥル・サマド・ビルディングから、クアラルンプールのブキ・プタリン（Bukit Petaling）にある**Wisma Putra**という新しい複合施設へ移転した。この建物の名称こそが、その後同省の通称として定着したものであり、現在その本部はプトラジャヤに置かれている。

この機関の歩みが重要なのは、それが初期の試練の時期——1963年のマレーシア誕生を迎えたインドネシアとの対決（Konfrontasi）を含む——を経てきたからであり、それは地域の安定と隣国との良好な関係が贅沢品ではなく、生存に不可欠なものであることを教えている。

## 「中立」とは何を意味し、ZOPFANはどこに関わるのか？

マレーシアの文脈における中立とは、孤立や無関心を意味するものではない。それは、積極的に発言し続けながらも、*大国のブロックに肩入れしない*ことを意味する。

この理念には公式な歴史がある。**1971年11月27日**、インドネシア、マレーシア、フィリピン、シンガポール、タイの東南アジア5か国は、クアラルンプールで開催されたASEAN特別外相会議において**平和・自由・中立地帯宣言（ZOPFAN）**に署名した。その目的は明確だった——東南アジアをあらゆる形態の域外大国の干渉から自由にすることである。この宣言は、ベトナム戦争と冷戦期の大国間競争の影の中で生まれたものであり、マレーシアはその推進国の一つであった。

半世紀以上を経た今も、ZOPFANはマレーシアの立場の基礎として言及され続けている。2025年7月、クアラルンプールで開催された第58回ASEAN外相会議の後、**モハマド・ハサン**外相は、マレーシアの外交政策が依然として均衡が取れており、ZOPFANを断固として守っていると強調した。彼はその論理を率直に説明した。

- マレーシアは貿易を基盤とする国であるため、「良好な均衡を保っている」。
- アメリカはマレーシアにとって**最大の投資国**である一方、中国は**最大の貿易相手国**である。
- したがって、マレーシアは「いずれの側にも傾いていると見られてはならない」。

外相はまた、マレーシアの外交が常に「原則的かつ実務的」であり続けなければならないと強調した——この二語は、価値観には忠実でありながら戦術には柔軟であるという、国全体のアプローチを捉えるものである。

## ASEANはどのようにして外交政策の柱となったのか？

中立が原則であるとすれば、ASEANはその原則が実践される主要な舞台である。

マレーシアは1967年に設立されたASEANの創設国の一つである。それ以来、ASEANの結束性と*centrality*（中心的地位）が国の外交政策の基礎となっている。その論理はこうだ——マレーシアのような中規模国家は、単独で行動するよりも、十の隣国とともに行動するときの方が、はるかに強い発言力を持つ。ASEANは、マレーシアが大国との関係を単独で圧力にさらされるのではなく、集団として管理するための基盤を提供している。

しかし、ASEANが唯一の舞台ではない。マレーシアの外交政策は、いくつかの枠組みにおける積極的な参加によっても支えられている。

- **国連（UN）**——マレーシアが世界的な課題について立場を表明し、平和維持活動に貢献する場。
- **イスラム協力機構（OIC）**——イスラム教徒が多数を占める国々との連帯、そしてパレスチナのような問題に関する立場表明の経路。
- **非同盟運動（NAM）**——マレーシアと同様に、大国のブロックに縛られないことを選んだ国々の集まり。
- **南南協力**——相互尊重に基づく発展途上国間の協力。

これらの枠組みの組み合わせにより、マレーシアは*イデオロギーや政治制度を問わず*、すべての国と調和の取れた関係を維持することができている——これは、その外交政策における長年の重点である。

## 『外務省戦略計画2026-2030』とは何か？

安定した原則であっても、更新されたロードマップは必要である。現在のロードマップが**『外務省戦略計画2026-2030』**であり、**アンワル・イブラヒム**首相により、同省のMADANIイフタール行事にあわせて**2026年2月23日**に発表された。

この5か年計画は『戦略計画2021-2025』を引き継ぎ、第13次[マレーシア計画](/economy/malaysia-plans)（RMK13）、MADANI経済枠組み、そして公共サービス改革アジェンダ（ARPA）と整合している。その枠組みは広範であり、**8つの戦略的推進軸**を、より詳細な**33の戦略**と**139のプログラム**が支え、それぞれに重要業績評価指標（KPI）及びモニタリング・評価の枠組みが備えられている。

8つの戦略的推進軸は、次のとおりである。

| # | 戦略的推進軸 |
| --- | --- |
| 1 | 二国間（bilateral）外交の強化 |
| 2 | 多国間（multilateral）外交の強化 |
| 3 | ASEANにおけるマレーシアの積極的役割 |
| 4 | 海洋領域の主権と一体性の維持 |
| 5 | 利害関係者への積極的かつ効果的なサービス提供 |
| 6 | 戦略的コミュニケーションと革新的なパブリック・ディプロマシーの強化 |
| 7 | 組織の卓越性と人的資本の強化 |
| 8 | 化学兵器禁止条約（CWC）の実施における国家当局の権限強化 |

これらの推進軸が、古い原則を新しい形で反映していることに注目してほしい。ASEANは中心にあり続けている（推進軸3）。経済外交は推進軸1と2にまたがっている。海洋主権（推進軸4）は、南シナ海のような地域における重複する主張という現実に、いずれの当事者にも肩入れすることなく対処している。推進軸5と6は、国民に最も身近な実務的事項——領事サービスと海外のマレーシア国民の福祉——を取り上げている。言い換えれば、この計画は「原則的かつ実務的」を、測定可能な課題のリストへと翻訳しているのである。

## マレーシアはある問題に対する立場をどのように決定するのか？

公表された公式な公式は存在しないが、マレーシアの外交政策の決定パターンはかなり一貫している。次の簡単な枠組みは、マレーシアがなぜ特定の立場を取るのかを理解する助けとなる。

1. **それはマレーシアの主権や安全保障に直接影響するか？** もしそうであれば——例えば領土主張——マレーシアは、対立ではなく通常は外交チャネルと国際法を通じて、自国の利益を断固として守る。
2. **それは大国間での選択を伴うか？** もしそうであれば、既定の傾向は*中立*である——すべての当事者と関係を維持し、肩入れしていると見られることを避ける。
3. **それは普遍的な原則に関わる問題——不公正、侵略、主権侵害——か？** ここでは、マレーシアはたとえ大国に対してであっても、通常は原則に基づいて発言し、しばしばASEAN、OIC、国連の集団としての声の中で発言する。
4. **それは集団的に対処できるか？** もしできるのであれば、マレーシアは単独で行動するよりも、ASEANや多国間の枠組みを通じて行動することを好む。集団としての声の方が強く、リスクも小さいためである。

この枠組みは、一見矛盾しているように見える事柄を説明している——マレーシアがいかにして大国の間では中立でありながら、原則的な問題については声高に主張できるのかということである。両者は同じ論理から生じている——宣言された価値に忠実であり続けながら、開放的な国家の利益を守ることである。

## マレーシアの外交政策について最もよくある誤解は何か？

いくつかの誤りが、公共の議論の中でたびたび現れる。

- **「中立とは、マレーシアが何に対しても立場を取らないことを意味する。」** 誤り。中立とは、大国の軍事ブロックに加わらないことを指す。マレーシアは、多くの問題について依然として原則に基づく断固たる立場を取っている。
- **「Wisma Putraがすべての外交政策の決定を行う。」** 正確ではない。Wisma Putraは実施と調整を行う。最高の政策決定は首相と内閣のものである。
