在利马遗失护照、在多哈被捕，或需要在首尔办理文件公证时，真正能帮到你的
那个办公室，只是遍布85个国家的111个马来西亚使团网络中的一个节点——
而每一个都由位于布城的外交部（Wisma Putra）统筹运营。

## 马来西亚的海外网络有多大？

外交部将其海外机构划分为若干使团类型。它们合计构成
**85个国家的111个使团**。

| 使团类型 | 数量 | 具体含义 |
| --- | ---: | --- |
| 使馆 | 66 | 马来西亚在非英联邦国家的主要使团 |
| 高级专员公署 | 18 | 在英联邦成员国的使馆等同机构 |
| 总领事馆 | 21 | 设于主要城市、由总领事领导的次级使团 |
| 领事办事处 | 2 | 规模较小的领事机构 |
| 常驻联合国代表 | 2 | 马来西亚驻联合国的使团 |
| 常驻东盟代表 | 1 | 马来西亚驻该区域集团的使团 |
| 马来西亚友好贸易中心 | 1 | 在未维持正式邦交处设立的事实使团 |

最容易让人混淆的，是"使馆"与"高级专员公署"之间的区别。两者都是一个
国家的最高级别使团，都由级别相同的使节领导——大使或高级专员——
且从事相同的工作。马来西亚只是在驻在国为另一个英联邦成员（英国、印度、
新加坡、澳大利亚等）时使用**高级专员公署**，在其他所有地方则使用
**使馆**。

## 使团提供哪些领事服务？

使团的职责不仅仅是政府间的外交。对于一名普通的海外马来西亚人而言，
使馆、高级专员公署或总领事馆就是马来西亚政府的前台。各使团的核心
领事服务大体一致。

| 服务 | 涵盖内容 |
| --- | --- |
| 护照 | 为居住在使团辖区内的公民更新马来西亚国际护照 |
| 紧急证件（SPC） | 在护照遗失、过期或即将过期时，返回马来西亚的单程旅行证件 |
| 公证与认证 | 核证真实副本、认证文件，以及认证商业发票和官方文书 |
| 登记 | 通过在线 e-Consular 系统登记居住在辖区内的马来西亚人 |
| 困境援助 | 为被捕、住院、遭遇罪案或在海外陷入其他困境的马来西亚人提供协助 |

政府自身的指引对最常见的紧急情况直言不讳：如果马来西亚人在旅行途中
遗失护照，回国的途径是就近的使团和一份**紧急证件（Sijil Perakuan
Cemas，SPC）**——而不是当日补发的护照。这是一份仅限用于返回马来西亚
旅程的一次性证件。

并非每个机构都提供所有服务。规模较小的领事办事处可能办理公证事务和
紧急事项，但将完整的护照办理转交给其上级使馆，因此在出行前查阅具体
使团的页面很重要。

## 哪个使团负责哪个国家？

每个使团都被指定一个**辖区**——它所负责的国家，有时还有具体地区。
一个使馆常常同时兼驻多个邻近国家，这就是为什么在没有常驻使馆的国家里，
马来西亚人由邻国首都的使团服务。总领事馆则进一步细分：在大国之内，
设于某一城市的总领事馆可能只负责某些州或省，其余部分则由首都的使馆
负责。

实用要点：在断定"这里没有马来西亚使馆"之前，先查一查哪个使团派驻该
国。通常都有一个——只是不一定在该国境内。

## 那外国驻马来西亚的使馆呢？

往来是双向的。数十个外国政府在马来西亚维持常驻使馆和高级专员公署，
绝大多数集中在**吉隆坡和布城**，还有若干国家在槟城、新山、亚庇和
古晋等区域城市设立领事馆。有些国家从另一个亚洲首都派驻其大使，而非
在吉隆坡设立常驻使团。

关于谁在此地的权威登记册是由外交部礼宾司发布的**《外交与领事名录》**。
它记录了每个常驻马来西亚的外国使团的经认证外交与领事官员，以及名誉领事
和国际组织的高级官员，并通过外交部门户免费发放。

## 接下来

如果你是即将出国的马来西亚人，请在出发前记下派驻你目的地的使团及其
领事联系方式——真正需要它的那一刻（护照遗失、被捕、需要公证文件）
往往不是开始搜索的时刻。如果你想核实某位外国外交官，或核对一个派驻
马来西亚的使团，外交部的《外交与领事名录》就是应当查阅的登记册。而
如果你的问题是关于向海外推广出口而非服务公民，那走的是一套平行的
[MATRADE](/zh/government/matrade) 贸易办事处网络，而非使馆。
