当美国是马来西亚经济中最大的外国投资者，而中国却是它最大的贸易伙伴时，一个开放的小国无从选边站。这正是为什么数十年来，马来西亚的外交政策始终紧扣一个说来容易、守起来却很难的词：中立。每天负责维系这份平衡的部门，就是 Wisma Putra（外交部）。

## 究竟是谁制定马来西亚的外交政策？

许多人以为"外交政策"是单一部门的工作。其实它是分层的。

外交部——以其大楼命名而更广为人知的 **Wisma Putra**——被授予依据《联邦宪法》*执行*并协调马来西亚外交政策的使命，目标是在国际层面保护并促进国家利益。Wisma Putra 管理马来西亚遍布全球的大使馆、高级专员公署与领事馆网络，在国际论坛上谈判国家立场，并照顾海外马来西亚公民的福祉。

但最高层级的政策决定并非该部一家独有。它掌握在**首相与内阁**手中。首相在官方访问与峰会中常常充当国家外交的门面，而外交部长则领导 Wisma Putra 并在多数部长级会议中代表马来西亚。在马来西亚历史上，曾有首相与外交部长由同一人兼任的时期，可见这两个角色关系之密切。

理解它最简单的方式是：内阁决定马来西亚立场*是什么*，而 Wisma Putra 则日复一日地管理这一立场*如何*被传达、谈判与捍卫。

## 指导马来西亚外交政策的核心原则是什么？

马来西亚的外交政策并非对世界事件的随意反应。它紧扣着几项在不同政府之间都相当稳定的原则。

其主要重点可以这样概括：

| 原则 | 实践中的含义 |
| --- | --- |
| **开放经济** | 马来西亚是以贸易为基础的国家；其对外关系旨在保护市场准入、投资与供应链 |
| **和平与稳定** | 优先以外交方式解决问题，并支持区域稳定，尤其是在东南亚 |
| **不干涉** | 尊重他国主权，不干涉其内政——并期望获得同样对待 |
| **独立与中立** | 采取独立立场，不加入大国军事集团，同时反对任何不公、侵略与主权侵犯 |

这些原则彼此支撑。由于马来西亚同时依赖与多方的贸易，倾向某一大国就意味着拿与另一大国的关系冒险。因此中立不仅是道德立场——它也是经济逻辑。

依据 Wisma Putra 所勾勒的方向，马来西亚外交政策的做法以国家利益、价值观与优先事项为基础，与《联邦宪法》、《东盟宪章》及《联合国宪章》中的原则和目标相一致。它强调通过**有原则且务实**的外交，致力于双边、区域与多边的参与。

## Wisma Putra 从何而来？

要理解中立为何如此根深蒂固，不妨看看守护它的机构的起源。

根据外交部自身的历史记载，其设立的基础始于**1956年**，即独立前一年，当时它被称为 *Ministry of External Affairs*（对外事务部）。一批**11名职业外交官**的先驱被派往英国与澳大利亚受训——这一小步为这个年轻国家的外交队伍奠定了核心。

**1966年**，该部更名为 *Ministry of Foreign Affairs*，并从苏丹阿都沙末大厦迁至吉隆坡武吉冕丁一座名为 **Wisma Putra** 的新大楼。正是这座大楼的名称，后来成了该部的通用称呼，尽管如今其总部已设在布城。

这一机构的历程之所以重要，是因为它经历了早期的考验时刻——包括迎接1963年马来西亚诞生的与印尼的对抗（Konfrontasi）——这些经历教会了人们：区域稳定与睦邻关系并非奢侈品，而是生存的必需。

## "中立"是什么意思，ZOPFAN 又从何切入？

在马来西亚语境中，中立并不意味着孤立或漠不关心。它意味着*不倒向大国集团*，同时保持积极与发声。

这一理念有其正式的历史。**1971年11月27日**，五个东盟国家——印尼、马来西亚、菲律宾、新加坡与泰国——在吉隆坡召开的东盟部长特别会议上签署了**《和平、自由与中立区宣言》（ZOPFAN）**。其目标清晰：使东南亚免受任何形式的外部大国干涉。这份宣言诞生于越南战争与冷战大国竞争的阴影之下，而马来西亚正是其推动者之一。

半个多世纪之后，ZOPFAN 仍被视为马来西亚立场的基础。2025年7月，在吉隆坡举行的第58届东盟外长会议之后，外交部长**莫哈末·哈山**强调，马来西亚的外交政策依然保持平衡且坚定地捍卫 ZOPFAN。他直白地阐明了其中的逻辑：

- 马来西亚"保持良好的平衡"，因为它是以贸易为基础的国家。
- 美国是马来西亚**最大的投资者**，而中国是其**最大的贸易伙伴**。
- 因此马来西亚"不能被视为倾向任何一方"。

外交部长还强调，马来西亚的外交必须始终"有原则且务实"——这两个词概括了整个国家的做法：坚守价值，却在策略上灵活。

## 东盟如何成为外交政策的支柱？

如果说中立是原则，那么东盟就是实践这一原则的主要舞台。

马来西亚是1967年成立的东盟的创始国之一。自那以后，东盟的完整性与*中心地位*（centrality）便成为国家外交政策的基础。其逻辑是：像马来西亚这样一个中等规模的国家，与十个邻国共同行动时的声音，远比孤军奋战时更为响亮。东盟为马来西亚提供了一个集体管理与大国关系的平台，而非独自面对压力。

然而东盟并非唯一的舞台。马来西亚的外交政策还得到在多个论坛中积极参与的支撑：

- **联合国（UN）**——马来西亚在此就全球议题表达立场，并为维和行动作出贡献。
- **伊斯兰合作组织（OIC）**——与穆斯林占多数的国家团结的渠道，以及就巴勒斯坦等议题表态的场所。
- **不结盟运动（NAM）**——一批与马来西亚一样、选择不与大国集团绑定的国家的集合。
- **南南合作**——发展中国家之间基于相互尊重的合作。

这些论坛的组合使马来西亚得以*不论意识形态与政治制度*地与所有国家保持和谐关系——这是其外交政策中一贯的重点。

## 什么是《外交部2026-2030年战略计划》？

稳定的原则仍然需要一份不断更新的路线图。当前的路线图是**《外交部2026-2030年战略计划》**，由首相**安华·依布拉欣**于**2026年2月23日**在该部的 MADANI 开斋宴上推出。

这份五年计划接续《2021-2025年战略计划》，并与《第十三大马计划》（RMK13）、MADANI 经济框架及《公共服务改革议程》（ARPA）相协调。其框架庞大：**8个战略重点**，由更为细致的 **33项战略**与 **139个项目**支撑，每一项都配有关键绩效指标（KPI）以及监测与评估框架。

八个战略重点是：

| # | 战略重点 |
| --- | --- |
| 1 | 加强双边（bilateral）外交 |
| 2 | 加强多边（multilateral）外交 |
| 3 | 马来西亚在东盟中的主动角色 |
| 4 | 维护海洋区域的主权与领土完整 |
| 5 | 向利益相关方提供主动且有效的服务 |
| 6 | 加强战略沟通与创新的公共外交 |
| 7 | 加强机构卓越与人力资本 |
| 8 | 加强国家主管机关在执行《化学武器公约》（CWC）中的职权 |

请注意这些重点如何以新的形式反映旧有的原则。东盟仍居中心（重点3）。经济外交贯穿重点1与重点2。海洋主权（重点4）应对南中国海等地区权利主张重叠的现实，却不偏袒任何一方。重点5与重点6突出与人民最贴近的实务——领事服务与海外马来西亚公民的福祉。换言之，这份计划把"有原则且务实"转化成一份可衡量的任务清单。

## 马来西亚如何决定其对某一议题的立场？

并没有公开发表的正式公式，但马来西亚外交政策的决策模式相当一致。以下这个简明框架有助于理解马来西亚为何采取某些立场：

1. **它是否直接影响马来西亚的主权或安全？** 如果是——例如领土主张——马来西亚会坚定捍卫其利益，通常通过外交渠道与国际法，而非对抗。
2. **它是否涉及在大国之间作出选择？** 如果是，默认的倾向就是*中立*——与各方保持关系并避免被视为偏袒。
3. **它是否是普世原则的议题——不公、侵略、主权侵犯？** 在这里马来西亚通常基于原则发声，即便是针对大国，且往往以东盟、OIC 或联合国的集体声音发出。
4. **它能否以集体方式处理？** 如果可以，马来西亚更倾向于通过东盟或多边论坛行动，而非单打独斗，因为集体的声音更强、风险更小。

这个框架解释了一件看似矛盾的事：马来西亚为何能在大国之间保持中立，却在原则性议题上大声疾呼。两者都出自同一逻辑——保护开放国家的利益，同时忠于所宣示的价值。

## 关于马来西亚外交政策最常见的误解是什么？

在公众讨论中经常出现几个错误：

- **"中立意味着马来西亚对任何事都不站队。"** 错误。中立指的是不加入大国军事集团。在许多议题上，马来西亚仍会基于原则采取坚定立场。
- **"Wisma Putra 作出所有外交政策决定。"** 不准确。Wisma Putra 负责执行与协调；最高的政策决定属于首相与内阁。
- **"每当政府更替，马来西亚的外交政策就会改变。"** 大部分保持不变。开放经济、东盟优先与中立在不同的政府之间都得以延续；改变的更多是重点与风格，而非根本。
- **"Wisma Putra 只负责官方仪式与礼宾。"** 它的范围广泛得多——从在联合国谈判立场，到营救与协助滞留海外的马来西亚公民。
- **"ZOPFAN 只是一份历史文件。"** 它至今仍被引用为当前立场的基础，正如外交部长在2025年亲自强调的那样。

## Wisma Putra 与其他部门相比：谁负责什么？

外交政策与其他几个部门有重叠，人们容易对管辖范围感到困惑。以下是一份简明指南：

| 领域 | 主要牵头单位 |
| --- | --- |
| 外交政策、外交、驻外使团、海外公民福祉 | **外交部（Wisma Putra）** |
| 贸易与投资政策、自由贸易协定谈判 | **MITI**（投资、贸易及工业部） |
