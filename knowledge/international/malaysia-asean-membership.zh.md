1967年8月8日，五个人聚集在曼谷外交部大楼的主厅，签署了一份两页的文件。其中一人——马来西亚副首相敦阿都拉萨·胡先——正将马来西亚置入一个日后将成为这个国家近六十年外交政策主要框架的组织，而马来西亚本身也在2025年担任了该组织的轮值主席国。

## 概览：马来西亚在东盟

| | |
| --- | --- |
| 全称 | Association of Southeast Asian Nations（东南亚国家联盟） |
| 成立 | 1967年8月8日，泰国曼谷 |
| 创始文书 | 《东盟宣言》（《曼谷宣言》） |
| 马来西亚签署人 | 敦阿都拉萨·胡先（时任副首相） |
| 现有成员国数目 | 11国 |
| 法定文件 | 《东盟宪章》（2008年12月15日生效） |
| 结构 | 东盟共同体三大支柱（自2015年12月31日起） |
| 秘书处 | 印尼雅加达 |
| 马来西亚轮值主席任期 | 5次——1977、1997、2005、2015、2025年 |

马来西亚不仅仅是东盟的成员国。它是最初创建该组织的五个国家之一，东盟近六十年的历史与马来西亚外交政策的历史紧密交织。

## 东盟如何诞生，马来西亚扮演什么角色？

东盟诞生于1960年代东南亚地缘政治的动荡——区域对抗、冷战紧张局势，以及新独立国家在没有大国干预下管理彼此关系的需求。其解决方案是一个区域合作论坛，而非军事同盟。

《曼谷宣言》由五位部长签署：亚当·马利克（Adam Malik，印尼）、敦阿都拉萨·胡先（马来西亚）、纳西索·拉莫斯（Narciso R. Ramos，菲律宾）、拉惹勒南（S. Rajaratnam，新加坡）与他纳·科曼（Thanat Khoman，泰国）。这五人后来被称为东盟的创始之父。对马来西亚而言，这次参与确立了一项延续至今的原则：优先采取区域解决方案、不干预邻国内政，以及通过协商一致（共识）方式作出决定。

该宣言设定了加速本区域经济增长、社会进步与文化发展，以及促进区域和平与稳定的目标。它刻意保持简短且不具约束力——这一特点被称为「东盟方式」（the ASEAN Way）。

## 今天东盟有哪些成员国？

东盟从1967年的五个国家发展至十一个。以下是每个成员国及其加入日期：

| 成员国 | 加入日期 |
| --- | --- |
| 印尼 | 1967年8月8日（创始国） |
| 马来西亚 | 1967年8月8日（创始国） |
| 菲律宾 | 1967年8月8日（创始国） |
| 新加坡 | 1967年8月8日（创始国） |
| 泰国 | 1967年8月8日（创始国） |
| 文莱达鲁萨兰国 | 1984年1月7日 |
| 越南 | 1995年7月28日 |
| 老挝（Lao PDR） | 1997年7月23日 |
| 缅甸 | 1997年7月23日 |
| 柬埔寨 | 1999年4月30日 |
| 东帝汶 | 2025年10月26日 |

东帝汶的加入是东盟自1999年以来的首次扩员。此事在马来西亚担任主席国期间完成：接纳东帝汶为第11个成员国的决定于2025年5月第46届东盟峰会上作出，《东帝汶加入宣言》则于2025年10月26日在吉隆坡举行的第47届东盟峰会开幕仪式上签署。

## 什么是《东盟宪章》，为何它重要？

在最初的40年里，东盟在没有正式章程的情况下运作。这一情况随着《东盟宪章》而改变。

该宪章由10个成员国的领导人于2007年11月20日在新加坡举行的第13届东盟峰会上签署，并在所有成员国批准后于2008年12月15日生效。宪章首次赋予东盟作为政府间组织的**法律人格**——这意味着东盟如今成为一个独立的法律实体，而不再只是各国的松散集合。

宪章的作用：

- 使东盟的宗旨、原则与价值观成为具有法律约束力的文件。
- 保留诸如不干预、主权平等，以及通过协商与共识作出决定等核心原则。
- 确立制度架构——东盟峰会、协调理事会、共同体理事会与秘书处。
- 为东盟共同体的建立奠定基础。

对马来西亚而言，宪章进一步巩固了让它能够将区域议题——从南中国海争端到缅甸危机——带上正式谈判桌，而非通过临时渠道处理的框架。

## 东盟共同体的三大支柱是什么？

2015年12月31日，东盟正式成立**东盟共同体**，依据三大支柱组织架构。每一支柱都有自己的行动计划。

| 支柱 | 重点 | 对马来西亚的意义 |
| --- | --- | --- |
| 东盟政治-安全共同体（APSC） | 和平、稳定、争端解决、区域规范 | 处理南中国海与缅甸等安全议题的论坛 |
| 东盟经济共同体（AEC） | 单一市场与生产基地——货物、服务、投资、资本与技能的自由流动 | 进入一个超过6亿人口的区域市场 |
| 东盟社会-文化共同体（ASCC） | 教育、卫生、环境、文化、灾害应对 | 民间往来合作与社会保障 |

经济支柱（AEC）对马来西亚企业的影响或许最为显著。其理念是以单一市场和共同生产基地取代各成员国分立的经济，让企业能够构建跨区域的产业网络并融入全球供应链。据新加坡政府的经济教育门户网站（SG101），AEC开启了通往本区域约6亿消费者的准入。AEC也成为更广泛的贸易协定（如RCEP，区域全面经济伙伴关系协定）的基础，该协定将东盟与中国、日本、韩国、澳大利亚与新西兰等伙伴整合在一起。

## 东盟的主要机构：谁作决定？

东盟常被误解为一个中央集权的官僚机构。事实上，它是一个由成员国驱动、主席国轮替的组织。

**东盟峰会**是最高决策机构，汇集各国国家元首或政府首脑。它通常每年在担任主席国的国家召开两次会议。

**东盟秘书处**设于印尼雅加达，通过《1976年东盟秘书处设立协定》成立。它协调并支持东盟决定的执行，但对成员国没有强制权力。

**东盟秘书长**领导秘书处。现任者为高金洪博士（Dr. Kao Kim Hourn），第15任秘书长，于2023年1月上任，是首位担任该职务的柬埔寨籍人士。

**东盟轮值主席国**每年按成员国英文名称的字母顺序轮替。主席国负责主办峰会、设定该年度的主题与优先事项，以及主持主要会议。正是这一机制在2025年将马来西亚推上了主导地位。

## 马来西亚作为2025年东盟轮值主席国的角色

马来西亚于2025年**第五度**担任东盟轮值主席国——继1977、1997、2005及2015年之后。主席权杖在2024年10月于万象举行的第44届及第45届东盟峰会闭幕时从老挝接过，主席任期于2025年1月1日正式开始。首相安华·依布拉欣（Anwar Ibrahim）在这一年领导该集团。

其主题为**「Inclusivity and Sustainability」**（包容与可持续）。这一主题的选择意味深长：2025年标志着东盟共同体成立十周年，是为接下来二十年设定方向的一个自然节点。据马来西亚财政部资料，马来西亚全年在全国各地主办了超过300场主要会议与活动；Bernama报道，到年底东盟三大支柱范围内的会议总数约为320场。

据官方来源与新闻机构报道，马来西亚2025年主席任期内的主要进展包括：

- **东帝汶成为第11个成员国**，于2025年10月在吉隆坡举行的第47届峰会上完成——这是东盟自1999年以来的首次扩员。
- **《东盟共同体愿景2045》的通过**，主题为「Resilient, Innovative, Dynamic, and People-Centred ASEAN」，于2025年5月26日在吉隆坡举行的第46届东盟峰会上通过，同时通过了《关于东盟2045的吉隆坡宣言》。该愿景为东盟未来20年绘制了发展方向。马来西亚外交部长拿督斯里莫哈末·哈山（Datuk Seri Mohamad Hasan）在国会下议院的声明（2025年2月6日）中，将马来西亚形容为该愿景的「常任牧者」（permanent shepherd）——这是政府对马来西亚角色的一个描述性用语，而非法定的正式职位。
- **《吉隆坡和平协议》（Kuala Lumpur Peace Accord）**，为柬埔寨与泰国之间的协议，于2025年10月26日在吉隆坡趁第47届东盟峰会之机签署。马来西亚作为2025年东盟轮值主席国，在首相安华·依布拉欣领导下，担任该次签署的东道主与调解人（并由美国总统唐纳德·特朗普共同见证）；该协议设立了边境观察团队，并促成18名被扣押柬埔寨士兵的释放。
- 举办新平台——**第2届东盟-海湾合作委员会（GCC）峰会**及首届**东盟-GCC-中国**峰会，两者均于2025年5月27日在吉隆坡与第46届东盟峰会同期举行——扩大了区域外交影响力。

马来西亚在整个2025年历年担任东盟轮值主席国。在2025年10月28日第47届东盟峰会闭幕仪式上，主席权杖移交给菲律宾；然而，菲律宾要到2026年1月1日才正式担任主席国。

## 正确理解东盟的框架

东盟之所以复杂，是因为它被刻意设计得松散。要准确解读任何东盟议题，请按顺序问以下三个问题：

1. **属于哪个支柱？** 安全议题（南中国海、缅甸）归属APSC；贸易与投资议题归属AEC；灾害、教育与文化议题归属ASCC。支柱决定了涉及哪些会议与官员。
2. **属于哪个机构？** 重大政策决定来自峰会；日常协调来自秘书处。切勿误将秘书处的声明当作对成员国具约束力的决定。
3. **它是否具约束力？** 东盟的多数成果是宣言与行动计划，而非可强制执行的法律。宪章具约束力；多数峰会声明属于政治承诺性质。

## 关于马来西亚与东盟的常见误解

- **以为马来西亚「加入」东盟。** 马来西亚于1967年创建东盟；它并非日后才加入。
- **以为东盟有10个成员国。** 这个数字在2025年10月之前是正确的。自东帝汶于2025年10月26日加入后，东盟拥有11个成员国。
- **混淆《曼谷宣言》与《东盟宪章》。** 《曼谷宣言》（1967年）创建东盟且不具约束力；《东盟宪章》（2008年生效）才是其法定文件。
- **将东盟等同于欧盟。** 东盟没有共同货币、没有超国家议会，并通过共识而非多数投票作出决定。
- **以为主席国拥有统治权力。** 主席国设定议程并主办会议，但不能强制其他成员国。决定仍须协商一致。
