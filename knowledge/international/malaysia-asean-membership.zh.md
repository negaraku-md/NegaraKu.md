1967年8月8日，五名男子聚集在曼谷外交部大楼的主厅内，签署了一份两页的文件。其中一人，马来西亚副首相敦阿都拉萨·胡先（Tun Abdul Razak Hussein），正把马来西亚纳入一个组织——这个组织日后将在近六十年间成为马来西亚外交政策的主要框架，而马来西亚本身也于2025年出任其轮值主席国。

## 概览：马来西亚在东盟

| | |
| --- | --- |
| 全称 | Association of Southeast Asian Nations（东南亚国家联盟） |
| 成立 | 1967年8月8日，泰国曼谷 |
| 创始文书 | 《东盟宣言》（《曼谷宣言》） |
| 马来西亚签署人 | 敦阿都拉萨·胡先（时任副首相） |
| 现有成员国数目 | 11国 |
| 法定文件 | 《东盟宪章》（2008年12月15日生效） |
| 架构 | 东盟共同体三大支柱（自2015年12月31日起） |
| 秘书处 | 印度尼西亚雅加达 |
| 马来西亚轮值主席国 | 5次——1977、1997、2005、2015、2025年 |

马来西亚不仅仅是东盟的成员国，它更是最初创建这个组织的五个国家之一，而东盟近六十年的历史与马来西亚外交政策的历史紧密交织。

## 东盟如何诞生，马来西亚扮演什么角色？

东盟诞生于1960年代东南亚的地缘政治动荡——区域对抗、冷战紧张局势，以及新独立国家需要在没有大国干预的情况下处理彼此关系。其解决方案是一个区域合作论坛，而非军事同盟。

《曼谷宣言》由五位部长签署：阿丹·马利克（Adam Malik，印度尼西亚）、敦阿都拉萨·胡先（Tun Abdul Razak Hussein，马来西亚）、纳西索·R·拉莫斯（Narciso R. Ramos，菲律宾）、S·拉惹勒南（S. Rajaratnam，新加坡）以及他纳·科曼（Thanat Khoman，泰国）。这五人后来被称为东盟创始之父。对马来西亚而言，这次参与确立了一项延续至今的原则：优先寻求区域内解决方案、不干涉邻国内政，以及以协商一致（共识）方式作出决定。

该宣言设定的目标是加速本区域的经济增长、社会进步与文化发展，并促进区域和平与稳定。它刻意保持简短且不具约束力——这一特点被称为「东盟方式」（the ASEAN Way）。

## 东盟今天有哪些成员国？

从1967年的五国，东盟已发展为十一国。以下是各成员国及其加入日期：

| 成员国 | 加入日期 |
| --- | --- |
| 印度尼西亚 | 1967年8月8日（创始国） |
| 马来西亚 | 1967年8月8日（创始国） |
| 菲律宾 | 1967年8月8日（创始国） |
| 新加坡 | 1967年8月8日（创始国） |
| 泰国 | 1967年8月8日（创始国） |
| 文莱达鲁萨兰 | 1984年1月7日 |

东帝汶的加入是东盟自1999年以来的首次扩员。它在马来西亚担任轮值主席国期间敲定：接纳东帝汶为第11个成员国的决定于2025年5月第46届东盟峰会上作出，而《东帝汶加入宣言》则于2025年10月26日在吉隆坡第47届东盟峰会开幕仪式上签署。

## 什么是《东盟宪章》，它为何重要？

在最初的40年里，东盟在没有正式章程的情况下运作。这随着《东盟宪章》的出现而改变。

该宪章由10个成员国领导人于2007年11月20日在新加坡第13届东盟峰会上签署，并在所有成员国批准后于2008年12月15日生效。宪章首次赋予东盟作为政府间组织的**法律人格**——意味着东盟如今成为一个独立的法律实体，而不再只是各国的松散集合。

宪章的作用：

- 使东盟的目标、原则和价值观成为具有法律约束力的文件。
- 保留不干涉、主权平等，以及通过协商与共识作出决定等核心原则。
- 确立制度架构——东盟峰会、协调理事会、共同体理事会，以及秘书处。
- 为东盟共同体的形成奠定基础。

对马来西亚而言，宪章进一步巩固了让它能够把区域议题——从南海争端到缅甸危机——带到正式桌面上，而非通过临时渠道处理的框架。

## 东盟共同体的三大支柱是什么？

2015年12月31日，东盟正式成立**东盟共同体**，按三大支柱组织架构。每一支柱都有其各自的行动计划。

| 支柱 | 焦点 | 对马来西亚意味着什么 |
| --- | --- | --- |
| 东盟政治安全共同体（APSC） | 和平、稳定、争端解决、区域规范 | 处理南海和缅甸等安全议题的论坛 |
| 东盟经济共同体（AEC） | 单一市场与生产基地——货物、服务、投资、资本和技能的自由流动 | 通往超过6亿人口区域市场的通道 |
| 东盟社会文化共同体（ASCC） | 教育、卫生、环境、文化、灾害应对 | 人民之间的合作与社会保障 |

经济支柱（AEC）对马来西亚企业的影响或许最为显著。其理念是以单一市场和共同生产基地取代各成员国分立的经济体，让企业能够跨区域构建产业网络并参与全球供应链。根据新加坡政府的经济教育门户（SG101），AEC开启了通往本区域约6亿消费者的通道。AEC也是更广泛贸易协定（如RCEP，区域全面经济伙伴关系协定）的基础，该协定将东盟与中国、日本、韩国、澳大利亚和新西兰等伙伴整合在一起。

## 东盟的主要机构：谁作决定？

东盟常被误解为一个中央集权的官僚机构。事实上，它是一个由成员国驱动、主席国轮替的组织。

**东盟峰会**是最高决策机构，汇集各国国家元首或政府首脑。它通常每年在担任主席国的国家召开两次会议。

**东盟秘书处**设于印度尼西亚雅加达，依据1976年《东盟秘书处设立协定》成立。它协调并支持东盟决定的执行，但对成员国没有强制权力。

**东盟秘书长**领导秘书处。现任秘书长是高金洪博士（Dr. Kao Kim Hourn），第15任秘书长，于2023年1月上任，是首位担任该职位的柬埔寨公民。

**东盟轮值主席国**按成员国英文国名的字母顺序每年轮替。主席国举办峰会，设定当年的主题和优先事项，并主持主要会议。正是这一机制让马来西亚在2025年坐上驾驶座。

## 马来西亚作为2025年东盟轮值主席国的角色

马来西亚于2025年**第五次**担任东盟轮值主席国——继1977、1997、2005和2015年之后。接力棒是在2024年10月万象举行的第44届和第45届东盟峰会闭幕时从老挝接过的，而主席任期于2025年1月1日正式开始。首相安华·依布拉欣（Anwar Ibrahim）在这一整年领导该集团。

其主题是**「Inclusivity and Sustainability」**（包容与可持续）。这一主题的选择意味深长：2025年标志着东盟共同体成立十周年，是为接下来二十年设定方向的自然节点。根据马来西亚财政部和Bernama，马来西亚全年在全国各地举办了超过300场会议和活动（确切数字需由官方来源核实）。

马来西亚2025年主席任期内的主要进展，如官方来源和新闻机构所报道，包括：

- **东帝汶加入成为第11个成员国**，于2025年10月吉隆坡第47届峰会上敲定——这是东盟自1999年以来的首次扩员。
- **通过《东盟共同体愿景2045》**，主题为「Resilient, Innovative, Dynamic, and People-Centred ASEAN」，于2025年5月26日在吉隆坡第46届东盟峰会上通过，同时通过了《关于东盟2045的吉隆坡宣言》。这一愿景为东盟未来20年的方向绘制蓝图。
- **柬埔寨—泰国边境和平努力**，马来西亚在其中担任斡旋者（正式文书的名称和范围需核实）。
- 举办新平台，如**东盟—海湾合作委员会（ASEAN–GCC）**和**东盟—海湾合作委员会—中国（ASEAN–GCC–China）**会议，扩大区域外交影响力。

马来西亚在整个2025日历年担任东盟轮值主席国。在2025年10月28日第47届东盟峰会闭幕仪式上，主席权杖移交给菲律宾；然而菲律宾自2026年1月1日起才正式担任主席国。

## 正确理解东盟的框架

东盟之所以复杂，是因为它被刻意建构得松散。要准确解读任何东盟议题，请按顺序问以下三个问题：

1. **属于哪个支柱？** 安全议题（南海、缅甸）归APSC；贸易和投资议题归AEC；灾害、教育和文化议题归ASCC。支柱决定涉及哪些会议和哪些官员。
2. **属于哪个机构？** 重大政策决定来自峰会；日常协调来自秘书处。切勿把秘书处的声明误认为是对成员国具约束力的决定。
3. **是否具约束力？** 大多数东盟成果是宣言和行动计划，而非可强制执行的法律。宪章具约束力；大多数峰会声明属于政治承诺。

## 关于马来西亚与东盟的常见误解

- **以为马来西亚「加入」东盟。** 马来西亚于1967年创立东盟，并非后来才加入。
- **以为东盟有10个成员国。** 这个数字在2025年10月之前是正确的。自东帝汶于2025年10月26日加入后，东盟有11个成员国。
- **混淆《曼谷宣言》与《东盟宪章》。** 《曼谷宣言》（1967年）创立东盟且不具约束力；《东盟宪章》（2008年生效）才是其法定文件。
- **把东盟等同于欧盟。** 东盟没有共同货币、没有超国家议会，且以共识而非多数投票作出决定。
- **以为主席国拥有统治权力。** 主席国设定议程并举办会议，但无法强迫其他成员国。决定仍须协商一致。

## 接下来做什么

如果你想深入了解某个特定部分，请从与你需求最相关的支柱入手——经济（AEC和RCEP等贸易协定）、安全（APSC），或社会文化（ASCC）。要核实任何东盟事实，请查阅东盟秘书处官方门户 `asean.org`，而关于马来西亚的立场，请查阅外交部（Wisma Putra）网站 `kln.gov.my`。阅读有关峰会的新闻时，请务必检查某项成果究竟是政治宣言还是真正具约束力的文书——这一区别对于理解东盟实际如何运作至关重要。
