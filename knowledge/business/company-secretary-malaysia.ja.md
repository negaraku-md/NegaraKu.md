マレーシアの会社秘書役について書かれたもののほとんどは、会社秘書役自身によって書かれている。

それは別にスキャンダルではない——彼らはこの主題を知っている当人たちなのだから。しかしそれは、
入手できる案内が一つの問い（「なぜ私たちが必要なのか」）には徹底的に答える一方で、もう一つの
問い（「私は実際に何に対してお金を払っているのか」）にはほとんど答えていないことを意味する。
このページが扱うのは、その二つ目の問いである。

## 実際に義務なのか？

その通りであり、しかも小規模企業向けの例外はない。

2016年会社法（Companies Act 2016、Act 777）s.235(1)：会社は、自然人であり、18歳以上であり、
マレーシアの市民または永住者であって、マレーシアに主たる居所を有することによって通常居住する、
少なくとも1名の秘書役を置かなければならない。

s.236(2)：最初の秘書役の任命は、会社設立の日から30日以内に行わなければならない。

s.235に違反する会社およびすべての取締役は、犯罪を犯したことになる。休眠に対する免除はなく、
売上高の基準もなく、まだ営業を開始していない会社に対する猶予もない。

## 誰が秘書役になれるか

関門は二つあり、その両方をクリアしなければならない。

**関門その一——人物要件。** 自然人であり、18歳以上であり、市民または永住者であり、マレーシアに
通常居住していること（s.235(1)）。

**関門その二——資格要件。** 同法のFourth Schedule（第四附則）に掲げる団体の会員であるか、または
2001年マレーシア企業委員会法（Companies Commission of Malaysia Act 2001）のs.20Gに基づき企業
委員会（SSM）の免許を受けた者であること（s.235(2)）。大臣は官報告示により、さらに団体を指定する
ことができる（s.235(3)）。

それに加えて、実務に従事しようとする有資格者は、登記官に登録し、開業証明書を保持しなければ
ならない（s.241）。SSMは秘書役の登記簿を保持しており、各秘書役の氏名、住所および事業所の所在地、
ならびに資格の詳細を記録している（s.241(2)）。

**取締役との非対称性に注意すること。** 取締役は、マレーシアに主たる居所を有することによって通常
居住していればよい（s.196(4)）——実際にマレーシアに住んでいる外国人であれば、それで資格を満たす。
これに対し秘書役は、**市民または永住者**でなければならない。外国人の創業者は、しばしばこの二つの
基準が同じものだと思い込む。しかしそれらは同じではない。

### 誰が資格を失うか

s.238(1)のもとで、次のいずれかに該当する者は秘書役として職務を行う資格を失う——復権していない
破産者であること、マレーシア国内または国外においてs.198にいう犯罪について有罪判決を受けたこと、
または、s.241のもとで発行された開業証明書を保持しなくなったこと。

資格を失った者が職務を続ける場合、その者と、それを知りながら許容したすべての取締役の双方が犯罪を
犯したことになる（s.238(3)）。したがって、開業証明書を確認することは、彼らだけの問題ではなく、
あなた自身の問題でもある。

## 同法が実際に彼らに求めていること

ここが、営業資料が飛ばす部分である。

Companies Act 2016は、**誰が秘書役になれるか**については詳細に定めている一方で、**秘書役が何を
しなければならないか**についてはほとんど何も述べていない。法定の職務記述というものは存在しない。
同法における届出および記録保存の義務は、*会社*およびその*役員*の側にある——登記簿の保持、会計
記録の保持、年次報告書（annual return）の呈出、財務諸表の呈出——そして秘書役は、それらの義務が
慣行として履行される際に経由する、免許を持つ専門家である。

そこから二つの帰結が生じ、それこそが本稿の要点である。

1. **サービスの範囲は契約上のものであり、法定のものではない。** 価格が大きく異なる二つの見積もりは、
   必ずしも一方が誠実でもう一方が強欲だというわけではない。それらは通常、範囲が異なる二つのもので
   ある。あなたが比較すべきなのは委嘱状であり、それを一行ずつ比較することである。
2. **秘書役だけが許された署名者ではない。** s.68(5)は、年次報告書は取締役*または*秘書役が署名する
   ものと定めている。同法が認める範囲では、会社自身が書類を呈出することもできる。実務上、ほとんど
   のオーナーは委託を選ぶ——ポータルや様式は慣れた者に有利にできているからである——しかし委託は
   利便性についての選択であって、あらゆる作業について法が強制するものではない。

## 顧問契約に通常含まれるもの、通常含まれないもの

秘書役サービスについて公式の料金表は存在せず、業者の価格設定は引用可能な情報源ではないため、
以下は価格表ではなく構造の見取り図である。書面での提示を求めること。

| 通常、年間顧問契約に含まれるもの | 通常、別途請求されるもの |
| --- | --- |
| 指名された秘書役と法定の職 | 会社設立そのもの |
| 法定登記簿の維持 | 取締役、秘書役または監査人の変更 |
| 例年の定型的な届出 | 株式の譲渡または割当、および割当申告書 |
| 標準的な年次決議および議事録 | 定款の採択または変更 |
| 基本的なコンプライアンス・リマインダー | 会社名の変更 |
| | 登録事務所／郵便物処理サービス |
| | 特別決議および臨時総会 |
| | 登記抹消または清算 |
| | SSMの法定手数料および立替費用 |

その最後の行こそ、最初に確認すべきものである。**SSMの手数料は立替払いであり、かつ公表されて
いる。** 私会社の年次報告書の呈出手数料はRM150、監査済み財務諸表の呈出はRM50、未監査はRM20、
会社名の変更はRM100、定款の変更はRM30、書類呈出の期限延長はRM100である。これらはSSMのROC
手数料表による政府の課金であり、専門家報酬ではない。それらを区別のない「年間コンプライアンス・
パッケージ」にまとめた見積もりが誤りだというわけではないが、求めれば個別に示してもらえるはずで
ある。

### 見積もりを比較可能にする五つの質問

- SSMの法定手数料は含まれているか、それとも実費で別途加算されるか？
- 取締役、株主または住所の変更は、年間何件まで含まれているか？
- 登録事務所の住所は含まれているか、また銀行や税務関係の連絡先として使用できるか？
- 年次報告書と財務諸表の呈出は誰が準備するのか——あなたか、それとも私の会計士か、そしてその費用は
  この料金の内か外か？
- 私が別の事務所に移る場合、登記簿を引き渡して辞任してもらうための費用はいくらか？

最後の質問は診断的である。明確で見積もり済みの引き継ぎプロセスを持つ事務所は、その関係がどのように
終わることを想定しているかについて、何かを物語っている。

## 秘書役の交代

秘書役は、取締役会への通知により辞任することができ、その通知から30日が経過した時点、または定款
もしくは任命条件に定める期間の経過をもって、その職を離れる（s.237(1)および(3)）。いずれの取締役
にも、最後に判明している住所で連絡が取れない場合、秘書役は登記官に直接通知することができ、30日後
にその職を離れる（s.237(2)）。

取締役会は、任命条件または定款に従って秘書役を解任することができる（s.239）。

双方に共通する制約はs.240である。**その職を、いかなる一度の空席期間においても30日を超えて空けた
ままにしてはならない。** 現任の事務所を辞めさせる前に、後任の事務所を手配しておくこと。引き継ぎを
めぐる紛争——通常は、会社に帰属する法定登記簿と会社自身の議事録簿をめぐるもの——が、意図しない
空席が生じる最も一般的な原因である。

## よくある誤り

- **休眠会社は秘書役なしで済むと思い込むこと。** s.235には休眠に対する免除がない。一度も営業した
  ことのない会社であっても、秘書役は必要である。
- **外国人の取締役が秘書役を兼任できると思い込むこと。** s.235(1)(c)により、市民権または永住権が
  求められる。
- **範囲を比較せずに見積もりを比較すること。** 価格の差は、通常は範囲の違いに加えて、SSMの手数料が
  内か外かの違いである。
- **開業証明書を確認しないこと。** s.238(1)(c)は、これを保持しなくなった者の資格を失わせ、
  s.238(3)は、それを知りながら継続させた取締役に責任を負わせる。
- **新しい秘書役を任命する前に、旧い秘書役を辞任させること。** s.240は空席期間の上限を30日と定めて
  いる。
- **秘書役があなたの登記簿を所有していると思い込むこと。** 法定登記簿と議事録簿は会社の記録であり、
  s.47のもとで登録事務所または通知された代替の場所に保管される。

## 次にすべきこと

委嘱状を入手し、含まれるものよりも先に除外されるものを読むこと。それから、開業証明書をSSMの
登記簿と照合すること。

もし、まだ最初の1年目にあるなら、秘書役の任命は、会社設立日から起算が始まる十数件の期限付き義務
の一つにすぎない——危機が起きるたびに一つずつ対処するのではなく、残りの義務も同時に洗い出して
おくこと。
