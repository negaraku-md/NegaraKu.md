マレーシアには三十いくつかの商業港があるが、コンテナで重要なのは二つだけである。国際空港は六つあるが、大規模に空輸貨物を動かしているのは一つだけである。自分の立地がその境界線のどちら側にあるかを知ることは、州のパンフレットに載っているどんな施設一覧よりも価値がある。

以下の数字はすべて、運輸省自身のソースファイル、MCMCの四半期統計、またはエネルギー委員会（Energy Commission）の規制検討報告のいずれかに由来する。公式な数字が存在しない箇所——そしてECRLの貨物運送能力については実際に存在しない——については、埋め合わせるのではなく、その旨を明記する。

## どの港が実際に取扱量を動かしているのか？

2025年のコンテナ取扱量、出典は運輸省の海事統計：

| 港 | 2025年TEU | 2024年TEU |
| --- | --- | --- |
| **クラン港**（Northport及びWestports） | **15,138,772** | 14,644,527 |
| **タンジュン・プレパス**（ジョホール） | **14,028,375** | 12,253,309 |
| ペナン | 1,351,448 | 1,416,450 |
| ジョホール港（パシール・グダン） | 1,081,675 | 1,059,117 |
| サバ（全港湾合計） | 533,332 | 501,944 |
| クチン | 325,431 | 305,197 |
| ビントゥル | 305,308 | 342,429 |
| クアンタン | 145,234 | 147,460 |
| **マレーシア** | **33,070,778** | 30,798,477 |

二つの港が全国のコンテナ数の88%を運んでいる。それ以外はすべて一桁小さく、しかもその差は広がっている——PTPは一年で14.5%成長した。

**しかし規模は、あなたにとっての有用性と同じではない。** トランシップメント（積み替え貨物）は2025年の全国合計の**2,190万TEU、すなわち66.2%**を占めた。PTPは**95.3%**がトランシップメントであり、クラン港は55.6%である。その量の大半は、マレーシアに入ることも出ることもない。高いトランシップメント比率が地元の輸出業者にもたらすものは、実在するが間接的なものである——より多くの航路サービス、より多くの直航便、より良い便数。それは周辺の産業基盤について何も語らない。

バラ積み貨物とプロジェクト貨物では、順位はまったく変わる。2025年の貨物トン数（千貨物重量トン）：クラン港248,705・PTP153,992・**ビントゥル45,072**・ペナン30,724・ジョホール港30,256・サバ28,685・クアンタン21,339・ポート・ディクソン15,130・クチン10,451・ケママン7,802。

ビントゥルはトン数で全国第3位、コンテナ数では第8位であり、これはまさに液化天然ガス及びバラ積み貨物港の姿である。同港自身の年次報告書はコンテナ容量を年間350,000TEUとしており——コンテナの面ではほぼ満杯に近く、コンテナ集約型の事業を吸収することはない。**ケママンは部門の表のいずれの年においても、コンテナをまったく取り扱っていない。**

容量は、すでに取扱量がある場所に追加されつつある。運輸省自身の発表は、**Westportsの CT10 から CT17 への拡張により、2028年までに容量が1,400万TEUから2,800万TEUへと倍増する**と記録しており、Carey Islandは2060年までに3,000万TEUを目標としている。

## どこから空輸貨物を送り出せるのか？

2024年の空輸貨物（メートルトン）、出典は運輸省の年鑑——これが唯一の公式情報源である。Malaysia Airportsは2024年12月以降、交通統計を一切公表しておらず、空港別の貨物トン数もこれまで一度も公表していないからである：

| 空港 | 2024年トン数 |
| --- | --- |
| **KLIA（第1・第2ターミナル）** | **809,333** |
| ペナン | 114,551 |
| コタキナバル | 57,113 |
| クチン | 53,534 |
| タワウ | 8,905 |
| **ジョホールバル（スナイ）** | **6,742** |
| スバン | 5,994 |
| ミリ | 4,736 |
| **マレーシア** | **1,073,082** |

KLIAは全国の空輸貨物の75%を占める。ペナンは114,551トンで、意味のある取扱能力を持つ唯一の他の空港であり、これは電子産業クラスターが統計に現れたものである——高付加価値・低重量・時間制約の厳しい貨物こそ、E&Eサプライチェーンが生み出すものそのものである。

**スナイについては特に注意が必要である。** ジョホールバルは2024年に6,742トンを取り扱った——KLIAの1%にも満たない。同空港を運営するのはSenai Airport Terminal Servicesであり、Malaysia Airportsではない。空輸貨物を必要とするジョホールの事業は、現実にはKLIAまたはシンガポールのチャンギ空港までトラック輸送することになり、それは想定から外すのではなく、モデルに組み込んでおくべきである。

## ECRLは実際に何を変えるのか、そしていつ変わるのか？

東海岸鉄道連絡線（East Coast Rail Link、ECRL）は**2026年2月時点で92.62%が完成**しており、コタバルからゴンバまでの区間519km全線で軌道が敷設済みである。見出しの数字よりも、段階分けのほうが重要である。

| 区間 | 完工 | 運行開始 |
| --- | --- | --- |
| コタバル～ゴンバ | 2026年12月 | **2027年1月** |
| ゴンバ～ポートクラン | 2027年12月 | **2028年1月** |

2028年1月までは、この路線は東海岸とクラン・バレーの縁を結ぶのであって、港とは結ばれていない。ポートクランまでの直通運行を前提とする2027年の物流計画は、1年早い。

路線は五つの州と一つの連邦直轄区にまたがる665kmで、三区間に分かれる——コタバルからドゥンゴン、ドゥンゴンからムンタカブ、ムンタカブからポートクラン——20の駅、Kertih、ケママン及びクアンタン港への貨物支線、そしてジャラン・カスタムからNorthport及びWestportsへの複線支線を有する。**運輸省自身のプロジェクトページはいまなお640kmと記載している**が、これは既に取って代わられた線形の数字である。同ページはLRT3の開業を2024年2月としたままであり、ゲマスからジョホールバルまでの区間を完全に省いている。運輸省とプロジェクト会社の記述が食い違う箇所では、プロジェクト会社の記述が最新である。

**陸橋（ランドブリッジ）は公式政策であり、売り込み文句ではない。** Kuantan Port Consortium、Northport及びMalaysia Rail Linkは2024年8月19日、交通大臣立ち会いのもと覚書を締結し、*クアンタン港とクラン港を結ぶECRL陸橋*を実現することとした。MRLの最高経営責任者は、シンガポールを迂回する航路をなくすことで、船舶の航行時間を最大2.5日短縮できると述べたと引用されている。

これに対して踏まえておくべきことが二つある。第一に、**公式な貨物運送能力の数字は存在しない**——トン数でも、TEUでも、列車の運行頻度でも。公表されているのは**貨物70%対旅客30%という容量配分**と、**80km/hの貨物設計速度**である。ネット上に出回っているトン数の数字には政府の出典がなく、頼るべきではない。第二に、総費用は**RM749.6億**である——建設費RM502.7億に、開発費RM246.9億を加えたものである。「RM500億」を引用する報道は、建設部分のみを引用しているにすぎない。

## 鉄道貨物輸送は今日、現実的な選択肢か？

たいていの計画が想定する以上に、現実的である。KTMBの公式数字、2024年：**600万トン**、11.94億トンキロ、そして**540,446TEU**——2022年の324,764TEUから増加した。

2024年の貨物種類別（千トン）：海上コンテナ3,839・セメント及びクリンカー1,090・**陸橋（Landbridge）469**・加工食品及び飲料355・化学品248。

海上コンテナは鉄道貨物トン数のおよそ64%を占めており、これは鉄道がすでにニッチなバラ積み輸送モードとしてではなく、港湾のドレージ（横持ち輸送）として機能していることを意味する。そして**KTMBはすでにLandbridge（陸橋）と呼ばれる貨物区分を運行している**——タイへ向かうSetia JayaからBang Sueまでのサービスである——これは2015年の133,000トンから2024年の469,000トンへと増加しており、トンキロは2024年だけでほぼ倍増した。ECRL陸橋は、すでに測定されている何かの延長であって、新しい概念ではない。

パダン・ブサール、バターワース、Northport及びパシール・グダンにサービスが提供されている。**どの港が稼働中の鉄道側線を有しているかについて、統合された公式声明は存在せず**、PTP及びWestportsにおける現状は、いずれの港湾当局によっても確認できなかった——それを前提に設計する前に、具体的なターミナルを確認すること。

旅客側では、ゲマスからジョホールバルまでの電化複線——195km——がすでに商業運行に入っている。2026年4月18日発効のKTMB公式時刻表には、JB Sentralとゲマスをつなぐ ETS サービスが22本掲載されている。

## 接続性はどこにあるのか？

MCMCの2026年第1四半期のFacts and Figuresは、州別に両方の指標を示している。全国の5Gカバー率は**82.4%**、4Gは99.73%である。

パーリスは示唆に富む行である。5Gカバー率91.4%でありながら、固定ブロードバンドは100施設あたり25.2と全国最悪である。モバイルカバレッジと固定インフラは同じ資産ではなく、対称的で低遅延の固定回線容量を必要とする事業は、一方をもう一方で代替することはできない。

この表について二点、注意が必要である。MCMCは固定回線の数字を**100世帯あたりではなく100施設あたり**と表示しており、その自身の注記は、この数字に商業及び政府向けの契約が含まれると述べている——したがってこれは世帯普及率ではない。また、5Gの割合は**2025年第4四半期以降、小数点第1位まで変化していない**——これは展開がまだ伸びているのではなく、頭打ちになっていることを示している。

MCMCは自ら**平均又は中央値のブロードバンド速度を公表していない**——そのInternet Users Surveyで引用される速度の数字はOoklaのデータであり、脚注にもそう明記されている——また**州レベルのインターネット普及率も公表していない**。

## 産業用電力はどれほど信頼できるのか？

エネルギー委員会（Energy Commission）が2026年4月に公表した初のAnnual Regulatory Review、及びTNB自身の年次報告書より：

| 地域 | 2025年SAIDI、顧客一人当たり年間分数 |
| --- | --- |
| クアラルンプール | 20.28 |
| **マレー半島** | **46.93**（2024年：47.88） |
| W.P. ラブアン | 82.16 |
| **サバ** | **187.13**（2024年：203.65） |

サバの停電分数は、半島の数字の4倍である。改善はしている——前年比で16分の減少——が、停電を許容できない工程は、セランゴールでは不要な形で、サバでは予備発電のコストを織り込む必要がある。**この四つの数字を超える州レベル又は地域レベルのSAIDI内訳は公表されておらず**、TNB自身の報告書は、異なる箇所でサバを187.13と186.00の両方として記載している。

半島の送電網の余力、2025年：設備容量**28,192MW**、ピーク需要は2025年5月28日に**21,049MW**、予備率**25%**——2024年の29%から低下した。容量構成は石炭43.20%、ガス41.16%、水力7.98%、太陽光6.64%、小水力1.02%である。予備率の低下がデータセンターの負荷増加と重なっていることこそ、電力を大量に消費するプロジェクトであれば注視すべき点である。

## よくある誤り

**トランシップメント量を経済活動として読むこと。** マレーシアのコンテナ取扱量の3分の2は、コンテナが船を乗り換えているだけである。PTPの95.3%がトランシップメントであるという事実が語るのは、海運アライアンスのことであって、ジョホールの産業基盤のことではない。

**2027年にECRL経由でポートクランへ至る物流ルートを計画すること。** 西側区間は2028年1月まで運行しない。

**ECRLの貨物トン数を公表すること。** 公式な数字は存在しない。出回っている数字には出典がない。

**スナイが空輸貨物を扱えると想定すること。** 2024年の6,742トンはKLIAの取扱量の1%にも満たず、しかもMalaysia Airportsの施設ではない。

**ペナン港自身のウェブサイトを引用すること。** そのコンテナサービスのページは、いまなお2017年の「150万TEU超」を引用している。運輸省の2025年の数字は1,351,448であり——ペナンは後退しているのに、運営者のページはそれを隠している。

**現行の交通量データにMalaysia Airportsを用いること。** 同社は2024年12月以降公表を停止しており、そもそも空港別の貨物トン数を公表したことは一度もない。

## 次のステップ

立地を輸送モードに合わせること。コンテナはクラン港またはPTPから、バラ積み及びガスはビントゥルまたはケママンから、空輸貨物はKLIAから——ペナンが唯一の現実的な代替である。次に、人材がそこにいるかどうかを[地域別人材供給](/ja/business/talent-availability-by-region)で、そしてその拠点を運営するのにいくらかかるかを[地域別事業コスト](/ja/business/business-costs-by-region)で確認すること。回廊奨励措置が検討材料に含まれるなら、[州投資機関](/ja/business/state-investment-agencies)が実際に誰がそれを付与できるのかを示している。
