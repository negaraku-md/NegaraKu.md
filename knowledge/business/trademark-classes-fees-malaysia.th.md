answer: "มาเลเซียใช้การจำแนก Nice — จำพวกสินค้า 34 จำพวกและจำพวกบริการ 11 จำพวก MyIPO เรียกเก็บต่อจำพวก ไม่ใช่ต่อคำขอ: RM950 ต่อจำพวกหากถ้อยคำสินค้าและบริการของคุณนำมาจากรายการที่ได้รับอนุมัติล่วงหน้าของ MyIPO, RM1,100 ต่อจำพวกหากไม่ใช่ การต่ออายุคือ RM1,000 ต่อจำพวกทุกสิบปี คำขอเดียวอาจครอบคลุมหลายจำพวกภายใต้ s.18 ของ Trademarks Act 2019 แต่ค่าธรรมเนียมยังคงคูณเพิ่ม"
keyTakeaways:
  - "45 จำพวก: 1 ถึง 34 เป็นสินค้า, 35 ถึง 45 เป็นบริการ"
  - "การยื่นคือ RM950 ต่อจำพวกจากรายการที่ได้รับอนุมัติล่วงหน้า, RM1,100 ต่อจำพวกในกรณีอื่น"
  - "การต่ออายุ RM1,000 ต่อจำพวก; การต่ออายุล่าช้า RM1,200; การฟื้นฟู RM1,500"
  - "การคัดค้าน RM950 ต่อจำพวก, คำแก้คำคัดค้าน RM350 ต่อจำพวก"
  - "การตรวจสอบแบบเร่งด่วน RM1,000 ต่อจำพวกเพิ่มจากค่าธรรมเนียมการยื่น"
  - "การบันทึกการโอนสิทธิคือ RM300 ต่อคำขอ; สัญญาอนุญาตให้ใช้สิทธิคือ RM100 ต่อจำพวก"
  - "ค่าธรรมเนียมการจัดการของ MyIPO สำหรับคำขอระหว่างประเทศ Madrid คือ RM200 — ค่าธรรมเนียมของ WIPO เองแยกต่างหากและชำระเป็นฟรังก์สวิส"
appliesTo: "ผู้ใดที่กำลังตั้งงบสำหรับการยื่นเครื่องหมายการค้ามาเลเซียหรือกำลังตัดสินใจว่าจะครอบคลุมกี่จำพวก"

faq:
  - q: "ฉันต้องมีกี่จำพวก?"
    a: "มากเท่าที่บรรยายสิ่งที่คุณขายจริง บวกกับสิ่งที่คุณกำลังจะขาย ร้านกาแฟที่ขายกาแฟบรรจุหีบห่อโดยทั่วไปต้องการจำพวก 30 สำหรับกาแฟและจำพวก 43 สำหรับบริการร้านกาแฟ แต่ละจำพวกเป็น RM950 หรือ RM1,100 แยกต่างหาก ดังนั้นจำนวนจำพวกจึงเป็นตัวขับเคลื่อนต้นทุนที่ใหญ่ที่สุดเดียว"
  - q: "ความแตกต่างระหว่างค่าธรรมเนียม RM950 และ RM1,100 คืออะไร?"
    a: "RM950 (รหัสค่าธรรมเนียม TMA2A) ใช้ในกรณีที่ทุกรายการในรายละเอียดของคุณนำมาจากรายการสินค้าและบริการที่ได้รับอนุมัติล่วงหน้าของ MyIPO RM1,100 (TMA2B) ใช้ในกรณีที่คุณร่างถ้อยคำของคุณเอง MyIPO ระบุว่าความรับผิดชอบในการอ้างรายการที่ได้รับอนุมัติล่วงหน้าอยู่ที่ผู้ยื่นคำขอ"
  - q: "คำขอหลายจำพวกถูกกว่าคำขอแยกกันหรือไม่?"
    a: "ไม่ มาตรา 18 ของ Trademarks Act 2019 อนุญาตให้คำขอเดียวครอบคลุมหลายจำพวก ซึ่งประหยัดงานธุรการและให้เลขแฟ้มเดียวแก่คุณ แต่ค่าธรรมเนียมยังเรียกเก็บสำหรับแต่ละจำพวกอยู่ดี"
  - q: "ฉันอ้างหัวข้อทั้งจำพวกได้หรือไม่?"
    a: "MyIPO ไม่สนับสนุนอย่างชัดแจ้ง หัวข้อจำพวกเป็นเพียงข้อบ่งชี้ทั่วไปและอาจไม่ครอบคลุมสินค้าหรือบริการเฉพาะที่คุณสนใจ ให้ระบุรายละเอียดเป็นรายรายการแทน"

จำนวนจำพวก ไม่ใช่การยื่น คือสิ่งที่กำหนดว่าเครื่องหมายการค้ามาเลเซียมีราคาเท่าใด ทุกอย่างด้านล่างเป็นต่อจำพวก

## จำพวกเครื่องหมายการค้า

จำพวก 1 ถึง 34 ครอบคลุมสินค้า; 35 ถึง 45 ครอบคลุมบริการ คำอธิบายด้านล่างย่อเพื่อการปฐมนิเทศ — ตรวจสอบถ้อยคำที่แน่นอนของคุณกับรายการที่ได้รับอนุมัติล่วงหน้าของ MyIPO ก่อนยื่น

| จำพวก | ครอบคลุม |
| --- | --- |
| 1 | เคมีภัณฑ์อุตสาหกรรมและวิทยาศาสตร์ พลาสติกและเรซินที่ยังไม่แปรรูป ปุ๋ย กาวอุตสาหกรรม |
| 2 | สี น้ำมันวาร์นิช แลกเกอร์ สารให้สี หมึกพิมพ์ สารป้องกันสนิม |
| 3 | เครื่องสำอางที่ไม่ใช่ยา เครื่องประทินโฉม น้ำหอม ผลิตภัณฑ์ทำความสะอาดและซักล้าง |
| 4 | น้ำมันและจาระบีอุตสาหกรรม น้ำมันหล่อลื่น เชื้อเพลิง เทียนไข |
| 5 | เภสัชภัณฑ์ ผลิตภัณฑ์สำหรับสัตวแพทย์และสุขอนามัย ผลิตภัณฑ์เสริมอาหาร สารฆ่าเชื้อ ยาฆ่าแมลง |
| 6 | โลหะสามัญและโลหะผสม วัสดุก่อสร้างที่เป็นโลหะ เครื่องโลหะภัณฑ์ ตู้นิรภัย |
| 7 | เครื่องจักร เครื่องมือกล เครื่องมือไฟฟ้า มอเตอร์ที่ไม่ใช่สำหรับยานพาหนะทางบก เครื่องขายสินค้าอัตโนมัติ |
| 8 | เครื่องมือและอุปกรณ์ใช้มือ ช้อนส้อมมีด มีดโกน |
| 9 | คอมพิวเตอร์ ซอฟต์แวร์ สื่อที่ดาวน์โหลดได้และบันทึกไว้ อุปกรณ์ไฟฟ้าและการวัด อุปกรณ์ความปลอดภัย |
| 10 | อุปกรณ์ศัลยกรรม การแพทย์ ทันตกรรม และสัตวแพทย์ อวัยวะเทียม อุปกรณ์ช่วยเหลือ |
| 11 | อุปกรณ์ให้แสงสว่าง ความร้อน ความเย็น การหุงต้ม การอบแห้ง การระบายอากาศ การจ่ายน้ำและสุขาภิบาล |
| 12 | ยานพาหนะและอุปกรณ์การเคลื่อนที่ทางบก ทางอากาศ หรือทางน้ำ |
| 13 | อาวุธปืน กระสุน วัตถุระเบิด ดอกไม้ไฟ |
| 14 | โลหะมีค่า อัญมณี พลอย นาฬิกาและนาฬิกาแขวน |
| 15 | เครื่องดนตรีและขาตั้ง |
| 16 | กระดาษ สิ่งพิมพ์ เครื่องเขียน วัสดุบรรจุภัณฑ์ สื่อการสอน |
| 17 | ยาง พลาสติกและเรซินในรูปอัดขึ้นรูป วัสดุฉนวนและบรรจุ ท่อที่ไม่ใช่โลหะ |
| 18 | หนังและหนังเทียม กระเป๋าเดินทางและกระเป๋า ร่ม เครื่องอานม้า เครื่องแต่งกายสัตว์ |
| 19 | วัสดุก่อสร้างที่ไม่ใช่โลหะ ยางมะตอยและบิทูเมน อาคารเคลื่อนย้ายได้ที่ไม่ใช่โลหะ |
| 20 | เฟอร์นิเจอร์ กระจกเงา กรอบรูป ภาชนะที่ไม่ใช่โลหะ |
| 21 | เครื่องใช้ในครัวเรือนและครัว เครื่องครัวและเครื่องใช้บนโต๊ะอาหาร แปรง เครื่องแก้วและเครื่องกระเบื้อง |
| 22 | เชือก ตาข่าย เต็นท์ ผ้าใบกันน้ำ กระสอบ วัสดุบุนวมและเส้นใยดิบสิ่งทอ |
| 23 | เส้นด้ายและด้ายสำหรับใช้ในสิ่งทอ |
| 24 | สิ่งทอและสิ่งทดแทน ผ้าลินินในครัวเรือน ผ้าม่าน |
| 25 | เสื้อผ้า รองเท้า เครื่องสวมศีรษะ |
| 26 | ลูกไม้ งานปัก เครื่องประกอบการเย็บ กระดุม เข็มหมุดและเข็ม เครื่องประดับผม |
| 27 | พรม พรมเช็ดเท้า เสื่อ วัสดุปูพื้น เครื่องแขวนผนังที่ไม่ใช่สิ่งทอ |
| 28 | เกม ของเล่น อุปกรณ์วิดีโอเกม อุปกรณ์ยิมนาสติกและกีฬา |
| 29 | เนื้อสัตว์ ปลา สัตว์ปีก ผลไม้และผักถนอมและแปรรูป ไข่ ผลิตภัณฑ์นม น้ำมันบริโภค |
| 30 | กาแฟ ชา โกโก้ ข้าว พาสตาและก๋วยเตี๋ยว แป้งและผลิตภัณฑ์ธัญพืช ขนมปังและขนมหวาน ซอสและเครื่องเทศ |
| 31 | ผลผลิตทางการเกษตร การเพาะเลี้ยงสัตว์น้ำ และพืชสวนดิบ ผลไม้และผักสด สัตว์มีชีวิต อาหารสัตว์ |
| 32 | เบียร์ เครื่องดื่มไม่มีแอลกอฮอล์ น้ำแร่ น้ำผลไม้ น้ำเชื่อมสำหรับเครื่องดื่ม |
| 33 | เครื่องดื่มแอลกอฮอล์นอกเหนือจากเบียร์ |
| 34 | ยาสูบและสิ่งทดแทน บุหรี่และซิการ์ บุหรี่ไฟฟ้า เครื่องใช้ของผู้สูบบุหรี่ ไม้ขีดไฟ |
| 35 | การโฆษณา การจัดการธุรกิจ การบริหารธุรกิจ งานสำนักงาน |
| 36 | การประกันภัย กิจการการเงิน กิจการการเงินตรา กิจการอสังหาริมทรัพย์ |
| 37 | บริการก่อสร้างอาคาร การซ่อมแซม การติดตั้ง |
| 38 | โทรคมนาคม |
| 39 | การขนส่ง การบรรจุหีบห่อและการเก็บรักษาสินค้า การจัดการเดินทาง |
| 40 | การแปรรูปวัสดุ |
| 41 | การศึกษา การฝึกอบรม ความบันเทิง กิจกรรมกีฬาและวัฒนธรรม |
| 42 | บริการและการวิจัยทางวิทยาศาสตร์และเทคโนโลยี การวิเคราะห์อุตสาหกรรม การออกแบบและพัฒนาฮาร์ดแวร์และซอฟต์แวร์คอมพิวเตอร์ |
| 43 | การจัดหาอาหารและเครื่องดื่ม ที่พักชั่วคราว |
| 44 | บริการทางการแพทย์และสัตวแพทย์ การดูแลสุขอนามัยและความงาม บริการเกษตรกรรม พืชสวน และป่าไม้ |
| 45 | บริการทางกฎหมาย บริการรักษาความปลอดภัยทางกายภาพ บริการส่วนบุคคลและสังคม |

## ค่าธรรมเนียมการยื่นและการตรวจสอบ

| เรื่อง | รหัสค่าธรรมเนียม | ค่าธรรมเนียม (RM) |
| --- | --- | --- |
| คำแนะนำและการสืบค้นเบื้องต้น | TMA1 | 250 ต่อจำพวก |
| คำขอ รายการสินค้าและบริการที่ได้รับอนุมัติล่วงหน้า | TMA2A | 950 ต่อจำพวก |
| คำขอ ถ้อยคำของตนเอง | TMA2B | 1,100 ต่อจำพวก |

## ข้อผิดพลาดที่พบบ่อย

**ตั้งงบสำหรับค่าธรรมเนียมเดียว** สามจำพวกที่ RM1,100 เท่ากับ RM3,300 ก่อนที่ใครจะดูเครื่องหมายของคุณเสียอีก ตัดสินใจรายการจำพวกก่อน

**ร่างรายละเอียดของคุณเองโดยไม่ตรวจสอบ** การใช้รายการที่ได้รับอนุมัติล่วงหน้าของ MyIPO ประหยัด RM150 ต่อจำพวกและกำจัดข้อโต้แย้งด้านความถูกต้องตามแบบที่พบบ่อยที่สุด MyIPO วางภาระของการอ้างที่ได้รับอนุมัติล่วงหน้าไว้ที่ผู้ยื่นคำขอ ดังนั้นการอ้าง TMA2A ที่ไม่มีหลักฐานรองรับจึงเชื้อเชิญการปฏิเสธชั่วคราว

**ลืมว่าการคัดค้านมีต้นทุนทั้งสองฝ่าย** การยื่นคัดค้านคือ RM950 ต่อจำพวก; การป้องกันคือ RM350 ต่อจำพวกสำหรับคำแก้คำคัดค้าน บวก RM200 ต่อเดือนสำหรับการขยายเวลาทุกครั้ง

**สมมติว่าการโอนสิทธิบันทึกได้ฟรี** RM300 ต่อคำขอ และจนกว่าจะบันทึก s.65(2) ของ Trademarks Act 2019 ทำให้ธุรกรรมไม่มีผลต่อผู้ที่ได้ประโยชน์ที่ขัดกันโดยไม่มีการแจ้งเตือน
