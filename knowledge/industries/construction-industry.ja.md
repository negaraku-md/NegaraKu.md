請負業者登録証を持たずにRM250,000相当の学校フェンス建設を試みれば、最初の支柱を打ち込む前に、プロジェクトは即座に停止を命じられかねない。マレーシアでは、建設する権利は機械や労働力から始まるのではなく、一つの登録から始まる。

国の建設産業は、端から端まで厳格に規制された分野である。誰が入札できるか、どれほどの価値の案件を請け負えるか、誰が現場に立てるか、どのような資材を施工できるか——そのすべてが、建設産業開発庁（CIDB）という一つの法定機関に結びついている。本稿では、その構造を解説する。G1からG7の等級制度、登録要件、作業員カード、そして産業変革の方向性である。

## 誰が建設の前に登録しなければならないのか？

出発点は**Akta 520**——すなわち**1994年マレーシア建設産業開発庁法（Malaysian Construction Industry Development Board Act 1994）**である。この法令はCIDBを設立し、三つの中核的な責務を定めている。請負業者及び建設人員の登録並びに技能認証を通じて建設の質を高めること、建設資材の品質が基準を満たすことを確保すること、そして建物の安全責任を請負業者及び現場管理者に課すことである。

あらゆる建設会社にとって最も重要な規定は**s.25**である。この条項のもとで、国内・海外を問わずすべての請負業者は、適用除外を受ける場合を除き、マレーシア国内でいかなる建設工事を請け負い完成させる前にも、CIDBに登録しなければならない。

これは単なる行政上の形式にとどまらない。CIDBによれば、s.25に違反した請負業者は、有罪となった場合、**RM10,000を下回らず、RM100,000を超えない**罰金を科される可能性がある。さらに、同局は請負業者に対し建設工事の開始又は継続の停止を命じる書面通知を発する権限を有する。つまり、登録は「後で」処理できるものではなく、工事が始まる前に整っていなければならない。

登録が承認されると、請負業者は**請負業者登録証明書（PPK）**を受け取る。政府案件に入札したい請負業者は、さらに**政府工事調達証明書（SPKK）**を必要とする。

## G1からG7までの請負業者等級はどのように機能するのか？

国内の請負業者は一律に扱われるわけではない。彼らは七つの等級に分類され、この等級こそが入札可能な**案件価値の上限**を決定する。等級が高いほど、許容される案件は大きくなる。

CIDBによれば、各等級の入札上限は次のとおりである。

| 等級 | 許容される案件価値の上限 |
| --- | --- |
| G1 | RM200,000を超えない |
| G2 | RM500,000を超えない |
| G3 | RM100万を超えない |
| G4 | RM300万を超えない |
| G5 | RM500万を超えない |
| G6 | RM1,000万を超えない |
| G7 | 上限なし |

G1は、小規模な会社や新規起業家にとっての入口である——住宅改修工事、小規模な現場作業、軽微な下請け工事である。一方、G7は頂点である。価値の上限がなく、高速道路、病院、超高層ビルといった大型プロジェクトへの扉を開く。CIDBは、このG1からG7までの等級分類は国内の請負業者にのみ適用され、外国の請負業者には等級分類が存在しないと強調している。

より高い等級には、より重い条件が伴う。実績のほかに、上位等級は、より大きな払込資本と、より有資格の技術者（例えば最上位等級ではディプロマ、学位保有者又は専門エンジニア）を要求する。これにより、数千万リンギット規模の案件に入札する会社が、それを完成させる財務的・技術的能力を実際に備えていることが確保される。

登録料もまた等級によって異なる。CIDBによれば、新規登録の料率は次のとおりである。

| 等級 | 新規登録料 |
| --- | --- |
| G1 | RM20 |
| G2 | RM80 |
| G3 | RM150 |
| G4 | RM350 |
| G5 | RM700 |
| G6 | RM1,000 |
| G7 | RM1,400 |

更新には、対象となる等級に変更がないことを条件に、**登録料の50%**が課される。

## 登録の区分及び専門分野とは何か？

等級は「どれほど大きいか」という問いに答える。しかしCIDBは「どのような工事か」も問う。すべての請負業者は、等級だけでなく、工事の**区分**、及び各区分の下でさらに細分化された**専門分野コード**によっても登録される。

一般に、登録区分は異なる工事分野を包含する——建築物工事、土木工事、機械及び電気工事、並びに施設工事などである。各区分の正確な定義、及びその下にある専門分野コードの完全な一覧は、CIDBの請負業者登録マニュアルに定められており、随時更新されるため、公式の情報源で直接確認すべきである。

会社は、要件を満たせば複数の区分で登録することができる。この重層的な構造——等級、区分、専門分野——は、入札案件が通常、入札者が保持しなければならない正確な組み合わせを指定することを意味する。区分を誤った請負業者は、等級が十分に高くても資格を有しない。

## 現場の作業員も登録する必要があるのか？

必要である——そして、これはしばしば見落とされる。登録されるのは会社だけではない。**現場の個人も**登録される必要がある。

**Akta 520 s.33(1)**のもとで、何人も、同局に登録されていない限り、建設人員として従事し又は働くことはできない。この登録は建設人員登録カードによって証明され、これは一般に**グリーンカード（Kad Hijau）**として知られている。

「建設人員」の範囲は広い。それには次が含まれる。

- 一般建設作業員
- 半熟練建設作業員
- 熟練建設作業員
- 建設現場監督者
- 建設プロジェクトマネージャー

登録するには、申請者は**16歳以上**でなければならず、また**建設作業員のための安全衛生導入講習（SICW）**又はそのeラーニング版など、認定された安全証明書を保持していなければならない。カードは新規登録につき一度のみ印刷され、支払い後**14日**以内に発送される。

この要件により、安全は現場に入るための入場券となる。安全導入講習がなければカードはなく、カードがなければ仕事はない。請負業者にとって、これはコンプライアンスが会社の登録だけの問題ではなく、現場のすべての人が有効なカードを保持していることを確保する問題でもあることを意味する。

## マレーシアの建設産業はどれほどの規模なのか？

この厳格な規制構造が、大規模かつ急速に成長する分野を支えている。マレーシア統計局（DOSM）によれば、マレーシアにおける**完成建設工事額**は**2024年にRM1,588億**に達し、前年比**20.2%**の増加となった。

この勢いは年末に最も顕著であった。2024年第4四半期だけで、完成工事額は**RM420億**に達し、前年同期比**23.1%**の成長を見せた。

2024年第4四半期のサブセクター別内訳は、活動がどこに集中しているかを示している。

| サブセクター | 価値（2024年第4四半期） | 割合 | 成長率 |
| --- | --- | --- | --- |
| 土木工事 | RM156億 | 37.2% | 9.3% |
| 非住宅建築 | RM118億 | 28.0% | 24.6% |
| 住宅建築 | RM99億 | 23.5% | 38.9% |
| 特殊取引活動 | RM47億 | 11.3% | 44.9% |

同四半期の資金源別に見ると、**民間セクターがRM270億（64.2%）**を占め32.9%の成長を、**公共セクターがRM151億（35.8%）**を占め8.8%の成長を示した。これは、今日の産業が政府支出のみに頼るのではなく、より民間投資によって牽引されていることを映し出している。

土木工事は価値の面で依然として最大の柱であり——大規模なインフラプロジェクトを反映している——しかし住宅及び特殊取引のサブセクターが最も急速な成長を記録しており、建築及び専門工事に対する需要の回復を示している。

## この産業はどのように変化しているのか？

登録による規制は、一つの層にすぎない。第二の層は**変革**である——この分野の生産性、安全性、及び品質を高める継続的な取り組みである。

最初の包括的なロードマップは、**建設産業変革プログラム（CITP）2016〜2020**であった。CITPは、今や業界の基準となった評価ツールを導入した。建設工事の品質を評価する**QLASSIC**、及び現場の安全と衛生を評価する**SHASSIC**である。その二つの主要な生産性推進要因は、**ビルディング・インフォメーション・モデリング（BIM）**と**工業化建築システム（IBS）**であり——現場打ちの手法から、工場で製造されるプレキャスト部材への転換である。

CITPの期間終了後、CIDBは2021年の国際建設週間（ICW）において**国家建設政策（NCP 2030）**を発表した。NCP 2030はデジタル化の時代へと焦点を移し、**六つの戦略的柱**に沿って編成されている。

1. プロジェクト実施における品質と安全性の強化
2. 持続可能な建設環境の実践
3. 建設生産性の向上
4. インフラ維持管理の強化
5. 国際化と競争力の強化
6. 優れたガバナンスとベストプラクティスの強化

NCP 2030はまた、2030年までに達成すべき五つの目標成果を定めており、その中には**産業サイクルの50%をデジタル化する**こと、国連の持続可能な開発目標との整合、そしてインフラ維持管理を新たな経済活動とすることが含まれる。これは第4次産業革命（IR 4.0）の九つの柱の上に築かれており、明確なシグナルを発している。マレーシアの建設の未来は、データ、自動化、そして持続可能性にあるということである。

## どの等級を選ぶべきか？

新規参入する会社にとって、正しい登録等級を選ぶことは戦略的な決定であり、単に到達可能な最高等級を選べばよいというものではない。次の簡単な枠組みが役立つだろう。

- **願望ではなく、案件の現実から始める。** 今後2年間の工事価値がRM200,000未満であれば、G1で始めるだけで十分である。維持できない条件の高い等級のために費用を払うことは、後の更新を困難にするだけである。
- **区分を実際の工事に合わせる。** 道路工事を行う会社は、建築区分ではなく土木工事区分で登録しなければならない。区分を誤れば、等級が十分であっても入札資格を得られない。
- **格上げの道筋を計画する。** 等級を上げるには、より大きな払込資本と有資格の技術者が必要である。3年以内にRM300万（G4）の案件を目指すのであれば、今から実績を積み上げ、財務書類を保管し始めるべきである。
- **政府案件は早めに検討する。** 公共入札を目指すのであれば、PPKだけでは不十分であり、SPKKが必要となる。最初の入札が開かれる前にこれを計画しておくこと。
- **国際化を考慮に入れる。** NCP 2030は海外での競争力を重視しており、地域市場を志向する会社は、早い段階から品質基準（QLASSIC）及び安全基準（SHASSIC）に沿った能力を築くべきである。

## 避けるべきよくある誤り

いくつかの繰り返し起こる誤りが、特に新規参入の建設会社を陥れている。

- **登録が承認される前に工事を始めること。** s.25は、工事を請け負う*前*の登録を求めている。早く始めすぎれば、RM10,000〜RM100,000の罰金及び工事停止通知のリスクにさらされる。
- **等級の上限を超えて入札すること。** G3の請負業者はRM200万の案件を請け負うことができない。等級の上限を超えて入札すれば、その入札は無効となり、登録の評判を損なう可能性がある。
- **作業員のグリーンカードを忘れること。** 多くの人が会社のライセンスに注目する一方で、s.33の要件を見落としている。監督者やプロジェクトマネージャーを含め、現場のすべての人が有効なカードを保持し、SICWに合格していなければならない。
- **登録を失効させること。** 登録は更新しなければならない。失効させれば、回復するまで入札資格を失うことになる。更新（料金の50%）は、工事停止のリスクよりも安価である。
- **区分と専門分野の不一致。** 高い等級を保持していても、あらゆる種類の工事に資格があるわけではない。区分及び専門分野コードが、目標とする入札案件と一致していることを確認すること。
- **変革を選択肢の一つと見なすこと。** NCP 2030がBIM、IBS及びデジタル化を推進する中、適応を拒む会社は、これらの能力をますます求める大型プロジェクトの入札で取り残されるリスクを負う。

## 次のステップ

この産業に参入する、あるいは事業を拡大することを計画しているのであれば、最も実践的な一歩は、まず自社の登録状況を確認することである。CIDBのオンラインシステムを通じて自社の等級、区分及び専門分野を確認し、現場のすべての人員が有効なグリーンカードを保持していることを確認すること。

これらすべての基盤となる法的枠組みを理解するには、**Akta 520**、及び主要な規制機関としての**CIDB**の役割について、さらに読み進めていただきたい。両者は、ここで論じた等級制度及び登録要件の背後にある権限を説明するものである。

本稿の数値及び要件は、CIDB及びマレーシア統計局の公式発行物から得たものである。料率、等級上限及び資本要件は随時改定される可能性がある——登録又は入札に関する決定を行う前に、常にCIDBに直接最新の詳細を確認すること。
