まだ遠い。公立病院でこの瞬間を経験したことがある人は多い。しかしその表示板
の隣には、なぜ多くの人がそれでも戻ってくるのかを物語る料金表が貼られている。
民間クリニックでは数十リンギットかかる診察も、ここではわずかRM1で済む。問
題は公立病院が割に合うかどうかではない——実際にどう利用すれば補助料金が適
用されるのか、そして待ち時間の長さを何が決めるのか、である。

## KKM施設の構造——すべての「公立病院」が同じ階層にあるわけではない

マレーシア保健省（Kementerian Kesihatan Malaysia、KKM）は、病院、保健クリ
ニック（Klinik Kesihatan）、コミュニティクリニック（Klinik Komuniti）、歯
科クリニック（Klinik Pergigian）など、いくつかの種類の公共医療施設を設けて
おり、それぞれが同じ制度の中で独自の役割を担っている。

| 階層 | 一般的な役割 |
| --- | --- |
| 保健クリニック（Klinik Kesihatan）／コミュニティクリニック（Klinik Komuniti） | 初期治療（プライマリケア）——日常的な健康関連の用件のほとんどにおける最初の入口 |
| 県病院（Hospital Daerah） | 県レベルの一般治療および救急治療で、すべての専門診療を網羅しているわけではない |
| 専門病院／州病院（Hospital Pakar／Hospital Negeri） | 専門治療およびより複雑な紹介症例を扱い、通常は下位階層からの紹介を受け入れる |

多くの人は「公立病院」を単一のカテゴリーだと思い込んでいるが、実際には互い
に関連し合ういくつもの階層からなる施設群であり——最初にどの階層を利用する
かによって、全額補助の料金が適用されるかどうかが決まる。

## 紹介制度の仕組み

緊急を要さないほとんどの治療の場合、通常の流れは次のとおりである。

1. **まず保健クリニック（Klinik Kesihatan）または県病院で医師の診察を受け
   る。** これは初期評価の段階であり、専門治療が始まる場所ではない。
2. **医師が専門医の診察が必要と判断した場合、** 関連する病院の専門外来宛て
   に書面の紹介状が発行される。
3. **専門外来への初診時にはその紹介状を持参する。** これによって適用される
   料金が変わる。

その差は料金の段階に如実に表れる。あるKKM施設（Hospital Tengku Ampuan
Afzan、HTAA）の公式サイトで確認された例では、政府医師からの紹介であれば専
門外来への初診は無料である——これに対し、民間の医療従事者からの紹介の場合
はRM30となる。その後の再診は、最初の紹介元がどこであったかにかかわらず、
一律RM5が課される。

真の救急の場合は紹介状を必要としない——患者はどの公立病院の救急外来（ED）
にも直接向かうことができる。

## 国民向けの補助料金——ある病院の公式な例

KKM施設の料金は、市場価格ではなく1951年料金法（Fees Act 1951、Akta 209）に
基づく規則によって定められている——これが民間セクターと比べてはるかに低い
理由である。以下の表はHTAAが公表している公式料金であり、ここでは1つの病院
の例として示す。執筆時点で他の複数の病院や州保健局のサイトにアクセスでき
ず、横断的な比較ができなかったためである。

| サービス（国民） | 料金 |
| --- | --- |
| 一般外来／救急外来 | RM1.00 |
| 専門外来、初診（政府医師の紹介） | 無料 |
| 専門外来、再診 | RM5.00 |
| 専門外来、初診（民間医療従事者の紹介） | RM30.00 |
| 病棟クラス3等、1日 | RM3.00 |
| 病棟クラス1等（4人部屋）、1日 | RM60.00 |
| 病棟クラス1等（2人部屋）、1日 | RM90.00 |
| 病棟クラス1等（個室）、1日 | RM120.00 |

病棟クラス3等（開放型の部屋で、部屋の選択はできない）は最も手厚く補助され
るクラスであり、一般の患者に最もよく利用される。病棟クラス1等はよりプライ
バシーを確保できるが、1日あたりの料金は高くなる——それでも民間病院の同等
の部屋に比べればはるかに低い。

## 非国民向けの異なる料金

非国民——訪問者、外国人労働者、一部のビザ保有者を含む——は、KKM施設におい
て同じ規則のもとではるかに高い料率を課される。同じ病院の公式料金表による
と次のとおりである。

| サービス（非国民） | 料金 |
| --- | --- |
| 一般外来 | RM40.00 |
| 救急外来 | RM100.00 |
| 専門外来 | RM120.00 |
| 病棟クラス3等、1日 | RM160.00 |
| 病棟クラス1等（個室）、1日 | RM320.00 |

病棟の保証金についても、非国民は事前により高額を求められる——病棟クラスお
よび治療の種類（内科、外科、産科）によって異なる——一方、国民の場合、同じ
病院でのクラス3等の保証金はわずか数十リンギットにとどまる。

1つ特別な例外がある——有効な**UNHCR**カード（国連難民高等弁務官事務所
〔Suruhanjaya Tinggi Pertubuhan Bangsa-Bangsa Bersatu bagi Pelarian〕に登
録された難民のもの）を提示すれば、この病院において保証金および請求料金の
**50%の減免**を受ける資格がある。

## 高齢者——制度は存在するが、正確な数字は自分で確認する必要がある

60歳以上の国民は、KKMの方針のもとで専門外来の登録料の免除および病棟クラス
3等の料金軽減を受ける資格があるという報道が広く見られる。しかし本記事で
は、その方針を掲載する公式サイトが執筆時点で確認のために直接アクセスでき
なかった（403 Forbidden）ため、**正確な数字はあえて記載していない**。

本人または家族が60歳以上である場合は、該当する病院の登録窓口で直接、適用
され得る免除や割引について尋ねてほしい——このような方針はすべてのKKM病院
で一般的に実施されているが、正確な料率はその場で確認する必要がある。

## 待ち時間の実際

病院、サービスの種類、時間帯によって異なるため、ここで統一的な待ち時間の
数字を示すことはできない。しかし、公立病院での待ち時間の長さに一貫して影
響する要因としては、次のようなものがある。

- **重症度によるトリアージ。** 救急外来（ED）では、到着順にかかわらず、よ
  り重篤な症例が先に対応される——そのため同時に到着した2人の患者でも、待
  ち時間が大きく異なることがある。
- **予約診療と飛び込み受診の違い。** 予約制で運営される専門外来は、予約な
  しで直接受け付ける窓口に比べ、通常は待ち時間が短くなる。
- **当該病院の業務負荷。** 大都市圏にある専門病院／州病院は、規模の小さい
  県病院に比べて、より多くの紹介症例を受け入れる傾向にある。
- **治療の種類。** 緊急治療（真の救急）や定型的な外来治療は、予定された待
  機手術とは完全に異なる流れをたどり、後者は通常、当該病院の待機リストに
  従って別途の待機期間を要する。

だからこそ、早期の紹介と適切な予約制度は単に料金だけの問題ではなく——プロ
セス全体にかかる時間にも影響する。

## よくある誤解

- **紹介なしで直接病院の専門外来へ行き、その後で高い料金に驚く。** 有効な
  政府医師の紹介があれば初診は無料になり得るが、それがない場合は民間紹介
  の料金（確認した病院ではRM30）が適用される。
- **料率がすべての国籍身分で同じだと思い込む。** 非国民は1951年料金法
  （Fees Act 1951）のもとではるかに高い料率を課される——これは窓口の誤り
  ではなく、別の規則によるものである。
- **窓口で高齢者の免除やUNHCRカードについて尋ねない。** この種の割引は通
  常、患者が申し出て関連書類で確認する必要があり、提示しなければ自動的に
  適用されるものではない。
- **すべての病院・すべての時間帯で待ち時間が必ず長いと思い込む。** それは
  トリアージ、予約制度、そして訪れる特定の病院に大きく左右される。
