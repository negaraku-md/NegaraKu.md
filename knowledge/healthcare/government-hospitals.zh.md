## KKM 设施的架构：并非所有「政府医院」都属同一层级

马来西亚卫生部（KKM）设有几种类型的公共医疗设施——Hospital（医院）、Klinik
Kesihatan（健康诊所）、Klinik Komuniti（社区诊所）与 Klinik Pergigian（牙科
诊所）——各自在同一体系内扮演不同角色。

| 层级 | 一般职责 |
| --- | --- |
| Klinik Kesihatan（健康诊所）／ Klinik Komuniti（社区诊所） | 初级护理——大部分日常健康事务的第一入口 |
| 县医院（Hospital Daerah） | 县级的普通与紧急治疗，未涵盖所有专科服务 |
| 专科医院／州医院（Hospital Pakar／Hospital Negeri） | 专科治疗与更复杂的转诊病例，通常接收下一层级转来的病患 |

许多人以为「政府医院」是单一类别，但实际上它是几个彼此相连的设施层级——而
首先该使用哪一层级，决定了完全津贴收费是否适用。

## 转诊制度如何运作

对大多数非紧急治疗而言，一般途径如下：

1. **先到 Klinik Kesihatan 或县医院看医生。** 这是初步评估阶段——并非专科
   治疗开始的地方。
2. **若医生评估病例需要专科诊治，** 便会开出书面转诊信，转介至相关医院的
   专科诊所。
3. **首次到专科诊所看诊时须携带该转诊信。** 这就是收费差异之所在。

差别明显反映在收费层面。以一间 KKM 医院（Hospital Tengku Ampuan Afzan，
HTAA）官方网站所确认的例子来说，若病患由政府医生转诊，首次到专科诊所看诊是
**免费**的——相较之下，若转诊来自私人医生则须缴付 **RM30**。此后的复诊则一
律收费 RM5，不论最初转诊来源为何。

真正的紧急情况不需要转诊信——病患可直接前往任何政府医院的急诊部。

## 公民的津贴收费：一间医院的官方示例

KKM 设施的收费是依据 Akta Fee 1951（Akta 209）之下的条例订定的，并非依市场
价格——这正是它远低于私人界的原因。以下表格为 HTAA 所公布的官方收费，在此
仅作为**一间医院的示例**，因为撰写本文期间，其他几间医院与州卫生局的网站皆
无法访问，故无法作交叉比对。

| 服务项目（公民） | 收费 |
| --- | --- |
| 普通门诊／急诊部 | RM1.00 |
| 专科诊所，首次看诊（由政府医生转诊） | 免费 |
| 专科诊所，复诊 | RM5.00 |
| 专科诊所，首次看诊（由私人医生转诊） | RM30.00 |
| 三等病房，每日 | RM3.00 |
| 头等病房（四人房），每日 | RM60.00 |
| 头等病房（双人房），每日 | RM90.00 |
| 头等病房（单人房），每日 | RM120.00 |

三等病房（开放式房间，不可选择房型）是津贴幅度最大、也是普通病患最常使用的
等级。头等病房提供更多隐私，但每日收费较高——仍远低于私人医院同等级房间的
收费。

## 非公民的不同费率

非公民——包括访客、外籍员工与部分签证持有人——在 KKM 设施须缴付高出许多的
费率，同样是依据上述条例订定。根据同一间医院的官方收费表：

| 服务项目（非公民） | 收费 |
| --- | --- |
| 普通门诊 | RM40.00 |
| 急诊部 | RM100.00 |
| 专科诊所 | RM120.00 |
| 三等病房，每日 | RM160.00 |
| 头等病房（单人房），每日 | RM320.00 |

非公民也须预先缴付病房按金——按病房等级与治疗类型（内科、外科或产科）而
异——相较之下，公民在同一间医院的三等病房按金仅为数十令吉。

有一项特别的例外：持有效 **UNHCR** 卡（向联合国难民署〔Suruhanjaya Tinggi
Pertubuhan Bangsa-Bangsa Bersatu bagi Pelarian〕登记的难民）者，在此医院出
示该卡后，其按金与账单收费可获 **50% 的豁免**。

## 乐龄人士：政策确实存在，但确切数字须自行查证

有广泛报道指出，年满 60 岁的公民依据 KKM 政策，可获豁免专科诊所挂号费，以及
三等病房收费的减免。不过，本文刻意**不列出确切数字**，因为撰写本文期间，展
示该政策的官方网站无法直接访问（403 Forbidden），无法查证。

若你本人或家人年满 60 岁，请直接向相关医院的挂号柜台询问可能适用的豁免或折
扣——这类政策通常在所有 KKM 医院执行，但确切的比率须在现场确认。

## 轮候时间的实际情况

本文无法在此列出统一的轮候时间数字，因为它会依医院、服务类型与时间而异。不
过，以下几项因素一贯会影响政府医院的轮候时长：

- **依病情严重程度分诊。** 在急诊部，病情较危急的病例会先获处理，不论抵达
  顺序如何——这就是为什么同一时间抵达的两名病患，等候时间可能大不相同。
- **预约与 walk-in（免预约）之别。** 采用预约制度运作的专科诊所，通常比不
  需预约、直接受理病例的柜台缩短轮候时间。
- **该医院的工作量。** 位于大城市地区的专科／州医院，往往比规模较小的县医
  院接获更多转诊病例。
- **治疗类型。** 紧急治疗（真正的急症）与常规门诊治疗，与已排期的择期手
  术，走的是完全不同的途径，后者通常须依该医院的轮候名单，另行等待一段时间。

这正是为什么及早转诊与正确的预约制度，不仅仅关乎收费——它同样影响整个流程
须耗费多长时间。

## 常见错误

- **未经转诊直接前往医院专科诊所，之后才对较高收费感到意外。** 有效的政府
  医生转诊可让首次看诊免费；若无转诊，则适用私人转诊收费（所查核医院为
  RM30）。
- **以为收费率对所有公民身份都一样。** 非公民依据 Akta Fee 1951 须缴付高出
  许多的费率——这并非柜台出错，而是另一套条例。
- **未在柜台询问乐龄人士豁免或 UNHCR 卡优惠。** 此类折扣通常须主动要求，并
  以相关文件确认，不会在病患未出示文件的情况下自动给予。
- **认为所有医院、所有时段的轮候时间必然很长。** 这在很大程度上取决于分
  诊、预约制度，以及所到访的特定医院。
