バレーボールを思い浮かべ、そこから各選手の両手を取り上げてほしい。残るもの——頭の高さのバックフリップ・アタック、胸を使ったトス、高く上げてかかとで蹴るサーブ——それがセパタクローである。世界でもっともアクロバティックなスポーツの一つであり、マレー世界のアイデンティティともっとも深く結びついた競技の一つだ。

## この籐ボールを蹴る競技はどこから来たのか？

セパタクローは、マレー世界で**セパ・ラガ**（sepak raga）として知られる古い民俗遊びから育った——文字どおり籐を編んで作ったボールを蹴ることを意味する。その原形はネットを挟んで対戦する競技ではなく、円になって行う遊びだった。選手たちが輪になって立ち、手以外の体のどの部分を使ってもよいという条件で、ボールをできるだけ長く空中に保とうとするものである。

その正確な起源はあいまいで、単一の民族に属するものではない。似たような遊びはマレー世界と東南アジア全域で発展し、この遊びの最も基本的な用語自体が、すでに二つの異なる言語に由来している。

| 名称 | 意味 |
| --- | --- |
| sepak raga | 体でボールを蹴る |
| sepak raga jaring | 体でボールをネット越しに蹴る |
| sepak bola rotan | 籐ボールを蹴る |
| takraw（タイ語） | 籐ボール |

**「sepak」**という語はマレー語で「蹴る」を意味し、**「takraw」**はタイ語で籐ボールを表す語に由来する。この組み合わせ名称そのものが、すでに地域的な妥協である——どの国もそれを自国だけのものだと主張できないという事実の反映だ。

## 民俗遊びはどのようにして競技スポーツになったのか？

転換点は1960年に訪れた。マラヤ、シンガポール、インドネシア、ラオス、タイの代表団がクアラルンプールに集まり、ルールを統一し、各地のさまざまな名称に代えて**sepak takraw**という用語を正式に採用した。これ以降、伝統的な円形の遊びは、コート・得点・セットを備えた、今日私たちが知るバレーボール式のネット競技へと発展した。

ボールも時代によって異なる。伝統的なボールは籐を手で編んだものだった——だからこそかつては「sepak bola rotan」（籐ボールを蹴る）と呼ばれた。一方、現代の公認試合球は合成素材で作られ、国際的な使用のための規格に従って12の穴と20の交点を持つ。

## セパタクローはどのようにプレーするのか？

中核となる編成は**レグ**（regu、3人制）と呼ばれる——3人1組だ。テコン（tekong、サーバー）1人が後方に立ってサーブを行い、2人の前衛（左と右）がネットに近い位置に立ってトスやアタックを担う。目標はバレーボールと同じである。相手が正当に返球できないようにボールをネット越しに送ることだ。

| 要素 | 詳細 |
| --- | --- |
| チーム規模 | 3人の選手（1つのレグ）——テコン＋2人の前衛 |
| 使用が許される体の部位 | 足・膝・胸・頭——**手は禁止** |
| コートの寸法 | 13.4 m x 6.1 m |
| ネットの高さ | 1.52 m（男子）；1.42 m（女子） |
| 各サイドの触球回数 | ボールを返す前に最大3回まで |
| 得点方式 | 1セットは15点かつ最低2点差で勝ち |
| 試合の勝利 | 2セット先取 |
| 同点 | 14-14の場合、最大17点まで試合を続行 |

得点は相手が反則を犯したときに与えられる——手でボールに触れる、ボールを自陣に落とす、あるいはボールを外に送るなどである。手の使用禁止と3回の触球制限の組み合わせこそが、この競技の最も象徴的な動作を生み出す。**バックフリップ・アタック**である。選手が跳び上がり、空中で体を反転させ、足裏を頭上高くに掲げてボールをネット越しに下へ蹴り込む。

## マレーシアでセパタクローを統括しているのは誰か？

本種目のマレーシアにおける統括団体は**PSM**である。2025年9月10日、マレーシアスポーツコミッショナーは、その正式名称を*Persatuan*（協会）Sepaktakraw Malaysiaから*Persekutuan*（総会）Sepaktakraw Malaysiaへ変更する改正を承認した——これは「協会」から「総会」への象徴的な格上げであり、本種目の運営と専門性を強化することを狙いとしている。略称PSMとロゴは維持された。

国際レベルでは、本種目は**国際セパタクロー連盟（ISTAF）**によって統括されている。ISTAFは複数の東南アジア諸国の代表による共同の取り組みを通じて設立され、マレーシア・タイ・インドネシアの関係者が重要な役割を果たした。PSMはその創設メンバーの一つである。ISTAFはルールを統一し、本種目の世界的な広がりを拡大している。地域レベルでは、セパタクローは1965年クアラルンプールの東南アジア半島競技大会（SEAP Games）以来、正式な金メダル種目として継続的に競われてきた——東南アジア半島競技大会はその後1977年に東南アジア競技大会（SEA Games）と改称された。本種目は1990年（北京）のアジア競技大会にも初登場した。

## マレーシアの世界舞台での記録はどうか？

物語がここで複雑になる。セパタクローはマレーシアを含むマレー世界に深く根ざしているが、タイは長らくエリート大会を支配してきた——とりわけタイで開催される世界で最も権威あるセパタクロー大会、**キングス・カップ**（King's Cup）である。

マレーシアが最後に団体レグ種目のキングス・カップのタイトルを獲得したのは**1988年**である。2024年までに、その待ち時間は約36年に及んだ。2024年9月8日、ナコーンラーチャシーマーで、マレーシアは団体レグ種目において再び地元タイに0-2で敗れ、このタイトルの空白を延ばした。

しかし2024年は決して暗いだけの年ではなかった。その数か月前、マレーシアは数十年ぶりの大きな勝利の一つを収め、キングス・カップそのものでもマレーシアは個人レグ種目で金メダルを獲得している。

| 種目 | 日付と場所 | 結果 |
| --- | --- | --- |
| セパタクロー・ワールドカップ——レグ決勝 | 2024年5月22日、クアラルンプール、ティティワンサ・スタジアム | **マレーシア 2-0 タイ**（15-8, 15-12） |
| セパタクロー・ワールドカップ——ダブルス（doubles） | 2024年5月22日、クアラルンプール | マレーシアが2-0で勝利（17-16, 15-13） |
| キングス・カップ——レグ種目 | 2024年9月2日、ナコーンラーチャシーマー（コラート） | マレーシア 2-0 インド（金メダル） |
| キングス・カップ——団体レグ種目（決勝） | 2024年9月8日、ナコーンラーチャシーマー（コラート） | マレーシア 0-2 タイ |

ティティワンサ・スタジアムでのあのワールドカップ優勝——ファルハン・アダム（トサー）、モハマド・シャヒル・モハマド・ロスディ（テコン）、モハマド・アズラン・アリアス（アタッカー）の布陣が地元ファンの前でタイを破った——は、世界王者としてのタイの支配に終止符を打ち、それ以前の決勝敗退に報いるものだった。それはまた同じ日の「二重の成功」の一部でもあった。マレーシアはダブルス種目も制したからである。

このパターンが今日のマレーシアのセパタクローの立ち位置を要約している。伝統がこの競技に根ざし、調子の良い日には誰にでも勝てる国でありながら、タイが最も切望されるタイトルを年々守り続けられるような安定性を、なお追い求めている国なのだ。

## 次のステップ

この競技を生で観たいなら、PSMが主催する全国セパタクロー・リーグが最も手軽な入口であり、セパタクロー種目は東南アジア競技大会（SEA Games）でも最も盛り上がる競技の一つである。なぜこの競技の伝統が同時に複数の国から主張されるのかを理解するには、その名前そのものから始めるとよい——「sepak」（マレー語）と「takraw」（タイ語）の組み合わせは、同じ一つの遊びが東南アジア各地の異なる文化によって育てられてきたことの証なのだ。
