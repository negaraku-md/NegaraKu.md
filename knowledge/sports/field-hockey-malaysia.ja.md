1975年3月15日、クアラルンプールのあるスタジアムは、インドが男子ホッケー・ワールドカップを掲げる瞬間を目撃した——それは彼らの歴史上唯一の栄冠であり——そして開催国はインドではなく、マレーシアであった。半世紀を経ても、同じ国が今なお毎年、世界のホッケー強豪をイポーに招いている。ホッケー（フィールドホッケー）は今日のマレーシアで最も人気のあるスポーツではないかもしれないが、この国が国際的に最も尊敬を集めるスポーツ遺産と言えるだろう。

## マレーシアの本当のホッケーの遺産とは何か？

その頂点は **1975年** にある。マレーシアは **1975年3月1日から15日** までクアラルンプールで **第3回男子ホッケー・ワールドカップ** を主催し、**11チーム** が参加した。決勝では、インドが満員の観客の前でパキスタンを **2–1** で破った——これは今日に至るまでインドにとって最初で唯一の世界王者の称号である。

しかしマレーシアにとって本当の物語は、自国の道のりにある。開催国は準決勝に進出し、**4位** で大会を終えた——これは国際舞台における同国の最高成績である。大会を通じて、マレーシアは **ディフェンディングチャンピオンのオランダを2–1** で破り、この結果は今なお同国のスポーツ史上最も偉大な瞬間の一つとして記憶されている。この大会はまた、豪雨と酷暑の天候により複数の試合が再スケジュールを余儀なくされたにもかかわらず、オリンピックの式典に匹敵する開催国のもてなしでも記憶に残っている。

それ以来、ホッケーはマレーシアに、この国の他の団体競技がめったに到達できない国際的な舞台を与えてきた。

## 誰がマレーシアのホッケーを統括しているのか？

全国統括団体は **マレーシアホッケー連盟**（Malaysian Hockey Confederation, MHC）である。同団体は男女のフィールドホッケーおよびインドアホッケーの代表チームを管掌し、**アジアホッケー連盟（AHF）** および **国際ホッケー連盟（FIH）** に加盟している。MHCはクアラルンプールの **ブキ・ジャリルにある国立ホッケースタジアム** を拠点に活動している。

代表チームの運営に加え、MHCは代表チームへ人材を送り込む国内大会のエコシステムを構築している。

| 大会 | レベル |
| --- | --- |
| TNB マレーシア・ホッケーリーグ（TNBMHL） | シニアプロリーグ |
| TNB マレーシア・ユースホッケーリーグ（TNBMJHL） | 全国ユースリーグ |
| TNB トゥン・アブドゥル・ラザク・カップ | チーム間／州間選手権 |
| TNB マレーシア・インドアホッケーリーグ（MIHL） | インドアホッケー |

この階層構造——シニアリーグ、ユースリーグ、州間選手権、インドアホッケーリーグ——は、マレーシアの代表選手育成の屋台骨である。

## なぜスルタン・アズラン・シャー・カップはこれほど重要なのか？

1975年が歴史の頂点だとすれば、**スルタン・アズラン・シャー・カップ** は今なお続く遺産である。この大会は **1983年** に **隔年開催** の大会として初めて開催され、その後 **2003年から年次開催** に変わった。長年にわたり **ペラ州の州都イポー** を拠点とし、世界屈指のチームの一部を招く舞台としてFIHに公認されている。

この大会は **スルタン・アズラン・シャー** にちなんで名付けられた。彼は **1989年から1994年までマレーシア国王（ヤン・ディ・プルトゥアン・アゴン）** を務めた。彼は単なる名目上の後援者ではなかった。幼少期からホッケーをプレーし、**1940年代末にはペラ州を代表して出場し**、のちに **アジアホッケー連盟の会長** を務めて、大陸全体でこの競技の発展を推進した。彼の名を冠したこのカップは、イポーを毎年、世界のホッケーカレンダーに知られる名前にしている。

近年の大会はその地位を物語る。**2025年**、第 **31回** 大会では、**ベルギー**——世界ランキングトップ3の一角——がティボー・ストックブロークのゴールにより、**インドを1–0** で破り、**初めて** スルタン・アズラン・シャー・カップを制した。**ニュージーランド** が3位に入り、開催国 **マレーシア** も韓国、オーストラリア、カナダ、インドなどのチームとともに参加した。この大会は **15試合で92ゴール** を生み出した——このエリート形式がイポーにもたらす競争水準の証である。

ベルギーの初優勝は一つの事実を思い起こさせる。このカップはほとんど常に、訪れるホッケー強豪によって持ち帰られてきた。マレーシアにとっての本当の価値はトロフィーではなく、権威ある国際大会の常設開催国としての役割にある。

## マレーシアは今日どこに位置しているのか？

FIH男子ホッケーランキングにおいて、マレーシアは2025年に世界 **13位** 前後に位置している。これはマレーシアをアジアで最も安定したチームの一つに位置づけるが、ランキングを牽引するヨーロッパとオセアニアのエリートチームの一群の外にある。正確な順位とポイントはFIHが各主要大会後に更新するため、最新の数値についてはFIHのランキングページを参照してほしい。

次の表は、審査済みの情報源に基づいてマレーシアのホッケーの地位をまとめたものである。

| 指標 | 詳細 |
| --- | --- |
| 1975年ワールドカップ（開催国） | クアラルンプール、3月1〜15日；マレーシアは4位 |
| スルタン・アズラン・シャー・カップ | 1983年から；2003年から年次；イポーにて |
| 第31回大会（2025年） | ベルギー優勝、インドを1–0で破る |
| FIH世界ランキング（男子） | 13位前後（2025年）；最新の数値はFIHを参照 |
| 次回のFIHワールドカップ | マレーシアはグループB |

MHCによれば、マレーシア男子代表チームは、ベルギーで開催される次回の **FIHワールドカップ** に向けて準備を進めており、**グループB** に組み分けされている。数名のベテラン選手が4度目のワールドカップ出場を果たすと見込まれている——1975年以降は一時達成が困難だった世界舞台への出場権が、今や再び現実のものになりつつあることを示す兆候である。

## 次のステップ

マレーシアのホッケーの歩みを追うには、国内リーグの日程と代表チームのニュースについて **MHC** の公式サイトを確認し、各主要大会後に再計算される世界ランキングの更新について **FIH** のサイトを閲覧するとよい。次回 **イポー** で開催されるスルタン・アズラン・シャー・カップは、世界レベルのチームがマレーシアの地で戦うのを目にする最良の機会であり続けている——1975年に始まった遺産への直接のつながりである。
