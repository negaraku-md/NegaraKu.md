1975年3月15日，吉隆坡的一座体育场见证了印度举起男子曲棍球世界杯——这是他们历史上唯一的一次——而东道主并非印度，而是马来西亚。半个世纪后，同一个国家仍然每年邀请世界曲棍球强国来到怡保。草地曲棍球或许不是今日马来西亚最受欢迎的运动，但它可能是这个国家在国际上最受敬重的体育传统。

## 马来西亚真正的曲棍球传统是什么？

其巅峰在于 **1975年**。马来西亚于 **1975年3月1日至15日** 在吉隆坡主办了 **第三届男子曲棍球世界杯**，共有 **11支球队** 参赛。在决赛中，印度当着满座观众的面以 **2–1** 击败巴基斯坦——这是印度至今唯一的一次世界冠军头衔。

但对马来西亚而言，真正的故事是它自己的征程。东道主晋级半决赛，并以 **第四名** 结束赛事——这是它在国际赛场上的最佳成绩。在整届赛事中，马来西亚击败了 **卫冕冠军荷兰2–1**，这一结果至今仍被铭记为国家体育史上最伟大的时刻之一。那届赛事还因东道主媲美奥运仪式的接待而令人难忘，尽管暴雨与酷热的天气迫使多场比赛重新安排。

自那以后，曲棍球为马来西亚提供了一个其他团队运动在这个国家鲜少企及的国际舞台。

## 谁管理马来西亚的曲棍球？

全国管理机构是 **马来西亚曲棍球联合会**（Malaysian Hockey Confederation，MHC）。它负责草地曲棍球与室内曲棍球的男女国家队，并隶属于 **亚洲曲棍球联合会（AHF）** 及 **国际曲棍球联合会（FIH）**。MHC 的运营基地设于吉隆坡的 **武吉加里尔国家曲棍球体育场**。

除了管理国家队之外，MHC 还构建了一套将人才输送至国家队的国内赛事生态：

| 赛事 | 级别 |
| --- | --- |
| TNB 马来西亚曲棍球联赛（TNBMHL） | 高级职业联赛 |
| TNB 马来西亚青年曲棍球联赛（TNBMJHL） | 全国青年联赛 |
| TNB 敦阿都拉萨杯 | 队际／州际锦标赛 |
| TNB 马来西亚室内曲棍球联赛（MIHL） | 室内曲棍球 |

这一分层架构——高级联赛、青年联赛、州际锦标赛及室内曲棍球联赛——是马来西亚国家球员培养的支柱。

## 为什么苏丹阿兹兰沙杯如此重要？

如果说1975年是历史的巅峰，那么 **苏丹阿兹兰沙杯** 便是延续至今的传统。这项赛事于 **1983年** 首次举办，最初是 **两年一届** 的比赛，后来在 **2003年起转为年度赛事**。长期以来，它以 **霹雳州首府怡保** 为基地，并获FIH认可，成为一个邀请世界部分顶尖球队参加的舞台。

这项赛事以 **苏丹阿兹兰沙** 命名，他于 **1989年至1994年出任马来西亚国家元首（最高元首）**。他不仅仅是挂名的赞助人：他自幼便打曲棍球，**在1940年代末代表霹雳州参赛**，后来出任 **亚洲曲棍球联合会主席**，推动这项运动在整个大陆的发展。这座以他命名的奖杯，让怡保每年都成为世界曲棍球日历上一个响亮的名字。

近期的赛事彰显了它的地位。**2025年**，第 **31届** 赛事见证了 **比利时**——世界排名前三的球队之一——通过 Thibeau Stockbroekx 的进球，以 **1–0** 击败 **印度**，**首次** 赢得苏丹阿兹兰沙杯。**新西兰** 位居第三，东道主 **马来西亚** 也与韩国、澳大利亚、加拿大和印度等球队一同参赛。那届赛事在 **15场比赛中打入92球**——证明了这一精英赛制为怡保带来的竞争水准。

比利时的首次夺冠印证了一个事实：这座奖杯几乎总是被到访的曲棍球强国捧走。对马来西亚而言，真正的价值不在于奖杯，而在于它作为一项享有盛誉的国际赛事常驻东道主的角色。

## 马来西亚今日处于什么位置？

在FIH男子曲棍球排名中，马来西亚在2025年位居世界 **第13位** 左右。这使马来西亚成为亚洲最稳定的球队之一，尽管仍处于领跑排名的欧洲和大洋洲精英球队之外。确切排名与积分由FIH在每项大型锦标赛后更新，因此请参阅FIH排名页面获取最新数据。

下表根据所审阅的资料总结了马来西亚曲棍球的地位：

| 指标 | 详情 |
| --- | --- |
| 1975年世界杯（东道主） | 吉隆坡，3月1至15日；马来西亚第4名 |
| 苏丹阿兹兰沙杯 | 始于1983年；2003年起为年度赛事；在怡保举行 |
| 第31届（2025年） | 比利时夺冠，1–0击败印度 |
| FIH世界排名（男子） | 约第13位（2025年）；最新数据请参阅FIH |
| 即将到来的FIH世界杯 | 马来西亚在B组 |

据MHC称，马来西亚男队正为即将在比利时举办的 **FIH世界杯** 做准备，并被编入 **B组**。数名老将预计将迎来他们的第四次世界杯亮相——这表明晋级世界舞台（在1975年之后一度难以企及）如今重新成为现实。
