想象一场排球赛，然后拿走每名球员的双手。剩下的——齐头高的倒挂金钩扣杀、
用胸口的传球、把球高高抛起再用脚跟踢出的发球——那就是藤球：世界上最富
杂技色彩的运动之一，也是与马来世界身份最紧密相连的运动之一。

## 这项踢藤球的运动源自何处？

藤球从一种古老的民间游戏演变而来，在马来世界称为 **sepak raga**（藤篮球）——
字面意思就是踢一颗用藤条编织的球。它最初的形态并非隔网对抗的比赛，而是
围圈游戏：一群球员站成一圈，尝试用除手以外的任何身体部位让球尽可能久地
留在空中。

它确切的起源模糊不清，也不属于某个单一民族。类似的游戏在整个马来世界和
东南亚各地发展起来，而这项游戏最基本的术语本身就来自两种不同的语言：

| 名称 | 意思 |
| --- | --- |
| sepak raga | 用身体踢球 |
| sepak raga jaring | 用身体把球踢过球网 |
| sepak bola rotan | 踢藤球 |
| takraw（泰语） | 藤球 |

**「sepak」**一词在马来语中意为「踢」，而**「takraw」**则源自泰语中表示
藤球的术语。这个组合名称本身就已是一种区域性的妥协——反映出没有任何一个
国家能够宣称它专属于自己这一事实。

## 民间游戏如何变成竞技运动？

转折点出现在1960年。来自马来亚、新加坡、印尼、老挝和泰国的代表团在吉隆坡
会面，统一规则并正式采用**sepak takraw**这一术语，取代各种地方名称。自此
以后，传统的围圈游戏发展成我们今天所熟知的排球式隔网运动，配有球场、
分数和局。

球也随时代不同而变化。传统的球是用藤条手工编织的——这正是它曾被称为
「sepak bola rotan」（踢藤球）的原因；而现代获批准的比赛用球则以合成材料
制成，按照国际使用的规格有12个孔和20个交叉点。

## 藤球是怎么打的？

核心编制称为 **regu**——三名球员一队。一名tekong（发球员）站在后方发球；
两名前排球员（左和右）站得更靠近球网，负责传球和扣杀。目标和排球一样：
把球送过球网，让对手无法合法地把它回击过来。

| 要素 | 详情 |
| --- | --- |
| 队伍规模 | 3名球员（一个regu）——tekong + 两名前排球员 |
| 允许使用的身体部位 | 脚、膝、胸和头——**禁止用手** |
| 球场尺寸 | 13.4 米 x 6.1 米 |
| 球网高度 | 1.52 米（男子）；1.42 米（女子） |
| 每一方的触球次数 | 把球送回之前最多触球三次 |
| 计分 | 一局以15分且至少领先两分取胜 |
| 赢得比赛 | 赢下两局 |
| 平局 | 若14比14，比赛继续进行至最多17分 |

当对方犯规时得分——用手触球、让球落在自己的场地内，或把球送出界。禁止
用手与三次触球限制的结合，正是造就这项运动最具标志性动作的原因：
**倒挂金钩扣杀**，球员跳起，在空中翻转身体，以高过头顶的脚掌把球向下
踢过球网。

## 谁在马来西亚主管藤球？

这项运动在马来西亚的主管机构是 **PSM**。2025年9月10日，马来西亚体育专员
批准了修订，把其正式名称由 *Persatuan*（协会）Sepaktakraw Malaysia 改为
*Persekutuan*（总会）Sepaktakraw Malaysia——这是从「协会」到「总会」的象征性
升格，旨在加强这项运动的管理和专业化。缩写PSM及其标志则予以保留。

在国际层面，这项运动由**国际藤球联合会（ISTAF）**主管，它是通过多个东南亚
国家代表的共同努力成立的，来自马来西亚、泰国和印尼的官员发挥了重要作用。
PSM是它的创始会员之一。ISTAF统一规则并扩大这项运动的全球影响力。在区域
层面，藤球自1965年吉隆坡东南亚半岛运动会（SEAP Games）以来一直作为正式
颁发奖牌的项目持续参赛——东南亚半岛运动会后来在1977年更名为东南亚运动会
（SEA Games）。这项运动也在1990年（北京）亚运会上首次亮相。

## 马来西亚在世界舞台上的纪录如何？

故事在这里变得复杂。尽管藤球根植于包括马来西亚在内的马来世界，泰国却
长期主导着顶尖赛事——尤其是**国王杯**（King's Cup），这是在泰国举办的
世界上最负盛名的藤球赛事。

马来西亚最后一次赢得团体regu项目国王杯冠军是在**1988年**。到了2024年，
这段等待已长达约36年。2024年9月8日在Nakhon Ratchasima，马来西亚在团体
regu项目中再次以0比2不敌东道主泰国，延长了这项冠军荒。

不过2024年并非全然黯淡。就在几个月前，马来西亚取得了数十年来最重大的
胜利之一，而在国王杯本身，马来西亚仍在个人regu项目中摘金：

| 项目 | 日期及地点 | 结果 |
| --- | --- | --- |
| 藤球世界杯——regu决赛 | 2024年5月22日，吉隆坡蒂蒂旺沙体育馆 | **马来西亚 2-0 泰国**（15-8, 15-12） |
| 藤球世界杯——双人（doubles） | 2024年5月22日，吉隆坡 | 马来西亚 2-0 获胜（17-16, 15-13） |
| 国王杯——regu项目 | 2024年9月2日，Nakhon Ratchasima（Korat） | 马来西亚 2-0 印度（金牌） |
| 国王杯——团体regu项目（决赛） | 2024年9月8日，Nakhon Ratchasima（Korat） | 马来西亚 0-2 泰国 |

在蒂蒂旺沙体育馆的那场世界杯胜利——由Farhan Adam（传球员）、Mohammad
Syahir Mohd Rosdi（发球员）和Mohamad Azlan Alias（扣杀员）组成的阵容在
主场球迷面前击败泰国——终结了泰国的世界冠军统治，并报了此前决赛落败之仇。
它也是同一天「双喜临门」的一部分，因为马来西亚还赢得了双人项目。

这一模式概括了马来西亚藤球今天的处境：一个遗产根植于这项运动、在状态好
时能击败任何对手的国家，但仍在追求能让泰国年复一年守住那座最令人梦寐以求
奖杯的那种稳定性。

## 下一步

如果你想现场观看这项运动，PSM主办的全国藤球联赛是最简单的切入点，而藤球
项目也是东南亚运动会上最热闹的比赛之一。要理解为何这项运动的遗产同时被
多个国家所主张，就从它的名字本身开始吧——「sepak」（马来语）与「takraw」
（泰语）的组合本身就是明证：同一场游戏被东南亚各地不同的文化共同养育长大。
