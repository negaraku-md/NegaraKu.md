マレーシアで供される地元産の米は、そのほぼすべてがMARDIの試験場で育種された品種にたどり着く。この国の水稲、養鶏、熱帯果実、そして加工食品の棚の背後には、科学をより高い収量へと変える一つの連邦研究機関が控えている。

## MARDIとは正確には何か？

マレーシア農業研究開発研究院（Malaysian Agricultural Research and Development Institute、MARDI）は、農業・食料安全保障省傘下の連邦法定機関である。MARDI法（第11号法令）のもとで1969年10月28日に正式に設立され、1971年に本格的な運営を開始した。その設立目的は、「食料、農業、農業関連産業を発展させるための新規で適切かつ効率的な技術」を生み出し、普及させることにある。

簡単に言えば、MARDIは農家や農業関連企業に代わって研究を行う存在である。作物品種を育種し、農業システムと収穫後処理システムを設計し、その成果を産業界に引き渡している。

## MARDIはどのように統治・組織されているか？

MARDIはMARDI理事会（MARDI Governing Board）が定める方針のもとで運営されており、その決定には農業・食料安全保障大臣の承認が必要である。技術的な品質はMARDI科学評議会（MARDI Science Council）が監督する。同院の戦略的方向性は、数十年にわたり、基礎研究能力の構築から技術の商業化と卓越性の文化の追求へと移行してきた。

研究活動は10の研究分野に分類されている。

| 研究分野 | 重点領域 |
| --- | --- |
| 水稲・稲米 | 稲の育種、生産、収穫後処理システム |
| 園芸 | 果物、野菜、観賞植物 |
| 工業作物 | 非食用作物およびプランテーション作物 |
| 畜産科学 | 畜産と動物衛生 |
| 食品科学技術 | 加工と食品製品開発 |
| バイオテクノロジー・ナノテクノロジー | 分子育種と先端技術 |
| 工学 | 農業機械と自動化 |
| 土壌科学・水・肥料 | 投入資材と土地管理 |
| 農業生物多様性・環境 | 遺伝資源と持続可能性 |
| 経済・社会科学 | 農業経済と普及・導入研究 |

## MARDIは稲作農家に何をもたらしたか？

稲はMARDIの最も目に見える成果である。水稲・稲米プログラムは、交配種、純系種、特殊品種、生産システム、病害虫管理技術、収穫後処理方法を開発している。同院が発表した品種は、マレーシアの水田の大半を占めている。

MARDIの稲品種の一例と、それぞれの報告された収量ポテンシャルは以下のとおりである。

| 品種 | 種類 | 報告された収量 |
| --- | --- | --- |
| MR 219 | 純系白米 | 最大10.5トン/ha |
| MR 297 | 純系白米 | 9.28〜9.52トン/ha；半島部の水田面積の約50%（2021年） |
| MR 326（Kesidang） | 白米、2024年導入 | 4.8〜7.3トン/ha |
| MR 333（Menora） | 白米、2025年発表 | 5〜9トン/ha |
| KADARIA 1 | マレーシア初の交配種 | 肥沃な地域で9.7〜12トン/ha |

主食品種にとどまらず、MARDIは香り米のMRQ品種（MRQ 76やMRQ 104など）、もち米品種（Pulut Malaysia 1、Pulut Hitam 9）、色付き米（MRM 16赤米）、そして除草剤耐性のClearfield系統（MR CL3、MR CL4）も発表している。MARDIはまた、16,000件を超える植物種質を保存する国家作物遺伝子バンクを管理しており、そのうち稲——約13,020件——が単一のコレクションとして最大規模となっている。

## MARDIは国家水稲プログラムの中でどのような位置を占めているか？

マレーシアが稲の自給率のギャップを埋めるための旗艦的取り組みが、SMART SBB、または「ミニ・スキンチャン（Mini Sekinchan）」として知られる大規模SMART水稲田プログラムである。農業・食料安全保障省が主導し、田植機とIoT（モノのインターネット）モニタリングを用いて、個々の零細農地を体系的に管理されたブロックへと統合している。

同プログラムは、平均約3.75トン/haの単収を、農家1人当たり1ヘクタールあたり7〜10トンという目標へと引き上げることを目指している。2023年半ばまでに、全国で11,000ヘクタール超をカバーし、約5,000人の農家が参加、参加地域では稲の単収を50%超引き上げていた。

MARDIの役割は上流にある。すなわち、こうした収量の飛躍を可能にする高収量の種子品種、育種ノウハウ、精密農業技術を供給することである。研究院が遺伝的資源を開発し、省がそれを大規模に展開する。

## 今後の展望

MARDIの軌跡は、商業化と気候変動に強い農業——除草剤耐性米や交配種、バイオテクノロジーを活用した育種、そしてSMART SBBのようなプログラムを支える精密農業——へと向かっている。マレーシアの食料安全保障を注視する者にとっては、MARDIの品種発表や、国家自給目標をめぐる省との協力関係に注目する価値がある。一次情報としては、同院自身のプロフィールおよび水稲・稲米研究のページが最も権威ある出発点であり、MARDI法（第11号法令）がその法定の使命を定めている。
