輸入牛の検疫が必要なとき、稲の種もみの検査が必要なとき、あるいは小売店が米を
販売したいとき——それぞれ異なる3つの政府機関が関わることがある。そしてその
すべてが、プトラジャヤにある一つの省に行き着く。どの機関が何を担当している
かを知っておけば、間違った窓口を叩かずに済む。

## 概要

| | |
| --- | --- |
| 名称 | 農業・食料安全保障省（KPKM）/ Ministry of Agriculture and Food Security |
| 種類 | 連邦省 |
| 役割 | 国家の農業、畜産、漁業及び食料安全保障の政策を策定し、実施する |
| 本部 | Wisma Tani, No. 28, Persiaran Perdana, Presint 4, Pusat Pentadbiran Kerajaan Persekutuan, 62624 Putrajaya |
| ウェブサイト | `kpkm.gov.my` |

KPKM は自らを「農業変革のリーダー（Peneraju Transformasi Pertanian）」と位置
づけている——技術部門、法定機関、そして一つの金融機関を、国家の食料政策とい
う一つの傘の下に結びつける調整機関である。

## KPKM の役割とは何か？

同省は、食料生産、農業、畜産及び漁業に関する政策の策定、監視及び実施を担い、
国家の食料安全保障アジェンダを主導している。その主要な政策アジェンダの一つ
は、国家農業食料政策（DAN 2.0）のもと、スマート農業とより効率的な作物管理
を通じて、国家の米自給率（SSL）を引き上げることである。

同省はこの業務を単一の部門として行うのではなく、それぞれが狭い所管事項を持
つ部門及び機関の集合体を通じて行っている。

## どの部門・機関が KPKM の傘下にあるか？

同省の公式ディレクトリは、傘下の機関を以下のように分類している。

| 略称 | 正式名称 | 種類 |
| --- | --- | --- |
| DOA | マレーシア農業局 | 部門 |
| DVS | 獣医サービス局 | 部門 |
| DOF | マレーシア漁業局 | 部門 |
| MAQIS | マレーシア検疫検査サービス局 | 部門 |
| MARDI | マレーシア農業研究開発研究所 | 研究機関 |
| LPP | 農民組織庁 | 法定機関 |
| FAMA | 連邦農産物マーケティング庁 | 法定機関 |
| LKIM | マレーシア漁業開発庁 | 法定機関 |
| MADA | ムダ農業開発庁 | 法定機関 |
| KADA | クムブ農業開発庁 | 法定機関 |
| LPNM | マレーシアパイナップル産業庁 | 法定機関 |
| Agrobank | マレーシア農業銀行 | 金融機関 |

このほか、同省はシャー・アラム国立植物園、公式ディレクトリに記載されている
全国各地の複数の統合農業開発地域（IADA）、そして米産業のライセンス発給を管
理する稲・米統制局を監督している。

簡単な覚え方はこうである。**部門**（DOA、DVS、DOF、MAQIS）は技術及び執行の
機能を担い、**庁**（FAMA、LPP、LKIM、MADA、KADA、LPNM）は開発・マーケティ
ングを担う法定機関であり、MARDI は研究を行い、Agrobank は資金供給を行う。

## なぜ FELDA、FELCRA、RISDA はこの一覧にないのか？

これはよくある誤解である。この3つの土地・小規模生産者関連機関は農業と結び
付けられることが多いが、KPKM の機関では**ない**。

農村地域開発省（KKDW）の公式ディレクトリは、**FELCRA Berhad** と **RISDA**
（ゴム産業小規模生産者開発庁）を、MARA、KEMAS、JAKOA 及びいくつかの地域開発
庁とともに、傘下の機関として記載している。一方 FELDA はこの KKDW のページに
は記載されておらず、FELCRA と RISDA に合わせて KKDW の傘下に置くべきだとい
う公的な提案がある——したがって、公式文書でこれに依拠する前に、現在の所属
を確認すること。

本ページにとって重要な点は次のとおりである。入植者、ゴム又はパーム油の小規
模生産者、あるいは開発計画地に関する用件であれば、出発点は KPKM ではなく
KKDW である。

## BERNAS はどのように同省と結びついているか？

BERNAS（Padiberas Nasional Berhad）は政府機関だと誤解されることが多い。し
かし実際には、政府との協定に基づいて公的な機能を担う**民間企業**である。

その歴史がこの関係を説明している。国家稲穀庁（LPN）は1971年10月20日に設立
され、世界的な食料危機を受けて米の単一輸入業者となった。Padiberas Nasional
社は1994年7月7日に法人化され、BERNAS は1996年1月12日に民営化された——LPN
の商業的・社会的な役割を引き継ぐ一方、政府は政策及び法執行に対する統制を維
持した。

ここで KPKM が関わってくる。稲・米産業は**1994年稲・米統制法（Control of
Padi and Rice Act 1994、Act 522）**のもとで規制されており、稲・米統制総局
長が精米、卸売、小売、輸入、輸出及び州間移送についてライセンスを発給する。
同省内の稲・米統制課（KPB）も、BERNAS のコンセッション協定に基づく社会的義
務（Social Obligation）の遵守を監督している。

この単一輸入業者の地位は恒久的なものではない。農業・食料安全保障副大臣
Chan Foong Hin 氏が2026年7月13日、下院（Dewan Rakyat）における2026年稲・米
統制（改正）法案の討議の総括で述べたところによれば、当該政策は2031年に満了
するコンセッション協定に沿ったものであり、政府はその満了前に同コンセッショ
ンを見直す予定である。

## 次のステップ

個別の用件については、正しい部門に直接連絡すること。作物と植物検疫は
`doa.gov.my`、畜産と動物衛生は `dvs.gov.my`、漁業は `dof.gov.my`、輸入検疫
は `maqis.gov.my` である。米のライセンスについては、稲・米統制の e-Lesen
電子ライセンスポータルを参照すること。そして、あなたの疑問が実際には入植者
やゴムの小規模生産者に関するものであれば、`rurallink.gov.my` の KKDW へと
目を向けてほしい。
