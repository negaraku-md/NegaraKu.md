[キャメロンハイランド](/ja/tourism/cameron-highlands-visitor-guide)（Cameron Highlands）の野菜農家は最高の作物を育てることができても、
農場で受け取る価格は、都市部の屋台での価格とはしばしば大きくかけ離れている。
その差——農場から食卓までの間にあるギャップ——こそが、名前が語られることは
少ないが、その成果には誰もが頻繁に触れている、ある法定機関の仕事なのである。

## FAMAは何をしているのか？

FAMAはマーケティング機関であり、生産機関ではない。人々に農業の仕方を教える
わけではない——それは他の部門の仕事である。その業務は収穫後から始まる。
すなわち、生産者が正当な収益を確保しながら、いかに適正な価格で買い手に
届けるかである。

そのマーケティング範囲は**農産食品**——野菜、果物、花卉、ならびに食品産業
製品と基礎農産物である。3つの中核目標がその業務を導いている。

1. **国内外における農産物の市場機会を拡大すること。**
2. **生産者の所得を向上させること。**
3. **農産物と食品**が消費者にとって引き続き入手しやすく、手頃な価格で
   あり続けるようにすること。

## FAMAはどのように仕事を組み立てているのか？

FAMAは、5つの開発の柱を通じてそのアプローチを示している。それぞれの柱が、
マーケティング上の課題の一部分に対応している。

| 柱 | 何を管理するか |
| --- | --- |
| 市場空間の開発 | 農産物を販売できる場所を開拓・拡大する |
| マーケティング基盤の開発 | 物理的施設——市場、集荷センター、物流 |
| 起業家育成の開発 | 農産食品分野の企業家を育成・レベルアップする |
| 製品マーケティングの開発 | 販売、プロモーションおよびブランド化プログラム |
| マーケティング規制の開発 | 登録、等級付け、包装およびラベリング |

## FAMAはどのような法律を執行しているのか？

FAMAの権限はAkta 141に由来し、農産物がどのように登録され、等級付けされ、
ラベル表示されるかを規律するいくつかの附属規則によって裏付けられている。

- **登録規則（1989年）**——農産物の加工または販売に従事する者を登録する。
- **等級付け・包装・ラベリング規則（2008年）**——農産物の等級とラベルの
  基準。
- **果物輸出ライセンス規則（1990年）**[P.U.(A) 65/90]。
- **マーケティング制度（Skim Pemasaran）**——特定品目向け。ココナッツ・
  マーケティング制度（1973年）、野菜マーケティング規則（1975年）および
  コーヒー・マーケティング制度（1971年）を含む。

## 小規模生産者はFAMAを通じてどのように販売するのか？

ここにこそ、FAMAが一般の人々にとって最も目に見える形で現れている——
仲介業者を飛び越え、農場の収穫物を直接消費者へと届ける直接販売チャネルの
ネットワークである。

| チャネル | 何のためのものか |
| --- | --- |
| 常設農民市場（Pasar Tani Kekal、PTK） | 常設の農民市場、通常は午前6時～午後4時営業 |
| Agrobazaar（ABR / AKR） | 食品と新鮮な農産物を販売する小売店舗 |
| My Farm Outlet（MFO） | 現代的な小売店舗——プトラジャヤ（Putrajaya）やチェンデリン（Chendering）などに展開 |
| 生鮮フルーツスタンド（Gerai Buah-buahan Segar、GBBS） | 生鮮フルーツの屋台 |
| 契約栽培（Ladang Kontrak） | 作付け・買取契約；申請は14営業日以内に処理 |
| RANTAI | サプライチェーン・プログラム——マーケティングパートナーを通じた販売、研修および物流 |

このネットワークの規模を示す一例として、2021年10月のある報道は、FAMAが
2021年9月1日から10月18日まで——2か月に満たない期間で——移動制限後に
標準作業手続きに従って再開した368カ所にわたり、**RM1億2,200万**の
売上を記録したと報じたことを引用している。同じ報道によれば、この数字には
常設農民市場35カ所、農民市場266カ所、生鮮フルーツスタンド19カ所、
R&R（休憩所）内のAgrobazaar 5カ所、および臨時市場（pasar tamu）5カ所が
含まれる。（この数字は2021年時点の引用であり、最新データではない——
査証ノートを参照。）

## 料率と条件に関する注記

本ページでは、登録料、プログラムの参加資格、または店舗の所在地について
詳細には記載していない。これらの詳細は随時変更され、FAMA内の異なる部門
によって管理されている。手続きを行う当日に`fama.gov.my`で確認するか、
マーケティング機関発展部門（Bahagian Pembangunan Institusi Pemasaran）に
問い合わせること。

## 次のステップ

もしあなたが農産食品の生産者または企業家であれば、まず自分に適した販路を
見極めること——農民市場での直接販売、AgrobazaarやMy Farm Outletへの出店、
あるいはLadang KontrakやRANTAIといったプログラムへの参加など——そのうえで
`fama.gov.my`で参加の申込書と条件を確認すること。もしあなたが消費者で
あれば、お住まいの地域のFAMA農民市場や店舗の一覧も同機関の公式サイトで
確認できる。
