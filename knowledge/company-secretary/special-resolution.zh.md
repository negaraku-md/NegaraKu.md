answer: "根据《2016年公司法令》，普通决议以简单多数通过——即超过半数的投票成员赞成（s.291）；而特别决议则需要不低于75%的多数（s.292(1)）。召开会议通过特别决议须发出21天通知（s.292(1)），而以书面形式通过的特别决议必须在其文本表面载明它是一项特别决议（s.292(2)）。凡是法令与公司章程均未规定所需决议类型的事项，普通决议即已足够（s.290(3)）；法令将特别决议保留给一份特定的重大决策清单，例如修改公司章程（s.36）、更改公司名称（s.28）和减少资本（ss.116–117）。"

  - q: "普通决议与特别决议分别以多少百分比通过？"
    a: "普通决议需要简单多数——即有权投票的成员中，超过半数亲自出席、在允许情况下委任代理人（proxy）或以书面决议投票赞成（《2016年公司法令》s.291）。特别决议则需要上述成员中不低于75%的多数（s.292(1)）。除非公司章程另有规定，这些百分比是以已投出的票数为基准计算，而非以全体成员为基准。"
  - q: "特别决议需要多长的通知期？"
    a: "为通过特别决议而召开的会议，根据s.292(1)须至少发出21天通知——比私人公司会议根据s.316(1)一般所需的14天更长。公司章程可要求更长的通知期，但绝不可缩短。这21天同时适用于私人公司和公众公司。"
  - q: "特别通知与特别决议是同一回事吗？"
    a: "不是。特别决议是指75%的多数（s.292）。特别通知则是另一项独立的、由成员向公司发出的28天通知要求（s.322(1)），法令仅就少数特定决议施加此要求——例如罢免公众公司董事（s.206(3)）或罢免核数师（auditor，s.277）。一项决议可以要求特别通知，但仍然是一项普通决议。"
  - q: "哪些决策需要特别决议？"
    a: "法令明确列出了这些决策。常见的包括修改公司章程（s.36(1)）、更改公司名称（s.28）、减少股本（s.116的法院途径或s.117的偿债能力声明途径），以及成员自愿清盘（members' voluntary winding up，s.439(1)）。凡无条文规定决议类型的，s.290(3)将其定为普通决议。"
  - q: "书面特别决议的运作方式是否相同？"

两个词决定了一项股东决策有多难通过。称它为**普通决议**（ordinary
resolution），仅需微弱多数即可通过。称它为**特别决议**（special resolution），
你就需要在场四分之三的赞成、三周的通知，而且——若采书面形式——文本上还需
载明正确的字样。把标示弄错，不仅可能危及一次表决；更可能使该决议在法律上
归于无效。

## 核心区别

两种决议类型在《2016年公司法令》中相邻定义，且两者都涵盖会议上的表决
*以及*书面决议的表决。

| | 普通决议 | 特别决议 |
| --- | --- | --- |
| 多数 | 投票成员中**超过半数** | 投票成员中**不低于75%** |
| 条文 | s.291 | s.292(1) |
| 会议通知 | 私人公司14天／公众公司股东周年大会（AGM）21天（s.316） | **21天**，任何公司皆同（s.292(1)） |
| 书面形式 | 超过半数同意即通过（s.291） | 75%同意**并且**载明为特别决议（s.292(2)） |
| 适用时机 | 默认类型——s.290(3) | 仅在法令或公司章程有规定时 |

除非公司章程另有规定，多数是以**已投出**的票数为基准衡量，而非以全体成员
为基准。就书面决议而言，s.293规定每名成员按其所持每一股份享有一票（受公司
章程约束）。

## 法令何时要求特别决议

法令并不把选择权交给公司。对于一组特定的结构性决策，它规定必须采用特别决议，
任何低于此标准者概不接受：

| 决策 | 条文 |
| --- | --- |
| 变更或修改公司章程 | s.36(1) |
| 更改公司名称 | s.28(1) |
| 减少股本——法院确认途径 | s.116 |
| 减少股本——偿债能力声明途径 | s.117 |
| 成员自愿清盘 | s.439(1) |
| 议决由法院将公司清盘 | s.465(1)(a) |

其中几项附带一项自决议起算（而非自会议起算）的存档义务：公司章程的修改
必须在**30天**内向注册官（Registrar）存档（s.36(3)），名称变更须在**30天**内
通知（s.28）。资本减少只在存档时才生效，而非在表决时生效。

## 默认为普通决议——s.290(3)

对于法令*没有*特别指明的一切事项，s.290(3)是概括性条文：凡法令与公司章程
均未规定决议类型的，普通决议即已足够。因此公司的日常事务都以简单多数运作：

| 决策 | 条文 |
| --- | --- |
| 委任董事（后续委任） | s.202 |
| 罢免私人公司董事 | s.206(1)(a) |
| 在股东大会上批准董事酬金（公众／上市公司） | s.230(1) |
| 法令与公司章程未加规定的任何事项 | s.290(3) |

请留意罢免的例子。s.206(1)(a)允许私人公司以*普通*决议罢免董事——门槛很低——
但仍必须为此召开会议，而该项罢免须发出特别通知。门槛容易，并不等于程序容易。

## 标示的陷阱

特别决议有一项普通决议所没有的手续。根据s.292(2)，私人公司的书面决议
**除非载明为特别决议并以特别决议方式通过，否则不构成特别决议**。就会议而言，
s.292(5)(a)要求通知须载明该决议的文本，并说明其系作为特别决议提呈——而
s.292(5)(b)随即使之具约束力：一旦通知载明「特别」，该决议就只能以特别决议
方式通过。

这是马来西亚决议中最常见的单一技术性瑕疵：一份跨过75%门槛却从未载有该字样
的文件。就s.292(2)表面而言，它不成立。

## 特别通知是另一回事

不要把**特别决议**（75%多数，s.292）与**特别通知**（由提呈人向公司发出的
28天通知，s.322(1)）混为一谈。特别通知附着于少数几项*普通*决议——罢免公众
公司董事（s.206(3)）、罢免核数师（s.277）。决议本身仍属普通决议；只是通知
更为繁重。那些把「special」当作单一概念处理的指南，两者都会弄错。
