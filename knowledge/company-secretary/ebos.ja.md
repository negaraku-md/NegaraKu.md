e-BOSは電子実質的所有者システム（Electronic Beneficial Ownership System）——
マレーシアの会社が実質的所有権情報を登記官に提出する窓口である。

| | |
| --- | --- |
| **正式名称** | 電子実質的所有者システム（Electronic Beneficial Ownership System） |
| **運営者** | SSM |
| **開始日** | 2024年4月1日 |
| **アクセス方法** | SSM4Uポータル（ssm4u.com.my）経由 |
| **法的根拠** | s.60B(7)、2016年会社法；2001年マレーシア企業委員会法（Companies Commission of Malaysia Act 2001）s.20Cに基づき2024年5月13日発出のPD 9/2024 |
| **適用範囲** | 2016年会社法に基づき設立されたすべての会社、および登録されたすべての外国会社 |
| **提出手数料** | なし |

## 目的

2016年会社法Division 8Aは、会社に対し実質的所有権情報を登記官に提出することを
義務付けている。PD 9/2024は、登記官が別段の許可をしない限り、その提出はe-BOSを
通じて**行わなければならない**と定めている。同システムは登記官の登録処（RBO）に
データを供給しており、これは各会社が自らの登録事務所に備え置く登録簿と並存する
——ただし両者は別個のものである。

## 提供するサービス

- **実質的所有権情報の通報**——新たな実質的所有者または上級管理職の追加、既存の
  詳細事項の更新、または終了の記録
- **実質的所有権情報の更正**——2016年会社法s.602および実務通知6/2019号（Practice
  Note 6/2019）に基づき、証明書類を添えて、提出時点で誤っていた情報を訂正すること
- **削除または取消**——なされるべきでなかった記載を削除または取消すこと

実質的所有者登録簿が登録事務所以外の場所に保存されている場合、その保存場所は
e-BOSを通じてではなく、s.47(2)に基づきSSMに通報する。

## アクセスの取得

アクセスは、開放型のログインではなく、検証済みのアカウントを通じて行われる。
ユーザーはまずSSM4Uポータルに登録して本人確認を受け、その後e-BOSダッシュボード
から**検証済みプロフェッショナルユーザー（Verified Professional User）**への
昇格を申請する。提出が可能になるのはこの申請が承認された後であり、承認は即時
には行われない。

大半の提出は自動登録される。証明書類の添付が必要な例外は、ステータスがExisting
以外の会社による提出、およびs.602に基づく更正である。

## 誰が保存されている情報を閲覧できるか

実質的所有権情報は**公衆に公開されていない**。登記官の登録処へのアクセスは、
主管当局、法執行機関、政府調達を行う公的機関、実質的所有者本人、およびその者
が承認した者に限られる。

Companies (Access to Register and Information Relating to Beneficial Ownership)
Regulations 2025は2025年1月10日に施行され、情報への何人がアクセスできるか、
いかなる条件で、いくらの手数料でアクセスできるかを定める大臣の権限（s.60B(9)）
に基づき制定された。SSMは2025年1月28日、Menara SSM@Sentralに供給設備を開設し、
会社1社あたりRM20.00と定められた料金で窓口にて申請する方式とし、主管当局および
法執行機関の場合を除き、実質的所有者本人による書面同意が必要とされる。
