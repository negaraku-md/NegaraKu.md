このテーマに関するあらゆるガイドは会社側の視点で書かれている——秘書が辞任した、
さあ何を提出すべきか、というものだ。それは読者を取り違えている。実際に夜11時に
検索しているのは、メールに応答しなくなり、支払いも止まり、SSMへの提出など絶対に
してくれないクライアントから抜け出したい秘書のほうだ。

2016年会社法のs.237は、まさにその人物のために起草されたものであり、会社が何も
しなくても機能する。

## 通常の経路：取締役会への通知

s.237(1)は、会社定款または委任条件に従うことを条件として、秘書は取締役会に通知を
行うことで職を辞任できると定めている。

何が存在しないかに注目してほしい。承諾もなければ、離任を承認する取締役会決議もなく、
報酬を先に清算しておく必要もない。これは一方的な行為である。

s.237(3)(a)は続いて、それがいつ効力を生じるかを確定する。秘書は、**通知の日から
30日**が満了した時点、または会社定款もしくは委任条件に定める期間が満了した時点――
いずれが適用されるかに従う――で、その職を退く。Practice Note 4/2018は、この3つの
可能性を改めて示している。

| 退任の契機 | 出典 |
| --- | --- |
| 会社定款に定める期間の満了 | 会社定款 |
| 委任条件における通知期間の満了 | 委嘱状 |
| 取締役会への通知日から30日の満了 | s.237(1)のデフォルト |

取締役会はこの期間を短縮できる。Practice Note 4/2018は、**秘書が同意すれば**、
取締役がs.58の通報を提出することにより、定められた通知期間より早く任期を終わらせる
ことができると確認している。取締役にできないのは、これを引き延ばすこと、あるいは
辞任を人質に取ることである。

## 誰も応答しない場合の脱出経路：s.237(2)

これはs.237を本当に有用にしている規定であり、他のほぼどのページもきちんと説明して
いないものでもある。

s.237(2)は、会社のいずれの取締役とも最後に判明している住所で連絡が取れない場合、
秘書はその事実および辞任の意向を登記官に通報できると定めている。続いてs.237(3)(b)
が、登記官へのその通知の日から30日が満了した時点で委任を終了させる。

会社は完全に迂回される。SSMに直接伝えられ、時計は動き出す。

### SSMが証拠として求めるもの

Practice Note 4/2018は、当該通知にはいずれの取締役とも連絡が取れないことを裏付ける
証拠――例えば取締役宛ての郵便物が返送された証明――を添付しなければならないと定めて
いる。SSM自身のFAQは、実際の案件の大半を左右する2つの補足を加えている。

- **電子メールだけでは主要な証拠にならない。** 秘書がそのメールが取締役との通常の
  連絡手段であったことを証明できる場合に限り、メールの写しは*追加の*裏付け書類と
  して使用できる。
- **受領の証拠があるとこの経路は成り立たなくなる。** SSMは明確にしている。取締役に
  書留郵便で送達した辞任通知の受領証明がある場合、取締役にはなお連絡が取れるため、
  秘書はs.237(2)を通じて辞任することが**できない**。

最後の点が落とし穴である。返送された配達不能の書留郵便こそ、あなたが欲しい証拠だ。
署名入りの配達受領証は、代わりにs.237(1)を使わなければならない――そして30日を
待ち切らなければならない――ことを示す証拠である。

## 会社が呈報しない場合に自分を守る

s.237に基づく辞任は、あなたの職を終了させる。だがSSMの記録を更新するわけではない。
ある者が秘書でなくなったことを14日以内に登記官へ通報する義務は、s.58(1)(e)の下で
*会社*にあり、あなたへの応答を止めてしまった会社がそれを履行する見込みは薄い。

SSMはその結果を率直に確認している。会社がs.58に基づいて辞任を更新するまで、秘書の
氏名は会社の企業プロファイルに表示され続ける。

Practice Note 4/2018は対抗策を用意している。s.237(1)に基づいて辞任した秘書は、
自らの辞任が登記官に通報されないおそれがあると考える場合、**通知の写しを登記官に
提出**でき、その際は当該Practice Noteに添付された様式による宣誓書を添える。その
様式は『Declaration by Secretary to Cease Office』と題され、s.237(3)(a)に基づく
ものと明記されている。そこには会社の詳細、秘書の詳細（免許番号または会員番号
およびSSM開業証明書番号を含む）、退任日、そして3つの退任契機のうちどれが適用
されるかが記録される。

いったん提出されると、その文書は所定の手数料の支払いにより誰でも入手できるように
なる。企業プロファイルにはなおあなたの名前が表示されていても、あなたの辞任は
検索可能な記録の一部となる。

**このページから手続き上のステップを一つだけ取るなら、これにしてほしい。** かかる
のは様式一枚と手数料だけであり、それが「辞任した」ことと「辞任したと証明できる」
ことの違いになる。

## 第31日目からしてはならないこと

Practice Note 4/2018は明確である。秘書は、当該会社の秘書でなくなった後は、会社
または取締役に代わっていかなる文書も提出することが認められなくなる。

秘書事務所は、習慣や善意からこれを日常的に誤る――すでに進行中だった年次報告書を
仕上げてしまう、ちょうど去ったばかりのクライアントのために住所変更を提出して
しまう、といった具合に。退任後のあなたは会社の役員ではなく、その立場で提出する
ことは好意ではなく、登記官に対する不実表示である。

## 辞任してもファイルは終わらない

s.237(4)は責任を存続させる。s.237(1)または(2)のいかなる規定も、秘書がその職を
離れる**前に**行った作為または不作為についての責任を免除するものではない。

不正確なまま残された登記簿、誤った詳細で提出された申告書、在任中に一度も作成
されなかった議事録――辞任は時間を遡らない。これは、第30日に立ち去るのではなく
引継ぎをきちんと終えるべきこと、そして自分が提出したものの写しを自ら保管して
おくべきことの実務的な理由になる。

名指しする価値のある第二のリスクがある。あなたがなお複数の会社の秘書として名を
連ねている間に開業証明書が失効した場合、s.238(1)(c)により自動的に資格を失い、
またSSMのGuidelinesは更新にあたり直前の証明書期間中に有効な委任があることを
求めている。すべての委任を辞任したうえで証明書を失効させてしまうと、新しい証明書
番号のもとで改めてs.241の申請をしなければならなくなる道をたどることになる。

## あなたが去った後に会社がすべきこと

あなたが唯一の秘書であった場合、あなたの離任は欠員を生じさせ、s.240はいかなる
時点においても職を30日を超えて空席のままにしてはならないと定めている。Practice
Note 4/2018は率直に述べている。辞任する秘書が唯一の秘書である場合、新しい秘書の
委任は、その職が空席となった日から30日以内に行わなければならない。

その義務は会社およびその取締役に属する。あなたのものではなく、あなたの通知期間を
延長するものでもない。取締役は、後任が見つかるまで退任する秘書が留まらなければ
ならないと主張することがあるが、s.237にはそのような要求は一切含まれていない。

## よくある誤り

- **会社が辞任を受け入れるのを待つこと。** s.237(1)が求めているのは通知であって、
  同意ではない。30日はどちらにせよ進んでいく。
- **取締役に無視されているという理由でs.237(2)に手を伸ばすこと。** 無視される
  ことと連絡が取れないことは同じではない。通知が受領されていた場合、SSMは
  s.237(2)の経路を認めない。
- **s.237(2)の下で電子メールのみを証拠として頼ること。** SSMはメールを追加的な
  裏付けとして扱うにすぎず、しかもそれが通常の連絡手段であった場合に限られる。
- **辞任すればSSMが登記簿を更新してくれると思い込むこと。** そうはならない。
  会社がs.58に基づいて提出するまで、あなたの名前は企業プロファイルに残る。
- **Practice Note 4/2018の宣誓書を省略すること。** それは、s.237(1)に基づいて
  辞任し、かつ呈報しようとしない会社に直面した者にとって、唯一利用できる自助策
  である。
- **引継ぎの間も文書を提出し続けること。** 退任後、あなたにはその会社のために
  何かを提出する権限は一切ない。
- **辞任を過去の提出からのきれいな決別だと扱うこと。** s.237(4)はそうは言って
  いない。

## この先

あなたが離任する秘書ではなく会社の立場であるなら、s.240の下での後任選任の時計は
職が空席になった日から動き出し、リスクを負うのは取締役である。すでに後任が決まって
いるなら、登記簿、議事録簿、システムアクセスの引継ぎこそが、新任の秘書が実際に
仕事をこなせるかどうかを決める部分である。
