同法に定められたすべての期限のなかで、s.352は結果が最も鋭いものであり、会社秘書役
関連のブログが最も見落としがちな条文でもある——たいていは、担保権は銀行の問題か、
弁護士の問題だという理屈による。

そうではない。s.352(1)は、提出義務を**会社**に課している。そしてs.352(2)は、同法の
他のどの提出期限も行わないことを行う——担保権そのものを破壊するのである。罰金では
ない。コンパウンド（和解金）でもない。当該担保権は清算人及びすべての債権者に対して
無効となり、s.352(3)により被担保債務は即時に弁済期が到来する。貸し手は無担保債権者
として順番待ちの列に残される。その原因は、誰も提出しなかった一枚の書式である。

## 何を、いつまでに登録しなければならないか

s.352(1)は、自社の財産又は事業に担保権を設定した会社に対し、**担保権の設定から30日
以内**に、登記官が定める様式及び方法により、所定の手数料とともに、担保権の詳細陳述書
を登記官へ提出することを求めている。

s.353は対象となる担保権を列挙している。

| 登録可能な担保権 | 項 |
| --- | --- |
| 社債の発行を担保する担保権 | s.353(a) |
| 未催告株式資本に対する担保権 | s.353(b) |
| 会社が保有する子会社株式に対する担保権 | s.353(c) |
| 個人が行った場合にBills of Sale Act 1950の登録を要する担保権又は譲渡 | s.353(d) |
| 所在地を問わず土地、又は土地上のいかなる権益に対する担保権 | s.353(e) |
| 帳簿上の債権に対する担保権 | s.353(f) |
| 事業又は財産に対する浮動担保権 | s.353(g) |
| 催告済みだが未払の株式払込金に対する担保権 | s.353(h) |
| 船舶又は航空機、又はそれらの持分に対する担保権 | s.353(i) |
| のれん、特許若しくは特許実施許諾、商標、又は著作権若しくは著作権実施許諾に対する担保権 | s.353(j) |
| 預金口座の貸方残高に対する担保権 | s.353(k) |

このうち2つは、中小企業の取締役をしばしば驚かせる。s.353(f)の**帳簿上の債権**に
対する担保権は、インボイスファイナンス及び債権譲渡を対象とする。s.353(k)の**預金
口座の貸方残高**に対する担保権は、融資の担保として質入れされた定期預金を対象とする
——これは銀行が書類を作成しながら、会社が一度も提出しないという、マレーシアで非常
によくある取り決めである。

主たる期限のほかにも、関連する期限が並んでいる。s.355(1)は、一連の社債について30日
以内の一括提出を認めている。s.356(1)は、会社が既に登録可能な担保権が付いた財産を
取得する場合、又は外国会社が既存の担保権を伴ってマレーシアに登録する場合に、完了から
30日を定めている。証書がマレーシア国外で作成又は作成された場合、s.363はこれらいずれ
の期間も**7日間**、又は登記官の裁量によりさらに長く延長する。

## 30日を逃すと、正確には何が起こるのか

s.352(2)：会社の財産又は事業に付与された担保である限り、当該担保権は清算人及び会社
のすべての債権者に対して無効となる。

s.352(3)は背後にある義務を保全する——返済に関する契約又は義務を害するものではない
——が、被担保債務は**即時に弁済期が到来する**。したがって、借り手は期限の利益を失い、
貸し手は担保の利益を失う。両者は同時に生じる。

除外規定が1つ、救済が1つある。

除外規定はs.352(5)である。**土地以外**の財産に対する担保権を登録しなかったことは、
当事者間における当該担保権の有効性に影響せず、その効力を制限しない。ここは注意深く
読む必要がある——これは、清算人及び債権者に対するs.352(2)の効果を取り消すものでは
ない。あくまで当事者間において担保権を保全するにすぎない。

救済はs.361である。裁判所は、当該懈怠が偶発的なものであったこと、不注意その他の十分
な理由によるものであったこと、債権者又は株主を害する性質のものではないこと、又はその
他救済を与えることが公正かつ衡平であることを認める場合、登録期間を延長し、又は登録簿
を更正することができる。救済は裁量的であり、条件付きであり、期限内に提出するよりも
はるかに費用がかかる。

これとは別に、s.352(10)は、s.352(1)及びs.354への違反を、会社及びすべての役員による
犯罪とし、RM50,000を超えない罰金、継続犯の場合はさらに1日あたりRM500を超えない罰金
を科す。

s.352(8)は実務上のセーフティネットである。**当該担保権に利害関係を有する者**は、登録
期間が終了する前に詳細を提出することができ、s.352(9)により費用を会社から回収できる。
借り手の秘書役が提出することを信頼できない貸し手は、自ら提出できる。

## 内部の担保権登録簿の義務はどこにあるか

s.362であり、これはs.352とは完全に別個の義務である。

**s.352は通知義務である。** 30日以内にSSMへ詳細を提出する。怠った場合の帰結は、優先
順位の喪失及びs.352(2)による無効である。

**s.362は登録簿の義務である。** s.362(1)は、会社に対し、登録可能な担保権を設定する
証書、又はその写しを、**登録事務所**において保管することを求めている。s.362(3)は、
会社に対し、登録事務所において担保権登録簿を備え置き、会社の財産に特に影響する担保権
及びすべての浮動担保権をそこに記入し、それぞれについて担保に供された財産の簡単な説明、
担保権の金額、及び当該担保権を有する者の氏名を記載することを求めている。ただし、無記名
証券は除く。

両者は互いに代替できない。すべての担保権をSSMへ提出しながら内部登録簿を一切備え置か
ない会社は、s.362に違反する——そしてs.362(6)は、s.352と同じ名目上のリスクである、
RM50,000を超えない罰金及び1日あたりRM500を科す。完璧な内部登録簿を維持しながら何も
提出しない会社は、有効な書類作業と、無価値な担保権を持つことになる。

s.362には独自の閲覧規定もある。s.362(4)により、債権者又は社員はRM5で証書及び登録簿
を閲覧できる。それ以外の者は、会社が定める手数料（1回の閲覧につきRM10を超えないもの）
を支払う。s.362(5)により、何人も担保権証書又は社債証書の写しを申請でき、申請から**3
日以内**に、1ページあたりRM10を超えない手数料で交付を受けなければならない。

## 担保権の存続期間中に何が起こるか

さらに3つの提出があり、それぞれ独自の時計で動いている。

**譲渡——30日。** s.359(1)により、元の担保権者以外の者が新たな担保権者となった場合、
**新たな担保権者**は30日以内に登記官へ通知を提出し、その通知の写しを会社に交付しなけ
ればならない。この義務は会社ではなく譲受人に課される。

**変更——30日。** s.359(2)により、被担保債務又は負債の金額を変更するように条件が
変更された場合、又は当該財産に対する後続の担保権の設定を禁止若しくは制限するように
変更された場合、**会社**は変更が生じてから30日以内に変更通知を提出しなければならない。

**弁済又は解除——14日。** s.360(1)により、債務の全部若しくは一部が支払われ若しくは
弁済され、又は財産が担保権から解除され若しくは会社の財産の一部でなくなった場合、会社
はs.360(2)に基づく十分な証拠を添えて、**14日以内**に詳細を提出しなければならない。
s.360(3)により、当該担保権を有するその他の者が代わりに提出することもできる。

この14日間の消滅の時計が人をつまずかせるのは、まさにそもそも登録に認められている30日
より短いからである。融資を清算してそのまま進んでしまう会社は、SSM記録上に担保権が
有効なまま残ることになり——それが次の銀行デューデリジェンスの際に表面化する。

## SSMの登録は何を証明するか

s.357(1)は、登記官に対し、提出されたすべての担保権の登録簿を備え置くことを求めて
おり、s.357(2)は記入される詳細事項を定めている。s.357(3)が肝心な部分である。登記官
が発行する登録証明書は、登録に関する要件が遵守されたことの**決定的証拠**となる。

これは、s.50(3)に基づく社員名簿に適用される一応の証拠（prima facie）の基準よりも強い
証拠力を持つ陳述であり、だからこそ貸し手は提出受領書ではなく証明書の提示を求めるので
ある。

## よくある誤り

- **銀行又はその弁護士が提出してくれると思い込む。** s.352(1)は義務を会社に課して
  いる。s.352(8)は、利害関係人も併せて提出できることを認めているにすぎない。
- **30日を引出し日又は印紙貼付日から起算してしまう。** 時計は担保権の**設定**から
  起算する。
- **定期預金の質入れを見落とす。** 預金口座の貸方残高に対する担保権は、s.353(k)に
  より登録可能である。
- **インボイスファイナンスを見落とす。** 帳簿上の債権に対する担保権は、s.353(f)に
  より登録可能である。
- **s.352(5)を万能の言い訳として読んでしまう。** これは非土地担保権を当事者間に
  おいて保全するにすぎず、清算人に対して担保権を救済するものではない。
- **SSMへ提出しながらs.362の登録簿を備え置かない。** 2つの義務、2つのRM50,000の
  リスク、そのうち1つは登録事務所にある。
- **解除を忘れる。** s.360(1)はわずか14日しか認めておらず、SSM記録上に残った古い
  担保権は、会社が今後行うすべての資金調達に付いて回る。
- **取得した財産を見落とす。** 会社が既に登録可能な担保権を伴う資産を購入する場合、
  s.356(1)が適用される。

## 次にすべきこと

会社のSSM担保権一覧を取り出し、s.362の登録簿及び融資ファイルと並べてみる。3つの問い
で、ほとんどのリスクが解消する。有効な融資はすべて登録されているか、清算済みの融資は
すべて解除されているか、そしてすべての担保権証書の写しが、s.362(1)が求めるとおり
