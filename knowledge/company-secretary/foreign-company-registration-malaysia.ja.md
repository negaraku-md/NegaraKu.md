海外企業は長期間、国外からマレーシアに向けて販売を行うことができる——しかし、事務所を開設し、現地でリースを締結し、あるいは現地に人員を配置した瞬間、一線を越える。マレーシアで*事業を営む*状態になると、2016年会社法（Companies Act 2016、Act 777）はまず登録することを義務付けており、それによって同じ海外企業がマレーシアに登録された支店へと姿を変える。

本ガイドでは、s.562に基づくこの登録の仕組み、支店がコンプライアンスを維持するために必要な事項、そして多くの外国投資家が支店を避けて代わりに現地子会社を設立する理由について説明する。

## 海外企業はいつ登録が必要になるか？

2016年会社法のs.561は、外国会社が企業委員会（SSM）に外国会社として登録しない限り、マレーシアで事業を営むことを禁じている。「事業を営む」は広く解釈される——s.561(3)により、店舗の運営に限らず、株式譲渡事務所や株式登録事務所の設立・利用、あるいは代理人、遺産管理人（legal personal representative）または受託者として現地の財産を管理、運営またはその他の方法で処理する行為といった活動も含まれる。

「外国会社」とは、マレーシア国外で設立された法人、または訴訟の当事者となる能力を有し、かつマレーシアに本社または主たる営業所を持たない非法人団体をいう。自社の実体がこれに該当し、同国内で継続的な物理的拠点を持とうとする場合、登録は任意ではない。

登録によって新しい会社が設立される**わけではない**。支店は海外の親会社と*同一の*法人である。支店が行うすべての行為について、親会社が責任を負う。

## s.562の申請には何が必要か？

登録は、親会社の名称について名称検索をクリアした後に行う、s.562に基づくSSMへの申請である（支店は親会社の既存の名称で登録され、新たな名称を考案することはできない）。中核となる書類は次のとおりである。

- 外国会社の**設立証明書**（または同等の登録書類）の**認証謄本**。
- その**定款／基本定款及び附属定款**、またはその組織構造を定める憲章の認証謄本。
- **取締役**の名簿、及び該当する場合は現地取締役の詳細。
- 設立地における**株主または社員**の名簿、及び株式資本の詳細。
- マレーシア居住者を会社の代理人として指名する**委任備忘録または委任状**、及び当該代理人の書面による同意。
- マレーシアにおける**登録事務所**の住所、及び異なる場合は**営業所**の所在地。

SSMが認めれば、登録通知書を発行し、当該外国会社は登録簿に登録される。

## 登録費用はいくらか？

一括登録費用は均一ではなく、親会社の**株式資本**に応じて段階的に設定され、現行の為替レートでリンギットに換算される。親会社の資本が高いほど、費用も高くなる。株式資本を持たない親会社は、最高額の定額を支払う。

| 外国会社の株式資本 | 登録費用（RM） |
| --- | --- |
| RM1,000,000を超えない | 5,000 |
| RM1,000,000を超え、RM10,000,000を超えない | 20,000 |
| RM10,000,000を超え、RM50,000,000を超えない | 40,000 |
| RM50,000,000を超え、RM100,000,000を超えない | 60,000 |
| RM100,000,000を超える | 70,000 |
| 株式資本なし | 70,000（定額） |

*出典：s.562（2017年会社規則）に基づく外国会社登録に関するSSM手数料表。MIDAの手数料表により裏付けられている。*

この段階制は初めて申請する者を驚かせることが多い。資本力のある多国籍企業は、支店の登録にRM70,000の費用を負担することになりかねない一方、新規に現地会社を設立する場合の設立費用ははるかに低額である。このコスト差が、子会社ルートが好まれる理由の一つである。

## 現地代理人とは誰か、なぜ重要か？

外国会社は単独で登録することはできない——s.563に基づき、少なくとも一名の**マレーシア居住の代理人**を選任しなければならない。代理人は、規制上の目的における会社の授権された現地代表者であり、同法が会社に求めるすべての事項について責任を負い、コンプライアンス違反により会社に科される罰則について**個人的に責任を負う**ことがある。

これは単なる形式ではなく、実質的なリスク負担である。代理人となることに同意する者——多くの場合、専門事務所または信頼できる現地の個人——は、支店が必要な書類を必要な時期に提出する責任を引き受けることになる。代理人の詳細の変更自体も、s.563に基づきSSMへの通報が必要である。

支店はまた、通信や通知の送付先となる**マレーシアにおける登録事務所**を保持しなければならず、その事務所に変更があった場合はSSMに通報しなければならない。

## 支店は毎年何を提出しなければならないか？

登録は、一度限りのものではなく、継続的なコンプライアンス関係の始まりである。登録された外国会社は、その他の義務の中でも特に以下を行わなければならない。

- 登録の記念日から30日以内に、毎暦年一回**年次申告書（annual return）**を提出する（**s.576**）。
- SSMに**財務諸表**を提出する（**s.575**）。通常は、親会社が自国の法域で作成する会計書類の写しを、当該法域で求められる様式で提出する。
- 取締役、代理人、登録事務所、会社名、または基本書類の変更について、法定期間内にSSMに通報する。

これらの期限を守らなければ、会社とその現地代理人の双方が罰則を科されるおそれがあり、これこそが代理人の役割が重い理由である。

## 支店か子会社か——どちらの形態が適しているか？

支店は、外国人がマレーシアに拠点を設立する一般的な二つの経路のうちの一つに過ぎない。もう一つは、私会社——*Sendirian Berhad*（Sdn Bhd）——を設立することであり、これは当該外国会社が所有する、まったく新しいマレーシアの法人である。この選択は、責任、税務上の立場、設立費用を左右する。

| 特徴 | 外国会社（支店） | 現地子会社（Sdn Bhd） |
| --- | --- | --- |
| 法的地位 | 海外親会社の延長——同一法人 | 独立したマレーシアの法人 |
| 責任 | 親会社が支店のすべての責任を負う | 責任は一般に子会社内に限定される |
| 名称 | 親会社の名称を使用しなければならない | 独自の新しい名称を採用できる |
| 適用規定 | s.561～s.563（外国会社制度） | 同法に基づく一般的な設立制度 |
| 登録費用 | 親会社の資本に応じて段階的、最大RM70,000 | 標準的な設立費用（はるかに低額） |
| 許容される事業活動 | 親会社の事業を反映しなければならない | 現地市場向けに改めて定義できる |
| 現地代表者 | マレーシア居住の代理人 | 通常、少なくとも一名のマレーシア居住取締役に加えて会社秘書役（同法に照らして要確認） |

実務上、多くの外国投資家はSdn Bhdを選択する。それは親会社の下振れリスクを限定し、通常は設立費用が低く、現地の顧客、銀行、規制当局からは居住会社として認識される。支店は、親会社がマレーシア事業を特に同一法人の内部に置きたい場合——例えば単一のグローバル貸借対照表を示すため、または親会社自体と直接取引することを求める取引先を満足させるため——に適する傾向がある。

## 次に行うべきこと

- 計画している活動が、マレーシアにおいて実際に「事業を営む」ことに該当するかを確認する——それが真に一時的なものか、純粋に国境を越えたものであれば、そもそも登録が不要な場合もある。
- **支店かSdn Bhdか**を早期に決定する。これは書類作業が始まる前に、費用、責任、税務を左右するためである。自社の具体的な事実関係については、資格を有する税務・法律の助言を受けること。
- 提出前に、意欲と能力を備えた**マレーシア居住の代理人**（支店の場合）、または**居住取締役に加えて会社秘書役**（子会社の場合）を確保する。
- 親会社の設立書類及び基本書類を準備・認証し、SSM名称検索を行い、s.562の申請を一度で提出できる状態にする。
- 初日から、年次申告書及び財務諸表という反復的な義務をスケジュールに組み込み、支店がSSMにおいて良好な地位を維持できるようにする。
