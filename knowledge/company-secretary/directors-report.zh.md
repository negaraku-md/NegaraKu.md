先从一处更正说起，因为它会改变你的做法。

**Companies Act 2016 s.251 不是提交条文。** 它没有提到注册官。它是**董事局批准**
财务报表并附上**法定声明**的那条条文。传阅在 s.258，提交在 s.259。有不少广为流传的
摘要把 s.251 说成要求把财务报表提交给 SSM，照着做的公司会去找一个根本不在该条里的
期限。

以下是每一条条文实际上在做什么。

## s.251——董事局批准与法定声明

s.251(1) 要求财务报表：

- **(a)** 经董事局批准；**并且**
- **(b)** 附上由一名董事所作的**法定声明**；若该董事并非主要负责公司财务管理者，则
  由如此负责的人作出；声明中须述明他对财务报表（以及在适用情况下，综合财务报表）
  **是否正确**的意见。

第二项要细读。默认作出声明的是董事。只有在该董事**并非**主要负责财务管理者时，另一
条路才开放——这时由如此负责的人作出声明。这不是两者之间的自由选择。

s.251(2) 随后要求董事们**依董事局的一项决议案**作出陈述，说明他们是否认为该等财务
报表是依适用会计准则编制，从而对公司与集团的财务状况与财务表现呈现**真实与公允的
观点**。

s.251(3) 定下签署：s.251(2) 的陈述须由**至少两名董事**签署，若只有一名董事则由该
董事签署——并须依 s.257 **附于供传阅的财务报表**。

s.251(4) 规定，就任何经传阅、发表或发出的财务报表，违反规定的公司与每一名高职人员
可被罚款最高 **RM500,000** 或监禁最高**一年**或两者兼施。

## s.252——编制与签署报告

s.252(1) 要求董事**就每一个财政年度**编制一份报告，而该报告**须附于依 s.248 编制的
财务报表**。

s.252(2) 随后要求董事报告：

- **(a)** 须经**董事局批准**；以及
- **(b)** 须由**至少两名董事代表董事们签署**，若只有一名董事则由该董事签署。

s.252(3) 另加一项很容易失守的呈现要求：依 s.340 在常年股东大会上提呈、依 s.257 寄送
予成员，或以其他方式由公司传阅、发表或发出的董事报告的**每一份副本**，都**须述明
代表董事们签署该报告者的姓名**。只有扫描签名而没有打印姓名，并不满足这一点。

罚则是分开的：

| 违反 | 风险 |
| --- | --- |
| 董事未采取**一切合理步骤**确保遵守 s.252(1) | 罚款最高 **RM500,000** 或监禁最高 **1 年**或两者兼施——s.252(4) |
| 公司与每一名高职人员违反 s.252(2) 的批准与签署规则 | 罚款最高 **RM20,000**——s.252(5) |

## s.253 与 Fifth Schedule——里面要放什么

s.253(1) 要求报告载明：

- **(a)** **在该财政年度内**，以及**自财政年度结束至报告日期这段期间内**，曾任公司
  董事的每一个人的姓名；
- **(b)** 公司在该财政年度过程中的**主要业务**，包括其子公司；以及
- **(c)** **Fifth Schedule（第五附表）**所列的事项。

凡编制综合财务报表，s.253(2) 把提及公司之处读作提及该公司**及**纳入合并的子公司
企业。s.253(3) 允许报告载入 Fifth Schedule Part II 所列的**业务回顾**，或任何其他
订明的报告——这是许可性的，不是强制性的。

Fifth Schedule Part I 第 1 段才是实质。摘要如下：

| 项目 | 要求 |
| --- | --- |
| (a) | 该财政年度**扣除所得税拨备后**的净利或净亏损 |
| (b) | 转入或转出储备或拨备的重大款额与详情 |
| (c) | 年内发行的股份或债券——用途、类别、数目与款额，以及发行条款 |
| (d) | 使董事得以通过取得股份或债券而获取利益的安排，凡于年结时或年内任何时候仍然存续者，连同所涉董事的姓名 |
| (e) | 就年结时在任的每一个人——**依 s.59 登记册**所载，他在股份与债券中的权益：年末的、年初或成为董事时的，以及年内**买入与卖出**的总数 |
| (f) | 建议派发的股息，以及自上一个财政年度结束以来已派发或已宣派的股息 |
| (g)、(h) | 是否已就坏账与呆账采取合理步骤，以及董事是否知悉有任何情况会令那些款额不足 |
| (i)、(j) | 是否已采取合理步骤把无法变现的流动资产减值，以及有关价值或估值方法是否具误导性 |
| (k) | 自年结以来出现的、为他人的负债提供担保的资产押记，以及或有负债 |
| (l) | 于年结后**十二个月**内变为可强制执行、并可能影响公司履行其义务能力的或有负债或其他负债 |
| (m) | 任何未在他处处理、而会令账目中所列款额具误导性的情况 |
| (n) | 业绩是否受某项**重大且不寻常性质**的项目、交易或事件所实质影响 |
| (o) | 于**年结与报告日期之间**出现的任何重大且不寻常的项目、交易或事件 |
| (p) | 注册官所决定的任何其他细节 |

第 1(e) 段正是 s.219 持股通知之所以要紧的原因——这份报告是从 **s.59 登记册**组装
出来的，而该登记册又是从那些通知组装出来的。

**第 2 段**要求报告就董事与前任董事述明袍金与其他福利的款额，且须**分项列示**，
包括袍金、百分比酬金、花红、佣金与失去职位的补偿；非现金福利的估计货币价值；就董事
的服务付予任何第三方的款额；以及**为任何董事、高职人员或核数师所给予的弥偿、或所作
投保**的总额。凡董事或其事务所以专业身份行事，该等款额不计入总额，但必须分开列示。

**第 3 段**要求每一名董事述明，自上一个财政年度结束以来，他是否因公司或关联法团与他
本人、与他为成员的事务所、或与他拥有重大财务利益的公司订立的合约，而收取或有权收取
某项利益——已列入所披露报酬、或属其全职雇员固定薪金者除外——若有，则述明其一般
性质。

**第 4 段**要求子公司列明其**最终控股公司**，以及（如已知）其注册成立的国家。
**第 5 与第 6 段**涵盖就未发行股份授出的认购权——数目与类别、期满日期、行使基础，
以及参与另一家公司股份发行的任何权利——以及期内因行使该等认购权而发行的股份。

## 真正的期限在哪里

s.251 与 s.252 都没有载明日期。时钟在这里：

- **s.258(1)(a)**——私人公司须**自其财政年度结束起六个月内**传阅财务报表与各项
  报告；
- **s.259(1)(a)**——**自传阅起三十天内**向注册官提交；
- **s.248(1)(a)**——**首份**财务报表须于注册成立后**十八个月**内完成。

那两条宽免条文值得知道。**s.255** 允许董事向注册官申请命令，免除他们关于财务报表或
董事报告**形式与内容**的任何要求——但依 s.255(2) 不得与获批准的会计准则相抵触，并且
依 s.255(5) 仅限于遵行该要求会具误导性、不适合公司情况，或造成不合理负担的情形。
s.255(3) 允许作出适用于某一类别的命令。而 **s.254** 则把形式与内容规则适用于持牌
机构，并作出国家银行（BNM）所决定的修改。

## 常见错误

**把 s.251 当成提交条文。** 它是董事局批准加上法定声明。提交是 s.259，传阅是 s.258。
这个错误在已发表的摘要里常见到值得你去查一查手上继承下来的任何清单。

**由错的人作出法定声明。** s.251(1)(b) 只有在该董事并非主要负责者时，才把它交给
**主要负责财务管理的人**。这不是图方便的选择。

**两人董事局只有一个签名。** s.251(3) 与 s.252(2)(b) 在董事多于一名时，都要求**至少
两名**。

**传阅副本上漏掉签署人姓名。** s.252(3) 要求每一份副本都述明。

**只列出年结时在任的董事。** s.253(1)(a) 要求列出在该年度**内**曾任董事的每一个人，
以及自年结至报告日期这段期间内曾任董事的每一个人。

**用股东名册来填第 1(e) 段。** 它必须来自 **s.59 董事持股登记册**，那是另一本簿册，
有另一个法定触发点。

**忘了第 2 段的最后一项。** 为任何董事、高职人员或**核数师**所给予的弥偿、或所作
投保的总额，是必须披露的项目，而它经常被漏掉。
