秘書役事務所を切り替えることは、一見すると事務的な用事に見えるが、実際には小規模な移行に
等しい。SSMへの提出は簡単な部分にすぎない。新しい事務所が実際に業務を行えるかどうかを決め
るのは、旧事務所が記録一式を完全に引き渡すかどうかである——そして、その一式に何が含まれる
かを記したマレーシアのガイドは存在しない。なぜなら、そうしたガイドを書く事務所こそが、それ
を引き渡すよう求められる当事者だからである。

それでも2016年会社法（Companies Act 2016、Act 777）はこの問いに答えている。ただし、その答
えは誰もこの目的では読まない条文の中にある。

## s.47が引継ぎチェックリストである

s.47(1)は、会社がその登録事務所に保管しなければならないものを定めている。これを裏返せば、
離任秘書役が会社に代わって保有している目録となる。

| s.47(1) | 項目 |
| --- | --- |
| (a) | s.15に基づき発行された登録通知書 |
| (b) | 会社の定款（ある場合） |
| (c) | 同法又は以前の成文法に基づき発行された証明書 |
| (d) | 同法が要求するすべての登記簿、帳簿、記録及び文書 |
| (e) | 社員総会の議事録及び社員決議の全て |
| (f) | 取締役会及び取締役会委員会の会議の議事録及び決議の全て |
| (g) | 全社員又はある種類の株式の全保有者に対して発せられた書面による通信の全ての写し |
| (h) | 全ての財務諸表及びグループ財務諸表の写し |
| (i) | s.245が要求する会計記録 |
| (j) | s.357に基づき担保権を設定又は証明する文書の全ての写し |
| (k) | 登記官が保管を要求するその他の文書 |

(d)項が大きな役割を担っている。これは、社員登記簿、s.57に基づく取締役、マネージャー及び秘
書役の登記簿、担保権登記簿、そして——2024年会社法改正法（Companies (Amendment) Act 2024、
Act A1701）が第8A編を挿入して以降は——実質的所有者登記簿を取り込む。

### 他の場所には置けない唯一のもの

s.47(2)は、登記官への通報を条件として、第(1)項のいずれの文書も登録事務所以外の場所に保管
することを認めている——**ただし第(1)(e)項の文書を除く**。

社員総会の議事録及び社員決議は、登録事務所に置かなければならない。それだけのことである。
離任する事務所がこれらを保有しており、登録事務所がその事務所とともに移転しようとしている
場合、これが最初に追いかけるべき項目である。

関連して、同じく見落とされがちな点として：s.342(2)は、決議及び会議の記録が登録事務所以外
の場所に保管される場合、又はその場所が変更される場合、14日以内に登記官へ通報することを求
めている。その通報なしに議事録簿を移転する引継ぎは、それ自体が違反を生じさせる。

## 変更が起動する３つの時計

取締役は秘書役の変更を一件の提出手続と考えがちである。実際には通常３件であり、並行して進
行する。

1. **s.58——SSMへの通報、14日。** s.58(1)(e)は秘書役でなくなる者を対象とし、s.58(1)(d)は
   秘書役になる者を対象とする。いずれも14日である。s.58(4)はRM50,000を超えない罰金を定め、
   違反が継続する場合は1日につきRM500を加算する。
2. **s.57(4)——会社自身の登記簿、14日。** 別個の義務である。取締役、マネージャー又は秘書
   役の詳細事項に変更があった場合、会社は14日以内に登記簿にその変更を反映しなければならな
   い。s.57(6)はRM10,000を超えない罰金及び1日につきRM500の加算を定めている。
3. **s.46(3)——登録事務所、14日。** 住所が移転する場合にのみ適用されるが、通常は移転する。
   s.46(4)はRM50,000を超えない罰金を定めている。

s.57とs.58の組み合わせは、多くの同業サイトが混同している区別である。一方は会社が維持する
内部登記簿であり、他方は登記官への通報である。提出を行っても登記簿の義務は免除されず、登
記簿を更新しても提出の義務は免除されない。

## 登録事務所は事務所とともに移転する

これが、整然とした変更を混乱に変えてしまう実務上の細部である。多くの秘書役事務所は、顧問
契約の一部として登録事務所の住所を提供している。事務所を離れることは、その住所を離れるこ
とを意味する——そして、s.46(1)に基づき、会社は常時、通信及び通知の宛先となり得るマレーシ
ア国内の登録事務所を有していなければならず、それは通常の営業時間中、公衆に開放され、立ち
入り可能でなければならない。

そこから２つの失敗パターンが生じる。ひとつは、会社がもはや使用する権利のない住所を使い続
け、SSM及び内国歳入庁（LHDN）からの書面が、転送する動機のない事務所に届いてしまう場合であ
る。もうひとつは、後任の事務所がその住所を受け入れることに実際にはまだ同意していないのに、
会社が新住所を通報してしまう場合である。

順序立てて進める：新しい登録事務所を確認し、新秘書役を委任し、その後に通報する。

## s.47を超えて求めるべきもの

s.47が対象とするのは文書である。実際に機能する引継ぎには、同法が列挙していない運用面の層
も必要となる：

- **実質的所有者登記簿。** 第8A編は2024年会社法改正法により挿入された。同登記簿及びその裏
  付け資料は会社の記録であり、会社とともに移動する。
- **提出システムへのアクセス権。** MBRS及びMyCoIDの認証情報は、通常は会社名義ではなく事務
  所名義で保有されている。だからこそ、その移転は当然のこととせず、明示的に提起する必要が
  ある。
- **会社印（ある場合）。** s.61(1)は、会社が会社印を有していても有していなくてもよいと定
  めている。会社が一度も採用したことのない物を追いかける必要はないが、定款又は過去の文書
  がそれを前提としている場合は追いかけるべきである。
- **会計記録。** s.245(3)は取引完了後7年間の保存を求めており、s.245(4)はそれらを取締役が
  いつでも閲覧できる状態にしておくことを求めている。s.245(9)はこの分野で最も厳しい罰則で
  あり——RM500,000を超えない罰金若しくは3年以下の禁錮、又はその両方である。
- **決議及び議事録。** s.341(2)は、決議、会議又は決定の日から少なくとも7年間これらを保管
  することを求めている。

### 訂正しておく価値のある点

ガイドは、議事録簿への記入について固定の期限があるとしばしば述べる。s.341はそのような期限
を課していない。同条が課すのは、s.341(3)に基づきRM10,000を超えない罰金を伴う、少なくとも
7年間の**保存**義務である。同法のこの部分で記入期限に最も近いものはs.245(2)であり、これは、
関連する取引が完了してから60日以内に*会計*記録に適切な記入を行うことを求めている。両者を
混同してはならない。

## 離任する事務所が権限を失うとき

『実務通知第4/2018号』（Practice Note No. 4/2018）は、秘書役がその職を退いた後は、会社又
は取締役のために如何なる文書も提出することを認められない旨を明記している。この点は、引継
ぎの間、両方向に作用する。

これは、離任が効力を生じた後は、離任する事務所は進行中の提出手続を完了できないことを意味
する——したがって、効力発生日より前に完了させるか、後任秘書役に引き継ぐかのいずれかとなる。
また、会社が事後になって、旧事務所にその離任自体のs.58通報の提出を頼ることはできないこと
も意味する。

SSMはまた、会社がs.58に基づき更新するまで、離任秘書役の氏名が会社の企業プロファイルに残り
続けることを確認している。プロファイル検索で旧い氏名を目にすることは、引継ぎが失敗した証
拠ではなく、通常は提出がまだ行われていない証拠である。

## 欠員を避ける順序立て

s.240は30日を与えているが、それを使い切る理由はない。整然とした順序は次のとおりである：

1. s.236(3)に基づき後任秘書役の**書面による就任承諾**を得るとともに、同人がs.241に基づく
   現行の開業証明書を保有していることを確認する。
2. 離任秘書役との間で退任日を合意するか、又はs.237の通知期間がすでに進行中であることを確
   認する。
3. 後任秘書役を委任する**取締役会決議**を、退任日**から効力を生じる**形で可決し、両方の日
   付の間に空白が生じないようにする。
4. s.47の文書を受領し、登録事務所を確認する。
5. s.58通報を提出し、住所が変更された場合はs.46(3)通報も提出する。
6. s.57登記簿を更新する。

## よくある誤り

- **s.58の提出だけで全てが終わったと考えること。** s.57登記簿は、独自の14日間の期限と独自
  の罰則を持つ、別個の義務である。
- **登録事務所が移転することを忘れること。** これは変更の際に最も見落とされがちな義務であ
  り、最高RM50,000の罰金を伴う。
- **社員の議事録を旧事務所に残しておくこと。** s.47(2)は、それらを登録事務所以外の場所に
  保管することを認めていない。
- **報酬をめぐる紛争によって引継ぎを停滞させること。** 記録は会社に帰属するものであり、請
  求書は別個の契約上の問題である。
- **新秘書役の委任日を退任日より後にすること。** いかなる空白も、s.240に基づく欠員であり、
  s.235(1)違反である。
- **システムへのアクセス権が自動的に移転すると想定すること。** そうはならない。旧事務所が
  手を引いた後にそれに気づくのは高くつく。
- **実質的所有者登記簿なしに引継ぎを受け入れること。** これは第8A編の下での法定記録であり、
  任意の付随物ではない。

## 次に確認すべきこと

今回の変更が会社ではなく現職者の辞任によって引き起こされたものである場合、s.237に基づく通
知期間が時期を支配し、会社は想定しているよりも日付を管理できない可能性がある。欠員がすで
に30日を超えている場合は、まずそのリスクに対処すること——それは取締役個人の責任として及ぶ。
