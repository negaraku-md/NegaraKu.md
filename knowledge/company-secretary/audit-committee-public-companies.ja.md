たいていのマレーシアの取締役に、監査委員会の要件はどこから来るのかと尋ねれば、会社法（Companies
Act）だという答えが返ってくるだろう。それは違う。**「audit committee」という語句は2016年会社法の
どこにも出てこない**——620の条文全体を通じて一度も——そして2024年会社法改正法もそれを追加しなかった。

それは起草上の見落としではない。意図的な移設であり、この義務が実際にどこに存在するかを知ることは、
誰がそれに拘束され、誰がそれを執行するのかを変える。

## この要求は実際どこから来るのか

**1965年会社法 s.15A**のもとでは、上場株式を有するすべての会社が監査委員会を設置しなければならな
かった。2016年会社法のSection 620が1965年会社法を廃止し、2016年会社法は後継規定を設けなかった。
この義務は丸ごと**ブルサ・マレーシア上場規則第15章**に移った。

そこから3つの帰結が生じ、そのいずれもがしばしば誤解されている。

**この義務は上場発行体のみを拘束する。** 第15章はMain Marketの「上場発行体（listed issuer）」及び
ACE Marketの「上場法人（listed corporation）」について定めている。**未上場の公開会社——一度も上場
したことのない普通のBerhad——には、監査委員会を組成する一般的な法的義務はなく**、Sdn Bhdも同様で
ある。業界監督当局は例外である：免許を受けた金融機関は、マレーシア国立銀行（Bank Negara）独自の
ガバナンス要件に従うが、これは本稿の対象外である。

**執行するのはブルサであり、企業委員会（SSM）ではない。** 構成の不備は上場規則違反であ
る。登記官はこれについて管轄権を持たない。同法の中に違反すべきものが何もないからである。

**違反は同法のもとでの刑事犯罪ではない。** その代わりにブルサの規制上の制裁を招く——これは、例えば
s.236のもとで30日以内に会社秘書役を選任しなかった場合とは、実質的に異なるリスクである。

## 誰が委員会に加われるのか？

Rule 15.09(1)は4つの構成要件を定めており、そのすべてが同時に満たされなければならない。

| 要件 | 内容 |
| --- | --- |
| 人数 | **3名以上**の委員 |
| 業務執行の有無 | 委員は**全員**が非業務執行取締役でなければならない |
| 独立性 | **過半数**が独立取締役でなければならない |
| 財務リテラシー | 少なくとも1名の委員が下記の資格要件を満たさなければならない |

財務リテラシーの要件（rule 15.09(1)(c)）は、「financially literate（財務リテラシーを有する）」と
いう略称が示唆するよりも具体的である。少なくとも1名の委員は、次のいずれかでなければならない。

- **マレーシア会計士協会（Malaysian Institute of Accountants、MIA）の会員**であること；又は
- MIA会員でない場合は、**少なくとも3年の実務経験**を有し、かつ**1967年会計士法（Accountants Act
  1967）First Schedule Part I**に定める試験に合格しているか、又は**同First Schedule Part II**に
  定める会計士団体のいずれかの会員であること；又は
- 取引所（Exchange）が定め又は承認するその他の要件を満たす者であること。

続いてRule 15.09(2)は、人々がやろうとしがちなことを禁じている：**代理取締役は監査委員会の委員に
選任されてはならない。** 委員の出張予定を代役で解決することはできない。

**委員長は選出されるものであり、取締役会が任命するものではない。** Rule 15.10は、委員が自らの中
から独立取締役である委員長を選出することを求めている。取締役会が代わりに選ぶことはできない。

**MCCG（2021年4月28日現在）**は、その上に遵守するか説明するか（apply-or-explain）の実務を重ねて
いる。Practice 9.1：監査委員会の委員長は取締役会議長ではない。2021年版で新設されたPractice 1.4：
取締役会議長は監査、指名又は報酬委員会のいずれの委員にもなるべきではない。Step Up 9.4は、委員会
を独立取締役のみで構成することを推奨している。Practice 9.5は、全委員が財務リテラシーを有し、継続
的専門能力開発（continuous professional development）に取り組むことを求めている。

> **クーリングオフ規則はMCCGによるものであり、ブルサによるものではない。** Practice 9.2は、委員会
> に対し、**外部監査事務所の前任パートナーが選任前に少なくとも3年のクーリングオフ期間を遵守する**
> ことを求める方針を採用するよう要請している。2021年の改訂により、対象は*主要監査パートナー（key
> audit partner）*から、助言又は税務サービスのみを提供していたパートナーを含む、当該事務所又は
> 関連事務所の**あらゆる前任パートナー**へと広げられた。2017年版に基づいて書かれた手引きは今なお
> 「主要監査パートナー」と記しているが、それは旧版のもとでの用語である。

## 構成が崩れたらどうなるのか？

取締役は辞任し、業務執行取締役となり、又は在任期間によって独立性を失う。その後をめぐっては2つの
規則が適用され、それぞれ異なる役割を果たす。

**Rule 15.19——是正期間。** 構成が要件を満たさなくなった場合、欠員又は不足は**3か月以内**に補充
しなければならない。

**Rule 15.18——定足数。** いかなる会議においても、**出席委員の過半数**が独立取締役でなければなら
ない。これは会議ごとの基準であり、常態としての構成の基準ではない。書面上は適正に構成されている
委員会であっても、出席した2名の顔ぶれが悪ければ定足数不足の会議になり得るし、そこで下された決定
はリスクにさらされる。

Rule 15.13は外部からの出席を制御する：他の取締役及び従業員は、**監査委員会が当該会議に限って招請
した場合にのみ**出席する。CFOに常時の招請状を出すことは、この規則が想定するところではない。

## 委員会は実際に何をするのか？

Rule 15.12は職務を列挙している。実務上、それらは4つの仕事に集約される。

**外部監査を審査する。** 委員会は外部監査人とともに、監査計画、内部統制制度に対する監査人の評価、
及び監査報告書を審査する。

**取締役会が数字を目にする前に審査する。** 四半期業績及び年度末財務諸表は、取締役会の承認の**前
に**監査委員会へ送られる——委員会は取締役会の上流に位置しており、取締役会が既に通過させたものの
審査者ではない。

**利益相反を監視する。** 関連当事者取引及び利益相反状況は、まさに委員会の仕事であり、rule 15.15
は年次報告書に審査した利益相反状況の概要を記載することを求めている。

**監査人との関係を統括する。** 委員会は外部監査人の辞任通知書を審査し、当該監査人を再任するには
不適当であると信ずべき理由があるかどうかについて見解を形成し、外部監査人の指名を推薦する。

Rule 15.15はまた、年次報告書における**監査委員会報告書（Audit Committee Report）**が開示しなけれ
ばならない内容を定めている：各委員の役職及び独立性を含む構成、会議の回数及び各委員の出席状況、
委員会の業務の概要、並びに実施された内部監査業務の概要である。

そして**rule 15.27**は、上場発行体に対し、自らが監査する活動から**独立した内部監査機能**を設置し、
**直接監査委員会に**報告することを義務付けている。報告経路こそがこの規則の要点であり、CFOに報告
する内部監査責任者はこれを満たさない。

## 外部監査人とどう関わるのか？

第15章は委員会に仕組みを与え、会社法は監査人にそれと対をなす権利を与える。両者は組み合わさるよう
に設計されている。

**Rule 15.17——委員会の権利。** その職権範囲内のいかなる事項も調査する権限；必要とする資源；情報
への**完全かつ制限のない取用権**；外部監査人及び内部監査との**直接の連絡経路**；**独立した専門家
の助言**を得る権限；並びに**必要と認めるときはいつでも、他の取締役及び従業員を除いて外部監査人と
会議を招集する**権限。

その基準に注目されたい：*必要と認めるときはいつでも*。**第15章はこの種の非公開会合の年間最低回数
を定めていない。** マレーシアのガバナンス関連コンテンツで流布している「年に少なくとも2回」という
数字は上場規則には存在しない——それをブルサの規則として扱ってはならない。

**Rule 15.24**はこの経路を逆方向にも通す：外部監査人は監査委員会の委員長に対し、会議の招集を要請
することができる。

会社法の側では、公開会社の監査人は意見を受動的に供給するだけの存在ではない。

| 権利又は義務 | 条文 |
| --- | --- |
| 会計その他の記録に合理的な時間にいつでも取用でき、いかなる役員に対しても情報を求めることができる | s.266(4) |
| 連結財務諸表を作成する場合、子会社の記録についても同様の取用権を有する | s.266(5) |
| 株主総会に出席し、通知を受け取り、監査事項について意見を述べる権利を有する | s.266(7) |
| 同法違反がほかの方法では対処されない場合、登記官に報告する義務を負う | s.266(8) |
| 報酬は社員が普通決議により定めるか、取締役会が委任した場合は取締役会が定める | s.274 |
| 特別通知に基づき、株主総会における普通決議によってのみ解任される | ss.276, 277 |
| 登記された事務所への書面通知により辞任し、21日後又は指定された時に効力を生じる | s.281 |
| 公開会社の監査人は、財務諸表が提出される**すべての年次株主総会（AGM）に出席しなければならない** | s.285(1) |

s.285(1)こそ心に留めておくべき条文である。上場会社では、外部監査人は監査に関連する質問に答える
ためAGMの場にいる義務を負い、これを怠れば犯罪となる。ただしs.285(3)の除外事由が適用される場合を
除く。監査委員会の非公開会合と監査人のAGM出席は、監査人が経営陣によるフィルターを経ずに発言でき
る、2つの構造的な機会である。

> **取締役会を越える報告経路。** Rule 15.16は第15章の中で最も鋭く、最も議論されていない条文であ
> る：取締役会に報告された事項が**十分に解決されず、上場規則違反という結果に至った場合、監査委員
> 会は速やかにそれを取引所に報告しなければならない。** 委員会の最終的な報告経路はブルサであって、
> それを任命した取締役会ではない。

ACE Marketの規則もこれをすべて踏襲している。ACE第15章は**同一の規則番号**と実質的に同一の文言を
用いる——同じ3名の委員、同じ非業務執行及び過半数独立の要件、同じ会計士法の資格要件、同じ代理取締
役の禁止、同じ3か月の是正期間、同じ定足数、同じ内部監査の報告経路である。違いは起草上のものにす
ぎない：「上場発行体（listed issuer）」に代えて「上場法人（listed corporation）」、そしてPractice
Note 13ではなくGuidance Note 9への相互参照である。

## よくある誤り

**2016年会社法を根拠として引用すること。** 引用すべきものは何もない。本稿にある監査委員会に関す
る義務は、すべてブルサ又はMCCGに由来する。

**未上場のBerhadに必要だと思い込むこと。** 会社法の観点からは必要ない。取締役会が自主的に設置す
ることは多く、それは賢明ではあるが、あくまでガバナンス上の選択であって、成文法の遵守ではない。

**欠席する委員の穴を埋めるために代理取締役を選任すること。** Rule 15.09(2)はこれを完全に禁じてい
る。

**構成と定足数を同じ基準として扱うこと。** Rule 15.09は委員が誰であるかを規律し、rule 15.18は誰
がその場にいるかを規律する。両方が満たされなければならない。

**取締役会議長に委員会の委員長を兼任させること。** 独立取締役であればブルサはこれを許容するが、
MCCG Practices 9.1及び1.4はそうすべきでないとしており、上場発行体はrule 15.25のもとでMCCGの適用
状況を開示しなければならない。説明なしに逸脱することがリスクである。

**内部監査をCFOの系統に組み込むこと。** Rule 15.27は、当該機能が直接監査委員会に報告することを
求めている。

**クーリングオフ方針について「主要監査パートナー」を引用すること。** 2021年のMCCGは、これを当該
事務所又は関連事務所のあらゆる前任パートナーにまで広げた。

## 次にすべきこと

自社の委員会の職権範囲（terms of reference）を取り出し、rule 15.09と一行ずつ照らし合わせて検証
されたい——人数、非業務執行の地位、過半数独立性、資格要件、そして代理取締役の禁止である。Rule
15.11は職権範囲を**上場発行体のウェブサイトに公開する**ことを求めているため、古くなった文書はそ
のまま公に古びていることになる。

続いて、静かに失敗しがちな2点を確認されたい：直近4回の会議がrule 15.18のもとで定足数を満たして
いたか、そして内部監査の報告経路が経営陣にではなく委員会に向いているかである。

委員会に加わる取締役は、2016年会社法Part III（第III部）の一般的な義務に引き続き拘束される——委員
会の委員となることは義務を追加するのであって、いずれの義務にも取って代わるものではない。
[取締役の義務](/ja/company-secretary/directors-duties/)を参照のこと。監査人側の選任及び解任の
仕組みについては、[マレーシア会社における監査人の委任](/ja/audit/appointing-an-auditor/)を参照
のこと。
