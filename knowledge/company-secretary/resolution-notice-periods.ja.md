マレーシアの秘書業務事務所3社に、特別決議に何日の通知が必要かと尋ねれば、14日、21日、
そして「定款による」という3つの答えが返ってくるだろう。そのうち正しいのは一つだけで
あり、定款はそれを長くすることしかできない。

以下は、2016年会社法におけるすべての通知期間を一か所にまとめ、それぞれ条文と対応させ
たものである。

## 通知期間の一覧表

| 内容 | 期間 | 条文 |
| --- | --- | --- |
| 私会社の社員の会議 | 最低**14日**、定款によりそれより長い場合はそれに従う | s.316(1) |
| 公開会社のAGM | 最低**21日**、定款によりそれより長い場合はそれに従う | s.316(2)(a) |
| 公開会社のその他の会議 | 最低**14日**、定款によりそれより長い場合はそれに従う | s.316(2)(b) |
| 特別決議を通過させるための会議 | **21日** | s.292(1) |
| 同法が要求する場合の特別通知 | 会議前**28日** | s.322(1) |
| 延期された会議の通知 | 延期が**30日以上**の場合に必要 | s.318 |
| 取締役が請求された会議を招集する | 請求から**14日** | s.312(1)(a) |
| 請求された会議が開催されるべき期限 | 招集通知後**28日を超えない** | s.312(1)(b) |
| 取締役の不履行後の社員自身による会議 | 請求から**3か月以内** | s.313(3) |
| 社員が請求した書面決議の配布 | **21日** | s.303(3) |
| 書面決議の失効 | 配布日から**28日** | s.307(1) |
| 公開会社：決議の配布請求 | 会議前**28日**までに受領 | s.323(3)(d)(i) |
| 公開会社：陳述書の配布請求 | 会議前**7日**までに受領 | s.323(3)(d)(ii) |
| 委任状の提出 | 会議前**48時間** | s.334(3) |
| 投票表決のための委任状の提出 | 投票表決前**24時間** | s.334(3) |
| 買収のための株式発行の意向通知 | 発行前**14日** | s.75(2)(d) |

最低期間として表されているすべての期間は、定款によって長くすることができる。そのいず
れも定款によって短くすることはできない——短縮通知は、代わりにs.316(3)から(5)の手続き
による。

## 短縮通知：人々が誤る基準

s.316(4)は、AGM以外の会議について、出席・議決権を有する社員の人数上の多数——その多数
が合わせて、その権利を与える株式のうち自己株式を除いた所要の百分率以上を保有する者
——が同意すれば、より短い通知で招集することを認めている。

s.316(5)に基づく所要の百分率は次のとおりである。

- 私会社では**90%**——または定款が指定するそれより高い数値。ただし上限は95%
- 公開会社では**95%**

見落とされがちな点が2つある。第一に、これは二重の検証である——社員の人数上の多数で
あり、かつその多数が合わせて所要の百分率を保有していなければならない。5名の株主のう
ち1名が保有する90%の株式では足りない。第二に、私会社の定款は基準を引き上げることが
できるが、95%を超えることはできない。

AGMについては、s.316(3)が、出席・議決権を有するすべての社員の同意を要求している。
95%ではなく、全員一致である。

## 特別通知は28日であり、21日ではない

s.322(1)は、決議を動議する意向の通知を、会議前少なくとも28日までに会社に対して行う
ことを要求している。これは社員から会社への時計であり、その後会社が社員に対して行う
通常の通知の上に重ねて存在する。

同法が特別通知を要求する場合、その旨が明文で定められている。主な2つの事例は、公開会
社の取締役の解任に関するs.206(3)と、監査人の解任に関するs.277(1)である。

見落とされがちな仕組みが2つある。

- s.322(4)により、会議の通知と併せて社員に通知することが実行可能でない場合、会社は、
  マレーシアで広く発行されているマレー語新聞1紙及び英語新聞1紙に広告を掲載する方法、
  または定款が指定する方法により、決議について社員に少なくとも14日の通知を与えなけ
  ればならない。
- s.322(5)により、会社が特別通知を受領してから**28日以内**の日を会議の日として招集
  した場合であっても、当該通知は適法に与えられたものとみなされる。取締役会は、会議
  を前倒しすることによって特別通知を無効にすることはできない。

## 通知に記載しなければならない事項

s.317(1)は簡潔である——場所、日時、及び議事の一般的な性質である。s.317(2)は決議の全
文を含めることを任意としている——ただし一つの厳格な例外がある。

会議で通過させる特別決議については、s.292(5)(a)が、通知に**決議の全文**を含め、かつ
それが特別決議として提案されている旨を述べることを要求している。そしてs.292(5)(b)
は、その記載を拘束力のあるものとする——通知が特別であると述べていれば、その決議は特
別決議としてしか通過させることができない。

s.335(1)は、別個の必須事項を追加している——会議を招集するすべての通知は、s.334に基
づく社員の代理人選任権を**目立つように**記載しなければならず、違反した役員はそれぞ
れ最大RM10,000の罰金に処せられる。s.335(3)は、それにもかかわらず会議の有効性を保持
する。

## 誰が通知を受け取らなければならないか

s.321(1)は、社員の会議の通知を、会社の**すべての社員、取締役及び監査人**に対して行
うことを要求している。マレーシアの通知リストでは、表決するのは株主だけであるという
前提から、取締役と監査人が日常的に除外されている——しかし同条は、表決する権利を有す
る者に自らを限定していない。

s.321(2)は、リストをさらに拡張する。ある者が、社員の死亡または破産の結果として株式
についての権利を取得し、かつ会社がその権利について**書面**による通知を受けている場
合、その者は、本来権利を有していたはずの社員に代わって通知を受け取らなければならな
い。書面による通知が到着するまでは、会社はs.101(2)に基づき、登録株主のみをその権利
を有する者として扱うことができる。

方法はs.319によって定められている——通知は書面で行わなければならず、ハードコピー、
電子形式、またはその両方を部分的に組み合わせた方法で行うことができる。s.319(2)によ
り、ハードコピーは、社員がその目的のために提供した住所宛てに本人交付または郵送によ
り送付し、電子通知は提供された電子アドレス宛てに送付する——またはウェブサイトへの掲
載による。ウェブサイトへの掲載は、会社がs.320(2)に基づき、それが社員の会議に関する
ものであること、場所、日時、及び（公開会社の場合は）AGMであるか否かを述べる別個の
書面による通知を併せて行う場合にのみ有効である。s.320(3)は続けて、当該通知が、その
通知の日から会議が終了するまでウェブサイト上に掲載され続けることを要求している。

## よくある誤り

**特別通知に21日を用いること。** 正しくは28日である（s.322(1)）。21日という数字は、
特別決議（s.292(1)）と公開会社のAGM（s.316(2)(a)）に属するものである。

**短縮通知を90%の持株検証だと捉えること。** それは人数上の多数と所要の株式百分率の
両方を必要とする（s.316(4)）。

**95%でAGMを短縮通知すること。** s.316(3)は、出席・議決権を有するすべての社員の同意
を要求している。

**特別決議の通知から決議全文を省くこと。** s.292(5)(a)がそれを要求している。それが
なければ、その決議は特別決議とならない。

**代理人選任権の記載を忘れること。** s.335(1)は独立した違反行為であり、遵守は容易だ
が、ひな形の中では見落とされやすい。

## 次に確認すべきこと

日数の数え方は、この表そのものよりも重要である。同法は最低期間を定めているが、通知
の日と会議の日を算入するかどうかについては自ら定義していない——安全な実務は、両方を
除外して暦日（clear days）で加算することであり、また定款を確認することである。定款
はしばしばそれを明文で定めている。

この大半を回避できる書面決議の方法については`written-resolutions`を参照。そもそも
誰がAGMを開催しなければならないかについては`agm-requirements`を参照。取締役会が望
まない会議を強制する方法については`egm-requisition`を参照。
