まず一つの訂正から始める。それによって取るべき対応が変わるからだ。

**2016年会社法（Companies Act 2016、Act 777）s.251は提出に関する条文ではない。** 登記官については一切言及されていない。これは、財務諸表が**取締役会の承認**を受け、**法定宣誓書**を添付する条文である。回付はs.258に、提出はs.259に定められている。広く流布している要約の中には、s.251が財務諸表をSSMに提出することを求めていると説明するものが少なくないが、それに従う会社は、その条文には存在しない期限を探すことになる。

以下、それぞれの条文が実際に定めている内容を見ていく。

## s.251——取締役会の承認と法定宣誓書

s.251(1)は、財務諸表について次のことを求めている。

- **(a)** 取締役会の承認を受けること；**かつ**
- **(b)** 取締役、または当該取締役が会社の財務管理を主として担当していない場合は財務管理を主として担当する者による**法定宣誓書**を添付すること。当該宣誓書には、財務諸表、及び該当する場合は連結財務諸表が**正確であるか否か**についての意見を記す。

この2番目の項目を注意深く読む必要がある。原則として宣誓者は取締役である。取締役が財務管理を主として担当して**いない**場合にのみ代替が可能となり、その場合は実際に担当している者が宣誓を行う。両者のどちらかを自由に選べるわけではない。

s.251(2)は続いて、取締役に対し、**取締役会の決議に基づき**、財務諸表が該当する会計基準に従って作成され、会社及びグループの財政状態及び財務業績について**真実かつ公正な概観**を示しているか否かについての意見を述べる陳述を作成することを求めている。

s.251(3)は署名について定めている。s.251(2)の陳述は**少なくとも2名の取締役**によって、取締役が1名のみの場合はその取締役によって署名されなければならず、かつs.257に基づき**回付用の財務諸表に添付**されなければならない。

s.251(4)は、回付、公表または発行された財務諸表について違反した会社及びすべての役員に対し、最高**RM500,000**の罰金または最高**1年**の禁錮、あるいはその両方を科すことができるとしている。

## s.252——報告書の作成と署名

s.252(1)は、取締役に対し**各会計年度について**報告書を作成することを求めており、当該報告書は**s.248に基づき作成された財務諸表に添付**されなければならない。

s.252(2)は続いて、取締役報告書について次のことを求めている。

- **(a)** **取締役会の承認**を受けること；及び
- **(b)** **取締役を代表して少なくとも2名の取締役によって署名**されること、または取締役が1名のみの場合はその取締役によって署名されること。

s.252(3)は、見落としやすい表示要件を追加している。s.340に基づき定時株主総会に提出され、s.257に基づき社員に送付され、またはその他の方法で会社により回付、公表もしくは発行された取締役報告書の**すべての副本**は、**取締役を代表して報告書に署名した者の氏名を記載**しなければならない。印字された氏名のないスキャン署名では、この要件を満たさない。

罰則は次のように分かれている。

| 違反 | 罰則 |
| --- | --- |
| s.252(1)の遵守を確保するために**あらゆる合理的な措置**を取らなかった取締役 | 最高**RM500,000**の罰金または最高**1年**の禁錮、あるいはその両方——s.252(4) |
| s.252(2)の承認及び署名規則に違反した会社及びすべての役員 | 最高**RM20,000**の罰金——s.252(5) |

## s.253とFifth Schedule——記載すべき内容

s.253(1)は、報告書に次の事項を記載することを求めている。

- **(a)** **当該会計年度中**、及び**会計年度末から報告書の日付までの期間中**に会社の取締役であったすべての者の氏名；
- **(b)** 当該会計年度中における、子会社を含む会社の**主たる事業**；及び
- **(c)** **Fifth Schedule**に定める事項。

連結財務諸表が作成される場合、s.253(2)は、会社への言及を、会社**及び**合算に含まれる子会社企業への言及として読み替える。s.253(3)は、報告書にFifth ScheduleのPart IIに定める**事業レビュー**、またはその他の所定の報告事項を含めることを認めている——これは義務ではなく任意である。

Fifth Schedule Part I第1項が実質的な内容である。要約すると次のとおり。

| 項目 | 要件 |
| --- | --- |
| (a) | 当該会計年度の**所得税引当後**の純利益または純損失 |
| (b) | 準備金または引当金への、または準備金・引当金からの重大な振替の金額及び詳細 |
| (c) | 当該年度中に発行された株式または社債——目的、種類、数量及び金額、並びに発行条件 |
| (d) | 取締役が株式または社債を取得することにより利益を得ることを可能にする取り決めで、年度末時点または年度内のいずれかの時点で存続していたもの、及びこれに関与した取締役の氏名 |
| (e) | 年度末時点で取締役であった各人について——**s.59登録簿**に基づく、株式及び社債における同人の持分（年度末時点、年度当初または取締役に就任した時点）、並びに当該年度中に買い付け及び売却された総数 |
| (f) | 勧告された配当、及び前会計年度末以降に支払われた、または宣言された配当 |
| (g)、(h) | 貸倒れ及び回収困難債権について合理的な措置が取られたか、並びに取締役がそれらの金額を不十分にする事情を認識しているか |
| (i)、(j) | 換価不能な流動資産を減額するために合理的な措置が取られたか、並びに価額または評価方法に誤解を招くものがあるか |
| (k) | 年度末以降に発生した、他人の債務を担保する資産に対する担保権、及び偶発債務 |
| (l) | 年度末後**12か月以内**に強制執行可能となる偶発債務またはその他の債務で、会社の債務履行能力に影響を及ぼしうるもの |
| (m) | 他の箇所で扱われていない事情で、会計書類に記載された金額を誤解を招くものにするもの |
| (n) | **重大かつ異常な性質**の項目、取引または事象によって業績が実質的に影響を受けたか |
| (o) | **年度末から報告書の日付までの間**に生じた重大かつ異常な項目、取引または事象 |
| (p) | 登記官が決定するその他の詳細事項 |

第1(e)項が、s.219の持株通知が重要である理由である——この報告書は**s.59登録簿**から組み立てられており、その登録簿はそれらの通知から組み立てられている。

**第2項**は、報告書に、取締役及び前取締役について、報酬及びその他の給付の金額を**区分して**記載することを求めている。これには報酬、歩合、賞与、手数料及び退職慰労金が含まれる。また、非現金給付の見積金額、取締役の役務に対して第三者に支払われた金額、並びに**取締役、役員または監査人のために与えられた補償、または付保された保険**の総額を記載しなければならない。取締役またはその事務所が専門的な立場で行為する場合、それらの金額は合計から除外されるが、別途表示しなければならない。

**第3項**は、各取締役に対し、前会計年度末以降に、開示された報酬または専従従業員としての固定給与に含まれるものを除き、会社または関連法人が同人本人、同人が社員である事務所、または同人が実質的な財務上の利害を有する会社と締結した契約により、利益を受領した、またはその権利を取得したか、また該当する場合はその概要を述べることを求めている。

**第4項**は、子会社に対し、その**最終持株会社**の名称、及び判明している場合はその設立国を記載することを求めている。**第5項及び第6項**は、未発行株式について付与されたオプション——数量及び種類、失効日、行使の基準、並びに他社の株式発行に参加する権利——及び当該オプションの行使により当該期間中に発行された株式を扱っている。

## 実際の期限はどこにあるか

s.251にもs.252にも日付は定められていない。期限は次のとおりである。

- **s.258(1)(a)**——私会社は、**会計年度末から6か月以内**に財務諸表及び各報告書を回付しなければならない；
- **s.259(1)(a)**——**回付から30日以内**に登記官に提出しなければならない；
- **s.248(1)(a)**——**最初**の財務諸表は、設立から**18か月**以内に期限を迎える。

2つの免除条文を知っておく価値がある。**s.255**は、取締役が、財務諸表または取締役報告書の**様式及び内容**に関する要件を免除する命令を登記官に申請することを認めている——ただし、s.255(2)により、承認された会計基準と矛盾する場合には認められず、s.255(5)により、遵守することが誤解を招くか、会社の状況に不適切であるか、または不合理な負担を課すこととなる場合に限られる。s.255(3)は、特定の類型全体に適用される命令を認めている。そして**s.254**は、様式及び内容の規則を、国家銀行（Bank Negara Malaysia、BNM）が定める修正を加えたうえで免許を受けた機関に適用する。

## よくある誤り

**s.251を提出に関する条文として扱うこと。** これは取締役会の承認と法定宣誓書の条文である。提出はs.259、回付はs.258である。この誤りは公表されている要約の中でよく見られるため、引き継いだチェックリストがあれば確認する価値がある。

**法定宣誓書を誤った者に作成させること。** s.251(1)(b)は、取締役が財務管理を主として担当していない場合に限り、**財務管理を主として担当する者**に宣誓を委ねる。都合のよい選択ではない。

**取締役2名の取締役会で署名が1つしかないこと。** s.251(3)とs.252(2)(b)はいずれも、取締役が2名以上いる場合には**少なくとも2名**を求めている。

**回付される副本に署名者の氏名を記載し忘れること。** s.252(3)は、すべての副本にこれを記載することを求めている。

**年度末時点で在任していた取締役のみを記載すること。** s.253(1)(a)は、当該年度**中**に取締役であったすべての者、及び年度末から報告書の日付までの期間中に取締役であったすべての者の記載を求めている。

**株主名簿から第1(e)項を記入すること。** これは**s.59の取締役持株登録簿**から得なければならず、それは異なる法定トリガーを持つ別の帳簿である。

**第2項の最後の項目を忘れること。** 取締役、役員または**監査人**のために与えられた補償、または付保された保険の総額は必須の開示事項であり、しばしば漏れている。
