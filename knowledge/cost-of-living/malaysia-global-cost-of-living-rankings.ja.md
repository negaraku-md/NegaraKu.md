アジアで限られた予算の駐在員をどこに配属すべきか、移転コンサルタントに尋ねれば、クアラルンプールの名前が何度も挙がる——それは調査がこの都市を持ち上げているからではなく、数字が実際にこの都市を生活費表の底辺近くに位置づけているからだ。マレーシアを代表するこの都市は、安さと暮らしやすさを*同時に*兼ね備える数少ない場所の一つである。

## 三大調査はマレーシアをどうランク付けしているか？

議論を主導する指数は三つあり、それぞれ測定対象がわずかに異なる。

| 調査 | 測定対象 | マレーシアの位置 |
|---|---|---|
| **Mercer生活費調査（2023年）** | 企業の海外赴任向けに、227都市における駐在員バスケットのコストを測定 | クアラルンプールは**227都市中180位**にランクイン |
| **Numbeo（2025年）** | クラウドソースによる消費者物価の相対指数 | マレーシアは**29.7**、東南アジア8カ国中5位 |
| **EIU世界生活費調査（2023年）** | 173都市における200以上の製品・サービスにわたる400超の価格 | マレーシアの都市は上位層から大きく外れている |

三つの調査はいずれも異なる角度から同じ結論を語っている——国際基準で見ればマレーシアは物価が安い、という結論だ。意見が分かれるのは、*どれほど*安いかという点だけである。

## クアラルンプールは地域内でどの位置にあるか？

Mercerの2023年調査は、個々の都市を単一の尺度でランク付けしているため、最も明確な同地域内比較となる。香港が世界1位、シンガポールが2位となり、チューリッヒ（3位）、ジュネーブ（4位）、バーゼル（5位）を上回った。クアラルンプールは大きく引き離され、180位にとどまった。

| 都市 | Mercer 2023年 世界ランク |
|---|---|
| シンガポール | 2 |
| バンコク | 105 |
| プノンペン | 132 |
| マニラ | 133 |
| ジャカルタ | 151 |
| ハノイ | 156 |
| ホーチミン市 | 164 |
| バンダルスリブガワン | 172 |
| **クアラルンプール** | **180** |
| ジョホールバル | 212 |

東南アジア域内では、クアラルンプールはMercerが追跡した都市の中でも特に生活費の低い都市の一つであり、212位のジョホールバルは、この発表において東南アジアで最も順位の低い都市となり、上記のすべての地域首都を下回った。

## 安さと暮らしやすさ——稀な組み合わせか？

安さは通常、生活の利便性を犠牲にすることを意味する。Mercerの2024年都市ランキングがクアラルンプールを特別に取り上げたのは、まさにそうではなかったからだ。同調査は、低い生活費と高い生活の質を兼ね備えた世界でわずか**8都市**の一つにクアラルンプールを挙げた——リュブリャナ、モントリオール、ワルシャワ、ザグレブ、ブダペスト、パナマシティ、サンティアゴと並んでである。Mercerは、このグループが家族連れやリモートワーカー、そして人材を惹きつけやすく費用対効果の高い赴任先を探す企業にとって魅力的であると指摘した。

## 日常的な数字はどうなっているか？

Numbeoのクラウドソースデータは、日常生活に具体的な数字を与える。その2025年東南アジア国別指数では、マレーシアは**29.7**——シンガポール（79.1）、ブルネイ（44.4）、カンボジア（33.9）、タイ（33.7）を下回り、フィリピン（28.8）をわずかに上回る水準であり、ベトナム（26.6）とインドネシア（24.6）が域内で最も低い。

金額で見ると、Numbeoは単身者の月間支出を家賃を除いて約**RM2,174**、4人家族では家賃を除いて約**RM7,923**と見積もっている。全体の生活費は米国と比べて約51.5%低く、家賃は約76.9%低いと試算されており、この住宅費の格差がマレーシアの割安感を生む最大の要因となっている。

## なぜこれらはマレーシア自身の物価データと一致しないのか？

ここで重要な注意点がある。Mercer、Numbeo、EIUはいずれも特定の読者——駐在員、モビリティ・マネージャー、国際的な雇用主——のために設計されている。これらは輸入・国際基準のバスケット（駐在員水準の住宅、外国人向け学校教育、輸入食料品）を価格評価し、しばしばすべてを米ドルに換算するため、現地の物価が一切変わらなくても、リンギットの上昇や下落だけでマレーシアの順位が動くことがある。

マレーシア統計局（DOSM）が測定しているのは、これとは異なるものである。その消費者物価指数（CPI）は、マレーシアの家計が消費する財・サービスのバスケットの価格を追跡しており、そのバスケットの構成と重み付けは家計支出調査（Household Expenditure Survey）——住宅、食料、交通、サービスにわたって現地の家計が実際にどのように支出しているかを記録する調査——から導き出されている。このバスケットが国内消費に重点を置いているため、世界的な調査が依然としてこの国を「安い」と評しているあいだにも、国内では物価上昇を示すことがある。両者は単に異なる問いに答えているにすぎない——マレーシアが世界と比べてどうかを知るには世界ランキングを、現地に暮らす人々にとってコストがどう動いているかを知るにはDOSMのデータを見ればよい。

## 次にすべきこと

これらの指数は方向性の目安として使うものであり、個人の予算計画そのものではない。転居や赴任を計画している場合は、ランキングについて最新年のMercerおよびEIUの発表を確認し、クアラルンプール、ペナン、ジョホールバルについてはNumbeoの都市別ページで突き合わせたうえで、実際の数字をDOSMの国内物価データに照らして確認するとよい。ランキングは為替レートに応じて年ごとに変動するため、引用する調査の版を必ず明記すること。
