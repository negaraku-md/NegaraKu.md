多くの新米の親は、子の出生登録を、時間ができたときまで先延ばしにできる無料の
書類仕事だと考えている。確かに無料である——ただし**最初の60日間**に限っての
話だ。その期間を過ぎると、JPNは申請を遅延登録として分類し、RM50の手数料が課
され、持参すべき書類のリストも長くなる。以下は、国民登録局（Jabatan Pendaftaran
Negara、JPN）の公式ポータルに従って、この手続きが実際にどう機能するかを説明する。

## 60日の期間：無料だが厳格

マレーシア（半島部）で発生したすべての出生は、**出生日から60日以内**に登録しな
ければならない。申請がこの期間内に行われる限り、JPNは一切の手数料を課さない。

この期限は緩やかな指針ではない——それは申請が「通常の登録」として扱われるか
「遅延登録」として扱われるかを決定し、この二つは書類と手数料がまったく異なる
経路である。

## 誰が届出人になれるか

JPNは、いくつかのカテゴリーの人が出生の届出人（出生を報告し登録する者）として
行動することを認めている。

- 子の実母または実父
- 子の法定後見人
- その出生が発生したことを目撃した、または知っている者
- 両親の双方（嫡出でない子の出生登録に限る）

届出人は、最寄りのJPN事務所に**自ら出頭する**ことが求められる——通常の登録は完全
にオンラインで完結させることはできない。

## 必要書類

通常の出生登録に必要な中核的書類：

| 書類 | 備考 |
| --- | --- |
| JPN.LM01様式（記入済み） | 公式の出生登録様式、原本 |
| 病院の出生確認書、または医師・助産師の確認書 | 居宅出産の場合 |
| 警察報告書 | 居宅出産に限る |
| 妊娠前・妊婦の記録カード | 原本および写し |
| 両親の身分証明書 | 原本および写し |
| 届出人の身分証明書（親でない場合） | 原本および写し |
| 母または父の死亡証明書（該当する場合） | 原本および写し |
| 両親の婚姻または離婚に関する書類 | 原本および写し、該当する場合 |
| 宣誓供述書AM80 | 母の保健医療記録が入手できない場合 |
| 公共料金の請求書（水道・電気・電話） | 居住地の住所が身分証明書と異なる場合 |

60日以内の通常の登録には、手数料は一切かからない。

## 60日を過ぎた後：遅延登録

60日の期間が経過すると、申請は**遅延登録**とみなされる。主に二つの変化が生じる。

- **RM50の申請手数料**が課される。
- 追加の証明書類が必要となる——その中には、JPNの検索結果、子の写真、子の
  健康・予防接種カード、学校の記録または認知書（該当する場合）、そして裏付け
  資料としての兄弟姉妹の出生証明書が含まれる。

遅延登録の申請も、必要な書類を持参のうえ、半島マレーシア全域のいずれのJPN事務所
でも行うことができる。

## サバとサラワク：異なる期間

サバとサラワクは、半島部と同じ60日の期限には従わない。サバでは、出生後**15日目
から42日目まで**に行われた申請が**遅延登録**とみなされ、**RM5**の処理手数料がかかる。
サバとサラワクの親または後見人は、期限と手数料が半島部と異なる場合があるため、
登録日を計画する前に、それぞれの州のJPN事務所で適用される期間を確認することが
勧められる。

## 出生証明書の再取得（抄本／写し）

出生証明書は登録が完了した時点で発行される。その証明書が後に紛失し、破損し、
または追加の写しが必要となった場合（例えばパスポートや学校の申請のため）、JPNは
**JPN.LM12**様式（半島部）を用いて**出生登録の検索／抄本**サービスを提供している。

課される手数料：

| サービス | 手数料 |
| --- | --- |
| 申請手数料（出生登録の検索結果） | RM10.00 |
| 出生登録の抄本 | RM5.00 |

この申請も、身分証明書または本人確認書類の原本および写しを持参のうえ、最寄りの
JPN事務所に自ら出頭して行う。他人に代わって申請する弁護士および政府機関は、
それぞれの資格に応じて追加の書類が必要となる。

## よくある誤り

- **登録の前に「時間ができるまで」待つこと。** 60日の期間は思ったより早く過ぎる。
  とりわけ、病院から帰宅して新生児の世話をしている間はそうである。
- **母の出産関係書類（妊婦カード）を持参しないこと。** 多くの届出人は身分証明書と
  様式だけを持参し、母の健康カードも必要となるためにJPNへ再度足を運ぶ羽目になる。
- **遅延登録がオンラインで行えると思い込むこと。** 通常の登録も遅延登録も、届出人が
  JPNの窓口に物理的に出頭することが必要である。
- **サバ・サラワクの期間を半島部の期間と混同すること。** 60日の期限は半島部に限った
  ものであり、サバやサラワクに同じ期間が適用されると思い込んではならない。
- **出生証明書の原本を安全に保管しないこと。** 紛失した証明書は別途、抄本の申請が
  必要となり、検索手数料と抄本手数料がそれぞれかかる。

## 次のステップ

子の出生証明書を取得した後、この書類は他の登録手続き——子が対象年齢に達した際の
[MyKad](/glossary/mykad)の申請を含む——の基礎となる。この部門が扱うサービスの
全体像——出生から死亡、居住状況まで——を理解するには、[国民登録局（JPN）](/government/jpn)
のページを参照されたい。
