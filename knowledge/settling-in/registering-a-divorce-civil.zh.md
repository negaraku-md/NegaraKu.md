在JPN登记结婚的非穆斯林夫妻，往往以为同一个部门也能为他们办理离婚。事实并非如此。在马来西亚，民事婚姻是通过行政方式登记的，但只能凭法庭命令予以解除——而从貌合神离的婚姻到一纸盖章判令的路径，要经过一个调解仲裁庭、一份高等法院呈请，以及离婚正式生效前内建的三个月缓冲期。

本文是[为什么马来西亚的离婚也按宗教划分](getting-divorced-in-malaysia)这一较宏观概述的配套细节。它只描述根据**《1976年法律改革（婚姻与离婚）法令》（第164号法令）**的民事（非穆斯林）路径——这也正是槟城妇女醒觉中心（WCC）等社区法律普及资源为非穆斯林所概括的同一套框架。本文属描述性质，并非法律意见；时限、费用与策略因个案而异。

## 谁做什么——以及为何JPN无法为你办理离婚

有必要区分人们常常混为一谈的两种角色。

- **国民登记局（JPN）**负责登记非穆斯林婚姻，设有用于调解的**婚姻仲裁庭**，并在离婚生效后更新婚姻记录。
- **民事高等法院**是唯一能够真正解除婚姻的机构。第164号法令第48条明确规定，只有当婚姻是根据该法令登记（或视为登记）、属于一夫一妻制，且在呈请提交时双方的居籍（domicile）在马来西亚时，法院方可批准离婚。

因此，JPN处于*起点*（登记与调解）和*终点*（更新记录），而解除婚姻本身则是一项法庭行为。

## 结婚是否有最短年限要求？

多数情况下有。第50(1)条规定：“离婚呈请不得在结婚之日起两年期届满之前向法院提交。”

有一个狭窄的例外。根据第50(2)条，法官可基于“个案属于特殊情况，或呈请人遭受困苦”为由准许提前呈请——但在裁定时，法官须顾及任何子女的利益，以及和解是否有合理可能。

有一种情形完全不受此限：因一方**皈依伊斯兰教**而寻求的离婚。第51(3)条明确规定第50条不适用于此类呈请；取而代之的是，第51条要求自皈依之日起等待三个月。双方同意的联合呈请（第52条）并非两年规则的例外——第52条本身即要求结婚已满两年，因此绝不可能更早采用。第52条路径的不同之处在于其调解步骤，详见下文。

## 是否必须先尝试和解？

对多数呈请而言，是的。第106(1)条规定：“任何人不得呈请离婚，第51条与第52条所列者除外，除非其已先将婚姻困难转介至一个调解机构，且该机构已证明其未能使双方和解。”

实务上，调解机构通常是**JPN婚姻仲裁庭**。若双方无法就另一个可接受的机构达成一致，第106(2)条规定将困难转介至双方居住地所属地区的婚姻仲裁庭——若双方分居，则为最后共同居住地所属地区的仲裁庭。仲裁庭须在**六个月**内尝试化解该事项（第106(5)条）。

转介是在JPN办事处进行的一项行政步骤。据报道的实务做法为：提交一份转介表格（表格JPN.KC14），亲身出席为数不多的几次会谈，若和解失败，则领取一份未和解证明（一般引述为表格KC29），随后出具给法院。具体表格与象征性费用由JPN设定，可能变动，因此请直接向办事处核实。

第106(1)条也列出了该要求**不**适用的情形：

| 情形（第106条但书） | 效果 |
| --- | --- |
| 呈请人被遗弃且不知配偶下落 | 无须转介 |
| 答辩人居于国外，六个月内不太可能进入司法管辖范围 | 无须转介 |
| 答辩人被要求出席却蓄意未出席 | 无须转介 |
| 答辩人被判处五年或以上监禁 | 无须转介 |
| 答辩人被指患有不可治愈的精神疾病 | 无须转介 |
| 法院认定存在特殊情况使转介不切实际 | 无须转介 |

根据第51条（皈依）和第52条（双方同意）提出的呈请，从一开始即被豁免。

## 联合呈请还是单方呈请？

第164号法令提供两条各不相同的诉诸法院路径。

- **联合呈请——双方同意（第52条）。** 若丈夫与妻子一致同意应解除婚姻，他们可在结婚满两年后提交联合呈请。若法院确信双方均属自愿同意，且已为配偶以及任何子女的抚养、照顾与监护作出妥善安排，则可批准判令。
- **单方呈请——无可挽回的破裂（第53条）。** 任何一方均可以“婚姻已无可挽回地破裂”为理由提出呈请。法院会调查相关事实，若认为公正合理，即作出判令。

对于单方呈请，第54(1)条列出了法院在裁定婚姻是否已破裂时须考虑的事实：

1. 答辩人已犯**通奸**，且呈请人认为无法忍受与其共同生活；
2. 答辩人的**行为**已使人不能合理期望呈请人与其共同生活；
3. 答辩人已连续**遗弃**呈请人至少两年；或
4. 双方已连续**分居**至少两年。

法院仍须权衡所有情况，包括双方的行为以及对任何子女的影响，若解除婚姻属不当，可驳回呈请（第54(2)条）。

## 暂准判令与绝对判令有何区别？

这是多数人最容易读错的一步。离婚并非在法院“批准”的当天即告最终生效。第61(1)条规定：“每一项离婚判令首先应为暂准判令，且除非法院不时以一般或特别命令订定较短期限，否则不得在判令作出起三个月届满前成为绝对判令。”

用平实的说法，其顺序为：

- 法院作出**暂准判令**——一项临时命令。
- 三个月期届满后，可经申请使判令**成为绝对**。
- **暂准判令转为绝对**之时，即为双方在法律上离婚的时点。

第61(2)条还允许在某些情形下，若取得判令的一方未提出申请，另一方可申请使判令成为绝对。

## 更新JPN的记录

一旦判令成为绝对，即可更新婚姻记录。做法是将盖章的法庭命令——即暂准判令转为绝对的证明（或其经核证副本）——出具给JPN，由其相应更新登记册。这是一项记录维护步骤：离婚在判令成为绝对时即已产生法律效力，而非在JPN更新档案之时。
