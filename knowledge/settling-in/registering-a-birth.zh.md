许多新手父母把登记孩子的出生当作可以拖延到有空才办的免费文书工作。这确实是免费的——但仅限于**头60天**。过了这段期限，JPN会把申请归类为迟延登记，须缴付RM50费用，而须携带的文件清单也会变得更长。以下根据国民登记局（Jabatan Pendaftaran Negara，JPN）的官方门户网站，说明此手续实际上是如何运作的。

## 60天期限：免费，但不容通融

凡在马来西亚（西马）发生的出生，均须在出生日期起**60天**内登记。只要申请在此期限内提出，JPN不会收取任何费用。

这项限期并非可有可无的指引——它决定申请会被当作「普通登记」还是「迟延登记」处理，这是两条文件与费用完全不同的途径。

## 谁可以担任呈报人

JPN允许以下几类人士担任出生呈报人（负责申报及登记出生的人）：

- 孩子的亲生母亲或父亲
- 孩子的合法监护人
- 目睹或知悉该出生事件发生的任何人
- 父母双方（专用于非婚生子女的出生登记）

呈报人必须**亲自**前往邻近的JPN办事处——普通登记无法完全在线上完成。

## 所需文件

普通出生登记所需的核心文件：

| 文件 | 备注 |
| --- | --- |
| JPN.LM01表格（填妥） | 官方出生登记表格，正本 |
| 医院出生确认书，或医生／助产士确认信 | 适用于居家分娩 |
| 警方报告 | 专用于居家分娩 |
| 产前记录卡／孕妇卡 | 正本及副本 |
| 父母身份证 | 正本及副本 |
| 呈报人身份证（若非父母） | 正本及副本 |
| 母亲或父亲的死亡证（如适用） | 正本及副本 |
| 父母的结婚或离婚文件 | 正本及副本（如适用） |
| AM80法定声明书 | 若无孕产健康护理记录可提供 |
| 水电／电话账单 | 若居住地址与身份证不同 |

在60天期限内办理普通登记，不收取任何费用。

## 超过60天后：迟延登记

一旦60天期限届满，申请即被视为**迟延登记**。届时会有两项主要变化：

- **须缴付RM50申请费。**
- 须提交额外证明文件——包括JPN查询结果、孩子的照片、孩子的健康／疫苗接种卡、学校记录或承认信（如适用），以及兄弟姐妹的出生证明书作为佐证。

迟延登记申请仍可在西马各地任何一间JPN办事处办理，只须携带所需文件。

## 沙巴与砂拉越：不同的期限

沙巴与砂拉越并不适用与西马相同的60天限期。在沙巴，出生后**第15天至第42天**内提出的申请视为迟延登记，须缴付**RM5**手续费。建议沙巴与砂拉越的父母或监护人在安排登记日期前，先向所在州属的JPN办事处查询适用的期限，因为限期与费用可能与西马不同。

## 重新领取出生证明书（摘录／副本）

出生证明书在登记完成后即发出。若证明书日后遗失、损坏，或需要额外副本（例如用于护照或学校申请），JPN提供**出生登记查询／摘录**服务，使用**JPN.LM12**表格（西马）办理。

收费如下：

| 服务 | 费用 |
| --- | --- |
| 申请费（出生登记查询结果） | RM10.00 |
| 出生登记摘录 | RM5.00 |

此申请同样须亲自前往邻近的JPN办事处办理，携带身份证或身份证明文件正本及副本。律师及代他人申请的政府机构，须按各自的资格提供额外文件。

## 常见错误

- **等到「有空才办」才登记。** 60天期限过得比预期快，尤其是从医院回家后还要照顾新生儿。
- **未携带产妇文件（产前卡）。** 许多呈报人只带身份证与表格，结果因为母亲的健康卡也是必需文件而须多跑一趟JPN。
- **以为迟延登记可以在线上办理。** 普通登记与迟延登记都须呈报人亲自到JPN柜台办理。
- **把沙巴／砂拉越的期限与西马的期限混淆。** 60天限期专属于西马；不要假设沙巴或砂拉越适用相同期限。
- **未妥善保管出生证明书正本。** 遗失的证明书须另行申请摘录，须另缴查询费与摘录费。

## 下一步

孩子的出生证明书取得后，这份文件将成为其他登记事项的基础——包括孩子达到合格年龄后申请[MyKad](/zh/glossary/mykad)。若要了解本部门所处理服务的完整范围——从出生、死亡，到居留身份——请参阅[国民登记局（JPN）](/zh/government/jpn)页面。
