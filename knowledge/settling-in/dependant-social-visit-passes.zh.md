一名迁居马来西亚的 Employment Pass 持证人，可以用一张准证带上配偶与年幼子女。他们的父母，或一名刚满十八岁的子女，则需要一张完全不同的准证。同一位主要持证人，同一个家庭，却是两个各自独立的移民类别——把两者混为一谈，是家庭担保申请卡住最常见的原因。

## 分野：年龄与关系决定准证

马来西亚没有依附于 Employment Pass 的单一「家庭签证」。根据外籍人士服务组（Expatriate Services Division，ESD）自家的准证页面，移民局按家属身份把他们分成两条路线。

| 与主要持证人的关系 | 准证 |
| --- | --- |
| 配偶 | Dependant Pass |
| 十八岁以下子女（包括合法领养的子女） | Dependant Pass |
| 父母或岳父母／公婆 | Long-Term Social Visit Pass（LTSVP） |
| 十八岁以上子女 | Long-Term Social Visit Pass（LTSVP） |

Dependant Pass 是较窄、也较自动的路线：它专门为 Employment Pass 持证人的配偶与未成年子女而设。LTSVP 则是范围更广的兜底类别——ESD 用它来涵盖 Dependant Pass 未覆盖的家属，但大马移民局也在与 Employment Pass 完全无关的情形下签发 LTSVP，例如一名直接与马来西亚公民结婚的外籍人士。LTSVP 的这第二种用途按自己的一套条件运作——对公民的外籍配偶而言，它以更长、可续期的基础获批——这与本文所述外籍专才父母或成年子女的路径是不同的途径。

## 两种准证都拴在主要持证人身上

不论家属持有哪一种准证，它都不能独立存在。ESD 在两个页面上都说得很明确：有效期跟随主要持证人本身的 Employment Pass，以较早届满者为准——主要持证人的准证，或家属本人的护照。若主要持证人的 Employment Pass 获得续期，家属的准证也可随之续期；若主要持证人的身份终止，家属的身份也随之终止。

这种依附关系只朝一个方向运作。Dependant Pass 或 LTSVP 持证人本身不能担保任何人，一旦脱离主要持证人，也就没有独立的移民身份——打断整条链的，是主要持证人失去作为依据的 Employment Pass，而不是反过来。

## 两种准证都不允许你工作

多数混淆都出在这里。透过 Employment Pass 主要持证人取得的 Dependant Pass 或 LTSVP，都不带在马来西亚工作的权利。ESD 自家页面就 Dependant Pass 说得很直白：持证人若想就业，「须申请 Employment Pass」——现有准证必须搁置一旁，改以家属本人的名义、由其自己的雇主担保，重新申请一张 Employment Pass。

这与签发给马来西亚公民外籍配偶的 LTSVP 是一条真正独立的规则——根据移民局自家针对该类别的页面，这种 LTSVP 可以在不转换为 Employment Pass 的情况下附带工作许可，惟须符合其自身的签注条件。教训是：「LTSVP」并非统一的一套权利。某一张具体的 LTSVP 允许什么，取决于它是在哪一个资格类别下获批的，而不只是准证的名称。

## 透过保荐方的 ESD 账户申请

对于依托 Employment Pass 担保的家属，Dependant Pass 与 LTSVP 的申请方式相同：都透过保荐公司在 ESD 门户上的注册账户提交，而不是由家属本人直接申请。这意味着文书工作落在雇主的人力资源或调动团队身上，不亚于落在家属身上——一名抵达马来西亚的配偶或父母，不能脱离主要持证人本身的 Employment Pass 记录，径自走进移民局柜台申请任何一种准证。

## 常见错误

- **以为子女会自动「长大转入」LTSVP。** 满十八岁会改变适用的准证，但 ESD 的页面并未把这描述为自动发生——在 Dependant Pass 原本会失效之前，需要另行提交申请。
- **把「LTSVP」当成一套固定不变的规则。** Employment Pass 主要持证人名下成年子女的 LTSVP，与马来西亚公民外籍配偶的 LTSVP，是两个资格类别，尽管共用同一个名称，期限与工作权利却各不相同。
- **期望家属的准证比主要持证人的准证更长久。** 由于有效期以主要持证人本身的 Employment Pass 为上限，家属的准证不可能比它所依附的保荐准证更长。
- **以为准证本身就授权工作。** 两种准证都不会；要工作，就得以家属本人的名义申请 Employment Pass。
