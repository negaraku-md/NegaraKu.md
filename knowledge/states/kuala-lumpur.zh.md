吉隆坡是马来西亚的国家首都，但在宪制上它并不是一个州属——它是联邦直辖区，1974 年从雪兰莪划出，由联邦政府直接管辖，而不是由州统治者或民选州议会管辖。

## 重点资料

| | |
| --- | --- |
| 首府 | 吉隆坡（它本身就是国家首都） |
| 人口 | 约 200 万（市区）；大吉隆坡逾 800 万 |
| 元首 | 联邦直辖区——由联邦政府管辖 |
| 主要产业 | 金融与银行、企业总部、专业服务、旅游 |

## 地理

吉隆坡是一块小而完全城市化的飞地，四面被雪兰莪州包围，位于巴生河与鹅唛河交汇处附近——正是这个交汇点给了这座城市名字，意为「泥泞的河口」。它约 243 平方公里，是本系列所涵盖的地区中面积最小的，但它的市区无缝并入邻近的雪兰莪城镇，如八打灵再也、梳邦再也与莎阿南，共同构成更大的巴生谷都会连绵区。行政机关的职能自 1999 年起大体迁往专门兴建的联邦直辖区布城，让吉隆坡专注于它作为商业与金融首都的角色。

## 经济

吉隆坡的人均 GDP 是马来西亚各地之冠，几乎完全由服务业而非工业带动。全国证券交易所 Bursa Malaysia 设于市内，几乎所有马来西亚主要银行、保险公司与上市集团的总办事处也在此。黄金三角一带（KLCC、武吉免登及周边街区）拥有全国最昂贵的办公空间，以及最密集的跨国公司区域总部。旅游、零售与会展（MICE）产业也是重要贡献者，由吉隆坡会展中心与庞大的酒店基础支撑。由于这座城市的土地面积固定且大体已开发殆尽，增长日益外溢到邻近的雪兰莪，这正是为什么把两地理解为一个整合的经济体最为恰当。

## 在这里做生意

吉隆坡地址带来的是声望，以及与决策者、专业服务公司和资本市场的邻近——多数寻求在 Bursa Malaysia 上市，或与本地大型银行建立往来关系的公司，都会通过吉隆坡的据点来办。KLCC 等优质地段的办公室租金是全国最高的，这把许多后勤与营运职能推向八打灵再也、赛城或雪兰莪其他地方，同时把注册或代表办事处留在吉隆坡本身。公司注册、向 SSM 申领执照，以及大多数联邦监管机构的总部都在市内或附近，使亲身与机构打交道更为简便。交通拥堵与高昂的房地产成本，是在这里营运的企业主要的摩擦点。

## 值得一看的地方

曾是世界最高建筑的国油双峰塔，连同 KLCC 公园与购物区，仍是这座城市的标志性地标。吉隆坡塔（Menara KL）从俯瞰市中心的山丘上提供全景视野。1957 年宣布马来西亚独立的独立广场（Dataran Merdeka），与包括苏丹阿都沙末大厦在内的殖民时期建筑并立。茨厂街及周边的唐人街一带，以及位于历史河口的占美清真寺一带，为黄金三角的玻璃高楼提供了更古老、更密实的对照。武吉免登仍是这座城市主要的零售与夜生活区。
