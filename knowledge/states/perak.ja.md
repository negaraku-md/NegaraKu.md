1874年1月20日、パンコール島（Pulau Pangkor）近海で一通の条約が締結された。この文書は領土を割譲するものでも、戦争を宣言するものでもなかった。それはただ一つの新しい役職——その助言に従わなければならない一人の駐在官——を導入したにすぎなかった。

この一条項から、マラヤにおける統治の構造が変わり始めた——そしてペラは、それを最初に経験した州であった。

## 条約以前：ラルットの錫

ペラ・スルタン国は1528年、スルタン・ムザッファル・シャー1世によって始まった。州政府公式サイトによれば、同スルタンはマラッカのスルタン・マームード・シャーの後裔であり——1511年に陥落した[マラッカ王国](/malaysia/melaka-sultanate)からの直接の系譜である。

それから三世紀のあいだ、ペラは西海岸の他の州々と同様、ペラ川（Sungai Perak）のほとりに位置する一つのマレー州にすぎなかった。

状況を一変させたのは鉱物であった。州政府公式サイトは、ペラが「その大地の富が知られるようになって初めて広く知られるようになった、すなわち1848年にチェ・ロン・ジャアファル（Cik Long Jaafar）がラルット（Larut）で錫鉱石を発見したことに続いて」と記している。

錫は、この州の経済を農業と河川交易から大規模な鉱業へと転換させた。それは資本と労働力を引き寄せ——そして最終的には——外部勢力の関心をも引き寄せることとなった。

## 1874年1月20日に締結された内容

パンコール条約は、英国側とペラのマレー人首長たちとの間で締結された。ペラ州政府公式サイトは、この条約の締結が「英国のペラにおける権力を確立した」と述べている。

もっとも決定的な条項は、駐在官という役職に関するものであった。州政府公式サイトはこれを次のように要約している。すなわち、スルタンは一人の英国人駐在官（Resident）を受け入れるものとし、その助言は**「マレー人の宗教と慣習に関わる事項を除くすべての事柄において求められ、かつ従われなければならない」**とされた。

この設計には三つの特徴があることに注目したい。

1. **それはスルタン国を廃止しなかった。** スルタンは引き続き州元首であり続けた。変わったのは、行政事項について拘束力を持つ助言を誰が与えるかということであった。
2. **それは権限の境界を定めた。** マレー人の宗教と慣習は、駐在官の助言の対象から明確に除外されており——この区分は、後の憲政上の枠組みにおいてもその形を保ち続けた。
3. **それは助言を通じて機能するものであり、直接の統治ではなかった。** 公式には統治権はスルタンの手にとどまったが、実際には、行政権はその助言が従われなければならない側へと移った。

ペラ州議会公式サイトは、この変化を一文で要約している。マレー諸州における英国の間接的な介入の後、スルタンに助言する英国人駐在官が任命されたことにより、スルタンとマレー人首長たちの間の伝統的な統治体制が変化したのである。

## パンコール条約後：バーチ、1875年、そして1877年の会議

ペラ初代の英国人駐在官はJ.W.W.バーチ（J.W.W. Birch）であった。州政府公式サイトの記録によれば、彼は初代駐在官に任命され、条約締結からわずか一年後の1875年に暗殺された。

条約締結から三年後、新たな統治構造が制度としての形を取り始めた。ペラ州議会公式サイトの記録によれば、ペラ州務会議（Majlis Mesyuarat Negeri Perak）の第一回会合は**1877年9月10日**、クアラ・カンサーの英国人駐在官官邸にて開かれた。

その第一回会合の構成は、当時の権力構造について多くを物語っている。

| 役職 | 人物 |
| --- | --- |
| 議長 | ラジャ・ムダ・ユソフ（Raja Muda Yusuf） |
| 英国人駐在官 | サー・ヒュー・ロー（Sir Hugh Low） |
| 議員 | ラジャ・イドリス（Raja Idris） |
| 議員 | スピーディー大尉（Captain Speedy） |

会議はマレー語で行われ、[ジャウィ文字](/arts-culture/jawi-script)で記録され、議事録は英語に翻訳された。すべての議案は、法律となる前に審議され、採決にかけられた。

これが、マレーシアの憲政史はある意味で1874年のパンコール条約に始まり、それが1877年のペラ州務会議を通じて実施されたと、ペラ州議会が述べる理由である。この制度の系譜は今日のペラ州議会にまで続いており、同議会はN.01からN.59まで番号が付された59の州議員選挙区を有する。

## イポーとキンタ・バレー

ラルットが最初の錫鉱山であったとすれば、キンタ・バレー（Kinta Valley）は一つの都市を築き上げた鉱山であった。

イポー市議会（Majlis Bandaraya Ipoh）の記録によれば、1884年、ゴペン（Gopeng）村とコタ・バハル（Kota Bharu）にあるその港とを結ぶ道路の建設が始まり、さらにパパン（Papan）とバトゥ・ガジャ（Batu Gajah）の鉱区へと延びた。1895年、イポーはペラ州最大の町となり、マレー連合州では二番目に大きな町となった。1905年から1914年にかけて、市街地はキンタ川（Sungai Kinta）の対岸へと広がった——この地域は今日イポー・ニュータウン（Ipoh New Town）として知られている。

一方、首府としての地位は、ある戦争の出来事を通じてもたらされた。ペラ州議会公式サイトの記録によれば、1942年に日本軍がペラを占領した際、州の行政の中心は太平（Taiping）からイポーへと移された。

その行政上の地位は、その後に確立された。イポーは1962年5月31日にイポー市議会（Majlis Perbandaran Ipoh）となり、**1988年5月27日**、ペラ・スルタンがイポーを市（バンダラヤ）、すなわちペラ・ダルル・リザンの首府と宣言した。

一方、クアラ・カンサーは王室儀礼の中心地であり続けている。その地にあるイスカンダリア宮殿（Istana Iskandariah）は、第35代ペラ・スルタンであるスルタン・ナズリン・ムイッズッディン・シャー・イブニ・アルマルフム・スルタン・アズラン・ムヒッブッディン・シャー・アル＝マグフルラーの即位式が2015年5月6日に行われた場所であり、続いて2015年5月7日にタバル・プサカの儀（Istiadat Tabal Pusaka）とブルシラム・タバルの儀（Istiadat Bersiram Tabal）が執り行われた。

## 公式統計にみる今日のペラ

マレーシア統計局（DOSM）は、2025年（暫定値）のペラの人口を**257.49万人**と推計しており、2024年の256.94万人と比較される。このうち241.54万人が国民である。

| 指標（2025年、暫定値） | ペラ |
| --- | --- |
| 人口総数 | 257.49万人 |
| 人口密度 | 1平方キロメートルあたり122人 |
| 年齢中央値 | 32.1歳 |
| 65歳以上人口 | 10.3% |
| 世帯数 | 73.04万世帯 |
| 平均世帯規模 | 3.5人 |

2025年（暫定値）の国民の民族構成は、ブミプトラ62.4%（マレー人59.2%、その他ブミプトラ3.2%）、華人26.0%、インド系11.2%、その他0.4%である。

注目すべき数字が一つある。ペラの人口のうち10.3%が65歳以上であり、2020年の8.9%から上昇している。これは半島の中でも最も高齢化が進んだ年齢構造の一つである。

経済面では、DOSMはペラ経済が**2025年に5.7%成長した**と報告しており、これは全国の成長率5.2%を上回り、同州にとって十年余りで最も力強い成長となった。主な牽引役は[製造業](/economy/manufacturing)であり、15.2%増加した。とりわけ、同州における自動車製造活動の拡大を受けて、輸送機器その他の製造業が162.9%急増した。サービス業は3.4%成長した。

2025年のペラの一人当たりGDPはRM41,960（2024年：RM39,057）であり、マレーシア全体の平均RM59,167と比較される。

行政面では、ペラ州議会の公式議事録は、同州が12の県を有すると記録している。

## いかなるスルタン国よりも古い：レンゴン・バレー

ペラの遥か北方では、人類の記録は1528年よりもはるかに古くから始まっている。

国家遺産局（Jabatan Warisan Negara）の記録によれば、レンゴン・バレー考古遺産（Warisan Arkeologi Lembah Lenggong）は、ロシア・サンクトペテルブルクで開催された第36回世界遺産委員会の会議において、**2012年6月30日**にUNESCO世界遺産として登録された。遺産地の面積は398.64ヘクタールに及ぶ。

この遺跡には野外遺跡と洞窟が含まれ、旧石器時代、新石器時代から金属器時代にいたる文化の連続層があり、その年代は183万年前から1,000年前にまでさかのぼる。

もっとも広く知られる発見は、グア・グヌン・ルントゥ（Gua Gunung Runtuh）から出土した**ペラ人（Perak Man）**である——東南アジアで発見された、もっとも完全でもっとも古い先史時代の人骨であり、年代は約10,000年前と推定され、また、A2型の先天性短中節骨症（Brachymesophalangia）を伴って生まれた、世界で唯一の先史時代の人骨でもある。一方、1987年に発見されたコタ・タンパン（Kota Tampan）は、約74,000年前のものと推定されている。

## よくある誤り

**「パンコール条約はペラを植民地にした。」** 形式の上では正確ではない。この条約はスルタン国を存続させ、行政事項において拘束力を持つ助言を与える一人の駐在官を導入したにすぎず、マレー人の宗教と慣習は除外されていた。直接統治と助言を通じた統治との違いこそが、直接統治された[ペナン](/states/penang)のような海峡植民地とペラとを分けるものである。

**「イポーは常にペラの首府であった。」** 誤りである。ペラ州議会公式サイトの記録によれば、州の行政の中心は、日本占領下の1942年に太平からイポーへと移された。イポーが市に宣言されたのは1988年になってからである。

**「ペラ・スルタンの役割は国王（Yang di-Pertuan Agong）と同じである。」** 両者はまったく異なる職位である。ペラ・スルタンはペラ州の元首であり、[国王（Yang di-Pertuan Agong）](/government/yang-di-pertuan-agong)は連邦憲法のもとにある連邦最高元首であり、統治者会議（Majlis Raja-Raja）によって選出される。

**「錫鉱石はただの昔話にすぎない。」** 錫の遺産は今日に至るまでペラの都市の地理を形づくっているが——2025年時点の同州の経済構造は、鉱業ではなく、自動車、電気・電子を含む製造業によって牽引されている。

## 次のステップ

パンコール条約の影響をさらに追いたい読者には、ペラ・スルタン国の系譜の起源を理解するための[マラッカ王国](/malaysia/melaka-sultanate)、そして駐在官制度と連邦の枠組みが最終的にどのように終わったかを見るための[1957年独立](/malaysia/independence-1957)という、二つの有用な参考記事がある。

異なる植民地化の道をたどった隣接州の文脈を知るには、直接統治された海峡植民地である[ペナン](/states/penang)、そしてペラの後に英国人駐在官を受け入れた[セランゴール](/states/selangor)と比較するとよい。

最新の数値については、マレーシア統計局の最新発表による州別の人口推計とGDPを確認されたい。いずれも毎年更新されるためである。
