ほぼすべてのマレーシア人が一度は答えを誤る質問がある——パーリスのスルタンとは誰か。

答えは——存在しない。パーリスにスルタンはいない。パーリスはマレーシアで唯一、州元首が**ラジャ（Raja）**を名乗る州であり、この称号は単なる言葉の選択ではない。それは1843年にこの州が建てられた経緯に由来する。

## 基本情報

| | |
| --- | --- |
| 州都 | カンガー |
| 面積 | 約821平方キロメートル——マレーシア最小 |
| 人口 | 約30万人（DOSM 2025年推計） |
| 人口密度 | 1平方キロメートルあたり365人（2025年）、全国平均104人を上回る |
| 州元首 | パーリス・ラジャ殿下 |
| 州GDP | RM65億（2024年）、3.3%成長 |
| 議席 | 国会3、州議会（Dewan Undangan Negeri）15 |

## なぜラジャであってスルタンではないのか

パーリス・ラジャ殿下事務局（Pejabat DYMM Tuanku Raja Perlis）の公式記録がこれを直接説明している。1843年、ラジャ・サイード・フセイン・ジャマルライル（Raja Syed Hussein Jamalullail）は、シャム語で正式に**Phya Polit**として、マレー語では**ラジャ・パーリス（Raja Perlis）**として冊封された。ラマ3世（Raja Rama III）から授けられた正式な称号はPhya Songkram Ramu Wichit Wilis Asmara Phya Politであった。

このマレー語の称号——ラジャ（Raja）——は、その日から現在まで使われ続けている。

この冊封以来、パーリスはワンサ・ジャマルライル家（Wangsa Jamalullail）という一つの家系のみによって統治されており、これまでに7人のラジャを数える。

| ラジャ | 統治期間 |
| --- | --- |
| ラジャ・サイード・フセイン・ジャマルライル | 1843–1873 |
| ラジャ・サイード・アハマッド・ジャマルライル | 1873–1897 |
| ラジャ・サイード・サフィ・ジャマルライル | 1897–1904 |
| サイード・アルウィ・ジャマルライル | 1905–1943 |
| ラジャ・サイード・ハムザ・ジャマルライル | 1943–1945 |
| DYMM トゥアンク・サイード・プトラ・ジャマルライル | 1945–2000 |
| DYMM トゥアンク・サイード・シラジュディン・ジャマルライル | 2000–現在 |

現在のパーリス・ラジャ、トゥアンク・サイード・シラジュディン・イブニ・アルマルフム・トゥアンク・サイード・プトラ・ジャマルライル殿下（Duli Yang Maha Mulia Tuanku Syed Sirajuddin ibni Almarhum Tuanku Syed Putra Jamalullail）は、2000年4月17日に第7代パーリス・ラジャとして即位を宣布された。

## 称号は違っても、連邦における地位は同じ

ここで、多くの簡略な説明が誤りを犯す。称号が異なっても、連邦構造における地位が異なるわけではない。

[マレーシア統治者会議](/government/majlis-raja-raja)（Majlis Raja-Raja Malaysia）は、すべての統治者及び州元首（Yang di-Pertua Negeri）が自動的に会議の構成員となり、統治者会議の議長職は9人のマレー統治者が輪番で務めると述べている。パーリス・ラジャもこの9人のうちの1人である。

その記録はマレーシア国会の公式名簿に明記されている。パーリス・ラジャは2人が[国王（Yang di-Pertuan Agong）](/government/yang-di-pertuan-agong)を務めた経験がある。

- **トゥアンク・サイード・プトラ（Tuanku Syed Putra）**——第3代国王、1960年9月21日から1965年9月20日まで
- **トゥアンク・サイード・シラジュディン（Tuanku Syed Sirajuddin）**——第12代国王、2001年12月13日から2006年12月12日まで

父と子、2つの任期——連邦で最も小さな州から。

## 小さく、人口稠密で、人口統計的に異例

約821平方キロメートルという面積は、他州の大規模な県の多くにすっぽり収まる広さである。MKNは、州都カンガーを筆頭に、アラウ、カキブキット、クアラパーリス、パダンブサール、シンパンエンパットという6つの主要行政区を挙げている。

だが、小さいことは人が少ないことを意味しない。DOSMの記録によれば、パーリスの人口密度は2025年時点で1平方キロメートルあたり365人——全国平均104人の3倍以上である。

もう一つ、あまり語られない事実がある。2025年、パーリスの性比は女性100人に対して男性99人であった。マレーシア全土で女性が男性を上回る地域はわずか2つ——パーリスとプトラジャヤ連邦直轄区（W.P. Putrajaya）のみである。全国の性比は110である。

2025年のパーリスの人口成長率は0.3%で、全国の0.5%を下回る。

## RM65億の経済

DOSMの「2024年州別GDP」公表資料によれば、パーリスの経済は2024年に3.3%成長し（2023年：2.0%）、GDP額はRM65億（2023年：RM63億）であった。

その内訳は、この州について多くを物語っている。

- **サービス業**は州経済を牽引し、3.3%増加した。これは政府サービス部門、並びに卸売・小売業、飲食業、宿泊業の各副部門に支えられている。
- **農業**は第2位の貢献産業であり——半島の州では珍しい位置づけである——2.9%増加し、州GDPの17.1%を占める。漁業副部門は10.5%急増した。
- **建設業**は16.9%と大きく伸びた（2023年：1.4%）。これは土木工学副部門の著しい成長によるものである。

正直に述べておかねばならない。2024年、全国水準RM56,734を上回る1人当たりGDPを記録したのは、クアラルンプール連邦直轄区、ラブアン連邦直轄区、ペナン、サラワク、セランゴールの5州のみであった。パーリスはこのリストに含まれない。この構造を、[ペナン](/states/penang)のような製造業主体の州と比較するか、[マレーシアのGDP](/economy/gdp-overview)の全体像を参照されたい。

## タイ国境：地理的な不利が強みに変わる

パーリスは、北部国境の全体がタイと接するマレーシア唯一の州であり、その開発戦略は今やこの事実の上に築かれている。

**チュピン・バレー工業地帯（Chuping Valley Industrial Area、CVIA）**——国境の町パダンブサール近郊のチュピン渓谷に位置する2,482エーカーの工業地帯で、北部回廊実施機構（Northern Corridor Implementation Authority、NCIA）がNCERの枠組みの下で開発している。重点となる4つのクラスターは、グリーン製造業、ハラル産業、再生可能エネルギー発電、電気自動車である。NCIAは、国民総所得（Gross National Income）へRM25億超、民間投資RM45億、そして12,000件超の雇用機会をもたらすと見込んでいる。

**パーリス・インランド・ポート（Perlis Inland Port、PIP）**——CVIA区域内のパダンブサールにある内陸港プロジェクト。MKNによれば、政府は外部インフラ整備にRM3.18億を割り当てており、運用区域の開発には民間投資RM12億が充てられる。

人の往来については、ワンクリアンICQS及びパダンブサール入国地点を含む、イミグレーション・税関・検疫・保安総合施設（Immigration, Customs, Quarantine and Security、ICQS）を通じて国境が管理されている。必要書類及び運用時間は[マレーシア移民局](/government/imigresen)（Jabatan Imigresen Malaysia）が定めており、変更されることがある。

## よくある誤り

**「パーリスのスルタン」。** そのような職位は存在しない。正式な称号はパーリス・ラジャ殿下（Duli Yang Maha Mulia Raja Perlis）である。9人のマレー統治者のうち、7人がスルタン、1人が最高元首（Yang di-Pertuan Besar、ヌグリ・スンビラン）、1人がラジャ（パーリス）を名乗る。

**ラジャという称号が地位の低さを意味すると考えること。** そうではない。パーリス・ラジャは統治者会議（Majlis Raja-Raja）の正式な構成員であり、国王（Yang di-Pertuan Agong）に選出される資格を有する——そして実際に選出された。

**パーリスを単なる農業州とみなすこと。** 州GDPへの最大の貢献産業は農業ではなくサービス業である。農業は第2位にとどまる。

**パーリスのパダンブサールをブキットカユヒタムと混同すること。** ブキットカユヒタムはケダにある。パーリスの主要な陸路出入国地点はパダンブサールとワンクリアンである。

**議席数を混同すること。** パーリスは国会3議席（P001パダンブサール、P002カンガー、P003アラウ）と、マレーシアで最少となる州議会（Dewan Undangan Negeri）15議席を持つ。

## 次のステップ

投資先としてパーリスを検討している場合は、NCIAと州当局から着手するとよい。CVIA及びPerlis Inland Portの立地が、この国境地点が自社のサプライチェーンに適しているかどうかを左右する。

マレーシアの王室制度を研究している場合、パーリスは最も有用な事例である——称号と憲法上の権限が別物であることを示しているからである。

そして、この地域を理解したいだけであれば、半島北部の歴史は1843年よりもはるかに古くから始まっている。いかなるマレー・スルタン国よりも古い記録を持つ初期王国、[ランカスカ](/malaysia/langkasuka)を参照されたい。
