2024年、電気・電子・光学製品はケダの製造業付加価値の51.1%を占めた。パディは、
州GDPの10.6%を占める農業部門の一部を担っている。

全国の米どころとして知られるこの州は、自らの経済計算においては、工場の州で
ある。

この二つの事実は同時に真実である——そしてその理由を理解することこそが、ケダ
を理解する最良の方法である。

## 基本情報

| | |
| --- | --- |
| 州都 | アロースター |
| 州元首 | ケダ州スルタン |
| 面積 | 9,447平方キロメートル |
| 行政区 | 12、[ランカウイ](/tourism/langkawi-visitor-guide)を含む |
| 人口 | 223万人（DOSM 2025年推計） |
| 2024年GDP | RM540億、4.2%成長 |
| 2024年承認投資額 | RM458億——全国州の中で4番目に高い |
| 2022年パディ生産量 | 834,901メトリックトン——マレーシア最高 |

出典：ケダ州政府公式ポータル、DOSM、MIDA。

## 経済構造：GDPを実際に生み出しているもの

DOSMが発表した「2024年州別GDP」のプレスリリースによれば、ケダのGDPは
**RM540億**で、2023年の1.7%に対し**4.2%**の成長を記録した。

その産業別内訳は、どのような呼び名よりも正確にこの州を物語っている。

| 産業 | 金額（2024年） | GDPに占める割合 | 成長率 |
| --- | --- | --- | --- |
| サービス業 | RM303億 | 56.1% | +3.8% |
| 製造業 | RM161億 | 29.9% | +6.6% |
| 農業 | RM57億 | 10.6% | +4.0% |
| 建設業 | RM14億 | 2.6% | −11.1% |
| 鉱業・採石業 | RM1億 | 0.2% | −3.0% |

第二の成長エンジンは製造業であり、2023年に3.2%縮小した後、6.6%へと急伸し
た。この分野の中で、電気・電子・光学製品は付加価値の51.1%を占め、6.5%成長
した。

言い換えれば、価値で見ればケダの工場生産の半分以上が[電子・半導体](/economy/electronics-semiconductors)である。

## なぜケダは今も米どころなのか

この呼び名が測っているのは別のものである——ケダ経済に占めるパディの割合で
はなく、全国のパディ供給に占めるケダの割合である。

DOSMの2022年参照年の農作物データセットによれば：

| | ケダ | マレーシア |
| --- | --- | --- |
| パディ作付面積 | 213,718ヘクタール | 637,935ヘクタール |
| パディ生産量 | 834,901メトリックトン | 2,281,739メトリックトン |

これは、全国のパディ生産量の約**36.6%**が、この一州だけで生み出されている
ことを意味する。第2位と第3位の産地——クランタン（272,633メトリックトン）
とペラ（269,790メトリックトン）——は、それぞれケダの総量の3分の1にも満た
ない。

その技術的な基盤にあるのは水である。ムダ農業開発庁（Lembaga Kemajuan
Pertanian Muda、MADA）は、**1972年ムダ農業開発庁法（Akta Lembaga
Kemajuan Pertanian Muda 1972、Akta 70）**——1972年3月31日に施行——のもと
で設立され、Pedu、Muda、Ahningの三つのダムを管理している。これにより、ムダ
地区では**年2回**のパディ作付けが可能になっている。

この管理された灌漑がなければ、ケダの平野は年1作しかできない。この呼び名を
生み出しているのは、土地そのものというよりも、この制度的な仕組みなのであ
る。

## Kulim Hi-Tech Park：水田の隣の工場

1996年、クリム県で一つの工業団地が正式に稼働を開始した。[ペナン](/states/penang)
州境から車で約1時間の場所である。

Kulim Hi-Tech Park（KHTP）公式サイトは、これをマレーシア初の完全統合型ハ
イテクパークと説明しており、スローガンは*Leading Global Science City*で
ある。

その数値と構成：

- **面積：** 4,736エーカー
- **ゾーン：** 6つ——工業、都市、研究・研修、機関、施設、住宅
- **所有者・運営者：** Kulim Technology Park Corporation Sdn Bhd（KTPC）、
  ケダ州開発公社（Perbadanan Kemajuan Negeri Kedah）の完全子会社
- **位置：** 北部経済回廊（Koridor Ekonomi Utara）内
- **重点分野：** ハイテク製造業、研究開発（R&D）、技術教育活動

公式サイトに記録されている最新フェーズは、2023年に完成した工業ゾーンの
フェーズ4Aである。

その効果は投資データにも表れている。MIDAの報告によれば、ケダは2024年に
**RM458億**の承認投資を集め、セランゴール（RM1,011億）、クアラルンプール
連邦直轄区（RM915億）、ジョホール（RM485億）に次ぐ全国第4位であり、ペナン
（RM320億）を上回った。

全国の米の約3分の1を担う州にしては、めったに予想されない順位である。マレ
ーシア全体の[製造業](/economy/manufacturing)の概観もあわせて参照された
い。

## 古ケダと[ブジャン渓谷](/malaysia/bujang-valley)

Merbok県、ジュライ山のふもとには、いかなる工場や水田よりもはるかに古い歴
史の層が眠っている。

マレーシア国立公文書館（Arkib Negara Malaysia）は、ブジャン渓谷で**50の
チャンディ**が発見されたと記録しており、これらは**西暦4世紀から12世紀**の
間に建てられたと推定されている。個別に言及されているものとして、6世紀ごろ
の建立と考えられるCandi Bukit Batu Pahatのほか、Candi Pengkalan Bujangと
Candi Pendiatがある。

ジュライ山は航海の目印として機能しており、この地域はインドと中国を行き来
する商人にとって重要な寄港地であった。

マレーシア博物館局（Jabatan Muzium Malaysia）が所管するブジャン渓谷考古学
博物館（Muzium Arkeologi Lembah Bujang）は、Merbok県のBukit Batu Pahat
上、Sungai Petaniから約23kmの場所にある。**1980年1月23日**に正式開館し、
3世紀から12世紀にかけての数千点の遺物——陶磁器、ガラス玉、その他の資料—
—を収蔵しており、ブジャン渓谷が国際貿易の中心地であったことを示している。

ケダ州政府公式ポータルによれば、ブジャン渓谷の考古学的証拠は、早くも**西暦
110年**には一つのヒンドゥー教・仏教王国が古代ケダを統治していたことを示し
ている。

これにより、ケダはこの地域で最も早期の文明の遺跡の一つとなっている——半島
の初期史における[ランカスカ](/malaysia/langkasuka)の位置づけに匹敵するも
のである。

## 王室制度と州都

ケダの州元首はケダ州スルタンである。ケダ州政府公式ポータルによれば、現州
元首は第**29**代ケダ州スルタンである**Kebawah Duli Yang Maha Mulia
Al-Aminul Karim Sultan Sallehuddin Ibni Almarhum Sultan Badlishah**であ
り、**2017年9月12日**に即位が宣言された。正式な王宮はアロースターのアナ・
ブキット宮殿（Istana Anak Bukit）である。

同ポータルは、ケダ・スルタン国が**1136年**に始まったと記録している。この
年、Raja Phra Ong Mahawangsaがイスラームに改宗し、Sultan Mudzafar Shahの
称号を名乗った。その後この州は[シュリーヴィジャヤ](/malaysia/srivijaya)、
シャム、そしてイギリスの影響下にある時期を経て、1948年にマラヤ連邦に加わ
った。

アロースター自体は、Sultan Muhammad Jiwa Sultan Zainal Adilin Mu'adzam
Shah IIによって**1735年**に建設された。州の地方自治体ポータルによれば、マ
レーシアで最も古い州都である。**2003年11月28日**にマレーシア**第9の市**
として宣言された。

## 十二の県、ひとつではない顔

ケダは12の行政県に分かれている。州の地方自治体を見ると、各地域の性格がい
かに異なるかが分かる。

| 種類 | 地方自治体 |
| --- | --- |
| 市（バンダラヤ） | Majlis Bandaraya Alor Setar |
| 自治都市（ペルバンダラン） | Sungai Petani、Kulim、Kubang Pasu、Langkawi（Bandaraya Pelancongan） |
| 県（ダエラ） | Baling、Pendang、Yan、Sik、Padang Terap、Bandar Baharu |
| 特別機関 | PBT Taman Perindustrian Hi-Tech Kulim |

三つの異なるブロックに注目してほしい——北部の行政と水田地帯（アロースタ
ー、Kubang Pasu、Pendang、Yan）、南部の工業地帯（Sungai Petani、Kulim、
Bandar Baharu）、そして西部の島嶼観光地帯（ランカウイ）である。

ランカウイは特別な事例である。UNESCOはランカウイをランカウイ・ユネスコ世
界ジオパークとして登録しており、この群島99島、面積92,000ヘクタールに及
び、5億5,000万年以上前のカンブリア紀の岩石構造を有する。マレーシア初の
ユネスコ・ジオパークである。

## 人口構成

DOSMによる2025年推計では、ケダの人口は**222.8万人**とされ、内訳は以下の
とおりである（単位：千人）：

| グループ | 人数 |
| --- | --- |
| ブミプトラ・マレー系 | 1,711.3 |
| 華人系 | 246.7 |
| インド系 | 128.4 |
| その他ブミプトラ | 4.9 |
| その他国籍 | 25.9 |

これらの数値はDOSMによる現行の推計値であり、国勢調査の実数ではない。2020
年マレーシア国勢調査の数値はこれより低く、DOSMが別途公表している。正確な
数値については公式の国勢調査資料を参照されたい。

## よくある誤り

**「ケダは農業州だから、経済は小さく遅れている。」**
農業は2024年に州GDPの10.6%を占めるにすぎない。製造業はその約3倍を占めて
おり、同年、この州はマレーシアで4番目に高い承認投資額を集めている。

**「Kulim Hi-Tech Parkはペナンの一部である。」**
KHTPはケダ州クリム県に位置し、ケダ州開発公社の完全子会社によって所有され
ている。ペナンの電子産業クラスターに隣接してはいるが、事業としても行政と
してもケダのものである。

**「ランカウイは独立した州である。」**
ランカウイはケダ州の12県の一つである。

**「ブジャン渓谷は一つのチャンディ遺跡である。」**
国立公文書館は、この地域全体で50のチャンディ遺跡を記録しており、単一の建
造物ではない。

**「マレーシアのパディはすべてケダ産である。」**
DOSMの2022年データによれば、約36.6%にとどまる。クランタン、ペラ、パーリ
ス、セランゴール、サラワクも無視できない量を産出している。

- DOSMが公開している農作物データセットは、依然として2022年参照年までしか
  更新されていない——ケダの直近年のパディ生産量は、DOSMがこのカタログを更
  新した時点で改めて確認する必要がある。
- 州別GDPのプレスリリースはDOSMによって毎年半ばに発表されており、2025年
  の数値は製造業の6.6%という成長の勢いが持続するかどうかを示すことにな
  る。

  よびランカウイを含む[観光業](/economy/tourism)を参照されたい。
- 本稿は、州の政治的在任者をあえて実名で挙げていない。現職者の一覧につい
  ては、ケダ州政府公式ポータルを参照されたい。
