マレーシアの九つの州には統治者（Raja）がいる。マラッカはその一つではない——その
名前が、この地域の歴史上もっとも著名なマレー・スルタン国と結びついているにも
かかわらず。

これこそが、この州についてもっとも誤解されやすい逆説である。「マラッカ」とい
う名前は宮廷のイメージを呼び起こすが、現代のマラッカ州を率いるのは、限られた
任期のために**任命された州元首（Yang di-Pertua Negeri）**であり、王位を世襲す
る統治者ではない。

## 基本情報

| | |
| --- | --- |
| 州都 | マラッカ市（Bandaraya Melaka） |
| 元首 | 州元首（Yang di-Pertua Negeri）（任命制、世襲ではない） |
| 州のイスラム教首長 | 国王（Yang di-Pertuan Agong）、連邦憲法第3(3)条のもとで |
| 人口 | 105.25万人（2025年推計、DOSM） |
| 面積 | 1,712平方キロメートル（JUPEM、My Local Stats経由） |
| 行政県 | 3——マラッカ・トゥンガ（Melaka Tengah）、アロール・ガジャ（Alor Gajah）、ジャシン（Jasin） |
| GDP（2025年、2015年基準価格） | RM503億、3.0%成長 |
| UNESCO世界遺産 | 2008年登録、基準(ii)(iii)(iv) |

## なぜ称号が州元首（Yang di-Pertua Negeri）なのか

連邦憲法第160(2)条はこの用語を簡潔に定義している：州元首（Yang di-Pertua
Negeri）とは、**統治者を持たない**州の州の長を意味する。

この区分に該当する州は四つある——マラッカ、[ペナン](/states/penang)、サバ、
サラワクである。その基本規定は[連邦憲法](/law/federal-constitution)の
Eighth Scheduleのs.19Aからs.19Dにある。

| 規定 | 内容 |
| --- | --- |
| s.19A(1) | 国王（Yang di-Pertuan Agong）が自らの裁量により、ただし首席大臣（Ketua Menteri）と協議したうえで任命する |
| s.19A(2) | 任期は**4年**；いつでも辞任できる；州議会（Dewan Undangan Negeri、DUN）の動議が全議員の3分の2の支持を得た場合、国王により罷免され得る |
| s.19B(1) | 市民でない者、または帰化もしくは登録により市民となった者は任命され得ない |
| s.19B(2) | 有給の職に就くことはできず、いかなる商業事業にも積極的に関与してはならない |
| s.19C | 州法律は、統合基金（Kumpulan Wang Disatukan）に賦課されるシビル・リスト（Civil List）を定めなければならず、任期中は減額してはならない |

Eighth Scheduleのs.22は、その代替の仕組みを説明している：同附表のPart I
およびPart IIがマラッカとペナンに適用される場合、州元首（Yang di-Pertua
Negeri）への言及が統治者（Raja）への言及に**取って代わる**。

州政府公式ポータルによれば、任命は国王が首席大臣（Ketua Menteri）と協議した
うえで行い、同ポータルはTun Seri Setia Dr. Haji Mohd Ali bin Mohd Rustamを
第7代マラッカ州元首として挙げており、2020年より在任している。現在の状況に
ついては同ポータルを確認のこと。

## あまり語られない影響

この称号の違いは、三つの具体的な憲法上の帰結をもたらす。

**イスラム教首長が異なる。** 連邦憲法第3(3)条は、マラッカ、ペナン、サバ、
サラワクの州憲法がそれぞれ、当該州におけるイスラム教首長の地位を国王
（Yang di-Pertuan Agong）に与える旨を定めなければならないと規定している。
統治者を持つ州では、この地位は当該州の統治者が保持する。

**統治者会議（Majlis Raja-Raja）の構成員資格は完全ではない。** Fifth
Scheduleのs.1は、各州元首（Yang di-Pertua Negeri）を統治者会議の構成員に
含めている。しかしs.7は、国王の選出もしくは罷免、副国王（Timbalan Yang
di-Pertuan Agong）の選出、並びに専ら統治者の特権、地位、栄誉及び威厳、また
は宗教上の行為及び儀式にのみ関わる事項に関する手続から、彼らを除外している。

**この職には任期がある。** 4年、更新可能——これは終身続く王位とは対照的で
ある。これはまた、マラッカを[ヌグリ・スンビラン](/states/negeri-sembilan)
のモデルとも区別する。同州では州元首がウンダン・ヤン・ウンパット（Undang
Yang Empat）によって推選されるが、それでもなお慣習上の統治者である。

## 一つの都市に折り重なる四層の権力

州政府公式ポータルは、次の順序を記録している。

| 期間 | 出来事 |
| --- | --- |
| 1511年まで | [マラッカ王国](/malaysia/melaka-sultanate) |
| 1511–1641年 | ポルトガル統治；アフォンソ・デ・アルブケルケが1511年8月10日に到着、8月24日に城が陥落——130年間の統治 |
| 1641–1795年 | オランダ統治、オランダ–ジョホール連合軍によるポルトガルの敗北の後——154年間；スタダイス（Stadthuys）が1650年に、セント・ピーターズ教会（St. Peter's Church）が1710年に建設された |
| 1795–1957年 | 英国統治；1824年英蘭協約と1826年海峡植民地（Straits Settlements）の設立 |
| 1942–1945年 | 日本占領 |
| 1956年 | 2月20日、パダン・バンダ・ヒリル（Padang Banda Hilir）で独立が宣言された |

このパダン・バンダ・ヒリルこそが、マラッカを[1957年の独立](/malaysia/independence-1957)
の物語における象徴的な場所たらしめている。

マラッカは1989年4月15日に歴史都市（Bandaraya Bersejarah）に指定された。マ
ラッカ歴史都市地方議会（Majlis Perbandaran Melaka Bandaraya Bersejarah）は
その後、2003年4月15日にマラッカ歴史都市議会（Majlis Bandaraya Melaka
Bersejarah、MBMB）へと格上げされ、現在の行政区域は270.39平方キロメートルに
及ぶ。

## UNESCOが実際に認定したもの

この登録はマラッカ単独のものではない。この一連の資産は**「Melaka and
George Town, Historic Cities of the Straits of Malacca」**という名称で、
2008年に基準(ii)、(iii)、(iv)のもとで登録され、2011年には境界の小幅な変更
が登録されている。

二つの都市の間での役割分担は、UNESCOの説明の中に直接示されている——その政
庁建築、教会、広場、要塞をもって、**マラッカはこの歴史の初期段階を代表する**
——すなわち15世紀のマレー・スルタン国、そして16世紀初頭に始まるポルトガル
とオランダの時代である。**ジョージタウンは18世紀末に始まる英国時代を代表す
る**。

したがって、この登録の中でもっとも目立つ英国の層は、マラッカではなくペナン
にある。この機微は、一般向けの概説ではしばしば見落とされる。

基準(iv)は、その一部がオランダ時代またはポルトガル時代に由来する、卓越し
た店屋とタウンハウスの連なりを特に挙げている。この一連の資産全体は154.68
ヘクタールに及び、緩衝地帯は392.8ヘクタールである。

## 経済：観光だけではない

ここで公式データは一般的な思い込みと食い違う。マラッカは確かに観光州である
——しかし製造業がその経済の3分の1以上を占めている。

| 産業 | 2025年GDP（RM百万） | 構成比 |
| --- | --- | --- |
| サービス業 | 26,369.9 | 52.4% |
| 製造業 | 17,777.4 | 35.4% |
| 農業 | 4,686.2 | 9.3% |
| 建設業 | 1,258.8 | 2.5% |
| 鉱業・採石業 | 72.1 | 0.1% |
| **購入者価格によるGDP** | **50,286.0** | **100%** |

2015年基準価格。2025年の全体成長率は3.0%で、2024年の4.2%に続くものである。

観光はそれでもデータの中に独自の痕跡を残している。Domestic Tourism Survey
(States) 2024において、DOSMはマラッカが、国内宿泊旅行の主目的が休暇・休息
・レクリエーションである**唯一の州**であることを明らかにした——他のすべて
の州では、主目的は親族・友人訪問である。

人口はマラッカ・トゥンガに集中している：2025年の105.25万人のうち63.33万人
がここに住み、アロール・ガジャの26.18万人、ジャシンの15.73万人と対照的であ
る。しかし面積で見ると、マラッカ・トゥンガは最小（359平方キロメートル）で
あり、ジャシン（679）やアロール・ガジャ（674）より小さい。

## よくある誤り

**「マラッカには今もスルタンがいる。」** 誤りである。州の元首は州元首
（Yang di-Pertua Negeri）であり、国王（Yang di-Pertuan Agong）によって任
期4年で任命される。マラッカ王国は、1511年にマラッカにおける統治権力として
は終焉を迎えた歴史的な存在である。

**「州元首（Yang di-Pertua Negeri）は統治者（Raja）と同じで、称号が違うだ
けだ。」** 同じではない。この職には任期があり、世襲ではなく、州のイスラム
教首長の地位を持たず、国王の選出にも参加しない。

**「マラッカ市全体がUNESCO遺産である。」** この登録が対象とするのは、ジョ
ージタウンと共有する一連の資産の中で特定の境界を持つコア・ゾーンとバッフ
ァー・ゾーンであり——270.39平方キロメートルに及ぶ市の行政区域全体ではない。

**「マラッカの経済は観光客に完全に依存している。」** 州のGDPデータは、製
造業が約35%を占め、サービス業には観光以外の多くの活動が含まれていることを
示している。

## 範囲についての注記

本稿は、憲法上の構造、歴史、そして公式データのみを説明するものである。いか
なる政治的評価も行わず、現在進行中のいかなる解釈上の論争にも触れない。本稿
は草稿であり、まだ人間による審査を経ていない。
