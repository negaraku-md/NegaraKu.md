有一个问题，几乎每个马来西亚人都曾答错过：谁是玻璃市苏丹？

答案是——没有这个人。玻璃市没有苏丹。它是马来西亚唯一一个州元首称号为
**拉惹（Raja）**的州属，而这个称号并非单纯的用词选择，而是源自这个州属于
1843年建州的方式。

## 基本资料

| | |
| --- | --- |
| 首府 | 加央 |
| 面积 | 约821平方公里——马来西亚最小的州属 |
| 人口 | 约30万人（DOSM 2025年估计） |
| 人口密度 | 每平方公里365人（2025年），高于全国平均104人 |
| 州元首 | 玻璃市拉惹陛下 |
| 州GDP | RM6.5 billion（2024年），增长3.3% |
| 议席 | 国会3席，州立法议会15席 |

## 为何是拉惹而非苏丹

端姑玻璃市拉惹办公室（Pejabat DYMM Tuanku Raja Perlis）的官方记录直接说明了
这一点：1843年，Raja Syed Hussein Jamalullail 在暹罗语中被正式册封为
**Phya Polit**，马来语则称为**拉惹玻璃市（Raja Perlis）**。暹罗国王拉玛三世
（Raja Rama III）所颁赐的全衔为 Phya Songkram Ramu Wichit Wilis Asmara Phya
Polit。

这个马来语称号——拉惹（Raja）——从那天起一直沿用至今。

自那次册封以来，玻璃市一直由同一个家族统治，即 Wangsa Jamalullail
（查马鲁莱王朝），历经七位拉惹：

| 拉惹 | 在位期间 |
| --- | --- |
| Raja Syed Hussein Jamalullail | 1843–1873 |
| Raja Syed Ahmad Jamalullail | 1873–1897 |
| Raja Syed Safi Jamalullail | 1897–1904 |
| Syed Alwi Jamalullail | 1905–1943 |
| Raja Syed Hamzah Jamalullail | 1943–1945 |
| DYMM Tuanku Syed Putra Jamalullail | 1945–2000 |
| DYMM Tuanku Syed Sirajuddin Jamalullail | 2000–至今 |

现任玻璃市拉惹 Duli Yang Maha Mulia Tuanku Syed Sirajuddin ibni Almarhum
Tuanku Syed Putra Jamalullail，于2000年4月17日册封为第七任玻璃市拉惹。

## 称号不同，联邦地位相同

多数简略的说法在此就出错了。称号不同，并不代表在联邦体制中的地位也不同。

[马来西亚统治者会议](/zh/government/majlis-raja-raja)（Majlis Raja-Raja
Malaysia）指出，所有拉惹与州元首（Yang di-Pertua Negeri）都自动成为会议成员，
而统治者会议会议的主席一职，由九位马来统治者轮流担任。玻璃市拉惹正是这九位
统治者之一。

马来西亚国会的官方名单清楚记录了这一点：曾有两位玻璃市拉惹出任
[最高元首](/zh/government/yang-di-pertuan-agong)（Yang di-Pertuan Agong）：

- **Tuanku Syed Putra**——第三任最高元首，1960年9月21日至1965年9月20日
- **Tuanku Syed Sirajuddin**——第十二任最高元首，2001年12月13日至2006年12月12日

父子两代，两个任期，都来自联邦中面积最小的州属。

## 面积虽小，人口稠密，人口结构特殊

以约821平方公里的面积计算，玻璃市可以整个塞进其他州属许多面积较大的县份之中。
国家安全理事会（MKN）列出其六个主要行政区：首府加央，其余依次为Arau、Kaki
Bukit、Kuala Perlis、Padang Besar与Simpang Empat。

但面积小不代表人烟稀少。统计局（DOSM）记录显示，玻璃市2025年的人口密度为每
平方公里365人——超过全国平均104人的三倍。

还有一个鲜少被提及的细节：2025年，玻璃市的性别比例为每100名女性对99名男性。
全马来西亚只有两个地区的女性人数多于男性——玻璃市与联邦直辖区布城。全国的
性别比例为110。

玻璃市2025年的人口增长率为0.3%，低于全国0.5%的增长率。

## RM6.5 billion 的经济体

根据统计局（DOSM）发布的《2024年各州GDP》报告，玻璃市经济在2024年增长3.3%
（2023年：2.0%），GDP值为RM6.5 billion（2023年：RM6.3 billion）。

细项分类透露了这个州属的许多特点：

- **服务业**是该州经济的龙头，增长3.3%，由政府服务分领域，以及批发零售贸易、
  餐饮与住宿分领域带动。
- **农业**是第二大贡献领域——这在半岛州属中相当罕见——增长2.9%，占州GDP的
  17.1%。渔业分领域猛增10.5%。
- **建筑业**增强16.9%（2023年：1.4%），主要由土木工程分领域的显著增长带动。

必须坦白说明：2024年，只有五个州属的人均GDP超过全国RM56,734的水平，即联邦
直辖区吉隆坡、联邦直辖区纳闽、槟城、砂拉越与雪兰莪。玻璃市并不在这份名单之
内。可将这种经济结构，与槟城这类以制造业为主的州属做比较，参见
[槟城](/zh/states/penang)，或参阅[马来西亚GDP](/zh/economy/gdp-overview)概览。

## 泰国边境：从地理劣势变成优势

玻璃市是马来西亚唯一一个整条北部边界都与泰国接壤的州属，其发展策略如今正
建立在这个事实之上。

**Chuping Valley Industrial Area（CVIA）**——位于边境市镇Padang Besar附近
Chuping谷的一处工业区，占地2,482英亩，由北部走廊管理机构（Northern
Corridor Implementation Authority，NCIA）依NCER框架开发。其四大重点产业群
为绿色制造业、清真产业、可再生能源发电与电动车。NCIA预计将为国民总收入
（Gross National Income）贡献超过RM2.5 billion，带来RM4.5 billion的私人
投资，并创造超过12,000个就业机会。

**Perlis Inland Port（PIP）**——CVIA范围内、位于Padang Besar的内陆港项目。
根据国家安全理事会（MKN），政府为外部基础设施建设拨款RM318.0 million，另有
RM1.2 billion私人投资用于营运区域的开发。

在人员往来方面，边境由移民、关税、检疫与安全综合关卡（Immigration,
Customs, Quarantine and Security，ICQS）管理，包括ICQS Wang Kelian与Padang
Besar入境关口。文件要求与开放时间由[马来西亚移民局](/zh/government/imigresen)
（Jabatan Imigresen Malaysia）订定，且可能随时变动。

## 常见错误

**「玻璃市苏丹」。** 并无此职位。其正式称号是玻璃市拉惹陛下。九位马来统治者
当中，七位称号为苏丹，一位称号为最高元首（Yang di-Pertuan Besar，森美兰），
一位称号为拉惹（玻璃市）。

**以为拉惹的称号意味着地位较低。** 并非如此。玻璃市拉惹是统治者会议的正式
成员，也符合资格被选为最高元首——而且确实曾经当选。

**以为玻璃市只是个农业州。** 州GDP的最大贡献领域是服务业，而非农业。农业排
在第二位。

**把玻璃市的Padang Besar与Bukit Kayu Hitam混为一谈。** Bukit Kayu Hitam位于
吉打。玻璃市主要的陆路关口是Padang Besar与Wang Kelian。

**混淆议席数目。** 玻璃市有三个国会议席（P001 Padang Besar、P002 加央、
P003 Arau）与15个州立法议会议席——是马来西亚州议会议席数最少的州属。

## 下一步

如果你正在评估是否到玻璃市投资，先从NCIA与州政府当局着手：CVIA与Perlis
Inland Port的地理位置，将决定这个边境地点是否适合你的供应链。

如果你正在研究马来西亚的皇室制度，玻璃市是最有用的一个案例——因为它说明了
称号与宪制权力，是两回事。

而如果你只是想了解这个地区，半岛北部的历史其实远早于1843年就已经开始。参见
[狼牙修](/zh/malaysia/langkasuka)——一个历史记录早于任何马来苏丹国的早期
王国。
