雪兰莪是马来西亚经济默默运转所依靠的那个州属。它完全环绕着联邦首都吉隆坡与行政首都布城，三者共同构成巴生谷——全国最大的城市与工业连绵区。

## 重点资料

| | |
| --- | --- |
| 首府 | 莎阿南 |
| 王城 | 巴生 |
| 人口 | 约 700 万 |
| 元首 | 雪兰莪苏丹 |
| 主要产业 | 制造业、物流与贸易、科技、金融 |

## 地理

雪兰莪位于马来半岛西海岸，面向马六甲海峡，围着吉隆坡与布城两个联邦直辖区形成一个马蹄形。它的海岸线上有全国最繁忙的巴生港，而内陆县属则从八打灵再也、莎阿南这类密集的城市中心，一路延伸到远离巴生谷核心的农业与森林地带。该州北接霹雳，东接彭亨，南接森美兰。

## 经济

雪兰莪以产出计是马来西亚最大的州属经济体，其工业基础也是全国最多元的。围绕莎阿南、巴生与八打灵再也的制造业集群涵盖电子、汽车零件、消费品与制药。巴生港处理马来西亚大部分的货柜贸易，而同样位于雪兰莪雪邦县内的吉隆坡国际机场（KLIA）与 KLIA2，则撑起该州在航空与空运中的角色。作为多媒体超级走廊一部分而开发的赛城，已成长为科技与共享服务枢纽，而八打灵再也与梳邦再也则容纳了密集的企业区域办事处。服务业、批发与零售贸易以及金融活动，构成了这个经济体的其余部分——它长期在各州之中占马来西亚 GDP 最大的单一份额。

## 在这里做生意

雪兰莪对企业的吸引力，建立在规模与连通性之上：它提供吉隆坡本身以外最大的消费市场、直接接入全国主要港口与机场的通道，以及成本低于首都的工业用地。巴生、莎阿南与万宜一带的自由工业区与保税制造仓库，支撑着进出口导向的业务。赛城的 MSC 地位为合资格的科技与服务公司提供特定的税务与监管奖掖，而雪兰莪的州属投资机构则与 MIDA 等联邦机构并肩处理奖掖申请。人才供给受惠于邻近吉隆坡的劳动市场，以及散布巴生谷各处的大学。主要的取舍是拥堵——雪兰莪的道路网络承载着全国最繁重的车流之一，因此围绕巴生港与 KLIA 的物流规划必须把高峰时段的延误算进去。

## 值得一看的地方

位于鹅唛的印度教圣地与石灰岩洞群黑风洞，是马来西亚访客最多的宗教与旅游景点之一。莎阿南是苏丹沙拉胡丁阿都阿兹清真寺的所在地，那是东南亚最大的清真寺之一，本地称之为蓝色清真寺。八打灵再也的双威城把主题公园、购物商场、大学与医疗中心结合在一个综合市镇之内。该州的王城巴生在现代港口业务之外保留了一片历史核心区，并以其小印度聚落与街头美食闻名。再往北，瓜拉雪兰莪以河畔萤火虫群落与自然保护区闻名，与该州的工业腹地形成对照。
