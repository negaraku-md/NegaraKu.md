パハンは半島マレーシアの国土の4分の1以上を占めるが、そこに暮らすマレーシア人はわずか20人に1人にすぎない。

この一つの事実が、この州についてのほぼすべてを説明している。なぜ森林が今なお広大なのか、なぜ経済が工場ではなく土地に支えられているのか、そしてなぜタマンヌガラ（Taman Negara）が[セランゴール](/states/selangor)や[ペナン](/states/penang)では存続しえない形で存在できるのかを。

## 広い国土、少ない人口

パハンは北をクランタン、西をペラ、セランゴール、ヌグリ・スンビランと接し、南はジョホール、東はトレンガヌと南シナ海に面している。他の6州と国境を接しており——これは半島の他のどの州よりも多い。

人口の推移は緩やかである。DOSMは2025年の人口を1,678,200人と推計しており、2024年の1,667,700人から増加した。年間0.6%という成長率は、全国の0.5%を実際には上回っているが、母数が小さい——パハンはマレーシアの人口3,420万人のうち、わずか4.9%を占めるにすぎない。

人口を土地面積で割ると、現れる数字がすべてを物語っている。

| 地域 | 人口密度（人/平方キロメートル、2025年） |
| --- | --- |
| クアラルンプール連邦直轄区 | 8,546 |
| ペナン | 1,749 |
| マレーシア平均 | 104 |
| トレンガヌ | 96 |
| サバ | 51 |
| **パハン** | **46** |
| サラワク | 20 |

出典：DOSM、Anggaran Penduduk Semasa Malaysia 2025。

人口密度がパハンより低いのはサラワクのみである。DOSMは2025年についてさらに二つの人口統計上の特徴を記録している。パハンの性比は女性100人に対し男性114人——全国でも最も高い水準の一つである——そしてパハンは、65歳以上の人口が7.1%に達し、新たに高齢化州の地位に達した3州の一つとなった。

## 十一県、二つの中心

パハンは11の行政県に分かれている：**ペカン、クアンタン、ロンピン、マラン、ベラ、ジェランツ、テメルロ、ラウブ、ベントン、リピス**、そして**[キャメロンハイランド](/tourism/cameron-highlands-visitor-guide)**。

この州は、機能の異なる二つの中心によって運営されている。**クアンタン**は行政州都であり、州秘書室（Pejabat Setiausaha Kerajaan Negeri）が置かれるウィスマ・スリ・パハン（Wisma Sri Pahang）の所在地である。**ペカン**は王室の町である。

地形も階層をなしている。東海岸には、南シナ海に面した約208キロメートルの沿岸地帯が広がる。内陸にはパハン川（Sungai Pahang）の流域が広がる。そして西部には高原地帯——キャメロンハイランド、ゲンティンハイランド、フレイザーズヒル——があり、これによりパハンは半島の三大高原リゾートをすべて擁する唯一の州となっている。

## 経済：最も土地に依存する州

パハンのGDPは**2025年にRM710億**（2015年基準価格）に達し、2024年のRM688億から増加した——約3.2%の成長であり、前年のより速い約5.8%の伸びに続くものである。

部門別の内訳こそが、パハンを他州と区別する点である。

| 部門 | 2025年の値 | 州GDPに占める割合 |
| --- | --- | --- |
| サービス業 | RM373億 | 52.6% |
| 農業 | RM159億 | 22.4% |
| 製造業 | RM147億 | 20.8% |
| 建設業 | RM23億 | 3.3% |
| 鉱業・採石業 | RM6億 | 0.8% |

数値はDOSMのデータカタログによるものであり、比率はこれらの数値から算出した。

この農業比率22.4%は、DOSMの2025年の数値に基づくと、マレーシアの全州の中で最も高い——クランタン（約19.8%）やパーリス（約16.5%）を上回っている。比較すると、セランゴールでは農業の占める割合はわずか約1.1%にすぎない。

その大部分を説明するのが油ヤシである。2025年12月時点で、MPOBはパハンの油ヤシ植栽面積を**745,445ヘクタール**と記録している——マレーシア全体の13.1%を占め、半島で最大の面積であり、[ジョホール](/states/johor)（675,558ヘクタール）を上回る。半島マレーシアの油ヤシ植栽面積のほぼ30%がパハンにある。この部門の背景は[パーム油産業](/economy/palm-oil-sector)で説明されている。

小さい部分にも注目したい。鉱業・採石業は州GDPの1%未満にとどまっているが、パハンの歴史はしばしば錫鉱や金鉱と結び付けられてきた。

## タマンヌガラ：ヒマラヤ山脈より古い森

タマンヌガラ（Taman Negara）は**面積4,343平方キロメートル**で、パハン、クランタン、トレンガヌの三州の境界にまたがっている。規模の目安として、この面積はパハンの面積の約12%に相当するが、公園はこの州内に完全に位置しているわけではない。

Tourism Pahangの公式ポータルは、これを世界最古の熱帯雨林の一つとし、樹齢約1億3,000万年、植物種約14,000種、鳥類300種以上、淡水魚250種、哺乳類200種を擁すると説明している。

園内には標高**2,187メートルのタハン山（Gunung Tahan）**があり、半島マレーシアの最高峰である。PERHILITAN（野生生物・国立公園局）は7日6泊の登山ルートを2つ挙げている——クアラ・タハンから登り、再びクアラ・タハンへ下るルートと、クアラ・タハンから下ってメラポー（Merapoh）のクアラ・ジュラム（Kuala Juram）に至るルートである——そして各グループにはガイドの同行を義務づけている。

| 項目 | 詳細 |
| --- | --- |
| 主要な入口 | クアラ・タハン、ジェランツ県 |
| ジェランツの町からの距離 | 約68キロメートル |
| 公園管理機関 | PERHILITAN（野生生物・国立公園局） |
| 名物 | 地上約45メートルに架かるキャノピーウォーク |

タマンヌガラの重要性は観光にとどまらない。それは半島において独立以前から継続して保護されてきた唯一の大規模な低地熱帯雨林ブロックであり、三州にまたがって流れる河川系の集水域としても機能している。観光業が国の経済に与える貢献については、[観光業](/economy/tourism)の記事で論じられている。

## 王室制度とペカン

パハンの州元首は**パハン・スルタン（Sultan Pahang）**と称される。パハン王宮（Istana Pahang）の公式サイトは、陛下の正式な称号を*Kebawah Duli Paduka Baginda Sultan Pahang Al-Sultan Abdullah Ri'ayatuddin Al-Mustafa Billah Shah ibni Al-Marhum Sultan Haji Ahmad Shah*と記載している。

同サイトによれば、陛下は1959年7月30日に生まれ、1975年7月1日にパハン王太子（Tengku Mahkota Pahang）に任命され、1979年4月28日に摂政（Pemangku Raja）となった。

マレーシア国会（Parlimen Malaysia）の公式名簿によれば、陛下は2019年1月31日から2024年1月30日まで**第16代国王（Yang di-Pertuan Agong）**を務め、統治者会議（Majlis Raja-Raja）の輪番においてパハンを代表した。この職は2024年1月31日以降、ジョホールのスルタン・イブラヒム・イブニ・アルマルフム・スルタン・イスカンダル（Sultan Ibrahim ibni Almarhum Sultan Iskandar）が務めている。

州の王室の町は**ペカン**であり、パハンの王室制度の中心であるとともに、クアンタンが州都となる以前の旧行政中心地でもある。

州元首としてのスルタンの地位、そして州と連邦との関係は、[連邦憲法](/law/federal-constitution)と各州独自の州憲法によって枠づけられている。この構造は州によって異なる——[ヌグリ・スンビラン](/states/negeri-sembilan)と比較されたい。同州の州元首は選挙によって選ばれ、最高元首（Yang di-Pertuan Besar）と称される。

この節は記述的な内容にとどまり、いかなる評価も行うものではない。

## よくある誤り

**「パハンはマレーシアで最大の州である。」** それは*半島*で最大の州である。サラワクとサバはいずれもより広い。

**「クアンタンは王室の町である。」** クアンタンは行政州都である。王室の町はペカンである。

**「タマンヌガラはパハン州立公園である。」** それはパハン、クランタン、トレンガヌにまたがっており、半島マレーシアについては連邦レベルでPERHILITAN（野生生物・国立公園局）が管理している。

**「人口が希薄であれば経済も小さいはずだ。」** 2025年のパハンのGDP、RM710億は、より人口の多いいくつかの州を上回っている。土地単位あたりの経済規模は確かに低いが、生産の総量は小さくない。

**「キャメロンハイランドは県ではなく町である。」** キャメロンハイランドはパハンの11の行政県の一つである。

## 数字についての注記

2025年の人口数値はDOSMの初期推計であり、完全な国勢調査ではないため、通常は後に修正される。GDPの数値は年ごとの比較を意味あるものにするため2015年基準価格で示されており、当年価格での数値は異なる。上表の部門別割合は、DOSMの実数値をもとに編集者が算出したものである。

本稿は草稿の状態であり、まだ人による審査を経ていない。
