槟城的分量远超它的体型。它是马来西亚面积最小的州属之一，却也是全国最重要的制造业经济体之一，以及游客最多的旅游目的地之一。

## 重点资料

| | |
| --- | --- |
| 首府 | 乔治市 |
| 人口 | 约 170 万 |
| 元首 | 州元首（Yang di-Pertua Negeri） |
| 主要产业 | 电子与半导体制造、旅游、港口与物流 |

## 地理

槟城由两部分组成：槟岛，乔治市与大部分旅游经济所在之处；以及大陆上的威省，两者由槟威大桥、第二槟威大桥与渡轮服务相连。该州位于马来半岛西北海岸，面向马六甲海峡，北面与东面与吉打接壤。它位处世界上最繁忙的航道之一，自 1786 年英国东印度公司在乔治市设立贸易站以来，这个位置就一直形塑着它的经济。

## 经济

槟城常被形容为「东方硅谷」。1970 年代设立的 Bayan Lepas 自由工业区，容纳了 Intel、AMD、Bosch 与 Dell 等全球半导体与电子公司的封装、测试以及日益增加的设计业务，此外还有一个由本地供应链公司组成的密集生态系统。电气与电子产品占该州出口的大宗，而在巴生谷以外的州属中，槟城的人均 GDP 长期名列前茅。旅游业是经济的第二根支柱，以乔治市的文化遗产地位、它的饮食文化，以及岛屿北岸的海滩度假区为支撑。以槟城港为中心的港口与物流活动，则同时支撑制造业与贸易领域。

## 在这里做生意

槟城对制造商的主要吸引力，是五十年电子投资所累积起来的成熟熟练工程人才队伍，加上一条由零件制造商、测试商与物流供应商组成的既有供应链。州属投资推广机构 InvestPenang 与 MIDA 等联邦机构并肩支援新的制造项目，而 Bayan Lepas 的自由工业区地位，让合资格的出口导向制造商在原料上享有关税豁免。工业用地与熟练劳工在岛上本身较为紧张，把较新的投资推向威省与邻近吉打的居林高科技园。制造业之外，乔治市的文化遗产地位带来保育规则，历史核心区的商家必须在其中运作，而这里同时也有一个服务游客与居民的强劲酒店与餐饮业。

## 值得一看的地方

乔治市列入 UNESCO 名录的核心区，混合了英国殖民建筑、华人姓氏桥与峇峇娘惹店屋，以街头艺术景观和马来西亚最受推崇的饮食文化之一闻名。升旗山有缆索列车通往城市上方较凉爽的高处，而极乐寺则是东南亚最大的佛教寺庙建筑群之一。峇都丁宜的海滩撑起岛上的度假旅游，而新关仔角则是知名的海滨餐饮与零售带。连接岛屿与大陆的槟威大桥与第二槟威大桥，本身也是值得一看的基建地标。
