セランゴールは、マレーシア経済が静かに依拠している州である。連邦首都クアラルンプールと行政中心地であるプトラジャヤを完全に取り囲んでおり、この三者が合わさってクランバレーを形成している——同国最大の都市・工業連担地域である。

## 基本情報

| | |
| --- | --- |
| 州都 | シャー・アラム |
| 王室の町 | クラン |
| 人口 | 約700万人 |
| 元首 | セランゴール・スルタン |
| 主要産業 | 製造業、物流・貿易、テクノロジー、金融 |

## 地理

セランゴールは半島マレーシアの西海岸に位置し、マラッカ海峡に面しており、クアラルンプールとプトラジャヤという二つの連邦直轄区を取り囲む形で馬蹄形を成している。その海岸線には同国で最も繁忙なポートクランがあり、一方その内陸部は、プタリンジャヤやシャー・アラムのような人口密集地の都市中心部から、クランバレーの核から離れた農業・森林地帯にまで広がっている。同州は北はペラ、東はパハン、南はヌグリ・スンビランと接している。

## 経済

セランゴールは産出額でマレーシア最大の州経済であり、同国で最も多様な産業基盤を有している。シャー・アラム、クラン、プタリンジャヤ一帯の製造業クラスターは、電子機器、自動車部品、消費財、製薬にまで及ぶ。ポートクランはマレーシアのコンテナ貿易の大部分を取り扱い、いずれもセランゴール州セパン県に位置するクアラルンプール国際空港（KLIA）とKLIA2は、同州の航空・空運における役割の柱となっている。マルチメディア・スーパー回廊の一部として開発されたサイバージャヤは、テクノロジーと共有サービスのハブへと成長し、一方プタリンジャヤとスバンジャヤには企業の地域オフィスが密集している。サービス業、卸売・小売貿易、そして金融活動が、この経済を締めくくっており、これは全州の中で一貫してマレーシアのGDPの最大の単一シェアを占めている。

## ここでのビジネス

セランゴールが企業を引きつける理由は、規模と接続性にある。すなわち、クアラルンプール自体を除けば国内最大の消費市場、国の主要な港と空港への直接アクセス、そして首都より低コストの工業用地である。クラン、シャー・アラム、バンギ一帯の自由工業地区と保税製造倉庫は、輸出入志向の業務を支えている。サイバージャヤのMSCステータス指定は、適格な技術・サービス企業に特定の税務および規制上の優遇措置を与え、一方セランゴール州の投資誘致機関はMIDAなどの連邦機関と協力してインセンティブの申請にあたる。人材供給は、クアラルンプールの労働市場やクランバレー全域の大学に近接していることの恩恵を受けている。主な代償は渋滞である——セランゴールの道路網は国内でも有数の交通量を抱えており、そのためポートクランとKLIA周辺の物流計画は、ピーク時の遅延を織り込む必要がある。

## 見どころ

バトゥ洞窟は、ゴンバ（Gombak）にあるヒンドゥー教寺院と石灰岩洞窟群であり、マレーシアで最も多くの人が訪れる宗教・観光地のひとつである。シャー・アラムには、東南アジア最大級のモスクのひとつであるマスジッド・スルタン・サラフディン・アブドゥル・アジズ（Masjid Sultan Salahuddin Abdul Aziz）があり、地元では「青いモスク」（Masjid Biru）として知られている。プタリンジャヤのSunway Cityは、テーマパーク、ショッピングモール、大学、医療センターをひとつの複合タウンシップの中に統合している。同州の王室の町であるクランは、近代的な港湾運営とあわせて歴史的中心部を保っており、リトルインディアの飛び地とその屋台料理で知られている。さらに北にあるクアラ・セランゴールは、川辺のホタルの群生地と自然保護区で知られ、同州の工業の中枢地帯とは対照的な景観を見せている。
