クアラルンプールはマレーシアの首都であるが、憲法上は州ではない——連邦直轄区（Wilayah Persekutuan）であり、1974年にセランゴールから分離され、州政府や民選の州議会ではなく連邦政府によって直接統治されている。

## 基本情報

| | |
| --- | --- |
| 州都 | クアラルンプール（首都そのもの） |
| 人口 | 約200万人（市域）；大クアラルンプール全体では800万人を超える |
| 元首 | 連邦直轄区——連邦政府により統治 |
| 主要産業 | 金融・銀行、企業本社機能、専門サービス、観光 |

## 地理

クアラルンプールは、完全に都市化した小さな飛び地であり、四方をセランゴール州に囲まれ、クラン川とゴンバック川の合流点近くに位置している——この合流点こそが、「泥だらけの川の合流点」を意味するこの都市の名前の由来となっている。面積は約243平方キロメートルで、本シリーズが扱う地域の中では今のところ最も小さいが、その市街地はプタリンジャヤ、スバンジャヤ、シャー・アラムといった隣接するセランゴール州の各都市とシームレスに一体化し、より広いクランバレー都市圏を形成している。政府の行政機能の大半は、1999年以降、専用に建設された連邦直轄区プトラジャヤへと移転し、クアラルンプールは商業・金融の首都としての役割に専念することとなった。

## 経済

クアラルンプールは、マレーシアの他のどの地域よりも高い一人当たりGDPを生み出しており、それはほぼ完全にサービス業によって牽引されたものであり、工業によるものではない。マレーシアの国立証券取引所であるBursa Malaysiaはこの都市に本拠を置き、それに加えてマレーシアのほぼすべての銀行、保険会社、主要な公開上場コングロマリットの本社もここにある。ゴールデン・トライアングル地区（Segi Tiga Emas、KLCC、ブキッ・ビンタン及びその周辺一帯）には、国内で最も高額なオフィススペースがあり、多国籍企業の地域本社の集積度も国内最高である。観光、小売、そして会議・インセンティブ旅行・コンベンション・展示会（MICE）産業もまた主要な貢献分野であり、クアラルンプール・コンベンションセンターと大規模なホテル基盤に支えられている。この都市の土地面積は固定されており、その大部分はすでに完全に開発され尽くしているため、成長は隣接するセランゴールへとますます溢れ出しており、これこそが、この二つの地域を一体となった一つの経済として理解するのが最も適切である理由である。

## ここでのビジネス

クアラルンプールの住所は、威信をもたらすとともに、意思決定者、専門サービス会社、資本市場への近接性ももたらす——Bursa Malaysiaへの上場や、主要な地場金融機関との銀行取引関係の構築を望む企業の多くは、KLに拠点を置くことでそれを実現している。KLCCのような高級エリアのオフィス賃料は国内で最も高く、これが多くの管理・運営の支援機能をプタリンジャヤ、サイバージャヤ、あるいはセランゴールの他の地域へと押しやる一方で、登記上または代表としてのオフィスはKL自体に維持されている。会社登記、SSMへのライセンス手続、そして大半の連邦規制機関は、この都市の内部またはその近くに本部を置いており、機関との対面での手続きを容易にしている。交通渋滞と高い不動産コストは、ここで事業を営む企業にとっての主要な摩擦点である。

## 見どころ

かつて世界最高層のビルであったペトロナス・ツインタワーは、KLCCの公園やショッピングエリアとともに、この都市を象徴する独自のランドマークであり続けている。クアラルンプール塔（Menara KL）は、都心を見下ろす丘からのパノラマの眺望を提供している。1957年にマレーシアの独立が宣言されたムルデカ広場（Dataran Merdeka）は、スルタン・アブドゥル・サマド・ビル（Bangunan Sultan Abdul Samad）をはじめとする植民地時代の建物と隣接している。プタリン・ストリート（Petaling Street）とその周辺のチャイナタウン地区、そして歴史的な川の合流点にあるマスジッド・ジャメ（Masjid Jamek）一帯は、ゴールデン・トライアングルのガラス張りの高層ビル群とは対照的な、より古く、より密集した街並みを提供している。ブキッ・ビンタンは、この都市の主要な小売と夜の娯楽エリアであり続けている。
