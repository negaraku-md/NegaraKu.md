マレーシアには13の州があるが、王位はわずか九つしかない。残る四つの州は、王位に就くことのない人物によって統治されている——その人物は任命され、限られた任期のあいだ職務を務め、その後は一般市民として戻っていく。

これこそがしばしば混同される基本的な区分である。すなわち、九つの州において世襲される**統治者（Raja）**と、四つの州において任命される**州元首（Yang di-Pertua Negeri）**である。両者はともに憲法上の州元首であるが、連邦憲法はそれぞれに異なる就任の経路、任期、そして役割を与えている。

## 二つの類型、一つの表

| | 統治者を有する州 | 統治者を有しない州 |
| --- | --- | --- |
| 数 | 九つ | 四つ |
| 州 | ジョホール、ケダ、クランタン、パハン、ペラ、パーリス、セランゴール、トレンガヌ、ヌグリ・スンビラン | マラッカ、ペナン、サバ、サラワク |
| 元首の称号 | スルタン／ラジャ（Raja）／最高元首（Yang di-Pertuan Besar） | 州元首（Yang di-Pertua Negeri） |
| 就任の方法 | 州憲法及び習俗に従い世襲 | 国王（Yang di-Pertuan Agong）により任命 |
| 任期 | 終身 | 4年（再任可） |
| 州のイスラム教の長 | 当該州の統治者 | 国王（Yang di-Pertuan Agong）（第3(3)条） |

## 九人の統治者、三つの称号

一部の人を驚かせる点がある。すべての統治者が「スルタン」と称されるわけではない。連邦憲法は、**統治者（Raja、*Ruler*）**という総称のもとに、三つの異なる称号を含めている。

| 称号 | 州 |
| --- | --- |
| スルタン | ジョホール、ケダ、クランタン、パハン、ペラ、セランゴール、トレンガヌ |
| ラジャ（Raja） | パーリス |
| 最高元首（Yang di-Pertuan Besar） | ヌグリ・スンビラン |

称号が異なるのは、それぞれの州の歴史と習俗が異なるためである。[ヌグリ・スンビラン](/states/negeri-sembilan)の最高元首は、王位を直接世襲するのではない。同元首は、アダット・プルパティ（Adat Perpatih）の制度に従い、ウンダン・ヤン・ウンパット（Undang Yang Empat）によって選ばれる——しかし憲法上は、依然として世襲の統治者である。

これら三つの称号を一つに結びつけているのは、職位が引き継がれる方法である。すなわち**世襲**であり、連邦のいかなる機関によっても任命されるものではない。連邦憲法第71条は、統治者が当該州の統治者としての地位、権利及び特権を継承し、かつ保持する権利を保障している。継承権をめぐるいかなる争いも、連邦政府ではなく、当該州の州憲法に従って決定される。

## 四人の州元首、一つの仕組み

[マラッカ](/states/melaka)、[ペナン](/states/penang)、サバ及びサラワクには統治者がいない。連邦憲法第160(2)条は、**州元首（Yang di-Pertua Negeri）**を、統治者を持たない州の州元首と定義している。英語では、この職位は*Governor*と呼ばれる。

この職位の運用の仕組みは、[連邦憲法](/law/federal-constitution)のEighth Scheduleのs.19Aからs.19Dに定められている。

| 規定 | 効力 |
| --- | --- |
| s.19A(1) | 国王（Yang di-Pertuan Agong）が自らの裁量により、ただし首席大臣（Ketua Menteri）と協議したうえで任命する |
| s.19A(2) | 任期は**4年**；いつでも辞任できる；州議会（Dewan Undangan Negeri）の動議が全議員の3分の2以上の支持を得た場合、国王により罷免され得る |
| s.19B(1) | 市民でない者、または帰化もしくは登録により市民となった者は任命され得ない |
| s.19B(2) | 有給の職に就くことはできず、いかなる商業事業にも積極的に関与してはならない |
| s.19C | 州法律は、州の統合基金（Kumpulan Wang Disatukan）に賦課されるシビル・リスト（Civil List）を定めなければならず、任期中は減額してはならない |

この職位は任命によるものであるため、特定の家系の継承者ではなく、選ばれた個人に開かれている。4年の任期が終了する（あるいは延長される）と、その職にあった者は一般市民に戻る。

## 真に具体的な違い

この称号の違いは、単なる呼び名の違いにとどまらず、現実の憲法上の帰結をもたらす。

**州のイスラム教の長。** 統治者を有する州では、統治者がその州のイスラム教の長である。統治者を有しない四つの州については、第3(3)条が、マラッカ、ペナン、サバ及びサラワクの州憲法がそれぞれ、当該州におけるイスラム教の長の地位を**国王（Yang di-Pertuan Agong）**に与えなければならないと定めている。

**統治者会議（Majlis Raja-Raja）の構成員資格は対等ではない。** 統治者会議の公式サイトによれば、同会議は九人の統治者と四人の州元首から構成される。しかし、連邦憲法のFifth Scheduleは、次の事項に関する手続から州元首を除外している。

- 国王（Yang di-Pertuan Agong）の選出又は罷免；
- 副国王（Timbalan Yang di-Pertuan Agong）の選出；並びに
- 専ら統治者の特権、地位、栄誉及び威厳、又は宗教上の行為及び儀式にのみ関わる事項。

つまり、**九人の統治者のみ**が国王を選出し、罷免することができる——国王は、彼ら自身の中から輪番で選ばれる連邦最高元首である。四人の州元首は、特定の法律への裁可や特別法廷への任命といった他の事項については会議に出席するが、国王の選出には関与しない。

**任期と継続性。** 統治者の王位は終身であり、世襲される。州元首の職位は任期4年である。それゆえ、これら四つの州の歴史には、統治者を有する州であれば一人の統治者が務めるはずの期間内に、複数の州元首が記録されている。

## 両者に共通すること

違いはあるものの、統治者と州元首は、憲法上の州元首としての基本的な性質を共有している。

- 両者はともに**州**の元首であり、政府の長ではない。州政府の長は、州首相（Menteri Besar、統治者を有する州）又は首席大臣（Ketua Menteri、統治者を有しない州並びにペナン及びマラッカ）であり、[州議会](/government/state-assemblies-dun)を率いる。
- 両者とも、立憲君主制のモデルと同様に、ほとんどの事項において州政府の助言に従って行動する。
- 両者とも、統治者会議のほとんどの事務において構成員である。
- 統治者の地位、主権及び特権は、連邦憲法第181条によって保護されており、同条はマレー統治者の主権及び大権を従前のとおり維持する。

## よくある誤解

**「マレーシアのスルタンがいる。」** いない。マレーシア全体を治める単一のスルタンは存在しない。九つの州にはそれぞれ対等な統治者がおり、連邦最高元首は、その九人の統治者の中から輪番で選出される[国王（Yang di-Pertuan Agong）](/glossary/yang-di-pertuan-agong)である。

**「州元首はスルタンと同じで、称号が違うだけだ。」** 同じではない。州元首の職位は任命によるものであり、任期は4年で、世襲されず、州のイスラム教の長でもなく、国王の選出にも関与しない。

**「パーリスとヌグリ・スンビランには統治者がいない。称号がスルタンではないからだ。」** 誤りである。パーリス（ラジャ）とヌグリ・スンビラン（最高元首）は、統治者を有する九つの州に含まれる。異なるのは称号のみであり、地位ではない。

**「州元首は州首相を任命する。」** 統治者を有しない四つの州では、政府の長の称号は州首相ではなく首席大臣である。州首相という称号は、統治者を有する州で用いられる。

## 範囲に関する注記

本稿は、憲法上の構造及び公式な呼称のみを説明するものである。いかなる政治的評価も行わず、現任のいずれの在職者個人にも触れず、進行中のいかなる解釈上の論争についても論評しない。現任の在職者については、州政府の公式ポータル又は統治者会議のウェブサイトを参照されたい。本稿は草稿の段階にあり、まだ人による査読を経ていない。
