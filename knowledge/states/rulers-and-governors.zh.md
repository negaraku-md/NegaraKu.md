马来西亚有13个州属，却只有九个王位。另外四个州由不曾登上王位的人领导——他
是被委任的，任期有限，任满之后便回归为普通公民。

这正是常被混淆的基本分野：在九个州属中**世袭继位**的**统治者**，以及在四个
州属中**委任产生**的**州元首（Yang di-Pertua Negeri）**。两者皆为宪制上的州
元首，但联邦宪法赋予他们不同的产生方式、不同的任期，以及不同的角色。

## 两个类别，一张表

| | 有统治者的州属 | 没有统治者的州属 |
| --- | --- | --- |
| 数目 | 九个 | 四个 |
| 州属 | 柔佛、吉打、吉兰丹、彭亨、霹雳、玻璃市、雪兰莪、登嘉楼、森美兰 | 马六甲、槟城、沙巴、砂拉越 |
| 元首称号 | 苏丹／拉惹／最高统治者 | 州元首（Yang di-Pertua Negeri） |
| 产生方式 | 依该州宪法与习俗世袭 | 由最高元首委任 |
| 任期 | 终身 | 四年（可续任） |
| 该州伊斯兰教首长 | 该州本身的统治者 | 最高元首（第3(3)条） |

## 九位统治者，三个称号

有一点令不少人感到意外：并非所有统治者都称为「苏丹」。联邦宪法使用**统治者**
（*Raja*，*Ruler*）这一通称，涵盖三个不同的称号。

| 称号 | 州属 |
| --- | --- |
| 苏丹 | 柔佛、吉打、吉兰丹、彭亨、霹雳、雪兰莪、登嘉楼 |
| 拉惹（Raja） | 玻璃市 |
| 最高统治者（Yang di-Pertuan Besar） | 森美兰 |

称号之所以不同，是因为每个州属的历史与习俗各异。[森美兰](/zh/states/negeri-sembilan)
的最高统治者并非直接世袭王位；他是依据玻璃甲习俗（Adat Perpatih）由四位酋长
（Undang Yang Empat）推选产生——但在宪法眼中，他依然是一位世袭继位的统治者。

将这三个称号统一起来的，是职位交接的方式：**世袭继位**，而不是由任何联邦一方
委任。联邦宪法第71条保障统治者继承并持有该州统治者的地位、权利与特权的权利。
任何关于继承权的争议，皆依有关州属的宪法裁定，而非由联邦政府裁定。

## 四位州元首，一套机制

[马六甲](/zh/states/melaka)、[槟城](/zh/states/penang)、沙巴与砂拉越都没有统治
者。联邦宪法第160(2)条将**州元首（Yang di-Pertua Negeri）**定义为没有统治者的
州属之元首。在英文中，这个职位称为*Governor*。

该职位的运作机制载于[联邦宪法](/zh/law/federal-constitution)第八附表第19A条
至第19D条：

| 条文 | 效力 |
| --- | --- |
| 第19A(1)条 | 由最高元首行使酌情权委任，但须先咨询首席部长 |
| 第19A(2)条 | 任期**四年**；可随时辞职；若州立法议会以不少于议员总数三分之二的票数支持一项动议，最高元首可将其罢免 |
| 第19B(1)条 | 非公民，或经归化或登记而成为公民者，不得获委任 |
| 第19B(2)条 | 不得担任有收入的职位，也不得积极参与任何商业经营 |
| 第19C条 | 州法律须为其订定民事表（Senarai Sivil），由该州综合基金支付，且在任期内不得削减 |

由于此职位是委任产生的，它向获选个人开放——而非某个家族的继承人。四年任期届满
（或获续任）之后，该职位的持有人便回归为普通公民。

## 真正具体的差异

称号上的差异带来的是实实在在的宪制后果，而不只是名称上的不同。

**该州的伊斯兰教首长。** 在有统治者的州属，统治者即为其州属的伊斯兰教首长。
对于四个没有统治者的州属，第3(3)条规定马六甲、槟城、沙巴与砂拉越的宪法须分别
赋予**最高元首**该州伊斯兰教首长的地位。

**在统治者会议中的席位并不对等。** 根据统治者会议官方网站，该会议由九位统治
者与四位州元首组成。然而，联邦宪法第五附表将州元首排除于以下事务的程序之外：

- 最高元首的选举或罢免；
- 副最高元首的选举；以及
- 纯粹涉及统治者的特权、地位、尊荣与位阶，或宗教行为与仪式的事务。

这意味着**只有九位统治者**才能选举及罢免最高元首——最高元首是从他们之中轮流
选出的国家元首。四位州元首出席会议是为了处理其他事务，例如认可特定法律与
特别法庭的委任，但不参与最高元首的选举。

**任期与延续性。** 统治者的王位终身持有，且属世袭。州元首的职位任期为四年。
这正是为何这四个州属的历史上，会在一个于有统治者州属只由一位统治者担任的
时间跨度内，记录下好几位州元首。

## 两者的共同之处

尽管有所不同，统治者与州元首作为宪制上州元首的基本性质是相同的：

- 两者皆为**州**元首，而非政府首长。该州政府首长为州务大臣（在有统治者的州
  属）或首席部长（在没有统治者的州属，以及槟城与马六甲），领导
  [州立法议会](/zh/government/state-assemblies-dun)。
- 两者在大多数事务上皆依州政府的意见行事，一如君主立宪制的模式。
- 两者在统治者会议的大多数事务上皆为其成员。
- 统治者的地位、主权与特权受联邦宪法第181条保障，该条文维持马来统治者现有的
  主权及特权权利。

## 常见误解

**「有一位马来西亚苏丹。」** 没有。并不存在一位统领全马来西亚的苏丹。九个州
属各自拥有地位平等的统治者，而国家元首是[最高元首（Yang di-Pertuan
Agong）](/zh/glossary/yang-di-pertuan-agong)，从这九位统治者之中轮流选出。

**「州元首与苏丹相同，只是称号不同。」** 并不相同。州元首的职位是委任产生的，
任期四年，不世袭，不是该州的伊斯兰教首长，也不参与最高元首的选举。

**「玻璃市与森美兰没有统治者，因为其称号不是苏丹。」** 错误。玻璃市（拉惹）
与森美兰（最高统治者）皆属于九个有统治者的州属之一；不同的只是称号，而非
地位。

**「州元首委任首席部长。」** 在四个没有统治者的州属，政府首长的称号是首席
部长，而非州务大臣。州务大臣这一称号用于有统治者的州属。
