马来西亚有九个州属拥有统治者（Raja）。马六甲并非其中之一——尽管它的名字，仍系着
这个地区历史上最负盛名的马来苏丹国。

这正是这个州属最常被误解的悖论所在。「马六甲」这个名字总让人联想到宫廷，但现代
马六甲州的元首，是一位任期有限、经**委任**产生的**州元首（Yang di-Pertua
Negeri）**，而不是世袭继位的统治者。

## 重点资料

| | |
| --- | --- |
| 首府 | Bandaraya Melaka（马六甲市） |
| 元首 | 州元首（Yang di-Pertua Negeri，委任产生，非世袭） |
| 州属伊斯兰教首长 | 最高元首（Yang di-Pertuan Agong），依据第3(3)条 |
| 人口 | 1,052.5 千人（2025年估计，DOSM） |
| 面积 | 1,712 平方公里（JUPEM，经《My Local Stats》） |
| 行政区 | 三个——马六甲中央（Melaka Tengah）、亚罗牙也（Alor Gajah）、野新（Jasin） |
| GDP | RM50.3 billion（2025年，2015年固定价格），增长3.0% |
| UNESCO世界遗产 | 2008年列入，标准(ii)(iii)(iv)项 |

## 为何称号是州元首（Yang di-Pertua Negeri）

联邦宪法第160(2)条将该用语定义得相当简洁：州元首（Yang di-Pertua Negeri）意即
**没有统治者（Raja）**之州属的元首。

符合这项定义的共有四个州属——马六甲、[槟城](/zh/states/penang)、沙巴与砂拉越。
其核心条文载于[联邦宪法](/zh/law/federal-constitution)第八附表（Eighth
Schedule）第19A条至第19D条：

| 条文 | 效力 |
| --- | --- |
| 19A(1) | 由最高元首依其酌情权委任，但须先咨询首席部长 |
| 19A(2) | 任期为**四年**；可随时辞职；若州立法议会（Dewan Undangan Negeri，DUN）以不少于全体议员三分之二的票数通过动议，最高元首可将其罢免 |
| 19B(1) | 非公民，或经归化或登记而成为公民者，不得受委任 |
| 19B(2) | 不得担任任何有薪职位，亦不得积极参与任何商业活动 |
| 19C | 州法律须订明由统一基金（Consolidated Fund）拨付的民事清单（Senarai Sivil / Civil List），且在其任期内不得削减 |

第八附表第22条则说明替代的具体机制：在该附表第I与第II部分适用于马六甲与槟城时，
凡提及统治者（Raja）之处，均以州元首（Yang di-Pertua Negeri）**取代**。

州政府官方门户网站指出，委任由最高元首在咨询首席部长后作出，并将 Tun Seri
Setia Dr. Haji Mohd Ali bin Mohd Rustam 列为马六甲第七任州元首，自2020年起在
任。请查阅该门户网站以取得最新任职状况。

## 鲜少被说明的后果

称号的差异带来三项具体的宪制后果。

**伊斯兰教首长的归属不同。** 第3(3)条规定，马六甲、槟城、沙巴与砂拉越的州宪法
须各自订明，赋予最高元首在该州担任伊斯兰教首长的地位。在有统治者的州属，这项
地位则由该州的统治者担任。

**统治者会议的成员资格并不完整。** 第五附表第1条将各州元首（Yang di-Pertua
Negeri）纳入统治者会议（Majlis Raja-Raja）成员之列。但同一附表第7条，将他们
排除在以下事项之外：最高元首的推选或罢黜、副最高元首的推选，以及纯粹涉及统治
者特权、地位、荣衔与位阶或宗教行为与仪式的事项。

**这个职位有任期限制。** 四年一任，可连任——相较于终身在位的王位。这也使马六
甲有别于[森美兰](/zh/states/negeri-sembilan)的模式：森美兰的州元首由四位酋长
（Undang Yang Empat）推选产生，但仍属习俗上的统治者。

## 一座城市里的四层权力

州政府官方门户网站记录了以下的历史顺序。

| 时期 | 事件 |
| --- | --- |
| 1511年以前 | [马六甲苏丹国](/zh/malaysia/melaka-sultanate) |
| 1511–1641 | 葡萄牙统治；Afonso de Albuquerque 于1511年8月10日抵达，马六甲城于8月24日陷落——统治130年 |
| 1641–1795 | 荷兰统治，接续葡萄牙败于荷兰—柔佛联军之后——共154年；Stadthuys建于1650年，圣彼得教堂（St. Peter's Church）建于1710年 |
| 1795–1957 | 英国统治；1824年英荷条约与1826年海峡殖民地（Straits Settlements）的设立 |
| 1942–1945 | 日本占领 |
| 1956 | 独立宣言于2月20日在班达希利尔草场（Padang Banda Hilir）宣布 |

正是这片班达希利尔草场（Padang Banda Hilir），使马六甲成为[1957年独立](/zh/malaysia/independence-1957)
故事中一个具象征意义的地点。

马六甲于1989年4月15日被宣布为历史名城。马六甲历史名城市议会（Majlis
Perbandaran Melaka Bandaraya Bersejarah）其后于2003年4月15日升格为马六甲历史
名城市政局（Majlis Bandaraya Melaka Bersejarah，MBMB），现时的行政范围为
270.39平方公里。

## UNESCO实际认可的是什么

这项列名并非马六甲独有。该系列遗产项目名为**「Melaka and George Town,
Historic Cities of the Straits of Malacca」**，于2008年依标准(ii)、(iii)与
(iv)项列入，2011年再列入一项小幅边界修改。

两座城市之间的角色分工，在UNESCO本身的描述中已直接说明：以其政府建筑、教堂、
广场与堡垒而言，**马六甲代表的是这段历史的早期阶段**——即15世纪的马来苏丹国，
以及始于16世纪初的葡萄牙与荷兰时期。**乔治市则代表英国统治的时代**，始于18
世纪末。

因此，这项列名中最显著的英国层面其实落在槟城，而非马六甲。这个细微差别，在通
俗的概述中常常被忽略。

标准(iv)项特别提到一系列非凡的店屋与市镇屋，部分可追溯至荷兰或葡萄牙时期。整
个系列遗产项目的面积为154.68公顷，缓冲区为392.8公顷。

## 经济：并非只靠旅游业

官方数据在这一点上，正好与普遍印象相左。马六甲的确是个旅游州属——但制造业对
其经济的贡献超过三分之一。

| 行业 | 2025年GDP（RM million） | 占比 |
| --- | --- | --- |
| 服务业 | 26,369.9 | 52.4% |
| 制造业 | 17,777.4 | 35.4% |
| 农业 | 4,686.2 | 9.3% |
| 建筑业 | 1,258.8 | 2.5% |
| 采矿与采石业 | 72.1 | 0.1% |
| **按购买者价格计算的GDP** | **50,286.0** | **100%** |

以2015年固定价格计算。2025年整体增长3.0%，此前2024年增长4.2%。

旅游业在数据中仍有自己独特的印记。在《Domestic Tourism Survey (States)
2024》中，DOSM发现马六甲是**唯一一个**州属，其境内过夜旅游的主要目的是度假、
休闲与娱乐——在其他所有州属，主要目的都是探亲访友。

人口集中在马六甲中央：2025年1,052.5千人中有633.3千人居于此，相比之下亚罗牙也
为261.8千人，野新为157.3千人。然而以面积而论，马六甲中央却是最小的（359平方
公里），小于野新（679）与亚罗牙也（674）。

## 常见误解

**「马六甲仍有苏丹。」** 不对。马六甲的元首是州元首（Yang di-Pertua
Negeri），由最高元首委任，任期四年。马六甲苏丹国是一个历史实体，已于1511年结
束其在马六甲的统治地位。

**「州元首（Yang di-Pertua Negeri）跟统治者一样，只是称号不同。」** 并不一
样。这个职位有任期限制、并非世袭、不担任该州伊斯兰教首长的地位，也不参与最高
元首的推选。

**「整个 Bandaraya Melaka 都是UNESCO遗址。」** 该项列名所涵盖的，是与乔治市
共享的系列遗产项目中，具特定边界的核心区与缓冲区——并非整个270.39平方公里的
市行政范围。

**「马六甲的经济完全依赖游客。」** 州属GDP数据显示，制造业贡献约35%，而服务
业涵盖了旅游业以外的许多活动。
