彭亨的国土面积占马来西亚半岛土地的四分之一以上，但每20名马来西亚人当中，
只有一人居住在此。

这一个事实几乎解释了这个州属的一切：为什么它的森林至今仍然广袤，为什么它
的经济依靠土地而非工厂，以及为什么国家公园（Taman Negara）能够以一种在
[雪兰莪（Selangor）](/zh/states/selangor)或
[槟城（Penang）](/zh/states/penang)都无法存续的形式存在。

## 空间广阔，人口稀疏

彭亨北接吉兰丹（Kelantan）；西接霹雳（Perak）、雪兰莪（Selangor）与森美兰
（Negeri Sembilan）；南接柔佛（Johor）；东临登嘉楼（Terengganu）与南中国海。
它与其他六个州相邻——比半岛任何其他州属都多。

其人口数字变动缓慢。DOSM估计2025年人口为1,678,200人，较2024年的1,667,700人
有所增加。0.6%的年增长率其实高于全国0.5%的增长率，但基数偏小：彭亨仅占
马来西亚3,420万人口的4.9%。

将人口除以土地面积，得出的数字说明了一切：

| 地区 | 人口密度（人/平方公里，2025年） |
| --- | --- |
| 吉隆坡联邦直辖区 | 8,546 |
| 槟城 | 1,749 |
| 全国平均 | 104 |
| 登嘉楼 | 96 |
| 沙巴（Sabah） | 51 |
| **彭亨** | **46** |
| 沙拉越（Sarawak） | 20 |

资料来源：DOSM，《Anggaran Penduduk Semasa Malaysia 2025》。

只有沙拉越的人口比彭亨更稀疏。DOSM还记录了2025年彭亨的另外两项人口特征：
彭亨的性别比为每100名女性对114名男性——是全国最高之一；而彭亨也成为新晋
入列的三个「老龄化州属」之一，其65岁及以上人口占比达7.1%。

## 十一个县，两个中心

彭亨划分为11个行政县：**北根（Pekan）、关丹（Kuantan）、劳勿（Rompin）、
文冬（Maran）、比劳（Bera）、珍德本（Jerantut）、淡马鲁（Temerloh）、劳勿
（Raub）、文冬（Bentong）、立卑（Lipis）**与**金马仑高原（Cameron
Highlands）**。

该州以两个功能不同的中心运作。**关丹**是行政州府，也是彭亨州务大臣署
（Wisma Sri Pahang，即州秘书署）的所在地。**北根**则是皇城。

其地理形态也呈层次分布。东海岸有一条长约208公里、面向南中国海的沿海地带。
内陆延伸着彭亨河（Sungai Pahang）流域。西部则是高原地带——金马仑高原、云顶
高原（Genting Highlands）与福隆港（Bukit Fraser）——使彭亨成为唯一同时坐拥
半岛三大高原度假胜地的州属。

## 经济：最依赖土地的州属

2025年，彭亨的KDNK（以2015年固定价格计）达到**RM71.0 bilion**，较2024年的
RM68.8 bilion有所增长——增幅约3.2%，此前一年的增幅则更快，约为5.8%。

按部门划分的比例，正是彭亨的独特之处：

| 部门 | 2025年数值（RM bilion） | 占州内生产总值比例 |
| --- | --- | --- |
| 服务业 | 37.3 | 52.6% |
| 农业 | 15.9 | 22.4% |
| 制造业 | 14.7 | 20.8% |
| 建筑业 | 2.3 | 3.3% |
| 矿业与采石业 | 0.6 | 0.8% |

数值来自DOSM数据目录；百分比比例根据这些数值计算得出。

根据2025年DOSM数据，农业22.4%的占比是马来西亚所有州属中最高的——高于吉兰丹
（约19.8%）与玻璃市（Perlis）（约16.5%）。相比之下，雪兰莪的农业贡献比例
仅约1.1%。

油棕解释了其中的大部分原因。截至2025年12月，MPOB（马来西亚棕油局）记录彭亨
的油棕种植面积为**745,445公顷**——占马来西亚总面积的13.1%，也是半岛面积
最大的，超越[柔佛（Johor）](/zh/states/johor)（675,558公顷）。马来西亚半岛
近30%的油棕种植面积都位于彭亨。该行业的背景在
[油棕行业](/zh/economy/palm-oil-sector)一文中有说明。

同样值得留意的是规模小的部分。矿业与采石业占州内生产总值不到1%，尽管彭亨
的历史常与锡矿和金矿业联系在一起。

## 国家公园：比喜马拉雅山脉更古老的森林

国家公园（Taman Negara）面积达**4,343平方公里**，横跨彭亨、吉兰丹与登嘉楼
三州边界。作为规模参照，该面积相当于彭亨自身面积的约12%，尽管该公园并非
完全位于本州境内。

Tourism Pahang官方门户网站将其描述为全球最古老的雨林之一，距今约1.3亿年，
拥有约14,000种植物、超过300种鸟类、250种淡水鱼类与200种哺乳动物。

园内矗立着**海拔2,187米的大汉山（Gunung Tahan）**，是马来西亚半岛的最高峰。
野生动物与国家公园局（PERHILITAN）列出两条为期七天六夜的登山路线套餐——
从瓜拉大汉（Kuala Tahan）上山后再原路返回瓜拉大汉，或从瓜拉大汉下山至
美拉波（Merapoh）的瓜拉朱伦（Kuala Juram）——并规定每个登山队伍都必须配备
向导。

| 项目 | 详情 |
| --- | --- |
| 主要入口 | 珍德本县（Jerantut）瓜拉大汉（Kuala Tahan） |
| 距珍德本镇的距离 | 约68公里 |
| 公园管理机构 | 野生动物与国家公园局（PERHILITAN） |
| 特色景点 | 悬空于地面约45米高的树冠吊桥步道 |

国家公园的重要性不仅在于旅游。它是半岛自独立前以来持续受保护、规模庞大的
唯一低地雨林区块，并作为流经三个州的河流系统的集水区。旅游业对国家经济的
贡献在[旅游业](/zh/economy/tourism)一文中有讨论。

## 皇室体制与北根

彭亨的州元首称号为**彭亨苏丹（Sultan Pahang）**。彭亨皇宫（Istana Pahang）
官方网站列出其陛下的全衔为*Kebawah Duli Paduka Baginda Sultan Pahang
Al-Sultan Abdullah Ri'ayatuddin Al-Mustafa Billah Shah ibni Al-Marhum Sultan
Haji Ahmad Shah*。

同一网站记载，其陛下于1959年7月30日出生，于1975年7月1日受封为彭亨王储
（Tengku Mahkota Pahang），并于1979年4月28日出任摄政王（Pemangku Raja）。

根据马来西亚国会（Parlimen Malaysia）的官方名单，其陛下自2019年1月31日
至2024年1月30日期间出任**第16任最高元首（Yang di-Pertuan Agong）**，
在统治者会议（Majlis Raja-Raja）的轮值中代表彭亨。该职位自2024年1月31日
起由柔佛的苏丹依布拉欣（Sultan Ibrahim ibni Almarhum Sultan Iskandar）
出任。

该州的皇城为**北根（Pekan）**，是彭亨皇室体制的中心，也是关丹成为州府之前
该州的旧行政中心。

苏丹作为州元首的地位，以及州属与联邦之间的关系，由
[联邦宪法（Perlembagaan Persekutuan）](/zh/law/federal-constitution)连同
各州自身的州宪法共同规范。这一架构在各州之间有所不同——可与
[森美兰（Negeri Sembilan）](/zh/states/negeri-sembilan)比较，该州的州元首
由选举产生，称号为最高统治者（Yang di-Pertuan Besar）。

本节纯属描述性质，不作任何评价。

## 常见误解

**「彭亨是马来西亚面积最大的州属。」** 它是*半岛*面积最大的州属。沙拉越
与沙巴的面积都比它大。

**「关丹是皇城。」** 关丹是行政州府。皇城是北根。

**「国家公园是彭亨的州立公园。」** 它横跨彭亨、吉兰丹与登嘉楼，并由野生
动物与国家公园局（PERHILITAN）在联邦层级为马来西亚半岛统一管理。

**「人口稀疏意味着经济规模小。」** 2025年彭亨的KDNK达RM71.0 bilion，超过
若干人口更多的州属。其单位土地的经济产出确实较低，但整体产值并不小。

**「金马仑高原是一个市镇，而非一个县。」** 金马仑高原是彭亨11个行政县之一。

## 关于数字的说明

2025年的人口数字是DOSM的初步估计，并非完整人口普查数据，通常会经过修订。
KDNK数字以2015年固定价格列示，以使跨年比较具有意义；以当期价格计算的数值
将有所不同。上表中的部门比例由编辑根据DOSM的绝对值计算得出。
