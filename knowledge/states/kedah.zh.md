2024年，电气、电子与光学产品占吉打制造业增加值的51.1%。稻米则是该州GDP中
10.6%农业贡献的一部分。

这个被称为全国稻米粮仓的州属，若按自身的经济核算来看，其实是一个工厂州。

这两个事实同时成立——理解为什么，正是理解吉打的最佳方式。

## 重点资料

| | |
| --- | --- |
| 首府 | 亚罗士打 |
| 州元首 | 吉打苏丹 |
| 面积 | 9,447平方公里 |
| 行政县 | 12个，包括浮罗交怡 |
| 人口 | 223万人（DOSM 2025年估计） |
| 2024年GDP | RM54.0 billion，增长4.2% |
| 2024年获批投资 | RM45.8 billion——全国各州第四高 |
| 2022年稻米产量 | 834,901公吨——全马最高 |

来源：吉打州政府官方网站、DOSM与MIDA。

## 经济结构：真正撑起GDP的是什么

DOSM发布的《2024年各州GDP》新闻稿显示，吉打的GDP为**RM54.0 billion**，
增长**4.2%**，高于2023年的1.7%。

其产业结构比任何称号都更准确地描绘了这个州属：

| 产业 | 数值（2024年） | 占GDP比重 | 增长 |
| --- | --- | --- | --- |
| 服务业 | RM30.3 billion | 56.1% | +3.8% |
| 制造业 | RM16.1 billion | 29.9% | +6.6% |
| 农业 | RM5.7 billion | 10.6% | +4.0% |
| 建筑业 | RM1.4 billion | 2.6% | −11.1% |
| 采矿与採石业 | RM0.1 billion | 0.2% | −3.0% |

第二大增长动力是制造业，该产业在2023年萎缩3.2%之后，猛增6.6%。在该产业
内，电气、电子与光学产品贡献了51.1%的增加值，并增长6.5%。

换句话说，按价值计算，吉打逾半数的工厂产出属于[电子与半导体](/zh/economy/electronics-semiconductors)。

## 吉打为何仍是稻米粮仓

这个称号衡量的是不同的东西：吉打在全国稻米供应中的份额，而不是稻米在吉打
经济中的份额。

根据DOSM 2022参考年的农作物数据集：

| | 吉打 | 马来西亚 |
| --- | --- | --- |
| 水稻种植面积 | 213,718公顷 | 637,935公顷 |
| 稻米产量 | 834,901公吨 | 2,281,739公吨 |

这意味着全国稻米产量中约有**36.6%**来自单一一个州属。第二与第三大产
区——吉兰丹（272,633公吨）与霹雳（269,790公吨）——各自都不到吉打总量的
三分之一。

其技术基础在于水。慕达农业发展局（Muda Agricultural Development
Authority，MADA）根据**Akta Lembaga Kemajuan Pertanian Muda 1972 (Akta
70)**设立，该法令于1972年3月31日生效，负责管理三座水坝——Pedu、Muda与
Ahning——使Muda区得以**一年两造**种植稻米。

若没有那套受控灌溉系统，吉打平原一年只能种一造。正是这套体制架构，而非
土地本身，造就了这个称号。

## Kulim Hi-Tech Park：稻田旁的工厂

1996年，一座工业园在居林县正式开始运作，距[槟城](/zh/states/penang)边界
约一小时车程。

居林高科技园（Kulim Hi-Tech Park，KHTP）官方网站将其描述为马来西亚第一
个完全整合的高科技园区，标语为*Leading Global Science City*。

其数据与结构：

- **占地面积：** 4,736英亩
- **分区：** 六个——工业区、市镇区、研发与培训区、机构区、配套设施区，以
  及住宅区
- **拥有人与管理者：** Kulim Technology Park Corporation Sdn Bhd
  （KTPC），吉打州发展机构（Perbadanan Kemajuan Negeri Kedah）的全资子
  公司
- **位置：** 位于北马经济走廊范围内
- **重点：** 高科技制造业、研发以及科技教育活动

官方网站记录的最新阶段，是2023年竣工的工业区第4A期。

这一效应也反映在投资数据上。MIDA报告指出，吉打在2024年吸引了**RM45.8
billion**的获批投资——仅次于雪兰莪（RM101.1 billion）、吉隆坡联邦直辖区
（RM91.5 billion）与柔佛（RM48.5 billion），位居全国第四，并领先槟城
（RM32.0 billion）。

对一个供应全国约三分之一稻米的州属而言，这样的排名出乎大多数人的预料。
另可参阅马来西亚[制造业](/zh/economy/manufacturing)的整体概况。

## 古吉打与布秧谷

在Merbok县，Gunung Jerai山脚下，埋藏着一层比任何工厂或稻田都古老得多的
历史。

大马国家档案局（Arkib Negara Malaysia）记录，布秧谷（Lembah Bujang）共
发现**50处庙宇遗址**，估计建于**公元4世纪至12世纪**之间。当中特别提及
的包括相信建于公元6世纪左右的Candi Bukit Batu Pahat，以及Candi
Pengkalan Bujang与Candi Pendiat。

Gunung Jerai曾作为航海地标，该地区也曾是印度与中国商人之间重要的中途
停靠站。

布秧谷考古博物馆（Muzium Arkeologi Lembah Bujang）隶属大马博物院
（Jabatan Muzium Malaysia），坐落于Merbok的Bukit Batu Pahat之上，距双溪
大年约23公里。它于**1980年1月23日**正式开幕，馆藏数千件公元3世纪至12世
纪的文物——陶瓷、玻璃珠及其他显示布秧谷曾为国际贸易中心的物品。

吉打州政府官方网站指出，布秧谷的考古证据显示，早在**公元110年**，已有
一个印度教—佛教王国统治着古代吉打。

这使吉打成为本区域最早的文明遗址之一——其地位可媲美[狼牙修](/zh/malaysia/langkasuka)
在马来半岛早期历史中的地位。

## 王室体制与州首府

吉打的州元首为吉打苏丹。吉打州政府官方网站指出，现任州元首为**Kebawah
Duli Yang Maha Mulia Al-Aminul Karim Sultan Sallehuddin Ibni Almarhum
Sultan Badlishah**，是第**29**任吉打苏丹，于**2017年9月12日**颁布册封。
正式王宫为亚罗士打的Istana Anak Bukit。

同一份官方网站记录，吉打苏丹国始于**1136年**，当时Raja Phra Ong
Mahawangsa皈依伊斯兰教，并受封为Sultan Mudzafar Shah。此后该州历经室
利佛逝、暹罗与英国影响之下的不同时期，最终于1948年加入马来亚联合邦。

亚罗士打本身则由Sultan Muhammad Jiwa Sultan Zainal Adilin Mu'adzam Shah
II于**1735年**建立，根据州属地方政府官方网站，是马来西亚历史最悠久的州
首府。它于**2003年11月28日**获宣布为马来西亚**第9座市**。

## 十二个县，十二种面貌

吉打分为12个行政县。该州的地方政府显示出各地区性格差异有多大：

| 类型 | 地方政府 |
| --- | --- |
| 市理会 | Majlis Bandaraya Alor Setar |
| 市议会 | Sungai Petani、Kulim、Kubang Pasu、Langkawi（Bandaraya Pelancongan） |
| 县议会 | Baling、Pendang、Yan、Sik、Padang Terap、Bandar Baharu |
| 特别机构 | PBT Taman Perindustrian Hi-Tech Kulim |

请留意三个不同的板块：北部以行政与稻田为主（亚罗士打、Kubang Pasu、
Pendang、Yan），南部以工业为主（双溪大年、居林、Bandar Baharu），西部
则以岛屿旅游为主（浮罗交怡）。

浮罗交怡是特殊的一例。UNESCO将浮罗交怡列为浮罗交怡世界地质公园，涵盖该
群岛99个岛屿、面积达92,000公顷，展示着超过5亿5000万年历史的寒武纪岩层
构造。它是马来西亚第一个UNESCO地质公园。

千人）：

| 群体 | 人数 |

## 常见误解

**「吉打是农业州，所以经济规模小又落后。」**
农业在2024年只占该州GDP的10.6%。制造业的贡献几乎是农业的三倍，而该州同
年也吸引了全国第四高的获批投资。

**「Kulim Hi-Tech Park是槟城的一部分。」**
KHTP位于吉打居林县，由吉打州发展机构的全资子公司拥有。它与槟城的电子业
集群为邻，但项目本身与行政管辖都属于吉打。

**「浮罗交怡是一个独立的州属。」**
浮罗交怡是吉打州12个县之一。

**「布秧谷只有一处庙宇遗址。」**
国家档案局记录该区域共有50处庙宇遗址，而非单一一座建筑。

**「马来西亚所有的稻米都来自吉打。」**
根据DOSM 2022年数据，约为36.6%。吉兰丹、霹雳、玻璃市、雪兰莪与砂拉越也
贡献了可观的份额。
