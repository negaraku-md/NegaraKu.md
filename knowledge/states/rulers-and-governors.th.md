มาเลเซียมี 13 รัฐ แต่มีเพียงเก้าราชบัลลังก์ อีกสี่รัฐนำโดยบุคคลที่ไม่ได้ประทับบนราชบัลลังก์โดยตรง — เขาได้รับการแต่งตั้ง ดำรงตำแหน่งเป็นระยะเวลาจำกัด แล้วกลับไปเป็นสามัญชน

นั่นคือการแบ่งพื้นฐานที่มักถูกสับสน: **ผู้ปกครอง (Raja)** ที่สืบทอดตำแหน่งในเก้ารัฐ และ**ยังดีเปอร์ตวนเนอเกอรี (Yang di-Pertua Negeri)** ที่มาจากการแต่งตั้งในสี่รัฐ ทั้งสองเป็นประมุขของรัฐตามรัฐธรรมนูญ แต่รัฐธรรมนูญแห่งสหพันธรัฐให้ทางเข้าสู่ตำแหน่ง วาระ และบทบาทที่แตกต่างกันแก่พวกเขา

## สองหมวด หนึ่งตาราง

| | รัฐที่มีผู้ปกครอง | รัฐที่ไม่มีผู้ปกครอง |
| --- | --- | --- |
| จำนวน | เก้า | สี่ |
| รัฐ | ยะโฮร์ เกอดะฮ์ กลันตัน ปะหัง เปรัก ปะลิส สลังงอร์ ตรังกานู เนอเกอรีเซิมบีลัน | มะละกา ปีนัง ซาบาห์ ซาราวัก |
| ตำแหน่งประมุข | สุลต่าน / รายา / ยังดีเปอร์ตวนเบอซาร์ | ยังดีเปอร์ตวนเนอเกอรี |
| วิธีดำรงตำแหน่ง | สืบทอดตามรัฐธรรมนูญและจารีตของรัฐ | แต่งตั้งโดยยังดีเปอร์ตวนอากง |
| วาระ | ตลอดพระชนม์ชีพ | สี่ปี (ต่ออายุได้) |
| ประมุขศาสนาอิสลามของรัฐ | ผู้ปกครองของรัฐนั้น | ยังดีเปอร์ตวนอากง (มาตรา 3(3)) |

## ผู้ปกครองเก้าพระองค์ สามตำแหน่ง

สิ่งที่ทำให้บางคนประหลาดใจ: ไม่ใช่ผู้ปกครองทุกพระองค์มีตำแหน่ง "สุลต่าน" รัฐธรรมนูญแห่งสหพันธรัฐใช้คำทั่วไปว่า **ผู้ปกครอง (Raja / Ruler)** เพื่อครอบคลุมสามตำแหน่งที่แตกต่างกัน

| ตำแหน่ง | รัฐ |
| --- | --- |
| สุลต่าน | ยะโฮร์ เกอดะฮ์ กลันตัน ปะหัง เปรัก สลังงอร์ ตรังกานู |
| รายา | ปะลิส |
| ยังดีเปอร์ตวนเบอซาร์ | เนอเกอรีเซิมบีลัน |

ตำแหน่งแตกต่างกันเพราะประวัติศาสตร์และจารีตของแต่ละรัฐแตกต่างกัน ยังดีเปอร์ตวนเบอซาร์แห่ง[เนอเกอรีเซิมบีลัน](/states/negeri-sembilan)ไม่ได้สืบทอดราชบัลลังก์โดยตรง แต่ถูกเลือกโดยอูนดังยังเอิมปัตตามระบบอาดัตเปอร์ปาติฮ์ — ทว่ายังคงเป็นผู้ปกครองในสายตาของรัฐธรรมนูญ

สิ่งที่รวมสามตำแหน่งนี้เข้าด้วยกันคือวิธีที่ตำแหน่งนั้นถ่ายโอน: **สืบทอด** ไม่ใช่แต่งตั้งโดยฝ่ายสหพันธรัฐใด ๆ มาตรา 71 ของรัฐธรรมนูญแห่งสหพันธรัฐรับรองสิทธิของผู้ปกครองในการสืบทอดและดำรงฐานะ สิทธิ และเอกสิทธิ์ของผู้ปกครองรัฐนั้น ข้อพิพาทใด ๆ เกี่ยวกับสิทธิในการสืบทอดจะตัดสินตามรัฐธรรมนูญของรัฐที่เกี่ยวข้อง ไม่ใช่โดยรัฐบาลสหพันธรัฐ

## ยังดีเปอร์ตวนเนอเกอรีสี่คน หนึ่งกลไก

[มะละกา](/states/melaka) [ปีนัง](/states/penang) ซาบาห์ และซาราวักไม่มีผู้ปกครอง มาตรา 160(2) ของรัฐธรรมนูญแห่งสหพันธรัฐนิยาม **ยังดีเปอร์ตวนเนอเกอรี** ว่าเป็นประมุขของรัฐสำหรับรัฐที่ไม่มีผู้ปกครอง ในภาษาอังกฤษ ตำแหน่งนี้เรียกว่า *Governor*

กลไกของตำแหน่งนี้อยู่ในมาตรา 19A ถึง 19D ของตารางที่แปดของ[รัฐธรรมนูญแห่งสหพันธรัฐ](/law/federal-constitution):

| บทบัญญัติ | ผลของมัน |
| --- | --- |
| 19A(1) | แต่งตั้งโดยยังดีเปอร์ตวนอากงที่กระทำตามดุลยพินิจของตน แต่หลังหารือกับมุขมนตรี |
| 19A(2) | วาระ **สี่ปี** ลาออกเมื่อใดก็ได้ อาจถูกถอดถอนโดยยังดีเปอร์ตวนอากงตามญัตติของสภานิติบัญญัติแห่งรัฐที่ได้รับการสนับสนุนด้วยคะแนนเสียงไม่น้อยกว่าสองในสามของสมาชิกทั้งหมด |
| 19B(1) | ผู้ที่ไม่ใช่พลเมือง หรือพลเมืองโดยการแปลงสัญชาติหรือการจดทะเบียน ไม่อาจได้รับการแต่งตั้ง |
| 19B(2) | ไม่อาจดำรงตำแหน่งที่มีรายได้และไม่อาจมีส่วนร่วมอย่างแข็งขันในกิจการเชิงพาณิชย์ |
| 19C | กฎหมายของรัฐต้องบัญญัติให้มีรายการเงินหลวง (Civil List) ที่ตั้งจ่ายจากกองทุนรวมของรัฐและไม่อาจลดลงตลอดวาระ |

เพราะตำแหน่งนี้มาจากการแต่งตั้ง จึงเปิดกว้างแก่บุคคลที่ถูกเลือก — ไม่ใช่ทายาทของครอบครัวใดครอบครัวหนึ่ง เมื่อวาระสี่ปีสิ้นสุด (หรือได้รับการต่ออายุ) ผู้ดำรงตำแหน่งกลับไปเป็นสามัญชน

## ความแตกต่างที่เป็นรูปธรรมอย่างแท้จริง

ความแตกต่างของตำแหน่งนำมาซึ่งผลทางรัฐธรรมนูญที่ชัดเจน ไม่ใช่เพียงชื่อเรียก

**ประมุขศาสนาอิสลามของรัฐ** ในรัฐที่มีผู้ปกครอง ผู้ปกครองเป็นประมุขศาสนาอิสลามของรัฐ สำหรับสี่รัฐที่ไม่มีผู้ปกครอง มาตรา 3(3) บัญญัติว่ารัฐธรรมนูญของมะละกา ปีนัง ซาบาห์ และซาราวักต้องให้ **ยังดีเปอร์ตวนอากง** มีสถานะเป็นประมุขศาสนาอิสลามในรัฐนั้น

**การเป็นสมาชิกสภาผู้ปกครองไม่เท่าเทียมกัน** ตามเว็บไซต์ทางการของสภาผู้ปกครอง สภาประกอบด้วยผู้ปกครองเก้าพระองค์และยังดีเปอร์ตวนเนอเกอรีสี่คน อย่างไรก็ตาม ตารางที่ห้าของรัฐธรรมนูญแห่งสหพันธรัฐกันยังดีเปอร์ตวนเนอเกอรีออกจากกระบวนการที่เกี่ยวกับ:

- การเลือกหรือถอดถอนยังดีเปอร์ตวนอากง
- การเลือกรองยังดีเปอร์ตวนอากง และ
- เรื่องที่เกี่ยวข้องเฉพาะกับเอกสิทธิ์ ฐานะ เกียรติยศ และความสูงส่งของผู้ปกครอง หรือการกระทำและพิธีทางศาสนา

หมายความว่า **เฉพาะผู้ปกครองเก้าพระองค์**ที่เลือกและสามารถถอดถอนยังดีเปอร์ตวนอากง — ประมุขสูงสุดของประเทศที่เลือกจากในบรรดาพวกเขาเองโดยหมุนเวียน ส่วนยังดีเปอร์ตวนเนอเกอรีสี่คนเข้าร่วมในสภาสำหรับกิจการอื่น เช่น การให้ความเห็นชอบกฎหมายบางฉบับและการแต่งตั้งสู่ศาลพิเศษ แต่ไม่ใช่ในการเลือกยังดีเปอร์ตวนอากง

**วาระและความต่อเนื่อง** ราชบัลลังก์ของผู้ปกครองคงอยู่ตลอดพระชนม์ชีพและสืบทอด ตำแหน่งยังดีเปอร์ตวนเนอเกอรีมีวาระสี่ปี นี่คือเหตุผลที่ประวัติศาสตร์ของทั้งสี่รัฐนั้นบันทึกยังดีเปอร์ตวนเนอเกอรีหลายคนในช่วงเวลาหนึ่งที่สำหรับรัฐที่มีผู้ปกครองมีเพียงผู้ปกครองพระองค์เดียว

## สิ่งที่เหมือนกันระหว่างทั้งสอง

แม้จะแตกต่างกัน ทั้งผู้ปกครองและยังดีเปอร์ตวนเนอเกอรีต่างมีลักษณะพื้นฐานร่วมกันในฐานะประมุขของรัฐตามรัฐธรรมนูญ:

- ทั้งสองเป็นประมุขของ**รัฐ** ไม่ใช่หัวหน้ารัฐบาล หัวหน้ารัฐบาลของรัฐคือเมินเตอรีเบอซาร์ (ในรัฐที่มีผู้ปกครอง) หรือมุขมนตรี (ในรัฐที่ไม่มีผู้ปกครอง ตลอดจนปีนังและมะละกา) ซึ่งนำ[สภานิติบัญญัติแห่งรัฐ](/government/state-assemblies-dun)
- ทั้งสองกระทำการตามคำแนะนำของรัฐบาลของรัฐในเรื่องส่วนใหญ่ ตามแบบจำลองกษัตริย์ภายใต้รัฐธรรมนูญ
- ทั้งสองเป็นสมาชิกสภาผู้ปกครองสำหรับกิจการส่วนใหญ่ของสภา
- ฐานะ อำนาจอธิปไตย และเอกสิทธิ์ของผู้ปกครองได้รับการคุ้มครองโดยมาตรา 181 ของรัฐธรรมนูญแห่งสหพันธรัฐ ซึ่งคงไว้ซึ่งอำนาจอธิปไตยและพระราชอำนาจของผู้ปกครองมลายูตามที่มีอยู่เดิม

## ความเข้าใจผิดที่พบบ่อย

**"มีสุลต่านแห่งมาเลเซีย"** ไม่มี ไม่มีสุลต่านหนึ่งพระองค์สำหรับทั้งมาเลเซีย เก้ารัฐมีผู้ปกครองของตนเองที่มีฐานะเท่าเทียมกัน และประมุขสูงสุดของประเทศคือ[ยังดีเปอร์ตวนอากง](/glossary/yang-di-pertuan-agong)ที่เลือกหมุนเวียนจากในบรรดาผู้ปกครองเก้าพระองค์นั้น

**"ยังดีเปอร์ตวนเนอเกอรีเหมือนสุลต่าน เพียงแต่ตำแหน่งต่างกัน"** ไม่เหมือนกัน ตำแหน่งยังดีเปอร์ตวนเนอเกอรีมาจากการแต่งตั้ง มีวาระสี่ปี ไม่สืบทอด ไม่ใช่ประมุขศาสนาอิสลามของรัฐ และไม่ร่วมในการเลือกยังดีเปอร์ตวนอากง

**"ปะลิสและเนอเกอรีเซิมบีลันไม่มีผู้ปกครองเพราะตำแหน่งไม่ใช่สุลต่าน"** ผิด ปะลิส (รายา) และเนอเกอรีเซิมบีลัน (ยังดีเปอร์ตวนเบอซาร์) จัดอยู่ในเก้ารัฐที่มีผู้ปกครอง เพียงตำแหน่งของพวกเขาต่างกัน ไม่ใช่สถานะ

**"ยังดีเปอร์ตวนเนอเกอรีแต่งตั้งเมินเตอรีเบอซาร์"** ในสี่รัฐที่ไม่มีผู้ปกครอง หัวหน้ารัฐบาลมีตำแหน่งมุขมนตรี ไม่ใช่เมินเตอรีเบอซาร์ ตำแหน่งเมินเตอรีเบอซาร์ใช้ในรัฐที่มีผู้ปกครอง

## หมายเหตุเกี่ยวกับขอบเขต

บทความนี้อธิบายโครงสร้างทางรัฐธรรมนูญและชื่อเรียกทางการเท่านั้น ไม่ได้ทำการประเมินทางการเมืองใด ๆ ไม่ได้แตะต้องผู้ดำรงตำแหน่งปัจจุบันคนใด และไม่ได้แสดงความเห็นต่อข้อพิพาทด้านการตีความที่กำลังดำเนินอยู่ สำหรับผู้ดำรงตำแหน่งปัจจุบัน โปรดอ้างอิงพอร์ทัลทางการของรัฐบาลรัฐหรือเว็บไซต์สภาผู้ปกครอง บทความนี้มีสถานะเป็นร่างและยังไม่ผ่านการทบทวนโดยมนุษย์

## อ่านต่อ

- สำหรับตัวบทจริงของมาตรา 19A ถึง 19D และมาตรา 3(3), 71, 160(2) และ 181 โปรดอ้างอิง [รัฐธรรมนูญแห่งสหพันธรัฐ](/law/federal-constitution) ในฉบับพิมพ์ซ้ำทางการของ AGC
- เพื่อเข้าใจว่ายังดีเปอร์ตวนอากงถูกเลือกจากในบรรดาผู้ปกครองเก้าพระองค์อย่างไร ดู [ยังดีเปอร์ตวนอากง](/glossary/yang-di-pertuan-agong)
- สำหรับตัวอย่างรัฐที่ไม่มีผู้ปกครองโดยละเอียด ดู [มะละกา](/states/melaka) และ [ปีนัง](/states/penang)
- สำหรับแบบจำลองประมุขของรัฐที่มีผู้ปกครองซึ่งถูกเลือกและไม่ได้สืบทอดโดยตรง ดู [เนอเกอรีเซิมบีลัน](/states/negeri-sembilan)
