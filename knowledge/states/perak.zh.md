1874年1月20日，一份条约在邦咯岛（Pangkor Island）附近海域签署。这份文件既未割让领土，也未宣战。它只引入了一个新的职位：一位参政司，其意见必须遵从。

正是从这一条条款开始，马来亚的政府架构发生了改变——而霹雳，正是第一个经历这一切的州属。

## 条约之前：拉律的锡矿

霹雳苏丹国始于1528年的苏丹 Muzaffar Syah 一世，根据州政府官方网站，他是马六甲苏丹马末沙（Sultan Mahmud Syah）的后裔——与1511年陷落的[马六甲苏丹国](/zh/malaysia/melaka-sultanate)有直接的世系联系。

此后三个世纪，霹雳一直是位于霹雳河畔的一个马来州属，与西海岸其他州属并无二致。

真正改变局面的是矿产。州政府官方网站记载，霹雳「在其土地的富饶被发现后才广为人知，即1848年 Cik Long Jaafar 在拉律发现锡矿之后」。

锡矿把这个州属的经济，从农业与河运贸易，转变为大规模的矿业开采。它吸引了资本、劳动力，并最终——引来了外部势力的关注。

## 1874年1月20日缔结的内容

邦咯条约由英方与霹雳的马来贵族缔结。霹雳州政府官方网站指出，该条约的缔结「确立了英国在霹雳的权力」。

最具决定性的条款，是关于参政司这一职位。州政府官方网站是这样概括的：苏丹将接受一位英国参政司，其意见**「必须在一切事务上征询并遵从，唯独涉及马来人的宗教与风俗的事项除外」**。

留意这项设计的三个特点：

1. **它并未废除苏丹国体制。** 苏丹仍是州属元首；改变的是谁在行政事务上给出具有约束力的意见。
2. **它划定了权限的界线。** 马来人的宗教与习俗被明确排除在参政司的意见范围之外——这项区分的形态，延续到了后来的宪政安排之中。
3. **它是透过意见来运作，而非直接管治。** 名义上，治理权仍握在苏丹手中；实际上，行政权力已转移到那个意见必须被遵从的一方。

霹雳州议会官方网站用一句话概括了这一变化：在英国以间接方式干预马来各州、委任一位英国参政司来向苏丹提供意见之后，苏丹与马来贵族之间的传统统治体制发生了改变。

## 邦咯条约之后：Birch、1875年与1877年的会议

霹雳首位英国参政司是 J.W.W. Birch。州政府官方网站记载，他被委任为首任参政司，并于1875年遇害身亡——距条约缔结仅一年。

条约签订三年后，新的政府架构开始具备制度形态。霹雳州议会官方网站记载，首届霹雳州务会议于**1877年9月10日**在江沙的英国参政司官邸召开。

首次会议的组成，透露了当时权力布局的许多信息：

| 职位 | 人物 |
| --- | --- |
| 主席 | Raja Muda Yusuf |
| 英国参政司 | Sir Hugh Low |
| 议员 | Raja Idris |
| 议员 | Speedy 上尉 |
| 议员 | Orang Kaya Temenggung |
| 甲必丹（Kapitan Cina） | Chung Ah Kwee |
| 甲必丹 | Ching Ah Yam |

会议事务以马来语进行，并以爪夷文（Jawi）记录，会议记录则翻译成英文。每项议案都经过辩论与表决，才能成为法律。

这正是霹雳州议会指出马来西亚宪政史可说是始于1874年邦咯条约的原因，该条约通过1877年成立的霹雳州务会议得以落实。这一制度的传承一直延续到今日的霹雳州议会，该议会共有59个州议员选区，编号从N.01至N.59。

## 怡保与近打河谷

如果说拉律是第一个锡矿场，那么近打河谷就是造就一座城市的矿场。

怡保市政局记载，1884年开始修建一条道路，将 Gopeng 村与其位于 Kota Bharu 的港口连接起来，并进一步延伸到 Papan 与 Batu Gajah 等矿区。1895年，怡保成为霹雳州最大的市镇，也是马来联邦（Federated Malay States）中第二大的市镇。1905年至1914年间，市区范围扩展到近打河（Sungai Kinta）对岸——即今日所称的怡保新市区（Ipoh New Town）。

然而，首府地位是通过一场战争事件而来的。霹雳州议会官方网站记载，1942年日军攻占霹雳后，州行政中心从太平（Taiping）迁至怡保。

其行政地位则是后来才确立的。怡保于1962年5月31日成为怡保市议会（Majlis Perbandaran Ipoh），并于**1988年5月27日**由霹雳苏丹颁布怡保为市，即霹雳达鲁益尊的首府。

江沙（Kuala Kangsar）则仍然是皇家仪式的中心。当地的依斯干达里亚皇宫（Istana Iskandariah）是第35任霹雳苏丹 Sultan Nazrin Muizzuddin Shah ibni Almarhum Sultan Azlan Muhibbuddin Shah Al-Maghfur-Lah 登基仪式的举行地点，仪式于2015年5月6日举行，随后于2015年5月7日举行 Istiadat Tabal Pusaka 与 Istiadat Bersiram Tabal 仪式。

## 今日霹雳：官方数据

大马统计局估计，霹雳2025年（初步数据）人口为**2,574.9千人**，相较于2024年的2,569.4千人。其中，2,415.4千人为公民。

| 指标（2025年，初步数据） | 霹雳 |
| --- | --- |
| 人口总数 | 2,574.9千人 |
| 人口密度 | 每平方公里122人 |
| 年龄中位数 | 32.1岁 |
| 65岁及以上人口 | 10.3% |
| 家庭户数 | 730.4千户 |
| 平均家庭户规模 | 3.5人 |

2025年（初步数据）公民种族构成：土著62.4%（马来人59.2%，其他土著3.2%），华人26.0%，印度人11.2%，其他0.4%。

有一个数字值得关注：霹雳有10.3%的人口年龄在65岁及以上，高于2020年的8.9%。这是半岛地区最成熟（老龄化程度最高）的年龄结构之一。

在经济方面，大马统计局报告指出，霹雳经济在**2025年增长5.7%**，超过全国5.2%的增长率，也是该州十多年来最强劲的增长。主要推动力来自[制造业](/zh/economy/manufacturing)，增长15.2%，尤其是运输设备与其他制造业，随着该州汽车制造活动的扩张而飙升162.9%。服务业则增长3.4%。

霹雳2025年人均GDP为RM41,960（2024年：RM39,057），相较于全国平均的RM59,167。

在行政方面，霹雳州议会官方议事录记载，该州共有12个县。

## 比任何苏丹国都古老：冷岳河谷

在霹雳的最北端，人类活动的记录远比1528年更为久远。

国家文物局（Jabatan Warisan Negara）记载，冷岳河谷考古遗产于**2012年6月30日**在俄罗斯圣彼得堡举行的第36届世界遗产委员会会议上，被列为UNESCO世界遗产地。该遗址面积达398.64公顷。

该遗址包括露天地点与洞穴，涵盖从旧石器时代、新石器时代到金属时代的文化序列，年代介于183万年前至1,000年前之间。

最广为人知的发现，是来自 Gua Gunung Runtuh 岩洞的**霹雳人（Perak Man）**——东南亚发现的最完整、最古老的史前人类骨骸，年代约为10,000年前，也是世界上唯一一具天生患有A2型 Brachymesophalangia（先天性短中间指／趾骨畸形）缺陷的史前骨骸。而1987年发现的 Kota Tampan，年代则约为74,000年前。

## 常见误解

**「邦咯条约使霹雳成为殖民地。」** 就形式而言并不准确。该条约保留了苏丹国体制，并引入一位参政司，其意见在行政事务上具有约束力，唯独马来人的宗教与习俗被排除在外。直接管治与透过意见来统治之间的区别，正是霹雳有别于[槟城](/zh/states/penang)等海峡殖民地（这些殖民地是被直接管治的）之处。

**「怡保一直都是霹雳的首府。」** 不对。霹雳州议会官方网站记载，州行政中心是在1942年日据时期从太平迁至怡保的。怡保直到1988年才被宣布为市。

**「霹雳苏丹的角色与最高元首相同。」** 这是两个不同的职位。霹雳苏丹是霹雳州的元首；[最高元首（Yang di-Pertuan Agong）](/zh/government/yang-di-pertuan-agong)则是根据联邦宪法担任联邦最高国家元首，由统治者会议（Majlis Raja-Raja）选出。

**「锡矿只是陈年往事。」** 锡矿的遗产至今仍塑造着霹雳城镇的地理格局——但该州2025年的经济结构是由制造业（包括汽车业以及电子电气业）驱动的，而非矿业。

## 下一步

如果你想继续追踪邦咯条约带来的影响，两篇最有用的延伸阅读是[马六甲苏丹国](/zh/malaysia/melaka-sultanate)，可了解霹雳苏丹国世系的起源，以及[1957年独立](/zh/malaysia/independence-1957)，可了解参政司与联邦体制最终如何走向终结。

若要了解走过不同殖民路径的邻近州属之脉络，可比较[槟城](/zh/states/penang)——一个被直接管治的海峡殖民地——以及[雪兰莪](/zh/states/selangor)，该州是在霹雳之后才接受英国参政司的。

如需最新数据，请查阅大马统计局最新发布的州属人口估计与GDP数据，因为两者都是每年更新的。
