马来西亚的经济故事通常围绕工厂展开。吉兰丹是最鲜明的例外：2025年，制造业仅
占该州GDP的4.7%——在13个州属中比重最低——而农业的贡献接近五分之一。

该数据来自统计局（Jabatan Perangkaan Malaysia，DOSM）按州分列的GDP数据集，
也说明了这个州许多其他方面：人口分布、就业模式，以及为什么其工艺与表演传统
仍然依附于家庭网络，而非大规模产业。

## 重点资料

| | |
| --- | --- |
| 州首府 | 哥打巴鲁（Kota Bharu） |
| 州名尊称 | Kelantan Darul Naim |
| 面积 | 约15,040平方公里 |
| 人口（2025年） | 约191万 |
| 州元首 | 吉兰丹苏丹 |
| 行政区划 | 10个县及1个小县（Lojing） |
| GDP（2025年） | RM29.8 billion，2015年不变价格 |
| 最大产业 | 服务业（71.8%）、农业（19.8%） |

## 地理与行政

吉兰丹位于马来半岛东北部，北接泰国，东北面朝南中国海，根据国家安全理事会
（Majlis Keselamatan Negara，MKN）资料，面积约为15,040平方公里。

该州名称的由来有两种常见说法——一是与「闪电」一词有关，二是与格兰木
（*Melaleuca leucadendron*）林有关。州属格言为「Berserah Kepada Tuhan」
（意为「顺从真主」）。

州行政划分为十个县（jajahan）：哥打巴鲁（Kota Bharu）、Bachok、Pasir Mas、
Pasir Puteh、Tumpat、Tanah Merah、Machang、Kuala Krai、Gua Musang与Jeli——
加上小县（jajahan kecil）Lojing。DOSM的县级人口数据将这十一个单位分别列出。

人口分布极不均衡。2025年，哥打巴鲁县居住约590,100人，其次是Pasir Mas
（242,700人）与Tumpat（191,200人），而Jeli（58,200人）与Lojing（11,700人）
则处于另一端——这与人口稠密的沿海平原和多丘陵的内陆地区之间的差异相符。

## 哥打巴鲁

哥打巴鲁（Kota Bharu）是州首府，根据其地方政府的说法，也是全州行政、商业、
金融、文化与教育的主要中心。

市区行政范围涵盖115.64平方公里。皇家聚落于1844年在此建立；1936年获得市镇
地位，1971年重组为市镇局，现行的市议会地位则于1978年授予。地方政府正式名
称为哥打巴鲁伊斯兰市市议会（Majlis Perbandaran Kota Bharu Bandar Raya
Islam，MPKB-BRI）。

## 经济结构

以2015年不变价格计算，吉兰丹2025年GDP为RM29.8 billion，较2024年的RM28.6
billion增长4.1%。

| 行业 | 占州GDP比重（2025年） |
| --- | --- |
| 服务业 | 71.8% |
| 农业 | 19.8% |
| 制造业 | 4.7% |
| 建筑业 | 2.0% |
| 采矿与采石业 | 1.5% |

该表中有两个数字与其他州属相比显得特别突出。19.8%的农业比重是马来西亚仅
次于彭亨（22.4%）的第二高比重，远高于工业化州属的平均水平。而4.7%的制造
业比重则是13个州属中最低的——相比之下，槟城为47.3%，[柔佛](/zh/states/johor)
为28.0%。

这一结构也反映在住户数据中。2024年，吉兰丹的住户月收入中位数为RM4,083
（平均数为RM5,265），是该调查年度各州属与联邦直辖区中最低的数字。

有关这些数字如何计算与比较的全国背景，见[马来西亚GDP概览](/zh/economy/gdp-overview)。

## 文化、表演与手工艺

政府资料一致将吉兰丹与一组传统工艺及表演形式联系在一起：月亮风筝（wau
bulan）、[皮影戏](/zh/arts-culture/wayang-kulit)、木雕、银器工艺、
[峇迪](/zh/arts-culture/batik)与songket织造。

**玛蓉剧（mak yong）**拥有其中最正式的国际认可。联合国教科文组织（UNESCO）
于2008年将其列入人类非物质文化遗产代表作名录，此前已于2005年宣布，并将其
描述为源自吉兰丹乡村的传统。UNESCO还指出，这一表演形式主要以口传方式传承，
且面临年轻传承者数量减少的困境。

这个州的地理位置也塑造了它的物质文化。与泰国接壤，影响了当地的方言、饮食
与服饰——这一特点在政府宣传资料中被直接提及。

这里的手工艺仍然是以作坊与家庭为基础的活动，而非工厂生产。这也是它们在统
计数据中被归入贸易与旅游——见[马来西亚旅游业](/zh/economy/tourism)——而非
制造业的其中一个原因。

## 州机构

州元首是吉兰丹苏丹，是出席统治者会议（Majlis Raja-Raja）的马来统治者之一。
根据统治者御玺守护官署（Pejabat Penyimpan Mohor Besar Raja-Raja）资料，现
任苏丹为苏丹穆罕默德五世殿下（Kebawah Duli Yang Maha Mulia Sultan Muhammad
V），于2010年9月13日登基。

日常行政权力由州政府行使，州政府以州务大臣（Menteri Besar）为首，并由州行
政议会（Majlis Mesyuarat Kerajaan）成员协助，州立法议会（Dewan Undangan
Negeri）为州立法机关。土地行政与县务由每个县的土地与县务局（Pejabat Tanah
dan Jajahan）处理。吉兰丹在联邦国会也设有代表——见
[马来西亚国会的架构](/zh/government/parliament)。

## 常见误解

**「吉兰丹没有悠久的城市历史。」** 这一带是马来半岛最古老的有人居住地区之
一，其周边的考古遗址与[狼牙修](/zh/malaysia/langkasuka)等早期政治网络有关。

**「哥打巴鲁的人口就是市区人口。」** 两个不同的数字经常被混淆：115.64平方
公里的MPKB-BRI行政区，以及范围大得多、2025年人口约590,100人的哥打巴鲁县。

**「该州经济纯粹是农业。」** 按马来西亚标准，农业确实庞大，但服务业仍占州
经济的71.8%，超过三分之二。

**「州GDP数字可以直接与名义数字比较。」** 此处使用的州属数据系列是以2015
年不变价格计算。直接与名义值比较会给出错误的印象。
