# Understand Malaysia — content plan

Research-backed article map for the **Understand Malaysia** section.
Current state: **26 articles** across 7 categories (thin — most topics are a single
stub). This plan proposes **~200 articles** to make the section genuinely complete.

Every article must go through the mandatory pipeline in
`memory/negaraku-article-standard.md` — SERP recon FIRST, official sources only,
claim-to-source mapping, honest trust badge. **Nothing here is pre-approved to
publish**: tier-S items are a hard governance gate.

## Legend

| Field | Meaning |
| --- | --- |
| **Tier** | 1 authoritative guide · 2 standard · 3 direct answer · 4 entity/data · **S sensitive (3R+1)** |
| **Sens** | `none`, or race / religion / royalty / constitution / elections / security |
| **Master** | Authoritative origin language for the topic (per-article, per `MASTER-LANGUAGE.md`) |
| **P** | Priority — P1 core (a reader is lost without it) · P2 depth · P3 long tail |
| **✓** | Already exists |

### Governance summary

Of the ~200 proposed, roughly **70 are tier S** (race, religion, royalty,
constitution, elections, security). Per the standard I **cannot mark those
reviewed or published** — they ship as `status: draft`, `reviewer: null`, and need
a named human reviewer before they go live. That is not a limitation to work
around; it is the product's core promise.

## Proposed build order

| Phase | Content | Count | Publishable by AI? |
| --- | --- | --- | --- |
| **1** | The 11 missing state profiles + Sabah/Labuan | ~13 | Mixed — most touch royalty → S |
| **2** | Government institutions + agencies (entity pages) | ~25 | Agencies yes; institutions S |
| **3** | Economy indicators + sectors (data pages) | ~20 | **Yes — tier 4, none** |
| **4** | Glossary expansion | ~30 | **Yes — mostly tier 4** |
| **5** | History: colonial → modern | ~25 | Largely S |
| **6** | Law: constitutional + legal system | ~20 | Largely S |
| **7** | Arts, culture, festivals, languages | ~32 | Festivals/languages largely S |

**Recommended start: Phase 3 + 4** — highest volume of genuinely publishable,
non-sensitive, high-search-demand pages, and they need no governance gate. Phase 1
is the most *visible* gap but roughly two-thirds of it carries royalty sensitivity.
