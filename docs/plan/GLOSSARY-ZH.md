# Chinese glossary — shared memory for translators

Same role as `VERIFIED-SOURCES.md`, for terminology instead of facts. Every translator
reads this first and **appends** to it. Consistency across 312 articles is impossible if
each translator invents its own rendering of "company secretary".

**Malaysian Simplified Chinese.** Where Malaysian usage differs from mainland or Taiwanese
convention, Malaysian wins.

## Rule

If a term is already here, **use it exactly**. If it is not, decide, use it consistently,
and add a row — with a note on why, if the choice was not obvious.

## House style set by the pilot batch

These are decisions the spec does not cover. Follow them — they are why the corpus will read as one voice.

1. **Schedules are references, not prose.** `Third Schedule`, `First Schedule`, `Schedule 1 Part I paragraph 2B(d)`, `Schedule Part I item 94` stay English, like section refs. Gloss the *first* one in an article — `Third Schedule（第三附表）` — then use it bare.
2. **Internal site links get the `/zh/` prefix.** The masters link to `/en/...`; a Chinese page must link to `/zh/...`. Every route falls back to the master when a translation is missing, so this is always safe. **Link text is translated; the path is rewritten, never the slug.**
3. **Percentages stay as numerals with `%`.** Do not write 巴仙 even though Malaysian speech does. Where the master spells a figure in words for emphasis ("Twenty per cent is a low bar"), render the emphasis in Chinese but keep the numeral: **20% 是很低的门槛**.
4. **Money keeps its English magnitude words.** `RM2.5 million` stays `RM2.5 million` — never 250万. This is the spec's "do not translate 万/亿 groupings" rule applied consistently. Same for `RM500,000`, `RM110,031.1m`.
5. **Frontmatter fields the spec's table omits.** Translate `seoTitle`, `socialTitle` and `appliesTo` — all three render to readers. Copy `keywords` and `entity` unchanged — they are identifiers/search tokens, and the masters already mix Malay into `keywords`.
6. **`obligations[].what` is translated; `due`, `trigger`, `authority`, `statute` and `consequence` copy unchanged.** `consequence` is a citation-dense penalty recital and behaves like the English audit trail in `revisions[].change`.
7. **Quotation marks.** Use 「」 in frontmatter (a raw `"` breaks the YAML) and in body prose. Reserve `"` for text that is literally quoted from an English source, e.g. MDEC's `will go live on 27 April 2026`.
8. **Em-dash asides.** The masters lean hard on `—`. Render as `——` (full-width double), not `-` or `–`.
9. **Hedged/negative findings must not be flattened.** Articles like digital-free-trade-zone are built on the difference between "not found", "not confirmed" and "does not exist". 找不到 ≠ 无法证实 ≠ 并不存在. Do not smooth these into 没有.
