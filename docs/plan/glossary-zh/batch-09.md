## Coined / decided here

| English | Chinese | Notes |
| --- | --- | --- |
| business name registration (BNR, Sarawak Cap. 64) | 商号名称注册 | Sarawak's Cap. 64 instrument. Built on the glossary's `enterprise` ruling — 商号 keeps it distinct from 公司名称 (a company name under CA 2016) and from 营业执照 |
| trade licence (TL, Sarawak Cap. 33) | 贸易执照 | Deliberately not 营业执照 — the glossary already assigns 营业执照 to `business licence`, and in Sarawak TL and OL are two different instruments that stack |
| operating licence (OL, council by-law) | 营运执照 | The council layer. Kept distinct from 贸易执照 because the whole Sarawak article turns on the two not being the same thing |
| Registrar (of Business Names) | 注册官 | Same rendering used for the CA 2016 Registrar; the Sarawak office is a different person under the same word in English |
| Collector (Cap. 33) | Collector | Left in English. It is a defined statutory office ("Collector means the Director of Inland Revenue"), and 征收官 would read as a generic tax collector and lose the definitional joke the article is built on. Deputy Collector likewise |
| District Officer | 县长 | Malaysian Chinese press usage for Pegawai Daerah |
| Kanowit / Sibu Rural District Council | 加拿逸／诗巫乡区县议会 | Standard Malaysian Chinese place names |
| compliance officer (LLP Act 2012 s.27) | 合规主任 | Rejected 合规官 (mainland-flavoured) and 合规人员 (too soft for a statutory office carrying personal liability). The article's whole argument is that it is an *office*, not a service |
| annual declaration (LLP s.68) | 常年申报 | Parallel to the glossary's 常年申报表 for `annual return`, but deliberately without 表 — the LLP instrument is a solvency declaration, not a return |
| declaration of solvency | 偿付能力申报／偿付能力声明 | 申报 where it is the lodged LLP instrument (s.68), 声明 where it is the CA 2016 statement in a conversion |
| nominee director | 挂名董事 | Malaysian Chinese press usage. Rejected 名义董事 (reads as "titular", losing the commercial arrangement) and 代持董事 (that is nominee *shareholder*) |
| reverse onus | 举证责任倒置 | Appears three times across resident-director-malaysia; needed a fixed rendering |
| D&O insurance | 董事及高级职员责任保险 | Then 董事责任险 in running prose. No settled Malaysian short form |
| indemnity (s.288/s.289) | 弥偿 | Malaysian legal usage (弥偿保证), not mainland 赔偿 — the distinction from damages matters in this article |
| officer (of a company) | 高级职员 | The Act's "officer". Kept distinct from 董事 and from 雇员 |
| ordinarily resides / principal place of residence | 通常居住／主要居住地 | s.196(4)(a). The two must stay distinct because the section uses one to define the other |
| alternate or substitute director | 替任或代任董事 | s.196(4)(b) |
| lodge (a document with the Registrar) | 呈报 | Distinct from 提交 (submit) and 存档. Used consistently for CA 2016 "lodge" |
| circulate (financial statements, s.258) | 传阅 | The s.258 step, deliberately distinct from 呈报 (s.259) — the article's point is that the two clocks chain |
| return of allotment | 配发申报表 | s.78(1) |
| statement in lieu of prospectus | 代替招股章程的陈述书 | s.42(5)(c) |
| strike-off | 除名 | Distinct from the glossary's 除牌 (delisting from an exchange) |
| basis period (first) | 第一个基期 | Uses the glossary's 基期 |
| stub period | 残期 | For a short first financial period |
| Thirteenth Schedule / First Schedule etc. | left English | Per house-style rule 1; glossed once on first use (e.g. 第十三附表) |
| local agent (foreign company, s.563) | 本地代理人 | |
| take-or-pay (PPA) | 照付不议 | Standard energy-contract term |
| power purchase agreement | 购电协议 | |
| growth node (SCORE) | 增长节点 | |
| Mixed Zone Land / Native Area Land / Native Customary Land / Interior Area Land / Reserved Land | 混合区地／土著地区地／土著习俗地／内陆地区地／保留地 | Sarawak Land Code s.2 five classes. Malaysian Chinese press uses 土著习俗地 for NCL; the others are built to match |
| native (of Sarawak) / non-native | 土著／非土著 | Land Code s.8 |
| State Authority (Immigration Act s.62) | 州政府当局 | Uses the glossary's existing entry; the article turns on it meaning the Chief Minister specifically |
| belongs to (a State), s.66 | 属于（该州） | Kept literal — it is a statutory term of art |
| distributive trade | 分销贸易 | KPDN's sector |
| premise licence (lesen premis) | 处所执照 | Kept distinct from 营业执照 (business licence) and 招牌执照 (signboard licence) |
| prescribed premises (EQA s.25) | 订明处所 | |

| recognised market operator | 认可市场营运者 | SC term |
| class licence (MCMC) | 类别执照 | |
| e-hailing intermediation licence | 电召车中介执照 | Malaysian Chinese press says 电召车 |
| air operator certificate | 航空营运人证书 | |
| certificate of completion and compliance (CCC) | 竣工与合规证书 | |
| Board of Valuers, Appraisers, Estate Agents and Property Managers | 估价师、估值师、房地产经纪与产业管理师局 | Long, but the Act's own enumeration; the article's point is that "and Property Managers" was added by Act A1550 |
