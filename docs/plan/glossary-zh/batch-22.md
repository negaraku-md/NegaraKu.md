| English | Chinese | Notes |
| --- | --- | --- |
| Stamp Duty Self-Assessment System (STSDS) | 印花税自评估制度（STSDS） | Then `STSDS` alone |
| self-assessment | 自评估 | Kept distinct from 自行评估 (the act) — 自评估 is the regime |
| formal assessment | 正式评估 | The pre-STSDS model. Deliberately not 正式评税 — stamp duty is 税额厘定, not 评税 |
| adjudication | 裁定 | Stamp Act s.36 adjudication. The whole STSDS article turns on 裁定 vs 自评估 |
| Collector (of Stamp Duties) | 征收官 | LHDN's Pemungut. Not 收税官 |
| instrument (chargeable document) | 文书 | Distinct from the glossary's 法律文书 (Orders/notifications). A stamp-duty instrument is a private document, not subsidiary legislation |
| stamping | 盖印花 / 加盖印花 | `late stamping` → 逾期盖印花 |
| deemed assessment (stamp duty) | 视为已作出的评估 | s.36 mechanism |
| deficient duty | 不足税额 | s.47A base |
| penalty remission programme | 罚款豁免计划 | The 2026 s.72D(3) programme |

| wilful default | 故意失责 | Paired with 疏忽 (negligence) — the master keeps them distinct and so must we |
