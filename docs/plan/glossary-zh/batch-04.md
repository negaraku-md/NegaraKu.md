# Glossary additions — batch 04 (business, 11 articles)

Terms coined or first settled while translating batch 4. Merge into `GLOSSARY-ZH.md`.

## Coined / first settled

| English | Chinese | Notes |
| --- | --- | --- |
| striking off (a company) | 除名 | close-a-company. Matches the glossary's existing `delisting → 除牌` ruling that Malaysian usage prefers short verbal forms. Rejected 注销 (that reads as dissolution) |
| winding up | 清盘 | Standard Malaysian Chinese press term. Never 清算 (that is liquidation of assets, a step inside it) |
| members' / creditors' voluntary winding up | 成员自愿清盘／债权人自愿清盘 | Built on the glossary's `member → 成员` ruling. s.443/s.444 pair |
| declaration of solvency | 偿债能力声明 | s.443 |
| corporate rescue | 企业拯救 | Act 777 Division heading. Rejected 公司拯救 — the Act's Malay/English usage is corporate-level |
| judicial management | 司法管理 | s.405 |
| scheme of arrangement | 债务重整方案 | Glossed for readability; 安排方案 is a calque nobody uses |
| corporate voluntary arrangement | 企业自愿安排 | Kept parallel with 企业拯救 |
| undue preference | 不当优惠 | s.528 |
| reinstatement (of a struck-off company) | 复原 | s.555 |
| business judgment rule | 商业判断规则 | s.214. Settled term in Chinese-language corporate law writing |
| nominee director | 代名董事 | s.217. Malaysian Chinese press usage; rejected mainland 名义董事 |
| ordinarily resident | 通常居住 | s.196(4). The whole article turns on this being a residence not a nationality test |
| alternate / substitute director | 替代董事／代任董事 | s.196(4)(b) — master keeps the two distinct, so the translation must too |
| disqualification (of a director) | 取消资格 | Consistent with the glossary's existing `disqualifier → 取消资格条件` |
| undischarged bankrupt | 未获解除破产令的破产人 | s.198(1) |
| pre-emption (on new share issues) | 优先认购权 | s.85. Distinguished from 优先购买权 which this file uses for pre-emption *on transfer* |
| shareholders agreement | 股东协议 | company-constitution-malaysia |
| tag-along / drag-along | 随售权／强售权 | Standard in Malaysian/HK deal Chinese |
| ring-fencing | 风险隔离 | branch-vs-subsidiary. Rejected literal 围栏 |
| local agent (of a foreign company) | 本地代理人 | s.563 |
| representative office / regional office | 代表处／区域办事处 | MIDA RE/RO |
| principal customs area (PCA) | 主要关税区（PCA） | Free Zones Act / Customs Act. Then `PCA` alone |
| special area (Sales Tax Act 2018 s.2) | 特别区域 | Deliberately NOT 特区 — that collides with 特别经济区 (SEZ) |
| licensed manufacturing warehouse (LMW) | 持牌制造仓库（LMW） | Gloss once, then `LMW` bare — the acronym is a scheme name under the spec |
| deeming provision | 视为条文 | bayan-lepas. The article turns on what is deemed to be where |
| anti-dumping duty | 反倾销税 | Settled term |
| countervailing duty | 反补贴税 | Settled term |
| dumping margin | 倾销幅度 | |
| material injury | 实质损害 | ss.22A/7A |
| standing (test, to petition) | 申诉资格 | reg 7(2). Rejected 诉讼资格 — this is administrative, not litigation |
| provisional / definitive duty | 临时税／确定税 | s.24/s.25 pair; must stay distinct |
| expiry review / administrative review / refund review / expedited review | 届满复审／行政复审／退税复审／加速复审 | ss.28, 28A, 28B — four distinct reviews, kept parallel |
| facts available | 可得事实 | s.41, WTO term of art |
| anti-circumvention | 反规避 | s.37 |
| safeguard (measure) | 保障措施 | Act 657. Never 保障税 — it is a measure, not always a duty |
| average base tariff | 平均基本电费 | business-costs-by-region. 电费 not 关税 — 关税 is customs duty and both appear in this batch |
| peak / off-peak | 高峰／非高峰 | Sarawak Energy schedule |
| statutory add-on (employer cost) | 法定附加成本 | Built on the glossary's `statutory contribution → 法定缴纳金` |
| by-laws (local council) | 附例 | Act 171 s.102. Malaysian usage; not 细则 |
| State Authority | 州政府当局 | Already in glossary — used unchanged |
| Concurrent List / Federal List / State List | 共同清单／联邦清单／州清单 | Ninth Schedule. `List I`/`List II`/`List III`/`List IIIA` and item numbers stay English |
| composite licence | 复合执照 | s.107(1A) |
| designated premises (fire) | 指定场所 | Act 341 s.28(1) |
| distributive trade approval (WRT) | 分销贸易批准 | `WRT` stays English |
| corridor (economic) | 走廊 | Standard Malaysian Chinese press term for NCER/ECER/SCORE etc. |
| paid-up capital threshold (ESD) | 实缴资本门槛 | Uses the glossary's existing 实缴资本 |
