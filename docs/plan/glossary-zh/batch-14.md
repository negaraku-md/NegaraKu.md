# Batch 14 — coined terms (company-secretary: statutory registers, unaudited FS, beneficial owner, written resolutions)

| English | Chinese | Notes |
| --- | --- | --- |
| register of members | 成员登记册 | Built on GLOSSARY's `member = 成员` / `statutory registers = 法定登记册` rulings. Deliberately not 股东名册 — the Act counts *members* |
| index of members | 成员索引 | s.52(1). Rejected 成员索引册 — the Act calls it an index, not a register |
| register of directors, managers and secretaries | 董事、经理与秘书登记册 | s.57(1), literal and unambiguous |
| register of directors' shareholdings | 董事持股登记册 | s.59(1) |
| register of charges | 押记登记册 | 押记 is the settled Malaysian/HK rendering of *charge* as a security interest. Rejected 抵押 (that is *mortgage*) and 留置 (*lien*) |
| charge instrument | 押记文书 | Follows GLOSSARY `instrument = 法律文书`, shortened in-context |
| beneficial owner | 实益拥有人 | SSM's own Chinese-language usage and Malaysian press usage. Rejected mainland 受益所有人 |
| beneficial ownership | 实益拥有权 | Same family; the abstract noun |
| ultimate effective control | 最终有效控制 | Tracks the Guidelines' phrasing literally; the whole s.60A test turns on it |
| nominee (shareholder) | 代名人 | Malaysian usage. Rejected 名义股东 — the Act's exclusion covers "a nominee of any description", broader than a shareholder |
| effective interest | 实际权益 | The chain-multiplication concept. Rejected 有效权益 (reads as "valid"), 实益权益 (collides with 实益拥有人) |
| Criteria A–F | 标准 A–F | The master uses "Criteria" as a singular for each lettered test; 标准 is number-neutral in Chinese so the master's grammatical quirk does not have to be reproduced or corrected |
| senior management (BO fallback) | 高级管理层 | |
| registered office | 注册办事处 | Already in GLOSSARY — used unchanged |
| circulate / circulation date | 传阅／传阅日 | s.299. Rejected 分发 — the Act's concept is circulating a document round the members, not distributing it |
| written resolution | 书面决议 | |
| circular resolution | 传阅决议 | Kept distinct from 书面决议 because the master's "Common mistakes" contrasts the informal practice (*circular resolution*) with the statutory instrument (*written resolution*) |
| ordinary / special resolution | 普通决议／特别决议 | |
| signify agreement | 表示同意 | s.306(1) |
| authenticated document | 经认证文件 | s.306(1). Rejected 认证文件 — the Act's adjective is on the act of authentication by the sender, not a certification by a third party |
| lapse (of a resolution) | 失效 | s.307(1) |
| requisitioning member | 提出要求的成员 | Rejected 请求成员 as too weak for a statutory requisition right |
| eligible member | 合资格成员 | s.298(1). Malaysian usage 合资格, not mainland 合格 |
| special notice | 特别通知 | ss.207, 277(3) |
| representations (by a director/auditor) | 陈述 | The right-to-be-heard sense, not 申述 |
| capital reduction | 资本削减 | s.115. Rejected 减资 as too colloquial for a statutory heading |
| statement by directors | 董事声明 | The s.251 document |
| statutory declaration | 法定声明 | The s.251 declaration |
| directors' report | 董事报告书 | Malaysian usage 报告书 |
| audit exemption certificate | 审计豁免证明书 | Malaysian usage 证明书, not 证书 |
| exempt private company (EPC) | 豁免私人公司（EPC） | s.260. `EPC` alone thereafter |
| circulate financial statements | 传阅财务报表 | Same 传阅 ruling as written resolutions — one verb across both articles |
| lodge / lodgement | 呈报 | Distinguished from 提交. Used consistently across all four files |
| approved accounting standards | 获批准的会计准则 | s.244(1). MASB's own framing |
| Appendix 1 | Appendix 1（附录一） | Treated like `Third Schedule` under house rule 1 — reference, glossed once, then bare |
| Division 8A | Division 8A | Reference, not prose — same treatment as Schedules/Parts |
| officer (of a company) | 高职人员 | Malaysian usage; s.68(3) "particulars of officers" |
