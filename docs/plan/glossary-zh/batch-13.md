# Batch 13 — coined terms (company-secretary, 14 articles)

Terms decided by this translator that are not in `GLOSSARY-ZH.md`. Malaysian
Simplified Chinese. Flagged for a native reviewer.

## Registers, records and the registered office

| English | Chinese | Notes |
| --- | --- | --- |
| Registrar (of Companies) | 注册官 | The office, not SSM the body. Kept distinct from 大马公司委员会（SSM）, which the glossary already fixes |
| minutes / minute book | 会议记录／会议记录簿 | Rejected 会议纪要 (mainland office register) — 记录 is what Malaysian secretarial practice writes |
| accounting records | 会计记录 | Not 会计账簿; s.245 covers records wider than books |
| officer (of a company) | 高职人员 | Malaysian statutory usage for *officer* under Act 777. Rejected 管理人员 (too HR) and 高级职员 |
| beneficial owner / BO register | 实益拥有人／实益拥有人登记册 | Matches SSM's own Chinese-language e-BOS material. Rejected 受益所有人 (mainland AML usage) |
| service address | 送达地址 | s.2 definition; kept distinct from 住址 (residential address), which the s.57 article turns on |
| identification (s.57(7)) | 身份识别 | The Act's defined term covering NRIC *or* passport particulars — deliberately broader than 身份证号码 |
| alternate / substitute / local director | 替代董事／代任董事／本地董事 | Three separate limbs of the s.57(7) definition; kept three separate renderings |
| index of members (s.52) | 成员索引 | |
| prima facie evidence | 表面证据 | |
| conclusive evidence | 决定性证据 | Kept distinct from 表面证据 — s.357(3) vs s.50(3) is an argument in the charges article |
| certified true copy | 经核证真实副本 | |
| corporate profile (SSM product) | 公司资料档 | SSM's searchable company profile. Rejected 公司简介 (marketing sense) |
| practising certificate | 执业证书 | |
| compound (SSM) | 复合罚款 | Malaysian usage; the noun SSM issues in lieu of prosecution. Kept alongside 罚款 (fine) |
| strike off | 除名 | s.549. Distinct from the glossary's 除牌 (delisting from an exchange) |
