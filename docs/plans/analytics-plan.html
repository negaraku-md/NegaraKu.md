How we'll measure reach for NegaraKu.md

Every discovery channel — Google, AI assistants, Facebook, and anywhere an article gets shared — measured in the same four layers, funnelled into one self-owned dashboard grouped by pillar → category → article.

  • L1CrawlA bot fetches the page. The precondition for ever being shown.
  • L2Impression / reachShown to a human — no click yet. Lives platform-side only.
  • L3Click / referralA human lands on the site. Read from the referrer / UTM, our side.
  • L4On-site behaviourWhat they do after arriving — views, time on page, scroll.

Build roadmap ordered by leverage

One change — the referrer classifier — fills the entire Click column for every channel at once, so it goes first. Everything else layers on top.

  1. Unified referrer / channel classifier

    Extend the edge Worker to read each human visit's referrer and tag its channel — search · AI · Facebook · other social · messaging · direct — with any unknown source kept as its bare domain, so a share to a brand-new place shows up on its own. Store the channel alongside the existing bucket/bot in Analytics Engine; add a "Traffic by channel" dashboard panel like the AI one.

    covers: whole Click columnCloudflare Workerseparate wrangler deploy

  2. UTM tagging on shared links

    The Facebook poster (and a convention for future shares) appends utm_source/utm_medium, so a click stays attributable even when the app strips the referrer. Canonical tags already protect SEO.

    rescues: messaging + in-app clicksPages

  3. Analytics archive — own every source's history

    One scheduled job that commits a permanent snapshot of every source: the Cloudflare edge tail (already running), plus a Search Console pull (impressions / clicks / queries, tagged by pillar & category) and a Facebook Insights pull (reach / impressions / link-clicks per Page, per language). This is the single move that defeats all the retention limits at once — the 90-day, the 16-month, Facebook's window — so nothing measurable ever expires.

    fills: Google + Facebook Impressionkills: every retention limitCI + committed snapshot

  4. Bing Webmaster Tools

    Set up the property — it doubles as partial AI-search coverage, since Copilot and ChatGPT-search draw on Bing's index.

    fills: Bing / Copilot Impressionexternal setup

  5. On-site engagement beacon

    A tiny cookieless beacon on page-unload sends time-on-page and max scroll depth to the Worker, grouped by article. The whole L4 column, self-owned.

    fills: whole On-site columnWorker + client

  6. AI citation probe — experimental

    The only shot at the "AI impression" blank: a scheduled job asks fixed target questions against the Perplexity API (which returns its sources) and logs whether NegaraKu.md was cited. Best-effort, not a true impression count.

    chips at: AI Impression gapCI · optional

Already standing & every limit handled

Already live

  • Edge classifier — every hit sorted into readers / search / AI + the specific bot, per article, all-time.
  • AI-crawler panel — 18,071 fetches from 8 crawlers, by bot and by pillar (Meta-ExternalAgent is ~87%).
  • All-time page views — self-owned snapshot that survives Cloudflare's 90-day window.
  • Search Console — Google impressions, clicks, queries, position (domain property, active).
  • Cloudflare — native AI-crawler monitoring & one-click block, if any bot turns abusive.

Every limit & what we do

  • SolvedRetention — the 90-day, 16-month and Facebook windows all fall to the one archive job; owned history never expires.
  • MitigatedReferrer-less clicks — UTM on links we share keeps them attributable; the rest still fall to "direct."
  • MitigatedBot spoofing — trust Cloudflare's verified-bot signal over a raw User-Agent.
  • InherentAI citations — no source exists; a probe approximates it, and crawl + referral bracket it from both ends.
  • InherentGoogle AI Overviews — GSC won't split them; track the Google total plus an AIO-presence probe.
  • InherentCross-device journey — a deliberate cookieless trade-off, accepted.

Principles the whole thing holds to

Privacy-first
Cookieless, no consent banner, no personal data — same stance as the site.
Self-owned
Data folded into committed snapshots, so it outlives every platform's retention limit.
Performance
No heavy third-party scripts on the page; work happens at the edge and in CI.
One taxonomy
Every metric rolls up by pillar → category → article, so channels compare like-for-like.
Deploy note. Steps that touch the Cloudflare Worker go live via a separate wrangler deploy — not the GitHub Pages push — so they're a deliberate, confirmed step. Everything is committed locally and held until you say push; the standing no-auto-push rule is unchanged.
