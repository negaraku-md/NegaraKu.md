# Glossary — Tamil (Malaysian usage)

Agreed Tamil renderings for recurring NegaraKu.md terms, so translators render
them consistently. Tamil here is **Malaysian Tamil** — the terms Malaysian Tamil
media actually use for local institutions, not Indian-standard where they differ.

This file is seeded from the pilot batch and grows as translators coin terms.
Read `docs/TRANSLATION-SPEC.md` first — this glossary only settles the recurring
renderings; the spec's rules (never-translate list, first-use pattern, faithful
translation) always apply.

## Never translate — keep in the original script

Statute short titles (`Companies Act 2016`, `Akta 777`), gazette citations
(`P.U.(A) 445/2017`), section/paragraph refs (`s.7(f)`), Schedules/Parts (gloss
once, keep English), agency acronyms (SSM, LHDN, RMCD, MDEC, MIDA, MITI, DOSM,
EPF, SOCSO/PERKESO, BNM, SC, MCMC, AKPK, HRD), form/scheme names (`Form E`,
`MD Status`, `LMW`, `DMP`), URLs, and company/place names in local form
(`Sdn Bhd`, `Bursa Malaysia`, `Ipoh`, `Cyberjaya`).

## First use of an institution

Give the Tamil term, then the original English/acronym in brackets, then the
short form after: e.g. `நிறுவனங்கள் ஆணையம் (SSM)` … then `SSM`.
