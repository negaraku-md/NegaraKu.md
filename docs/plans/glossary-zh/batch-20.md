| joint assessment / separate assessment | 联合评税／个别评税 | Malaysian Chinese press usage. Rejected 合并申报/分开申报 (mainland framing); LHDN's Malay is *taksiran bersama/berasingan*, and 评税 tracks *assessment* as an act of the DG |
| election (s.45(2), s.3A, s.77C) | 选择 | Kept the plain verb. Rejected 选举 and 申请 — the statute's *election* is a unilateral irrevocable choice, not an application |
| rebate (s.6A) | 回扣 | Malaysian usage. Must stay distinct from 减免 (relief) — the whole personal-tax cluster turns on rebate-against-tax vs relief-against-income |
| adjusted loss / adjusted income | 调整后亏损／调整后收入 | Built on the glossary's 会计盈利 ruling; 调整后 not 经调整 for compactness in repeated use |
| defined aggregate income | 既定总收入 | s.44A term of art. Rejected 界定汇总收入 as opaque |
| substantially the same (shareholders) | 实质相同 | Paired with the glossary's existing 股东连续性测试 |
| dormancy carve-out / dormant | 休眠 | Reuses glossary 休眠公司. Carve-out rendered 豁除条款 in headings, 剔了出去 in prose where the master is verbal |
| permanent establishment | 常设机构 | Settled OECD/treaty term, used identically in Malaysian Chinese tax press |
| place of business (s.12(3)) | 营业场所 | Deliberately NOT 常设机构 — the article's whole argument is that the domestic s.12(4) test and the treaty PE test differ |
| dependent agent / independent agent | 非独立代理人／独立代理人 | Rejected 从属代理人 (calque). 非独立 mirrors the treaty pairing |
