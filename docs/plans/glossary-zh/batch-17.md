# Batch 17 — coined terms (employment: termination, dismissal, work passes, accommodation, hours, harassment)

| English | Chinese | Notes |
| --- | --- | --- |
| at-will employment | 随意雇佣 | Rejected 任意雇佣 and 自由雇佣. The whole article turns on Malaysia *not* having it, so the term must read as a named foreign doctrine, not a description |
| just cause or excuse | 正当理由或藉口 | The s.20 IRA 1967 term of art. Kept as a fixed two-part phrase throughout — never shortened to 正当理由 |
| termination benefits / lay-off benefits | 解雇津贴／停工津贴 | TBLB Regulations 1980. 停工 for *lay-off* (not 解雇) because reg 5(1) lay-off is work not provided, not employment ended |
| relevant date | 相关日期 | Defined term in the TBLB Regulations; kept literal so the reg 11(1) seven-day clock is traceable |
| continuous service | 连续服务年资 | |
| a day's wages / average day's wages | 一天薪金／平均一天薪金 | Built on the glossary's 薪金 (not 工资) ruling |
| payment in lieu of notice / indemnity | 代通知金／赔偿金 | 代通知金 is the Malaysian Chinese press term. The s.13(1) statutory word *indemnity* rendered 赔偿金 where the master uses it as the legal quantum |
| constructive dismissal | 推定解雇 | Malaysian practitioner usage; rejected mainland 拟制解雇 |
| summary dismissal / dismissal without notice | 即时解雇／无须通知即予解雇 | |
| due inquiry (s.14(1)) | 妥当查问 | Rejected 正当调查 — 查问 tracks the Malay *siasatan* register and keeps it distinct from *investigation* |
| domestic inquiry | 内部纪律查问 | Full form on first use; 内部查问 thereafter. Needed to stay distinct from the s.81B statutory inquiry, also 查问 |
| redundancy | 职位冗余 | Distinguished from 裁员 (retrenchment, the exercise). The master turns on the reason attaching to the position |
| retrenchment | 裁员 | Per glossary |
| mutual separation agreement | 合意分手协议 | Rejected 协议解除 (reads as unilateral). 合意 carries the consent point the Industrial Court examines |
| backwages | 欠薪 | Malaysian Industrial Court usage; rejected 追溯工资 |
| compensation in lieu of reinstatement | 代复职赔偿 | Coined. Rejected 代替复职的赔偿金 as too long for a term that recurs |
| reinstatement | 复职 | |
| mitigation (post-dismissal earnings) | 减损 | Kept the legal term; the master glosses it inline as what the employee earned after dismissal |
| contributory misconduct | 雇员本身的过失／过失行为 | No settled term. Rendered descriptively so the Second Schedule limb stays readable |
| representation (s.20) | 陈情 | Rejected 申诉 — a s.20 representation is not a grievance, and the master distinguishes it from a court claim |
| Industrial Court | 劳资法庭 | Standard Malaysian Chinese press term |
| Department / Director General for Industrial Relations | 劳资关系局／劳资关系总监 | JPPM kept as the acronym |
| Director General (of Labour) | 总监／劳工总监 | Bare 总监 inside an article whose only DG is that one |
| workman | 工人 | The IRA's word; kept distinct from 雇员 (employee, the EA's word) |
| probationer | 试用期雇员 | |
| show-cause letter | 要求解释信 | |
| spread-over (s.60A(1)) | 跨度 | Coined. `10-hour spread-over` → 一日 10 小时的跨度. Rejected 延展时间 |
| ordinary rate of pay / hourly rate of pay | 普通薪酬率／时薪率 | s.60I defined terms. Kept 薪酬率 rather than 工资率 per the 薪金 ruling |
| wage period | 薪金期 | s.19; distinct from the glossary's 薪金月份 (wage month, EPF/SOCSO) |
| rest day | 休息日 | |
| roster | 轮值表 | |
| compressed schedule | 压缩工时安排 | Proviso (iii) to s.60A(1) |
| shift worker | 轮班工作者 | |
| Certificate for Accommodation | 住宿准证书 | Coined. Rejected 住宿证明 (reads as evidence, not permission). The whole Act 446 article turns on it being a prior permission |
| centralised accommodation provider | 集中式住宿供应商 | Statutory category under Act 446 |
| dormitory | 宿舍 | Reg 5 draws the in/out-of-dormitory line for floor area |
| person in charge (s.24L) | 负责人 | |
| notice of occupation | 入住呈报 | `Borang AC2` kept unchanged as a form name |
| compounding (s.28A) | 罚款和解 | |
| work pass | 工作准证 | Malaysian usage 准证, not 许可证 |
| Employment Pass / Professional Visit Pass / Dependant Pass / Investor Pass / Residence Pass-Talent / DE Rantau Nomad Pass / PLKS | unchanged | Pass names treated as scheme names per spec. Glossed inline where the master glosses them |
| expatriate | 外籍专才 | Malaysian Chinese press usage; distinct from 外劳 (foreign worker) already in the glossary |
| sponsor (of a pass) | 保荐人／保荐 | |
| portable (between employers) | 可携带／可在雇主之间携带 | RP-T's selling point; rendered descriptively |

| Long-Term Social Visit Pass (LTSVP) | Long-Term Social Visit Pass（LTSVP） | Kept English; no settled Malaysian Chinese rendering |
| sexual harassment | 性骚扰 | |

| Tribunal for Anti-Sexual Harassment / ASHA Tribunal | 仲裁庭 | Body name kept English on first use; 仲裁庭 thereafter. Rejected 法庭 — it is not a court, which is the article's central point |
| frivolous, vexatious or not made in good faith | 琐屑无聊、无理缠扰或并非出于善意 | s.81B(3) recital; standard Malaysian legal-drafting Chinese |
