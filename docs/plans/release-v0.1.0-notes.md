## NegaraKu.md v0.1.0 — first tagged release

NegaraKu.md is an open, AI-friendly knowledge base about Malaysia — **1,158 topics across 13 languages** (Bahasa Melayu, English, 中文, தமிழ், 日本語, 한국어, ไทย, Tiếng Việt, Bahasa Indonesia, العربية, हिन्दी, Español, Français), readable by both people and large language models, built with Astro and deployed to GitHub Pages at <https://negaraku.md>.

This first tagged release marks the point where the project **operates in the open** as a *stewarded open knowledge base*: open contribution with a mandatory editorial review gate (sources, neutrality, a hard gate on sensitive content, four-eyes) and a named steward. The review gate is the product — the public trust badges are only honest because it exists.

### What's in place
- **Governance & contribution:** `GOVERNANCE.md` (reader → contributor → reviewer → steward), `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md`, `ROADMAP.md`, `RELEASING.md`, and `CITATION.cff` for citing the project.
- **Open on-ramps:** good-first-issues, seeded Discussions, issue templates, and a non-developer contributor path on the site in every language.
- **Content pipeline:** every article carries cited sources, a review cadence, and a revision history; translations are freshness-tracked against their master.
- **Breadth:** a complete Industries of Malaysia atlas (46 sector guides) plus law, taxation, business, government, culture, geography, history, healthcare, education and daily-life coverage — each in all 13 languages.
- **AI-friendly distribution:** per-locale `llms.txt` / `llms-full.txt`, per-article Markdown endpoints, an MCP surface, rich structured data (incl. a `Dataset` node for Google Dataset Search), Wikidata entity links, and open dataset mirrors on [Hugging Face](https://huggingface.co/datasets/negaraku-md/negaraku-md) and Kaggle (CC BY-SA 4.0).
- **Search discovery:** indexed via Google, Bing, Naver and Yandex; change-pinged through IndexNow.
