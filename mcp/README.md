# negaraku.md MCP server

A [Model Context Protocol](https://modelcontextprotocol.io) server that exposes the negaraku.md
knowledge base to AI clients (Claude, editors, agents).

## Tools

- `search_articles(query, lang?)` — keyword search over titles and summaries.
- `read_article(slug, lang?)` — full Markdown of an article.
- `list_categories()` — the category taxonomy with counts.

## Setup

```bash
cd mcp
npm install
```

The server reads `../public/api/articles.json` (generated by `npm run sync` in the project root)
and the Markdown in `../knowledge/`. Make sure you've run a sync/build first.

## Wire it into a client

Add to your MCP client config (paths must be absolute):

```json
{
  "mcpServers": {
    "negaraku-md": {
      "command": "node",
      "args": ["/absolute/path/to/negaraku.md/mcp/server.mjs"]
    }
  }
}
```

Then ask your assistant to search or read Malaysia articles — e.g. *"search negaraku.md for nasi
lemak"* or *"read the kesultanan-melaka article"*.
